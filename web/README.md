# CadCraft: browser edition

CadCraft as plain files: put the folder on any web server and open it in your browser. No account, no install, nothing to build. Your files stay on your computer.

- **Get it:** `cadcraft-browser-edition-v0.6.0.zip` from [Releases](https://github.com/getcadcraft/cadcraft/releases) (checksum beside it). It unzips to a folder with an INSTALL.md that covers servers and updating.
- **Build it from a clone:** `node devshell/edition.mjs` ([BUILDING.md](../BUILDING.md#the-browser-edition)).
- **Use it now:** https://getcadcraft.com/use/cadcraft

On the desktop, CadCraft runs inside [CadCraft Studio](https://github.com/getcadcraft/studio).
