## የሚማሩት

ለትእዛዞች የራስዎን አጭር ስሞች እንዴት እንደሚጨምሩ፤ ለምሳሌ {{cmd:LINE}}ን `LL` ብሎ መጥራት፤ ሁሉም በአንድ የጽሑፍ ፋይል ውስጥ።

## ተለዋጭ ስም ጨምር

1. {{ui:View}} › {{ui:More}} › {{ui:Edit aliases…}} ይክፈቱ፤ ወይም {{cmd:ALIASEDIT}} ብለው ይጻፉ እና {{key:Enter}} ይጫኑ።
2. ተለዋጭ ስሙን፣ ኮማ እና ከኮከብ በኋላ ትእዛዙን የያዘ መስመር ይጨምሩ፦

```
LL,     *LINE
```

3. {{ui:Save}} ላይ ጠቅ ያድርጉ። የትእዛዝ መስመሩ ስንት ተለዋጭ ስሞችዎ በሥራ ላይ እንዳሉ ይነግርዎታል።
4. `LL` ብለው ይጻፉ እና {{key:Enter}} ይጫኑ፦ LINE ይጀምራል።

ተለዋጭ ስሞችዎ ከCadCraft የራሱ ላይ ይሆናሉ። የእርስዎ መስመር ከተመሳሳይ ስም ካለው አብሮ ከተሠራው ተለዋጭ ስም ያሸንፋል፤ የእርስዎን መስመር ካስወገዱ የተሠራው ይመለሳል።

## CadCraft የማይቀበላቸው መስመሮች

አርታኢው በሚጽፉበት ጊዜ እያንዳንዱን ችግር ከመስመሩ ቁጥር ጋር ይዘረዝራል፦

- ትእዛዙ የለም፤
- ተለዋጭ ስሙ ራሱ የትእዛዝ ስም ነው (`LINE, *CIRCLE` LINEን ይደብቃል)፤
- መስመሩ `ALIAS, *COMMAND` አይደለም፤
- ተመሳሳይ ተለዋጭ ስም በሁለት መስመሮች ላይ አለ (የኋለኛው ያሸንፋል)።

በኮምፒውተርዎ ላይ ፕሮግራም የሚጀምሩ መስመሮች፣ ለምሳሌ `NOTEPAD, START, 1, *File to edit: ,`፣ በማስታወሻ ይዘለላሉ፤ ምክንያቱም በአሳሽ ውስጥ ያለ መተግበሪያ ፕሮግራም መጀመር አይችልም።

## ተለዋጭ ስሞችዎን ከሌላ ፕሮግራም አምጡ

1. በተለዋጭ ስም አርታኢው ውስጥ {{ui:Import .pgp…}} ላይ ጠቅ ያድርጉ እና ፋይሉን ይምረጡ። `.pgp` ፋይል በንድፉ ላይም መጣል ይችላሉ።
2. የተዘረዘሩትን ችግሮች ያረጋግጡ (CadCraft የሌሉት ትእዛዞች አይቀበሉም፤ ቀሪዎቹ ይሠራሉ)።
3. {{ui:Save}} ላይ ጠቅ ያድርጉ።

{{ui:Export .pgp}} የCadCraft ተለዋጭ ስሞችንና የእርስዎን ተለዋጮች በአንድ ፋይል ውስጥ በተመሳሳይ ቅርጸት ያስቀምጣል።

## ፋይሉን እንደገና ጫን

{{cmd:REINIT}} ብለው ይጻፉ እና {{key:Enter}} ይጫኑ ተለዋጭ ስሞች ፋይልዎን እንደገና ለመተግበር። በዚህ አሳሽ ውስጥ ይቀመጣል፤ የዴስክቶፕ መተግበሪያው በራሱ አቃፊ ያስቀምጠዋል፤ የደመና አገልግሎቱ ደግሞ ያመሳስለዋል።

## ለማንኛውም ትእዛዝ የቁልፍ ሰሌዳ አቋራጮች

ተለዋጭ ስም የሚጻፍ ነው፤ አቋራጭ ግን ቁልፍ ነው። ለትእዛዝ የራስዎን ቁልፍ ለመስጠት፦

1. {{ui:View}} › {{ui:More}} › {{ui:Keyboard shortcuts…}} ላይ ጠቅ ያድርጉ፤ ወይም `KEYS` ብለው ይጻፉ እና {{key:Enter}} ይጫኑ።
2. የ{{ui:Key}} ሳጥኑን ጠቅ ያድርጉ እና ቁልፎቹን ይጫኑ፤ ለምሳሌ {{key:Alt+Shift+C}}።
3. በ{{ui:Runs}} ውስጥ ትእዛዙን ይጻፉ፤ ከፈለጉ ከዚያ በኋላ የሚጻፈውንም፦ `CIRCLE` ወይም `ZOOM E`።
4. {{ui:Add}} ላይ ጠቅ ያድርጉ።

ቁልፍ {{key:Mod}} ወይም {{key:Alt}} ከፊደል ወይም ከቁጥር ጋር፣ ወይም ነጻ የተግባር ቁልፍ ({{key:F2}}፣ {{key:F4}}፣ {{key:F5}}፣ {{key:F6}}፣ {{key:F9}}) ያስፈልገዋል። CadCraftን፣ መተግበሪያውን ወይም አሳሹን የሚጠቀሙባቸው ቁልፎች፣ እንዲሁም የ"የእኔ መሳሪያዎች" አዝራር ያለው ቁልፍ (ይመልከቱ፦ [የራስዎ አዝራሮች](topic:my-tools)) ይከለከላሉ፤ ሳጥኑም ምክንያቱን ይነግርዎታል። አቋራጮች በዚህ አሳሽ (ወይም በዴስክቶፕ መተግበሪያ) ይቀመጣሉ፤ {{ui:Remove}} አንዱን ያስወግዳል።
