አቋራጮች ለኮምፒውተርዎ ይታያሉ። በMac ላይ እያንዳንዱ {{key:Mod}} አቋራጭ Command ቁልፉን ይጠቀማል፤ Control ቁልፉም ይሰራል። ቁልፎች እንዴት እንደሚጻፉና በMac ላይ F ቁልፎችን እንዴት እንደሚጠቀሙ በ[ቁልፎች፣ አይጦችና ትራክፓዶች](common:keys) ውስጥ ነው።

| {{key:Enter}} | የጻፉትን ይልካል። ባዶ ጥያቄ ላይ፦ የመጨረሻውን ትዕዛዝ ይደግማል፣ ትዕዛዝን ያበቃል፣ ምርጫን ይጨርሳል፣ ወይም በ`<…>` ውስጥ ያለውን ነባሪ ይቀበላል |
| {{key:Space}} | ከ{{key:Enter}} ጋር ተመሳሳይ፣ CadCraft ጽሑፍ ሲጠይቅ (ጽሑፍ፣ የብሎክ ስሞች፣ የልኬት ጽሑፍ) ካልሆነ በስተቀር፤ እዚያ ክፍተት ይጽፋል |
| {{key:Esc}} | ትዕዛዙን ይሰርዛል። ምንም ትዕዛዝ ካልሰራ፦ የመያዣ እንቅስቃሴን ወይም የምርጫ ሳጥንን ይሰርዛል፣ ከዚያም ምርጫውን ያጸዳል |
| {{key:Tab}} | ከትዕዛዝ መስመሩ ቀኝ የሚታየውን የተጠቆመ ትዕዛዝ ይቀበላል። ምንም ካልተጻፈና ጠቋሚው በተደራረቡ ነገሮች ላይ ከሆነ፦ የሚቀጥለውን ነገር ያደምቃል (ለመምረጥ ይንኩ) |
| {{key:Up}} {{key:Down}} | ከዚህ በፊት የጻፏቸውን መስመሮች ይቃኛል (የመጨረሻዎቹ 100) |

| {{key:Delete}} | የተመረጡ ነገሮችን ይሰርዛል ({{cmd:ERASE}})፣ በትዕዛዝ መስመሩ ምንም ካልጻፉ በስተቀር |
| {{key:Backspace}} | ትዕዛዝ መስመሩ ጠቋሚ ከሌለው የተመረጡ ነገሮችን ይሰርዛል፤ በትዕዛዝ መስመሩ ላይ የጻፉትን ይሰርዛል |
| {{key:Esc}} | ምንም ትዕዛዝ ካልሰራ፦ ምርጫውን ያጸዳል ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | በንድፉ ቅርጸት (DWG ወይም DXF) ቅጂ ያስቀምጣል |
| {{key:Mod+Shift+S}} | እንደ አስቀምጥ፦ DWG ወይም DXF ይምረጡ፣ ከዚያ ቅጂ ያስቀምጡ |
| {{key:Mod+O}} | DWG ወይም DXF ይከፍታል |

## መቅዳት፣ መቁረጥና መለጠፍ

| ቁልፍ | ምን ያደርጋል |
|---|---|

| {{key:Mod+X}} | ቁረጥ፦ ምርጫውን ይገለብጣል፣ ከዚያ ይሰርዛል ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | ለጥፍ፦ ቅጂው ጠቋሚውን ይከተላል፤ ለማስቀመጥ ይንኩ፣ ወይም ነጥብ ይጻፉ ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | በቦታው ለጥፍ፦ ከተገለበጠበት መጋጠሚያ ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | ቅጂ ፍጠር፦ የምርጫው ቅጂ ከጠቋሚው ጋር ይንቀሳቀሳል፤ ለማስቀመጥ ይንኩ፣ {{key:Esc}} ምንም አይተውም ({{cmd:DUPLICATE}}) |

እነዚህ እርምጃዎች በመሣሪያ አሞሌው {{ui:አርትዕ}} ቡድን ({{ui:ቅዳ}}, {{ui:ለጥፍ}}) እና በ{{ui:ተጨማሪ}} ምናሌ ውስጥም አሉ። ሌላ ትዕዛዝ እየሰራ ሳለ መጀመሪያ ይጨርሱት ወይም {{key:Esc}} ይጫኑ፤ ቅጂው ጠቋሚውን እየተከተለ ሳለ {{key:Mod+V}} ወይም {{key:Mod+D}} እንደገና ቢጫኑ ከመጀመሪያ ይጀምራል። በትዕዛዝ መስመሩ ጽሑፍ ጽፈው ወይም ትዕዛዙ ጽሑፍ ሲጠይቅ እነዚህ ቁልፎች ያንን ጽሑፍ ይገለብጣሉ፣ ይቆርጣሉና ይለጥፋሉ። [ቅዳ፣ ለጥፍና ቅጂ ፍጠር](topic:copy-paste) ይመልከቱ።
