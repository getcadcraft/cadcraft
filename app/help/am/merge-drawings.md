ሁለት ሰዎች አንድ ንድፍ ያስተካክላሉ። የተለያዩ ነገሮችን ከቀየሩ፣ ማዋሃዱ በራስ-ሰር ሊሆን ይችላል፦ በእጅ የሚደገም ነገር የለም።

## ይህን የሚያሰራው

CadCraft የሚስሉት እያንዳንዱ ነገር አጭር **ቁልፍ** ይሰጠዋል፣ ይህ ፈጽሞ የማይለወጥ እና ለሁለት ነገሮች ፈጽሞ የማይሰጥ ነው። ከነገሩ ጋር በDWG ወይም DXF ውስጥ ይቀመጣል (ሌሎች ፕሮግራሞች የሚይዙት ተጨማሪ መረጃ ሆኖ)። ማዋሃዱ ነገሮችን በዚያ ቁልፍ ይፈልጋል፣ በፋይሉ ውስጥ ባለው ቦታ አይደለም፣ ምክንያቱም ሁሉም ፕሮግራሞች ሲያስቀምጡ ቦታዎችን እንደገና ይቆጥራሉ። በፍጹም ካላዋሃዱ በ{{ui:ቅንብሮች}} › CadCraft › ለማዋሃድ ምቹ ፋይሎች ውስጥ ያጥፉት፤ ፋይሎቹ 10 በመቶ ያህል ያንሳሉ።

ቁልፎች ከመኖራቸው በፊት የተቀመጠ ንድፍ አሁንም ይዋሃዳል፦ ነገሮቹ ቁልፍ የሚያገኙት በፋይሉ ውስጥ ካላቸው ቦታ ነው፣ ይህም ለሚከፍቱት ሁሉ ተመሳሳይ ነው።

## ማዘጋጀት

Git ለእያንዳንዱ ማከማቻ አንዴ ሁለት መስመሮች ያስፈልጉታል፦

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# አንዴ፣ በእያንዳንዱ ኮምፒውተር ላይ
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

git ከሌለ በእጅ ያስኬዱት፦ `cadcraft merge <base> <ours> <theirs> -o <result>`። Fossil እና Mercurial ተመሳሳዩን ሦስት ፋይሎች በየራሳቸው የማዋሃጃ-መሣሪያ ቅንብር ይወስዳሉ።

## ደንቦቹ

- በአንድ ወገን ብቻ የተለወጠ ነገር ይወሰዳል። በሁለቱም ወገኖች ተመሳሳይ ለውጥ አንድ ጊዜ ይወሰዳል።
- ተመሳሳይ ባህሪ በሁለት መንገድ ከተለወጠ **ግጭት** ነው፦ የእርስዎ ወገን ይቀራል እና ሪፖርቱ ሁለቱንም እሴቶች ይዘረዝራል። ውጤቱን ይክፈቱ፣ ያንን ነገር ይመልከቱ፣ በእጅ ያስተካክሉት።
- በየትኛውም ወገን የተጨመረ ነገር ይቀራል። በአንድ ወገን የተወገደና በሌላኛው ያልተነካ ነገር ይወገዳል። በአንድ ወገን የተወገደና በሌላኛው የተለወጠ፦ ይወገዳል እና ሪፖርት ይደረጋል።
- ንብርብሮች፣ ብሎኮች፣ ጽሑፍና የልኬት ዘይቤዎች፣ ሉሆችና የተሰየሙ እይታዎች በተመሳሳይ መንገድ ይዋሃዳሉ። ገደቦች የሚጠቅሷቸውን ነገሮች ይከተላሉ።
- ውጤቱ ከእርስዎ ጋር በተመሳሳይ የፋይል ቅርጸትና ስሪት ይጻፋል።

የማይዋሃድ፦ ነገሮች የሚሳሉበት ቅደም ተከተል የእርስዎ ነው፣ ከዚያም የሌላው ወገን የጨመራቸው ነገሮች። በሁለቱም ወገኖች በተመሳሳይ የብሎክ ትርጉም ላይ የተደረጉ ለውጦች ግጭት ናቸው፣ በፍጹም አይደባለቁም። ምንም አይሰቀልም፤ ሁሉም በኮምፒውተርዎ ላይ ይሰራል።
