Digite o nome curto (o alias) e pressione Enter, ou clique na ferramenta. Esc cancela. Enter em uma linha vazia repete o último comando.

**Imprima:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (uma página A4; em papel Carta, imprima com "ajustar à página").

## Desenhar

| Digite | Comando | O que faz |
|---|---|---|
| `L` | {{cmd:LINE}} | Desenha linhas retas |
| `PL` | {{cmd:PLINE}} | Desenha uma cadeia conectada de linhas e arcos |
| `C` | {{cmd:CIRCLE}} | Desenha um círculo (centro e raio) |
| `A` | {{cmd:ARC}} | Desenha um arco |
| `REC` | {{cmd:RECTANG}} | Desenha um retângulo a partir de dois cantos |
| `POL` | {{cmd:POLYGON}} | Desenha um polígono regular |
| `EL` | {{cmd:ELLIPSE}} | Desenha uma elipse |
| `DT` | {{cmd:TEXT}} | Escreve uma linha de texto |
| `T` | {{cmd:MTEXT}} | Escreve um texto com quebra de linha (parágrafo) |
| `H` | {{cmd:HATCH}} | Preenche uma área com um padrão |

## Modificar

| Digite | Comando | O que faz |
|---|---|---|
| `M` | {{cmd:MOVE}} | Move objetos |
| `CO` | {{cmd:COPY}} | Copia objetos |
| `RO` | {{cmd:ROTATE}} | Gira objetos em torno de um ponto |
| `SC` | {{cmd:SCALE}} | Aumenta ou diminui objetos |
| `MI` | {{cmd:MIRROR}} | Espelha objetos em relação a uma linha |
| `O` | {{cmd:OFFSET}} | Desenha uma cópia paralela a uma distância |
| `TR` | {{cmd:TRIM}} | Apara objetos até onde outros os cruzam |
| `EX` | {{cmd:EXTEND}} | Alonga objetos até outros |
| `F` | {{cmd:FILLET}} | Arredonda um canto com um arco |
| `CHA` | {{cmd:CHAMFER}} | Corta um canto com uma aresta reta |
| `E` | {{cmd:ERASE}} | Apaga objetos |
| `X` | {{cmd:EXPLODE}} | Separa um bloco ou polilinha em suas partes |
| `S` | {{cmd:STRETCH}} | Move as extremidades dentro de uma janela de cruzamento |
| `AR` | {{cmd:ARRAY}} | Copia em grade ou em círculo |
| `J` | {{cmd:JOIN}} | Une linhas e arcos em um só objeto |
| `BR` | {{cmd:BREAK}} | Divide um objeto em dois, ou retira um pedaço |

## Cotar

| Digite | Comando | O que faz |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Cota na horizontal ou na vertical |
| `DAL` | {{cmd:DIMALIGNED}} | Cota ao longo de uma linha inclinada |
| `DRA` | {{cmd:DIMRADIUS}} | Cota um raio |
| `DAN` | {{cmd:DIMANGULAR}} | Cota um ângulo |

## Blocos e camadas

| Digite | Comando | O que faz |
|---|---|---|
| `B` | {{cmd:BLOCK}} | Cria um bloco a partir de objetos |
| `I` | {{cmd:INSERT}} | Coloca um bloco |
| `LA` | {{cmd:LAYER}} | Abre as camadas |

## Vista e consulta

| Digite | Comando | O que faz |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | Aproxima, afasta ou mostra tudo (E) |
| `DI` | {{cmd:DIST}} | Mede uma distância e um ângulo |
| `LI` | {{cmd:LIST}} | Mostra os detalhes de um objeto |
| `MA` | {{cmd:MATCHPROP}} | Copia a aparência de um objeto para outros |

## Arquivo

| Digite | Comando | O que faz |
|---|---|---|
| `U` | {{cmd:UNDO}} | Desfaz o último comando |
| `SAVE` | {{cmd:SAVE}} | Salva o desenho |
| `PLOT` | {{cmd:PLOT}} | Plota em PDF |

## Teclas

Ctrl (Cmd no Mac): Z desfazer · Y refazer · S salvar · P plotar.  F3 snap de objeto · F8 orto · F10 polar.  Espaço ou Enter repete o último comando · a roda dá zoom · arrastar a roda faz pan

Novo no desenho técnico? Digite `TOUR` para um primeiro desenho guiado, leia [Primeiros passos](topic:getting-started) ou veja todos os comandos em [Comandos](topic:commands). Vindo de outro programa de desenho: [Quem vem de outro programa de desenho](topic:coming-from) e o [mapa de comandos](topic:command-map).
