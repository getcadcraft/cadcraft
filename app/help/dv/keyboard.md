ޝޯޓްކަޓްތައް ކަލޭގެ ކޮމްޕިއުޓަރަށް ފަދަ ގޮތުން ދައްކާ. މެކްގައި ކޮންމެ {{key:Mod}} ޝޯޓްކަޓެއް Command ކީ ބޭނުން ކުރޭ، އަދި Control ކީ ވެސް މަސައްކަތް ކުރޭ. ކީތައް ލިޔޭ ގޮތާއި، މެކުގައި F-ކީތައް ބޭނުން ކުރާ ގޮތް [ކީތައް، މައުސް އަދި ޓްރެކްޕެޑް](common:keys) ގައި ވޭ.

## ކޮމާންޑް ޓައިޕްކުރުން

| ކީ | ކުރާ ކަން |
|---|---|
| ކޮންމެ އަކުރެއް، އަދަދެއް ނުވަތަ ސިމްބަލް | ކޮމާންޑް ލައިނަށް ދާ، މައުސް ކޮހެއްކަމުގައި ހުރިޔަސް، ޕެނަލްގެ ބޮކްސެއްގައި ކަރްސަރ ނުހުރިނަމަ |
| {{key:Enter}} | ލިޔެފައިވާ ކަން ފޮނުވޭ. ހުސް ޕްރޮމްޕްޓެއްގައި: އެންމެ ފަހު ކޮމާންޑް ހަދާ، ކޮމާންޑް ނިންމާ، ޚިޔާރު ނިންމާ، ނުވަތަ `<…>` ގައި ހުރި ޑިފޯލްޓް ޤަބޫލު ކުރޭ |
| {{key:Space}} | {{key:Enter}} ފަދައި، ނަމަވެސް CadCraft ލިޔުން (ލިޔުން، ބްލޮކް ނަންތައް، ޑައިމެންޝަން ލިޔުން) ހޯދާ ވަގުތު ސްޕޭސް ލިޔޭ |
| {{key:Esc}} | ކޮމާންޑް ބާޠިލު ކުރޭ. ކޮމާންޑެއް ހިނގަމުން ނެތްއިރު: ގްރިޕް ހިއްލުން ނުވަތަ ޚިޔާރު ބޮކްސް ބާޠިލު ކޮށް، ދެން ޚިޔާރު ފޮހެލާ |
| {{key:Tab}} | ކޮމާންޑް ލައިނުގެ ކަނާރައިން ދައްކާ ކޮމާންޑް ޤަބޫލު ކުރޭ. އެއްވެސް ކަމެއް ނުލިޔާ، ފޮއިންޓަރ އޮވަރލެޕް ޝޭޕްތަކުގެ މަތީގައި ހުރިއިރު: އެ ތަނުގެ އެންމެ ފަހު ހުރި އެއް ހައިލައިޓް ކުރޭ (ނެގުމަށް ކްލިކް ކުރޭ) |
| {{key:Up}} {{key:Down}} | ކުރީގެ ލިޔެފައިވާ ލައިންތައް ބަލާ (އެންމެ ފަހު 100) |

## ޑްރޯއިންގާއި އެޑިޓް

| ކީ | ކުރާ ކަން |
|---|---|
| {{key:Mod+Z}} | އެންމެ ފަހު ކޮމާންޑް އަންޑޫ ކުރޭ |
| {{key:Mod+Y}} ނުވަތަ {{key:Mod+Shift+Z}} | އަލުން ކުރޭ |
| {{key:Mod+A}} | ހުޅުވާފައިވާ ޓެބުގައި ކަމުން ބަދަލުކުރެވޭ ހުރިހާ އޮބްޖެކްޓް ޚިޔާރު ކުރޭ ({{cmd:SELECTALL}}). ކޮމާންޑް ލައިނުގައި ލިޔުމެއް ލިޔާފައިވާނަމަ އެ ލިޔުން ޚިޔާރު ކުރޭ |
| {{key:Delete}} | ޚިޔާރުކުރެވުނު އޮބްޖެކްޓް ފޮހެލާ ({{cmd:ERASE}})، ކޮމާންޑް ލައިނުގައި ކަމެއް ލިޔާފައިނުވާނަމަ |
| {{key:Backspace}} | ކޮމާންޑް ލައިނަށް ކަރްސަރ ނުހުރިއިރު ޚިޔާރުކުރެވުނު އޮބްޖެކްޓް ފޮހެލާ؛ ކޮމާންޑް ލައިނުގައި ލިޔާފައިވާ ކަން ފޮހެލާ |
| {{key:Esc}} | ކޮމާންޑެއް ހިނގަމުން ނެތްއިރު: ޚިޔާރު ފޮހެލާ ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | ޑްރޯއިންގުގެ ފޯމެޓުގައި (DWG ނުވަތަ DXF) ކޮޕީއެއް ރައްކާ ކުރޭ |
| {{key:Mod+Shift+S}} | އެހެން ނަމަކުން ރައްކާ ކުރޭ: DWG ނުވަތަ DXF ޚިޔާރު ކޮށް، ދެން ކޮޕީ ރައްކާ ކުރޭ |
| {{key:Mod+O}} | DWG ނުވަތަ DXF ހުޅުވާ |
| {{key:Mod+P}} | PDF އަށް ޕްލޮޓް ކުރޭ |

ކޮމާންޑެއް ހިނގަމުންދާއިރު އަންޑޫ، އަލުން ކުރުން، ހުރިހާ އެއްޗެއް ޚިޔާރު ކުރުން އަދި ޕްލޮޓް އެއްވެސް ކަމެއް ނުކުރޭ: ފުރަތަމަ {{key:Esc}} ޕްރެސް ކުރޭ.

## ކޮޕީ، ކަޓް އަދި ޕޭސްޓް

| ކީ | ކުރާ ކަން |
|---|---|
| {{key:Mod+C}} | ޚިޔާރުކުރެވުނު އެއްޗެއް ކްލިޕްބޯޑަށް ކޮޕީ ކުރޭ ({{cmd:COPYCLIP}}). އެއްވެސް ކަމެއް ނޭ ޚިޔާރުކޮށް: CadCraft އޮބްޖެކްޓް ހޯދޭ |
| {{key:Mod+X}} | ކަޓް: ޚިޔާރުކުރެވުނު ކޮޕީ ކުރޭ، ދެން ފޮހެލާ ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | ޕޭސްޓް: ކޮޕީ ކަރްސަރާ އެކު ދަނީ؛ ކްލިކް ކުރޭ، ނުވަތަ ނުކުތާ ޓައިޕްކުރޭ، ބަހައްޓުމަށް ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | ތަނުން ޕޭސްޓް: ކޮޕީ ކުރެވުނު ތަނުގެ ކޯޑިނޭޓްތަކަށް ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | ޑުޕްލިކޭޓް: ޚިޔާރުކުރެވުނު ކޮޕީއެއް ފޮއިންޓަރާއެކު ހިއްލޭ؛ ކްލިކް ކޮށް ބަހައްޓާ، {{key:Esc}} ން އެއްވެސް ކަމެއް ނުބާއްވޭ ({{cmd:DUPLICATE}}) |

އެ އަމަލުތައް ޓޫލްބާރުގެ {{ui:Edit}} ގްރޫޕުގައި ({{ui:Copy}}، {{ui:Paste}}) އަދި އޭގެ {{ui:More}} މެނޫގައި ވެސް ވޭ. އެހެން ކޮމާންޑެއް ހިނގަމުންދާއިރު، އެ ނިންމާ ނުވަތަ ފުރަތަމަ {{key:Esc}} ޕްރެސް ކުރޭ؛ ކޮޕީއެއް ކަރްސަރާ އެކު ދާއިރު {{key:Mod+V}} ނުވަތަ {{key:Mod+D}} އަލުން ޕްރެސް ކުރުމުން ފެށިގެން ދެއެވެ. ކޮމާންޑް ލައިނުގައި ލިޔުމެއް ލިޔާފައިވާނަމަ ނުވަތަ ކޮމާންޑެއް ލިޔުމެއް ހޯދާއިރު، މި ކީތައް އެ ލިޔުން ކޮޕީ، ކަޓް އަދި ޕޭސްޓް ކުރޭ. [ކޮޕީ، ޕޭސްޓް އަދި ޑުޕްލިކޭޓް](topic:copy-paste) ބެލޭ.

## ޓޮގަލްތައް

| ކީ | ޓޮގަލް | ސްޓޭޓަސް ބާރުގެ ބަޓަން |
|---|---|---|
| {{key:F3}} | އޮބްޖެކްޓް ސްނެޕް އޮން ނުވަތަ އޮފް | {{ui:Snap}} |
| {{key:F7}} | ގްރިޑް އޮން ނުވަތަ އޮފް | {{ui:Grid}} |
| {{key:F8}} | އޯތޯ އޮން ނުވަތަ އޮފް | {{ui:Ortho}} |
| {{key:F10}} | Polar ޓްރެކިންގ އޮން ނުވަތަ އޮފް | {{ui:Polar}} |
| {{key:F11}} | އޮބްޖެކްޓް ސްނެޕް ޓްރެކިންގ އޮން ނުވަތަ އޮފް | {{ui:Track}} |
| {{key:F12}} | ޑައިނެމިކް އިންޕުޓް އޮން ނުވަތަ އޮފް | {{ui:Dyn}} |

:::mac
މެކުގައި F3، F7 އަދި F8 އާދައިން Mission Control އަދި މީޑިއާ ކީތައް. ކަލޭ އެ ކީތައް **fn** އާއެކު ހިފާ، ނުވަތަ System Settings ގައި ސްޓޭންޑަރޑް ފަންކްޝަން ކީތައް އޮން ކުރޭ، [ކީތައް، މައުސް އަދި ޓްރެކްޕެޑް](common:keys) ގައި ބުނެވިފައިވާ ގޮތުން. ސްޓޭޓަސް ބާރުގެ ބަޓަންތައް ހުރިހާ ވަގުތެއްގައި މަސައްކަތް ކުރޭ.
:::

:::firefox
Firefox ގައި F7 ން ކާރެޓް ބްރައުޒިންގ އޮން ކުރުމަށް ސުވާލު ކުރެވޭނެ. **ނޫން** ޚިޔާރު ކުރޭ، އަދި އެ ސުވާލު ކުރުން ނިމޭކަށް ނޫނަމަ {{ui:Grid}} ބަޓަން ބޭނުން ކުރޭ.
:::

## ހެލްޕް

| ކީ | ކުރާ ކަން |
|---|---|
| {{key:F1}} | މި ހެލްޕް ޑްރޯއިންގުގެ ކައިރީގައި ހުޅުވާ ނުވަތަ ބަންދު ކުރޭ. ކޮމާންޑެއް ހިނގަމުންވެސް މަސައްކަތް ކުރޭ، އަދި ކޮމާންޑް ލައިނަށް ދާކަމެއް ނޫން. |
| {{key:Esc}} | ހެލްޕް ޕެނަލުގައި ކަރްސަރ ހުރިއިރު: ސަރޗް ފޮހެލާ، ނުވަތަ ޕެނަލް ބަންދު ކުރޭ |

މަތީ ބާރުގެ {{ui:Help}} ބަޓަން {{key:F1}} ފަދައިން ކުރޭ. ހެލްޕްގެ ސަރޗް ބޮކްސްގައި ލިޔުމެއް ލިޔާއިރު އެއްވެސް ކަމެއް ކޮމާންޑް ލައިނަށް ނުދޭ. ކީތައް CadCraft އަށް ދިނުމަށް ޑްރޯއިންގުގައި ކްލިކް ކުރޭ؛ ޕެނަލް އެތަނުގެ ކައިރީގައި ހުޅުވިފައި ހުންނާނެ.

:::mac
މެކް ކީބޯޑުގައި **fn** ހިފާ F1 ޕްރެސް ކުރޭ، ނުވަތަ {{ui:Help}} ކްލިކް ކުރޭ.
:::

| {{key:Ctrl+Shift+F}} | ނޯމަލް، ފުލް ސްކްރީން، އަދި ބާރު ހިއްކިފައި ފުލް ސްކްރީން ދައުރުކުރޭ. މި ކީ ކޮންމެ ކޮމްޕިއުޓަރެއްގައިވެސް Control ކީ ބޭނުން ކުރޭ، މެކްވެސް ހިމެނޭ. |
| {{key:Left}} {{key:Right}} | ޑްރޯއިންގުގެ ދަށުގައިވާ ޓެބެއް ފޯކަސްވެފައިވާއިރު: ކުރީގެ ނުވަތަ އަނެއް ޓެބް |

ފުލް ސްކްރީން ގައި، ބްރައުޒަރ ފުރަތަމަ {{key:Esc}} އިން ފުލް ސްކްރީން ދޫކުރެވޭ. ކޮމާންޑް ބާޠިލު ކުރުމަށް {{key:Esc}} އަލުން ޕްރެސް ކުރޭ.

## ޑައިލޮގްތައް

ޑައިލޮގެއް ހުޅުވާއިރު، ޑްރޯއިންގުގެ ކީތައް ކުރެވޭކަށް ނުވޭ.

## ޕެނަލް ފީލްޑްތައް

ރައިޓް ނުވަތަ ލެފްޓް ޕެނަލުގެ ބޮކްސެއްގައި:

| ކީ | ކުރާ ކަން |
|---|---|
| {{key:Enter}} | އަގު ގަދަކޮށް ބޮކްސުން ނިކުމޭ |
| {{key:Esc}} | ފަހަތަށް ހުރި އަގު ގެނެސް ބޮކްސުން ނިކުމޭ |
| {{key:Tab}} | އަގު ގަދަކޮށް އެއް ބޮކްސަށް ދާ |

ބޮކްސެއްގައި ކަރްސަރ ހުރިއިރު، އަކުރުތައް އެތަނަށް ލިޔޭ، ކޮމާންޑް ލައިނަށް ނޫން.

## ބްރައުޒަރ ކީތައް

{{key:Mod+N}}، {{key:Mod+W}} އަދި {{key:Mod+T}} އަބަދުވެސް ބްރައުޒަރގެ ކަމެކެވެ. CadCraft އެ ކީތައް ބޭނުން ނުކުރޭ: އާ ޑްރޯއިންގަކަށް {{ui:New}} ބޭނުން ކުރޭ ނުވަތަ `NEW` ޓައިޕްކުރޭ. CadCraft ގެ ކްލިޕްބޯޑް އަމިއްލަ އެކެވެ: {{key:Mod+C}} އަދި {{key:Mod+V}} އެއް CadCraft ޑްރޯއިންގުތަކާއި ޓެބުތަކާ ދެމެދު އޮބްޖެކްޓް ކޮޕީ ކުރޭ، އެހެން ޕްރޮގްރާމްތަކާ ދެމެދު ނޫން.

## Move ހުރި ތަން

Move ކަމަށް `MOVE` ކޮމާންޑް ({{key:M}} ކީ): އޮބްޖެކްޓްތައް ޚިޔާރު ކޮށް، ދެން ބޭސް ނުކުތާ އަދި ދެވަނަ ނުކުތާ ނުވަތަ ޓައިޕްކުރެވުނު މިން. `ALIGN` އަދި `DISTRIBUTE` ވެސް އެތަނުގައި ވޭ. BimCraft ކަމަށް އެއް ނަން އެއް ކަމަށް ބޭނުން ކުރޭ، ނަމަވެސް އޭގެ {{key:M}} ން މިން ނެގުން އެވެ: އޭގެ Move ނަމަ {{key:Shift+M}} އެވެ.
