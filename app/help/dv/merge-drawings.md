ދެ މީހަކު އެއް ޑްރޯއިންގް އެޑިޓް ކުރެވެއެވެ. އެމީހުން ވަކި އެއްޗެހި ބަދަލުކުރެއްވިނަމަ، ޖޯޑުކުރުން އޮޓޮމެޓިކް ވެދާނެ: އަތުން އަލުން ކުރަން އެއްވެސް ކަމެއް ނެތް.

## އެއީ މަސައްކަތް ކުރާ ގޮތް

CadCraft ތިބާ ޑްރޯކުރާ ކޮންމެ އޮބްޖެކްޓަކަށް ކުރު **ކީ** އެއް ދެއެވެ، އެއީ ކޮންދަތުރުވެސް ނުބަދަލުވޭ އަދި ދެ އޮބްޖެކްޓަކަށް ދެވެނީ ނުވޭ. އެއީ އޮބްޖެކްޓާއެކު DWG ނުވަތަ DXF ގައި ސޭވްވޭ (އެހެން ޕްރޮގްރާމްތައް ރައްކާ ކުރާ އިތުރު ޑޭޓާ ގޮތުގައި). ޖޯޑުކުރުން އޮބްޖެކްޓް ހޯދާނީ އެ ކީން، ފައިލުގެ ތަނުން ނޫން، ސަބަބަކީ ކޮންމެ ޕްރޮގްރާމެއް ސޭވްކުރާއިރު ތަންތަން އަލުން ނަންބަރު ކުރާތީއެވެ. ތިބާ ކޮންދަތުރުވެސް ޖޯޑު ނުކުރާ ނަމަ {{ui:ސެޓިންގްސް}} › CadCraft › ޖޯޑުކުރުމަށް ފަހަލާ ފައިލް ތަކުން މިން ކުރޭ؛ ފައިލްތައް 10 ޕަސެންޓް ފަދަ ކުޑަވޭ.

ކީ ހުރުމުގެ ކުރިން ސޭވްވެފައިވާ ޑްރޯއިންގ އަދިވެސް ޖޯޑުކުރޭ: އޭގެ އޮބްޖެކްޓްތަކަށް ފައިލްގެ ތަނުން ކީއެއް ލިބޭ، ހުޅުވާ ހުރިހާ މީހަކަށް އެއްގޮތް.

## ސެޓަޕް ކުރޭ

Git އަށް ރިޕޮޒިޓަރީއަކަށް ދެ ލައިން އެއްފަހަރު ބޭނުންވޭ:

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# އެއްފަހަރު، ކޮންމެ ކޮމްޕިއުޓަރެއްގައި
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git ނެތިފަ، އެ އަތުން ހިންގާ: `cadcraft merge <base> <ours> <theirs> -o <result>`. Fossil އަދި Mercurial ގެ އަމިއްލަ merge-tool ސެޓިންގުގައި އެ ތިން ފައިލް ހަމަ ގަންނާނެ.

## ގާއިދުތައް

- އެއް ފަރާތުން ބަދަލު ކުރެވުނު އޮބްޖެކްޓް ނަގާނެ. ދެފަރާތުން އެއް ބަދަލެއް ކުރެވިއްޖެނަމަ އެކްމެ އެއްފަހަރު ނަގާނެ.
- އެއް ޚާއްޞަ ގުނައެއް ދެ ގޮތަކަށް ބަދަލުވާއިރު **ކޮންފްލިކްޓް** އެވެ: ތިބާގެ ފަރާތް ހުންނާނެ އަދި ރިޕޯޓުން ދެ އަގު ދައްކާނެ. ނަތީޖާ ހުޅުވާ، އޭ އޮބްޖެކްޓް ބަލާ، އަތުން ރަނގަޅު ކުރޭ.
- ދެ ފަރާތުގެ އެއްވެސް ފަރާތުން އިތުރު ކުރެވުނު އޮބްޖެކްޓް ރައްކާ ކުރެވޭ. އެއް ފަރާތުން ފޮހެލި އަދި އަނެއް ފަރާތުގައި ނުބަދަލުވި އޮބްޖެކްޓް ފޮހެލޭ. އެއް ފަރާތުން ފޮހެލި އަދި އަނެއް ފަރާތުން ބަދަލު ކުރެވުނު: ފޮހެލާ، އަދި ރިޕޯޓުވޭ.
- ލޭޔަރު، ބްލޮކް، ލިޔުން އަދި ޑައިމެންޝަން ސްޓައިލް، ޝީޓް އަދި ނަމުންނާ ވިއުތައް އެ ގޮތުން ޖޯޑުވޭ. ކޮންސްޓްރެއިންޓްތައް ނަމަކުރާ އޮބްޖެކްޓްތައް ފޮލޯކުރޭ.
- ނަތީޖާ ލިޔެވޭ ތިބާގެ ފައިލްގެ ފޯމެޓް އަދި ވާރޝަންއާ އެއްގޮތަށް.

ޖޯޑުނުވާ: އޮބްޖެކްޓްތައް ޑްރޯކުރާ ތަރުތީބަކީ ތިބާގެ ޙައްޤެވެ، ދެން އަނެއް ފަރާތުގެ އިތުރު ކުރި އޮބްޖެކްޓްތައް. ދެ ފަރާތުގައި އެއް ބްލޮކް ތަޢުރީފުގެ ބަދަލުތަކަކީ ކޮންފްލިކްޓެވެ، ފަހުން އެއްކޮށް ނުކުރެވޭ. އެއްވެސް ކަމެއް އަޕްލޯޑު ނުކުރެވޭ؛ ހުރިހާ އެއްކަން ކޮމްޕިއުޓަރުގައި ހިނގޭ.
