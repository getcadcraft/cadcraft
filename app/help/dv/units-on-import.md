## ކުރާ ކަން

ފައިލެއް ޑްރޯއިންގަށް ގެނެސް، ސައްޙަ ސައިޒުން އެ ގެނެވޭކަށް ޔަޤީން ކުރޭ.

## ގަދަމަސް

1. ފައިލް އާދަތުން ގެނެސް: `INSERT` › File، `XATTACH`، `POINTCLOUDATTACH`، ނުވަތަ Library ޕެނެލުގެ {{ui:Files}}.
2. ފައިލް އޭގެ ޔުނިޓްތައް ބުނެއްޖެނަމަ، އެއްވެސް ސުވާލެއް ނުކުރެވޭ. ކޮމާންޑް ލައިނުން ފައިލް ކޮން ޔުނިޓް ބުނޭ، އަދި ޑްރޯއިންގާ ނުއެއްވާނަމަ އެ ސްކޭލް ފެންނާނެއެވެ.
3. ނުބުނެއްޖެނަމަ، ޑައިލޮގ ސުވާލު ކުރޭ **Units of** ފައިލަށް. ފައިލްގައި އެއް ޔުނިޓަކީ ކޮން ޔުނިޓެއް ހޮވޭ އަދި {{ui:Use these units}} ކްލިކް ކުރޭ. ޖަވާބު ނުދިން ކުރީން ކުރެއްވެސް ކަމެއް ބަހައްޓާނުވެއެވެ.
4. {{ui:Cancel}} (ނުވަތަ {{key:Esc}}) ކަމެއް ނުގެނެސް.

## ކޮބައިގެ ފައިލްތައް ޔުނިޓް ބުނެއެވެ

- **DWG އަދި DXF**: ޑްރޯއިންގުގެ އިންސާޓު ޔުނިޓްސް (`$INSUNITS`). ގެން ނުވާ ފައިލަކު ސުވާލު ކުރެވޭ.
- **Point clouds**: LAS އަދި LAZ ކޯޑިނޭޓް ސިސްޓަމާއެކު، E57، PTX އަދި PLY އެމީހުންގެ ޔުނިޓް ބުނެއެވެ. އެހެން ޑެޓާތައް ސުވާލު ކުރެވޭ.
- **OBJ**: ޔުނިޓް ކަމަށް ނުބުނޭ. ސުވާލު ކުރެވޭ.
- **glTF އަދި GLB**: މީޓަރު، ފޯމެޓުގެ އަމިއްލަ ގަވާއިދަށް ބަޔަށް.
- **ފޮޓޯތައް**: އެމީހުންގެ އަމިއްލަ ސައިޒެއް ނެތް. `IMAGEATTACH` ފުޅާމިން ސުވާލު ކުރޭ، އަދި ކުރީން ކުރި އަނގައި ދޭ.
- **ސްކޭންތައް**: އެ ސްކޭން އޭގެ ޑެންސިޓީ (dots per inch) ބުނެއްޖެނަމަ، ޑްރޯއިންގގެ ޔުނިޓްތަކުގައި އޭގެ ހަމަ ސައިޒުން ގެނެވޭ؛ `SCANATTACH` އަދި ފުޅާމިން ސުވާލު ކުރޭ.
- **Point clouds އެޑްއޮން**: ފައިލް ޔުނިޓެއް ނުބުނެ ނުހުރި ޕޮއިންޓް ކްލައުޑް ހަދާއިރު ސުވާލު ކުރޭ، އަދި ކްލައުޑްގެ އަދަދުތައް އޭގެ ޔުނިޓުން ލޭބަލް ކުރޭ.

## ފައިދާއިން ހާސިލުވާ ކަންތައް

- DWG ނުވަތަ DXF އެކަނި ޑްރޯއިންގެ ގޮތުން ހުޅުވުމުން އެއްވެސް ސުވާލެއް ނުކުރޭ: ކޮމާންޑް ލައިނުން ފައިލް ކޮން ޔުނިޓް ބުނޭ، ނުވަތަ އެއްވެސް ޔުނިޓެއް ނުބުނޭ ކަން. Properties ން ޑްރޯއިންގުގެ ޔުނިޓް ސެޓް ކުރޭ.
- މި ޑްރޯއިންގުގައިވެސް ޔުނިޓް ނެތްނަމަ، ފައިލް ބަދަލުކުރެވޭނެ ނޫން: އެކަން އެ ނަމްބަރުތަކުގެ ގޮތުން ބަހައްޓައި، ކޮމާންޑް ލައިނުން ފާހަގަ ކުރޭ.
- ޖަވާބު އެ ފައިލަށް މި ކޮމްޕިއުޓަރުގައި ކޮންމެ CadCraft އެޕްލިކޭޝަނެއްގައި ހަނދާންވެއެވެ. އެ ފައިލް އަނބުރާ ގެނެވޭއިރު ސުވާލު ނުކުރެވޭ، އަދި ކޮމާންޑް ލައިނުން ހަނދާންކުރެވުނު ޔުނިޓްތައް ބޭނުންކުރެވުނު ކަން ފާހަގަ ކުރޭ.
- ފަހުން ސުވާލު ކުރުމަށް: ކޮމާންޑް ޕެލެޓް ({{key:Mod+K}}) › **Ask again for the units of imported files**.
