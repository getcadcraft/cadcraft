## ހުރިހާ ސައިޒަކަށް އެއް ޓޭބަލް

{{ui:Parameters}} ޕެނަލް ({{ui:Parametric}} ގްރޫޕުގައި {{ui:Parameters}} ބަޓަން، ނުވަތަ {{cmd:PARAMETERS}} ޓައިޕްކުރޭ) ހުރިހާ ޑައިމެންޝަނަލް ކޮންސްޓްރެއިންޓެއް (`d1`، `rad1`، `dia1`، `ang1`، ނުވަތަ ތިޔަ ދިން ނަން) އަދި ތިޔަ އަމިއްލަ ޕެރަމީޓަރތައް އެކުގައި ލިސްޓު ކުރޭ. ކޮންމެ ނަމެއް ކޮންމެ އެކްސްޕްރެޝަނެއްގައި ބޭނުން ކުރެވޭ.

ކޮންމެ ރޯއެއްގައި:

- **Name**: އައު ނަމެއް ޓައިޕްކޮށް ނަން ބަދަލުކުރޭ؛ އެ ނަން ބޭނުން ކުރާ ކޮންމެ އެކްސްޕްރެޝަނެއް ފަހަރު ހަމަވޭ.
- **Expression**: އަދަދެއް (`40`) ނުވަތަ އެކްސްޕްރެޝަނެއް (`width / 2 + gap`). އެތަނުގައި ޓައިޕްކޮށް {{key:Enter}} ފިރުމާ: ޑްރޯއިންގ އެ ތަނެއް ފަހަނައަޅާ.
- **Value**: އޭގެ ނަތީޖާ. އެކްސްޕްރެޝަނެއް ޑްރައިވް ކުރާ ރޯއެއްގައި، މިތަނުގައި އަދަދެއް ޓައިޕްކުރުން ހުއްދަ: CadCraft އެ އަދަދުގެ ފަހަތުގެ ޕެރަމީޓަރ ހިސާބު ކުރޭ. `d1 = width / 2` ހިސާބުން، d1 ގެ value ގައި `30` ޓައިޕްކުރުމުން `width` 60 ވާންޖެހޭ.

ދެ ޕެރަމީޓަރ އަގެއް ޑްރައިވް ކުރާއިރު (`width / 2 + gap`)، ޑައިލޮގެއް އަސްލުން ބަދަލުކުރަންޖެހޭ ކޮން އެއް ހޮވުމަށް ސުވާލު ކުރާ. ކޮންމެ ބަދަލެއް {{key:Mod+Z}} އަނބުރާ ކުރެވޭ އެއް ޢަމަލެއް.

## އަމިއްލަ އެއް އިތުރު ކުރޭ

1. {{ui:Parameters}} ޕެނަލް ހުޅުވާ.
2. ނަމެއް (`gap`) އަދި އަގެއް (`10`) ޓައިޕްކޮށް، {{ui:Add}} ހޮވާ.
3. ބޭނުން ކުރޭ: d1 ގެ އެކްސްޕްރެޝަނުގައި `width / 2 + gap` ޓައިޕްކޮށް {{key:Enter}} ފިރުމާ.

ނާވާ ނަންތައް ލެޓަރ ނުވަތަ `_` އިން ފަށާ، އަދި ލެޓަރ، ޑިޖިޓް އަދި `_` ހިމަނާ. ފަންކްޝަން ނަންތައް، `pi` އަދި ޔުނިޓް ނަންތައް ނަން ނޫން.

## އެކްސްޕްރެޝަންތައް

| ލިޔޭ | މާނަ |
|---|---|
| `+ - * / ^ %` | އިތުރު، ނެގުން، ގުނާ، ބަހާ، ބާވަތް (power)، ބާކީ |
| `( )` | ގްރޫޕްކުރުން |
| `sin cos tan asin acos atan atan2` | ޑިގްރީގައި ޓްރިގޮނޮމެޓްރީ |
| `sqrt pow exp ln log abs sign` | ރޫޓް، ބާވަތް، ލޮގެރިތަމް |
| `ceil floor int round min max` | ރައުންޑިންގ އަދި ހައްދު |
| `if(a > b, x, y)` | ޗޮއިސް |
| `pi` | 3.14159… |

ނަންބަރުތަކުގައި ޔުނިޓެއް ހިމެނިދާނެ: `25mm`، `1in`، `2'`، `90deg`. ޔުނިޓް ހުރި ދިގުތައް މިލީމީޓަރަށް ބަދަލުވެއެވެ، އެހެންކަމުން ޔުނިޓް ބޭނުން ކުރޭ މިލީމީޓަރުގައި މިން ކުރާ ޑްރޯއިންގުތަކުގައި ނޫން؛ އެހެން ތަނުގައި ސާދާ އަދަދު ޓައިޕްކުރޭ.

## ކޮމާންޑް ލައިނުގައި

`-PARAMETERS` ޕެނަލް ނެތި އެ ހަމަ ކުރެއެވެ: `N` އައު، `E` އެޑިޓް (ޑައިމެންޝަނަލް ކޮންސްޓްރެއިންޓެއްވެސް)، `R` ނަން ބަދަލު، `D` ފޮހެލާ، `?` ލިސްޓް.

## ކޮބާ ރައްދުކުރެވޭ

- ފަހަރު ކުރާ އެކްސްޕްރެޝަނެއް، ސީދާ ނުވަތަ އަނެކުންގެ ތެރެއިން: "width, d1 use each other."
- ސައިޒަކަށް ނުކުރެވޭ އަގެއް: މިނަސް ދިގެއް، 180° އަށްވުރެ ގިނަ އެންގަލެއް.
- ޑްރޯއިންގ އެކަމުގެ އެހެން ކޮންސްޓްރެއިންޓްތަކާއެކު ނުކުރެވޭ އަގެއް: އެއްވެސް ކަމެއް ނުބަދަލުވޭ، އަދި މެސެޖް ބާރު ކޮންސްޓްރެއިންޓްތައް ނަން ދައްކާ.
- ކަމެއް ބޭނުން ކުރާ ޕެރަމީޓަރ ފޮހެލުން: ޕެނަލް އެކަމުގެ އަގު ފުރަތަމަ އެ ތަންތަނަށް ލިޔުން ފޮނުއްވައެވެ. ޑައިމެންޝަނަލް ކޮންސްޓްރެއިންޓެއްގެ ނަން ފޮހެލާ ކޮންސްޓްރެއިންޓް ފޮހެލުމުން.
