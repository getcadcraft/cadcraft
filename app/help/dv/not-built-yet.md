CadCraft ހަދަމުންދަނީ. މި ޞަފްޙާގައި މި ބިލްޑުން ނުކުރާ ކަންތައް ލިސްޓު ކުރާފައިވެއެވެ، ކަންތައް ހޯދަން ނޫން ބޭނުން ނުވުމަށްޓަކައި. ކޮންމެ އައިޓަމެއްގައި އަދު ކުރަންވީ ކަން ބުނެފައިވެއެވެ.

## ފައިލް އާއި ރައްކާކުރުން

| އަދި ހަދާފައެއް ނެތް | ބަދަލަށް، މިއަދު |
|---|---|
| AutoCAD ގައި އަމިއްލައަށް ޗެކްކުރެވިފައިވާ CadCraft DWG | ރައްކާކުރެވޭ ކޮންމެ ވަރުޝަނެއް ކިޔައި ބަލާނީ ތިން އެހެން ޕްރޮގްރާމެއްގެ DWG ރީޑަރުންނާއި CadCraft އިންނެވެ. [DWG ގައި ހިފާ އަދި ބަދަލުވާ ކަންތައް](topic:files#what-a-dwg-keeps-and-changes) ބަލާ. |
| 2000 ގެ ފަހުން DXF ރައްކާކުރުން | DXF 2000 ގެ ގޮތުން ރައްކާކުރޭ، ނުވަތަ DWG ގެ ގޮތުން AutoCAD 2018 އާއި ހަމައަށް ރައްކާކުރޭ. |
| browser ގައި ހުޅުވާފައިވާ ފައިލުގެ މަތީން ރައްކާކުރުން | ކޮންމެ ރައްކާކުރުމަކުން އައު ކޮޕީއެއް ޑައުންލޯޑުކުރެވެ؛ ބޭނުން ނަމަ އަސްލު ފައިލް އަމިއްލައަށް ބަދަލުކުރޭ. CadCraft Studio ގައި {{key:Mod+S}} އިން ހުޅުވާފައިވާ ފައިލަށް ފަހަރު ރައްކާކުރެވެ. |
| ކްލައުޑް ރައްކާކުރުމާއި ކޮމްޕިއުޓަރުތަކުގެ ދެމެދު ސިންކް | CadCraft އަށް ރައްކާކުރުން ފަހަރުން ކްލައުޑަށް ނުލާ ހުރެއެވެ: DWG އަދި DXF ފައިލްތައް ތިޔަ އަމިއްލަ ފޯލްޑަރުތަކުގައި ބަހައްޓާ. CadCraft Studio ގައި، [ހިސްޓަރީ](topic:history) އިން އެހެން ތަނެއްގައި ރައްކާކުރެވުނު ޑްރޯއިންގެ ކްލައުޑް ވާރޝަންތަކާއި މި ކޮމްޕިއުޓަރުގައި ތިޔަ އަމިއްލަ ރައްކާކުރުންތަކުގެ ކޮޕީތައް ފެންނާނެއެވެ. |
| އޯވަލޭ، އަދި ގުޅުވާފައިވާ ޑްރޯއިންގެ ތަނުން ތަނަށް އެޑިޓްކުރުން | ޑްރޯއިންގ ލިންކެއްގެ ގޮތުގައި ހައްދަވާ، އެހެން ޑްރޯއިންގ ބަދަލުކުރުމަށްފަހު ރީލޯޑު ކުރޭ. ލިންކް ލިންކަށް ހުރެގެން DWG ގެ ގޮތުން ރައްކާކުރުމުން ހުންނާނެ، އަދި {{cmd:XCLIP}} އިން ކްލިޕް ކުރެވެ. |
| DXF ގައި ޕިކްޗަރ؛ ދަށުގައި ހުރި އެއްޗެއް ފޮރުވާ ވައިޕްއައުޓްތައް | DXF ގައި ޕިކްޗަރ ރައްކާކުރެވެނީ ފައިލް ނަމާއެކު އެގެ ފްރޭމެއްގެ ގޮތުގައެވެ؛ DWG ގައި ޕިކްޗަރގެ ގޮތުގައި ރައްކާކުރެވެ — [ޕިކްޗަރ](topic:pictures) ބަލާ. ވައިޕްއައުޓް އޭގެ ފްރޭމުގެ ގޮތުގައި ފެނެއެވެ. |
| ވަށާ ހުރި ލީޑަރ ރޮނގުތައް ހުންނަ މަލްޓީލީޑަރުތަކާއި، ކޮންޓެންޓުގެ ދެފަރާތުގައި ލީޑަރ ރޮނގުތައް ހުންނަ މަލްޓީލީޑަރުތަކާއި، ނުވަތަ ފަރުމާ ނުކުރެވޭ ގޮތެއްގައި ފަރުމާ ކުރެވިފައިވާ ބްލޮކްތަކެއްގެ މަލްޓީލީޑަރުތައް އެޑިޓްކުރުން | އެހެން ޕްރޮގްރާމުން ކުރި ގޮތުގައި ޑްރޯކުރެވި، އެކަމަކު އެއް ޔުނިޓެއްގެ ގޮތުގައި މޫވް ވެއެވެ. އެއް ލޭންޑިންގަކަށް ސްޓްރެއިޓް ލީޑަރ ރޮނގު ހުންނަ މަލްޓީލީޑަރުތަކާއި، ޓެކްސްޓް ނުވަތަ ބްލޮކް ކޮންޓެންޓަކަށް ހުންނަ މަލްޓީލީޑަރުތައް އެޑިޓްކުރެވޭ ގޮތުން ލިބެއެވެ ({{cmd:MLEADEREDIT}}). |
| އެހެން ޕްރޮގްރާމްތަކުން ހަދާ ޓޭބަލްތައް: ސެލްގައި ބްލޮކް ހުންނަ ސެލް، ސެލްގެ ތެރޭގެ ޓެކްސްޓް ފޯމެޓިންގ، DXF ޓޭބަލްގެ ސެލް ސެލް އަށް ބޯޑަރާއި ރަނގު، ކޮލަމްތަކަށް ބޮޑުވެފައިވާ ޓޭބަލް | ޓޭބަލް އެޑިޓުކުރެވޭ ޓޭބަލްގެ ގޮތުގައި ހުޅުވެއެވެ ({{cmd:TABLEDIT}})، އަދި އެޑިޓް ނުކުރާ ހިނދު އެހެން ޕްރޮގްރާމުން ކުރި ގޮތުގައި ފެނޭ؛ ފަހުން CadCraft އިން ސެލްތަކުންނެވެ ރީޑްރޯ ކުރެވެ: ސާދާ ޓެކްސްޓް، `=G3*H3` އާއި `=Sum(I3:I9)` ފަދަ ފޯމިއުލާ، ސެޓްކުރުން އަދި ޓެކްސްޓްގެ އުސްތައް. ބްލޮކް ސެލް ފަހުން ހުސްވެއެވެ. އެހެން ނުބަދަލުވާ DWG ޓޭބަލް އޭގެ ސެލް ޑޭޓާއާއެކު އަލުން ރައްކާކުރެވެ. |
| ރައްކާކުރެވުނު DXF ގައި ޓޭބަލް އޮބްޖެކްޓް | DWG ގައި ޓޭބަލް އެހެން ޕްރޮގްރާމްތަކުން އެޑިޓްކުރެވޭ ޓޭބަލްގެ ގޮތުގައި ރައްކާކުރެވެ. DXF ގައި އޭގެ ޑްރޯކުރާ ބްލޮކުގެ ގޮތުގައި ރައްކާކުރެވެ، CadCraft ގެ އަމިއްލަ ރެކޯޑަކާއެކު: CadCraft އިން ޓޭބަލްގެ ގޮތުގައި އަލުން ހުޅުވެއެވެ؛ އެހެން ޕްރޮގްރާމްތަކުން ބްލޮކްއެއްގެ ގޮތުގައި ފެނެއެވެ. މިރާއްސާ ނުވަތަ ނުސަމާންތަ ސްކޭލް ކުރެވުނު ޓޭބަލް DWG ގައިވެސް އެގޮތަށް ރައްކާކުރެވެ. |
| އެހެން ޕްރޮގްރާމްތަކާއެކު ކޮޕީކުރުމާއި ޕޭސްޓްކުރުން | CadCraft ގެ ކްލިޕްބޯޑު CadCraft ޑްރޯއިންގުތަކާއި އެއް ބްރައުޒަރުގެ ޓެބްތަކުގެ ދެމެދު މަސައްކަތް ކުރެވެ، އެހެން ޕްރޮގްރާމްތަކާ ނޫން. DWG ނުވަތަ DXF ގެ ގޮތުން ރައްކާކޮށް އޭގައި ހުޅުވާ. [ކޮޕީ، ޕޭސްޓް އަދި ޑުޕްލިކޭޓް](topic:copy-paste) ބަލާ. |

## ޑްރޯއިންގ އަދި އެޑިޓިންގ

| އަދި ހަދާފައެއް ނެތް | ބަދަލަށް، މިއަދު |
|---|---|
| CadCraft ގައި ނެތް ހެޗް ޕެޓާންތައް، އަދި ގްރޭޑިއަންޓް ފިލްތައް އެހެން ޕްރޮގްރާމްތަކުން ޕެއިންޓް ކުރާ ގޮތަށް ހަމައަށް | ނެތް ޕެޓާންތަކުގެ ހެޗް ހުޅުވާފައި ފެނޭނީ ޓޯނެއްގެ ގޮތުގައެވެ. ގްރޭޑިއަންޓް ފިލް ({{cmd:GRADIENT}}) ކޮންމެ ޓައިޕަށް CadCraft ގެ އަމިއްލަ ގޮތުން ޕެއިންޓް ކުރެވެ: އެހެން ޕްރޮގްރާމްތަކުގެ ޖިންސުން ހަމަ، ނަމަވެސް ޕޮއިންޓް ޕޮއިންޓަށް ނޫން. DWG 2004 އާއި ފަހުން އެއީ ޙަޤީޤީ ގްރޭޑިއަންޓް ހެޗް ގޮތުގައި ރައްކާކުރެވެ؛ DXF 2000 ނުވަތަ DWG 2000 ފައިލެއްގައި CadCraft ން ކަމުގައި ކިޔާ ބަލާނީ، އެހެން ޕްރޮގްރާމްތައް ސޮލިޑް ފިލްތައް ފެނެއެވެ. ޕެޓާންތައް `.pat` ފައިލެއްން ލޯޑުވެ، ހެޗް އޭގެ ބައުންޑަރީ އާ ގުޅުވައިލެވިދާނެއެވެ: [ހެޗް އަދި ފިލް ޒޯނުތައް](topic:hatch) ބަލާ. |
| ލައިންޓައިޕްތައް ޝޭޕް އަދި ޓެކްސްޓް ހުންނަވި، އަދި R12 ގައި ރައްކާކުރެވުނު DXF ގައި ލައިންވެއިޓްތައް | ފައިލުގެ ލައިންޓައިޕުގެ ޝޭޕް އަދި ޓެކްސްޓް ޑޭޝްތަކުން ބޭރުވެއެވެ؛ ލައިންވެއިޓް ރައްކާކުރުމަށް DWG ގެ ގޮތުން ރައްކާކުރޭ. |
| ރައްކާކުރެވުނު DXF ގައި ޕެޓާންވެރި ހެޗް | R12 ގައި ހެޗް ނެތެވެ: އެއީ އޮތް ކުރިމަތީގެ ގޮތުން ރައްކާކުރެވެ. ޕެޓާން ރައްކާކުރުމަށް DWG ގެ ގޮތުން ރައްކާކުރޭ. |
| އެހެން ޕްރޮގްރާމެއްގެ އެރޭތައް ނުވަތަ އެޑިޓްކުރެވޭ އެރޭތައް؛ ޕާތް އަދި ޕޯލާ އެރޭތަކުގެ ރޯތަކާއި ލެވެލްތައް؛ ޕާތް ކާރވް ފޮލޯ ކުރާ އެރޭ | ASsociative ({{cmd:ARRAY}}، {{cmd:ARRAYPATH}}؛ {{cmd:ARRAYEDIT}} އިން ބަދަލުކުރޭ) ގޮތުން ހަދާ އެރޭ، CadCraft ގެ އަމިއްލަ އަދަދުތަކާއެކު ބްލޮކް ރެފަރެންސެއްގެ ގޮތުގައި ރައްކާކުރެވެ: އެހެން ޕްރޮގްރާމްތަކުން ފެނޭ، މޫވް ކުރޭ، ޕްލޮޓް ކުރޭ އަދި އެކްސްޕްލޯޑް ކުރޭ، އެކަމަކު އެގެ އަދަދު ބަދަލުކުރެވޭނެ ނޫން. އެހެން ޕްރޮގްރާމެއްގައި ހަދާ އެރޭ މިތަނުގައި ހުޅުވާއިރު ސާދާ ބްލޮކް ރެފަރެންސެއްގެ ގޮތުގައި ހުޅުވެއެވެ. ޕާތް އެރޭއަކީ އޭގެ ޕާތުގެ ކޮޕީއެއް ހިފާ ރައްކާކުރޭ: ފަހުން ކާރވް ބަދަލުކުރުމުން އައިޓަމްތައް ނުހަރަކާތް ކުރެއެވެ. |
| އެހެން ޕްރޮގްރާމްތަކާ ގުޅޭ ކްލިޕްކުރެވުނު ޝީޓް ވިއުޕޯޓްތައް | {{cmd:VPCLIP}} އިން ކްލިޕްކުރެވުނު ނުވަތަ {{cmd:MVIEW}} Polygonal ނުވަތަ Object އިން ހަދާ ވިއުޕޯޓެއް CadCraft ގެ އަމިއްލަ އައުޓްލައިނުން ރައްކާކުރެވެ: އެހެން ޕްރޮގްރާމްތަކުން އޭގެ ވަށާ ހުރި ރެކްޓެންގަލެއްގެ ގޮތުގައި ހުޅުވެއެވެ، އަދި އެހެން ޕްރޮގްރާމެއްގައި ކްލިޕްކުރެވުނު ވިއުޕޯޓް މިތަނުގައި އޭގެ ރެކްޓެންގަލުގެ ގޮތުގައި ހުޅުވެއެވެ. DXF R12 ގައި ރެކްޓެންގަލް ކަމުން ހުންނެވެ. |
| {{cmd:STRETCH}} ކްރޮސިން ޕޮލިގަން ރަސްމަކާއެކު | ކްރޮސިން ވިންޑޯ އެއް ނުވަތަ ގިނަ ހަމައެކަނި ބޭނުން ކުރޭ. |
| {{cmd:PEDIT}} Edit vertex (ކޮމާންޑް ލައިނުގައި އެއް ވަރޓެކްސެއް ވަރުގަނޑަށް) | ގްރިޕްސް، އަދި {{ui:ޕްރޮޕަޓީޒް}} ގައިވާ ވަރޓެކްސް ބްރައުޒަރ (ހުރިހާ ވަރޓެކްސެއް، އޭގެ ފުޅާމިންތަކާއި ބަލްޖް). PEDIT ގެ ބާކީ ކަންތައް ހަދާފައިވެއެވެ: [ސްޕްލައިން އަދި ޕޮލިލައިން](topic:splines) ބަލާ. |
| ޑައިމާ އަދި ސްޕްލައިންތަކުގައި {{cmd:BREAK}}، {{cmd:LENGTHEN}}، {{cmd:OFFSET}}، {{cmd:TRIM}}، {{cmd:EXTEND}}، {{cmd:FILLET}} އަދި {{cmd:JOIN}} | ސްޕްލައިނެއް {{cmd:EXPLODE}} ކުރޭ (ނުވަތަ {{cmd:PEDIT}} ކުރޭ)، ރަނގަޅު ޕޮލިލައިނެއް ލިބޭނެ ގޮތަށް މި ކޮމާންޑްތައް ބޭނުން ކުރެވޭ. |
| ޕޮލިލައިނެއްގެ އާރކް ސެގްމަންޓާއި އޭގެ ކައިރީ ސެގްމަންޓާ ދެމެދު ފިލެޓް އަދި ޗޭމްފަރ؛ ލައިނެއް ޕޮލިލައިނަށް ފިލެޓްކުރުން | ޕޮލިލައިން {{cmd:EXPLODE}} ކުރޭ، ފަހުން ޓުކުޑަ ބައިތަކަށް ފިލެޓް ކުރޭ. ފިލެޓް އާރކް އޭގެ އަމިއްލަ އޮބްޖެކްޓެއްގެ ގޮތުގައި އިތުރު ކުރެވެ. |
| Trim އަދި extend: ޕްރޮޖެކްޓް އޮޕްޝަން (3D) އަދި ޕޮލިލައިނުގެ އާރކް އެންޑް އިތުރުކުރުން | ޑްރޯއިންގުގެ ސަފުހާ މަތީގައި Trim ކުރޭ؛ އާރކް އެންޑަށް ފޮނި ޕޮލިލައިން {{cmd:EXPLODE}} ކުރޭ، ނުވަތަ އާރކް އަލުން ޑްރޯ ކުރޭ. |
| OLE އޮބްޖެކްޓްތައް: އިންސާޓުކުރުން، ރަން ކުރުން ނުވަތަ އެޑިޓްކުރުން؛ DWG ގައި ފައިލް ކޮތަން ބަހައްޓަނީ އެތަން ފެންނަވާ ކަންތައް؛ މެޓާފައިލް ޕިކްޗަރތައް | [ޕިކްޗަރ](topic:pictures#objects-from-other-programs-ole) ބަލާ. DXF ގެ އޮބްޖެކްޓްތައް އޭގެ ބިޓްމެޕެއް ނުވަތަ ލޭބަލް ފްރޭމަކުން ފެނޭ؛ DWG ގެ އޮބްޖެކްޓްތައް ރައްކާކުރެވެ، އެކަމަކު އެތަނުގައި ނުޑްރޯކުރެވޭ ({{cmd:OLELIST}} އިން ލިސްޓް ކުރެވޭ އަދި ބުނި ތަނުގައި ކޮޕީ ޕިކްޗަރ ދަމާލެވޭ). |
| ޕެރާގްރާފް ޓެކްސްޓުގައި ފޯމެޓިން ކޯޑްތައް (ބޯލްޑް، ސްޓެކްޑް ފްރެކްޝަން، ހަރ ވާޑުންގެ ކަލާ) ޓައިޕްކުރުން؛ ހެލްވެޓިކާ ސްޓައިލުގެ ފޮންޓުން އިތުރު ފޮންޓްތައް؛ ކޮލަމްތައް | ފައިލަކުން ނެރުނު ފޯމެޓިން ރައްކާކުރެވެ، ޑްރޯކުރެވެ އަދި ރައްކާކުރެވެ ({{ui:ޓެކްސްޓް}} ބަލާ)؛ އައު ޕެރާގްރާފް ޓެކްސްޓް އެއް އުސް އަދި އެއް ރަނގެއްގެ ގޮތުގައި ލިބެއެވެ. |
| ޕެރާގްރާފް ޓެކްސްޓް އޭގެ ރޮޓޭޝަނުގައި އެޑިޓްކުރުން | އެޑިޓަރު ލެވެލްގައި ހުޅުވޭ؛ ޓެކްސްޓް އޭގެ ރޮޓޭޝަން ހިފާ ހުރެއެވެ. |
| DXF ގައި ރައްކާކުރެވުނު މަލްޓީލީޑަރ އޮބްޖެކްޓްތައް | DWG ގައި އެ މަލްޓީލީޑަރުތައް ރައްކާކުރެވެ، ކޮންމެ ލީޑަރ ރޮނގާއި ބްލޮކް ކޮންޓެންޓަށް ހުރެއެވެ؛ DXF ގައި އެމީހުން ޑްރޯ ކުރާ ކަންތައް (ރޮނގު، އެރޯހެޑް، ޓެކްސްޓް ނުވަތަ ބްލޮކް) ރައްކާކުރެވެ. |
| ޓޭބަލްތައްގައި ({{cmd:TABLE}}): ސެލްގެ ތެރޭގައި ޓެކްސްޓް ބޮޑުވާ ގޮތް، ޓޭބަލްތައް ބައިތަކަށް ބެހޭ، ޓޭބަލް ސްޓައިލްގެ ޓެކްސްޓް ސްޓައިލް އަދި ޑައިލޮގުގައި ކޮންމެ ރޯއެއްގެ ރަނގު، ސްޕްރެޑްޝީޓް ފައިލް (`.xlsx`) އަށް ޑޭޓާ ލިންކް ނުވަތަ ފައިލް އަމިއްލައަށް ކިޔާ ލިންކް | ސެލްގެ ޓެކްސްޓް ބޮޑުވެފައިވަނީ ތިބާ ބޮޑުކުރާ ތަނުގައި ބަހުސް ({{key:Alt+Enter}})؛ ކޮލަމް ފުޅާ ކުރޭ. {{cmd:DATALINK}} އިން `.csv` ފައިލް ކިޔާ، އަދި {{cmd:DATALINKUPDATE}} އިން ފައިލް އަލުން އިޚްތިޔާރުކުރުމަށް ބުނެ. {{cmd:DATAEXTRACTION}} އަދި {{cmd:COUNTTABLE}} ޑްރޯއިންގ ފަދައިން އަމިއްލައަށް ނުބަދަލުވާ ޓޭބަލް ހަދައެވެ: އަލުން ރަން ކުރޭ (ލައިވް ގުނުން: {{cmd:BOMTABLE}}). |
| ރައްކާކުރެވުނު ފައިލެއްގައި އޮތް އެޓްރިބިއުޓް ޑެފިނިޝަންތައް (ބްލޮކުގެ ބޭރުން)، ލައިނުން ގިނަ އެޓްރިބިއުޓްތައް | ރައްކާކުރުމުގެ ކުރިން އެޓްރިބިއުޓް ޑެފިނިޝަންތައް ބްލޮކަކަށް ޖައްސާ: އެކަމުގެ ފަހަރު ކޮޅުން ރައްކާކުރެވުނުކަމުން ޓެގް ފެންނާ ޓެކްސްޓެއްގެ ގޮތުގައި ރައްކާކުރެވެ. |
| ލޭޔަރ ސްޓޭޓްސް (ލޭޔަރުތައް ނުވަތަ ހުރި ގޮތް ރައްކާކުރުން އަދި ރީސްޓޯ ކުރުން) | {{cmd:LAYISO}} / {{cmd:LAYUNISO}} ބޭނުން ކުރޭ، ނުވަތަ ލޭޔަރުތައް އަތުން އޮންކޮށް އޮފްކުރޭ. |
| ވިންޑޯ ޕޮލިގަން އަދި ކްރޮސިން ޕޮލިގަން ސިލެކްޝަން، އަދި ރައްކާކުރެވުނު ސިލެކްޝަން ފިލްޓަރުތައް | ފެންސް (`F`)، ވިންޑޯ، ކްރޮސިން، ނެގުން (`R`)، ރޫލެއްގައި {{cmd:QSELECT}}. |


## ޕްރޮޕަޓީޒް ޕެނަލް

| އަދި ހަދާފައެއް ނެތް | ބަދަލަށް، މިއަދު |
|---|---|
| Fit އިޚްތިޔާރުތައް ޑްރޯކުރުން، އަދި ލީނިއަރ އާއި އެލައިންޑް ނޫން ޑައިމެންޝަންތަކުގައި ހޯރިޒަންޓަލް ޓެކްސްޓް ޕޮޒިޝަނާއި ލައިނުގެ ދަށުގެ ޓެކްސްޓް | އޭގެ އޮބްޖެކްޓުގައި ހިފާ ޕްރޮޕަޓީޒްގައި ފެންނައި ރައްކާކުރެވެ؛ CadCraft އިން ޓެކްސްޓް ޕޮޒިޝަން އޭގެ އަމިއްލަ ގޮތުން ކުރެވެ. |
| އެހެން ޕްރޮގްރާމްތަކުން ފެންނާ މެޓީރިއަލްތައް | ރައްކާކުރެވުނު ފައިލް CadCraft އަށް މެޓީރިއަލް ނަން ހިފެހެއްޓެވެ؛ އެހެން ޕްރޮގްރާމްތަކުން ލޭޔަރގެ މެޓީރިއަލް ފެންނާނެއެވެ. |
| DWG 2000 އަދި DXF ފައިލްތަކުގައި ޓްރާންސްޕެރެންސީ | އެހެން ޕްރޮގްރާމްތަކުން އެ އޮބްޖެކްޓްތައް ސޮލިޑް ކަމުގައި ފެންނާނެ؛ CadCraft އިން ޓްރާންސްޕެރެންސީ ހިފާ ހުރެއެވެ. ހުރިހާ މީހަކަށް DWG 2004 ނުވަތަ ފަހުން ރައްކާކުރޭ. |
| އެހެން ޕްރޮގްރާމްތަކުން ހަދާ ހެޗް ލިންކް | CadCraft އިން DWG އަދި DXF 2000 ފައިލްތަކުގައި އޭގެ އަމިއްލަ ލިންކް ރައްކާކުރެވެ؛ އެހެން ޕްރޮގްރާމްތަކުން ހަދާ ލިންކްތައް ކިޔެވެނީ ނުވެ. `HATCHEDIT` އަދި Link ބޭނުން ކުރޭ: [ހެޗް އަދި ފިލް ޒޯނުތައް](topic:hatch) ބަލާ. |
| ޕްރޮޕަޓީޒް ގައި UCS ގައި ކޯޑިނޭޓްތައް | ޕްރޮޕަޓީޒް ވޯލްޑް ކޯޑިނޭޓްތައް ދައްކާ؛ ސްޓޭޓަސް ބާރާއި {{cmd:ID}} ގައި UCS ކޯޑިނޭޓްތައް ފެނޭ. [ވިއު ރޮޓޭޓް ކުރުމާއި ތިބާގެ އަމިއްލަ ކޯޑިނޭޓްތައް ބޭނުން ކުރުން](topic:ucs-and-turned-view) ބަލާ. |
| އެނޮޓޭޓިވް އޮބްޖެކްޓަކަށް އެކި ސްކޭލުތަކުގައި އަމިއްލަ ޕޮޒިޝަން؛ އެހެން ޕްރޮގްރާމްތައް ރައްކާކުރާ ސްކޭލްގެ ރެކޯޑްތައް ކިޔުން | އެނޮޓޭޓިވް ޓެކްސްޓް ނުވަތަ ޑައިމެންޝަނެއް ސްކޭލްތަކުގެ ލިސްޓެއް ({{cmd:OBJECTSCALE}}) ހިފާ، ކޮންމެ ވިއުޕޯޓް އޭގެ ސްކޭލަށް ހަމަޖެހިފައިވާ ސައިޒުގައި އެއް ތަނުގައި ދައްކައެވެ. ލިސްޓް CadCraft ގެ އަމިއްލަ ޑޭޓާއެއްގެ ގޮތުން ރައްކާކުރެވެ؛ އެހެން ޕްރޮގްރާމެއްގައި އޮބްޖެކްޓް ހަމައެކަނި އެ ސްކޭލުގައި ފެނޭ، އަދި އެހެން ޕްރޮގްރާމެއްގައި ހަދާ ލިސްޓް ނުކިޔެވެ. [ޔުނިޓްތައް، ޕޭޕަރ އަދި ސްކޭލްތައް](topic:units-papers-scales#annotate-by-scale) ބަލާ. |
| ޑައިނަމިކް ބްލޮކްގެ ދުރުތަކާއި ކޯނަތައް ބަދަލުކުރުން، ފްލިޕް ކުރުން؛ ޑައިނަމިކް ބްލޮކްތައް ތިބާ ދިމާވާ DWG ވަރުޝަނަށް ނުވަތަ DXF ގެ ގޮތުން ރައްކާކުރުމުން ޑައިނަމިކް ކަމުގައި ހުރުން | ޕްރޮޕަޓީޒް › {{ui:ކަސްޓަމް}} ގައި އޭގެ ފެނުން ސްޓޭޓް ބަދަލުކުރޭ؛ އެހެން އަގުތައް އޭގައި ކިޔެވޭ ނުވަތަ ފިޔަވާ ކަމުގައި ފެނޭ. DWG ގެ ގޮތުން ފައިލް އައި ވަރުޝަނުގައި ރައްކާކުރުމުން އެ ޑައިނަމިކް ކަމުގައި ހުރެއެވެ. [ޑައިނަމިކް ބްލޮކް](topic:dynamic-blocks) ބަލާ. |
| ސްޕްލައިން ފިޓް ޓޮލަރެންސް، ސްޕްލައިން ޑިގްރީ 6 އަދި އެއަށްވުރެ މަތިން، 3D ސްޕްލައިން | ފިޓް އަދި ކޮންޓްރޯލް ޕޮއިންޓް، ޑިގްރީ 1 އިން 5 އަށް އަދި ވެއިޓްތައް ހަދާފައިވެއެވެ: [ސްޕްލައިން އަދި ޕޮލިލައިން](topic:splines) ބަލާ. ސްޕްލައިންގެ އުސް (Z) ހިފަން ނުވެ. |

## ޕްރިސިޝަން އެއިޑްސް

| އަދި ހަދާފައެއް ނެތް | ބަދަލަށް، މިއަދު |
|---|---|
| ކޮމާންޑްތަކުގެ ނުކުތާތަކުން ޓްރެކިންގ، އަދި ޓްރެކިންގ ސެޓިންގްސް ޑައިލޮގް (ރޯލޭޓިވް ޕޮލާރ ކޯނާ، އިތުރު ކޯނަތައް) | {{cmd:POLARANG}} ސްޓެޕް ސެޓްކުރޭ؛ ނުކުތާތައް އަލުން ނަގާ ފަހުގެ ކޮމާންޑުގައި. |
| ގްރިޑަށް ސްނެޕް | ކޯޑިނޭޓްތައް ޓައިޕްކުރޭ؛ ގްރިޑް ހަމައެކަނި ފެނުމުގެ ގައިޑެއް. |
| ޕޮލިގަން ކޯނާއި ލެންގްތް އިޚްތިޔާރުތައް ދަތި ކުރުން، އަދި MEASUREGEOM ވޮލިއުމް | {{cmd:PLINE}} އިން އައުޓްލައިން ޑްރޯ ކުރޭ (އާރކްތަކާއެކު)، ފަހުން {{cmd:AREA}} `O`. |
| ގްރިޕްސް އަށް ޑައިނަމިކް އިންޕުޓް، އަދި އޭގެ އޮޕްޝަން ލިސްޓް (ތިރީގައި ހުރި ތީރު) | ކޮމާންޑް ލައިން އޮޕްޝަންތައް ދައްކާ. |
| ޑިގްރީ–މިނިޓް–ސެކަންޑް، ގްރޭޑް ނުވަތަ ސަރވޭޔަރގެ ބެއަރިންގ ކޯނާ | ދިހަ ބައި ޑިގްރީ ޓައިޕްކުރޭ: `30.5` ކަމަށްވާ 30°30' ގެ ގޮތުގައި. |
| ވިއު މެނޭޖަރ ޑައިލޮގް؛ ޝީޓެއްގެ ނަން ކުރެވުނު ވިއުތައް އެ ޝީޓުގައި އަލުން ފެނޭ | {{cmd:NAMEDVIEW}} ވިއުތައް ލިސްޓްކޮށް އަލުން ރީސްޓޯ ކުރޭ. ރައްކާކުރެވުނު ފައިލް އެތަކެތި ރައްކާ ކުރެއެވެ، އެކަމަކު ޝީޓުގެ ވިއުތައް ފުރަތަމަ ޝީޓުގައި އަލުން ފެނޭ. |

## ޝީޓް، ޑައިމެންޝަން އަދި ޕްލޮޓިންގ

| އަދި ހަދާފައެއް ނެތް | ބަދަލަށް، މިއަދު |
|---|---|
| ވިއުޕޯޓްގެ ސްކޭލަށް ފީލްޑްތައް، ލޭޔަރ ނުވަތަ ބްލޮކް ފަދަ ނަމާއެކު އޮބްޖެކްޓް، ހައިޕަރލިންކް، އަދި ޝީޓް ސެޓް ފީލްޑްތައް ޝީޓް ނަންބަރާއި ނަމަށްވުރެ ބޮޑަށް؛ އެހެން ޕްރޮގްރާމްތައް އަލުން އަޕްޑޭޓް ކުރާ ފީލްޑް އޮބްޖެކްޓްތަކެއްގެ ގޮތުން ލިޔެފައިވާ ފީލްޑްތައް | {{cmd:FIELD}} ގައި ތާރީޚު، ފައިލް ނަން، ޝީޓް ނަންބަރު، ނަން އަދި ޢަދަދު، ޑްރޯއިންގުގެ ޕްރޮޕަޓީޒް ({{cmd:DWGPROPS}})، އޮބްޖެކްޓެއްގެ ޕަރިމީޓަރ، ލެންގްތް އަދި އެހެން ޕްރޮޕަޓީޒް، އަދި ފޯމިއުލާތައް، ޓެކްސްޓް، އެޓްރިބިއުޓް އަދި ޓޭބަލް ސެލްތަކުގައި ހުރެއެވެ. އެހެން ޕްރޮގްރާމެއް CadCraft ފީލްޑެއް އޭގެ ފަހުން ކިޔެވި ޓެކްސްޓުގެ ގޮތުން ފެންނާނެ؛ CadCraft އިން އެހެން ޕްރޮގްރާމެއްގެ ތާރީޚު، ފައިލް ނަން، ޕްރޮޕަޓީ، ޝީޓް އަދި ފޯމިއުލާ ފީލްޑްތައް ކިޔައި، އެހެން ބާވަތްތައް ޓެކްސްޓުގެ ގޮތުން ބާކީ ނެގެ. ވިއުޕޯޓްގެ ސްކޭލް އަތުން ޓައިޕްކުރެވޭ. |
| ޑައިމެންޝަން ސްޓައިލް ކަރަންޓް ކަމުގައި ރައްކާކުރުން؛ ޑައިމެންޝަން ޓެކްސްޓް ހުސްކަމުގެ ތަނަކަށް ދުވުން | ޑްރޯއިންގ ފެށޭނީ Standard ކަރަންޓް ގޮތުން. ޓެކްސްޓް ޑައިމެންޝަން ލައިނުގައި ހުރެއެވެ ({{cmd:DIMTEDIT}} Left / Right / Center). [ޑައިމެންޝަން ސައިޒް ސެޓް ކުރުން](topic:dimension-settings) ބަލާ. |
| ފައިލްތައް ކިޔާ ނުވަތަ ހުށަހަޅާ ނުކުރެވޭ ކާޑިނަލް މައުލޫމާތުންތަކުގެ ދެ ލައިން އެންގުލާ ޑައިމެންޝަންތައް ކިޔެވޭ ހުރިހާ ހިސާބަކަށް | ފައިލްގައި ޑްރޯކުރާ ގޮތުގައި ފެނޭ. އޯޑިނޭޓް، އާރކް ލެންގްތް އަދި ޖޮގްޑް ރޭޑިއަސް ޑައިމެންޝަންތައް ބަދަލުކުރެވޭ ޑައިމެންޝަންތަކުގެ ގޮތުން ހުޅުވެއެވެ. |
| CTB ރީޑަރ އެހެން ޕްރޮގްރާމެއްގެ ފައިލަކާއެކު ޗެކްކުރުން (ޑްރޯ ކުރެވިފައި ވޭ، ޕަބްލިޝް ކުރެވުނު ޑިސްކްރިޕްޝަނަށް ބަލާ)، ނަމަކުރެވުނު ޕްލޮޓް ސްޓައިލްތައް (STB)، ޑިތަރ، ޕެން ނަންބަރު، CTB އިން ގްރޭސްކޭލް އަދި ޕްލޮޓް ސްޓައިލްގެ އެޑެޕްޓިވް ލައިންޓައިޕް އެޑްޖަސްޓްމަންޓް | {{ui:ޕްލޮޓް ސްޓައިލް ޓޭބަލްތައް}} ގައި ޓޭބަލް ހަދާ (ކަލާ، ގްރޭ، އިންކް، ލައިންވެއިޓް، ލައިންޓައިޕް، ލައިން އެންޑް ޖޮއިން، ކަލާ ވަރަށް ފިލް ސްޓައިލް): [ޕްލޮޓް ސްޓައިލް ޓޭބަލްތައް](topic:plot-pdf#plot-style-tables) ބަލާ. |
| ޕޭޖް ސެޓަޕްތައް | {{ui:PDF އަށް ޕްލޮޓް ކުރޭ}} ޑައިލޮގުގައި ޕޭޕަރ، ސްކޭލް އަދި ޕްލޮޓް ސްޓައިލް އިޚްތިޔާރުކުރޭ؛ ޝީޓް އޭގެ ޕްލޮޓް ސްޓައިލް ހިފާ ހުރެއެވެ. |
| PDF ގައި ހިންދީ އަދި އެހެން ސްކްރިޕްޓްތައް ކޮމްޕްލެކްސް ޝޭޕިންގ ބޭނުންވާ، އަދި ރެއާ އައިޑިއޮގްރާފްތައް (ޔޫރަޕިއަން ސްކްރިޕްޓްތައް، ސިރިލިކް، ގްރީކް، ހީބްރު، ޢަރަބި، ފާރސީ، އުރްދޫ، ތާއި، ޗައިނީޒް، ޖަޕާނީޒް އަދި ކޮރިއަން ޕްރިންޓް) | "?" ގެ ގޮތުގައި ޕްރިންޓް ކުރެވެ. |
| ޕްލޮޓް ކުރެވުނު އެއް PDF ގައި ޢަރަބި-ސްކްރިޕްޓް އަދި ޗައިނީޒް، ޖަޕާނީޒް ނުވަތަ ކޮރިއަން ޓެކްސްޓް | ޕްލޮޓަކަށް އެއް ފޮންޓެއް ހުންނާނެ: ދެ ސްކްރިޕްޓުގެ އެއް ސްކްރިޕްޓް "?" ގެ ގޮތުގައި ޕްރިންޓް ކުރެވެ. |
| ޓެކްސްޓުގައި ސަރީހު ދިމާ ނިޝާންތައް (އެމްބެޑިންގ، އޯވަރރައިޑް، އައިސޯލޭޓް) | އެތަކެއް ނޭވާކުރެވެ: ކޮންމެ ލައިނަކީ އޭގެ އަކުރުތަކުން މަތިން ހިމެނޭ ގޮތަށް ޢަމަލު ކުރެވޭ. |
| ބެހޭ PDF ޕޭޖްގެ ތެރޭ ޕިކްޗަރ، ޕްލޮޓަކަށް | ޕޭޖްގެ ލައިން، ފިލްތަކާއި ޓެކްސްޓް ޕްރިންޓް ކުރެވެ. ޕިކްޗަރ ޕޭޖެއް ފަދަ ޕޭޖެއް {{cmd:SCANATTACH}} އިން ހުރިއިރު ޕިކްޗަރ ޕްރިންޓް ކުރެވެ. [PDF އަންޑަލޭ](topic:pdf-underlay#plot-and-save) ބަލާ. |
| CadCraft Studio އިން ލޭޒާއަށް ޖޮބެއް ފޮނުވުން (Studio ގައި Web Serial ނެތް) | G-code ރައްކާކޮށް އޭގެ އަމިއްލަ ޕްރޮގްރާމުން ފޮނުވާ، ނުވަތަ Chrome އަށް ނުވަތަ Edge އިން ފޮނުވާ. [ލޭޒާއަށް ޑްރޯއިންގ ފޮނުވުން](topic:laser-cutting#send-from-the-browser) ބަލާ. |

## ކޮންސްޓްރެއިންޓްސް އަދި ޕެރާމީޓަރުތައް

| އަދި ހަދާފައެއް ނެތް | ބަދަލަށް، މިއަދު |
|---|---|
| ޝީޓްތަކުގައި، ބްލޮކްތަކުގައި، ޑައިލިޕްސްތަކުގައި، ސްޕްލައިންތަކުގައި ނުވަތަ ޓެކްސްޓްގައި ކޮންސްޓްރެއިންޓްސް | {{ui:މޮޑެލް}} ޓެބުގައި ކޮންސްޓްރެއިން ކުރޭ، ލައިން، ޕޮލިލައިން، ސަރކަލް، އާރކް އަދި ނުކުތާތަކުގައި. |
| ސްމޫތް (G2)، އަދި ޕޮލިލައިނުގެ އާރކް ބަލްޖް ސީދާ ކޮންސްޓްރެއިން ކުރުން | ޓޭންޖެންޓް އަދި އެކްވަލް؛ އާރކް ސެގްމަންޓް އޭގެ ދެ އެންޑް ފޮލޯ ކުރެއެވެ. |
| ރެފަރެންސް (ޑްރައިވަން) ޑައިމެންޝަނަލް ކޮންސްޓްރެއިންޓްސް، އަދި {{cmd:DCANGULAR}} ގައި `3Point` | ސާދާ ޑައިމެންޝަނެއް (DIMLINEAR …) އަގެއް ދައްކަނީ އޭގެ ފަހަރު ނުކުރާ. |
| ކާޑް ސައިޒުގެ ޑައިމެންޝަނަލް ކޮންސްޓްރެއިންޓްސް، އަދި އެތަކެތި ޕްލޮޓް ކުރުން | އެތައް ހުރީ ސްކްރީން ގައި ހަމައެކަނި؛ ޕްލޮޓަށް ސާދާ ޑައިމެންޝަންތައް އިތުރު ކުރޭ. |
| EXPLODE، BREAK، JOIN އަދި އެހެން އައު އޮބްޖެކްޓްތައް ހަދާ ކޮމާންޑްތައް މެދުވެރި ކޮންސްޓްރެއިންޓްސް، އަދި ޓްރިމް ކުރެވުނު ޕޮލިލައިންތައް | އަލުން ކޮންސްޓްރެއިން ކުރޭ (AUTOCONSTRAIN އިތުރު އަޅައެވެ). {{cmd:MIRROR}} އަދި {{cmd:TRIM}} ލައިންތަކާއި އާރކްތަކާއި ސަރކަލްތަކުގެ ކޮންސްޓްރެއިންޓްސް ބެހެއްޓެވެ. |
| CadCraft ގައި ޑިޒައިން ޓޭބަލްތައް (ކޮންފިގަރޭޝަންތައް) | ޕެނަލްގައި ޕެރާމީޓަރ ބަދަލުކުރޭ. |
| SolidWorks ފަހުން ޓެސްޓް ކުރެވުނު ރައުންޑް ޓްރިޕް | މެކްރޯ ހަދާ ސްކެޗް ބަލާ ކަމަށް ބަލާ ކުރުމުގެ ކުރިން ބަލާ. |

## 3D

| އަދި ހަދާފައެއް ނެތް | ބަދަލަށް، މިއަދު |
|---|---|
| ފިލެޓް، ޗޭމްފަރ، ޝެލް އަދި ލޯފްޓް؛ މަތިން އުރުވާ ޕާތް ސުވޭޕް (3D ޕާތް) | އާރކްތަކާއެކު އައުޓްލައިންތައް އެކްސްޓްރޫޑް ކުރޭ، ފުރާ ފެންމަތި ފުރާ ނުވަތަ ފަހަލަށް ދާ ޕާތް ސުވޭޕް ކުރޭ؛ ރިވޯލްވް ކުރޭ އަދި ސޮލިޑް ފަހުން ފެންނާ ކޯނަ ކުރޭ. |
| މަތީ ދިމާއަށް ނޫން އެހެން ދިމާއަކަށް އެކްސްޓްރޫޑް ކުރުން | ބިމުގައި ޝޭޕް ޑްރޯ ކޮށް އުރުން ނުވަތަ ދަށަށް އެކްސްޓްރޫޑް ކުރޭ (ޓޭޕަރ ނުވަތަ ޕާތާއި އެކު ބޭނުންނަމަ)، ފަހުން ސޮލިޑް ފަރުމާ ކުރޭ. |
| 2D އޮބްޖެކްޓްތަކުގެ އުސް އަދި ޘިކްނަސް | ޑްރޯއިންގ 3D ޓެބުގައި ބިމުގައި (އުސް 0) ހުރެއެވެ. |
| ބޭރުގެ ޕްރޮގްރާމްތަކުން ސޮލިޑްސް، ރީޖަންސް އަދި ބޮޑީޒް އެޑިޓްކުރުން؛ ބްލޮކްތަކުގެ ތެރޭ އެތައް ފެންނަން؛ ސުވޭޕް، ލޮފްޓް ނުވަތަ އެހެން ފްރީފޯމް މަތިތަކުގެ ފޭސްތައް؛ ޕޮލިފޭސް އަދި ޕޮލިގަން މެޝްތައް | މޮޑެލް ސްޕޭސްގެ ސޮލިޑްސް 3D ޓެބުގައި ހުންނަ ގޮތުގައި ފެންނާ އަދި DWG ގައި ބަދަލެއް ނެތި ރައްކާކުރެވެ؛ ނުދައްކާ ހުރިހާ އެއްޗެއް 3D ޓެބް ހުޅުވާއިރު ލިސްޓް ކުރެވެ. މެޝްތައް މޮޑެލް ސްޕޭސްގައި 3D ފޭސް ގޮތުން ހޯދާ. [އެހެން ޕްރޮގްރާމްތަކުން ސޮލިޑްސް](topic:3d-solids#solids-from-other-programs) ބަލާ. |
| ސޮލިޑްސް ކޮޕީ ކުރުން އަދި ޕޭސްޓް ކުރުން | 3D ޓެބުގައި {{cmd:COPY}} ބޭނުން ކުރޭ. ކްލިޕްބޯޑުގައި 2D އޮބްޖެކްޓްތައް ނޫން ހުންނާނެ. |
| ކަނޑުތައް، ސޮލިޑްތަކުގެ ބަދަލުވާ ވިއުތައް ފަހަރު ފައްސާކުރުން؛ ޕްލޮޓް ކުރެވުނު ޝީޓްތަކުގައި ހަދާ ޝޭޑްޑް ސޮލިޑްސް | {{cmd:VIEWBASE}} ފްލެޓް ވިއުތައް ޖައްސަވާ (ސްނެޕްޝޮޓެއް)؛ ސޮލިޑްސް ބަދަލުކުރެވުނު ފަހަރު އަލުން ރަން ކުރޭ. |
| މެޓީރިއަލްތައް، ޓެކްސްޗަރތައް އަދި ލައިޓިންގ ސެޓިންގްސް | ވިޒުއަލް ސްޓައިލްތައް: ޝޭޑްޑް، އެޖަސް، ހިޑަން ލައިން، ވައިރްފްރޭމް، އެކްސް-ރޭ. |
| ޕްލޮޓް ކުރެވުނު ލޭގެ ނަޤްޝާ ޝީޓްތަކުގެ ވިއުޕޯޓްތަކާއި 3D ޓެބުގައި؛ ފައިލްތަކުން ރައްކާކުރެވުނު ޕިކްޗަރތައް ޑްރޯއިންގާއެކު؛ ޑްރޯއިންގެ ލޮކޭޝަން DWG 2000–2007 އަދި DXF R12 ގައި އެހެން ޕްރޮގްރާމްތަކަށް ލިޔެފައިވާ | މޮޑެލް ސްޕޭސްގެ ދަށުން ސްކްރީންގައި ނަޤްޝާ ލޭ ފެންނާ؛ ސިސްޓަމާއި ލޭ ލިސްޓް ޑްރޯއިންގާއެކު ރައްކާކުރެވެ: [ޑްރޯއިންގުގެ ދަށުގެ ނަޤްޝާ ލޭ](topic:map-layers) ބަލާ |
| 6 މިލިއަންއަށްވުރެ ގިނަ ޕޮއިންޓް ނުވަތަ 512 MB ވާ E57 ސްކޭންތައް، ސްކޭނަރ ހަދާ މީހުންގެ އަމިއްލަ ފައިލްތައް (RCP, RCS, FLS, LGS, TZF, ZFS)، ޑްރޯއިންގާއެކު ރައްކާކުރެވުނު ނުވަތަ ޕްލޮޓް ކުރެވުނު ޕޮއިންޓް ކްލައުޑް، 3D ޓެބުގައި ކްލައުޑަށް ސްނެޕްކުރުން، މޮޑެލް ޓެބުގައި އުނދަ (ސެކްޝަން) ޝްލައިސްތައް | ބޮޑު ނުވަތަ ހަދާ މީހުންގެ ސްކޭނުތައް LAS ނުވަތަ LAZ ގެ ގޮތުން އެކްސްޕޯޓް ކުރޭ ([ޕޮއިންޓް ކްލައުޑް ފޯމެޓްސް](topic:point-cloud-formats))؛ ޑްރޯއިންގ ހުޅުވާ ކޮންމެ ފަހަރުވެސް ކްލައުޑް އަލުން އެޓާޗް ކުރޭ؛ މޮޑެލް ޓެބުގައި ޕްލޭން ޝްލައިސްއިން ޓްރޭސް ކުރޭ: [ޕޮއިންޓް ކްލައުޑްގެ މަތީން ބިނާ ލައިން ޓްރޭސް ކުރުން](topic:point-clouds) ބަލާ |
| ސްކޭންތައް ރެޖިސްޓަރ ކުރުން: ސްކޭންތަކުގައި އަމިއްލައަށް ޓާގެޓް (ސްފެއާ، ޗެކަބޯޑް) ހޯދުން، ހުރިހާ ސްކޭންތައް އެއްކޮޅަށް ސޮލްވްކުރުން (bundle adjustment)، ސްކޭލް، މޮޑެލަކާ ރެޖިސްޓަރ ކުރުން | ދެމިހުރި ޕޮއިންޓްތައް އިޚްތިޔާރުކުރޭ ނުވަތަ ޓާގެޓް ކޯޑިނޭޓްތައް ޓައިޕްކުރޭ، ފަހުން ICP އިން ސްކޭނެއް އެއް ފަހަރަށް ރިފައިން ކުރޭ: [ސްކޭން ގިނަ ތަކެއް އެއް ތަނަކަށް ރެޖިސްޓަރ ކުރުން](topic:register-scans) ބަލާ |

## ހެލްޕް

ހެލްޕް މި ބިލްޑް ވިސްނައިދެއެވެ. އައު ކަމެއް ލިބުމުން، އެ މި ޞަފްޙާއިން ނުކުތާ ކުރައްވާ އަދި ހަދާ ޕުރުކްރަމްތަކަށް ގެނެސްދެއެވެ.
