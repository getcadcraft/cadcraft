## ތިރީގައި ދަސްކުރާނީ

ޑްރޯއިންގ ފައިލްތަކުން ޝީޓްތައް (ލޭއައުޓްތައް) ކިހިނެއްތޯ **ޝީޓް ސެޓް** އަކަށް އެއްކުރުން، އަދި ނަންބަރު ދީ ސުރުޚީ ދިނުން، އެމީހުންގެ ޓައިޓްލް ބްލޮކްތައް އަމިއްލަ ގޮތުން ފުރާ ދިނުން، މުޅި ސެޓް އެއް PDF އަށް ޕަބްލިޝް ކުރުން، އަދި ފުރަތަމަ ފާޅު ފޮނުވުމަށް ހުރިހާ ކަމެއް އެއް ޒިޕަށް ޕެކް ކުރުން.

ޝީޓް ސެޓް އަމިއްލަ ފައިލަކުގައި ހުންނާނެ، `<name>.ccsheets` ގެ ގޮތުން، ޑްރޯއިންގ ހުރި ފޯލްޑަރުގައި. ސެޓް ފައިލް ޝީޓްތައް ފޯލްޑަރުން ސާފު ފަތުރު ޖަހައި ލިސްޓް ކުރެއެވެ، އެހެންވީމާ ފޯލްޑަރ ހުރިހާ ހިއްލާ ނުވަތަ ކޮޕީ ކުރެވޭ.

:::note
ފޯލްޑަރއެއް ކިޔުމަށާއި ލިޔުމަށް Chrome ނުވަތަ Edge ބޭނުންވެއެވެ (ފޯލްޑަރ ހޮވާފައި ހުރި ހިސާއިން ކުރެވޭ)، ނުވަތަ ޑެސްކްޓޮޕް އެޕް. އެހެން ބްރައުޒަރުތައް ސެޓް ރީޑް އޮންލީން ހުޅުވައެވެ: ބަލަން އަދި ޕަބްލިޝް ކުރެވޭ، އަދި ސެޓް ފައިލް ޑައުންލޯޑު ވެއެވެ.
:::

## ސެޓެއް ފެށޭ

1. ގަޑު ޕެނަލުގައި {{ui:Sheet set}} ބައި ހޯދާ، އޭގެ {{ui:Set}} މެނޫ ހުޅުވާ. {{cmd:SHEETSET}} (ނުވަތަ `SSM`) ޓައިޕް ކުރުމުންވެސް އެތަނަށް ވާނެއެވެ.
2. {{ui:New set…}} ހޮވޭ. ސެޓަށް ނަމެއް ދީ، ބޭނުންނަމަ ޕްރޮޖެކްޓް ނަމާއި ނަންބަރު ވެސް ލިޔޭ.
3. ޑްރޯއިންގ ހުންނަ ފޯލްޑަރ ހޮވޭ. ސެޓް ފައިލް އޭގައި ރައްކާވެއެވެ.

ފަހުން ސެޓް ހުޅުވުމަށް {{ui:Open set…}} ހޮވައި އެ ފޯލްޑަރ ހޮވޭ. ފޯލްޑަރ ސެޓް ގިނަ ނަމަ CadCraft ސުވާލު ކުރެއެވެ ކޮންކަން.

## ޝީޓް އިތުރު ކުރޭ

1. {{ui:Add sheets from a drawing…}} ހޮވާ، އަދި ފޯލްޑަރގެ ޑްރޯއިންގ އެއް ހޮވޭ.
2. CadCraft އެ ޑްރޯއިންގ ފަހަށް ކިޔަވައި (ސްކްރީނުގައި ނުހުޅުވާ) އޭގެ ޝީޓްތައް ލިސްޓް ކުރެއެވެ. ބޭނުންވާ ޝީޓްތައް ޓިކް ކޮށް {{ui:OK}} ކްލިކް ކުރޭ.
3. ޝީޓެއް ހޮވައި {{key:F2}} ފިތާ (ނުވަތަ {{ui:Rename and renumber…}}) އަދި ނަންބަރެއް އަދި ސުރުޚީއެއް ދޭ، ފަދައިން `A-101` އަދި `Floor plan`.

{{ui:New sheet from template…}} އެއް ޑްރޯއިންގ ޝީޓުން އާ ޑްރޯއިންގ އެއް ހަދައި، އެ ޑްރޯއިންގ (ޓައިޓްލް ބްލޮކް އަދި ވިއުޕޯޓްތައް) އާ ޝީޓުގެ ނަމަކަށް ނަމަކޮށް އިތުރުކުރޭ. ސެޓް އޭގެ ޓެމްޕްލޭޓް ކަމަށް ބޭނުން ކުރި ޑްރޯއިންގ ހަނދާން ކުރެއެވެ.

## ސެޓް ރީތިކޮށް ހަމަޖެހޭ

- **ސަބްސެޓްތައް** ޝީޓްތައް ގުޅައި ގްރޫޕްކުރޭ، ފަދައިން Architectural › Plans: ކޮތަނަށް ދާ ތަން ހޮވާ، {{ui:New subset…}} ހޮވޭ.
- **ތަރުތީބު**: ޝީޓެއް ލިސްޓްގެ އަނެއް ތަނަކަށް ހެޔޮ ކުރޭ، ނުވަތަ ސަބްސެޓަކަށް ފޮނުވަން ހެޔޮ ކުރޭ. ކީބޯޑުން، ހޮވާ {{key:Alt+Up}} ނުވަތަ {{key:Alt+Down}} ފިތާ.
- **ޝީޓް ހުޅުވޭ**: ދެ ފަހަރު ކްލިކް ކުރޭ (ނުވަތަ {{key:Enter}} ފިތާ). އޭގެ ޑްރޯއިންގ އަމިއްލަ ޓެބުގައި އެ ޝީޓުގައި ހުޅުވޭ.
- **ނެގުން**: ހޮވާ {{key:Delete}} ފިތާ. ޑްރޯއިންގ އަމިއްލައަށް ނުބަދަލުވެއެވެ.
- **އަނބުރާ**: {{ui:Undo set change}} އަދި {{ui:Redo set change}} ސެޓުގައި ބަދަލު ކުރި ކަންތައް ސްޓެޕްކޮށް ދާއެވެ.
- **ރީނަންބަރު**: {{ui:Renumber sheets…}} ހުރިހާ ޝީޓަކަށް، ނުވަތަ ސަބްސެޓަކުގެ ޝީޓްތަކަށް، ލިސްޓުގެ ތަރުތީބުން ނަންބަރުކުރޭ: ޕްރީފިކްސް، ފުރަތަމަ އަދަދު އަދި ހަ ސްޓެޕް (`A-` އަދި `101` ހިނގާ A-101، A-102 …).

ހުރިހާ ބަދަލެއް ސެޓް ފައިލްގައި ވަގުތުން ރައްކާ ވެއެވެ.

## ފީލްޑްތައް ހަދާ ނަންބަރު ދޭ

ކަލޭގެފާނު ނަންބަރު އަތުން ނުދެވުމަށް، ޝީޓުގެ ފީލްޑްތަކުން ކޮންމެ ނަންބަރެއް ހަދާ ރަނގަޅު ގާޢިދާއެއް ބޭނުން ކުރޭ، ފަދައިން ޝީޓް އެއް ލެވެލަށް ނުވަތަ ޑިސިޕްލިން އަށް ފޮނުވާ އަދި ނަންބަރު ގޮތުން ލިބެއެވެ.

1. ކޮންމެ ޝީޓަކަށް އޭގެ ފީލްޑްތައް ދީ: ހޮވާ، {{ui:Rename…}} ކްލިކް ކުރޭ، އަދި {{ui:Fields of this sheet}} ގައި، ކޮންމެ ލައިނަށް އެއް ލިޔުއްވާ، ފަދައިން `DISCIPLINE = A` އަދި `LEVEL = 1`. ހުރިހާ ސެޓަށް ހަމަ ފީލްޑެއް (ފަދައިން `DISCIPLINE = A`) ސެޓުގެ {{ui:Properties…}} ގައި ލިޔެވޭ.
2. ޕެނަލުގެ މެނޫ ހުޅުވާ، {{ui:Numbering rule…}} ކްލިކް ކުރޭ.
3. ގާޢިދާ ލިޔުއްވާ، ފަދައިން `{DISCIPLINE}-{LEVEL}{SEQ:2}`. `{SEQ}` ގުނަނީ އެ ޝީޓުތަކުގެ ތެރޭގައި އެންމެހައި އަނެއް ފީލްޑްތައް އެއްބަސްވާ ނަމަ؛ ލެވެލް 1 އަށް A-101، A-102 އަދި ލެވެލް 2 އަށް A-201 ފެށޭ. `{SEQ:2}` ދެ ނަމްބަރުން ލިޔެދެއެވެ؛ `{SUBSET}` ޝީޓް ހުރި ސަބްސެޓުގެ ނަމެވެ.
4. ފީލްޑެއް ބަދަލުވުމުން ކުރެވޭ ކަން ނިންމާ: {{ui:Renumber the sheets}} ބަދަލު ކޮންމެ ފަހަރަކު ގާޢިދާ ފަހުން ނަންބަރުތައް ބެހެއްޓެއެވެ؛ އެހެން ހުއްޓުން ތަނުގައި ހަމަ ހުރި ގޮތުން ނަންބަރު ދެއެވެ.

ގާޢިދާ ސެޓް ފައިލްގައި ރައްކާވެއެވެ. އެ އަމިއްލައަށް ރީނަންބަރު ކުރާ ހިނދު ޝީޓުގެ ނަންބަރު ބަދަލު ނުކުރި، ފީލްޑްތައް ބަދަލު ކުރޭ.

## ޓައިޓްލް ބްލޮކްތައް ސެޓުން ފުރާ

ޓައިޓްލް ބްލޮކެއްގެ ޓެކްސްޓް ސެޓުން ލިބެނީ އޭގެ އެޓްރިބިއުޓުތައް ފީލްޑް ނަމާ ޓެގް ކުރާއިރު:

| ޓެގް | ދައްކާ ކަން |
|---|---|
| `SHEETNUMBER` (ނުވަތަ `SHEET_NO`، `DWG_NO`) | ޝީޓްގެ ނަންބަރު |
| `SHEETTITLE` (ނުވަތަ `TITLE`، `SHEET_TITLE`) | ޝީޓްގެ ސުރުޚީ |
| `SHEETDESC` | ޝީޓްގެ ތަފްޞީލް |
| `PROJECTNAME` (ނުވަތަ `PROJECT`) | ޕްރޮޖެކްޓްގެ ނަން |
| `PROJECTNUMBER` (ނުވަތަ `PROJECT_NO`، `JOB_NO`) | ޕްރޮޖެކްޓްގެ ނަންބަރު |
| `SHEETSETNAME` | ސެޓްގެ ނަން |
| `SHEETINDEX`، `SHEETCOUNT` | "3 of 12"، އަދި 12 |
| ތިބާގެ އަމިއްލަ، ފަދައިން `CLIENT` | {{ui:Set fields…}} ގައި ތިބާ ލިޔެފައިވާ އެކަން |

{{ui:Set fields…}} ގައި ޕްރޮޖެކްޓް ނަމާއި ނަންބަރާއި ތިބާގެ އަމިއްލަ ފީލްޑްތައް، ކޮންމެ ލައިނަކަށް `NAME = value` ގެ ގޮތުން.

{{ui:Update drawings}} ސެޓުގެ ހުރިހާ ޑްރޯއިންގެ ޓައިޓްލް ބްލޮކްތަކަށް ނަންބަރުތައް، ސުރުޚީތައް އަދި ފީލްޑްތައް ލިޔެ، ކޮންމެ ޝީޓުގެ ލޭއައުޓް ޓެބް ސެޓުގެ ގޮތުން ރީނަމް ކުރެއެވެ (ފުރަތަމަ ގޮތުން ނަންބަރާއި ސުރުޚީ، ފަދައިން `A-101 Floor plan`؛ {{ui:Set fields…}} › {{ui:Layout tab names}} އިން ބަދަލު ކުރެވޭ). ކޮންމެ ޑްރޯއިންގ އެ ތަނުގައި އޭގެ ފޯމެޓާއި ވާރޝަނުން ރައްކާ ވެއެވެ. ނަންބަރު ނުވަތަ ސުރުޚީ ބަދަލު ކުރުމަށްފަހު އަލުން ހިންގޭ، އަދި ޓެބުތަކާއި ޓައިޓްލް ބްލޮކްތައް ފަހުން ފޮލޯ ކުރައި.

## ޝީޓް ލިސްޓެއް ކަވާ ޝީޓްގައި

ޝީޓް ލިސްޓުގައި ކަވާ ޝީޓް ހޮވޭ، އަދި {{ui:Put the sheet list on this sheet}} ހޮވޭ. ހުރިހާ ޝީޓެއްގެ ޓޭބަލެއް (ނަންބަރާއި ސުރުޚީ، އޭގެ ސަބްސެޓުގެ ދަށުން) އެ ޝީޓުގެ ބާ އުޑު ކުރި ކޮޅުގައި ވާ. {{ui:Update drawings}} އަދި {{ui:Publish to PDF}} އެ އަލުން ހަދައި ގެންދެއެވެ. އެއީ ބްލޮކެއް، `CC_SHEETLIST`: އެއް ބްލޮކް ރެފަރެންސެއް ފަދައިން ހިއްލާ ކުރޭ.

## ސެޓް ޕަބްލިޝް ކުރޭ

{{ui:Publish to PDF}} PDF އެއް ހަދައި، ކޮންމެ ޝީޓަށް ޞަފްޙާއެއް، ސެޓުގެ ތަރުތީބުން، ކޮންމެ ޝީޓުގެ އަމިއްލަ ކާޑު ސައިޒުން، ކޮންމެ ޝީޓަށް ބުކްމާކެއް ("A-101 — Floor plan"). ސަބްސެޓެއް ހޮވިއްޔާ CadCraft އަހާ ހޭދަ ކުރޭ އެ ސަބްސެޓް ކަމަށް ޕަބްލިޝް ކުރުމަށް. PDF ގައި ޓައިޓްލް ބްލޮކްތައް ސެޓުން ފުރާ، ބޭވަނީ ޑްރޯއިންގ ތާޒާ ނުކުރި ކުރިންވެސް؛ ޕަބްލިޝް ކުރުމުން ޑްރޯއިންގ ބަދަލު ނުވެއެވެ. PDF ޑައުންލޯޑް ވެއެވެ.

{{ui:Publish to DWG…}} ކޮންމެ ޝީޓަކަށް އަމިއްލަ DWG އެއް (DWG 2018): މޮޑެލް އަދި އެ ޝީޓް އެކަނި، އޭގެ ޓައިޓްލް ބްލޮކް ސެޓުން ފުރައި، ނަންބަރާއި ސުރުޚީން ނަމަކޮށް (`A-101 Level 1 floor plan.dwg`). {{ui:DWG}} ހޮވޭ، ނުވަތަ {{ui:DWG + PDF}} ސެޓް PDF ހާއި އެކު. `publish.json` ކޮންމެ ފައިލެއް ސައިޒާއި SHA-256 ހިމެނޭ ލިސްޓް. ސެޓުގެ ފޯލްޑަރ ލިޔެވެންޖެހޭ ހިނދު (CadCraft Studio، ނުވަތަ ބްރައުޒަރުގައި ހޮވި ފޯލްޑަރ)، ފައިލްތައް `<set name> - published` ފޯލްޑަރއަކަށް ވަންނާނެ؛ އެހެން ނަމަ އެކަކު ޒިޕްގެ ގޮތުން ޑައުންލޯޑް ވެއެވެ. Viewport [class overrides](topic:viewport-overrides) ކޮންމެ DWG އަކާ އެކު ގެންދެއެވެ.

## ސެޓް އާކައިވް ކުރޭ

{{ui:Archive as a zip}} ސެޓް ފައިލް، އެ ގެން ދާ ހުރިހާ ޑްރޯއިންގ، އަދި އެ ޑްރޯއިންގ ބެހެއްޓި ކަންތައް (ލިންކްކޮށްފައިވާ ޑްރޯއިންގ، އަދި އެގެ ތަކެތި، އަދި ފޮޓޯތައް)، ފޯލްޑަރ ފަރާތް ރައްކާކޮށް، އަދި ހުރިހާ ފައިލް ލިސްޓް ކުރާ `Transmittal.txt` ހިމަނައި ޕެކްކުރޭ. ސެޓްގެ ފޯލްޑަރުގައި ނެތް ލިންކެއް މެދު ނެތް ގޮތުން ލިސްޓުގައި ދެވޭ. ލިންކްތައް ޑްރޯއިންގުން އޭގެ ފަތުރުން، ދެން ފޯލްޑަރުގައި ހުރި ނަމުން ހޯދެވެ.

## ސެޓް ފައިލް

`.ccsheets` ފައިލް JSON އެވެ، ކޮންމެ ޓެކްސްޓް އެޑިޓަރެއްގައި ކިޔެވޭ:

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

ފަތުރުތައް ސެޓުގެ ފޯލްޑަރުން ރެޕަރީ، ފޯލްޑަރު ތަފާތު `/` ނިޝާނުން. CadCraft ފައިލް ހުޅުވާ ހިނދު ހުށަހަޅާ: އެއްޗެއް ދިމާ ފަތުރެއް، ފައިލެއް ނެތް ޝީޓެއް ނުވަތަ ލޭއައުޓެއް، ނުވަތަ ސާދާ ނޫން ޓެކްސްޓް ލިބިފައި ހުރި ނަމަ ފޮހެލާ، އަދި ހިސްޓްރީ އެ ކަން ދައްކާ.
