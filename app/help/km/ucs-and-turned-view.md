## អ្វីដែលអ្នកនឹងរៀន

របៀបមើលគំនូរប្លង់ដែលបានបង្វិល ដូច្នេះអាគារដែលគូរជាមុំមើលទៅត្រង់នៅលើអេក្រង់ និងរបៀបវាយចំណុចតាមអ័ក្សរបស់វា។ គ្មានអ្វីនៅក្នុងគំនូរប្លង់ផ្លាស់ទីពេលអ្នកធ្វើវា៖ វត្ថុរក្សាកូអរដោនេរបស់ពួកវា ការបង្វិលមិនមែនជាការកែសម្រួល ហើយគំនូរប្លង់មិនត្រូវបានសម្គាល់ថាបានផ្លាស់ប្ដូរទេ។

## បង្វិលទិដ្ឋភាពមួយភាគបួន

1. ចុច {{ui:View}} › {{ui:More}} › {{ui:Turn view 90° left}} ឬ {{ui:Turn view 90° right}}។

គំនូរប្លង់បង្វិលនៅលើអេក្រង់ជុំវិញកណ្ដាលតំបន់គំនូរប្លង់។ ធ្វើវាម្ដងទៀតដើម្បីបង្វិលបន្ត។

2. ចុច {{ui:View}} › {{ui:More}} › {{ui:Back to world}} ដើម្បីធ្វើឱ្យវាត្រង់ម្ដងទៀត។

ពាក្យបញ្ជាពីក្រោយពួកវាគឺ {{cmd:TURNLEFT}}, {{cmd:TURNRIGHT}} និង {{cmd:TURNWORLD}}។ ដើម្បីផ្ដល់គ្រាប់ចុចមួយ បន្ថែមបន្ទាត់ដូចជា `TL=TURNLEFT` ទៅ alias របស់អ្នកជាមួយ {{cmd:ALIASEDIT}}។

## តម្រឹមជាមួយអាគារមុំ

1. វាយ `UCS` ហើយចុច {{key:Enter}} បន្ទាប់មក `OB` និង {{key:Enter}}។
2. ចុចបន្ទាត់ជញ្ជាំងនៅជិតចុងដែលគួរជាដើម។

UCS ឥឡូវចាប់ផ្ដើមនៅចុងនោះ ជាមួយអ័ក្ស X របស់វាតាមជញ្ជាំង ហើយទិដ្ឋភាពបង្វិលដូច្នេះជញ្ជាំងត្រង់នៅលើអេក្រង់។ រូបតំណាងអ័ក្សនៅជ្រុងខាងក្រោមឆ្វេងបង្ហាញទិសដៅដែលអ័ក្ស UCS ចង្អុល។

3. គូរដូចធម្មតា។ ពេល UCS ត្រូវបានកំណត់៖
   - `x,y` និង `@dx,dy` ត្រូវបានវាស់តាមអ័ក្ស UCS; `d<a` វាស់មុំពីអ័ក្ស X របស់ UCS។
   - {{ui:Ortho}} ការតាមដានប៉ូឡា និងក្រឡាចត្រង្គធ្វើតាមអ័ក្ស UCS ហើយឈើឆ្កាងក៏ដូចគ្នាដែរ។
   - អត្ថបទថ្មី និងកថាខណ្ឌថ្មីដំណើរការតាមអ័ក្ស X របស់ UCS; ផ្ដេក និងបញ្ឈរនៃ {{cmd:DIMLINEAR}} ធ្វើតាមវាដែរ។
   - កូអរដោនេនៅរបារស្ថានភាព និងពី {{cmd:ID}} គឺជាកូអរដោនេ UCS។
4. ដើម្បីវាយចំណុចពិភពលោកខណៈ UCS ត្រូវបានកំណត់ ដាក់ `*` នៅខាងមុខ៖ `*0,0` ឬ `@*100,0`។
5. វាយ `UCS` {{key:Enter}} បន្ទាប់មក {{key:Enter}} ម្ដងទៀតដើម្បីត្រឡប់ទៅពិភពលោក។

## វិធីផ្សេងទៀតដើម្បីកំណត់ UCS

នៅសំណួរ {{cmd:UCS}}៖

| អ្នកវាយ | អ្វីដែលវាធ្វើ |
|---|---|
| ចំណុច | ដើមថ្មី; បន្ទាប់មកចុចចំណុចលើអ័ក្ស X ថ្មី ឬចុច {{key:Enter}} ដើម្បីរក្សាមុំ |
| `Z` | បង្វិល UCS ជុំវិញដើមរបស់វាដោយមុំដែលអ្នកវាយ (ដឺក្រេ ច្រាសទ្រនិចនាឡិកា) ឬជ្រើស |
| `3` (3point) | ដើម ចំណុចតាមអ័ក្ស X វិជ្ជមាន និងចំណុចនៅផ្នែក Y វិជ្ជមាន |
| `OB` (OBject) | ពីបន្ទាត់ ធ្នូ រង្វង់ ផ្នែកពហុបន្ទាត់ អត្ថបទ យោងប្លុក ចំណុច ឬបន្ទាត់ជាក់ស្ដែង |
| `P` (Previous) | UCS មុនមួយនេះ (ដប់ចុងក្រោយត្រូវបានរក្សាខណៈគំនូរប្លង់បើក) |
| `W` (World) | ត្រឡប់ទៅពិភពលោក |
| `NA` (NAmed) | `S` រក្សាទុក UCS បច្ចុប្បន្នក្រោមឈ្មោះ `R` ស្ដារមួយ `D` លុបមួយ `?` បញ្ជីពួកវា |

គ្រប់ការផ្លាស់ប្ដូរបង្វិលទិដ្ឋភាពដូច្នេះអ័ក្ស X UCS ថ្មីត្រង់។ {{cmd:PLAN}} បង្វិលទិដ្ឋភាពដោយមិនផ្លាស់ប្ដូរ UCS៖ {{key:Enter}} សម្រាប់ UCS បច្ចុប្បន្ន `U` សម្រាប់ដែលបានរក្សាទុក `W` សម្រាប់ពិភពលោក។

## ដែលគួរដឹង

- ផ្ទាំងនីមួយៗនៃអេក្រង់បែងចែករក្សាការបង្វិលរបស់ខ្លួន។ UCS ជារបស់គំនូរប្លង់។
- សន្លឹកធ្វើការជាមួយកូអរដោនេក្រដាស; កំណត់ UCS នៅផ្ទាំង {{ui:Model}} ឬនៅខាង viewport។
- វិនដូជ្រើសរើសដែលអូសនៅក្នុងទិដ្ឋភាពបង្វិល ជ្រើសអ្វីដែលស្ថិតនៅខាងក្នុងពួកវានៅលើអេក្រង់។
- ការបញ្ជា LISP ទទួលចំណុចក្នុង UCS ពី `getpoint` អាចអាន `UCSORG`, `UCSXDIR`, `UCSYDIR` និង `VIEWTWIST` ហើយ `trans` បម្លែងរវាងពិភពលោក UCS និងការបង្ហាញ។

:::note
ឯកសារដែលបានរក្សាទុកនឹងរក្សា UCS និងការបង្វិលទិដ្ឋភាពនៅកំណែក្រោយ; រហូតដល់ពេលនោះ វានៅជាប់ខណៈគំនូរប្លង់បើក។
