## អ្វីដែលអ្នកនឹងរៀន

របៀបផ្លាស់ប្ដូរអក្សរដែលអ្នកវាយដើម្បីឆ្លើយតបជម្រើសពាក្យបញ្ជា។ ឧទាហរណ៍ {{cmd:ARRAY}} សួរ `[Rectangular/POlar]` ហើយយក `PO` សម្រាប់ Polar; អ្នកអាចធ្វើឱ្យ `P` ឬអក្សរផ្សេងទៀតធ្វើដូចគ្នា ជាភាសារបស់អ្នកក៏បាន។

## របៀបឆ្លើយតបជម្រើស

ពេលពាក្យបញ្ជាបង្ហាញជម្រើសក្នុងវង់ក្រចកការ៉េ អក្សរធំគឺជាអ្វីដែលត្រូវវាយ៖ `POlar` គឺ `PO`, `eXit` គឺ `X`។

អ្នកក៏អាចវាយអក្សរតិចជាងនេះបានដែរ។ បើអ្វីដែលអ្នកវាយសមតែជម្រើសមួយក្នុងចំណោមជម្រើសដែលបង្ហាញ CadCraft យកវា៖ ជាមួយ `[Rectangular/POlar]` `P` តែមួយគឺ Polar។ បើសមពីរ បន្ទាត់បញ្ជាបញ្ជាក់ឈ្មោះទាំងពីរ ហើយសួរម្ដងទៀត៖

```
C could be COUnt, COLumns. Type more letters.
```

លេខមិនដែលត្រូវបានទាយទេ ដូច្នេះចម្ងាយ ឬចំនួនដែលបានវាយតែងតែអានជាលេខ។

## បន្ថែមអក្សររបស់អ្នក

ពាក្យបញ្ជាទាំងអស់រក្សាអក្សរដែលមកជាមួយរបស់ខ្លួន។ អ្នកបន្ថែមអក្សររបស់អ្នកពីលើ ដូច្នេះបញ្ជីរបស់អ្នកមានតែអ្វីដែលអ្នកបានផ្លាស់ប្ដូរប៉ុណ្ណោះ។

1. បើក {{ui:Settings}} ({{key:Mod+,}}) › {{ui:CadCraft}} › {{ui:Option letters}} ហើយចុច {{ui:Edit…}}។ ឬវាយ {{cmd:OPTIONKEYS}} ហើយចុច {{key:Enter}}។
2. នៅក្រោម {{ui:Command}} ជ្រើសពាក្យបញ្ជា ឧទាហរណ៍ `ARRAY`។ បញ្ជីមានពាក្យបញ្ជាទាំងអស់ដែលសួរជម្រើស ហើយចាប់ផ្ដើមនៅពាក្យបញ្ជាដែលអ្នកបានប្រើចុងក្រោយ។
3. នៅក្រោម {{ui:Option}} ជ្រើសជម្រើស។ ជម្រើសនីមួយៗបង្ហាញអក្សរដែលមកជាមួយរបស់វានៅក្នុងវង់ក្រចក ឧទាហរណ៍ `POlar (PO)`។
4. នៅ {{ui:Your letters}} វាយអក្សរដែលអ្នកចង់បាន ឧទាហរណ៍ `P` ហើយចុច {{ui:Add}}។
5. ជម្រើសឥឡូវបង្ហាញនៅក្រោម {{ui:Your letters}} ជាមួយអក្សរដែលមកជាមួយ និងអក្សររបស់អ្នក។ ចុច {{ui:Save}}។

ចាប់ផ្ដើម {{cmd:ARRAY}} ជ្រើសវត្ថុមួយ ហើយចុច {{key:Enter}}។ ការសួរបង្ហាញអក្សររបស់អ្នកបន្ទាប់ពីជម្រើស `POlar (P)` ហើយ `P` ឆ្លើយតប។

ដើម្បីដកមួយចេញ ចុចសញ្ញា x នៅចុងជួររបស់វា ហើយបន្ទាប់មកចុច {{ui:Save}}។ ជម្រើសនោះត្រឡប់ទៅអក្សរដែលមកជាមួយតែប៉ុណ្ណោះ។

## អក្សរដែលអ្នកមិនអាចប្រើបាន

កម្មវិធីកែសម្រួលបដិសេធអក្សរដែលនឹងលាក់អ្វីមួយដែលបន្ទាត់បញ្ជាអានរួចហើយ ហើយបង្ហាញមូលហេតុ៖

- អក្សរដែលមកជាមួយរបស់ជម្រើសផ្សេងទៀតនៃពាក្យបញ្ជាដដែល (`R` សម្រាប់ Polar ក្នុង `ARRAY` ដែល `R` ជា Rectangular);
- ពាក្យចាប់ជាប់វត្ថុបីអក្សរ ឬច្រើនជាងនេះ ដូចជា `END`, `MID` ឬ `CEN` និងពាក្យ `ALL` និង `LAST`;
- អក្សរដូចគ្នាសម្រាប់ជម្រើសផ្សេងគ្នាពីរនៃពាក្យបញ្ជាតែមួយ។

នៅពេលអ្វីមួយត្រូវបានបញ្ជីជាពណ៌ក្រហម {{ui:Save}} ត្រូវបានបិទ៖ កែបន្ទាត់ ឬដកវាចេញ ហើយវាត្រឡប់មកវិញ។ អក្សរដែលមកជាមួយនៃការសួរតែងតែឈ្នះអក្សររបស់អ្នក ដូច្នេះបញ្ជីរបស់អ្នកមិនអាចបញ្ឈប់ការឆ្លើយតបដែលមកជាមួយពីការដំណើរការបានឡើយ។ អក្សរដែលជាឈ្មោះពាក្យបញ្ជា ដូចជា `L` ឬ `C` គឺអនុញ្ញាត៖ នៅពេលសួរជម្រើស បន្ទាត់បញ្ជាកំពុងអានចម្លើយ មិនមែនចាប់ផ្ដើមពាក្យបញ្ជាទេ។

ជម្រើសដែលបានបញ្ជីសម្រាប់ពាក្យបញ្ជាមកពីពាក្យបញ្ជាដែលចែករំលែកការសួររបស់វា ដូច្នេះម្ដងម្កាលពាក្យបញ្ជាបញ្ជីជម្រើសមួយដែលវាសួរតែក្នុងករណីខ្លះ។

## ជម្រើសមួយសម្រាប់ពាក្យបញ្ជាគ្រប់ប្រភេទ

នៅក្រោម {{ui:Command}} ជ្រើស {{ui:Every command}}។ ជម្រើសនោះជាជម្រើសទាំងអស់ដែលពាក្យបញ្ជាណាមួយមាន ដូចជា eXit ឬ Undo។ អក្សរដែលអ្នកបន្ថែមនៅទីនោះឆ្លើយតបជម្រើសនោះគ្រប់ទីកន្លែងដែលពាក្យបញ្ជាផ្ដល់ជូន។ អក្សរដែលបន្ថែមសម្រាប់ពាក្យបញ្ជាមួយឈ្នះលើទាំងនេះ។

## អក្សរក្នុងភាសារបស់អ្នក

អក្សរអាចមកពីអក្ខរក្រមណាក៏បាន ដូច្នេះអ្នកអាចឆ្លើយតបជម្រើសដោយមិនបាច់ប្ដូរក្ដារចុច៖ បន្ថែម `З` សម្រាប់ Close នៅក្រោម {{ui:Every command}} ឬ `П` សម្រាប់ POlar ក្នុង `ARRAY`។

CadCraft មកជាមួយអក្សរអង់គ្លេសតែប៉ុណ្ណោះ។ បញ្ជីផ្ទាល់ខ្លួនរបស់អ្នកគឺជាវិធីដែលអ្នក ការិយាល័យរបស់អ្នក ឬអ្នកដែលចែករំលែកភាសាដូចគ្នា កំណត់ផ្សេងទៀត ហើយ {{ui:Export}} បង្កើតឯកសារដែលអ្នកអាចបញ្ជូនបន្តបាន។

## កែជាអត្ថបទ

{{ui:Edit as text}} ក្នុងកម្មវិធីកែសម្រួលបង្ហាញបញ្ជីដូចគ្នាជាបន្ទាត់អក្សរ មួយសម្រាប់ជម្រើសនីមួយៗ ដែល {{ui:Export}} រក្សាទុកដែរ៖

```
ARRAY.PO,  P
*.X,       Q
```

បន្ទាត់នីមួយៗគឺពាក្យបញ្ជា ចុច អក្សរដែលមកជាមួយនៃជម្រើស ក្បៀស និងអក្សររបស់អ្នក។ ផ្កាយជំនួសពាក្យបញ្ជាមានន័យថាគ្រប់ពាក្យបញ្ជា។ បន្ទាត់ដែលចាប់ផ្ដើមដោយ `;` គឺជាចំណាំ។

## អ្វីដែលនៅដដែល

- អក្សរដែលមកជាមួយនៅតែដំណើរការជាមួយអក្សររបស់អ្នក។
- Routine និងប៊ូតុងរបារឧបករណ៍នៅតែប្រើអក្សរដែលមកជាមួយ ដូច្នេះអ្វីដែលអ្នកបានផ្ទុកមិនខូចទេ។ ដើម្បីវាយអក្សរដែលមកជាមួយដោយខ្លួនឯង នៅកន្លែងដែលអក្សររបស់អ្នកនឹងជាប់ផ្លូវ ដាក់សញ្ញាគូសក្រោមនៅមុខ៖ `_PO`។
- ឈ្មោះខ្លីរបស់ពាក្យបញ្ជាគឺជារឿងផ្សេង៖ សូមមើល [កែសម្រួលឈ្មោះខ្លីពាក្យបញ្ជា](topic:command-aliases)។

## បន្ទាត់ដែល CadCraft បដិសេធ

ពេលអ្នកកែជាអត្ថបទ ឬនាំចូលឯកសារ កម្មវិធីកែសម្រួលបញ្ជីបញ្ហានីមួយៗជាមួយលេខបន្ទាត់៖

- ពាក្យបញ្ជាមិនមាន (ឈ្មោះខ្លីរបស់ពាក្យបញ្ជាអនុញ្ញាត៖ `AR.PO` ត្រូវបានអានជា `ARRAY.PO`);
- បន្ទាត់មិនមែនជា `COMMAND.OPTION, LETTERS`;
- អក្សរមានដកឃ្លា ឬសញ្ញា (អក្សរ និងលេខតែប៉ុណ្ណោះ ច្រើនបំផុត 16);
- អក្សរដូចគ្នាឆ្លើយតបជម្រើសពីរផ្សេងគ្នានៃពាក្យបញ្ជាតែមួយ។
