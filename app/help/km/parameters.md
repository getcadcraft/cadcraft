## តារាងតែមួយសម្រាប់ទំហំទាំងអស់

ផ្ទាំង {{ui:Parameters}} (ប៊ូតុង {{ui:Parameters}} នៅក្រុម {{ui:Parametric}} ឬវាយ {{cmd:PARAMETERS}}) បញ្ជីការរឹតបន្តឹងវិមាត្រទាំងអស់ (`d1`, `rad1`, `dia1`, `ang1` ឬឈ្មោះដែលអ្នកបានផ្ដល់) និងប៉ារ៉ាម៉ែត្ររបស់អ្នកផ្ទាល់ជាមួយគ្នា។ ឈ្មោះណាមួយអាចប្រើនៅក្នុងកន្សោមណាមួយ។

ជួរនីមួយៗមាន៖

- **Name (ឈ្មោះ)**៖ វាយឈ្មោះថ្មីដើម្បីប្ដូរឈ្មោះ; កន្សោមណាដែលប្រើវាធ្វើតាម។
- **Expression (កន្សោម)**៖ លេខ (`40`) ឬកន្សោម (`width / 2 + gap`)។ វាយក្នុងវា ហើយចុច {{key:Enter}}៖ គំនូរប្លង់ធ្វើតាម។
- **Value (តម្លៃ)**៖ អ្វីដែលវាគណនាបាន។ នៅជួរដែលកន្សោមបញ្ជា អ្នកអាចវាយលេខនៅទីនេះផងដែរ៖ CadCraft គណនាប៉ារ៉ាម៉ែត្រដែលនៅពីក្រោយវា។ ជាមួយ `d1 = width / 2` ការវាយ `30` នៅតម្លៃ d1 កំណត់ `width` ទៅ 60។

នៅពេលប៉ារ៉ាម៉ែត្រពីរបញ្ជាតម្លៃមួយ (`width / 2 + gap`) ប្រអប់មួយសួរថាតើត្រូវផ្លាស់ប្ដូរមួយណា។ ការផ្លាស់ប្ដូរនីមួយៗគឺជាជំហានមួយនៃការមិនធ្វើវិញ ({{key:Mod+Z}})។

## បន្ថែមប៉ារ៉ាម៉ែត្ររបស់អ្នក

1. បើកផ្ទាំង {{ui:Parameters}}។
2. វាយឈ្មោះមួយ (`gap`) និងតម្លៃមួយ (`10`) ហើយជ្រើស {{ui:Add}}។
3. ប្រើវា៖ នៅកន្សោមរបស់ d1 វាយ `width / 2 + gap` ហើយចុច {{key:Enter}}។

ឈ្មោះចាប់ផ្ដើមជាអក្សរ ឬ `_` ហើយមានអក្សរ លេខ និង `_`។ ឈ្មោះមុខងារ `pi` និងឈ្មោះឯកតាមិនអាចជាឈ្មោះបានទេ។

| `( )` | ការដាក់ក្រុម |
| `sin cos tan asin acos atan atan2` | ត្រីកោណមាត្រជាដឺក្រេ |

លេខអាចមានឯកតា៖ `25mm`, `1in`, `2'`, `90deg`។ ប្រវែងដែលមានឯកតាត្រូវបានបំលែងទៅជាមីលីម៉ែត្រ ដូច្នេះប្រើឯកតាតែក្នុងគំនូរប្លង់ដែលវាស់ជាមីលីម៉ែត្រ; នៅកន្លែងផ្សេង វាយលេខធម្មតា។

## នៅបន្ទាត់ពាក្យបញ្ជា

`-PARAMETERS` ធ្វើដូចគ្នាដោយគ្មានផ្ទាំង៖ `N` ថ្មី, `E` កែសម្រួល (រួមទាំងការរឹតបន្តឹងវិមាត្រ), `R` ប្ដូរឈ្មោះ, `D` លុប, `?` បញ្ជី។

## អ្វីដែលត្រូវបានបដិសេធ

- កន្សោមដែលប្រើខ្លួនឯង ដោយផ្ទាល់ ឬតាមរយៈអ្វីផ្សេង៖ "width, d1 use each other."
- តម្លៃដែលទំហំមិនអាចយក៖ ប្រវែងអវិជ្ជមាន ឬមុំលើសពី 180°។
- តម្លៃដែលគំនូរប្លង់មិនអាចយកជាមួយការរឹតបន្តឹងផ្សេងទៀតរបស់វា៖ គ្មានអ្វីផ្លាស់ប្ដូរ ហើយសារឈ្មោះការរឹតបន្តឹងដែលកំពុងវាង។
- ការលុបប៉ារ៉ាម៉ែត្រដែលអ្វីមួយប្រើ៖ ផ្ទាំងផ្ដល់ឱ្យសរសេរតម្លៃរបស់វាចូលក្នុងអ្វីទាំងនោះជាមុនសិន។ ឈ្មោះការរឹតបន្តឹងវិមាត្រត្រូវបានលុបដោយការលុបការរឹតបន្តឹង។
