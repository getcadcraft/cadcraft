មនុស្សពីរនាក់កែសម្រួលគំនូរប្លង់តែមួយ។ ប្រសិនបើពួកគេបានផ្លាស់ប្ដូរវត្ថុផ្សេងគ្នា ការបញ្ចូលអាចដោយស្វ័យប្រវត្តិ៖ គ្មានអ្វីត្រូវធ្វើដោយដៃទេ។

## អ្វីដែលធ្វើឱ្យវាដំណើរការ

CadCraft ផ្ដល់ឱ្យវត្ថុគ្រប់ដែលអ្នកគូសនូវ **គន្លឹះ** ខ្លីមួយ ដែលមិនដែលផ្លាស់ប្ដូរ ហើយមិនដែលត្រូវបានផ្ដល់ឱ្យវត្ថុពីរឡើយ។ វាត្រូវបានរក្សាទុកជាមួយវត្ថុនៅក្នុង DWG ឬ DXF (ជាទិន្នន័យបន្ថែមដែលកម្មវិធីផ្សេងទៀតរក្សា)។ ការបញ្ចូលរកវត្ថុតាមគន្លឹះ មិនមែនតាមទីតាំងរបស់វាក្នុងឯកសារទេ ព្រោះកម្មវិធីទាំងអស់ដាក់លេខទីតាំងឡើងវិញនៅពេលរក្សាទុក។ ប្រសិនបើអ្នកមិនបញ្ចូលគ្នាឡើយ អាចបិទវានៅ {{ui:ការកំណត់}} › CadCraft › ឯកសារងាយស្រួលបញ្ចូល; ឯកសារនឹងតូចជាងប្រមាណ 10 ភាគរយ។

គំនូរប្លង់ដែលបានរក្សាទុកមុនពេលមានគន្លឹះ នៅតែបញ្ចូលបាន៖ វត្ថុរបស់វាទទួលគន្លឹះពីទីតាំងរបស់វាក្នុងឯកសារ ដូចគ្នាសម្រាប់មនុស្សគ្រប់គ្នាដែលបើកវា។

## ការតំឡើង

Git ត្រូវការបន្ទាត់ពីរម្ដងក្នុងមួយ repository៖

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# ម្ដងតែមួយ នៅលើកុំព្យូទ័រនីមួយៗ
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

បើគ្មាន git ដំណើរការវាដោយដៃ៖ `cadcraft merge <base> <ours> <theirs> -o <result>`។ Fossil និង Mercurial យកឯកសារបីដូចគ្នានៅក្នុងការកំណត់ឧបករណ៍បញ្ចូលរបស់ពួកគេផ្ទាល់។

## ច្បាប់

- វត្ថុដែលបានផ្លាស់ប្ដូរតែនៅម្ខាងត្រូវបានយក។ ការផ្លាស់ប្ដូរដូចគ្នានៅទាំងពីរខាងត្រូវបានយកតែម្ដង។
- លក្ខណៈសម្បត្តិតែមួយដែលបានផ្លាស់ប្ដូរតាមពីរវិធី គឺជា **ជម្លោះ**៖ ផ្នែករបស់អ្នកនៅតែមាន ហើយរបាយការណ៍បញ្ជីតម្លៃទាំងពីរ។ បើកលទ្ធផល មើលវត្ថុនោះ ហើយកែវាដោយដៃ។
- វត្ថុដែលបានបន្ថែមនៅម្ខាងណាក៏ដោយ ត្រូវបានរក្សាទុក។ វត្ថុដែលត្រូវបានលុបនៅម្ខាង ហើយមិនបានប៉ះពាល់នៅម្ខាងទៀត ត្រូវបានលុប។ លុបនៅម្ខាង ហើយផ្លាស់ប្ដូរនៅម្ខាងទៀត៖ លុប ហើយរាយការណ៍។
- ស្រទាប់ ប្លុក រចនាបថអក្សរ និងរចនាបថវិមាត្រ សន្លឹក និងទិដ្ឋភាពដែលបានដាក់ឈ្មោះ បញ្ចូលគ្នាតាមរបៀបដូចគ្នា។ ការរឹតបន្តឹងធ្វើតាមវត្ថុដែលពួកវាដាក់ឈ្មោះ។
- លទ្ធផលត្រូវបានសរសេរក្នុងទម្រង់ឯកសារ និងកំណែដូចឯកសាររបស់អ្នក។

មិនត្រូវបានបញ្ចូល៖ លំដាប់ដែលវត្ថុត្រូវបានគូរគឺជារបស់អ្នក បន្ទាប់មកវត្ថុដែលម្ខាងទៀតបានបន្ថែម។ ការផ្លាស់ប្ដូរនិយមន័យប្លុកដូចគ្នានៅទាំងពីរខាង គឺជាជម្លោះ មិនដែលត្រូវបានលាយគ្នាឡើយ។ គ្មានអ្វីត្រូវបានផ្ទុកឡើងទេ; អ្វីៗទាំងអស់ដំណើរការនៅលើកុំព្យូទ័ររបស់អ្នក។
