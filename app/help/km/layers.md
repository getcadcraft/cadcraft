## អ្វីដែលអ្នកនឹងបង្កើត

ស្រទាប់បីគឺ ជញ្ជាំង ទ្វារ និងកំណត់ចំណាំ ដែលនីមួយៗមានពណ៌ផ្ទាល់ខ្លួន ជាមួយវត្ថុដែលគូរនៅលើនីមួយៗ ហើយផ្លាស់ទីរវាងពួកវា។

## ផ្ទាំងស្រទាប់

ស្រទាប់ស្ថិតនៅក្នុងផ្ទាំងខាងឆ្វេង នៅក្រោម {{ui:Layers}}។ ជួរនីមួយៗបង្ហាញ ពីឆ្វេងទៅស្ដាំ៖

- ចំណុច៖ ពេញសម្រាប់ស្រទាប់**បច្ចុប្បន្ន** ជាកន្លែងដែលវត្ថុថ្មីទៅ;
- ប្រអប់ពណ៌;
- ឈ្មោះស្រទាប់;
- ប៊ូតុងបួន៖ បើក/បិទ (ភ្នែក) ផ្អាក (ព្រិល) ចាក់សោ (សោ) និងបោះពុម្ព (ម៉ាស៊ីនបោះពុម្ព)។

គំនូរប្លង់ទាំងអស់មានស្រទាប់ដែលហៅថា `0`។ វាយ `LA` ហើយចុច {{key:Enter}} ដើម្បីទៅផ្ទាំងនេះ។

## បង្កើតស្រទាប់

1. ចុច {{ui:New layer}} នៅខាងលើបញ្ជី។ ប្រអប់ឈ្មោះបើក។
2. វាយ `Walls` ហើយចុច {{key:Enter}} (ឬចុច {{ui:Add}})។

របារស្ថានភាពនិយាយថា "Added layer Walls and made it current។" ស្រទាប់ថ្មីទទួលពណ៌ 7 (ខ្មៅលើផ្ទៃភ្លឺ ស លើផ្ទៃងងឹត)។

3. ចុច {{ui:New layer}} ម្ដងទៀត វាយ `Doors` ហើយចុច {{key:Enter}}។
4. ចុច {{ui:New layer}} ម្ដងទៀត វាយ `Notes` ហើយចុច {{key:Enter}}។

Notes ឥឡូវជាបច្ចុប្បន្ន។

## ផ្ដល់ពណ៌ដល់ស្រទាប់នីមួយៗ

1. ចុចប្រអប់ពណ៌នៅជួរ Walls។ ឧបករណ៍ជ្រើសពណ៌របស់ប្រព័ន្ធរបស់អ្នកបើក។
2. ជ្រើសពណ៌ ហើយបញ្ជាក់។

ប្រអប់ពណ៌ និងអ្វីៗទាំងអស់ក្នុង Walls ដែលមានពណ៌ {{ui:By layer}} ផ្លាស់ប្ដូរ។

:::note
ពណ៌ដែលបានជ្រើសដែលត្រូវនឹងពណ៌ CAD ស្តង់ដារ 255 មួយត្រូវបានរក្សាទុកជាលេខនោះ។ ពណ៌ផ្សេងទៀតត្រូវបានរក្សាទុកដូចដើមក្នុង CadCraft ប៉ុន្តែត្រូវបានរក្សាទុកជាពណ៌ស្តង់ដារដែលជិតបំផុតក្នុងឯកសារ DWG ឬ DXF។
:::

## គូរលើស្រទាប់

1. ចុចឈ្មោះ **Walls** ក្នុងបញ្ជី។ ចំណុចរបស់វាពេញ ហើយរបារស្ថានភាពនិយាយថា "Current layer: Walls"។
2. គូររាងចតុកោណ (`REC`)។ វាទៅលើ Walls។
3. ចុច **Doors** ហើយគូរធ្នូ (`A`)។ វាទៅលើ Doors។

អ្នកក៏អាចជ្រើសស្រទាប់បច្ចុប្បន្នក្នុង {{ui:Current settings}} នៅខាងស្ដាំ (នៅពេលមិនបានជ្រើសអ្វី) នៅក្រោម {{ui:Layer}}។

## ផ្លាស់ទីវត្ថុទៅស្រទាប់ផ្សេង

1. ជ្រើសវត្ថុ។
2. នៅផ្ទាំងខាងស្ដាំ ជ្រើសស្រទាប់ថ្មីនៅ {{ui:Layer}}។

វាផ្លាស់ទីទៅស្រទាប់នោះ ហើយយកពណ៌របស់វាប្រសិនបើពណ៌របស់វាគឺ {{ui:By layer}}។

## បិទ ផ្អាក ចាក់សោ និងបោះពុម្ព

| ប៊ូតុង | វាធ្វើអ្វី |
|---|---|
| បើក/បិទ (ភ្នែក) | លាក់វត្ថុរបស់ស្រទាប់។ ពួកវាមិនអាចមើលឃើញ ជ្រើសបាន ឬចាប់ជាប់បានទេ។ |
| ផ្អាក (ព្រិល) | ផលដូចការបិទក្នុង CadCraft។ ត្រូវបានរក្សាដាច់ដោយឡែក ពីព្រោះកម្មវិធីផ្សេងទៀតប្រព្រឹត្តខុសគ្នា ហើយការកំណត់ត្រូវបានរក្សាទុក។ |
| ចាក់សោ (សោ) | វត្ថុនៅតែមើលឃើញ ហើយអ្នកអាចចាប់ជាប់ទៅវាបាន ប៉ុន្តែមិនអាចជ្រើស ឬផ្លាស់ប្ដូរបាន។ ល្អសម្រាប់ផ្ទៃខាងក្រោយដែលអ្នកតាមដាន។ |
| បោះពុម្ព (ម៉ាស៊ីនបោះពុម្ព) | នៅពេលចុច ស្រទាប់បង្ហាញលើអេក្រង់ ប៉ុន្តែ**ត្រូវបានដកចេញពីការបោះពុម្ព** និង PDF។ ប្រើសម្រាប់បន្ទាត់ជំនួយ និងកំណត់ចំណាំដល់ខ្លួនអ្នក។ |

ដាក់កណ្ដុរលើប៊ូតុងដើម្បីមើលអ្វីដែលវានឹងធ្វើ ("Turn off", "Freeze", "Lock", "Do not plot this layer")។

អ្នកមិនអាចបិទស្រទាប់បច្ចុប្បន្នបានទេ៖ របារស្ថានភាពនិយាយថា "That is the current layer. Make another layer current first."។ ការចុចឈ្មោះស្រទាប់ដើម្បីធ្វើឱ្យវាជាបច្ចុប្បន្ន ក៏បើក និងផ្អាកវាដែរ។

ការផ្លាស់ប្ដូរស្រទាប់ទាំងអស់ ក្នុងផ្ទាំង ឬតាមពាក្យបញ្ជា គឺជាជំហានមិនធ្វើវិញមួយ៖ {{key:Mod+Z}} ត្រលប់វាមកវិញ។

## ធ្វើការលើស្រទាប់ដោយជ្រើសវត្ថុ

អ្នកមិនចាំបាច់ដឹងឈ្មោះស្រទាប់ទេ៖ ជ្រើសវត្ថុមួយនៅលើវា។ វាយពាក្យបញ្ជា ឬបើក {{ui:Tools}} នៅខាងលើផ្ទាំង {{ui:Layers}}។

| ពាក្យបញ្ជា | វាធ្វើអ្វី |
|---|---|
| {{cmd:LAYISO}} | ជ្រើសវត្ថុ ហើយចុច {{key:Enter}}៖ មានតែស្រទាប់របស់វាដែលនៅបើក ស្រទាប់ផ្សេងទៀតទាំងអស់ត្រូវបានបិទ។ បើស្រទាប់បច្ចុប្បន្នត្រូវបានបិទ ស្រទាប់មួយក្នុងចំណោមស្រទាប់ដាច់ដោយឡែកក្លាយជាបច្ចុប្បន្ន។ |
| {{cmd:LAYUNISO}} | ត្រឡប់មកបើកវិញនូវស្រទាប់ដែល {{cmd:LAYISO}} ចុងក្រោយបានបិទ ហើយផ្ដល់ស្រទាប់បច្ចុប្បន្នដែលវាបានផ្លាស់ប្ដូរ។ |
| {{cmd:LAYOFF}} | ចុចវត្ថុម្ដងមួយៗ៖ ស្រទាប់របស់វានីមួយៗត្រូវបានបិទ។ វាយ `U` ដើម្បីយកមួយចុងក្រោយមកវិញ ហើយ {{key:Enter}} ដើម្បីបញ្ចប់។ |
| {{cmd:LAYFRZ}} | ដូចគ្នា ប៉ុន្តែផ្អាកស្រទាប់នីមួយៗ។ |
| {{cmd:LAYMCUR}} | ចុចវត្ថុមួយ៖ ស្រទាប់របស់វាក្លាយជាបច្ចុប្បន្ន (ហើយត្រូវបានបើក និងផ្អាក)។ បើវត្ថុមួយត្រូវបានជ្រើសរួចហើយ នោះត្រូវបានប្រើ។ |
| {{cmd:LAYON}} | បើកស្រទាប់ទាំងអស់។ |
| {{cmd:LAYTHW}} | ផ្អាកស្រទាប់ទាំងអស់។ |

ស្រទាប់បច្ចុប្បន្នមិនត្រូវបានបិទ ឬផ្អាកតាមវិធីនេះឡើយ៖ ប្រវត្តិនិយាយដូច្នេះ ហើយអ្នកអាចធ្វើឱ្យស្រទាប់មួយទៀតជាបច្ចុប្បន្នជាមួយ {{cmd:LAYMCUR}} ជាមុនសិន។ ការជ្រើសប្លុកយោង ប្រើស្រទាប់របស់យោងនោះផ្ទាល់។

## ប្ដូរឈ្មោះ បញ្ចូល និងលុបស្រទាប់

- {{cmd:RENAME}}៖ វាយ `LA` ឈ្មោះចាស់ និងឈ្មោះថ្មី។ វត្ថុទាំងអស់នៅលើស្រទាប់នោះដើរតាម។ (`B` ប្ដូរឈ្មោះប្លុកតាមរបៀបដូចគ្នា ជាមួយយោងទាំងអស់ទៅវា។)
- {{cmd:LAYMRG}}៖ ចុចវត្ថុមួយនៅលើស្រទាប់នីមួយៗដើម្បីបញ្ចូល (ឬវាយ `N` និងឈ្មោះ) ចុច {{key:Enter}} បន្ទាប់មកជ្រើសស្រទាប់គោលដៅ ហើយឆ្លើយ `Y`។ វត្ថុផ្លាស់ទៅគោលដៅ ក្នុងម៉ូដែល នៅលើសន្លឹក និងនៅក្នុងប្លុក ហើយស្រទាប់ដែលបានបញ្ចូលត្រូវបានលុប។
- {{cmd:LAYDEL}}៖ ជ្រើសវត្ថុមួយនៅលើស្រទាប់ (ឬ `N` និងឈ្មោះរបស់វា) ហើយឆ្លើយ `Y`។ ស្រទាប់ត្រូវបានលុប **ជាមួយវត្ថុទាំងអស់ដែលនៅលើវា** គ្រប់ទីកន្លែង។ ស្រទាប់ 0 DEFPOINTS និងស្រទាប់បច្ចុប្បន្នមិនអាចលុបបានទេ។

ការធ្វើនីមួយៗគឺជាជំហានមិនធ្វើវិញមួយ។ ទាំងបីស្ថិតនៅក្នុង {{ui:Tools}} នៅខាងលើផ្ទាំង {{ui:Layers}}។

1. ចុចបន្ទាត់ជញ្ជាំងមួយ ហើយវាយ `LAYISO` ហើយចុច {{key:Enter}}។ មានតែ Walls នៅបើក។
2. គូរ ឬផ្លាស់ប្ដូរអ្វីដែលអ្នកត្រូវការនៅលើ Walls។
3. វាយ `LAYUNISO` ហើយចុច {{key:Enter}}។ Doors និង Notes ត្រឡប់មកវិញ។

## ខ្លឹមសារធម្មតាដែលខុស

- **បន្ទាត់ថ្មីបានទៅលើស្រទាប់ខុស។** ពិនិត្យមើលចំណុចមួយណាពេញមុនពេលអ្នកគូរ។ ស្រទាប់ថ្មីក្លាយជាបច្ចុប្បន្នភ្លាមៗពេលអ្នកបន្ថែមវា។
- **វត្ថុមិនជ្រើសបាន។** ស្រទាប់របស់វាត្រូវបានចាក់សោ បិទ ឬផ្អាក។
- **ស្រទាប់នៅតែបោះពុម្ពក្នុងកម្មវិធីផ្សេង។** DXF R12 មិនអាចរក្សា "do not plot" បានទេ។ CadCraft រក្សាការកំណត់សម្រាប់ខ្លួនវាផ្ទាល់ នៅពេលគំនូរមានសន្លឹក ប៉ុន្តែកម្មវិធីផ្សេងទៀតនឹងបោះពុម្ពស្រទាប់នោះ។
- **ឈ្មោះស្រទាប់ជាអក្សរធំបន្ទាប់ពីរក្សាទុក។** DXF R12 រក្សាទុកឈ្មោះជាអក្សរធំ ដូច្នេះ `Walls` ត្រឡប់មកជា `WALLS`, ហើយដកឃ្លាក្លាយជា `_`។ DWG ដែលបានរក្សាទុករក្សាឈ្មោះដូចដែលអ្នកបានវាយ។
- **ប្ដូរឈ្មោះ បញ្ចូល ឬលុបស្រទាប់។** ប្រើ {{cmd:RENAME}}, {{cmd:LAYMRG}} ឬ {{cmd:LAYDEL}} (ក៏នៅក្នុង {{ui:Tools}} ដែរ)៖ សូមមើលខាងក្រោម។

## ក្រុមស្រទាប់

រក្សាបញ្ជីឱ្យខ្លី ដោយដាក់ស្រទាប់ក្នុងថត ដូចជា Existing, Proposed និង Services។ ថតនីមួយៗអាចបត់បាន ហើយប៊ូតុងរបស់វាបើក ឬបិទស្រទាប់ទាំងអស់របស់វា ផ្អាកវា ឬចាក់សោជាមួយគ្នា។ ស្រទាប់បច្ចុប្បន្នមិនដែលត្រូវបានបិទឡើយ។

នៅក្នុង {{ui:Tools}} នៃផ្ទាំងស្រទាប់ ជ្រើស {{ui:Add ready-made groups}} សម្រាប់សំណុំដែលបានធ្វើសម្រាប់ការងារលំនៅដ្ឋានតូច {{ui:Group by name}} ដើម្បីដាក់ក្រុមស្រទាប់ដែលមានបុព្វបទដូចគ្នា (`E-Walls`, `E-Doors`) ឬ {{ui:New group}}។ អូសស្រទាប់ទៅថតមួយ ឬប្រើបញ្ជីខាងលើសម្រាប់ស្រទាប់បច្ចុប្បន្ន។ វាយក្នុង {{ui:Find a layer}} ដើម្បីកាត់បន្ថយបញ្ជី។ `LAYGROUP` (`LG`) ធ្វើដូចគ្នានៅបន្ទាត់បញ្ជា។

ដើម្បីប្ដូរឈ្មោះក្រុម ចុចពីរដងលើឈ្មោះរបស់វា (ឬជ្រើសវា ហើយចុច {{key:F2}}) វាយឈ្មោះថ្មី ហើយចុច {{key:Enter}}; {{key:Esc}} រក្សាឈ្មោះចាស់ ហើយ {{cmd:UNDO}} ត្រឡប់វាមកវិញ។ {{ui:New group}} នៅក្នុង {{ui:Tools}} នៃផ្ទាំងស្រទាប់។

ស្រទាប់ខ្លួនវាមិនផ្លាស់ប្ដូរទេ ដូច្នេះកម្មវិធីគូរ CAD ផ្សេងទៀតឃើញពួកវាជាបញ្ជីសាមញ្ញធម្មតា។ CadCraft រក្សាក្រុមក្នុងឯកសារ។
