## អ្វីដែលអ្នកនឹងរៀន

មានវិធីរហ័សពីរដើម្បីប្ដូរវត្ថុដោយមិនប្រើពាក្យបញ្ជា៖ អូស **ចំណុចចាប់** របស់វា ឬវាយតម្លៃថ្មីនៅក្នុងផ្ទាំង **លក្ខណៈសម្បត្តិ** នៅខាងស្ដាំ។

## ចំណុចចាប់

នៅពេលអ្នកជ្រើសវត្ថុ (រហូតដល់ 200 ក្នុងពេលតែមួយ) ដោយគ្មានពាក្យបញ្ជាដំណើរការ ការ៉េតូចៗនឹងលេចឡើងលើវត្ថុទាំងនោះ។ ទាំងនេះជាចំណុចចាប់៖

| វត្ថុ | ចំណុចចាប់ |
|---|---|
| បន្ទាត់ | ចុងទាំងពីរ និងកណ្ដាល (ផ្លាស់ទីបន្ទាត់ទាំងមូល) |
| រង្វង់ | ផ្ចិត (ផ្លាស់ទីវា) និងចំណុចទាំងបួនលើរង្វង់ (ប្ដូរកាំ) |
| ធ្នូ | ផ្ចិត និងចុងទាំងពីរ (ប្ដូរកន្លែងចាប់ផ្តើម និងបញ្ឈប់) |
| ប៉ូលីឡាញ | ចំនុចកំពូលគ្រប់ទាំងអស់ |
| អត្ថបទ ចំណុច យោងប្លុក | ចំណុចបញ្ចូល |
| អេលីប | ផ្ចិត |
| វិមាត្រ | ចំណុចកំណត់របស់វា និងទីតាំងខ្សែវិមាត្រ |
| ផ្ទាំងមើល | ផ្ចិត (ផ្លាស់ទីវា) និងជ្រុងទាំងបួន (ប្ដូរទំហំវា) |

### ផ្លាស់ទីចំណុចចាប់

1. គូសបន្ទាត់មួយ ហើយចុចលើវា។ ចំណុចចាប់បីនឹងលេចឡើង។
2. ចុចចំណុចចាប់នៅចុងម្ខាង។ របារស្ថានភាពនិយាយថា "ចុចកន្លែងដែលចំណុចចាប់នេះត្រូវទៅ (Esc ដើម្បីបោះបង់)។ ការចាប់ជាប់ និង Ortho ត្រូវបានអនុវត្ត។"
3. ផ្លាស់ទីអ័ក្សកាកបាទ។ មានការមើលជាមុនតាម។
4. ចុចទីតាំងថ្មី ឬចាប់ជាប់ទៅចំណុចលើវត្ថុផ្សេង ហើយចុច។

ចុងនោះផ្លាស់ទី ហើយផ្នែកដែលនៅសល់របស់បន្ទាត់នៅនឹងកន្លែង។ អ្នកក៏អាចចុចលើចំណុចចាប់ ហើយអូសវា ហើយលែងដៃនៅកន្លែងដែលវាគួរទៅ។

:::note
អ្នកមិនអាចវាយកូអរដោនេសម្រាប់ចំណុចចាប់បានទេ។ សម្រាប់ទីតាំងជាក់លាក់ ចាប់ជាប់ទៅចំណុចមួយ ឬវាយតម្លៃនៅក្នុង **លក្ខណៈសម្បត្តិ**។
:::

ចុច {{key:Esc}} ឬចុចកណ្ដុរស្ដាំ ដើម្បីបោះបង់ការផ្លាស់ទីចំណុចចាប់។

## លក្ខណៈសម្បត្តិ

ផ្ទាំងខាងស្ដាំបង្ហាញលក្ខណៈសម្បត្តិនៃអ្វីដែលបានជ្រើស។

1. ចុចលើបន្ទាត់មួយ។ ក្បាលផ្ទាំងអានថា "បន្ទាត់"។
2. ចុចក្នុង {{ui:ប្រវែង}} វាយ `2500` ហើយចុច {{key:Enter}}។

បន្ទាត់នោះឥឡូវវែង 2500 យ៉ាងជាក់លាក់ ដោយរក្សាចំណុចចាប់ផ្ដើម និងមុំរបស់វា។ {{key:Enter}} ឬចុចកន្លែងផ្សេងអនុវត្តតម្លៃ; {{key:Esc}} ដាក់តម្លៃចាស់វិញ។ ការផ្លាស់ប្ដូរនីមួយៗគឺជាជំហានមិនធ្វើវិញមួយ សូម្បីតែនៅពេលវត្ថុជាច្រើនប្ដូរក្នុងពេលតែមួយ។

ប្រអប់អាចទទួលកន្សោម (`=2*45`) និងប្រវែងជាមួយឯកតា (`3'6"`, `900mm`) ចំណុចនីមួយៗមាន X, Y និង Z ហើយវត្ថុជាច្រើនអាចប្ដូរជាមួយគ្នាបាន។ ទាំងអស់នេះមាននៅក្នុង [ផ្ទាំងលក្ខណៈសម្បត្តិ](topic:properties-panel)។

## កំហុសទូទៅ

- **មិនមានចំណុចចាប់លេចឡើងទេ។** ពាក្យបញ្ជាកំពុងដំណើរការ (ចុច {{key:Esc}}) ឬមានវត្ថុលើសពី 200 ត្រូវបានជ្រើស ឬវត្ថុនោះនៅលើស្រទាប់ដែលបានចាក់សោ។
- **ចំណុចចាប់ទៅកន្លែងខុស។** ការចាប់ជាប់បានចាប់វា។ សង្កត់ {{key:Shift}} ពេលចុច ដើម្បីមិនអើពើការចាប់ជាប់។
- **ការវាយនៅក្នុង លក្ខណៈសម្បត្តិ មិនមានអ្វីកើតឡើង។** ចុច {{key:Enter}} ឬចុចកន្លែងផ្សេងដើម្បីអនុវត្ត។ ការបញ្ចូលដែលមិនត្រូវបានទទួល (ប្រវែង និងកាំស្មើសូន្យ ឬអវិជ្ជមាន ឬអក្សរដែលមិនមែនជាតម្លៃ) ធ្វើឱ្យប្រអប់ក្លាយទៅជាពណ៌ក្រហម ហើយប្រាប់ពីមូលហេតុ។
- **អក្សរដែលបានវាយបានចូលទៅក្នុងប្រអប់ លក្ខណៈសម្បត្តិ។** ខណៈដែលប្រអប់មានទស្សន៍ទ្រនិច គ្រាប់ចុចវាយនៅទីនោះ។ ចុច {{key:Enter}} ឬ {{key:Esc}} រួចវាយពាក្យបញ្ជា។
