## អ្វីដែលអ្នកនឹងរៀន

CadCraft **មិនមាន AI ផ្ទាល់ខ្លួនទេ** ហើយមិនផ្ញើអ្វីទៅកន្លែងណាឡើយ។ អ្នកនាំជំនួយការមកដោយខ្លួនឯង៖ កម្មវិធីណាមួយដែលនិយាយភាសា Model Context Protocol (MCP)។ CadCraft គ្រាន់តែផ្តល់ឧបករណ៍ឱ្យវា ហើយអ្នកជ្រើសរើសថាមួយណា។

មានវិធីពីរយ៉ាងដើម្បីចូល៖

- **គំនូរនៅលើកុំព្យូទ័ររបស់អ្នក ដោយមិនបើកកម្មវិធី។** ម៉ាស៊ីនមេ CadCraft MCP និងបន្ទាត់បញ្ជា `cadcraft` អាន និងសរសេរឯកសារ DWG និង DXF នៅក្នុងថតដែលអ្នកដាក់ឈ្មោះ។ មើល "ធ្វើការលើឯកសារដោយមិនបើក CadCraft" ខាងក្រោម។

## អនុញ្ញាតឱ្យវាប្រើឯកសារក្នុងថតដែលអ្នកជ្រើសរើស

នៅក្នុង CadCraft Studio ជំនួយការអាចបើក រក្សាទុក និងបោះពុម្ពឯកសារតាមឈ្មោះ ជំនួសឱ្យប្រអប់ឯកសារ ប៉ុន្តែតែនៅក្នុងថតដែលអ្នកបន្ថែមនៅក្រោម {{ui:ជំនួយការ}} › {{ui:ថតដែលវាអាចប្រើ}} ប៉ុណ្ណោះ៖

1. ជ្រើសរើស {{ui:បន្ថែមថត…}} ហើយជ្រើសថតនៅក្នុងប្រអប់របស់ Studio ខ្លួនឯង។
2. ឥឡូវជំនួយការអាចរាយបញ្ជីឯកសារនៅទីនោះ (`files_list`), បើកគំនូរ (`drawing_open`), រក្សាទុកវានៅទីនោះជាកំណែ DWG ឬជា DXF, បោះពុម្ពទៅជាឯកសារ PDF ឬ SVG, ផ្ទុកឯកសារ LISP, និងផ្តល់ដល់ពាក្យបញ្ជានូវឯកសារដែលវាស្នើសុំ (`INSERT` `F`, `XATTACH`, ឯកសារចំណុច) ឬប្រាប់ថាឯកសាររបស់ពាក្យបញ្ជាទៅកន្លែងណា (CSV របស់ `COUNT`, `PUBLISH`)។

## ធ្វើការលើឯកសារដោយមិនបើក CadCraft

ម៉ាស៊ីនមេ CadCraft MCP (`cadcraft-mcp`) និងបន្ទាត់បញ្ជា (`cadcraft`) ដំណើរការកូដគំនូររបស់ CadCraft ខ្លួនឯងនៅក្នុង Node.js ដោយគ្មានបង្អួច។ ពួកវាត្រូវការ Node.js 20 ឬថ្មីជាង។

- **ម៉ាស៊ីនមេ MCP** ធ្វើការតែនៅក្នុងថតដែលអ្នកដាក់ឈ្មោះ ហើយតែជាមួយការអនុញ្ញាតដែលអ្នកផ្តល់ឱ្យវាប៉ុណ្ណោះ៖ `npx @getcadcraft/mcp --root ~/Drawings --allow read,edit`។ បើគ្មាន `--root` វាមិនអាចបើកឯកសារណាមួយបានទេ; បើគ្មាន `--allow` វាអាចអានបានតែប៉ុណ្ណោះ។ វាក៏អាចអានម៉ូដែល IFC ការគណនាបរិមាណ និងការសម្គាល់នៅក្នុងសំណុំ PDF បានដែរ។
- **បន្ទាត់បញ្ជា** សម្រាប់ស្គ្រីបរបស់អ្នកផ្ទាល់៖ `cadcraft info plan.dwg`, `cadcraft run cleanup.scr plan.dwg -o plan-clean.dwg`, `cadcraft convert plan.dwg plan.dxf`, `cadcraft plot plan.dwg plan.pdf --all`, `cadcraft plot plan.dwg plan.svg`, `cadcraft check plan.dwg --rules rules.json`។ ឯកសារច្រើនក្នុងពេលតែមួយ៖ `cadcraft convert *.dwg out --to dxf`, `cadcraft plot *.dwg pdfs --to pdf`, `cadcraft check *.dwg --rules rules.json`។ បន្ថែម `--json` សម្រាប់លទ្ធផលដែលកម្មវិធីអាចអានបាន។

:::note
ប្រសិនបើ `npx @getcadcraft/mcp` បង្ហាញថារកមិនឃើញកញ្ចប់ នោះមានន័យថាវាមិនទាន់បានបោះផ្សាយនៅឡើយ។ ព័ត៌មាននៅ getcadcraft.com នឹងប្រាប់នៅពេលវាបាន។
:::

## បើមានអ្វីមិនដំណើរការ

- **ជំនួយការមើលមិនឃើញឧបករណ៍ CadCraft ឡើយ៖** ពិនិត្យថាប៊ូតុងបើកនៅក្នុងបង្អួចនេះ ហើយបង្អួចបើកនៅក្នុង Studio។
- **"ត្រូវការការអនុញ្ញាតកែសម្រួល"៖** ធីក **កែសម្រួល** នៅក្រោម {{ui:ជំនួយការ}} បន្ទាប់មកសួរម្តងទៀត។
