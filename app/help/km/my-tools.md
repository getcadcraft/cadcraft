## អ្វីដែលអ្នកនឹងរៀន

របៀបដាក់ប៊ូតុងរបស់អ្នកនៅលើរបារឧបករណ៍ ដែលនីមួយៗដំណើរការម៉ាក្រូដែលសរសេរតាមរបៀប AutoCAD សរសេរ របៀបផ្ដល់គន្លឹះមួយដល់ប៊ូតុង និងរបៀបនាំប៊ូតុងនៃឯកសារ CUIx មក។

## បន្ថែមប៊ូតុង

1. បើក {{ui:Settings}} ({{key:Mod+,}}) ហើយនៅផ្ទាំង {{ui:CadCraft}}។ រំកិលទៅ {{ui:My tools}}។
2. ចុច {{ui:Add a button…}}។
3. បំពេញប្រអប់៖
   - {{ui:Group}}៖ ក្រុមរបារឧបករណ៍ដែលវានឹងទៅ ឧទាហរណ៍ `My tools`។ ឈ្មោះថ្មីបង្កើតក្រុមថ្មី។
   - {{ui:Label}}៖ ពាក្យនៅលើប៊ូតុង។
   - {{ui:Macro}}៖ អ្វីដែលវាវាយ ឧទាហរណ៍ `^C^C_rectang;0,0;@100,50;`។
   - {{ui:Shortcut key}}៖ ចុចប្រអប់ ហើយចុចគ្រាប់ចុច ឧទាហរណ៍ {{key:Ctrl+Alt+B}}។
   - {{ui:Icon}}៖ រូបភាព PNG ឬ SVG ដែលមានទំហំមិនលើស 64 KB ឬគ្មាន (ផ្កាយមួយនឹងបង្ហាញ)។
4. ចុច {{ui:Save}}។

ប៊ូតុងលេចឡើងនៅចុងរបារឧបករណ៍ ក្នុងក្រុមរបស់វា។ ចុចវា ឬចុចគ្រាប់ចុចរបស់វា ដើម្បីដំណើរការ។ {{ui:Edit}} និង {{ui:Delete}} នៅក្នុងបញ្ជីកែប្រែ ឬដកវាចេញ។

## សរសេរម៉ាក្រូ

ម៉ាក្រូគឺជាអ្វីដែលអ្នកនឹងវាយនៅបន្ទាត់ពាក្យបញ្ជា ជាមួយសញ្ញាពិសេសមួយចំនួន៖

| សញ្ញា | មានន័យថា |
|---|---|
| `^C` | បោះបង់អ្វីដែលកំពុងដំណើរការ (`^C^C` ជាការចាប់ផ្ដើមធម្មតា) |
| `;` ឬចន្លោះ | {{key:Enter}} |
| `\` | រង់ចាំអ្នក៖ ការចុច ឬចម្លើយដែលវាយ បន្ទាប់មកម៉ាក្រូបន្ត |
| `_` ឬ `.` មុនពាក្យបញ្ជា | ទទួលយក ហើយមិនអើពើ (ឈ្មោះអន្តរជាតិ និងឈ្មោះដែលមានស្រាប់) |
| `*` នៅដើមបំផុត | ដំណើរការម្ដងទៀតរាល់ពេលវាចប់ រហូតដល់អ្នកចុច {{key:Esc}} |
| `^O`, `^G` | បើក ឬបិទ Ortho ឬក្រឡាចត្រង្គ |
| `$M=` | អ្វីដែលនៅសល់គឺ DIESEL។ មានតែ `$(if,…)`, `$(getvar,…)`, `$(=,…)` និង `$(eq,…)` ដែលត្រូវបានអាន; ប៊ូតុងដែលប្រើអ្វីផ្សេងនឹងប្រាប់ និងមិនធ្វើអ្វីទេ |

ឧទាហរណ៍៖

- `^C^C_line;0,0;@100,0;;` គូសបន្ទាត់ប្រវែង 100 ចាប់ពីប្រភព។
- `^C^C_circle;\25;` សួរអ្នកសម្រាប់ផ្ចិត បន្ទាប់មកគូសរង្វង់ដែលមានកាំ 25 នៅទីនោះ។
- `^C^C_turnright` បង្វិលទិដ្ឋភាព 90° ទៅស្ដាំ។

## គន្លឹះផ្លូវកាត់

គ្រាប់ចុចត្រូវការ {{key:Mod}} (Ctrl, ឬ Cmd នៅលើ Mac) ឬ {{key:Alt}} ជាមួយអក្សរ ឬលេខ ឬមួយក្នុងចំណោមគ្រាប់ចុចមុខងារទំនេរ {{key:F2}}, {{key:F4}}, {{key:F5}}, {{key:F6}}, {{key:F9}}។ អក្សរដោយឯកឯងទៅបន្ទាត់ពាក្យបញ្ជា។ គ្រាប់ចុចដែល CadCraft, កម្មវិធី ឬកម្មវិធីរុករកប្រើរួចហើយ (ដូចជា {{key:Ctrl+S}} ឬ {{key:Ctrl+Z}}) និងគ្រាប់ចុចដែលប៊ូតុងមួយទៀតមាន ត្រូវបានបដិសេធ ហើយប្រអប់នឹងបញ្ជាក់ហេតុផល។

## ចែករំលែកប៊ូតុងរបស់អ្នក

- {{ui:Export…}} រក្សាទុកក្រុម និងប៊ូតុងទាំងអស់ (ជាមួយរូបភាព និងគ្រាប់ចុច) ជា `my-tools.json`។
- {{ui:Import…}} បន្ថែមក្រុមនៃឯកសារបែបនេះបន្ទាប់ពីរបស់អ្នក។ ឈ្មោះក្រុមដែលអ្នកប្រើរួចហើយទទួលបាន "(2)"; គ្រាប់ចុចដែលនឹងបង្ករឡើងជាមួយគ្នា ត្រូវបានលុបចេញ ហើយផ្ទាំងនឹងបញ្ជាក់។

## នាំប៊ូតុងមកពីឯកសារ CUIx

1. ចុច {{ui:Import CUIx…}} ហើយជ្រើសរើសឯកសារ `.cuix`។

របារឧបករណ៍ និងផ្ទាំងបូនរបស់វាក្លាយជាក្រុម ដោយប៊ូតុងនីមួយៗមានម៉ាក្រូ និងរូបភាពរបស់វា (PNG ឬ BMP ដែលបានបំលែងទៅជា PNG)។ គន្លឹះផ្លូវកាត់របស់វាមកក្នុងក្រុមផ្ទាល់ខ្លួន ដោយប៊ូតុងនីមួយៗមានគន្លឹះរបស់វា; នាមធៀបពាក្យបញ្ជាដែលវាអាចមាន មកក្នុងក្រុម {{ui:Aliases}}។ ផ្ទាំងនេះបង្ហាញអ្វីដែលបានមក។

:::note
ឯកសារគ្រាន់តែត្រូវបានអានប៉ុណ្ណោះ។ ពាក្យបញ្ជាដែល CadCraft មិនមាន ត្រូវបានបញ្ជីតាមឈ្មោះ មិនមែនទាយទេ៖ ប៊ូតុងរបស់វានឹងប្រាប់នៅពេលចុច។ DIESEL លើសពីមុខងារមួយចំនួនខាងលើ ម៉ឺនុយ ប៊ូតុងកណ្ដុរ និងកន្លែងធ្វើការ មិនត្រូវបានអានទេ។
:::

## ដឹងថាជាប្រយោជន៍

- ប៊ូតុងត្រូវបានរក្សាទុកក្នុងកម្មវិធីរុករកនេះ (ឬកម្មវិធីលើកុំព្យូទ័រនេះ) មិនមែនក្នុងគំនូរប្លង់ទេ។
- ប៊ូតុងដំណើរការតាមបន្ទាត់ពាក្យបញ្ជា ដូច្នេះវាត្រូវបានមិនធ្វើវិញដូចអ្វីក៏ដោយដែលអ្នកវាយ៖ {{key:Mod+Z}} មួយក្នុងពាក្យបញ្ជាមួយដែលវាបានដំណើរការ។
