ផ្លូវកាត់ត្រូវបានបង្ហាញសម្រាប់កុំព្យូទ័ររបស់អ្នក។ នៅលើ Mac ផ្លូវកាត់ {{key:Mod}} ទាំងអស់ខាងក្រោមប្រើគ្រាប់ចុច Command ហើយគ្រាប់ចុច Control ក៏ដំណើរការដែរ។ របៀបសរសេរគ្រាប់ចុច និងរបៀបប្រើគ្រាប់ចុច F នៅលើ Mac ស្ថិតនៅក្នុង [គ្រាប់ចុច កណ្ដុរ និងបន្ទះតាមដាន](common:keys)។

## វាយពាក្យបញ្ជា

|---|---|
| អក្សរ លេខ ឬនិមិត្តសញ្ញាណាមួយ | ទៅកាន់បន្ទាត់ពាក្យបញ្ជា ទោះបីទស្សន៍ទ្រនិចនៅទីណាក៏ដោយ លុះត្រាតែប្រអប់មួយនៅក្នុងផ្ទាំងមានទស្សន៍ទ្រនិច |
| {{key:Enter}} | ផ្ញើអ្វីដែលអ្នកបានវាយ។ នៅប្រអប់ទទេ៖ ធ្វើពាក្យបញ្ជាចុងក្រោយម្ដងទៀត បញ្ចប់ពាក្យបញ្ជា បញ្ចប់ការជ្រើសរើស ឬយល់ព្រមតម្លៃលំនាំដើមក្នុង `<…>` |
| {{key:Space}} | ដូចគ្នានឹង {{key:Enter}} លើកលែងតែនៅពេល CadCraft សួរអត្ថបទ (អត្ថបទ ឈ្មោះប្លុក អត្ថបទវិមាត្រ) ដែលវាវាយដកឃ្លា |
| {{key:Esc}} | បោះបង់ពាក្យបញ្ជា។ ពេលគ្មានពាក្យបញ្ជាដំណើរការ៖ បោះបង់ការផ្លាស់ទីចំណុចចាប់ ឬប្រអប់ជ្រើសរើស ហើយបន្ទាប់មកលុបការជ្រើសរើស |
| {{key:Tab}} | ទទួលពាក្យបញ្ជាដែលបានណែនាំ ដែលបង្ហាញនៅខាងស្ដាំនៃបន្ទាត់ពាក្យបញ្ជា។ ពេលគ្មានអ្វីត្រូវបានវាយ ហើយទស្សន៍ទ្រនិចនៅលើវត្ថុដែលត្រួតគ្នា៖ បន្លិចវត្ថុបន្ទាប់នៅទីនោះ (ចុចដើម្បីជ្រើសវា) |
| {{key:Up}} {{key:Down}} | ដើរតាមបន្ទាត់ដែលអ្នកបានវាយមុនមក (100 ចុងក្រោយ) |

## គូរ និងកែសម្រួល

| គ្រាប់ចុច | អ្វីដែលវាធ្វើ |
|---|---|
| {{key:Mod+Z}} | មិនធ្វើវិញពាក្យបញ្ជាចុងក្រោយ |
| {{key:Mod+Y}} ឬ {{key:Mod+Shift+Z}} | ធ្វើវិញ |
| {{key:Mod+A}} | ជ្រើសវត្ថុទាំងអស់ដែលអ្នកអាចកែសម្រួលបាននៅលើផ្ទាំងបើក ({{cmd:SELECTALL}})។ បើអ្នកបានវាយអ្វីមួយនៅបន្ទាត់ពាក្យបញ្ជា វាជ្រើសអត្ថបទនោះជំនួសវិញ |
| {{key:Delete}} | លុបវត្ថុដែលបានជ្រើស ({{cmd:ERASE}}) លុះត្រាតែអ្នកបានវាយអ្វីមួយនៅបន្ទាត់ពាក្យបញ្ជា |
| {{key:Backspace}} | លុបវត្ថុដែលបានជ្រើស នៅពេលបន្ទាត់ពាក្យបញ្ជាមិនមានទស្សន៍ទ្រនិច; នៅបន្ទាត់ពាក្យបញ្ជា វាលុបអ្វីដែលអ្នកបានវាយ |
| {{key:Esc}} | ពេលគ្មានពាក្យបញ្ជាដំណើរការ៖ លុបការជ្រើសរើស ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | រក្សាទុកច្បាប់ចម្លងក្នុងទម្រង់របស់គំនូរប្លង់ (DWG ឬ DXF) |
| {{key:Mod+Shift+S}} | រក្សាទុកជា៖ ជ្រើស DWG ឬ DXF ហើយបន្ទាប់មករក្សាទុកច្បាប់ចម្លង |
| {{key:Mod+O}} | បើក DWG ឬ DXF |
| {{key:Mod+P}} | បោះពុម្ពទៅ PDF |

មិនធ្វើវិញ ធ្វើវិញ ជ្រើសទាំងអស់ និងបោះពុម្ព មិនធ្វើអ្វីទេខណៈពេលពាក្យបញ្ជាកំពុងដំណើរការ៖ ចុច {{key:Esc}} ជាមុនសិន។

## ចម្លង កាត់ និងបិទភ្ជាប់

| គ្រាប់ចុច | អ្វីដែលវាធ្វើ |
|---|---|
| {{key:Mod+C}} | ចម្លងការជ្រើសរើសទៅ clipboard ({{cmd:COPYCLIP}})។ មិនបានជ្រើសអ្វីទេ៖ CadCraft សួរវត្ថុ |
| {{key:Mod+X}} | កាត់៖ ចម្លងការជ្រើសរើស ហើយបន្ទាប់មកលុបវា ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | បិទភ្ជាប់៖ ច្បាប់ចម្លងដើរតាមទស្សន៍ទ្រនិច; ចុច ឬវាយចំណុច ដើម្បីដាក់វា ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | បិទភ្ជាប់នៅកន្លែងដដែល៖ នៅកូអរដោនេដែលវាត្រូវបានចម្លងពី ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | ច្បាប់ចម្លង៖ ច្បាប់ចម្លងនៃការជ្រើសរើសផ្លាស់ទីជាមួយទស្សន៍ទ្រនិច; ចុចដើម្បីដាក់វា {{key:Esc}} មិនទុកអ្វីទាំងអស់ ({{cmd:DUPLICATE}}) |

សកម្មភាពដូចគ្នាមាននៅក្នុងក្រុម {{ui:កែសម្រួល}} នៃរបារឧបករណ៍ ({{ui:ចម្លង}}, {{ui:បិទភ្ជាប់}}) និងម៉ីនុយ {{ui:ច្រើនទៀត}} របស់វា។ ខណៈពេលពាក្យបញ្ជាផ្សេងកំពុងដំណើរការ បញ្ចប់វា ឬចុច {{key:Esc}} ជាមុនសិន; ចុច {{key:Mod+V}} ឬ {{key:Mod+D}} ម្ដងទៀតខណៈពេលច្បាប់ចម្លងកំពុងដើរតាមទស្សន៍ទ្រនិច ចាប់ផ្ដើមម្ដងទៀត។ នៅពេលអ្នកបានវាយអ្វីមួយនៅបន្ទាត់ពាក្យបញ្ជា ឬពាក្យបញ្ជាកំពុងសួរអត្ថបទ គ្រាប់ចុចទាំងនេះចម្លង កាត់ និងបិទភ្ជាប់អត្ថបទនោះវិញ។ សូមមើល [ចម្លង បិទភ្ជាប់ និងច្បាប់ចម្លង](topic:copy-paste)។

| {{key:F1}} | បើក ឬបិទជំនួយនេះ នៅក្បែរគំនូរប្លង់។ វាដំណើរការសូម្បីតែពាក្យបញ្ជាកំពុងដំណើរការ ហើយមិនដែលទៅដល់បន្ទាត់ពាក្យបញ្ជាទេ។ |
| {{key:Esc}} | ជាមួយទស្សន៍ទ្រនិចនៅក្នុងផ្ទាំងជំនួយ៖ លុបការស្វែងរក ឬបិទផ្ទាំង |
