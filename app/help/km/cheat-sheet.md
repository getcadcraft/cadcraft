វាយឈ្មោះខ្លី (alias) ហើយចុច Enter ឬចុចលើឧបករណ៍។ Esc បោះបង់។ Enter នៅលើជួរទទេនឹងធ្វើពាក្យបញ្ជាចុងក្រោយម្ដងទៀត។

**បោះពុម្ពវា៖** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (មួយទំព័រ A4; លើក្រដាស Letter ត្រូវបោះពុម្ពជាមួយ "ឱ្យសមនឹងទំព័រ")

## គូរ

| វាយ | ពាក្យបញ្ជា | ធ្វើអ្វី |
|---|---|---|
| `L` | {{cmd:LINE}} | គូរបន្ទាត់ត្រង់ |
| `PL` | {{cmd:PLINE}} | គូរច្រវាក់បន្ទាត់ និងធ្នូដែលភ្ជាប់គ្នា |
| `C` | {{cmd:CIRCLE}} | គូររង្វង់ (ចំកណ្ដាល និងកាំ) |
| `A` | {{cmd:ARC}} | គូរធ្នូ |
| `REC` | {{cmd:RECTANG}} | គូរចតុកោណពីជ្រុងពីរ |
| `POL` | {{cmd:POLYGON}} | គូរពហុកោណធម្មតា |
| `EL` | {{cmd:ELLIPSE}} | គូរអេលីប |
| `DT` | {{cmd:TEXT}} | សរសេរអត្ថបទមួយជួរ |
| `T` | {{cmd:MTEXT}} | សរសេរអត្ថបទដែលចូលជួរដោយស្វ័យប្រវត្តិ (កថាខណ្ឌ) |
| `H` | {{cmd:HATCH}} | បំពេញតំបន់ដោយលំនាំ |

| `TR` | {{cmd:TRIM}} | កាត់វត្ថុត្រឡប់ទៅកន្លែងដែលវត្ថុផ្សេងឆ្លងកាត់ |

| `X` | {{cmd:EXPLODE}} | បំបែកប្លុក ឬប៉ូលីឡាញទៅជាផ្នែករបស់វា |
| `S` | {{cmd:STRETCH}} | ផ្លាស់ទីចុងនៅក្នុងបង្អួចឆ្លងកាត់ |
| `AR` | {{cmd:ARRAY}} | ចម្លងជាក្រឡាចត្រង្គ ឬរង្វង់ |
| `J` | {{cmd:JOIN}} | ភ្ជាប់បន្ទាត់ និងធ្នូទៅជាវត្ថុមួយ |
| `BR` | {{cmd:BREAK}} | កាត់វត្ថុជាពីរ ឬយកផ្នែកមួយចេញ |
