## អ្វីដែលអ្នកនឹងបង្កើត

ស្លាកបន្ទប់ពីរ ដែលមានកណ្ដាលនៅក្នុងបន្ទប់របស់ពួកវា កំណត់ចំណាំមួយដែលបត់តាមទទឹងរបស់វា បន្ទាប់មកកែស្លាកមួយក្នុងចំណោមស្លាកទាំងនោះ។

## កម្ពស់អត្ថបទ និងមាត្រដ្ឋានគំនូរប្លង់

កម្ពស់អត្ថបទគិតជាឯកតាគំនូរ។ នៅក្នុងគំនូរប្លង់ជាមីលីម៉ែត្រ ដែលនឹងបោះពុម្ពនៅ 1:50 អត្ថបទដែលមានកម្ពស់ 2.5 mm លើក្រដាស ត្រូវតែមានកម្ពស់ 2.5 × 50 = 125 ឯកតានៅក្នុងម៉ូដែល។ នៅលើផ្ទាំងសន្លឹក ដែលអ្នកគូរជាឯកតាក្រដាស 2.5 នៅទីនោះមានន័យថា 2.5 mm លើក្រដាស។

## ដាក់ស្លាកកណ្ដាល

1. វាយ `DT` ហើយចុច {{key:Enter}} (ឬចុច {{ui:Text}} នៅរបារឧបករណ៍)។ សំណួរនឹងបង្ហាញ `Specify start point of text [Justify]:`។
2. វាយ `J` ហើយចុច {{key:Enter}}។
3. នៅសំណួរ `Enter an option [Left/Center/Right/Middle/TL/MC] <L>:` វាយ `MC` ហើយចុច {{key:Enter}}។
4. នៅ `Specify insertion point of text` ចុចកណ្ដាលបន្ទប់មួយ។
5. នៅ `Specify height` វាយ `250` ហើយចុច {{key:Enter}}។
6. នៅ `Specify rotation angle of text <0>` ចុច {{key:Enter}}។
7. នៅ `Enter text` វាយ `KITCHEN` ហើយចុច {{key:Enter}}។

ស្លាកបង្ហាញឡើង ដោយមានកណ្ដាលនៅចំណុចដែលអ្នកបានចុច។

8. ចុច {{key:Enter}} នៅសំណួរ `Enter text` ទទេ ដើម្បីបញ្ចប់ពាក្យបញ្ជា។

## សរសេរកំណត់ចំណាំដែលបត់

អត្ថបទកថាខណ្ឌ ({{cmd:MTEXT}}) បត់ទៅទទឹងមួយ ហើយត្រូវបានវាយដោយផ្ទាល់លើគំនូរ។

1. វាយ `T` ហើយចុច {{key:Enter}} ឬចុច {{ui:Paragraph}} នៅរបារឧបករណ៍។
2. នៅ `Specify first corner` ចុចកន្លែងដែលជ្រុងខាងលើ-ឆ្វេងនៃកំណត់ចំណាំត្រូវទៅ។
3. ដើម្បីផ្លាស់ប្តូរកម្ពស់ជាមុនសិន វាយ `H` ចុច {{key:Enter}} វាយ `250` ហើយចុច {{key:Enter}}។
4. នៅ `Specify opposite corner [Height/Justify/Line spacing/Rotation/Width]` ចុចទៅស្តាំនៃជ្រុងទីមួយ។ ចម្ងាយឆ្លងកាត់គឺជាទទឹងដែលអត្ថបទបត់; ចម្ងាយដែលអ្នកចុចចុះក្រោមមិនកំណត់វាទេ។
5. ប្រអប់មួយបើកលើគំនូរ ដោយទស្សន៍ទ្រនិចនៅក្នុងវា។ វាយ `ALL DIMENSIONS ARE IN MILLIMETERS UNLESS NOTED`។ ពាក្យនឹងបត់ទៅទទឹងនៅពេលអ្នកវាយ។
6. ចុច {{key:Enter}} ដើម្បីចាប់ផ្តើមកថាខណ្ឌថ្មី ហើយវាយ `CHECK ON SITE`។
7. ចុច {{key:Mod+Enter}} ចុច {{ui:OK}} ឬចុចកន្លែងណាមួយនៅក្រៅប្រអប់។ កំណត់ចំណាំនោះជាវត្ថុតែមួយ។

របារខាងលើប្រអប់ផ្លាស់ប្តូរ {{ui:Height}}, {{ui:Line spacing}} (1 គឺធម្មតា, 1.5 គឺច្រើនជាងមួយភាគពីរ), {{ui:Width}} (0 = គ្មានការបត់) និង {{ui:Justify}} ខណៈពេលអ្នកវាយ។ {{key:Esc}} ឬ {{ui:Cancel}} បិទវាដោយមិនបន្ថែមអ្វីឡើយ។

ជម្រើសនៅជ្រុងទីពីរ៖ `H` កម្ពស់ `J` តម្រឹម (`TL` កំពូលឆ្វេង … `BR` ក្រោមស្តាំ៖ ជ្រុង ឬកណ្ដាលនៃប្រអប់ដែលនៅដដែល) `L` គម្លាតបន្ទាត់ `R` ការបង្វិល `W` ទទឹងដែលវាយចូល ជំនួសឱ្យជ្រុងទីពីរ។

:::note
ខណៈពេលប្រអប់បើក {{key:Space}} វាយចន្លោះ ហើយ {{key:Enter}} ចាប់ផ្តើមកថាខណ្ឌថ្មី។ DWG ដែលបានរក្សាទុកនៅតែរក្សាអត្ថបទកថាខណ្ឌជា MTEXT; DXF R12 គ្មានអត្ថបទកថាខណ្ឌទេ ដូច្នេះបន្ទាត់នីមួយៗត្រូវបានរក្សាទុកជាអត្ថបទរៀងៗខ្លួន។

### បន្ទាត់តែមួយជាច្រើនវិញ

{{cmd:TEXT}} (`DT`) សុំបន្ទាត់មួយក្នុងមួយដង៖ {{key:Enter}} នីមួយៗចាប់ផ្តើមបន្ទាត់បន្ទាប់ ទាបជាង 1.667 ដងនៃកម្ពស់អត្ថបទ ហើយបន្ទាត់នីមួយៗជាវត្ថុរៀងខ្លួន។ ចុច {{key:Enter}} លើបន្ទាត់ទទេដើម្បីបញ្ចប់។

## ជម្រើសតម្រឹម

| ជម្រើស | ចំណុចដែលអ្នកចុចគឺ |
|---|---|
| ឆ្វេង (L) (លំនាំដើម) | ចុងឆ្វេងនៃខ្សែមូលដ្ឋាន |
| កណ្ដាល (C) | កណ្ដាលនៃខ្សែមូលដ្ឋាន |
| ស្តាំ (R) | ចុងស្តាំនៃខ្សែមូលដ្ឋាន |
| ចំកណ្ដាល (MC) | កណ្ដាលនៃអត្ថបទ ទាំងផ្តេក និងឡើង-ចុះ |
| កំពូលឆ្វេង (TL) | ជ្រុងខាងលើ-ឆ្វេង |

## កែសម្រួលអត្ថបទ

1. ចុចពីរដងលើវត្ថុអត្ថបទ។ វាបើកក្នុងប្រអប់ដូចអត្ថបទកថាខណ្ឌថ្មី ដោយទស្សន៍ទ្រនិចនៅចុង។
2. ផ្លាស់ប្តូរពាក្យ។
3. ចុច {{key:Mod+Enter}} ឬចុចក្រៅប្រអប់។ អត្ថបទនៅលើគំនូរប្លង់ផ្លាស់ប្តូរ; {{key:Esc}} ទុកវាដូចដើម។

{{cmd:TEXTEDIT}} (`ED`) ធ្វើដូចគ្នា៖ ជ្រើសអត្ថបទមួយបន្ទាប់ពីមួយ ហើយចុច {{key:Enter}} នៅពេលរួច។

ដើម្បីផ្លាស់ប្តូរអត្ថបទដែលបានជ្រើស សូមប្រើបន្ទះខាងស្តាំវិញ៖ {{ui:Text}}, {{ui:Height}}, {{ui:Wrap width}} (0 = គ្មានការបត់), {{ui:Line spacing}}, {{ui:Rotation}}, ទីតាំង X និង Y និង {{ui:Justify}}។ បញ្ជី {{ui:Justify}} ក៏មានជម្រើសក្រោមឆ្វេង ដែលអត្ថបទពីកម្មវិធីផ្សេងពេលខ្លះប្រើ។

## ទម្រង់នៅខាងក្នុងអត្ថបទកថាខណ្ឌពីកម្មវិធីផ្សេង

អត្ថបទកថាខណ្ឌក្នុង DWG ឬ DXF អាចមានកូដនៅខាងក្នុង៖ ពណ៌តាមពាក្យ ដិត និងទ្រេត គូសក្រោម គូសលើ និងគូសឆ្លង ប្រភាគជាប់គ្នាដូចជា 1/2 និងកម្ពស់ផ្សេងសម្រាប់ពាក្យមួយ។ CadCraft រក្សាកូដទាំងនោះ គូរវា (នៅលើអេក្រង់ និងក្នុង PDF ដែលបានបោះពុម្ព) ហើយរក្សាទុកវាមកវិញដោយមិនផ្លាស់ប្តូរ។

នៅពេលអ្នកកែអត្ថបទបែបនេះ (ចុចពីរដង {{cmd:TEXTEDIT}} ប្រអប់ Text នៃបន្ទះខាងស្តាំ ឬ {{cmd:FIND}} ជាមួយ Replace) អ្នកកែតែពាក្យធម្មតារបស់វា។ ពាក្យដែលអ្នកវាយនៅជាប់ run ណាមួយ ហើយយកពណ៌ និងរចនាបថរបស់វា; កូដផ្សេងទៀតនៅកន្លែងរបស់វា។ ប្រសិនបើអ្នកវាយលេខនៃប្រភាគជាប់គ្នាឡើងវិញ ប្រភាគនោះក្លាយជាអត្ថបទធម្មតា។ ការកំណត់អត្ថបទទាំងមូលពីប្រអប់ Text រក្សាកូដតែកន្លែងដែលអាចប្រាប់បានថាពាក្យណាបាននៅដដែល។

ឈ្មោះ font (`\F`) ត្រូវបានរក្សា និងរក្សាទុក ប៉ុន្តែអ្វីៗទាំងអស់ត្រូវបានគូរដោយ font រចនាបថ Helvetica តែមួយ។ មិនទាន់មានរបារឧបករណ៍សម្រាប់វាយកូដនៅឡើយទេ។

## ចង្អុលទៅអ្វីមួយ៖ multileader

{{ui:Leader}} នៅក្រុម {{ui:Annotate}} ({{cmd:MLEADER}}, `MLD`) គូរព្រួញ បន្ទាត់ចង្អុល ចុងខ្សែខ្លី និងកំណត់ចំណាំ ជាវត្ថុតែមួយ។

1. ចុច {{ui:Leader}}។ នៅ `Specify leader arrowhead location` ចុចអ្វីដែលកំណត់ចំណាំនោះនិយាយអំពី។
2. នៅ `Specify leader landing location` ចុចកន្លែងដែលកំណត់ចំណាំទៅ។ ចុងខ្សែបត់ទៅខាងដែលអ្នកបានចុច។
3. វាយកំណត់ចំណាំក្នុងប្រអប់ដែលបើក ហើយចុច {{key:Mod+Enter}}។

`A` និង `L` នៅសំណួរដំបូង កំណត់ទំហំក្បាលព្រួញ និងប្រវែងចុងខ្សែ; កម្ពស់អត្ថបទមកពី {{ui:Text height}} សម្រាប់វិមាត្រថ្មី គុណនឹង {{ui:Overall scale}}។ ចុចពីរដងលើ multileader ដើម្បីផ្លាស់ប្តូរពាក្យរបស់វា។ ចំណុចចាប់ផ្លាស់ទីក្បាលព្រួញ និងចុងខ្សែ; កំណត់ចំណាំធ្វើតាមចុងខ្សែ។ នៅ {{ui:Properties}}៖ {{ui:Text}}, {{ui:Height}}, {{ui:Wrap width}}, {{ui:Arrowhead size}} និង {{ui:Landing distance}}។

## សម្គាល់ការផ្លាស់ប្តូរដោយ revision cloud
