## អ្វីដែលអ្នកនឹងរៀន

## ដាក់លេខតាមវាលរបស់សន្លឹក

ជំនួសឱ្យការដាក់លេខសន្លឹកដោយដៃ ឱ្យច្បាប់មួយសាងសង់លេខនីមួយៗពីវាលរបស់សន្លឹក ដូច្នេះសន្លឹកដែលផ្លាស់ទៅជាន់ ឬផ្នែកផ្សេង ទទួលលេខថ្មីរបស់វាដោយខ្លួនឯង។

1. ផ្ដល់វាលដល់សន្លឹកនីមួយៗ៖ ជ្រើសវា ចុច {{ui:ប្ដូរឈ្មោះ…}} ហើយនៅ {{ui:វាលនៃសន្លឹកនេះ}} សរសេរមួយក្នុងមួយបន្ទាត់ ឧទាហរណ៍ `DISCIPLINE = A` និង `LEVEL = 1`។ វាលដែលឈុតទាំងមូលចែករំលែក (ឧទាហរណ៍ `DISCIPLINE = A`) អាចដាក់ក្នុង {{ui:លក្ខណៈ…}} របស់ឈុតវិញ។
2. បើកម៉ឺនុយនៃផ្ទាំង ហើយចុច {{ui:ច្បាប់ដាក់លេខ…}}។
3. សរសេរច្បាប់ ឧទាហរណ៍ `{DISCIPLINE}-{LEVEL}{SEQ:2}`។ `{SEQ}` រាប់ឡើងក្នុងចំណោមសន្លឹកដែលវាលផ្សេងរបស់វាដូចគ្នា ដូច្នេះកម្រិត 1 ទទួល A-101, A-102 ហើយកម្រិត 2 ចាប់ផ្ដើមឡើងវិញនៅ A-201។ `{SEQ:2}` សរសេរវាជាលេខពីរខ្ទង់; `{SUBSET}` ជាឈ្មោះឈុតរងដែលសន្លឹកស្ថិតនៅក្នុងនោះ។
4. ជ្រើសអ្វីដែលកើតឡើងនៅពេលវាលមួយផ្លាស់ប្ដូរ៖ {{ui:ដាក់លេខសន្លឹកឡើងវិញ}} រក្សាលេខឱ្យធ្វើតាមច្បាប់បន្ទាប់ពីការផ្លាស់ប្ដូរនីមួយៗ; ជម្រើសមួយទៀតដាក់លេខវាម្ដង ឥឡូវនេះ។

ច្បាប់ត្រូវបានរក្សាទុកក្នុងឯកសារឈុត។ ខណៈដែលវាដាក់លេខដោយខ្លួនឯង សូមផ្លាស់ប្ដូរវាលរបស់សន្លឹក មិនមែនលេខរបស់វាទេ។

ជ្រើសសន្លឹកគម្របនៅក្នុងបញ្ជី ហើយជ្រើស {{ui:ដាក់បញ្ជីសន្លឹកលើសន្លឹកនេះ}}។ តារាងនៃសន្លឹកគ្រប់ (លេខ និងចំណងជើង នៅក្រោមឈុតរងរបស់វា) ត្រូវដាក់ក្នុងជ្រុងខាងលើឆ្វេងរបស់សន្លឹក។ {{ui:ធ្វើបច្ចុប្បន្នភាពគំនូរប្លង់}} និង {{ui:បោះពុម្ពផ្សាយទៅ PDF}} រក្សាវាឱ្យទាន់សម័យ។ វាជាប្លុកមួយ `CC_SHEETLIST`៖ ផ្លាស់ទីវាដូចការយោងប្លុកណាមួយ។

## បោះពុម្ពឈុត

{{ui:បោះពុម្ពផ្សាយទៅ PDF}} ធ្វើ PDF តែមួយដែលមានទំព័រមួយក្នុងមួយសន្លឹក តាមលំដាប់ឈុត ក្នុងទំហំក្រដាសរបស់សន្លឹកនីមួយៗ ជាមួយចំណាំមួយក្នុងមួយសន្លឹក ("A-101 — Floor plan")។ នៅពេលឈុតរងមួយត្រូវបានជ្រើស CadCraft សួរថាតើត្រូវបោះពុម្ពតែឈុតរងនោះឬអត់។ ប្លុកចំណងជើងក្នុង PDF ត្រូវបានបំពេញពីឈុតសូម្បីមុនពេលអ្នកធ្វើបច្ចុប្បន្នភាពគំនូរ; គំនូរខ្លួនឯងមិនត្រូវបានផ្លាស់ប្ដូរដោយការបោះពុម្ពទេ។ PDF ត្រូវបានទាញយក។

{{ui:បោះពុម្ពទៅ DWG…}} សរសេរសន្លឹកនីមួយៗជា DWG របស់ខ្លួន (DWG 2018)៖ ម៉ូដែល និងសន្លឹកនោះ ជាមួយប្លុកចំណងជើងរបស់វាបំពេញពីឈុត ដាក់ឈ្មោះតាមលេខ និងចំណងជើង (`A-101 Level 1 floor plan.dwg`)។ ជ្រើស {{ui:DWG}}, ឬ {{ui:DWG + PDF}} សម្រាប់ PDF របស់ឈុតនៅក្បែរវា។ `publish.json` រាយបញ្ជីឯកសារនីមួយៗជាមួយទំហំ និង SHA-256 របស់វា។ នៅពេលថតរបស់ឈុតអាចសរសេរបាន (CadCraft Studio ឬថតដែលអ្នកជ្រើសក្នុងកម្មវិធីរុករក) ឯកសារចូលក្នុងថត `<set name> - published`; បើមិនដូច្នេះ ពួកវាទាញយកជា zip តែមួយ។ [ការជំនួសថ្នាក់វ្យូផត](topic:viewport-overrides) មកជាមួយក្នុង DWG នីមួយៗ។

## ទុកឈុតជា zip

{{ui:ទុកជាឯកសារ zip}} ខ្ចប់ឯកសារឈុត គំនូរគ្រប់ដែលវាប្រើ និងអ្វីដែលគំនូរទាំងនោះតភ្ជាប់ (គំនូរដែលបានតភ្ជាប់ និងរបស់ពួកវា និងរូបភាព) ដោយរក្សាថតរបស់ពួកវា ហើយ `Transmittal.txt` ដែលរាយបញ្ជីឯកសារគ្រប់។ តំណដែលមិនស្ថិតនៅក្នុងថតឈុតត្រូវបានរាយនៅទីនោះថាបាត់។ តំណត្រូវបានរកឃើញតាមផ្លូវរបស់វាពីគំនូរ ហើយបន្ទាប់មកតាមឈ្មោះឯកសាររបស់វានៅកន្លែងណាមួយក្នុងថត។

## ឯកសារឈុត

ឯកសារ `.ccsheets` គឺជា JSON ដែលអ្នកអាចអានក្នុងកម្មវិធីកែអត្ថបទណាមួយ៖

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

ផ្លូវគឺទាក់ទងនឹងថតឈុត ជាមួយ `/` រវាងថត។ CadCraft ពិនិត្យឯកសារនៅពេលវាបើក៖ ផ្លូវដាច់ខាត សន្លឹកដែលគ្មានឯកសារ ឬប្លង់ ឬអត្ថបទដែលមិនមែនសុទ្ធ ត្រូវបានទុកចោល ហើយប្រវត្តិនិយាយអំពីវា។
