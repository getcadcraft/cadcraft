## Юу сурах вэ

Олон зургийн файлаас хуудсуудыг (байрлалуудыг) **хуудасны багц** болгон цуглуулах, тэдгээрийг дугаарлаж, нэрлэх, гарчгийн блокуудыг чинь багцаас автоматаар бөглөх, бүх багцыг нэг PDF болгон нийтлэх, мөн бүгдийг нэг zip болгон илгээхэд бэлтгэх.

Хуудасны багц нь өөрийн жижиг файлд, `<name>.ccsheets` гэж, зургуудын хавтсанд амьдардаг. Багцын файл нь хавтаснаас харьцангуй замаар хуудсуудыг жагсаадаг, тиймээс та бүх хавтсыг зөөж эсвэл хуулж болно.

:::note
Хавтсыг унших, бичихийн тулд Chrome эсвэл Edge (тэд хуудсыг таны сонгосон хавтсанд ажиллуулж чадна), эсвэл ширээний апп хэрэгтэй. Бусад хөтөч багцыг зөвхөн унших горимд нээнэ: та үзэж, нийтлэж болно, харин багцын файл хадгалахын оронд татагдана.
:::

## Багц эхлүүлэх

1. Зүүн самбарт {{ui:Sheet set}} хэсгийг олоод, түүний {{ui:Set}} цэсийг нээнэ. {{cmd:SHEETSET}} (эсвэл `SSM`) бичвэл та мөн тэнд очно.
2. {{ui:New set…}}-ийг сонгоно. Багцад нэр өгнө, хүсвэл төслийн нэр ба дугаарыг оруулна.
3. Зургуудыг агуулсан хавтсыг сонгоно. Багцын файл тэнд хадгалагдана.

Багцыг дараа нээхдээ {{ui:Open set…}}-ийг сонгоод ижил хавтсыг сонгоно. Хавтсанд нэгээс олон багц байвал CadCraft аль нь вэ гэж асууна.

## Хуудас нэмэх

1. {{ui:Add sheets from a drawing…}}-ийг сонгоод, хавтсан дахь зургуудын нэгийг сонгоно.
2. CadCraft тэр зургийг дэвсгэрт уншиж (дэлгэцэнд нээгдэхгүй), түүний хуудсуудыг жагсаана. Хүссэн хуудсуудын тэмдгийг тавиад {{ui:OK}} дарна.
3. Хуудсыг сонгоод {{key:F2}} дарна (эсвэл {{ui:Rename and renumber…}}) дугаар ба гарчиг өгнө, жишээ нь `A-101` ба `Floor plan`.

{{ui:New sheet from template…}} нь өөр зургийн хуудсаас (түүний гарчгийн блок ба харагдацууд) шинэ зураг үүсгэж, шинэ хуудсын нэрээр нэрлээд нэмнэ. Багц таны ашигласан зургийг загвар болгож санана.

## Багцаа зохион байгуулах

- **Дэд багцууд** хуудсуудыг бүлэглэнэ, жишээ нь Архитектур › Төлөвлөгөө: хаана байрлахыг сонгоод {{ui:New subset…}}-ийг сонгоно.
- **Дараалал**: хуудсыг жагсаалтын өөр газарт чирнэ, эсвэл дэд багц дээр чирч түүнд зөөнө. Гараар бол сонгоод {{key:Alt+Up}} эсвэл {{key:Alt+Down}} дарна.
- **Хуудас нээх**: хоёр удаа дарна (эсвэл {{key:Enter}} дарна). Түүний зураг тусдаа табд тэр хуудсан дээр нээгдэнэ.
- **Хасах**: сонгоод {{key:Delete}} дарна. Зураг өөрөө өөрчлөгдөхгүй.
- **Буцаах**: {{ui:Undo set change}} ба {{ui:Redo set change}} нь багцад хийсэн өөрчлөлтүүдээр алхам алхмаар явна.
- **Дахин дугаарлах**: {{ui:Renumber sheets…}} нь бүх хуудсыг, эсвэл нэг дэд багцын хуудсыг жагсаалтын дарааллаар дугаарлана: угтвар, эхлэх тоо ба алхам (`A-` ба `101` нь A-101, A-102 …).

Өөрчлөлт бүр багцын файлд шууд хадгалагдана.

## Хуудасны дугаарыг талбараас нь үүсгэх

Хуудсуудыг гараар дугаарлахын оронд дүрэм нь дугаар бүрийг хуудасны талбаруудаас автоматаар бүтээж болно, тиймээс түвшин эсвэл салбар солигдсон хуудас шинэ дугаараа өөрөө авна.

1. Хуудас бүрт талбаруудаа өгнө: хуудсыг сонгоод {{ui:Rename…}}-г дарж, {{ui:Fields of this sheet}}-д нэг мөрөнд нэгийг бичнэ, жишээ нь `DISCIPLINE = A` ба `LEVEL = 1`. Бүх багцад хамаатай талбар (жишээ нь `DISCIPLINE = A`) багцын {{ui:Properties…}}-д орж болно.
2. Самбарын цэсийг нээгээд {{ui:Numbering rule…}}-г дарна.
3. Дүрмээ бичнэ, жишээ нь `{DISCIPLINE}-{LEVEL}{SEQ:2}`. `{SEQ}` нь бусад талбар нь ижил байдаг хуудсуудын дотор тоолно, тиймээс түвшин 1 нь A-101, A-102 авч, түвшин 2 дахин A-201-ээс эхэлнэ. `{SEQ:2}` нь хоёр оронтой бичнэ; `{SUBSET}` нь хуудас байгаа дэд багцын нэр.
4. Талбар өөрчлөгдөхөд юу болохыг сонгоно: {{ui:Renumber the sheets}} нь өөрчлөлт бүрийн дараа дугаарыг дүрмийн дагуу байлгана; нөгөө сонголт нь тэдгээрийг одоо нэг удаа дугаарлана.

Дүрмийг багцын файлд хадгална. Энэ нь өөрөө дахин дугаарлах үед, хуудасны дугаарыг бус талбарыг нь өөрчил.

## Гарчгийн блокуудыг багцаас бөглөх

Гарчгийн блок нь текстээ багцаас авдаг, хэрэв түүний шинж чанарууд талбарын нэрээр тэмдэглэгдсэн бол:

| Таг | Юу харуулах |
|---|---|
| `SHEETNUMBER` (эсвэл `SHEET_NO`, `DWG_NO`) | Хуудасны дугаар |
| `SHEETTITLE` (эсвэл `TITLE`, `SHEET_TITLE`) | Хуудасны гарчиг |
| `SHEETDESC` | Хуудасны тайлбар |
| `PROJECTNAME` (эсвэл `PROJECT`) | Төслийн нэр |
| `PROJECTNUMBER` (эсвэл `PROJECT_NO`, `JOB_NO`) | Төслийн дугаар |
| `SHEETSETNAME` | Багцын нэр |
| `SHEETINDEX`, `SHEETCOUNT` | "12-оос 3", ба 12 |
| Өөрийн, жишээ нь `CLIENT` | {{ui:Set fields…}}-д таны бичсэн утга |

{{ui:Set fields…}} нь төслийн нэр ба дугаар болон өөрийн талбаруудыг агуулна, нэг мөрөнд нэг нь `NAME = value` хэлбэрээр.

{{ui:Update drawings}} нь багцын зураг бүрийн гарчгийн блокуудад дугаар, гарчиг, талбарыг бичиж, хуудас бүрийн байрлалын табыг багц хэлсэнчлэн нэрлэнэ (анхдагчаар дугаар ба гарчиг, жишээ нь `A-101 Floor plan`; {{ui:Set fields…}} › {{ui:Layout tab names}} үүнийг өөрчилнө). Зураг бүрийг өөрийн хэлбэр, хувилбартайгаа хэвээр нь хадгална. Хуудсуудыг дахин дугаарлах эсвэл нэрлэсний дараа дахин ажиллуулбал табууд ба гарчгийн блокууд дагана.

## Нүүрний хуудсан дээрх хуудасны жагсаалт

Жагсаалтаас нүүрний хуудсаа сонгоод {{ui:Put the sheet list on this sheet}}-ийг сонгоно. Бүх хуудасны хүснэгт (дугаар ба гарчиг, дэд багцынхаа доор) хуудасны зүүн дээд буланд орно. {{ui:Update drawings}} ба {{ui:Publish to PDF}} үүнийг шинэчлэн байлгана. Энэ нь нэг блок, `CC_SHEETLIST`: бусад блок лавлагаа шиг зөөнө.

## Багцыг нийтлэх

{{ui:Publish to PDF}} нь багцын дарааллаар, хуудас бүр өөрийн цаасны хэмжээгээр, хуудас бүрт нэг хуудастай нэг PDF үүсгэж, хуудас бүрт тэмдэгт ("A-101 — Floor plan") нэмнэ. Дэд багц сонгогдсон үед CadCraft тэр дэд багцыг л нийтлэх эсэхийг асууна. PDF дэх гарчгийн блокууд таныг зургуудаа шинэчлээгүй ч багцаас бөглөгдөнө; нийтлэх нь зургуудыг өөрчилдөггүй. PDF татагдана.

{{ui:Publish to DWG…}} хуудас бүрийг өөрийн DWG (DWG 2018) болгон бичнэ: загвар ба тэр нэг хуудас, гарчгийн блок нь багцаас бөглөгдөж, дугаар ба гарчгаараа нэрлэгдэнэ (`A-101 Level 1 floor plan.dwg`). {{ui:DWG}}-ийг, эсвэл багцын PDF-г хажууд нь авахыг хүсвэл {{ui:DWG + PDF}}-ийг сонгоно. `publish.json` файл бүх файлыг хэмжээ ба SHA-256-тайгаар жагсаана. Багцын хавтас бичигдэх боломжтой үед (CadCraft Studio эсвэл хөтөч дээр таны сонгосон хавтас) файлууд `<set name> - published` хавтсанд орно; үгүй бол нэг zip болгон татагдана. Харагдацын [класс тохируулга](topic:viewport-overrides) DWG бүрт хамт явна.

## Багцыг архивлах

{{ui:Archive as a zip}} нь багцын файл, түүний ашигладаг бүх зургийг, мөн тэдгээрийн холбоосууд (холбосон зурагууд, тэдгээрийнх нь цаашдын зурагууд, зургууд)-ыг хавтасны бүтэцтэй нь хамт савална, мөн бүх файлыг жагсаасан `Transmittal.txt` нэмнэ. Багцын хавтаснаас гадуур байгаа холбоосыг тэнд алга гэж жагсаана. Холбоосуудыг зургаас нь зам, дараа нь хавтасны дотор ямар ч газар байгаа нэр нь ялгана.

## Багцын файл

`.ccsheets` файл бол дурын текст засварлагчаар уншиж болох JSON:

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

Замууд багцын хавтаснаас харьцангуй, хавтсуудын хооронд `/`. CadCraft нээхдээ файлыг шалгана: бүрэн зам, файлгүй эсвэл байрлалын нэргүй хуудас, эсвэл энгийн биш текст хасагдана, түүх үүнийг хэлнэ.
