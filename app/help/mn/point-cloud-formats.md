## Энд юу хавсрах вэ

Эдгээрийг {{cmd:POINTCLOUDATTACH}}, {{ui:Нээх}} командаар эсвэл хуудас дээр чирж хавсаргана (см. сэдэв: цэгийн үүл дээр баригдсан шугамыг мөрлөх).

| Формат | Өргөтгөл | Юу уншигдах |
|---|---|---|
| LAS, LAZ | `.las`, `.laz` | LAS 1.0–1.4: цэгүүд, өнгө, эрч хүч, LiDAR ангилал, координатын систем ба түүний нэгж. LAZ 1 ГБ хүртэл. |
| E57 | `.e57` | Файл дахь скан бүр, өөрийн байрлалаараа байрлуулсан; өнгө, эсвэл файлд өнгө байхгүй бол эрч хүч; метр. Файл дахь зургууд орхигдоно (үүнийг хэлнэ). Одоогоор 6 сая цэг ба 512 МБ хүртэл: илүү том скануудыг LAS эсвэл LAZ-аар экспортло. |
| PLY | `.ply` | Текст ба хоёртын (хоёр байт дарааллаар): оройн x y z, өнгө ба эрч хүч. Гадаргуу орхигдоно (үүнийг хэлнэ). |
| PCD | `.pcd` | Текст ба хоёртын: x y z, багцалсан эсвэл тусдаа өнгө, эрч хүч. Шахагдсан PCD файлыг одоогоор уншихгүй: хоёртын эсвэл текст хэлбэрээр хадгал. |
| PTX | `.ptx` | Нэг буюу хэд хэдэн скан, тус бүр өөрийн хувиргалтаар байрлана; скан хэмжээгээгүй цэгүүд орхигдоно. Метр. |
| PTS, XYZ | `.pts`, `.xyz` | Текст: x y z, багана байвал эрч хүч ба өнгөтэй. |

## Зөвхөн скан хийгчийн программ уншдаг файлууд

Зарим скан файл нь скан хийгч үйлдвэрлэгчийн өөрийн формат бөгөөд нийтлэгдсэн тодорхойлолт, нээлттэй уншигчгүй. CadCraft эдгээрийг уншиж чадахгүй: хавсаргахад юу болохыг, мөн юу хийхийг команд мөрөнд хэлнэ. Скан файлыг үйлдвэрлэгчийн программаас E57 эсвэл LAS (эсвэл PTX, PTS) болгон экспортлоод, экспортолсон файлаа хавсаргана.

| Файл | Өргөтгөл | Экспортлох программ |
|---|---|---|
| ReCap төсөл | `.rcp` | ReCap: төслийг нээж экспортлоно. Төсөл зөвхөн скануудаа заадаг тул `.rcp`-ийг ганцаар хуулахад цэг гарахгүй. |
| ReCap скан | `.rcs` | ReCap: скан харьяалагдах төслийг нээж экспортлоно. |
| FARO скан | `.fls` | FARO SCENE. |
| Leica скан | `.lgs` | Leica Cyclone REGISTER 360. |
| Trimble скан | `.tzf` | Trimble RealWorks эсвэл Trimble Business Center. |
| Z+F скан | `.zfs` | Z+F LaserControl. |

:::tip
Экспорт формат асуухад LAS эсвэл LAZ нь CadCraft-ийн ашигладаг бүх зүйлийг (өнгө, эрч хүч, ангилал, координатын систем ба түүний нэгж) хамгийн жижиг файлд хадгална.
:::

## Яагаад эдгээр файлыг уншихгүй вэ

Эдгээр формат нийтлэгдээгүй бөгөөд тэдгээрийг уншиж чадах цорын ганц арга бол үйлдвэрлэгч бүрийн өөрийн программын сан, өөрийн нөхцөлөөр. CadCraft зөвхөн компьютер дээрээ өөрийн кодоор уншиж чаддаг форматыг уншдаг тул хавсаргахын тулд скан хэзээ ч илгээгдэх шаардлагагүй.
