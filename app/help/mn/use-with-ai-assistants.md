## Та юу сурах вэ

AI туслах (эсвэл таны бичсэн скрипт) зургийг хэрхэн харах, CadCraft-ийн командуудыг хэрхэн ажиллуулах, хэрхэн зурж хадгалах, мөн түүнд юуг хөндөхийг хэрхэн шийдэх вэ гэдгийг сурах.

CadCraft-д **өөрийн AI байхгүй** бөгөөд юуг ч хаашаа ч илгээдэггүй. Туслахаа та өөрөө авчирна: Model Context Protocol (MCP)-ийг ярьдаг ямар ч програм. CadCraft зөвхөн түүнд хэрэгслүүдийг өгнө, харин аль нь вэ гэдгийг та сонгоно.

Хоёр арга байна:

- **Таны нээлттэй зураг.** Туслах энэ цонхонд, танд зэрэгцэн, таны компьютер дээрх CadCraft Studio-оор ажиллана. Энэ нь {{ui:Тохиргоо}} › {{ui:CadCraft}} › {{ui:Туслахууд}}-д зориулагдсан.
- **Компьютер дээрх зургууд, аппыг нээхгүйгээр.** CadCraft MCP сервер болон `cadcraft` командын мөр таны нэрлэсэн хавтсанд байгаа DWG ба DXF файлуудыг уншиж, бичнэ. Доорх "CadCraft-ийг нээхгүйгээр файлтай ажиллах" хэсгийг үзнэ үү.

## Асаах

1. {{ui:Тохиргоо}}-г нээ (аппын дээд мөрний тэмдэг, эсвэл {{key:Mod+,}}), дараа нь {{ui:CadCraft}} таб руу орно.
2. {{ui:Туслахууд}}-ын доор **AI туслах болон скриптүүдэд CadCraft ашиглуулах** гэснийг тэмдэглэ. Та асаах хүртэл энэ унтраалттай байна.
3. Түүнд юу хийхийг зөвшөөрөхөө сонгоно. **Read** эхлээд тэмдэглэгдсэн байна; бусдыг хэрэгтэй үед л тэмдэглэ.

| Зөвшөөрөл | Туслах юу хийж чадах вэ |
|---|---|
| Read | Зургийг харах: тайлбарлах, объектуудыг жагсаах ба олох, сонголтыг харах, харагдацыг тайлбарлах ба зургийг авах, давхарга болон зурах дүрмээр шалгах |
| Edit | Зурган дээр командуудыг ажиллуулах ба сонголтыг өөрчлөх. Үйлдэл бүр нэг буцаах алхам |
| Save | Зургийг хадгалах (компьютер дээр файл руугаа; браузерт татаж авах хэлбэрээр) |
| Export | PDF руу гаргах болон бусад файл үүсгэх |

## Танаа сонгосон хавтсын файлуудыг ашиглуулах

CadCraft Studio дээр туслах файлуудыг диалог ашиглахгүйгээр нэрээр нь нээж, хадгалж, PDF гаргаж чадна, гэхдээ зөвхөн {{ui:Туслахууд}} › {{ui:Хандаж болох хавтаснууд}}-д нэмсэн хавтсын дотор:

1. {{ui:Хавтас нэмэх…}}-ийг сонгоод Studio-ийн өөрийн харилцах цонхоос хавтсаа сонго.
2. Туслах одоо тэр хавтсын файлуудыг жагсаах (`files_list`), зургийг нээх (`drawing_open`), түүнийг тэнд DWG хувилбараар эсвэл DXF болгон хадгалах, PDF эсвэл SVG файл руу гаргах, LISP файлыг ачаалах, командад шаардсан файлыг өгөх (`INSERT` `F`, `XATTACH`, цэгийн файл) эсвэл команд файлаа хаана бичихээ хэлэх (`COUNT`-ийн CSV, `PUBLISH`) боломжтой.
3. {{ui:Хасах}} хавтсыг тэр даруй буцаан авна. Өөр газрын замыг татгалзана, мөн файл аль хэдийн байвал зөвхөн туслах тэгэхийг хүсэх эсвэл өөрөө бичсэн бол л солигдоно.

Зургийг нээхэд **Read** хэрэгтэй; зураг хадгалахад **Save** хэрэгтэй; бусад файлд **Export** хэрэгтэй.

Таны тэмдэглээгүй зөвшөөрлийн гадуурх хэрэгслүүдийг туслахад огт санал болгохгүй. Хэрэв тэр ямар нэгийг хүссэн ч CadCraft татгалзаж, үйл ажиллагааны бүртгэлд бичнэ. Унтраалтыг унтраавал бүх холболт нэг дор тасрана. {{ui:CadCraft-ийн тохиргоог дахин тохируулах}} мөн үүнийг унтраана.

## Туслахаа холбох

Туслахууд компьютер дээрх **CadCraft Studio**-оор холбогдоно: энэ нь зөвхөн энэ компьютер хандаж чадах жижиг сервер ажиллуулж (хаяг `127.0.0.1`), Studio эхлэх бүрт үүсгэдэг токеноор хамгаалагдсан. Studio-г нээж, {{ui:Туслах холбох}}-ыг сонгоод хаяг ба токеныг хуулна.

- Туслахдаа хаяг (жишээ нь `http://127.0.0.1:47615/mcp`) бүхий HTTP төрлийн MCP сервер нэмж, толгой мөрөнд `Authorization: Bearer <token>` тохируулна. Studio буулгах тохиргоог харуулна.

{{ui:Шинэ токен}} Studio-д холбогдсон туслах бүрийг шинэ токентой дахин холбогдуулна. Токеныг хэзээ ч бүү хуваалц: түүнтэй хүн Studio ажиллаж байгаа хугацаанд таны асаасан аппуудыг ашиглаж чадна.

:::note
Хөтчийн таб туслахад холболт нээж чадахгүй: браузер аппууд дээр унтраалт танд CadCraft Studio компьютер дээр ашиглахаас өмнө ямар ч үр нөлөөгүй.
:::

## Та удирдсаар байна

- **Үйлдэл бүр нэг буцаах алхам**, туслахын нэрээр тэмдэглэгдэнэ, жишээ нь "Assistant: LINE". {{key:Mod+Z}} дарвал туслахын сүүлийн үйлдлийг бүхэлд нь буцаана.
- **Та юу хийснийг харна.** Түүний командууд команд түүхэнд **[Assistant]** угтвартайгаар харагдана, зураг ажиллахад дахин зурагдана.
- **Тэр таныг хүлээнэ.** Та команд дунд байх үед туслах зургийг уншиж чадна, харин өөрчилж чадахгүй; таныг дуусмагц дахин оролдохыг түүнд хэлнэ.
- **Холбогдсон эсэхийг мэднэ.** Аппын дээд мөрний товчлуур холбогдсон туслахын нэрийг харуулна. Дарвал тэр юу хийж болохыг харуулна, эсвэл түүнийг **Салгах** боломжтой.
- **Үйл ажиллагаа.** {{ui:Тохиргоо}} › {{ui:CadCraft}} › {{ui:Туслахууд}} › {{ui:Үйл ажиллагаа}} дуудлага бүрийг жагсаана: хэзээ, ямар хэрэгсэл, дууссан эсвэл татгалзсан, мөн түүний хийсэн буцаах алхам. {{ui:Бүртгэлийг хадгалах}} хуулбарыг хадгална.

## Туслах юу хүсч болох вэ

| Хэрэгсэл | Зөвшөөрөл | Юу хийдэг |
|---|---|---|
| `app_info`, `drawing_describe`, `view_describe` | Read | Зургийн нэр, нэгж, давхарга, блок, хуудсууд; дэлгэц дээр юу байгаа |
| `files_list`, `drawing_open` | Read | Studio: таны хавтсуудын файлууд; нэгийг нь энэ цонхонд нээх |
| `objects_list`, `object_get`, `selection_get` | Read | Объектууд геометр, урт, талбайтай (эсвэл зөвхөн төрөл, давхаргаар тоо); сонголт |
| `drawing_check` | Read | Зөвшөөрөгдсөн давхарга, 0 давхарга дээр юу ч байхгүй, ByLayer өнгө, текстийн өндөр зэрэг дүрмүүд |
| `view_screenshot` | Read | Зургийн харагдаж буй зураг |
| `command_run` | Edit | Командын мөрөнд бичнэ: `LINE 0,0 @100,0 @0,50 ` нь таныг бичих шиг уншина (зай нь хариултыг төгсгөнө), эсвэл хариулт бүрт нэгтэй жагсаалт. Команд нээлттэй үлдэж, дараагийн дуудлагад үргэлжлүүлж болно |
| `script_run` | Edit | Скрипт (`.scr`) эсвэл LISP файл, {{ui:APPLOAD}}-ийн ачаалдаг шиг |
| `block_insert` | Edit | Блокийг түүний атрибутын утгуудтай нь нэг алхмаар байрлуулна |
| `selection_set`, `undo` | Edit | Дараагийн командад объектуудыг сонгоно; өөрийн алхмуудыг буцаана |
| `drawing_save` | Save | CadCraft-ийн өөрийн {{ui:Хадгалах}}, эсвэл таны хавтсуудын нэгэнд {{ui:Өөр нэрээр хадгалах}} |
| `drawing_plot` | Export | Хуудас эсвэл загварын PDF эсвэл SVG, масштабтай эсвэл тохирсон хэмжээтэй (PDF доорх зургууд одоохондоо энэ замаар хэвлэгдэхгүй) |

Туслах команд ажиллуулж байхад CadCraft асуултуудаа диалогийн оронд командын мөр дээр асууна (жишээ нь бүхэл зургийг оруулах уу эсвэл нэг блокийг уу), ингэснээр туслах тэдгээрт хариулж чадна. {{ui:Сан}} ба Хайх нь танд хэрэгтэй хэвээр; туслахад таныг асуух ёстой гэж хэлэгдсэн байна.

## CadCraft-ийг нээхгүйгээр файлтай ажиллах

CadCraft MCP сервер (`cadcraft-mcp`) ба командын мөр (`cadcraft`) нь CadCraft-ийн өөрийн зураг боловсруулах кодыг Node.js дээр, цонхгүйгээр ажиллуулна. Node.js 20 эсвэл шинэ хувилбар хэрэгтэй.

- **MCP сервер** зөвхөн таны нэрлэсэн хавтсанд, танд өгсөн зөвшөөрлөөр ажиллана: `npx @getcadcraft/mcp --root ~/Drawings --allow read,edit`. `--root`-гүйгээр ямар ч файл нээж чадахгүй; `--allow`-гүйгээр зөвхөн унших. Мөн IFC загвар, ажлын тоо хэмжээ, PDF багц дахь тэмдэглэгээг уншиж чадна.
- **Командын мөр** таны өөрийн скриптүүдэд зориулагдсан: `cadcraft info plan.dwg`, `cadcraft run cleanup.scr plan.dwg -o plan-clean.dwg`, `cadcraft convert plan.dwg plan.dxf`, `cadcraft plot plan.dwg plan.pdf --all`, `cadcraft plot plan.dwg plan.svg`, `cadcraft check plan.dwg --rules rules.json`. Олон файлыг нэг дор: `cadcraft convert *.dwg out --to dxf`, `cadcraft plot *.dwg pdfs --to pdf`, `cadcraft check *.dwg --rules rules.json`. Програм уншиж чадах гаралтын хувьд `--json` нэмнэ.

:::note
Хэрэв `npx @getcadcraft/mcp` багц олдсонгүй гэвэл, энэ багц одоохондоо нийтлэгдээгүй байна. getcadcraft.com дээрх мэдээнд нийтлэгдэх үед дурдагдана.
:::

## Хэрэв ажиллахгүй бол

- **Туслах CadCraft-ийн хэрэгслүүдийг харахгүй байна:** энэ цонхонд унтраалт асаалттай, цонх Studio-д нээлттэй эсэхийг шалгана уу.
- **"needs the edit permission":** {{ui:Туслахууд}}-ын доор **Edit**-ийг тэмдэглээд дахин асуу.
- **"outside the folders assistants may use":** {{ui:Туслахууд}} › {{ui:Хандаж болох хавтаснууд}}-д тэр хавтсыг нэмэх, эсвэл туслахаас аль хэдийн нэмсэн хавтсын файлыг ашиглахыг хүс.
- **"401" эсвэл "token" алдаа:** токен солигдсон (Studio дахин эхэлсэн, эсвэл {{ui:Шинэ токен}}). Шинэ токеныг туслахын тохиргоонд хуулна.
- **Түүний өөрчлөлт буруу байсан:** {{key:Mod+Z}} дар. Нэг дарахад туслахын нэг бүтэн үйлдэл буцна.
