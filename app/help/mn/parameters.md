## Бүх хэмжээнд нэг хүснэгт

{{ui:Параметрүүд}} самбар ({{ui:Параметрүүд}} товч {{ui:Параметр}} бүлэгт, эсвэл {{cmd:PARAMETERS}} бичнэ) нь хэмжээний бүх хязгаарлалтуудыг (`d1`, `rad1`, `dia1`, `ang1`, эсвэл таны өгсөн нэр) болон өөрийн параметрүүдийг нэг дор жагсаана. Аль ч нэрийг аль ч илэрхийлэлд хэрэглэж болно.

Мөр бүрт:

- **Нэр**: шинэ нэр бичвэл нэрийг солино; үүнийг ашигласан илэрхийлэл бүр дагана.
- **Илэрхийлэл**: тоо (`40`) эсвэл илэрхийлэл (`width / 2 + gap`). Бичээд {{key:Enter}} дарвал зураг дагана.
- **Утга**: тооцоолсон утга. Илэрхийлэл жолоодож буй мөрөн дээр та энд тоо ч бичиж болно: CadCraft тэрний ард байгаа параметрийг тооцоолно. `d1 = width / 2`-тэй бол d1-ийн утганд `30` бичвэл `width` 60 болно.

Хоёр параметр утгыг жолоодох үед (`width / 2 + gap`) харилцах цонх аль нэгийг өөрчлөхийг асууна. Өөрчлөлт бүр нэг буцаах алхам ({{key:Mod+Z}}).

## Өөрийнхөө параметр нэмэх

1. {{ui:Параметрүүд}} самбарыг нээнэ.
2. Нэр (`gap`) ба утга (`10`) бичиж, {{ui:Нэмэх}} дарна.
3. Ашиглах: d1-ийн илэрхийлэлд `width / 2 + gap` бичээд {{key:Enter}} дарна.

Нэр нь үсгээр эсвэл `_`-ээр эхэлж, үсэг, цифр, `_`-ээс бүрдэнэ. Функцийн нэр, `pi` ба нэгжийн нэрс нэр болж чадахгүй.

## Илэрхийлэл

| Бичих | Утга |
|---|---|
| `+ - * / ^ %` | нэмэх, хасах, үржүүлэх, хуваах, зэрэг, үлдэгдэл |
| `( )` | бүлэглэх |
| `sin cos tan asin acos atan atan2` | градусаар тригонометр |
| `sqrt pow exp ln log abs sign` | язгуур, зэрэг, логарифм |
| `ceil floor int round min max` | бүхэлчлэх ба хязгаар |
| `if(a > b, x, y)` | сонголт |
| `pi` | 3.14159… |

Тоонд нэгж хамаарч болно: `25mm`, `1in`, `2'`, `90deg`. Нэгжтэй урт нь миллиметр болгон хөрвүүлэгдэнэ, тиймээс нэгжийг зөвхөн миллиметрээр хэмжсэн зурагт ашигла; бусад тохиолдолд энгийн тоо бич.

## Командын мөрөнд

`-PARAMETERS` самбаргүйгээр ижил зүйлийг хийнэ: `N` шинэ, `E` засах (хэмжээний хязгаарлалтыг оруулаад), `R` нэр солих, `D` устгах, `?` жагсаах.

## Юуг татгалзах вэ

- Өөртөө шууд эсвэл бусдаар дамжуулан ашигладаг илэрхийлэл: "width, d1 хоорондоо ашиглаж байна."
- Хэмжээнд авч чадахгүй утга: сөрөг урт, 180°-аас дээш өнцөг.
- Бусад хязгаарлалттайгаа зургийн авч чадахгүй утга: юу ч өөрчлөгдөхгүй, мессеж нь замд байгаа хязгаарлалтуудыг нэрлэнэ.
- Ашиглагдаж байгаа параметрийг устгах: самбар эхлээд түүний утгыг тэдэнд бичих саналыг тавина. Хэмжээний хязгаарлалтын нэрийг хязгаарлалтыг устгаснаар устгана.
