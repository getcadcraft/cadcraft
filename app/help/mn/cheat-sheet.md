Богино нэрийг (алиасыг) бичээд Enter дарах, эсвэл багажийг дарна. Esc цуцална. Хоосон мөр дээр Enter дарвал сүүлийн команд давтагдана.

**Хэвлэх:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (нэг A4 хуудас; Letter цаасан дээр "хуудсанд багтаах" гэж сонгож хэвлэнэ).

## Зурах

| Бичих | Команд | Юу хийдэг |
|---|---|---|
| `L` | {{cmd:LINE}} | Шулуун шугам зурна |
| `PL` | {{cmd:PLINE}} | Холбогдсон шугам, нумын гинж зурна |
| `C` | {{cmd:CIRCLE}} | Тойрог зурна (төв ба радиус) |
| `A` | {{cmd:ARC}} | Нум зурна |
| `REC` | {{cmd:RECTANG}} | Хоёр оройгоос тэгш өнцөгт зурна |
| `POL` | {{cmd:POLYGON}} | Тэгш олон өнцөгт зурна |
| `EL` | {{cmd:ELLIPSE}} | Эллипс зурна |
| `DT` | {{cmd:TEXT}} | Нэг мөр текст бичнэ |
| `T` | {{cmd:MTEXT}} | Мөрлөдөг текст (догол мөр) бичнэ |
| `H` | {{cmd:HATCH}} | Талбайг загвараар штрихлэнэ |

## Засах

| Бичих | Команд | Юу хийдэг |
|---|---|---|
| `M` | {{cmd:MOVE}} | Объектуудыг зөөнө |
| `CO` | {{cmd:COPY}} | Объектуудыг хуулна |
| `RO` | {{cmd:ROTATE}} | Объектуудыг цэгийн эргэн тойронд эргүүлнэ |
| `SC` | {{cmd:SCALE}} | Объектуудыг томруулах эсвэл жижигрүүлнэ |
| `MI` | {{cmd:MIRROR}} | Объектуудыг шугамаар толин тусгал хийнэ |
| `O` | {{cmd:OFFSET}} | Зайтай параллель хуулбар зурна |
| `TR` | {{cmd:TRIM}} | Объектуудыг бусад объекттой огтлолцох хүртэл тайрна |
| `EX` | {{cmd:EXTEND}} | Объектуудыг бусад хүртэл сунгана |
| `F` | {{cmd:FILLET}} | Буланг нумаар бөөрөнхийлнө |
| `CHA` | {{cmd:CHAMFER}} | Буланг шулуун ирмэгээр тайрна |
| `E` | {{cmd:ERASE}} | Объектуудыг устгана |
| `X` | {{cmd:EXPLODE}} | Блок эсвэл полишугамыг хэсгүүдэд нь задална |
| `S` | {{cmd:STRETCH}} | Огтлолцсон цонхны дотор үзүүрүүдийг зөөнө |
| `AR` | {{cmd:ARRAY}} | Тор эсвэл тойрогт хуулна |
| `J` | {{cmd:JOIN}} | Шугам ба нумыг нэг объект болгон нийлүүлнэ |
| `BR` | {{cmd:BREAK}} | Объектыг хоёрт хуваана, эсвэл нэг хэсгийг нь авна |

## Хэмжээс

| Бичих | Команд | Юу хийдэг |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Хэвтээ эсвэл босоо хэмжээс тавина |
| `DAL` | {{cmd:DIMALIGNED}} | Налуу шугамын дагуу хэмжээс тавина |
| `DRA` | {{cmd:DIMRADIUS}} | Радиусын хэмжээс тавина |
| `DAN` | {{cmd:DIMANGULAR}} | Өнцгийн хэмжээс тавина |

## Блок ба давхарга

| Бичих | Команд | Юу хийдэг |
|---|---|---|
| `B` | {{cmd:BLOCK}} | Объектуудаас блок үүсгэнэ |
| `I` | {{cmd:INSERT}} | Блок байрлуулна |
| `LA` | {{cmd:LAYER}} | Давхаргуудыг нээнэ |

## Харагдац ба лавлагаа

| Бичих | Команд | Юу хийдэг |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | Томруулах, багасгах эсвэл бүгдийг харуулах (E) |
| `DI` | {{cmd:DIST}} | Зай ба өнцгийг хэмжинэ |
| `LI` | {{cmd:LIST}} | Объектын мэдээллийг харуулна |
| `MA` | {{cmd:MATCHPROP}} | Нэг объектын хэв маягийг бусдад хуулна |

## Файл

| Бичих | Команд | Юу хийдэг |
|---|---|---|
| `U` | {{cmd:UNDO}} | Сүүлийн командыг буцаана |
| `SAVE` | {{cmd:SAVE}} | Зурагийг хадгална |
| `PLOT` | {{cmd:PLOT}} | PDF-рүү хэвлэнэ |

## Товчлууд

Ctrl (Mac дээр Cmd): Z буцаах · Y дахин хийх · S хадгалах · P хэвлэх. F3 объект барих · F8 орто · F10 полар. Space эсвэл Enter сүүлийн командыг давтана · дугуй нь томруулна · дугуйг чирэхэд харагдац шилжинэ

Зурах ажил шинэ байна уу? `TOUR` бичээд анхны зургаа удирдлагатайгаар зурна, [Эхлэх](topic:getting-started)-ийг уншина уу, эсвэл [Командууд](topic:commands)-аас бүх командыг харна уу. Бусад зурах программаас шилжиж байгаа бол: [Бусад зурах программаас шилжих нь](topic:coming-from) ба [командын зураглал](topic:command-map).
