Товчлолыг таны компьютерт тохируулан харуулна. Mac дээр доорх {{key:Mod}} товчлол бүр Command товчийг ашиглана; Control товч ч ажиллана. Товчуудыг яаж бичдэг, Mac дээр F товчийг хэрхэн ашиглахыг [Товчууд, хулгана, трекпад](common:keys) хуудсанд үзнэ үү.

## Команд бичих

| Товч | Юу хийдэг |
|---|---|
| Ямар ч үсэг, тоо эсвэл тэмдэг | Командын мөрт очно, заагч хаана ч байсан, харин самбарын хайрцагт курсор байхгүй бол |
| {{key:Enter}} | Бичсэнээ илгээнэ. Хоосон асуултанд: сүүлийн командыг давтана, команд эсвэл сонголтыг дуусгана, эсвэл `<…>` доторх анхдагч утгыг зөвшөөрнө |
| {{key:Space}} | {{key:Enter}}-тэй адил, гэхдээ CadCraft текст (текст, блокийн нэр, хэмжээсийн текст) асуух үед зай бичнэ |
| {{key:Esc}} | Командыг цуцална. Команд ажиллаагүй үед: бариул цэгийн зөөлт эсвэл сонголтын хайрцгийг цуцалж, дараа нь сонголтыг арилгана |
| {{key:Tab}} | Командын мөрний баруун талд харагдах санал болгосон командыг хүлээн авна. Юу ч бичээгүй, заагч давхцсан объектуудын дээр байвал: тэнд дараагийнхыг тодруулна (дарж сонгоно) |
| {{key:Up}} {{key:Down}} | Өмнө бичсэн мөрүүдээр (сүүлийн 100) алхана |

## Зурах ба засах

| Товч | Юу хийдэг |
|---|---|
| {{key:Mod+Z}} | Сүүлийн командыг буцаана |
| {{key:Mod+Y}} эсвэл {{key:Mod+Shift+Z}} | Дахин хийнэ |
| {{key:Mod+A}} | Нээлттэй табан дээр засах боломжтой бүх объектыг сонгоно ({{cmd:SELECTALL}}). Командын мөрөнд юу бичсэн бол тэр текстийг сонгоно |
| {{key:Delete}} | Сонгосон объектуудыг устгана ({{cmd:ERASE}}), командын мөрөнд юу бичсэн бол биш |
| {{key:Backspace}} | Командын мөрт курсор байхгүй үед сонгосон объектуудыг устгана; командын мөрт таны бичсэнийг устгана |
| {{key:Esc}} | Команд ажиллаагүй үед: сонголтыг арилгана ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | Зургийн форматаар (DWG эсвэл DXF) хуулбар хадгална |
| {{key:Mod+Shift+S}} | Өөр нэрээр хадгалах: DWG эсвэл DXF сонгоод хуулбар хадгална |
| {{key:Mod+O}} | DWG эсвэл DXF нээнэ |
| {{key:Mod+P}} | PDF-рүү хэвлэнэ |

Команд ажиллаж байх үед буцаах, дахин хийх, бүгдийг сонгох, хэвлэх ажиллахгүй: эхлээд {{key:Esc}} дарна уу.

## Хуулах, таслах, буулгах

| Товч | Юу хийдэг |
|---|---|
| {{key:Mod+C}} | Сонголтыг clipboard руу хуулна ({{cmd:COPYCLIP}}). Юу ч сонгоогүй бол CadCraft объект асууна |
| {{key:Mod+X}} | Таслах: сонголтыг хуулаад, дараа нь устгана ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | Буулгах: хуулбар заагчийг дагана; дарж эсвэл цэг бичиж байрлуулна ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | Яг байрлалд буулгах: хуулсан координатад ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | Давхардуулах: сонголтын хуулбар заагчийг дагана; дарж байрлуулна, {{key:Esc}} бол юу ч үлдээхгүй ({{cmd:DUPLICATE}}) |

Ижил үйлдлүүд багажийн мөрний {{ui:Edit}} бүлэгт ({{ui:Copy}}, {{ui:Paste}}) болон түүний {{ui:More}} цэсэнд байна. Өөр команд ажиллаж байвал эхлээд түүнийг дуусгах эсвэл {{key:Esc}} дарна уу; хуулбар заагчийг дагаж байхад {{key:Mod+V}} эсвэл {{key:Mod+D}}-г дахин дарвал дахин эхэлнэ. Командын мөрт юу бичсэн эсвэл команд текст асууж байвал эдгээр товч тэр текстийг хуулж, таслаж, буулгана. [Хуулах, буулгах, давхардуулах](topic:copy-paste)-г үзнэ үү.

| Товч | Шилжүүлэгч | Төлөвийн мөрийн товч |
|---|---|---|
| {{key:F3}} | Объектын бариулт асаах/унтраах | {{ui:Snap}} |
| {{key:F7}} | Тор асаах/унтраах | {{ui:Grid}} |
| {{key:F8}} | Орто асаах/унтраах | {{ui:Ortho}} |
| {{key:F10}} | Полар мөрдөлт асаах/унтраах | {{ui:Polar}} |
| {{key:F11}} | Объектын бариултын мөрдөлт асаах/унтраах | {{ui:Track}} |
| {{key:F12}} | Динамик оруулалт асаах/унтраах | {{ui:Dyn}} |

:::mac
Mac дээр F3, F7 ба F8 ихэвчлэн Mission Control ба медиа товчууд байдаг. **fn** дарж байгаад ашиглана уу, эсвэл System Settings-д стандарт функцийн товчийг асаана уу, [Товчууд, хулгана, трекпад](common:keys) хуудсанд тайлбарласнаар. Төлөвийн мөрийн товчнууд үргэлж ажиллана.
:::

:::firefox
Firefox-д F7 нь caret browsing асаахыг санал болгож болно. **No** гэж сонгоно уу, мөн дахин асуусаар байвал {{ui:Grid}} товчийг ашиглана уу.
:::

## Тусламж

| Товч | Юу хийдэг |
|---|---|
| {{key:F1}} | Энэ тусламжийг зургийн хажууд нээх эсвэл хаах. Команд ажиллаж байсан ч ажиллана, командын мөрт хэзээ ч очихгүй. |
| {{key:Esc}} | Курсор тусламжийн самбарт байхад: хайлтыг арилгана, эсвэл самбарыг хаана |

Дээд талын мөрний {{ui:Help}} товч нь F1-тэй адил үйлдэнэ. Тусламжийн хайлтын талбарт бичих үед командын мөрт юу ч очихгүй. CadCraft рүү товчуудыг буцаахын тулд зурган дээр дарна уу; самбар хажууд нь нээлттэй үлдэнэ.

:::mac
Mac-ийн гарт **fn** дарж байгаад F1 дарна уу, эсвэл {{ui:Help}} дарна уу.
:::

## Дэлгэц

| Товч | Юу хийдэг |
|---|---|
| {{key:Ctrl+Shift+F}} | Энгийн, бүтэн дэлгэц, самбарыг нуусан бүтэн дэлгэцийн хооронд солино. Бүх компьютер дээр Control товчийг ашиглана, Mac-д ч. |
| {{key:Left}} {{key:Right}} | Зургийн доорх таб фокуст байвал: өмнөх эсвэл дараагийн таб |

Бүтэн дэлгэцэд хөтөч эхний {{key:Esc}}-ийг бүтэн дэлгэцээс гарахад ашиглаж болно. Команд цуцлахын тулд {{key:Esc}}-ийг дахин дарна уу.

## Харилцах цонхнууд

| Товч | Юу хийдэг |
|---|---|
| {{key:Esc}} | Харилцах цонхыг хаана ({{ui:Plot to PDF}}, эсвэл «Unsaved changes» гэх мэт асуултад {{ui:Cancel}} гэсэн утгатай) |
| {{key:Tab}} | Харилцах цонхны тохиргоо ба товчнуудын хооронд шилжинэ |

Харилцах цонх нээлттэй үед зургийн товчууд идэвхгүй.

## Самбарын талбарууд

Баруун эсвэл зүүн самбарын хайрцагт:

| Товч | Юу хийдэг |
|---|---|
| {{key:Enter}} | Утгыг хэрэглээд хайрцгаас гарна |
| {{key:Esc}} | Хуучин утгыг буцааж, хайрцгаас гарна |
| {{key:Tab}} | Хэрэглээд дараагийн хайрцаг руу шилжинэ |

Хайрцагт курсор байхад үсгүүд тэнд бичигдэж, командын мөрт биш.

## Хулгана

| Үйлдэл | Юу хийдэг |
|---|---|
| Дарах | Команд цэг асуух үед цэг сонгоно; объект асуух үед объект сонгоно; эс бөгөөс объект эсвэл бариул цэгийг сонгоно |
| Shift+дарах | Сонгосон объектыг сонголтоос хасна ([Тохиргоо](topic:settings) дахь {{ui:Clicking objects}}-г {{ui:Replaces the selection}} болгосон бол нэмнэ). Цэг сонгох үед: тэр дарахад объектын бариултыг үл тооцно |
| Хоосон зайд дараад, дахин дарах | Сонголтын хайрцаг: зүүнээс баруун тийш бол window, баруунаас зүүн тийш бол crossing |
| Хоосон зайд чирэх | Лассо: баруун тийш эхлээд чирвэл window, зүүн тийш бол crossing; чирэх явцад {{key:Space}} window, crossing, fence-ийн хооронд солино; {{key:Esc}} үүнийг хаяна (LASSOMODE 0, эсвэл Тохиргоо дөрвөлжин болгоно) |
| TRIM эсвэл EXTEND-д хэсгүүдийн дундуур чирэх | Замын гарсан хэсэг бүрийг тайрна (эсвэл сунгана); нөгөө нь {{key:Shift}}-ийг барьж байгаад |
| Бариул цэгийг чирэх | Бариул цэгийг зөөнө (эсвэл бариул дараад, очих газраа дарна) |
| Текст дээр хоёр удаа дарах | Сонгоно, баруун самбарын {{ui:Text}} хайрцагт курсорыг тавина |
| Баруун товч | Enter. Бариул цэгийн зөөлт эсвэл сонголтын хайрцгийн үед: цуцална |
| Баруун товчоор чирэх | Панорам |
| Дугуй | Загалмайн орчим томруулж, жижигрүүлнэ |
| Дугуйгаар (дунд товч) чирэх | Панорам |
| Дугуй дээр хоёр удаа дарах | Бүх зургийг (extents) харуулна |
| DWG эсвэл DXF-ийг зураг дээр унагах | Нээнэ |

Трекпад эсвэл мэдрэгчтэй дэлгэц дээр [Хулгана, трекпад, мэдрэгч](topic:mouse-trackpad-touch)-ийг үзнэ үү.

## Хөтчийн хадгалдаг товчууд

{{key:Mod+N}}, {{key:Mod+W}} ба {{key:Mod+T}} үргэлж хөтөчийнх. CadCraft эдгээрийг ашигладаггүй: шинэ зурагт {{ui:New}} дарна уу, эсвэл `NEW` гэж бичнэ үү. CadCraft-ын clipboard нь өөрийнх: {{key:Mod+C}} ба {{key:Mod+V}} нь объектыг CadCraft зургуудын болон табуудын хооронд хуулна, бусад програмд биш.

:::mac
Хэрэв {{key:Mod+Y}} дахин хийхийн оронд хөтчийн түүхийг нээвэл {{key:Mod+Shift+Z}} эсвэл {{ui:Redo}} товчийг ашиглана уу.
:::

## Move хаана байна вэ

Move бол `MOVE` команд (товч {{key:M}}): объектуудыг сонгоод, суурь цэг, дараа нь хоёр дахь цэг эсвэл бичсэн зайг өгнө. `ALIGN` ба `DISTRIBUTE` ч мөн байна. BimCraft ижил нэрийг ижил ажилд ашигладаг боловч түүний {{key:M}} нь Measure; түүний Move нь {{key:Shift+M}}.
