Escriba o nome curto (o alias) e prema Enter, ou prema na ferramenta. Esc cancela. Enter nunha liña baleira repite o último comando.

**Imprímao:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (unha páxina A4; en papel Letter imprímao con «axustar á páxina»).

## Debuxar

| Escritura | Comando | Que fai |
|---|---|---|
| `L` | {{cmd:LINE}} | Debuxar liñas rectas |
| `PL` | {{cmd:PLINE}} | Debuxar unha cadea de liñas e arcos conectados |
| `C` | {{cmd:CIRCLE}} | Debuxar un círculo (centro e raio) |
| `A` | {{cmd:ARC}} | Debuxar un arco |
| `REC` | {{cmd:RECTANG}} | Debuxar un rectángulo a partir de dúas esquinas |
| `POL` | {{cmd:POLYGON}} | Debuxar un polígono regular |
| `EL` | {{cmd:ELLIPSE}} | Debuxar unha elipse |
| `DT` | {{cmd:TEXT}} | Escribir unha liña de texto |
| `T` | {{cmd:MTEXT}} | Escribir texto con axuste de liña (parágrafo) |
| `H` | {{cmd:HATCH}} | Encher unha área cunha trama |

## Modificar

| Escritura | Comando | Que fai |
|---|---|---|
| `M` | {{cmd:MOVE}} | Mover obxectos |
| `CO` | {{cmd:COPY}} | Copiar obxectos |
| `RO` | {{cmd:ROTATE}} | Xirar obxectos arredor dun punto |
| `SC` | {{cmd:SCALE}} | Facer os obxectos máis grandes ou máis pequenos |
| `MI` | {{cmd:MIRROR}} | Voltear obxectos sobre unha liña |
| `O` | {{cmd:OFFSET}} | Debuxar unha copia paralela a unha distancia |
| `TR` | {{cmd:TRIM}} | Recortar obxectos ata onde os cruzan outros |
| `EX` | {{cmd:EXTEND}} | Alongar obxectos ata outros |
| `F` | {{cmd:FILLET}} | Redondear unha esquina cun arco |
| `CHA` | {{cmd:CHAMFER}} | Cortar unha esquina cunha liña recta |
| `E` | {{cmd:ERASE}} | Eliminar obxectos |
| `X` | {{cmd:EXPLODE}} | Desagregar un bloque ou unha polilínea nas súas partes |
| `S` | {{cmd:STRETCH}} | Mover os extremos dentro dunha xanela de cruzamento |
| `AR` | {{cmd:ARRAY}} | Copiar nunha cuadrícula ou nun círculo |
| `J` | {{cmd:JOIN}} | Unir liñas e arcos nun só obxecto |
| `BR` | {{cmd:BREAK}} | Partir un obxecto en dous, ou retirar un anaco |

## Cota

| Escritura | Comando | Que fai |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Cotar na horizontal ou na vertical |
| `DAL` | {{cmd:DIMALIGNED}} | Cotar ao longo dunha liña inclinada |
| `DRA` | {{cmd:DIMRADIUS}} | Cotar un raio |
| `DAN` | {{cmd:DIMANGULAR}} | Cotar un ángulo |

## Bloques e capas

| Escritura | Comando | Que fai |
|---|---|---|
| `B` | {{cmd:BLOCK}} | Crear un bloque a partir de obxectos |
| `I` | {{cmd:INSERT}} | Colocar un bloque |
| `LA` | {{cmd:LAYER}} | Abrir as capas |

## Vista e consulta

| Escritura | Comando | Que fai |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | Ampliar, reducir ou ver todo (E) |
| `DI` | {{cmd:DIST}} | Medir unha distancia e un ángulo |
| `LI` | {{cmd:LIST}} | Amosar os detalles dun obxecto |
| `MA` | {{cmd:MATCHPROP}} | Copiar o aspecto dun obxecto sobre outros |

## Ficheiro

| Escritura | Comando | Que fai |
|---|---|---|
| `U` | {{cmd:UNDO}} | Desfacer o último comando |
| `SAVE` | {{cmd:SAVE}} | Gardar o debuxo |
| `PLOT` | {{cmd:PLOT}} | Trazar a PDF |

## Teclas

Ctrl (Cmd nun Mac): Z desfacer · Y refacer · S gardar · P trazar.  F3 enganche a obxectos · F8 orto · F10 polar.  Espazo ou Enter repite o último comando · a roda fai zoom · arrastrar a roda desprazar

Novo no debuxo? Escriba `TOUR` para un primeiro debuxo guiado, lea [Primeiros pasos](topic:getting-started), ou vexa todos os comandos en [Comandos](topic:commands). Se vén doutro programa de debuxo: [Se vén doutro programa de debuxo](topic:coming-from) e o [mapa de comandos](topic:command-map).
