Izinqumo zibonisiwe ngekhompyutha yakho. Ku-Mac, zonke izinqumo {{key:Mod}} ezingezansi zisebenzisa inkinobho ye-Command, nenkinobho ye-Control nayo iyasebenza. Indlela yokubhala okhiye nokusebenzisa okhiye be-F ku-Mac itholakala ku-[Okhiye, amamawuse namaphedi wokuthinta](common:keys).

## Ukuthayipha imiyalo

| Ukhiye | Okwenzayo |
|---|---|
| Noma yiyiphi inhlamvu, inombolo noma uphawu | Iya kumugqa womyalo, noma iphi isikhomi sikhona, ngaphandle kwebhokisi ephaneli elinekhesa |
| {{key:Enter}} | Ithumela lokho obuthayiphile. Emugqeni ongenalutho: iphinda umyalo wokugcina, iqeda umyalo, iqedela ukukhetha, noma yamukela okuzenzakalelayo okusechibini `<…>` |
| {{key:Space}} | Okufanayo ne-{{key:Enter}}, ngaphandle uma i-CadCraft icela umbhalo (umbhalo, amagama amabhulokhi, umbhalo wesilinganiso), lapho ifaka isikhala |
| {{key:Esc}} | Ikhansela umyalo. Kungekho myalo oqhubekayo: ikhansela ukuhamba kwesibambisi noma ibhokisi lokukhetha, bese isula ukukhethwa |
| {{key:Tab}} | Yamukela umyalo ophakanyisiwe ohlangothini lwesokudla komugqa womyalo. Uma kungekho lutho obuthayiphile futhi isikhomi sisezintweni ezigqumile: igqamisa into elandelayo lapho (chofoza ukuze uyikhethe) |
| {{key:Up}} {{key:Down}} | Ihamba phakathi kwemigqa obuyithayiphile ngaphambili (eyokugcina eyi-100) |

## Ukudweba nokuhlela

| Ukhiye | Okwenzayo |
|---|---|
| {{key:Mod+Z}} | Hlehlisa umyalo wokugcina |
| {{key:Mod+Y}} noma {{key:Mod+Shift+Z}} | Phinda wenze |
| {{key:Mod+A}} | Khetha yonke into oyihlelayo ethebhini evulekile ({{cmd:SELECTALL}}). Uma uthayiphe okuthile emugqeni womyalo, lokho kukhethwa umbhalo waleyo ndawo |
| {{key:Delete}} | Sula izinto ezikhethiwe ({{cmd:ERASE}}), ngaphandle uma uthayiphe okuthile emugqeni womyalo |
| {{key:Backspace}} | Sula izinto ezikhethiwe uma umugqa womyalo ungenaso isikhomi; emugqeni womyalo ususa lokho obuthayiphile |
| {{key:Esc}} | Kungekho myalo oqhubekayo: sula ukukhetha ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | Londoloza ikhophi ngefomethi yomdwebo (DWG noma DXF) |
| {{key:Mod+Shift+S}} | Londoloza njenge: khetha i-DWG noma i-DXF, bese ulondoloza ikhophi |
| {{key:Mod+O}} | Vula i-DWG noma i-DXF |
| {{key:Mod+P}} | Shicilela ku-PDF |

Hlehlisa, phinda wenze, khetha konke nokushicilela akwenzi lutho lapho kusebenza umyalo: cindezela {{key:Esc}} kuqala.

## Kopisha, sika namathisela

| Ukhiye | Okwenzayo |
|---|---|
| {{key:Mod+C}} | Kopisha okukhethiwe ebhodini lokukopisha ({{cmd:COPYCLIP}}). Akukho okukhethiwe: i-CadCraft icela izinto |
| {{key:Mod+X}} | Sika: kopisha okukhethiwe, bese ukususa ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | Namathisela: ikhophi ilandela isikhomi; chofoza, noma uthayiphe iphuzu, ukuze uyibeke ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | Namathisela endaweni efanayo: ngama-coordinates ayo akopishelwa kuwo ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | Phinda: ikhophi yokukhethiwe ihamba nesikhomi; chofoza ukuze uyibeke, {{key:Esc}} ayishiyi lutho ({{cmd:DUPLICATE}}) |

Izenzo ezifanayo zitholakala eqenjini {{ui:Edit}} lethuluzi ({{ui:Copy}}, {{ui:Paste}}) nasemenywini {{ui:More}}. Uma omunye umyalo usebenza, qeda kuqala noma cindezela {{key:Esc}}; ukucindezela {{key:Mod+V}} noma {{key:Mod+D}} futhi ngenkathi ikhophi ilandela isikhomi kuqala kabusha. Uma uthayiphe okuthile emugqeni womyalo, noma umyalo ucela umbhalo, lezi zinkinobho zikopisha, zisike zinamathisele lowo mbhalo esikhundleni salokho. Bheka [Kopisha, namathisela nephinde](topic:copy-paste).

## Okushintshayo

| Ukhiye | Okushintshayo | Inkinobho yebha yesimo |
|---|---|---|
| {{key:F3}} | Izibambisi zezinto ziyavulwa noma ziyavalwa | {{ui:Snap}} |
| {{key:F7}} | Igridi liyavulwa noma liyavalwa | {{ui:Grid}} |
| {{key:F8}} | Ortho iyavulwa noma iyavalwa | {{ui:Ortho}} |
| {{key:F10}} | Ukulandela kwe-polar kuyavulwa noma kuyavalwa | {{ui:Polar}} |
| {{key:F11}} | Ukulandela izibambisi zezinto kuyavulwa noma kuyavalwa | {{ui:Track}} |
| {{key:F12}} | Ukufaka okuguquguqukayo kuyavulwa noma kuyavalwa | {{ui:Dyn}} |

:::mac
Ku-Mac, F3, F7 no-F8 ngokuvamile ngamakhiye e-Mission Control nawokulawula imidiya. Bamba **fn** nazo, noma vula izinkinobho ze-function ezijwayelekile ku-System Settings, njengoba kuchazwe ku-[Okhiye, amamawuse namaphedi wokuthinta](common:keys). Izinkinobho zebha yesimo zisebenza njalo.
:::

:::firefox
F7 ku-Firefox ingacela futhi ukuvula i-caret browsing. Khetha **Cha**, bese usebenzisa inkinobho ye-{{ui:Grid}} uma ibuya.
:::

## Usizo

| Ukhiye | Okwenzayo |
|---|---|
| {{key:F1}} | Ivula noma ivala lolu sizo, ecaleni komdwebo. Lusebenza nangesikhathi umyalo usebenza, futhi ngeke luze emugqeni womyalo. |
| {{key:Esc}} | Uma isikhomi sisephaneli yosizo: isula ukusesha, noma ivala iphaneli |

Inkinobho {{ui:Help}} ebhalini ephezulu yenza okufanayo nakwe-{{key:F1}}. Uma uthayipha ebhokisini lokusesha losizo, akukho okufika emugqeni womyalo. Chofoza emdwebweni ukuze ubuyisele okhiye kwi-CadCraft; iphaneli ihlala ivulekile ecaleni kwawo.

:::mac
Ku-khibhodi ye-Mac, bamba **fn** bese ucindezela F1, noma chofoza {{ui:Help}}.
:::

## Isikrini

| Ukhiye | Okwenzayo |
|---|---|
| {{key:Ctrl+Shift+F}} | Shintshanisa phakathi kwesimo sokujwayela, isikrini esigcwele, nesikrini esigcwele namabha afihliwe. Lokhu kusebenzisa inkinobho ye-Control kuzo zonke izikhompyutha, ku-Mac nakho. |
| {{key:Left}} {{key:Right}} | Uma ithebhu ngaphansi komdwebo igxilile: ithebhu yangaphambili noma elandelayo |

Esikrinini esigcwele, isiphequluli singasebenzisa i-{{key:Esc}} yokuqala ukuphuma kusikrini esigcwele. Cindezela {{key:Esc}} futhi ukuze ukhansele umyalo.

## Amadayalogi

| Ukhiye | Okwenzayo |
|---|---|
| {{key:Esc}} | Ivala idayalogi ({{ui:Plot to PDF}}, noma umbuzo onjengo "Izinguquko ezingalondolozwanga", lapho kusho {{ui:Cancel}}) |
| {{key:Tab}} | Ihamba phakathi kwezilungiselelo zedayalogi nezinkinobho |

Lapho idayalogi ivuliwe, okhiye bomdwebo bavalwa.

## Izinkambu zephaneli

Kwibhokisi ephaneli yesokudla noma yesobunxele:

| Ukhiye | Okwenzayo |
|---|---|
| {{key:Enter}} | Isebenzisa inani bese ishiya ibhokisi |
| {{key:Esc}} | Ibuyisela inani elidala bese ishiya ibhokisi |
| {{key:Tab}} | Isebenzisa bese ihamba kwibhokisi elilandelayo |

Lapho ibhokisi linesikhomi, izinhlamvu zibhalwa kulo, hhayi emugqeni womyalo.

## Imawuse

| Isenzo | Okwenzayo |
|---|---|
| Chofoza | Ikhetha iphuzu lapho umyalo ucela iphuzu; ikhetha into lapho icela izinto; ngaphandle kwalokho ikhetha into, noma isibambisi |
| Shift+chofoza | Isusa into ekhethiwe ekukhetheni (uma {{ui:Clicking objects}} isethelwe ku-{{ui:Replaces the selection}} ku-[Izilungiselelo](topic:settings): iyengeza). Lapho ikhetha iphuzu: iyayeqa ukubamba izinto ngalokho kuchofoza |
| Chofoza endaweni engenalutho, bese uchofoza futhi | Ibhokisi lokukhetha: esobunxeni kuya esokudla kuyi-window, kusuka esokudla kuya esobunxeni kuyi-crossing |
| Hudula endaweni engenalutho | I-lasso: ukuhamba kuqala kwesokudla kuyi-window, kwesobunxele kuyi-crossing; {{key:Space}} ngenkathi uhudula ijikeleza phakathi kwe-window, i-crossing ne-fence; {{key:Esc}} iyiyeka (LASSOMODE 0, noma Izilungiselelo, iyenza ibhokisi futhi) |
| Hudula ngamaphuzu ku-TRIM noma EXTEND | Isika (noma yandisa) yonke ingxenye umzila udlula kuyo; bamba {{key:Shift}} ukuze uthole enye |
| Hudula isibambisi | Ihambisa isibambisi (noma chofoza isibambisi, bese uchofoza lapho siya khona) |
| Chofoza kabili umbhalo | Uwukhetha futhi ubeka isikhomi ebhokisini le-{{ui:Text}} ephaneli yesokudla |
| Chofoza ngesokudla | {{key:Enter}}. Phakathi kokuhamba kwesibambisi noma ibhokisi lokukhetha: uyakhansela |
| Hudula ngesokudla | Ishelelisa |
| Ivili | Isondeza ngaphandle nangaphakathi ngokuzungeza i-crosshair |
| Hudula ngevili (inkinobho ephakathi) | Shelelisa |
| Chofoza kabili ivili | Isondeza kuwo wonke umdwebo (extents) |
| Hudula i-DWG noma i-DXF ngaphezu komdwebo | Iyayivula |

Kwiphedi yokuthinta noma kuskrini sokuthinta, bheka [Imawuse, iphedi yokuthinta nokuthinta](topic:mouse-trackpad-touch).

## Okhiye abaphequluli abawagcinayo

{{key:Mod+N}}, {{key:Mod+W}} kanye {{key:Mod+T}} njalo zingezesiphequluli. I-CadCraft ayizisebenzisi: sebenzisa {{ui:New}} noma thayipha `NEW` ukuze uthole umdwebo omusha. Ibhodi lokukopisha le-CadCraft liyeyayo: {{key:Mod+C}} kanye {{key:Mod+V}} zikopisha izinto phakathi kwemidwebo nethebhu ye-CadCraft, hhayi kuya noma kusuka kwezinye izinhlelo.

:::mac
Uma {{key:Mod+Y}} ivula umlando wesiphequluli esikhundleni sokuphinda wenze, sebenzisa {{key:Mod+Shift+Z}} noma inkinobho {{ui:Redo}}.
:::

## Lapho kukhona i-Move

I-Move ingumyalo `MOVE` (inkinobho {{key:M}}): khetha izinto, bese uthayipha iphuzu lesisekelo kanye nephuzu lesibili noma ibanga elithayiphiwe. `ALIGN` kanye `DISTRIBUTE` nazo zikhona. I-BimCraft isebenzisa amagama afanayo ngemisebenzi efanayo ezintweni zokwakha, kodwa i-{{key:M}} yayo iyi-Measure: i-Move yayo iyi-{{key:Shift+M}}.
