I-CadCraft isathuthukiswa. Leli khasi libala okungenziwa yileli bhilidi, ukuze ungasesidingi ukuyifuna. Isihloko ngasinye sitshela okufanele wenze esikhundleni salokho namuhla.

## Amafayela nokulondoloza

| Akukakwakhiwa | Okwenziwa esikhundleni, namuhla |
|---|---|
| I-CadCraft DWG ehlolwe ku-AutoCAD ngokwayo | Yonke inguqulo elondoloziwe ifundwa kabuyela emfundini ye-DWG yezinye izinhlelo ezintathu nakwi-CadCraft. Bona [Okugcinwa nokushintshwa yi-DWG](topic:files#what-a-dwg-keeps-and-changes). |
| Ukulondoloza i-DXF entsha kuno-2000 | Londoloza njenge-DXF 2000, noma njenge-DWG kuze kufike ku-AutoCAD 2018. |
| Ukulondoloza phezu kwefayela elivulwe ebhrawuzeni | Yonke ukulondoloza kulanda ikhophi entsha; faka esikhundleni sefayela elidala ngokwakho uma ufuna. Ku-CadCraft Studio, {{key:Mod+S}} ibhala kabusha efayeleni olivulile. |
| Ukulondoloza nokuvumelanisa phakathi kwamakhompyutha | I-CadCraft ayithumeli ukulondoloza kwayo efwini okwamanje: gcina amafayela wakho e-DWG ne-DXF kumafolda akho. Ku-CadCraft Studio, [History](topic:history) ibala izinguqulo zefu zomdwebo olondolozwe kwenye indawo nezikhopi zokulondoloza kwakho kulelikhompyutha. |
| Ukuxhumanisa nokuhlela umdwebo owenziwe ngaphakathi ngqo | Xhuma umdwebo njenge-link bese uyawulayisha kabusha ngemva kokushintsha omunye umdwebo. I-link ihlala iyi-link uma ulondoloza njenge-DWG, futhi i-{{cmd:XCLIP}} iyawunqamula. |
| Izithombe ku-DXF; ama-wipeout afihla okungaphansi kwawo | I-DXF igcina isithombe njengefreyimu yaso negama lefayela; i-DWG iyasigcina njengesithombe: bona [Izithombe emdwebweni](topic:pictures). I-wipeout ibonakala njengefreyimu yayo. |
| Ukuhlela ama-multileader anemigqa ekhokhayo ejikelezayo, anemigqa ekhokhayo ngaphezu nangaphansi kokuqukethwe, noma ibhlokhi eshintshwa noma enwetshwa ngokungalingani | Adwetshwa njengoba adwetshwe olunye uhlelo bese ehamba ndawonye. Ama-multileader anemigqa ekhokhayo eqondile eya kulandingi eyodwa, nombhalo noma ibhlokhi njengokuqukethwe, afika ehlelekayo ({{cmd:MLEADEREDIT}}). |
| Emathebulini avela kwezinye izinhlelo: iseli eligcina ibhlokhi, ukwakheka kombhalo phakathi kweseli, izingcezu namabala ngayinye yeseli ethebhuleni le-DXF, ithebula elihlukaniswe ezingxenyeni | Ithebula livulwa njengethebula elihlelekayo ({{cmd:TABLEDIT}}) futhi lidwetshwa njengoba lidwetshwe olunye uhlelo kuze kube yilapho ulihlela; bese i-CadCraft iyalidweba kabusha ngamaseli alo: umbhalo olula, izibalo ezinjengo `=G3*H3` no-`=Sum(I3:I9)`, ukuhlelwa nobude bombhalo. Iseli lebhlokhi liba lilingeni. Ithebula le-DWG elingashintshiwe ligcinwa libuyiswa ngedatha yeseli elafika nayo. |
| Ithebula langempela ku-DXF elonga | I-DWG igcina ithebula njengethebula ezinye izinhlelo ezingalihlela. I-DXF iligcina njengebhlokhi elidweba lona, nerekhodi lalo lika-CadCraft: i-CadCraft iyalivula njengethebula futhi; ezinye izinhlelo zibona ibhlokhi. Ithebula elibhobozwe noma elinwetshwe ngokungalingani ligcinwa ngale ndlela futhi ku-DWG. |
| Ukukopisha nokunamathisela nezinye izinhlelo | Ibhodi lokopisha le-CadCraft lisebenza phakathi kwemidwebo nemithebhu ye-CadCraft ebhrawuzeni elifanayo, hhayi nezinye izinhlelo. Londoloza njenge-DWG noma i-DXF uvule lapho. Bona [Kopisha, namathisela nephinda](topic:copy-paste). |

I-DXF R12 igcina isikwele kuphela. |

| {{cmd:BREAK}}, {{cmd:LENGTHEN}}, {{cmd:OFFSET}}, {{cmd:TRIM}}, {{cmd:EXTEND}}, {{cmd:FILLET}} ne-{{cmd:JOIN}} kuma-ellipse nama-spline | {{cmd:EXPLODE}} i-spline (noma {{cmd:PEDIT}} yayo) ukuze uthole i-polyline lezi zimiyalo ezizithatha. |
| I-fillet ne-chamfer phakathi kwesegment ye-arc ye-polyline nesegment esiseduze nayo; i-fillet ehlanganisa umugqa ube yi-polyline | {{cmd:EXPLODE}} i-polyline, bese wenza i-fillet ezingxenyeni. I-arc ye-fillet yengezwa njengento yayo. |
| Trim ne-extend: inketho ye-Project (3D) nokwelula isiphetho se-arc ye-polyline | Sika endizeni yomdwebo; ukuze uthole isiphetho se-arc, hlukanisa i-polyline noma udwebe i-arc kabusha. |
| Izinto ze-OLE: ukuzifaka, ukuzisebenzisa noma ukuzihlela; ukukhombisa ezisendaweni efayela eziyibeka kuyo ku-DWG; izithombe ze-metafile | Bona [Izithombe](topic:pictures#objects-from-other-programs-ole). Izinto ze-DXF zibonakala njengebitmap yazo noma njengefreyimu enegama; izinto ze-DWG ziyagcinwa, azidwetshwa endaweni yazo (i-OLELIST iyazibala futhi ibeke ikhophi yesithombe lapho uthi khona). |
| Ukubhala amakhodi wokwakha (umbhalo ogqamile, izimbobo ezimile, imibala ngamagama ngamagama) embhalweni wesigraphu; amafonti ngaphandle kwefonti eyodwa efana ne-Helvetica; amakholomu | Ukwakheka okufike efayeleni kuyagcinwa, kudwetshwe futhi kulondolozwe (bona Text); umbhalo wesigraphu omusha unokuphakama nombala kunye. |
| Umbhalo wesigraphu ohlelwa ngokuzungezwa kwawo | Umhleli uvula ulingene; umbhalo ugcina ukuzungezwa kwawo. |

| Kumathebula ({{cmd:TABLE}}): umbhalo ohlanganayo ngaphakathi kweseli, amathebula ahlukana izingxenye, isitayela sombhalo sethebula nemibala ngohlobo lomugqa ngengxoxo, ukuxhumana kwedatha nefayela le-spreadsheet (`.xlsx`) noma elifunda ifayela ngokwalo | Umbhalo weseli uhlukana lapho uwuhlukanisa kuphela ({{key:Alt+Enter}}); khulisa ikholomu. I-{{cmd:DATALINK}} ifunda ifayela `.csv`, futhi i-{{cmd:DATALINKUPDATE}} ikucela ukuthi ukhethe ifayela futhi. I-{{cmd:DATAEXTRACTION}} ne-{{cmd:COUNTTABLE}} zenza ithebula elingalandeli umdwebo ngokwalo: zisebenze futhi (ukubala okuphilayo: {{cmd:BOMTABLE}}). |
| Izichazi zezakhiwo ezigcinwe zodwa kufayela elilondoloziwe (ngaphandle kwebhlokhi), izakhiwo ezinemigqa eminingi | Faka izichazi zezakhiwo ebhlokhini ngaphambi kokulondoloza: zodwa zilondolozwa njengombhalo obonisa ithegi. |
| Izimo zezingqimba (ukulondoloza nokubuyisela ukuthi yiziphi izingqimba ezivuliwe) | Sebenzisa i-{{cmd:LAYISO}} / {{cmd:LAYUNISO}}, noma vula izingqimba uzivale ngesandla. |
| Ukukhethwa kwewindi nesiqhwaqwa esihlanganayo, nezihlungi zokukhetha ezilondoloziwe | Fence (`F`), Window, Crossing, Remove (`R`), {{cmd:QSELECT}} ngomthetho. |
