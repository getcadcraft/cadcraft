## Ukuvula amafayela

| Umlayezo noma isimo | Imbangela | Ukulungisa |
|---|---|---|
| "I-CadCraft ivula imidwebo ye-DWG ne-DXF. "…" akuyiyo nalokho." | Ifayela alisiyo `.dwg` noma `.dxf`. | Vula ifayela lodwebo ngokwalo. I-PDF ingaletwa (Vula ibuza: ngenisa noma xhuma, bheka [Ama-underlay e-PDF](topic:pdf-underlay)); izithombe zingena nge-`IMAGEATTACH`. |
| "Le DXF ye-binary iphela phakathi kwento: ifayela lifushane noma yonakele." | I-DXF ye-binary iyama ngaphambi kokuphela kwayo. | Thayipha RECOVER ukuze uvule lokho okungafundeka, noma cela ifayela futhi. |
| "Lolu fayela alisiyo i-DXF efundekayo (ikhodi yeqembu embi emugqeni …)." | I-DXF yonakele noma ayisiyo i-DXF ngempela. | Cela ifayela futhi, noma i-DWG. |
| "Lo dwebo abufundeki. Ungase wonakale, noma ulondolozwe enguqulweni umfundi angakasingathi (…)." | Umfundi we-DWG awukwazanga ukuwufunda. | Cela i-DWG elondolozwe enguqulweni endala, noma i-DXF. |
| "Lo dwebo ovela ku-AutoCAD R11 / R12 (DWG AC1009), omdala kunalokho i-CadCraft ayifunda …" | Amafayela e-DWG asuka ku-Release 12 nangaphambi kwawo asebenzisa ifomethi i-CadCraft engayifundi. | Esinhlelweni esiwenzile, wulondoloze njenge-DXF (noma iyiphi inguqulo) noma njenge-DWG entsha, bese uyavula. I-Londoloza njenge ye-CadCraft inikeza i-DXF R12 izinhlelo ezidinga leyo fomethi endala. |
| "Akukwazanga ukuvula …" kulandelwe umlayezo wenethiwekhi, ku-DWG yokuqala | Umfundi we-DWG akukwazanga ukulandwa: awuku-inthanethi futhi i-CadCraft ayilondolozelwe ukusebenza ngaphandle kwe-inthanethi, noma uxhumo luphelile. | Yiya ku-inthanethi uzame futhi, noma vula i-DXF. Chofoza {{ui:Londoloza ngaphandle kwe-inthanethi}} bese ulinda "Ilungele ngaphandle kwe-inthanethi" ukuze amafayela e-DWG avule ngaphandle kwe-inthanethi ngesikhathi esilandelayo. Bheka [Ukusebenza ngaphandle kwe-inthanethi](common:offline). |
| Inkinobho ye-offline ithi "Akukwazanga ukulondoloza" | Amanye amafayela awazange alandwe. | Hlola uxhumo bese uchofoza le nkinobho ukuze uzame futhi. |
| Inkinobho ye-offline ithi "Ngaphandle kwe-inthanethi akutholakali" | Amawindi asendaweni ayimfihlo namanye amakhompyutha alawulwayo awakwazi ukugcina ikhophi yangaphandle kwe-inthanethi. | Sebenzisa iwindi elijwayelekile, noma hlala ku-inthanethi. |
| I-CadCraft ayivuleki uma kungekho uxhumo | Kayilondolozelwe ukusebenza ngaphandle kwe-inthanethi kulesi sibhangqi, noma isibhangqi siyisusile. | Ngesikhathi esilandelayo uku-inthanethi, chofoza {{ui:Londoloza ngaphandle kwe-inthanethi}} bese ulinda "Ilungele ngaphandle kwe-inthanethi". |
| Udwebo luyavuleka kodwa izingxenye zishoda | Izinto i-CadCraft ingakadwebi, noma izingqimba ezicimiwe noma ezimisiwe kufayela. | Funda "Mayelana nalelifayela" ephaneli esekhoneni elingakwesobunxele. Hlola iphaneli ye-{{ui:Izingqimba}}. |
| Umbhalo uhlanganisa ube yimigqa emibili | I-CadCraft idweba umbhalo ngefonti efana ne-Helvetica, obanzi kunezinye izifonti ze-CAD. | Finyeza umbhalo ku-{{ui:Izakhiwo}}, noma uhlale nomugqa owengeziwe. |
| Indilinga iboniswa njenge-ellipse, noma umbhalo obukiwe ufundeka ngendlela efanele | Into idwetshwe endizeni ethambekile, noma ibonwe ngaphansi, kunhlelo olwenze ifayela. I-CadCraft iyibonisa njengoba ibonwa ngaphezulu, njengendlela ukubuka kwepulani kwaleyo nhlelo; umbhalo ugcinwa ufundeka. | Akukho okudingeka ukulungiswe. Ukuze ulibone ngendlela yenye inhlelo, cela udwebo oluhlanganisiwe, noma ngezinto ezidwetshwe ngaphezulu. |
| Ibhlokhi, indilinga noma isilinganiso sihlala endaweni engafani nenhlelo eyenze ifayela | Icala lodwebo i-CadCraft ilifunda ngendlela engalungile. | Sitshele ku-Discord, nefayela uma ungawabelana nalo. |

## Umugqa womyalo

| Umlayezo noma isimo | Imbangela | Ukulungisa |
|---|---|---|
| "Umyalo ongaziwa "…". Thayipha HELP ukuze ubone uhlu." | Akukho myalo noma igama elifushane elinalelo igama. | Thayipha `HELP`, noma bheka [Ireferensi yemiyalo](topic:commands). Imiyalo ethile ejwayelekile [akakakwakhiwa](topic:not-built-yet). |
| "Akukho umyalo onjalo" eduze komugqa womyalo ngenkathi uthayipha | Lokho othayiphe akufani nalutho okwamanje. | Qhubeka uthayipha, noma hlola ukubhalwa. |
| "Kudingeka iphuzu noma igama lenketho." | Lokho othayiphe akuyona iphuzu noma inketho. | Hlola ifomethi: `x,y`, `@dx,dy`, `@d<a`, noma inombolo eyodwa. Bheka [Ukufaka amaphuzu nobude](topic:coordinate-entry). |
| "Kudinga inombolo emihle noma amaphuzu amabili." | Ibanga belingaphansi kwe-zero noma belingeyona inombolo. | Thayipha inombolo emihle, noma chofoza amaphuzu amabili. |
| "Kudinga i-engeli ngamadigri noma amaphuzu amabili." | I-engeli ayisiyo inombolo. | Thayipha amadigri njengenombolo evamile. |
| "Kudinga inombolo." | Kulindeleke inombolo. | Thayipha izinombolo kuphela. |
| "Igama lenketho alivumelekile." | Izinhlamvu azihambisani nenketho. | Thayipha izinhlamvu ezinkulu ezibonakala phakathi kwamabhulaketi amasikwele. |
| `*Cancel*` | Ucindezele {{key:Esc}}, noma {{key:Enter}} lapho kwakudingeka iphuzu. | Qala umyalo futhi. |
| Ukuthayipha akufiki komugqa womyalo | Ibhokisi ephaneli noma kuxoxo linekhesa. | Cindezela {{key:Enter}} noma {{key:Esc}}, noma chofoza kudwebo. |
| Umyalo usebenzisa izinto ongazikhethanga | Zakhethwa ngaphambi kokuqala kwawo. | Cindezela {{key:Esc}} ngaphambi komyalo. |
| Umugqa uhambe endaweni engalindelekile | `x,y` ingeyokuphelele. | Sebenzisa `@dx,dy` amaphuzu ahlobene. |
| "Qeda noma khansela umyalo wamanje kuqala (Esc)." | Ucindezele {{key:Mod+S}} ngenkathi umyalo usebenza. | Cindezela {{key:Esc}}, bese ulondoloza. |
| "Akukwazanga ukulondoloza njenge-DWG (AutoCAD 2000): … Zama Londoloza njenge, bese DXF." | Okuthile kodwebo akukwazanga ukubhalwa njenge-DWG. | Cindezela {{key:Mod+Shift+S}}, khetha {{ui:DXF R12}} bese uchofoza {{ui:Londoloza}}. |
| "Akukalondolozwa." | Uvale ikhasi {{ui:Londoloza ikhophi njenge}} ngo-{{ui:Khansela}} noma ngo-{{key:Esc}}. | Cindezela {{key:Mod+Shift+S}} futhi uchofoze {{ui:Londoloza}}. |

## Ukuhlela

| Umlayezo noma isimo | Imbangela | Ukulungisa |
|---|---|---|
| Into ayikhethwa | Ingqimba yayo ikhiyiwe, icimiwe noma imisiwe; noma useshidini futhi yimodeli ngaphakathi kwe-viewport. | Vula ingqimba, noma uye ethebhini le-{{ui:Imodeli}}. |
| "Akukho okutholakele lapho." | Akukho nto ngaphansi kokuchofoza. | Sondeza bese uchofoza kumugqa uqobo. |
| "Akukho okuqamba lelo nto lapho." | I-{{cmd:TRIM}} ayitholanga into eqamba isiqephu okhethe sona. | Hlola ukuthi umugqa wokusika uqamba ngempela. |
| "Ayikwazi ukusika lelo nto." | Ukusika kusebenza kumigqa, ama-arc, izindilinga nama-polyline. | Hlukanisa amabhlokhi kuqala, noma sula udwebe kabusha. |
| "Akukho mkhawulo kuleyo ndlela." | I-{{cmd:EXTEND}} ayitholanga lutho okufanele ihlangane nalo. | Khetha eduze kwaleso siphetho okufanele sikhule. |
| "Ayikwazi ukushintshela ngaphandle lelo nto." | Ukushintshela ngaphandle kusebenza kumigqa, ama-arc, izindilinga nama-polyline. | Hlukanisa kuqala, noma dweba umugqa ofanayo. |
| "Ayikwazi ukushintshela ngaphandle kude kangako." | Ukushintshela ngaphandle bekuyoguqula isimo sibe ngaphakathi ngaphandle. | Sebenzisa ibanga elincane. |
| "Umsakazo mkhulu kakhulu." noma "Ibanga likhulu kakhulu." | I-fillet noma i-chamfer bekuyodlula ekugcineni komugqa. | Setha umsakazo omncane nge-`R`, noma amabanga amancane nge-`D`. |
| "Kungasikwa kuphela isegimenti lokuqala noma lokugcina lepolyline evulekile." | Ikhoneli bekuyosika maphakathi nepolyline. | Khetha izegimenti ezimbili ezihlangene zepolyline, noma sebenzisa `P` kuwo wonke amakhoneli. |
| "Khetha umugqa wesibili, omehlukile." | Ukukhetha kwesibili kwaba umugqa ofanayo, noma kwakungeyona umugqa. | Khetha omunye umugqa. |
| "Ama-polyline, izinkomba zamabhlokhi nezilinganiso kuphela ayahlukana." | Ukukhethwa kwakungenalutho okufanele kuhlukane. | Khetha i-polyline, inkomba yebhlokhi noma isilinganiso. |
| "Yona yingqimba yamanje. Yenza enye ingqimba ibe yamanje kuqala." | Uzamile ukucima ingqimba yamanje. | Chofoza igama lengqimba enye, bese ucima le. |
| "Sekukhona ingqimba ebizwa ngokuthi …" | Amagama wezingqimba kumele abe ahlukile. | Khetha elinye igama. |
| "Akukho okuhlehlisiwe." | Akukho okusele okungahlehliswa, noma uvule noma uqalise udwebo (lokho kususa umlando). | — |

## Izilinganiso namabhlokhi

| Umlayezo noma isimo | Imbangela | Ukulungisa |
|---|---|---|
| Umbhalo wesilinganiso namacibisholo amancane kakhulu noma mkhulu kakhulu | Usayizi useyamayunithi wodwebo; isikali sonke asifaneleki kudwebo. | Setha {{cmd:DIMSCALE}} kwisikali sokushicilela; bheka [Setha usayizi wezilinganiso](topic:dimension-settings). |
| "Khetha iphuzu ngaphakathi kwe-engeli ofuna ukuyilinganisa." | Indawo yesilinganiso se-engeli ihlala emlenzeni. | Chofoza ngaphakathi kwe-engeli. |
| "Lezo mugqa ziyafana." | Imigqa efanayo ayinayo i-engeli phakathi kwayo. | Khetha imigqa emibili ehlanganayo. |
| "Khetha isilinganiso esiqondile noma esihlelekile." | I-{{cmd:DIMCONTINUE}} noma i-{{cmd:DIMBASELINE}} idinga okokuqala lapho kuqala khona. | Khetha isilinganiso esiqondile noma esihlelekile. |
| "Lo dwebo alinamabhlokhi okwamanje: F ingenisa elinye kusuka kufayela, L kusuka kumtapo …" | Udwebo alinawo amabhlokhi awo. | Thayipha `F` noma `L`, noma yenza ibhlokhi nge-{{cmd:BLOCK}}. |
| "Akukho bhlokhi ebizwa ngokuthi "…"." | Igama alilungile. | Umlayezo uhlu lwamabhlokhi akhona. |
| "Igama lebhlokhi alikwazi ukuqala nge-* noma lisebenzise …" kulandelwe uhlu lwezinhlamvu | Igama linohlamvu amabhlokhi angalisebenzisi. | Sebenzisa izinhlamvu, izinombolo, `-` no `_`. |
| "Ibhlokhi alikwazi ukuqukatha lona lolu." | Ukukhetha kuqukethe inkomba yebhlokhi elenziwayo. | Khipha lowo mkhombo. |
| "Azikho izinto ezikhethiwe; akukho okwenziwe." | Ucindezele {{key:Enter}} ngaphambi kokukhetha. | Qalisa {{cmd:BLOCK}} futhi ukhethe izinto. |

| "Vula isakhiwo ne-viewport kuqala." | {{cmd:VPVIEW}} ethebhini le-{{ui:Imodeli}}. | Chofoza ithebhu yeshidi kuqala. |
| Isikali se-viewport sibukeka singaphindwe kashumi | Amayunithi odwebo angalungile. | Setha {{ui:Amayunithi}} ku-{{ui:Izilungiselelo zamanje}}. |
| "Akukho okushicilelwayo okwamanje." | Imodeli ilula. | Dweba okuthile, noma vula udwebo. |
| "Khetha iwindi lokushicilela." | {{ui:Iwindi…}} likhethiwe kodwa akukho windi okhethiwe. | Chofoza {{ui:Khetha}} bese ukhetha amakhoneli amabili. |
| "… ikhulu kuphepha: imiphetho isikiwe." | Indawo ayilingani kuleso sikali. | Khetha isikali esincane, iphepha elikhulu, noma {{ui:Lwanele iphepha}}. |
| "Isiphequluli sivimbe ithebhu entsha, ngakho i-PDF yalandelwa esikhundleni salokho." | Ama-pop-up avinjiwe kule sayithi. | Vula i-PDF elandiwe, noma vumela ama-pop-upale sayithi. |
| Izinhlamvu ziphrintwa njenge-"?" | Amafonti we-PDF awanayo izinhlamvu zazo (izinhlamvu ezingavamile, isiHindi nezinye izikripthi ezidinga ukwakheka okuyinkimbinkimbi, …), noma ifonti enkulu ayikwazanga ukulandwa (ngaphandle kwe-inthanethi). Izikripthi zaseYurophu, isiSirili, isiGreek, isiHebheru, isiArabhu, isiPheshiya, isiUrdu, isiThai, isiShayina, isiJapane nesiKorea ziphrinta njengazo. | Ku-isiArabhu, isiThai, isiShayina, isiJapane noma isiKorea, shicilela futhi uxhunywe. Ezinye izikripthi azikakwakhiwa. |
| Imigqa yokwakha ibonakala ku-PDF | Ingqimba yayo iyashicilelwa. | Chofoza inkinobho yomshicileli yengqimba. |
| Yonke imigqa inobukhulu obulinganayo | Ubukhulu bomugqa wayo buthi {{ui:Okuzenzakalelayo}}, ngakho ishicilelwa ngobubanzi bepeni kuxoxo. | Nikeza izingqimba noma izinto {{ui:Ubukhulu bomugqa}} ephaneli esekhoneni, noma khetha {{ui:Ubukhulu bomugqa}} kuxoxo. Ukuze ubone ubukhulu bomugqa esikrinini, cindezela {{ui:LWT}} kwibha yesimo. |

## Okhiye nesikrini

| Isimo | Imbangela | Ukulungisa |
|---|---|---|
| I-F3, F7 noma F8 ishintsha ivolumu noma ivula i-Mission Control | Okhiye bemisebenzi ye-Mac. | Bamba **fn**, noma sebenzisa izinkinobho zebha yesimo. Bheka [Okhiye, amagundane nama-trackpad](common:keys). |
| I-F7 ibuza mayelana nokuphequlula ngekhesa | I-Firefox isebenzisa i-F7 ngokwayo. | Khetha Cha; sebenzisa inkinobho ye-{{ui:Igridi}}. |
| {{key:Mod+N}} ivule iwindi lesiphequluli | Isiphequluli sigcina lowo khiye. | Chofoza {{ui:Okusha}} noma uthayipha `NEW`. |
| {{key:Mod+A}} ikhethe umbhalo womugqa womyalo | Umugqa womyalo wawunekhesa. | Chofoza into kuqala, noma uthayipha `ALL` ku-`Select objects`. |
| {{key:Delete}} ayisulí | Umugqa womyalo wawunekhesa. | Thayipha `E` bese ucindezela {{key:Enter}}. |
| Ukuchofoza ngesokudla akwenzi lutho ku-trackpad ye-Mac | I-Control-click ingabalwa njengokuchofoza okujwayelekile. | Chofoza ngeminwe emibili. |
| Akukho okuhambisa ku-trackpad | Akukho inkinobho ephakathi, futhi Space ayihambisi. | Swayiphela ngeminwe emibili: ukubuka kwe-2D kuyahamba (ukuncinza nevili lesilwane kuyasondeza). Noma donsa ngokubamba ngokuchofoza ngesokudla. |
| Ukucindezela kokuqala kwe-{{key:Esc}} kuphume esikrinini esigcwele | Isiphequluli sisebenzisa i-Esc ukuphuma esikrinini esigcwele. | Cindezela {{key:Esc}} futhi ukukhansela umyalo. |
| {{key:F1}} ayenzi lutho ku-Mac | I-F1 ingukhiye wokukhanya. | Bamba **fn**, noma chofoza {{ui:Usizo}}. |
| Ukuthayipha kungena ebhokisini lokusesha losizo | Iphaneli losizo linekhesa. | Chofoza kudwebo. |
| Udwebo lube mhlophe | Usondele kakhulu ukuya ngaphandle. | Chofoza {{ui:Konke}}, noma chofoza kabili evilini. |
| "Shiya isayithi?" uma uvala ithebhu | Kukhona izinguquko ezingalondolozwanga. | Hlala, londoloza nge-{{key:Mod+S}}, bese uvala. |
