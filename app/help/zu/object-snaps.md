## Okuzokwenza

Unxande onama-diagonal amabili, indilinga egxile lapho ezihlangana khona, nomugqa osuka phakathi kolunye uhlangothi lwesikwele uye endilingeni. Wonke amaphoyinti akhethwa ngemausi, futhi wonke anembile.

## Ukuthi ukubamba kusebenza kanjani

Lapho umyalo ucela iphoyinti, i-CadCraft ifuna amaphoyinti okubamba cishe ngaphakathi kwamapixel angu-10 esikhombisini sokuhlola. Lapho ithola elilodwa, kuvela uphawu nelebula ("Ukuphela", "Ukuhlangana"), futhi ukuchofoza kufika **ngqo** kulelo phoyinti, hhayi lapho kukhona isikhombisi sokuhlola.

Ukubamba kuvuliwe uma {{ui:Bamba}} kusilawuli sesimo icindezelwe. {{key:F3}} iyawavula nawavala.

Ukubamba okungasetshenziswa:

| Ukubamba | Kufika kuya |
|---|---|
| Ukuphela | Iziphetho zemigqa, nemisnsalo nezingxenye zephola-layini |
| Ingxenye ephakathi | Ingxenye ephakathi kwemigqa, imisnsalo nezingxenye zamaphola-layini |
| Isikhungo | Isikhungo sezindilinga nemisnsalo, nezingxenye zomsnsalo wephola-layini |
| Ikwadrandi | Amaphoyinti angu-0, 90, 180 no-270 degree ezindilingeni nasemisnsalweni |
| Ukuhlangana | Lapho izinto ezimbili zidlula khona |
| Okuthambekile | Iphoyinti ezintweni eliqondile kuphoyinti lokugcina (kudinga iphoyinti lesisekelo) |
| Ukuthinta | Iphoyinti endilingeni noma emsnsalweni lapho umugqa osuka ephoyintini lokugcina uthinta khona. Uma kungakabi ekugcineni (iphoyinti lokuqala lomugqa), uphawu luthi "deferred" (kuyolandelwa): iphoyinti lokuthinta libalwa uma iphoyinti elilandelayo seliziwe, ngakho umugqa osuka ku-Ukuthinta uye ku-Ukuthinta uthinta zombili izindilinga |
| Eseduze | Iphoyinti eliseduze kakhulu kunoma iyiphi into |
| Node | Izinto zamaphoyinti |
| Ukufaka | Iphoyinti lokufaka lombhalo nezethenjwa zamabhulokhi |

Konke kuvulwe ngokuzenzakalelayo ngaphandle kokuthinta neseduze. Okuseduze kuvame ukuwina uma ufuna enye into; vula Ukuthinta uma ukudinga.

## Khetha ukubamba kwakho

1. Chofoza utolo oluncane eduze kwe-{{ui:Bamba}} kusilawuli sesimo. Uhlu {{ui:Ukubamba izinto}} luyavula.
2. Khetha noma ususe ukubamba. Izinguquko zisebenza ngokushesha.
3. Chofoza utolo futhi ukuze uvale uhlu.

I-CadCraft ikhumbula ukukhetha kwakho, nezilungiselelo ze-{{ui:Igridi}}, {{ui:Ortho}} ne-{{ui:Bamba}}, kulesi siphequluli.

## Izinyathelo

1. Bhala `REC` bese ucindezela {{key:Enter}}.
2. Bhala `0,0` bese ucindezela {{key:Enter}}.
3. Bhala `@4000,3000` bese ucindezela {{key:Enter}}. Unxande uyavela.
4. Chofoza {{ui:Konke}}.
5. Bhala `L` bese ucindezela {{key:Enter}}.
6. Hambisa isikhombisi sokuhlola ekhoneni elingaphansi kwesobunxele. Uphawu lubonisa "Ukuphela". Chofoza.
7. Hambela ekhoneni elingaphezulu kwesokudla kuze kuvele "Ukuphela". Chofoza.
8. Cindezela {{key:Enter}} ukuze uphelise umugqa.
9. Cindezela {{key:Enter}} futhi ukuze uphinde {{cmd:LINE}}, bese udweba i-diagonal yesibili kusuka ekhoneni elingaphansi kwesokudla uye ekhoneni elingaphezulu kwesobunxele ngendlela efanayo.
10. Bhala `C` bese ucindezela {{key:Enter}} ukuze uqale indilinga.
11. Hambisa isikhombisi sokuhlola lapho ama-diagonal ahlangana khona. Uphawu lubonisa "Ukuhlangana". Chofoza.
12. Bhala `800` bese ucindezela {{key:Enter}}.

Kufanele ubone indilinga egxile ngokunembile endaweni yokuhlangana.

13. Bhala `L` bese ucindezela {{key:Enter}}.
14. Hambela ohlangothini lwesobunxele lweunxande phakathi kuze kuvele "Ingxenye ephakathi". Chofoza.
15. Hambisa isikhombisi sokuhlola endilingeni, ohlangothini lwayo lwesobunxele. Uphawu lubonisa "Okuthambekile" noma "Ikwadrandi"; kokubili kuyiphoyinti elifanayo lapha. Chofoza.
16. Cindezela {{key:Enter}}.

Umugqa omusha uqala ohlangothini lwesobunxele ngaphakathi futhi umise ngokunembile endilingeni.

## Yeqa ukubamba ngokuchofoza kunye

Bamba {{key:Shift}} uma uchofoza. Ukubamba izinto kuyanganakwa kokuchofoza kuleso, futhi iphoyinti lihamba ngqo lapho kukhona isikhombisi sokuhlola (noma ngokuqondile kuyo i-Ortho, uma i-Ortho ivuliwe).

## Ortho

{{ui:Ortho}} ({{key:F8}}) igcina iphoyinti elilandelayo liqondile ngakwesokudla noma phezulu nphansi kusuka ephoyintini lesisekelo. Isebenza kuchofoza nakokufakwa kwebanga eliqondile (inombolo eyodwa ebhalwe emyalezweni). Ukubamba izinto kunqoba i-Ortho: uma kuvela uphawu lokubamba, ukuchofoza kuya ekubambeni.

## Ukulandelela kwe-polar

{{ui:Polar}} ({{key:F10}}) kuyi-Ortho ngezingosi eziningi. Lapho umyalo unephoyinti lesisekelo (iphoyinti lokugcina lomugqa, iphoyinti lesisekelo lokuhamba), isikhombi siyahlelwa noma sisondela kumugqa osuka kulo ngokuphindeka kwesinyathelo se-polar: kuvela umugqa wamachashazi, nelebula eduze kwesikhombisi sokuhlola lifunda `Polar: 1200 < 30°`. Chofoza ukuze usebenzise leliphoyinti, noma bhala ibanga: `1200` ihamba ngqo ngama-1200 eduze komugqa.

Isinyathelo singu-90° kuze ushintshe: bhala {{cmd:POLARANG}}, cindezela {{key:Enter}}, bese ubhala `30` (noma 45, 22.5, 15 …). I-Polar ne-Ortho ayihlanganisi: ukuvula enye kuvala enye.

## Ukulandelela kokubamba izinto

{{ui:Landelela}} ({{key:F11}}) ilinganisa isikhombi namaphoyinti okubamba owamisa kuwo, ukuze ukwazi ukukhetha iphoyinti elilingana nekhona elilodwa futhi lingaphezulu kwelinye ngaphandle kokudweba imigqa yosizo.

1. Vula {{ui:Bamba}} kanye {{ui:Landelela}}, bese uqala umyalo ocela iphoyinti (`L`).
2. Misa isikhombi ephoyintini lokubamba, njengekhona, cishe isigamu sesekhondi, ngaphandle kokuchofoza. Ukuqamba okuncane kuyiphawula: liyithathiwe. Misa kuyo futhi ukuze uyilahle.
3. Hambisa isikhombi ngqo kuyo, ngokuthambile noma ngokuma. Umugqa wamachashazi uyalandela isikhombi, nelebula lifunda `Track: 600 < 90°`. Chofoza, noma bhala ibanga.
4. Thola iphoyinti lesibili, bese uhamba lapho okuma okudlula kolunye kuhlangana khona nokuthambile okudlula kolunye: isikhombi sibamba ekuhlanganeni (`Track: where two lines meet`).

Uma {{ui:Polar}} ivuliwe futhi, amaphoyinti athathiwe alandelela ezingosini zonke ze-polar. Kuya kwayi-ayisikhombisa amaphoyinti agcinwayo, kuze kuphele umyalo. {{key:Shift}} ivala ukulandelela ngokuchofoza kunye, njengokubamba.

## Igridi

{{ui:Igridi}} ({{key:F7}}) ibonisa igridi yemigqa ngemuva komdwebo, nemigqa emikhulu zonke ngemigqa yesihlanu; ukuhlukana kuyashintsha uma usondeza. Ikhomba nje kuze uvule {{ui:Ukubamba kugridi}} ({{key:F9}}): khona ukuchofoza kufika esiphethweni segridi eseduze, ngaphandle uma ukubamba izinto kuthatha iphoyinti kuqala.

## Izinkinobho zomsebenzi kukhompyutha yakho

{{key:F9}} yi-Ukubamba kugridi, {{key:F10}} yi-Polar futhi {{key:F11}} yi-Landelela.

:::mac
Kwi-Mac, F3, F7, F8 no-F9 ngokuvamile zilawula i-Mission Control nemidiya. Bamba **fn** kanye nokhiye, noma vula okhiye bomsebenzi ajwayelekile, njengoba kuchazwe ku-[Okhiye, imausi namaphedi okuthinta](common:keys). Izinkinobho zesilawuli sesimo zisebenza njalo.
:::

:::firefox
Ku-Firefox, F7 iphinde ibe ukhiye wokuphequlula ngekhesa. Uma i-Firefox ikubuza ukuthi uvule yini ukuphequlula ngekhesa, khetha **Cha**. Sebenzisa inkinobho ethi {{ui:Igridi}} uma umbuzo uqhubeka uvela.
:::

:::touch
Kusikrini sokuthinta akukho ukuhamba-phezulu, ngakho uphawu lokubamba livela kuphela lapho umunwe wakho uthinta khona. Sondeza ukuze uthole izinhloso ezincane, noma bhala ama-coordinate esikhundleni salokho.
:::

## Amaphutha ajwayelekile

- **Ukuchofoza kufike endaweni engafanele.** Bheka ilebula luphawu ngaphambi kokuchofoza: Ukuphela kunqoba Ingxenye ephakathi uma zombili zisondele. Sondeza, noma susa ukubamba ongadingi.
- **Akukho luphawu olubonakalayo.** {{ui:Bamba}} ivaliwe, noma ukubamba ofuna kususiwe, noma into isongqimbeni ovaliwe noma omisiwe.
- **Ukubamba kubamba into engafanele emdwebeni ogcwele izinto.** Sondeza. Ibanga lokubamba likalwa ngamapixel esikrini, ngakho ukusondeza kwenza lincane emdwebeni.
- **Ukulindele ukuthi i-Shift inikeze umugqa oqondile.** Ku-CadCraft, i-Shift ivala ukubamba ngokuchofoza kunye. Sebenzisa {{ui:Ortho}} imigqa eqondile.
- **Ukulindele amaphoyinti afike ezindaweni zegridi.** Vula {{ui:Ukubamba kugridi}} ({{key:F9}}), noma bhala ama-coordinate ezinombolweni ezigcwele.
