## Чӣ меомӯзед

Чӣ тавр варақҳо (тарҳҳо)-ро аз якчанд файли нақша ба як **маҷмӯаи варақҳо** ҷамъ кардан, онҳоро рақамгузорӣ ва ном гузоштан, блокҳои унвонашонро барои шумо пур кардан, тамоми маҷмӯаро ҳамчун як PDF нашр кардан ва ҳама чизро ба як zip барои фиристодан бастан.

Маҷмӯаи варақҳо дар файли хурди худаш `<name>.ccsheets` зиндагӣ мекунад, дар ҷузвдоне, ки нақшаҳоро нигоҳ медорад. Файли маҷмӯа варақҳоро бо роҳҳо аз он ҷузвдон рӯйхат мекунад, пас шумо метавонед тамоми ҷузвдонро ҳаракат ё нусха кунед.

:::note
Барои хондан ва навиштан дар ҷузвдон Chrome ё Edge (онҳо метавонанд саҳифаро дар ҷузвдоне, ки шумо интихоб мекунед, кор кунанд), ё барномаи мизи корӣ лозим аст. Браузерҳои дигар маҷмӯаро танҳо хониш мекунанд: шумо метавонед онро бинед ва нашр кунед, ва файли маҷмӯа ба ҷои захира шудан зеркашида мешавад.
:::

## Маҷмӯаро оғоз кунед

1. Бахши {{ui:Sheet set}}-ро дар панели чап пайдо кунед ва менюи {{ui:Set}}-ро кушоед. Ворид кардани {{cmd:SHEETSET}} (ё `SSM`) низ шуморо ба ҳамон ҷо меорад.
2. {{ui:New set…}}-ро интихоб кунед. Ба маҷмӯа ном диҳед, ва агар хоҳед, номи лоиҳа ва рақами онро.
3. Ҷузвдонеро интихоб кунед, ки нақшаҳоро нигоҳ медорад. Файли маҷмӯа дар он ҷо захира мешавад.

Барои кушодани маҷмӯа баъдтар, {{ui:Open set…}}-ро интихоб кунед ва ҳамон ҷузвдонро интихоб кунед. Агар ҷузвдон бештар аз як маҷмӯа дошта бошад, CadCraft мепурсад, ки кадомаш.

## Варақҳо илова кунед

1. {{ui:Add sheets from a drawing…}}-ро интихоб кунед ва яке аз нақшаҳои ҷузвдонро интихоб кунед.
2. CadCraft он нақшаро дар замина мехонад (дар экран кушода намешавад) ва варақҳояшро рӯйхат мекунад. Онҳоеро, ки мехоҳед, ишорат кунед ва {{ui:OK}}-ро пахш кунед.
3. Варақро интихоб кунед ва {{key:F2}} (ё {{ui:Rename and renumber…}})-ро пахш кунед, то рақам ва унвон диҳед, масалан `A-101` ва `Нақшаи ошёна`.

{{ui:New sheet from template…}} аз варақи нақшаи дигар (блоки унвон ва вьюпортҳояш) нақшаи нав месозад, онро ба номи варақи нав мегузорад ва илова мекунад. Маҷмӯа нақшаеро, ки ҳамчун қолаб истифода бурдед, ба ёд дорад.

## Маҷмӯаро тартиб диҳед

- **Зиербахшҳо** варақҳоро гурӯҳбандӣ мекунанд, масалан Меъморӣ › Нақшаҳо: ҷоеро, ки мехоҳед, интихоб кунед ва {{ui:New subset…}}-ро интихоб кунед.
- **Тартиб**: варақро ба ҷои дигар дар рӯйхат ё ба зиербахш кашед, то ба он ҷо ҳаракат кунад. Бо клавиатура, варақро интихоб кунед ва {{key:Alt+Up}} ё {{key:Alt+Down}} пахш кунед.
- **Кушодани варақ**: дуҷониба пахш кунед (ё {{key:Enter}} пахш кунед). Нақшаи он дар варақаи худаш, дар он варақ кушода мешавад.
- **Хориҷ кардан**: варақро интихоб кунед ва {{key:Delete}} пахш кунед. Худи нақша тағйир намеёбад.
- **Бозгардондан**: {{ui:Undo set change}} ва {{ui:Redo set change}} тағйиротеро, ки дар маҷмӯа кардаед, қадам-ба-қадам мегузаранд.
- **Аз нав рақамгузорӣ**: {{ui:Renumber sheets…}} ҳар варақро ё варақҳои як зиербахшро мувофиқи тартиби рӯйхат рақамгузорӣ мекунад: пешванд, оғоз ва қадам (`A-` ва `101` мешаванд A-101, A-102 …).

Ҳар тағйирот дарҳол дар файли маҷмӯа захира мешавад.

## Рақамҳоро аз майдонҳои варақ гиред

Ба ҷои рақамгузории дастӣ, бигзоред, ки қоида ҳар рақамро аз майдонҳои варақ созад, то варақе, ки ба сатҳ ё риштаи дигар мегузарад, рақами навро худаш гирад.

1. Ба ҳар варақ майдонҳояшро диҳед: онро интихоб кунед, {{ui:Rename…}}-ро пахш кунед ва дар {{ui:Fields of this sheet}} як майдонро дар як сатр нависед, масалан `DISCIPLINE = A` ва `LEVEL = 1`. Майдоне, ки тамоми маҷмӯа мубодила мекунад (масалан `DISCIPLINE = A`), метавонад ба {{ui:Properties…}}-и маҷмӯа гузошта шавад.
2. Менюи панелро кушоед ва {{ui:Numbering rule…}}-ро пахш кунед.
3. Қоидаро нависед, масалан `{DISCIPLINE}-{LEVEL}{SEQ:2}`. `{SEQ}` миён варақҳое, ки дигар майдонҳояшон ҳамон хонданд, ҳисоб мекунад: сатҳи 1 рақами A-101, A-102 мегирад ва сатҳи 2 аз нав A-201 мегирад. `{SEQ:2}` онро бо ду рақам менависад; `{SUBSET}` номи зиербахше аст, ки варақ дар он аст.
4. Интихоб кунед, ки вақти тағйир ёфтани майдон чӣ мешавад: {{ui:Renumber the sheets}} пас аз ҳар тағйирот рақамҳоро мувофиқи қоида нигоҳ медорад; интихоби дигар онҳоро як бор ҳозир рақамгузорӣ мекунад.

Қоида дар файли маҷмӯа захира мешавад. Вақте ки худаш аз нав рақамгузорӣ мекунад, майдонҳои варақро тағйир диҳед, на рақамашро.

## Блокҳои унвонро аз маҷмӯа пур кунед

Блоки унвон матнашро аз маҷмӯа мегирад, вақте атрибутҳояш бо номи майдон ишорат шудаанд:

| Ишора | Чиро нишон медиҳад |
|---|---|
| `SHEETNUMBER` (ё `SHEET_NO`, `DWG_NO`) | Рақами варақ |
| `SHEETTITLE` (ё `TITLE`, `SHEET_TITLE`) | Унвони варақ |
| `SHEETDESC` | Тавсифи варақ |
| `PROJECTNAME` (ё `PROJECT`) | Номи лоиҳа |
| `PROJECTNUMBER` (ё `PROJECT_NO`, `JOB_NO`) | Рақами лоиҳа |
| `SHEETSETNAME` | Номи маҷмӯа |
| `SHEETINDEX`, `SHEETCOUNT` | «3 аз 12», ва 12 |
| Майдони худатон, масалан `CLIENT` | Он чи дар {{ui:Set fields…}} барояш навиштаед |

{{ui:Set fields…}} номи лоиҳа ва рақами онро дар бар мегирад, ва майдонҳои худатонро, ҳар кадомаш дар як сатр бо шакли `NAME = value`.

{{ui:Update drawings}} рақамҳо, унвонҳо ва майдонҳоро ба блокҳои унвони ҳар нақшаи маҷмӯа менависад ва ҳар варақаи тарҳро мувофиқи маҷмӯа ном мегузорад (пешфарз рақам ва унвон, масалан `A-101 Нақшаи ошёна`; {{ui:Set fields…}} › {{ui:Layout tab names}} инро иваз мекунад). Ҳар нақша дар ҷои худ, дар формат ва версияи худаш захира мешавад. Пас аз рақамгузорӣ ё номгузории варақҳо, онро дубора иҷро кунед, то варақаҳо ва блокҳои унвон пайравӣ кунанд.

## Рӯйхати варақҳо дар варақаи сарлавҳа

Варақаи сарлавҳаро дар рӯйхат интихоб кунед ва {{ui:Put the sheet list on this sheet}}-ро интихоб кунед. Ҷадвали ҳамаи варақҳо (рақам ва унвон, дар зери зиербахш) дар кунҷи болоии чапи варақ гузошта мешавад. {{ui:Update drawings}} ва {{ui:Publish to PDF}} онро навсозӣ мекунанд. Ин як блок аст, `CC_SHEETLIST`: онро мисли ҳар истиноди блок ҳаракат диҳед.

## Маҷмӯаро нашр кунед

{{ui:Publish to PDF}} як PDF месозад, ки ҳар варақ дар он як саҳифа аст, дар тартиби маҷмӯа, дар андозаи коғази худи ҳар варақ, бо нишонак барои ҳар варақ («A-101 — Нақшаи ошёна»). Агар зиербахше интихоб шуда бошад, CadCraft мепурсад, ки оё танҳо он зиербахш нашр шавад. Блокҳои унвон дар PDF аз маҷмӯа пур мешаванд, ҳатто пеш аз навсозии нақшаҳо; худи нақшаҳо бо нашр тағйир намеёбанд. PDF зеркашида мешавад.

{{ui:Publish to DWG…}} ҳар варақро ҳамчун DWG-и худаш менависад (DWG 2018): модел ва он як варақ, блоки унвонаш аз маҷмӯа пур шуда, ба рақам ва унвонаш номгузорӣ шуда (`A-101 Нақшаи ошёнаи 1.dwg`). {{ui:DWG}} ё {{ui:DWG + PDF}}-ро интихоб кунед, то PDF-и маҷмӯа дар паҳлӯи онҳо гузошта шавад. `publish.json` ҳар файлро бо андозаи он ва SHA-256 рӯйхат мекунад. Вақте ҷузвдони маҷмӯа навишта мешавад (CadCraft Studio ё ҷузвдоне, ки дар браузер интихоб кардед), файлҳо ба ҷузвдони `<номи маҷмӯа> - published` мераванд; дар акси ҳол онҳо ҳамчун як zip зеркашида мешаванд. [Иваз кардани синфҳои вьюпорт](topic:viewport-overrides) ҳар DWG-ро ҳамроҳ мекунанд.

## Маҷмӯаро бойгонӣ кунед

{{ui:Archive as a zip}} файли маҷмӯа, ҳар нақшае, ки истифода мебарад, ва он чи ин нақшаҳо истинод мекунанд (нақшаҳои пайвандшуда, ва нақшаҳои онҳо, ва тасвирҳо) бо ҷузвдонҳояшон, ва ҳамчунин `Transmittal.txt`-ро, ки ҳар файлро рӯйхат мекунад, мебандад. Пайвандае, ки дар ҷузвдони маҷмӯа нест, дар он ҳамчун гумшуда рӯйхат мешавад. Пайвандҳо аз рӯи роҳ аз нақша ва, сипас, аз рӯи номи файл дар ҳар ҷои ҷузвдон ёфта мешаванд.

## Файли маҷмӯа

Файли `.ccsheets` JSON аст, ки онро дар ҳар муҳаррири матн хондан мумкин аст:

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

Роҳҳо нисбат ба ҷузвдони маҷмӯа ҳисоб мешаванд, бо `/` дар байни ҷузвдонҳо. CadCraft ҳангоми кушодан онро месанҷад: роҳи мутлақ, варақе бе файл ё тарҳ, ё матне, ки матни оддӣ нест, партофта мешавад ва таърих ин ро мегӯяд.
