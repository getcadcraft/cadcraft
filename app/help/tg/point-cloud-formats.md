## Ин ҷо чӣ пайваст мешавад

Инҳоро бо {{cmd:POINTCLOUDATTACH}}, {{ui:Open}} ё бо андохтан ба саҳифа пайваст кунед (ба мавзӯи нақшбарории хатҳои ҳолати воқеӣ дар болои абри нуқтаҳо нигаред):

| Формат | Пасванд | Чӣ хонда мешавад |
|---|---|---|
| LAS, LAZ | `.las`, `.laz` | LAS 1.0–1.4: нуқтаҳо, рангҳо, шиддат, синфҳои LiDAR, системаи координатҳо ва воҳидҳои он. LAZ то 1 GB. |
| E57 | `.e57` | Ҳар скан дар файл, ҳар кадом бо вазияти худаш ҷойгир; рангҳо, ё шиддат, агар файл рангҳо надошта бошад; m. Тасвирҳо дар файл партофта мешаванд (гуфта мешавад). То 6 миллион нуқта ва 512 MB барои ҳоло: скани калонтарро ҳамчун LAS ё LAZ содир кунед. |
| PLY | `.ply` | Матнӣ ва дуӣ (ҳар ду тартиби байт): x y z-и нуқтаҳо, рангҳо ва шиддат. Рӯяҳо партофта мешаванд (гуфта мешавад). |
| PCD | `.pcd` | Матнӣ ва дуӣ: x y z, рангҳои фишурдашуда ё ҷудо, шиддат. Файлҳои PCD-и фишурдашуда ҳанӯз хонда намешаванд: онҳоро дуӣ ё матнӣ захира кунед. |
| PTX | `.ptx` | Як ё чанд скан, ҳар кадом бо табдилдиҳандаи худаш ҷойгир; нуқтаҳое, ки скандер чен накардааст, партофта мешаванд. m. |
| PTS, XYZ | `.pts`, `.xyz` | Матнӣ: x y z, бо шиддат ва рангҳо, вақте ки сутунҳо ҳастанд. |

## Файлҳое, ки танҳо барномаи скан мехонад

Баъзе файлҳои скан формати хоси сохтори сканер ҳастанд, бе тавсифи кушод ва бе хонандаи кушод. CadCraft онҳоро хонда наметавонад: пайваст кардани яке он чиро, ки ҳаст, ва дар сатри фармон чӣ кор кардан лозимро чоп мекунад. Скан аз барномаи сохтор ҳамчун E57 ё LAS (ё PTX, PTS) содир кунед, сипас файли содиршударо пайваст кунед.

| Файл | Пасванд | Аз он содир кунед |
|---|---|---|
| ReCap project | `.rcp` | ReCap: лоиҳаро кушоед ва содир кунед. Лоиҳа танҳо ба сканҳои худаш ишора мекунад, пас танҳо нусхабардории `.rcp` ба шумо нуқта намедиҳад. |
| ReCap scan | `.rcs` | ReCap: лоиҳаи скани марбутро кушоед ва содир кунед. |
| FARO scan | `.fls` | FARO SCENE. |
| Leica scan | `.lgs` | Leica Cyclone REGISTER 360. |
| Trimble scan | `.tzf` | Trimble RealWorks ё Trimble Business Center. |
| Z+F scan | `.zfs` | Z+F LaserControl. |

:::tip
Вақте ки содирот формат талаб мекунад, LAS ё LAZ ҳама чизро, ки CadCraft истифода мебарад (рангҳо, шиддат, синфҳо, системаи координатҳо ва воҳидҳои он), дар хурдтарин файл нигоҳ медорад.
:::

## Чаро ин файлҳо хонда нашудаанд

Ин форматҳо нашр нашудаанд, ва танҳо роҳи хондани онҳо китобхонаи нармафзори ҳар сохтор аст, таҳти шартҳои худаш. CadCraft танҳо форматҳоеро мехонад, ки бо кодҳои худаш дар компютери шумо хонда мешаванд, пас скан ҳеҷ гоҳ барои пайваст шуданаш ба ҷое фиристода намешавад.
