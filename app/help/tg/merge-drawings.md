Ду нафар як нақшаро таҳрир мекунанд. Агар онҳо объектҳои гуногунро иваз карда бошанд, якҷоякунӣ худкор шуда метавонад: ҳеҷ чиз бо дасти худ такрор кардан лозим нест.

## Чӣ онро кор мекунад

CadCraft ба ҳар объекте, ки мекашед, як **калиди** кӯтоҳ медиҳад, ки ҳеҷ гоҳ тағйир намеёбад ва ба ду объект дода намешавад. Он бо объект дар DWG ё DXF захира мешавад (ҳамчун маълумоти иловагӣ, ки барномаҳои дигар нигоҳ медоранд). Якҷоякунӣ объектҳоро бо ин калид меёбад, на бо ҷойгиршавии онҳо дар файл, зеро ҳар барнома ҳангоми захира рақамҳои ҷойгиршавиро аз нав медиҳад. Агар шумо ҳеҷ гоҳ якҷоя накунед, онро дар Танзимот › CadCraft › Файлҳои барои якҷоякунӣ мувофиқ хомӯш кунед; файлҳо тақрибан 10 фоиз хурдтар мешаванд.

Нақшае, ки пеш аз пайдошавии калидҳо захира шудааст, низ якҷоя мешавад: объектҳояш калид аз ҷойгиршавиашон дар файл мегиранд, ҳамон хел барои ҳамаи касоне, ки онро мекушоянд.

## Танзим кунед

Git ду сатрро як бор барои ҳар анбор лозим дорад:

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# як бор, дар ҳар компютер
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Бе git, онро бо дастӣ иҷро кунед: `cadcraft merge <base> <ours> <theirs> -o <result>`. Fossil ва Mercurial ҳамон се файлро дар танзимоти абзори якҷоякунии худашон мегиранд.

## Қоидаҳо

- Объекте, ки танҳо дар як тараф тағйир ёфтааст, гирифта мешавад. Ҳамон тағйир дар ҳар ду тараф як бор гирифта мешавад.
- Хосияти якхела, ки ду роҳ тағйир ёфтааст, **низоъ** аст: тарафи шумо мемонад ва гузориш ҳарду қиматро номбар мекунад. Нақшаро кушоед, ба он объект нигаред ва онро бо дасти худ ислоҳ кунед.
- Объекте, ки дар як тараф илова шудааст, нигоҳ дошта мешавад. Объекте, ки дар як тараф нест карда шудааст ва дар тарафи дигар тағйир наёфтааст, нест карда мешавад. Дар як тараф нест карда шудааст ва дар тарафи дигар тағйир ёфтааст: нест карда мешавад ва гузориш карда мешавад.
- Қабатҳо, блокҳо, матн ва тарзҳои андоза, варақҳо ва намудҳои номдор ҳамин тавр якҷоя мешаванд. Маҳдудиятҳо ба объектҳое, ки номбар мекунанд, пайравӣ мекунанд.
- Натиҷа дар ҳамон формат ва версияи файли шумо навишта мешавад.

Якҷоя намешавад: тартиби кашидани объектҳо худи шумост, сипас объектҳое, ки тарафи дигар илова кардааст. Тағйироти як таърифи ҳамон блок дар ҳарду тараф низоъ аст ва ҳеҷ гоҳ омехта намешавад. Ҳеҷ чиз боргузорӣ намешавад; ҳамааш дар компютери шумо иҷро мешавад.
