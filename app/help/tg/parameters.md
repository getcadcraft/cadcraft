## Як ҷадвал барои ҳар андоза

Панели {{ui:Parameters}} (тугмаи {{ui:Parameters}} дар гурӯҳи {{ui:Parametric}}, ё нависед {{cmd:PARAMETERS}}) ҳар маҳдудияти андозавӣ (`d1`, `rad1`, `dia1`, `ang1` ё номе, ки додед) ва параметрҳои худатонро якҷоя рӯйхат мекунад. Ҳар номро дар ҳар ифода истифода бурдан мумкин аст.

Ҳар сатр дорад:

- **Ном**: номи навро нависед, то онро иваз кунед; ҳар ифода, ки онро истифода мебарад, пайравӣ мекунад.
- **Ифода**: рақам (`40`) ё ифода (`width / 2 + gap`). Дар он нависед ва {{key:Enter}}-ро пахш кунед: нақша пайравӣ мекунад.
- **Арзиш**: он чи ҳисоб мешавад. Дар сатре, ки ифода идора мекунад, рақам низ нависед: CadCraft параметре, ки паси он аст, ҳисоб мекунад. Бо `d1 = width / 2`, нависдани `30` дар арзиши d1 `width`-ро ба 60 мегузорад.

Вақте ки ду параметр арзишро идора мекунанд (`width / 2 + gap`), қуттӣ мепурсад, кадомашро иваз кунед. Ҳар тағйир як қадами баргардондан ({{key:Mod+Z}}) аст.

## Худатон илова кунед

1. Панели {{ui:Parameters}}-ро кушоед.
2. Номи (`gap`) ва арзиш (`10`)-ро нависед, сипас {{ui:Add}}-ро интихоб кунед.
3. Истифода баред: дар ифодаи d1 `width / 2 + gap` нависед ва {{key:Enter}}-ро пахш кунед.

Номҳо бо ҳарф ё `_` оғоз мешаванд ва ҳарфҳо, рақамҳо ва `_` доранд. Номҳои функсия, `pi` ва номҳои воҳидҳо номи параметр шуда наметавонанд.

## Ифодаҳо

| Нависед | Маъно |
|---|---|
| `+ - * / ^ %` | ҷамъ, тарҳ, зарб, тақсим, дараҷа, боқимонда |
| `( )` | гурӯҳбандӣ |
| `sin cos tan asin acos atan atan2` | тригонометрия бо дараҷа |
| `sqrt pow exp ln log abs sign` | решаҳо, дараҷаҳо, логарифмҳо |
| `ceil floor int round min max` | гирд кардан ва ҳудудҳо |
| `if(a > b, x, y)` | интихоб |
| `pi` | 3.14159… |

Рақамҳо метавонанд воҳид дошта бошанд: `25mm`, `1in`, `2'`, `90deg`. Дарозиҳо бо воҳид ба миллиметр табдил меёбанд, пас воҳидҳоро танҳо дар нақшаҳои бо миллиметр андозагирифташуда истифода баред; дар дигар ҷойҳо рақами оддӣ нависед.

## Дар хати фармон

`-PARAMETERS` ҳамин корро бе панел мекунад: `N` (`Нав (N)`) нав, `E` (`Таҳрир (E)`) таҳрир (маҳдудияти андозавӣ ҳам), `R` (`Номгузорӣ (R)`) номгузории нав, `D` (`Нест кардан (D)`) нест кардан, `?` рӯйхат.

## Чизҳое, ки рад мешаванд

- Ифодае, ки худаш ё тавассути дигарон худро истифода мебарад: «width, d1 якдигарро истифода мебаранд.»
- Арзише, ки андоза гирифта наметавонад: дарозии манфӣ, кунҷи бештар аз 180°.
- Арзише, ки нақша бо маҳдудиятҳои дигараш гирифта наметавонад: ҳеҷ чиз тағйир намеёбад ва паём маҳдудиятҳоеро, ки роҳ мебанданд, ном мебарад.
- Нест кардани параметре, ки чизе истифода мебарад: панел пешниҳод мекунад, ки аввал арзишашро ба онҳо нависад. Номи маҳдудияти андозавӣ бо нест кардани маҳдудият нест мешавад.
