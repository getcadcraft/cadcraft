Номи кӯтоҳро (тахаллусро) нависед ва {{key:Enter}} пахш кунед, ё ба абзор клик кунед. {{key:Esc}} бекор мекунад. {{key:Enter}} дар сатри холӣ фармони охиринро такрор мекунад.

**Чоп кунед:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (як саҳифаи A4; дар коғази Letter онро бо «мутобиқ ба саҳифа (fit to page)» чоп кунед).

## Кашидан

| Навишт | Фармон | Чӣ кор мекунад |
|---|---|---|
| `L` | {{cmd:LINE}} | Хатҳои ростро кашед |
| `PL` | {{cmd:PLINE}} | Занҷири пайвастаи хат ва камонро кашед |
| `C` | {{cmd:CIRCLE}} | Давра кашед (марказ ва радиус) |
| `A` | {{cmd:ARC}} | Камон кашед |
| `REC` | {{cmd:RECTANG}} | Росткунҷаро аз ду кунҷ кашед |
| `POL` | {{cmd:POLYGON}} | Бисёркунҷаи мунтазамро кашед |
| `EL` | {{cmd:ELLIPSE}} | Эллипс кашед |
| `DT` | {{cmd:TEXT}} | Як сатр матн нависед |
| `T` | {{cmd:MTEXT}} | Матни сатрбарандаро (абзац) нависед |
| `H` | {{cmd:HATCH}} | Масоҳатро бо нақш пур кунед |

## Тағйир додан

| Навишт | Фармон | Чӣ кор мекунад |
|---|---|---|
| `M` | {{cmd:MOVE}} | Объектҳоро кӯчонед |
| `CO` | {{cmd:COPY}} | Объектҳоро нусхабардорӣ кунед |
| `RO` | {{cmd:ROTATE}} | Объектҳоро дар атрофи нуқта гардонед |
| `SC` | {{cmd:SCALE}} | Объектҳоро калонтар ё хурдтар кунед |
| `MI` | {{cmd:MIRROR}} | Объектҳоро аз рӯи хат инъикос кунед |
| `O` | {{cmd:OFFSET}} | Нусхаи параллелиро дар масофаи муайян кашед |
| `TR` | {{cmd:TRIM}} | Объектҳоро то ҷойи бурришашон бо дигарон кӯтоҳ кунед |
| `EX` | {{cmd:EXTEND}} | Объектҳоро то дигарон дароз кунед |
| `F` | {{cmd:FILLET}} | Кунҷро бо камон ҳамвор кунед |
| `CHA` | {{cmd:CHAMFER}} | Кунҷро бо канораи рост бурред |
| `E` | {{cmd:ERASE}} | Объектҳоро нест кунед |
| `X` | {{cmd:EXPLODE}} | Блок ё полихатро ба ҷузъҳо ҷудо кунед |
| `S` | {{cmd:STRETCH}} | Нӯгҳоро дар дарвозаи бурранда кӯчонед |
| `AR` | {{cmd:ARRAY}} | Дар тор ё давра нусхабардорӣ кунед |
| `J` | {{cmd:JOIN}} | Хатҳо ва камонҳоро ба як объект пайваст кунед |
| `BR` | {{cmd:BREAK}} | Объектро ба ду бурред ё порчаеро бароред |

## Андоза

| Навишт | Фармон | Чӣ кор мекунад |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Уфуқӣ ё амудӣ андоза гузоред |
| `DAL` | {{cmd:DIMALIGNED}} | Андозаро дар самти хати майл гузоред |
| `DRA` | {{cmd:DIMRADIUS}} | Андозаи радиусро гузоред |
| `DAN` | {{cmd:DIMANGULAR}} | Кунҷро андоза кунед |

## Блокҳо ва қабатҳо

| Навишт | Фармон | Чӣ кор мекунад |
|---|---|---|
| `B` | {{cmd:BLOCK}} | Аз объектҳо блок созед |
| `I` | {{cmd:INSERT}} | Блокро ҷойгир кунед |
| `LA` | {{cmd:LAYER}} | Қабатҳоро кушоед |

## Намуд ва маълумот

| Навишт | Фармон | Чӣ кор мекунад |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | Калонкунӣ, хурдкунӣ ё ба ҳама (E) |
| `DI` | {{cmd:DIST}} | Масофа ва кунҷро чен кунед |
| `LI` | {{cmd:LIST}} | Тафсилоти объектро нишон диҳед |
| `MA` | {{cmd:MATCHPROP}} | Намуди як объектро ба дигарон нусхабардорӣ кунед |

## Файл

| Навишт | Фармон | Чӣ кор мекунад |
|---|---|---|
| `U` | {{cmd:UNDO}} | Фармони охиринро бекор кунед |
| `SAVE` | {{cmd:SAVE}} | Нақшаро захира кунед |
| `PLOT` | {{cmd:PLOT}} | Ба PDF чоп кунед |

## Калидҳо

Ctrl (Cmd дар Mac): Z Баргардондан · Y Такрор кардан · S Захира кардан · P Чоп.  F3 Ҷаззобиҳои объектҳо · F8 Ортогоналӣ · F10 Қутбӣ.  Space ё Enter фармони охиринро такрор мекунад · чарх калон мекунад · кашидани чарх ҷойивазкунии намудро мекунад
