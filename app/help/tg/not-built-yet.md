CadCraft дар таҳия аст. Ин саҳифа рӯйхат мекунад, ки нусхаи ҷорӣ чиро намекунад, то шумо онро набоед. Ҳар банд мегӯяд, ки имрӯз ба ҷои он чӣ кор кунед.

## Файлҳо ва захиракунӣ

| Ҳанӯз сохта нашудааст | Ба ҷои он, имрӯз |
|---|---|
| DWG-и CadCraft, ки худи AutoCAD санҷида бошад | Ҳар нусхаи захирашуда аз ҷониби хонандаҳои DWG-и се барномаи дигар ва CadCraft хонда мешавад. Нигаред ба [Чӣ DWG нигоҳ медорад ва тағйир медиҳад](topic:files#what-a-dwg-keeps-and-changes). |
| Захиракунии DXF навтар аз 2000 | Ҳамчун DXF 2000 захира кунед, ё ҳамчун DWG то AutoCAD 2018. |
| Захира ба ҷои файли кушодашуда дар браузер | Ҳар захира нусхаи нави зеркашӣ мекунад; файли кӯҳнаро худатон иваз кунед, агар хоҳед. Дар CadCraft Studio, {{key:Mod+S}} ба файле, ки кушодаед, бармегардонад. |
| Захираи абрӣ ва ҳамоҳангсозӣ байни компютерҳо | CadCraft захираҳояшро ҳанӯз ба абр намефиристад: файлҳои DWG ва DXF-и худро дар папкаҳои худатон нигоҳ доред. Дар CadCraft Studio, [Таърих](topic:history) нусхаҳои абрии нақшаеро, ки аз ҷои дигар захира шудааст, ва нусхаҳои захираҳои худатонро дар ин компютер рӯйхат мекунад. |
| Оверлейҳо ва таҳрири нақшаи пайвастшуда дар ҷои худаш | Нақшаро ҳамчун пайванд илова кунед ва пас аз тағйир додани нақшаи дигар аз нав бор кунед. Пайванд ҳангоми захира ҳамчун DWG пайванд мемонад ва {{cmd:XCLIP}} онро бурида мешавад. |
| Расмҳо дар DXF; wipeout-ҳое, ки чизи зери худро пинҳон мекунанд | DXF расмро ҳамчун чаҳорчӯбаи худ бо номи файл нигоҳ медорад; DWG онро ҳамчун расм нигоҳ медорад — нигаред ба [Расмҳо дар нақша](topic:pictures). Wipeout ҳамчун чаҳорчӯбааш нишон дода мешавад. |
| Таҳрири multileader-ҳо бо хатҳои роҳнамои каҷ, бо хатҳои роҳнамо дар ҳар ду тараф, ё бо блоки ғайримунтазам гардонда ё миқёсшуда | Онҳо мисли барномаи дигар кашида мешаванд ва ҳамчун як чиз ҳаракат мекунанд. Multileader-ҳо бо хатҳои роҳнамои рост ба як ҷой ва матн ё блок ҳамчун мундариҷа таҳрирпазир меоянд ({{cmd:MLEADEREDIT}}). |
| Дар ҷадвалҳои барномаҳои дигар: ҳуҷайре, ки блок дорад, форматкунии матн дар ҳуҷайра, сарҳад ва ранги ҳуҷайраи ҷадвали DXF, ҷадвале, ки ба сутунҳо шикастааст | Ҷадвал ҳамчун ҷадвали таҳрирпазир ({{cmd:TABLEDIT}}) меояд ва то таҳрир кардан ҳамчун барномаи дигар кашида нишон дода мешавад; сипас CadCraft онро аз ҳуҷайраҳояш аз нав мекашад: матни оддӣ, формулаҳо мисли `=G3*H3` ва `=Sum(I3:I9)`, ҷойгиршавӣ ва баландии матн. Ҳуҷайраи блокӣ пас холӣ мешавад. DWG-и дастнаҳӯрда бо маълумоти ҳуҷайраҳояш захира мешавад. |
| Объекти воқеии ҷадвал дар DXF-и захирашуда | DWG ҷадвалро ҳамчун ҷадвале нигоҳ медорад, ки барномаҳои дигар таҳрир карда метавонанд. DXF онро ҳамчун блоке нигоҳ медорад, ки онро мекашад, бо сабти худи CadCraft: CadCraft онро дубора ҳамчун ҷадвал мекушояд; барномаҳои дигар блокро мебинанд. Ҷадвали оина ё ғайримунтазам миқёсшуда ҳамин тавр дар DWG низ захира мешавад. |
| Нусхабардорӣ ва гузоштан бо барномаҳои дигар | Клипбории CadCraft танҳо байни нақшаҳо ва варақаҳои CadCraft дар ҳамон браузер кор мекунад, на бо барномаҳои дигар. DWG ё DXF захира кунед ва дар он ҷо кушоед. Нигаред ба [Нусхабардорӣ, гузоштан ва дубора кардан](topic:copy-paste). |
