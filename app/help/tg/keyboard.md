Миёнбурҳо барои компютери шумо нишон дода шудаанд. Дар Mac, ҳар миёнбури {{key:Mod}} дар зер калиди Command-ро истифода мебарад, ва калиди Control низ кор мекунад. Навиштани тугмаҳо ва истифодаи тугмаҳои F дар Mac дар [Тугмаҳо, мушҳо ва трекпадҳо](common:keys) оварда шудааст.

## Навиштани фармонҳо

| Тугма | Чӣ мекунад |
|---|---|
| Ҳар ҳарф, рақам ё нишона | Ба хати фармон меравад, ҳар ҷое ки муш бошад, магар қуттии панел курсор дошта бошад |
| {{key:Enter}} | Он чиро, ки навиштаед, мефиристад. Дар хати холӣ: фармони охиринро такрор мекунад, фармонро анҷом медиҳад, интихобро анҷом медиҳад ё пешфарзро дар `<…>` қабул мекунад |
| {{key:Space}} | Мисли {{key:Enter}}, ба истиснои вақте ки CadCraft матн мепурсад (матн, номҳои блок, матни андоза), ки фазо менависад |
| {{key:Esc}} | Фармонро бекор мекунад. Бе фармони иҷрошаванда: кӯчонидани дастак ё қуттии интихобро бекор мекунад, сипас интихобро пок мекунад |
| {{key:Tab}} | Фармони пешниҳодшударо қабул мекунад, ки дар тарафи рости хати фармон нишон дода мешавад. Бе навишта ва вақте ки муш болои объектҳои ҳамдигар аст: объекти навбатиро дар он ҷо таъкид мекунад (барои интихоб пахш кунед) |
| {{key:Up}} {{key:Down}} | Аз хатҳое, ки пештар навиштаед (100-тои охирин), мегузарад |

## Нақша ва таҳрир

| Тугма | Чӣ мекунад |
|---|---|
| {{key:Mod+Z}} | Фармони охиринро баргардонад |
| {{key:Mod+Y}} ё {{key:Mod+Shift+Z}} | Такрор кардан |
| {{key:Mod+A}} | Ҳамаи объектҳоеро, ки дар варақаи кушода таҳрир шуда метавонанд, интихоб мекунад ({{cmd:SELECTALL}}). Агар дар хати фармон чизе навишта бошед, он матнро интихоб мекунад |
| {{key:Delete}} | Объектҳои интихобшударо нест мекунад ({{cmd:ERASE}}), магар дар хати фармон чизе навишта бошед |
| {{key:Backspace}} | Объектҳои интихобшударо нест мекунад, вақте ки хати фармон курсор надорад; дар хати фармон он чиро, ки навиштаед, нест мекунад |
| {{key:Esc}} | Бе фармони иҷрошаванда: интихобро пок мекунад ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | Нусхаро дар формати нақша (DWG ё DXF) захира мекунад |
| {{key:Mod+Shift+S}} | Захира ҳамчун: DWG ё DXF-ро интихоб кунед, сипас нусхаро захира кунед |
| {{key:Mod+O}} | DWG ё DXF-ро мекушояд |
| {{key:Mod+P}} | Ба PDF чоп мекунад |

Баргардондан, такрор кардан, ҳамаро интихоб кардан ва чоп ҳеҷ коре намекунанд, вақте ки фармон иҷро мешавад: аввал {{key:Esc}}-ро пахш кунед.

## Нусхабардорӣ, бурондан ва гузоштан

| Тугма | Чӣ мекунад |
|---|---|
| {{key:Mod+C}} | Интихобро ба буфер нусха мебардорад ({{cmd:COPYCLIP}}). Чизе интихоб нашуда бошад: CadCraft объектҳоро мепурсад |
| {{key:Mod+X}} | Бурондан: интихобро нусха мебардорад, сипас онро нест мекунад ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | Гузоштан: нусха ба дунболи муш меравад; пахш кунед ё нуқтаро нависед, то онро гузоред ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | Гузоштан дар ҷои худ: дар координатаҳое, ки аз онҳо нусха шуда буд ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | Дубл: нусхаи интихоб бо муш ҳаракат мекунад; пахш кунед, то онро гузоред; {{key:Esc}} чизеро нигоҳ намедорад ({{cmd:DUPLICATE}}) |

Ҳамон амалҳо дар гурӯҳи {{ui:Таҳрир}} дар панели асбобҳо ({{ui:Нусха бардоштан}}, {{ui:Гузоштан}}) ва менюи {{ui:Бештар}} ҳастанд. Вақте ки фармони дигар иҷро мешавад, онро анҷом диҳед ё {{key:Esc}}-ро пахш кунед; пахши {{key:Mod+V}} ё {{key:Mod+D}} дубора, вақте ки нусха ба дунболи муш меравад, аз нав оғоз мекунад. Вақте ки шумо дар хати фармон чизе навиштаед ё фармон матн мепурсад, ин тугмаҳо он матнро нусхабардорӣ, бурида ва гузошта мекунанд. Нигаред ба [Нусхабардорӣ, гузоштан ва дубл](topic:copy-paste).

## Ивазкунакҳо

| Тугма | Ивазкунак | Тугмаи сатри ҳолат |
|---|---|---|
| {{key:F3}} | Миёнбурҳои объект фаъол ё ғайрифаъол | {{ui:Часпидан}} |
| {{key:F7}} | Тор фаъол ё ғайрифаъол | {{ui:Тор}} |
| {{key:F8}} | Ортогоналӣ фаъол ё ғайрифаъол | {{ui:Ортогоналӣ}} |
| {{key:F10}} | Пайгирии қутбӣ фаъол ё ғайрифаъол | {{ui:Қутбӣ}} |
| {{key:F11}} | Пайгирии миёнбурҳои объект фаъол ё ғайрифаъол | {{ui:Пайгирӣ}} |
| {{key:F12}} | Вуруди динамикӣ фаъол ё ғайрифаъол | {{ui:Динамикӣ}} |

:::mac
Дар Mac, F3, F7 ва F8 одатан Mission Control ва тугмаҳои медиа мебошанд. Онҳоро бо **fn** нигоҳ доред, ё тугмаҳои стандартии F-ро дар Танзимоти система фаъол кунед, тавре ки дар [Тугмаҳо, мушҳо ва трекпадҳо](common:keys) оварда шудааст. Тугмаҳои сатри ҳолат ҳамеша кор мекунанд.
:::

:::firefox
F7 дар Firefox метавонад ҳолати курсори браузерро фаъол кунад. **Не**-ро интихоб кунед ва агар пурсиданро давом диҳад, тугмаи {{ui:Тор}}-ро истифода баред.
:::

## Роҳнамо

| Тугма | Чӣ мекунад |
|---|---|
| {{key:F1}} | Ин роҳнаморо дар паҳлуи нақша мекушояд ё мепӯшад. Ҳатто вақте ки фармон иҷро мешавад, кор мекунад ва ҳеҷ гоҳ ба хати фармон намерасад. |
| {{key:Esc}} | Вақте ки курсор дар панели роҳнамо аст: ҷустуҷӯро пок мекунад ё панелро мепӯшад |

Тугмаи {{ui:Роҳнамо}} дар панели боло ҳамон корро мекунад, ки {{key:F1}}. Вақте ки дар ҷустуҷӯи роҳнамо менависед, ҳеҷ чиз ба хати фармон намерасад. Барои баргардонидани тугмаҳо ба CadCraft, ба нақша пахш кунед; панел дар паҳлӯ кушода мемонад.

:::mac
Дар клавиатураи Mac, **fn**-ро нигоҳ доред ва F1-ро пахш кунед, ё {{ui:Роҳнамо}}-ро пахш кунед.
:::

## Экран

| Тугма | Чӣ мекунад |
|---|---|
| {{key:Ctrl+Shift+F}} | Ба навбат: муқаррарӣ, экрани пурра ва экрани пурра бо пинҳон кардани панелҳо. Ин ба ҳамаи компютерҳо калиди Control-ро истифода мебарад, Mac низ. |
| {{key:Left}} {{key:Right}} | Бо варақаи зери нақша диққат: варақаи пешин ё навбатӣ |

Дар экрани пурра браузер метавонад аввалин {{key:Esc}}-ро барои баромадан истифода барад. Барои бекор кардани фармон боз {{key:Esc}}-ро пахш кунед.

| Пахш | Нуқтаро интихоб мекунад, вақте ки фармон нуқта мепурсад; объектро, вақте ки объектҳо мепурсад; дар ғайри ин, объект ё дастакро интихоб мекунад |

| Пахш дар фазои холӣ, сипас боз пахш | Қуттии интихоб: аз чап ба рост — тиреза, аз рост ба чап — тақотӯъ |

| Кашидани дастак | Дастакро мекӯчонад (ё дастакро пахш кунед, сипас нуқтае, ки меравад, пахш кунед) |
| Дупахши матн | Онро интихоб мекунад ва курсорро дар қуттии {{ui:Матн}} дар панели рост мегузорад |
| Пахши тугмаи рост | Ворид (Enter). Ҳангоми кӯчонидани дастак ё қуттии интихоб: онро бекор мекунад |
| Кашидан бо тугмаи рост | Ҷойивазкунӣ |
| Чарх | Калон ва хурд мекунад дар атрофи салиб |

Дар трекпад ё экрани ламс, нигаред ба [Муш, трекпад ва ламс](topic:mouse-trackpad-touch).

## Тугмаҳое, ки браузер нигоҳ медорад

{{key:Mod+N}}, {{key:Mod+W}} ва {{key:Mod+T}} ҳамеша ба браузер тааллуқ доранд. CadCraft онҳоро истифода намебарад: барои нақшаи нав {{ui:Нав}}-ро пахш кунед ё `NEW` нависед. Буфери CadCraft аз они худаш аст: {{key:Mod+C}} ва {{key:Mod+V}} объектҳоро байни нақшаҳо ва варақаҳои CadCraft нусха мебардоранд, на ба барномаҳои дигар ва не аз онҳо.

Агар {{key:Mod+Y}} ба ҷои такрор кардан таърихи браузерро кушояд, {{key:Mod+Shift+Z}} ё тугмаи {{ui:Такрор кардан}}-ро истифода баред.

## Кӯчонидан дар куҷост

Кӯчонидан фармони `MOVE` аст (тугма {{key:M}}): объектҳоро интихоб кунед, сипас нуқтаи асосӣ ва нуқтаи дуюм ё масофаи навишташударо. `ALIGN` ва `DISTRIBUTE` низ ҳастанд. BimCraft ҳамон номҳоро барои ҳамон корҳо дар элементҳои бино истифода мебарад, аммо {{key:M}} дар он Чен кардан аст: кӯчонидани он {{key:Shift+M}} аст.
