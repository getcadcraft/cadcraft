## Что вы узнаете

Как позволить ИИ-ассистенту (или написанному вами скрипту) посмотреть чертеж, выполнять команды CadCraft, печатать и сохранять, а также как решить, к чему он может прикасаться.

У CadCraft **нет собственного ИИ**, и он ничего никуда не отправляет. Ассистента вы приносите сами: это любая программа, которая работает по протоколу Model Context Protocol (MCP). CadCraft только предоставляет ей инструменты, а выбираете их вы.

Есть два способа:

- **Чертеж, который у вас открыт.** Ассистент работает в этом окне, рядом с вами, через CadCraft Studio на вашем компьютере. Для этого предназначен раздел {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Assistants}}.
- **Чертежи на вашем компьютере без открытия приложения.** Сервер CadCraft MCP и командная строка `cadcraft` читают и записывают файлы DWG и DXF в указанных вами папках. См. «Работа с файлами без открытия CadCraft» ниже.

## Включение

1. Откройте {{ui:Settings}} (шестеренку на панели приложения или {{key:Mod+,}}) и перейдите на вкладку {{ui:CadCraft}}.
2. В разделе {{ui:Assistants}} отметьте флажок «Разрешить ИИ-ассистентам и скриптам использовать CadCraft». Пока он выключен, ничего не работает.
3. Выберите, что ассистент может делать. **Чтение** отмечено с самого начала; остальные пункты отмечайте, только когда они нужны.

| Разрешение | Что может делать ассистент |
|---|---|
| Чтение | Смотреть чертеж: описывать его, перечислять и находить объекты, видеть выбор, описывать вид и делать его снимок, проверять по правилам слоев и черчения |
| Редактирование | Выполнять команды над чертежом и менять выбор. Каждое действие — один шаг, который можно отменить |
| Сохранение | Сохранять чертеж (на компьютере — в его файл; в браузере — как загрузку) |
| Экспорт | Печатать в PDF и создавать другие файлы |

## Разрешите использовать файлы в выбранных папках

В CadCraft Studio ассистент может открывать, сохранять и печатать файлы по имени, а не через диалоги выбора файлов, но только внутри папок, которые вы добавили в разделе {{ui:Assistants}} › {{ui:Folders it may use}}:

1. Выберите {{ui:Add a folder…}} и укажите папку в собственном диалоге Studio.
2. Теперь ассистент может показать список файлов в ней (`files_list`), открыть чертеж (`drawing_open`), сохранить его там в версии DWG или как DXF, напечатать в файл PDF или SVG, загрузить файл LISP и передать команде нужный ей файл (`INSERT` `F`, `XATTACH`, файл точек) либо указать, куда записывается файл команды (CSV для `COUNT`, `PUBLISH`).
3. {{ui:Remove}} сразу убирает папку. Пути за ее пределами отклоняются, а уже существующий файл заменяется только тогда, когда ассистент об этом просит или сам его записал.

Открытие требует **Чтения**; запись чертежа — **Сохранения**; любой другой файл — **Экспорта**.

Инструменты, которых нет среди отмеченных вами разрешений, ассистенту не предлагаются вовсе. Если он все же запросит один из них, CadCraft откажет и запишет это в журнал действий. Выключение переключателя разрывает все подключения сразу. {{ui:Reset CadCraft settings}} тоже его выключает.

## Подключите ассистента

Ассистенты подключаются через **CadCraft Studio** на вашем компьютере: он запускает небольшой сервер, до которого может добраться только этот компьютер (адрес `127.0.0.1`), и защищает его токеном, который Studio создает при каждом запуске. Откройте Studio, выберите {{ui:Connect an assistant}} и скопируйте адрес и токен.

- В вашем ассистенте добавьте сервер MCP типа HTTP с адресом (он выглядит так: `http://127.0.0.1:47615/mcp`) и заголовком `Authorization: Bearer <token>`. Studio показывает параметры, которые нужно вставить.

{{ui:New token}} в Studio заставляет всех подключенных ассистентов переподключиться с новым токеном. Никогда не передавайте токен: любой, у кого он есть, может пользоваться включенными вами приложениями, пока работает Studio.

:::note
Вкладка браузера не может открыть подключение для ассистента: в приложениях браузера переключатель не действует, пока вы не используете CadCraft Studio на своем компьютере.
:::

## Вы сохраняете контроль

- **Каждое действие — один шаг отмены** с подписью по имени ассистента, например «Ассистент: LINE». Нажмите {{key:Mod+Z}}, чтобы отменить последнее действие ассистента целиком.
- **Вы видите, что он делает.** Его команды появляются в истории команд с **[Ассистент]** впереди, а чертеж перерисовывается по мере работы.
- **Он ждет вас.** Пока вы находитесь в середине команды, ассистент может читать чертеж, но не менять его; ему сказано повторить попытку, когда вы закончите.
- **Вы знаете, когда он подключен.** Кнопка на панели приложения называет ассистента, пока он подключен. Нажмите ее, чтобы посмотреть, что ему разрешено, или чтобы **Отключить** его.
- **Действия.** {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Assistants}} › {{ui:Activity}} перечисляет каждый вызов: когда, какой инструмент, выполнен он или отклонен и какой шаг отмены создал. {{ui:Save the log}} сохраняет копию.

## Что может запросить ассистент

| Инструмент | Разрешение | Что он делает |
|---|---|---|
| `app_info`, `drawing_describe`, `view_describe` | Чтение | Имя чертежа, единицы, слои, блоки, листы; что видно на экране |
| `files_list`, `drawing_open` | Чтение | Studio: файлы в ваших папках; открыть один в этом окне |
| `objects_list`, `object_get`, `selection_get` | Чтение | Объекты с их геометрией, длиной и площадью (или только количество по типу и слою); выбор |
| `drawing_check` | Чтение | Правила, например разрешенные слои, ничего на слое 0, цвета «По слою», высоты текста |
| `view_screenshot` | Чтение | Снимок чертежа в том виде, в каком он показан |
| `command_run` | Редактирование | Вводит текст в командную строку: `LINE 0,0 @100,0 @0,50 ` читается так, как вы бы ввели (пробел завершает ответ), либо список с одним ответом на каждый запрос. Команда может остаться открытой, и ассистент продолжит ее в следующем вызове |
| `script_run` | Редактирование | Скрипт (`.scr`) или файл LISP, как его загружает {{ui:APPLOAD}} |
| `block_insert` | Редактирование | Вставляет блок вместе со значениями его атрибутов одним действием |
| `selection_set`, `undo` | Редактирование | Выбирает объекты для следующей команды; отменяет собственные шаги |
| `drawing_save` | Сохранение | Собственное {{ui:Save}} CadCraft или {{ui:Save as}} в одну из ваших папок |
| `drawing_plot` | Экспорт | PDF или SVG листа или модели, в масштабе или по размеру (подложки PDF так пока не печатаются) |

Пока ассистент выполняет команду, CadCraft задает ее вопросы в командной строке, а не в диалоге (например, вставить весь чертеж или один блок), чтобы ассистент мог на них ответить. Библиотека и Поиск по-прежнему требуют вас; ассистенту сказано, что нужно спросить вас.

## Работа с файлами без открытия CadCraft

Сервер CadCraft MCP (`cadcraft-mcp`) и командная строка (`cadcraft`) запускают собственный код чертежей CadCraft в Node.js, без окна. Им нужен Node.js 20 или новее.

- **Сервер MCP** работает только внутри указанных вами папок и только с теми разрешениями, которые вы ему дали: `npx @getcadcraft/mcp --root ~/Drawings --allow read,edit`. Без `--root` он не может открыть ни один файл; без `--allow` он может только читать. Он также может читать модели IFC, подсчеты объемов и пометки в наборах PDF.
- **Командная строка** предназначена для ваших собственных скриптов: `cadcraft info plan.dwg`, `cadcraft run cleanup.scr plan.dwg -o plan-clean.dwg`, `cadcraft convert plan.dwg plan.dxf`, `cadcraft plot plan.dwg plan.pdf --all`, `cadcraft plot plan.dwg plan.svg`, `cadcraft check plan.dwg --rules rules.json`. Несколько файлов сразу: `cadcraft convert *.dwg out --to dxf`, `cadcraft plot *.dwg pdfs --to pdf`, `cadcraft check *.dwg --rules rules.json`. Добавьте `--json`, чтобы получить вывод, который может прочитать программа.

:::note
Если `npx @getcadcraft/mcp` сообщает, что пакет не найден, значит, он еще не опубликован. Новости на getcadcraft.com сообщат, когда он появится.
:::

## Если что-то не работает

- **Ассистент не видит инструментов CadCraft:** проверьте, что переключатель включен в этом окне и что окно открыто в Studio.
- **«нужно разрешение на редактирование»:** отметьте **Редактирование** в разделе {{ui:Assistants}}, затем повторите запрос.
- **«вне папок, которые могут использовать ассистенты»:** добавьте эту папку в разделе {{ui:Assistants}} › {{ui:Folders it may use}} или попросите ассистента использовать файл из уже добавленной папки.
- **Ошибки «401» или «token»:** токен изменился (Studio был перезапущен или вы нажали {{ui:New token}}). Скопируйте новый токен в настройки ассистента.
- **Его изменение было неверным:** нажмите {{key:Mod+Z}}. Одно нажатие отменяет одно действие ассистента целиком.
