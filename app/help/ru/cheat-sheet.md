Введите короткое имя (псевдоним) и нажмите Enter либо щелкните инструмент. Esc отменяет команду. Enter на пустой строке повторяет последнюю команду.

**Распечатайте:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (одна страница A4; на бумаге Letter печатайте с параметром «по размеру страницы»).

## Черчение

| Ввод | Команда | Что делает |
|---|---|---|
| `L` | {{cmd:LINE}} | Рисует прямые отрезки |
| `PL` | {{cmd:PLINE}} | Рисует связанную цепочку отрезков и дуг |
| `C` | {{cmd:CIRCLE}} | Рисует окружность (центр и радиус) |
| `A` | {{cmd:ARC}} | Рисует дугу |
| `REC` | {{cmd:RECTANG}} | Рисует прямоугольник по двум углам |
| `POL` | {{cmd:POLYGON}} | Рисует правильный многоугольник |
| `EL` | {{cmd:ELLIPSE}} | Рисует эллипс |
| `DT` | {{cmd:TEXT}} | Пишет одну строку текста |
| `T` | {{cmd:MTEXT}} | Пишет текст с переносом строк (абзац) |
| `H` | {{cmd:HATCH}} | Заполняет область штриховкой |

## Редактирование

| Ввод | Команда | Что делает |
|---|---|---|
| `M` | {{cmd:MOVE}} | Перемещает объекты |
| `CO` | {{cmd:COPY}} | Копирует объекты |
| `RO` | {{cmd:ROTATE}} | Поворачивает объекты вокруг точки |
| `SC` | {{cmd:SCALE}} | Увеличивает или уменьшает объекты |
| `MI` | {{cmd:MIRROR}} | Отражает объекты относительно линии |
| `O` | {{cmd:OFFSET}} | Рисует параллельную копию на заданном расстоянии |
| `TR` | {{cmd:TRIM}} | Обрезает объекты по границам, где их пересекают другие |
| `EX` | {{cmd:EXTEND}} | Удлиняет объекты до других объектов |
| `F` | {{cmd:FILLET}} | Скругляет угол дугой |
| `CHA` | {{cmd:CHAMFER}} | Срезает угол прямой фаской |
| `E` | {{cmd:ERASE}} | Удаляет объекты |
| `X` | {{cmd:EXPLODE}} | Расчленяет блок или полилинию на части |
| `S` | {{cmd:STRETCH}} | Смещает концы, попавшие в секущую рамку |
| `AR` | {{cmd:ARRAY}} | Копирует в виде сетки или по окружности |
| `J` | {{cmd:JOIN}} | Объединяет отрезки и дуги в один объект |
| `BR` | {{cmd:BREAK}} | Разрывает объект надвое или вырезает его часть |

## Размеры

| Ввод | Команда | Что делает |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Ставит горизонтальный или вертикальный размер |
| `DAL` | {{cmd:DIMALIGNED}} | Ставит размер вдоль наклонной линии |
| `DRA` | {{cmd:DIMRADIUS}} | Ставит размер радиуса |
| `DAN` | {{cmd:DIMANGULAR}} | Ставит угловой размер |

## Блоки и слои

| Ввод | Команда | Что делает |
|---|---|---|
| `B` | {{cmd:BLOCK}} | Создает блок из объектов |
| `I` | {{cmd:INSERT}} | Вставляет блок |
| `LA` | {{cmd:LAYER}} | Открывает слои |

## Вид и запросы

| Ввод | Команда | Что делает |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | Увеличивает, уменьшает или показывает всё (E) |
| `DI` | {{cmd:DIST}} | Измеряет расстояние и угол |
| `LI` | {{cmd:LIST}} | Показывает сведения об объекте |
| `MA` | {{cmd:MATCHPROP}} | Копирует свойства одного объекта на другие |

## Файл

| Ввод | Команда | Что делает |
|---|---|---|
| `U` | {{cmd:UNDO}} | Отменяет последнюю команду |
| `SAVE` | {{cmd:SAVE}} | Сохраняет чертеж |
| `PLOT` | {{cmd:PLOT}} | Печатает в PDF |

## Клавиши

Ctrl (Cmd на Mac): Z отмена · Y возврат · S сохранение · P печать.  F3 объектная привязка · F8 орто · F10 полярное отслеживание.  Space или Enter повторяет последнюю команду · колесо меняет масштаб · перетаскивание колеса сдвигает вид

Только начинаете чертить? Введите `TOUR`, чтобы пройти первый чертеж с подсказками, прочитайте [Первые шаги](topic:getting-started) или посмотрите все команды в разделе [Команды](topic:commands). Если вы пришли из другой программы для черчения: [Переход из другой программы для черчения](topic:coming-from) и [карта команд](topic:command-map).
