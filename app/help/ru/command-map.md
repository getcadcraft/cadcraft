CadCraft использует имена команд и короткие имена, которые люди знают по другим чертежным программам: введите `L`, чтобы начертить отрезок, `TR`, чтобы обрезать, `E`, чтобы удалить. Поэтому для большинства команд не нужно учить таблицу соответствий: имя, которое вы знаете, работает и здесь. Ниже приведены все команды CadCraft, составленные самой программой. {{key:Enter}} повторяет последнюю команду; `HELP` в командной строке выводит тот же список.

Немногие команды отличаются или еще не созданы:

- **Сохранить** скачивает копию в браузере ({{cmd:SAVE}}, {{cmd:SAVEAS}}); в CadCraft Studio команда записывает файл. См. [Переход с других чертежных программ](topic:coming-from).
- **PLOT** создает PDF (также PNG и SVG) с таблицей стилей печати; менеджера параметров страницы нет.
- **DIMSTYLE** и **PEDIT** созданы; у **PEDIT** нет опции Edit-vertex (это делают ручки).
- **TABLE** еще не создана; {{cmd:XREF}}, {{cmd:SPLINE}} и {{cmd:WBLOCK}} созданы.
- Собственные команды программы (AutoLISP `C:NAME`) появляются после загрузки с помощью {{cmd:APPLOAD}}; здесь они не перечислены.

| `WALLOFFSET` | `WO` | Переместить стену под прямым углом к себе на расстояние (соединенные с ней стены следуют) или сделать копию на этом расстоянии. |

| `WALLSTRETCH` |  | Растянуть окном: концы стен внутри него перемещаются, стены, полностью внутри, перемещаются целиком, а стены, упирающиеся в их боковые стороны, скользят вместе с ними. |

| `WHOHAS` |  | Сообщает, кто открыл чертеж. CadCraft Studio хранит небольшой файл блокировки рядом с каждым открытым чертежом (Plan.dwg.cclock: кто, с какого времени, какая версия) и удаляет его при закрытии. Опции: Текущий (открытый чертеж), Файл (выбрать один), Папка (каждый чертеж в папке, который где-то открыт; это также позволяет Studio хранить файлы блокировки в этой папке), Путь (ввести один), Имя (имя, которое видят другие).
