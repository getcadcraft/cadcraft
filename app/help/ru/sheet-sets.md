## Что вы узнаете

Как собрать листы (макеты) из нескольких файлов чертежей в **подшивку листов**, пронумеровать и назвать их, заполнить их основные надписи автоматически, опубликовать всю подшивку как один PDF и упаковать все в один zip для отправки.

Подшивка живет в собственном небольшом файле `<name>.ccsheets` в папке, которая содержит чертежи. Файл подшивки перечисляет листы с путями от этой папки, так что можно переместить или скопировать всю папку.

:::note
Чтобы читать и записывать в папку, нужны Chrome или Edge (они могут позволить странице работать в папке, которую вы выбрали), либо настольное приложение. В других браузерах подшивка открывается только для чтения: ее можно смотреть и публиковать, а файл подшивки скачивается вместо сохранения.
:::

## Создание подшивки

1. Найдите раздел {{ui:Подшивка листов}} на левой панели и откройте его меню {{ui:Подшивка}}. Ввод {{cmd:SHEETSET}} (или `SSM`) тоже приведет туда.
2. Выберите {{ui:Новая подшивка…}}. Дайте подшивке имя и, если хотите, название проекта и его номер.
3. Выберите папку, которая содержит чертежи. Файл подшивки сохраняется там.

Чтобы открыть подшивку позже, выберите {{ui:Открыть подшивку…}} и укажите ту же папку. Если в папке больше одной подшивки, CadCraft спросит, какую открыть.

## Добавление листов

1. Выберите {{ui:Добавить листы из чертежа…}} и укажите один из чертежей в папке.
2. CadCraft читает этот чертеж в фоновом режиме (он не открывается на экране) и перечисляет его листы. Отметьте нужные и нажмите {{ui:ОК}}.
3. Выберите лист и нажмите {{key:F2}} (или {{ui:Переименовать и перенумеровать…}}), чтобы задать ему номер и название, например `A-101` и «План этажа».

{{ui:Новый лист из шаблона…}} создает новый чертеж из листа другого чертежа (его основной надписи и видовых экранов), называет его по новому листу и добавляет его. Подшивка запоминает чертеж, который вы использовали как шаблон.

## Упорядочение подшивки

- **Подмножества** группируют листы, например «Архитектура › Планы»: выберите место, где оно будет, и выберите {{ui:Новое подмножество…}}.
- **Порядок**: перетащите лист на другое место в списке или на подмножество, чтобы переместить его туда. С клавиатуры выберите лист и нажмите {{key:Alt+Up}} или {{key:Alt+Down}}.
- **Открыть лист**: дважды щелкните его (или нажмите {{key:Enter}}). Его чертеж открывается в собственной вкладке, на этом листе.
- **Удалить**: выберите лист и нажмите {{key:Delete}}. Сам чертеж не меняется.
- **Отмена**: {{ui:Отменить изменение подшивки}} и {{ui:Вернуть изменение подшивки}} переходят по тому, что вы изменили в подшивке.
- **Перенумерация**: {{ui:Перенумеровать листы…}} нумерует каждый лист, или листы одного подмножества, в порядке списка: префикс, начало и шаг (`A-` и `101` дают A-101, A-102 …).

Каждое изменение сразу сохраняется в файле подшивки.

## Нумерация листов по их полям

Вместо ручной нумерации позвольте правилу собирать номер из полей листа, чтобы лист, перенесенный на другой уровень или раздел, получил новый номер сам.

1. Задайте полям каждого листа значения: выберите лист, нажмите {{ui:Переименовать…}} и в {{ui:Поля этого листа}} напишите по одному полю на строке, например `DISCIPLINE = A` и `LEVEL = 1`. Поле, общее для всей подшивки (скажем, `DISCIPLINE = A`), можно поместить в {{ui:Свойства…}} подшивки.
2. Откройте меню панели и нажмите {{ui:Правило нумерации…}}.
3. Напишите правило, например `{DISCIPLINE}-{LEVEL}{SEQ:2}`. `{SEQ}` считает среди листов, у которых остальные поля совпадают, так что уровень 1 получает A-101, A-102, а уровень 2 начинает заново с A-201. `{SEQ:2}` записывает номер двумя цифрами; `{SUBSET}` — это имя подмножества, в котором лежит лист.
4. Выберите, что происходит при изменении поля: {{ui:Перенумеровать листы}} держит номера по правилу после каждого изменения; другой вариант нумерует их один раз, прямо сейчас.

Правило сохраняется в файле подшивки. Пока оно перенумеровывает листы само, меняйте поля листа, а не его номер.

## Заполнение основных надписей из подшивки

Основная надпись получает текст из подшивки, когда ее атрибуты помечены именем поля:

| Метка | Что показывает |
|---|---|
| `SHEETNUMBER` (или `SHEET_NO`, `DWG_NO`) | Номер листа |
| `SHEETTITLE` (или `TITLE`, `SHEET_TITLE`) | Название листа |
| `SHEETDESC` | Описание листа |
| `PROJECTNAME` (или `PROJECT`) | Название проекта |
| `PROJECTNUMBER` (или `PROJECT_NO`, `JOB_NO`) | Номер проекта |
| `SHEETSETNAME` | Имя подшивки |
| `SHEETINDEX`, `SHEETCOUNT` | «3 из 12», и 12 |
| Свои, например `CLIENT` | То, что вы написали для него в {{ui:Заполнить поля…}} |

{{ui:Заполнить поля…}} содержит название проекта и номер, а также ваши поля, по одному на строке в виде `NAME = value`.

{{ui:Обновить чертежи}} записывает номера, названия и поля в основные надписи каждого чертежа подшивки и переименовывает вкладку каждого листа по правилам подшивки (по умолчанию номер и название, например `A-101 План этажа`; это меняет {{ui:Заполнить поля…}} › {{ui:Имена вкладок листов}}). Каждый чертеж сохраняется на месте, в своем формате и версии. После перенумерации или переименования листов запустите это снова, и вкладки и основные надписи последуют за изменениями.

## Список листов на титульном листе

Выберите титульный лист в списке и выберите {{ui:Поместить список листов на этот лист}}. Таблица всех листов (номер и название, под своим подмножеством) помещается в верхний левый угол листа. {{ui:Обновить чертежи}} и {{ui:Опубликовать в PDF}} поддерживают ее актуальной. Это один блок, `CC_SHEETLIST`: перемещайте его как любое вхождение блока.

## Публикация подшивки

{{ui:Опубликовать в PDF}} создает один PDF со страницей на лист, в порядке подшивки, в собственном размере бумаги каждого листа, с закладкой на каждый лист («A-101 — План этажа»). Если выбрано подмножество, CadCraft спросит, публиковать ли только его. Основные надписи в PDF заполняются из подшивки даже до того, как вы обновите чертежи; сама публикация чертежи не меняет. PDF скачивается.

{{ui:Опубликовать в DWG…}} записывает каждый лист отдельным DWG (DWG 2018): модель и этот один лист с основной надписью, заполненной из подшивки, с именем по номеру и названию (`A-101 Level 1 floor plan.dwg`). Выберите {{ui:DWG}} или {{ui:DWG + PDF}}, чтобы рядом появился PDF подшивки. Файл `publish.json` перечисляет каждый файл с его размером и SHA-256. Когда папку подшивки можно записать (CadCraft Studio или папка, которую вы выбрали в браузере), файлы попадают в папку `<set name> - published`; иначе они скачиваются одним zip. [Переопределения классов видового экрана](topic:viewport-overrides) переносятся в каждый DWG.

## Архивация подшивки

{{ui:Архивировать в zip}} упаковывает файл подшивки, каждый чертеж, который она использует, и то, на что эти чертежи ссылаются (связанные чертежи, а в них — свои связи, и изображения), сохраняя их папки, плюс `Transmittal.txt`, который перечисляет каждый файл. Ссылка, которой нет в папке подшивки, перечисляется там как отсутствующая. Ссылки находятся по пути от чертежа, затем по имени файла в любом месте папки.

## Файл подшивки

Файл `.ccsheets` — это JSON, который можно прочитать в любом текстовом редакторе:

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

Пути задаются относительно папки подшивки, с `/` между папками. CadCraft проверяет файл при открытии: абсолютный путь, лист без файла или макета либо текст, который не является простым, пропускаются, и история сообщает об этом.

## Устранение неполадок

| Что вы видите | Почему | Что делать |
|---|---|---|
| «Эта папка здесь доступна только для чтения» | Браузер не может писать в папку | Используйте Chrome или Edge, либо настольное приложение; тем временем {{ui:Скачать файл подшивки}} сохраняет ваши изменения |
| Лист пропущен в PDF: «у листа нет макета с именем …» | Макет листа переименован или удален в своем чертеже | Откройте чертеж и проверьте его вкладки; удалите лист и добавьте его снова |
| Основная надпись остается пустой | Ее атрибуты помечены другими метками | Переименуйте метки атрибутов в имена полей выше (BEDIT) |
| «уже есть лист с именем … поэтому вкладка не переименована» | Два листа одного чертежа получили бы одно и то же имя вкладки | Дайте одному из них другой номер или название |
