Два человека редактируют один чертеж. Если они изменили разные объекты, слияние может быть автоматическим: ничего не нужно переделывать вручную.

## Как это работает

CadCraft дает каждому нарисованному объекту короткий **ключ**, который никогда не меняется и никогда не дается двум объектам. Он сохраняется вместе с объектом в DWG или DXF (как дополнительные данные, которые другие программы сохраняют). Слияние находит объекты по этому ключу, а не по их положению в файле, потому что каждая программа перенумеровывает положения при сохранении. Если вы никогда не сливаете файлы, отключите это в {{ui:Settings}} › CadCraft › «Файлы, удобные для слияния»; файлы станут примерно на 10 процентов меньше.

Чертеж, сохраненный до появления ключей, тоже сливается: его объекты получают ключ по своему месту в файле, одинаковый для всех, кто его открывает.

## Настройка

Git нужны две строки один раз на репозиторий:

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Без git запустите вручную: `cadcraft merge <base> <ours> <theirs> -o <result>`. Fossil и Mercurial принимают те же три файла в собственной настройке инструмента слияния.

## Правила

- Объект, измененный только с одной стороны, принимается. Одно и то же изменение с обеих сторон принимается один раз.
- Одно и то же свойство, измененное двумя способами, — это **конфликт**: ваша сторона остается, а отчет перечисляет оба значения. Откройте результат, посмотрите на этот объект и исправьте его вручную.
- Объект, добавленный с любой стороны, сохраняется. Объект, удаленный с одной стороны и не тронутый с другой, удаляется. Удален с одной стороны и изменен с другой: удаляется и сообщается.
- Слои, блоки, стили текста и размеров, листы и именованные виды сливаются так же. Ограничения следуют за объектами, которые они называют.
- Результат записывается в том же формате файла и версии, что и ваш.

Не сливается: порядок, в котором рисуются объекты, остается вашим, затем идут объекты, которые добавила другая сторона. Изменения одного и того же определения блока с обеих сторон — это конфликт, они никогда не смешиваются. Ничего не передается на сервер; всё работает на вашем компьютере.
