## Ano ang matututunan mo

Paano suriin kung ang dalawang drawing (o dalawang style sa iisang drawing) ay pareho ang setup, at gawing kapareho ng isa ang isa, isang value sa bawat pagkakataon.

## Ihambing

1. Buksan ang mga drawing na gusto mong ihambing, bawat isa sa sariling tab (o isa lang, para ikumpara ang dalawang sariling style nito).
2. I-click ang {{ui:View}} › {{ui:Higit pa}} › {{ui:Ihambing ang mga setting…}}, o i-type ang `CMPSET` at pindutin ang {{key:Enter}}.
3. Sa {{ui:Ikumpara}}, piliin kung ano ang ikukumpara: {{ui:Dimension style}}, {{ui:Text style}}, {{ui:Mga Layer}}, {{ui:Mga sheet (page setup)}} o {{ui:Mga unit}}.
4. Sa kaliwa, piliin ang item sa drawing na ito; sa ilalim ng {{ui:Laban sa}}, piliin ang drawing na ito o ibang bukas, at pagkatapos ang item nito.

Ipinapakita ang bawat property sa iisang hanay, ang value ng drawing na ito sa kaliwa at ang sa isa pa sa kanan. Ang mga hanay na magkaiba ay may kulay, at sinasabi ng linya sa itaas ng table kung ilan ang mga ito. Itinatago ng {{ui:Ang mga pagkakaiba lang}} ang iba. Ang {{ui:Mga setting para sa mga bagong dimension}} ay ang kinukuha ng mga bagong dimension sa drawing.

## Kopyahin ang isang value

- I-click ang arrow na nakaturo sa kanan sa isang hanay ({{ui:Kopyahin sa kanan}}) para kopyahin ang kaliwang value sa kanan, o ang arrow na nakaturo sa kaliwa para sa kabaligtaran.

Ang value ay mapupunta sa drawing na iyon bilang isang undo step: pumunta sa tab nito at pindutin ang {{key:Mod+Z}} para bawiin ito. Ang pagkopya sa isang layer o style na wala pa sa kabilang drawing ay gagawa nito roon.
