## Ano ang isinusulat ng CadCraft

{{ui:I-save}} ay nagsusulat ng totoong DWG, sa bersyong pinanggalingan ng drawing o sa piliin mo sa {{ui:I-save bilang}}: AutoCAD 2000, 2004, 2007, 2010, 2013 o 2018. Walang binabagong format sa likod mo: nakatala sa Kasaysayan ang anumang nabago sa daan (halimbawa, ang true colour na isinusulat bilang pinakamalapit na standard color sa 2000 DWG).

## Saan ito nabuksan

Bawat DWG na isinusulat ng CadCraft ay binubuksan, sa bawat bersyon, ng tatlong programang hindi CadCraft: ang ODA File Converter (na sinusuri ang file at walang inaayos dito), ang LibreDWG at ang libdxfrw. Ikinukumpara ang pagbasa nila sa pagbasa ng CadCraft: object, layer, block at attribute, dimension, hatch, sheet at ang kanilang viewport.

Sinusuri pa sa Windows ang pagbubukas ng DWG file ng CadCraft sa AutoCAD at sa libreng DWG TrueView, uri ng object kada uri (AUDIT, layer, sheet, dimension, hatch, attribute, dynamic block, clipped reference, larawan). Ilalista rito ang mga resulta kapag handa na ang mga ito.

## Kapag may nagreklamong programa

1. I-save ulit bilang DXF ({{ui:I-save bilang}} › {{ui:DXF 2000}}) at buksan iyon: karamihan ng programa ay nagbabasa ng DXF.
2. I-save ang DWG sa mas lumang bersyon (2013 o 2010).
3. Sabihin sa amin sa Discord kung anong programa at bersyon, at ano ang sinabi nito; pinakamalaking tulong ang file.
