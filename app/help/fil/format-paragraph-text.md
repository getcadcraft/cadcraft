## Ang gagawin mo

Sumulat ng note, gawing bold at pula ang isang salita, baguhin ang laki nito, magdagdag ng degree sign, at tapusin.

## Mga hakbang

1. I-type ang {{cmd:MTEXT}} at pindutin ang {{key:Enter}}, o i-double-click ang umiiral na text, o i-type ang {{cmd:TEXTEDIT}} at piliin ito. Bubukas ang text box na may formatting row sa itaas nito.
2. I-type ang note mo. Ang {{key:Enter}} ay nagsisimula ng bagong paragraph.
3. Pumili ng salita gamit ang mouse o {{key:Shift+Right}}.
4. Sa formatting row, gamitin ang {{ui:Font}} para sa font, ang {{ui:Sukat}} para sa sukat ng napili, ang mga button na {{ui:Bold}}, {{ui:Italic}}, {{ui:Salungguhit}} at {{ui:Tinawid}}, at ang {{ui:Kulay}} para pumili ng kulay. Kapag walang napili, binabago ng {{ui:Sukat}} ang lahat ng text.
5. Gamitin ang {{ui:I-align sa kaliwa}}, {{ui:Centre}} o {{ui:I-align sa kanan}} para sa alignment.
6. Para mag-type ng symbol, ilagay ang cursor kung saan ito pupunta at i-click ang {{ui:Simbolo ng degree}}, {{ui:Simbolo ng plus-minus}} o {{ui:Simbolo ng diameter}}.
7. I-click ang {{ui:OK}} o pindutin ang {{key:Ctrl+Enter}} para i-save ang text. Ang {{ui:Kanselahin}} o {{key:Esc}} ay iiwan itong gaya ng dati.

## Mga note

- May {{ui:Taas}}, {{ui:Line spacing}}, {{ui:Lapad}} (0 = walang wrapping) at {{ui:Justify}} din ang box.
- Ang formatting ay isinusulat bilang paragraph text codes kasama ng plain na mga salita, kaya patuloy na gumagana ang find, snap, DXF at DWG. Para itakda ang font ng buong note, gamitin ang isang [text style](topic:text-styles).
- Wala pang bullet o numbered list, tab ruler, o justified paragraph.
- Ang mga na-plot na PDF ay naglalagay ng text sa Helvetica.
