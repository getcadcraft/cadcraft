## ერთი ცხრილი ყველა ზომისთვის

{{ui:პარამეტრები}} პანელი ({{ui:პარამეტრები}} ღილაკი {{ui:პარამეტრული}} ჯგუფში, ან აკრიფეთ {{cmd:PARAMETERS}}) ჩამოთვლის ყველა ზომით შეზღუდვას (`d1`, `rad1`, `dia1`, `ang1`, ან თქვენ მიერ მიცემულ სახელს) და თქვენს საკუთარ პარამეტრებს ერთად. ნებისმიერი სახელი ნებისმიერ გამოსახულებაში შეიძლება იყოს.

თითოეულ სტრიქონს აქვს:

- **სახელი**: ჩაწერეთ ახალი, რომ გადაარქვათ; ყველა გამოსახულება, რომელიც მას იყენებს, მიჰყვება.
- **გამოსახულება**: რიცხვი (`40`) ან გამოსახულება (`width / 2 + gap`). ჩაწერეთ და დააჭირეთ {{key:Enter}}-ს: ნახაზი მიჰყვება.
- **მნიშვნელობა**: რა გამოდის. სტრიქონზე, რომელსაც გამოსახულება მართავს, აქაც შეგიძლიათ რიცხვის ჩაწერა: CadCraft პარამეტრს მის უკან ითვლის. `d1 = width / 2`-ის შემთხვევაში, d1-ის მნიშვნელობაში `30`-ის ჩაწერა `width`-ს 60-ზე დააყენებს.

როცა ორი პარამეტრი მართავს მნიშვნელობას (`width / 2 + gap`), დიალოგი გკითხავთ, რომელი შეიცვალოს. ყოველი ცვლილება ერთი დაბრუნების ნაბიჯია ({{key:Mod+Z}}).

## საკუთარის დამატება

1. გახსენით {{ui:პარამეტრები}} პანელი.
2. აკრიფეთ სახელი (`gap`) და მნიშვნელობა (`10`), შემდეგ აირჩიეთ {{ui:დამატება}}.
3. გამოიყენეთ: d1-ის გამოსახულებაში აკრიფეთ `width / 2 + gap` და დააჭირეთ {{key:Enter}}-ს.

სახელები იწყება ასოთი ან `_`-ით და შედგება ასოებისგან, ციფრებისა და `_`-ისგან. ფუნქციების სახელები, `pi` და ერთეულების სახელები სახელად ვერ გამოდგება.

## გამოსახულებები

| ჩაწერეთ | ნიშნავს |
|---|---|
| `+ - * / ^ %` | შეკრება, გამოკლება, გამრავლება, გაყოფა, ხარისხი, ნაშთი |
| `( )` | დაჯგუფება |
| `sin cos tan asin acos atan atan2` | ტრიგონომეტრია გრადუსებში |
| `sqrt pow exp ln log abs sign` | ფესვები, ხარისხები, ლოგარითმები |
| `ceil floor int round min max` | დამრგვალება და ზღვრები |
| `if(a > b, x, y)` | არჩევანი |
| `pi` | 3.14159… |

რიცხვებს შეიძლება ჰქონდეს ერთეული: `25mm`, `1in`, `2'`, `90deg`. ერთეულიანი სიგრძეები გარდაიქმნება მილიმეტრებში, ამიტომ ერთეულები გამოიყენეთ მხოლოდ მილიმეტრებში გაზომილ ნახაზებში; სხვაგან ჩაწერეთ უბრალო რიცხვები.

## ბრძანების ხაზზე

`-PARAMETERS` იგივეს აკეთებს პანელის გარეშე: `N` ახალი (ახალი), `E` რედაქტირება (ზომითი შეზღუდვაც), `R` სახელის შეცვლა, `D` წაშლა, `?` სია.

## რა უარყოფილია

- გამოსახულება, რომელიც საკუთარ თავს იყენებს, პირდაპირ ან სხვების გავლით: „width, d1 ერთმანეთს იყენებენ.“
- მნიშვნელობა, რომელსაც ზომა ვერ მიიღებს: უარყოფითი სიგრძე, კუთხე 180°-ზე მეტი.
- მნიშვნელობა, რომელსაც ნახაზი ვერ მიიღებს მის სხვა შეზღუდვებთან ერთად: არაფერი იცვლება, და შეტყობინება ასახელებს შეზღუდვებს, რომლებიც ხელს უშლის.
- პარამეტრის წაშლა, რომელსაც რაღაც იყენებს: პანელი გთავაზობთ, ჯერ მისი მნიშვნელობა ჩაწეროს მათში. ზომითი შეზღუდვის სახელი იშლება თავად შეზღუდვის წაშლით.
