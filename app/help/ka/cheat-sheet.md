აკრიფეთ მოკლე სახელი (მეტსახელი) და დააჭირეთ Enter-ს, ან დააწკაპუნეთ ინსტრუმენტზე. Esc აუქმებს. Enter ცარიელ ხაზზე იმეორებს ბოლო ბრძანებას.

**დაბეჭდვა:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (ერთი A4 გვერდი; Letter ფორმატის ქაღალდზე დაბეჭდეთ „გვერდზე მორგება“).

## ხაზვა

| ტიპი | ბრძანება | რას აკეთებს |
|---|---|---|
| `L` | {{cmd:LINE}} | სწორი ხაზების დახატვა |
| `PL` | {{cmd:PLINE}} | დაკავშირებული ხაზებისა და რკალების ჯაჭვის დახატვა |
| `C` | {{cmd:CIRCLE}} | წრეწირის დახატვა (ცენტრი და რადიუსი) |
| `A` | {{cmd:ARC}} | რკალის დახატვა |
| `REC` | {{cmd:RECTANG}} | მართკუთხედის დახატვა ორი კუთხით |
| `POL` | {{cmd:POLYGON}} | წესიერი მრავალკუთხედის დახატვა |
| `EL` | {{cmd:ELLIPSE}} | ელიფსის დახატვა |
| `DT` | {{cmd:TEXT}} | ტექსტის ერთი ხაზის ჩაწერა |
| `T` | {{cmd:MTEXT}} | ტექსტის ჩაწერა გადატანით (აბზაცი) |
