## რას ისწავლით

ორი სწრაფი გზა ობიექტის შესაცვლელად ბრძანების გარეშე: გადაათრიეთ მისი **მარკერები**, ან ჩაწერეთ ახალი მნიშვნელობები მარჯვენა პანელზე, **თვისებები**.

## მარკერები

როცა ობიექტებს ირჩევთ (ერთდროულად მაქსიმუმ 200) ბრძანების გარეშე, მათზე პატარა კვადრატები ჩნდება. ეს არის მარკერები:

| ობიექტი | მარკერები |
|---|---|
| ხაზი | ორივე ბოლო და შუა (მთელ ხაზს გადააადგილებს) |
| წრეწირი | ცენტრი (გადააადგილებს) და წრეწირზე ოთხი წერტილი (ცვლის რადიუსს) |
| რკალი | ცენტრი და ორივე ბოლო (ცვლის დაწყებისა და დასრულების ადგილს) |
| პოლიხაზი | ყოველი წვერო |
| ტექსტი, წერტილი, ბლოკის მითითება | ჩასმის წერტილი |
| ელიფსი | ცენტრი |
| ზომა | მისი განმსაზღვრელი წერტილები და ზომის ხაზის მდებარეობა |
| ხედის ფანჯარა | ცენტრი (გადააადგილებს) და ოთხი კუთხე (ზომას ცვლის) |

### მარკერის გადატანა

1. დახაზეთ ხაზი და დააწკაპუნეთ მასზე. გამოჩნდება სამი მარკერი.
2. დააწკაპუნეთ მარკერზე ერთ-ერთ ბოლოში. სტატუსის ზოლში წერია: „დააწკაპუნეთ იმ ადგილას, სადაც ეს მარკერი უნდა წავიდეს (გასაუქმებლად: Esc). მიბმა და ორტო მოქმედებს.“
3. გადაიტანეთ ჯვარედინი კურსორი. მის უკან გამოჩნდება წინასწარი ხედი.
4. დააწკაპუნეთ ახალ ადგილას, ან მიებით სხვა ობიექტზე არსებულ წერტილს და დააწკაპუნეთ.

ბოლო გადაადგილდება, ხოლო ხაზის დანარჩენი ნაწილი ადგილზე რჩება. ასევე შეგიძლიათ მარკერზე დააჭიროთ და გადაათრიოთ, შემდეგ კი გაუშვათ იქ, სადაც უნდა იყოს.

:::note
მარკერისთვის კოორდინატის აკრეფა შეუძლებელია. ზუსტი ადგილისთვის მიებით წერტილს, ან ჩაწერეთ მნიშვნელობა თვისებებში.
:::

მარკერის გადატანის გასაუქმებლად დააჭირეთ {{key:Esc}} ან დააწკაპუნეთ მარჯვენა ღილაკით.

## თვისებები

მარჯვენა პანელი აჩვენებს მონიშნული ობიექტის თვისებებს.

1. დააწკაპუნეთ ხაზზე. პანელის სათაური წერს „ხაზი“.
2. დააწკაპუნეთ ველზე {{ui:Length}}, ჩაწერეთ `2500` და დააჭირეთ {{key:Enter}}.

ხაზი ახლა ზუსტად 2500 სიგრძისაა და ინარჩუნებს თავის საწყის წერტილსა და კუთხეს. {{key:Enter}} ან სხვაგან დაწკაპუნება მნიშვნელობას იყენებს; {{key:Esc}} ძველ მნიშვნელობას აბრუნებს. ყოველი ცვლილება არის ერთი დაბრუნების ნაბიჯი, მაშინაც კი, როცა ბევრი ობიექტი ერთდროულად იცვლება.

ველები იღებენ გამოსახულებებს (`=2*45`) და სიგრძეებს ერთეულებით (`3'6"`, `900mm`), ყოველ წერტილს აქვს X, Y და Z, და რამდენიმე ობიექტი ერთად შეიძლება შეიცვალოს. ყველაფერი ამის შესახებ არის [თვისებების პანელში](topic:properties-panel).

## გავრცელებული შეცდომები

- **მარკერები არ ჩანს.** ბრძანება მუშაობს (დააჭირეთ {{key:Esc}}), ან მონიშნულია 200-ზე მეტი ობიექტი, ან ობიექტი ჩაკეტილ ფენაზეა.
- **მარკერი არასწორ ადგილას წავიდა.** მიბმამ დაიჭირა. დააწკაპუნეთ {{key:Shift}}-ის დაჭერით, რომ მიბმები უგულებელყოთ.
- **თვისებებში აკრეფამ არაფერი შეცვალა.** დააჭირეთ {{key:Enter}} ან დააწკაპუნეთ სხვაგან, რომ გამოიყენოთ. უარყოფილი მნიშვნელობა (ნულოვანი ან უარყოფითი სიგრძეები და რადიუსები, ტექსტი, რომელიც მნიშვნელობა არ არის) ველს წითლად ხდის და ამბობს მიზეზს.
- **აკრეფილი ასოები თვისებების ველში ჩაიწერა.** სანამ ველში კურსორია, კლავიშები იქ წერს. დააჭირეთ {{key:Enter}} ან {{key:Esc}}, შემდეგ ჩაწერეთ ბრძანება.
