Введіть коротке імʼя (псевдонім) і натисніть Enter або натисніть інструмент. Esc скасовує. Enter на порожньому рядку повторює останню команду.

**Надрукуйте її:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (одна сторінка A4; на папері Letter друкуйте з параметром «вмістити на сторінку»).

## Креслення

| Введіть | Команда | Що вона робить |
|---|---|---|
| `L` | {{cmd:LINE}} | Креслить прямі лінії |
| `PL` | {{cmd:PLINE}} | Креслить зʼєднаний ланцюжок ліній і дуг |
| `C` | {{cmd:CIRCLE}} | Креслить коло (центр і радіус) |
| `A` | {{cmd:ARC}} | Креслить дугу |
| `REC` | {{cmd:RECTANG}} | Креслить прямокутник за двома кутами |
| `POL` | {{cmd:POLYGON}} | Креслить правильний багатокутник |
| `EL` | {{cmd:ELLIPSE}} | Креслить еліпс |
| `DT` | {{cmd:TEXT}} | Пише один рядок тексту |
| `T` | {{cmd:MTEXT}} | Пише текст із переносом рядків (абзац) |
| `H` | {{cmd:HATCH}} | Заповнює область штрихуванням |

|---|---|---|
| `M` | {{cmd:MOVE}} | Переміщує обʼєкти |
| `CO` | {{cmd:COPY}} | Копіює обʼєкти |
| `RO` | {{cmd:ROTATE}} | Повертає обʼєкти навколо точки |
| `SC` | {{cmd:SCALE}} | Збільшує або зменшує обʼєкти |
| `MI` | {{cmd:MIRROR}} | Відображає обʼєкти відносно лінії |
| `O` | {{cmd:OFFSET}} | Креслить паралельну копію на відстані |
| `TR` | {{cmd:TRIM}} | Обрізає обʼєкти до місця, де їх перетинають інші |
| `EX` | {{cmd:EXTEND}} | Подовжує обʼєкти до інших |
| `F` | {{cmd:FILLET}} | Заокруглює кут дугою |
| `CHA` | {{cmd:CHAMFER}} | Зрізає кут прямою гранню |
| `E` | {{cmd:ERASE}} | Стирає обʼєкти |
| `X` | {{cmd:EXPLODE}} | Розбиває блок або полілінію на частини |
| `S` | {{cmd:STRETCH}} | Переміщує кінці всередині рамки перетину |
| `AR` | {{cmd:ARRAY}} | Копіює сіткою або по колу |
| `J` | {{cmd:JOIN}} | Обʼєднує лінії та дуги в один обʼєкт |
| `BR` | {{cmd:BREAK}} | Розрізає обʼєкт надвоє або вирізає частину |

## Розміри

| Введіть | Команда | Що вона робить |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Ставить розмір по горизонталі або вертикалі |

| `DRA` | {{cmd:DIMRADIUS}} | Ставить розмір радіуса |
| `DAN` | {{cmd:DIMANGULAR}} | Ставить розмір кута |

| Введіть | Команда | Що вона робить |
|---|---|---|

| `LI` | {{cmd:LIST}} | Показує подробиці обʼєкта |

## Файл

| Введіть | Команда | Що вона робить |
|---|---|---|
| `U` | {{cmd:UNDO}} | Скасовує останню команду |
| `SAVE` | {{cmd:SAVE}} | Зберігає креслення |
| `PLOT` | {{cmd:PLOT}} | Друкує в PDF |

## Клавіші

Ctrl (Cmd на Mac): Z скасувати дію · Y повторити дію · S зберегти · P друк.  F3 привʼязка до обʼєктів · F8 орто · F10 полярне.  Space або Enter повторює останню команду · колесо змінює масштаб · перетягування колесом зсуває вид
