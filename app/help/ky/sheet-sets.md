## Бул жерде үйрөнөсүз

Бир нече чийме файлынан барактарды (макеттерди) **барак топтомуна** кантип чогултуу, номерлөө жана аталыштыруу, титул блоктору топтомдон автоматтык түрдө толтурулушу, бүт топтомду бир PDF катары жарыялоо жана бардыгын жөнөтүү үчүн бир zip кылып таңгактоо.

Барак топтому өз кичине файлында, `<name>.ccsheets` деген ат менен, чиймелер турган папкада жашайт. Топтом файлы барактарды папкадан салыштырмалуу жолдор менен тизет, ошондуктан бүт папканы жылдыра же көчүрө аласыз.

:::note
Папканы окуу жана жазуу үчүн Chrome же Edge керек (алар тандалган папкада иштөөгө уруксат бере алат), же иш үстүндөгү колдонмо. Башка браузерлер топтомду окуу гана режиминде ачат: аны карап, жарыялай аласыз, ал эми топтом файлы сакталбай, жүктөлөт.
:::

## Топтом түзүү

1. Сол панелдеги {{ui:Sheet set}} бөлүмүн таап, анын {{ui:Set}} менюсун ачыңыз. {{cmd:SHEETSET}} (же `SSM`) териү дагы сизди ошол жерге алып барат.
2. {{ui:New set…}} тандаңыз. Топтомго ат коюңуз, кааласа долбоордун атын жана номерин кошуңуз.
3. Чиймелер турган папканы тандаңыз. Топтом файлы ошол жерге сакталат.

Топтомду кийинчерээк ачуу үчүн {{ui:Open set…}} тандап, ошол папканы тандаңыз. Папкада бир нече топтом болсо, CadCraft кайсынысын сурайт.

## Барактарды кошуу

1. {{ui:Add sheets from a drawing…}} тандап, папкадагы чиймелердин бирин тандаңыз.
2. CadCraft ал чиймени фонда окуйт (экранда ачылбайт) жана анын барактарын тизет. Керектүүлөрүн белгилеп, {{ui:OK}} басыңыз.
3. Баракты тандап, F2 басыңыз (же {{ui:Rename and renumber…}}), ага номер жана аталыш бериңиз, мисалы `A-101` жана `Кабаттын планы`.

{{ui:New sheet from template…}} башка чиймедеги барактан жаңы чийме жасайт (анын титул блогу жана көрүнүш терезелери), жаңы барактын атынан аталып, аны кошот. Топтом үлгү катары колдонгон чиймесин эстеп калат.

## Топтомду тартипке келтирүү

- **Ички топтомдор** барактарды топтойт, мисалы Архитектура › Пландар: барактар барууга тийиш жерди тандап, {{ui:New subset…}} тандаңыз.
- **Тартип**: баракты сүйрөп тизменин башка жерине же ички топтомго таштаңыз. Клавиатура менен барак тандап, {{key:Alt+Up}} же {{key:Alt+Down}} басыңыз.
- **Баракты ачуу**: эки жолу басыңыз (же {{key:Enter}}). Анын чиймеси өз өтмөгүндө, ошол барakta ачылат.
- **Алып салуу**: тандап, {{key:Delete}} басыңыз. Чийменин өзү өзгөрбөйт.
- **Артка кайтаруу**: {{ui:Undo set change}} жана {{ui:Redo set change}} топтомдо өзгөрткөн нерсеңизди кадам-кадам көрөт.
- **Кайра номерлөө**: {{ui:Renumber sheets…}} бардык барактарга же бир ички топтомдун барактарына, тизменин тартиби менен номер берет: префикс, башталыш жана кадам (`A-` жана `101` A-101, A-102 … берет).

Бардык өзгөртүү топтом файлында дароо сакталат.

## Номерлерди талааларынан коюу

Номерлерди колдон коюунун ордуна, эреже ар бир номерди баракчанын талааларынан түзсүн, ошондо баракты башка деңгээлге же дисциплинага өткөрсөңүз, ал жаңы номерди өзү алат.

1. Ар бир баракка талааларын бериңиз: тандап, {{ui:Атын өзгөртүү…}} басыңыз жана {{ui:Бул барактын талаалары}} талаасына, ар бир сапка бирден жазыңыз, мисалы `DISCIPLINE = A` жана `LEVEL = 1`. Бүт топтомго бирдей талаа (мисалы, `DISCIPLINE = A`) топтомдун {{ui:Касиеттер…}} бөлүмүнө коюлушу мүмкүн.
2. Панелдин менюсун ачып, {{ui:Нөмүрлөө эрежеси…}} басыңыз.
3. Эрежени жазыңыз, мисалы `{DISCIPLINE}-{LEVEL}{SEQ:2}`. `{SEQ}` башка талаалары бирдей окулган барактардын арасында эсептейт, ошондуктан 1-деңгээл A-101, A-102 алат, ал эми 2-деңгээл A-201 менен башынан баштайт. `{SEQ:2}` аны эки орундуу жазат; `{SUBSET}` барак кайсы ички топтомдо турганынын аты.
4. Талаа өзгөргөндө эмне болорун тандаңыз: {{ui:Барактарды кайра нөмүрлөө}} ар бир өзгөрүүдөн кийин эрежени сактайт; башка тандоо номерлерди бир жолу, азыр коёт.

Эреже топтом файлында сакталат. Өзү номерлеп жатканда баракчанын номерин эмес, талааларын өзгөртүңүз.

## Титул блоктору топтомдон толтуруу

Титул блогунун текстин топтом берет, эгерде анын атрибуттары талаанын аты менен белгиленсе:

| Тег | Эмнени көрсөтөт |
|---|---|
| `SHEETNUMBER` (же `SHEET_NO`, `DWG_NO`) | Баракчанын номери |
| `SHEETTITLE` (же `TITLE`, `SHEET_TITLE`) | Баракчанын аталышы |
| `SHEETDESC` | Баракчанын сүрөттөмөсү |
| `PROJECTNAME` (же `PROJECT`) | Долбоордун аты |
| `PROJECTNUMBER` (же `PROJECT_NO`, `JOB_NO`) | Долбоордун номери |
| `SHEETSETNAME` | Топтомдун аты |
| `SHEETINDEX`, `SHEETCOUNT` | `3 / 12`, жана 12 |
| Өзүңүздүкү, мисалы `CLIENT` | {{ui:Талааларды толтуруу…}} ичине ага жазганыңыз |

{{ui:Талааларды толтуруу…}} долбоордун атын жана номерин жана өз талааларыңызды `АТЫ = маани` түрүндө, ар бир сапка бирден камтыйт.

{{ui:Update drawings}} топтомдогу ар бир чиймедеги титул блокторуна номерлерди, аталыштарды жана талааларды жазат, ал эми ар бир барактын макет өтмөгүн топтом айткандай кайра аталыштырат (демейки боюнча номер жана аталыш, мисалы `A-101 Кабаттын планы`; {{ui:Талааларды толтуруу…}} › {{ui:План өтмөктөрүнүн аттары}} муну өзгөртөт). Ар бир чийме өз жеринде, өз форматында жана версиясында сакталат. Номерлерди же аттарды өзгөрткөндөн кийин, аны кайра иштетиңиз: өтмөктөр жана титул блоктору артынан ээрчийт.

## Мукаба барагындагы барактар тизмеси

Мукаба барагын тизмеден тандап, {{ui:Барактар тизмесин бул баракка коюу}} тандаңыз. Ар бир баракчанын тизмеси (номер жана аталыш, ички топтом астында) баракчанын жогорку сол бурчуна коюлат. {{ui:Update drawings}} жана {{ui:Publish to PDF}} аны жаңыртып турат. Бул бир блок, `CC_SHEETLIST`: аны башка блок шилтемесидей жылдырыңыз.

## Топтомду жарыялоо

{{ui:Publish to PDF}} бир PDF жасайт: ар бир барак үчүн бир бет, топтомдун тартибинде, ар бир баракчанын өз кагаз өлчөмүндө, ар бир барак үчүн китептин белгиси менен («A-101 — Кабаттын планы»). Ички топтом тандалса, CadCraft ошол ички топтомду гана жарыялайбы деп сурайт. PDF'тердеги титул блоктору чиймелерди жаңыртмай туруп эле топтомдон толтурулат; жарыялоо чиймелерди өзгөртпөйт. PDF жүктөлөт.

{{ui:Publish to DWG…}} ар бир баракты өз DWG файлы катары жазат (DWG 2018): модель жана ошол бир барак, титул блогу топтомдон толтурулган, номери жана аталышы менен аталган (`A-101 Level 1 floor plan.dwg`). {{ui:DWG}} же {{ui:DWG + PDF}} тандаңыз, топтомдун PDF'и алардын янында. `publish.json` ар бир файлды өлчөмү жана SHA-256 менен тизет. Топтомдун папкасына жазууга болсо (CadCraft Studio же браузерде тандалган папка), файлдар `<топтомдун аты> - published` папкасына түшөт; болбосо бир zip катары жүктөлөт. Көрүнүш терезелеринин [класс боюнча өзгөртүүлөрү](topic:viewport-overrides) ар бир DWG'га кошула келет.

## Топтомду архивдөө

{{ui:Archive as a zip}} топтом файлын, ал колдонгон ар бир чийменин жана ошол чиймелер шилтеме кылган нерселердин (шилтемеленген чиймелер, алардын шилтемелери да жана сүрөттөр) баарын папкаларын сактап таңгактайт, ошондой эле ар бир файлды тизген `Transmittal.txt` кошот. Топтом папкасынан тышкары шилтеме жолу жок деп ошол жерде тизилет. Шилтемелер чиймеден жолу боюнча, андан кийин файлдын аты боюнча папкадан издеп табылат.

## Топтом файлы

`.ccsheets` файлы каалаган текст редакторунда окула турган JSON:

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

Жолдор топтомдун папкасына салыштырмалуу, папкалар арасында `/` белгиси менен. CadCraft аны ачканда текшерет: абсолюттук жол, файлы же макети жок барак, же жөнөкөй эмес текст чыгарылат, жана тарых ушуну айтат.

| «Бул папка бул жерде окуу гана» | Браузер папкага жаза албайт | Chrome же Edge колдонуңуз, же иш үстүндөгү колдонмо; ошол арада {{ui:Download the set file}} өзгөртүүлөрүңүздү сактайт |
