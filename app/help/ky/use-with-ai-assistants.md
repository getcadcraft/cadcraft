## Эмнени үйрөнөсүз

AI ассистент (же сиз жазган скрипт) чиймеге кароосун, CadCraft буйруктарын иштетүүсүн, басып чыгарып жана сактоосун кантип жасоо керектигин жана эмнеге тийе аларын кантип чечүү керектигин үйрөнөсүз.

CadCraft'та **өз AI жок** жана эч нерсе эч жерге жөнөтпөйт. Ассистентти өзүңүз алып келесиз: Model Context Protocol (MCP) тилин түшүнгөн каалаган программа. CadCraft аны куралдар менен гана камсыздайт, ал эми кайсыларын берүү керектигин өзүңүз тандайсыз.

Кирүүнүн эки жолу бар:

- **Ачык турган чийме.** Ассистент ушул терезеде, сиздин жаныңызда, сиздин компьютериңиздеги CadCraft Studio аркылуу иштейт. Ал үчүн {{ui:Жөндөөлөр}} › {{ui:CadCraft}} › {{ui:Ассистенттер}} бар.
- **Компьютериңиздеги чиймелер, колдонмону ачпастан.** CadCraft MCP сервери жана `cadcraft` буйрук сабы сиз аткан папкалардагы DWG жана DXF файлдарын окуйт жана жазат. Төмөндөгү "Файлдар менен CadCraft'ты ачпастан иштөө" бөлүмүн караңыз.

## Күйгүзүү

1. {{ui:Жөндөөлөр}} ачыңыз (колдонмонун үстүнкү панелиндеги тиш белгиси, же {{key:Mod+,}}) жана {{ui:CadCraft}} өтмөгүнө өтүңүз.
2. {{ui:Ассистенттер}} астында **Ассистенттерге жана скрипттерге CadCraft'ты колдонууга уруксат берүү** белгисин коюңуз. Сиз муну кылмайынча ал өчүк турат.
3. Ал эмнени кыла аларын тандаңыз. **Read** башында белгilenген; башкаларын гана керек болгондо белгилеңиз.

| Уруксат | Ассистент эмне кыла алат |
|---|---|
| Read | Чиймеге кароо: сүрөттөө, объекттерди тизмелөө жана табуу, тандоону көрүү, көрүнүштү сүрөттөп анын сүрөтүн тартуу, катмар жана чийүү эрежелери боюнча текшерүү |
| Edit | Чиймеде буйруктарды иштетүү жана тандоону өзгөртүү. Ар бир аракет сиз артка кайтара ала турган бир кадам |
| Save | Чиймени сактоо (иш үстөлүндө — өз файлына; браузерде — жүктөлүп алынган файл катары) |
| Export | PDF файлга басып чыгаруу жана башка файлдарды жасоо |

## Сиз тандаган папкалардагы файлдарды колдонууга уруксат берүү

CadCraft Studio'до ассистент файлдарды файл диалогдорун колдонбостон, аты боюнча ача, сактай жана басып чыгара алат, бирок ал сиз {{ui:Ассистенттер}} астындагы {{ui:Колдоно ала турган папкалар}} бөлүмүнө кошкон папкалардын ичинде гана:

1. {{ui:Папка кошуу…}} тандап, папканы Studio'нун өз диалогунда тандаңыз.
2. Ассистент ошол папкадагы файлдарды тизмелей алат (`files_list`), чиймени ача алат (`drawing_open`), аны ошол жерге DWG версиясында же DXF катары сактай алат, PDF же SVG файлына басып чыгара алат, LISP файлын жүктөй алат, жана буйрукка керектүү файлды бере алат (`INSERT` `F`, `XATTACH`, чекиттер файлы), же буйруктун файлы кайда барарын айта алат (`COUNT`'тун CSV'си, `PUBLISH`).
3. {{ui:Алып салуу}} папканы дароо кайтарып алат. Башка жерлердеги жолдор четке кагылат, ал эми бар файл ассистент ошону сурагандыктан же ал файлды өзү жазгандыктан гана алмаштырылат.

Ачуу үчүн дагы **Read** керек; чиймени жазуу үчүн **Save** керек; башка ар кандай файл үчүн **Export** керек.

Сиз белгилеген уруксаттардан тышкары куралдар ассистентке таптакыр көрсөтүлбөйт, ал эми ал барабар сурап калса, CadCraft аны четке кагып, иш-аракеттердин журналына жазат. Тумблерди өчүрсөңүз, бардык туташуулар бир заматта үзүлөт. {{ui:CadCraft жөндөөлөрүн баштапкы абалга келтирүү}} да аны өчүрөт.

## Ассистентиңизди туташтыруу

Ассистенттер сиздин компьютериңиздеги **CadCraft Studio** аркылуу туташат: ал бул компьютер гана жете ала турган кичине сервер иштетет (дареги `127.0.0.1`), ал Studio ар бир ишке киргенде жараткан токен менен корголот. Studio'ну ачып, {{ui:Ассистентти туташтыруу}} тандаңыз жана даректи менен токенди көчүрүңүз.

- Ассистентиңизге HTTP түрүндөгү MCP сервери кошуңуз: дареги (ал `http://127.0.0.1:47615/mcp` сыяктуу көрүнөт) жана `Authorization: Bearer <token>` тилкеси менен. Studio киргизүү үчүн керектүү жөндөөлөрдү көрсөтөт.

Studio'дагы {{ui:Жаңы токен}} бардык туташкан ассистенттерди жаңы токен менен кайра туташтырат. Токенди эч качан бөлүшпөңүз: аны билген ар ким Studio иштеп turганда сиз күйгүзгөн колдонмолорду колдоно алат.

:::note
Браузер барагы ассистент үчүн туташуу ача албайт: браузердеги колдонмолордо тумблердин эч кандай таасири жок, сиз компьютериңиздеги CadCraft Studio'ну колдонмоюнча.
:::

## Сиз башкаруудасыз

- **Ар бир аракет — бир артка кайтаруу кадамы**, ассистенттин аты менен белгиленет, мисалы "Assistant: LINE". Ассистенттин акыркы аракетин толугу менен кайтаруу үчүн {{key:Mod+Z}} басыңыз.
- **Анын эмне кылып жатканын көрөсүз.** Анын буйруктары буйруктар тарыхында алдына **[Assistant]** коюлуп чыгат, ал иштеп жаткан сайын чийме кайра тартылат.
- **Ал сизди күтөт.** Сиз буйрук аткарып жатканда ассистент окуй алат, бирок чиймени өзгөртө албайт; ал бүткөндөн кийин кайра аракет кылууга айтылат.
- **Туташканын билесиз.** Колдонмонун үстүнкү панелиндеги баскыч туташып турганда ассистенттин атын көрсөтөт. Аны басып, ал эмне кыла аларын көрүңүз же **Ажыратуу** үчүн.
- **Иш-аракеттер.** {{ui:Жөндөөлөр}} › {{ui:CadCraft}} › {{ui:Ассистенттер}} › {{ui:Иш-аракеттер}} ар бир чакырууну тизмелейт: качан, кайсы курал, аткарылдыбы же четке кагылдыбы жана ал жасаган артка кайтаруу кадамы. {{ui:Журналды сактоо}} анын көчүрмөсүн сактайт.

## Ассистент эмнени сурай алат

| Курал | Уруксат | Эмне кылат |
|---|---|---|
| `app_info`, `drawing_describe`, `view_describe` | Read | Чийменин аты, бирдиктери, катмарлары, блоктору, барактары; экранда эмне бар |
| `files_list`, `drawing_open` | Read | Studio: папкаларыңыздагы файлдар; бирөөн бул терезеде ачуу |
| `objects_list`, `object_get`, `selection_get` | Read | Объекттер геометриясы, узундугу жана аянты менен (же түрү жана катмары боюнча саны гана); тандоо |
| `drawing_check` | Read | Эрежелер: уруксат берилген катмарлар, 0-катмарда эч нерсе жок, ByLayer түстөр, текст бийиктиктери |
| `view_screenshot` | Read | Чиймени көрүнгөндөй сүрөт |
| `command_run` | Edit | Буйрук сабына терет: `LINE 0,0 @100,0 @0,50 ` сиз терген сыяктуу окулат (боштук жооп бүтүрөт), же ар бирине бир жооп берилген тизме. Буйругун ачык калтырып, кийинки чакырууда улантышы мүмкүн |
| `script_run` | Edit | Скрипт (`.scr`) же LISP файлы, {{ui:APPLOAD}} жүктөгөндөй |
| `block_insert` | Edit | Блокту анын атрибут маанилери менен бир кадамда коёт |
| `selection_set`, `undo` | Edit | Кийинки буйрук үчүн объекттерди тандайт; өз кадамдарын артка кайтарат |
| `drawing_save` | Save | CadCraft'тын өз {{ui:Сактоо}}, же сиздин папкаларыңыздын бирине {{ui:Башкача сактоо}} |
| `drawing_plot` | Export | Барактын же модель PDF же SVG файлы, масштабда же тууралоо менен (PDF астындагылар азырынча ушундай басылбайт) |

Ассистент буйрук аткарганда, CadCraft суроолорун диалогдун ордуна буйрук сабында берет (мисалы, бүт чиймени же бир блокту киргизүүнү), ошондуктан ассистент аларга жооп бере алат. {{ui:Китепкана}} жана {{ui:Табуу}} дагы сизге керек; ассистентке сизден сурооно айтылат.

## Файлдар менен CadCraft'ты ачпастан иштөө

CadCraft MCP сервери (`cadcraft-mcp`) жана буйрук сабы (`cadcraft`) CadCraft'тын өз чийме кодун терезесиз, Node.js'те иштетет. Node.js 20 же андан жаңы версиясы керек.

- **MCP сервери** сиз атаган папкалардын ичинде гана жана сиз берген уруксаттар менен гана иштейт: `npx @getcadcraft/mcp --root ~/Drawings --allow read,edit`. `--root` жок болсо, ал эч бир файлды ача албайт; `--allow` жок болсо, ал окуй гана алат. Ал IFC моделдерин, көлөмдөрдү эсептөөнү жана PDF топтомдорундагы белгилөөлөрдү да окуй алат.
- **Буйрук сабы** — сиздин жеке скрипттериңиз үчүн: `cadcraft info plan.dwg`, `cadcraft run cleanup.scr plan.dwg -o plan-clean.dwg`, `cadcraft convert plan.dwg plan.dxf`, `cadcraft plot plan.dwg plan.pdf --all`, `cadcraft plot plan.dwg plan.svg`, `cadcraft check plan.dwg --rules rules.json`. Бир нече файл бир жолу: `cadcraft convert *.dwg out --to dxf`, `cadcraft plot *.dwg pdfs --to pdf`, `cadcraft check *.dwg --rules rules.json`. Программа окуй ала турган чыгарылыш үчүн `--json` кошуңуз.

:::note
Эгер `npx @getcadcraft/mcp` пакетти таппады деп жазса, ал али жарыяланган эмес. getcadcraft.com сайтындагы жаңылыктар буга байланыштуу кабарлайт.
:::

## Эгер бир нерсе иштебесе

- **Ассистент CadCraft куралдарын көрбөйт:** тумблер бул терезеде күйүк экенин жана терезе Studio'до ачык экенин текшериңиз.
- **"needs the edit permission":** {{ui:Ассистенттер}} астында **Edit** белгилеңиз, андан кийин кайра сураңыз.
- **"outside the folders assistants may use":** ошол папканы {{ui:Ассистенттер}} › {{ui:Колдоно ала турган папкалар}} астына кошуңуз же ассистентке сиз буга чейин кошкон папкадагы файлды колдонушун айтыңыз.
- **"401" же "token" каталары:** токен өзгөрдү (Studio кайра иштетилди же {{ui:Жаңы токен}}). Жаңы токенди ассистенттин жөндөөлөрүнө көчүрүңүз.
- **Анын өзгөртүүсү туура эмес болду:** {{key:Mod+Z}} басыңыз. Бир басуу ассистенттин бир толук аракетин кайтарат.
