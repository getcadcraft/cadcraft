Эки киши бир чийменин өзгөртөт. Алар ар башка объекттерди өзгөрткөн болсо, бириктирүү автоматтык болот: кол менен кайра жасоонун кереги жок.

## Бул эмнеге жетишет

CadCraft сиз тарткан ар бир объектке кыска **ачкыч** берет, ал эч качан өзгөрбөйт жана эч качан эки объектке берилбейт. Ал DWG же DXF файлында объект менен бирге сакталат (башка программалар сактаган кошумча маалымат катары). Бириктирүү объекттерди файлдагы орду боюнча эмес, ачкыч боюнча издейт, анткени ар бир программа сактаганда орундарды кайра номерлейт. Эч качан бириктирбесеңиз, муну {{ui:Жөндөөлөр}} › CadCraft › Бириктирүүгө ыңгайлуу файлдар бөлүмүндө өчүрүңүз; файлдар болжол менен 10 пайызга кичирейет.

Ачкычтар пайда болгонго чейин сакталган чийме дагы бириктирилет: анын объекттери файлдагы ордунан ачкыч алат, аны ачкан ар бир адамга бирдей.

## Орнотуу

Git үчүн ар бир репозиторий үчүн бир жолу эки сап керек:

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git жок болсо, аны кол менен иштетиңиз: `cadcraft merge <base> <ours> <theirs> -o <result>`. Fossil жана Mercurial ошол үч файлды өздөрүнүн бириктирүү куралынын жөндөөсүндө дал ушундай алышат.

## Эрежелер

- Бир тарапта гана өзгөртүлгөн объект алынат. Эки тарапта бирдей өзгөртүү бир жолу алынат.
- Бир касиет эки жол менен өзгөртүлсө, бул **карама-каршылык**: сиздин тарап калат жана отчётта эки маани тең тизмеленет. Натыйжаны ачып, ал объектти караңыз жана кол менен оңдоңуз.
- Кайсы бир тарапта кошулган объект сакталат. Бир тарапта өчүрүлгөн, экинчисинде өзгөртүлбөгөн объект өчүрүлөт. Бир тарапта өчүрүлүп, экинчисинде өзгөртүлгөн: өчүрүлөт жана отчётто айтылат.
- Катмарлар, блоктор, текст жана өлчөм стилдери, барактар жана аталган көрүнүштөр ушундай эле жол менен бириктирилет. Чектөөлөр алар аталган объекттерди ээрчийт.
- Натыйжа сиздикиндей файл форматында жана версияда жазылат.

Бириктирилбейт: объекттердин тартылуу тартиби сиздики болуп калат, андан кийин экинчи тарап кошкон объекттер. Эки тараптагы бир эле блок аныктамасына өзгөртүүлөр карама-каршылык болот, эч качан аралаштырылбайт. Эч нерсе жүктөлүп жиберилбейт; бардыгы сиздин компьютериңизде иштейт.
