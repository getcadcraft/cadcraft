CadCraft иштеп жатат. Бул бетте учурдагы версия эмнени аткарбай турганы көрсөтүлгөн, ошондуктан аны издеп убара болбойсуз. Ар бир пункт бүгүн эмне кылуу керектигин түшүндүрөт.

## Файлдар жана сактоо

| Азырынча жасалган эмес | Ордуна, бүгүн |
|---|---|
| CadCraft менен сакталган DWG файлын AutoCAD программасынын өзүндө текшерүү | Сакталган ар бир версия үч башка программанын DWG окургучу жана CadCraft тарабынан кайра окулат. Караңыз: [DWG эмнени сактайт жана эмнени өзгөртөт](topic:files#what-a-dwg-keeps-and-changes). |
| 2000-версиядан кийинки DXF сактоо | DXF 2000 катары сактаңыз, же DWG катары AutoCAD 2018 версиясына чейин сактаңыз. |
| Браузерде ачылган файлдын үстүнөн сактоо | Ар бир сактоо жаңы көчүрмөнү жүктөйт; кааласаңыз, эски файлды өзүңүз алмаштырыңыз. CadCraft Studio программасында {{key:Mod+S}} ачылган файлга кайра жазат. |
| Bulut сактоо жана компьютерлердин ортосундагы синхрондоштуруу | CadCraft сактоолорун азырынча булутка жөнөтпөйт: DWG жана DXF файлдарын өз папкаңызда сактаңыз. CadCraft Studio программасында [Тарых](topic:history) башка жерден сакталган чиймөнүн булуттагы версияларын жана бул компьютердеги өз сактоолоруңуздун көчүрмөлөрүн көрсөтөт. |
| Калкалар жана шилтеме чиймени ордунда түзөтүү | Чиймени шилтеме катары тиркеңиз жана экинчи чиймени өзгөрткөндөн кийин кайра жүктөңүз. Шилтеме DWG катары сакталганда шилтеме бойдон калат, а {{cmd:XCLIP}} аны кесет. |
| DXF'теги сүрөттөр; артындагысын жашыруучу тазалоо аймактары | DXF сүрөттү анын аталышы менен чиркин катары сактайт; DWG аны сүрөт катары сактайт. Караңыз: [Чиймедеги сүрөттөр](topic:pictures). Тазалоо аймагы өзүнүн чиркини катары көрүнөт. |
| Ийри жетектүү көп жетектүү белгилерди түзөтүү, жетектердин эки жагына чыгып турган көп жетектүү белгилер же туура эмес бурулган же туура эмес масштабдалган блок менен көп жетектүү белгилер | Алар башка программа тартканындай тартылат жана бир бүтүн катары жылат. Түз жетектүү жана бир гана жерге чыккан көп жетектүү белгилер, ошондой эле мазмун катары текст же блок түзөтүүгө болот ({{cmd:MLEADEREDIT}}). |
| Башка программалардын таблицаларында: блок камтыган уяча, уячанын ичиндеги текст форматы, DXF таблицасынын уячалык чектери жана түстөрү, мамычаларга бөлүнгөн таблица | Таблица түзөтүлүүчү таблица катары ачылат ({{cmd:TABLEDIT}}) жана түзөтмөйүнчө башка программа тарткандай көрсөтүлөт; андан кийин CadCraft аны уячаларынан кайра тартат: жөнөкөй текст, `=G3*H3` жана `=Sum(I3:I9)` сыяктуу формулалар, тегиздөө жана текст бийиктиктери. Блок уячасы андан кийин бош болот. Түзөтүлбөгөн DWG таблицасы келген уячалык маалымат менен кайра сакталат. |
| Сакталган DXF'те реалдуу таблица объектиси | DWG таблицаны башка программалар түзөтө ала турган таблица катары сактайт. DXF аны тартуучу блок катары жана CadCraft'тын өз жазуусу менен сактайт: CadCraft аны кайра таблица катары ачат; башка программалар блокту гана көрөт. Айнектелген же туура эмес масштабдалган таблица DWG'де да ушундай сакталат. |
| Башка программалар менен көчүрүү жана чаптоо | CadCraft'тын буфери бир эле браузердеги CadCraft чиймөлөрүнүн жана өтмөктөрүнүн ортосунда иштейт, башка программалар менен эмес. DWG же DXF катары сактап, ал жерде ачыңыз. Караңыз: [Көчүрүү, чаптоо жана көбөйтүү](topic:copy-paste). |

## Чиймелөө жана түзөтүү

| Азырынча жасалган эмес | Ордуна, бүгүн |
|---|---|
| CadCraft'та жок штриховка үлгүлөрү жана башка программалар тартканындай так градиенттүү толтуруулар | Ачылган штриховкалардын CadCraft'та жок үлгүлөрү тон катары көрүнөт. Градиенттүү толтуруу ({{cmd:GRADIENT}}) ар бир түр үчүн CadCraft'тын өз жолу менен тартылат: түрү боюнча башка программаларга окшош, бирок чекит-чекит так эмес. DWG 2004 жана андан кийинки версияларда аны реалдуу градиенттүү штриховка катары сактайт; DXF 2000 же DWG 2000 файлында аны CadCraft гана кайра окуйт, ал эми башка программалар катуу толтурууну көрөт. Үлгүлөр `.pat` файлынан жүктөлөт, ал эми штриховканы анын контуруна байланыштырып, ошол контур менен кошо жылдырууга болот. Караңыз: [Штриховка жана толтуруу аймактары](topic:hatch). |
| Ичинде фигуралар же текст бар сызык түрлөрү жана сакталган DXF R12'де сызык калыңдыктары | Файлдын сызык түрүндөгү фигуралар жана текст сызыктарынан чыгарылып калат; сызык калыңдыгын сактоо үчүн DWG катары сактаңыз. |
| Сакталган DXF'те үлгүлүү штриховкалар | R12'де штриховка жок: алар контуру катары сакталат. Үлгүнү сактоо үчүн DWG катары сактаңыз. |
| Башка программа түзгөн же түзөтө ала турган массивдер; жол жана полярдык массивдердеги катарлар жана кабаттар; жолдун ийри сызыгын ээрчиген массив | {{cmd:ARRAY}} жана {{cmd:ARRAYPATH}} менен ассоциативдүү түзүлгөн массив ({{cmd:ARRAYEDIT}} менен өзгөртүлөт) CadCraft'тын өз сандары менен блок шилтемеси катары сакталат: башка программалар аны көрсөтөт, жылдырат, басып чыгарат жана жарат, бирок анын санын өзгөртө алышпайт; башка программада түзүлгөн массив бул жерде жөнөкөй блок шилтемеси катары ачылат. Жол массиви жолдун көчүрмөсүн сактайт: кийин ийри сызыкты түзөтсөңүз, элементтер жылышпайт. |
| Башка программалар менен алмашылган кесилген барак көрүнүш терезелери | {{cmd:VPCLIP}} менен кесилген же {{cmd:MVIEW}} Polygonal же Object менен түзүлгөн көрүнүш терезеси өзүнүн CadCraft контуру менен сакталат: башка программалар аны айланасындагы тик бурчтук катары ачат, ал эми башка программада кесилген көрүнүш терезеси бул жерде өзүнүн тик бурчтугу катары ачылат. DXF R12 тик бурчтукту гана сактайт. |
| Кесилүүчү көп бурчтук менен {{cmd:STRETCH}} | Бир же бир нече кесилүүчү терезе колдонуңуз. |
| {{cmd:PEDIT}} Edit vertex (буйрук сабында бир учурда бир чокуу) | Туткалар жана Касиеттердеги чокуулар таблицасы (ар бир чокуу, анын туурасы жана бүктөлүшү). PEDIT'тин калган бөлүгү курулган: караңыз: [Сплайндар жана полисызыктар](topic:splines). |
| Эллипстердеги жана сплайндардагы {{cmd:BREAK}}, {{cmd:LENGTHEN}}, {{cmd:OFFSET}}, {{cmd:TRIM}}, {{cmd:EXTEND}}, {{cmd:FILLET}} жана {{cmd:JOIN}} | Бул буйруктар кабыл ала турган полисызыкты алуу үчүн сплайнды {{cmd:EXPLODE}} кылыңыз (же {{cmd:PEDIT}} менен иштетиңиз). |
| Полисызыктын аркасы менен анын жанындагы кесинди ортосундагы оймо жана фаска; сызыкты полисызыкка кошкон оймо | Полисызыкты {{cmd:EXPLODE}} кылыңыз, андан кийин бөлүктөрүнө оймо салыңыз. Оймо аркасы өз алдынча объект катары кошулат. |
| Кыркуу жана узартуу: Project опциясы (3D) жана полисызыктын аркасынын учун узартуу | Чиймөнүн тегиздигинде кыркыңыз; аркасынын учу үчүн полисызыкты жарып салыңыз же аркасын кайра тартыңыз. |
| OLE объекттери: киргизүү, иштетүү же түзөтүү; DWG файлында алар кайда койгондо көрсөтүү; метафайл сүрөттөрү | Караңыз: [Сүрөттөр](topic:pictures#objects-from-other-programs-ole). DXF объекттери өздөрүнүн растры же белгиленген чырак катары көрүнөт; DWG объекттери сакталат, бирок ордунда тартылбайт ({{cmd:OLELIST}} аларды тизмелейт жана сүрөттүн көчүрмөсүн сиз көрсөткөн жерге коет). |
| Абзац тексттеги форматтоо кодторун (калың, катмарлуу бөлчөктөр, сөзү сайын түстөр) терүү; Helvetica сымал шрифттен башка шрифттер; мамычалар | Файлда келген форматтоо сакталат, тартылат жана сакталат (караңыз: Текст); жаңы абзац тексттин бир бийиктиги жана бир түсү болот. |
| Бурчу менен түзөтүлгөн абзац тексти | Редактор текстти тегиз ачат; текст өзүнүн бурчун сактайт. |
| DXF'те көп жетектүү белгилер көп жетектүү белги объекттери катары сакталат | DWG аларды көп жетектүү белгилер катары сактайт, ар бир жетек сызыгы жана мазмун катары блок менен; DXF алар тарткан нерсени (сызыктар, жебелер жана текст же блок) сактайт. |
