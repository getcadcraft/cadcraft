## Бардык өлчөмдөр үчүн бир таблица

{{ui:Параметрлер}} панели ({{ui:Параметрдик}} тобундагы {{ui:Параметрлер}} баскычы, же {{cmd:PARAMETERS}} териңиз) ар бир өлчөмдүк чектөөнү (`d1`, `rad1`, `dia1`, `ang1`, же сиз берген ат) жана өз параметрлериңизди бир жерде тизет. Ар бир ат каалаган туюнтмада колдонулат.

Ар бир катарда:

- **Ат**: жаңы ат териңиз, аны өзгөртүү үчүн; ага туш келген ар бир туюнтма жаңыланат.
- **Туюнтма**: сан (`40`) же туюнтма (`width / 2 + gap`). Териңиз жана {{key:Enter}} басыңыз: чийме ээрчийт.
- **Маани**: ал эмнеге барабар. Туюнтма айдаган катарда маанини сан менен да терсеңиз болот: CadCraft артындагы параметрди эсептейт. `d1 = width / 2` болсо, d1дин маанисине `30` терүү `width` дегенди 60ка коёт.

Эки параметр маанини айдаганда (`width / 2 + gap`), диалог кайсысын өзгөртүү керектигин сурайт. Ар бир өзгөртүү бир артка кайтаруу кадамы ({{key:Mod+Z}}).

## Өзүңүздүкүн кошуңуз

1. {{ui:Параметрлер}} панелин ачыңыз.
2. Ат (`gap`) жана маани (`10`) териңиз, андан кийин {{ui:Кошуу}} басыңыз.
3. Колдонуңуз: d1дин туюнтмасында `width / 2 + gap` териңиз жана {{key:Enter}} басыңыз.

Аттар тамга же `_` менен башталат жана тамгалар, цифралар жана `_` камтыйт. Функция аттары, `pi` жана бирдик аттары ат боло албайт.

## Туюнтмалар

| Жазуу | Билдирет |
|---|---|
| `+ - * / ^ %` | кошуу, кемитүү, көбөйтүү, бөлүү, даража, калдык |
| `( )` | топтоо |
| `sin cos tan asin acos atan atan2` | градустагы тригонометрия |
| `sqrt pow exp ln log abs sign` | тамырлар, даражалар, логарифмдер |
| `ceil floor int round min max` | тегеректөө жана чектер |
| `if(a > b, x, y)` | тандоо |
| `pi` | 3.14159… |

Сандар бирдикти алып жүрүшү мүмкүн: `25mm`, `1in`, `2'`, `90deg`. Бирдиктүү узундуктар миллиметрге айланат, ошондуктан бирдиктерди миллиметр менен өлчөнгөн чийменелерде гана колдонуңуз; башка жерде жөнөкөй сан териңиз.

## Буйрук сабында

`-PARAMETERS` панелсиз ошол эле нерсени кылат: `N` жаңы, `E` түзөтүү (өлчөмдүк чектөө да), `R` атын өзгөртүү, `D` өчүрүү, `?` тизме.

## Эмне четке кагылат

- Өзүн өзү колдонгон туюнтма, түз же башкалар аркылуу: "width, d1 бири-бирин колдонушат."
- Өлчөм кабыл албаган маани: терс узундук, 180°тан чоң бурч.
- Чийме башка чектөөлөр менен кабыл албаган маани: эч нерсе өзгөрбөйт, жана билдирүү тоскоол болгон чектөөлөрдү атайт.
- Колдонулган параметрди өчүрүү: панель адегенде анын маанисин ага жазууну сунуш кылат. Өлчөмдүк чектөөнүн аты чектөөнү өчүрүү менен өчүрүлөт.
