## Эмне үйрөнөсүз

Чиймени бурулган абалда кантип карап, бурчта тартылган имарат экранда түз окулушу үчүн жана чекиттерди анын өз окторунун боюнда кантип терүү. Муну жасаганда чиймедеги эч нерсе жылбайт: объекттер өз координаттарын сактайт, буруу түзөтүү эмес жана чийме өзгөргөн деп белгиленбейт.

## Көрүнүштү чейрек бурулуу

1. {{ui:Көрүнүш}} › {{ui:Дагы}} › {{ui:Көрүнүштү 90° солго буруу}} же {{ui:Көрүнүштү 90° оңго буруу}} басыңыз.

Чийме экранда чийме аймагынын ортосунун айланасында бурулат. Дагы бурулуш үчүн кайра жасаңыз.

2. Кайра тегиздөө үчүн {{ui:Көрүнүш}} › {{ui:Дагы}} › {{ui:Дүйнөгө кайтуу}} басыңыз.

Алардын артындагы буйруктар: {{cmd:TURNLEFT}}, {{cmd:TURNRIGHT}} жана {{cmd:TURNWORLD}}. Биреөгө баскыч берүү үчүн, {{cmd:ALIASEDIT}} менен алиастарыңызга `TL=TURNLEFT` сыяктуу сап кошуңуз.

## Бурчтуу имаратты тегиздөө

1. `UCS` терип, {{key:Enter}} басыңыз, андан кийин `OB` жана {{key:Enter}} басыңыз.
2. Башталышы болушу керек учка жакын дубалдын сызыгын басыңыз.

UCS эми ошол учтан башталат, анын X огу дубал боюнда, ал эми көрүнүш дубал экранда тегиз болуу үчүн бурулат. Төмөнкү сол бурчтагы огдун белгиси UCS окторунун кайда караганын көрсөтөт.

3. Адаттагыдай тартыңыз. UCS коюлганда:
   - `x,y` жана `@dx,dy` UCS окторунун боюнча өлчөнөт; `d<a` бурчту UCS X огунан өлчөйт.
   - {{ui:Ортогоналдык}}, полярдык жолдоо жана тор UCS окторун ээрчишет, крест сызык да ошондой.
   - Жаңы текст жана жаңы абзацтар UCS X огунун боюнча жүрөт; {{cmd:DIMLINEAR}}'дин горизонталы жана вертикалы да аны ээрчишет.
   - Абал тилкесиндеги жана {{cmd:ID}} координаттары UCS координаттары болот.
4. UCS коюлганда дүйнө чекитин терүү үчүн, алдына `*` коюңуз: `*0,0` же `@*100,0`.
5. Дүйнөгө кайтуу үчүн `UCS`, {{key:Enter}} терип, андан кийин дагы {{key:Enter}} басыңыз.

## UCS коюунун башка жолдору

{{cmd:UCS}} суроосунда:

| Териңиз | Эмне кылат |
|---|---|
| чекит | Жаңы башталыш; андан кийин жаңы X огунда чекитти басыңыз же бурчту сактоо үчүн {{key:Enter}} басыңыз |
| `Z` | Башталышынын айланасында UCS'ти терген бурчка (градус, саат жебесине каршы) бурат же тандайт |
| `3` (үч чекит) | Башталыш, оң X огунун боюндагы чекит жана оң Y тарабындагы чекит |
| `OB` (объект) | Сызыктан, аркадан, айланадан, полисызык кесиндисинен, тексттен, блок шилтемесинен, чекиттен же курулуш сызыгынан |
| `P` (алдыңкы) | Бул UCS'тен мурунку (акыркы ондугу чийме ачык турганда сакталат) |
| `W` (дүйнө) | Дүйнөгө кайтуу |
| `NA` (аталган) | `S` учурдагы UCS'ти ат менен сактайт, `R` бирин калыбына келтирет, `D` бирин өчүрөт, `?` аларды тизмелейт |

Ар бир өзгөртүү жаңы UCS X огу тегиз болушу үчүн көрүнүштү бурат. {{cmd:PLAN}} UCS'ти өзгөртпөстөн көрүнүштү бурат: учурдагы UCS үчүн {{key:Enter}}, сакталганы үчүн `U`, дүйнө үчүн `W`.

## Билип коюу пайдалуу

- Бөлүнгөн экрандын ар бир панелинде өз бурулушу сакталат. UCS чиймеге таандык.
- Барактар кагаз координаттарында иштейт; UCS'ти {{ui:Модель}} барагында же viewport ичинде коюңуз.
- Бурулган көрүнүштө сүйрөлгөн тандоо терезелери экранда ичинде жаткан нерсени тандайт.
- LISP программалары `getpoint` аркылуу UCS'теги чекиттерди алат, `UCSORG`, `UCSXDIR`, `UCSYDIR` жана `VIEWTWIST` окуй алат, ал эми `trans` дүйнөнүн, UCS'тин жана экрандын ортосунда которот.

:::note
Сакталган файл UCS'ти жана көрүнүштүн бурулушун кийинки версияда сактайт; ага чейин алар чийме ачык турганда гана сакталат.
:::
