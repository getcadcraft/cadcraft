Кыска атты (алиасты) териңиз жана Enter басыңыз, же куралды басыңыз. Esc жокко чыгарат. Бош сапта Enter акыркы буйrukту кайталайт.

**Басып чыгаруу:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (бир A4 бет; Letter кагазында "баракка ылайыктоо" менен басып чыгарыңыз).

## Чийүү

| Терилүүчү ат | Буйрук | Эмне кылат |
|---|---|---|
| `L` | {{cmd:LINE}} | Түз сызыктарды чийет |
| `PL` | {{cmd:PLINE}} | Туташкан сызык жана жаа чынжырын чийет |
| `C` | {{cmd:CIRCLE}} | Айланы чийет (борбор жана радиус) |
| `A` | {{cmd:ARC}} | Жаа чийет |
| `REC` | {{cmd:RECTANG}} | Эки бурчтан тик бурчтукту чийет |
| `POL` | {{cmd:POLYGON}} | Туура көп бурчтукту чийет |
| `EL` | {{cmd:ELLIPSE}} | Эллипсти чийет |
| `DT` | {{cmd:TEXT}} | Бир сап текст жазат |
| `T` | {{cmd:MTEXT}} | Оронуп турган текст жазат (абзац) |
| `H` | {{cmd:HATCH}} | Аймакты үлгү менен толтурат |

| `MI` | {{cmd:MIRROR}} | Объекттерди сызык аркылуу чагылдырат |
| `O` | {{cmd:OFFSET}} | Аралыкта параллель көчүрмөсүн чийет |
| `TR` | {{cmd:TRIM}} | Объекттерди башкалар кесилишкен жерге чейин кыркат |
| `EX` | {{cmd:EXTEND}} | Объекттерди башкаларга чейин узартат |
| `F` | {{cmd:FILLET}} | Бурчту жаа менен тегеректейт |
| `CHA` | {{cmd:CHAMFER}} | Бурчту түз кыя менен кесет |
| `E` | {{cmd:ERASE}} | Объекттерди өчүрөт |
| `X` | {{cmd:EXPLODE}} | Блокту же полисызыкты бөлүктөргө бөлөт |

| `J` | {{cmd:JOIN}} | Сызыктар менен жааларды бир объектке бириктирет |

## Баскычтар

Ctrl (Mac'та Cmd): Z артка кайтаруу · Y кайра аткаруу · S сактоо · P басып чыгаруу.  F3 объекттик кармоолор · F8 ортогоналдык · F10 полярдык.  Space же Enter акыркы буйрукту кайталайт · дөңгөлөк чоңойтот · дөңгөлөктү сүйрөө көрүнүштү жылдырат

Чийүүгө жаңымы? Жетектелген биринчи чийме үчүн `TOUR` териңиз, [Баштоо](topic:getting-started) окуңуз же [Буйруктар](topic:commands) бөлүмүнөн бардык буйруктарды караңыз. Башка чийме программаларынан келдиңизби: [Башка чийме программаларынан келгендер](topic:coming-from) жана [буйруктар картасы](topic:command-map).
