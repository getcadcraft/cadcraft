## Эмне кыласыз

Файлды чиймеге киргизиңиз жана ал туура өлчөмдө киргенине ишенип коюңуз.

## Кадамдар

1. Файлды адаттагыдай киргизиңиз: `INSERT` › Файл, `XATTACH`, `POINTCLOUDATTACH`, же китепкана панелиндеги {{ui:Файлдар}}.
2. Эгер файл бирдиктерин айтса, эч нерсе суралбайт. Буйрук сабы файл кайсы бирдиктерди айтканын жана алар чийменикинен айырмаланса, колдонулган масштабды айтат.
3. Айтпаса, диалог файлдын **бирдиктерин** сурайт. Файлдагы бир бирдик эмне экенин тандап, {{ui:Бул бирдиктерди колдонуу}} басыңыз. Жообуңузга чейин эч нерсе коюлбайт.
4. {{ui:Жокко чыгаруу}} (же {{key:Esc}}) эч нерсени киргизбейт.

## Кайсы файлдар бирдиктерин айтат

- **DWG жана DXF**: чийменин киргизүү бирдиктери (`$INSUNITS`). Алар жок файл жөнүндө сурашат.
- **Чекиттик булуттар**: координаттар системасы бар LAS жана LAZ, E57, PTX жана PLY өз бирдиктерин айтат. Башкалары жөнүндө сурашат.
- **OBJ**: эч качан бирдиктерин айтпайт. Сизден сурашат.
- **glTF жана GLB**: метрлер, форматтын өз эрежеси боюнча.
- **Сүрөттөр**: өз өлчөмү жок. `IMAGEATTACH` туурасын сурайт жана ал файл үчүн мурун берген туураны сунуш кылат.
- **Скандар**: тыгыздыгын (DPI, дюйм начар чекит) айткан скан чийменин бирдиктеринде өз чыныгы өлчөмүндө киргизилет; `SCANATTACH` дагы туурасын сурайт.
- **Чекиттик булуттар кошумчасы**: бирдиги жок файлдан булут курганда сурайт жана булуттун сандарын ал алып жүргөн бирдикте белгилейт.

## Билип коюу пайдалуу

- DWG же DXF'ти өз алдынча чийме катары ачканда эч нерсе сурашпайт: буйрук сабы файл кайсы бирдиктерди айтканын же бирдик айтпаганын көрсөтөт. {{ui:Касиеттер}} чийменин бирдиктерин коёт.
- Эгер бул чийменин да бирдиги жок болсо, файлды конверттөө мүмкүн эмес: ал сан менен сандын ордуна коюлат жана буйрук сабы ушуну айтат.
- Жооп ошол файл үчүн бул компьютерде, бардык CadCraft колдонмолорунда эсте калат. Кийинки жолу киргенде сурашпайт, ал эми буйрук сабы эстеп калган бирдиктер колдонулганын айтат.
- Дагы сурашы үчүн: буйрук палитрасы ({{key:Mod+K}}) › **Импорттолгон файлдардын бирдиктерин кайра сурасын**.
