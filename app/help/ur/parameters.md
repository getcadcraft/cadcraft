## ہر سائز کے لیے ایک جدول

{{ui:پیرامیٹرز}} پینل ({{ui:پیرامیٹرک}} گروپ میں {{ui:پیرامیٹرز}} بٹن، یا {{cmd:PARAMETERS}} ٹائپ کریں) ہر ڈائمینشنل پابندی (`d1`، `rad1`، `dia1`، `ang1`، یا جو نام آپ نے دیا) اور آپ کے اپنے پیرامیٹرز ایک ساتھ دکھاتا ہے۔ کوئی بھی نام کسی بھی اظہار میں استعمال ہو سکتا ہے۔

ہر قطار میں یہ ہوتا ہے:

- **نام**: نیا نام لکھیں تاکہ اس کا نام بدلے؛ ہر وہ اظہار جو اسے استعمال کرتا ہے ساتھ بدلتا ہے۔
- **اظہار**: ایک عدد (`40`) یا ایک اظہار (`width / 2 + gap`)۔ اس میں ٹائپ کریں اور {{key:Enter}} دبائیں: ڈرائنگ ساتھ چلتی ہے۔
- **قدر**: جو وہ نکالتا ہے۔ جس قطار کو ایک اظہار چلاتا ہے، وہاں آپ یہاں بھی عدد ٹائپ کر سکتے ہیں: CadCraft اس کے پیچھے کا پیرامیٹر خود نکالتا ہے۔ `d1 = width / 2` کے ساتھ، d1 کی قدر میں `30` ٹائپ کرنے سے `width` 60 ہو جاتا ہے۔

جب دو پیرامیٹرز ایک قدر چلاتے ہیں (`width / 2 + gap`)، تو ایک ڈائیلاگ پوچھتا ہے کہ کون سا بدلنا ہے۔ ہر تبدیلی ایک کالعدم کا قدم ہے ({{key:Mod+Z}})۔

## اپنا شامل کریں

1. {{ui:پیرامیٹرز}} پینل کھولیں۔
2. ایک نام (`gap`) اور ایک قدر (`10`) ٹائپ کریں، پھر {{ui:شامل کریں}} چنیں۔
3. استعمال کریں: d1 کے اظہار میں `width / 2 + gap` ٹائپ کریں اور {{key:Enter}} دبائیں۔

نام ایک حرف یا `_` سے شروع ہوتے ہیں، اور حروف، ہندسے اور `_` رکھتے ہیں۔ فنکشن کے نام، `pi` اور اکائی کے نام نام نہیں بن سکتے۔

## اظہارات

| لکھیں | مطلب |
|---|---|
| `+ - * / ^ %` | جمع، تفریق، ضرب، تقسیم، طاقت، باقی |
| `( )` | گروپنگ |
| `sin cos tan asin acos atan atan2` | مثلثیات، ڈگری میں |
| `sqrt pow exp ln log abs sign` | جذر، طاقتیں، لوگارتھم |
| `ceil floor int round min max` | گول کرنا اور حدیں |
| `if(a > b, x, y)` | ایک انتخاب |
| `pi` | 3.14159… |

اعداد کے ساتھ اکائی ہو سکتی ہے: `25mm`، `1in`، `2'`، `90deg`۔ اکائی والی لمبائیاں ملی میٹر میں بدلی جاتی ہیں، اس لیے اکائیاں صرف ملی میٹر میں ناپی گئی ڈرائنگز میں استعمال کریں؛ باقی جگہ سادہ عدد ٹائپ کریں۔

## کمانڈ لائن پر

`-PARAMETERS` پینل کے بغیر یہی کرتا ہے: `N` نیا، `E` ایڈٹ (ڈائمینشنل پابندی بھی)، `R` نام بدلنا، `D` حذف، `?` فہرست۔

## کیا رد ہوتا ہے

- ایک اظہار جو خود کو استعمال کرے، براہ راست یا دوسروں کے ذریعے: "width، d1 ایک دوسرے کو استعمال کرتے ہیں۔"
- ایک قدر جو سائز نہیں لے سکتا: منفی لمبائی، 180° سے زیادہ کا زاویہ۔
- ایک قدر جو ڈرائنگ اپنی دوسری پابندیوں کے ساتھ نہیں لے سکتی: کچھ نہیں بدلتا، اور پیغام بتاتا ہے کہ کون سی پابندیاں رکاوٹ ہیں۔
- ایک پیرامیٹر حذف کرنا جسے کوئی چیز استعمال کرتی ہے: پینل پیشکش کرتا ہے کہ پہلے اس کی قدر انہیں میں لکھ دے۔ ایک ڈائمینشنل پابندی کا نام اس پابندی کو حذف کرنے سے حذف ہوتا ہے۔
