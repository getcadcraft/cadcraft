مختصر نام (عرفی نام) ٹائپ کریں اور Enter دبائیں، یا ٹول پر کلک کریں۔ Esc منسوخ کرتا ہے۔ خالی لائن پر Enter آخری کمانڈ دہراتا ہے۔

**پرنٹ کریں:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (A4 کاغذ کا ایک صفحہ؛ Letter کاغذ پر "fit to page" کے ساتھ پرنٹ کریں)۔

## ڈرائنگ بنانا

| ٹائپ کریں | کمانڈ | کیا کرتی ہے |
|---|---|---|
| `L` | {{cmd:LINE}} | سیدھی لائنیں کھینچیں |
| `PL` | {{cmd:PLINE}} | جڑی ہوئی لائن اور قوس کی زنجیر کھینچیں |
| `C` | {{cmd:CIRCLE}} | دائرہ کھینچیں (مرکز اور رداس) |
| `A` | {{cmd:ARC}} | قوس کھینچیں |
| `REC` | {{cmd:RECTANG}} | دو کونوں سے مستطیل کھینچیں |
| `POL` | {{cmd:POLYGON}} | باقاعدہ کثیر الاضلاع کھینچیں |
| `EL` | {{cmd:ELLIPSE}} | بیضہ کھینچیں |
| `DT` | {{cmd:TEXT}} | متن کی ایک لائن لکھیں |
| `T` | {{cmd:MTEXT}} | لپیٹنے والا متن لکھیں (پیراگراف) |
| `H` | {{cmd:HATCH}} | ایک نمونے سے کسی رقبے کو بھریں |

| ٹائپ کریں | کمانڈ | کیا کرتی ہے |
|---|---|---|
| `M` | {{cmd:MOVE}} | اشیاء منتقل کریں |
| `CO` | {{cmd:COPY}} | اشیاء نقل کریں |
| `RO` | {{cmd:ROTATE}} | اشیاء کو ایک نقطے کے گرد گھمائیں |
| `SC` | {{cmd:SCALE}} | اشیاء کو بڑا یا چھوٹا کریں |
| `MI` | {{cmd:MIRROR}} | کسی لائن کے آر پار اشیاء کا عکس بنائیں |
| `O` | {{cmd:OFFSET}} | فاصلے پر متوازی نقل بنائیں |
| `TR` | {{cmd:TRIM}} | اشیاء کو دوسری اشیاء کے قطع ہونے کی جگہ تک کاٹیں |
| `EX` | {{cmd:EXTEND}} | اشیاء کو دوسری اشیاء تک لمبا کریں |
| `F` | {{cmd:FILLET}} | کونے کو قوس سے گول کریں |
| `CHA` | {{cmd:CHAMFER}} | کونے کو سیدھی لائن سے کاٹیں |
| `E` | {{cmd:ERASE}} | اشیاء حذف کریں |
| `X` | {{cmd:EXPLODE}} | بلاک یا پولی لائن کو اس کے اجزا میں توڑیں |
| `S` | {{cmd:STRETCH}} | کراسنگ ونڈو کے اندر سروں کو منتقل کریں |
| `AR` | {{cmd:ARRAY}} | گرڈ یا دائرے میں نقل کریں |
| `J` | {{cmd:JOIN}} | لائنیں اور قوسیں جوڑ کر ایک شے بنائیں |
| `BR` | {{cmd:BREAK}} | ایک شے کو دو حصوں میں توڑیں، یا اس سے ایک ٹکڑا نکالیں |

## کلیدیں

Ctrl (Mac پر Cmd): Z کالعدم کریں · Y دوبارہ کریں · S محفوظ کریں · P پلاٹ کریں۔  F3 آبجیکٹ اسنیپ · F8 آرتھو · F10 پولر۔  Space یا Enter آخری کمانڈ دہراتے ہیں · وہیل سے زوم ہوتا ہے · وہیل کو گھسیٹنے سے پین ہوتا ہے

ڈرافٹنگ میں نئے ہیں؟ پہلی ڈرائنگ کے لیے رہنمائی کے ساتھ `TOUR` ٹائپ کریں، [شروع کرنا](topic:getting-started) پڑھیں، یا [کمانڈز](topic:commands) میں ہر کمانڈ دیکھیں۔ دوسرے ڈرافٹنگ سافٹ ویئر سے آ رہے ہیں؟ [دوسرے ڈرافٹنگ سافٹ ویئر سے آنا](topic:coming-from) اور [کمانڈ کا نقشہ](topic:command-map) دیکھیں۔
