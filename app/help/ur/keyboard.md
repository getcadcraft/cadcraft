شارٹ کٹ آپ کے کمپیوٹر کے مطابق دکھائے گئے ہیں۔ Mac پر، نیچے ہر {{key:Mod}} شارٹ کٹ Command کلید استعمال کرتا ہے، اور Control کلید بھی کام کرتی ہے۔ کلیدیں کیسے لکھی جاتی ہیں، اور Mac پر F-کلیدیں کیسے استعمال کریں، یہ [کلیدیں، ماؤس اور ٹریک پیڈ](common:keys) میں ہے۔

## کمانڈ ٹائپ کرنا

| کلید | کیا کرتی ہے |
|---|---|
| کوئی حرف، ہندسہ یا علامت | کمانڈ لائن پر جاتا ہے، پوائنٹر کہیں بھی ہو، جب تک کسی پینل کے باکس میں کرسر نہ ہو |
| {{key:Enter}} | جو لکھا ہے وہ بھیجتا ہے۔ خالی اشارے پر: آخری کمانڈ دہراتا ہے، کمانڈ ختم کرتا ہے، انتخاب مکمل کرتا ہے، یا `<…>` میں دی گئی پہلے سے طے شدہ قدر قبول کرتا ہے |
| {{key:Space}} | {{key:Enter}} جیسا، سوائے اس کے جب CadCraft متن مانگے (متن، بلاک کے نام، ڈائمینشن کا متن)، جہاں یہ خالی جگہ ٹائپ کرتا ہے |
| {{key:Esc}} | کمانڈ منسوخ کرتا ہے۔ کوئی کمانڈ نہ چل رہی ہو: گرپ کی منتقلی یا انتخابی باکس منسوخ کرتا ہے، پھر انتخاب صاف کرتا ہے |
| {{key:Tab}} | کمانڈ لائن کے دائیں طرف دکھائی گئی تجویز کردہ کمانڈ قبول کرتا ہے۔ کچھ ٹائپ نہ ہو اور پوائنٹر ایک دوسرے پر چڑھی اشیاء پر ہو: وہاں اگلی شے نمایاں کرتا ہے (چننے کے لیے کلک کریں) |
| {{key:Up}} {{key:Down}} | پہلے ٹائپ کی گئی لائنوں میں آگے پیچھے جاتا ہے (آخری 100) |

## ڈرائنگ اور ترمیم

| کلید | کیا کرتی ہے |
|---|---|
| {{key:Mod+Z}} | آخری کمانڈ کالعدم کرتا ہے |
| {{key:Mod+Y}} یا {{key:Mod+Shift+Z}} | دوبارہ کرتا ہے |
| {{key:Mod+A}} | کھلے ٹیب پر ہر وہ شے منتخب کرتا ہے جس میں ترمیم ہو سکے ({{cmd:SELECTALL}})۔ اگر آپ نے کمانڈ لائن پر کچھ ٹائپ کیا ہو تو یہ وہ متن منتخب کرتا ہے |
| {{key:Delete}} | منتخب اشیاء مٹاتا ہے ({{cmd:ERASE}})، جب تک آپ نے کمانڈ لائن پر کچھ ٹائپ نہ کیا ہو |
| {{key:Backspace}} | کمانڈ لائن پر کرسر نہ ہو تو منتخب اشیاء مٹاتا ہے؛ کمانڈ لائن پر وہ متن مٹاتا ہے جو آپ نے ٹائپ کیا |
| {{key:Esc}} | کوئی کمانڈ نہ چل رہی ہو: انتخاب صاف کرتا ہے ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | ڈرائنگ کے فارمیٹ (DWG یا DXF) میں ایک کاپی محفوظ کرتا ہے |
| {{key:Mod+Shift+S}} | بطور محفوظ کریں: DWG یا DXF چنیں، پھر کاپی محفوظ کریں |
| {{key:Mod+O}} | DWG یا DXF کھولتا ہے |
| {{key:Mod+P}} | PDF میں پلاٹ کرتا ہے |

کوئی کمانڈ چل رہی ہو تو کالعدم کرنا، دوبارہ کرنا، سب منتخب کرنا اور پلاٹ کچھ نہیں کرتے: پہلے {{key:Esc}} دبائیں۔

## کاپی، کاٹنا اور چسپاں کرنا

| کلید | کیا کرتی ہے |
|---|---|
| {{key:Mod+C}} | انتخاب کلپ بورڈ پر کاپی کرتا ہے ({{cmd:COPYCLIP}})۔ کچھ منتخب نہ ہو: CadCraft اشیاء مانگتا ہے |
| {{key:Mod+X}} | کاٹیں: انتخاب کاپی کرتا ہے، پھر اسے مٹاتا ہے ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | چسپاں کریں: کاپی پوائنٹر کے ساتھ چلتی ہے؛ اسے رکھنے کے لیے کلک کریں، یا نقطہ ٹائپ کریں ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | اسی جگہ چسپاں کریں: ان کوآرڈینیٹس پر جہاں سے کاپی ہوئی تھی ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | ڈپلیکیٹ: انتخاب کی کاپی پوائنٹر کے ساتھ چلتی ہے؛ رکھنے کے لیے کلک کریں، {{key:Esc}} کچھ نہیں چھوڑتا ({{cmd:DUPLICATE}}) |

یہی عمل ٹول بار کے {{ui:Edit}} گروپ ({{ui:Copy}}، {{ui:Paste}}) اور اس کے {{ui:More}} مینو میں بھی ہیں۔ جب کوئی اور کمانڈ چل رہی ہو تو پہلے اسے ختم کریں یا {{key:Esc}} دبائیں؛ جب کاپی پوائنٹر کے ساتھ چل رہی ہو تو {{key:Mod+V}} یا {{key:Mod+D}} دوبارہ دبانے سے نئے سرے سے شروع ہوتا ہے۔ جب آپ نے کمانڈ لائن پر کچھ ٹائپ کیا ہو، یا کوئی کمانڈ متن مانگ رہی ہو، تو یہ کلیدیں اس متن کو کاپی، کاٹ اور چسپاں کرتی ہیں۔ دیکھیں [کاپی، چسپاں اور ڈپلیکیٹ](topic:copy-paste)۔

## ٹوگلز

| کلید | ٹوگل | اسٹیٹس بار بٹن |
|---|---|---|
| {{key:F3}} | آبجیکٹ اسنیپ آن یا آف | {{ui:Snap}} |
| {{key:F7}} | گرڈ آن یا آف | {{ui:Grid}} |
| {{key:F8}} | آرتھو آن یا آف | {{ui:Ortho}} |
| {{key:F10}} | پولر ٹریکنگ آن یا آف | {{ui:Polar}} |
| {{key:F11}} | آبجیکٹ اسنیپ ٹریکنگ آن یا آف | {{ui:Track}} |
| {{key:F12}} | ڈائنامک ان پٹ آن یا آف | {{ui:Dyn}} |

:::mac
Mac پر F3، F7 اور F8 عام طور پر Mission Control اور میڈیا کلیدیں ہوتی ہیں۔ ان کے ساتھ **fn** دبائے رکھیں، یا System Settings میں معیاری فنکشن کلیدیں آن کریں، جیسا کہ [کلیدیں، ماؤس اور ٹریک پیڈ](common:keys) میں ہے۔ اسٹیٹس بار کے بٹن ہمیشہ کام کرتے ہیں۔
:::

:::firefox
Firefox میں F7 کیرٹ براؤزنگ آن کرنے کا پوچھ سکتا ہے۔ **نہیں** چنیں، اور اگر یہ بار بار پوچھے تو {{ui:Grid}} بٹن استعمال کریں۔
:::

## مدد

| کلید | کیا کرتی ہے |
|---|---|
| {{key:F1}} | یہ مدد ڈرائنگ کے ساتھ کھولتا یا بند کرتا ہے۔ یہ کمانڈ چلتے ہوئے بھی کام کرتا ہے، اور کمانڈ لائن تک کبھی نہیں جاتا۔ |
| {{key:Esc}} | مدد پینل میں کرسر ہو: تلاش صاف کرتا ہے، یا پینل بند کرتا ہے |

{{ui:Help}} بٹن، جو اوپر والی بار میں ہے، وہی کرتا ہے جو {{key:F1}}۔ مدد کے تلاش والے باکس میں ٹائپ کرتے وقت کچھ بھی کمانڈ لائن تک نہیں جاتا۔ کلیدیں واپس CadCraft کو دینے کے لیے ڈرائنگ پر کلک کریں؛ پینل اس کے ساتھ کھلا رہتا ہے۔

:::mac
Mac کی کی بورڈ پر **fn** دبائے رکھیں اور F1 دبائیں، یا {{ui:Help}} پر کلک کریں۔
:::

## اسکرین

| کلید | کیا کرتی ہے |
|---|---|
| {{key:Ctrl+Shift+F}} | عام، فل اسکرین، اور وہ فل اسکرین جس میں بارز چھپے ہوں، باری باری۔ یہ ہر کمپیوٹر پر Control کلید استعمال کرتا ہے، Mac بھی۔ |
| {{key:Left}} {{key:Right}} | ڈرائنگ کے نیچے والے ٹیب پر فوکس ہو: پچھلا یا اگلا ٹیب |

فل اسکرین میں براؤزر پہلی {{key:Esc}} کو فل اسکرین چھوڑنے کے لیے استعمال کر سکتا ہے۔ کمانڈ منسوخ کرنے کے لیے {{key:Esc}} دوبارہ دبائیں۔

## ڈائیلاگ

| کلید | کیا کرتی ہے |
|---|---|
| {{key:Esc}} | ڈائیلاگ بند کرتا ہے ({{ui:Plot to PDF}}، یا "غیر محفوظ شدہ تبدیلیاں" جیسا سوال، جہاں اس کا مطلب {{ui:Cancel}} ہے) |
| {{key:Tab}} | ڈائیلاگ کی ترتیبات اور بٹنوں کے درمیان حرکت کرتا ہے |

ڈائیلاگ کھلا ہو تو ڈرائنگ کی کلیدیں بند ہوتی ہیں۔

## پینل فیلڈز

دائیں یا بائیں پینل کے کسی باکس میں:

| کلید | کیا کرتی ہے |
|---|---|
| {{key:Enter}} | قدر لاگو کرتا ہے اور باکس چھوڑ دیتا ہے |
| {{key:Esc}} | پرانی قدر واپس رکھتا ہے اور باکس چھوڑ دیتا ہے |
| {{key:Tab}} | لاگو کرتا ہے اور اگلے باکس پر جاتا ہے |

جب کسی باکس میں کرسر ہو تو حروف وہیں ٹائپ ہوتے ہیں، کمانڈ لائن پر نہیں۔

## ماؤس

| عمل | کیا کرتا ہے |
|---|---|
| کلک | جب کمانڈ نقطہ مانگے تو نقطہ چنتا ہے؛ جب اشیاء مانگے تو شے چنتا ہے؛ ورنہ شے، یا گرپ منتخب کرتا ہے |
| Shift+کلک | منتخب شے کو انتخاب سے ہٹاتا ہے ([ترتیبات](topic:settings) میں {{ui:Clicking objects}} کو {{ui:Replaces the selection}} پر رکھا ہو تو شامل کرتا ہے)۔ نقطہ چنتے وقت: اس کلک کے لیے آبجیکٹ اسنیپ نظر انداز کرتا ہے |
| خالی جگہ پر کلک، پھر دوبارہ کلک | انتخابی باکس: بائیں سے دائیں ونڈو ہے، دائیں سے بائیں کراسنگ |
| خالی جگہ پر کھینچیں | لاسو: پہلے دائیں طرف حرکت ونڈو ہے، پہلے بائیں طرف کراسنگ؛ کھینچتے وقت {{key:Space}} ونڈو، کراسنگ اور فنس کے درمیان باری باری بدلتا ہے؛ {{key:Esc}} اسے چھوڑ دیتا ہے (LASSOMODE 0، یا ترتیبات، اسے دوبارہ مستطیل بنا دیتا ہے) |
| TRIM یا EXTEND میں ٹکڑوں کے اوپر سے کھینچیں | راستے کو عبور کرنے والے ہر ٹکڑے کو ٹرم (یا توسیع) کرتا ہے؛ دوسرے عمل کے لیے {{key:Shift}} دبائے رکھیں |
| گرپ کو کھینچیں | گرپ کو منتقل کرتا ہے (یا گرپ پر کلک کریں، پھر جہاں جانا ہو وہاں کلک کریں) |
| متن پر ڈبل کلک | اسے منتخب کرتا ہے اور دائیں پینل میں اس کے {{ui:Text}} باکس میں کرسر رکھتا ہے |
| دائیں کلک | Enter۔ گرپ کی منتقلی یا انتخابی باکس کے دوران: اسے منسوخ کرتا ہے |
| دائیں بٹن سے کھینچیں | پین کرتا ہے |
| وہیل | کراس ہیئر کے گرد زوم ان اور آؤٹ کرتا ہے |
| وہیل (درمیانی بٹن) سے کھینچیں | پین کرتا ہے |
| وہیل پر ڈبل کلک | پوری ڈرائنگ پر زوم کرتا ہے (حدود) |
| ڈرائنگ پر DWG یا DXF چھوڑیں | اسے کھولتا ہے |

ٹریک پیڈ یا ٹچ اسکرین کے لیے دیکھیں [ماؤس، ٹریک پیڈ اور ٹچ](topic:mouse-trackpad-touch)۔

## براؤزر کی رکھی ہوئی کلیدیں

{{key:Mod+N}}، {{key:Mod+W}} اور {{key:Mod+T}} ہمیشہ براؤزر کے ہیں۔ CadCraft انہیں استعمال نہیں کرتا: نئی ڈرائنگ کے لیے {{ui:New}} استعمال کریں یا `NEW` ٹائپ کریں۔ CadCraft کا کلپ بورڈ اپنا ہے: {{key:Mod+C}} اور {{key:Mod+V}} اشیاء کو CadCraft کی ڈرائنگز اور ٹیبز کے درمیان کاپی کرتے ہیں، دوسرے پروگراموں سے یا ان کی طرف نہیں۔

:::mac
اگر {{key:Mod+Y}} دوبارہ کرنے کے بجائے آپ کی براؤزر کی ہسٹری کھولے، تو {{key:Mod+Shift+Z}} یا {{ui:Redo}} بٹن استعمال کریں۔
:::

## Move کہاں ہے

منتقل کرنے کی کمانڈ `MOVE` ہے (کلید {{key:M}}): اشیاء چنیں، پھر بنیادی نقطہ اور دوسرا نقطہ، یا ٹائپ کیا ہوا فاصلہ۔ `ALIGN` اور `DISTRIBUTE` بھی موجود ہیں۔ BimCraft عمارت کے عناصر پر یہی نام اسی کام کے لیے استعمال کرتا ہے، لیکن اس کی {{key:M}} Measure ہے: اس کا Move {{key:Shift+M}} ہے۔
