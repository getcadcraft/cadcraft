دو لوگ ایک ہی ڈرائنگ میں تبدیلیاں کرتے ہیں۔ اگر انھوں نے مختلف اشیاء بدلیں تو ضم خودکار ہو سکتا ہے: ہاتھ سے دوبارہ کچھ نہیں کرنا پڑتا۔

## یہ کیسے کام کرتا ہے

CadCraft آپ کی بنائی ہر شے کو ایک چھوٹی **کلید** دیتا ہے جو کبھی نہیں بدلتی اور کبھی دو اشیاء کو نہیں دی جاتی۔ یہ DWG یا DXF میں شے کے ساتھ محفوظ ہوتی ہے (اضافی ڈیٹا کے طور پر جسے دوسرے پروگرام محفوظ رکھتے ہیں)۔ ضم اشیاء کو کلید سے تلاش کرتا ہے، فائل میں ان کی جگہ سے نہیں، کیونکہ ہر پروگرام محفوظ کرتے وقت جگہوں کو دوبارہ نمبر دیتا ہے۔ اگر آپ کبھی ضم نہیں کرتے تو اسے {{ui:ترتیبات}} › CadCraft › ضم کے لیے موزوں فائلیں میں بند کریں؛ فائلیں تقریباً 10 فیصد چھوٹی ہو جاتی ہیں۔

کلیدیں آنے سے پہلے محفوظ ہونے والی ڈرائنگ پھر بھی ضم ہوتی ہے: اس کی اشیاء کو فائل میں ان کی جگہ سے کلید ملتی ہے، جو ہر اس شخص کے لیے ایک ہی ہوتی ہے جو اسے کھولتا ہے۔

## سیٹ اپ کریں

Git کو ہر ریپوزٹری کے لیے ایک بار دو لائنیں درکار ہیں:

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

git کے بغیر اسے ہاتھ سے چلائیں: `cadcraft merge <base> <ours> <theirs> -o <result>`۔ Fossil اور Mercurial اپنی merge-tool ترتیب میں وہی تین فائلیں لیتے ہیں۔

## اصول

- ایک طرف بدلی ہوئی شے لی جاتی ہے۔ دونوں طرف ایک ہی تبدیلی ہو تو ایک بار لی جاتی ہے۔
- ایک ہی خاصیت دو طرح بدلی جائے تو یہ **تضاد** ہے: آپ کی طرف والی قائم رہتی ہے اور رپورٹ دونوں قدریں درج کرتی ہے۔ نتیجہ کھولیں، اس شے کو دیکھیں اور ہاتھ سے درست کریں۔
- کسی ایک طرف شامل ہونے والی شے رہتی ہے۔ ایک طرف سے ہٹائی گئی اور دوسری طرف بغیر چھیڑی گئی شے ہٹا دی جاتی ہے۔ ایک طرف ہٹائی گئی اور دوسری طرف بدلی گئی: ہٹا دی جاتی ہے، اور رپورٹ کی جاتی ہے۔
- لیئرز، بلاکس، متن اور ڈائمینشن اسٹائلز، شیٹس اور نامزد منظر اسی طرح ضم ہوتے ہیں۔ پابندیاں ان اشیاء کے ساتھ چلتی ہیں جن کا وہ نام لیتی ہیں۔
- نتیجہ آپ کی فائل والے فارمیٹ اور ورژن میں لکھا جاتا ہے۔

ضم نہیں ہوتی: اشیاء جس ترتیب سے بنائی جاتی ہیں وہ آپ کی ہوتی ہے، اس کے بعد دوسری طرف کی شامل کی گئی اشیاء۔ ایک ہی بلاک کی تعریف کی دونوں طرف تبدیلیاں تضاد ہیں، کبھی ملائی نہیں جاتیں۔ کچھ بھی اپ لوڈ نہیں ہوتا؛ سب کچھ آپ کے کمپیوٹر پر چلتا ہے۔
