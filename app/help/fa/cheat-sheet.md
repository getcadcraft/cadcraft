نام کوتاه (میان‌بر) را تایپ کنید و Enter بزنید، یا روی ابزار کلیک کنید. Esc لغو می‌کند. Enter روی یک خط خالی آخرین فرمان را تکرار می‌کند.

**چاپ آن:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (یک صفحه A4؛ روی کاغذ Letter آن را با «تناسب با صفحه» چاپ کنید).

## رسم

| تایپ کنید | فرمان | کاری که انجام می‌دهد |
|---|---|---|
| `L` | {{cmd:LINE}} | رسم خط‌های راست |
| `PL` | {{cmd:PLINE}} | رسم زنجیره‌ای از خط و کمان به‌هم‌پیوسته |
| `C` | {{cmd:CIRCLE}} | رسم دایره (مرکز و شعاع) |
| `A` | {{cmd:ARC}} | رسم کمان |
| `REC` | {{cmd:RECTANG}} | رسم مستطیل از دو گوشه |
| `POL` | {{cmd:POLYGON}} | رسم چندضلعی منظم |
| `EL` | {{cmd:ELLIPSE}} | رسم بیضی |
| `DT` | {{cmd:TEXT}} | نوشتن یک خط متن |
| `T` | {{cmd:MTEXT}} | نوشتن متنی که خودبه‌خود می‌شکند (پاراگراف) |
| `H` | {{cmd:HATCH}} | پر کردن یک ناحیه با یک الگو |

## ویرایش

| تایپ کنید | فرمان | کاری که انجام می‌دهد |
|---|---|---|
| `M` | {{cmd:MOVE}} | جابه‌جایی شیء‌ها |
| `CO` | {{cmd:COPY}} | کپی شیء‌ها |
| `RO` | {{cmd:ROTATE}} | چرخاندن شیء‌ها حول یک نقطه |
| `SC` | {{cmd:SCALE}} | بزرگ‌تر یا کوچک‌تر کردن شیء‌ها |
| `MI` | {{cmd:MIRROR}} | قرینه کردن شیء‌ها نسبت به یک خط |
| `O` | {{cmd:OFFSET}} | رسم یک کپی موازی در یک فاصله |
| `TR` | {{cmd:TRIM}} | برش شیء‌ها تا محل تقاطع با بقیه |
| `EX` | {{cmd:EXTEND}} | امتداد شیء‌ها تا رسیدن به بقیه |
| `F` | {{cmd:FILLET}} | گرد کردن یک گوشه با کمان |
| `CHA` | {{cmd:CHAMFER}} | بریدن یک گوشه با یک لبه راست |
| `E` | {{cmd:ERASE}} | حذف شیء‌ها |
| `X` | {{cmd:EXPLODE}} | تجزیه یک بلوک یا پلی‌لاین به اجزایش |
| `S` | {{cmd:STRETCH}} | جابه‌جا کردن انتهاهای داخل پنجره عبوری |
| `AR` | {{cmd:ARRAY}} | کپی در یک شبکه یا یک دایره |
| `J` | {{cmd:JOIN}} | اتصال خط‌ها و کمان‌ها به یک شیء |
| `BR` | {{cmd:BREAK}} | شکستن یک شیء به دو قسمت یا حذف یک تکه از آن |

## کلیدها

کلید Ctrl (روی Mac: Cmd): Z واگرد · Y ازنو · S ذخیره · P پلات. F3 اسنپ به شیء · F8 اورتو · F10 قطبی. Space یا Enter آخرین فرمان را تکرار می‌کند · چرخ ماوس بزرگ‌نمایی می‌کند · کشیدن چرخ ماوس پن می‌کند

تازه با نقشه‌کشی آشنا شده‌اید؟ برای یک نقشه اول راهنمادار `TOUR` را تایپ کنید، [شروع کار با CadCraft](topic:getting-started) را بخوانید، یا همه فرمان‌ها را در [فرمان‌ها](topic:commands) ببینید. اگر از نرم‌افزار نقشه‌کشی دیگری می‌آیید: [از نرم‌افزار نقشه‌کشی دیگر](topic:coming-from) و [نقشه فرمان‌ها](topic:command-map) را ببینید.
