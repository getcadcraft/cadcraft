CadCraft نام فرمان‌ها و نام‌های کوتاهی را می‌پذیرد که مردم از نرم‌افزارهای نقشه‌کشی دیگر می‌شناسند: برای خط `L`، برای برش `TR`، برای پاک کردن `E` تایپ کنید. بنابراین برای بیشتر آن‌ها جدول ترجمه‌ای برای یاد گرفتن لازم نیست: نامی که می‌شناسید همان نام اینجاست. فهرست زیر همه فرمان‌های CadCraft است که از خود برنامه ساخته شده است. {{key:Enter}} آخرین فرمان را تکرار می‌کند و `HELP` در خط فرمان همین فهرست را چاپ می‌کند.

موارد اندکی که یکسان نیستند یا ساخته نشده‌اند:

- **ذخیره** یک نسخه را در مرورگر بارگیری می‌کند ({{cmd:SAVE}}، {{cmd:SAVEAS}})؛ در CadCraft Studio فایل را می‌نویسد. [از نرم‌افزارهای طراحی دیگر به CadCraft](topic:coming-from) را ببینید.
- **PLOT** یک PDF می‌سازد (و PNG و SVG هم)، با یک جدول سبک پلات؛ مدیر تنظیم صفحه ندارد.
- **DIMSTYLE** و **PEDIT** ساخته شده‌اند؛ **PEDIT** گزینه Edit-vertex ندارد (دستگیره‌ها این کار را انجام می‌دهند).
- **TABLE** ساخته نشده است؛ {{cmd:XREF}}، {{cmd:SPLINE}} و {{cmd:WBLOCK}} ساخته شده‌اند.
- فرمان‌های یک روال (AutoLISP `C:NAME`) بعد از بارگذاری آن با {{cmd:APPLOAD}} ظاهر می‌شوند؛ اینجا فهرست نشده‌اند.

| `WALLREJOIN` |  | دوباره یک دیوار کردن دو قسمت یک دیوار. قسمت اول جایش در نقشه را نگه می‌دارد. |
| `WALLROT` |  | کشیدن چهار دیوار متصل به‌صورت یک مستطیل چرخیده با هر زاویه: ضلع اول، سپس تا کجا بیرون برود. |
| `WALLSPLIT` | `WS` | تقسیم دیوار به دو در یک نقطه یا جایی که دیوار دیگری از آن عبور می‌کند. قسمت‌ها متصل می‌مانند، مگر اینکه فاصله یا انتهای آزاد بخواهید. در و پنجره با قسمت خودشان می‌روند. |
| `WALLSPLITGAP` |  | تقسیم یک دیوار با گذاشتن فاصله: فاصله را تایپ کنید، دیوار را انتخاب کنید، سپس نقطه. قسمت‌ها انتهای آزاد دارند و می‌توانند دوباره به هم متصل شوند. |
| `WALLSTRETCH` |  | کشیدن با یک پنجره: انتهای دیوارهایی که داخلش‌اند جابه‌جا می‌شوند، دیوارهایی که کاملاً داخلش‌اند کامل جابه‌جا می‌شوند، و دیوارهایی که به پهلوی‌شان می‌خورند همراه آن‌ها می‌لغزند. |
| `WALLTAN` |  | ادامه دادن یک دیوار با کمانی که در امتداد آن از آن جدا می‌شود (به‌صورت دیوارهای کوتاه مستقیم کشیده می‌شود). |
| `WALLTRACE` |  | ساختن دیوارها دور کوچک‌ترین ناحیه بسته از خط‌ها و دیوارها اطراف نقطه‌ای که کلیک می‌کنید. |
| `WALLUNHOLD` |  | برداشتن قفل‌های یک دیوار (و قفل‌های دیوارهای دیگر به آن). |
| `WBLOCK` | `W`، `-WBLOCK` | نوشتن یک بلوک، چند شیء یا کل نقشه در یک فایل تازه DWG یا DXF (W) |
| `WEDGE` | `WE` | یک گوه: دو گوشه و یک ارتفاع؛ از گوشه اول شیب می‌گیرد (سه‌بعدی) |
| `WHEREAMI` | `WHERE` | گفتن اینکه نشانگر کجاست. |
| `WHOHAS` |  | گفتن اینکه چه کسی یک نقشه را باز کرده است. CadCraft Studio کنار هر نقشه باز یک فایل قفل کوچک نگه می‌دارد (Plan.dwg.cclock: چه کسی، از چه زمانی، کدام نسخه) و وقتی بسته شود آن را برمی‌دارد. گزینه‌ها: Current (نقشه باز)، File (یکی را انتخاب کنید)، FOlder (هر نقشه‌ای در یک پوشه که جایی باز است؛ این هم به Studio اجازه می‌دهد فایل‌های قفل را آنجا نگه دارد)، Path (تایپ یک مسیر)، Name (نامی که دیگران می‌بینند). قفلی که پنج دقیقه تازه نشده، کهنه گفته می‌شود. در مرورگر در دسترس نیست. |
| `WINDOW` | `WN` | قرار دادن یک پنجره در یک دیوار. |
| `XATTACH` | `XA` | پیوند دادن یک DWG یا DXF دیگر به این نقشه، فقط‌خواندنی نشان داده می‌شود (XREF آن‌ها را فهرست و دوباره بارگذاری می‌کند) |
| `XCLIP` | `XC` | برش ارجاع‌های بلوک و نقشه‌های پیوندی به یک مستطیل یا چندضلعی، یا برداشتن برش. |
| `XLINE` | `XL` | خط ساختاری، بی‌پایان به هر دو سو: از دو نقطه، افقی، عمودی، با زاویه، نیم‌ساز یک زاویه، یا افست از یک خط. |
| `XREF` | `XR`، `-XREF` | نقشه‌های پیوندی (ارجاع‌های خارجی): فهرست، پیوست، بارگذاری دوباره، اتصال، جدا کردن |
| `ZOOM` | `Z` | حدود، یا یک پنجره |
