دوه کسان یوه نقشه سموي. که دوی توپیرې شیان بدل کړي، یوځای کول اتوماتیک کېدای شي: هېڅ شی په لاس بېرته کول اړین نه دی.

## دا څنګه کار کوي

CadCraft هر هغه شی چې رسموئ یوه لنډه **کیلي** ورکوي چې هېڅکله نه بدلېږي او هېڅکله دوو شیانو ته نه ورکول کېږي. دا د شي سره په DWG یا DXF کې خوندي کېږي (د اضافي معلوماتو په توګه چې نور برنامې ساتي). یوځای کول شیان د هغې کیلي له مخې ومومي، نه د فایل د ځای له مخې، ځکه هره برنامه کله چې خوندي کوي ځایونه بیا شمېري. که هېڅکله یوځای نه کوئ، دا په {{ui:امستنې}} › CadCraft › د یوځای کېدو وړ فایلونه کې بند کړئ؛ فایلونه شاوخوا 10 سلنه کوچني کېږي.

هغه نقشه چې مخکې له دې چې کیلي موجودې وي خوندي شوې، بیا هم یوځای کېږي: د هغې شیان د فایل د ځای څخه کیلي ترلاسه کوي، د هر هغه چا لپاره یو شان چې خلاصوي.

## ترتیب

Git په هر ریپازیټوري کې یو ځل دوه کرښې غواړي:

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# یو ځل، په هر کمپیوټر کې
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

له git پرته، په لاس یې چل کړئ: `cadcraft merge <base> <ours> <theirs> -o <result>`. Fossil او Mercurial همدا درې فایلونه د خپل یوځای کولو وسیلې امستنې کې اخلي.

## قواعد

- یو شی چې یوازې په یو لوري بدل شوی وي اخیستل کېږي. ورته بدلون په دواړو لوریو کې یو ځل اخیستل کېږي.
- ورته ملکیت په دوو لارو بدل شوی یو **شخړه** ده: ستاسو لوری پاتې کېږي او راپور دواړه ارزښتونه لیست کوي. پایله خلاصه کړئ، هغه شی وګورئ، او په لاس یې سم کړئ.
- هر شی چې په کوم یو لوري اضافه شوی ساتل کېږي. یو شی چې په یو لوري لرې شوی او بل لوري نه دی بدل شوی لرې کېږي. په یو لوري لرې شوی او بل لوري بدل شوی: لرې کېږي، او راپور کېږي.
- لایې، بلاکونه، متن او د اندازې سټایلونه، پاڼې او نومول شوي لیدونه په ورته ډول یوځای کېږي. محدودیتونه هغه شیان تعقیبوي چې نومي.
- پایله د ستاسو په شان ورته فایل فارمټ او نسخه کې لیکل کېږي.

یوځای نه کېږي: د شیانو د رسمولو ترتیب ستاسو دی، بیا هغه شیان چې بل لوری یې اضافه کړي. په دواړو لوریو کې د ورته بلاک تعریف بدلونونه شخړه ده، هېڅکله نه گډېږي. هېڅ نه پورته کېږي؛ دا ټول ستاسو په کمپیوټر کې چلېږي.
