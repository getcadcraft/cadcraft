د لاندې ګړندۍ لارې ستاسو کمپیوټر لپاره ښودل شوي. په Mac کې، هر {{key:Mod}} ګړندۍ لاره د Command کیلي کاروي، او Control کیلي هم کار کوي. کیلي څنګه لیکل کېږي، او په Mac کې د F کیلي څنګه کارول کېږي، په [کیلي، ماوس او ټرېک پیډ](common:keys) کې دي.

## کمانډ لیکل

| کیلي | څه کوي |
|---|---|
| هر حرف، شمېره یا نښه | کمانډ کرښې ته ځي، هر ځای چې ماوس وي، پرته لدې چې په پینل کې کوم ډګر کرسر ولري |
| {{key:Enter}} | هغه څه لېږي چې ولیکل شوي. په خالي پوښتنه کې: وروستی کمانډ تکراروي، کمانډ پای ته رسوي، ټاکنه بشپړوي، یا په `<…>` کې ټاکل شوی ارزښت منې |
| {{key:Space}} | د {{key:Enter}} په شان، پرته لدې چې CadCraft متن (متن، د بلاکونو نومونه، د اندازې متن) وغواړي؛ هلته یو خالي ځای لیکي |
| {{key:Esc}} | کمانډ لغوه کوي. که کمانډ نه روان وي: د ګرپ خوځول یا ټاکنه بکس لغوه کوي، بیا ټاکنه پاکوي |
| {{key:Tab}} | هغه وړاندیز کمانډ منې چې د کمانډ کرښې ښي خوا ته ښکاري. کله چې هېڅ نه وي لیکل شوي او ماوس د تېر شیانو پر سر وي: ښې خوا شی ته لاړ شي (کلیک یې وټاکي) |
| {{key:Up}} {{key:Down}} | هغه کرښې چې دمخه مو لیکلې (وروستۍ 100) ګوري |

## رسم او سمون

| کیلي | څه کوي |
|---|---|
| {{key:Mod+Z}} | وروستی کمانډ بېرته اخلي |
| {{key:Mod+Y}} یا {{key:Mod+Shift+Z}} | بیا کول |
| {{key:Mod+A}} | په پرانیستې ټب کې هر سمولی شی ټاکي ({{cmd:SELECTALL}}). که تاسو په کمانډ کرښه کې څه لیکلي وي، هغه متن ټاکي |
| {{key:Delete}} | ټاکل شوي شیان ړنګوي ({{cmd:ERASE}})، پرته لدې چې په کمانډ کرښه کې څه ولیکلی شي |
| {{key:Backspace}} | ټاکل شوي شیان ړنګوي کله چې کمانډ کرښه کرسر نه لري؛ په کمانډ کرښه کې هغه څه ړنګوي چې ولیکل شوي |
| {{key:Esc}} | که کمانډ نه روان وي: ټاکنه پاکوي ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | د نقشې په بڼه کاپي ساتي (DWG یا DXF) |
| {{key:Mod+Shift+S}} | په بل نوم ساتل: DWG یا DXF وټاکئ، بیا کاپي وساتئ |
| {{key:Mod+O}} | یو DWG یا DXF پرانیزي |
| {{key:Mod+P}} | PDF ته چاپ کوي |

بېرته کول، بیا کول، ټول ټاکل او چاپ هېڅ نه کوي کله چې کمانډ روان وي: لومړی {{key:Esc}} کېکاږئ.

## کاپي، پرې کول او سرېښول

| کیلي | څه کوي |
|---|---|
| {{key:Mod+C}} | ټاکنه کلیپ بورډ ته کاپي کوي ({{cmd:COPYCLIP}}). که هېڅ نه وي ټاکل شوي: CadCraft شیان غواړي |
| {{key:Mod+X}} | پرې کول: ټاکنه کاپي کوي، بیا یې ړنګوي ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | سرېښول: کاپي د کرسر تعقیبوي؛ کلیک وکړئ، یا یو ټکی ولیکئ، تر څو یې ږدئ ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | په ځای کې سرېښول: په هماغو همغږو کې چې له هغې کاپي شوی و ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | نقل: د ټاکنې یوه کاپي د ماوس سره خوځي؛ کلیک وکړئ تر څو یې ږدئ، {{key:Esc}} هېڅ نه پرېږدي ({{cmd:DUPLICATE}}) |

همدې عملونه د ټول افزار {{ui:Edit}} ګروپ کې ({{ui:Copy}}، {{ui:Paste}}) او د هغه {{ui:More}} مینو کې دي. پداسې حال کې چې بل کمانډ روان وي، هغه بشپړ کړئ یا لومړی {{key:Esc}} کېکاږئ؛ که کاپي کرسر تعقیبوي او تاسو بیا {{key:Mod+V}} یا {{key:Mod+D}} کېکاږئ، بیا له لومړي پیل کېږي. کله چې تاسو په کمانډ کرښه کې څه لیکلي یا کمانډ متن غواړي، دا کیلي هغه متن کاپي، پرې او سرېښي. [کاپي، سرېښول او نقل](topic:copy-paste) وګورئ.

## ټوګلونه

| کیلي | ټوګل | د حالت بار تڼۍ |
|---|---|---|
| {{key:F3}} | د شیانو نیول پرانیزي یا بندوي | {{ui:Snap}} |
| {{key:F7}} | ګرډ پرانیزي یا بندوي | {{ui:Grid}} |
| {{key:F8}} | Ortho پرانیزي یا بندوي | {{ui:Ortho}} |
| {{key:F10}} | قطبي تعقیب پرانیزي یا بندوي | {{ui:Polar}} |
| {{key:F11}} | د شیانو نیولو تعقیب پرانیزي یا بندوي | {{ui:Track}} |
| {{key:F12}} | متحرک ننوتنه پرانیزي یا بندوي | {{ui:Dyn}} |

:::mac
په Mac کې، F3، F7 او F8 معمولاً د Mission Control او رسنیو کیلي دي. د **fn** سره یې ونیسئ، یا په System Settings کې معیاري F کیلي فعال کړئ، لکه څنګه چې په [کیلي، ماوس او ټرېک پیډ](common:keys) کې ویل شوي. د حالت بار تڼۍ تل کار کوي.
:::

:::firefox
په Firefox کې F7 هم پوښتنه کولای شي چې د کرسر براوزینګ فعال کړئ. **No** وټاکئ، او که پوښتنه تکراره شي، د {{ui:Grid}} تڼۍ وکاروئ.
:::

## مرسته

| کیلي | څه کوي |
|---|---|
| {{key:F1}} | دې مرستې ته، د نقشې ترڅنګ، پرانیزي یا بندوي. حتی کله چې کمانډ روان وي کار کوي، او هېڅکله کمانډ کرښې ته نه رسي. |
| {{key:Esc}} | کله چې کرسر د مرستې پینل کې وي: پلټنه پاکوي، یا پینل بندوي |

د پورتنۍ بار {{ui:Help}} تڼۍ هماغه کار کوي لکه {{key:F1}}. کله چې په مرستې کې د پلټنې بکس کې لیکئ، هیڅ نه کمانډ کرښې ته رسي. د CadCraft ته د کیلیو د بېرته ورکولو لپاره په نقشه کلیک وکړئ؛ پینل د هغې ترڅنګ خلاص پاتې کېږي.

:::mac
په Mac کیبورډ کې، **fn** ونیسئ او F1 کېکاږئ، یا {{ui:Help}} کلیک وکړئ.
:::

## پرده

| کیلي | څه کوي |
|---|---|
| {{key:Ctrl+Shift+F}} | عادي، بشپړه پرده، او بشپړه پرده بې بارونو ترمنځ بدلوي. دا په هر کمپیوټر کې Control کیلي کاروي، Mac هم په ګډون. |
| {{key:Left}} {{key:Right}} | کله چې د نقشې لاندې ټب فوکس ولري: مخکنی یا راتلونکی ټب |

په بشپړه پرده کې، براوزر ممکن لومړی {{key:Esc}} د بشپړې پردې د وتلو لپاره وکاروي. بیا {{key:Esc}} کېکاږئ تر څو کمانډ لغوه شي.

## ډیالوګونه

| کیلي | څه کوي |
|---|---|
| {{key:Esc}} | ډیالوګ بندوي ({{ui:Plot to PDF}}، یا پوښتنه لکه "Unsaved changes"، چېرې چې دا {{ui:Cancel}} معنا لري) |
| {{key:Tab}} | د ډیالوګ د امستنو او تڼیو ترمنځ حرکت کوي |

کله چې ډیالوګ پرانیستل شوی وي، د نقشې کیلي بندې دي.

## د پینل ډګرونه

په ښي یا کیڼ پینل کې یو بکس کې:

| کیلي | څه کوي |
|---|---|
| {{key:Enter}} | ارزښت پلي کوي او بکس پرېږدي |
| {{key:Esc}} | زوړ ارزښت بېرته راوړي او بکس پرېږدي |
| {{key:Tab}} | پلي کوي او راتلونکي بکس ته ځي |

کله چې بکس کرسر ولري، توري هلته لیکل کېږي، نه کمانډ کرښې ته.

## ماوس

| عمل | څه کوي |
|---|---|
| کلیک | ټکی ټاکي کله چې کمانډ یو ټکی وغواړي؛ شی ټاکي کله چې شیان وغواړي؛ نور یو شی یا ګرپ ټاکي |
| Shift+کلیک | یو ټاکل شوی شی له ټاکنې لرې کوي ([امستنې](topic:settings) کې د {{ui:Clicking objects}} د {{ui:Replaces the selection}} ټاکلو سره: اضافه کوي). کله چې ټکی ټاکي: هغه کلیک لپاره د شیانو نیولو له پامه غورځوي |
| په تش ځای کلیک، بیا بیا کلیک | د ټاکنې بکس: له چپ څخه ښي ته یو کړکۍ دی، له ښي څخه چپ ته یو کراسینګ |
| په تش ځای ونیسئ او کش کړئ | لاسو: لومړی ښي ته کش یوه کړکۍ ده، لومړی چپ ته یو کراسینګ؛ {{key:Space}} د کش پر مهال کړکۍ، کراسینګ او فینس بدلوي؛ {{key:Esc}} یې پرېږدي (LASSOMODE 0، یا امستنې، بیرته مستطیل جوړوي) |
| د TRIM یا EXTEND کې ټوټو ته کش کول | هر هغه ټوټه چې لاره یې پرې کوي، پرې (یا اوږدوي)؛ د بل لپاره {{key:Shift}} ونیسئ |
| ګرپ ونیسئ | ګرپ خوځوي (یا ګرپ کلیک کړئ، بیا هغه ځای کلیک کړئ چېرې چې لاړ شي) |
| متن دوه ځله کلیک کړئ | هغه ټاکي او کرسر د ښي پینل {{ui:Text}} بکس کې اچوي |
| ښي تڼۍ کلیک | Enter. د ګرپ د خوځولو یا ټاکنې بکس پر مهال: هغه لغوه کوي |
| ښي تڼۍ سره کش کول | لید خوځوي |
| د تڼۍ (منځنۍ) سره کش کول | لید خوځوي |
| د تڼۍ دوه ځله کلیک | ټوله نقشه (extents) ته زوم کوي |
| DWG یا DXF په نقشه کې راولئ | پرانیزي |

په ټچ پیډ یا ټچ سکرین کې، [ماوس، ټچ پیډ او ټچ](topic:mouse-trackpad-touch) وګورئ.

## کیلي چې براوزر یې ساتي

{{key:Mod+N}}، {{key:Mod+W}} او {{key:Mod+T}} تل د براوزر دي. CadCraft یې نه کاروي: د نوې نقشې لپاره {{ui:New}} وکاروئ یا `NEW` ولیکئ. د CadCraft کلیپ بورډ خپل دی: {{key:Mod+C}} او {{key:Mod+V}} شیان د CadCraft نقشو او ټبونو ترمنځ کاپي کوي، نه له یا ته د نورو برنامو سره.

:::mac
که {{key:Mod+Y}} د بیا کولو پر ځای ستاسو د براوزر تاریخچه خلاصوي، {{key:Mod+Shift+Z}} یا {{ui:Redo}} تڼۍ وکاروئ.
:::

## Move چېرته دی

Move د `MOVE` کمانډ دی (کیلي {{key:M}}): شیان وټاکئ، بیا د اساس ټکی او دوهم ټکی یا ټاکلی واټن. `ALIGN` او `DISTRIBUTE` هم شتون لري. BimCraft په ودانۍ عناصرو کې همدې نومونه د همدې دندو لپاره کاروي، خو د هغه {{key:M}} Measure دی: د هغه Move {{key:Shift+M}} دی.
