د لنډ نوم (مستعار نوم) ولیکئ او Enter کېکاږئ، یا وسیله کلیک کړئ. Esc لغوه کوي. په تشه کرښه Enter، وروستی امر بیا ترسره کوي.

**چاپ یې کړئ:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (یوه A4 پاڼه؛ د Letter کاغذ کې دا د "fit to page" سره چاپ کړئ).

## ترسیم

| ډول | امر | څه کار کوي |
|---|---|---|
| `L` | {{cmd:LINE}} | مستقیمې کرښې ترسیمول |
| `PL` | {{cmd:PLINE}} | یو تړلی کرښه او قوس زنځیر ترسیمول |
| `C` | {{cmd:CIRCLE}} | دایره ترسیمول (مرکز او شعاع) |
| `A` | {{cmd:ARC}} | قوس ترسیمول |
| `REC` | {{cmd:RECTANG}} | مستطیل د دوو کونجونو څخه ترسیمول |
| `POL` | {{cmd:POLYGON}} | منظم کثیرالاضلاع ترسیمول |
| `EL` | {{cmd:ELLIPSE}} | بیضوي ترسیمول |
| `DT` | {{cmd:TEXT}} | یوه کرښه متن لیکل |
| `T` | {{cmd:MTEXT}} | متن لیکل چې پرېکیږي (پاراګراف) |
| `H` | {{cmd:HATCH}} | یوه ساحه د نمونې سره ډکول |

## بدلول

| ډول | امر | څه کار کوي |
|---|---|---|
| `M` | {{cmd:MOVE}} | شیان لېږدول |
| `CO` | {{cmd:COPY}} | شیان کاپي کول |
| `RO` | {{cmd:ROTATE}} | شیان د یوې ټکي شاوخوا ګرځول |
| `SC` | {{cmd:SCALE}} | شیان لوی یا کوچني کول |
| `MI` | {{cmd:MIRROR}} | شیان د یوې کرښې له پلوه انعکاس کول |
| `O` | {{cmd:OFFSET}} | په واټن کې موازي کاپي ترسیمول |
| `TR` | {{cmd:TRIM}} | شیان د نورو د تقاطع ځای ته پرې کول |
| `EX` | {{cmd:EXTEND}} | شیان تر نورو پورې اوږدول |
| `F` | {{cmd:FILLET}} | یو کونج د قوس سره ګردول |
| `CHA` | {{cmd:CHAMFER}} | یو کونج د مستقیم کنار سره پرې کول |
| `E` | {{cmd:ERASE}} | شیان ړنګول |
| `X` | {{cmd:EXPLODE}} | بلاک یا پولي لاین په خپلو برخو ویشل |
| `S` | {{cmd:STRETCH}} | پایونه د تقاطعي کړکۍ دننه حرکت ورکول |
| `AR` | {{cmd:ARRAY}} | په شبکه یا دایره کې کاپي کول |
| `J` | {{cmd:JOIN}} | کرښې او قوسونه په یو شي کې یوځای کول |
| `BR` | {{cmd:BREAK}} | یو شی په دوو برخو ویشل، یا یوه برخه ایستل |

## کیلي

Ctrl (په Mac کې Cmd): Z بېرته کول · Y بیا کول · S خوندي کول · P چاپ کول.  F3 د شیانو نښلونه · F8 اورتو · F10 قطبي.  Space یا Enter وروستی امر بیا ترسره کوي · د ماوس څرخ زوم کوي · د ماوس څرخ کش کول لید خوځوي

نوي یاست ترسیم ته؟ د لارښود لومړنۍ نقشې لپاره `TOUR` ولیکئ، یا [د CadCraft سره پیل کول](topic:getting-started) ولولئ، یا په [امرونو](topic:commands) کې هر امر وګورئ. د نورو ترسیم سافټویرونو څخه راځئ؟ [د نورو ترسیم سافټویرونو څخه راتلل](topic:coming-from) او [د امرونو نقشه](topic:command-map) وګورئ.
