## څه به زده کړئ

څنګه یو AI مرستندوی (یا هغه سکریپټ چې تاسو ولیکلی) ته اجازه ورکړئ چې نقشه وګوري، د CadCraft کمانډونه چلوي، چاپ او خوندي کوي، او دا چې پرېکړه وکړئ چې دا باید کوم شیان لمس کړي.

**CadCraft پخپله هیڅ AI نلري** او هیڅ شی هیڅ ځای ته نه لېږي. مرستندوی تاسو وړئ: هر هغه برنامه چې د Model Context Protocol (MCP) ژبه پوهیږي. CadCraft یوازې ورته وسایل ورکوي، او ټاکل تاسو کوئ چې کوم یې.

دوه لارې شتون لري:

- **هغه نقشه چې خلاصه لرئ.** مرستندوی په دې کړکۍ کې، ستاسو په څنګ کې، د CadCraft Studio له لارې ستاسو په کمپیوټر کار کوي. دا هغه برخه ده چې {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Assistants}} لپاره ده.
- **نقشې ستاسو په کمپیوټر کې، پرته له دې چې برنامه خلاصه کړئ.** د CadCraft MCP سرور او `cadcraft` د کمانډ کرښه هغو فولډرونو کې DWG او DXF فایلونه لولي او لیکي چې تاسو یې نوم اخلئ. د «پرته له CadCraft خلاصولو فایلونو سره کار» برخه ولولئ.

## یې فعالول

1. {{ui:Settings}} خلاص کړئ (د اپ بار ګیر، یا {{key:Mod+,}}) او {{ui:CadCraft}} ټب ته ولاړ شئ.
2. د {{ui:Assistants}} لاندې، **AI مرستندويانو او سکریپټونو ته د CadCraft کارولو اجازه ورکول** چیک کړئ. تر هغې بند دی تر څو تاسو دا ونه کړئ.
3. وټاکئ چې دا څه کولی شي. **Read** په پیل کې چیک دی؛ نور یوازې هغه وخت چیک کړئ کله چې ورته اړتیا ولرئ.

| اجازه | مرستندوی څه کولی شي |
|---|---|
| Read (لوستل) | نقشه کتل: تشریح کول، شیان لیست او موندل، ټاکنه لیدل، د لید تشریح او انځور اخیستل، د لایې او ډرافټینګ قواعدو سره چک کول |
| Edit (سمون) | په نقشه کې کمانډونه چلول او ټاکنه بدلول. هر عمل یو بېرته کېدونکی ګام دی |
| Save (خوندي کول) | نقشه خوندي کول (په ډیسک کې، خپل فایل ته؛ په براوزر کې، د ډاونلوډ په توګه) |
| Export (صادرول) | PDF ته چاپ کول او نور فایلونه جوړول |

## د هغو فولډرونو کې فایلونه کارول چې غوره کوئ

په CadCraft Studio کې مرستندوی کولی شي فایلونه د نوم په واسطه خلاص، خوندي او چاپ کړي، د فایل ډیالوګونو پر ځای، مګر یوازې په هغو فولډرونو کې چې تاسو د {{ui:Assistants}} › {{ui:Folders it may use}} لاندې اضافه کوئ:

1. {{ui:Add a folder…}} وټاکئ او فولډر د Studio په خپل ډیالوګ کې وټاکئ.
2. اوس مرستندوی کولی شي هلته فایلونه وښيي (`files_list`)، نقشه خلاصه کړي (`drawing_open`)، هلته یې د DWG نسخه یا DXF په توګه خوندي کړي، PDF یا SVG فایل ته چاپ کړي، LISP فایل پورته کړي، او یو کمانډ ته هغه فایل ورکړي چې غواړي (`INSERT` `F`، `XATTACH`، د ټکي فایل)، یا ووايي چې د یو کمانډ فایل چېرته لاړ شي (د `COUNT` CSV، `PUBLISH`).
3. {{ui:Remove}} فولډر سمدلاسه بېرته اخلي. د نورو ځایونو لارې رد کېږي، او هغه فایل چې دمخه شتون لري یوازې هغه وخت بدلېږي کله چې مرستندوی دا وغواړي یا خپله فایل لیکلی وي.

خلاصول لاهم **Read** ته اړتیا لري؛ د نقشې لیکل **Save** ته اړتیا لري؛ هر بل فایل **Export** ته اړتیا لري.

هغه وسایل چې ستاسو په چیک شوو اجازو کې نه دي، اصلاً مرستندوی ته نه وړاندې کېږي، او که مرستندوی بیا هم یو وغواړي، CadCraft یې رد کوي او په فعالیت لاګ کې یې لیکي. سوئچ بند کول هرې اړیکې سمدلاسه پای ته رسوي. {{ui:Reset CadCraft settings}} هم دا بند کوي.

## خپل مرستندوی وصل کړئ

مرستندويان ستاسو په کمپیوټر کې **CadCraft Studio** له لارې نښلېږي: دا یو کوچنی سرور پیلوي چې یوازې همدا کمپیوټر ورته رسېدای شي (پته `127.0.0.1`)، او د یوې ټوکن لخوا ساتل کېږي چې Studio یې هر پیل کې جوړوي. Studio خلاص کړئ، {{ui:Connect an assistant}} وټاکئ، او پته او ټوکن کاپي کړئ.

- په خپل مرستندوی کې د HTTP ډول MCP سرور د پتې سره (داسې ښکاري `http://127.0.0.1:47615/mcp`) او هیډر `Authorization: Bearer <token>` اضافه کړئ. Studio د پیست کولو امستنې ښيي.

په Studio کې {{ui:New token}} ټول نښلېدلي مرستندويان په نوي ټوکن بیا نښلوي. هېڅکله ټوکن شریک نکړئ: هر څوک چې دا ولري، تر هغې چې Studio خلاص وي، د هغو اپلیکیشنونو کارولی شي چې تاسو یې فعال کړي.

:::note
یو براوزر ټب د مرستندوي لپاره اړیکه نشي خلاصولی: په براوزر اپلیکیشنونو کې سوئچ هېڅ اغېز نلري تر هغې چې تاسو په خپل کمپیوټر کې CadCraft Studio ونه کاروئ.
:::

## تاسو لاهم کنټرول لرئ

- **هر عمل یو بېرته کولو ګام دی**، د مرستندوی نوم ورسره لیکل شوی، د بېلګې په توګه "Assistant: LINE". {{key:Mod+Z}} وټکاوئ څو د مرستندوی وروستی عمل په بشپړه توګه بېرته واخلئ.
- **تاسو ګورئ چې دا څه کوي.** د هغه کمانډونه د کمانډ تاریخ کې د **[Assistant]** په مخ کې ښکاري، او نقشه د کار پر مهال بیا انځوریږي.
- **دا ستاسو انتظار کوي.** کله چې تاسو په یو کمانډ کې یاست، مرستندوی کولی شي نقشه ولولي خو بدلون ورنکړي؛ ورته ویل کېږي چې کله تاسو بشپړ کړئ بیا هڅه وکړي.
- **تاسو پوهېږئ کله چې یو وصل وي.** د اپ بار یوه تڼۍ د نښلېدلي مرستندوی نوم ښيي. پرې کلیک وکړئ څو وګورئ چې څه کولی شي، یا دا **قطع** کړئ.
- **فعالیت.** {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Assistants}} › {{ui:Activity}} هر غږ لیست کوي: کله، کوم وسیله، ترسره شو یا رد شو، او د بېرته کولو هغه ګام چې جوړ یې کړ. {{ui:Save the log}} یوه کاپي ساتي.

## مرستندوی څه غوښتلی شي

| وسیله | اجازه | څه کوي |
|---|---|---|
| `app_info`, `drawing_describe`, `view_describe` | Read | د نقشې نوم، واحدونه، لایې، بلاکونه، پاڼې؛ څه چې په پرده کې دي |
| `files_list`, `drawing_open` | Read | Studio: په خپلو فولډرونو کې فایلونه؛ یو یې په دې کړکۍ کې خلاصول |
| `objects_list`, `object_get`, `selection_get` | Read | شیان د خپلې جیومیټري، اوږدوالي او مساحت سره (یا یوازې شمیر، د ډول او لایې له مخې)؛ ټاکنه |
| `drawing_check` | Read | قواعد لکه اجازه شوې لایې، د 0 لایې کې هېڅ نه، رنګونه ByLayer، د متن لوړوالی |
| `view_screenshot` | Read | د نقشې انځور لکه څنګه چې ښودل شوی |
| `command_run` | Edit | د کمانډ کرښې ته لیکي: `LINE 0,0 @100,0 @0,50 ` داسې لوستل کېږي لکه څنګه چې تاسو یې لیکئ (ځای ځواب پای ته رسوي)، یا د هر ځواب سره یوه لیست. کمانډ خلاص پریښودای شي او په بل غږ کې دوام ورکوي |
| `script_run` | Edit | یو سکریپټ (`.scr`) یا LISP فایل، لکه څنګه چې {{ui:APPLOAD}} یې پورته کوي |
| `block_insert` | Edit | یو بلاک د خپلو ځانګړتیا ارزښتونو سره په یو ګام کې ږدي |
| `selection_set`, `undo` | Edit | شیان د راتلونکي کمانډ لپاره ټاکي؛ خپل ګامونه بېرته کوي |
| `drawing_save` | Save | د CadCraft خپل {{ui:Save}}، یا {{ui:Save as}} ستاسو په یو فولډر کې |
| `drawing_plot` | Export | د پاڼې یا ماډل PDF یا SVG، په پیمانه یا برابر شوی (د PDF لاندې پاڼې تر اوسه په دې لاره نه چاپېږي) |

کله چې مرستندوی کمانډ چلوي، CadCraft خپلې پوښتنې د ډیالوګ پر ځای په کمانډ کرښه کې کوي (د بېلګې په توګه، آیا بشپړه نقشه یا یو بلاک دننه کړي)، څو مرستندوی ورته ځواب ووایي. کتابتون او موندنه لاهم تاسو ته اړتیا لري؛ مرستندوی ته ویل شوي چې له تاسو وپوښتي.

## پرته له CadCraft خلاصولو فایلونو سره کار

د CadCraft MCP سرور (`cadcraft-mcp`) او د کمانډ کرښه (`cadcraft`) د CadCraft د خپل نقشې کوډ په Node.js کې چلوي، پرته له کړکۍ. دوی Node.js 20 یا نوی ته اړتیا لري.

- **MCP سرور** یوازې په هغو فولډرونو کې کار کوي چې تاسو یې نوم اخلئ، او یوازې په هغو اجازو سره چې ورکوئ: `npx @getcadcraft/mcp --root ~/Drawings --allow read,edit`. پرته له `--root` نشي کولی هیڅ فایل خلاص کړي؛ پرته له `--allow` یوازې لوستلی شي. دا IFC ماډلونه، د مقدار محاسبې او په PDF سیټونو کې نښې هم لوستلی شي.
- **د کمانډ کرښه** ستاسو د خپلو سکریپټونو لپاره ده: `cadcraft info plan.dwg`، `cadcraft run cleanup.scr plan.dwg -o plan-clean.dwg`، `cadcraft convert plan.dwg plan.dxf`، `cadcraft plot plan.dwg plan.pdf --all`، `cadcraft plot plan.dwg plan.svg`، `cadcraft check plan.dwg --rules rules.json`. څو فایلونه یوځل: `cadcraft convert *.dwg out --to dxf`، `cadcraft plot *.dwg pdfs --to pdf`، `cadcraft check *.dwg --rules rules.json`. د پروګرام لپاره د لوستلو وړ محصول لپاره `--json` اضافه کړئ.

:::note
که `npx @getcadcraft/mcp` ووایي چې بسته ونه موندل شوه، دا لا خپره شوې نه ده. په getcadcraft.com خبرونه به ووایي کله چې وي.
:::

## که یو شی کار ونه کړي

- **مرستندوی هېڅ CadCraft وسیله نه ویني:** وګورئ چې سوئچ په دې کړکۍ کې فعال وي، او کړکۍ په Studio کې خلاصه وي.
- **"needs the edit permission":** د {{ui:Assistants}} لاندې **Edit** چیک کړئ، بیا بیا وپوښتئ.
- **"outside the folders assistants may use":** هغه فولډر د {{ui:Assistants}} › {{ui:Folders it may use}} لاندې اضافه کړئ، یا مرستندوی ته ووایاست چې یو فایل وکاروي چې په یو مخکې اضافه شوي فولډر کې دی.
- **"401" یا "token" تېروتنې:** ټوکن بدل شوی (Studio بیا پیل شو، یا {{ui:New token}}). نوی یې د مرستندوي په امستنو کې کاپي کړئ.
- **د هغه بدلون غلط و:** {{key:Mod+Z}} وټکاوئ. یو ټک د مرستندوي یو بشپړ عمل بېرته اخلي.
