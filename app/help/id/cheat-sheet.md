Ketik nama pendek (alias) lalu tekan Enter, atau klik alatnya. Esc membatalkan. Enter pada baris kosong mengulang perintah terakhir.

**Cetak:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (satu halaman A4; pada kertas Letter, cetak dengan "paskan ke halaman").

## Menggambar

| Ketik | Perintah | Fungsi |
|---|---|---|
| `L` | {{cmd:LINE}} | Menggambar garis lurus |
| `PL` | {{cmd:PLINE}} | Menggambar rantai garis dan busur yang tersambung |
| `C` | {{cmd:CIRCLE}} | Menggambar lingkaran (pusat dan radius) |
| `A` | {{cmd:ARC}} | Menggambar busur |
| `REC` | {{cmd:RECTANG}} | Menggambar persegi panjang dari dua sudut |
| `POL` | {{cmd:POLYGON}} | Menggambar poligon beraturan |
| `EL` | {{cmd:ELLIPSE}} | Menggambar elips |
| `DT` | {{cmd:TEXT}} | Menulis satu baris teks |
| `T` | {{cmd:MTEXT}} | Menulis teks yang membungkus (paragraf) |
| `H` | {{cmd:HATCH}} | Mengisi area dengan pola |

## Mengubah

| Ketik | Perintah | Fungsi |
|---|---|---|
| `M` | {{cmd:MOVE}} | Memindahkan objek |
| `CO` | {{cmd:COPY}} | Menyalin objek |
| `RO` | {{cmd:ROTATE}} | Memutar objek mengelilingi sebuah titik |
| `SC` | {{cmd:SCALE}} | Memperbesar atau memperkecil objek |
| `MI` | {{cmd:MIRROR}} | Membalik objek terhadap sebuah garis |
| `O` | {{cmd:OFFSET}} | Menggambar salinan sejajar pada jarak tertentu |
| `TR` | {{cmd:TRIM}} | Memotong objek sampai ke tempat objek lain memotongnya |
| `EX` | {{cmd:EXTEND}} | Memperpanjang objek sampai objek lain |
| `F` | {{cmd:FILLET}} | Membulatkan sudut dengan busur |
| `CHA` | {{cmd:CHAMFER}} | Memotong sudut dengan tepi lurus |
| `E` | {{cmd:ERASE}} | Menghapus objek |
| `X` | {{cmd:EXPLODE}} | Menguraikan blok atau polyline menjadi bagian-bagiannya |
| `S` | {{cmd:STRETCH}} | Memindahkan ujung-ujung di dalam jendela silang |
| `AR` | {{cmd:ARRAY}} | Menyalin dalam grid atau lingkaran |
| `J` | {{cmd:JOIN}} | Menggabungkan garis dan busur menjadi satu objek |
| `BR` | {{cmd:BREAK}} | Memotong objek menjadi dua, atau mengambil satu bagian |

## Dimensi

| Ketik | Perintah | Fungsi |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Memberi dimensi horizontal atau vertikal |
| `DAL` | {{cmd:DIMALIGNED}} | Memberi dimensi sepanjang garis miring |
| `DRA` | {{cmd:DIMRADIUS}} | Memberi dimensi radius |
| `DAN` | {{cmd:DIMANGULAR}} | Memberi dimensi sudut |

## Blok dan layer

| Ketik | Perintah | Fungsi |
|---|---|---|
| `B` | {{cmd:BLOCK}} | Membuat blok dari objek |
| `I` | {{cmd:INSERT}} | Menempatkan blok |
| `LA` | {{cmd:LAYER}} | Membuka layer |

## Tampilan dan pemeriksaan

| Ketik | Perintah | Fungsi |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | Zoom masuk, keluar, atau ke semuanya (E) |
| `DI` | {{cmd:DIST}} | Mengukur jarak dan sudut |
| `LI` | {{cmd:LIST}} | Menampilkan rincian sebuah objek |
| `MA` | {{cmd:MATCHPROP}} | Menyalin tampilan satu objek ke objek lain |

## File

| Ketik | Perintah | Fungsi |
|---|---|---|
| `U` | {{cmd:UNDO}} | Membatalkan perintah terakhir |
| `SAVE` | {{cmd:SAVE}} | Menyimpan gambar |
| `PLOT` | {{cmd:PLOT}} | Plot ke PDF |

## Tombol

Ctrl (Cmd pada Mac): Z urungkan · Y ulangi · S simpan · P plot.  F3 snap objek · F8 ortho · F10 polar.  Space atau Enter mengulang perintah terakhir · roda mouse melakukan zoom · menyeret roda menggeser tampilan

Baru mulai menggambar? Ketik `TOUR` untuk gambar pertama yang dipandu, baca [Memulai](topic:getting-started), atau lihat semua perintah di [Perintah](topic:commands). Berasal dari perangkat lunak gambar lain: [Jika Anda berasal dari perangkat lunak gambar lain](topic:coming-from) dan [peta perintah](topic:command-map).
