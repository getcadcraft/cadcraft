Escriba el nombre corto (el alias) y pulse Intro, o haga clic en la herramienta. Esc cancela. Intro en una línea vacía repite el último comando.

**Imprímala:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (una página A4; en papel Carta imprímala con "ajustar a la página").

## Dibujar

| Escriba | Comando | Qué hace |
|---|---|---|
| `L` | {{cmd:LINE}} | Dibuja líneas rectas |
| `PL` | {{cmd:PLINE}} | Dibuja una cadena de líneas y arcos unidos |
| `C` | {{cmd:CIRCLE}} | Dibuja un círculo (centro y radio) |
| `A` | {{cmd:ARC}} | Dibuja un arco |
| `REC` | {{cmd:RECTANG}} | Dibuja un rectángulo desde dos esquinas |
| `POL` | {{cmd:POLYGON}} | Dibuja un polígono regular |
| `EL` | {{cmd:ELLIPSE}} | Dibuja una elipse |
| `DT` | {{cmd:TEXT}} | Escribe una línea de texto |
| `T` | {{cmd:MTEXT}} | Escribe texto que se ajusta al ancho (párrafo) |
| `H` | {{cmd:HATCH}} | Rellena un área con una trama |

## Modificar

| Escriba | Comando | Qué hace |
|---|---|---|
| `M` | {{cmd:MOVE}} | Desplaza objetos |
| `CO` | {{cmd:COPY}} | Copia objetos |
| `RO` | {{cmd:ROTATE}} | Gira objetos alrededor de un punto |
| `SC` | {{cmd:SCALE}} | Hace los objetos más grandes o más pequeños |
| `MI` | {{cmd:MIRROR}} | Voltea objetos respecto a una línea |
| `O` | {{cmd:OFFSET}} | Dibuja una copia paralela a una distancia |
| `TR` | {{cmd:TRIM}} | Recorta objetos hasta donde los cruzan otros |
| `EX` | {{cmd:EXTEND}} | Alarga objetos hasta otros |
| `F` | {{cmd:FILLET}} | Redondea una esquina con un arco |
| `CHA` | {{cmd:CHAMFER}} | Corta una esquina con un borde recto |
| `E` | {{cmd:ERASE}} | Borra objetos |
| `X` | {{cmd:EXPLODE}} | Descompone un bloque o una polilínea en sus partes |
| `S` | {{cmd:STRETCH}} | Desplaza los extremos que quedan dentro de una ventana de cruce |
| `AR` | {{cmd:ARRAY}} | Copia en una rejilla o en un círculo |
| `J` | {{cmd:JOIN}} | Une líneas y arcos en un solo objeto |
| `BR` | {{cmd:BREAK}} | Parte un objeto en dos, o quita un trozo |

## Acotar

| Escriba | Comando | Qué hace |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Acota en horizontal o en vertical |
| `DAL` | {{cmd:DIMALIGNED}} | Acota a lo largo de una línea inclinada |
| `DRA` | {{cmd:DIMRADIUS}} | Acota un radio |
| `DAN` | {{cmd:DIMANGULAR}} | Acota un ángulo |

## Bloques y capas

| Escriba | Comando | Qué hace |
|---|---|---|
| `B` | {{cmd:BLOCK}} | Crea un bloque a partir de objetos |
| `I` | {{cmd:INSERT}} | Coloca un bloque |
| `LA` | {{cmd:LAYER}} | Abre las capas |

## Vista y consulta

| Escriba | Comando | Qué hace |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | Acerca, aleja o muestra todo (E) |
| `DI` | {{cmd:DIST}} | Mide una distancia y un ángulo |
| `LI` | {{cmd:LIST}} | Muestra los detalles de un objeto |
| `MA` | {{cmd:MATCHPROP}} | Copia el aspecto de un objeto a otros |

## Archivo

| Escriba | Comando | Qué hace |
|---|---|---|
| `U` | {{cmd:UNDO}} | Deshace el último comando |
| `SAVE` | {{cmd:SAVE}} | Guarda el dibujo |
| `PLOT` | {{cmd:PLOT}} | Traza a PDF |

## Teclas

Ctrl (Cmd en Mac): Z deshacer · Y rehacer · S guardar · P trazar.  F3 referencia a objetos · F8 orto · F10 polar.  Espacio o Intro repite el último comando · la rueda hace zoom · arrastrar la rueda desplaza

¿Empieza en el dibujo? Escriba `TOUR` para un primer dibujo guiado, lea [Primeros pasos](topic:getting-started), o consulte todos los comandos en [Comandos](topic:commands). Si viene de otro programa de dibujo: [Si viene de otro programa de dibujo](topic:coming-from) y el [mapa de comandos](topic:command-map).
