छोटो नाम (उपनाम) टाइप गरेर Enter थिच्नुहोस्, वा उपकरणमा क्लिक गर्नुहोस्। Esc ले रद्द गर्छ। खाली लाइनमा Enter ले अन्तिम आदेश दोहोर्याउँछ।

**छाप्नुहोस्:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (एउटा A4 पाना; Letter कागजमा "पृष्ठमा फिट गर्नुहोस्" विकल्पसँग छाप्नुहोस्।)

## रेखाङ्कन

| प्रकार | आदेश | यसले के गर्छ |
|---|---|---|
| `L` | {{cmd:LINE}} | सीधा रेखाहरू कोर्नुहोस् |
| `PL` | {{cmd:PLINE}} | जोडिएका रेखा र चापहरूको शृंखला कोर्नुहोस् |
| `C` | {{cmd:CIRCLE}} | वृत्त कोर्नुहोस् (केन्द्र र त्रिज्या) |
| `A` | {{cmd:ARC}} | चाप कोर्नुहोस् |
| `REC` | {{cmd:RECTANG}} | दुई कुनाबाट आयत कोर्नुहोस् |
| `POL` | {{cmd:POLYGON}} | नियमित बहुभुज कोर्नुहोस् |
| `EL` | {{cmd:ELLIPSE}} | अण्डाकार कोर्नुहोस् |
| `DT` | {{cmd:TEXT}} | पाठको एउटा लाइन लेख्नुहोस् |
| `T` | {{cmd:MTEXT}} | पङ्क्तिभित्र बेरिने पाठ (अनुच्छेद) लेख्नुहोस् |
| `H` | {{cmd:HATCH}} | क्षेत्रलाई ढाँचाले भर्नुहोस् |

## परिमार्जन

| प्रकार | आदेश | यसले के गर्छ |
|---|---|---|
| `M` | {{cmd:MOVE}} | वस्तुहरू सार्नुहोस् |
| `CO` | {{cmd:COPY}} | वस्तुहरू प्रतिलिपि गर्नुहोस् |
| `RO` | {{cmd:ROTATE}} | वस्तुहरूलाई एउटा बिन्दुको वरिपरि घुमाउनुहोस् |
| `SC` | {{cmd:SCALE}} | वस्तुहरू ठूला वा साना बनाउनुहोस् |
| `MI` | {{cmd:MIRROR}} | वस्तुहरूलाई एउटा रेखाको आरपार पल्टाउनुहोस् |
| `O` | {{cmd:OFFSET}} | निश्चित दूरीमा समानान्तर प्रतिलिपि कोर्नुहोस् |
| `TR` | {{cmd:TRIM}} | अरू वस्तुहरू काटिने ठाउँसम्म वस्तुहरू छोट्याउनुहोस् |
| `EX` | {{cmd:EXTEND}} | अरू वस्तुहरूसम्म वस्तुहरू लम्ब्याउनुहोस् |
| `F` | {{cmd:FILLET}} | चापले कुना गोलो बनाउनुहोस् |
| `CHA` | {{cmd:CHAMFER}} | सीधा किनाराले कुना काट्नुहोस् |
| `E` | {{cmd:ERASE}} | वस्तुहरू मेटाउनुहोस् |
| `X` | {{cmd:EXPLODE}} | ब्लक वा पोलिलाइनलाई यसका भागहरूमा तोड्नुहोस् |
| `S` | {{cmd:STRETCH}} | क्रसिङ विन्डोभित्रका छेउहरू सार्नुहोस् |
| `AR` | {{cmd:ARRAY}} | ग्रिड वा वृत्तमा प्रतिलिपि गर्नुहोस् |
| `J` | {{cmd:JOIN}} | रेखा र चापहरूलाई एउटै वस्तुमा जोड्नुहोस् |
| `BR` | {{cmd:BREAK}} | एउटा वस्तुलाई दुई भागमा काट्नुहोस्, वा एउटा टुक्रा निकाल्नुहोस् |
