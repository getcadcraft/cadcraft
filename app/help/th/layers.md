## สิ่งที่คุณจะสร้าง

เลเยอร์สามชั้น ได้แก่ Walls, Doors และ Notes แต่ละชั้นมีสีของตัวเอง มีวัตถุวาดอยู่บนแต่ละชั้น และย้ายวัตถุระหว่างชั้นได้

## พาเนลเลเยอร์

เลเยอร์อยู่ในพาเนลด้านซ้าย ภายใต้ {{ui:เลเยอร์}} แต่ละแถวแสดง จากซ้ายไปขวา:

- จุด: เต็มสำหรับ**เลเยอร์ปัจจุบัน** ซึ่งวัตถุใหม่จะไปอยู่ที่นั่น
- ช่องสี
- ชื่อเลเยอร์
- ปุ่มสี่ปุ่ม: เปิด/ปิด (ตา) แช่แข็ง (เกล็ดหิมะ) ล็อก (แม่กุญแจ) และพล็อต (เครื่องพิมพ์)

ทุกแบบมีเลเยอร์ชื่อ `0` พิมพ์ `LA` แล้วกด {{key:Enter}} เพื่อกระโดดไปที่พาเนล

## สร้างเลเยอร์

1. คลิก {{ui:เลเยอร์ใหม่}} เหนือรายการ กล่องชื่อจะเปิดขึ้น
2. พิมพ์ `Walls` แล้วกด {{key:Enter}} (หรือคลิก {{ui:เพิ่ม}})

แถบสถานะจะบอกว่า "Added layer Walls and made it current." เลเยอร์ใหม่ได้สีที่ 7 (ดำบนธีมสว่าง ขาวบนธีมมืด)

3. คลิก {{ui:เลเยอร์ใหม่}} อีกครั้ง พิมพ์ `Doors` แล้วกด {{key:Enter}}
4. คลิก {{ui:เลเยอร์ใหม่}} อีกครั้ง พิมพ์ `Notes` แล้วกด {{key:Enter}}

ตอนนี้ Notes เป็นเลเยอร์ปัจจุบัน

## ให้แต่ละเลเยอร์มีสี

1. คลิกช่องสีในแถว Walls ตัวเลือกสีของระบบจะเปิดขึ้น
2. เลือกสีแล้วยืนยัน

ช่องสีและทุกอย่างบน Walls ที่มีสี {{ui:ตามเลเยอร์}} จะเปลี่ยนตาม

:::note
สีที่คุณเลือกซึ่งตรงกับสีมาตรฐาน CAD 255 สีหนึ่ง จะถูกเก็บเป็นหมายเลขนั้น สีอื่นจะถูกเก็บไว้อย่างตรงตามใน CadCraft แต่จะถูกบันทึกเป็นสีมาตรฐานที่ใกล้ที่สุดในไฟล์ DWG หรือ DXF
:::

## วาดบนเลเยอร์

1. คลิกชื่อ **Walls** ในรายการ จุดของมันจะเต็ม และแถบสถานะจะบอกว่า "Current layer: Walls"
2. วาดสี่เหลี่ยม (`REC`) มันจะไปอยู่บน Walls
3. คลิก **Doors** แล้ววาดส่วนโค้ง (`A`) มันจะไปอยู่บน Doors

คุณยังเลือกเลเยอร์ปัจจุบันได้ใน {{ui:การตั้งค่าปัจจุบัน}} ทางขวา (เมื่อไม่ได้เลือกอะไร) ภายใต้ {{ui:เลเยอร์}}

## ย้ายวัตถุไปเลเยอร์อื่น

1. เลือกวัตถุ
2. ในพาเนลขวา เลือกเลเยอร์ใหม่ใน {{ui:เลเยอร์}}

วัตถุจะย้ายไปเลเยอร์นั้นและรับสีของมัน หากสีของมันเป็น {{ui:ตามเลเยอร์}}

## ปิด แช่แข็ง ล็อก และพล็อต

| ปุ่ม | สิ่งที่ทำ |
|---|---|
| เปิด/ปิด (ตา) | ซ่อนวัตถุของเลเยอร์ มองไม่เห็น เลือกไม่ได้ และจับจุดไม่ได้ |
| แช่แข็ง (เกล็ดหิมะ) | ผลเหมือนปิดใน CadCraft แยกไว้เพราะโปรแกรมอื่นปฏิบัติต่างกัน และการตั้งค่านี้ถูกบันทึกไว้ |
| ล็อก (แม่กุญแจ) | วัตถุยังมองเห็นได้และคุณจับจุดได้ แต่เลือกหรือเปลี่ยนไม่ได้ เหมาะกับพื้นหลังที่คุณลอกทับ |
| พล็อต (เครื่องพิมพ์) | เมื่อกดไว้ เลเยอร์จะแสดงบนหน้าจอแต่**ถูกตัดออกจากการพล็อตและ PDF** ใช้กับเส้นช่วยวาดและหมายเหตุถึงตัวเอง |

วางเมาส์บนปุ่มเพื่อดูว่าจะทำอะไร ("Turn off", "Freeze", "Lock", "Do not plot this layer")

คุณปิดเลเยอร์ปัจจุบันไม่ได้ แถบสถานะจะบอกว่า "That is the current layer. Make another layer current first." การคลิกชื่อเลเยอร์เพื่อทำให้เป็นปัจจุบันจะเปิดและยกเลิกการแช่แข็งให้ด้วย

การเปลี่ยนแปลงเลเยอร์ทุกครั้ง ไม่ว่าในพาเนลหรือโดยคำสั่ง เป็นหนึ่งขั้นของ undo: {{key:Mod+Z}} จะคืนค่าเดิม

## ทำงานกับเลเยอร์โดยการเลือกวัตถุ

คุณไม่ต้องรู้ชื่อเลเยอร์ เพียงเลือกวัตถุที่อยู่บนเลเยอร์นั้น พิมพ์คำสั่ง หรือเปิด {{ui:เครื่องมือ}} ที่ด้านบนของพาเนล {{ui:เลเยอร์}}

| คำสั่ง | สิ่งที่ทำ |
|---|---|
| {{cmd:LAYISO}} | เลือกวัตถุ แล้วกด {{key:Enter}}: เปิดเฉพาะเลเยอร์ของมัน เลเยอร์อื่นทั้งหมดจะปิด ถ้าเลเยอร์ปัจจุบันถูกปิด เลเยอร์ที่แยกไว้หนึ่งชั้นจะกลายเป็นปัจจุบัน |
| {{cmd:LAYUNISO}} | เปิดเลเยอร์ที่ {{cmd:LAYISO}} ครั้งล่าสุดปิดไว้กลับ และคืนเลเยอร์ปัจจุบันที่มันเปลี่ยน |
| {{cmd:LAYOFF}} | คลิกวัตถุทีละชิ้น: เลเยอร์ของแต่ละชิ้นจะถูกปิด พิมพ์ `U` เพื่อเอาชิ้นสุดท้ายกลับ และ {{key:Enter}} เพื่อจบ |
| {{cmd:LAYFRZ}} | เหมือนกัน แต่แช่แข็งแต่ละเลเยอร์ |
| {{cmd:LAYMCUR}} | คลิกวัตถุ: เลเยอร์ของมันจะเป็นปัจจุบัน (และเปิดและยกเลิกการแช่แข็งด้วย) เมื่อเลือกวัตถุหนึ่งชิ้นอยู่แล้ว จะใช้ชิ้นนั้น |
| {{cmd:LAYON}} | เปิดทุกเลเยอร์ |
| {{cmd:LAYTHW}} | ยกเลิกการแช่แข็งทุกเลเยอร์ |

เลเยอร์ปัจจุบันจะไม่ถูกปิดหรือแช่แข็งด้วยวิธีนี้ ประวัติจะบอกเช่นนั้น และคุณทำให้เลเยอร์อื่นเป็นปัจจุบันด้วย {{cmd:LAYMCUR}} ก่อนได้ การเลือกอินสแตนซ์บล็อกจะใช้เลเยอร์ของอินสแตนซ์นั้น

## เปลี่ยนชื่อ รวม และลบเลเยอร์

- {{cmd:RENAME}}: พิมพ์ `LA` ชื่อเก่า แล้วชื่อใหม่ วัตถุทุกชิ้นบนเลเยอร์จะตามไป (`B` เปลี่ยนชื่อบล็อกในลักษณะเดียวกัน พร้อมทุกอินสแตนซ์ของมัน)
- {{cmd:LAYMRG}}: คลิกวัตถุบนแต่ละเลเยอร์ที่จะรวม (หรือพิมพ์ `N` แล้วชื่อ) กด {{key:Enter}} แล้วเลือกเลเยอร์เป้าหมาย และตอบ `Y` วัตถุจะย้ายไปเลเยอร์เป้าหมาย ทั้งในโมเดล บนแผ่นงาน และในบล็อก และเลเยอร์ที่รวมแล้วจะหายไป
- {{cmd:LAYDEL}}: เลือกวัตถุบนเลเยอร์ (หรือ `N` แล้วชื่อ) และตอบ `Y` เลเยอร์จะหายไป**พร้อมวัตถุทุกชิ้นบนมัน** ทุกที่ เลเยอร์ 0, DEFPOINTS และเลเยอร์ปัจจุบันจะลบไม่ได้

แต่ละอย่างเป็นหนึ่งขั้นของ undo ทั้งสามอยู่ใน {{ui:เครื่องมือ}} ที่ด้านบนของพาเนล {{ui:เลเยอร์}}

1. คลิกเส้นผนังหนึ่งเส้น แล้วพิมพ์ `LAYISO` และกด {{key:Enter}} มีเพียง Walls ที่เปิดอยู่
2. วาดหรือเปลี่ยนสิ่งที่ต้องการบน Walls
3. พิมพ์ `LAYUNISO` และกด {{key:Enter}} Doors และ Notes จะกลับมา

## ข้อผิดพลาดที่พบบ่อย

- **เส้นใหม่ไปอยู่ผิดเลเยอร์** ดูว่าจุดใดเต็มก่อนวาด เลเยอร์ใหม่จะเป็นปัจจุบันทันทีที่คุณเพิ่ม
- **วัตถุเลือกไม่ได้** เลเยอร์ของมันถูกล็อก ปิด หรือแช่แข็ง
- **เลเยอร์ยังพิมพ์ในโปรแกรมอื่น** DXF R12 เก็บค่า "ไม่พล็อต" ไม่ได้ CadCraft เก็บการตั้งค่านี้ไว้เองเมื่อแบบมีแผ่นงาน แต่โปรแกรมอื่นจะพล็อตเลเยอร์นั้น
- **ชื่อเลเยอร์เป็นตัวพิมพ์ใหญ่หลังบันทึก** DXF R12 เก็บชื่อเป็นตัวพิมพ์ใหญ่ ดังนั้น `Walls` จะกลับมาเป็น `WALLS` และช่องว่างจะกลายเป็น `_` DWG ที่บันทึกไว้จะเก็บชื่อตามที่คุณพิมพ์
- **เปลี่ยนชื่อ รวม หรือลบเลเยอร์** ใช้ {{cmd:RENAME}}, {{cmd:LAYMRG}} หรือ {{cmd:LAYDEL}} (อยู่ใน {{ui:เครื่องมือ}} ด้วย) ดูด้านบน

## จัดกลุ่มเลเยอร์

ทำให้รายการสั้นลงด้วยการใส่เลเยอร์ในโฟลเดอร์ เช่น Existing, Proposed และ Services แต่ละโฟลเดอร์พับได้ และสวิตช์ของมันจะเปิดหรือปิด แช่แข็ง หรือล็อกเลเยอร์ทั้งหมดในโฟลเดอร์ร่วมกัน เลเยอร์ปัจจุบันจะไม่ถูกปิดเลย

ใน {{ui:เครื่องมือ}} บนพาเนลเลเยอร์ เลือก {{ui:เพิ่มกลุ่มสำเร็จรูป}} สำหรับชุดที่ทำไว้สำหรับงานที่อยู่อาศัยขนาดเล็ก {{ui:จัดกลุ่มตามชื่อ}} เพื่อจัดกลุ่มเลเยอร์ที่มีคำนำหน้าเดียวกัน (`E-Walls`, `E-Doors`) หรือ {{ui:กลุ่มใหม่}} ลากเลเยอร์ไปยังโฟลเดอร์ หรือใช้รายการด้านบนสำหรับเลเยอร์ปัจจุบัน พิมพ์ใน {{ui:ค้นหาเลเยอร์}} เพื่อกรองรายการ `LAYGROUP` (`LG`) ทำเช่นเดียวกันที่บรรทัดคำสั่ง

หากต้องการเปลี่ยนชื่อกลุ่ม ดับเบิลคลิกชื่อของมัน (หรือเลือกแล้วกด {{key:F2}}) พิมพ์ชื่อใหม่แล้วกด {{key:Enter}} {{key:Esc}} จะคงชื่อเดิมไว้ และ {{cmd:UNDO}} จะคืนค่า {{ui:กลุ่มใหม่}} อยู่ใน {{ui:เครื่องมือ}} บนพาเนลเลเยอร์

เลเยอร์เองไม่เปลี่ยน ดังนั้นโปรแกรม CAD อื่นจะเห็นเป็นรายการแบบแบนทั่วไป CadCraft เก็บกลุ่มไว้ในไฟล์
