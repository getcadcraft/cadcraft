CadCraft ใช้ชื่อคำสั่งและชื่อย่อที่คนรู้จักจากโปรแกรมการร่างแบบอื่น: พิมพ์ `L` สำหรับเส้น `TR` เพื่อตัดแต่ง `E` เพื่อลบ ดังนั้นสำหรับคำสั่งส่วนใหญ่ไม่มีตารางแปลให้เรียนรู้ ชื่อที่คุณรู้คือชื่อที่ใช้ได้ที่นี่ รายการด้านล่างคือทุกคำสั่งที่ CadCraft มี สร้างจากโปรแกรมเอง {{key:Enter}} ทำซ้ำคำสั่งล่าสุด และ `HELP` ในบรรทัดคำสั่งจะพิมพ์รายการเดียวกัน

สิ่งที่ไม่เหมือนกัน หรือยังไม่ได้สร้าง:

- **Save** ดาวน์โหลดสำเนาในเบราว์เซอร์ ({{cmd:SAVE}}, {{cmd:SAVEAS}}) ใน CadCraft Studio จะเขียนไฟล์ ดู [มาจากซอฟต์แวร์ร่างแบบอื่น](topic:coming-from)
- **PLOT** สร้าง PDF (และ PNG กับ SVG) พร้อมตารางรูปแบบการพล็อต ไม่มีตัวจัดการการตั้งค่าหน้า
- **DIMSTYLE** และ **PEDIT** ถูกสร้างแล้ว **PEDIT** ไม่มีตัวเลือก Edit-vertex (grip ทำหน้าที่นั้น)
- **TABLE** ยังไม่ได้สร้าง ส่วน {{cmd:XREF}}, {{cmd:SPLINE}} และ {{cmd:WBLOCK}} สร้างแล้ว
- คำสั่งของรูทีนเอง (AutoLISP `C:NAME`) จะปรากฏหลังจากคุณโหลดด้วย {{cmd:APPLOAD}} ไม่ได้แสดงในที่นี้

| `ARRAYPATH` |  | สำเนาของวัตถุตามเส้น ส่วนโค้ง โพลีไลน์ หรือเส้นโค้งอื่น |

| `AUNITS` | `ANGUNITS` | แสดงและพิมพ์มุมอย่างไร: องศาทศนิยม องศา-นาที-วินาที หรือทิศทางแบบสำรวจเช่น N45°23'30"E (ANGUNITS) |
