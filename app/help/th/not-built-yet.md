CadCraft อยู่ระหว่างการพัฒนา หน้านี้แสดงสิ่งที่บิลด์ปัจจุบันยังไม่ทำ เพื่อให้ไม่ต้องไปค้นหาเอง แต่ละรายการระบุสิ่งที่ควรทำแทนในวันนี้

## ไฟล์และการบันทึก

| ยังไม่ได้สร้าง | แทนที่ด้วยวันนี้ |
|---|---|
| ไฟล์ DWG ของ CadCraft ที่ตรวจในตัว AutoCAD เอง | ทุกเวอร์ชันที่บันทึกจะถูกอ่านกลับด้วยตัวอ่าน DWG ของโปรแกรมอื่นสามตัวและโดย CadCraft ดู [DWG เก็บอะไรและเปลี่ยนอะไร](topic:files#what-a-dwg-keeps-and-changes) |
| การบันทึก DXF ที่ใหม่กว่า 2000 | บันทึกเป็น DXF 2000 หรือเป็น DWG ถึง AutoCAD 2018 |
| การบันทึกทับไฟล์ที่เปิดในเบราว์เซอร์ | ทุกการบันทึกจะดาวน์โหลดสำเนาใหม่ ให้แทนที่ไฟล์เก่าด้วยตนเองหากต้องการ ใน CadCraft Studio {{key:Mod+S}} จะเขียนกลับไปยังไฟล์ที่คุณเปิด |
| การบันทึกบนคลาวด์และการซิงค์ระหว่างคอมพิวเตอร์ | CadCraft ยังไม่ส่งไฟล์ที่บันทึกขึ้นคลาวด์: เก็บไฟล์ DWG และ DXF ไว้ในโฟลเดอร์ของคุณเอง ใน CadCraft Studio [ประวัติ](topic:history) จะแสดงเวอร์ชันบนคลาวด์ของแบบที่บันทึกจากที่อื่น และสำเนาการบันทึกของคุณเองบนคอมพิวเตอร์เครื่องนี้ |
| โอเวอร์เลย์ และการแก้ไขแบบที่เชื่อมโยงในที่ | แนบแบบเป็นลิงก์และโหลดใหม่หลังจากเปลี่ยนแบบอื่น ลิงก์จะยังคงเป็นลิงก์เมื่อบันทึกเป็น DWG และ {{cmd:XCLIP}} ตัดลิงก์ได้ |
| ภาพใน DXF; ไวพ์เอาต์ (wipeout) ที่บังสิ่งที่อยู่ข้างใต้ | DXF เก็บภาพเป็นกรอบพร้อมชื่อไฟล์; DWG เก็บเป็นภาพ ดู [ภาพในแบบ](topic:pictures) ไวพ์เอาต์จะแสดงเป็นกรอบ |
| การแก้ไขมัลติลีดเดอร์ที่มีเส้นลีดเดอร์โค้ง มีเส้นลีดเดอร์ทั้งสองด้านของเนื้อหา หรือมีบล็อกที่หมุนหรือสเกลไม่เท่ากัน | วาดตามที่โปรแกรมอื่นวาด และเคลื่อนที่เป็นชิ้นเดียว มัลติลีดเดอร์ที่มีเส้นลีดเดอร์ตรงไปยังจุดลงจอดเดียว และมีข้อความหรือบล็อกเป็นเนื้อหา แก้ไขได้ ({{cmd:MLEADEREDIT}}) |
| ในตารางจากโปรแกรมอื่น: เซลล์ที่มีบล็อก การจัดรูปแบบข้อความในเซลล์ เส้นขอบและสีรายเซลล์ของตารางใน DXF ตารางที่แบ่งเป็นคอลัมน์ | ตารางจะเปิดเป็นตารางที่แก้ไขได้ ({{cmd:TABLEDIT}}) และแสดงตามที่โปรแกรมอื่นวาดจนกว่าคุณจะแก้ไข จากนั้น CadCraft จะวาดใหม่จากเซลล์: ข้อความธรรมดา สูตรเช่น `=G3*H3` และ `=Sum(I3:I9)` การจัดแนว และความสูงของข้อความ เซลล์ที่เป็นบล็อกจะว่างเปล่า ตาราง DWG ที่ไม่ได้แก้ไขจะถูกบันทึกกลับพร้อมข้อมูลเซลล์เดิม |
| วัตถุตารางจริงในไฟล์ DXF ที่บันทึกแล้ว | DWG เก็บตารางเป็นตารางที่โปรแกรมอื่นแก้ไขได้ DXF เก็บเป็นบล็อกที่วาดตาราง พร้อมบันทึกของ CadCraft เอง: CadCraft จะเปิดเป็นตารางอีกครั้ง โปรแกรมอื่นจะเห็นเป็นบล็อก ตารางที่สะท้อนหรือสเกลไม่เท่ากันจะถูกบันทึกแบบนั้นใน DWG ด้วย |
| การคัดลอกและวางกับโปรแกรมอื่น | คลิปบอร์ดของ CadCraft ทำงานระหว่างแบบและแท็บของ CadCraft ในเบราว์เซอร์เดียวกัน ไม่ทำงานกับโปรแกรมอื่น บันทึกเป็น DWG หรือ DXF แล้วเปิดที่โปรแกรมนั้น ดู [คัดลอก วาง และทำสำเนา](topic:copy-paste) |

## การวาดและการแก้ไข

| ยังไม่ได้สร้าง | แทนที่ด้วยวันนี้ |
|---|---|
| แพตเทิร์นแฮตช์ที่ CadCraft ไม่มี และการเติมแบบไล่สีตามที่โปรแกรมอื่นวาดทุกประการ | แฮตช์ที่เปิดมาพร้อมแพตเทิร์นที่ CadCraft ไม่มีจะแสดงเป็นโทนสี การเติมไล่สี ({{cmd:GRADIENT}}) วาดด้วยวิธีของ CadCraft เองสำหรับแต่ละชนิด คล้ายกับโปรแกรมอื่นในลักษณะ แต่ไม่ตรงจุดต่อจุด DWG 2004 ขึ้นไปเก็บเป็นแฮตช์ไล่สีจริง ในไฟล์ DXF 2000 หรือ DWG 2000 เฉพาะ CadCraft ที่อ่านกลับได้ ส่วนโปรแกรมอื่นจะเห็นเป็นการเติมทึบ แพตเทิร์นโหลดจากไฟล์ `.pat` ได้ และแฮตช์เชื่อมกับขอบเขตของมันได้ จากนั้นจะตามขอบเขตนั้น ดู [แฮตช์และพื้นที่เติม](topic:hatch) |
| เส้นชนิดที่มีรูปร่างหรือข้อความ และความหนาเส้นใน DXF R12 ที่บันทึกแล้ว | รูปร่างและข้อความในเส้นชนิดของไฟล์จะไม่ถูกนำมาใช้ในช่วงเส้นประ บันทึกเป็น DWG เพื่อเก็บความหนาเส้น |
| แฮตช์แบบมีแพตเทิร์นใน DXF ที่บันทึกแล้ว | R12 ไม่มีแฮตช์: จะบันทึกเป็นเส้นขอบ บันทึกเป็น DWG เพื่อเก็บแพตเทิร์น |
| อาร์เรย์ที่โปรแกรมอื่นสร้างหรือแก้ไขได้; แถวและระดับในอาร์เรย์แบบเส้นทางและโพลาร์; อาร์เรย์ที่ตามเส้นโค้งของเส้นทาง | อาร์เรย์ที่สร้างแบบเชื่อมโยง (ASsociative) ({{cmd:ARRAY}}, {{cmd:ARRAYPATH}}; แก้ไขด้วย {{cmd:ARRAYEDIT}}) จะถูกบันทึกเป็นการอ้างอิงบล็อกพร้อมตัวเลขของ CadCraft เอง โปรแกรมอื่นแสดง ย้าย พิมพ์ และแยกได้ แต่เปลี่ยนจำนวนไม่ได้ และอาร์เรย์ที่สร้างในโปรแกรมอื่นจะเปิดที่นี่เป็นการอ้างอิงบล็อกธรรมดา อาร์เรย์แบบเส้นทางเก็บสำเนาของเส้นทาง การแก้ไขเส้นโค้งภายหลังจะไม่ย้ายรายการ |
| วิวพอร์ตแผ่นที่ถูกตัดไปยังและมาจากโปรแกรมอื่น | วิวพอร์ตที่ถูกตัดด้วย {{cmd:VPCLIP}} หรือสร้างด้วย {{cmd:MVIEW}} แบบ Polygonal หรือ Object จะถูกบันทึกด้วยเส้นขอบของ CadCraft เอง โปรแกรมอื่นจะเปิดเป็นสี่เหลี่ยมรอบมัน และวิวพอร์ตที่ถูกตัดในโปรแกรมอื่นจะเปิดที่นี่เป็นสี่เหลี่ยมของมัน DXF R12 เก็บเฉพาะสี่เหลี่ยม |
| {{cmd:STRETCH}} ด้วยรูปหลายเหลี่ยมแบบข้าม | ใช้หน้าต่างข้ามหนึ่งอันหรือหลายอัน |
| {{cmd:PEDIT}} แก้ไขจุดยอด (ทีละจุดที่บรรทัดคำสั่ง) | กริป และเบราว์เซอร์จุดยอดในคุณสมบัติ (ทุกจุดยอด ความกว้าง และ bulge) ส่วนอื่นของ PEDIT ทำงานได้แล้ว ดู [สไปลน์และโพลีไลน์](topic:splines) |
| {{cmd:BREAK}}, {{cmd:LENGTHEN}}, {{cmd:OFFSET}}, {{cmd:TRIM}}, {{cmd:EXTEND}}, {{cmd:FILLET}} และ {{cmd:JOIN}} กับวงรีและสไปลน์ | {{cmd:EXPLODE}} สไปลน์ (หรือ {{cmd:PEDIT}}) เพื่อให้ได้โพลีไลน์ที่คำสั่งเหล่านี้ใช้ได้ |
| ฟิลเลตและชัมเฟอร์ระหว่างส่วนโค้งของโพลีไลน์กับส่วนที่อยู่ถัดไป; ฟิลเลตที่ต่อเส้นเข้าเป็นโพลีไลน์ | {{cmd:EXPLODE}} โพลีไลน์ แล้วทำฟิลเลตกับชิ้นส่วน ส่วนโค้งของฟิลเลตจะถูกเพิ่มเป็นวัตถุของมันเอง |
| ตัดแต่งและยืดออก: ตัวเลือกการฉายภาพ (3D) และการยืดปลายส่วนโค้งของโพลีไลน์ | ตัดแต่งในระนาบของแบบ สำหรับปลายส่วนโค้ง ให้แยกโพลีไลน์หรือวาดส่วนโค้งใหม่ |
| ออบเจกต์ OLE: การแทรก การรันหรือการแก้ไข; การแสดงชิ้นที่อยู่ใน DWG ตามที่ไฟล์วางไว้; ภาพ metafile | ดู [ภาพ](topic:pictures#objects-from-other-programs-ole) ออบเจกต์ของ DXF จะแสดงเป็นบิตแมปหรือกรอบที่มีป้าย ออบเจกต์ของ DWG จะถูกเก็บไว้ ไม่วาดในตำแหน่งเดิม (OLELIST แสดงรายการ และวางสำเนาภาพตรงตำแหน่งที่คุณระบุ) |
| การพิมพ์รหัสจัดรูปแบบ (ตัวหนา เศษส่วนซ้อน สีรายคำ) ในข้อความย่อหน้า; แบบอักษรอื่นนอกจากแบบอักษรแนว Helvetica; คอลัมน์ | การจัดรูปแบบที่มาในไฟล์จะถูกเก็บ วาด และบันทึก (ดู ข้อความ) ข้อความย่อหน้าใหม่จะมีความสูงและสีเดียว |
| ข้อความย่อหน้าที่แก้ไขที่การหมุนของมัน | ตัวแก้ไขเปิดในแนวราบ ข้อความยังคงการหมุนของมัน |
| มัลติลีดเดอร์ที่บันทึกเป็นวัตถุมัลติลีดเดอร์ใน DXF | DWG เก็บเป็นมัลติลีดเดอร์ โดยมีเส้นลีดเดอร์ทุกเส้นและบล็อกเป็นเนื้อหา DXF เก็บสิ่งที่มันวาด (เส้น หัวลูกศร และข้อความหรือบล็อก) |
| ในตาราง ({{cmd:TABLE}}): ข้อความที่ตัดบรรทัดในเซลล์ ตารางที่แบ่งเป็นส่วน สไตล์ข้อความของสไตล์ตารางเองและสีตามชนิดแถวในกล่องโต้ตอบ การเชื่อมข้อมูลกับไฟล์สเปรดชีต (`.xlsx`) หรือไฟล์ที่อ่านไฟล์เองได้ | ข้อความในเซลล์จะตัดบรรทัดเฉพาะตรงที่คุณตัด ({{key:Alt+Enter}}) ให้ขยายคอลัมน์ {{cmd:DATALINK}} อ่านไฟล์ `.csv` และ {{cmd:DATALINKUPDATE}} จะให้คุณเลือกไฟล์อีกครั้ง {{cmd:DATAEXTRACTION}} และ {{cmd:COUNTTABLE}} สร้างตารางที่ไม่ตามแบบเองอัตโนมัติ: ให้รันใหม่ (การนับแบบสด: {{cmd:BOMTABLE}}) |
| นิยามแอตทริบิวต์ที่เก็บแยกในไฟล์ที่บันทึก (นอกบล็อก) แอตทริบิวต์หลายบรรทัด | ใส่นิยามแอตทริบิวต์ลงในบล็อกก่อนบันทึก: เมื่ออยู่ลำพังจะบันทึกเป็นข้อความที่แสดงแท็ก |
| สถานะเลเยอร์ (การบันทึกและกู้คืนว่าเลเยอร์ใดเปิดอยู่) | ใช้ {{cmd:LAYISO}} / {{cmd:LAYUNISO}} หรือเปิดปิดเลเยอร์ด้วยตนเอง |
| การเลือกหน้าต่างแบบโพลีกอนและแบบข้าม และตัวกรองการเลือกที่บันทึกไว้ | รั้ว (`F`), หน้าต่าง, ข้าม, นำออก (`R`), {{cmd:QSELECT}} สำหรับกฎ |

## พาเนลคุณสมบัติ

| ยังไม่ได้สร้าง | แทนที่ด้วยวันนี้ |
|---|---|
| การวาดตัวเลือกการพอดี และตำแหน่งข้อความแนวนอนและข้อความใต้เส้นบนไดเมนชันที่ไม่ใช่เส้นตรงและขนาน | ค่าเหล่านี้เก็บไว้บนวัตถุ แสดงในคุณสมบัติ และบันทึกไว้ CadCraft วางข้อความตามกฎของตัวเอง |
| วัสดุที่โปรแกรมอื่นเห็น | ไฟล์ที่บันทึกจะเก็บชื่อวัสดุสำหรับ CadCraft โปรแกรมอื่นจะแสดงวัสดุของเลเยอร์ |
| ความโปร่งใสใน DWG 2000 และไฟล์ DXF | โปรแกรมอื่นจะแสดงวัตถุเหล่านั้นทึบ CadCraft เก็บความโปร่งใสไว้ บันทึกเป็น DWG 2004 ขึ้นไปเพื่อให้ทุกคนเห็นได้ |
| ลิงก์แฮตช์ที่สร้างในโปรแกรมอื่น | CadCraft บันทึกลิงก์ของตัวเองใน DWG และไฟล์ DXF 2000 ลิงก์จากโปรแกรมอื่นจะไม่ถูกอ่าน ใช้ `HATCHEDIT` และ ลิงก์: ดู [แฮตช์และพื้นที่เติม](topic:hatch) |
| พิกัดในคุณสมบัติในระบบ UCS | คุณสมบัติแสดงพิกัดโลก แถบสถานะและ {{cmd:ID}} แสดงพิกัด UCS ดู [หมุนมุมมองและใช้พิกัดของคุณเอง](topic:ucs-and-turned-view) |
| ตำแหน่งแยกสำหรับวัตถุ annotative ในแต่ละสเกล; การอ่านบันทึกรายสเกลที่โปรแกรมอื่นเก็บไว้ | ข้อความหรือไดเมนชันแบบ annotative เก็บรายการสเกล ({{cmd:OBJECTSCALE}}) และแต่ละวิวพอร์ตแสดงที่ขนาดตามสเกลของมันในตำแหน่งเดียวกัน รายการนี้บันทึกเป็นข้อมูลของ CadCraft: โปรแกรมอื่นจะเห็นวัตถุที่สเกลเดียวซึ่งกำหนดขนาดไว้ และรายการที่สร้างในโปรแกรมอื่นจะไม่ถูกอ่าน ดู [หน่วย กระดาษ และสเกล](topic:units-papers-scales#annotate-by-scale) |
| การเปลี่ยนระยะ มุม หรือการพลิกของบล็อกไดนามิก; บล็อกไดนามิกที่คงความไดนามิกเมื่อบันทึกเป็นเวอร์ชัน DWG อื่นหรือเป็น DXF | สลับสถานะการมองเห็นใน คุณสมบัติ › {{ui:กำหนดเอง}} ค่าอื่นจะแสดงที่นั่นแบบอ่านอย่างเดียว บล็อกจะยังคงไดนามิกเมื่อบันทึกเป็น DWG ในเวอร์ชันที่แบบมา ดู [บล็อกไดนามิก](topic:dynamic-blocks) |
| ค่าความคลาดเคลื่อนการพอดีของสไปลน์ สไปลน์ดีกรี 6 ขึ้นไป สไปลน์ 3 มิติ | การพอดีและจุดควบคุม ดีกรี 1 ถึง 5 และน้ำหนักถูกสร้างแล้ว ดู [สไปลน์และโพลีไลน์](topic:splines) ความสูง (Z) ของสไปลน์จะไม่ถูกเก็บ |

## ตัวช่วยความแม่นยำ

| ยังไม่ได้สร้าง | แทนที่ด้วยวันนี้ |
|---|---|
| การติดตามจากจุดข้ามคำสั่ง และกล่องโต้ตอบการตั้งค่าการติดตาม (มุมขั้วสัมพัทธ์ มุมเพิ่มเติม) | {{cmd:POLARANG}} ตั้งขั้น; จับจุดอีกครั้งในคำสั่งถัดไป |
| การสแนปไปยังกริด | พิมพ์พิกัด กริดเป็นแนวทางภาพเท่านั้น |
| ตัวเลือกส่วนโค้งและความยาวขณะเลือกมุมของพื้นที่ และ MEASUREGEOM Volume | วาดเส้นรอบรูปด้วย {{cmd:PLINE}} (รวมส่วนโค้ง) แล้วใช้ {{cmd:AREA}} `O` |
| อินพุตไดนามิกสำหรับกริป และรายการตัวเลือกของมัน (ลูกศรลง) | บรรทัดคำสั่งแสดงตัวเลือก |
| มุมแบบองศา-ลิปดา-วินาที เกรด หรือทิศทางของผู้สำรวจ | พิมพ์มุมแบบทศนิยม: `30.5` สำหรับ 30°30' |
| กล่องโต้ตอบตัวจัดการมุมมอง; มุมมองที่ตั้งชื่อของแผ่นที่จะกลับมาในแผ่นนั้น | {{cmd:NAMEDVIEW}} แสดงรายการและเรียกมุมมองกลับมา ไฟล์ที่บันทึกเก็บมุมมองไว้ แต่มุมมองของแผ่นจะกลับมาที่แผ่นแรก |

## แผ่น ไดเมนชัน และการพล็อต

| ยังไม่ได้สร้าง | แทนที่ด้วยวันนี้ |
|---|---|
| ฟิลด์สำหรับสเกลของวิวพอร์ต ชื่อวัตถุ เช่นเลเยอร์หรือบล็อก ไฮเปอร์ลิงก์ และฟิลด์ชุดแผ่นนอกเหนือจากหมายเลขและชื่อแผ่น; ฟิลด์ที่เขียนเป็นออบเจกต์ฟิลด์ที่โปรแกรมอื่นอัปเดต | {{cmd:FIELD}} มีวันที่ ชื่อไฟล์ หมายเลข ชื่อ และจำนวนแผ่น คุณสมบัติของแบบ ({{cmd:DWGPROPS}}) พื้นที่ ความยาว และคุณสมบัติอื่นของวัตถุ และสูตร ในข้อความ แอตทริบิวต์ และเซลล์ตาราง โปรแกรมอื่นจะแสดงฟิลด์ของ CadCraft เป็นข้อความที่อ่านครั้งล่าสุด CadCraft อ่านฟิลด์วันที่ ชื่อไฟล์ คุณสมบัติ แผ่น และนิพจน์ของโปรแกรมอื่น และเก็บฟิลด์ชนิดอื่นไว้เป็นข้อความ สเกลของวิวพอร์ตพิมพ์ด้วยมือ |
| การบันทึกว่าสไตล์ไดเมนชันใดเป็นปัจจุบัน; ข้อความไดเมนชันที่ลากไปตำแหน่งอิสระ | แบบจะเปิดด้วย Standard เป็นปัจจุบัน ข้อความอยู่บนเส้นไดเมนชัน (DIMTEDIT Left / Right / Center) ดู [กำหนดขนาดไดเมนชัน](topic:dimension-settings) |
| ไดเมนชันมุมแบบสองบรรทัดที่แก้ไขได้จากไฟล์ที่เปิด ซึ่ง CadCraft หาไม่ได้ | แสดงตามที่วาดในไฟล์ ไดเมนชันพิกัด ความยาวส่วนโค้ง และรัศมีแบบหัก จะเปิดเป็นไดเมนชันที่แก้ไขได้ |
| การตรวจสอบตัวอ่าน CTB กับไฟล์จากโปรแกรมอื่น (สร้างแล้วจากคำอธิบายที่เผยแพร่) สไตล์การพล็อตแบบมีชื่อ (STB) ดิเธอร์ หมายเลขปากกา เกรย์สเกลจาก CTB และการปรับเส้นชนิดแบบปรับตัวในสไตล์การพล็อต | สร้างตารางใน {{ui:ตารางรูปแบบการพล็อต}} (สี เกรย์ หมึก ความหนาเส้น เส้นชนิด ปลายและการต่อเส้น และสไตล์การเติมตามสี) ดู [ตารางสไตล์การพล็อต](topic:plot-pdf#plot-style-tables) |
| การตั้งค่าหน้า | เลือกกระดาษ สเกล และสไตล์การพล็อตในกล่องโต้ตอบ {{ui:พล็อตเป็น PDF}} แผ่นจะเก็บสไตล์การพล็อตของมัน |
| ภาษาฮินดีและภาษาอื่นที่ต้องการการจัดรูปอักษรที่ซับซ้อนใน PDF และอักษรภาพหายาก (อักษรยุโรป ซีริลลิก กรีก ฮีบรู อาหรับ เปอร์เซีย อูรดู ไทย จีน ญี่ปุ่น และเกาหลี) | พิมพ์ออกมาเป็น "?" |
| ข้อความอักษรอาหรับกับจีน ญี่ปุ่น หรือเกาหลี ในไฟล์ PDF ที่พล็อตเดียวกัน | การพล็อตมีแบบอักษรเดียว อักษรหนึ่งในสองระบบจะพิมพ์เป็น "?" |
| เครื่องหมายทิศทางแบบชัดเจนในข้อความ (embeddings, overrides, isolates) | จะถูกละเว้น แต่ละบรรทัดจะเรียงลำดับตามตัวอักษรของมันเอง |
| ภาพในหน้า PDF ที่แนบมา ในการพล็อต | เส้น การเติม และข้อความของหน้าจะพิมพ์ หน้าที่เป็นภาพอย่างเดียวจะนำเข้าด้วย {{cmd:SCANATTACH}} และภาพจะพิมพ์ ดู [PDF ใต้แบบ](topic:pdf-underlay#plot-and-save) |
| การส่งงานไปยังเลเซอร์จาก CadCraft Studio (Studio ไม่มี Web Serial) | บันทึก G-code แล้วส่งด้วยโปรแกรมของเลเซอร์ของคุณเอง หรือส่งจาก Chrome หรือ Edge ดู [ส่งแบบไปยังเลเซอร์](topic:laser-cutting#send-from-the-browser) |

## ข้อจำกัดและพารามิเตอร์

| ยังไม่ได้สร้าง | แทนที่ด้วยวันนี้ |
|---|---|
| ข้อจำกัดบนแผ่น ในบล็อก บนวงรี สไปลน์ หรือข้อความ | กำหนดข้อจำกัดบนแท็บ {{ui:โมเดล}} บนเส้น โพลีไลน์ วงกลม ส่วนโค้ง และจุด |
| G2 แบบเรียบ และการกำหนดความโค้งของส่วนโค้งโพลีไลน์โดยตรง | แทนเจนต์และเท่ากัน ส่วนโค้งจะตามปลายทั้งสองข้าง |
| ข้อจำกัดมิติแบบอ้างอิง (ไม่ขับเคลื่อน) และ `3Point` ใน {{cmd:DCANGULAR}} | ไดเมนชันธรรมดา (DIMLINEAR …) แสดงค่าโดยไม่ขับเคลื่อน |
| ข้อจำกัดมิติขนาดคงที่บนกระดาษ และการพล็อต | แสดงบนหน้าจอเท่านั้น เพิ่มไดเมนชันธรรมดาสำหรับการพล็อต |
| ข้อจำกัดที่คงอยู่ผ่าน EXPLODE, BREAK, JOIN และคำสั่งอื่นที่สร้างวัตถุใหม่ และบนโพลีไลน์ที่ถูกตัดแต่ง | กำหนดข้อจำกัดใหม่ (AUTOCONSTRAIN ช่วยได้) {{cmd:MIRROR}} และ {{cmd:TRIM}} ของเส้น ส่วนโค้ง และวงกลมจะคงข้อจำกัดไว้ |
| ตารางการออกแบบ (การกำหนดค่า) ใน CadCraft | เปลี่ยนพารามิเตอร์ในพาเนล |
| การทดสอบไปกลับกับ SolidWorks ที่ผ่านแล้ว | ตรวจสเกตช์ที่มาโครสร้างก่อนนำไปใช้งาน |

## 3D

| ยังไม่ได้สร้าง | แทนที่ด้วยวันนี้ |
|---|---|
| ฟิลเลต ชัมเฟอร์ เชลล์ และลอฟต์; สวีปตามเส้นทางที่ยกขึ้น (เส้นทาง 3D) | เอ็กซ์ทรูดรูปร่างที่มีส่วนโค้ง ดันและดึงหน้า หมุนรอบแกน และสวีปตามเส้นทางราบ |
| เอ็กซ์ทรูดในทิศทางอื่นนอกจากขึ้น | วาดรูปร่างบนพื้นแล้วเอ็กซ์ทรูดขึ้นหรือลง (พร้อมความลาดหรือตามเส้นทางหากต้องการ) แล้วหมุนโซลิดภายหลัง |
| ระดับและความหนาของวัตถุ 2 มิติ | แบบวางอยู่บนพื้น (ความสูง 0) บนแท็บ 3D |
| การแก้ไขโซลิด รีเจียน และบอดี้จากโปรแกรมอื่น; การแสดงสิ่งเหล่านั้นภายในบล็อก; หน้าบนพื้นผิวฟรีฟอร์มที่สวีป ลอฟต์ หรืออื่น ๆ; โพลีเฟซและเมชโพลีกอน | โซลิดในพื้นที่โมเดลจะแสดงบนแท็บ 3D ตามที่เป็น และถูกบันทึกกลับโดยไม่เปลี่ยนแปลงใน DWG สิ่งที่ไม่ได้วาดจะถูกแสดงรายการเมื่อเปิดแท็บ 3D ขอเมชเป็นหน้า 3D ในพื้นที่โมเดล ดู [โซลิดจากโปรแกรมอื่น](topic:3d-solids#solids-from-other-programs) |
| การคัดลอกและวางโซลิด | บนแท็บ 3D ใช้ {{cmd:COPY}} คลิปบอร์ดเก็บวัตถุ 2 มิติเท่านั้น |
| ภาคตัด มุมมองที่ตามการเปลี่ยนแปลงของโซลิดภายหลัง และโซลิดแบบแรเงาบนแผ่นที่พล็อต | {{cmd:VIEWBASE}} วางมุมมองแบบแบน (สแนปช็อต) รันใหม่หลังเปลี่ยนโซลิด |
| วัสดุ พื้นผิว และการตั้งค่าแสง | สไตล์ภาพ: แรเงา ขอบ เส้นซ่อน ลวดเส้น X-ray |
| เลเยอร์แผนที่ที่พล็อต บนวิวพอร์ตของแผ่นและบนแท็บ 3D; ภาพจากไฟล์ที่บันทึกกับแบบ; ตำแหน่งของแบบที่เขียนให้โปรแกรมอื่นใน DWG 2000–2007 และ DXF R12 | เลเยอร์แผนที่แสดงใต้พื้นที่โมเดลบนหน้าจอ ระบบและรายการเลเยอร์จะถูกบันทึกกับแบบ ดู [เลเยอร์แผนที่ใต้แบบ](topic:map-layers) |
| การสแกน E57 เกิน 6 ล้านจุดหรือ 512 MB ไฟล์ของผู้ผลิตเครื่องสแกน (RCP, RCS, FLS, LGS, TZF, ZFS) กลุ่มจุดที่บันทึกกับแบบหรือพล็อต การสแนปไปยังกลุ่มเมฆบนแท็บ 3D การตัดตั้ง (ส่วน) บนแท็บโมเดล | ส่งออกการสแกนขนาดใหญ่หรือของผู้ผลิตเป็น LAS หรือ LAZ ([รูปแบบกลุ่มจุด](topic:point-cloud-formats)) แนบกลุ่มเมฆทุกครั้งที่เปิดแบบ; ลากเส้นจากภาคตัดแผนบนแท็บโมเดล ดู [ลากเส้นตามสร้างจริงบนกลุ่มจุด](topic:point-clouds) |
| การลงทะเบียนการสแกน: ค้นหาเป้าหมาย (ทรงกลม กระดานตาราง) ในการสแกนเอง แก้ทุกการสแกนพร้อมกัน (bundle adjustment) มาตราส่วน การลงทะเบียนกับโมเดล | เลือกจุดที่ตรงกันหรือพิมพ์พิกัดเป้าหมาย แล้วปรับแต่งทีละการสแกนด้วย ICP ดู [ลงทะเบียนการสแกนหลายชุดให้เป็นหนึ่ง](topic:register-scans) |
