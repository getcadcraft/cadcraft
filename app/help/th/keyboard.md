ปุ่มลัดที่แสดงเป็นแบบที่ใช้กับคอมพิวเตอร์ของคุณ บน Mac ปุ่มลัด {{key:Mod}} ทุกปุ่มด้านล่างใช้ปุ่ม Command และปุ่ม Control ก็ใช้ได้ด้วย วิธีเขียนชื่อปุ่ม และวิธีใช้ปุ่ม F บน Mac อยู่ใน[ปุ่ม เมาส์ และแทร็กแพด](common:keys)

## การพิมพ์คำสั่ง

| ปุ่ม | สิ่งที่ทำ |
|---|---|
| ตัวอักษร ตัวเลข หรือสัญลักษณ์ใดก็ได้ | ไปที่บรรทัดคำสั่ง ไม่ว่าตัวชี้จะอยู่ตรงไหน ยกเว้นเมื่อกล่องในพาเนลมีเคอร์เซอร์อยู่ |
| {{key:Enter}} | ส่งสิ่งที่คุณพิมพ์ เมื่อพรอมต์ว่าง: ทำซ้ำคำสั่งล่าสุด จบคำสั่ง จบการเลือก หรือยอมรับค่าเริ่มต้นใน `<…>` |
| {{key:Space}} | เหมือน {{key:Enter}} ยกเว้นขณะที่ CadCraft ถามข้อความ (ข้อความ ชื่อบล็อก ข้อความไดเมนชัน) ซึ่งจะพิมพ์เว้นวรรค |
| {{key:Esc}} | ยกเลิกคำสั่ง เมื่อไม่มีคำสั่งทำงาน: ยกเลิกการย้ายกริปหรือกรอบการเลือก จากนั้นล้างการเลือก |
| {{key:Tab}} | ยอมรับคำสั่งที่แนะนำซึ่งแสดงทางขวาของบรรทัดคำสั่ง เมื่อไม่ได้พิมพ์อะไรและตัวชี้อยู่เหนือวัตถุที่ซ้อนกัน: ไฮไลต์วัตถุถัดไปตรงนั้น (คลิกเพื่อเลือก) |
| {{key:Up}} {{key:Down}} | เลื่อนดูบรรทัดที่คุณพิมพ์ไว้ก่อนหน้า (100 รายการล่าสุด) |

## การวาดและแก้ไข

| ปุ่ม | สิ่งที่ทำ |
|---|---|
| {{key:Mod+Z}} | เลิกทำคำสั่งล่าสุด |
| {{key:Mod+Y}} หรือ {{key:Mod+Shift+Z}} | ทำซ้ำ |
| {{key:Mod+A}} | เลือกทุกวัตถุที่แก้ไขได้ในแท็บที่เปิดอยู่ ({{cmd:SELECTALL}}) หากคุณพิมพ์อะไรไว้ที่บรรทัดคำสั่ง จะเลือกข้อความนั้นแทน |
| {{key:Delete}} | ลบวัตถุที่เลือก ({{cmd:ERASE}}) เว้นแต่คุณจะพิมพ์อะไรไว้ที่บรรทัดคำสั่ง |
| {{key:Backspace}} | ลบวัตถุที่เลือกเมื่อบรรทัดคำสั่งไม่มีเคอร์เซอร์ ที่บรรทัดคำสั่งจะลบสิ่งที่คุณพิมพ์ |
| {{key:Esc}} | เมื่อไม่มีคำสั่งทำงาน: ล้างการเลือก ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | บันทึกสำเนาในรูปแบบของแบบ (DWG หรือ DXF) |
| {{key:Mod+Shift+S}} | บันทึกเป็น: เลือก DWG หรือ DXF แล้วบันทึกสำเนา |
| {{key:Mod+O}} | เปิด DWG หรือ DXF |
| {{key:Mod+P}} | พล็อตเป็น PDF |

เลิกทำ ทำซ้ำ เลือกทั้งหมด และพล็อต จะไม่ทำงานขณะที่มีคำสั่งกำลังทำงาน ให้กด {{key:Esc}} ก่อน

## คัดลอก ตัด และวาง

| ปุ่ม | สิ่งที่ทำ |
|---|---|
| {{key:Mod+C}} | คัดลอกที่เลือกไปยังคลิปบอร์ด ({{cmd:COPYCLIP}}) หากไม่มีอะไรที่เลือก CadCraft จะขอให้เลือกวัตถุ |
| {{key:Mod+X}} | ตัด: คัดลอกที่เลือกแล้วลบ ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | วาง: สำเนาจะตามตัวชี้ คลิก หรือพิมพ์จุดเพื่อวาง ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | วางที่เดิม: ที่พิกัดเดิมที่คัดลอกมา ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | ทำสำเนา: สำเนาของที่เลือกจะเคลื่อนไปตามตัวชี้ คลิกเพื่อวาง กด {{key:Esc}} จะไม่ทิ้งอะไรไว้ ({{cmd:DUPLICATE}}) |

การกระทำเดียวกันอยู่ในกลุ่ม {{ui:Edit}} ของแถบเครื่องมือ ({{ui:Copy}} {{ui:Paste}}) และในเมนู {{ui:More}} ขณะที่คำสั่งอื่นกำลังทำงาน ให้ทำให้เสร็จหรือกด {{key:Esc}} ก่อน การกด {{key:Mod+V}} หรือ {{key:Mod+D}} อีกครั้งขณะที่สำเนาตามตัวชี้อยู่จะเริ่มใหม่ เมื่อคุณพิมพ์อะไรไว้ที่บรรทัดคำสั่ง หรือคำสั่งกำลังถามข้อความ ปุ่มเหล่านี้จะคัดลอก ตัด และวางข้อความนั้นแทน ดู[คัดลอก วาง และทำสำเนา](topic:copy-paste)

## สวิตช์

| ปุ่ม | สวิตช์ | ปุ่มในแถบสถานะ |
|---|---|---|
| {{key:F3}} | เปิดหรือปิดสแนปวัตถุ | {{ui:Snap}} |
| {{key:F7}} | เปิดหรือปิดกริด | {{ui:Grid}} |
| {{key:F8}} | เปิดหรือปิดออร์โธ | {{ui:Ortho}} |
| {{key:F10}} | เปิดหรือปิดการติดตามขั้ว | {{ui:Polar}} |
| {{key:F11}} | เปิดหรือปิดการติดตามสแนปวัตถุ | {{ui:Track}} |
| {{key:F12}} | เปิดหรือปิดอินพุตไดนามิก | {{ui:Dyn}} |

:::mac
บน Mac, F3, F7 และ F8 มักเป็น Mission Control และปุ่มมีเดีย กด **fn** ค้างไว้ด้วย หรือเปิดปุ่มฟังก์ชันมาตรฐานในการตั้งค่าระบบ ตามที่อธิบายใน[ปุ่ม เมาส์ และแทร็กแพด](common:keys) ปุ่มในแถบสถานะจะทำงานเสมอ
:::

:::firefox
F7 ใน Firefox อาจขอให้เปิดการท่องด้วยเคอร์เซอร์ (caret browsing) เลือก **No** และใช้ปุ่ม {{ui:Grid}} หากยังขอให้เลือกอยู่
:::

## ช่วยเหลือ

| ปุ่ม | สิ่งที่ทำ |
|---|---|
| {{key:F1}} | เปิดหรือปิดหน้าช่วยเหลือนี้ข้างแบบ ใช้งานได้แม้ขณะที่คำสั่งกำลังทำงาน และจะไม่ไปถึงบรรทัดคำสั่งเลย |
| {{key:Esc}} | เมื่อเคอร์เซอร์อยู่ในพาเนลช่วยเหลือ: ล้างการค้นหา หรือปิดพาเนล |

ปุ่ม {{ui:Help}} บนแถบด้านบนทำเหมือน {{key:F1}} ขณะที่คุณพิมพ์ในช่องค้นหาของช่วยเหลือ จะไม่มีอะไรไปถึงบรรทัดคำสั่ง คลิกที่แบบเพื่อคืนปุ่มให้ CadCraft พาเนลจะเปิดอยู่ข้างแบบต่อไป

:::mac
บนแป้นพิมพ์ Mac ให้กด **fn** ค้างไว้แล้วกด F1 หรือคลิก {{ui:Help}}
:::

## หน้าจอ

| ปุ่ม | สิ่งที่ทำ |
|---|---|
| {{key:Ctrl+Shift+F}} | สลับระหว่างปกติ เต็มหน้าจอ และเต็มหน้าจอโดยซ่อนแถบ ปุ่มนี้ใช้ปุ่ม Control ในทุกคอมพิวเตอร์ รวมถึง Mac |
| {{key:Left}} {{key:Right}} | เมื่อโฟกัสแท็บใต้แบบ: แท็บก่อนหน้าหรือถัดไป |

ในโหมดเต็มหน้าจอ เบราว์เซอร์อาจใช้ {{key:Esc}} ครั้งแรกเพื่อออกจากโหมดเต็มหน้าจอ กด {{key:Esc}} อีกครั้งเพื่อยกเลิกคำสั่ง

## กล่องโต้ตอบ

| ปุ่ม | สิ่งที่ทำ |
|---|---|
| {{key:Esc}} | ปิดกล่องโต้ตอบ ({{ui:Plot to PDF}} หรือคำถามเช่น "การเปลี่ยนแปลงที่ยังไม่ได้บันทึก" ซึ่งหมายถึง {{ui:Cancel}}) |
| {{key:Tab}} | เลื่อนระหว่างการตั้งค่าและปุ่มของกล่องโต้ตอบ |

ขณะที่กล่องโต้ตอบเปิดอยู่ ปุ่มของแบบจะไม่ทำงาน

## ช่องในพาเนล

ในกล่องในพาเนลด้านขวาหรือด้านซ้าย:

| ปุ่ม | สิ่งที่ทำ |
|---|---|
| {{key:Enter}} | ใช้ค่าและออกจากกล่อง |
| {{key:Esc}} | คืนค่าเดิมและออกจากกล่อง |
| {{key:Tab}} | ใช้ค่าและไปยังกล่องถัดไป |

ขณะที่กล่องมีเคอร์เซอร์ ตัวอักษรจะพิมพ์ลงในกล่อง ไม่ใช่บรรทัดคำสั่ง

## เมาส์

| การกระทำ | สิ่งที่ทำ |
|---|---|
| คลิก | เลือกจุดเมื่อคำสั่งขอจุด เลือกวัตถุเมื่อขอวัตถุ มิฉะนั้นเลือกวัตถุหรือกริป |
| Shift+คลิก | เอาวัตถุที่เลือกออกจากการเลือก (เมื่อ {{ui:Clicking objects}} ตั้งเป็น {{ui:Replaces the selection}} ใน[การตั้งค่า](topic:settings) จะเป็นการเพิ่มเข้าไปแทน) ขณะเลือกจุด: ไม่สนใจสแนปวัตถุสำหรับการคลิกนั้น |
| คลิกบนพื้นที่ว่าง แล้วคลิกอีกครั้ง | กรอบการเลือก: จากซ้ายไปขวาเป็นหน้าต่าง จากขวาไปซ้ายเป็นข้าม |
| ลากบนพื้นที่ว่าง | ลาสโซ: เคลื่อนไปทางขวาก่อนเป็นหน้าต่าง ไปทางซ้ายก่อนเป็นข้าม {{key:Space}} ขณะลากจะสลับระหว่างหน้าต่าง ข้าม และรั้ว {{key:Esc}} จะยกเลิก (LASSOMODE 0 หรือการตั้งค่า จะทำให้กลับเป็นสี่เหลี่ยมผืนผ้าอีกครั้ง) |
| ลากผ่านชิ้นในคำสั่ง TRIM หรือ EXTEND | ตัดแต่ง (หรือยืดออก) ทุกชิ้นที่เส้นทางตัดผ่าน กด {{key:Shift}} ค้างไว้เพื่อทำอีกแบบ |
| ลากกริป | ย้ายกริป (หรือคลิกกริป แล้วคลิกตรงที่จะไป) |
| ดับเบิลคลิกข้อความ | เลือกข้อความและวางเคอร์เซอร์ในกล่อง {{ui:Text}} ของพาเนลด้านขวา |
| คลิกขวา | เหมือน {{key:Enter}} ระหว่างการย้ายกริปหรือกรอบการเลือก: ยกเลิก |
| ลากด้วยปุ่มขวา | แพน |
| ล้อ | ซูมเข้าและออกรอบเคอร์เซอร์กากบาท |
| ลากด้วยล้อ (ปุ่มกลาง) | แพน |
| ดับเบิลคลิกที่ล้อ | ซูมไปยังทั้งแบบ (ขอบเขต) |
| ลากไฟล์ DWG หรือ DXF มาปล่อยบนแบบ | เปิดไฟล์นั้น |

สำหรับแทร็กแพดหรือหน้าจอสัมผัส ดู[เมาส์ แทร็กแพด และการสัมผัส](topic:mouse-trackpad-touch)

## ปุ่มที่เบราว์เซอร์ยึดไว้

{{key:Mod+N}} {{key:Mod+W}} และ {{key:Mod+T}} เป็นของเบราว์เซอร์เสมอ CadCraft ไม่ใช้ปุ่มเหล่านี้ ให้ใช้ {{ui:New}} หรือพิมพ์ `NEW` สำหรับแบบใหม่ คลิปบอร์ดของ CadCraft เป็นของตัวเอง: {{key:Mod+C}} และ {{key:Mod+V}} คัดลอกวัตถุระหว่างแบบและแท็บของ CadCraft ไม่ได้คัดลอกไปหรือมาจากโปรแกรมอื่น

:::mac
หาก {{key:Mod+Y}} เปิดประวัติของเบราว์เซอร์แทนการทำซ้ำ ให้ใช้ {{key:Mod+Shift+Z}} หรือปุ่ม {{ui:Redo}}
:::

## ตำแหน่งของ Move

Move คือคำสั่ง `MOVE` (ปุ่ม {{key:M}}) เลือกวัตถุ จากนั้นเลือกจุดฐานและจุดที่สองหรือระยะที่พิมพ์ `ALIGN` และ `DISTRIBUTE` ก็อยู่ที่นั่นเช่นกัน BimCraft ใช้ชื่อเดียวกันสำหรับงานเดียวกันบนองค์ประกอบอาคาร แต่ {{key:M}} ของมันคือ วัด และ Move ของมันคือ {{key:Shift+M}}
