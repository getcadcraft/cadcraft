CadCraft ออกแบบมาสำหรับเมาส์ที่มีล้อ ทุกอย่างใช้ได้กับแทร็คแพดเช่นกัน โดยต้องเรียนรู้นิสัยเพิ่มเล็กน้อย หน้าจอสัมผัสใช้สำหรับการเลือกได้ แต่มีข้อจำกัด

## เมาส์ล้อ

- **ซูม:** หมุนล้อ แบบจะซูมรอบเครื่องหมายกากบาท ให้ชี้ไปที่สิ่งที่ต้องการดู
- **แพน:** กดค้างที่ล้อแล้วลาก หรือลากด้วยปุ่มขวา
- **ซูมให้เห็นทุกอย่าง:** ดับเบิลคลิกที่ล้อ หรือคลิก {{ui:ขอบเขต}}
- **กลับไปมุมมองก่อนหน้า:** คลิก {{ui:ก่อนหน้า}} ในกลุ่มมุมมอง หรือพิมพ์ `Z`, {{key:Enter}}, `P`, {{key:Enter}} การหมุนล้อต่อเนื่องนับเป็นหนึ่งมุมมอง ดังนั้น {{ui:ก่อนหน้า}} หนึ่งครั้งจะเลิกทั้งหมด บันทึกมุมมองที่ต้องกลับมาบ่อยด้วย {{cmd:NAMEDVIEW}} (`NV`)
- **Enter:** คลิกขวา

## แทร็คแพด

:::mac
- **แพน:** เลื่อนนิ้วสองนิ้วบนแทร็คแพดไปทางใดก็ได้: แบบจะเคลื่อนตามนิ้ว หรือลากด้วยการคลิกสองนิ้วค้างไว้ (การลากด้วยปุ่มขวา)
- **ซูม:** บีบด้วยสองนิ้ว การซูมจะตามเครื่องหมายกากบาท
- **คลิกขวา (Enter):** คลิกด้วยสองนิ้ว หากไม่ทำงาน ให้เปิด "คลิกรอง" ใน **การตั้งค่าระบบ** แล้วเลือก **แทร็คแพด** การคลิกด้วย Control อาจนับเป็นการคลิกธรรมดาใน CadCraft แทนที่จะเป็นคลิกขวา จึงควรใช้การคลิกสองนิ้ว
- **ซูมไปยังพื้นที่:** คลิก {{ui:หน้าต่าง}} ในกลุ่มมุมมอง แล้วคลิกสองมุม
:::

:::windows linux
- **แพน:** เลื่อนนิ้วสองนิ้วบนทัชแพดไปทางใดก็ได้: แบบจะเคลื่อนตามนิ้ว หรือลากด้วยปุ่มขวาที่กดค้างไว้
- **ซูม:** บีบด้วยสองนิ้ว การซูมจะตามเครื่องหมายกากบาท
- **คลิกขวา (Enter):** คลิกด้วยสองนิ้ว หรือคลิกมุมล่างขวาของทัชแพด ขึ้นอยู่กับการตั้งค่าทัชแพดของคุณ
- **ซูมไปยังพื้นที่:** คลิก {{ui:หน้าต่าง}} ในกลุ่มมุมมอง แล้วคลิกสองมุม
:::

การกด {{key:Space}} ค้างแล้วลาก **ไม่** แพนใน CadCraft: {{key:Space}} คือ Enter

ล้อเมาส์ยังซูมทีละขั้น ทัชแพดที่ส่งการเลื่อนเป็นขั้นเต็มเหมือนล้อ จะซูมด้วยการเลื่อนสองนิ้วแทนการแพน: ซูมออก ชี้ไปยังพื้นที่ที่ต้องการ แล้วซูมเข้าอีกครั้ง แท็บ 3D มีการเคลื่อนไหวของแทร็คแพดของตัวเอง (ดู [มองโมเดลใน 3D](topic:3d-solids#look-around))

## หน้าจอสัมผัสและแท็บเล็ต

CadCraft อ่านนิ้วเป็นการคลิกเมาส์:

- การแตะจะเลือกจุดหรือวัตถุ หรือเลือก
- ลากนิ้วบนพื้นที่ว่างเพื่อวาดลาสโซ (ลากไปทางขวาก่อนเป็นหน้าต่าง ลากไปทางซ้ายก่อนเป็นกรอบข้าม ดู [การเลือกด้วยลาสโซ](topic:lasso-selection))
- ใน {{cmd:TRIM}} และ {{cmd:EXTEND}} การลากนิ้วผ่านชิ้นส่วนจะตัดแต่งหรือยืดทั้งหมด
- ลากกริปของวัตถุที่เลือกเพื่อย้ายกริป (กริปและกรอบการเลือกจะใหญ่ขึ้นสำหรับนิ้ว)
- **บีบ** ด้วยสองนิ้วเพื่อซูมรอบจุดระหว่างนิ้ว เลื่อนสองนิ้วพร้อมกันเพื่อ **แพน** นิ้วที่สองจะยกเลิกสิ่งที่นิ้วแรกเริ่มทำ ดังนั้นการบีบจะไม่ทิ้งร่องรอยไว้
- **กดค้าง** (กดนิ่งประมาณครึ่งวินาที) คือคลิกขวา: {{key:Enter}} มันจะจบคำสั่ง จบการเลือก หรือทำคำสั่งล่าสุดซ้ำ

ใต้บรรทัดคำสั่งจะมี **แถวปุ่ม** ปรากฏขึ้น: {{ui:Esc}}, {{ui:เลิกทำ}}, {{ui:ทำซ้ำ}}, อักขระที่คีย์บอร์ดแท็บเล็ตซ่อนไว้ (`@` `,` `<` `'` `"` `-`), {{ui:สแนป}}, {{ui:ออร์โธ}}, ปุ่มคีย์บอร์ด และปุ่ม {{ui:Enter}} ขนาดใหญ่ แตะปุ่มคีย์บอร์ด (หรือบรรทัดคำสั่ง) เพื่อพิมพ์คำสั่งหรือตัวเลข

ไม่มีการโฮเวอร์บนหน้าจอสัมผัส เครื่องหมายสแนปจึงแสดงเฉพาะตรงที่นิ้วอยู่

:::touch
กำลังใช้หน้าจอสัมผัส สำหรับงานที่มากกว่าการดูอย่างรวดเร็ว การต่อคีย์บอร์ดและเมาส์หรือแทร็คแพดจะทำให้ CadCraft ใช้งานได้สะดวกกว่ามาก
:::

## เบราว์เซอร์

CadCraft ทำงานเหมือนกันใน Chrome, Edge, Firefox และ Safari บน Mac, Windows และ Linux ความแตกต่างมีเพียงเล็กน้อย:

| หัวข้อ | สิ่งที่ควรรู้ |
|---|---|
| การเปิด DWG | แบบขนาดใหญ่ใช้เวลาอ่านหลายวินาทีในทุกเบราว์เซอร์ บรรทัดสถานะจะแสดง "กำลังอ่าน …" ระหว่างนั้น |
| การดาวน์โหลด | แต่ละเบราว์เซอร์กำหนดว่าดาวน์โหลดไปที่ใดและจะถามก่อนหรือไม่ ดู [เบราว์เซอร์และคอมพิวเตอร์](common:browsers) |
| เปิดเพื่อพิมพ์ | เปิด PDF ในแท็บใหม่ หากเบราว์เซอร์บล็อกป๊อปอัป CadCraft จะดาวน์โหลด PDF แทน |
| F7 | Firefox อาจเสนอการเรียกดูด้วยเคอร์เซอร์ ให้เลือก ไม่ |
| ออกไปโดยมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก | ทุกเบราว์เซอร์จะแสดงคำถามออกจากเว็บไซต์ของตัวเอง ซึ่ง CadCraft เปลี่ยนไม่ได้ |

:::safari
ใน Safari PDF ที่เปิดด้วย {{ui:เปิดเพื่อพิมพ์}} อาจแสดงในแท็บโดยไม่พิมพ์: ใช้ **ไฟล์** แล้วเลือก **พิมพ์**
:::

:::firefox
Firefox อาจถามว่าจะทำอย่างไรกับการดาวน์โหลดแต่ละครั้ง เลือกบันทึกไฟล์ หรือเปลี่ยนครั้งเดียวในการตั้งค่าของ Firefox ภายใต้ **การดาวน์โหลด**
:::
