**Access** ช่วยให้วาดได้โดยไม่ต้องมองหน้าจอ ปิดอยู่จนกว่าจะเปิด เพื่อไม่ให้ใครเปิดโดยไม่ตั้งใจ

## เปิดใช้งาน

เปิด **การตั้งค่า** (รูปเฟือง หรือ Ctrl+,) หา **วาดแบบโดยไม่ใช้สายตา** แล้วเลือก **เปิด** หรือพิมพ์ `ACCESS` ที่บรรทัดคำสั่งแล้วตอบ เปิด การตั้งค่านี้จะถูกจำไว้บนคอมพิวเตอร์เครื่องนี้

เมื่อเปิด Access:

- **ทุกอย่างที่บรรทัดคำสั่งแสดงจะถูกอ่านออกเสียง** ผ่านตัวอ่านหน้าจอ: สิ่งที่พิมพ์ พรอมต์ที่ถาม คำตอบ และทุกข้อผิดพลาด CadCraft ใช้ live region แบบสุภาพและแบบเร่งด่วนของตนเอง ตัวอ่านหน้าจอที่อ่าน live region จึงไม่ต้องตั้งค่าเพิ่ม ข้อผิดพลาดและการยกเลิกจะขัดจังหวะ ส่วนอื่นจะรอคิว
- **เข้าถึงพื้นที่แบบได้** กด Tab จนได้ยิน "พื้นที่แบบ" หรือกด Shift+Tab จากบรรทัดคำสั่ง เป็นภูมิภาคที่ส่งปุ่มผ่านไปยัง CadCraft

## ปุ่มบนแบบ

| ปุ่ม | ทำอะไร |
|---|---|
| ปุ่มลูกศร | ย้ายเคอร์เซอร์คีย์บอร์ด หนึ่งก้าวประมาณหนึ่งในร้อยของสิ่งที่หน้าจอแสดง ปัดเป็น 1, 2 หรือ 5 Shift เลื่อนไปสิบเท่า Ctrl เลื่อนหนึ่งในสิบ |
| Enter | เลือกจุดใต้เคอร์เซอร์ เหมือนการคลิก |
| Space | กด Enter ที่บรรทัดคำสั่ง: จบ LINE และรับค่าเริ่มต้น |
| Tab, Shift+Tab | ไปยังจุดสแนปถัดไปหรือก่อนหน้าที่อยู่ใกล้เคอร์เซอร์ เรียงจากใกล้ที่สุด |
| G | วนดูกริปของวัตถุที่เลือก |
| D | บรรยายแบบ: มีวัตถุกี่ชิ้น เป็นชนิดใด ขนาดเท่าใด และอะไรถูกเลือกอยู่ |
| W | บอกตำแหน่งเคอร์เซอร์ และห่างจากจุดสุดท้ายเท่าไร |
| N | บอกสิ่งที่อยู่ใกล้เคอร์เซอร์ เรียงจากใกล้ที่สุด พร้อมระยะและด้าน |
| S | บรรยายวัตถุที่เลือก |
| R | อ่านสิ่งสุดท้ายซ้ำ |
| V | เปิดหรือปิดเสียง |
| / | ไปยังบรรทัดคำสั่ง |
| ? | แสดงรายการปุ่มเหล่านี้ |

การเลื่อนด้วยปุ่มจะบอกว่าไปถึงตำแหน่งใด เมื่อคำสั่งกำลังรอจุด จะบอกด้วยว่าห่างจากจุดสุดท้ายเท่าไรและไปทางใด เช่น "ห่างจากจุดสุดท้าย 2400 ไปทางขวา ที่ 0 องศา"

## คำสั่ง

- {{cmd:ACCESS}} เปิดหรือปิด Access เสียงสแนป และเสียงพูด และบอกสถานะ
- {{cmd:DESCRIBE}} บอกว่าแบบมีอะไรบ้าง
- {{cmd:WHEREAMI}} บอกตำแหน่งเคอร์เซอร์
- {{cmd:NEARBY}} บอกสิ่งที่อยู่ใกล้เคอร์เซอร์
- {{cmd:SAYSEL}} บอกสิ่งที่เลือก หนึ่งประโยคต่อหนึ่งวัตถุ
- {{cmd:VOICE}} เปิดหรือปิดคำสั่งพูด

ทั้งห้าคำสั่งนี้อ่านแบบและแสดงคำตอบ โดยไม่เปลี่ยนแปลงอะไรเลย

## เสียงสำหรับสแนปและกริป

เปิด **เสียงสแนปและกริป** ในการตั้งค่า แต่ละชนิดของสแนปมีระดับเสียงและเสียงของตนเอง จึงแยกจุดปลาย จุดกึ่งกลาง จุดศูนย์กลาง จุดตัด และอื่น ๆ ได้ กริปมีเสียงติ๊กสองครั้ง เสียงจะเคลื่อนไปทางซ้ายหรือขวาตามเคอร์เซอร์บนหน้าจอ เสียงถูกสร้างบนคอมพิวเตอร์เครื่องนี้ ไม่มีการดาวน์โหลดอะไร

## คำสั่งด้วยเสียง

เปิด **คำสั่งด้วยเสียง** ในการตั้งค่า พูดชื่อคำสั่ง ("line", "circle", "move") แล้วพูดตัวเลขตามที่อ่าน: "point three hundred comma four hundred", "distance twelve hundred", "angle forty five" "Enter", "cancel", "undo" และ "redo" ทำงานตามที่พูด สิ่งที่ได้ยินจะถูกอ่านกลับ และวลีที่ไม่ใช่คำสั่งจะถูกรายงาน ไม่ใช่เดา

**ที่รับรู้เสียงพูด** CadCraft ไม่มีบริการเสียงพูดของตนเองและไม่ส่งเสียงไปที่ใดเลย มันขอให้เบราว์เซอร์รับรู้เสียงพูดบนคอมพิวเตอร์เครื่องนี้ หากเบราว์เซอร์ทำได้ ตัวเลือกคือ **บนคอมพิวเตอร์เครื่องนี้** และไม่มีเสียงออกจากเครื่อง หากทำไม่ได้ เสียงจะปิดอยู่ เว้นแต่จะเลือก **บริการออนไลน์ของเบราว์เซอร์** ซึ่งให้เบราว์เซอร์ส่งเสียงไปยังบริการเสียงพูดของผู้ผลิต การตั้งค่าจะบอกว่าใช้กับกรณีใดก่อนตัดสินใจ

## สิ่งที่ยังไม่ทำ

- มีเพียง CadCraft เท่านั้นที่มี Access แอปอีกเจ็ดตัวจะตามมา พร้อมปุ่มและเสียงเดียวกัน
- ข้อความในแบบ (หมายเหตุ ชื่อบล็อก) จะถูกอ่านตามที่เขียน และจะไม่ถูกนำไปใช้เป็นคำสั่งเด็ดขาด
- ได้ทดสอบด้วยการตรวจสอบสังเคราะห์และการทดสอบเบราว์เซอร์แล้ว การตรวจด้วยมือกับ NVDA, VoiceOver และผู้ทดสอบที่ตาบอดหรือสายตาเลือนรางยังรอดำเนินการ หากลองใช้แล้ว โปรดแจ้งว่ายังขาดอะไร
