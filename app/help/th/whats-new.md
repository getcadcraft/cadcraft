นี่คือสิ่งที่เปลี่ยนไปใน CadCraft 0.9 เมื่อเทียบกับ 0.8.1 CadCraft เป็นแอปวาดแบบ 2D และ 3D ของ CadCraft Studio 0.9 และแอปอีกแปดตัว 0.9 ทำการร่างผังพื้นให้สมบูรณ์ เพิ่มสไตล์ข้อความและตัวแก้ไขข้อความที่ใช้งานได้จริง และให้พื้นที่บนหน้าจอมากขึ้น

## ใหม่

### การร่างผังพื้น

- **แฮตช์ที่ตามขอบเขต** {{cmd:HATCH}} เชื่อมกับขอบเขตที่กำหนดมัน ย้าย หมุน หรือสเกลขอบเขต แล้วแฮตช์และแพตเทิร์นจะตามไปด้วย ปรับรูปร่างขอบเขต แฮตช์จะถูกคำนวณใหม่ {{cmd:HATCHEDIT}} (`HE`) เปลี่ยนแฮตช์ภายหลัง และสร้างหรือยกเลิกการเชื่อมโยงได้ ดู [แฮตช์และพื้นที่เติมสี](topic:hatch)
- **ไฟล์แพตเทิร์นของแฮตช์** ที่คำถาม {{cmd:HATCH}} `เลือกจุดภายใน` ให้พิมพ์ `F` (ไฟล์แพตเทิร์น) แล้วเลือกไฟล์ `.pat` ทดสอบเฉพาะไฟล์ที่เขียนตามรูปแบบทั่วไปแล้วเท่านั้น
- **กลุ่มเลเยอร์** ในเครื่องมือบนพาเนลเลเยอร์: กลุ่มใหม่, เพิ่มกลุ่มสำเร็จรูป, จัดกลุ่มตามชื่อ และค้นหาเลเยอร์ หรือพิมพ์ {{cmd:LAYGROUP}} (`LG`) ดู [จัดระเบียบแบบด้วยเลเยอร์](topic:layers#group-layers)
- **ชั้นซ้อน** {{cmd:FLOORS}} (`FLR`) หรือ ชั้น… ในเมนูเพิ่มเติมของกลุ่มมุมมอง วิวพอร์ตบนแผ่นงานแสดงชั้นหนึ่งได้ผ่าน ชั้นที่แสดง ในคุณสมบัติ {{cmd:FLOORLAYERS}} เปลี่ยนชั้นให้เป็นเลเยอร์สำหรับไฟล์ที่จะส่งให้คนอื่น ดู [วางหลายชั้นในแบบเดียว](topic:floors)
- **ผนัง ประตู และหน้าต่าง 2D อัจฉริยะ** {{cmd:WALL}} (`WA`), {{cmd:DOOR}} (`DR`), {{cmd:WINDOW}} (`WN`) และ {{cmd:DELOPENING}} มุม การต่อแบบตัวที และจุดตัดถูกคำนวณให้อัตโนมัติ ผนังเก็บบันทึกว่าต่อกันอย่างไร และคุณสมบัติมี ไม่อนุญาตให้ต่อที่จุดเริ่มต้น / ที่จุดสิ้นสุด บรรทัดตำแหน่ง และความยาวที่แก้ไขได้ ดู [วาดผนัง ประตู และหน้าต่าง 2D](topic:walls-2d)
- **เครื่องมือผนังสำหรับผนังผังพื้น** พิมพ์ {{cmd:WALLRECT}}, {{cmd:WALLPOLY}}, {{cmd:WALLARC}}, {{cmd:WALLTRACE}}, {{cmd:WALLDIM}}, {{cmd:WALLOFFSET}}, {{cmd:WALLSPLIT}}, {{cmd:WALLGRID}} และคำสั่งอื่น ๆ ยังไม่มีปุ่มบนแถบเครื่องมือ ดู [รูปร่าง การตัด ออฟเซ็ต และการล็อกของผนัง 2D](topic:wall-tools-2d)

### ข้อความ

- **สไตล์ข้อความ** {{cmd:STYLE}} (`ST`) หรือ สไตล์ข้อความ บนแถบเครื่องมือวาด: สไตล์ที่ตั้งชื่อได้พร้อมฟอนต์ ความสูง อัตราส่วนความกว้าง และความเอียง ดู [กำหนดฟอนต์และขนาดของข้อความด้วยสไตล์ข้อความ](topic:text-styles)
- **ตัวแก้ไขข้อความย่อหน้าแบบจัดรูปแบบ** {{cmd:MTEXT}}, {{cmd:TEXTEDIT}} หรือดับเบิลคลิกที่ข้อความจะเปิดกล่องที่มีฟอนต์ ขนาด ตัวหนา ตัวเอียง ขีดเส้นใต้ ขีดฆ่า สี การจัดแนว และเครื่องหมายองศา บวกลบ และเส้นผ่านศูนย์กลาง พร้อม ตกลง และ ยกเลิก ดู [จัดรูปแบบข้อความย่อหน้า](topic:format-paragraph-text)
- **ไดอะแกรมจาก draw.io XML** {{cmd:DIAGRAM}} (`T2D`) อ่าน draw.io XML ที่วางด้วย ดู [วาดไดอะแกรมจากข้อความ](topic:text-to-diagram)
- **ข้อความภาษาไทยในการพล็อต PDF** ก่อนหน้านี้พิมพ์ออกมาเป็นเครื่องหมายคำถาม

### พื้นที่มากขึ้นและตัวช่วยวาด

- **บรรทัดคำสั่งแบบลอยที่บางลงและพื้นที่ด้านบนที่กะทัดรัด** ลากกริปของบรรทัดคำสั่งเพื่อให้ลอย ลากขอบด้านบนเพื่อให้เห็นบรรทัดน้อยลง {{key:F2}} เปิดประวัติ การตั้งค่า › CadCraft › บรรทัดคำสั่ง และตัวเลือกพื้นที่ด้านบนมีการตั้งค่าเดียวกัน ดู [การตั้งค่า](topic:settings#command-line)
- **เมนูสแนปวัตถุ** คลิกขวาที่ สแนป บนแถบสถานะ หรือพิมพ์ {{cmd:OSNAP}}
- **สแนปไปยังกริด** ปุ่ม สแนปกริด บนแถบสถานะ หรือ {{key:F9}} จุดที่เลือกจะไปยังจุดกริดที่ใกล้ที่สุดเมื่อไม่มีสแนปวัตถุจับจุดนั้น
- **ส่วนโค้งสิบวิธี และต่อเนื่อง** ส่วนโค้ง บนแถบเครื่องมือวาด หรือ {{cmd:ARC}}: 3 จุด กลุ่มจุดเริ่มต้น/จุดศูนย์กลาง/จุดสิ้นสุด และกลุ่มจุดศูนย์กลาง/จุดเริ่มต้น/จุดสิ้นสุด และ ต่อเนื่อง (กด {{key:Enter}} ที่จุดเริ่มต้น) จากเส้น ส่วนโค้ง หรือโพลีไลน์ล่าสุด
- **พาเนลเอกสาร** {{cmd:DOCUMENTS}} (`DOCS`) หรือ เอกสาร… ในเมนูเพิ่มเติมของกลุ่มมุมมอง: การแก้ไข สถานะ และเช็กเอาต์สำหรับทุกแบบในโฟลเดอร์โปรเจกต์ เปิดเป็นกล่องโต้ตอบกลางจอ ดู [เอกสาร](topic:documents)

### ไฟล์

- **ขนาดเหล็ก UK** 976 หน้าตัดในพาเนลมาตรฐาน พิมพ์ได้เหมือนในแบบ (เช่น `305x165x40 UB`)
- **ชุดข้อมูลของแอฟริกาใต้** (แนวปฏิบัติการร่างแบบและข้อบังคับอาคาร) เป็นชุดของส่วนเสริมข้อบังคับอาคาร ตัวเลขยังไม่ได้รับการยืนยัน
- **ส่วนเสริมสำหรับ CadCraft** เพิ่มเมื่อต้องการและปิดไว้เป็นค่าเริ่มต้น ได้แก่ การออกแบบแสงสว่างภายใน การออกแบบชิป (HDL เป็นแผนผัง) การแกะสลักด้วยเราเตอร์ การจำลองวงจร โซ่ลูกโซ่ฟันเฟืองแบบลูกกลิ้ง และชุดประเทศของข้อบังคับอาคาร

## แก้ไขแล้ว

- การย้าย หมุน หรือสเกลแฮตช์ทำให้แพตเทิร์นค้างอยู่ที่เดิม
- {{cmd:GRIDMOVE}} ลากผนังผังพื้นทั้งเส้นที่เริ่มเฉพาะบนเส้นกริด ตอนนี้จะพิจารณาผนังจากปลายทั้งสองข้าง
- กริดแสดงเฉพาะภายในขีดจำกัดของแบบ แม้ปิดขีดจำกัดไว้
- รายการบล็อกในแถบด้านข้างเลื่อนได้ และชื่อที่ไม่ตรงกับบล็อกใด จะแสดงบล็อกที่ขึ้นต้นด้วยชื่อนั้น ("หมายถึง")
- ไฟล์ DXF R12 ที่ AutoCAD ปฏิเสธ ("Unknown group 1001 for table") เปิดได้แล้วที่นี่
- ไฟล์ขนาดใหญ่มาก (ราว 70,000 เอนทิตีขึ้นไป) เปิดไม่ได้พร้อมข้อความ "Maximum call stack size exceeded"
- ไฟล์ DWG จาก AutoCAD 2018 ขึ้นไปที่มีเวอร์ชันการบำรุงรักษาสูง เปิดไม่ได้พร้อมข้อความ "bad BITLONG code 11"
- ในกล่องข้อความย่อหน้า ขนาดใหม่ที่พิมพ์สำหรับส่วนที่เลือกจะคงการเลือกไว้

## ในทุกแอป

คำแนะนำแบบ Bootstrap บนทุกตัวควบคุมที่มีคำแนะนำ เคล็ดลับเริ่มต้นที่ปิดได้ แท็บที่เลื่อนได้เมื่อไม่พอดี และชื่อแท็บของเบราว์เซอร์ที่ตามแบบที่เปิดอยู่ (`<drawing> - CadCraft | CadCraft`) การตั้งค่า › เลย์เอาต์ ตอนนี้เป็นรายการแบบดรอปดาวน์ของตัวเลือกสองบรรทัด รายการภาษาในการตั้งค่ายาวกว่าใน 0.8 การแก้ไขร่วมแบบ Live คอลเลกชันของไลบรารี และหน่วยน้ำหนักและอุณหภูมิ อธิบายไว้ในหมายเหตุของ Studio

## ข้อจำกัดที่ยอมรับ

- ข้อความย่อหน้าไม่มีรายการแบบจุดหรือเลขลำดับ ไม้บรรทัดแท็บ หรือการจัดชิดขอบ PDF ที่พล็อตแล้วใช้ Helvetica สำหรับข้อความ
- ผนังผังพื้นเป็นเส้นตรง ส่วนโค้งจึงวาดเป็นผนังสั้น ๆ การตรวจสอบด้วยมือของชุมชนสำหรับเครื่องมือผนังยังรอดำเนินการ
- ชั้นของเลเยอร์กลุ่มไม่ได้เขียนในรูปแบบของ AutoCAD เอง AutoCAD จึงแสดงเป็นรายการแบน โปรแกรมอื่นแสดงทุกชั้นรวมกันเว้นแต่คุณจะรัน {{cmd:FLOORLAYERS}}
- พาเนลเอกสารยังไม่ได้ทดสอบโดยสองคนบนโฟลเดอร์แชร์จริง การแกะสลักด้วยเราเตอร์ยังไม่เคยทำงานบนเครื่องจริง การประมาณแสงตรวจสอบด้วยการติดตามโฟตอน ไม่ใช่กับโปรแกรมอื่น ส่วนเสริมด้านวิศวกรรมเป็นเครื่องมือช่วยตรวจสอบ ไม่ใช่การแทนที่การตรวจทานของวิศวกร
- ภาษาอื่นที่ไม่ใช่ภาษาอังกฤษเป็นฉบับร่างจากเครื่อง และคำใหม่บางคำมีเฉพาะภาษาอังกฤษ

## ก่อนหน้านี้: 0.8 และ 0.8.1

นี่คือสิ่งที่เปลี่ยนไปใน CadCraft 0.8 และ 0.8.1 เมื่อเทียบกับ 0.7 0.8 (1 พฤศจิกายน 2026) เพิ่มตัวช่วยการวาดที่ทำงานจากแบบของคุณเอง ด้วยกฎบนคอมพิวเตอร์ของคุณ และไม่ใช้โมเดล ส่วน 0.8.1 (2 พฤศจิกายน 2026) แก้ข้อบกพร่องที่รายงานหลังจากนั้น

### ใหม่

**การวาดที่ต่อความคิดของคุณ**

- **โกสต์แสดงสิ่งที่จะตามมา** เมื่อไม่มีคำสั่งทำงาน โกสต์เส้นประสีเทาจะแสดงสิ่งที่รูปแบบของแบบคุณบอกว่าจะตามมา: โครงถัดไปที่ระยะเท่ากัน ขั้นถัดไปของบันได หรือผนังที่หายไปของห้อง กด {{key:Tab}} เพื่อวาดเป็นหนึ่งขั้นการเลิกทำ หรือ {{key:Esc}} เพื่อปิด มันดูเฉพาะวัตถุที่ใหม่ที่สุด จึงยังลื่นไหลกับแบบขนาดใหญ่ ปิดได้ใน การตั้งค่า › CadCraft หรือด้วย {{cmd:AUTOCOMPLETE}} `Off`
- **จุดถัดไปขณะวาดเส้น** ระหว่าง {{cmd:LINE}} หรือ {{cmd:PLINE}} โกสต์คือจุดถัดไป: ขั้นถัดไปของบันได มุมที่สี่ของสี่เหลี่ยม หรือจุดที่ปิดรูป นำเคอร์เซอร์เข้าใกล้แล้วกด {{key:Tab}} เหมือนคุณคลิกตรงนั้น
- **ลายเส้นปากกากลายเป็นรูปทรงที่แม่นยำ** {{cmd:SKETCHFIX}} วาดเส้นร่างด้วยปากกา เมาส์ หรือนิ้ว แต่ละเส้นจะกลายเป็นเส้น วงกลม ส่วนโค้ง สี่เหลี่ยมผืนผ้า หรือโพลีไลน์ที่สะอาด และสแนปกับสิ่งที่วาดไว้แล้ว ดู [ร่างด้วยปากกาและได้รูปทรงที่แม่นยำ](topic:sketch-with-a-pen)
- **รูปถ่ายของภาพร่างกลายเป็นแบบ** {{cmd:PHOTOSKETCH}} (`PSK`) หาแผ่นกระดาษในรูปถ่าย ปรับมุมมองให้ตรง ใช้ขนาดกระดาษและมาตราส่วนที่คุณให้ และลอกเส้นปากกาลงเลเยอร์สำหรับสีปากกาแต่ละสี ตัวอักษรจะไม่ถูกลอก
- **ให้มิติตามกฎ** {{cmd:AUTODIM}} (`ADIM`) สร้างลูกโซ่ของไดเมนชันตามด้านที่คุณเลือก ขนาดรวม ความกว้างช่องเปิด เส้นผ่านศูนย์กลางรู และระยะกริดเมื่อใช้ `Grid` ไม่เคยทำซ้ำไดเมนชันที่มีอยู่แล้ว
- **ย้ายเส้นกริดแล้วชุดตามไป** {{cmd:GRIDMOVE}} (`GM`): ผนังที่จบบนเส้นกริดยืดตามไป ผนังที่อยู่ตามแนวเส้นจะเคลื่อนไป รวมทั้งเสา ฟองกลม และแท็ก ส่วนไดเมนชันบนเส้นวัดระยะใหม่ เป็นหนึ่งขั้นการเลิกทำ

**แผ่นงานที่จัดวางเอง รายละเอียด และแท็ก**

- **แผ่นงานที่จัดวางตัวเอง** {{cmd:AUTOSHEET}} ใช้มุมมองที่ตั้งชื่อของคุณ (หรือชิ้นส่วนที่แยกของโมเดล) เลือกขนาดกระดาษและมาตราส่วนมาตรฐาน แล้ววางมุมมองลงบนแผ่นใหม่พร้อมตารางชื่อเรื่องและคำบรรยายชื่อกับมาตราส่วน ทุกอย่างยังแก้ไขได้ ดู [จัดเลย์เอาต์แผ่นงานให้ฉัน](topic:lay-out-sheets-for-me)
- **รายละเอียดของบริษัทคุณ ที่เสนอขณะวาด** {{cmd:DETAILS}} (`DET`) เก็บบล็อกรายละเอียดของคุณเอง เมื่อสิ่งที่คุณเลือกตรงกับบล็อกหนึ่งตามคำในชื่อเลเยอร์ ชื่อบล็อก และหมายเหตุ แถบสถานะจะบอก เลือกแล้ววาง {{cmd:DETAILS}} › แชร์ นำรายการของคุณไปไว้ในโฟลเดอร์เอกสาร และนำสิ่งที่ทีมเพิ่มเข้ามาไว้ด้วย การตั้งค่าปิดข้อเสนอได้
- **แท็กบนบล็อก** {{cmd:TAGS}} กำหนดแท็ก (ชนิด ค่าที่รับได้ และบล็อกที่ใช้) ตั้งค่าให้การอ้างอิงบล็อกที่คุณเลือก และแสดงเป็นตารางรายการที่บันทึกเป็น CSV ได้ นิยามเก็บไว้ใน DWG ดู [แท็ก](topic:tags)
- **ขีดจำกัดของแบบ** {{cmd:LIMITS}} ตั้งสี่เหลี่ยมสำหรับแบบ กริดเติมเต็มและการซูมทั้งหมดแสดงสี่เหลี่ยมนั้น ขีดจำกัดแสดงเป็นเส้นโครงร่างและบันทึกใน DWG และ DXF พร้อมขีดจำกัดของกระดาษ ดู [ตั้งขีดจำกัดของแบบ](topic:drawing-limits)

**การทำงานร่วมกับคนอื่นและโปรแกรมอื่น**

- **เปลี่ยนมาร์กอัปเป็นการแก้ไข** {{cmd:REDLINE}} อ่านแพ็กเกจที่ MarkupCraft เขียนและแสดงทุกการเปลี่ยนแปลง ยอมรับหรือปฏิเสธแต่ละรายการพร้อมหมายเหตุ รายการที่ยอมรับจะได้เมฆการแก้ไขและบันทึกการแก้ไขในขั้นการเลิกทำเดียว และคุณบันทึกไฟล์คำตอบที่ปิดมาร์กอัปใน MarkupCraft ดู [เปลี่ยนมาร์กอัปเป็นการแก้ไข](topic:redline-to-revision)
- **แบบที่ git และ Fossil รวมได้** เมื่อเปิด ไฟล์ที่รวมกันได้ง่าย ใน การตั้งค่า › CadCraft วัตถุทุกชิ้นจะได้คีย์ที่ไม่เปลี่ยน (ไฟล์ใหญ่ขึ้นราว 10 เปอร์เซ็นต์) `cadcraft merge base ours theirs` จะรวมการแก้ไขของสองคนในแบบ DWG หรือ DXF ทีละวัตถุ และรายงานเฉพาะจุดที่คนสองคนเปลี่ยนสิ่งเดียวกัน ดู [รวมการแก้ไขของสองคนในแบบเดียว](topic:merge-drawings)
- **อะไรเปลี่ยนไป เป็นคำอธิบาย** ใน ประวัติ เปรียบเทียบให้รายการแบบข้อความธรรมดา: สิ่งที่เปลี่ยนอยู่ที่ไหน พื้นที่มีขนาดเท่าใด สิ่งที่เพิ่ม ลบ หรือเปลี่ยน และข้อความที่ถูกแก้ไข ดู [บอกเป็นคำว่าอะไรเปลี่ยนไป](topic:changes-in-words)
- **ทิศทางและมุม** พิมพ์ทิศทางแบบมุมสำรวจ เช่น N45°23'30"E หรือเป็นองศา นาที และวินาทีได้ทุกที่ที่ถามหามุม AUNITS กำหนดวิธีแสดงมุม ดู [พิมพ์และแสดงทิศทางและมุม](topic:bearings-and-angles)
- **ฟอนต์ SHX ของคุณเอง** ให้ CadCraft ใช้โฟลเดอร์ฟอนต์ SHX และสไตล์ข้อความที่ระบุชื่อฟอนต์เหล่านั้นจะถูกวาดด้วยฟอนต์เหล่านั้น ทั้งบนหน้าจอและในการพล็อต ดู [วาดข้อความด้วยฟอนต์ SHX ของคุณเอง](topic:shx-fonts)
- **ไดอะแกรมจากข้อความ** {{cmd:DIAGRAM}} อ่านผังงาน Mermaid แผนภาพส่วนประกอบ PlantUML, D2 หรือรายการจากไป-ถึง แล้ววาดบล็อกและตัวเชื่อมที่แก้ไขได้ ดู [วาดไดอะแกรมจากข้อความ](topic:text-to-diagram)
- **วัตถุ OLE ใน DWG** {{cmd:OLELIST}} แสดงรายการวัตถุ OLE ที่ DWG มีและ CadCraft วางเองไม่ได้ และวางสำเนารูปภาพตรงที่คุณระบุ ดู [รูปภาพ](topic:pictures#objects-from-other-programs-ole)
- **การคำนวณของคุณอยู่กับแบบ** แผ่นคำนวณและเหตุผลการออกแบบถูกเก็บใน DWG พร้อมตารางคลาส

**การร่างแบบโดยไม่ต้องมองเห็น**

- เปิด ร่างแบบโดยไม่ต้องมองเห็น ในการตั้งค่า (หรือพิมพ์ {{cmd:ACCESS}} แล้วตอบ `On`) CadCraft จะอ่านทุกคำสั่งและผลลัพธ์ผ่านโปรแกรมอ่านหน้าจอของคุณ อธิบายแบบและสิ่งที่อยู่ใกล้เคอร์เซอร์ ให้คุณย้ายเคอร์เซอร์และเลือกจุดด้วยคีย์บอร์ด และเล่นเสียงสำหรับทุกสแนปและกริป เมื่อเบราว์เซอร์ของคุณจดจำเสียงพูดบนคอมพิวเตอร์ได้ จะพูดคำสั่งได้ ดู [ร่างแบบโดยไม่ต้องมองเห็น](topic:draft-without-sight)

**ในทุกแอป**

- **ภาษา** 54 ภาษา ใหม่ 10 ภาษา (ลิทัวเนีย ลัตเวีย บอสเนีย มราฐี เตลูกู แอลเบเนีย แอฟริกาอันส์ ฟิลิปปินส์ สวาฮีลี อุซเบก) ภาษาอื่นนอกจากอังกฤษเป็นฉบับร่างจากเครื่องจนกว่าเจ้าของภาษาจะอ่าน
- **อุปกรณ์ป้อนข้อมูล** การควบคุมด้วยแทร็กแพด ปากกา เมาส์ 3 มิติ จอยเกม และ MIDI
- **จำนวนแถวของแถบเครื่องมือและตารางคุณสมบัติ** การตั้งค่า › ทั่วไป › จำนวนแถวของแถบเครื่องมือ มีให้เลือก ห่อ 2 แถว หรือ 1 แถวในแอปอื่น CadCraft มีการตั้งค่าของตัวเองใน การตั้งค่า › CadCraft (ดู [จำนวนแถวของแถบเครื่องมือ](topic:settings#toolbar-rows)) ตารางคุณสมบัติที่ใช้ร่วมกันอยู่ในแอปอื่นสามตัว ไม่ได้อยู่ใน CadCraft
- **ปัญหา Live และส่วนเสริม** พาเนลปัญหาที่ใช้ร่วมกันซึ่งเตือนในทุกแอป มุม Live ที่แสดงว่าใครอยู่ตรงไหนใน CadCraft Studio (ดู [ทำงานกับแบบเดียวกันร่วมกัน](topic:work-live)) และรายการส่วนเสริม
- **เชื่อมต่อ AI ของคุณ** การเชื่อมต่อหนึ่งครั้งจาก CadCraft Studio ไปยังทั้งแปดแอป พร้อมระดับ อ่านอย่างเดียว แนะนำ หรือแก้ไขต่อแอป และบันทึกที่เป็นคำอธิบายธรรมดาของสิ่งที่ผู้ช่วยทำ CadCraft ไม่มี AI ของตัวเอง และ ถามในทุกแอป ใช้ AI ที่คุณเชื่อมต่อ

### แก้ไขใน 0.8.1

- **คุณสมบัติแสดง 150 แทน 12'-6"** ในแบบที่ใช้ฟุตและนิ้ว ฟิลด์ที่แอปอ่านเองกลับมาคงข้อความไว้
- **ไฟล์ DWG ที่ส่วนคลาสถูกอ่านเป็นชนิดผิด** (GitHub cadcraft#5) ตอนนี้เปิดได้ถูกต้อง
- **เคอร์เซอร์รูปกากบาทไม่แสดงอยู่หลังป๊อปอัปอีกต่อไป**
- **Studio และรุ่นแพ็กสามารถเปลี่ยนภาษาขณะทำงานได้** ก่อนหน้านี้มีเฉพาะภาษาอังกฤษ ยังไม่ได้ทดสอบบนทุกแพลตฟอร์ม แจ้งให้เราทราบหากภาษาไม่เปลี่ยน
- **แท็บเล็ตในแนวตั้ง** ให้พื้นที่กริดที่เหลือแก่แคนวาส และโหมดแผ่นงานเริ่มที่ 760 px หรือน้อยกว่า
- **STRETCH ด้วยหน้าต่างข้าม และ LIMITS** ถูกรายงานบน Studio 0.8.0 และถูกต้องอยู่แล้วในบิลด์เว็บ 0.8 ตัวติดตั้งของผู้รายงานเก่ากว่า Studio 0.8.1 มีแก้ไขแล้ว

### ยังไม่มีในรุ่นนี้

- **0.8 และ 0.8.1 ยังไม่ได้ลงนามโค้ด** Windows อาจเตือน (เลือก ข้อมูลเพิ่มเติม แล้ว เรียกใช้ต่อไป) บน Mac ให้คลิกขวาที่ CadCraft Studio แล้วเลือก เปิด บิลด์ของร้านค้ายังค้างอยู่ และบิลด์ iPad กับ iPhone ยังไม่ได้สร้างใหม่สำหรับ 0.8.1
- **ภาพร่างด้วยปากกาและรูปถ่ายภาพร่าง** ทดสอบเฉพาะกับรูปถ่ายที่สร้างขึ้นและเมาส์ ยังไม่ได้ทดสอบกับปากกาจริง จอสัมผัส หรือภาพร่างด้วยมือบนกระดาษ
- **การร่างแบบโดยไม่ต้องมองเห็น** ทดสอบด้วยการตรวจอัตโนมัติ ยังไม่ได้ทดสอบกับโปรแกรมอ่านหน้าจอหรือผู้ทดสอบที่ตาบอด
- **การแชร์รายละเอียด** ยังไม่ผ่านการตรวจสอบโดยคนสองคน และโฟลเดอร์ Team Cloud Plan เป็นโฟลเดอร์เอกสารยังไม่ได้สร้าง
- **การรวม** ใช้ได้กับไฟล์ DWG และ DXF ของ CadCraft ไฟล์ของแอปอื่นยังไม่ได้สร้าง
- **การเลิกทำข้ามหน้าต่าง** CadCraft รายงานทุกขั้นที่เสร็จ แต่ Studio ยังไม่มีการเลิกทำเดียวสำหรับทุกแอป แต่ละแอปเลิกทำขั้นของตัวเอง
- **วัตถุ OLE ของ DWG** ถูกเก็บไว้แต่ยังไม่วาดตามตำแหน่ง
- **การอ่านตารางสไตล์การพล็อต (ไฟล์ CTB)** จากโปรแกรมอื่นสร้างแล้วแต่ยังไม่ได้ตรวจกับไฟล์จากโปรแกรมอื่น
- **เชื่อมต่อ AI ของคุณ:** การเชื่อมต่อด้วยคลิกเดียวใน Studio ตัวเชื่อมต่อแบบโฮสต์สำหรับ AI บนเบราว์เซอร์ คีย์ API ของคุณเองภายใน Studio และแพ็กเกจ MCP ที่เผยแพร่ ไม่ได้รับรองในรุ่นนี้

สำหรับเวอร์ชันก่อนหน้า ดู [มีอะไรใหม่ใน 0.7](topic:whats-new-0-7)
