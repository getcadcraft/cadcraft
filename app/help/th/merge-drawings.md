สองคนแก้ไขแบบเดียวกัน หากพวกเขาเปลี่ยนวัตถุต่างกัน การรวมสามารถทำโดยอัตโนมัติ ไม่ต้องทำซ้ำด้วยมือ

## สิ่งที่ทำให้ใช้งานได้

CadCraft ให้ทุกวัตถุที่วาดมี **คีย์** สั้น ๆ ที่ไม่เปลี่ยนแปลง และจะไม่ให้กับสองวัตถุ คีย์จะถูกบันทึกไว้กับวัตถุใน DWG หรือ DXF (เป็นข้อมูลเพิ่มเติมที่โปรแกรมอื่นเก็บไว้) การรวมจะค้นหาวัตถุตามคีย์นั้น ไม่ใช่ตามตำแหน่งในไฟล์ เพราะทุกโปรแกรมจะกำหนดหมายเลขตำแหน่งใหม่เมื่อบันทึก ปิดการตั้งค่านี้ที่ {{ui:การตั้งค่า}} › CadCraft › ไฟล์ที่รองรับการรวม หากไม่เคยรวมไฟล์ ไฟล์จะเล็กลงประมาณ 10 เปอร์เซ็นต์

แบบที่บันทึกก่อนมีคีย์ก็ยังรวมได้ วัตถุของแบบนั้นจะได้คีย์จากตำแหน่งในไฟล์ ซึ่งจะเหมือนกันสำหรับทุกคนที่เปิดไฟล์

## การตั้งค่า

Git ต้องการสองบรรทัดหนึ่งครั้งต่อหนึ่งรีโพซิทอรี:

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# ครั้งเดียว บนแต่ละเครื่อง
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

หากไม่ใช้ git ให้รันด้วยตนเอง: `cadcraft merge <base> <ours> <theirs> -o <result>` Fossil และ Mercurial ใช้ไฟล์สามไฟล์เดียวกันนี้ในการตั้งค่าเครื่องมือรวมของตนเอง

## กฎ

- วัตถุที่เปลี่ยนเพียงฝั่งเดียวจะถูกนำมาใช้ การเปลี่ยนแปลงแบบเดียวกันทั้งสองฝั่งจะนำมาใช้เพียงครั้งเดียว
- คุณสมบัติเดียวกันที่เปลี่ยนแปลงสองแบบคือ**ความขัดแย้ง**: ฝั่งของคุณจะคงอยู่ และรายงานจะแสดงค่าทั้งสอง เปิดผลลัพธ์ ดูวัตถุนั้น แล้วแก้ไขด้วยมือ
- วัตถุที่เพิ่มในฝั่งใดก็ได้จะถูกเก็บไว้ วัตถุที่ถูกลบในฝั่งหนึ่งและไม่ถูกแตะต้องในอีกฝั่งจะถูกลบ ถูกลบในฝั่งหนึ่งแต่ถูกเปลี่ยนในอีกฝั่ง: จะถูกลบและรายงาน
- เลเยอร์ บล็อก ข้อความและรูปแบบไดเมนชัน แผ่น และมุมมองที่ตั้งชื่อ จะรวมในลักษณะเดียวกัน ข้อจำกัดจะตามวัตถุที่ระบุไว้
- ผลลัพธ์จะถูกเขียนในรูปแบบไฟล์และเวอร์ชันเดียวกับของคุณ

ไม่รวมกัน: ลำดับการวาดวัตถุจะเป็นของฝั่งคุณ จากนั้นจึงเป็นวัตถุที่อีกฝั่งเพิ่มเข้ามา การเปลี่ยนแปลงนิยามบล็อกเดียวกันทั้งสองฝั่งคือความขัดแย้ง จะไม่ผสมกันเด็ดขาด ไม่มีการอัปโหลดอะไร ทุกอย่างทำงานบนคอมพิวเตอร์ของคุณ
