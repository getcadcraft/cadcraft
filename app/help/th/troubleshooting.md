## การเปิดไฟล์

| ข้อความหรืออาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| "CadCraft เปิดแบบ DWG และ DXF "…" ไม่ใช่ทั้งสองแบบ" | ไฟล์ไม่ใช่ `.dwg` หรือ `.dxf` | เปิดไฟล์แบบโดยตรง นำเข้า PDF ได้ (เปิดจะถามว่านำเข้าหรือแนบ ดู [พื้นหลัง PDF](topic:pdf-underlay)); ใส่รูปภาพด้วย `IMAGEATTACH` |
| "ไฟล์ DXF แบบไบนารีนี้จบกลางคันของวัตถุ: ไฟล์ถูกตัดสั้นหรือเสียหาย" | DXF แบบไบนารีหยุดก่อนถึงจุดจบ | พิมพ์ RECOVER เพื่อเปิดส่วนที่อ่านได้ หรือขอไฟล์ใหม่ |
| "ไฟล์นี้อ่านเป็น DXF ไม่ได้ (รหัสกลุ่มผิดที่บรรทัด …)" | DXF เสียหาย หรือไม่ใช่ DXF จริง | ขอไฟล์ใหม่ หรือขอ DWG |
| "ไม่สามารถอ่านแบบนี้ได้ อาจเสียหาย หรือบันทึกด้วยเวอร์ชันที่ตัวอ่านยังไม่รองรับ (…)" | ตัวอ่าน DWG อ่านไม่ได้ | ขอ DWG ที่บันทึกด้วยเวอร์ชันเก่ากว่า หรือขอ DXF |
| "แบบนี้มาจาก AutoCAD R11 / R12 (DWG AC1009) เก่ากว่าที่ CadCraft อ่านได้ …" | ไฟล์ DWG จาก Release 12 และรุ่นก่อนใช้รูปแบบที่ CadCraft ไม่อ่าน | ในโปรแกรมที่สร้างไฟล์ ให้บันทึกเป็น DXF (เวอร์ชันใดก็ได้) หรือ DWG รุ่นใหม่กว่า แล้วเปิดไฟล์นั้น {{ui:บันทึกเป็น}} ของ CadCraft มี DXF R12 สำหรับโปรแกรมที่ต้องการรูปแบบเก่านั้น |
| "ไม่สามารถเปิด …" ตามด้วยข้อความเครือข่าย ในครั้งแรกของ DWG | ดาวน์โหลดตัวอ่าน DWG ไม่ได้: คุณออฟไลน์และ CadCraft ไม่ได้บันทึกไว้ใช้ออฟไลน์ หรือการเชื่อมต่อขาด | เชื่อมต่ออินเทอร์เน็ตแล้วลองใหม่ หรือเปิด DXF คลิก {{ui:บันทึกสำหรับออฟไลน์}} และรอจนขึ้น "พร้อมใช้งานออฟไลน์" เพื่อให้ไฟล์ DWG เปิดแบบออฟไลน์ได้ครั้งหน้า ดู [การทำงานแบบออฟไลน์](common:offline) |
| ปุ่มออฟไลน์ขึ้นว่า "บันทึกไม่ได้" | ไฟล์บางไฟล์ไม่ได้ดาวน์โหลด | ตรวจการเชื่อมต่อ แล้วคลิกปุ่มเพื่อลองอีกครั้ง |
| ปุ่มออฟไลน์ขึ้นว่า "ออฟไลน์ไม่พร้อมใช้งาน" | หน้าต่างส่วนตัวและคอมพิวเตอร์บางเครื่องที่มีการจัดการไม่สามารถเก็บสำเนาออฟไลน์ได้ | ใช้หน้าต่างปกติ หรืออยู่ออนไลน์ |
| CadCraft ไม่เปิดเมื่อไม่มีการเชื่อมต่อ | ยังไม่ได้บันทึกไว้ใช้ออฟไลน์ในเบราว์เซอร์นี้ หรือเบราว์เซอร์ล้างข้อมูลนั้นไปแล้ว | ครั้งหน้าที่ออนไลน์ คลิก {{ui:บันทึกสำหรับออฟไลน์}} แล้วรอจนขึ้น "พร้อมใช้งานออฟไลน์" |
| แบบเปิดขึ้นแต่บางส่วนหายไป | วัตถุที่ CadCraft ยังวาดไม่ได้ หรือเลเยอร์ที่ปิดหรือแช่แข็งในไฟล์ | อ่าน "About this file" ในพาเนลซ้าย และตรวจพาเนล {{ui:เลเยอร์}} |
| ข้อความตัดเป็นสองบรรทัด | CadCraft วาดข้อความด้วยฟอนต์แบบ Helvetica ซึ่งกว้างกว่าฟอนต์ CAD บางตัว | ย่อข้อความในคุณสมบัติ หรือยอมรับบรรทัดเพิ่ม |
| วงกลมแสดงเป็นวงรี หรือข้อความที่สะท้อนอ่านได้ถูกทิศ | วัตถุถูกวาดบนระนาบเอียง หรือมองจากด้านล่าง ในโปรแกรมที่สร้างไฟล์ CadCraft แสดงจากมุมมองด้านบน ตามที่มุมมองแผนของโปรแกรมนั้นทำ ข้อความยังคงอ่านได้ | ไม่ต้องแก้ไข หากต้องการดูตามแบบของโปรแกรมอื่น ให้ขอแบบที่แบนราบ หรือวัตถุที่วาดจากด้านบน |
| บล็อก วงกลม หรือไดเมนชันอยู่ผิดที่จากในโปรแกรมที่สร้างไฟล์ | กรณีของแบบที่ CadCraft อ่านผิด | แจ้งบน Discord พร้อมไฟล์ หากคุณแชร์ได้ |

## บรรทัดคำสั่ง

| ข้อความหรืออาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| "คำสั่งที่ไม่รู้จัก "…" พิมพ์ HELP เพื่อดูรายการ" | ไม่มีคำสั่งหรือชื่อย่อที่ชื่อนั้น | พิมพ์ `HELP` หรือดู [รายการคำสั่ง](topic:commands) คำสั่งที่คุ้นบางอย่าง [ยังไม่ได้สร้าง](topic:not-built-yet) |
| "ไม่มีคำสั่งนี้" ขึ้นข้างบรรทัดคำสั่งขณะพิมพ์ | สิ่งที่คุณพิมพ์ยังไม่ตรงกับอะไร | พิมพ์ต่อ หรือตรวจการสะกด |
| "ต้องใช้จุดหรือคำสำคัญของตัวเลือก" | สิ่งที่คุณพิมพ์ไม่ใช่จุดหรือตัวเลือก | ตรวจรูปแบบ: `x,y`, `@dx,dy`, `@d<a` หรือตัวเลขเดียว ดู [การป้อนพิกัดและระยะทาง](topic:coordinate-entry) |
| "ต้องใช้จำนวนบวกหรือจุดสองจุด" | ระยะเป็นลบหรือไม่ใช่ตัวเลข | พิมพ์จำนวนบวก หรือคลิกสองจุด |
| "ต้องใช้มุมเป็นองศาหรือจุดสองจุด" | มุมไม่ใช่ตัวเลข | พิมพ์องศาเป็นตัวเลขธรรมดา |
| "ต้องใช้ตัวเลข" | คาดว่าจะเป็นตัวเลข | พิมพ์เฉพาะตัวเลข |
| "คำสำคัญของตัวเลือกไม่ถูกต้อง" | ตัวอักษรไม่ตรงกับตัวเลือกใด | พิมพ์ตัวอักษรตัวพิมพ์ใหญ่ที่แสดงในวงเล็บเหลี่ยม |
| `*Cancel*` | คุณกด {{key:Esc}} หรือกด {{key:Enter}} ตรงที่ต้องใช้จุด | เริ่มคำสั่งอีกครั้ง |
| การพิมพ์ไม่เข้าบรรทัดคำสั่ง | กล่องในพาเนลหรือกล่องโต้ตอบมีเคอร์เซอร์อยู่ | กด {{key:Enter}} หรือ {{key:Esc}} หรือคลิกที่แบบ |
| คำสั่งใช้วัตถุที่คุณไม่ได้เลือก | วัตถุถูกเลือกไว้ก่อนเริ่มคำสั่ง | กด {{key:Esc}} ก่อนเริ่มคำสั่ง |
| เส้นไปอยู่ผิดที่ | `x,y` เป็นค่าสัมบูรณ์ | ใช้ `@dx,dy` สำหรับจุดสัมพัทธ์ |
| "จบหรือยกเลิกคำสั่งปัจจุบันก่อน (Esc)" | คุณกด {{key:Mod+S}} ขณะที่คำสั่งกำลังทำงาน | กด {{key:Esc}} แล้วจึงบันทึก |
| "บันทึกเป็น DWG (AutoCAD 2000) ไม่ได้: … ลองบันทึกเป็น แล้วเลือก DXF" | บางอย่างในแบบเขียนเป็น DWG ไม่ได้ | กด {{key:Mod+Shift+S}} เลือก DXF R12 แล้วคลิก {{ui:บันทึก}} |
| "ยังไม่ได้บันทึก" | คุณปิดกล่อง {{ui:บันทึกสำเนาเป็น}} ด้วย {{ui:ยกเลิก}} หรือ {{key:Esc}} | กด {{key:Mod+Shift+S}} อีกครั้งแล้วคลิก {{ui:บันทึก}} |

## การแก้ไข

| ข้อความหรืออาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| วัตถุเลือกไม่ได้ | เลเยอร์ของมันถูกล็อก ปิด หรือแช่แข็ง หรือคุณอยู่บนแผ่นและวัตถุเป็นโมเดลในวิวพอร์ต | ปลดล็อกเลเยอร์ หรือไปที่แท็บ {{ui:โมเดล}} |
| "ไม่พบอะไรตรงนั้น" | ไม่มีวัตถุอยู่ใต้การคลิก | ซูมเข้า และคลิกบนเส้นเอง |
| "ไม่มีอะไรตัดวัตถุนั้นตรงนั้น" | {{cmd:TRIM}} ไม่พบวัตถุที่ตัดชิ้นที่คุณเลือก | ตรวจว่าเส้นตัดจริงตัดผ่านชิ้นนั้น |
| "ตัดวัตถุนั้นไม่ได้" | การตัดทำได้กับเส้น ส่วนโค้ง วงกลม และโพลีไลน์ | แตกบล็อกออกก่อน หรือลบแล้ววาดใหม่ |
| "ไม่มีขอบเขตในทิศทางนั้น" | {{cmd:EXTEND}} ไม่พบอะไรให้ไปถึง | เลือกปลายที่ใกล้กว่าซึ่งควรยาวขึ้น |
| "ออฟเซ็ตวัตถุนั้นไม่ได้" | ออฟเซ็ตทำได้กับเส้น ส่วนโค้ง วงกลม และโพลีไลน์ | แตกออกก่อน หรือวาดเส้นขนานขึ้นใหม่ |
| "ออฟเซ็ตไกลขนาดนั้นไม่ได้" | ออฟเซ็ตจะทำให้รูปพลิกด้านในออก | ใช้ระยะที่สั้นกว่า |
| "รัศมีใหญ่เกินไป" หรือ "ระยะใหญ่เกินไป" | ฟิลเลตหรือชัมเฟอร์จะวิ่งเกินปลายของเส้น | ตั้งรัศมีที่เล็กลงด้วย `R` หรือระยะที่เล็กลงด้วย `D` |
| "ตัดกลับได้เฉพาะส่วนแรกหรือส่วนสุดท้ายของโพลีไลน์เปิด" | มุมจะตัดเข้าไปกลางโพลีไลน์ | เลือกสองส่วนของโพลีไลน์ที่อยู่ติดกัน หรือใช้ `P` สำหรับทุกมุม |
| "เลือกเส้นที่สองที่ต่างออกไป" | การเลือกที่สองเป็นเส้นเดิม หรือไม่ใช่เส้น | เลือกเส้นอื่น |
| "แตกออกได้เฉพาะโพลีไลน์ การอ้างอิงบล็อก และไดเมนชัน" | การเลือกไม่มีอะไรที่แตกออกได้ | เลือกโพลีไลน์ การอ้างอิงบล็อก หรือไดเมนชัน |
| "นี่คือเลเยอร์ปัจจุบัน ตั้งเลเยอร์อื่นเป็นปัจจุบันก่อน" | คุณพยายามปิดเลเยอร์ปัจจุบัน | คลิกชื่อของเลเยอร์อื่น แล้วปิดเลเยอร์นี้ |
| "มีเลเยอร์ชื่อ … อยู่แล้ว" | ชื่อเลเยอร์ต้องไม่ซ้ำกัน | เลือกชื่ออื่น |
| "ไม่มีอะไรให้เลิกทำ" | ไม่มีอะไรเหลือให้เลิกทำ หรือคุณเปิดหรือเริ่มแบบใหม่ (ซึ่งล้างประวัติ) | — |

## ไดเมนชันและบล็อก

| ข้อความหรืออาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| ข้อความและหัวลูกศรของไดเมนชันเล็กหรือใหญ่มาก | ขนาดเป็นหน่วยของแบบ มาตราส่วนรวมไม่เข้ากับแบบ | ตั้ง {{cmd:DIMSCALE}} ให้เป็นมาตราส่วนพล็อต ดู [ตั้งขนาดไดเมนชัน](topic:dimension-settings) |
| "เลือกจุดภายในมุมที่ต้องการวัด" | ตำแหน่งของไดเมนชันมุมอยู่บนขาข้างหนึ่ง | คลิกภายในมุม |
| "เส้นเหล่านั้นขนานกัน" | เส้นขนานไม่มีมุมระหว่างกัน | เลือกเส้นสองเส้นที่มาบรรจบกัน |
| "เลือกไดเมนชันเส้นตรงหรือไดเมนชันขนาน" | {{cmd:DIMCONTINUE}} หรือ {{cmd:DIMBASELINE}} ต้องมีจุดเริ่มต้น | เลือกไดเมนชันเส้นตรงหรือไดเมนชันขนาน |
| "แบบนี้ยังไม่มีบล็อก: F แทรกจากไฟล์ L จากไลบรารี …" | แบบไม่มีบล็อกของตัวเอง | พิมพ์ `F` หรือ `L` หรือสร้างบล็อกด้วย {{cmd:BLOCK}} |
| "ไม่มีบล็อกชื่อ "…"" | ชื่อผิด | ข้อความจะแสดงรายการบล็อกที่มีอยู่ |
| "ชื่อบล็อกต้องไม่ขึ้นต้นด้วย * หรือใช้ …" ตามด้วยรายการอักขระ | ชื่อมีอักขระที่บล็อกใช้ไม่ได้ | ใช้ตัวอักษร ตัวเลข `-` และ `_` |
| "บล็อกไม่สามารถมีตัวมันเองอยู่ข้างใน" | การเลือกมีการอ้างอิงถึงบล็อกที่กำลังสร้างอยู่ | ตัดการอ้างอิงนั้นออก |
| "ไม่ได้เลือกวัตถุ จึงไม่ได้สร้างอะไร" | คุณกด {{key:Enter}} ก่อนเลือกวัตถุ | รัน {{cmd:BLOCK}} อีกครั้งแล้วเลือกวัตถุ |

## ปุ่มและหน้าจอ

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| F3, F7 หรือ F8 เปลี่ยนระดับเสียงหรือเปิด Mission Control | ปุ่มฟังก์ชันของ Mac | กด **fn** ค้างไว้ หรือใช้ปุ่มบนแถบสถานะ ดู [คีย์ เมาส์ และแทร็กแพด](common:keys) |
| F7 ถามเรื่อง caret browsing | Firefox ใช้ F7 เอง | เลือก ไม่ แล้วใช้ปุ่ม {{ui:กริด}} |
| {{key:Mod+N}} เปิดหน้าต่างเบราว์เซอร์ | เบราว์เซอร์สงวนปุ่มนั้นไว้ | คลิก {{ui:ใหม่}} หรือพิมพ์ `NEW` |
| {{key:Mod+A}} เลือกข้อความในบรรทัดคำสั่ง | บรรทัดคำสั่งมีเคอร์เซอร์อยู่ | คลิกวัตถุก่อน หรือพิมพ์ `ALL` ที่พรอมต์ `Select objects` |
| {{key:Delete}} ไม่ลบ | บรรทัดคำสั่งมีเคอร์เซอร์อยู่ | พิมพ์ `E` แล้วกด {{key:Enter}} |
| คลิกขวาไม่ทำอะไรบนแทร็กแพด Mac | Control-คลิกอาจนับเป็นการคลิกธรรมดา | คลิกด้วยสองนิ้ว |
| ไม่มีการแพนบนแทร็กแพด | ไม่มีปุ่มกลาง และ Space ไม่แพน | ปัดด้วยสองนิ้ว มุมมอง 2D จะแพน (การ pinch และล้อเมาส์ใช้ซูม) หรือลากโดยกดคลิกขวาค้างไว้ |
| {{key:Esc}} ครั้งแรกออกจากเต็มหน้าจอ | เบราว์เซอร์ใช้ Esc เพื่อออกจากเต็มหน้าจอ | กด {{key:Esc}} อีกครั้งเพื่อยกเลิกคำสั่ง |
| {{key:F1}} ไม่ทำงานบน Mac | F1 เป็นปุ่มความสว่าง | กด **fn** ค้างไว้ หรือคลิก {{ui:ช่วยเหลือ}} |
| การพิมพ์ไปอยู่ในช่องค้นหาของช่วยเหลือ | พาเนลช่วยเหลือมีเคอร์เซอร์อยู่ | คลิกที่แบบ |
| แบบว่างเปล่า | คุณซูมออกไปไกลมาก | คลิก {{ui:ขอบเขต}} หรือดับเบิลคลิกล้อเมาส์ |
| "ออกจากเว็บไซต์?" เมื่อปิดแท็บ | มีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก | อยู่ต่อ บันทึกด้วย {{key:Mod+S}} แล้วจึงปิด |
