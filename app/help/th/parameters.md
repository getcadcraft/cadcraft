## ตารางเดียวสำหรับทุกขนาด

แผง {{ui:พารามิเตอร์}} (ปุ่ม {{ui:พารามิเตอร์}} ในกลุ่ม {{ui:พาราเมตริก}} หรือพิมพ์ {{cmd:PARAMETERS}}) แสดงทุกข้อจำกัดมิติ (`d1`, `rad1`, `dia1`, `ang1` หรือชื่อที่คุณตั้งให้) และพารามิเตอร์ของคุณเองรวมกัน ชื่อใดก็ใช้ได้ในนิพจน์ใดก็ได้

แต่ละแถวมี:

- **ชื่อ**: พิมพ์ชื่อใหม่เพื่อเปลี่ยนชื่อ นิพจน์ทุกตัวที่ใช้ชื่อนั้นจะตามไปด้วย
- **นิพจน์**: ตัวเลข (`40`) หรือนิพจน์ (`width / 2 + gap`) พิมพ์ในช่องแล้วกด {{key:Enter}} แบบจะตาม
- **ค่า**: ค่าที่คำนวณได้ บนแถวที่นิพจน์ขับเคลื่อนอยู่ คุณสามารถพิมพ์ตัวเลขที่นี่ได้เช่นกัน CadCraft จะคำนวณพารามิเตอร์ที่อยู่เบื้องหลัง เมื่อ `d1 = width / 2` การพิมพ์ `30` ในค่าของ d1 จะตั้ง `width` เป็น 60

เมื่อพารามิเตอร์สองตัวขับเคลื่อนค่าหนึ่ง (`width / 2 + gap`) กล่องโต้ตอบจะถามว่าจะเปลี่ยนตัวไหน การเปลี่ยนแปลงทุกครั้งเป็นหนึ่งขั้นของการเลิกทำ ({{key:Mod+Z}})

## เพิ่มของคุณเอง

1. เปิดแผง {{ui:พารามิเตอร์}}
2. พิมพ์ชื่อ (`gap`) และค่า (`10`) แล้วเลือก {{ui:เพิ่ม}}
3. ใช้งาน: ในนิพจน์ของ d1 พิมพ์ `width / 2 + gap` แล้วกด {{key:Enter}}

ชื่อขึ้นต้นด้วยตัวอักษรหรือ `_` และมีได้เฉพาะตัวอักษร ตัวเลข และ `_` ชื่อฟังก์ชัน `pi` และชื่อหน่วยใช้เป็นชื่อไม่ได้

## นิพจน์

| เขียน | หมายถึง |
|---|---|
| `+ - * / ^ %` | บวก ลบ คูณ หาร ยกกำลัง เศษจากการหาร |
| `( )` | การจัดกลุ่ม |
| `sin cos tan asin acos atan atan2` | ตรีโกณมิติเป็นองศา |
| `sqrt pow exp ln log abs sign` | ราก กำลัง ลอการิทึม |
| `ceil floor int round min max` | การปัดเศษและขีดจำกัด |
| `if(a > b, x, y)` | การเลือก |
| `pi` | 3.14159… |

ตัวเลขอาจมีหน่วยได้: `25mm`, `1in`, `2'`, `90deg` ค่าที่มีหน่วยความยาวจะถูกแปลงเป็นมิลลิเมตร ดังนั้นใช้หน่วยเฉพาะในแบบที่วัดเป็นมิลลิเมตร ที่อื่นให้พิมพ์ตัวเลขเปล่า

## ที่บรรทัดคำสั่ง

`-PARAMETERS` ทำสิ่งเดียวกันโดยไม่ต้องใช้แผง: `N` ใหม่ `E` แก้ไข (รวมข้อจำกัดมิติด้วย) `R` เปลี่ยนชื่อ `D` ลบ `?` แสดงรายการ

## สิ่งที่ถูกปฏิเสธ

- นิพจน์ที่ใช้ตัวเอง ไม่ว่าจะโดยตรงหรือผ่านตัวอื่น: "width, d1 ใช้ซึ่งกันและกัน"
- ค่าที่ขนาดรับไม่ได้: ความยาวติดลบ หรือมุมเกิน 180°
- ค่าที่แบบรับไม่ได้ร่วมกับข้อจำกัดอื่น: ไม่มีอะไรเปลี่ยน และข้อความจะบอกชื่อข้อจำกัดที่ขวางอยู่
- การลบพารามิเตอร์ที่มีบางอย่างใช้อยู่: แผงจะเสนอให้เขียนค่าของมันลงในที่เหล่านั้นก่อน ชื่อของข้อจำกัดมิติจะถูกลบเมื่อลบข้อจำกัดนั้น
