## สิ่งที่ทำงานได้

แบบ DWG ที่สร้างด้วยบล็อกไดนามิกจะเปิดขึ้นพร้อมการทำงานดังนี้:

- **ชื่อจริง** บล็อกไดนามิกแสดงในพาเนล {{ui:Blocks}} ด้วยชื่อของตนเอง ("Receptacle", "Sink") ไม่ใช่เป็นบล็อก `*U` ที่ไม่มีชื่อ
- **สถานะที่บันทึกไว้** การอ้างอิงแต่ละรายการแสดงสิ่งที่โปรแกรมอื่นแสดงไว้ คือ สถานะการมองเห็นที่ตั้งไว้ ยืดหรือพลิกตามที่บันทึก
- **การสลับสถานะการมองเห็น** เลือกการอ้างอิงหนึ่งรายการ (หรือหลายรายการของบล็อกเดียวกัน) เปิด {{ui:Properties}} แล้วในส่วน {{ui:Custom}} เลือกสถานะอื่นจากรายการ {{ui:Visibility}} การอ้างอิงจะแสดงสถานะนั้นทันที รวมถึงแอตทริบิวต์ของมัน: ที่สถานะซ่อนจะหายไป ที่สถานะแสดงจะปรากฏพร้อมค่า การอ้างอิงเก็บทุกค่าไว้ จึงไม่มีค่าใดกลับมาว่างเปล่า {{ui:Properties}} แสดงรายการที่ซ่อนอยู่พร้อมเครื่องหมาย "hidden" {{key:Mod+Z}} คืนสถานะเดิมในหนึ่งขั้น
- **กริป** บล็อกไดนามิกที่เลือกจะแสดงกริปของตนเองตรงตำแหน่งพารามิเตอร์: สามเหลี่ยมเล็กสำหรับสถานะการมองเห็น (คลิกเพื่อดูรายการสถานะ) ลูกศรที่ปลายของระยะ และลูกศรคู่สำหรับการพลิก ตอนนี้มีเพียงกริปการมองเห็นที่ทำงาน กริปอื่นจะแจ้งในแถบสถานะ
- **ค่าอื่นแบบอ่านอย่างเดียว** ใต้รายการการมองเห็น {{ui:Custom}} แสดงระยะ มุมการจัดแนว สถานะการพลิก และจุดของบล็อก ตามที่แบบเก็บไว้
- **แก้ไขสถานะการมองเห็น** เปิดบล็อกด้วย {{cmd:BEDIT}} ตัวแก้ไขจะแสดงหนึ่งสถานะ ซึ่งมีชื่อในแถบเหนือแบบ (เลือกสถานะอื่นได้ที่นั่น) พิมพ์ {{cmd:BVSTATE}} เพื่อสลับ เพิ่ม (ซ่อนทุกอย่าง แสดงทุกอย่าง หรือคงสิ่งที่แสดงอยู่) เปลี่ยนชื่อ หรือลบสถานะ {{cmd:BVHIDE}} ซ่อนวัตถุที่เลือกในสถานะที่แสดงอยู่ {{cmd:BVSHOW}} แสดงสิ่งที่ถูกซ่อนแบบจาง เพื่อให้คลิกเลือกสิ่งที่จะนำกลับมา เมื่อบันทึกบล็อก การอ้างอิงที่ตั้งเป็นสถานะที่เปลี่ยนชื่อจะคงไว้ด้วยชื่อใหม่ และที่ตั้งเป็นสถานะที่ถูกลบจะแสดงสถานะแรก
- **คงความเป็นไดนามิก** เมื่อบันทึกเป็น DWG ในเวอร์ชันที่แบบนั้นมา บล็อกจะยังคงเป็นไดนามิก พร้อมสถานะที่เลือกไว้ โปรแกรมอื่นจะเปิดเป็นบล็อกไดนามิกเดียวกัน สถานะการมองเห็นที่แก้ไขก็ถูกบันทึกด้วย ทั้งชื่อใหม่ สถานะที่เพิ่ม และสิ่งที่แต่ละสถานะแสดง

## อ่านอย่างเดียว หรือยังไม่มี

| ยังไม่มี | แทนด้วยในตอนนี้ |
|---|---|
| การเปลี่ยนระยะ มุม หรือการพลิก (การกระทำยืด ย้าย พลิก) | แสดงแบบอ่านอย่างเดียวใน {{ui:Custom}} แก้ไขในโปรแกรมที่สร้างบล็อก |
| พารามิเตอร์ Lookup, XY, การหมุน และเชิงขั้ว | ยังไม่อ่าน การอ้างอิงแสดงตามที่บันทึก |
| การลากกริประยะ การพลิก และจุด | แสดงตรงตำแหน่งพารามิเตอร์ กริปการมองเห็นและรายการ {{ui:Visibility}} ในคุณสมบัติใช้สลับสถานะ |
| การสร้างบล็อกไดนามิก (เพิ่มพารามิเตอร์ หรือสถานะการมองเห็นให้บล็อกที่ไม่มี) | บล็อกที่สร้างใน CadCraft เป็นบล็อกธรรมดา {{cmd:BPARAMETER}} จะแจ้งเช่นนั้น |
| การเพิ่มหรือลบวัตถุของบล็อกที่มีสถานะการมองเห็นในตัวแก้ไขบล็อก | บล็อกจะถูกบันทึกเป็นบล็อกธรรมดา (ตัวแก้ไขจะแจ้งเมื่อปิด) |
| การคงความเป็นไดนามิกในเวอร์ชัน DWG อื่นหรือใน DXF | บันทึกเป็นบล็อกธรรมดาที่แสดงสถานะที่เลือก และการบันทึกจะแจ้งเช่นนั้น |

:::note
การย้ายหรือเปลี่ยนวัตถุใน {{cmd:BEDIT}} จะคงบล็อกที่มีสถานะการมองเห็นให้เป็นไดนามิก บล็อกที่ไม่มีสถานะ หรือบล็อกที่มีวัตถุถูกเพิ่มหรือลบในตัวแก้ไข จะกลายเป็นบล็อกธรรมดา
:::
