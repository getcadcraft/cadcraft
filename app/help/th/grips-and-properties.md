## สิ่งที่จะได้เรียนรู้

มีวิธีด่วนสองวิธีในการเปลี่ยนวัตถุโดยไม่ใช้คำสั่ง คือลาก**กริป**ของวัตถุ หรือพิมพ์ค่าใหม่ในพาเนล**คุณสมบัติ**ทางด้านขวา

## กริป

เมื่อคุณเลือกวัตถุ (สูงสุด 200 ชิ้นพร้อมกัน) โดยไม่มีคำสั่งทำงานอยู่ จะมีสี่เหลี่ยมเล็กๆ ปรากฏบนวัตถุ สิ่งเหล่านี้คือกริป:

| วัตถุ | กริป |
|---|---|
| เส้น | ปลายทั้งสอง และจุดกึ่งกลาง (ย้ายทั้งเส้น) |
| วงกลม | จุดศูนย์กลาง (ย้ายวงกลม) และสี่จุดบนเส้นรอบวง (เปลี่ยนรัศมี) |
| ส่วนโค้ง | จุดศูนย์กลาง และปลายทั้งสอง (เปลี่ยนจุดเริ่มและจุดสิ้นสุด) |
| โพลีไลน์ | ทุกจุดยอด |
| ข้อความ จุด การอ้างอิงบล็อก | จุดแทรก |
| วงรี | จุดศูนย์กลาง |
| ไดเมนชัน | จุดที่กำหนดของมัน และตำแหน่งของเส้นไดเมนชัน |
| วิวพอร์ต | จุดศูนย์กลาง (ย้าย) และมุมทั้งสี่ (ปรับขนาด) |

### ย้ายกริป

1. วาดเส้นแล้วคลิกที่เส้น กริปสามตัวจะปรากฏขึ้น
2. คลิกกริปที่ปลายด้านหนึ่ง แถบสถานะจะขึ้นว่า "Click where this grip goes (Esc to cancel). Snaps and Ortho apply." (คลิกตรงที่กริปนี้จะไป (Esc เพื่อยกเลิก) สแนปและออร์โธใช้ได้)
3. เลื่อนเคอร์เซอร์กากบาท จะมีตัวอย่างตามมา
4. คลิกตำแหน่งใหม่ หรือสแนปไปยังจุดบนวัตถุอื่นแล้วคลิก

ปลายจะย้ายไป ส่วนที่เหลือของเส้นอยู่กับที่ คุณยังสามารถกดที่กริปแล้วลากไปยังตำแหน่งที่ต้องการ จากนั้นปล่อย

:::note
ไม่สามารถพิมพ์พิกัดให้กริปได้ สำหรับตำแหน่งที่แน่นอน ให้สแนปไปยังจุด หรือพิมพ์ค่าในคุณสมบัติ
:::

กด {{key:Esc}} หรือคลิกขวาเพื่อยกเลิกการย้ายกริป

## คุณสมบัติ

พาเนลด้านขวาแสดงคุณสมบัติของสิ่งที่ถูกเลือก

1. คลิกเส้น หัวข้อของพาเนลจะแสดงว่า "Line"
2. คลิกใน {{ui:Length}} พิมพ์ `2500` แล้วกด {{key:Enter}}

เส้นจะยาวพอดี 2500 โดยคงจุดเริ่มและมุมไว้ {{key:Enter}} หรือคลิกที่อื่นจะใช้ค่า ส่วน {{key:Esc}} จะคืนค่าเดิม การเปลี่ยนแปลงแต่ละครั้งเป็นหนึ่งขั้นของการเลิกทำ แม้จะเปลี่ยนวัตถุหลายชิ้นพร้อมกัน

ช่องรับนิพจน์ (`=2*45`) และความยาวพร้อมหน่วย (`3'6"`, `900mm`) ทุกจุดมี X, Y และ Z และเปลี่ยนวัตถุหลายชิ้นพร้อมกันได้ ทั้งหมดนี้อยู่ใน[พาเนลคุณสมบัติ](topic:properties-panel)

## ข้อผิดพลาดที่พบบ่อย

- **ไม่มีกริปปรากฏ** มีคำสั่งกำลังทำงานอยู่ (กด {{key:Esc}}) หรือเลือกวัตถุเกิน 200 ชิ้น หรือวัตถุอยู่บนเลเยอร์ที่ถูกล็อก
- **กริปไปผิดที่** สแนปจับไว้ กด {{key:Shift}} ค้างไว้ขณะคลิกเพื่อไม่สนใจสแนป
- **พิมพ์ในคุณสมบัติแล้วไม่เกิดอะไร** กด {{key:Enter}} หรือคลิกที่อื่นเพื่อใช้ค่า การป้อนค่าที่ไม่ยอมรับ (ความยาวและรัศมีที่เป็นศูนย์หรือติดลบ หรือข้อความที่ไม่ใช่ค่า) จะทำให้ช่องเป็นสีแดงและแสดงเหตุผล
- **ตัวอักษรที่พิมพ์ไปอยู่ในช่องคุณสมบัติ** ขณะที่ช่องมีเคอร์เซอร์ ปุ่มกดจะพิมพ์ลงในช่องนั้น กด {{key:Enter}} หรือ {{key:Esc}} แล้วพิมพ์คำสั่ง
