หากเคยใช้ AutoCAD หรือโปรแกรมที่สร้างบนโมเดลเดียวกัน สิ่งที่รู้อยู่แล้วส่วนใหญ่ใช้ได้ที่นี่: บรรทัดคำสั่ง นามแฝงเช่น `L`, `C`, `TR` และ `O` Enter หรือ Space เพื่อทำซ้ำ การเลือกแบบหน้าต่างและแบบข้าม จุดสแนปวัตถุที่ F3 ออร์โธที่ F8 พื้นที่โมเดลกับเลย์เอาต์และวิวพอร์ต หน้านี้แสดงสิ่งที่จับคู่กันได้โดยตรง แล้วจึงแสดงความแตกต่างที่ทำให้คนสะดุด อ่านครึ่งหลังด้วย แม้จะอ่านครึ่งแรกอย่างผ่าน ๆ

## สิ่งที่จับคู่กันได้โดยตรง

| นิสัย | ใน CadCraft |
|---|---|
| `L`, `PL`, `C`, `A`, `REC`, `POL`, `EL`, `PO`, `T`, `DT` | คำสั่งเดียวกัน นามแฝงเดียวกัน |
| `M`, `CO`, `RO`, `SC`, `MI`, `O`, `TR`, `EX`, `F`, `X`, `E` | เหมือนเดิม |
| `DLI`, `DAL`, `DAN`, `DRA`, `DDI`, `DCO`, `DBA` | คำสั่งไดเมนชันเดียวกัน |
| `DIMSCALE`, `DIMTXT`, `DIMASZ`, `DIMDEC`, `DIMGAP`, `DIMEXE`, `DIMEXO` พิมพ์ที่บรรทัดคำสั่ง | เหมือนเดิม สำหรับไดเมนชันใหม่ |
| `B` เพื่อสร้างบล็อก `I` เพื่อแทรก `PU` เพื่อล้าง | เหมือนเดิม (การล้างลบเฉพาะบล็อกที่ไม่ได้ใช้) |
| `LAYOUT`, `MV`, `PLOT`, `DI`, `ID`, `LI`, `Z` แล้ว `E` หรือ `W` | เหมือนเดิม |
| พิมพ์ `_LINE` หรือ `-LAYER` จากสคริปต์หรือจากนิสัย | ไม่สนใจ `_`, `-`, `.` หรือ `'` ที่นำหน้า |
| Enter หรือ Space ที่พรอมต์ว่างจะทำซ้ำคำสั่งล่าสุด | เหมือนเดิม |
| Esc ยกเลิก; Esc อีกครั้งล้างการเลือก | เหมือนเดิม |
| `@dx,dy`, `@d<a`, มุมที่พิมพ์ทวนเข็มนาฬิกาจากทิศตะวันออก | เหมือนเดิม |
| หน้าต่างจากซ้ายไปขวา การข้ามจากขวาไปซ้าย คลิก-คลิก; กดค้างแล้วลากเพื่อลาสโซ Space วนระหว่างหน้าต่าง / ข้าม / รั้ว (LASSOMODE) | เหมือนเดิม |
| เลือกก่อนแล้วจึงใช้คำสั่ง (นาม-กริยา) | เหมือนเดิม; คำสั่งที่เสร็จแล้วจะล้างการเลือก |
| `ALL` และ `L` ที่พรอมต์เลือกวัตถุ | เหมือนเดิม |
| Shift+คลิก นำออกจากการเลือก | เหมือนเดิม การตั้งค่าสามารถทำให้การคลิกแทนที่การเลือกแทนได้ เช่นเดียวกับ PICKADD 0 ดูที่ [การตั้งค่า CadCraft](topic:settings) |
| Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+Shift+V (COPYCLIP, CUTCLIP, PASTECLIP, PASTEORIG), COPYBASE | คำสั่งและปุ่มเดียวกัน; การวางจะวางสำเนาตามมุมล่างซ้าย เช่นเดียวกับ PASTECLIP |
| F3 สแนปวัตถุ, F7 กริด, F8 ออร์โธ | ปุ่มเดียวกัน |
| ดับเบิลคลิกล้อเลื่อนเพื่อซูมขอบเขต | เหมือนเดิม |
| ข้อความที่สะท้อนยังอ่านได้ | เหมือนเดิม (เหมือนกับ MIRRTEXT 0) |
| Ctrl+Z, Ctrl+Y, Ctrl+S, Ctrl+O, Ctrl+P, Ctrl+A | เหมือนเดิม; บน Mac ใช้ Command ได้ด้วย |

## ความแตกต่างที่ทำให้คนสะดุด

### จุดที่พิมพ์เป็นค่าสัมบูรณ์

เมื่อเปิดอินพุตไดนามิก โปรแกรมอื่นจะถือว่า `100,0` ที่พิมพ์สำหรับจุดที่สองเป็นค่าสัมพัทธ์ **บรรทัดคำสั่งของ CadCraft ไม่ทำเช่นนั้น:** ที่นั่น `x,y` จะวัดจากจุดกำเนิดเสมอ เมื่อเปิด {{ui:ไดนามิก}} ({{key:F12}}) ให้ใช้ช่องของมันแทน: ระยะ {{key:Tab}} มุม ใช้ `@100,0` สำหรับ "100 ไปทางขวาของจุดล่าสุด" หรือย้ายเส้นกากบาทไปในทิศทางที่ถูกต้องแล้วพิมพ์ `100` เฉพาะตัวเลข

### Shift ข้ามสแนป แต่ไม่เปิดออร์โธ

การกด Shift ค้างขณะคลิกจะไม่สนใจสแนปวัตถุสำหรับการคลิกนั้น และไม่ได้สลับออร์โธชั่วคราว ใช้ F8 หรือปุ่ม {{ui:ออร์โธ}}

### คลิกขวาคือ Enter เสมอ

ไม่มีเมนูคลิกขวา การคลิกขวาในแบบคือ Enter: จะจบคำสั่ง จบการเลือก หรือทำซ้ำคำสั่งล่าสุด ระหว่างการย้ายกริปหรือกล่องการเลือก จะยกเลิกแทน ลากด้วยปุ่มขวาเพื่อแพน

### ไม่มีการแพนด้วยแถบ Space

Space คือ Enter ดังนั้นการกด Space ค้างแล้วลากจะไม่แพน ใช้ปุ่มกลางหรือปุ่มขวาเพื่อแพน หรือซูมออกแล้วซูมเข้าใหม่ที่จุดอื่นด้วยล้อเลื่อน

### ตัดแต่งและยืดออก

การตัดแต่งและการยืดออกเริ่มในโหมด Quick: ทุกวัตถุที่มองเห็นเป็นขอบตัดหรือขอบเขต ชิ้นที่อยู่ใต้ตัวชี้จะแสดงว่าจะถูกลบ เส้นทางที่ลากจะตัดทุกชิ้นที่ข้าม และวัตถุที่ไม่มีอะไรข้ามจะถูกลบ {{key:Shift}} สลับระหว่างตัดและยืด `O` สลับไปโหมด Standard (เลือกขอบก่อน) `F` และ `C` คือรั้วและการข้าม `E` คือ EDGEMODE `R` ลบ ไม่มีตัวเลือกฉาย (P) เพราะ CadCraft ตัดในระนาบของแบบ

### ฟิลเลตและชัมเฟอร์

{{cmd:FILLET}} และ {{cmd:CHAMFER}} รับตัวเลือกที่รู้จัก ได้แก่ เลิกทำ (U) โพลีไลน์ (P) รัศมี (R) (หรือ ระยะ (D) มุม (A) และวิธี (E)) ตัดแต่ง (T) และหลายครั้ง (M) และ {{key:Shift}}+คลิกสำหรับมุมคม ฟิลเลตระหว่างโพลีไลน์กับเส้นจะเพิ่มส่วนโค้งเป็นวัตถุของตัวเองแทนที่จะรวมเข้ากับโพลีไลน์ และมุมของโพลีไลน์ที่อยู่ติดกับส่วนโค้งจะคงไว้ตามเดิม

### ข้อความย่อหน้าและข้อความบรรทัดเดียว

`T`, `MT` และ `MTEXT` คือข้อความย่อหน้าที่พิมพ์ในตำแหน่ง มีความกว้าง ระยะบรรทัด และการจัดแนว; `DT` และ `DTEXT` คือข้อความบรรทัดเดียวตามที่รู้จัก ยังไม่มีสไตล์ข้อความหรือคอลัมน์ และยังพิมพ์การจัดรูปแบบในข้อความ (ตัวหนา เศษส่วนซ้อน) ไม่ได้ การจัดรูปแบบที่มาจากไฟล์จะถูกเก็บไว้ วาด และบันทึก (ดูที่ [เพิ่มข้อความและป้ายกำกับ](topic:text#formatting-inside-paragraph-text-from-other-programs)) ทุกอย่างวาดด้วยฟอนต์แบบ Helvetica

### การบันทึกหมายถึง "ดาวน์โหลดสำเนา"

{{key:Mod+S}}, `SAVE` และ `QSAVE` ดาวน์โหลดสำเนาในรูปแบบของแบบ: DWG ที่เปิดไว้จะบันทึกเป็น DWG และ DXF เป็น DXF ในเบราว์เซอร์จะไม่มีการเขียนทับไฟล์เดิม และไฟล์ที่เปิดจะไม่ถูกเปลี่ยนแปลง ใน CadCraft Studio {{key:Mod+S}} จะเขียนกลับไปยังไฟล์ที่เปิด

`SAVEAS` ({{key:Mod+Shift+S}}) เป็นกล่องโต้ตอบขนาดเล็ก ไม่ใช่ตัวเรียกดูไฟล์: เลือก {{ui:DWG}} (พร้อม {{ui:เวอร์ชัน}} ตั้งแต่ AutoCAD 2000 ถึง 2018) {{ui:DXF R12}} หรือ {{ui:DXF 2000}} แล้วคลิก {{ui:บันทึก}} เบราว์เซอร์เป็นผู้กำหนดว่าการดาวน์โหลดจะไปที่ใด `DXFOUT` ดาวน์โหลด DXF R12 เสมอ

DWG ที่เปิดไว้จะบันทึกในเวอร์ชันเดิม แบบใหม่จะบันทึกในรูปแบบ AutoCAD 2000 เว้นแต่จะเลือกอย่างอื่น แผ่น ไดเมนชัน และลวดลายแฮตช์จะถูกเก็บไว้ ดูที่ [ไฟล์: เปิดอะไรได้ บันทึกอะไรได้](topic:files#saving)

### เลเยอร์: ง่ายกว่า

- การเปลี่ยนเลเยอร์ทุกครั้ง (เปิด แช่แข็ง ล็อก สี พล็อต ชนิดเส้น ความหนาเส้น เลเยอร์ปัจจุบัน) เป็นหนึ่งขั้นตอนการเลิกทำ
- ปิดและแช่แข็งให้ผลเหมือนกันใน CadCraft
- เลเยอร์ที่แบบแช่แข็งในวิวพอร์ตหนึ่งจะยังคงถูกแช่แข็งที่นั่น ทั้งบนหน้าจอ ในการพล็อต และเมื่อบันทึกเป็น DWG หรือ DXF
- วิวพอร์ตที่แสดงเลเยอร์ด้วยสี ชนิดเส้น ความหนาเส้น หรือความโปร่งใสของตัวเอง จะยังคงทำเช่นนั้นบนหน้าจอ ในการพล็อต และในไฟล์ DWG ที่บันทึก (DXF จะเก็บการตั้งค่าของเลเยอร์เอง และการบันทึกจะแจ้งไว้) การเปลี่ยนค่าเหล่านั้นต่อวิวพอร์ตยังไม่ได้สร้าง
- ไม่มีตัวจัดการคุณสมบัติเลเยอร์และไม่มีสถานะเลเยอร์ {{cmd:RENAME}}, {{cmd:LAYMRG}} และ {{cmd:LAYDEL}} ใช้เปลี่ยนชื่อ รวม และลบเลเยอร์ ชนิดเส้นและความหนาเส้นตั้งค่าในพาเนลด้านขวา (ดูที่ [ชนิดเส้นและความหนาเส้น](topic:units-papers-scales#line-weights-and-linetypes)); {{cmd:LAYISO}}, {{cmd:LAYOFF}}, {{cmd:LAYFRZ}} และ {{cmd:LAYMCUR}} ทำงานด้วยการเลือกวัตถุ
- การบันทึกเป็น DXF R12 เขียนชื่อเลเยอร์เป็นตัวพิมพ์ใหญ่ DWG จะเก็บชื่อตามที่พิมพ์

### รูปแบบไดเมนชัน

`DIMSTYLE` เปิดตัวจัดการรูปแบบที่ตั้งชื่อ (ใหม่ แก้ไข ตั้งเป็นปัจจุบัน เปรียบเทียบ ใช้) `DIMSCALE` และการตั้งค่าอื่น ๆ ยังเปลี่ยนค่าที่ไดเมนชันใหม่ใช้ และไดเมนชันแต่ละอันจะเก็บขนาดของตัวเอง ซึ่งเปลี่ยนได้ในพาเนลคุณสมบัติด้วย รูปแบบปัจจุบันจะไม่ถูกบันทึกไว้ในไฟล์ ไดเมนชันทำตามรูปแบบความยาวของแบบ (ทศนิยม หรือฟุตกับนิ้วด้วย {{cmd:UNITS}}) หรือตาม {{ui:รูปแบบ}} ของตัวเอง ดูที่ [ตั้งขนาดไดเมนชัน](topic:dimension-settings)

### การพล็อตง่ายกว่า

ตารางรูปแบบการพล็อตทำงานตามสี เหมือนไฟล์ CTB: Monochrome, Colour และ Grayscale มีให้ในตัว สร้างของตัวเองได้ และแต่ละแผ่นเก็บตารางของตนเอง การอ่านไฟล์ CTB สร้างจากคำอธิบายที่เผยแพร่ และทดสอบเฉพาะกับไฟล์ที่เราสร้างเท่านั้น ตารางรูปแบบการพล็อตที่มีชื่อ (STB) และการตั้งค่าหน้ายังไม่ได้สร้าง เส้นพิมพ์ตามความหนาเส้น ส่วนอื่นพิมพ์ด้วยความกว้างปากกาเดียว แผ่นพล็อตที่ 1:1 บนกระดาษของตัวเอง ส่วนโมเดลพล็อตที่สเกลที่เลือกหรือพอดีกับหน้า ดูที่ [พล็อตเป็น PDF](topic:plot-pdf)

### การทำงานภายในวิวพอร์ต

เหมือนที่รู้จัก: ดับเบิลคลิกภายในวิวพอร์ต (หรือพิมพ์ {{cmd:MSPACE}}) เพื่อทำงานกับโมเดลผ่านวิวพอร์ตนั้น และดับเบิลคลิกนอกวิวพอร์ต (หรือ {{cmd:PSPACE}}) เพื่อกลับไปยังแผ่น ภายในวิวพอร์ต การแพนและการซูมจะเปลี่ยนสิ่งที่วิวพอร์ตแสดง เว้นแต่การแสดงผลจะถูกล็อก ซึ่งในกรณีนั้นจะเลื่อนแผ่นแทน การคลิกแท็บใต้แบบก็ออกจากวิวพอร์ตเช่นกัน ดูที่ [ทำงานกับโมเดลผ่านวิวพอร์ต](topic:sheets-and-viewports#work-on-the-model-through-a-viewport)

### การติดตามและอินพุตไดนามิกมีแล้ว สแนปกริดยังไม่มี

กริดใช้สำหรับดูเท่านั้น จุดจะไม่สแนปเข้ากับกริด (ไม่มีโหมดสแนป F9) การติดตามขั้ว ({{key:F10}} ขั้นตั้งด้วย {{cmd:POLARANG}}) และการติดตามสแนปวัตถุ ({{key:F11}}: พักที่จุดสแนปเพื่อรับจุดนั้น) ทำงานตามที่รู้จัก ดูที่ [สแนปเข้ากับวัตถุ](topic:object-snaps#polar-tracking) อินพุตไดนามิก ({{key:F12}}) แสดงระยะและมุม (หรือ X และ Y) ข้างเส้นกากบาท ดูที่ [การป้อนพิกัดและระยะ](topic:coordinate-entry#dynamic-input)

### ฟุตและนิ้ว

เลือก {{ui:รูปแบบความยาว}} เป็น {{ui:สถาปัตย์}} หรือ {{ui:วิศวกรรม}} (หรือพิมพ์ {{cmd:UNITS}}) แล้วพิมพ์ความยาวตามที่รู้จัก: `12'6"`, `12'6-1/2"` ใช้ขีดกลาง ไม่ใช่การเว้นวรรค ก่อนเศษส่วน: {{key:Space}} คือ {{key:Enter}} ตั้ง {{ui:หน่วย}} เป็น {{ui:นิ้ว}} ด้วย เพื่อให้แผ่นและการพล็อตเสนอสเกลสถาปัตย์ รูปแบบจะถูกเก็บไว้ในไฟล์ DWG และ DXF ที่บันทึก ดูที่ [ฟุตและนิ้ว](topic:units-papers-scales#feet-and-inches-and-fractions)

### การคัดลอกและวางอยู่ภายใน CadCraft

{{key:Mod+C}}, {{key:Mod+X}} และ {{key:Mod+V}} คัดลอก ตัด และวางวัตถุภายในแบบ ระหว่างแบบ และระหว่างแท็บ CadCraft ในเบราว์เซอร์เดียวกัน คลิปบอร์ดเป็นของ CadCraft เอง คุณไม่สามารถวางวัตถุของ CadCraft ลงในโปรแกรมอื่น หรือวางวัตถุจากโปรแกรมอื่นลงใน CadCraft ได้ การวางจากแบบที่ใช้หน่วยอื่นจะไม่ปรับสเกล ให้ใช้ {{cmd:SCALE}} ภายหลัง {{key:Mod+D}} คือการทำสำเนาที่เคลื่อนที่ตามตัวชี้ ซึ่งเป็นส่วนเพิ่มเติมของ CadCraft ดูที่ [คัดลอก วาง และทำสำเนา](topic:copy-paste)

### ปุ่มของเบราว์เซอร์ที่ใช้ไม่ได้

หน้าเว็บไม่สามารถรับ {{key:Mod+N}}, {{key:Mod+W}} หรือ {{key:Mod+T}} จากเบราว์เซอร์ได้: ปุ่มเหล่านี้ใช้เปิดและปิดหน้าต่างและแท็บ ให้ใช้ปุ่ม {{ui:ใหม่}} หรือพิมพ์ `NEW` ดูที่ [ปุ่ม เมาส์ และแทร็กแพด](common:keys)
