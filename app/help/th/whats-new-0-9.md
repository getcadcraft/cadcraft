นี่คือสิ่งที่เปลี่ยนใน CadCraft 0.9 เมื่อเทียบกับ 0.8.1 CadCraft คือแอปการวาด 2D และ 3D ของ CadCraft Studio 0.9 และแอปทั้งแปดของมัน 0.9 ทำให้การร่างแบบบนแปลนเสร็จสมบูรณ์ เพิ่มสไตล์ข้อความและตัวแก้ไขข้อความที่แท้จริง และให้พื้นที่บนหน้าจอมากขึ้น

## ใหม่

### การร่างแบบบนแปลน

- **ฮัตช์ที่ตามขอบเขตของมัน** {{cmd:HATCH}} เชื่อมกับสิ่งที่ล้อมมัน เลื่อน หมุน หรือย่อขยายขอบเขต แล้วฮัตช์และรูปแบบของมันจะตาม วาดขอบเขตใหม่ แล้วฮัตช์จะถูกคำนวณใหม่ {{cmd:HATCHEDIT}} (`HE`) เปลี่ยนฮัตช์ภายหลังและสร้างหรือยกเลิกการเชื่อม ดู [ฮัตช์และพื้นที่เติม](topic:hatch)
- **ไฟล์รูปแบบฮัตช์** ที่คำถาม `Pick internal point` ของ {{cmd:HATCH}} พิมพ์ `F` (Pattern file) แล้วเลือกไฟล์ `.pat` ใช้ได้เฉพาะไฟล์ที่เขียนตามรูปแบบทั่วไป
- **กลุ่มเลเยอร์** ใน {{ui:เครื่องมือ}} บนพาเนล {{ui:เลเยอร์}}: {{ui:กลุ่มใหม่}}, {{ui:เพิ่มกลุ่มสำเร็จรูป}}, {{ui:จัดกลุ่มตามชื่อ}} และ {{ui:ค้นหาเลเยอร์}} หรือพิมพ์ {{cmd:LAYGROUP}} (`LG`) ดู [จัดระเบียบแบบด้วยเลเยอร์](topic:layers#group-layers)
- **ชั้นซ้อน** {{cmd:FLOORS}} (`FLR`) หรือ {{ui:ชั้น…}} ในเมนู {{ui:เพิ่มเติม}} ของกลุ่ม {{ui:มุมมอง}} วิวพอร์ตบนแผ่นงานแสดงชั้นหนึ่งได้ภายใต้ {{ui:ชั้นที่แสดง}} ในคุณสมบัติ {{cmd:FLOORLAYERS}} เปลี่ยนชั้นเป็นเลเยอร์สำหรับไฟล์ที่จะส่งให้คนอื่น ดู [จัดชั้นซ้อนในแบบเดียว](topic:floors)
- **ผนัง ประตู และหน้าต่างอัจฉริยะ 2D** {{cmd:WALL}} (`WA`), {{cmd:DOOR}} (`DR`), {{cmd:WINDOW}} (`WN`) และ {{cmd:DELOPENING}} มุม การต่อแบบตัว T และการตัดกันถูกคำนวณให้ ผนังเก็บบันทึกว่ามันต่อกันอย่างไร และคุณสมบัติได้ ไม่ให้เชื่อมที่จุดเริ่ม / ที่จุดปลาย, เส้นกำหนดตำแหน่ง และความยาวที่แก้ไขได้ ดู [วาดผนัง ประตู และหน้าต่าง 2D](topic:walls-2d)
- **เครื่องมือผนังบนผนังแปลน** พิมพ์ {{cmd:WALLRECT}}, {{cmd:WALLPOLY}}, {{cmd:WALLARC}}, {{cmd:WALLTRACE}}, {{cmd:WALLDIM}}, {{cmd:WALLOFFSET}}, {{cmd:WALLSPLIT}}, {{cmd:WALLGRID}} และอื่นๆ ยังไม่มีปุ่มบนแถบเครื่องมือ ดู [รูปร่าง การตัด การเลื่อน และการล็อกผนังสำหรับผนัง 2D](topic:wall-tools-2d)

### ข้อความ

- **สไตล์ข้อความ** {{cmd:STYLE}} (`ST`) หรือ {{ui:สไตล์ข้อความ}} บนแถบ {{ui:วาด}}: สไตล์ที่มีชื่อพร้อมฟอนต์ ความสูง ตัวคูณความกว้าง และความเอียง ดู [ตั้งฟอนต์และขนาดข้อความด้วยสไตล์ข้อความ](topic:text-styles)
- **ตัวแก้ไขย่อหน้าแบบจัดรูปแบบ** {{cmd:MTEXT}}, {{cmd:TEXTEDIT}} หรือดับเบิลคลิกข้อความจะเปิดกล่องที่มีฟอนต์ ขนาด ตัวหนา ตัวเอียง ขีดเส้นใต้ ขีดฆ่า สี การจัดแนว และเครื่องหมายองศา บวกลบ และเส้นผ่านศูนย์กลาง พร้อม {{ui:ตกลง}} และ {{ui:ยกเลิก}} ดู [จัดรูปแบบข้อความย่อหน้า](topic:format-paragraph-text)
- **ไดอะแกรมจาก draw.io XML** {{cmd:DIAGRAM}} (`T2D`) ยังอ่าน draw.io XML ที่วางได้ ดู [วาดไดอะแกรมจากข้อความ](topic:text-to-diagram)
- **ข้อความไทยในการพล็อต PDF** เคยพิมพ์ออกมาเป็นเครื่องหมายคำถาม

### พื้นที่มากขึ้นและเครื่องมือช่วยวาด

- **บรรทัดคำสั่งลอยที่บางลง และพื้นที่ด้านบนแบบกะทัดรัด** ลากปุ่มจับของบรรทัดคำสั่งเพื่อทำให้ลอย ลากขอบบนเพื่อให้เหลือบรรทัดน้อยลง {{key:F2}} เปิดประวัติ การตั้งค่าใน {{ui:การตั้งค่า}} › {{ui:CadCraft}} › {{ui:บรรทัดคำสั่ง}} และตัวเลือกพื้นที่ด้านบนก็เหมือนกัน ดู [การตั้งค่า](topic:settings#command-line)
- **เมนูจับจุดวัตถุ** คลิกขวา {{ui:สแนป}} ในแถบสถานะ หรือพิมพ์ {{cmd:OSNAP}}
- **สแนปไปยังกริด** ปุ่ม {{ui:สแนปกริด}} ในแถบสถานะ หรือ {{key:F9}}: จุดที่เลือกจะไปยังจุดกริดที่ใกล้ที่สุดเมื่อไม่มีการจับจุดวัตถุใดจับจุดนั้น
- **ส่วนโค้งสิบวิธี และ Continue** {{ui:ส่วนโค้ง}} บนแถบ {{ui:วาด}} หรือ {{cmd:ARC}}: สามจุด ตระกูล Start/Center/End และตระกูล Center/Start/End และ Continue (กด {{key:Enter}} ที่จุดเริ่มต้น) จากเส้น ส่วนโค้ง หรือโพลีไลน์ล่าสุด
- **พาเนลเอกสาร** {{cmd:DOCUMENTS}} (`DOCS`) หรือ {{ui:เอกสาร…}} ในเมนู {{ui:เพิ่มเติม}} ของกลุ่ม {{ui:มุมมอง}}: การแก้ไข สถานะ และการเช็กเอาต์ของทุกแบบในโฟลเดอร์โครงการ เปิดเป็นกล่องโต้ตอบกลางจอ ดู [เอกสาร](topic:documents)

### ไฟล์

- **ขนาดเหล็กของ UK** มี 976 หน้าตัดในพาเนลมาตรฐาน พิมพ์ได้ตามที่เขียนในแบบ (เช่น `305x165x40 UB`)
- **ชุดข้อมูลของแอฟริกาใต้** (แนวปฏิบัติการร่างแบบและข้อบังคับอาคาร) เป็นชุดของส่วนเสริม Building regulations ตัวเลขยังไม่ได้รับการตรวจสอบ
- **ส่วนเสริมสำหรับ CadCraft** เพิ่มเมื่อต้องการและปิดไว้เป็นค่าเริ่มต้น ได้แก่ การออกแบบแสงสว่างภายใน การออกแบบชิปจาก HDL เป็นผัง การแกะสลักด้วยเราเตอร์ การจำลองวงจร สเปรกเก็ตโซ่ลูกกลิ้ง และชุดประเทศของ Building regulations

## แก้ไขแล้ว

- การย้าย หมุน หรือย่อขยายฮัตช์ทำให้รูปแบบของมันค้างอยู่
- {{cmd:GRIDMOVE}} เคลื่อนผนังแปลนทั้งเส้นที่เริ่มต้นบนเส้นกริดเท่านั้น ตอนนี้ผนังถูกตัดสินจากปลายของมัน
- กริดแสดงเฉพาะภายในขอบเขตของแบบ แม้จะปิดขอบเขต
- รายการบล็อกในแผงข้างเลื่อนได้ และชื่อที่ไม่ใช่บล็อกจะแสดงบล็อกที่ขึ้นต้นด้วยชื่อนั้น ("Did you mean")
- ไฟล์ DXF R12 ที่ AutoCAD ปฏิเสธ ("Unknown group 1001 for table") ตอนนี้เปิดได้ที่นั่น
- ไฟล์ขนาดใหญ่มาก (ราว 70,000 เอนทิตีขึ้นไป) เคยเปิดไม่ได้พร้อมข้อความ "Maximum call stack size exceeded"
- ไฟล์ DWG จาก AutoCAD 2018 ขึ้นไปที่มีเวอร์ชันการบำรุงรักษาสูงเคยเปิดไม่ได้พร้อมข้อความ "bad BITLONG code 11"
- ในกล่องข้อความย่อหน้า ขนาดใหม่ที่พิมพ์สำหรับส่วนที่เลือกจะคงการเลือกไว้

## ในทุกแอป

ทูลทิปของ Bootstrap ที่ทุกตัวควบคุมที่มีคำแนะนำ เคล็ดลับเริ่มต้นที่ปิดได้ แถบแท็บที่เลื่อนได้เมื่อไม่พอดี และชื่อแท็บเบราว์เซอร์ที่ตามแบบที่เปิดอยู่ (`<drawing> - CadCraft | CadCraft`) {{ui:การตั้งค่า}} › {{ui:เลย์เอาต์}} ตอนนี้เป็นรายการแบบดรอปดาวน์ของตัวเลือกสองบรรทัด รายการภาษาใน {{ui:การตั้งค่า}} ยาวกว่าใน 0.8 การทำงานร่วมกันแบบสดและไลบรารีคอลเลกชัน รวมถึงหน่วยน้ำหนักและอุณหภูมิ อธิบายไว้ในหมายเหตุของ Studio

## ข้อจำกัดที่ยังมี

- ข้อความย่อหน้าไม่มีบูลเล็ตหรือรายการมีหมายเลข ไม้บรรทัดแท็บ หรือการจัดชิดขอบ PDF ที่พล็อตตั้งข้อความด้วย Helvetica
- ผนังแปลนเป็นเส้นตรง ดังนั้นส่วนโค้งจะวาดเป็นผนังสั้น การตรวจสอบเครื่องมือผนังโดยชุมชนยังรอดำเนินการ
- กลุ่มเลเยอร์ไม่ได้เขียนในรูปแบบของ AutoCAD เอง ดังนั้น AutoCAD จะแสดงเป็นรายการแบบแบน โปรแกรมอื่นจะแสดงชั้นทั้งหมดรวมกันเว้นแต่คุณจะรัน {{cmd:FLOORLAYERS}}
- พาเนลเอกสารยังไม่เคยถูกทดลองโดยสองคนบนการแชร์จริง การลากเส้นทางการแกะสลักด้วยเราเตอร์ยังไม่เคยรันบนเครื่องจริงเลย การประมาณแสงสว่างตรวจกับการติดตามโฟตอน ไม่ใช่โปรแกรมอื่น ส่วนเสริมด้านวิศวกรรมเป็นเครื่องมือช่วยตรวจสอบ ไม่ใช่การแทนที่การพิจารณาของวิศวกร
- ภาษาอื่นนอกจากภาษาอังกฤษเป็นฉบับร่างด้วยเครื่อง และคำใหม่บางคำมีเฉพาะภาษาอังกฤษ
