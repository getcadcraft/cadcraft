## สิ่งที่จะได้เรียนรู้

วิธีรวบรวมแผ่น (เลย์เอาต์) จากไฟล์แบบหลายไฟล์เข้าเป็น **ชุดแผ่น** ใส่หมายเลขและตั้งชื่อ ให้ตารางชื่อเรื่องถูกกรอกให้โดยอัตโนมัติ เผยแพร่ทั้งชุดเป็น PDF ไฟล์เดียว และรวมทุกอย่างเป็น zip ไฟล์เดียวเพื่อส่ง

ชุดแผ่นอยู่ในไฟล์เล็ก ๆ ของตัวเอง คือ `<name>.ccsheets` ในโฟลเดอร์ที่มีแบบ ไฟล์ชุดระบุแผ่นด้วยพาธจากโฟลเดอร์นั้น ดังนั้นสามารถย้ายหรือคัดลอกทั้งโฟลเดอร์ได้

:::note
การเปิดโฟลเดอร์เพื่ออ่านและเขียนต้องใช้ Chrome หรือ Edge (ซึ่งอนุญาตให้หน้าเว็บทำงานในโฟลเดอร์ที่เลือกได้) หรือแอปเดสก์ท็อป เบราว์เซอร์อื่นจะเปิดชุดแบบอ่านอย่างเดียว: ดูและเผยแพร่ได้ แต่ไฟล์ชุดจะดาวน์โหลดแทนการบันทึก
:::

## เริ่มชุด

1. หาส่วน {{ui:Sheet set}} ในพาเนลซ้าย แล้วเปิดเมนู {{ui:Set}} การพิมพ์ {{cmd:SHEETSET}} (หรือ `SSM`) ก็นำไปยังที่นั่นได้เช่นกัน
2. เลือก {{ui:New set…}} ตั้งชื่อชุด และหากต้องการ ใส่ชื่อโครงการและหมายเลข
3. เลือกโฟลเดอร์ที่มีแบบ ไฟล์ชุดจะถูกบันทึกที่นั่น

หากต้องการเปิดชุดภายหลัง เลือก {{ui:Open set…}} แล้วเลือกโฟลเดอร์เดิม หากโฟลเดอร์มีมากกว่าหนึ่งชุด CadCraft จะถามว่าชุดไหน

## เพิ่มแผ่น

1. เลือก {{ui:Add sheets from a drawing…}} แล้วเลือกแบบหนึ่งในโฟลเดอร์
2. CadCraft จะอ่านแบบนั้นเบื้องหลัง (ไม่เปิดบนหน้าจอ) และแสดงรายการแผ่น ทำเครื่องหมายแผ่นที่ต้องการแล้วคลิก {{ui:OK}}
3. เลือกแผ่นแล้วกด {{key:F2}} (หรือ {{ui:Rename and renumber…}}) เพื่อกำหนดหมายเลขและชื่อ เช่น `A-101` และ `ผังพื้น`

{{ui:New sheet from template…}} สร้างแบบใหม่จากแผ่นของแบบอื่น (ตารางชื่อเรื่องและวิวพอร์ต) ตั้งชื่อตามแผ่นใหม่ แล้วเพิ่มเข้าไป ชุดจะจำแบบที่ใช้เป็นเทมเพลตไว้

## จัดเรียงชุด

- **ชุดย่อย** จัดกลุ่มแผ่น เช่น Architectural › Plans: เลือกตำแหน่งที่จะวาง แล้วเลือก {{ui:New subset…}}
- **ลำดับ**: ลากแผ่นไปยังตำแหน่งอื่นในรายการ หรือไปยังชุดย่อยเพื่อย้ายไปที่นั่น ด้วยคีย์บอร์ด เลือกแผ่นแล้วกด {{key:Alt+Up}} หรือ {{key:Alt+Down}}
- **เปิดแผ่น** ดับเบิลคลิก (หรือกด {{key:Enter}}) แบบจะเปิดในแท็บของตัวเอง บนแผ่นนั้น
- **นำออก** เลือกแล้วกด {{key:Delete}} ตัวแบบไม่ถูกเปลี่ยน
- **ย้อนกลับ** {{ui:Undo set change}} และ {{ui:Redo set change}} ไล่ดูสิ่งที่เปลี่ยนในชุด
- **ใส่หมายเลขใหม่**: {{ui:Renumber sheets…}} ใส่หมายเลขทุกแผ่น หรือของชุดย่อยหนึ่งชุด ตามลำดับในรายการ: คำนำหน้า จุดเริ่ม และขั้น (`A-` และ `101` ได้ A-101, A-102 …)

ทุกการเปลี่ยนแปลงจะถูกบันทึกลงในไฟล์ชุดทันที

## ใส่หมายเลขแผ่นจากฟิลด์

แทนที่จะใส่หมายเลขด้วยมือ ให้กฎสร้างหมายเลขแต่ละอันจากฟิลด์ของแผ่น แผ่นที่ย้ายไปชั้นหรือสาขาอื่นจะได้หมายเลขใหม่ของมันเองโดยอัตโนมัติ

1. ให้แต่ละแผ่นมีฟิลด์ของมัน: เลือกแผ่น คลิก {{ui:Rename…}} และในช่อง {{ui:Fields of this sheet}} เขียนหนึ่งบรรทัดต่อฟิลด์ เช่น `DISCIPLINE = A` และ `LEVEL = 1` ฟิลด์ที่ทั้งชุดใช้ร่วมกัน (เช่น `DISCIPLINE = A`) ใส่ได้ใน {{ui:Properties…}} ของชุดแทน
2. เปิดเมนูของพาเนลแล้วคลิก {{ui:Numbering rule…}}
3. เขียนกฎ เช่น `{DISCIPLINE}-{LEVEL}{SEQ:2}` `{SEQ}` นับขึ้นในหมู่แผ่นที่ฟิลด์อื่นเหมือนกัน ดังนั้นชั้น 1 จะได้ A-101, A-102 และชั้น 2 เริ่มใหม่ที่ A-201 `{SEQ:2}` เขียนเป็นสองหลัก; `{SUBSET}` คือชื่อของชุดย่อยที่แผ่นอยู่
4. เลือกสิ่งที่จะเกิดขึ้นเมื่อฟิลด์เปลี่ยน: {{ui:Renumber the sheets}} คงหมายเลขให้เป็นไปตามกฎหลังทุกการเปลี่ยนแปลง ตัวเลือกอื่นจะใส่หมายเลขเพียงครั้งเดียว ณ ตอนนี้

กฎจะถูกบันทึกในไฟล์ชุด ขณะที่กฎใส่หมายเลขใหม่เอง ให้เปลี่ยนฟิลด์ของแผ่นแทนการเปลี่ยนหมายเลข

## กรอกตารางชื่อเรื่องจากชุด

ตารางชื่อเรื่องจะได้ข้อความจากชุดเมื่อแอตทริบิวต์ของมันถูกติดแท็กด้วยชื่อของฟิลด์:

| แท็ก | แสดง |
|---|---|
| `SHEETNUMBER` (หรือ `SHEET_NO`, `DWG_NO`) | หมายเลขของแผ่น |
| `SHEETTITLE` (หรือ `TITLE`, `SHEET_TITLE`) | ชื่อของแผ่น |
| `SHEETDESC` | คำอธิบายของแผ่น |
| `PROJECTNAME` (หรือ `PROJECT`) | ชื่อโครงการ |
| `PROJECTNUMBER` (หรือ `PROJECT_NO`, `JOB_NO`) | หมายเลขโครงการ |
| `SHEETSETNAME` | ชื่อของชุด |
| `SHEETINDEX`, `SHEETCOUNT` | "3 จาก 12" และ 12 |
| ของตัวเอง เช่น `CLIENT` | ค่าที่เขียนไว้สำหรับแท็กนั้นใน {{ui:Set fields…}} |

{{ui:Set fields…}} เก็บชื่อโครงการและหมายเลข และฟิลด์ของตัวเอง หนึ่งบรรทัดต่อรายการ เขียนเป็น `NAME = value`

{{ui:Update drawings}} เขียนหมายเลข ชื่อ และฟิลด์ลงในตารางชื่อเรื่องของทุกแบบในชุด และเปลี่ยนชื่อแท็บเลย์เอาต์ของแต่ละแผ่นตามที่ชุดระบุ (ค่าเริ่มต้นคือหมายเลขและชื่อ เช่น `A-101 Floor plan`; {{ui:Set fields…}} › {{ui:Layout tab names}} เปลี่ยนได้) แต่ละแบบจะถูกบันทึกในที่เดิม ในรูปแบบและเวอร์ชันของตัวเอง หลังจากใส่หมายเลขใหม่หรือเปลี่ยนชื่อแผ่น ให้รันอีกครั้ง แท็บและตารางชื่อเรื่องจะตามมา

## รายการแผ่นบนแผ่นปก

เลือกแผ่นปกในรายการ แล้วเลือก {{ui:Put the sheet list on this sheet}} ตารางของทุกแผ่น (หมายเลขและชื่อ อยู่ใต้ชุดย่อย) จะวางที่มุมซ้ายบนของแผ่น {{ui:Update drawings}} และ {{ui:Publish to PDF}} ทำให้เป็นปัจจุบัน มันเป็นบล็อกเดียว `CC_SHEETLIST`: ย้ายได้เหมือนการอ้างอิงบล็อกอื่น

## เผยแพร่ชุด

{{ui:Publish to PDF}} สร้าง PDF หนึ่งไฟล์ที่มีหนึ่งหน้าต่อแผ่น ตามลำดับของชุด ที่ขนาดกระดาษของแต่ละแผ่น พร้อมบุ๊กมาร์กต่อแผ่น ("A-101 — Floor plan") เมื่อเลือกชุดย่อย CadCraft จะถามว่าจะเผยแพร่เฉพาะชุดย่อยนั้นหรือไม่ ตารางชื่อเรื่องใน PDF จะถูกกรอกจากชุดแม้ก่อนอัปเดตแบบ และการเผยแพร่ไม่เปลี่ยนแบบ PDF จะถูกดาวน์โหลด

{{ui:Publish to DWG…}} เขียนแต่ละแผ่นเป็นไฟล์ DWG ของตัวเอง (DWG 2018): โมเดลและแผ่นนั้นเพียงแผ่นเดียว พร้อมตารางชื่อเรื่องที่กรอกจากชุด ตั้งชื่อตามหมายเลขและชื่อ (`A-101 Level 1 floor plan.dwg`) เลือก {{ui:DWG}} หรือ {{ui:DWG + PDF}} เพื่อให้มี PDF ของชุดอยู่ข้างๆ ด้วย ไฟล์ `publish.json` ระบุทุกไฟล์พร้อมขนาดและ SHA-256 เมื่อโฟลเดอร์ของชุดเขียนได้ (CadCraft Studio หรือโฟลเดอร์ที่เลือกในเบราว์เซอร์) ไฟล์จะถูกใส่ในโฟลเดอร์ `<set name> - published`; มิฉะนั้นจะดาวน์โหลดเป็น zip ไฟล์เดียว [การแทนที่คลาสของวิวพอร์ต](topic:viewport-overrides) ติดไปกับแต่ละ DWG

## จัดเก็บชุด

{{ui:Archive as a zip}} รวมไฟล์ชุด ทุกแบบที่ชุดใช้ และสิ่งที่แบบเหล่านั้นเชื่อมโยง (แบบที่เชื่อมโยง และของพวกนั้นต่อไป รวมถึงรูปภาพ) พร้อมเก็บโฟลเดอร์ไว้ รวมถึง `Transmittal.txt` ที่ระบุทุกไฟล์ ลิงก์ที่ไม่อยู่ในโฟลเดอร์ของชุดจะถูกระบุว่าขาดหายที่นั่น ลิงก์ถูกค้นพบจากพาธในแบบ แล้วจึงจากชื่อไฟล์ในที่ใดก็ได้ในโฟลเดอร์

## ไฟล์ชุด

ไฟล์ `.ccsheets` เป็น JSON ที่อ่านได้ด้วยโปรแกรมแก้ไขข้อความใดก็ได้:

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

พาธสัมพัทธ์กับโฟลเดอร์ของชุด ใช้ `/` คั่นระหว่างโฟลเดอร์ CadCraft ตรวจไฟล์เมื่อเปิด: พาธสัมบูรณ์ แผ่นที่ไม่มีไฟล์หรือเลย์เอาต์ หรือข้อความที่ไม่ใช่ข้อความธรรมดา จะถูกตัดออก และประวัติจะระบุไว้

## การแก้ปัญหา

| สิ่งที่เห็น | สาเหตุ | สิ่งที่ควรทำ |
|---|---|---|
| "โฟลเดอร์นี้อ่านได้อย่างเดียวที่นี่" | เบราว์เซอร์เขียนในโฟลเดอร์นั้นไม่ได้ | ใช้ Chrome หรือ Edge หรือแอปเดสก์ท็อป ระหว่างนี้ {{ui:Download the set file}} จะเก็บการเปลี่ยนแปลงไว้ |
| แผ่นถูกตัดออกจาก PDF: "ไม่มีเลย์เอาต์ชื่อ …" | เลย์เอาต์ของแผ่นถูกเปลี่ยนชื่อหรือลบในแบบ | เปิดแบบและตรวจแท็บ แล้วนำแผ่นออกและเพิ่มใหม่ |
| ตารางชื่อเรื่องว่างเปล่า | แอตทริบิวต์ของมีแท็กอื่น | เปลี่ยนชื่อแท็กของแอตทริบิวต์ให้เป็นชื่อฟิลด์ข้างต้น (BEDIT) |
| "มีเลย์เอาต์ชื่อ … อยู่แล้ว จึงไม่ได้เปลี่ยนชื่อแท็บ" | แบบสองแผ่นจะได้ชื่อแท็บเดียวกัน | ให้แผ่นหนึ่งมีหมายเลขหรือชื่ออื่น |
