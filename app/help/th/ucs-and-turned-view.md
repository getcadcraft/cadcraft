## สิ่งที่คุณจะเรียนรู้

วิธีดูแบบที่ถูกหมุน เพื่อให้อาคารที่วาดเอียงแสดงตรงบนหน้าจอ และวิธีพิมพ์จุดตามแกนของอาคารเอง ไม่มีอะไรในแบบเคลื่อนที่ขณะที่คุณทำ: วัตถุคงพิกัดเดิม การหมุนไม่ใช่การแก้ไข และแบบจะไม่ถูกทำเครื่องหมายว่ามีการเปลี่ยนแปลง

## หมุนมุมมองทีละหนึ่งในสี่

1. คลิก {{ui:มุมมอง}} › {{ui:เพิ่มเติม}} › {{ui:หมุนมุมมอง 90° ไปทางซ้าย}} หรือ {{ui:หมุนมุมมอง 90° ไปทางขวา}}

แบบจะหมุนบนหน้าจอรอบกลางพื้นที่วาด ทำซ้ำเพื่อหมุนต่อ

2. คลิก {{ui:มุมมอง}} › {{ui:เพิ่มเติม}} › {{ui:กลับสู่โลก}} เพื่อปรับให้ตรงอีกครั้ง

คำสั่งเบื้องหลังคือ {{cmd:TURNLEFT}}, {{cmd:TURNRIGHT}} และ {{cmd:TURNWORLD}} หากต้องการให้มีปุ่มลัด ให้เพิ่มบรรทัดอย่าง `TL=TURNLEFT` ในชื่อย่อของคุณด้วย {{cmd:ALIASEDIT}}

## จัดให้ตรงกับอาคารเอียง

1. พิมพ์ `UCS` แล้วกด {{key:Enter}} จากนั้นพิมพ์ `OB` และกด {{key:Enter}}
2. คลิกเส้นผนังใกล้ปลายที่ควรเป็นจุดกำเนิด

UCS จะเริ่มที่ปลายนั้น โดยแกน X อยู่ตามผนัง และมุมมองจะหมุนให้ผนังอยู่ระดับบนหน้าจอ ไอคอนแกนที่มุมล่างซ้ายแสดงว่าแกนของ UCS ชี้ไปทางไหน

3. วาดตามปกติ เมื่อตั้ง UCS แล้ว:
   - `x,y` และ `@dx,dy` วัดตามแกนของ UCS; `d<a` วัดมุมจากแกน X ของ UCS
   - {{ui:ออร์โธ}} การติดตามขั้ว และกริดตามแกนของ UCS และเคอร์เซอร์ก็เช่นกัน
   - ข้อความใหม่และย่อหน้าใหม่วิ่งตามแกน X ของ UCS; แนวนอนและแนวตั้งของ {{cmd:DIMLINEAR}} ก็ตามไปด้วย
   - พิกัดในแถบสถานะและจาก {{cmd:ID}} เป็นพิกัดของ UCS
4. หากต้องการพิมพ์จุดโลกขณะตั้ง UCS ให้ใส่ `*` ข้างหน้า: `*0,0` หรือ `@*100,0`
5. พิมพ์ `UCS` กด {{key:Enter}} แล้วกด {{key:Enter}} อีกครั้งเพื่อกลับสู่โลก

## วิธีอื่นในการตั้ง UCS

ที่พรอมต์ {{cmd:UCS}}:

| คุณพิมพ์ | สิ่งที่เกิดขึ้น |
|---|---|
| จุด | จุดกำเนิดใหม่; จากนั้นคลิกจุดบนแกน X ใหม่ หรือกด {{key:Enter}} เพื่อเก็บมุมไว้ |
| `Z` | หมุน UCS รอบจุดกำเนิดตามมุมที่คุณพิมพ์ (องศา ทวนเข็มนาฬิกา) หรือที่คุณเลือก |
| `3` (สามจุด) | จุดกำเนิด จุดบนแกน X บวก และจุดที่อยู่ฝั่ง Y บวก |
| `OB` (วัตถุ) | จากเส้น ส่วนโค้ง วงกลม ส่วนของโพลีไลน์ ข้อความ การอ้างอิงบล็อก จุด หรือเส้นช่วยสร้าง |
| `P` (ก่อนหน้า) | UCS ก่อนหน้านี้ (สิบอันล่าสุดจะถูกเก็บไว้ขณะที่เปิดแบบอยู่) |
| `W` (โลก) | กลับสู่โลก |
| `NA` (ตั้งชื่อ) | `S` บันทึก UCS ปัจจุบันภายใต้ชื่อ `R` คืนค่าอันหนึ่ง `D` ลบอันหนึ่ง `?` แสดงรายการ |

ทุกการเปลี่ยนแปลงจะหมุนมุมมองให้แกน X ของ UCS ใหม่อยู่ในระดับ {{cmd:PLAN}} หมุนมุมมองโดยไม่เปลี่ยน UCS: {{key:Enter}} สำหรับ UCS ปัจจุบัน `U` สำหรับอันที่บันทึกไว้ `W` สำหรับโลก

## ควรรู้

- แต่ละบานของหน้าจอที่แบ่งจะเก็บการหมุนของตัวเอง UCS เป็นของแบบ
- แผ่นทำงานด้วยพิกัดกระดาษ ตั้ง UCS ที่แท็บ {{ui:โมเดล}} หรือภายในวิวพอร์ต
- กรอบการเลือกที่ลากในมุมมองที่หมุนจะเลือกสิ่งที่อยู่ภายในกรอบบนหน้าจอ
- รูทีน LISP รับจุดในพิกัด UCS จาก `getpoint` อ่าน `UCSORG`, `UCSXDIR`, `UCSYDIR` และ `VIEWTWIST` ได้ และ `trans` แปลงระหว่างโลก UCS และการแสดงผล

:::note
ไฟล์ที่บันทึกจะเก็บ UCS และการหมุนมุมมองในเวอร์ชันถัดไป จนกว่าจะถึงตอนนั้น ค่าเหล่านี้จะคงอยู่ขณะที่แบบยังเปิดอยู่
:::
