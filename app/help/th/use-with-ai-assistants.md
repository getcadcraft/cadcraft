## สิ่งที่คุณจะได้เรียนรู้

วิธีให้ผู้ช่วย AI (หรือสคริปต์ที่คุณเขียนเอง) ดูแบบ รันคำสั่งของ CadCraft พล็อตและบันทึก และตัดสินใจว่ามันแตะต้องอะไรได้บ้าง

CadCraft **ไม่มี AI ของตัวเอง** และไม่ส่งข้อมูลไปที่ใดเลย คุณนำผู้ช่วยมาเอง คือโปรแกรมใดก็ได้ที่ใช้ Model Context Protocol (MCP) CadCraft เพียงมอบเครื่องมือให้ และคุณเป็นผู้เลือกว่าจะให้เครื่องมือใดบ้าง

มีสองวิธีในการเข้าถึง:

- **แบบที่คุณเปิดอยู่** ผู้ช่วยทำงานในหน้าต่างนี้ ข้างคุณ ผ่าน CadCraft Studio บนคอมพิวเตอร์ของคุณ นี่คือหน้าที่ {{ui:การตั้งค่า}} › {{ui:CadCraft}} › {{ui:ผู้ช่วย}} ใช้สำหรับ
- **แบบบนคอมพิวเตอร์ของคุณ โดยไม่ต้องเปิดแอป** เซิร์ฟเวอร์ MCP ของ CadCraft และ `cadcraft` บนบรรทัดคำสั่ง อ่านและเขียนไฟล์ DWG และ DXF ในโฟลเดอร์ที่คุณระบุ ดูหัวข้อ "ทำงานกับไฟล์โดยไม่เปิด CadCraft" ด้านล่าง

## เปิดใช้งาน

1. เปิด {{ui:การตั้งค่า}} (ไอคอนรูปเฟืองบนแถบแอป หรือ {{key:Mod+,}}) แล้วไปที่แท็บ {{ui:CadCraft}}
2. ใต้ {{ui:ผู้ช่วย}} ทำเครื่องหมาย **ให้ผู้ช่วย AI และสคริปต์ใช้ CadCraft** ระบบจะปิดอยู่จนกว่าคุณจะทำเช่นนั้น
3. เลือกสิ่งที่ให้ทำได้ **อ่าน** ถูกทำเครื่องหมายไว้ตั้งแต่แรก ทำเครื่องหมายอย่างอื่นเฉพาะเมื่อคุณต้องการเท่านั้น

| สิทธิ์ | ผู้ช่วยทำอะไรได้บ้าง |
|---|---|
| อ่าน | ดูแบบ: อธิบายแบบ แสดงรายการและค้นหาวัตถุ ดูที่เลือก อธิบายมุมมองและถ่ายภาพมุมมอง ตรวจสอบตามกฎเลเยอร์และการร่าง |
| แก้ไข | รันคำสั่งกับแบบ และเปลี่ยนที่เลือก แต่ละการกระทำเป็นหนึ่งขั้นที่ย้อนกลับได้ |
| บันทึก | บันทึกแบบ (บนเดสก์ท็อป บันทึกลงไฟล์ของแบบ ในเบราว์เซอร์ บันทึกเป็นการดาวน์โหลด) |
| ส่งออก | พล็อตเป็น PDF และสร้างไฟล์อื่น |

## ให้ใช้ไฟล์ในโฟลเดอร์ที่คุณเลือก

ใน CadCraft Studio ผู้ช่วยสามารถเปิด บันทึก และพล็อตไฟล์โดยระบุชื่อ แทนการใช้กล่องโต้ตอบไฟล์ แต่ทำได้เฉพาะภายในโฟลเดอร์ที่คุณเพิ่มใต้ {{ui:ผู้ช่วย}} › {{ui:โฟลเดอร์ที่ผู้ช่วยใช้ได้}}:

1. เลือก {{ui:เพิ่มโฟลเดอร์…}} แล้วเลือกโฟลเดอร์ในกล่องโต้ตอบของ Studio
2. ตอนนี้ผู้ช่วยสามารถแสดงรายการไฟล์ในโฟลเดอร์นั้น (`files_list`) เปิดแบบ (`drawing_open`) บันทึกแบบในโฟลเดอร์นั้นเป็นเวอร์ชัน DWG หรือเป็น DXF พล็อตเป็นไฟล์ PDF หรือ SVG โหลดไฟล์ LISP และส่งไฟล์ที่คำสั่งขอให้กับคำสั่ง (`INSERT` `F`, `XATTACH`, ไฟล์จุด) หรือระบุว่าไฟล์ของคำสั่งจะไปอยู่ที่ใด (CSV ของ `COUNT`, `PUBLISH`)
3. {{ui:เอาออก}} นำโฟลเดอร์ออกทันที เส้นทางที่อยู่นอกโฟลเดอร์จะถูกปฏิเสธ และไฟล์ที่มีอยู่แล้วจะถูกแทนที่ก็ต่อเมื่อผู้ช่วยขอให้ทำเช่นนั้น หรือผู้ช่วยเป็นคนเขียนไฟล์นั้นเอง

การเปิดยังต้องใช้ **อ่าน** การเขียนแบบต้องใช้ **บันทึก** ไฟล์อื่นทุกชนิดต้องใช้ **ส่งออก**

เครื่องมือที่อยู่นอกสิทธิ์ที่คุณทำเครื่องหมายไว้จะไม่ถูกเสนอให้ผู้ช่วยเลย และหากผู้ช่วยขอใช้อยู่ดี CadCraft จะปฏิเสธและบันทึกไว้ในบันทึกกิจกรรม การปิดสวิตช์จะยุติการเชื่อมต่อทั้งหมดในทันที {{ui:รีเซ็ตการตั้งค่า CadCraft}} ก็ปิดสวิตช์นี้เช่นกัน

## เชื่อมต่อผู้ช่วยของคุณ

ผู้ช่วยเชื่อมต่อผ่าน **CadCraft Studio** บนคอมพิวเตอร์ของคุณ Studio จะรันเซิร์ฟเวอร์ขนาดเล็กที่คอมพิวเตอร์เครื่องนี้เข้าถึงได้เท่านั้น (ที่อยู่ `127.0.0.1`) และป้องกันด้วยโทเคนที่ Studio สร้างขึ้นทุกครั้งที่เริ่มทำงาน เปิด Studio เลือก {{ui:เชื่อมต่อผู้ช่วย}} แล้วคัดลอกที่อยู่และโทเคน

- ในผู้ช่วยของคุณ เพิ่มเซิร์ฟเวอร์ MCP ชนิด HTTP โดยใช้ที่อยู่ (หน้าตาคล้าย `http://127.0.0.1:47615/mcp`) และเฮดเดอร์ `Authorization: Bearer <token>` Studio จะแสดงการตั้งค่าที่ให้วาง

{{ui:โทเคนใหม่}} ใน Studio ทำให้ผู้ช่วยที่เชื่อมต่ออยู่ทุกตัวเชื่อมต่อใหม่ด้วยโทเคนใหม่ อย่าแชร์โทเคนเด็ดขาด เพราะทุกคนที่มีโทเคนสามารถใช้แอปที่คุณเปิดสวิตช์ไว้ได้ ตราบเท่าที่ Studio ยังทำงานอยู่

:::note
แท็บเบราว์เซอร์ไม่สามารถเปิดการเชื่อมต่อให้ผู้ช่วยได้: ในแอปบนเบราว์เซอร์ สวิตช์นี้จะไม่มีผลจนกว่าคุณจะใช้ CadCraft Studio บนคอมพิวเตอร์ของคุณ
:::

## คุณยังควบคุมอยู่

- **ทุกการกระทำคือหนึ่งขั้นย้อนกลับ** ติดป้ายด้วยชื่อที่ผู้ช่วยใช้เรียก เช่น "Assistant: LINE" กด {{key:Mod+Z}} เพื่อย้อนการกระทำล่าสุดของผู้ช่วยทั้งชุด
- **คุณเห็นสิ่งที่มันทำ** คำสั่งของมันปรากฏในประวัติคำสั่งโดยมี **[Assistant]** นำหน้า และแบบจะวาดใหม่ขณะที่มันทำงาน
- **มันรอคุณ** ขณะที่คุณกำลังอยู่กลางคำสั่ง ผู้ช่วยอ่านได้แต่แก้ไขแบบไม่ได้ และจะถูกบอกให้ลองใหม่เมื่อคุณทำเสร็จ
- **คุณจะรู้เมื่อมีการเชื่อมต่อ** ปุ่มบนแถบแอปจะแสดงชื่อผู้ช่วยขณะที่เชื่อมต่ออยู่ คลิกเพื่อดูว่ามันทำอะไรได้ หรือเพื่อ **ตัดการเชื่อมต่อ**
- **กิจกรรม.** {{ui:การตั้งค่า}} › {{ui:CadCraft}} › {{ui:ผู้ช่วย}} › {{ui:กิจกรรม}} แสดงรายการการเรียกทุกครั้ง: เมื่อไร ใช้เครื่องมือใด สำเร็จหรือถูกปฏิเสธ และขั้นย้อนกลับที่สร้างขึ้น {{ui:บันทึกบันทึกกิจกรรม}} เก็บสำเนาไว้

## สิ่งที่ผู้ช่วยขอใช้ได้

| เครื่องมือ | สิทธิ์ | ทำอะไร |
|---|---|---|
| `app_info`, `drawing_describe`, `view_describe` | อ่าน | ชื่อแบบ หน่วย เลเยอร์ บล็อก แผ่น และสิ่งที่อยู่บนหน้าจอ |
| `files_list`, `drawing_open` | อ่าน | Studio: ไฟล์ในโฟลเดอร์ของคุณ เปิดหนึ่งไฟล์ในหน้าต่างนี้ |
| `objects_list`, `object_get`, `selection_get` | อ่าน | วัตถุพร้อมรูปทรง ความยาว และพื้นที่ (หรือเฉพาะจำนวนตามชนิดและเลเยอร์) และที่เลือก |
| `drawing_check` | อ่าน | กฎ เช่น เลเยอร์ที่อนุญาต ไม่มีอะไรบนเลเยอร์ 0 สีแบบ ByLayer ความสูงข้อความ |
| `view_screenshot` | อ่าน | ภาพของแบบตามที่แสดงอยู่ |
| `command_run` | แก้ไข | พิมพ์ที่บรรทัดคำสั่ง: `LINE 0,0 @100,0 @0,50 ` อ่านเหมือนที่คุณพิมพ์ (การเว้นวรรคจบคำตอบ) หรือเป็นรายการที่มีคำตอบหนึ่งรายการต่อหนึ่งคำสั่ง มันสามารถเก็บคำสั่งให้ค้างไว้และทำงานต่อในการเรียกครั้งถัดไป |
| `script_run` | แก้ไข | สคริปต์ (`.scr`) หรือไฟล์ LISP ตามที่ {{ui:APPLOAD}} โหลด |
| `block_insert` | แก้ไข | วางบล็อกพร้อมค่าแอตทริบิวต์ในขั้นตอนเดียว |
| `selection_set`, `undo` | แก้ไข | เลือกวัตถุสำหรับคำสั่งถัดไป และย้อนขั้นตอนของตัวเอง |
| `drawing_save` | บันทึก | {{ui:บันทึก}} ของ CadCraft เอง หรือ {{ui:บันทึกเป็น}} ไปยังโฟลเดอร์ของคุณโฟลเดอร์ใดโฟลเดอร์หนึ่ง |
| `drawing_plot` | ส่งออก | PDF หรือ SVG ของแผ่นหรือของโมเดล ที่สเกลที่กำหนดหรือพอดี (ยังไม่รองรับการพิมพ์ PDF underlay ด้วยวิธีนี้) |

ขณะที่ผู้ช่วยรันคำสั่ง CadCraft จะถามคำถามบนบรรทัดคำสั่งแทนการใช้กล่องโต้ตอบ (เช่น จะแทรกทั้งแบบหรือบล็อกเดียว) เพื่อให้ผู้ช่วยตอบได้ คลังไลบรารีและการค้นหายังต้องให้คุณดำเนินการเอง และผู้ช่วยจะถูกบอกให้ถามคุณ

## ทำงานกับไฟล์โดยไม่เปิด CadCraft

เซิร์ฟเวอร์ MCP ของ CadCraft (`cadcraft-mcp`) และบรรทัดคำสั่ง (`cadcraft`) รันโค้ดการวาดของ CadCraft เองบน Node.js โดยไม่มีหน้าต่าง ต้องใช้ Node.js เวอร์ชัน 20 หรือใหม่กว่า

- **เซิร์ฟเวอร์ MCP** ทำงานได้เฉพาะภายในโฟลเดอร์ที่คุณระบุ และด้วยสิทธิ์ที่คุณให้เท่านั้น: `npx @getcadcraft/mcp --root ~/Drawings --allow read,edit` หากไม่มี `--root` จะเปิดไฟล์ใดไม่ได้ หากไม่มี `--allow` จะอ่านได้อย่างเดียว นอกจากนี้ยังอ่านโมเดล IFC การคำนวณปริมาณ (takeoff) และมาร์กอัปในชุด PDF ได้ด้วย
- **บรรทัดคำสั่ง** ใช้สำหรับสคริปต์ของคุณเอง: `cadcraft info plan.dwg`, `cadcraft run cleanup.scr plan.dwg -o plan-clean.dwg`, `cadcraft convert plan.dwg plan.dxf`, `cadcraft plot plan.dwg plan.pdf --all`, `cadcraft plot plan.dwg plan.svg`, `cadcraft check plan.dwg --rules rules.json` หลายไฟล์พร้อมกัน: `cadcraft convert *.dwg out --to dxf`, `cadcraft plot *.dwg pdfs --to pdf`, `cadcraft check *.dwg --rules rules.json` เพิ่ม `--json` สำหรับผลลัพธ์ที่โปรแกรมอ่านได้

:::note
หาก `npx @getcadcraft/mcp` แจ้งว่าไม่พบแพ็กเกจ แสดงว่ายังไม่ได้เผยแพร่ ข่าวบน getcadcraft.com จะแจ้งเมื่อเผยแพร่แล้ว
:::

## หากมีบางอย่างไม่ทำงาน

- **ผู้ช่วยไม่เห็นเครื่องมือของ CadCraft:** ตรวจว่าสวิตช์เปิดอยู่ในหน้าต่างนี้ และหน้าต่างเปิดอยู่ใน Studio
- **"ต้องใช้สิทธิ์แก้ไข":** ทำเครื่องหมาย **แก้ไข** ใต้ {{ui:ผู้ช่วย}} แล้วขอใหม่อีกครั้ง
- **"อยู่นอกโฟลเดอร์ที่ผู้ช่วยใช้ได้":** เพิ่มโฟลเดอร์นั้นใต้ {{ui:ผู้ช่วย}} › {{ui:โฟลเดอร์ที่ผู้ช่วยใช้ได้}} หรือขอให้ผู้ช่วยใช้ไฟล์ในโฟลเดอร์ที่คุณเพิ่มไว้แล้ว
- **ข้อผิดพลาด "401" หรือ "token":** โทเคนเปลี่ยนไปแล้ว (Studio เริ่มต้นใหม่ หรือ {{ui:โทเคนใหม่}}) คัดลอกโทเคนใหม่ไปใส่ในการตั้งค่าของผู้ช่วย
- **การเปลี่ยนแปลงของมันผิด:** กด {{key:Mod+Z}} การกดหนึ่งครั้งจะย้อนการกระทำทั้งชุดของผู้ช่วยหนึ่งครั้ง
