พิมพ์ชื่อย่อ (นามแฝง) แล้วกด Enter หรือคลิกเครื่องมือ Esc ยกเลิก กด Enter บนบรรทัดว่างเพื่อทำคำสั่งล่าสุดซ้ำ

**พิมพ์:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (หนึ่งหน้า A4 หากพิมพ์บนกระดาษ Letter ให้พิมพ์แบบ "fit to page")

## วาด

| พิมพ์ | คำสั่ง | ทำอะไร |
|---|---|---|
| `L` | {{cmd:LINE}} | วาดเส้นตรง |
| `PL` | {{cmd:PLINE}} | วาดโซ่ของเส้นและส่วนโค้งที่ต่อกัน |
| `C` | {{cmd:CIRCLE}} | วาดวงกลม (จุดศูนย์กลางและรัศมี) |
| `A` | {{cmd:ARC}} | วาดส่วนโค้ง |
| `REC` | {{cmd:RECTANG}} | วาดสี่เหลี่ยมผืนผ้าจากสองมุม |
| `POL` | {{cmd:POLYGON}} | วาดรูปหลายเหลี่ยมปกติ |
| `EL` | {{cmd:ELLIPSE}} | วาดวงรี |
| `DT` | {{cmd:TEXT}} | เขียนข้อความหนึ่งบรรทัด |
| `T` | {{cmd:MTEXT}} | เขียนข้อความที่ตัดบรรทัด (ย่อหน้า) |
| `H` | {{cmd:HATCH}} | เติมพื้นที่ด้วยลาย |

## แก้ไข

| พิมพ์ | คำสั่ง | ทำอะไร |
|---|---|---|
| `M` | {{cmd:MOVE}} | ย้ายวัตถุ |
| `CO` | {{cmd:COPY}} | คัดลอกวัตถุ |
| `RO` | {{cmd:ROTATE}} | หมุนวัตถุรอบจุด |
| `SC` | {{cmd:SCALE}} | ทำวัตถุให้ใหญ่ขึ้นหรือเล็กลง |
| `MI` | {{cmd:MIRROR}} | พลิกวัตถุข้ามเส้น |
| `O` | {{cmd:OFFSET}} | วาดสำเนาขนานที่ระยะหนึ่ง |
| `TR` | {{cmd:TRIM}} | ตัดวัตถุถอยกลับไปที่จุดที่วัตถุอื่นตัดผ่าน |
| `EX` | {{cmd:EXTEND}} | ยืดวัตถุไปจนถึงวัตถุอื่น |
| `F` | {{cmd:FILLET}} | ทำมุมโค้งด้วยส่วนโค้ง |
| `CHA` | {{cmd:CHAMFER}} | ตัดมุมด้วยขอบตรง |
| `E` | {{cmd:ERASE}} | ลบวัตถุ |
| `X` | {{cmd:EXPLODE}} | แยกบล็อกหรือโพลีไลน์ออกเป็นส่วนย่อย |
| `S` | {{cmd:STRETCH}} | ย้ายปลายที่อยู่ในหน้าต่างแบบข้าม |
| `AR` | {{cmd:ARRAY}} | คัดลอกเป็นกริดหรือวงกลม |
| `J` | {{cmd:JOIN}} | ต่อเส้นและส่วนโค้งเป็นวัตถุเดียว |
| `BR` | {{cmd:BREAK}} | ตัดวัตถุเป็นสองส่วน หรือเอาชิ้นหนึ่งออก |

## ไดเมนชัน

| พิมพ์ | คำสั่ง | ทำอะไร |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | ใส่ไดเมนชันแนวนอนหรือแนวตั้ง |
| `DAL` | {{cmd:DIMALIGNED}} | ใส่ไดเมนชันตามเส้นเฉียง |
| `DRA` | {{cmd:DIMRADIUS}} | ใส่ไดเมนชันรัศมี |
| `DAN` | {{cmd:DIMANGULAR}} | ใส่ไดเมนชันมุม |

## บล็อกและเลเยอร์

| พิมพ์ | คำสั่ง | ทำอะไร |
|---|---|---|
| `B` | {{cmd:BLOCK}} | สร้างบล็อกจากวัตถุ |

## มุมมองและการสอบถาม

| พิมพ์ | คำสั่ง | ทำอะไร |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | ซูมเข้า ซูมออก หรือซูมให้เห็นทั้งหมด (E) |
| `DI` | {{cmd:DIST}} | วัดระยะและมุม |
| `LI` | {{cmd:LIST}} | แสดงรายละเอียดของวัตถุ |
| `MA` | {{cmd:MATCHPROP}} | คัดลอกหน้าตาของวัตถุหนึ่งไปยังวัตถุอื่น |

## ไฟล์

| พิมพ์ | คำสั่ง | ทำอะไร |

| `PLOT` | {{cmd:PLOT}} | พล็อตเป็น PDF |

## ปุ่ม

Ctrl (Cmd บน Mac): Z เลิกทำ · Y ทำซ้ำ · S บันทึก · P พล็อต  F3 สแนปวัตถุ · F8 ออร์โธ · F10 โพลาร์  Space หรือ Enter ทำคำสั่งล่าสุดซ้ำ · ล้อซูม · ลากล้อเพื่อแพน

เพิ่งเริ่มเขียนแบบ พิมพ์ `TOUR` เพื่อวาดแบบแรกอย่างมีผู้นำทาง อ่าน [เริ่มต้นใช้งาน](topic:getting-started) หรือดูทุกคำสั่งใน [คำสั่ง](topic:commands) มาจากโปรแกรมเขียนแบบอื่น: [มาจากโปรแกรมเขียนแบบอื่น](topic:coming-from) และ[แผนที่คำสั่ง](topic:command-map)
