সংক্ষিপ্ত নাম (অ্যালিয়াস) টাইপ করে Enter চাপুন, অথবা টুলে ক্লিক করুন। Esc বাতিল করে। খালি লাইনে Enter চাপলে শেষ কমান্ডটি আবার চলে।

**প্রিন্ট করুন:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (একটি A4 পাতা; Letter কাগজে "fit to page" দিয়ে প্রিন্ট করুন।)

## আঁকা

| টাইপ | কমান্ড | কী করে |
|---|---|---|
| `L` | {{cmd:LINE}} | সরল লাইন আঁকুন |
| `PL` | {{cmd:PLINE}} | সংযুক্ত লাইন ও আর্কের শৃঙ্খল আঁকুন |
| `C` | {{cmd:CIRCLE}} | একটি বৃত্ত আঁকুন (কেন্দ্র ও ব্যাসার্ধ) |
| `A` | {{cmd:ARC}} | একটি আর্ক আঁকুন |
| `REC` | {{cmd:RECTANG}} | দুটি কোণ থেকে একটি আয়তক্ষেত্র আঁকুন |
| `POL` | {{cmd:POLYGON}} | একটি নিয়মিত বহুভুজ আঁকুন |
| `EL` | {{cmd:ELLIPSE}} | একটি উপবৃত্ত আঁকুন |
| `DT` | {{cmd:TEXT}} | এক লাইন টেক্সট লিখুন |
| `T` | {{cmd:MTEXT}} | মোড়ানো টেক্সট লিখুন (অনুচ্ছেদ) |
| `H` | {{cmd:HATCH}} | একটি প্যাটার্ন দিয়ে একটি এলাকা ভরাট করুন |

| টাইপ | কমান্ড | কী করে |
|---|---|---|
| `M` | {{cmd:MOVE}} | বস্তু সরান |
| `CO` | {{cmd:COPY}} | বস্তু কপি করুন |
| `RO` | {{cmd:ROTATE}} | একটি বিন্দুর চারপাশে বস্তু ঘোরান |
| `SC` | {{cmd:SCALE}} | বস্তু বড় বা ছোট করুন |
| `MI` | {{cmd:MIRROR}} | একটি রেখার ওপর দিয়ে বস্তু উল্টে দিন |
| `O` | {{cmd:OFFSET}} | একটি দূরত্বে সমান্তরাল কপি আঁকুন |
| `TR` | {{cmd:TRIM}} | অন্য বস্তু যেখানে ছেদ করে সেখানে বস্তু কেটে ছোট করুন |
| `EX` | {{cmd:EXTEND}} | অন্য বস্তু পর্যন্ত বস্তু লম্বা করুন |
| `F` | {{cmd:FILLET}} | একটি আর্ক দিয়ে কোণ গোলাকার করুন |
| `CHA` | {{cmd:CHAMFER}} | একটি সরল প্রান্ত দিয়ে কোণ কেটে দিন |
| `E` | {{cmd:ERASE}} | বস্তু মুছুন |
| `X` | {{cmd:EXPLODE}} | একটি ব্লক বা পলিলাইনকে তার অংশে ভাঙুন |
| `S` | {{cmd:STRETCH}} | একটি ক্রসিং উইন্ডোর ভেতরে প্রান্ত সরান |
| `AR` | {{cmd:ARRAY}} | গ্রিড বা বৃত্তে কপি করুন |
| `J` | {{cmd:JOIN}} | লাইন ও আর্ককে একটি বস্তুতে জোড়া দিন |
| `BR` | {{cmd:BREAK}} | একটি বস্তু দুভাগ করুন, অথবা একটি অংশ সরিয়ে নিন |
