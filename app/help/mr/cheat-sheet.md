छोटे नाव (alias) टाइप करा आणि Enter दाबा, किंवा टूलवर क्लिक करा. Esc रद्द करतो. रिकाम्या ओळीवर Enter दाबल्यास शेवटची कमांड पुन्हा चालते.

**छापा:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (A4 कागदाचे एक पान; Letter कागदावर छापताना "पानावर बसवा" निवडा).

## काढा

| प्रकार | कमांड | ती काय करते |
|---|---|---|
| `L` | {{cmd:LINE}} | सरळ रेषा काढा |
| `PL` | {{cmd:PLINE}} | जोडलेल्या रेषा आणि कंसांची साखळी काढा |
| `C` | {{cmd:CIRCLE}} | वर्तुळ काढा (केंद्र आणि त्रिज्या) |
| `A` | {{cmd:ARC}} | कंस काढा |
| `REC` | {{cmd:RECTANG}} | दोन कोपऱ्यांवरून आयत काढा |
| `POL` | {{cmd:POLYGON}} | नियमित बहुभुज काढा |
| `EL` | {{cmd:ELLIPSE}} | लंबवर्तुळ काढा |
| `DT` | {{cmd:TEXT}} | मजकुराची एक ओळ लिहा |
| `T` | {{cmd:MTEXT}} | गुंडाळणारा मजकूर लिहा (परिच्छेद) |
| `H` | {{cmd:HATCH}} | एका पॅटर्नने क्षेत्र भरा |

## बदला

| प्रकार | कमांड | ती काय करते |
|---|---|---|
| `M` | {{cmd:MOVE}} | वस्तू हलवा |
| `CO` | {{cmd:COPY}} | वस्तूंची कॉपी करा |
| `RO` | {{cmd:ROTATE}} | एका बिंदूभोवती वस्तू फिरवा |
| `SC` | {{cmd:SCALE}} | वस्तू मोठ्या किंवा लहान करा |
| `MI` | {{cmd:MIRROR}} | एका रेषेपलीकडे वस्तू पलटा |
| `O` | {{cmd:OFFSET}} | ठराविक अंतरावर समांतर प्रत काढा |
| `TR` | {{cmd:TRIM}} | इतर वस्तू ज्यांना छेदतात तिथपर्यंत वस्तू कापा |
| `EX` | {{cmd:EXTEND}} | इतर वस्तूंपर्यंत वस्तू लांब करा |
| `F` | {{cmd:FILLET}} | कंसाने कोपरा गोल करा |
| `CHA` | {{cmd:CHAMFER}} | सरळ कडेने कोपरा कापा |
| `E` | {{cmd:ERASE}} | वस्तू हटवा |
| `X` | {{cmd:EXPLODE}} | ब्लॉक किंवा पॉलिलाइन त्याच्या भागांमध्ये तोडा |
| `S` | {{cmd:STRETCH}} | क्रॉसिंग विंडोच्या आतील टोके हलवा |
| `AR` | {{cmd:ARRAY}} | ग्रिड किंवा वर्तुळात कॉपी करा |
| `J` | {{cmd:JOIN}} | रेषा आणि कंस जोडून एक वस्तू बनवा |
| `BR` | {{cmd:BREAK}} | वस्तू दोन भागांत तोडा, किंवा त्यातील एक तुकडा काढा |

## की

Ctrl (Mac वर Cmd): Z पूर्ववत करा · Y पुन्हा करा · S जतन करा · P छापा. F3 ऑब्जेक्ट स्नॅप · F8 ऑर्थो · F10 पोलर. Space किंवा Enter शेवटची कमांड पुन्हा चालवतात · चाकाने झूम होतो · चाक ओढल्यास पॅन होतो.
