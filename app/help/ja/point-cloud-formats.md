## 添付できるもの

{{cmd:POINTCLOUDATTACH}}、{{ui:Open}}、またはページにドロップして添付します (点群の上で出来形の線をトレースするトピックを参照)。

| 形式 | 拡張子 | 読み取る内容 |
|---|---|---|
| LAS, LAZ | `.las`, `.laz` | LAS 1.0〜1.4: 点、色、強度、LiDARの分類、座標系とその単位。LAZは1 GBまで。 |
| E57 | `.e57` | ファイル内のすべてのスキャンを、それぞれの姿勢で配置します。色、またはファイルに色がない場合は強度。単位はメートル。ファイル内の画像は除外されます (その旨が表示されます)。現時点では最大600万点、512 MBまでです。それより大きいスキャンはLASまたはLAZとして書き出してください。 |
| PLY | `.ply` | テキストとバイナリ (両方のバイト順): 頂点のx、y、z、色、強度。面は除外されます (その旨が表示されます)。 |
| PCD | `.pcd` | テキストとバイナリ: x、y、z、パック済みまたは個別の色、強度。圧縮PCDファイルはまだ読み取れません。バイナリまたはテキストとして保存してください。 |
| PTX | `.ptx` | 1つ以上のスキャン。それぞれ独自の変換で配置されます。スキャナーが測定しなかった点は除外されます。単位はメートル。 |
| PTS, XYZ | `.pts`, `.xyz` | テキスト: x、y、z。列がある場合は強度と色も。 |

## スキャナーのソフトウェアだけが読み取れるファイル

一部のスキャンファイルは、スキャナーメーカー独自の形式で、公開された説明もオープンなリーダーもありません。CadCraftはそれらを読み取れません。添付しようとすると、それが何であるかと、コマンドラインでどうすべきかが表示されます。メーカーのソフトウェアからスキャンをE57、LAS (またはPTX、PTS) として書き出し、書き出されたファイルを添付してください。

| ファイル | 拡張子 | 書き出し元 |
|---|---|---|
| ReCapプロジェクト | `.rcp` | ReCap: プロジェクトを開いて書き出します。プロジェクトはスキャンを指しているだけなので、`.rcp`だけをコピーしても点は得られません。 |
| ReCapスキャン | `.rcs` | ReCap: スキャンが属するプロジェクトを開いて書き出します。 |
| FAROスキャン | `.fls` | FARO SCENE。 |
| Leicaスキャン | `.lgs` | Leica Cyclone REGISTER 360。 |
| Trimbleスキャン | `.tzf` | Trimble RealWorks または Trimble Business Center。 |
| Z+Fスキャン | `.zfs` | Z+F LaserControl。 |

:::tip
書き出しで形式を尋ねられたとき、LASまたはLAZを選ぶと、CadCraftが使用するすべて (色、強度、分類、座標系とその単位) を、最も小さいファイルで保持します。
:::

## これらのファイルが読み取れない理由

これらの形式は公開されておらず、読み取る唯一の方法は、各メーカー独自のソフトウェアライブラリを、そのメーカーの条件のもとで使用することです。CadCraftは、お使いのコンピューター上で自身のコードで読み取れる形式だけを読み取ります。そのため、スキャンを添付するためにどこかへ送信する必要はありません。
