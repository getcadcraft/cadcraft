**アクセス** を使うと、画面を見ずに作図できます。オフのままになっているため、誰かが誤って有効にすることはありません。

## オンにする

**設定** (歯車、または Ctrl+,) を開き、**図面を見ずに作図** を見つけて **オン** を選びます。または、コマンドラインに `ACCESS` と入力して `On` と答えます。この設定はこのコンピューターに記憶されます。

アクセスをオンにすると:

- **コマンドラインの内容はすべてスクリーンリーダーで読み上げられます**: 入力した内容、求められるプロンプト、回答、そしてすべてのエラーです。CadCraft は独自の丁寧なライブリージョンと緊急のライブリージョンを使うため、ライブリージョンを読むスクリーンリーダーなら設定は不要です。エラーと取り消しは割り込み、それ以外は順番を待ちます。
- **図面領域に移動できます**: Tab を押して "Drawing" と聞こえるまで移動するか、コマンドラインから Shift+Tab を押します。キーを CadCraft に渡す領域です。

## 図面でのキー

| Key | 動作 |
|---|---|
| Arrow keys | キーボードカーソルを動かします。1 ステップは画面に表示されている範囲のおよそ 100 分の 1 で、1、2、5 のいずれかに丸められます。Shift を押すと 10 倍、Ctrl を押すと 10 分の 1 動きます。 |
| Enter | クリックしたときと同じように、カーソル位置の点を指定します。 |
| Space | コマンドラインで Enter を押すのと同じです。LINE を終了し、既定値を使います。 |
| Tab, Shift+Tab | カーソル付近のスナップ点を、近いものから順に次または前へ移動します。 |
| G | 選択したオブジェクトのグリップを順に移動します。 |
| D | 図面を説明します: オブジェクトの数、種類、大きさ、選択状態。 |
| W | カーソルの位置と、最後に指定した点からの距離を読み上げます。 |
| N | カーソル付近にあるものを、近い順に、距離と側とともに読み上げます。 |
| S | 選択したオブジェクトを説明します。 |
| R | 直前に読み上げた内容をもう一度読み上げます。 |
| V | 音声のオンとオフを切り替えます。 |
| / | コマンドラインに移動します。 |
| ? | これらのキーを一覧表示します。 |

キーで移動すると、移動先が読み上げられます。コマンドが点の指定を待っているときは、最後に指定した点からの距離と方向も読み上げます。たとえば「最後の点から 2400、右方向、0 度」のように読み上げます。

## コマンド

- {{cmd:ACCESS}} は、アクセス、スナップの音、音声のオンとオフを切り替え、その状態を読み上げます。
- {{cmd:DESCRIBE}} は、図面にあるものを読み上げます。
- {{cmd:WHEREAMI}} は、カーソルの位置を読み上げます。
- {{cmd:NEARBY}} は、カーソルの近くにあるものを読み上げます。
- {{cmd:SAYSEL}} は、選択されているものを、オブジェクトごとに 1 文で読み上げます。
- {{cmd:VOICE}} は、音声によるコマンドをオンまたはオフにします。

これらの 5 つは図面を読み取って回答を表示するだけで、何も変更しません。

## スナップとグリップの音

設定で **スナップとグリップの音** をオンにします。スナップの種類ごとに音の高さと音色が決まっているため、端点、中点、中心、交点などを聞き分けられます。グリップは二重のクリック音で鳴ります。音はカーソルの画面上の位置に合わせて左右に定位します。音はお使いのコンピューター上で生成され、何もダウンロードされません。

## 音声でコマンドを入力

設定で **音声によるコマンド** をオンにします。"line"、"circle"、"move" のようにコマンド名を言い、数値は読むように言います: "point three hundred comma four hundred"、"distance twelve hundred"、"angle forty five"。"Enter"、"cancel"、"undo"、"redo" は、それぞれの動作を行います。聞き取った内容は読み上げられ、コマンドではないフレーズは推測されず、そのように報告されます。

**音声を認識する場所。** CadCraft は独自の音声サービスを持たず、音声をどこにも送信しません。このコンピューター上で音声を認識するよう、ブラウザーに依頼します。ブラウザーが対応している場合、選択肢は **このコンピューター上** で、音声がコンピューターの外に出ることはありません。対応していない場合、ブラウザーの提供元の音声サービスに音声を送信する **ブラウザーのオンラインサービス** を選ばない限り、音声はオフのままです。設定画面に、どちらが適用されるかが、決める前に表示されます。

## まだ対応していないこと

- アクセスに対応しているのは CadCraft だけです。他の 7 つのアプリも、同じキーと音で順次対応します。
- 図面内の文字 (注記、ブロック名) は、書かれているとおりに読み上げられます。指示として解釈されることはありません。
- 合成データによるチェックとブラウザーのテストで試験されています。NVDA、VoiceOver、そして全盲または弱視のテスターによる実機確認はこれからです。お試しいただいた場合は、不足している点をお知らせください。
