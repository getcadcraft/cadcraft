## できること

ダイナミックブロックを含むDWGを開くと、次のことができます:

- **元の名前。** ダイナミックブロックは、名前のない`*U`ブロックではなく、{{ui:ブロック}}パネルに元の名前(「Receptacle」「Sink」など)で表示されます。
- **保存されたときの状態。** 各参照には、他のプログラムで表示されていたとおりの内容が表示されます。設定された表示状態、保存時のストレッチや反転が再現されます。
- **表示状態の切り替え。** 参照を1つ(または同じブロックの複数)選択し、{{ui:プロパティ}}を開いて、{{ui:カスタム}}セクションの{{ui:表示}}一覧から別の状態を選びます。参照はすぐにその状態を表示し、属性も同様に切り替わります。状態で非表示になる属性は消え、表示される属性は値とともに現れます。参照はすべての値を保持するので、空になるものはありません。{{ui:プロパティ}}には非表示の項目が「非表示」と表示されます。{{key:Mod+Z}}で1回の操作で元の状態に戻ります。
- **グリップ。** 選択したダイナミックブロックには、そのパラメーターの位置にグリップが表示されます。表示状態には小さな三角形(クリックすると状態の一覧)、距離の両端には矢印、反転には両矢印が表示されます。現在動作するのは表示状態のグリップのみで、他のグリップは動作しないことをステータスバーに表示します。
- **他の値(読み取り専用)。** {{ui:カスタム}}の表示一覧の下には、ブロックの距離、位置合わせの角度、反転の状態、点が、図面に保存された値のまま表示されます。
- **表示状態の編集。** {{cmd:BEDIT}}でブロックを開きます。エディターは1つの状態を表示し、図面の上のバーにその名前が表示されます(バーで別の状態を選べます)。{{cmd:BVSTATE}}と入力すると、切り替え、追加(すべて非表示、すべて表示、または表示中のものを保持)、名前変更、削除ができます。{{cmd:BVHIDE}}は、表示中の状態で選択したオブジェクトを非表示にします。{{cmd:BVSHOW}}は、非表示のオブジェクトを薄く表示するので、クリックして戻すものを選べます。ブロックを保存すると、名前を変えた状態を参照している参照は新しい名前を保持し、削除された状態を参照している参照は最初の状態を表示します。
- **ダイナミックのまま保存。** 図面が読み込まれたときと同じバージョンのDWGとして保存すると、ブロックはダイナミックのまま、選んだ状態で保存されます。他のプログラムでは同じダイナミックブロックとして開かれます。編集した表示状態も保存され、新しい名前、追加した状態、各状態の表示内容が含まれます。

## 読み取り専用、またはまだ対応していないもの

| まだ対応していないもの | 現在の代替 |
|---|---|
| 距離、角度、反転(ストレッチ、移動、反転の操作)の変更 | {{ui:カスタム}}に読み取り専用で表示されます。ブロックを作成したプログラムで編集してください。 |
| ルックアップ、XY、回転、極のパラメーター | まだ読み取りません。参照は保存されたままに表示されます。 |
| 距離、反転、点のグリップのドラッグ | パラメーターの位置には表示されます。表示状態のグリップとプロパティの{{ui:表示}}一覧で状態を切り替えます。 |
| 他のプログラムの種類のダイナミックブロック(ストレッチ、反転、ルックアップ)の作成 | CadCraftで作成したブロックは通常のブロックです。{{cmd:BPARAMETER}}がそのことを示します。独自のパラメーターと複数の表示パラメーターは、パラメーターマネージャーにあります(後述の「独自のパラメーターと表示状態」を参照)。 |
| 表示状態を持つブロックのオブジェクトの追加や削除(ブロックエディター) | そのブロックは通常のブロックとして保存されます(エディターを閉じるときに通知されます)。 |
| 別のDWGバージョンやDXFでのダイナミックのままの保存 | 選んだ状態を表示する通常のブロックとして保存され、保存時にその旨が通知されます。 |

:::note
{{cmd:BEDIT}}でオブジェクトを移動や変更しても、表示状態を持つブロックはダイナミックのままです。状態のないブロック、またはエディターでオブジェクトを追加・削除したブロックは、通常のブロックになります。
:::

## 独自のパラメーターと表示状態

CadCraftで作成したブロックは、独自のパラメーターと**複数の**表示パラメーターを持てます。それぞれに独自の状態があります。{{cmd:BEDIT}}で編集中のブロック、選択した参照のブロック、または指定したブロックについて、**パラメーターマネージャー**を開くには{{cmd:BPARAMS}}(または`BPM`)と入力します。

- **パラメーター。** 名前、種類(数値、長さ、角度、個数、はい/いいえ)、および値、または他のパラメーターに基づく数式(`w * 2`、`if(n > 3, 1, 0)`)を指定します。結果は{{ui:算出結果}}に表示されます。動作しない数式や、種類に合わない値(個数に1.5など)は受け付けられず、マネージャーが理由を表示します。他の項目は変わりません。
- **表示パラメーター。** {{ui:表示パラメーターを追加}}で、最初の状態を持つパラメーターを作成します。各状態は名前を変更したり、削除したり(最後の1つは残ります)、「表示する値」を設定したりできます。数式で、パラメーターから状態を選べます(数式の値と一致する状態、または一覧のその位置の状態)。数式がない場合は、各参照が独自に状態を選びます。
- **オブジェクトを状態に入れる。** ブロックエディターでオブジェクトを選択し、{{cmd:BPARAMS}}と入力して、状態の{{ui:選択したオブジェクトをここに配置}}をクリックします。どの表示パラメーターにも含まれないオブジェクトは、常に表示されます。
- **この参照。** 選択した参照から開始すると、マネージャーにはその参照独自の値と状態も表示されます。

ブロックエディターの外では、変更はすべて1回の元に戻すになります。ブロックエディターでは、変更はエディターの扱いになり、{{ui:ブロックを保存}}で保持されます。`-BPARAMS`は、コマンドラインで同じことを行います。

**ファイル内の扱い。** DWGとDXFは、パラメーター、どのオブジェクトがどの状態にあるか、各参照独自の値を、CadCraft独自の記録として保存します。CadCraftで再度開くと、すべてが元どおりになります。他のプログラムでは、各参照はすべてのオブジェクトを含むブロックとして見えます。DWGは、同じ種類のブロックごとに表示パラメーターを1つまでしか持てないためです。他のプログラムが移動した参照や、オブジェクトを変更したブロックは、位置が合わなくなった部分を除いて戻ります(推測はしません)。
