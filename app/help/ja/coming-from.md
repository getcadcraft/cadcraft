AutoCAD、または同じモデルに基づくプログラムを使ったことがあれば、知っていることの大部分がここでも使えます。コマンドライン、`L`、`C`、`TR`、`O` などの別名、繰り返しの Enter または Space、窓選択と交差選択、F3 のオブジェクトスナップ、F8 の直交モード、レイアウトとビューポートを使うモデル空間などです。このページでは、そのまま対応するものと、そのあとで利用者がつまずきやすい違いを示します。前半を流し読みする場合でも、後半は必ず読んでください。

## そのまま対応するもの

| 操作習慣 | CadCraft での対応 |
|---|---|
| `L`、`PL`、`C`、`A`、`REC`、`POL`、`EL`、`PO`、`T`、`DT` | 同じコマンド、同じ別名 |
| `M`、`CO`、`RO`、`SC`、`MI`、`O`、`TR`、`EX`、`F`、`X`、`E` | 同じ |
| `DLI`、`DAL`、`DAN`、`DRA`、`DDI`、`DCO`、`DBA` | 同じ寸法コマンド |
| コマンドラインで入力する `DIMSCALE`、`DIMTXT`、`DIMASZ`、`DIMDEC`、`DIMGAP`、`DIMEXE`、`DIMEXO` | 同じ。新しい寸法に対して有効 |
| `B` でブロックを作成、`I` で挿入、`PU` で消去 | 同じ（消去は未使用のブロックのみを削除します） |
| `LAYOUT`、`MV`、`PLOT`、`DI`、`ID`、`LI`、`Z` のあとに `E` または `W` | 同じ |
| スクリプトや操作習慣から `_LINE` や `-LAYER` と入力する | 先頭の `_`、`-`、`.`、`'` は無視されます |
| 空のプロンプトで Enter または Space を押す（直前のコマンドを繰り返す） | 同じ |
| Esc でキャンセル。もう一度 Esc で選択解除 | 同じ |
| `@dx,dy`、`@d<a`、東から反時計回りに入力する角度 | 同じ |
| 左から右へ窓、右から左へ交差、2 回クリック。ドラッグで投げ縄、Space で窓 / 交差 / フェンスを切り替え（LASSOMODE） | 同じ |
| 先に選択してからコマンド（名詞-動詞） | 同じ。完了したコマンドは選択を解除します |
| オブジェクトの選択で `ALL` と `L` | 同じ |
| Shift+クリックで選択から除外 | 同じ。設定により、PICKADD 0 と同様に、クリックで選択を置き換えることもできます: [CadCraft の設定](topic:settings) を参照 |
| Ctrl+C、Ctrl+X、Ctrl+V、Ctrl+Shift+V（COPYCLIP、CUTCLIP、PASTECLIP、PASTEORIG）、COPYBASE | 同じコマンドとキー。貼り付けは、PASTECLIP と同様に、左下隅を基準にコピーを配置します |
| F3 オブジェクトスナップ、F7 グリッド、F8 直交モード | 同じキー |
| ホイールをダブルクリックして範囲ズーム | 同じ |
| 鏡像の文字も読める状態のまま | 同じ（MIRRTEXT 0 と同様） |
| Ctrl+Z、Ctrl+Y、Ctrl+S、Ctrl+O、Ctrl+P、Ctrl+A | 同じ。Mac では Command も使えます |

[コマンドリファレンス](topic:commands) に、すべてのコマンドと別名があります。

:::tip
AutoCADのリボンが好みなら、{{ui:設定}} › {{ui:CadCraft}} › {{ui:メニュー、キー、マウス}} で {{ui:製図クラシック}} のメニュースタイルを選びます。同じコマンドラインの上に、ホーム、挿入、注釈、パラメトリック、ビュー、管理、出力の各タブが表示され、中ボタンでパン、右クリックで Enter になります。[メニュー、キー、マウス](topic:menus-keys-and-mouse) を参照してください。
:::

[コマンドマップ](topic:command-map) には、CadCraft のすべてのコマンドと短縮名が載っています。[チートシート](topic:cheat-sheet) には、最もよく使う 40 個のコマンドが載っています（1 ページの PDF でもあります）。

## つまずきやすい違い

### 入力した点は絶対座標

動的入力がオンのとき、ほかのプログラムでは、2 番目の点として入力した `100,0` を相対座標として扱います。**CadCraft のコマンドラインは違います:** ここでは、`x,y` は常に原点からの値になります。{{ui:動的}}（{{key:F12}}）をオンにしている場合は、代わりにその入力欄を使ってください: 距離、{{key:Tab}}、角度。最後の点から右へ100の位置を指定するには `@100,0` を使うか、十字カーソルを正しい方向に動かして、単に `100` と入力します。

### Shiftはスナップを無視し、直交モードにはなりません

クリック中に Shift を押すと、そのクリックではオブジェクトスナップを無視します。直交モードが一時的に切り替わることはありません。F8 または {{ui:直交}} ボタンを使ってください。

### 右クリックは常に Enter

右クリックメニューはありません。図面上の右クリックは Enter です。コマンドを終了し、選択を完了し、または直前のコマンドを繰り返します。グリップの移動中や選択ボックスの操作中は、代わりにキャンセルになります。右ボタンでドラッグするとパンします。

### Space によるパンはできません

Space は Enter なので、Space を押しながらドラッグしてもパンしません。中ボタンまたは右ボタンでパンするか、ホイールでズームアウトしてから、別の場所でズームインしてください。

### トリムと延長

TRIM と EXTEND は、クイックモードで始まります。表示されているすべてのオブジェクトが切り取りエッジまたは境界になり、ポインターの下の部分が削除される部分を示し、ドラッグした経路が通過するすべての部分をトリムし、どこも交差しないオブジェクトは削除されます。{{key:Shift}} でトリムと延長を切り替えます。`O` で標準モードに切り替えます（先にエッジを選択）。`F` と `C` はフェンスと交差、`E` は EDGEMODE、`R` は削除です。`P`（投影）オプションはありません: CadCraft は図面の平面内でトリムします。

### フィレットと面取り

{{cmd:FILLET}} と {{cmd:CHAMFER}} では、おなじみのオプションが使えます: 元に戻す、ポリライン、半径（または距離、角度、mEthod）、トリム、複数。鋭い角には {{key:Shift}}+クリックします。ポリラインと線の間のフィレットでは、円弧をポリラインに結合するのではなく、独立したオブジェクトとして追加します。円弧セグメントに隣接するポリラインの角は、そのまま残ります。

### 段落文字と1行文字

`T`、`MT`、`MTEXT` は、その場で入力する段落文字です。幅、行間、位置合わせを指定できます。`DT` と `DTEXT` は、おなじみの 1 行文字です。文字スタイルや段組みはなく、現時点では文字内の書式（太字、積み重ねた分数）は入力できません。ファイルから取り込んだ書式は保持、描画、保存されます（[文字とラベルの追加](topic:text#formatting-inside-paragraph-text-from-other-programs) を参照）。すべての文字は Helvetica 系のフォントで描画されます。

### 保存は「コピーをダウンロード」を意味します

{{key:Mod+S}}、`SAVE`、`QSAVE` は、図面の形式でコピーをダウンロードします。開いた DWG は DWG として、DXF は DXF として保存されます。ブラウザーでは、その場で上書きされることはなく、開いたファイルが変更されることもありません。CadCraft Studio では、{{key:Mod+S}} で開いたファイルに書き戻されます。

`SAVEAS`（{{key:Mod+Shift+S}}）は、ファイルブラウザーではなく小さなダイアログです: {{ui:DWG}}（その {{ui:バージョン}}、AutoCAD 2000 から 2018）、DXF R12、または {{ui:DXF 2000}} を選び、{{ui:保存}} をクリックします。ダウンロード先はブラウザーが決めます。`DXFOUT` は常に DXF R12 をダウンロードします。

開いた DWG は、読み込んだときのバージョンで保存されます。新規図面は、別のものを選ばない限り AutoCAD 2000 形式で保存されます。シート、寸法、ハッチングパターンは保持されます。[ファイル: 開けるもの、保存できるもの](topic:files#saving) を参照してください。

### レイヤー: より簡単

- レイヤーの変更（オン、フリーズ、ロック、色、印刷、線種、線の太さ、現在のレイヤー）はすべて、1 回の元に戻す操作になります。
- CadCraft では、オフとフリーズは同じ効果があります。
- 1 つのビューポートで図面がフリーズしたレイヤーは、そこでフリーズされたままになります: 画面上、印刷、DWG または DXF として保存したときも同様です。
- レイヤーを独自の色、線種、線の太さ、または透明度で表示しているビューポートは、画面上、印刷、保存された DWG でも、その表示を維持します（DXF はレイヤー自身の設定を保持します。保存時にその旨が表示されます）。ビューポートごとにこれらを変更する機能は、まだ作成されていません。
- レイヤープロパティマネージャーとレイヤー状態はありません。{{cmd:RENAME}}、{{cmd:LAYMRG}}、{{cmd:LAYDEL}} で、レイヤーの名前変更、結合、削除を行います。線種と線の太さは右パネルで設定します（[線の太さと線種](topic:units-papers-scales#line-weights-and-linetypes) を参照）。{{cmd:LAYISO}}、{{cmd:LAYOFF}}、{{cmd:LAYFRZ}}、{{cmd:LAYMCUR}} は、オブジェクトを選択して動作します。
- DXF R12 として保存すると、レイヤー名は大文字で書き込まれます。DWG では、入力したとおりに保持されます。

### 寸法スタイル

`DIMSTYLE` は、名前付きスタイルのマネージャーを開きます（新規、修正、現在に設定、比較、適用）。`DIMSCALE` とほかの設定は、新しい寸法が使う値を変更します。各寸法は独自のサイズを保持し、プロパティパネルでも変更できます。現在のスタイルはファイルに保存されません。寸法は、図面の長さの形式（小数、または {{cmd:UNITS}} によるフィートとインチ）に従うか、または独自の {{ui:形式}} に従います。[寸法のサイズを設定](topic:dimension-settings) を参照してください。

### 印刷はより簡単

印刷スタイルテーブルは、CTB ファイルと同様に色で動作します。モノクロ、カラー、グレースケールが組み込まれており、独自のものも作成でき、各シートがそのテーブルを保持します。CTB ファイルの読み込みは、公開されている仕様に基づいて作成されており、当社が作成したファイルでのみ試されています。名前付き印刷スタイルテーブル（STB）とページ設定は、まだ作成されていません。線は線の太さで印刷され、それ以外は 1 つのペン幅で印刷されます。シートは、それぞれの用紙上で 1:1 で印刷されます。モデルは、選択した縮尺、または用紙に合わせた縮尺で印刷されます。[PDFに印刷](topic:plot-pdf) を参照してください。

### ビューポート内での作業

おなじみの操作です。ビューポート内をダブルクリック（または {{cmd:MSPACE}} と入力）すると、ビューポートを通してモデルを編集でき、その外側をダブルクリック（または {{cmd:PSPACE}}）すると、シートに戻ります。ビューポート内でパンやズームを行うと、ビューポートの表示が変わります。表示がロックされている場合は、代わりにシートが移動します。図面の下にあるタブをクリックしても、ビューポートから抜けます。[ビューポートを通してモデルで作業](topic:sheets-and-viewports#work-on-the-model-through-a-viewport) を参照してください。

### トラッキングと動的入力は対応、グリッドスナップは未対応

グリッドは表示のみに使います。点はグリッドにスナップしません（F9 のスナップモードはありません）。極トラッキング（{{key:F10}}、刻みは {{cmd:POLARANG}} で設定）と、オブジェクトスナップトラッキング（{{key:F11}}: スナップ点に留めると取得されます）は、おなじみの動作です。[オブジェクトにスナップ](topic:object-snaps#polar-tracking) を参照してください。動的入力（{{key:F12}}）は、十字カーソルの横に距離と角度（または X と Y）を表示します。[座標と距離の入力](topic:coordinate-entry#dynamic-input) を参照してください。

### フィートとインチ

{{ui:長さの形式}} で {{ui:建築}} または {{ui:工学}} を選び（または {{cmd:UNITS}} と入力し）、おなじみの方法で長さを入力します: `12'6"`、`12'6-1/2"`。分数の前には、スペースではなくハイフンを使います。{{key:Space}} は {{key:Enter}} になります。シートと印刷で建築縮尺が使えるように、{{ui:単位}} も {{ui:インチ}} に設定します。形式は、保存された DWG と DXF ファイルで保持されます。[フィートとインチ](topic:units-papers-scales#feet-and-inches-and-fractions) を参照してください。

### コピーと貼り付けは CadCraft 内に限られます

{{key:Mod+C}}、{{key:Mod+X}}、{{key:Mod+V}} は、図面内、図面間、同じブラウザー内の CadCraft タブ間で、オブジェクトのコピー、切り取り、貼り付けを行います。クリップボードは CadCraft 専用です。CadCraft のオブジェクトをほかのプログラムに貼り付けたり、ほかのプログラムのオブジェクトを CadCraft に貼り付けたりすることはできません。異なる単位の図面から貼り付けた場合は、自動的に拡大縮小されません。その後で {{cmd:SCALE}} を使ってください。{{key:Mod+D}} は、ポインターとともに移動する複製で、CadCraft の追加機能です。[コピー、貼り付け、複製](topic:copy-paste) を参照してください。

### 使用できないブラウザーのキー

Web ページでは、ブラウザーの {{key:Mod+N}}、{{key:Mod+W}}、{{key:Mod+T}} を使用できません。これらのキーは、ウィンドウとタブを開いたり閉じたりします。{{ui:新規}} ボタンを使うか、`NEW` と入力してください。[キー、マウス、トラックパッド](common:keys) を参照してください。

## まだ対応していないコマンド

{{cmd:TABLE}} はまだ作成されていません。入力すると「不明なコマンド」と表示されます。（{{cmd:PEDIT}}、{{cmd:SPLINE}}、{{cmd:SPLINEDIT}}、{{cmd:XREF}} は作成済みです。）[まだ作成されていません](topic:not-built-yet) に、現時点での代替手段が載っています。
