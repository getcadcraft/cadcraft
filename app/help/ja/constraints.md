## 作るもの

幅を一か所で変更できる板を作ります。辺は直角のまま、一つの角は動かず、高さは幅の半分に保たれます。

拘束は {{ui:モデル}} タブの線、ポリライン、円、円弧、点に付けられます。追加した拘束は、それぞれ元に戻す操作一回分になります。

## 外枠を描いて拘束する

1. `REC` と入力して {{key:Enter}} を押します。`0,0`、{{key:Enter}}、`100,50`、{{key:Enter}} と入力します。
2. `AUTOCONSTRAIN` と入力して {{key:Enter}} を押します。`ALL` と入力して {{key:Enter}}、さらにもう一度 {{key:Enter}} を押します。

   履歴に「4 件の拘束を適用しました」と表示されます。辺の横に **H** と **V** の付いた小さな箱が表示されます。これが拘束バーです。
3. `GCFIX` と入力して {{key:Enter}} を押します。左下の角の近くをクリックします。⊕ の付いた箱が表示されます。この角は現在の位置に固定されます。

`AUTOCONSTRAIN` は、線の端点がほぼ重なる場所には一致拘束を、ほぼ水平または垂直の線には水平拘束または垂直拘束を追加します。どの程度近いと見なすかを変えるには、プロンプトで `S` と入力します（初期値は 0.05 図面単位と 1°です）。

## 寸法を追加する

1. `DCHORIZONTAL` と入力して {{key:Enter}} を押します。
2. 左下の角の近くをクリックし、次に右下の角の近くをクリックします。
3. 長方形の下をクリックして寸法線の位置を指定します。
4. プロンプトに `Dimension text <d1=100>` と表示されます。`width=120` と入力して {{key:Enter}} を押します。

   長方形の幅が 120 になり、ラベルに `width=120` と表示されます。
5. `DCVERTICAL` と入力して {{key:Enter}} を押し、`O` と入力して {{key:Enter}} を押します。次に右の辺をクリックします。
6. 辺の右側をクリックし、`width/2` と入力して {{key:Enter}} を押します。

   高さは 60 になります。ラベルには `fx: d1=width/2` と表示されます。数式によって寸法が決まっています。

履歴には、外枠が完全拘束されたと表示されます。サイズを変更するには、`width` を変更するか（[パラメーターと方程式を使う](topic:parameters)を参照）、`width=120` のラベルをダブルクリックして新しい値を入力し、{{ui:適用}} を選びます。

## 拘束されたオブジェクトを動かす

移動、回転、尺度変更、グリップ、プロパティパネルのいずれでも、拘束は保持されます。動かしたものは固定され、残りはそれに従います。拘束が従えない場合は、編集は行われず、履歴に理由が表示されます（例: 「未実行: 拘束によりこのオブジェクトは現在の位置に保持されています」）。オブジェクトを削除すると、その拘束も一緒に削除されます。

## 拘束されたオブジェクトを鏡像とトリムする

- {{cmd:MIRROR}} は、鏡像にするオブジェクト同士の拘束を複製先にもコピーします。接線の接触側や寸法の測定側は鏡像の複製用に計算し直され、複製された寸法には貼り付けと同様に独自の名前が付けられます。`Erase source objects` で `Y` を選ぶと、拘束は鏡像にしたオブジェクトに残ります。履歴に、一緒に移った拘束の数が表示されます。
- {{cmd:TRIM}} は、線や円弧の拘束を残った部分に引き継ぎます。端点に付いた拘束は、その端点を持つ部分に移ります。方向に関する規則（{{ui:水平}}、{{ui:垂直}}、{{ui:平行}}、{{ui:直角}}）はすべての部分で保持されます。両端の間の寸法は、その両端を測定し続けます。切り取られた部分を拘束していた拘束や、切断によって変わる長さに関する拘束（{{ui:等しい}}、円弧の掃引角）は削除されます。トリムした円は中心と半径の拘束を保持します。トリムしたポリラインの拘束は失われます。

## 拘束の種類

| {{ui:コマンド}} | 保持するもの |
|---|---|
| {{cmd:GCHORIZONTAL}}, {{cmd:GCVERTICAL}} | 線または線分を水平または垂直に保ちます（`2P`: 二点を水平または垂直に揃えます） |
| {{cmd:GCPARALLEL}}, {{cmd:GCPERPENDICULAR}}, {{cmd:GCCOLLINEAR}} | 二本の線を平行、直角、または同一直線上に保ちます |
| {{cmd:GCCOINCIDENT}} | 二点を一致させます。`O`: 点を線、円、円弧の上に置きます |
| {{cmd:GCTANGENT}} | 線と円または円弧、または二つの円弧や円を接させます |
| {{cmd:GCCONCENTRIC}}, {{cmd:GCEQUAL}} | 二つの円や円弧を同じ中心にします。二つの長さまたは二つの半径を等しくします |
| {{cmd:GCSYMMETRIC}} | 二点、線、または円を、ある線に対して対称に保ちます |
| {{cmd:GCFIX}} | 点（近くをクリック）またはオブジェクト全体（`O`）を現在の位置に固定します |
| {{cmd:DCLINEAR}}, {{cmd:DCHORIZONTAL}}, {{cmd:DCVERTICAL}}, {{cmd:DCALIGNED}} | 距離 |
| {{cmd:DCRADIUS}}, {{cmd:DCDIAMETER}}, {{cmd:DCANGULAR}} | 半径、直径、二本の線の間の角度、または円弧の角度 |

{{cmd:GEOMCONSTRAINT}} と {{cmd:DIMCONSTRAINT}} は、どの拘束を付けるかを尋ねます。{{ui:拘束}} と {{ui:寸法}} は {{ui:パラメトリック}} グループにあり、それぞれを実行します。{{ui:その他}} には各拘束が一覧されます。どこをクリックするかで対象が決まります。端点、中点、中心の近くをクリックすると、その点が選ばれます。ポリラインをクリックすると、その下にある線分が選ばれます。最初のオブジェクトは動かず、二番目のオブジェクトが動いて合わさります。

他の拘束と矛盾する拘束、または他の拘束から既に導かれるため何も追加しない拘束は、メッセージとともに拒否され、何も動きません。

## 表示、選択、削除

- 拘束バーの箱（または一致拘束の小さな四角、寸法ラベル）をクリックすると、その拘束が選択されます。履歴に拘束の名前が表示されます。{{key:Delete}} を押すと削除されます。
- {{cmd:DELCONSTRAINT}} は、選択したオブジェクトのすべての拘束を削除します。
- {{cmd:CONSTRAINTBAR}}: `S` ですべてのバーを表示し、`H` で非表示にします。先にオブジェクトを選択すると、そのオブジェクトのバーだけを表示または非表示にできます。{{ui:その他}} には {{ui:拘束バーを表示}} と {{ui:拘束バーを非表示}} があります。
- {{cmd:DCDISPLAY}} は寸法拘束を表示または非表示にします。寸法拘束は印刷されません。
- {{cmd:DCCONVERT}} は、線、円、円弧に付けられた寸法を寸法拘束に変換します。

:::note
AutoCAD のパラメトリック作図を使ったことがある場合、コマンド名とプロンプトは同じです。拘束とパラメーターは、他のプログラムが無視する形式で DWG および DXF ファイルに保存されます。[ファイル](topic:files#constraints-in-files)を参照してください。
:::
