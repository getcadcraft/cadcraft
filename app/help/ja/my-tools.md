## 学習内容

ツールバーに独自のボタンを配置する方法、AutoCAD と同じ書き方で書かれたマクロを各ボタンに実行させる方法、ボタンにキーを割り当てる方法、CUIx ファイルのボタンを取り込む方法を学びます。

## ボタンを追加

1. {{ui:Settings}}（{{key:Mod+,}}）を開き、{{ui:CadCraft}}タブのままにします。{{ui:My tools}}までスクロールします。
2. {{ui:Add a button…}}をクリックします。
3. ボックスに入力します。
   - {{ui:Group}}: ボタンを配置するツールバーのグループ（例: `My tools`）。新しい名前を入力すると、新しいグループが作成されます。
   - {{ui:Label}}: ボタンに表示される文字。
   - {{ui:Macro}}: 入力される内容（例: `^C^C_rectang;0,0;@100,50;`）。
   - {{ui:Shortcut key}}: ボックスをクリックして、キーを押します（例: {{key:Ctrl+Alt+B}}）。
   - {{ui:Icon}}: 最大64 KB の PNG または SVG 画像。または指定なし（星が表示されます）。
4. {{ui:Save}}をクリックします。

ボタンは、そのグループのツールバーの末尾に表示されます。クリックするか、そのキーを押すと実行されます。一覧の{{ui:Edit}}と{{ui:Delete}}で、変更または削除できます。

## マクロを書く

マクロは、コマンドラインに入力するものと同じですが、いくつかの記号を使います。

| 記号 | 意味 |
|---|---|
| `^C` | 実行中のものをキャンセルします（`^C^C` が一般的な始め方です） |
| `;` またはスペース | {{key:Enter}} |
| `\` | 入力を待ちます。クリックまたは入力された回答の後、マクロが続行されます |
| コマンドの前の `_` または `.` | 受け付けられ、無視されます（国際名および組み込みの名前） |
| 先頭の `*` | 終了するたびに再実行されます。{{key:Esc}}を押すまで続きます |
| `^O`、`^G` | 直交モードとグリッドをオンまたはオフにします |
| `$M=` | 残りは DIESEL です。読み取られるのは `$(if,…)`、`$(getvar,…)`、`$(=,…)`、`$(eq,…)` だけです。それ以外を使うボタンは、その旨を表示し、何も実行しません |

例:

- `^C^C_line;0,0;@100,0;;` は、原点から長さ100の線を描きます。
- `^C^C_circle;\25;` は中心を尋ね、その位置に半径25の円を描きます。
- `^C^C_turnright` は、表示を右に90°回転します。

## ショートカットキー

キーには、{{key:Mod}}（Ctrl、Mac では Cmd）または {{key:Alt}} と、文字または数字の組み合わせが必要です。空いているファンクションキー {{key:F2}}、{{key:F4}}、{{key:F5}}、{{key:F6}}、{{key:F9}} も使えます。文字だけのキーはコマンドラインに入力されます。CadCraft、アプリ、ブラウザーがすでに使用しているキー（{{key:Ctrl+S}}、{{key:Ctrl+Z}} など）や、別のボタンが使用しているキーは拒否され、そのボックスに理由が表示されます。

## ボタンを共有

- {{ui:Export…}}は、すべてのグループとボタン（アイコンとキーを含む）を `my-tools.json` として保存します。
- {{ui:Import…}}は、そのようなファイルのグループを、既存のグループの後に追加します。すでに使われているグループ名には「(2)」が付きます。競合するキーは外され、パネルにその旨が表示されます。

## CUIx ファイルからボタンを取り込む

1. {{ui:Import CUIx…}}をクリックし、`.cuix` ファイルを選択します。

そのツールバーとリボンパネルはグループになり、各ボタンはマクロと画像（PNG、または PNG に変換された BMP）を持ちます。そのショートカットキーは独自のグループにまとめられ、各ボタンにそのキーが付きます。含まれているコマンドの別名は、{{ui:Aliases}}グループに入ります。パネルには、取り込まれた内容が表示されます。

:::note
ファイルは読み取りのみで、変更されません。CadCraft にないコマンドは推測せず、名前で一覧に表示されます。そのボタンをクリックすると、その旨が表示されます。上記のいくつかの関数を超える DIESEL、メニュー、マウスボタン、ワークスペースは読み取られません。
:::

## 知っておくと便利なこと

- ボタンは、図面ではなく、このブラウザー（またはこのデスクトップアプリ）に保存されます。
- ボタンはコマンドラインを通して実行されるため、入力したものと同じように元に戻せます。実行されたコマンドごとに{{key:Mod+Z}}が1回必要です。
