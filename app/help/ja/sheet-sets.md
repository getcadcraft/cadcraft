## 学習内容

複数の図面ファイルからシート（レイアウト）を**シートセット**に集め、番号と名前を付け、表題欄を自動的に埋めてもらい、セット全体を1つの PDF として発行し、送付用にすべてを1つの zip にまとめる方法です。

シートセットは、図面のあるフォルダーに、`<name>.ccsheets` という小さな独自のファイルとして保存されます。セットファイルには、そのフォルダーからの相対パスでシートが記録されているため、フォルダー全体を移動またはコピーできます。

:::note
フォルダーを読み書きして開くには、Chrome または Edge（選んだフォルダーでページを動作させられるブラウザー）、またはデスクトップアプリが必要です。他のブラウザーでは、セットは読み取り専用で開きます。内容を確認して発行することはできますが、セットファイルは保存されず、ダウンロードされます。
:::

## セットを作成する

1. 左パネルの「{{ui:Sheet set}}」セクションを探し、その「{{ui:Set}}」メニューを開きます。{{cmd:SHEETSET}}（または `SSM`）と入力しても、同じ場所に移動します。
2. 「{{ui:New set…}}」を選びます。セットに名前を付けます。必要に応じて、プロジェクト名と番号も付けます。
3. 図面が入っているフォルダーを選びます。セットファイルはそこに保存されます。

後でセットを開くには、「{{ui:Open set…}}」を選び、同じフォルダーを指定します。フォルダーに複数のセットがある場合、CadCraft はどれを開くかを尋ねます。

## シートを追加する

1. 「{{ui:Add sheets from a drawing…}}」を選び、フォルダー内の図面のいずれかを指定します。
2. CadCraft はその図面をバックグラウンドで読み込み（画面には開きません）、そのシートを一覧表示します。必要なものにチェックを付け、「{{ui:OK}}」をクリックします。
3. シートを選択して {{key:F2}} を押す（または「{{ui:Rename and renumber…}}」を選ぶ）と、`A-101` や `平面図` のような番号と名前を付けられます。

「{{ui:New sheet from template…}}」は、別の図面のシート（その表題欄とビューポート）から新しい図面を作成し、新しいシートにちなんだ名前を付けて追加します。セットは、テンプレートとして使った図面を記憶します。

## セットを整理する

- **サブセット** は、`建築 › 平面図` のようにシートをまとめます。移動先を選び、「{{ui:New subset…}}」を選びます。
- **順序**: シートを一覧内の別の場所にドラッグするか、サブセットにドロップしてそこへ移動します。キーボードでは、シートを選択して {{key:Alt+Up}} または {{key:Alt+Down}} を押します。
- **シートを開く**: ダブルクリックします（または {{key:Enter}} を押します）。その図面が、そのシートを表示した状態で独自のタブに開きます。
- **削除**: 選択して {{key:Delete}} を押します。図面自体は変更されません。
- **元に戻す**: 「{{ui:Undo set change}}」と「{{ui:Redo set change}}」で、セットに対して行った変更を順に戻し、やり直します。
- **番号の付け直し**: 「{{ui:Renumber sheets…}}」は、すべてのシート、または1つのサブセットのシートを、一覧の順に番号付けします。接頭辞、開始番号、増分を指定します（`A-` と `101` を指定すると A-101、A-102 …）。

すべての変更は、すぐにセットファイルに保存されます。

## フィールドからシートに番号を付ける

シートに手で番号を付ける代わりに、規則でシートのフィールドから番号を作らせると、別の階や分野へ移動したシートは、自動的に新しい番号を受け取ります。

1. 各シートにフィールドを設定します。シートを選択し、「{{ui:Rename…}}」をクリックして、「{{ui:Fields of this sheet}}」に 1 行に 1 つずつ書きます（例: `DISCIPLINE = A` と `LEVEL = 1`）。セット全体で共有するフィールド（例: `DISCIPLINE = A`）は、代わりにセットの「{{ui:Properties…}}」に入れることもできます。
2. パネルのメニューを開き、「{{ui:Numbering rule…}}」をクリックします。
3. 規則を書きます（例: `{DISCIPLINE}-{LEVEL}{SEQ:2}`）。`{SEQ}` は、他のフィールドの値が同じシートの中で連番を数えます。そのため、階 1 は A-101、A-102 となり、階 2 は A-201 から再び始まります。`{SEQ:2}` は 2 桁で書きます。`{SUBSET}` は、シートが属するサブセットの名前です。
4. フィールドが変わったときの動作を選びます。「{{ui:Renumber the sheets}}」は、変更のたびに規則に従って番号を保ちます。もう一方の選択肢は、今この時点で一度だけ番号を付けます。

規則はセットファイルに保存されます。規則に従って自動で付け直されている間は、番号ではなく、シートのフィールドを変更してください。

## セットから表題欄を埋める

表題欄の属性がフィールド名でタグ付けされていると、そのテキストはセットから取得されます。

| タグ | 表示内容 |
|---|---|
| `SHEETNUMBER`（または `SHEET_NO`、`DWG_NO`） | シートの番号 |
| `SHEETTITLE`（または `TITLE`、`SHEET_TITLE`） | シートの名前 |
| `SHEETDESC` | シートの説明 |
| `PROJECTNAME`（または `PROJECT`） | プロジェクト名 |
| `PROJECTNUMBER`（または `PROJECT_NO`、`JOB_NO`） | プロジェクト番号 |
| `SHEETSETNAME` | セットの名前 |
| `SHEETINDEX`、`SHEETCOUNT` | 「3 / 12」、および 12 |
| `CLIENT` など、独自のもの | 「{{ui:Set fields…}}」に入力した値 |

「{{ui:Set fields…}}」には、プロジェクト名と番号、および独自のフィールドを、1 行に `NAME = value` の形式で 1 つずつ保持します。

「{{ui:Update drawings}}」は、セット内のすべての図面の表題欄に、番号、名前、フィールドを書き込み、各シートのレイアウトタブの名前もセットの指定どおりに変更します（既定では番号と名前。例: `A-101 平面図`。「{{ui:Set fields…}}」›「{{ui:Layout tab names}}」で変更できます）。各図面は、その形式とバージョンのまま、その場所に保存されます。番号や名前を変更した後は、もう一度実行すると、タブと表題欄が追従します。

## 表紙シートにシート一覧を入れる

表紙シートを一覧で選択し、「{{ui:Put the sheet list on this sheet}}」を選びます。すべてのシートの表（番号と名前。サブセットごとにまとめて表示）が、シートの左上隅に配置されます。「{{ui:Update drawings}}」と「{{ui:Publish to PDF}}」で最新の状態に保たれます。これは `CC_SHEETLIST` という1つのブロックなので、通常のブロック参照と同様に移動できます。

## セットを発行する

「{{ui:Publish to PDF}}」は、セットの順序で、各シートをそのシート自身の用紙サイズで1ページずつ含む 1 つの PDF を作成し、シートごとにしおり（「A-101 — 平面図」）を付けます。サブセットを選択している場合、CadCraft はそのサブセットだけを発行するかを尋ねます。PDF 内の表題欄は、図面を更新する前でも、セットから埋められます。発行しても図面は変更されません。PDF はダウンロードされます。

「{{ui:Publish to DWG…}}」は、各シートをそれぞれ独自の DWG（DWG 2018）として書き出します。各 DWG には、モデルとそのシートの1つが含まれ、表題欄はセットから埋められ、番号と名前で名前が付けられます（`A-101 Level 1 floor plan.dwg` など）。「{{ui:DWG}}」を選ぶか、セットの PDF を並べて出すには「{{ui:DWG + PDF}}」を選びます。`publish.json` には、すべてのファイルのサイズと SHA-256 が記載されます。セットのフォルダーに書き込める場合（CadCraft Studio、またはブラウザーで選んだフォルダー）は、ファイルは `<set name> - published` というフォルダーに保存されます。それ以外の場合は、1つの zip としてダウンロードされます。ビューポートの[クラス上書き](topic:viewport-overrides)は、各 DWG に含まれます。

## セットをアーカイブする

「{{ui:Archive as a zip}}」は、セットファイル、それが使用するすべての図面、およびそれらの図面がリンクしているもの（外部参照、さらにその先の参照、画像）を、フォルダー構造を保ったまま1つにまとめます。すべてのファイルを列挙した `Transmittal.txt` も追加されます。セットのフォルダーにないリンクは、欠落として一覧に示されます。リンクは、図面からのパスで検索され、見つからない場合は、フォルダー内のどこかにあるファイル名で検索されます。

## セットファイル

`.ccsheets` ファイルは、どのテキストエディターでも読める JSON です。

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

パスは、セットのフォルダーからの相対パスで、フォルダーの区切りには `/` を使います。CadCraft は、開くときにファイルを確認します。絶対パス、ファイルまたはレイアウトのないシート、通常のテキストではない文字列は除外され、その旨が履歴に表示されます。

## トラブルシューティング

| 表示される内容 | 原因 | 対処 |
|---|---|---|
| 「このフォルダーは、ここでは読み取り専用です」 | ブラウザーがそのフォルダーに書き込めない | Chrome か Edge、またはデスクトップアプリを使います。それまでは「{{ui:Download the set file}}」で変更を保存できます |
| PDF からシートが抜ける: 「…という名前のレイアウトがありません」 | 図面内で、そのシートのレイアウトが名前変更または削除された | 図面を開いてタブを確認し、シートを削除して、もう一度追加します |
| 表題欄が空のまま | 属性のタグが別の名前になっている | 属性のタグ名を上記のフィールド名に変更します（BEDIT） |
| 「…という名前のレイアウトが既にあるため、そのタブは名前変更されませんでした」 | 1つの図面の2つのシートが同じタブ名になる | どちらかに、別の番号または名前を付けます |
