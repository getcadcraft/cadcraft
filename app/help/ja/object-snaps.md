## 作成するもの

長方形とその2本の対角線、対角線の交点を中心とする円、そして左辺の中央から円まで引く線です。すべての点はマウスで指定され、どの点も正確です。

## スナップの仕組み

コマンドが点を尋ねている間、CadCraft は十字カーソルの約10ピクセル以内にあるスナップ点を探します。見つかると、マーカーとラベル（「端点」、「交点」）が表示され、クリックすると、カーソルの位置ではなく、その点に**正確に**配置されます。

ステータスバーの{{ui:スナップ}}が押されているとき、スナップはオンです。{{key:F3}}でオンとオフを切り替えます。

使用できるスナップは次のとおりです:

| スナップ | 指定される位置 |
|---|---|
| 端点 | 線分、円弧、ポリラインのセグメントの端 |
| 中点 | 線分、円弧、ポリラインのセグメントの中央 |
| 中心 | 円と円弧の中心、およびポリラインの円弧セグメントの中心 |
| 四半円点 | 円と円弧の 0、90、180、270 度の点 |
| 交点 | 2つのオブジェクトが交わる点 |
| 垂線 | 最後の点から直角になるオブジェクト上の点（基点が必要） |
| 接線 | 最後の点から引いた線が、円または円弧に接する点。最後の点がまだない場合（線分の1点目）は、マーカーに「延期」と表示されます。接する点は次の点が決まってから求められるため、接線から接線への線は、両方の円に接します。 |
| 最近点 | 任意のオブジェクト上の最も近い点 |
| ノード | 点オブジェクト |
| 挿入点 | 文字とブロック参照の挿入点 |

接線と最近点を除き、すべては既定でオンです。最近点は、ほかの点を指定したいときにも選ばれやすくなっています。接線が必要なときにオンにしてください。

## スナップを選ぶ

1. ステータスバーの{{ui:スナップ}}の横にある小さな矢印をクリックします。{{ui:オブジェクトスナップ}}の一覧が開きます。
2. スナップをチェックまたは解除します。変更はすぐに適用されます。
3. 矢印をもう一度クリックして、一覧を閉じます。

CadCraft は、このブラウザーで、{{ui:スナップ}}、{{ui:グリッド}}、{{ui:直交}}の設定を記憶します。

## 手順

1. `REC`と入力して{{key:Enter}}を押します。
2. `0,0`と入力して{{key:Enter}}を押します。
3. `@4000,3000`と入力して{{key:Enter}}を押します。長方形が表示されます。
4. {{ui:範囲}}をクリックします。
5. `L`と入力して{{key:Enter}}を押します。
6. 十字カーソルを左下の角に動かします。マーカーに「端点」と表示されます。クリックします。
7. 右上の角に動かし、「端点」と表示されたらクリックします。
8. {{key:Enter}}を押して、線を終了します。
9. もう一度{{key:Enter}}を押して{{cmd:LINE}}を繰り返し、右下の角から左上の角へ、もう一方の対角線を同じ方法で描きます。
10. `C`と入力して{{key:Enter}}を押し、円を開始します。
11. 十字カーソルを対角線の交点に動かします。マーカーに「交点」と表示されます。クリックします。
12. `800`と入力して{{key:Enter}}を押します。

交点を中心とする円が正確に表示されるはずです。

13. `L`と入力して{{key:Enter}}を押します。
14. 長方形の左辺の中央に移動し、「中点」と表示されたらクリックします。
15. 十字カーソルを円の上、左側に移動します。マーカーに「垂線」または「四半円点」と表示されます。ここでは同じ点です。クリックします。
16. {{key:Enter}}を押します。

新しい線は、左辺の中点から始まり、円上でぴったり止まります。

## 1回のクリックだけスナップを無効にする

クリックしながら{{key:Shift}}を押します。そのクリックではオブジェクトスナップが無視され、点はカーソルの位置に配置されます（直交がオンなら、直交の方向に配置されます）。

## 直交

{{ui:直交}}（{{key:F8}}）は、次の点を基点から水平方向または垂直方向に、まっすぐ保ちます。これはクリックと、直接距離の入力（プロンプトに入力した数値だけ）に適用されます。オブジェクトスナップは直交より優先されます。スナップマーカーが表示されている場合は、クリックはそのスナップに対して行われます。

## 極トラッキング

{{ui:極}}（{{key:F10}}）は、より多くの角度で直交する機能です。コマンドに基点（線分の最後の点、移動の基点など）がある間、ポインターが、極ステップの倍数の角度で、その基点から伸びる線に近づくと、ポインターがその線に合います。点線が表示され、十字カーソルの横のラベルに`極: 1200 < 30°`のように表示されます。クリックしてその点を使うか、距離を入力します。`1200`と入力すると、その線に沿って正確に 1200 進みます。

ステップは、変更するまで 90° です。{{cmd:POLARANG}}と入力して{{key:Enter}}を押し、`30`（または 45、22.5、15 …）と入力します。極と直交は同時に使えません。一方をオンにすると、もう一方はオフになります。

## オブジェクトスナップトラッキング

{{ui:トラック}}（{{key:F11}}）は、ポインターを、止めたスナップ点に合わせます。そのため、補助線を描かなくても、ある角と同じ高さで、別の角の真上にある点を指定できます。

1. {{ui:スナップ}}と{{ui:トラック}}をオンにし、点を尋ねるコマンドを開始します（`L`）。
2. 角などのスナップ点の上で、クリックせずにポインターを約0.5秒止めます。小さな十字が表示され、その点が取得されます。もう一度その上で止めると、取得が解除されます。
3. ポインターを、その点から水平または垂直にまっすぐ離します。点線がポインターに従い、ラベルに`トラック: 600 < 90°`と表示されます。クリックするか、距離を入力します。
4. 2つ目の点を取得し、一方の点を通る垂直線と、もう一方の点を通る水平線が交わる位置に移動します。ポインターがその交点にスナップします（`トラック: 2本の線の交点`）。

{{ui:極}}もオンにすると、取得した点は、すべての極角度で追跡されます。コマンドが終わるまで、最大7つの点が保持されます。{{key:Shift}}を押すと、スナップと同様に、1回のクリックでトラッキングが無効になります。

## グリッド

{{ui:グリッド}}（{{key:F7}}）は、図面の背後にグリッド線を表示します。5本ごとに太い線になります。間隔はズームに応じて変わります。{{ui:グリッドスナップ}}（{{key:F9}}）をオンにするまでは、目安にすぎません。オンにすると、オブジェクトスナップが先に点を取らない限り、クリックは最も近いグリッド点に配置されます。

## お使いのコンピューターのファンクションキー

{{key:F9}}は{{ui:グリッドスナップ}}、{{key:F10}}は{{ui:極}}、{{key:F11}}は{{ui:トラック}}です。

:::mac
Mac では、F3、F7、F8、F9 は通常、Mission Control やメディアを操作します。**fn**を押しながらそのキーを押すか、標準のファンクションキーをオンにしてください（[キー、マウス、トラックパッド](common:keys) を参照）。ステータスバーのボタンは、常に動作します。
:::

:::firefox
Firefox では、F7 はキャレットブラウズのキーでもあります。Firefox がキャレットブラウズをオンにするかどうか尋ねたら、**いいえ**を選んでください。この質問が繰り返し表示される場合は、{{ui:グリッド}}ボタンを使ってください。
:::

:::touch
タッチスクリーンでは、ホバーがないため、スナップマーカーは指が触れた位置にのみ表示されます。小さな対象には、拡大して近づくか、座標を入力してください。
:::

## よくある間違い

- **クリックした位置が違う点になった。** クリックする前に、マーカーのラベルを確認してください。両方が近くにある場合は、端点が中点より優先されます。拡大するか、必要のないスナップを解除してください。
- **マーカーが表示されない。** {{ui:スナップ}}がオフであるか、必要なスナップが解除されているか、オブジェクトが非表示またはフリーズされたレイヤー上にあります。
- **込み入った図面で、スナップが違うものを拾う。** 拡大してください。スナップの距離は画面のピクセル単位で測られるため、拡大すると図面上では小さくなります。
- **Shift で直線になると思った。** CadCraft では、Shift は1回のクリックでスナップを無効にします。直線には{{ui:直交}}を使ってください。
- **点がグリッド点に合うと思った。** {{ui:グリッドスナップ}}（{{key:F9}}）をオンにするか、切りのよい数値を座標で入力してください。
