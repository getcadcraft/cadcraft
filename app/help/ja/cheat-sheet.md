短い名前(エイリアス)を入力してEnterキーを押すか、ツールをクリックします。Escキーで取り消します。空のコマンドラインでEnterキーを押すと、直前のコマンドを繰り返します。

**印刷する:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf)(A4で1ページ。Letter用紙では「用紙に合わせる」を選んで印刷します)。

## 作図

| 入力 | コマンド | 内容 |
|---|---|---|
| `L` | {{cmd:LINE}} | 直線を描く |
| `PL` | {{cmd:PLINE}} | つながった線分と円弧の連なりを描く |
| `C` | {{cmd:CIRCLE}} | 円を描く(中心と半径) |
| `A` | {{cmd:ARC}} | 円弧を描く |
| `REC` | {{cmd:RECTANG}} | 2つの角から長方形を描く |
| `POL` | {{cmd:POLYGON}} | 正多角形を描く |
| `EL` | {{cmd:ELLIPSE}} | 楕円を描く |
| `DT` | {{cmd:TEXT}} | 1行の文字を記入する |
| `T` | {{cmd:MTEXT}} | 折り返される文字(段落)を記入する |
| `H` | {{cmd:HATCH}} | 領域をパターンで塗る |

## 修正

| 入力 | コマンド | 内容 |
|---|---|---|
| `M` | {{cmd:MOVE}} | オブジェクトを移動する |
| `CO` | {{cmd:COPY}} | オブジェクトをコピーする |
| `RO` | {{cmd:ROTATE}} | 点を中心にオブジェクトを回転する |
| `SC` | {{cmd:SCALE}} | オブジェクトを拡大または縮小する |
| `MI` | {{cmd:MIRROR}} | 線を軸にオブジェクトを反転する |
| `O` | {{cmd:OFFSET}} | 指定した距離に平行なコピーを描く |
| `TR` | {{cmd:TRIM}} | 他のオブジェクトと交差する位置までオブジェクトを切り取る |
| `EX` | {{cmd:EXTEND}} | オブジェクトを他のオブジェクトまで延長する |
| `F` | {{cmd:FILLET}} | 角を円弧で丸める |
| `CHA` | {{cmd:CHAMFER}} | 角を直線で面取りする |
| `E` | {{cmd:ERASE}} | オブジェクトを削除する |
| `X` | {{cmd:EXPLODE}} | ブロックやポリラインを部品に分解する |
| `S` | {{cmd:STRETCH}} | 交差選択の範囲内の端点を移動する |
| `AR` | {{cmd:ARRAY}} | 格子状または円形にコピーする |
| `J` | {{cmd:JOIN}} | 線分と円弧を1つのオブジェクトに結合する |
| `BR` | {{cmd:BREAK}} | オブジェクトを2つに分割する、または一部を取り除く |

## 寸法

| 入力 | コマンド | 内容 |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | 水平または垂直に寸法を記入する |
| `DAL` | {{cmd:DIMALIGNED}} | 斜めの線に沿って寸法を記入する |
| `DRA` | {{cmd:DIMRADIUS}} | 半径を記入する |
| `DAN` | {{cmd:DIMANGULAR}} | 角度を記入する |

## ブロックとレイヤー

| 入力 | コマンド | 内容 |
|---|---|---|
| `B` | {{cmd:BLOCK}} | オブジェクトからブロックを作成する |
| `I` | {{cmd:INSERT}} | ブロックを配置する |
| `LA` | {{cmd:LAYER}} | レイヤーを開く |

## 表示と照会

| 入力 | コマンド | 内容 |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | 拡大、縮小、または全体表示(E) |
| `DI` | {{cmd:DIST}} | 距離と角度を計測する |
| `LI` | {{cmd:LIST}} | オブジェクトの詳細を表示する |
| `MA` | {{cmd:MATCHPROP}} | 1つのオブジェクトの見た目を他のオブジェクトにコピーする |

## ファイル

| 入力 | コマンド | 内容 |
|---|---|---|
| `U` | {{cmd:UNDO}} | 直前のコマンドを元に戻す |
| `SAVE` | {{cmd:SAVE}} | 図面を保存する |
| `PLOT` | {{cmd:PLOT}} | PDFに印刷する |

## キー

Ctrl(MacではCmd): Z元に戻す · Yやり直し · S保存 · P印刷。F3オブジェクトスナップ · F8直交モード · F10極トラッキング。SpaceキーまたはEnterキーで直前のコマンドを繰り返す · ホイールでズーム · ホイールをドラッグしてパン

作図は初めてですか? `TOUR` と入力すると、最初の図面をガイドに沿って作成できます。[はじめに](topic:getting-started)を読むか、[コマンド](topic:commands)ですべてのコマンドを確認してください。ほかの作図ソフトから移行する場合: [ほかの作図ソフトから移行する場合](topic:coming-from)と[コマンド対応表](topic:command-map)。
