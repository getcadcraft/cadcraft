CadCraftでは、他の製図プログラムで知られているコマンド名と短い名前をそのまま使えます。線分には`L`、トリムには`TR`、消去には`E`と入力します。そのため、多くのコマンドについて覚える対応表はありません。知っている名前が、ここでもそのまま使えます。以下の一覧は、プログラム自体から作成した、CadCraftのすべてのコマンドです。{{key:Enter}}キーで直前のコマンドを繰り返します。コマンドラインで`HELP`と入力すると、同じ一覧が表示されます。

異なるもの、または未作成のものは次のとおりです:

- **保存**はブラウザーでコピーをダウンロードします({{cmd:SAVE}}、{{cmd:SAVEAS}})。CadCraft Studioではファイルに書き込みます。[他の製図ソフトからの移行](topic:coming-from)を参照してください。
- **PLOT**は、印刷スタイルテーブルを使ってPDFを作成します(PNGとSVGも可能です)。ページ設定マネージャーはありません。
- **DIMSTYLE**と**PEDIT**は作成済みです。**PEDIT**には頂点を編集のオプションはありません(グリップで行います)。
- **TABLE**は未作成です。{{cmd:XREF}}、{{cmd:SPLINE}}、{{cmd:WBLOCK}}は作成済みです。
- ルーチン独自のコマンド(AutoLISPの`C:NAME`)は、{{cmd:APPLOAD}}で読み込むと表示されます。ここには掲載していません。

| `WINDOW` | `WN` | 壁に窓を配置する。 |
| `XATTACH` | `XA` | 別のDWGまたはDXFをこの図面にリンクし、読み取り専用で表示(XREFで一覧と再読み込み) |
| `XCLIP` | `XC` | ブロック参照とリンクされた図面を矩形または多角形でクリップ、またはクリップを取り除く。 |
| `XLINE` | `XL` | 構築線、両方向に無限: 2点を通る、水平、垂直、角度指定、角の二等分、または線からのオフセット。 |
| `XREF` | `XR`, `-XREF` | リンクされた図面(外部参照): 一覧、添付、再読み込み、バインド、取り外し |
| `ZOOM` | `Z` | 範囲、または窓 |
