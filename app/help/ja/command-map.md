CadCraft は、他の製図ソフトで使われているコマンド名と短縮名をそのまま採用しています。線分を描くには `L`、トリムするには `TR`、削除するには `E` と入力します。そのため、ほとんどのコマンドについて覚えるべき対応表はありません。知っている名前がそのまま使えます。以下の一覧は、CadCraft のすべてのコマンドを本体から自動的に作成したものです。{{key:Enter}}を押すと直前のコマンドを繰り返します。コマンドラインで `HELP` と入力すると、同じ一覧が表示されます。

動作が異なるもの、またはまだ作成されていないものは次のとおりです:

- **保存**はブラウザーでコピーをダウンロードします ({{cmd:SAVE}}、{{cmd:SAVEAS}})。CadCraft Studio では、ファイルに保存します。[他の製図ソフトからの移行](topic:coming-from)も参照してください。
- **PLOT** は PDF を作成します (PNG と SVG にも対応)。印刷スタイルテーブルを使用します。ページ設定マネージャーはありません。
- **DIMSTYLE** と **PEDIT** は利用できます。**PEDIT** には頂点の編集オプションはありません (グリップで行います)。
- **TABLE** はまだ作成されていません。{{cmd:XREF}}、{{cmd:SPLINE}}、{{cmd:WBLOCK}} は利用できます。
- ルーチン独自のコマンド (AutoLISP の `C:NAME`) は、{{cmd:APPLOAD}} で読み込んだ後に表示されます。ここには掲載していません。

| `WALLSPLITGAP` |  | 隙間を残して壁を分割します: 隙間を入力し、壁を指定してから点を指定します。部分は自由端を保持し、再び結合できます。 |

| `WALLTRACE` |  | クリックした点の周りにある、線と壁で囲まれた最小の閉じた領域の周りに壁を作成します。 |
| `WALLUNHOLD` |  | 壁のロックを解除します (他の壁との間のロックも解除されます)。 |
| `WBLOCK` | `W`, `-WBLOCK` | ブロック、一部のオブジェクト、または図面全体を新しい DWG または DXF ファイルに書き出します (W) |
| `WEDGE` | `WE` | くさび: 2つの角と高さ。最初の角から傾斜します (3D) |
| `WHEREAMI` | `WHERE` | カーソルの位置を読み上げます。 |
