ショートカットは、お使いのコンピューターに合わせて表示されています。Mac では、以下のすべての {{key:Mod}} ショートカットが Command キーを使用します。Control キーも使用できます。キーの表記方法と、Mac で F キーを使用する方法は、[キー、マウス、トラックパッド](common:keys)を参照してください。

## コマンドの入力

| キー | 動作 |
|---|---|
| 任意の文字、数字、記号 | ポインターの位置に関係なくコマンドラインに入力されます。ただし、パネル内の欄にカーソルがある場合は除きます |
| {{key:Enter}} | 入力内容を送信します。空のプロンプトでは、直前のコマンドを繰り返す、コマンドを終了する、選択を完了する、または `<…>` の既定値を確定します |
| {{key:Space}} | {{key:Enter}} と同じですが、テキスト（文字、ブロック名、寸法の文字）を入力中は空白を入力します |
| {{key:Esc}} | コマンドをキャンセルします。コマンドが実行されていない場合は、グリップの移動または選択枠をキャンセルし、その後選択を解除します |
| {{key:Tab}} | コマンドラインの右側に表示されている候補のコマンドを確定します。何も入力されておらず、ポインターが重なったオブジェクト上にある場合は、そこで次のオブジェクトを強調表示します（クリックして選択）|
| {{key:Up}} {{key:Down}} | 以前入力した行（直近100行）を順番に表示します |

## 作図と編集

| キー | 動作 |
|---|---|
| {{key:Mod+Z}} | 直前のコマンドを元に戻します |
| {{key:Mod+Y}} または {{key:Mod+Shift+Z}} | やり直し |
| {{key:Mod+A}} | 開いているタブの編集可能なすべてのオブジェクトを選択します（{{cmd:SELECTALL}}）。コマンドラインに何か入力されている場合は、その入力テキストを選択します |
| {{key:Delete}} | 選択したオブジェクトを削除します（{{cmd:ERASE}}）。ただし、コマンドラインに入力がある場合は除きます |
| {{key:Backspace}} | コマンドラインにカーソルがない場合は、選択したオブジェクトを削除します。コマンドラインにある場合は、入力した文字を削除します |
| {{key:Esc}} | コマンドが実行されていない場合、選択を解除します（{{cmd:DESELECT}}）|
| {{key:Mod+S}} | 図面の形式（DWG または DXF）でコピーを保存します |
| {{key:Mod+Shift+S}} | 名前を付けて保存: DWG または DXF を選択してから、コピーを保存します |
| {{key:Mod+O}} | DWG または DXF を開きます |
| {{key:Mod+P}} | PDFに印刷します |

コマンドの実行中は、元に戻す、やり直し、すべて選択、印刷は動作しません。先に {{key:Esc}} を押してください。

## コピー、切り取り、貼り付け

| キー | 動作 |
|---|---|
| {{key:Mod+C}} | 選択範囲をクリップボードにコピーします（{{cmd:COPYCLIP}}）。何も選択されていない場合は、CadCraft がオブジェクトの選択を求めます |
| {{key:Mod+X}} | 切り取り: 選択範囲をコピーしてから削除します（{{cmd:CUTCLIP}}）|
| {{key:Mod+V}} | 貼り付け: コピーがポインターに追従します。クリックするか、点を入力して配置します（{{cmd:PASTECLIP}}）|
| {{key:Mod+Shift+V}} | 同じ位置に貼り付け: コピー元の座標に貼り付けます（{{cmd:PASTEORIG}}）|
| {{key:Mod+D}} | 複製: 選択範囲のコピーがポインターとともに移動します。クリックして配置します。{{key:Esc}} を押すと何も作成されません（{{cmd:DUPLICATE}}）|

同じ操作は、ツールバーの {{ui:編集}} グループ（{{ui:コピー}}、{{ui:貼り付け}}）と {{ui:その他}} メニューにもあります。別のコマンドが実行中の場合は、先にそのコマンドを完了するか、{{key:Esc}} を押してください。コピーがポインターに追従している間に {{key:Mod+V}} または {{key:Mod+D}} をもう一度押すと、最初からやり直します。コマンドラインに入力がある場合、またはコマンドがテキストを要求している場合は、これらのキーがそのテキストをコピー、切り取り、貼り付けします。[コピー、貼り付け、複製](topic:copy-paste)を参照してください。

## 切り替え

| キー | 切り替え | ステータスバーのボタン |
|---|---|---|
| {{key:F3}} | オブジェクトスナップのオン/オフ | {{ui:スナップ}} |
| {{key:F7}} | グリッドのオン/オフ | {{ui:グリッド}} |
| {{key:F8}} | 直交モードのオン/オフ | {{ui:直交}} |
| {{key:F10}} | 極トラッキングのオン/オフ | {{ui:極}} |
| {{key:F11}} | オブジェクトスナップトラッキングのオン/オフ | {{ui:トラック}} |
| {{key:F12}} | 動的入力のオン/オフ | {{ui:動的}} |

:::mac
Mac では、F3、F7、F8 は通常、Mission Control とメディアキーとして動作します。これらのキーとともに **fn** を押すか、システム設定で標準のファンクションキーを有効にしてください（[キー、マウス、トラックパッド](common:keys)を参照）。ステータスバーのボタンは常に動作します。
:::

:::firefox
Firefox では、F7 でキャレットブラウズを有効にするかどうかを尋ねられることがあります。**いいえ** を選択してください。繰り返し尋ねられる場合は、{{ui:グリッド}} ボタンを使用してください。
:::

## ヘルプ

| キー | 動作 |
|---|---|
| {{key:F1}} | このヘルプを図面の横に開く、または閉じます。コマンドの実行中でも動作し、コマンドラインには送られません。 |
| {{key:Esc}} | ヘルプパネルにカーソルがある場合: 検索をクリアするか、パネルを閉じます |

上部のバーにある {{ui:ヘルプ}} ボタンは、{{key:F1}} と同じ動作をします。ヘルプの検索ボックスに入力している間は、キー入力がコマンドラインに送られません。図面をクリックすると、キー入力が CadCraft に戻ります。パネルは図面の横に開いたままです。

:::mac
Mac キーボードでは、**fn** を押しながら F1 を押すか、{{ui:ヘルプ}} をクリックしてください。
:::

## 画面

| キー | 動作 |
|---|---|
| {{key:Ctrl+Shift+F}} | 通常、全画面、バーを非表示にした全画面の順に切り替えます。どのコンピューター（Mac を含む）でも Control キーを使用します。 |
| {{key:Left}} {{key:Right}} | 図面の下のタブにフォーカスがある場合: 前のタブまたは次のタブ |

全画面表示では、ブラウザーが最初の {{key:Esc}} で全画面表示を終了する場合があります。コマンドをキャンセルするには、もう一度 {{key:Esc}} を押してください。

## ダイアログ

| キー | 動作 |
|---|---|
| {{key:Esc}} | ダイアログを閉じます（{{ui:PDFに印刷}}、または「保存されていない変更」などの確認では、{{ui:キャンセル}} を意味します）|
| {{key:Tab}} | ダイアログの設定とボタンの間を移動します |

ダイアログが開いている間は、図面のキー操作が無効になります。

## パネルの欄

右側または左側のパネルの欄では:

| キー | 動作 |
|---|---|
| {{key:Enter}} | 値を適用し、欄から出ます |
| {{key:Esc}} | 元の値に戻し、欄から出ます |
| {{key:Tab}} | 適用して次の欄に移動します |

欄にカーソルがある間は、文字はコマンドラインではなく欄に入力されます。

## マウス

| 操作 | 動作 |
|---|---|
| クリック | コマンドが点を求めている場合は点を指定します。オブジェクトを求めている場合はオブジェクトを選択します。それ以外の場合は、オブジェクトまたはグリップを選択します |
| {{key:Shift}}+クリック | 選択済みのオブジェクトを選択範囲から除外します（[設定](topic:settings)で {{ui:オブジェクトのクリック}} を {{ui:選択を置き換え}} に設定している場合は追加します）。点を指定中: そのクリックではオブジェクトスナップを無視します |
| 空白部分をクリックし、再度クリック | 選択枠。左から右は窓選択、右から左は交差選択です |
| 空白部分をドラッグ | 投げ縄。右に動かすと窓選択、左に動かすと交差選択です。ドラッグ中に {{key:Space}} を押すと、窓、交差、フェンスの順に切り替わります。{{key:Esc}} で投げ縄を解除します（LASSOMODE 0、または設定で、長方形に戻ります）|
| TRIM または EXTEND 中に部分をドラッグ | 経路が横切るすべての部分をトリム（または延長）します。もう一方の動作には {{key:Shift}} を押したままにします |
| グリップをドラッグ | グリップを移動します（またはグリップをクリックしてから移動先をクリックします）|
| 文字をダブルクリック | 文字を選択し、右側のパネルの {{ui:文字}} 欄にカーソルを置きます |
| 右クリック | {{key:Enter}} と同じです。グリップの移動または選択枠の間は、それをキャンセルします |
| 右ボタンでドラッグ | パン |
| ホイール | 十字カーソルの位置を中心にズームイン・ズームアウトします |
| ホイールを押したままドラッグ（中ボタン） | パン |
| ホイールをダブルクリック | 図面全体にズームします（範囲）|
| 図面に DWG または DXF をドロップ | 開きます |

トラックパッドまたはタッチスクリーンについては、[マウス、トラックパッド、タッチ](topic:mouse-trackpad-touch)を参照してください。

## ブラウザーが保持するキー

{{key:Mod+N}}、{{key:Mod+W}}、{{key:Mod+T}} は常にブラウザーのものです。CadCraft では使用しません。新しい図面には {{ui:新規}} を使用するか、`NEW` と入力してください。CadCraft のクリップボードは独自のものです。{{key:Mod+C}} と {{key:Mod+V}} は、CadCraft の図面やタブの間でオブジェクトをコピーします。他のプログラムとの間ではコピーしません。

:::mac
{{key:Mod+Y}} でやり直しではなくブラウザーの履歴が開く場合は、{{key:Mod+Shift+Z}} または {{ui:やり直し}} ボタンを使用してください。
:::

## 移動の場所

移動はコマンド `MOVE`（キー {{key:M}}）です。オブジェクトを選択し、基点と2点目、または入力した距離を指定します。`ALIGN` と `DISTRIBUTE` もあります。BimCraft も建築要素に対して同じ名前を同じ作業に使用しますが、BimCraft の {{key:M}} は計測であり、移動は {{key:Shift+M}} です。
