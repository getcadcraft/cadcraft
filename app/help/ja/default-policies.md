## この項目で行うこと

新規図面が最初にどの設定を使うかを CadCraft に指定します。こうすると、事務所の誰もが毎回 UNITS を実行して同じ項目を変更する必要がなくなります。この機能はアドオンです。オンにするまで無効になっています。ポリシーを設定しない場合は、CadCraft 独自の既定値がそのまま使われます。

:::note
これらは**新規**の図面と**新規**のシートの既定値です。すでに作業を始めている図面は変更されません。開いただけの図面も変更されません。
:::

## 手順

1. 設定を開き、{{ui:アドオン}} に進んで {{ui:既定のポリシー}} をオンにします。
2. 設定で **CadCraft** タブを開き、左の一覧から {{ui:既定のポリシー}} を選びます。
3. 必要なポリシーを設定します。各項目は **CadCraft の既定値** から始まります。**メートル法** と **inch 系** のボックスがあるポリシーは、図面の種類ごとに値を一つずつ指定します。必要なものだけに入力します。
4. 保存ボタンはありません。変更するたびに自動的に保存されます。
5. 新規図面を開始します。設定した単位、長さの形式、精度、文字の高さになり、最初の新規シートは選んだ用紙になります。

## ポリシーの項目

- **新規図面の単位**: なし、ミリメートル、センチメートル、メートル、インチ、フィートのいずれか。
- **長さの形式** と **長さの精度**: 新規図面で UNITS コマンドが設定する内容です。
- **新規文字の高さ**（図面の単位）。
- **新規シートの用紙**: 新規シートが使う用紙です。
- **用紙上の注釈サイズ**（設定 › グローバル › 既定のポリシー）: 印刷上の注釈の高さをミリメートルで指定します。CadCraft は注釈とラベルにこの値を使います。{{cmd:ANNOSCALE}} は、注釈尺度でこの高さになるように新規文字の高さを設定します。[単位、用紙、尺度](topic:units-papers-scales#annotate-by-scale)を参照してください。

inch またはフィートの図面には inch 系の値が、それ以外の図面にはメートル法の値が使われます。単位が設定されていない図面は、設定 › グローバル › 既定のポリシーで指定した単位系を使います。指定がない場合はメートル法になります。

## 事務所全体で共有する

1. 設定で **グローバル** タブを開き、{{ui:既定のポリシー}} を選びます。
2. {{ui:ファイルに保存}} をクリックします。拡張子 `.ccdefaults.json` の小さなファイルが作成されます。
3. 別のコンピューターでアドオンをオンにし、同じ場所を開いて {{ui:ファイルから読み込む}} をクリックします。ファイルのポリシーが、そのコンピューターの既存のポリシーを置き換えます。

一つのファイルにすべての CadCraft アプリのポリシーが含まれるため、同じファイルを BimCraft でも使えます。

## 知っておくと便利な点

- シートの尺度に関するポリシーはありません。新規シートのビューは図面に合わせて表示され、尺度はシート上で設定します。
- 寸法スタイルに関するポリシーはありません。新規図面には名前付きの寸法スタイルはありません。寸法は DIMSTYLE で設定するか、寸法スタイルを持つ図面から始めてください。
- ファイルは通常のテキスト形式の JSON です。このバージョンが認識しないポリシーは読み込まれず、メッセージでその名前が表示されます。残りのポリシーは読み込まれます。
- ポリシーは図面ではなく、このブラウザーに保存されます。アドオンをオフにすると、すべての設定が CadCraft の既定値に戻ります。
