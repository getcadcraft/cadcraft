## 学習内容

LISP ルーチン (`.lsp` ファイル) を読み込んで、CadCraft でそのコマンドを使えるようにする方法、アンロードする方法、そして CadCraft の起動時に毎回読み込まれるようにする方法を説明します。

## ルーチンを読み込む

1. {{ui:View}} › {{ui:More}} › {{ui:Load application…}} を開くか、{{cmd:APPLOAD}} (または `AP`) と入力して {{key:Enter}} を押します。
2. {{ui:Load a file…}} をクリックし、1 つ以上の `.lsp` ファイルを選びます。ダイアログを開くルーチンには通常 `.dcl` ファイルが付属します。そのファイルも選んでください。
3. ダイアログには、各ファイルが作成したものが表示されます (例: 「delblocks.lsp を読み込みました: コマンド 1 件、DELBLOCKS」)。
4. {{ui:Close}} をクリックし、ルーチンのコマンドを入力して {{key:Enter}} を押します。

`.lsp` と `.dcl` ファイルを図面上、または {{ui:Load applications}} ダイアログにドロップすることもできます。その場合はすぐに読み込まれます。

ファイルはここでブラウザー内で読み込まれます。何もアップロードされません。

:::tip
空のコマンドラインで {{key:Enter}} を押すと、ほかのコマンドと同じように、ルーチンのコマンドを再実行できます。コマンドのエイリアスからも実行できます。「コマンドのエイリアスの編集」を参照してください。
:::

## ルーチンをアンロードする

{{ui:Load applications}} の {{ui:Loaded applications}} で、ファイルの横にある {{ui:Unload}} をクリックします。そのファイルが作成したコマンドは、再度読み込むまで使えなくなります。

## CadCraft の起動時に毎回ルーチンを読み込む

1. ルーチンを読み込みます。
2. {{ui:Loaded applications}} で、ルーチンの横にある {{ui:Add to Startup Suite}} をクリックします。

このブラウザーで CadCraft を起動するたびに、自動的に読み込まれます。停止するには、{{ui:Startup Suite}} の下にあるルーチンの横の {{ui:Remove}} をクリックします。

スタートアップスイートには、各ファイルのコピーがこのブラウザーの保存領域に保持されます。ルーチンを変更した場合は、新しいファイルを読み込み、もう一度追加してください。

## サポートフォルダーから acad.lsp と acaddoc.lsp を読み込む (Studio)

CadCraft Studio では、{{ui:Load applications}} ダイアログの {{ui:Support folder}} で、お使いのコンピューター上のフォルダーを指定できます。{{ui:Choose folder…}} をクリックします。CadCraft の起動時に、そのフォルダーから `acad.lsp` を読み込み、続けて `acaddoc.lsp` を読み込み (名前の大文字・小文字は問いません)、それらを読み込んでから、スタートアップスイートを読み込みます。`acaddoc.lsp` は新しい図面のタブが開くたびに再読み込みされます。ほかのファイルは読み込まれず、2 MB を超えるファイルはメッセージを表示してスキップされます。

ファイルが `S::STARTUP` という名前の関数を定義している場合は、ファイルの読み込み後 (スタートアップスイートの後も) に 1 回実行されます。{{ui:Load now}} を押すと、要求に応じて同じ処理が実行されます。{{ui:Clear}} を押すと、フォルダーの記録が消去されます。

ブラウザーでは、ページはフォルダーを保持できないため、サポートフォルダーはありません。上記のスタートアップスイートを使用してください。コンパイル済みの `.fas` と `.vlx` ファイル、およびネイティブプログラムは、引き続き読み込みが拒否されます。

## 履歴からファイルを読み込み直す

{{ui:History}} には、このブラウザーで読み込んだファイルが新しい順に表示されます。いずれかの横にある {{ui:Load}} をクリックすると、コンピューター上で探さなくても再度読み込めます。

## CadCraft で読み込めないファイル

| ファイル | 種類 | 対処方法 |
|---|---|---|
| `.fas`、`.vlx` | コンパイル済みまたは保護された LISP | 代わりに `.lsp` のソースを読み込んでください |
| `.arx`、`.crx`、`.dbx` | ネイティブの Windows プログラム | CadCraft では実行できません |
| `.dvb` | VBA プロジェクト | CadCraft では実行できません |
| `.craft`、`.lua`、`.py` | CraftScript スクリプト | PartCraft のスクリプトワークスペースで開いてください |

{{ui:Load applications}} ダイアログでファイルを選ぶと、そのファイルがどれに該当するかが表示されます。

## ルーチンを停止する

{{key:Esc}} を押します。ルーチンの入力待ちプロンプトで Esc を押すと、ルーチンが想定している方法でキャンセルされます (後処理が実行されます)。ルーチンが処理中で何も要求していない場合、Esc は即座に停止し、その旨を表示します。読み込み済みのルーチンは読み込まれたままです。

:::note
ルーチンが図面に加えた変更はすべて 1 つの操作になり、{{key:Mod+Z}} を 1 回押すとすべて元に戻せます。
:::
