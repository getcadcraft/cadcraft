## 点

点を求められたら、次のいずれかを入力して {{key:Enter}} を押します。

| 入力 | 意味 | 例 |
|---|---|---|
| `x,y` | 絶対座標: 原点 0,0 からの位置 | `2500,1200` |
| `#x,y` | 同じく絶対座標（慣例として使えます） | `#2500,1200` |
| `@dx,dy` | 相対座標: 最後の点から横と上方向への位置 | `@600,0` |
| `@d<a` | 相対極座標: 最後の点からの距離と角度 | `@1500<45` |
| `d<a` | 絶対極座標: 原点からの距離と角度 | `3000<90` |
| 数値 1 つ | 直接距離: 基点から十字カーソルの方向にその距離 | `1200` |
| `*x,y`, `@*dx,dy` | UCS が設定されているときのワールド座標 | `*0,0` |

{{cmd:UCS}} が設定されているとき、`x,y`、`@dx,dy` および `d<a` の角度は UCS の軸に沿って測られます。[表示を回転して独自の座標を使う](topic:ucs-and-turned-view)を参照してください。

または、図面内をクリックします。オブジェクトスナップと直交モードはクリックに適用されます。

規則:

- コンマは X と Y を区切ります。小数点にはピリオドを使います: `1250.75,300`。
- 負の値は左と下に向かいます: `@-600,0`。
- スペースは入力しないでください。{{key:Space}} は {{key:Enter}} と同様に入力を確定します。
- 指数表記が使えます: `1e3` は 1000 です。
- 単位は入力しません。フィートとインチの表記も使えません。図面の単位で数値だけを入力します。

## 最後の点

`@` は、**任意のコマンドの任意の点プロンプトで最後に指定した点**から数えます。クリック、スナップ、入力した点のいずれも含みます。コマンドをまたいで記憶されるため、直前の線の終点から `@0,500` 離れた位置に新しい線を始められます。点をまだ指定していない場合、`@` は 0,0 から数えます。

次のような場面で重要になります:

- {{cmd:COPY}} では、最初の複写の後、最後の点はその複写の点になります。`@600,0` を 2 回入力すると、元のオブジェクトから 600 と 1200 離れた位置に複写が配置されます。
- 寸法を配置した後、最後の点は寸法線を配置した位置であり、寸法の端点ではありません。

迷ったときは、絶対座標、スナップ、または直接距離を使ってください。

## 直接距離の入力

数値だけを入力すると、コマンドの**基点**（ラバーバンドが始まる点）から十字カーソルの方向への距離になります。

1. 十字カーソルを目的の方向に動かします。
2. 距離を入力して {{key:Enter}} を押します。

{{ui:直交}} が有効なとき、方向は水平または垂直に固定されるため、正方形の壁を描く最も速い方法になります。基点がない場合、または十字カーソルがちょうど基点の上にある場合、数値は「点またはオプションのキーワードが必要です。」というメッセージとともに受け付けられません。

## 角度

- 度単位で、数値だけを入力します: `30`、`-45`、`112.5`。
- X の正の方向（右向き）から反時計回りに測ります。0 は右、90 は上、180 は左、270 または -90 は下です。
- 角度が求められる場合（回転、文字の角度）は、クリックでも指定できます。角度は基点からクリック位置までで測られます。基点がまだない場合、最初のクリックで基点が設定され、プロンプトは 2 点目を求めます。

## 距離

距離が求められる場合（半径、オフセット、文字の高さ、尺度係数）:

- 正の数を入力します（フィートとインチの図面では `12'6"` や `6-1/2` も入力できます。[フィートとインチ](topic:units-papers-scales#feet-and-inches-and-fractions)を参照してください）、または
- 点をクリックします: コマンドの基点からその点までの距離になります、または
- 基点がない場合は 2 点をクリックします: プロンプトが `2点目を指定` に変わります。

「正の数または 2 点が必要です。」は、値が数値でなかったか、負の値だったことを意味します。

## 入力値の計算

長さ、座標、角度、数値を入力するところならどこでも（コマンドライン、動的入力、プロパティのボックス、ダイアログ）、事前に計算しなくても、`+`、`-`、`*`、`/` と括弧を使って計算式を入力できます:

| 入力 | 結果 |
|---|---|
| `4+7/16` | 4.4375 |
| `12'6"+3/4"` | 12'-6 3/4"（フィートとインチの図面の場合） |
| `(24'-0")/3` | 8'-0" |
| `2*450mm` | 900 mm（図面の単位が設定されている場合、図面の単位で） |
| `@4+7/16,0` | 最後の点から右へ 4.4375 離れた点 |
| `360/7` | 51.43 度の角度 |

- 長さに書かれたダッシュは長さの一部のままです: `4-7/16` は 4 7/16、`24'-6"` は 24 フィート 6 インチです。フィートの記号の後で引き算するには、先に長さを終えてください（`24'-0"-6"`）。または、計算を括弧で囲み、ダッシュの前後にスペースを入れてください（`(24' - 6")`。括弧の中ではスペースはスペースとして扱われます。それ以外の場所では {{key:Enter}} を押したことになります）。
- 長さに数値を加えると、その数値は図面の単位として扱われます。長さに数値を掛けたり割ったりすると、長さが拡大縮小されます。2 つの長さを掛けると面積になるため、`2'*3'` は受け付けられません。
- `abs`、`round`、`ceil`、`floor` も使えます: `round(10/3)`。
- 読み取れない計算は、どこで誤ったかとともに拒否されます。例: 「計算が途中で終わっています（3 文字目）: 値がありません。」 0 として読み取られることはありません。{{cmd:CAL}} は計算の値を表示します。

## 動的入力

{{ui:動的}}（{{key:F12}}、ステータスバー内）を有効にすると、コマンドが点を求めている間、十字カーソルの横に値が表示されます。

- 基点がまだない場合（線の最初の点）、2 つの欄は **X** と **Y** です。
- その後は、最後の点からの **距離** と **角度** になります。

入力はコマンドラインに送られます。十字カーソルの横の欄にその値が表示され、ラバーバンドもそれに従います。

1. 値を入力します: 強調表示されている欄に入ります。
2. {{key:Tab}} を押す（または X の後にコンマを入力する）と、値が確定し（太字で表示）、次の欄が強調表示されます。確定した距離は、マウスで狙いを定める間もラバーバンドをその長さに保ちます。
3. 2 つ目の値を入力する、またはマウスで狙いを定めてから、{{key:Enter}} を押します。`50`、{{key:Tab}}、`90`、{{key:Enter}} と入力すると、最後の点から真上に 50 描きます。

{{key:Tab}} を押さずに値を 1 つ入力して {{key:Enter}} を押すと、直接距離の入力として動作します。欄でもフィートとインチが使えます（`12'6"`）。円の半径や回転など、距離や角度のプロンプトでも、十字カーソルの横に値が表示されます。

## オプションと既定値

- オプションは角括弧で示されます。オプションの大文字を入力し（`[直径(D)]` の `D`、`[閉じる(C)]` の `CL`）、{{key:Enter}} を押します。単語の先頭部分を長く入力しても機能します（`DIA`）。
- 既定値は `<500>` のように山括弧で示されます。{{key:Enter}} を押すか右クリックすると、既定値が使われます。

## その他のキーボード配列とテンキー

コマンド名、短縮名、オプションの文字はラテン文字です。ギリシャ語、キリル文字（ロシア語、ウクライナ語、ベラルーシ語、セルビア語、マケドニア語、ブルガリア語）、ヘブライ語、アラビア語、ペルシア語、タイ語、韓国語の配列が有効な場合も、配列を切り替える必要はありません。入力した語がそのままではコマンド、短縮名、オプションでないとき、CadCraft はキーの押下に基づいて読み取ります。ラテン配列のキーボードで `L` と書かれたキーは、配列がそのキーに別の文字を割り当てていても、引き続き LINE を開始します。`C` キーも同様に、引き続き「閉じる」に応答します。コマンドラインの上に表示される一致するコマンドの一覧も、同じ規則に従います。コマンドがテキストを求める場所（{{cmd:TEXT}} の内容や名前）に入力したテキストは、決して変換されません。

キーパッドの小数点キーがコンマを入力する配列では、そのキーでコマンドラインと数値ボックスに点を入力できるため、テンキーで `12.5` を入力できます。メインキーボードのコンマキーは、引き続き `x,y` の区切りとして機能します。

どちらも {{ui:Settings}} でオフにできます: {{ui:Commands on a non-Latin keyboard layout}} と {{ui:Keypad decimal key}}。

## 座標の表示

ステータスバーには、スナップと直交モードを適用した後の十字カーソルの X と Y が表示されます（UCS が設定されている場合は UCS 上の値）。コマンドが基点を持つ間は、その点からの距離と角度を `Δ` とともに追加表示します（例: `Δ 1500 < 30°`）。これは `@1500<30` と入力する数値です。

{{cmd:ID}} を使うと点の座標を表示し、{{cmd:DIST}} を使うと 2 点間の距離を計測します。
