CadCraft はホイール付きマウスを使うことを前提に設計されています。トラックパッドでもすべての操作が可能ですが、いくつかの操作に慣れる必要があります。タッチスクリーンでは、制限はあるものの、オブジェクトの選択が可能です。

## ホイール付きマウス

- **ズーム:** ホイールを回します。図面は十字カーソルを中心にズームするため、見たい部分にカーソルを合わせてください。
- **パン:** ホイールを押したままドラッグするか、右ボタンでドラッグします。
- **すべてをズーム:** ホイールをダブルクリックするか、{{ui:Extents}}をクリックします。
- **前の表示に戻る:** 表示グループの{{ui:Previous}}をクリックするか、`Z`、{{key:Enter}}、`P`、{{key:Enter}}と入力します。連続したホイール操作は1回の表示として扱われるため、{{ui:Previous}}を1回押すと、まとめて元に戻ります。繰り返し使う表示は、{{cmd:NAMEDVIEW}}（`NV`）で保存してください。
- **Enter:** 右クリックします。

## トラックパッド

:::mac
- **パン:** トラックパッド上で2本指を任意の方向に動かします。図面は指に追従します。2本指でクリックしたまま、ドラッグすることもできます（右ボタンでのドラッグ）。
- **ズーム:** 2本指でピンチします。ズームは十字カーソルに従います。
- **右クリック（Enter）:** 2本指でクリックします。動作しない場合は、**システム設定**、次に**トラックパッド**を開き、「セカンダリクリック」をオンにしてください。Control クリックは、CadCraft では右クリックではなく通常のクリックとして扱われることがあるため、2本指のクリックを使用してください。
- **領域をズーム:** 表示グループの{{ui:Window}}をクリックし、2つの角をクリックします。
:::

:::windows linux
- **パン:** タッチパッド上で2本指を任意の方向に動かします。図面は指に追従します。右ボタンを押したままドラッグすることもできます。
- **ズーム:** 2本指でピンチします。ズームは十字カーソルに従います。
- **右クリック（Enter）:** 2本指でクリックします。タッチパッドの設定によっては、タッチパッドの右下隅をクリックします。
- **領域をズーム:** 表示グループの{{ui:Window}}をクリックし、2つの角をクリックします。
:::

{{key:Space}}を押したままドラッグしても、CadCraft では**パンされません**。{{key:Space}}は Enter です。

マウスホイールは、引き続き1段階ずつズームします。トラックパッドがホイールのように段階単位でスクロールを送る場合、2本指のスクロールはパンではなくズームになります。その場合は、いったんズームアウトし、見たい部分にカーソルを合わせてからズームインしてください。3D タブでは、独自のトラックパッド操作を使います（[3D でモデルを見る](topic:3d-solids#look-around)を参照）。

## タッチスクリーンとタブレット

CadCraft は指を、マウスのクリックとして扱います。

- タップすると、点やオブジェクトを指定、または選択します。
- 何もない場所で指をドラッグすると投げ縄になります（右へ動かすと最初は窓、左へ動かすと最初は交差。[投げ縄による選択](topic:lasso-selection)を参照）。
- {{cmd:TRIM}}と{{cmd:EXTEND}}で、指で図形の部分をドラッグすると、それらをすべてトリム、または延長します。
- 選択したオブジェクトのグリップをドラッグすると、グリップが動きます（グリップとピックボックスは、指で操作しやすいように大きくなります）。
- 2本指で**ピンチ**すると、2本の指の中間点を中心にズームします。2本指を一緒に動かすと**パン**します。2本目の指は、1本目の指で始めた操作を取り消すため、ピンチが図形を残すことはありません。
- **長押し**（約0.5秒間じっと押さえる）は右クリック、つまり{{key:Enter}}です。コマンドを終了し、選択を完了し、または直前のコマンドを繰り返します。

コマンドラインの下に**キー行**が表示されます: {{ui:Esc}}、{{ui:Undo}}、{{ui:Redo}}、タブレットのキーボードでは隠れる文字（`@` `,` `<` `'` `"` `-`）、{{ui:Snap}}、{{ui:Ortho}}、キーボードボタン、大きな{{ui:Enter}}。キーボードボタン（またはコマンドライン）をタップすると、コマンドや数値を入力できます。

ホバーはないため、スナップマーカーは指が触れている場所にのみ表示されます。

:::touch
タッチスクリーンを使用しています。簡単な確認以上の作業をする場合は、キーボードとマウスまたはトラックパッドを接続すると、CadCraft がずっと使いやすくなります。
:::

## ブラウザー

CadCraft は、Mac、Windows、Linux の Chrome、Edge、Firefox、Safari で、同じように動作します。違いは小さく、次のとおりです。

| 項目 | 注意事項 |
|---|---|
| DWG を開く | 大きな図面は、どのブラウザーでも読み込みに数秒かかります。その間、ステータス行に「読み込み中 …」と表示されます |
| ダウンロード | ダウンロード先と、保存前に確認するかどうかは、ブラウザーが決めます。[ブラウザーとコンピューター](common:browsers)を参照してください |
| 開いて印刷 | PDF を新しいタブで開きます。ポップアップがブロックされている場合、CadCraft は代わりに PDF をダウンロードします |
| F7 | Firefox ではキャレットブラウズを提案することがあります。「いいえ」を選択してください |
| 保存していない変更がある状態で終了 | ブラウザーごとに独自の「サイトから移動しますか？」の確認が表示されます。CadCraft ではこれを変更できません |

:::safari
Safari では、{{ui:Open to print}}で開いた PDF が、印刷されずにタブに表示される場合があります。その場合は、**ファイル**、次に**印刷**を使用してください。
:::

:::firefox
Firefox では、ダウンロードごとに対応を尋ねられることがあります。ファイルを保存するように選択するか、Firefox の設定の「ダウンロード」で一度だけ変更してください。
:::
