## 学習内容

斜めに描かれた建物を画面上で正面に見えるように、図面を回転させて表示する方法と、建物独自の軸に沿って点を入力する方法です。この作業中、図面のものは何も移動しません。オブジェクトは座標を保持し、回転は編集ではないため、図面は変更済みとして扱われません。

## 表示を90°回転

1. {{ui:ビュー}} › {{ui:その他}} › {{ui:ビューを左に90°回転}} または {{ui:ビューを右に90°回転}} をクリックします。

図面は、描画領域の中央を中心に画面上で回転します。続けて回転させるには、もう一度実行してください。

2. {{ui:ビュー}} › {{ui:その他}} › {{ui:ワールドに戻る}} をクリックして、元の水平な向きに戻します。

これらの背後にあるコマンドは {{cmd:TURNLEFT}}、{{cmd:TURNRIGHT}}、{{cmd:TURNWORLD}} です。いずれかにキーを割り当てるには、{{cmd:ALIASEDIT}} でエイリアス設定に `TL=TURNLEFT` のような行を追加してください。

## 斜めの建物に合わせる

1. `UCS` と入力して {{key:Enter}} キーを押し、続いて `OB` と入力して {{key:Enter}} キーを押します。
2. 原点にしたい端に近い壁の線をクリックします。

UCS は、その端から始まり、X 軸が壁に沿う状態になります。表示は、壁が画面上で水平になるように回転します。左下隅の軸アイコンに、UCS の軸がどちらを向いているかが表示されます。

3. 通常どおり描きます。UCS を設定した状態では:
   - `x,y` と `@dx,dy` は UCS の軸に沿って測定されます。`d<a` は UCS の X 軸からの角度を測定します。
   - {{ui:直交}}、極トラッキング、グリッドは UCS の軸に従い、十字カーソルも同様です。
   - 新しい文字と新しい段落は UCS の X 軸に沿って配置されます。{{cmd:DIMLINEAR}} の水平と垂直も、同様に UCS に従います。
   - ステータスバーと {{cmd:ID}} の座標は UCS 座標です。
4. UCS が設定されている状態でワールド座標の点を入力するには、前に `*` を付けます: `*0,0` または `@*100,0`。
5. `UCS` と入力して {{key:Enter}} キーを押し、もう一度 {{key:Enter}} キーを押すと、ワールドに戻ります。

## UCS を設定するその他の方法

{{cmd:UCS}} のプロンプトで:

| 入力内容 | 動作 |
|---|---|
| 点 | 新しい原点になります。続けて新しい X 軸上の点をクリックするか、{{key:Enter}} キーを押して角度を維持します |
| `Z` | 入力した角度 (度、反時計回り) または指定した角度だけ、原点を中心に UCS を回転します |
| `3` (3point) | 原点、正の X 軸上の点、正の Y 側の点 |
| `OB` (OBject) | 線分、円弧、円、ポリラインのセグメント、文字、ブロック参照、点、または構築線から |
| `P` (Previous) | この前の UCS (直近の10個は図面を開いている間保持されます) |
| `W` (World) | ワールドに戻ります |
| `NA` (NAmed) | `S` は現在の UCS を名前付きで保存し、`R` は1つを復元、`D` は1つを削除、`?` は一覧を表示します |

変更するたびに、新しい UCS の X 軸が水平になるように表示が回転します。{{cmd:PLAN}} は UCS を変えずに表示を回転します: {{key:Enter}} キーは現在の UCS、`U` は保存した UCS、`W` はワールドです。

## 知っておくと便利なこと

- 分割画面の各ペインは、それぞれ独自の回転を保持します。UCS は図面に属します。
- シートは用紙座標で動作します。UCS は {{ui:モデル}} タブで、またはビューポート内で設定してください。
- 回転した表示でドラッグした選択窓は、画面上でその内側にあるものを選択します。
- LISP ルーチンは `getpoint` から UCS の点を受け取り、`UCSORG`、`UCSXDIR`、`UCSYDIR`、`VIEWTWIST` を読み取れます。`trans` はワールド、UCS、表示の間で変換します。

:::note
保存したファイルは、後のビルドで UCS と表示の回転を保持します。それまでは、図面を開いている間だけ保たれます。
:::
