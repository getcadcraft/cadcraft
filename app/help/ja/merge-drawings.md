2 人が同じ図面を編集しています。異なるオブジェクトを変更した場合、マージは自動で行えます。手作業でやり直す必要はありません。

## 仕組み

CadCraft は、描いたオブジェクトごとに、変わることのない短い**キー**を付与します。同じキーが 2 つのオブジェクトに割り当てられることはありません。キーは DWG または DXF 内でオブジェクトと一緒に保存されます (ほかのプログラムが保持する追加データとして)。マージでは、ファイル内の位置ではなく、このキーでオブジェクトを探します。すべてのプログラムは保存時に位置の番号を振り直すためです。マージを使わない場合は、{{ui:Settings}} › CadCraft › マージしやすいファイル をオフにできます。その場合、ファイルは約 10 パーセント小さくなります。

キーが導入される前に保存された図面もマージできます。その場合、オブジェクトはファイル内の位置からキーが付与されます。誰が開いても同じキーになります。

## セットアップ

Git では、リポジトリごとに 1 回、次の 2 行が必要です:

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# 1 回だけ、各コンピューターで
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git を使わない場合は、手動で実行します: `cadcraft merge <base> <ours> <theirs> -o <result>`。Fossil と Mercurial も、同じ 3 つのファイルをそれぞれのマージツールの設定で指定します。

## ルール

- 片方の側だけで変更されたオブジェクトは採用されます。両方の側で同じ変更が行われた場合は、1 回だけ採用されます。
- 同じプロパティが両側で別々に変更された場合は**競合**です。自分の側の値が残り、レポートには両方の値が表示されます。結果を開き、そのオブジェクトを確認して手作業で修正してください。
- どちらかの側で追加されたオブジェクトは残ります。片方の側で削除され、もう片方で変更されていないオブジェクトは削除されます。片方で削除され、もう片方で変更された場合は、削除されたものとして扱われ、報告されます。
- レイヤー、ブロック、文字と寸法スタイル、シート、名前の付いたビューも同様にマージされます。拘束は、それが参照するオブジェクトに従います。
- 結果は、自分のファイルと同じファイル形式とバージョンで書き込まれます。

マージされないもの: オブジェクトの描画順は自分の順序のままで、その後に相手側が追加したオブジェクトが続きます。両側で同じブロック定義が変更された場合は競合となり、決して混ぜられることはありません。何もアップロードされず、すべてお使いのコンピューター上で実行されます。
