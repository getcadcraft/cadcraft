## 学べること

AI アシスタント (または自分で書いたスクリプト) に図面を見せ、CadCraft のコマンドを実行させ、印刷と保存をさせる方法と、それが変更してよい範囲を決める方法を説明します。

CadCraft には **独自の AI はなく**、どこにも何も送信しません。アシスタントは自分で用意します。Model Context Protocol (MCP) に対応したプログラムなら何でも使えます。CadCraft はそれにツールを提供するだけで、どのツールを提供するかは自分で選びます。

利用方法は 2 つあります:

- **開いている図面。** アシスタントは、お使いのコンピューター上の CadCraft Studio を通じて、このウィンドウで隣り合って作業します。これは {{ui:設定}} › {{ui:CadCraft}} › {{ui:アシスタント}} で設定します。
- **アプリを開かずに、コンピューター上の図面を操作。** CadCraft MCP サーバーと `cadcraft` コマンドラインは、指定したフォルダー内の DWG および DXF ファイルを読み書きします。「下記の「CadCraft を開かずにファイルを操作する」」を参照してください。

## 有効にする

1. {{ui:設定}} (アプリバーの歯車、または {{key:Mod+,}}) を開き、{{ui:CadCraft}} タブに移動します。
2. {{ui:アシスタント}} で **AI アシスタントとスクリプトによる CadCraft の使用を許可** にチェックを入れます。チェックを入れるまでは無効です。
3. 実行できる操作を選びます。**読み取り** は最初からチェックされています。ほかの項目は必要なときだけチェックしてください。

| 権限 | アシスタントができること |
|---|---|
| 読み取り | 図面を確認します: 説明、オブジェクトの一覧と検索、選択の確認、ビューの説明と画像の取得、レイヤーや製図ルールとの照合 |
| 編集 | 図面に対してコマンドを実行し、選択を変更します。各操作は元に戻せる 1 ステップです |
| 保存 | 図面を保存します (デスクトップでは元のファイルへ、ブラウザーではダウンロードとして) |
| エクスポート | PDF に印刷し、ほかのファイルを作成します |

## 任意のフォルダー内のファイルを使わせる

CadCraft Studio では、アシスタントはファイルダイアログを使わずに、名前を指定してファイルを開く、保存する、印刷できます。ただし、{{ui:アシスタント}} › {{ui:アシスタントが使用できるフォルダー}} で追加したフォルダー内に限られます:

1. {{ui:フォルダーを追加…}} を選び、Studio 独自のダイアログでフォルダーを選択します。
2. これでアシスタントはそのフォルダー内のファイルを一覧表示 (`files_list`) し、図面を開き (`drawing_open`)、DWG のバージョンを指定するか DXF で保存し、PDF または SVG ファイルに印刷し、LISP ファイルを読み込み、コマンドが求めるファイルを渡す (`INSERT` `F`、`XATTACH`、点ファイル) か、コマンドのファイルの出力先を指定する (`COUNT` の CSV、`PUBLISH`) ことができます。
3. {{ui:除外}} を選ぶと、そのフォルダーをすぐに取り消せます。それ以外の場所のパスは拒否され、同名のファイルが既にある場合は、アシスタントがそれを求めたか、アシスタント自身が書いたファイルの場合にのみ置き換えられます。

開くには引き続き **読み取り** が必要です。図面の書き込みには **保存** が、ほかのファイルには **エクスポート** が必要です。

チェックした権限以外のツールは、アシスタントに一切提示されません。それでも要求された場合、CadCraft は拒否し、アクティビティログに記録します。スイッチをオフにすると、すべての接続が直ちに終了します。{{ui:CadCraft の設定をリセット}} でもオフになります。

## アシスタントを接続する

アシスタントは、お使いのコンピューター上の **CadCraft Studio** を通じて接続します。Studio は、このコンピューターからしか到達できない小さなサーバー (アドレス `127.0.0.1`) を起動します。サーバーは、Studio が起動するたびに作成されるトークンで保護されます。Studio を開き、{{ui:アシスタントを接続}} を選んで、アドレスとトークンをコピーします。

- アシスタント側で、タイプ HTTP の MCP サーバーを追加し、アドレス (`http://127.0.0.1:47615/mcp` のような形式) とヘッダー `Authorization: Bearer <token>` を入力します。貼り付ける設定は Studio に表示されます。

Studio の {{ui:新しいトークン}} を選ぶと、接続中のすべてのアシスタントが新しいトークンで再接続します。トークンは決して共有しないでください。トークンを持つ人は、Studio が起動している間ずっと、有効にしたアプリを使えてしまいます。

:::note
ブラウザータブではアシスタントの接続を開けません。ブラウザー版のアプリでは、お使いのコンピューター上の CadCraft Studio を使うまで、スイッチは効果がありません。
:::

## 主導権は自分にあります

- **すべての操作は 1 つの元に戻す手順です。** アシスタントの名前付きで記録されます (例: 「Assistant: LINE」)。{{key:Mod+Z}} を押すと、アシスタントの直前の操作を一括で取り消します。
- **動作は確認できます。** アシスタントのコマンドは、コマンド履歴に **[Assistant]** を先頭に付けて表示され、作業に合わせて図面が再描画されます。
- **アシスタントは待機します。** コマンドの実行中は、アシスタントは読み取りはできますが図面は変更できません。作業が終わると、再試行するよう伝えられます。
- **接続中かどうかが分かります。** 接続中は、アプリバーのボタンにアシスタント名が表示されます。そのボタンをクリックすると、実行できる操作を確認したり、**切断** したりできます。
- **アクティビティ。** {{ui:設定}} › {{ui:CadCraft}} › {{ui:アシスタント}} › {{ui:アクティビティ}} に、すべての呼び出しが一覧表示されます。実行日時、使用したツール、完了したか拒否されたか、作成された元に戻す手順です。{{ui:ログを保存}} で控えを保存できます。

## アシスタントが要求できること

| ツール | 権限 | 機能 |
|---|---|---|
| `app_info`, `drawing_describe`, `view_describe` | 読み取り | 図面の名前、単位、レイヤー、ブロック、シート、画面に表示されている内容 |
| `files_list`, `drawing_open` | 読み取り | Studio: フォルダー内のファイル一覧、このウィンドウで図面を開く |
| `objects_list`, `object_get`, `selection_get` | 読み取り | 形状、長さ、面積を含むオブジェクト (または種類とレイヤーごとの個数のみ)、選択内容 |
| `drawing_check` | 読み取り | 許可されたレイヤー、レイヤー 0 に何もないこと、色が ByLayer であること、文字の高さなどのルール |
| `view_screenshot` | 読み取り | 表示どおりの図面の画像 |
| `command_run` | 編集 | コマンドラインに入力します: `LINE 0,0 @100,0 @0,50 ` は入力したとおりに読み取られます (スペースは回答の終わりを示します)。または、1 回答ずつの一覧を入力します。コマンドを実行中のままにして、次の呼び出しで続行することもできます |
| `script_run` | 編集 | スクリプト (`.scr`) または LISP ファイルを、{{ui:APPLOAD}} が読み込むのと同じように実行します |
| `block_insert` | 編集 | 属性値を含むブロックを 1 回の操作で配置します |
| `selection_set`, `undo` | 編集 | 次のコマンド用にオブジェクトを選択します。自身の操作を元に戻します |
| `drawing_save` | 保存 | CadCraft 独自の {{ui:保存}}、または登録済みフォルダーの 1 つへの {{ui:名前を付けて保存}} |
| `drawing_plot` | エクスポート | シートまたはモデルの PDF または SVG を、縮尺を指定して、または用紙に合わせて出力します (PDF の下敷きは、まだこの方法では印刷されません) |

アシスタントがコマンドを実行している間、CadCraft は質問をダイアログではなくコマンドラインに表示します (例: 図面全体を挿入するか、1 つのブロックだけを挿入するか)。そのため、アシスタントが答えられます。ライブラリと検索には引き続きユーザーの操作が必要です。アシスタントには、ユーザーに確認するよう伝えられています。

## CadCraft を開かずにファイルを操作する

CadCraft MCP サーバー (`cadcraft-mcp`) とコマンドライン (`cadcraft`) は、CadCraft 独自の図面処理コードを、ウィンドウなしで Node.js 上で実行します。Node.js 20 以降が必要です。

- **MCP サーバー** は、指定したフォルダー内でのみ、与えた権限の範囲でのみ動作します: `npx @getcadcraft/mcp --root ~/Drawings --allow read,edit`。`--root` がなければ、どのファイルも開けません。`--allow` がなければ、読み取りだけができます。IFC モデル、拾い出し、PDF セット内のマークアップも読み取れます。
- **コマンドライン** は、自作のスクリプト向けです: `cadcraft info plan.dwg`、`cadcraft run cleanup.scr plan.dwg -o plan-clean.dwg`、`cadcraft convert plan.dwg plan.dxf`、`cadcraft plot plan.dwg plan.pdf --all`、`cadcraft plot plan.dwg plan.svg`、`cadcraft check plan.dwg --rules rules.json`。複数のファイルを一度に処理する場合: `cadcraft convert *.dwg out --to dxf`、`cadcraft plot *.dwg pdfs --to pdf`、`cadcraft check *.dwg --rules rules.json`。プログラムで読み取れる出力にするには `--json` を付けます。

:::note
`npx @getcadcraft/mcp` で「パッケージが見つかりません」と表示される場合は、まだ公開されていません。公開されたら getcadcraft.com のニュースでお知らせします。
:::

## うまく動かないとき

- **アシスタントに CadCraft のツールが表示されない:** このウィンドウでスイッチがオンになっていること、Studio でこのウィンドウが開いていることを確認してください。
- **「needs the edit permission」:** {{ui:アシスタント}} で **編集** にチェックを入れ、もう一度依頼してください。
- **「outside the folders assistants may use」:** そのフォルダーを {{ui:アシスタント}} › {{ui:アシスタントが使用できるフォルダー}} に追加するか、既に追加したフォルダー内のファイルを使うようアシスタントに依頼してください。
- **「401」や「token」のエラー:** トークンが変わっています (Studio を再起動した、または {{ui:新しいトークン}} を選んだ)。新しいトークンをアシスタントの設定にコピーしてください。
- **変更が誤っていた:** {{key:Mod+Z}} を押してください。1 回押すと、アシスタントの操作 1 つ分をまとめて取り消します。
