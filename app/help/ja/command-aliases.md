## 学習内容

コマンドに独自の短縮名を付ける方法を説明します。たとえば、{{cmd:LINE}} に `LL` を割り当てます。すべてを 1 つのテキストファイルで管理します。

## 別名を追加する

1. {{ui:ビュー}} › {{ui:その他}} › {{ui:別名を編集…}} を開くか、{{cmd:ALIASEDIT}} と入力して {{key:Enter}} を押します。
2. 別名、カンマ、アスタリスクの後にコマンドを続けた行を追加します:

```
LL,     *LINE
```

3. {{ui:保存}} をクリックします。コマンドラインに、使用中の別名の数が表示されます。
4. `LL` と入力して {{key:Enter}} を押します。LINE が始まります。

独自の別名は、CadCraft の標準の別名の上に配置されます。同じ名前の標準の別名より、独自の行が優先されます。その行を削除すると、標準の別名が戻ります。

## CadCraft が受け付けない行

エディターでは、入力中に、各問題を行番号とともに一覧表示します:

- コマンドが存在しない
- 別名がそれ自体コマンド名である（`LINE, *CIRCLE` は LINE を隠してしまいます）
- 行が `ALIAS, *COMMAND` の形式ではない
- 同じ別名が 2 つの行にある（後の行が優先されます）

コンピューター上でプログラムを起動する行（例: `NOTEPAD, START, 1, *File to edit: ,`）は、注意を表示してスキップされます。ブラウザー内のアプリはプログラムを起動できないためです。

## ほかのプログラムの別名を取り込む

1. 別名エディターで {{ui:.pgpを読み込み…}} をクリックし、ファイルを選択します。`.pgp` ファイルを図面にドロップすることもできます。
2. 一覧に表示された問題を確認します（CadCraft にないコマンドは受け付けられず、それ以外は動作します）。
3. {{ui:保存}} をクリックします。

{{ui:.pgpを書き出し}} は、CadCraft の別名と独自の別名を、同じ形式の 1 つのファイルに保存します。

## ファイルを再読み込みする

{{cmd:REINIT}} と入力して {{key:Enter}} を押すと、別名ファイルが再び適用されます。このファイルはこのブラウザーに保存されます。デスクトップアプリでは独自のフォルダーに保存され、クラウドサービスでは同期されます。

## どのコマンドにもキーボードショートカットを割り当てる

別名は入力するもの、ショートカットはキーです。コマンドに独自のキーを割り当てるには:

1. {{ui:ビュー}} › {{ui:その他}} › {{ui:キーボードショートカット…}} をクリックするか、`KEYS` と入力して {{key:Enter}} を押します。
2. {{ui:キー}} の欄をクリックして、キーを押します（例: {{key:Alt+Shift+C}}）。
3. {{ui:実行内容}} に、コマンドを入力します。必要に応じて、その後に入力する内容も書きます（例: `CIRCLE` や `ZOOM E`）。
4. {{ui:追加}} をクリックします。

キーには、{{key:Mod}} または {{key:Alt}} と文字または数字の組み合わせ、または空いているファンクションキー（{{key:F2}}、{{key:F4}}、{{key:F5}}、{{key:F6}}、{{key:F9}}）が必要です。CadCraft、アプリ、ブラウザーがすでに使用しているキーや、マイツールのボタンが使用しているキー（[独自のボタン](topic:my-tools) を参照）は受け付けられず、欄にその理由が表示されます。ショートカットはこのブラウザー（またはデスクトップアプリ）に保存されます。{{ui:除外}} で削除できます。
