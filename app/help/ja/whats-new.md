以下は、0.8.1 と比べて CadCraft 0.9 で変更された内容です。CadCraft は、CadCraft Studio 0.9 の 8 つのアプリに含まれる 2D および 3D 製図アプリです。0.9 では平面製図を完成させ、文字スタイルと実用的なテキストエディターを追加し、画面をより広く使えるようにしました。

## 新機能

### 平面製図

- **境界に追従するハッチ。** {{cmd:HATCH}} は、ハッチを囲む境界にリンクします。境界を移動、回転、または尺度変更すると、ハッチとそのパターンも追従します。形状を変えると、ハッチは計算し直されます。{{cmd:HATCHEDIT}} (`HE`) は、後からハッチを変更し、リンクを設定または解除します。「[ハッチングと塗りつぶし領域](topic:hatch)」を参照してください。
- **ハッチパターンファイル。** {{cmd:HATCH}} の質問 `内部の点を指定` で、`F` (パターンファイル) と入力し、`.pat` ファイルを選びます。一般的な形式で書かれたファイルのみ試されています。
- **レイヤーグループ。** {{ui:レイヤー}} パネルの {{ui:ツール}} で: {{ui:新しいグループ}}、{{ui:既製のグループを追加}}、{{ui:名前でグループ化}}、{{ui:レイヤーを検索}}。または {{cmd:LAYGROUP}} (`LG`) と入力します。「[レイヤーで図面を整理する](topic:layers#group-layers)」を参照してください。
- **階の重ね合わせ。** {{cmd:FLOORS}} (`FLR`)、または {{ui:ビュー}} グループの {{ui:その他}} メニューにある {{ui:階…}}。シート上のビューポートは、プロパティの {{ui:表示する階}} で 1 つの階を表示できます。{{cmd:FLOORLAYERS}} は、ほかの人に渡すファイル用に階をレイヤーに変換します。「[1 つの図面に階を重ねる](topic:floors)」を参照してください。
- **2D スマート壁、ドア、窓。** {{cmd:WALL}} (`WA`)、{{cmd:DOOR}} (`DR`)、{{cmd:WINDOW}} (`WN`)、{{cmd:DELOPENING}}。角、T 字の接合、交差は自動的に計算されます。壁は接合の記録を保持し、プロパティには {{ui:始点での結合をしない}} / {{ui:終点での結合をしない}}、基準線、編集可能な長さが追加されます。「[2D の壁、ドア、窓を作図する](topic:walls-2d)」を参照してください。
- **平面の壁のツール。** {{cmd:WALLRECT}}、{{cmd:WALLPOLY}}、{{cmd:WALLARC}}、{{cmd:WALLTRACE}}、{{cmd:WALLDIM}}、{{cmd:WALLOFFSET}}、{{cmd:WALLSPLIT}}、{{cmd:WALLGRID}} などを入力します。これらにはまだツールバーのボタンはありません。「[2D 壁の形状、分割、オフセット、ロック](topic:wall-tools-2d)」を参照してください。

### テキスト

- **文字スタイル。** {{cmd:STYLE}} (`ST`)、または {{ui:作図}} ツールバーの {{ui:文字スタイル}}。フォント、高さ、幅の係数、傾きを持つ名前付きスタイルです。「[文字スタイルでフォントとサイズを設定する](topic:text-styles)」を参照してください。
- **書式付きの段落テキストエディター。** {{cmd:MTEXT}}、{{cmd:TEXTEDIT}}、またはテキストのダブルクリックで、フォント、サイズ、太字、斜体、下線、取り消し線、色、配置、度記号、プラスマイナス記号、直径記号を設定できるボックスが開きます。{{ui:OK}} と {{ui:キャンセル}} も表示されます。「[段落テキストの書式設定](topic:format-paragraph-text)」を参照してください。
- **draw.io XML からのダイアグラム。** {{cmd:DIAGRAM}} (`T2D`) は、貼り付けた draw.io の XML も読み込みます。「[テキストからダイアグラムを作図する](topic:text-to-diagram)」を参照してください。
- **PDF 印刷でのタイ語テキスト。** 以前は、はてなマーク (?) として印刷されていました。

### 作業領域と作図の補助

- **フローティングの細いコマンドラインと、コンパクトな上部領域。** コマンドラインのグリップをドラッグするとフローティングになり、上端をドラッグすると行数を減らせます。{{key:F2}} で履歴を開きます。{{ui:設定}} › {{ui:CadCraft}} › {{ui:コマンドライン}} と上部領域の選択肢にも同じ設定があります。「[設定](topic:settings#command-line)」を参照してください。
- **オブジェクトスナップメニュー。** ステータスバーの {{ui:スナップ}} を右クリックするか、{{cmd:OSNAP}} と入力します。
- **グリッドにスナップ。** ステータスバーの {{ui:グリッドスナップ}} ボタン、または {{key:F9}}。オブジェクトスナップで点が決まらなかった場合、指定した点は最も近いグリッド点に移動します。
- **円弧の 10 通りの作図方法と続行。** {{ui:作図}} ツールバーの {{ui:円弧}}、または {{cmd:ARC}}: 3 点、始点/中心/終点の系統、中心/始点/終点の系統、そして前の線、円弧、ポリラインからの続行 (始点で {{key:Enter}} を押します)。
- **ドキュメントパネル。** {{cmd:DOCUMENTS}} (`DOCS`)、または {{ui:ビュー}} グループの {{ui:その他}} メニューにある {{ui:ドキュメント…}}: プロジェクトフォルダー内のすべての図面について、改訂、状態、チェックアウトを表示します。中央に配置されたダイアログとして開きます。「[ドキュメント](topic:documents)」を参照してください。

### ファイル

- **英国の鉄骨サイズ。** 標準パネルに 976 種類の断面があり、図面に記載されるとおりに入力します (例: `305x165x40 UB`)。
- **南アフリカのパック** (製図の慣行と建築規制) を、建築規制アドオンのパックとして提供します。数値は未確認です。
- **CadCraft 向けアドオン。** 必要に応じて追加され、既定ではオフです: 室内照明設計、チップ設計 (HDL からレイアウト)、ルーター彫刻、回路シミュレーション、ローラーチェーンのスプロケット、国別の建築規制パック。

## 修正

- ハッチを移動、回転、または尺度変更すると、パターンが取り残されていました。
- {{cmd:GRIDMOVE}} は、グリッド線上でのみ始まる平面の壁を全体で移動していました。現在は、壁は端によって判断されます。
- 制限をオフにしていても、グリッドは図面の制限内にのみ表示されていました。
- サイドパネルのブロック一覧はスクロールできるようになり、ブロックでない名前を入力すると、その名前で始まるブロックを「もしかして」として一覧表示します。
- AutoCAD が拒否していた DXF R12 ファイル (「Unknown group 1001 for table」) が、ここで開けるようになりました。
- 非常に大きなファイル (約 70,000 個のエンティティ以上) が「Maximum call stack size exceeded」で開けませんでした。
- 保守バージョンの高い AutoCAD 2018 以降の DWG ファイルが、「bad BITLONG code 11」で開けませんでした。
- 段落テキストボックスで、選択した部分に入力した新しいサイズは、選択を保持するようになりました。

## すべてのアプリ共通

ヒントのあるすべてのコントロールにツールチップ、閉じられるスタートのヒント、収まらないときにスクロールするタブ、開いている図面に追従するブラウザータブのタイトル (`<drawing> - CadCraft | CadCraft`) があります。{{ui:設定}} › {{ui:レイアウト}} は、2 行の選択肢を持つドロップダウンになりました。{{ui:設定}} の言語一覧は 0.8 より長くなりました。Live 共同編集、ライブラリのコレクション、重量と温度の単位については、Studio の注記に記載されています。

## 現在の制限

- 段落テキストには、箇条書きや番号付きリスト、タブルーラー、両端揃えはありません。印刷された PDF では、テキストは Helvetica で組まれます。
- 平面の壁は直線のため、円弧は短い壁で描かれます。壁ツールのコミュニティによる手作業での確認は、保留中です。
- レイヤーグループは AutoCAD 独自の形式では書き出されないため、AutoCAD ではフラットな一覧として表示されます。{{cmd:FLOORLAYERS}} を実行しない限り、ほかのプログラムはすべての階をまとめて表示します。
- ドキュメントパネルは、実際の共有フォルダーで 2 人以上により試されていません。ルーター彫刻は、実際の機械ではまだ動作していません。照明の見積もりは、別のプログラムではなくフォトントレースで確認されました。エンジニアリング系アドオンは確認を補助するものであり、エンジニアのレビューの代わりにはなりません。
- 英語以外の言語は機械翻訳の草稿であり、新しい語の一部は英語のみです。

## 以前の版: 0.8 と 0.8.1

以下は、0.7 と比べて CadCraft 0.8 と 0.8.1 で変更された内容です。0.8 (2026 年 11 月 1 日) では、図面そのものをもとに、コンピューター上のルールによって、モデルを使わずに動作する作図の補助機能が追加されました。0.8.1 (2026 年 11 月 2 日) では、その後に報告されたバグを修正しています。

### 新機能

**図面が次の作業を先取りする**

- **ゴーストで次を表示。** コマンドが実行されていないとき、グレーの破線のゴーストが、図面自体のパターンから次に来るものを表示します: 同じ間隔の次の間柱、階段の次の段、部屋の欠けている壁。{{key:Tab}} を押すと 1 回の元に戻す手順として作図し、{{key:Esc}} を押すと消えます。新しいオブジェクトだけを対象にするため、大きな図面でも滑らかに動作します。{{ui:設定}} › {{ui:CadCraft}} で、または {{cmd:AUTOCOMPLETE}} `Off` でオフにできます。
- **線の作図中の次の点。** {{cmd:LINE}} または {{cmd:PLINE}} の実行中、ゴーストは次の点を示します: 階段の次の段、長方形の 4 つ目の角、またはそれを閉じる点。カーソルをその近くに置いて {{key:Tab}} を押すと、そこをクリックしたかのように作図されます。
- **ペンのスケッチを正確な形状に。** {{cmd:SKETCHFIX}}: ペン、マウス、または指で大まかな線を描くと、それぞれが、既に描かれたものにスナップした、きれいな線、円、円弧、長方形、またはポリラインになります。「[ペンでスケッチして正確な形状を得る](topic:sketch-with-a-pen)」を参照してください。
- **スケッチの写真を図面に。** {{cmd:PHOTOSKETCH}} (`PSK`) は、写真内の用紙を見つけ、遠近を補正し、指定された用紙サイズと縮尺を適用し、ペンの色ごとにレイヤーへペンの線をトレースします。文字はトレースされません。
- **ルールに従って寸法を付ける。** {{cmd:AUTODIM}} (`ADIM`) は、選んだ辺に沿った寸法の連続、全体の寸法、開口幅、穴の直径、そして `Grid` を使えばグリッド間隔を作成します。既にある寸法を重複して作ることはありません。
- **グリッド線を移動すると一式が追従。** {{cmd:GRIDMOVE}} (`GM`): グリッド線で終わる壁はそれに合わせて伸縮し、線に沿った壁、柱、そのバブルとタグが移動し、線上の寸法は新しい間隔を測定します。元に戻す手順は 1 つです。

**シート、詳細、タグ**

- **自動で割り付けられるシート。** {{cmd:AUTOSHEET}} は、名前付きビュー (またはモデルの個別の部分) を取り込み、用紙サイズと標準縮尺を選び、表題欄と名称・縮尺のキャプション付きの新しいシートにビューを配置します。すべて編集可能なままです。「[シートを自動で配置する](topic:lay-out-sheets-for-me)」を参照してください。
- **作図中に提示される社内の詳細図。** {{cmd:DETAILS}} (`DET`) は、独自の詳細ブロックを保持します。選択したものが、レイヤー、ブロック名、注記の語句によって一致すると、ステータスバーに表示されます。それを選んで配置します。{{cmd:DETAILS}} › 共有は、一覧をドキュメントフォルダーに保存し、チームが追加したものを取り込みます。設定で提示をオフにします。
- **ブロックのタグ。** {{cmd:TAGS}} は、タグ (その種類、取り得る値、対象となるブロック) を定義し、選択したブロック参照に設定して、CSV として保存できる集計表として一覧表示します。定義は DWG 内に保持されます。「[タグ](topic:tags)」を参照してください。
- **図面の制限。** {{cmd:LIMITS}} は図面の矩形を設定します。グリッドはその範囲を埋め、全体ズームでそれが表示されます。制限は輪郭として表示され、用紙の制限とともに DWG と DXF に保存されます。「[図面の制限を設定する](topic:drawing-limits)」を参照してください。

**ほかの人やほかのプログラムとの作業**

- **マークアップを改訂に変える。** {{cmd:REDLINE}} は、MarkupCraft が書き出したパッケージを読み込み、すべての変更を一覧表示します。それぞれに注記を付けて承認または却下します。承認されたものには、1 回の元に戻す手順で雲マークと改訂ログが付き、MarkupCraft でマークアップを閉じる回答ファイルを保存します。「[マークアップを改訂に変える](topic:redline-to-revision)」を参照してください。
- **git と Fossil でマージできる図面。** {{ui:設定}} › {{ui:CadCraft}} で {{ui:マージしやすいファイル}} をオンにすると、すべてのオブジェクトに変更されないキーが付きます (ファイルは約 10 パーセント大きくなります)。`cadcraft merge base ours theirs` は、2 人による 1 つの DWG または DXF の編集を、オブジェクトごとにマージし、同じ箇所を 2 人が変更した場合のみ報告します。「[1 つの図面に対する 2 人の編集をマージする](topic:merge-drawings)」を参照してください。
- **何が変わったかを文章で。** 履歴の比較では、平易な一覧が表示されます: 変更された場所、その範囲の大きさ、追加、削除、変更された内容、そして編集されたテキスト。「[変更点を文章で説明する](topic:changes-in-words)」を参照してください。
- **方位と角度。** 角度を求められる場所であれば、N45°23'30"E のような測量の方位、または度、分、秒で方向を入力できます。AUNITS で角度の表示形式を設定します。「[方位と角度を入力して表示する](topic:bearings-and-angles)」を参照してください。
- **独自の SHX フォント。** CadCraft に SHX フォントのフォルダーを指定すると、それらのフォントを名前で指定した文字スタイルが、画面と印刷でそのフォントを使って描画されます。「[独自の SHX フォントでテキストを描画する](topic:shx-fonts)」を参照してください。
- **テキストからのダイアグラム。** {{cmd:DIAGRAM}} は、Mermaid のフローチャート、PlantUML のコンポーネント図、D2、または from-to の一覧を読み込み、編集可能なブロックと接続線を作図します。「[テキストからダイアグラムを作図する](topic:text-to-diagram)」を参照してください。
- **DWG 内の OLE オブジェクト。** {{cmd:OLELIST}} は、DWG に含まれる OLE オブジェクトのうち、CadCraft が自力で配置できないものを一覧表示し、指定した場所に画像のコピーを配置します。「[画像](topic:pictures#objects-from-other-programs-ole)」を参照してください。
- **計算は図面とともに保持されます。** 計算シートと設計根拠は、クラス表とともに DWG に保持されます。

**視覚に頼らない作図**

- {{ui:設定}} で {{ui:視覚に頼らない作図}} をオンにします ({{cmd:ACCESS}} と入力し、`On` と答えても構いません)。CadCraft は、すべてのコマンドと結果を利用中のスクリーンリーダーで読み上げ、図面とカーソル付近にあるものを説明し、キーボードでカーソルを移動して点を指定できるようにし、スナップとグリップごとに音を鳴らします。ブラウザーがコンピューター上の音声認識に対応している場合は、コマンドを音声で入力できます。「[視覚に頼らずに作図](topic:draft-without-sight)」を参照してください。

**すべてのアプリ共通**

- **言語。** 54 言語。そのうち 10 言語 (リトアニア語、ラトビア語、ボスニア語、マラーティー語、テルグ語、アルバニア語、アフリカーンス語、フィリピン語、スワヒリ語、ウズベク語) が新しく追加されました。英語以外の言語は、ネイティブ話者が確認するまで機械翻訳の草稿です。
- **入力デバイス。** トラックパッド、ペン、3D マウス、ゲームコントローラー、MIDI コントローラーの操作に対応しています。
- **ツールバーの行数とプロパティグリッド。** {{ui:設定}} › {{ui:全般}} › {{ui:ツールバーの行数}} では、ほかのアプリで折り返し、2 行、1 行を選べます。CadCraft は独自の設定を {{ui:設定}} › {{ui:CadCraft}} で保持します (「[ツールバーの行数](topic:settings#toolbar-rows)」を参照)。共通のプロパティグリッドは、CadCraft ではなく、ほかの 3 つのアプリにあります。
- **問題、Live、アドオン。** 全アプリで警告を表示する共通の問題パネル、CadCraft Studio でだれがどこにいるかを表示する Live ビュー (「[1 つの図面を共同で編集する](topic:work-live)」を参照)、アドオンの一覧。
- **AI を接続。** CadCraft Studio から 8 つのアプリすべてへの 1 つの接続。アプリごとに読み取り専用、提案、編集のレベルを設定でき、アシスタントの動作は平易な言葉でログに記録されます。CadCraft には独自の AI はなく、各アプリの「Ask」は、接続した AI を使います。

### 0.8.1 での修正

- **フィートとインチの図面で、プロパティに 150 と表示されていました (本来は 12'-6")。** アプリが自分で読み取るフィールドは、テキストを再び保持します。
- **クラスのセクションが誤った型として読み込まれていた DWG ファイル** (GitHub cadcraft#5) が、正しく開くようになりました。
- **ポップアップの後ろに十字カーソルが表示されなくなりました。**
- **Studio とパッケージ版は、実行中に言語を切り替えられるようになりました。** 以前は英語のみでした。すべてのプラットフォームではまだ試されていません。言語が変わらない場合はお知らせください。
- **縦向きのタブレット** では、余ったグリッドの高さがキャンバスに割り当てられ、シートモードは 760 px 以下で開始します。
- **交差選択による STRETCH と LIMITS** は、Studio 0.8.0 で報告されましたが、0.8 のウェブ版では既に正しく動作していました。報告者のインストーラーが古いものでした。Studio 0.8.1 にはこれらの修正が含まれています。

### このバージョンではまだ対応していないこと

- **0.8 と 0.8.1 はコード署名されていません。** Windows では警告が表示されることがあります ({{ui:詳細情報}} を選び、次に {{ui:実行}} を選びます)。Mac では CadCraft Studio を右クリックし、{{ui:開く}} を選びます。ストア版は保留中で、iPad と iPhone のビルドは 0.8.1 向けには再ビルドされていません。
- **ペンのスケッチとスケッチの写真** は、作成した写真とマウスでのみ試されており、実際のペン、タッチスクリーン、紙の手描きスケッチではまだ試されていません。
- **視覚に頼らない作図** は、自動チェックでテストされていますが、スクリーンリーダーや視覚障害のあるテスターではまだテストされていません。
- **詳細の共有** は、2 人による確認が行われておらず、ドキュメントフォルダーとしての Team Cloud Plan フォルダーはまだ作成されていません。
- **マージ** は CadCraft の DWG および DXF ファイルで動作します。ほかのアプリのファイルでの同様の機能はまだ作成されていません。
- **ウィンドウをまたぐ元に戻す:** CadCraft は完了した各手順を報告しますが、Studio にはまだすべてのアプリに共通の元に戻す機能はありません。各アプリは、自身の手順を元に戻します。
- **DWG の OLE オブジェクト** は保持されますが、その場所には描画されません。
- **ほかのプログラムのプロットスタイルテーブル (CTB ファイル)** の読み込みは作成済みですが、ほかのプログラムのファイルでの確認はされていません。
- **AI を接続:** Studio でのワンクリック接続、ブラウザー AI 向けのホスト型コネクター、Studio 内での独自の API キー、公開された MCP パッケージは、このリリースでは約束されていません。

このバージョンより前の内容については、[0.7 の新機能](topic:whats-new-0-7) を参照してください。
