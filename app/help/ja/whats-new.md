このページでは、0.7 からの 0.8 および 0.8.1 での変更点を説明します。0.8（2026年11月1日）では、お使いの図面そのものから作図を補助する機能を追加しました。これらはお使いのコンピューター上のルールで動作し、モデルは使用しません。0.8.1（2026年11月2日）では、0.8 の公開後に報告されたバグを修正しています。

## 新機能

### 作図の続きを補う機能

- **次に来るものをゴーストで示します。** コマンドが実行されていないとき、グレーの破線のゴーストが、図面自体のパターンから次に来るものを示します。例えば、同じ間隔の次の間柱、階段の次の段、部屋の欠けている壁です。{{key:Tab}}キーを押すと 1 回の元に戻す操作として描画され、{{key:Esc}}キーを押すと消えます。新しいオブジェクトだけを対象にするため、大きな図面でも動作は滑らかなままです。{{ui:設定}} › {{ui:CadCraft}} でオフにするか、{{cmd:AUTOCOMPLETE}} `Off` と入力してオフにできます。
- **線を描いているときの次の点。** {{cmd:LINE}} または {{cmd:PLINE}} の実行中は、ゴーストが次の点を示します。例えば、階段の次の段、長方形の 4 つ目の角、またはそれを閉じる点です。カーソルをその近くに置いて{{key:Tab}}キーを押すと、そこをクリックしたのと同じ扱いになります。
- **ペンによるスケッチを正確な図形にします。** {{cmd:SKETCHFIX}}: ペン、マウス、または指で大まかに描いた線は、それぞれ、既に描かれているものにスナップした、きれいな線、円、円弧、長方形、またはポリラインになります。[ペンでスケッチして正確な図形を得る](topic:sketch-with-a-pen) を参照してください。
- **スケッチの写真を図面にします。** {{cmd:PHOTOSKETCH}}（`PSK`）は、写真の中から紙を見つけ、遠近感を補正し、指定した用紙サイズと縮尺を適用して、ペンの線をペンの色ごとのレイヤーにトレースします。文字はトレースされません。
- **ルールに従って寸法を付けます。** {{cmd:AUTODIM}}（`ADIM`）は、選択した辺に沿った寸法の連続、全体の寸法、開口の幅、穴の直径を作成します。`Grid` を指定すると、グリッドの間隔も作成します。既に付いている寸法を重複して付けることはありません。
- **グリッド線を動かすと、関連するものも一緒に動きます。** {{cmd:GRIDMOVE}}（`GM`）: グリッド線で終わる壁はグリッドと一緒に伸縮します。グリッド線に沿った壁、柱、そのバブルとタグは移動し、その上の寸法は新しい間隔を計測します。元に戻す操作は 1 回です。

### シート、詳細図、タグ

- **自動で配置されるシート。** {{cmd:AUTOSHEET}} は、名前付きビュー（またはモデルの個別の部分）を使い、用紙サイズと標準縮尺を選んで、表題欄と名称・縮尺のキャプションを付けた新しいシートにビューを配置します。すべて編集可能なままです。[シートを自動で配置する](topic:lay-out-sheets-for-me) を参照してください。
- **会社の詳細図を、描画中に提案します。** {{cmd:DETAILS}}（`DET`）は、お使いの詳細図ブロックを保持します。選択したものが、そのレイヤー、ブロック名、注記の語句と一致すると、ステータスバーに表示されます。それを選んで配置します。{{cmd:DETAILS}} › 共有 は、一覧をお使いのドキュメント フォルダーに保存し、チームが追加したものを取り込みます。設定で提案をオフにできます。
- **ブロックへのタグ付け。** {{cmd:TAGS}} は、タグ（その種類、取り得る値、適用するブロック）を定義し、選択したブロック参照に設定して、CSV として保存できる集計表に一覧表示します。定義は DWG に保存されます。[タグ](topic:tags) を参照してください。
- **図面の範囲。** {{cmd:LIMITS}} は図面用の矩形を設定します。グリッドがその範囲を埋め、「ズーム」の「すべて」でその範囲が表示されます。範囲は輪郭として表示され、用紙の範囲とともに DWG と DXF に保存されます。[図面の範囲を設定する](topic:drawing-limits) を参照してください。

### 他の人やほかのプログラムとの作業

- **マークアップを改訂に変えます。** {{cmd:REDLINE}} は MarkupCraft が書き出したパッケージを読み込み、すべての変更を一覧表示します。各変更を、注記付きで承認または却下できます。承認された変更には雲マークと改訂履歴が付き、いずれも 1 回の元に戻す操作で行われます。また、MarkupCraft でマークアップを閉じるための回答ファイルを保存します。[マークアップを改訂に変える](topic:redline-to-revision) を参照してください。
- **git と Fossil でマージできる図面。** {{ui:マージしやすいファイル}} を {{ui:設定}} › {{ui:CadCraft}} でオンにすると、すべてのオブジェクトに決して変わらないキーが付きます（ファイルは約 10 パーセント大きくなります）。`cadcraft merge base ours theirs` を実行すると、2 人が 1 つの DWG または DXF に加えた編集を、オブジェクトごとにマージします。同じものを 2 人が変更した箇所だけを報告します。[1 つの図面に対する 2 人の編集をマージする](topic:merge-drawings) を参照してください。
- **変更内容を言葉で確認できます。** 「履歴」の「比較」では、分かりやすい一覧が表示されます。どこが変わったか、変更された範囲の大きさ、追加・削除・変更された内容、編集されたテキストです。[変更内容を言葉で説明する](topic:changes-in-words) を参照してください。
- **方位と角度。** 角度を求められるところならどこでも、N45°23'30"E のような測量の方位、または度・分・秒で方向を入力できます。AUNITS で角度の表示方法を設定します。[方位と角度を入力して表示する](topic:bearings-and-angles) を参照してください。
- **お使いの SHX フォント。** SHX フォントのフォルダーを CadCraft に指定すると、そのフォント名を指定した文字スタイルの文字が、画面上と印刷でそのフォントを使って描画されます。[お使いの SHX フォントで文字を描く](topic:shx-fonts) を参照してください。
- **テキストからの図表。** {{cmd:DIAGRAM}} は、Mermaid のフローチャート、PlantUML のコンポーネント図、D2、または「始点から終点」の一覧を読み取り、編集可能なブロックと接続線を描きます。[テキストから図表を描く](topic:text-to-diagram) を参照してください。
- **DWG 内の OLE オブジェクト。** {{cmd:OLELIST}} は、DWG が持つ OLE オブジェクトのうち、CadCraft が単独では配置できないものを一覧表示します。指定した場所に画像のコピーを配置します。[画像](topic:pictures#objects-from-other-programs-ole) を参照してください。
- **計算が図面と一緒に残ります。** 計算シートと設計上の理由は、クラス表とともに DWG に保存されます。

### 視覚に頼らない作図

- {{ui:視覚に頼らない作図}} を {{ui:設定}} でオンにします（または {{cmd:ACCESS}} と入力し、`On` と答えます）。CadCraft は、すべてのコマンドと結果をスクリーン リーダーで読み上げ、図面とカーソル付近にあるものを説明し、キーボードでカーソルを動かして点を指定できるようにします。また、スナップとグリップごとに音を鳴らします。ブラウザーがお使いのコンピューターで音声を認識できる場合は、コマンドを音声で入力できます。[視覚に頼らない作図](topic:draft-without-sight) を参照してください。

### 全アプリ共通

- **言語。** 54 言語に対応しています。そのうち 10 言語が新しく追加されました（リトアニア語、ラトビア語、ボスニア語、マラーティー語、テルグ語、アルバニア語、アフリカーンス語、フィリピン語、スワヒリ語、ウズベク語）。英語以外の言語は、ネイティブ スピーカーが確認するまで機械翻訳のドラフトです。
- **入力デバイス。** トラックパッド、ペン、3D マウス、ゲーム コントローラー、MIDI コントローラーを操作できます。
- **ツールバーの行数とプロパティ グリッド。** ほかの各アプリでは、{{ui:設定}} › {{ui:全般}} › {{ui:ツールバーの行数}} で、折り返し、2 行、1 行から選べます。CadCraft では、独自の設定を {{ui:設定}} › {{ui:CadCraft}} で保持します（[ツールバーの行数](topic:settings#toolbar-rows) を参照）。共有のプロパティ グリッドは、CadCraft ではなくほかの 3 つのアプリにあります。
- **問題、Live、アドオン。** すべてのアプリで警告を表示する共有の「問題」パネル、CadCraft Studio で誰がどこにいるかを示す Live ビュー（[1 つの図面を一緒に編集する](topic:work-live) を参照）、アドオンの一覧です。
- **お使いの AI を接続します。** CadCraft Studio から 8 つのアプリすべてに 1 回で接続できます。アプリごとに、読み取り専用、提案、編集のレベルを設定でき、アシスタントが行った操作を平易な言葉で記録したログを確認できます。CadCraft 自体は AI を持っていません。どのアプリの「質問」も、お使いが接続した AI を使います。

## 0.8.1 で修正

- **フィートとインチの図面で、プロパティに 150 と表示されていました**（本来は 12'-6" です）。アプリが自分で読み取る欄は、再びそのテキストを保持します。
- **クラス セクションが誤った型として読み取られていた DWG ファイル**（GitHub cadcraft#5）が、正しく開くようになりました。
- **十字カーソルがポップアップの後ろに表示されなくなりました。**
- **Studio と梱包版は、実行中に言語を切り替えられるようになりました。** 以前は英語のみでした。すべてのプラットフォームでは未検証です。言語が変わらない場合はお知らせください。
- **縦向きのタブレット**では、余ったグリッドの高さがキャンバスに割り当てられ、シート モードは 760 px 以下から始まります。
- **交差選択を使う STRETCH と LIMITS** は、Studio 0.8.0 で報告されていましたが、0.8 の Web ビルドではすでに正しく動作していました。報告者のインストーラーが古かったためです。Studio 0.8.1 にはこれらの修正が含まれています。

## このバージョンではまだ提供していないもの

- **0.8 と 0.8.1 にはコード署名がありません。** Windows で警告が表示されることがあります（{{ui:詳細情報}} を選び、次に {{ui:実行}} を選びます）。Mac では、CadCraft Studio を右クリックして {{ui:開く}} を選びます。ストア版のビルドは保留中です。iPad と iPhone のビルドは 0.8.1 で再ビルドされていません。
- **ペンのスケッチとスケッチ写真**は、作成したサンプル写真とマウスでのみ試されています。実際のペン、タッチ スクリーン、紙の上の手描きスケッチではまだ試されていません。
- **視覚に頼らない作図**は自動チェックでテストされています。スクリーン リーダーや視覚障害のあるテスターではまだテストされていません。
- **詳細図の共有**は 2 人での確認を受けていません。また、Team Cloud Plan のフォルダーをドキュメント フォルダーとして使う機能はまだ作成されていません。
- **マージ**は CadCraft の DWG および DXF ファイルで機能します。ほかのアプリのファイルについては、まだ作成されていません。
- **ウィンドウをまたいだ元に戻す:** CadCraft は完了した各操作を報告しますが、Studio にはすべてのアプリをまとめて元に戻す機能がまだありません。各アプリは、自分の操作だけを元に戻します。
- **DWG の OLE オブジェクト**は保持されますが、その場所には描画されません。
- **ほかのプログラムの印刷スタイル テーブル（CTB ファイル）の読み取り**は作成されていますが、ほかのプログラムのファイルでの確認はまだです。
- **AI の接続:** Studio でのワンクリック接続、ブラウザー AI 用のホスト型コネクター、Studio 内でのご自身の API キー、公開された MCP パッケージは、このリリースでは提供を約束していません。

それ以前のバージョンについては、[0.7 の新機能](topic:whats-new-0-7) を参照してください。
