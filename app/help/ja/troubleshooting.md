## ファイルを開く

| メッセージまたは症状 | 原因 | 対処 |
|---|---|---|
| 「CadCraft は DWG と DXF の図面を開きます。「…」はどちらでもありません。」 | ファイルが `.dwg` でも `.dxf` でもありません。 | 図面ファイル自体を開いてください。PDF は取り込むことができます (開くときにインポートするか添付するかを尋ねられます。[PDF下図](topic:pdf-underlay) を参照してください)。画像は `IMAGEATTACH` で挿入します。 |
| 「このバイナリ DXF は、オブジェクトの途中で終わっています。ファイルが途中で切れているか、破損しています。」 | バイナリ DXF が終端の前で止まっています。 | RECOVER と入力して読み取れる内容を開くか、ファイルを再度入手してください。 |
| 「このファイルは読み取り可能な DXF ではありません (行 … のグループコードが不正です)。」 | DXF が破損しているか、実際には DXF ではありません。 | ファイルを再度入手するか、DWG を入手してください。 |
| 「この図面は読み込めませんでした。破損しているか、リーダーがまだ対応していないバージョンで保存されています (…)。」 | DWG リーダーがこの図面を読み込めませんでした。 | 古いバージョンで保存された DWG、または DXF を入手してください。 |
| 「この図面は AutoCAD R11 / R12 (DWG AC1009) のもので、CadCraft が読み込める版より古いです …」 | Release 12 以前の DWG ファイルは、CadCraft が読み込めない形式を使用しています。 | 作成したプログラムで、DXF (任意のバージョン) または新しい DWG として保存し、それを開いてください。CadCraft の {{ui:名前を付けて保存}} では、この古い形式を必要とするプログラム向けに DXF R12 を選択できます。 |
| 最初の DWG で、「…を開けませんでした」の後にネットワークに関するメッセージが表示される | DWG リーダーをダウンロードできませんでした。オフラインで、CadCraft がオフライン用に保存されていないか、接続が切断されました。 | オンラインになって再試行するか、DXF を開いてください。{{ui:オフライン用に保存}} をクリックし、「オフライン準備完了」と表示されるまで待つと、次回からオフラインでも DWG ファイルを開けます。[オフラインでの作業](common:offline) を参照してください。 |
| オフラインボタンに「保存できませんでした」と表示される | 一部のファイルがダウンロードされませんでした。 | 接続を確認し、ボタンをクリックして再試行してください。 |
| オフラインボタンに「オフラインでは利用できません」と表示される | プライベートウィンドウや一部の管理対象コンピューターでは、オフラインのコピーを保存できません。 | 通常のウィンドウを使用するか、オンラインのままで作業してください。 |
| 接続がないと CadCraft が開かない | このブラウザーでオフライン用に保存されていないか、ブラウザーによって消去されました。 | 次回オンラインのときに {{ui:オフライン用に保存}} をクリックし、「オフライン準備完了」と表示されるまで待ってください。 |
| 図面は開くが一部が見当たらない | CadCraft がまだ描画できないオブジェクト、またはファイル内でオフまたはフリーズされているレイヤーです。 | 左パネルの「このファイルについて」を確認してください。{{ui:レイヤー}} パネルを確認してください。 |
| 文字が2行に折り返される | CadCraft はヘルベチカ系フォントで文字を描画するため、一部の CAD フォントより幅が広くなります。 | プロパティで文字を短くするか、追加の行をそのままにしてください。 |
| 円が楕円に見える、またはミラーされた文字が正しい向きで表示される | 作成元のプログラムで、オブジェクトが傾いた平面に描かれたか、下から見た状態でした。CadCraft はそのプログラムの平面図と同じく、上から見た状態で表示します。文字は左から右に読める状態に保たれます。 | 修正する必要はありません。他のプログラムと同じ見え方にするには、図面を平面化するか、オブジェクトを上から描いたものを依頼してください。 |
| ブロック、円、または寸法が、作成元のプログラムとは別の場所にある | CadCraft が誤って読み取る図面の要素です。 | Discord でお知らせください。可能であればファイルも添付してください。 |

## コマンドライン

| メッセージまたは症状 | 原因 | 対処 |
|---|---|---|
| 「不明なコマンド "…"。一覧は HELP で表示します。」 | その名前のコマンドまたはエイリアスはありません。 | `HELP` と入力するか、[コマンドリファレンス](topic:commands) を参照してください。一部のおなじみのコマンドは、[まだ作成されていません](topic:not-built-yet)。 |
| 入力中にコマンドラインの横に「No such command」と表示される | 入力内容に一致するものがまだありません。 | 入力を続けるか、スペルを確認してください。 |
| 「点またはオプションのキーワードが必要です。」 | 入力内容が点でもオプションでもありません。 | 形式を確認してください: `x,y`、`@dx,dy`、`@d<a`、または1つの数値。[座標と距離の入力](topic:coordinate-entry) を参照してください。 |
| 「正の数値または2点が必要です。」 | 距離が負の数値であるか、数値ではありません。 | 正の数値を入力するか、2点をクリックしてください。 |
| 「角度 (度) または2点が必要です。」 | 角度が数値ではありません。 | 度を数値だけで入力してください。 |
| 「数値が必要です。」 | 数値が求められていました。 | 数字だけを入力してください。 |
| 「無効なオプションキーワードです。」 | 入力した文字がオプションと一致しません。 | 角かっこ内に示された大文字の文字を入力してください。 |
| `*Cancel*` | {{key:Esc}} を押したか、点が必要な場所で {{key:Enter}} を押しました。 | コマンドをもう一度開始してください。 |
| コマンドラインに入力が届かない | パネルまたはダイアログ内のボックスにカーソルがあります。 | {{key:Enter}} または {{key:Esc}} を押すか、図面をクリックしてください。 |
| コマンドで、選択していないオブジェクトが使われる | コマンドを開始する前に選択されていました。 | コマンドの前に {{key:Esc}} を押してください。 |
| 線が予期しない場所に描かれる | `x,y` は絶対座標です。 | 相対座標には `@dx,dy` を使用してください。 |
| 「先に現在のコマンドを完了するかキャンセルしてください (Esc)。」 | コマンド実行中に {{key:Mod+S}} を押しました。 | {{key:Esc}} を押してから保存してください。 |
| 「DWG (AutoCAD 2000) として保存できませんでした: … 名前を付けて保存を使用し、DXF を試してください。」 | 図面の一部を DWG として書き込めませんでした。 | {{key:Mod+Shift+S}} を押し、{{ui:DXF R12}} を選んで {{ui:保存}} をクリックしてください。 |
| 「保存されていません。」 | {{ui:コピーを保存}} ダイアログを {{ui:キャンセル}} または {{key:Esc}} で閉じました。 | {{key:Mod+Shift+S}} をもう一度押して {{ui:保存}} をクリックしてください。 |

## 編集

| メッセージまたは症状 | 原因 | 対処 |
|---|---|---|
| オブジェクトを選択できない | そのレイヤーがロック、オフ、またはフリーズされています。または、シート上にいて、それがビューポート内のモデルです。 | レイヤーのロックを解除するか、{{ui:モデル}} タブに移動してください。 |
| 「そこには何もありません。」 | クリックした場所にオブジェクトがありません。 | ズームインして、線そのものをクリックしてください。 |
| 「そこではそのオブジェクトと交差するものがありません。」 | {{cmd:TRIM}} は、指定した部分と交差するオブジェクトを見つけられませんでした。 | 切り取り線が本当にそれと交差しているか確認してください。 |
| 「そのオブジェクトはトリムできません。」 | トリムは、線、円弧、円、ポリラインで機能します。 | 先にブロックを分解するか、削除して描き直してください。 |
| 「その方向に境界がありません。」 | {{cmd:EXTEND}} が交差する対象を見つけられませんでした。 | 伸ばしたい側の端に近い位置を指定してください。 |
| 「そのオブジェクトはオフセットできません。」 | オフセットは、線、円弧、円、ポリラインで機能します。 | 先に分解するか、平行線を描いてください。 |
| 「その距離ではオフセットできません。」 | オフセットによって図形が裏返ってしまいます。 | より小さい距離を使用してください。 |
| 「半径が大きすぎます。」または「距離が大きすぎます。」 | フィレットまたは面取りが線の端を超えてしまいます。 | `R` で小さい半径を、または `D` で小さい距離を設定してください。 |
| 「開いたポリラインの最初または最後のセグメントのみ切り戻せます。」 | 角がポリラインの中央に切り込んでしまいます。 | 隣り合う2つのポリラインのセグメントを指定するか、すべての角に `P` を使用してください。 |
| 「2本目には、別の線を指定してください。」 | 2本目の指定が同じ線であるか、線ではありません。 | 別の線を指定してください。 |
| 「ポリライン、ブロック参照、寸法のみ分解できます。」 | 選択したものに分解できるものがありませんでした。 | ポリライン、ブロック参照、または寸法を選択してください。 |
| 「それは現在のレイヤーです。先に別のレイヤーを現在のレイヤーにしてください。」 | 現在のレイヤーをオフにしようとしました。 | 別のレイヤー名をクリックしてから、このレイヤーをオフにしてください。 |
| 「… という名前のレイヤーは既にあります」 | レイヤー名は一意である必要があります。 | 別の名前を選択してください。 |
| 「元に戻す操作はありません。」 | 元に戻せる操作がないか、図面を開いたまたは作成を開始した (これにより履歴が消去されます)。 | — |

## 寸法とブロック

| メッセージまたは症状 | 原因 | 対処 |
|---|---|---|
| 寸法の文字や矢印が極端に小さい、または大きい | サイズは図面単位で指定されます。全体の尺度が図面に合っていません。 | {{cmd:DIMSCALE}} を印刷縮尺に設定してください。[寸法サイズを設定する](topic:dimension-settings) を参照してください。 |
| 「測定したい角度の内側の点を指定してください。」 | 角度寸法の位置が辺の上にあります。 | 角の内側をクリックしてください。 |
| 「それらの線は平行です。」 | 平行線の間には角度がありません。 | 交わる2本の線を指定してください。 |
| 「直線寸法または平行寸法を指定してください。」 | {{cmd:DIMCONTINUE}} または {{cmd:DIMBASELINE}} は、開始点となる寸法が必要です。 | 直線寸法または平行寸法を指定してください。 |
| 「この図面にはまだブロックがありません。F はファイルから挿入し、L はライブラリから …」 | 図面に独自のブロックがありません。 | `F` または `L` と入力するか、{{cmd:BLOCK}} でブロックを作成してください。 |
| 「ブロック "…" がありません。」 | 名前が間違っています。 | メッセージに、存在するブロックの一覧が表示されます。 |
| 「ブロック名は * で始めることや … を使用することはできません」の後に文字の一覧 | 名前にブロックで使用できない文字が含まれています。 | 文字、数字、`-`、`_` を使用してください。 |
| 「ブロックは自分自身を含めることはできません。」 | 選択内容に、作成中のブロックへの参照が含まれています。 | その参照を除外してください。 |
| 「オブジェクトが選択されていないため、作成されませんでした。」 | 選択前に {{key:Enter}} を押しました。 | {{cmd:BLOCK}} をもう一度実行し、オブジェクトを選択してください。 |

## シートと印刷

| メッセージまたは症状 | 原因 | 対処 |
|---|---|---|
| 「ビューポートはレイアウト上に配置します。先にレイアウトタブを開くか、LAYOUT で作成してください。」 | {{ui:モデル}} タブで {{cmd:MVIEW}} を実行しました。 | 先にシートタブをクリックしてください。 |
| 「先にビューポートを含むレイアウトを開いてください。」 | {{ui:モデル}} タブで {{cmd:VPVIEW}} を実行しました。 | 先にシートタブをクリックしてください。 |
| ビューポートの尺度が10倍間違って見える | 図面の単位が間違っています。 | {{ui:現在の設定}} で {{ui:単位}} を設定してください。 |
| 「まだ印刷するものがありません。」 | モデルが空です。 | 何かを描くか、図面を開いてください。 |
| 「印刷する範囲を指定してください。」 | {{ui:窓…}} が選択されていますが、窓が指定されていません。 | {{ui:指定}} をクリックし、2つの角を指定してください。 |
| 「… 用紙より大きいため、端が切り取られます。」 | 範囲がその尺度に収まりません。 | より小さい尺度、またはより大きい用紙を選ぶか、{{ui:用紙に合わせる}} を選んでください。 |
| 「ブラウザーが新しいタブをブロックしたため、代わりに PDF がダウンロードされました。」 | このサイトではポップアップがブロックされています。 | ダウンロードされた PDF を開くか、このサイトのポップアップを許可してください。 |
| 文字が「?」として印刷される | PDF のフォントにその文字がありません (まれな漢字、複雑な字形処理が必要なヒンディー語などの文字)。またはより大きなフォントを取得できませんでした (オフライン)。ヨーロッパ系の文字、キリル文字、ギリシャ文字、ヘブライ語、アラビア語、ペルシア語、ウルドゥー語、タイ語、中国語、日本語、韓国語はそのままの文字で印刷されます。 | アラビア文字系、タイ語、中国語、日本語、韓国語の場合は、接続した状態で再度印刷してください。その他の文字は、まだ作成されていません。 |
| 構築線が PDF に表示される | そのレイヤーが印刷対象になっています。 | レイヤーのプリンターボタンをクリックしてください。 |
| すべての線が同じ太さに見える | 線の太さが {{ui:既定値}} であるため、ダイアログで設定されたペンの幅で印刷されます。 | レイヤーまたはオブジェクトに、右パネルで {{ui:線の太さ}} を設定するか、ダイアログで {{ui:線の太さ}} を選択してください。画面で線の太さを確認するには、ステータスバーの {{ui:線幅}} を押してください。 |

## キーと画面

| 症状 | 原因 | 対処 |
|---|---|---|
| F3、F7、または F8 で音量が変わるか、Mission Control が開く | Mac のファンクションキーです。 | **fn** を押しながら操作するか、ステータスバーのボタンを使用してください。[キー、マウス、トラックパッド](common:keys) を参照してください。 |
| F7 でキャレットブラウズについて尋ねられる | Firefox 独自の F7 の使用です。 | 「いいえ」を選び、{{ui:グリッド}} ボタンを使用してください。 |
| {{key:Mod+N}} でブラウザーウィンドウが開いた | ブラウザーがそのキーを使用しています。 | {{ui:新規}} をクリックするか、`NEW` と入力してください。 |
| {{key:Mod+A}} でコマンドラインのテキストが選択された | コマンドラインにカーソルがありました。 | 先にオブジェクトをクリックするか、`Select objects` のプロンプトで `ALL` と入力してください。 |
| {{key:Delete}} で削除されない | コマンドラインにカーソルがありました。 | `E` と入力して {{key:Enter}} を押してください。 |
| Mac のトラックパッドで右クリックが機能しない | Control-クリックは通常のクリックとみなされる場合があります。 | 2本の指でクリックしてください。 |
| トラックパッドで画面がパンしない | 中ボタンがなく、Space ではパンできません。 | 2本の指でスワイプすると 2D ビューがパンします (ピンチとマウスホイールでズームします)。または、右クリックを押したままドラッグしてください。 |
| 最初の {{key:Esc}} で全画面表示が終了した | ブラウザーは全画面表示の終了に Esc を使用します。 | {{key:Esc}} をもう一度押してコマンドをキャンセルしてください。 |
| Mac で {{key:F1}} が機能しない | F1 は明るさキーです。 | **fn** を押しながら操作するか、{{ui:ヘルプ}} をクリックしてください。 |
| ヘルプの検索ボックスに入力される | ヘルプパネルにカーソルがあります。 | 図面をクリックしてください。 |
| 図面が空白になった | 非常に遠くにズームしました。 | {{ui:範囲}} をクリックするか、ホイールをダブルクリックしてください。 |
| タブを閉じるときに「このサイトを離れますか?」と表示される | 保存されていない変更があります。 | 残って {{key:Mod+S}} で保存してから閉じてください。 |
