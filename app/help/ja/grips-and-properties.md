## 学習内容

コマンドを使わずにオブジェクトを変更する2つの簡単な方法があります。**グリップ**をドラッグするか、右側の**プロパティ**パネルに新しい値を入力します。

## グリップ

コマンドを実行していない状態でオブジェクトを選択する（一度に最大200個まで）と、小さな四角形が表示されます。これがグリップです。

| オブジェクト | グリップ |
|---|---|
| 線分 | 両端と中央（線分全体を移動） |
| 円 | 中心（移動）と円周上の4点（半径を変更） |
| 円弧 | 中心と両端（開始点と終了点を変更） |
| ポリライン | すべての頂点 |
| 文字、点、ブロック参照 | 挿入点 |
| 楕円 | 中心 |
| 寸法 | 寸法を定義する点と寸法線の位置 |
| ビューポート | 中心（移動）と4隅（サイズ変更） |

### グリップを移動する

1. 線を描いてクリックします。3つのグリップが表示されます。
2. 片端のグリップをクリックします。ステータスバーに「このグリップの移動先をクリック（Esc でキャンセル）。スナップと直交モードが適用されます。」と表示されます。
3. 十字カーソルを動かします。プレビューが追従します。
4. 新しい位置をクリックするか、別のオブジェクト上の点にスナップしてクリックします。

端点が移動し、線のほかの部分は動きません。グリップを押したままドラッグし、移動先で離すこともできます。

:::note
グリップの位置は座標で入力できません。正確な位置を指定するには、点にスナップするか、プロパティに値を入力してください。
:::

{{key:Esc}} を押すか右クリックすると、グリップの移動をキャンセルします。

## プロパティ

右側のパネルには、選択したもののプロパティが表示されます。

1. 線をクリックします。パネルの見出しに「{{ui:線分}}」と表示されます。
2. {{ui:長さ}} の欄をクリックし、`2500` と入力して {{key:Enter}} を押します。

線の長さが正確に2500になり、始点と角度は保持されます。{{key:Enter}} を押すか、ほかの場所をクリックすると値が適用されます。{{key:Esc}} を押すと、元の値に戻ります。すべての変更は1回の元に戻す操作になります。複数のオブジェクトを同時に変更した場合も同様です。

欄には式（`=2*45`）や単位付きの長さ（`3'6"`、`900mm`）を入力できます。すべての点にはX、Y、Zがあり、複数のオブジェクトをまとめて変更することもできます。これらの詳細は[プロパティパネル](topic:properties-panel)を参照してください。

## よくある間違い

- **グリップが表示されない。** コマンドが実行中（{{key:Esc}} を押してください）、200個を超えるオブジェクトが選択されている、またはオブジェクトがロックされたレイヤー上にあります。
- **グリップが間違った位置に移動した。** スナップが引っかかっています。クリックする間 {{key:Shift}} を押したままにすると、スナップを無視します。
- **プロパティへの入力が反映されない。** {{key:Enter}} を押すか、ほかの場所をクリックして適用してください。受け付けられない入力（0以下の長さや半径、数値ではない文字など）の場合は欄が赤くなり、理由が表示されます。
- **プロパティの欄に入力した文字がコマンドとして扱われない。** 欄にカーソルがあるとキー入力はその欄に入ります。{{key:Enter}} または {{key:Esc}} を押してから、コマンドを入力してください。
