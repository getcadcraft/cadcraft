## 行うこと

ファイルを図面に取り込み、正しいサイズで取り込まれていることを確認します。

## 手順

1. いつもどおりファイルを取り込みます: `INSERT` › ファイル、`XATTACH`、`POINTCLOUDATTACH`、またはライブラリパネルの {{ui:ファイル}}。
2. ファイルが単位を示している場合は、何も確認されません。コマンドラインに、ファイルが示す単位と、図面の単位と異なる場合に使用される尺度が表示されます。
3. 示していない場合は、ダイアログでファイルの **単位** が尋ねられます。ファイル内の1単位が何かを選び、{{ui:この単位を使用}} をクリックします。回答するまで、何も配置されません。
4. {{ui:キャンセル}} (または {{key:Esc}} キー) を押すと、何も取り込まれません。

## 単位を示すファイル

- **DWG と DXF**: 図面の挿入単位 (`$INSUNITS`)。これがないファイルについては確認されます。
- **点群**: 座標系を持つ LAS と LAZ、E57、PTX、PLY は単位を示します。それ以外は確認されます。
- **OBJ**: 単位を示すことはありません。確認されます。
- **glTF と GLB**: 形式独自の規則により、メートルです。
- **画像**: 固有のサイズを持ちません。`IMAGEATTACH` は幅を尋ね、そのファイルに以前指定した幅を提示します。
- **スキャン**: 解像度 (1インチあたりのドット数、dpi) を示すスキャンは、図面の単位で実際のサイズで取り込まれます。`SCANATTACH` は引き続き幅を尋ねます。
- **点群アドオン**: 単位を示さないファイルから点群を作成するときに確認し、点群の数値に、その点群が持つ単位で表示を付けます。

## 知っておくと便利なこと

- DWG または DXF を図面として開く場合は、何も確認されません。コマンドラインに、ファイルが示す単位、または単位を示していないことが表示されます。図面の単位は {{ui:プロパティ}} で設定します。
- この図面にも単位がない場合は、ファイルを変換できません。数値のまま配置され、コマンドラインにその旨が表示されます。
- 回答は、このコンピューター上のそのファイルについて、すべての CadCraft アプリで記憶されます。次回取り込むときには確認されず、コマンドラインに、記憶された単位が使用されたことが表示されます。
- 再度確認されるようにするには、コマンドパレット ({{key:Mod+K}}) › **インポートしたファイルの単位を再度確認** を選びます。
