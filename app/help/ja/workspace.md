画面は7つの部分でできています。上から順に、アプリバー、ツールバー、左右にパネルを持つ作図領域、図面の下のタブ、コマンドライン、ステータスバーです。

## アプリバー

いちばん上の細いバーは、図面ではなくサイトに属しています。CadCraftのマーク、アプリ名、実行中のバージョン、アプリのページへのリンク、{{ui:ヘルプ}}ボタン(または{{key:F1}}キー)、{{ui:オフライン用に保存}}ボタン、{{ui:全画面表示}}ボタン、2つのテーマボタン({{ui:ペーパー}}と{{ui:モデル}})が表示されます。

{{ui:設定}}ボタン(歯車)には、CadCraft独自の設定と、すべてのアプリが共有する設定があります。[CadCraftの設定](topic:settings)を参照してください。

{{ui:オフライン用に保存}}は、DWGリーダーを含むCadCraftのコピーをこのブラウザーに保持して、接続がなくても開けるようにします。ラベルには状態が表示されます。「Saving N of M」、「Offline ready」、「Could not save」、「Offline not available」のいずれかです。[オフラインで使う](common:offline)を参照してください。

:::note
アプリバーの{{ui:ペーパー}}ボタンと{{ui:モデル}}ボタンは、画面の色を変えるだけです。{{ui:ペーパー}}は明るいテーマ、{{ui:モデル}}は暗いテーマです。図面の下にある{{ui:モデル}}タブとは関係がありません。そちらは図面とそのシートを切り替えます。
:::

{{ui:全画面表示}}ボタン、または{{key:Ctrl+Shift+F}}キー(Macを含むすべてのコンピューターでControlキー)は、3つの画面モードを順に切り替えます。通常、全画面、バーを隠した全画面です。バーを隠しているときは、ポインターを画面の上端に移動すると、バーが戻ります。

## ツールバー

アプリバーの下がツールバーです。すべてのボタンは、入力したときとまったく同じようにコマンドを実行するので、どちらの方法でもコマンドラインは同じ質問をします。ボタンにポインターを合わせると、そのコマンドのエイリアスが表示されます。グループは次のとおりです。

| グループ | ボタン |
|---|---|
| ファイル | {{ui:新規}}、{{ui:開く}}、{{ui:保存}}、{{ui:名前を付けて保存}}、{{ui:印刷}} |
| 作図 | {{ui:線分}}、{{ui:ポリライン}}、{{ui:円}}、{{ui:円弧}}、{{ui:長方形}}、{{ui:多角形}}、{{ui:楕円}}、{{ui:文字}}、{{ui:段落}}、{{ui:ハッチング}}、および{{ui:その他}}: {{ui:点}}、{{ui:構築線}}、{{ui:レイ}}([構築線とレイ](topic:construction-lines)を参照) |
| 修正 | {{ui:移動}}、{{ui:コピー}}、{{ui:回転}}、{{ui:尺度変更}}、{{ui:鏡像}}、{{ui:ストレッチ}}、{{ui:オフセット}}、{{ui:トリム}}、{{ui:延長}}、{{ui:フィレット}}、{{ui:面取り}}、{{ui:分解}}、{{ui:削除}}、および{{ui:その他}}: {{ui:配列複写}}、{{ui:結合}}、{{ui:プロパティ複写}}、{{ui:部分削除}}、{{ui:長さ変更}} |
| 注釈 | {{ui:長さ}}、{{ui:平行}}、{{ui:角度}}、{{ui:半径}}、{{ui:直径}}(寸法)、{{ui:引出線}}(マルチ引出線)、および{{ui:その他}}: {{ui:直列寸法}}、{{ui:並列寸法}}、{{ui:雲マーク}} |
| パラメトリック | {{ui:自動}}、{{ui:拘束}}、{{ui:寸法}}、{{ui:パラメーター}}、および各拘束を含む{{ui:その他}}([図面を拘束する](topic:constraints)を参照) |
| ブロック | {{ui:作成}}、{{ui:挿入}}、{{ui:ライブラリ}}、および{{ui:その他}}: {{ui:ブロックを編集}}、{{ui:属性を定義}} |
| シート | {{ui:新規シート}}、{{ui:ビューポート}} |
| 編集 | {{ui:元に戻す}}、{{ui:やり直し}}、{{ui:コピー}}(クリップボードへ)、{{ui:貼り付け}}、および{{ui:その他}}: {{ui:切り取り}}、{{ui:コピー}}、{{ui:貼り付け}}、{{ui:同じ位置に貼り付け}}、{{ui:複製して移動}}、{{ui:削除}}、{{ui:すべて選択}}、{{ui:選択解除}}、{{ui:クイック選択}}、{{ui:類似選択}}、{{ui:検索と置換}}を、それぞれのキーとともに表示するメニュー |
| 表示 | {{ui:範囲}}、{{ui:窓}}、{{ui:直前}}、および{{ui:その他}}: {{ui:距離を計測}}、{{ui:面積}}、{{ui:計測(半径、角度 …)}}、画面分割の{{ui:左右に分割}}、{{ui:上下に分割}}、{{ui:4分割}}、{{ui:1ペイン}}([画面を分割する](topic:split-screen)を参照)、および{{ui:ビューを左に90°回転}}、{{ui:ビューを右に90°回転}}、{{ui:ワールドに戻る}}([ビューを回転する](topic:ucs-and-turned-view)を参照) |

{{ui:修正}}グループの{{ui:コピー}}は{{cmd:COPY}}コマンドです(基点を指定し、続いて各コピーの配置先を指定します)。{{ui:編集}}グループの{{ui:コピー}}は、オブジェクトをクリップボードに置き、{{ui:貼り付け}}に使います。[コピー、貼り付け、複製](topic:copy-paste)を参照してください。実行中のコマンドのボタンは、コマンドが終わるまで強調表示されたままです。ツールチップにはWindowsのショートカット(「Ctrl+O」)が表示されます。Macでは{{key:Mod+O}}でも動作します。

高さの低いウィンドウ(たとえば表示を125 %以上に拡大したノートパソコン)でも、ツールバーが図面の場所を奪うことはありません。図面の高さが足りなくなりそうなときは、ボタンのアイコンの下の文字とグループ名が省かれ(名前はボタンにポインターを合わせると表示されます)、それでも足りなければ、ツールバーは横にスクロールする1行になります。ウィンドウを高くすると、文字が戻ります。

## 左パネル

左のパネルには3つのセクションがあります。

- **{{ui:レイヤー}}。** 図面内のすべてのレイヤーが一覧表示され、現在のレイヤーには塗りつぶされた点が付きます。名前をクリックすると、そのレイヤーが現在のレイヤーになります。各行には色見本(クリックして色を選択)と4つのボタンがあります。オン・オフ(目)、フリーズ(雪の結晶)、ロック(南京錠)、印刷(プリンター)です。{{ui:新しいレイヤー}}は、追加用のボックスを開きます。[レイヤーで図面を整理する](topic:layers)を参照してください。
- **{{ui:ブロック}}。** 図面で定義されているブロックと、それぞれの使用回数、各ブロックの{{ui:挿入}}ボタンが表示されます。[ブロックを作成して挿入する](topic:blocks)を参照してください。
- **{{ui:図面}}。** 開いているファイルに関する情報です。名前(保存されていない編集があるときは「(変更あり)」付き)、形式、サイズ、単位、オブジェクト、レイヤー、ブロック、シートの数。ファイルを開いたあとは、「このファイルについて」ボックスに、CadCraftが表示できなかったもの、または変換が必要だったものが一覧表示されます。

## 作図領域

画面の中央が図面です。ポインターは十字カーソルです。CadCraftが点を求めているときは、小さなマーカーとラベル(「端点」、「中点」)で、オブジェクトスナップが当たる位置が示されます。オブジェクトを求めているときは、十字カーソルにピックボックスが付き、その下にあるオブジェクトが強調表示されます。

図面が空のときは、「作図を始める」カードにいくつかの最初のコマンドが表示されます。コマンドを実行するかファイルを開くとすぐに消えます。DWGまたはDXFファイルをこの領域のどこにでもドロップして開けます。

## 図面の下のタブ

図面の下にはタブがあります。最初に{{ui:モデル}}、次に{{ui:3D}}、続いてシート(レイアウト)ごとに1つのタブ、最後に{{ui:+}}ボタンです。

- {{ui:モデル}}は図面そのもので、実寸、図面の単位です。
- {{ui:3D}}は、地面の上に置かれた図面と、そこから作られたソリッドを表示します。表示している間、ツールバーには作図のグループの代わりに{{ui:3D}}グループが表示されます。[3Dでモデリングする](topic:3d-solids)を参照してください。
- 各シートのタブは、表題欄とモデルを映すビューポートを持つ用紙です。ここに描くものは用紙の単位(ミリメートルまたはインチ)です。ビューポートの内側をダブルクリックすると、ビューポート越しにモデルを操作できます([ビューポート越しにモデルを操作する](topic:sheets-and-viewports#work-on-the-model-through-a-viewport)を参照)。長いシート名はタブ上で短く切り詰められます。タブにポインターを合わせると全体の名前が表示されます。シートが多い場合は、{{ui:設定}} › {{ui:CadCraft}} › {{ui:シートタブ}} › {{ui:シート番号のみ}}にすると、タブに各シートの番号(A-101)だけが表示されます。
- {{ui:+}}は、境界線、表題欄、ビューポート1つを持つ新しいシートを作成します。{{cmd:LAYOUT}}コマンドと同じです。
- シートのタブをダブルクリックすると名前を変更できます。タブにフォーカスがあるときは、{{key:Left}}キーと{{key:Right}}キーでタブ間を移動できます。

各タブは、それぞれ独自のズームとパンを保持します。[シートを設定する](topic:sheets-and-viewports)を参照してください。

## 右パネル: プロパティ

右のパネルは、選択内容によって変わります。

- **何も選択されていない状態、{{ui:モデル}}タブ:** 見出しは{{ui:現在の設定}}です。ここで、新しいオブジェクトの{{ui:レイヤー}}、{{ui:色}}、{{ui:文字の高さ}}、図面の{{ui:単位}}、新しい寸法のサイズ({{ui:文字の高さ}}、{{ui:矢印のサイズ}}、{{ui:小数点以下の桁数}}、{{ui:全体の尺度}})を設定します。
- **何も選択されていない状態、シート上:** 見出しは「シート:」とシート名です。シートの名前を変更し、{{ui:用紙}}と{{ui:向き}}を変更し、{{ui:このシートを印刷}}または{{ui:このシートを削除}}できます。新しいオブジェクトの設定は、その下に続きます。
- **オブジェクトが1つ選択されている状態:** 見出しにその種類(線分、円、文字、寸法、ビューポート …)、続いてレイヤー、色、ジオメトリが表示されます。新しい値を入力して{{key:Enter}}キーを押すと変更されます。
- **複数のオブジェクトが選択されている状態:** その数と、共通の{{ui:レイヤー}}と{{ui:色}}が表示されます。どちらかを変更すると、すべてが変わります。「Varies」は、値が異なることを意味します。

[グリップとプロパティで編集する](topic:grips-and-properties)を参照してください。

その下には、{{ui:パラメーター}}を選ぶか{{cmd:PARAMETERS}}と入力すると{{ui:パラメーター}}パネルが開き、すべてのパラメーターと寸法拘束が1つの表にまとめて表示されます。[パラメーターと式を使う](topic:parameters)を参照してください。

## コマンドライン

下部がコマンドラインです。操作した内容の履歴と、その下にプロンプトがあります。

- 何も実行されていないとき、プロンプトのラベルは`コマンド:`です。コマンドの実行中は、質問、角かっこ内のオプション、山かっこ内の既定値が表示されます。たとえば`円の半径を指定 [直径(D)] <500>:`のようになります。
- コマンド名を入力すると、右側に一致するコマンドの候補が表示されます。{{key:Tab}}キーを押すと、先頭の候補を採用します。「そのようなコマンドはありません」は、一致するものがないことを意味します。
- {{key:Up}}キーと{{key:Down}}キーで、以前に入力した行を呼び出せます。
- 履歴には直近の400行が保持されます。コマンドからのメッセージ、{{cmd:DIST}}と{{cmd:LIST}}による計測結果、保存と印刷のレポートがここに表示されます。

## ステータスバー

最下段がステータスバーです。

- 左に**座標**: 十字カーソルのXとY。コマンドに基点があるときは、そこからの距離と角度も表示されます。たとえば`Δ 1200 < 90°`です。
- 中央に**メッセージ**: 「直交モード オン」や「現在のレイヤー: Walls」などです。数秒後に消えます。
- 右に**{{ui:グリッド}}**、**{{ui:直交}}**、**{{ui:極}}**、**{{ui:スナップ}}**、**{{ui:トラック}}**、**{{ui:動的}}**、**{{ui:線幅}}**。それぞれがトグルで、押されているボタンがオンです。{{ui:線幅}}は線の太さを画面に表示します([線の太さと線種](topic:units-papers-scales#line-weights-and-linetypes)を参照)。{{ui:スナップ}}の隣の小さな矢印は{{ui:オブジェクトスナップ}}を開き、有効にするスナップにチェックを入れます。[オブジェクト上の点にスナップする](topic:object-snaps)を参照してください。

## PDFに印刷ダイアログ

{{ui:印刷}}(または{{key:Mod+P}})は、左に設定、右にライブプレビューを表示する{{ui:PDFに印刷}}ダイアログを開きます。[PDFに印刷する](topic:plot-pdf)を参照してください。

## ヘルプ

{{key:F1}}キーまたは{{ui:ヘルプ}}ボタンで、このヘルプがサイドパネルとして開きます。その横で図面は引き続き使えます。接続がなくても動作します。もう一度{{key:F1}}キーを押すか、パネル内で{{key:Esc}}キーを押すと閉じます。[このヘルプの使い方](common:help)を参照してください。
