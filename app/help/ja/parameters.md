## すべてのサイズを1つの表で

{{ui:Parameters}}パネル（{{ui:Parametric}}グループの{{ui:Parameters}}ボタン、または{{cmd:PARAMETERS}}と入力）には、すべての寸法拘束（`d1`、`rad1`、`dia1`、`ang1`、または付けた名前）と、独自のパラメーターが一緒に表示されます。どの名前も、どの式でも使えます。

各行には次の項目があります。

- **名前:** 新しい名前を入力すると名前が変わります。その名前を使うすべての式が追従します。
- **式:** 数値（`40`）または式（`width / 2 + gap`）。式を入力して{{key:Enter}}を押すと、図面が追従します。
- **値:** 式を計算した結果。式で駆動されている行では、ここに数値を入力することもできます。CadCraft はその背後にあるパラメーターを計算します。`d1 = width / 2`の場合、d1の値に`30`を入力すると、`width`は60になります。

2つのパラメーターが1つの値を駆動している場合（`width / 2 + gap`）、どちらを変更するかをダイアログが尋ねます。すべての変更は、1回の元に戻す操作（{{key:Mod+Z}}）です。

## 独自のパラメーターを追加する

1. {{ui:Parameters}}パネルを開きます。
2. 名前（`gap`）と値（`10`）を入力し、{{ui:Add}}を選択します。
3. 使います: d1の式に`width / 2 + gap`と入力し、{{key:Enter}}を押します。

名前は文字または`_`で始まり、文字、数字、`_`で構成されます。関数名、`pi`、単位名は名前にできません。

## 式

| 書き方 | 意味 |
|---|---|
| `+ - * / ^ %` | 加算、減算、乗算、除算、べき乗、剰余 |
| `( )` | グループ化 |
| `sin cos tan asin acos atan atan2` | 角度（度）による三角関数 |
| `sqrt pow exp ln log abs sign` | 平方根、べき乗、対数、絶対値、符号 |
| `ceil floor int round min max` | 丸めと上限・下限 |
| `if(a > b, x, y)` | 条件による選択 |
| `pi` | 3.14159… |

数値には単位を付けられます: `25mm`、`1in`、`2'`、`90deg`。単位付きの長さはミリメートルに変換されるため、単位はミリメートルで測定された図面でのみ使ってください。それ以外の場合は、単位なしの数値を入力してください。

## コマンドラインで

`-PARAMETERS`は、パネルを使わずに同じことを行います: `N`（新規）、`E`（編集。寸法拘束も含む）、`R`（名前の変更）、`D`（削除）、`?`（一覧）。

## 拒否される内容

- 直接的または間接的に自分自身を使う式: 「width と d1 が互いに使用しています。」
- サイズとして取れない値: 負の長さ、180°を超える角度。
- 他の拘束と両立しない値: 何も変わらず、メッセージが妨げとなっている拘束の名前を示します。
- 使用されているパラメーターの削除: パネルは、先にその値を使用箇所に書き込むことを提案します。寸法拘束の名前は、拘束を削除することで削除されます。
