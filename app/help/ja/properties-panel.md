## これから学ぶこと

プロパティパネルを開く方法、1つまたは100のオブジェクトを一度に変更する方法、正確な座標 (Zを含む) を入力する方法、数値フィールドで式と単位を使う方法、そしてオブジェクトの種類ごとに表示される内容を説明します。

## 開く

パネルは右側にあります。前面に表示するには:

- {{key:Mod+1}}キーを押す、または{{cmd:PROPERTIES}} (または `PR`、`CH`、`MO`) と入力します。
- オブジェクトをダブルクリックします (文字とマルチ引出線は、代わりにテキストエディターを開きます)。

このパネルは他のパネルと同様に移動できます。グリップをドラッグすると、左、右、または下にドッキングします。図面の上にドロップすると、フローティングになります ([パネルを配置して、2台目のモニターを使う](common:arrange-panels)を参照)。

### 折りたたむ

パネル右上のピンボタンは、**自動的に非表示**をオンにします。パネルは右端の細い帯に折りたたまれ、図面に領域が広がります。帯にポインターを合わせる (または{{key:Mod+1}}キーを押す) と、図面の上に開きます。離れると再び折りたたまれます。ピンをもう一度クリックすると、開いたままになります。{{cmd:PROPERTIESCLOSE}}でも折りたたまれます。

## セクション

プロパティはセクションにまとめられ、折りたたむことができます: **全般**、**ジオメトリ**、**テキスト**、**線と矢印**、**フィット**、**基本単位**、**代替単位**、**公差**、**パターン**、**その他**。ブロックの場合は**属性**と**ライブラリ項目**も表示されます。セクション名をクリックすると、折りたたまれたり開いたりします。CadCraftは、どのセクションを折りたたんだかを記憶します。

名前と値の間の細い線をドラッグすると、名前の幅を広げたり狭めたりできます。ダブルクリックすると元に戻ります。キーボードを使う場合は、その線にフォーカスを移し、矢印キーを使用します。

## 値を変更する

1. 行をクリックします。見出しには「線分」と表示されます。
2. {{ui:Length}}をクリックします。編集中は、丸められた値ではなく、完全な値が表示されます。
3. `2500`と入力し、{{key:Enter}}キーを押します。線は長さ2500になり、始点と角度は保持されます。

{{key:Enter}}キーまたは別の場所をクリックすると値が適用され、{{key:Esc}}キーで古い値に戻ります。すべての変更は1回の元に戻す操作になります。

### 式と単位

すべての数値フィールドは、単なる数値より多くを受け付けます:

| 入力内容 | 結果 |
|---|---|
| `=2*45` | 90 |
| `=sqrt(2)*100` | 141.4214 |
| `1/4`, `6-1/2` | 0.25, 6.5 |
| `12'6"`, `12'-6 1/2"` | 150, 150.5 (インチ。フィートとインチで表示される図面の場合) |
| `900mm`, `3.5m`, `2ft` | 図面の単位に変換されます |
| `45d30'`, `45°30'15"` | 45.5°、45.5042° (角度フィールド) |
| `0.5r`, `100g` | ラジアンとグラード (度に変換) |

単位付きの長さは、図面に単位が必要です。まず、何も選択されていない状態で{{ui:New objects}}の下の{{ui:Units}}を設定してください。不正な入力は、パネルの下のメモとともに拒否され、何も変更されません。0として保存されることはありません。使用できる関数: sin、cos、tan、asin、acos、atan、atan2、sqrt、pow、exp、ln、log、abs、round、ceil、floor、min、max、if。角度は度で扱われます。

## 複数のオブジェクトを一度に変更する

1. 複数のオブジェクトを選択します。例: 線8本と寸法4個。
2. 見出しには「12個のオブジェクト」と表示され、上部のリストに**すべて (12)**、**線分 (8)**、**寸法 (4)** が表示されます。
3. **すべて**を選ぶと、すべてのオブジェクトが持つもの (レイヤー、色、線種など) が表示されます。**寸法 (4)** を選ぶと、寸法の設定が表示されます。
4. 値を変更します。例: {{ui:Decimals}}を`1`にします。

4つの寸法すべてが、1回の元に戻す操作で変更されます。**異なる値**と表示されるフィールドは、オブジェクトごとに値が異なることを意味します。値を入力すると、すべてのオブジェクトに設定されます。ロックされたレイヤーのオブジェクトは変更されず、メモにその数が表示されます。

## 選択の合計

複数のオブジェクトを選択すると、上部の{{ui:Totals}}セクションに次が表示されます:

- **オブジェクト**: 種類ごとの数。例: 「線分8本、ポリライン2本、円1個」。
- **合計の長さ**: 線、円弧、ポリラインの合計 (スプラインも含む)、およびそのオブジェクトの数。
- **合計の面積**: 閉じたものの合計: 円、完全な楕円、閉じたポリライン、ハッチング (ハッチングの穴は差し引かれます)。

これらは図面の長さの書式で表示されます (図面がフィートとインチを使う場合はそれを使用し、その場合の面積は in² と ft² になります)。オブジェクトが選択されているときは、ステータスバーに同じ長さと面積が表示されます。{{ui:Settings}} › {{ui:CadCraft}} › {{ui:Length and area of the selection}} › {{ui:Hidden}} でこれをオフにできます。1つのオブジェクトの場合は、従来どおり{{ui:Geometry}}にそのオブジェクト自身の長さと面積が表示されます。

## 座標

すべての点はX、Y、Zを表示します: 線の始点と終点、中心、挿入点、テキストの位置、現在のポリラインの頂点。線には、差分X、差分Y、差分Z (読み取り専用) も表示されます。ポリラインとハッチングには**標高**があります (オブジェクト全体に対する1つのZ)。

点の名前の横にある十字ボタンを使うと、図面上で点を指定できます。そのボタンをクリックしてから、新しい位置をクリックします (スナップが機能します)。値はワールド座標です。

## 種類ごとの表示

| 選択 | 変更できる項目 |
|---|---|
| 線分 | 始点と終点のX、Y、Z。長さ。角度 |
| 円 | 中心。半径。直径。円周。面積 (それぞれが半径を設定します) |
| 円弧 | 中心。半径。始点と終点の角度。全角度。弦 (円弧の長さと面積を表示) |
| 楕円 | 中心。長軸と短軸の半径。半径比。長軸の角度。始点と終点の角度 |
| ポリライン | 頂点ブラウザー (下記)。全体の幅。標高。閉じているかどうか。閉じている場合は面積 (中心を基準に尺度変更) |
| テキスト | 内容、スタイル、配置、高さ、回転、幅係数、斜体角、定義幅、行間隔、注釈性、位置 |
| ブロック参照 | 挿入点。回転。尺度のX、Y、Zおよび均一尺度。属性値 |
| ハッチング | パターン、尺度、角度、原点、関連付け、アイランド検出、背景色、標高 |
| 寸法 | 下記を参照 |
| マルチ引出線 | テキスト、高さ、幅、テキストの側、矢印のサイズ、ランディング距離、矢印の点 |
| ビューポート | 尺度。シート上の中心とサイズ。モデル内のビュー中心。オン。表示のロック |

### ポリラインの頂点

{{ui:Current vertex}}には、その下のフィールドがどの頂点に属するかが表示されます。矢印ボタンを使うか、番号を入力して別の頂点に移動します。頂点の数に制限はありません。各頂点は、X、Y、始点と終点のセグメント幅、およびそこから始まるセグメントの膨らみ (0は直線) を持ちます。

## 寸法

寸法は、その**寸法スタイル**、測定対象、点、およびすべての設定を表示します:

- **線と矢印:** 各端の矢印、矢印のサイズ、刻みのサイズ、寸法線と寸法補助線の色と線の太さ、いずれかの半分またはいずれかの寸法補助線の非表示、寸法補助線のオフセットと延長。
- **テキスト:** 上書き (測定値の場合は空のまま。独自のテキスト内では`<>`がそれを表します)、スタイル、色、高さ、オフセット、垂直および水平位置、常に水平、回転、背景の塗りつぶし。
- **フィット:** 全体の尺度、ベースラインの間隔、スペースが不足したときに移動するもの、テキストの移動。
- **基本単位:** 形式、小数点以下の桁数、四捨五入、接頭辞、接尾辞、測定尺度、小数点の区切り文字、先頭と末尾のゼロの抑制。角度の場合は、角度の形式と小数点以下の桁数。
- **代替単位:** オンまたはオフ、形式、小数点以下の桁数、倍率 (25.4でインチをミリメートルに変換)、四捨五入、接頭辞、接尾辞。
- **公差:** なし、対称、偏差、限界、または基本。上限値と下限値、小数点以下の桁数、高さと位置。

開いた寸法でこれらのいずれかを変更すると、他のプログラムが作成した図面は破棄され、CadCraftが再描画します。

:::note
寸法の水平テキスト位置 (最初または2番目の寸法補助線の横) と、線の下のテキストは、線形寸法と平行寸法で描画されます。その他の寸法では、保持され保存されますが、まだ描画されません。フィットの選択も、保持され保存されますが、まだ描画されません。CadCraftは独自のルールでテキストを配置します (線の上、収まらない場合は外側)。
:::

## 何も選択されていない場合

何も選択されていない場合、パネルには次が表示されます:

- **新しいオブジェクト:** 新しいオブジェクトが得るレイヤー、色、線種、線の太さ、テキストの高さ。図面の単位と長さの形式。現在のレイヤーの線種と線の太さ。新しい寸法のサイズ。シートでは、まずシート名、用紙、向きが表示されます。
- **ビュー:** 画面に表示されているものの中心、高さ、幅。値を入力すると、そのビューに移動します。
- **その他:** UCSアイコンのオンまたはオフ、UCS (常にワールド: CadCraftにはまだユーザー座標系がありません)、および注釈尺度。

## よくある間違い

- **フィールドに入力しても何も起きません。** {{key:Enter}}キーを押すか、別の場所をクリックして適用してください。赤いフィールドとメモは、入力が拒否されたことを意味します。
- **単位付きの長さが拒否されます。** 図面に単位がありません。何も選択されていない状態で{{ui:Units}}を設定してください。
- **レイヤーと色だけが表示されます。** 複数の種類のオブジェクトが選択され、**すべて**が選ばれています。上部のリストで1つの種類を選択してください。
- **一部のオブジェクトが変わりませんでした。** ロックされたレイヤーにあります。レイヤーパネルでレイヤーのロックを解除してください。
- **入力した文字がフィールドに入りました。** フィールドにカーソルがあるとき、キーはそこに入力されます。{{key:Enter}}キーまたは{{key:Esc}}キーを押してから、コマンドを入力してください。
