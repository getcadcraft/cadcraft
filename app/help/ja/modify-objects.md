## 作成するもの

テーブル1台と、その周りにコピーされ、回転、鏡像化、サイズ変更されたいすです。作業中に {{cmd:MOVE}}、{{cmd:COPY}}、{{cmd:ROTATE}}、{{cmd:MIRROR}}、{{cmd:SCALE}}、{{cmd:UNDO}} を使用します。

## 部品を描く

1. `REC`と入力して{{key:Enter}}を押し、`0,0`と入力して{{key:Enter}}を押し、次に`@1800,900`と入力して{{key:Enter}}を押します。これがテーブルです。
2. `REC`と入力して{{key:Enter}}を押し、`300,-700`と入力して{{key:Enter}}を押し、次に`@450,450`と入力して{{key:Enter}}を押します。テーブルの下にあるいすです。
3. {{ui:Extents}}をクリックします。

## 移動: 基点、次に2点目

すべての移動、コピー、回転、尺度変更は**基点**から始まります。基点は、一緒に動かされる点、または中心として回転させる点です。

1. いすをクリックして選択します。
2. `M`と入力して{{key:Enter}}を押します。履歴に`1 found`と表示されます。
3. `Specify base point`のプロンプトで、いすの左上隅に端点(Endpoint)スナップを合わせてクリックします。
4. `Specify second point`のプロンプトで、`@0,200`と入力して{{key:Enter}}を押します。

いすが200上に移動し、テーブルに近づきます。

:::tip
`Specify base point`で`D`と入力すると、代わりに変位を指定できます。CadCraftは続けて`Specify displacement`と尋ねるので、横と上への距離を`0,200`のように入力します（`@`は不要です）。
:::

## コピー、必要な回数だけ

1. いすをクリックします。
2. `CO`と入力して{{key:Enter}}を押します。
3. いすの左下隅に合わせてクリックし、基点とします。
4. `@600,0`と入力して{{key:Enter}}を押します。600右にコピーが表示されます。
5. もう一度`@600,0`と入力して{{key:Enter}}を押します。元のいすの1200右に2つ目のコピーが表示されます。
6. {{key:Enter}}を押してコマンドを終了します。

{{cmd:COPY}}は、{{key:Enter}}を押すまで続きます。各コピーは、基点から指定した点までの距離で配置されます。`@`の点は最後に入力した点を基準にするため、最初のコピーの後は、そのコピーの点が基準になります。そのため、`@600,0`を2回入力すると、600と1200の位置にコピーが作成されます。`U`と入力して{{key:Enter}}を押すと、コマンドを終了せずに最後のコピーを取り消せます。

テーブルの下に、いすが3脚並んで表示されているはずです。

:::tip
{{cmd:COPY}}は、1つの図面内で基点によって配置するコピーに使います。オブジェクトを別の図面やタブに運ぶ場合、または後で貼り付ける場合は、クリップボードを使用してください: {{key:Mod+C}}の後に{{key:Mod+V}}。{{key:Mod+D}}は、ポインターに合わせて動くコピーを1つ作成します。[コピー、貼り付け、複製](topic:copy-paste)を参照してください。
:::

## 行を反対側に鏡像で複製

1. テーブルに触れないように、3脚のいすの上を右から左へ交差選択でドラッグします。
2. `MI`と入力して{{key:Enter}}を押します。
3. `Specify first point of mirror line`のプロンプトで、テーブルの左辺の中点(Midpoint)スナップを合わせてクリックします。
4. `Specify second point of mirror line`のプロンプトで、テーブルの右辺の中点(Midpoint)スナップを合わせてクリックします。
5. `Erase source objects? [Yes/No] <N>`のプロンプトで、{{key:Enter}}を押して元のオブジェクトを残します。

テーブルの下に3脚、上に鏡像の3脚が表示されているはずです。鏡像にした選択範囲の文字は、鏡像として配置されますが、逆向きには書かれないため、読めたままです。

## いすを回転

1. テーブルの下にある一番右のいすをクリックします。
2. `RO`と入力して{{key:Enter}}を押します。
3. いすの右下隅に合わせてクリックし、基点とします。
4. `90`と入力して{{key:Enter}}を押します。

いすは基点を中心に反時計回りに90度回転します。負の角度を指定すると時計回りに回転します。入力する代わりに2点目をクリックすることもできます。その場合、角度は基点からその点までの方向で測定されます。

## テーブルの尺度変更

1. テーブルを選択します。
2. `SC`と入力して{{key:Enter}}を押します。
3. テーブルの左下隅に合わせてクリックし、基点とします。
4. `1.2`と入力して{{key:Enter}}を押します。

テーブルは20%大きくなり、基点から広がります。1未満の倍率を指定すると、小さくなります。

:::note
倍率を入力する代わりに点をクリックすると、倍率は基点からその点までの距離になります。描画単位で1離れた点をクリックすると、倍率は1になります。通常は数値を入力する方が確実です。
:::

## 元に戻すとやり直し

- {{key:Mod+Z}}、{{ui:Undo}}ボタン、または`U`の後に{{key:Enter}}で、最後のコマンドを元に戻します。コマンド全体が1回の操作として扱われます。5つのコピーを作成した{{cmd:COPY}}を元に戻すと、5つすべてが削除されます。
- {{key:Mod+Y}}、{{key:Mod+Shift+Z}}、{{ui:Redo}}ボタン、または`REDO`で、元に戻した操作をやり直します。
- 履歴には、何が元に戻されたかが表示されます（「COPYを元に戻しました」）。

CadCraftは直近500操作を保持します。レイヤーの設定（オン、フリーズ、ロック、色）は編集ではなく設定のため、元に戻されません。

## 部屋を幅広くストレッチ

{{cmd:STRETCH}}（`S`、または{{ui:Stretch}}）は、交差窓の内側にあるものだけを動かします。窓の内側にある角と線の端は動き、それ以外は動かないため、部屋全体が移動する代わりに、幅が広がります。

1. `S`と入力して{{key:Enter}}を押します。
2. 右の壁の上に、右から左へ窓をドラッグします。壁の角と、壁に接するものの端が含まれるようにします。
3. {{key:Enter}}を押します。
4. 基点をクリックし、`@600,0`と入力して{{key:Enter}}を押します。

長方形は600広がり、壁で止まっていた線はそのまま壁で止まります。片方の端だけが窓の内側にある円弧は高さを保ち、中心または挿入点が内側にある円と文字は動き、寸法は新しい長さを計測します。窓を使わずに1つずつ選んだオブジェクトは、単に移動します。

先に選択することもできます。コマンドが実行されていない状態で、壁の上に交差窓（または交差投げ縄）をドラッグし、その後`S`と入力します。STRETCHはその選択を使い、プロンプトで窓をドラッグしたときと同じように、窓に含まれるものを伸ばします。

## 配列: 行と列、または中心の周り

{{cmd:ARRAY}}（`AR`、または{{ui:Array}}）は、選択したものを格子状または円状に複写します。

1. いすを1脚選択し、`AR`と入力して{{key:Enter}}を押します。矩形の場合は{{key:Enter}}を押します。
2. 4列3行のプレビューが表示されます。`COU`と入力して{{key:Enter}}を押し、列数として`5`、行数として`2`を入力します。
3. `S`と入力して{{key:Enter}}を押し、列の間隔として`600`、行の間隔として`-900`を入力します（負の値は下方向です）。
4. {{key:Enter}}を押して複写を作成します。

テーブルの周りに円形にいすを並べる場合は、代わりに`PO`（極）を選び、テーブルの中心をクリックし、`I`（個数）、`F`（塗りつぶし角度: 全周は360、半周は180）、`ROT`（複写を中心に向けて回転させるかどうか）を設定します。{{cmd:ARRAYRECT}}と{{cmd:ARRAYPOLAR}}は、これらの質問を省略します。

## 線を1本のポリラインに結合

{{cmd:JOIN}}（`J`、または{{ui:Modify}} › {{ui:More}} › {{ui:Join}}）: 端が接している線、円弧、開いたポリラインを選択し、{{key:Enter}}を押します。それらは1本のポリラインになります。全周がつながっている場合は閉じたポリラインになり、一度にオフセットできます。隙間があっても同一直線上にある線は1本の線になり、同じ円の円弧は1本の円弧、または円になります。

## プロパティの複写

{{cmd:MATCHPROP}}（`MA`、または{{ui:Modify}} › {{ui:More}} › {{ui:Match properties}}）: 見た目を真似たいオブジェクトをクリックし、変更するオブジェクトを選択して{{key:Enter}}を押します。それらはクリックしたオブジェクトのレイヤーと色を引き継ぎます。文字は文字の高さ、寸法は寸法の大きさ、ハッチングはパターンを引き継ぎます。2番目の質問で`S`（設定）と入力すると、いずれかの項目を引き継がないようにできます。

## オブジェクトの位置合わせ

**点で合わせる。** {{cmd:ALIGN}}（`AL`、または{{ui:Modify}} › {{ui:More}} › {{ui:Align}}）: オブジェクトを選択して{{key:Enter}}を押し、次にオブジェクト上の点（元の点）と、そこを移動させたい先の点をクリックします。

- 1組の点を指定するとオブジェクトが移動します。`Specify second source point`のプロンプトで{{key:Enter}}を押すと、ここで止まります。
- 2組の点を指定すると、オブジェクトは回転もするため、元の2点を結ぶ線が、移動先の2点を結ぶ線に沿うようになります。CadCraftは続けて`Scale objects based on alignment points?`と尋ねます。`Y`と入力すると、オブジェクトもその分だけ大きくまたは小さくなります。
- 3組目の点を指定すると、その2点が上記の線の反対側にある場合、オブジェクトは鏡像になります。

**端と間隔。** {{ui:Modify}} › {{ui:More}} › {{ui:Align and distribute}}（または`ALIGNPANEL`）を選択すると、図面の上に小さなパネルが開きます。オブジェクトを選択し、次に以下を行います。

- {{ui:Align to}}で揃える基準を選び（選択全体、最初または最後に選んだオブジェクト、またはクリックした点）、{{ui:Left}}、{{ui:Center}}、{{ui:Right}}、{{ui:Top}}、{{ui:Middle}}、{{ui:Bottom}}のいずれかをクリックします。
- または{{ui:Equal gaps}}か{{ui:Equal centres}}を選び、{{ui:Across}}か{{ui:Up and down}}をクリックします。両端の2つのオブジェクトは動かず、その間のものが等間隔に配置されます（少なくとも3つのオブジェクトが必要です）。

それぞれのクリックが1回の元に戻す操作になり、選択は残るため、別の方法を試すこともできます。各オブジェクトは、UCSが設定されている場合はそのUCS上で、バウンディングボックスによって計算されます。コマンドラインでは、同じ機能が{{cmd:ALIGNTO}}と{{cmd:DISTRIBUTE}}になります。

## 削除と分解

- {{cmd:ERASE}}（`E`、または{{key:Delete}}）は、選択したオブジェクトを削除します。
- {{cmd:EXPLODE}}（`X`）は、ポリラインを線と円弧に、ブロック参照をそれを構成するオブジェクトに、寸法を線、矢印、文字に分解します。分解された寸法は、もう自動では計測されません。

## よくある間違い

- **2点目で`@`を付けずに距離を入力した。** `600,0`は絶対座標の点600,0を意味し、「右に600」ではありません。`@600,0`を使うか、十字カーソルが正しい方向を向いている状態で`600`とだけ入力します。
- **回転の方向が逆になった。** 正の角度は反時計回りに回転します。
- **元に戻しすぎた。** 1回の元に戻す操作で、最後のコマンド全体（そのコマンドが作成したすべてのコピーを含む）が取り消されます。
- **コマンドがオブジェクトの選択を求めなかった。** オブジェクトがすでに選択されていたため、それを使用しました。何も選択されていない状態から始めるには、まず{{key:Esc}}を押します。
