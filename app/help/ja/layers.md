## 作成するもの

壁、ドア、注記の3つのレイヤーを、それぞれ独自の色で作成し、各レイヤーにオブジェクトを描き、レイヤー間で移動します。

## レイヤーパネル

レイヤーは、左側のパネルの{{ui:レイヤー}}の下にあります。各行には、左から右へ次のものが表示されます:

- 点: **現在の**レイヤーは塗りつぶし、新しいオブジェクトはそこに作成されます。
- 色の見本。
- レイヤー名。
- 4つのボタン: オン/オフ(目)、フリーズ(雪の結晶)、ロック(南京錠)、印刷(プリンター)。

すべての図面には`0`というレイヤーがあります。`LA`と入力して{{key:Enter}}キーを押すと、パネルに移動します。

## レイヤーを作成

1. 一覧の上の{{ui:新しいレイヤー}}をクリックします。名前の入力欄が開きます。
2. `Walls`と入力して{{key:Enter}}キーを押します({{ui:追加}}をクリックしても可能です)。

ステータスバーに「レイヤーWallsを追加して現在のレイヤーにしました。」と表示されます。新しいレイヤーの色は7になります(ライトテーマでは黒、ダークテーマでは白)。

3. {{ui:新しいレイヤー}}をもう一度クリックし、`Doors`と入力して{{key:Enter}}キーを押します。
4. {{ui:新しいレイヤー}}をもう一度クリックし、`Notes`と入力して{{key:Enter}}キーを押します。

これで、Notesが現在のレイヤーになります。

## 各レイヤーに色を設定

1. Wallsの行の色の見本をクリックします。お使いのシステムの色選択ツールが開きます。
2. 色を選び、確定します。

見本と、Wallsにあり色が{{ui:ByLayer}}のすべてのものが、その色に変わります。

:::note
標準のCAD色255色のいずれかに一致する色を選んだ場合、その番号として保存されます。それ以外の色はCadCraftでは正確に保持されますが、DWGまたはDXFファイルには最も近い標準色として保存されます。
:::

## レイヤーに描く

1. 一覧の**Walls**という名前をクリックします。その点が塗りつぶされ、ステータスバーに「現在のレイヤー: Walls」と表示されます。
2. 長方形({{cmd:REC}})を描きます。Wallsに配置されます。
3. **Doors**をクリックし、円弧({{cmd:A}})を描きます。Doorsに配置されます。

右側のパネルで、何も選択していないときに、{{ui:現在の設定}}の{{ui:レイヤー}}から現在のレイヤーを選ぶこともできます。

## オブジェクトを別のレイヤーへ移動

1. オブジェクトを選択します。
2. 右側のパネルで、{{ui:レイヤー}}から新しいレイヤーを選びます。

オブジェクトは、そのレイヤーへ移動します。色が{{ui:ByLayer}}の場合は、そのレイヤーの色になります。

## オフ、フリーズ、ロック、印刷

| ボタン | 動作 |
|---|---|
| オン/オフ(目) | レイヤーのオブジェクトを非表示にします。見ること、選択すること、スナップすることはできません。 |
| フリーズ(雪の結晶) | CadCraftでは、オフと同じ効果です。他のプログラムでは扱いが異なるため、別々に保持され、設定は保存されます。 |
| ロック(南京錠) | オブジェクトは表示され、スナップもできますが、選択や変更はできません。なぞる下図の背景に便利です。 |
| 印刷(プリンター) | 押すと、レイヤーは画面に表示されたままですが、印刷とPDFから**除外**されます。補助線や自分用の注記に使います。 |

ボタンにマウスを合わせると動作が表示されます(「オフにする」「フリーズ」「ロック」「このレイヤーを印刷しない」)。

現在のレイヤーはオフにできません。ステータスバーに「現在のレイヤーです。先に別のレイヤーを現在にしてください。」と表示されます。レイヤーの名前をクリックして現在のレイヤーにすると、そのレイヤーはオンになり、フリーズも解除されます。

パネルでもコマンドでも、レイヤーの変更は1回の元に戻すになります。{{key:Mod+Z}}で元に戻ります。

## オブジェクトを指定してレイヤーを操作

レイヤーの名前がわからなくても、そのレイヤー上のオブジェクトを指定すれば操作できます。コマンドを入力するか、{{ui:レイヤー}}パネルの上の{{ui:ツール}}を開きます。

| コマンド | 動作 |
|---|---|
| {{cmd:LAYISO}} | オブジェクトを選択して{{key:Enter}}キーを押すと、そのレイヤーだけが表示され、他のレイヤーはすべてオフになります。現在のレイヤーがオフになる場合は、分離されたレイヤーのいずれかが現在のレイヤーになります。 |
| {{cmd:LAYUNISO}} | 直前の{{cmd:LAYISO}}がオフにしたレイヤーを再びオンにし、変更された現在のレイヤーを戻します。 |
| {{cmd:LAYOFF}} | オブジェクトを順にクリックすると、そのレイヤーがそれぞれオフになります。`U`で直前の操作を取り消し、{{key:Enter}}キーで終了します。 |
| {{cmd:LAYFRZ}} | 同様ですが、レイヤーをフリーズします。 |
| {{cmd:LAYMCUR}} | オブジェクトをクリックすると、そのレイヤーが現在のレイヤーになります(オンになり、フリーズも解除されます)。オブジェクトが既に1つ選択されている場合は、それが使われます。 |
| {{cmd:LAYON}} | すべてのレイヤーをオンにします。 |
| {{cmd:LAYTHW}} | すべてのレイヤーのフリーズを解除します。 |

現在のレイヤーは、この方法ではオフやフリーズになりません。履歴にその旨が表示されます。先に{{cmd:LAYMCUR}}で別のレイヤーを現在にしてください。ブロック参照を指定した場合は、その参照自身のレイヤーが使われます。

## レイヤーの名前変更、結合、削除

- {{cmd:RENAME}}: `LA`と入力し、古い名前と新しい名前を入力します。そのレイヤーの全オブジェクトが追従します。(`B`は、同様にブロック名を変更し、そのすべての参照も変わります。)
- {{cmd:LAYMRG}}: 結合する各レイヤーのオブジェクトを1つずつクリック(または`N`と入力して名前を指定)し、{{key:Enter}}キーを押してから、対象のレイヤーを指定し、`Y`と答えます。オブジェクトは対象へ移動し(モデル、シート、ブロック内も含む)、結合されたレイヤーは削除されます。
- {{cmd:LAYDEL}}: レイヤー上のオブジェクトを指定(または`N`と名前)し、`Y`と答えます。レイヤーは、**そこにある全オブジェクトとともに**削除されます(どこにあるものも含みます)。レイヤー0、DEFPOINTS、現在のレイヤーは削除できません。

それぞれ1回の元に戻すです。3つとも、{{ui:レイヤー}}パネルの上の{{ui:ツール}}にもあります。

1. Wallの線を1本クリックしてから、`LAYISO`と入力して{{key:Enter}}キーを押します。Wallsだけが表示されます。
2. Wallsで必要な描画や変更を行います。
3. `LAYUNISO`と入力して{{key:Enter}}キーを押します。DoorsとNotesが戻ります。

## よくある間違い

- **新しい線が違うレイヤーに入った。** 描く前に、どの点が塗りつぶされているかを確認してください。新しいレイヤーは、追加するとすぐに現在のレイヤーになります。
- **オブジェクトが選択できない。** そのレイヤーがロック、オフ、またはフリーズされています。
- **別のプログラムで、まだそのレイヤーが印刷される。** DXF R12では「印刷しない」を保存できません。図面に用紙がある場合、CadCraftはその設定を保持しますが、他のプログラムでは、そのレイヤーが印刷されます。
- **保存後、レイヤー名が大文字になる。** DXF R12はレイヤー名を大文字で保存するため、`Walls`は`WALLS`に、空白は`_`になります。DWGで保存した場合は、入力どおりの名前が保持されます。
- **レイヤーの名前変更、結合、削除。** {{cmd:RENAME}}、{{cmd:LAYMRG}}、{{cmd:LAYDEL}}を使います({{ui:ツール}}にもあります)。下記を参照してください。

## レイヤーのグループ化

レイヤーをフォルダーにまとめると、一覧を短く保てます。たとえば既存、計画、設備です。各フォルダーは折りたためて、そのスイッチで、中のすべてのレイヤーのオン/オフ、フリーズ、ロックを一緒に切り替えられます。現在のレイヤーは決してオフにはなりません。

{{ui:レイヤー}}パネルの{{ui:ツール}}で、小規模な住宅工事向けの既製のセットには{{ui:既製のグループを追加}}を、共通の接頭辞を持つレイヤー(`E-Walls`、`E-Doors`)をまとめるには{{ui:名前でグループ化}}を、または{{ui:新しいグループ}}を選びます。レイヤーをフォルダーにドラッグするか、一覧の上の現在のレイヤーを使ってください。{{ui:レイヤーを検索}}に入力すると、一覧を絞り込めます。`LAYGROUP`(`LG`)も、コマンドラインから同じことができます。

グループの名前を変更するには、名前をダブルクリックします(または選択して{{key:F2}}キーを押します)。新しい名前を入力して{{key:Enter}}キーを押します。{{key:Esc}}キーを押すと古い名前が保たれ、{{cmd:UNDO}}で元に戻ります。{{ui:新しいグループ}}は、{{ui:レイヤー}}パネルの{{ui:ツール}}にあります。

レイヤー自体は変わらないため、他のCADプログラムでは通常のフラットな一覧として見えます。CadCraftはグループをファイル内に保持します。
