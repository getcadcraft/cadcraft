## 만들 내용

직사각형과 두 대각선, 두 대각선이 만나는 곳에 중심을 둔 원, 그리고 한 변의 중간에서 원까지 이어지는 선을 만듭니다. 모든 점은 마우스로 찍으며, 모든 점은 정확합니다.

## 스냅 작동 방식

명령이 점을 요구하는 동안 CadCraft는 십자선에서 약 10픽셀 이내의 스냅 점을 찾습니다. 하나를 찾으면 마커와 레이블("끝점", "교차점")이 나타나며, 클릭하면 십자선 위치가 아니라 **정확히** 그 점에 놓입니다.

상태 표시줄의 {{ui:Snap}} 버튼이 눌려 있으면 스냅이 켜져 있습니다. {{key:F3}} 키로 켜고 끕니다.

사용할 수 있는 스냅은 다음과 같습니다.

| 스냅 | 찍히는 위치 |
|---|---|
| 끝점 | 선, 호, 폴리선 세그먼트의 끝 |
| 중간점 | 선, 호, 폴리선 세그먼트의 중간 |
| 중심 | 원과 호의 중심, 폴리선 호 세그먼트의 중심 |
| 사분점 | 원과 호의 0, 90, 180, 270도 지점 |
| 교차점 | 두 객체가 교차하는 곳 |
| 직교 | 마지막 점에서 객체에 수직인 점(기준점 필요) |
| 접점 | 마지막 점에서 그은 선이 원이나 호에 막 닿는 점. 마지막 점이 아직 없으면(선의 첫 점) 마커에 "보류"가 표시되며, 다음 점이 정해진 뒤에 접점이 계산됩니다. 그래서 접점에서 접점으로 그은 선은 두 원에 모두 접합니다. |
| 근접점 | 어떤 객체 위에서든 가장 가까운 점 |
| 노드 | 점 객체 |
| 삽입점 | 문자와 블록 참조의 삽입점 |

접점과 근접점을 제외하고는 모두 기본으로 켜져 있습니다. 다른 것을 원할 때도 근접점이 먼저 잡히는 경우가 많으니, 필요할 때 접점을 켜십시오.

## 스냅 선택

1. 상태 표시줄에서 {{ui:Snap}} 옆의 작은 화살표를 클릭합니다. {{ui:Object snaps}} 목록이 열립니다.
2. 스냅을 선택하거나 해제합니다. 변경 사항은 즉시 적용됩니다.
3. 화살표를 다시 클릭해 목록을 닫습니다.

CadCraft는 이 브라우저에서 선택한 항목과 {{ui:Grid}}, {{ui:Ortho}}, {{ui:Snap}} 설정을 기억합니다.

## 단계

1. `REC` 입력 후 {{key:Enter}} 키를 누릅니다.
2. `0,0` 입력 후 {{key:Enter}} 키를 누릅니다.
3. `@4000,3000` 입력 후 {{key:Enter}} 키를 누릅니다. 직사각형이 나타납니다.
4. {{ui:Extents}} 클릭.
5. `L` 입력 후 {{key:Enter}} 키를 누릅니다.
6. 십자선을 왼쪽 아래 모서리로 옮깁니다. 마커에 "끝점"이 표시되면 클릭합니다.
7. 오른쪽 위 모서리로 옮겨 "끝점"이 표시되면 클릭합니다.
8. {{key:Enter}} 키를 눌러 선을 끝냅니다.
9. {{key:Enter}} 키를 다시 눌러 {{cmd:LINE}} 명령을 반복하고, 같은 방식으로 오른쪽 아래 모서리에서 왼쪽 위 모서리까지 다른 대각선을 그립니다.
10. `C` 입력 후 {{key:Enter}} 키를 눌러 원을 시작합니다.
11. 십자선을 대각선이 교차하는 곳으로 옮깁니다. 마커에 "교차점"이 표시되면 클릭합니다.
12. `800` 입력 후 {{key:Enter}} 키를 누릅니다.

교차점에 정확히 중심을 둔 원이 보입니다.

13. `L` 입력 후 {{key:Enter}} 키를 누릅니다.
14. 사각형 왼쪽 변의 중간으로 옮겨 "중간점"이 표시되면 클릭합니다.
15. 십자선을 원 위, 왼쪽 쪽으로 옮깁니다. 마커에 "직교" 또는 "사분점"이 표시되며, 여기서는 두 가지가 같은 점이므로 어느 쪽이든 괜찮습니다. 클릭합니다.
16. {{key:Enter}} 키를 누릅니다.

새 선은 왼쪽 변의 중간에서 시작해 원에 정확히 멈춥니다.

## 한 번의 클릭에서 스냅 건너뛰기

클릭하는 동안 {{key:Shift}} 키를 누르고 있습니다. 그 클릭에서는 객체 스냅이 무시되며, 점은 정확히 십자선 위치에 놓입니다(직교가 켜져 있으면 직교 방향을 따릅니다).

## 직교

{{ui:Ortho}}({{key:F8}})는 다음 점을 기준점에서 가로 또는 세로로 곧게 맞춥니다. 클릭과 직접 거리 입력(프롬프트에 숫자만 입력) 모두에 적용됩니다. 객체 스냅이 직교보다 우선합니다. 스냅 마커가 보이면 클릭은 스냅으로 갑니다.

## 극좌표 추적

{{ui:Polar}} 기능({{key:F10}})은 여러 각도로 확장된 직교입니다. 명령에 기준점(선의 마지막 점, 이동의 기준점)이 있는 동안, 포인터가 그 점에서 극좌표 간격의 배수 각도로 나가는 광선 가까이 오면 포인터가 정렬됩니다. 점선이 나타나고, 십자선 옆 레이블에 `극좌표: 1200 < 30°`가 표시됩니다. 클릭하여 그 점을 사용하거나 거리를 입력합니다. `1200`을 입력하면 광선을 따라 정확히 1200만큼 이동합니다.

간격은 바꾸기 전까지 90°입니다. {{cmd:POLARANG}} 명령을 입력하고 {{key:Enter}} 키를 누른 뒤 `30`을 입력합니다(45, 22.5, 15 등도 가능). 극좌표와 직교는 서로 배타적입니다. 하나를 켜면 다른 하나는 꺼집니다.

## 객체 스냅 추적

{{ui:Track}} 기능({{key:F11}})은 머물러 둔 스냅 점과 포인터를 정렬합니다. 그래서 보조선을 그리지 않고도 한 모서리와 같은 높이에 있고 다른 모서리 위에 있는 점을 찍을 수 있습니다.

1. {{ui:Snap}}과 {{ui:Track}}을 켜고, 점을 요구하는 명령(`L`)을 시작합니다.
2. 클릭하지 않고 0.5초 동안 모서리 같은 스냅 점 위에 포인터를 머물러 둡니다. 작은 십자 표시가 나타나면 점이 **획득**된 것입니다. 같은 점에 다시 머물면 해제됩니다.
3. 포인터를 그 점에서 가로 또는 세로로 곧바로 이동합니다. 점선이 포인터를 따라가고, 레이블에 `추적: 600 < 90°`가 표시됩니다. 클릭하거나 거리를 입력합니다.
4. 두 번째 점을 획득하고, 한 점을 지나는 수직선과 다른 점을 지나는 수평선이 만나는 곳으로 이동합니다. 포인터가 그 교차점에 스냅됩니다(`추적: 두 선이 만나는 곳`).

{{ui:Polar}}도 켜면 획득한 점은 모든 극좌표 각도에서 추적됩니다. 명령이 끝날 때까지 최대 7개의 점이 유지됩니다. {{key:Shift}} 키는 스냅과 마찬가지로 한 번의 클릭에서 추적을 끕니다.

## 그리드

{{ui:Grid}} ({{key:F7}})은 도면 뒤에 격자선을 표시합니다. 다섯 번째마다 굵은 선이며, 확대/축소에 따라 간격이 바뀝니다. 그리드 스냅({{key:F9}})을 켜기 전까지는 안내선일 뿐입니다. 켜면 객체 스냅이 먼저 점을 잡지 않는 한, 클릭은 가장 가까운 그리드 점에 놓입니다.

## 컴퓨터의 기능 키

{{key:F9}}는 그리드 스냅, {{key:F10}}은 극좌표, {{key:F11}}은 추적입니다.

:::mac
Mac에서는 F3, F7, F8, F9가 보통 Mission Control과 미디어를 제어합니다. 키와 함께 **fn** 키를 누르거나, [키, 마우스, 트랙패드](common:keys)에 설명된 대로 표준 기능 키를 켜십시오. 상태 표시줄 버튼은 항상 작동합니다.
:::

:::firefox
Firefox에서는 F7이 캐럿 탐색 키이기도 합니다. Firefox가 캐럿 탐색을 켤지 물으면 **아니요**를 선택하십시오. 질문이 계속 나오면 {{ui:Grid}} 버튼을 사용하십시오.
:::

:::touch
터치 화면에는 호버가 없으므로, 스냅 마커는 손가락이 닿은 곳에만 나타납니다. 작은 대상은 가까이 확대하거나 좌표를 입력하십시오.
:::

## 자주 하는 실수

- **클릭이 엉뚱한 점에 갔습니다.** 클릭하기 전에 마커 레이블을 확인하십시오. 둘 다 가까우면 끝점이 중간점보다 우선합니다. 확대하거나, 필요 없는 스냅은 해제하십시오.
- **마커가 나타나지 않습니다.** {{ui:Snap}}이 꺼져 있거나, 원하는 스냅이 해제되어 있거나, 객체가 꺼진 도면층이나 동결된 도면층에 있을 수 있습니다.
- **복잡한 도면에서 스냅이 엉뚱한 것을 잡습니다.** 확대하십시오. 스냅 거리는 화면 픽셀로 측정되므로, 확대하면 도면 위에서는 거리가 작아집니다.
- **Shift로 직선이 나올 것으로 기대함.** CadCraft에서 Shift는 한 번의 클릭 동안 스냅을 끕니다. 직선에는 {{ui:Ortho}}를 사용하십시오.
- **점이 그리드 점에 맞기를 기대함.** {{ui:Grid snap}}({{key:F9}})을 켜거나, 둥근 숫자는 좌표를 입력하십시오.
