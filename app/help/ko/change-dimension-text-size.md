## 다음에 만들 치수용

1. {{key:Esc}}를 눌러 아무것도 선택하지 않은 상태로 만듭니다. 오른쪽 패널에 {{ui:현재 설정}}이 표시됩니다.
2. 패널을 아래로 스크롤하여 {{ui:새 치수}}로 이동합니다. {{ui:문자 높이}}에 종이에서 원하는 높이를 입력하고(예: 2.5 mm는 `2.5`, 또는 `3/32"`) {{key:Enter}}를 누릅니다.
3. {{ui:전체 축척}}을 출력 축척으로 설정합니다(1:50은 `50`, 1/4" = 1'-0"은 `48`). 모든 크기에 이 값이 곱해집니다.

명령행에서 {{cmd:DIMTXT}}는 높이를, {{cmd:DIMSCALE}}는 전체 축척을 설정합니다.

## 도면에 이미 있는 치수용

1. 치수를 선택합니다(하나 또는 여러 개. 속성 패널 상단 목록에서 {{ui:치수}}를 고릅니다).
2. {{ui:문자}} 섹션에서 새 {{ui:문자 높이}}를 입력하거나, 아래쪽 {{ui:맞춤}} 섹션에서 새 {{ui:전체 축척}}을 입력하고 {{key:Enter}}를 누릅니다.

치수는 즉시 다시 그려지며, 실행 취소 한 단계입니다. 다른 프로그램 파일의 치수는 변경하는 즉시 CadCraft 스타일로 다시 그려집니다.

:::tip
화면에서는 맞지만 출력된 시트에서 작게 보이는 문자는 보통 전체 축척이 1이기 때문입니다. 시트의 축척으로 설정하세요.
:::

모든 설정은 [치수 크기, 소수 자릿수, 축척 설정](topic:dimension-settings)을 참고하세요.
