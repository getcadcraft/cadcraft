## 학습 내용

명령 없이 객체를 바꾸는 빠른 방법 두 가지를 알아봅니다. 객체의 **그립**을 끌거나, 오른쪽 **속성** 패널에 새 값을 입력합니다.

## 그립

명령이 실행 중이 아닐 때 객체를 (한 번에 최대 200개) 선택하면 작은 사각형이 나타납니다. 이것이 그립입니다:

| 객체 | 그립 |
|---|---|
| 선 | 양 끝점과 중간점(선 전체를 이동) |
| 원 | 중심(이동)과 원 위의 네 점(반지름 변경) |
| 호 | 중심과 양 끝점(시작점과 끝점 변경) |
| 폴리선 | 모든 꼭짓점 |
| 문자, 점, 블록 참조 | 삽입점 |
| 타원 | 중심 |
| 치수 | 정의 점과 치수선 위치 |
| 뷰포트 | 중심(이동)과 네 모서리(크기 조정) |

### 그립 이동

1. 선을 그린 뒤 클릭합니다. 그립 세 개가 나타납니다.
2. 한쪽 끝의 그립을 클릭합니다. 상태 표시줄에 "이 그립이 놓일 위치를 클릭하십시오 (Esc로 취소). 스냅과 직교가 적용됩니다."라고 표시됩니다.
3. 십자선을 움직입니다. 미리 보기가 따라옵니다.
4. 새 위치를 클릭하거나, 다른 객체의 점에 스냅한 뒤 클릭합니다.

끝점이 이동하고 선의 나머지 부분은 그대로 있습니다. 그립을 누른 채 끌어서 원하는 곳에서 놓을 수도 있습니다.

:::note
그립의 위치는 좌표로 입력할 수 없습니다. 정확한 위치가 필요하면 점에 스냅하거나, 속성 패널에서 값을 입력하십시오.
:::

{{key:Esc}} 키를 누르거나 마우스 오른쪽 버튼을 클릭하면 그립 이동이 취소됩니다.

## 속성

오른쪽 패널에는 선택한 항목의 속성이 표시됩니다.

1. 선을 클릭합니다. 패널 제목에 "선"이 표시됩니다.
2. {{ui:길이}} 입력란을 클릭하고 `2500`을 입력한 뒤 {{key:Enter}} 키를 누릅니다.

선의 길이가 정확히 2500이 되며, 시작점과 각도는 유지됩니다. {{key:Enter}} 키를 누르거나 다른 곳을 클릭하면 값이 적용되고, {{key:Esc}} 키를 누르면 이전 값으로 돌아갑니다. 모든 변경은 실행 취소 한 단계이며, 여러 객체를 한꺼번에 바꿔도 마찬가지입니다.

입력란에는 식(`=2*45`)과 단위가 있는 길이(`3'6"`, `900mm`)를 입력할 수 있고, 모든 점은 X, Y, Z 값을 가지며, 여러 객체를 함께 바꿀 수 있습니다. 이 모든 내용은 [속성 패널](topic:properties-panel)에서 확인할 수 있습니다.

## 자주 하는 실수

- **그립이 나타나지 않습니다.** 명령이 실행 중이거나({{key:Esc}} 키를 누르십시오), 객체를 200개보다 많이 선택했거나, 객체가 잠긴 도면층에 있습니다.
- **그립이 엉뚱한 곳으로 갔습니다.** 스냅이 걸린 것입니다. 클릭하는 동안 {{key:Shift}} 키를 누르고 있으면 스냅을 무시합니다.
- **속성에 입력해도 아무 일도 없습니다.** {{key:Enter}} 키를 누르거나 다른 곳을 클릭해 적용하십시오. 허용되지 않는 입력(0 또는 음수의 길이와 반지름, 값이 아닌 문자)이면 입력란이 빨간색으로 바뀌고 이유가 표시됩니다.
- **속성 입력란에 입력한 문자가 들어갔습니다.** 입력란에 커서가 있으면 키 입력이 그곳에 들어갑니다. {{key:Enter}} 키 또는 {{key:Esc}} 키를 누른 뒤 명령을 입력하십시오.
