## 파일 열기

| 메시지 또는 증상 | 원인 | 해결 방법 |
|---|---|---|
| "CadCraft는 DWG 및 DXF 도면만 엽니다. "…" 파일은 둘 다 아닙니다." | 파일이 `.dwg`나 `.dxf`가 아닙니다. | 도면 파일 자체를 엽니다. PDF는 가져올 수 있습니다(열기에서 가져오기 또는 첨부를 묻습니다. [PDF 언더레이](topic:pdf-underlay) 참조). 그림은 `IMAGEATTACH`로 넣습니다. |
| "이 이진 DXF는 객체 중간에서 끝납니다. 파일이 잘렸거나 손상되었습니다." | 이진 DXF가 끝나기 전에 멈춥니다. | RECOVER를 입력하여 읽을 수 있는 내용을 엽니다. 또는 파일을 다시 요청합니다. |
| "이 파일은 읽을 수 있는 DXF가 아닙니다(…번 줄의 그룹 코드가 잘못됨)." | DXF가 손상되었거나 실제 DXF가 아닙니다. | 파일을 다시 요청하거나 DWG를 요청합니다. |
| "이 도면을 읽을 수 없습니다. 손상되었거나, 읽기 기능이 아직 지원하지 않는 버전(…)으로 저장되었을 수 있습니다." | DWG 읽기 기능이 파일을 읽지 못했습니다. | 이전 버전으로 저장된 DWG 또는 DXF를 요청합니다. |
| "이 도면은 AutoCAD R11 / R12(DWG AC1009)에서 만들어졌으며, CadCraft가 읽는 … 보다 오래되었습니다." | Release 12 이전의 DWG 파일은 CadCraft가 읽지 않는 형식을 사용합니다. | 파일을 만든 프로그램에서 DXF(어느 버전이든) 또는 최신 DWG로 저장한 뒤 엽니다. CadCraft의 {{ui:다른 이름으로 저장}}은 그 오래된 형식이 필요한 프로그램을 위해 DXF R12를 제공합니다. |
| 처음 연 DWG에서 "열지 못했습니다 …" 다음에 네트워크 메시지가 표시됨 | DWG 읽기 기능을 내려받을 수 없습니다. 오프라인 상태이며 CadCraft가 오프라인 사용을 위해 저장되지 않았거나, 연결이 끊어졌습니다. | 온라인 상태에서 다시 시도하거나 DXF를 엽니다. {{ui:오프라인용 저장}}을 클릭하고 "오프라인 준비 완료"가 표시될 때까지 기다리면, 다음번에는 오프라인에서도 DWG 파일이 열립니다. 자세한 내용은 [오프라인 작업](common:offline)을 참조합니다. |
| 오프라인 버튼에 "저장할 수 없음"이 표시됨 | 일부 파일을 내려받지 못했습니다. | 연결을 확인하고 버튼을 다시 클릭합니다. |
| 오프라인 버튼에 "오프라인 사용 불가"가 표시됨 | 비공개 창과 일부 관리되는 컴퓨터는 오프라인 사본을 보관할 수 없습니다. | 일반 창을 사용하거나 온라인 상태를 유지합니다. |
| 연결 없이는 CadCraft가 열리지 않습니다 | 이 브라우저에서 오프라인 사용을 위해 저장되지 않았거나, 브라우저가 저장된 내용을 지웠습니다. | 다음번에 온라인일 때 {{ui:오프라인용 저장}}을 클릭하고 "오프라인 준비 완료"가 표시될 때까지 기다립니다. |
| 도면은 열리지만 일부가 없습니다 | CadCraft가 아직 그릴 수 없는 객체, 또는 파일에서 꺼지거나 동결된 도면층. | 왼쪽 패널의 "이 파일에 대하여"를 읽습니다. {{ui:도면층}} 패널을 확인합니다. |
| 문자가 두 줄로 줄 바꿈됨 | CadCraft는 Helvetica 계열 글꼴로 문자를 그리며, 일부 CAD 글꼴보다 넓습니다. | {{ui:속성}}에서 문자를 줄이거나, 추가된 줄을 그대로 둡니다. |
| 원이 타원으로 보이거나, 대칭된 문자가 바른 방향으로 읽힘 | 객체가 기울어진 평면에 그려졌거나, 아래에서 본 상태로 파일을 만든 프로그램에서 그려졌습니다. CadCraft는 그 프로그램의 평면도처럼 위에서 본 모습으로 표시하며, 문자는 읽을 수 있게 유지됩니다. | 해결할 것이 없습니다. 다른 프로그램과 같은 방식으로 보려면, 도면을 평면화하거나 객체를 위에서 그린 상태로 요청합니다. |
| 블록, 원 또는 치수가 파일을 만든 프로그램과 다른 위치에 있음 | CadCraft가 잘못 읽는 도면 사례입니다. | Discord에 알려 주시고, 공유할 수 있으면 파일도 함께 보내 주시기 바랍니다. |

## 명령행

| 메시지 또는 증상 | 원인 | 해결 방법 |
|---|---|---|
| "알 수 없는 명령 "…". 목록을 보려면 HELP를 입력합니다." | 같은 이름의 명령이나 별칭이 없습니다. | `HELP`를 입력하거나 [명령 참조](topic:commands)를 확인합니다. 익숙한 명령 중 일부는 [아직 만들지 않았습니다](topic:not-built-yet). |
| 입력하는 동안 명령행 옆에 "해당 명령 없음" | 입력한 내용이 아직 아무 것과도 일치하지 않습니다. | 계속 입력하거나 철자를 확인합니다. |
| "점 또는 옵션 키워드가 필요합니다." | 입력한 내용이 점이나 옵션이 아닙니다. | 형식을 확인합니다: `x,y`, `@dx,dy`, `@d<a`, 또는 단일 숫자. [좌표 및 거리 입력](topic:coordinate-entry)을 참조합니다. |
| "양의 숫자 또는 두 점이 필요합니다." | 거리가 음수이거나 숫자가 아닙니다. | 양의 숫자를 입력하거나 두 점을 클릭합니다. |
| "각도(도 단위) 또는 두 점이 필요합니다." | 각도가 숫자가 아닙니다. | 도 단위를 숫자만으로 입력합니다. |
| "숫자가 필요합니다." | 숫자를 입력해야 했습니다. | 숫자만 입력합니다. |
| "잘못된 옵션 키워드입니다." | 입력한 글자가 옵션과 맞지 않습니다. | 대괄호 안에 표시된 대문자를 입력합니다. |
| `*Cancel*` | {{key:Esc}}를 눌렀거나, 점이 필요한 자리에서 {{key:Enter}}를 눌렀습니다. | 명령을 다시 시작합니다. |
| 입력이 명령행에 전달되지 않음 | 패널이나 대화상자의 입력란에 커서가 있습니다. | {{key:Enter}} 또는 {{key:Esc}}를 누르거나 도면을 클릭합니다. |
| 명령이 선택하지 않은 객체를 사용함 | 명령을 시작하기 전에 객체가 이미 선택되어 있었습니다. | 명령을 시작하기 전에 {{key:Esc}}를 누릅니다. |
| 선이 예상과 다른 곳으로 그려짐 | `x,y`는 절대 좌표입니다. | 상대 점에는 `@dx,dy`를 사용합니다. |
| "현재 명령을 먼저 마치거나 취소합니다 (Esc)." | 명령이 실행 중일 때 {{key:Mod+S}}를 눌렀습니다. | {{key:Esc}}를 누른 다음 저장합니다. |
| "DWG(AutoCAD 2000)로 저장하지 못했습니다: … 다른 이름으로 저장을 시도한 뒤 DXF로 저장합니다." | 도면의 일부를 DWG로 쓸 수 없습니다. | {{key:Mod+Shift+S}}를 누르고 {{ui:DXF R12}}를 선택한 뒤 {{ui:저장}}을 클릭합니다. |
| "저장되지 않음." | {{ui:다른 이름으로 복사본 저장}} 대화상자를 {{ui:취소}}나 {{key:Esc}}로 닫았습니다. | {{key:Mod+Shift+S}}를 다시 누르고 {{ui:저장}}을 클릭합니다. |

## 편집

| 메시지 또는 증상 | 원인 | 해결 방법 |
|---|---|---|
| 객체가 선택되지 않음 | 객체의 도면층이 잠기거나, 꺼지거나, 동결되었습니다. 또는 배치 위에 있으면서 뷰포트 안의 모델입니다. | 도면층을 잠금 해제하거나 {{ui:모델}} 탭으로 이동합니다. |
| "그 자리에는 아무것도 없습니다." | 클릭한 위치에 객체가 없습니다. | 확대하고 선 자체를 클릭합니다. |
| "그 자리에서 그 객체와 교차하는 것이 없습니다." | {{cmd:TRIM}}이 선택한 조각과 교차하는 객체를 찾지 못했습니다. | 자르기 선이 실제로 그 객체와 교차하는지 확인합니다. |
| "그 객체는 자를 수 없습니다." | 자르기는 선, 호, 원, 폴리선에서만 작동합니다. | 블록을 먼저 분해하거나, 지우고 다시 그립니다. |
| "그 방향에는 경계가 없습니다." | {{cmd:EXTEND}}가 만날 대상을 찾지 못했습니다. | 늘어나야 할 끝에 더 가깝게 클릭합니다. |
| "그 객체는 간격 띄우기를 할 수 없습니다." | 간격 띄우기는 선, 호, 원, 폴리선에서만 작동합니다. | 먼저 분해하거나, 평행선을 그립니다. |
| "그 거리만큼 간격 띄우기를 할 수 없습니다." | 간격 띄우기 결과로 도형이 안팎이 뒤집힙니다. | 더 작은 거리를 사용합니다. |
| "반지름이 너무 큽니다." 또는 "거리가 너무 큽니다." | 모깎기나 모따기가 선의 끝을 넘어가게 됩니다. | `R`로 더 작은 반지름을, 또는 `D`로 더 작은 거리를 설정합니다. |
| "열린 폴리선의 첫 번째 또는 마지막 세그먼트만 잘라 낼 수 있습니다." | 모서리가 폴리선의 가운데를 자르게 됩니다. | 서로 이웃한 폴리선 세그먼트 두 개를 선택하거나, 모든 모서리에 `P`를 사용합니다. |
| "두 번째로 다른 선을 고릅니다." | 두 번째 선택이 같은 선이거나 선이 아닙니다. | 다른 선을 고릅니다. |
| "분해되는 것은 폴리선, 블록 참조, 치수뿐입니다." | 선택 항목에 분해할 것이 없었습니다. | 폴리선, 블록 참조 또는 치수를 선택합니다. |
| "현재 도면층입니다. 먼저 다른 도면층을 현재 도면층으로 지정합니다." | 현재 도면층을 끄려고 했습니다. | 다른 도면층의 이름을 클릭한 다음, 이 도면층을 끕니다. |
| "이름이 …인 도면층이 이미 있습니다." | 도면층 이름은 고유해야 합니다. | 다른 이름을 고릅니다. |
| "실행 취소할 것이 없습니다." | 되돌릴 작업이 없거나, 도면을 열었거나 새로 시작하여 기록이 지워졌습니다. | — |

## 치수와 블록

| 메시지 또는 증상 | 원인 | 해결 방법 |
|---|---|---|
| 치수 문자와 화살표가 아주 작거나 큼 | 크기는 도면 단위로 지정되며, 전체 축척이 도면에 맞지 않습니다. | {{cmd:DIMSCALE}}을 플롯 축척으로 설정합니다. [치수 크기 설정](topic:dimension-settings)을 참조합니다. |
| "측정할 각의 안쪽 점을 고릅니다." | 각도 치수의 위치가 한 변 위에 있습니다. | 각의 안쪽을 클릭합니다. |
| "그 선들은 평행합니다." | 평행선 사이에는 각이 없습니다. | 만나는 두 선을 고릅니다. |
| "선형 또는 정렬 치수를 고릅니다." | {{cmd:DIMCONTINUE}} 또는 {{cmd:DIMBASELINE}}는 시작점으로 사용할 치수가 필요합니다. | 선형 또는 정렬 치수를 고릅니다. |
| "이 도면에는 아직 블록이 없습니다. F는 파일에서, L은 라이브러리에서 삽입합니다 …" | 도면에 자체 블록이 없습니다. | `F` 또는 `L`을 입력하거나, {{cmd:BLOCK}}으로 블록을 만듭니다. |
| "이름이 "…"인 블록이 없습니다." | 이름이 잘못되었습니다. | 메시지에 나오는 블록 목록을 확인합니다. |
| "블록 이름은 *로 시작할 수 없으며, 다음 문자는 쓸 수 없습니다 …" 뒤에 문자 목록이 이어짐 | 블록 이름에 블록이 쓸 수 없는 문자가 있습니다. | 문자, 숫자, `-`, `_`를 사용합니다. |
| "블록은 자기 자신을 포함할 수 없습니다." | 선택 항목에 만들고 있는 블록에 대한 참조가 있습니다. | 그 참조를 제외합니다. |
| "선택된 객체가 없어 아무것도 만들지 않았습니다." | 선택하기 전에 {{key:Enter}}를 눌렀습니다. | {{cmd:BLOCK}}을 다시 실행하고 객체를 선택합니다. |

## 배치와 플롯

| 메시지 또는 증상 | 원인 | 해결 방법 |
|---|---|---|
| "뷰포트는 배치에 놓입니다. 먼저 배치 탭을 열거나(또는 LAYOUT으로 하나 만듭니다)." | {{ui:모델}} 탭에서 {{cmd:MVIEW}}를 실행했습니다. | 먼저 시트 탭을 클릭합니다. |
| "먼저 뷰포트가 있는 배치를 엽니다." | {{ui:모델}} 탭에서 {{cmd:VPVIEW}}를 실행했습니다. | 먼저 시트 탭을 클릭합니다. |
| 뷰포트 축척이 열 배 잘못된 것처럼 보임 | 도면 단위가 잘못되었습니다. | {{ui:현재 설정}}에서 {{ui:단위}}를 설정합니다. |
| "아직 플롯할 것이 없습니다." | 모델이 비어 있습니다. | 무엇인가 그리거나 도면을 엽니다. |
| "플롯할 윈도우를 고릅니다." | {{ui:윈도우…}}를 선택했지만 윈도우를 고르지 않았습니다. | {{ui:고르기}}를 클릭하고 두 모서리를 고릅니다. |
| "… 용지보다 큼: 가장자리가 잘립니다." | 그 축척에서는 영역이 맞지 않습니다. | 더 작은 축척, 더 큰 용지, 또는 {{ui:용지에 맞춤}}을 선택합니다. |
| "브라우저가 새 탭을 막아서, 대신 PDF를 내려받았습니다." | 사이트의 팝업이 차단되어 있습니다. | 내려받은 PDF를 열거나, 사이트의 팝업을 허용합니다. |
| 문자가 "?"로 인쇄됨 | PDF 글꼴에 해당 글자가 없거나(드문 표의 문자, 힌디어 및 복잡한 글자 모양 처리가 필요한 다른 문자 …), 더 큰 글꼴을 가져오지 못했습니다(오프라인). 유럽 문자, 키릴 문자, 그리스 문자, 히브리 문자, 아랍 문자, 페르시아어, 우르두어, 태국어, 중국어, 일본어, 한국어는 그대로 인쇄됩니다. | 아랍 문자, 태국어, 중국어, 일본어, 한국어는 연결된 상태에서 다시 플롯합니다. 그 밖의 문자는 아직 만들지 않았습니다. |
| PDF에 작도선이 나타남 | 그 도면층이 플롯됩니다. | 도면층의 프린터 버튼을 클릭합니다. |
| 모든 선의 굵기가 같음 | 선가중치가 {{ui:기본값}}이므로, 대화상자의 펜 폭으로 인쇄됩니다. | 오른쪽 패널에서 도면층이나 객체에 {{ui:선가중치}}를 지정하거나, 대화상자에서 {{ui:선 가중치}}를 선택합니다. 화면에서 선가중치를 보려면 상태 표시줄의 {{ui:LWT}}를 누릅니다. |

## 키와 화면

| 증상 | 원인 | 해결 방법 |
|---|---|---|
| F3, F7 또는 F8이 볼륨을 바꾸거나 Mission Control을 엽니다 | Mac의 기능 키입니다. | **fn**을 누른 상태로 누르거나, 상태 표시줄 버튼을 사용합니다. [키, 마우스 및 트랙패드](common:keys)를 참조합니다. |
| F7이 캐럿 탐색을 묻습니다 | Firefox가 F7을 직접 사용합니다. | 아니요를 선택하고 {{ui:그리드}} 버튼을 사용합니다. |
| {{key:Mod+N}} 키로 브라우저 창이 열림 | 브라우저가 그 키를 사용합니다. | {{ui:새로 만들기}}를 클릭하거나 `NEW`를 입력합니다. |
| {{key:Mod+A}} 키로 명령행의 문자가 선택됨 | 명령행에 커서가 있었습니다. | 먼저 객체를 클릭하거나, `Select objects` 프롬프트에서 `ALL`을 입력합니다. |
| {{key:Delete}} 키로 지워지지 않음 | 명령행에 커서가 있었습니다. | `E`를 입력하고 {{key:Enter}}를 누릅니다. |
| Mac 트랙패드에서 우클릭이 동작하지 않음 | Control-클릭은 일반 클릭으로 처리될 수 있습니다. | 두 손가락으로 클릭합니다. |
| 트랙패드로 화면이 이동하지 않음 | 가운데 버튼이 없고, Space로는 이동하지 않습니다. | 두 손가락으로 스와이프하면 2D 뷰가 이동합니다(핀치와 마우스 휠은 확대/축소합니다). 또는 오른쪽 버튼을 누른 채 드래그합니다. |
| 처음 {{key:Esc}}를 눌렀을 때 전체 화면을 벗어남 | 브라우저가 Esc로 전체 화면을 나갑니다. | {{key:Esc}}를 한 번 더 눌러 명령을 취소합니다. |
| Mac에서 {{key:F1}}이 동작하지 않음 | F1은 밝기 키입니다. | **fn**을 누른 상태로 누르거나, {{ui:도움말}}을 클릭합니다. |
| 입력한 내용이 도움말의 검색 상자로 들어감 | 도움말 패널에 커서가 있습니다. | 도면을 클릭합니다. |
| 도면이 비어 보임 | 아주 멀리 확대했습니다. | {{ui:범위}}를 클릭하거나, 휠을 두 번 클릭합니다. |
| 탭을 닫을 때 "사이트를 떠나시겠습니까?" | 저장되지 않은 변경 사항이 있습니다. | 머무르고, {{key:Mod+S}}로 저장한 뒤 닫습니다. |
