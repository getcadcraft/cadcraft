## 만들 내용

문 기호를 `DOOR-900`이라는 블록으로 만든 뒤, 그린 그대로, 90도 회전한 것, 대칭한 것으로 세 번 삽입합니다.

블록은 이름이 붙은 객체 묶음입니다. 한 번만 그리고, 사용하는 곳마다 같은 정의를 가리키는 **블록 참조**를 만듭니다. 왼쪽 패널의 {{ui:Blocks}} 섹션에서 도면의 블록과 각 블록의 사용 횟수를 볼 수 있습니다.

## 문 그리기

1. `L` 입력 후 {{key:Enter}} 키를 누릅니다.
2. `0,0` 입력 후 {{key:Enter}} 키를 누릅니다.
3. `@0,900` 입력 후 {{key:Enter}} 키를 누르고, 한 번 더 {{key:Enter}} 키를 누릅니다. 이것이 문짝입니다.
4. `A` 입력 후 {{key:Enter}} 키를 누릅니다.
5. `C` 입력 후 {{key:Enter}} 키를 눌러 중심을 먼저 지정합니다.
6. 중심으로 `0,0` 입력 후 {{key:Enter}} 키를 누릅니다.
7. 시작점으로 `900,0` 입력 후 {{key:Enter}} 키를 누릅니다.
8. 끝점으로 `0,900` 입력 후 {{key:Enter}} 키를 누릅니다. 이것이 여닫이 호입니다.
9. {{ui:Extents}} 클릭.

호는 시작점에서 끝점까지 반시계 방향으로 그려집니다.

## 블록 만들기

1. `B` 입력 후 {{key:Enter}} 키를 누르거나, 블록 그룹의 {{ui:Make}} 클릭.
2. `블록 이름 입력` 프롬프트에 `DOOR-900` 입력 후 {{key:Enter}} 키를 누릅니다.
3. `삽입 기준점 지정` 프롬프트에 `0,0` 입력 후 {{key:Enter}} 키를 누릅니다. 이것은 경첩, 즉 블록을 놓을 때 위치가 되는 점입니다.
4. `객체 선택` 프롬프트에서 문짝과 호를 둘러싸도록 윈도우를 드래그합니다.
5. {{key:Enter}} 키를 누릅니다.

기록에는 `블록 "DOOR-900" 생성: 객체 2개를 블록 참조 1개로 바꿨습니다.`라고 표시됩니다. {{ui:Blocks}} 패널에서 DOOR-900 옆에 `1×` 표시가 나타나며, 이는 참조 1개라는 뜻입니다. 문을 클릭하면 이제 하나의 객체로 선택되며, '블록 참조'라고 표시됩니다.

:::tip
먼저 객체를 선택한 뒤 `B` 입력도 가능합니다. CadCraft는 여전히 이름과 기준점을 묻고, 그다음 선택한 객체를 사용합니다.
:::

## 블록 삽입

1. `I` 입력 후 {{key:Enter}} 키를 누르거나, {{ui:Blocks}} 패널에서 DOOR-900 옆의 {{ui:Insert}} 클릭.
2. `블록 이름 또는 [파일(F)/라이브러리(L)] <DOOR-900>` 프롬프트에서 {{key:Enter}} 키를 누릅니다. ({{ui:Insert}} 버튼은 이름을 자동으로 채웁니다.)
3. 문이 십자선을 따라 움직입니다. 경첩이 놓일 위치를 클릭합니다.

두 번째 문이 나타납니다.

## 회전 또는 축척을 적용해 삽입

1. `I` 입력 후 {{key:Enter}} 키를 누르고, 이름을 받아들이려고 한 번 더 {{key:Enter}} 키를 누릅니다.
2. `삽입점 지정 [축척(S)/회전(R)]` 프롬프트에 `R` 입력 후 {{key:Enter}} 키를 누릅니다.
3. `90` 입력 후 {{key:Enter}} 키를 누릅니다. 미리 보기가 회전합니다.
4. 클릭해서 놓습니다.

축척 비율을 지정하려면 `S`를 입력합니다. 이 비율은 두 방향 모두에 적용됩니다. 축척과 회전 값은 다음 삽입을 위해 기억됩니다. 문을 대칭하려면 먼저 삽입한 다음, 그 참조에 대해 {{cmd:MIRROR}} 명령을 사용합니다.

## 삽입한 블록 변경

블록 참조를 선택합니다. 오른쪽 패널에서 {{ui:X}}, {{ui:Y}}, {{ui:Scale X}}, {{ui:Scale Y}}, {{ui:Rotation}} 값을 바꿀 수 있습니다. {{ui:Scale X}} 값이 음수이면 뒤집힙니다.

## 블록 다시 정의

모든 문을 한 번에 바꾸려면 같은 이름으로 블록을 만듭니다.

1. 새 버전의 문을 그립니다.
2. `B` 입력 후 {{key:Enter}} 키를 누르고, `DOOR-900`을 입력합니다.
3. `이미 존재: 블록 "DOOR-900". 다시 정의할까요?` 메시지에서 `Y` 입력 후 {{key:Enter}} 키를 누릅니다.
4. 앞에서와 같이 기준점을 주고 새 객체를 선택합니다.

DOOR-900 참조는 모두 새 버전을 표시합니다.

또는 블록을 직접 편집할 수 있습니다: {{ui:Blocks}} › {{ui:More}} › {{ui:Edit block}} ({{cmd:BEDIT}}) 명령을 사용하면 블록만 따로 열립니다. 저장하려면 {{ui:Save block}} 버튼을 누릅니다. 자세한 내용: [블록 속성](topic:attributes#change-a-block-the-block-editor).

## 블록 개수 세기와 일람표 내보내기

{{cmd:COUNT}} 명령을 입력하거나(또는 {{ui:Blocks}} › {{ui:More}} › {{ui:Count blocks}}), 다음 중 하나를 합니다.

- 문 하나를 클릭합니다: 이 공간의 모든 문이 선택되고, 기록에 여기와 전체 도면의 개수가 표시됩니다.
- 또는 {{key:Enter}} 키를 누릅니다: 기록에 모든 블록과 개수가 많은 순서대로 나열됩니다.
- 또는 `E` 입력 후 `C`: 개수를 CSV로 저장합니다(모델, 시트, 전체). `A`: 참조마다 한 행씩, 도면층, 위치, 회전과 모든 속성 값을 담은 일람표가 만들어지며, 스프레드시트에서 열 수 있습니다.

이름 없는 블록(치수, 표)과 다른 블록 안의 참조는 세지 않습니다. 수식처럼 시작하는 셀(`=`, `+`, `-`, `@`)은 앞에 `'`가 붙어, 스프레드시트에서 텍스트로 표시됩니다.

## 분해와 제거

- {{cmd:EXPLODE}} (`X`): 선택한 블록 참조를 개별 객체로 되돌립니다. 블록 정의는 남습니다.
- {{cmd:PURGE}} (`PU`): 더 이상 사용되지 않는 블록 정의를 제거합니다. 기록에 제거된 개수가 표시됩니다.

## 블록 이름

이름은 최대 255자이며 공백을 포함할 수 있지만, 별표(`*`)로 시작할 수 없고, `<` `>` `/` `\` `"` `:` `;` `?` `*` `|` `=` 또는 백틱을 포함할 수 없습니다. DXF R12로 저장하면 이름은 대문자로 기록되고, 문자, 숫자, `$`, `_`, `-` 이외의 문자는 `_`로 바뀌며, 이름은 31자로 잘립니다. 바뀐 이름의 개수는 기록에 표시됩니다. `DOOR-900`처럼 대문자, 숫자, 하이픈으로 된 짧은 이름은 그대로 유지됩니다. DWG로 저장하면 입력한 대소문자 그대로 이름이 유지되며, DWG가 허용하지 않는 문자만 바뀝니다(`|`는 `$0$`, 나머지는 `_`).

## 블록이나 객체를 별도 파일로 쓰기

`W`({{cmd:WBLOCK}})를 입력한 뒤 **객체**, **블록** 또는 **전체 도면** 중 하나를 선택합니다. 결과는 사용하는 도면층, 스타일, 블록만 담은 새 DWG 또는 DXF이며, 기준점이 원점이 됩니다. 객체의 경우 유지하거나, 블록으로 바꾸거나, 이 도면에서 삭제할 수 있습니다.

## 자주 하는 실수

- **블록이 십자선에서 멀리 놓였습니다.** 기준점이 객체 위에 있지 않았습니다. 기준점을 모서리나 경첩 위에 두고 블록을 다시 만듭니다.
- **`"선택된 객체 없음; 아무것도 만들지 않았습니다."`** 객체를 선택하기 전에 {{key:Enter}} 키를 눌렀습니다.
- **`"이 도면에는 아직 블록이 없습니다: F 파일에서 삽입, L 라이브러리에서 삽입 (또는 BLOCK으로 만들기)."`** 다른 도면에서 블록을 가져오려면 `F`를, 라이브러리에서 가져오려면 `L`을 입력합니다. 자세한 내용: [파일 또는 라이브러리에서 삽입](topic:insert-from-file-and-library).
- **`"뷰포트는 블록에 넣을 수 없습니다."`** 선택에서 뷰포트 테두리를 제외하십시오.
