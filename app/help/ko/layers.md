## 만들 것

벽, 문, 메모라는 세 도면층을 각각 고유한 색으로 만들고, 각 도면층에 객체를 그린 뒤 도면층 사이로 이동합니다.

## 도면층 패널

도면층은 왼쪽 패널의 {{ui:도면층}} 아래에 있습니다. 각 행에는 왼쪽에서 오른쪽으로 다음이 표시됩니다.

- 점: **현재** 도면층이면 채워져 있으며, 새 객체는 여기에 그려집니다.
- 색상 견본
- 도면층 이름
- 네 개의 버튼: 켜기/끄기(눈), 동결(눈송이), 잠금(자물쇠), 플롯(프린터)

모든 도면에는 `0`이라는 도면층이 있습니다. `LA`를 입력하고 {{key:Enter}}를 누르면 패널로 이동합니다.

## 도면층 만들기

1. 목록 위의 {{ui:새 도면층}}을 클릭합니다. 이름 상자가 열립니다.
2. `Walls`를 입력하고 {{key:Enter}}를 누릅니다(또는 {{ui:추가}}를 클릭합니다).

상태 표시줄에 "도면층 Walls 추가 및 현재 도면층으로 지정"이 표시됩니다. 새 도면층의 색상은 7번(밝은 테마에서는 검정, 어두운 테마에서는 흰색)입니다.

3. {{ui:새 도면층}}을 다시 클릭하고 `Doors`를 입력한 뒤 {{key:Enter}}를 누릅니다.
4. {{ui:새 도면층}}을 다시 클릭하고 `Notes`를 입력한 뒤 {{key:Enter}}를 누릅니다.

이제 Notes가 현재 도면층입니다.

## 도면층마다 색 지정

1. Walls 행의 색상 견본을 클릭합니다. 시스템의 색상 선택기가 열립니다.
2. 색을 고르고 확인합니다.

색상 견본과, Walls에 있으면서 색상이 {{ui:도면층별}}인 객체가 모두 바뀝니다.

:::note
표준 CAD 색상 255가지 중 하나와 일치하는 색은 그 번호로 저장됩니다. 그 밖의 색은 CadCraft 안에서는 정확히 유지되지만, DWG 또는 DXF 파일로 저장될 때는 가장 가까운 표준 색으로 저장됩니다.
:::

## 도면층에 그리기

1. 목록에서 **Walls** 이름을 클릭합니다. 점이 채워지고 상태 표시줄에 "현재 도면층: Walls"가 표시됩니다.
2. 사각형(`REC`)을 그립니다. Walls에 그려집니다.
3. **Doors**를 클릭하고 호(`A`)를 그립니다. Doors에 그려집니다.

오른쪽의 {{ui:현재 설정}}(선택된 객체가 없을 때)에서 {{ui:도면층}} 아래에 있는 현재 도면층을 고를 수도 있습니다.

## 객체를 다른 도면층으로 이동

1. 객체를 선택합니다.
2. 오른쪽 패널의 {{ui:도면층}}에서 새 도면층을 고릅니다.

객체는 그 도면층으로 이동하며, 색상이 {{ui:도면층별}}이면 그 도면층의 색상을 따릅니다.

## 끄기, 동결, 잠금, 플롯

| 버튼 | 기능 |
|---|---|
| 켜기/끄기 (눈) | 도면층의 객체를 숨깁니다. 보이지 않으며, 선택하거나 스냅할 수 없습니다. |
| 동결 (눈송이) | CadCraft에서는 끄기와 같은 효과입니다. 다른 프로그램은 둘을 다르게 처리하므로 따로 두며, 설정은 저장됩니다. |
| 잠금 (자물쇠) | 객체는 보이고 스냅할 수 있지만 선택하거나 변경할 수 없습니다. 따라 그릴 배경에 알맞습니다. |
| 플롯 (프린터) | 누르면 도면층이 화면에는 표시되지만 플롯과 PDF에서는 **제외됩니다**. 구성선이나 나를 위한 메모에 사용하십시오. |

버튼 위에 마우스를 올리면 기능이 표시됩니다("끄기", "동결", "잠금", "이 도면층 플롯 안 함").

현재 도면층은 끌 수 없습니다. 상태 표시줄에 "현재 도면층입니다. 먼저 다른 도면층을 현재 도면층으로 지정하십시오."가 표시됩니다. 도면층 이름을 클릭해 현재 도면층으로 지정하면 해당 도면층은 켜지고 동결도 해제됩니다.

패널에서 하든 명령으로 하든, 도면층을 바꿀 때마다 실행 취소 한 단계입니다. {{key:Mod+Z}}를 누르면 되돌아갑니다.

## 객체를 선택해서 도면층 다루기

도면층 이름을 알 필요는 없습니다. 그 도면층의 객체를 선택하면 됩니다. 명령을 입력하거나, {{ui:도면층}} 패널 맨 위의 {{ui:도구}}를 여십시오.

| 명령 | 기능 |
|---|---|
| {{cmd:LAYISO}} | 객체를 선택하고 {{key:Enter}}를 누르면 선택한 객체의 도면층만 켜진 상태로 남고, 나머지 도면층은 모두 꺼집니다. 현재 도면층이 꺼지면 분리된 도면층 중 하나가 현재 도면층이 됩니다. |
| {{cmd:LAYUNISO}} | 마지막 {{cmd:LAYISO}}가 끈 도면층을 다시 켜고, 바꾸었던 현재 도면층을 되돌려 줍니다. |
| {{cmd:LAYOFF}} | 객체를 하나씩 클릭하면 각 객체의 도면층이 꺼집니다. 마지막 것을 되돌리려면 `U`를 입력하고, 마치려면 {{key:Enter}}를 누릅니다. |
| {{cmd:LAYFRZ}} | 같지만 각 도면층을 동결합니다. |
| {{cmd:LAYMCUR}} | 객체를 클릭하면 그 객체의 도면층이 현재 도면층이 되며, 켜지고 동결도 해제됩니다. 객체가 이미 하나 선택되어 있으면 그 객체를 사용합니다. |
| {{cmd:LAYON}} | 모든 도면층을 켭니다. |
| {{cmd:LAYTHW}} | 모든 도면층의 동결을 해제합니다. |

현재 도면층은 이 방법으로 꺼지거나 동결되지 않습니다. 기록에 이 사실이 표시되며, 먼저 {{cmd:LAYMCUR}}로 다른 도면층을 현재 도면층으로 지정할 수 있습니다. 블록 참조를 선택하면 그 참조 자체의 도면층을 사용합니다.

## 도면층 이름 바꾸기, 병합, 삭제

- {{cmd:RENAME}}: `LA`, 기존 이름, 새 이름을 입력합니다. 그 도면층의 모든 객체가 따라 바뀝니다. (`B`로 블록 이름도 같은 방식으로 바꾸며, 모든 참조에 반영됩니다.)
- {{cmd:LAYMRG}}: 병합할 도면층마다 객체를 하나씩 클릭하거나(또는 `N`을 입력하고 이름을 입력), {{key:Enter}}를 누른 뒤 대상 도면층을 고르고 `Y`로 답합니다. 객체는 대상으로 이동하며(모델, 시트, 블록 안 포함), 병합된 도면층은 사라집니다.
- {{cmd:LAYDEL}}: 도면층의 객체를 하나 선택하거나(또는 `N`과 이름), `Y`로 답합니다. 도면층은 **그 위의 모든 객체와 함께** 모든 곳에서 삭제됩니다. 도면층 0, DEFPOINTS 및 현재 도면층은 삭제할 수 없습니다.

세 가지 모두 실행 취소 한 단계이며, {{ui:도면층}} 패널 맨 위의 {{ui:도구}}에 있습니다.

1. 벽선 하나를 클릭한 뒤 `LAYISO`를 입력하고 {{key:Enter}}를 누릅니다. Walls만 켜진 상태로 남습니다.
2. Walls에서 필요한 것을 그리거나 변경합니다.
3. `LAYUNISO`를 입력하고 {{key:Enter}}를 누릅니다. Doors, Notes 도면층이 다시 나타납니다.

## 자주 하는 실수

- **새 선이 잘못된 도면층에 그려졌습니다.** 그리기 전에 어느 점이 채워져 있는지 확인하십시오. 새 도면층은 추가하는 즉시 현재 도면층이 됩니다.
- **객체가 선택되지 않습니다.** 그 도면층이 잠겨 있거나, 꺼져 있거나, 동결되어 있습니다.
- **다른 프로그램에서 도면층이 여전히 인쇄됩니다.** DXF R12는 "플롯 안 함"을 저장할 수 없습니다. 도면에 시트가 있으면 CadCraft는 이 설정을 자체적으로 유지하지만, 다른 프로그램은 그 도면층을 플롯합니다.
- **저장 후 도면층 이름이 대문자로 바뀝니다.** DXF R12는 이름을 대문자로 저장하므로 `Walls`는 `WALLS`로 돌아오고, 공백은 `_`가 됩니다. 저장된 DWG는 입력한 대로 이름을 유지합니다.
- **도면층 이름 바꾸기, 병합 또는 삭제.** {{cmd:RENAME}}, {{cmd:LAYMRG}} 또는 {{cmd:LAYDEL}}을 사용하십시오(이 명령들은 {{ui:도구}}에도 있습니다). 아래를 참조하십시오.

## 도면층 그룹화

폴더(기존, 제안, 설비 등)에 도면층을 넣어 목록을 짧게 유지합니다. 각 폴더는 접을 수 있으며, 폴더의 스위치는 그 안의 모든 도면층을 함께 켜거나 끄고, 동결하거나 잠급니다. 현재 도면층은 절대 꺼지지 않습니다.

도면층 패널의 {{ui:도구}}에서 {{ui:기본 그룹 추가}}는 소규모 주택 작업용으로 준비된 그룹 세트를 추가하고, {{ui:이름으로 그룹화}}는 접두사를 공유하는 도면층(`E-Walls`, `E-Doors`)을 묶으며, {{ui:새 그룹}}은 새 그룹을 만듭니다. 도면층을 폴더 위로 끌어 놓거나, 도면층 목록 위의 현재 도면층 항목을 사용하십시오. {{ui:도면층 찾기}}에 입력하면 목록이 좁혀집니다. `LAYGROUP`(`LG`)은 명령행에서 같은 일을 합니다.

도면층 자체는 바뀌지 않으므로 다른 CAD 프로그램에서는 일반적인 평면 목록으로 보입니다. CadCraft는 그룹 정보를 파일에 보관합니다.
