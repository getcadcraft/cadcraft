## 이 항목에서 배우는 것

AI 어시스턴트(또는 직접 작성한 스크립트)가 도면을 보고, CadCraft 명령을 실행하고, 플롯하고 저장하며, 어떤 것을 건드릴 수 있는지 정하는 방법입니다.

CadCraft에는 **자체 AI가 없으며** 아무것도 외부로 보내지 않습니다. 어시스턴트는 직접 준비합니다. 모델 컨텍스트 프로토콜(MCP)을 사용하는 프로그램이라면 무엇이든 쓸 수 있습니다. CadCraft는 도구만 제공하며, 어떤 도구를 쓸지는 사용자가 선택합니다.

접근 방법은 두 가지입니다.

- **지금 열린 도면.** 어시스턴트는 이 컴퓨터의 CadCraft Studio를 통해 사용자 옆 이 창에서 작업합니다. 이 방식은 {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Assistants}}에서 설정합니다.
- **앱을 열지 않고 컴퓨터의 도면 사용.** CadCraft MCP 서버와 `cadcraft` 명령행은 지정한 폴더의 DWG와 DXF 파일을 읽고 씁니다. 아래 "CadCraft를 열지 않고 파일 작업하기"를 참고하십시오.

## 켜기

1. {{ui:Settings}}(앱 막대의 톱니바퀴 또는 {{key:Mod+,}})을 열고 {{ui:CadCraft}} 탭으로 이동합니다.
2. {{ui:Assistants}} 아래에서 **AI 어시스턴트와 스크립트가 CadCraft를 사용하도록 허용**을 선택합니다. 사용자가 선택하기 전까지는 꺼져 있습니다.
3. 할 수 있는 작업을 고릅니다. **읽기**는 처음부터 선택되어 있습니다. 나머지는 필요할 때만 선택하십시오.

| 권한 | 어시스턴트가 할 수 있는 일 |
|---|---|
| 읽기 | 도면 보기: 설명, 객체 목록 및 찾기, 선택 보기, 뷰 설명과 사진 찍기, 도면층과 제도 규칙에 따른 검사 |
| 편집 | 도면에서 명령 실행과 선택 변경. 각 작업은 실행 취소할 수 있는 한 단계입니다 |
| 저장 | 도면 저장(데스크톱에서는 원래 파일에, 브라우저에서는 다운로드로) |
| 내보내기 | PDF로 플롯하고 기타 파일 만들기 |

## 선택한 폴더의 파일 사용 허용

CadCraft Studio에서 어시스턴트는 파일 대화상자 대신 파일 이름으로 파일을 열고, 저장하고, 플롯할 수 있습니다. 단, {{ui:Assistants}} › {{ui:Folders it may use}}에 추가한 폴더 안에서만 가능합니다.

1. {{ui:Add a folder…}} 버튼을 선택하고 Studio의 대화상자에서 폴더를 고릅니다.
2. 이제 어시스턴트는 그 폴더의 파일 목록(`files_list`)을 볼 수 있고, 도면을 열(`drawing_open`), DWG 버전이나 DXF로 저장하고, PDF 또는 SVG 파일로 플롯하고, LISP 파일을 불러오고, 명령이 요구하는 파일을 제공하거나(`INSERT` `F`, `XATTACH`, 점 파일) 명령의 파일을 어디에 둘지 지정할 수 있습니다(`COUNT`의 CSV, `PUBLISH`).
3. {{ui:Remove}}를 선택하면 폴더가 즉시 목록에서 빠집니다. 그 밖의 경로는 거부되며, 이미 있는 파일은 어시스턴트가 요청했거나 어시스턴트가 직접 만든 경우에만 교체됩니다.

파일 열기에는 **읽기**가 필요하고, 도면 저장에는 **저장**이 필요하며, 그 밖의 파일에는 **내보내기**가 필요합니다.

선택하지 않은 권한의 도구는 어시스턴트에게 제공되지 않습니다. 어시스턴트가 그런 도구를 요청하면 CadCraft는 거부하고 활동 기록에 남깁니다. 스위치를 끄면 모든 연결이 즉시 끊어집니다. {{ui:CadCraft 설정 초기화}}도 이 스위치를 끕니다.

## 어시스턴트 연결

어시스턴트는 이 컴퓨터의 **CadCraft Studio**를 통해 연결합니다. Studio는 이 컴퓨터에서만 접근할 수 있는 작은 서버(주소 `127.0.0.1`)를 실행하며, Studio가 시작될 때마다 새로 만드는 토큰으로 보호됩니다. Studio를 열고 {{ui:어시스턴트 연결}}을 선택해 주소와 토큰을 복사하십시오.

- 어시스턴트에서 HTTP 형식의 MCP 서버를 추가하고, 주소(`http://127.0.0.1:47615/mcp` 같은 형태)와 헤더 `Authorization: Bearer <token>`을 입력합니다. Studio는 붙여넣을 설정을 보여 줍니다.

Studio에서 {{ui:새 토큰}}을 만들면 연결된 모든 어시스턴트가 새 토큰으로 다시 연결합니다. 토큰을 절대 공유하지 마십시오. 토큰을 가진 사람은 Studio가 실행되는 동안 사용자가 켠 앱을 사용할 수 있습니다.

:::note
브라우저 탭에서는 어시스턴트 연결을 열 수 없습니다. 브라우저 앱에서는 이 컴퓨터의 CadCraft Studio를 사용하기 전까지 스위치가 적용되지 않습니다.
:::

## 사용자가 계속 주도합니다

- **모든 작업은 실행 취소 한 단계입니다.** 어시스턴트의 작업에는 이름이 붙습니다(예: "어시스턴트: LINE"). {{key:Mod+Z}}를 누르면 어시스턴트의 마지막 작업 전체가 되돌아갑니다.
- **무엇을 하는지 볼 수 있습니다.** 어시스턴트의 명령은 명령 기록에 **[어시스턴트]**가 붙어 나타나며, 도면은 작업하면서 다시 그려집니다.
- **사용자를 기다립니다.** 사용자가 명령 중간에 있을 때 어시스턴트는 도면을 읽을 수만 있고 바꿀 수는 없습니다. 사용자가 끝내면 다시 시도하라는 안내를 받습니다.
- **연결 여부를 알 수 있습니다.** 연결되어 있는 동안 앱 막대의 버튼에 어시스턴트 이름이 표시됩니다. 누르면 어시스턴트의 권한을 보거나 **연결 끊기**를 할 수 있습니다.
- **활동.** {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Assistants}} › {{ui:Activity}}에서 모든 호출을 확인할 수 있습니다. 시각, 도구, 완료 또는 거부 여부, 만들어진 실행 취소 단계가 나열됩니다. {{ui:기록 저장}}을 누르면 사본을 보관합니다.

## 어시스턴트가 요청할 수 있는 것

| 도구 | 권한 | 하는 일 |
|---|---|---|
| `app_info`, `drawing_describe`, `view_describe` | 읽기 | 도면 이름, 단위, 도면층, 블록, 시트, 화면에 보이는 내용 |
| `files_list`, `drawing_open` | 읽기 | Studio: 폴더의 파일 목록, 이 창에서 파일 열기 |
| `objects_list`, `object_get`, `selection_get` | 읽기 | 형상, 길이, 면적이 있는 객체(또는 종류와 도면층별 개수만), 선택 |
| `drawing_check` | 읽기 | 허용된 도면층, 0번 도면층에 객체 없음, ByLayer 색상, 문자 높이 같은 규칙 |
| `view_screenshot` | 읽기 | 표시된 대로의 도면 그림 |
| `command_run` | 편집 | 명령행에 입력: `LINE 0,0 @100,0 @0,50 `처럼 직접 입력한 것으로 읽힙니다(공백은 응답의 끝을 뜻함). 또는 응답이 하나씩 있는 목록. 명령을 열어 둔 채 다음 호출에서 이어 갈 수 있습니다 |
| `script_run` | 편집 | 스크립트(`.scr`) 또는 LISP 파일을 {{ui:APPLOAD}}가 불러오는 방식대로 실행 |
| `block_insert` | 편집 | 블록을 속성 값과 함께 한 번에 배치 |
| `selection_set`, `undo` | 편집 | 다음 명령을 위해 객체 선택, 자신의 단계만 실행 취소 |
| `drawing_save` | 저장 | CadCraft의 {{ui:Save}}, 또는 사용자 폴더 중 한 곳에 {{ui:Save as}} |
| `drawing_plot` | 내보내기 | 시트 또는 모델의 PDF나 SVG, 지정한 축척 또는 맞춤(PDF 밑그림은 아직 이 방식으로 인쇄되지 않습니다) |

어시스턴트가 명령을 실행하는 동안 CadCraft는 질문을 대화상자 대신 명령행에 표시합니다(예: 도면 전체를 삽입할지 블록 하나만 삽입할지). 그래야 어시스턴트가 답할 수 있습니다. 라이브러리와 찾기는 여전히 사용자가 직접 해야 하며, 어시스턴트에게는 사용자에게 물어보라고 안내됩니다.

## CadCraft를 열지 않고 파일 작업하기

CadCraft MCP 서버(`cadcraft-mcp`)와 명령행(`cadcraft`)은 창 없이 Node.js에서 CadCraft 자체의 도면 코드를 실행합니다. Node.js 20 이상이 필요합니다.

- **MCP 서버**는 지정한 폴더 안에서만, 허용한 권한 범위 안에서만 작동합니다: `npx @getcadcraft/mcp --root ~/Drawings --allow read,edit`. `--root`가 없으면 어떤 파일도 열 수 없고, `--allow`가 없으면 읽기만 가능합니다. IFC 모델, 물량 산출, PDF 세트의 마크업도 읽을 수 있습니다.
- **명령행**은 사용자의 스크립트를 위한 것입니다: `cadcraft info plan.dwg`, `cadcraft run cleanup.scr plan.dwg -o plan-clean.dwg`, `cadcraft convert plan.dwg plan.dxf`, `cadcraft plot plan.dwg plan.pdf --all`, `cadcraft plot plan.dwg plan.svg`, `cadcraft check plan.dwg --rules rules.json`. 여러 파일을 한 번에: `cadcraft convert *.dwg out --to dxf`, `cadcraft plot *.dwg pdfs --to pdf`, `cadcraft check *.dwg --rules rules.json`. 프로그램이 읽을 수 있는 출력이 필요하면 `--json`을 추가하십시오.

:::note
`npx @getcadcraft/mcp`가 패키지를 찾을 수 없다고 하면 아직 게시되지 않은 것입니다. 게시되면 getcadcraft.com의 소식에서 알려 드립니다.
:::

## 문제가 생기면

- **어시스턴트에 CadCraft 도구가 보이지 않음:** 이 창에서 스위치가 켜져 있는지, 그리고 이 창이 Studio에서 열려 있는지 확인하십시오.
- **"편집 권한이 필요합니다":** {{ui:Assistants}} 아래에서 **편집**을 선택한 뒤 다시 요청하십시오.
- **"어시스턴트가 사용할 수 있는 폴더 밖":** 해당 폴더를 {{ui:Assistants}} › {{ui:Folders it may use}} 아래에 추가하거나, 이미 추가한 폴더의 파일을 사용하도록 어시스턴트에 요청하십시오.
- **"401" 또는 "token" 오류:** 토큰이 바뀌었습니다(Studio를 다시 시작했거나 {{ui:새 토큰}}을 만든 경우). 새 토큰을 어시스턴트 설정에 복사하십시오.
- **어시스턴트의 변경이 잘못됨:** {{key:Mod+Z}}를 누르십시오. 한 번 누르면 어시스턴트의 작업 한 번 전체가 되돌아갑니다.
