CadCraft는 다른 도면 작성 프로그램에서 익숙한 명령 이름과 짧은 이름을 그대로 사용합니다. 예를 들어 선은 `L`, 자르기는 `TR`, 지우기는 `E`를 입력합니다. 그래서 대부분의 명령은 따로 익혀야 할 번역표가 없습니다. 아는 이름이 곧 여기서의 이름입니다. 아래 목록은 프로그램에서 직접 만든 CadCraft의 모든 명령입니다. {{key:Enter}} 키를 누르면 마지막 명령이 반복되며, 명령행에 `HELP`를 입력하면 같은 목록이 출력됩니다.

다르거나 아직 만들지 않은 명령은 다음과 같습니다:

- **저장**: 브라우저에서는 사본을 다운로드합니다 ({{cmd:SAVE}}, {{cmd:SAVEAS}}). CadCraft Studio에서는 파일을 직접 저장합니다. 자세한 내용은 [다른 도면 작성 소프트웨어에서 옮겨 오는 경우](topic:coming-from)를 참고하십시오.
- **PLOT**: 플롯 스타일 표를 사용해 PDF 출력물을 만듭니다(PNG와 SVG도 가능). 페이지 설정 관리자는 없습니다.
- **DIMSTYLE**: 사용할 수 있습니다. **PEDIT**: 사용할 수 있으며, 꼭짓점 편집 옵션은 없습니다(그립으로 편집).
- **TABLE**: 아직 만들지 않았습니다. 다음 명령은 만들어져 있습니다: {{cmd:XREF}}, {{cmd:SPLINE}}, {{cmd:WBLOCK}}.
- 루틴 고유의 명령(AutoLISP `C:NAME`)은 {{cmd:APPLOAD}}로 불러온 뒤에 나타나며, 이 목록에는 없습니다.
