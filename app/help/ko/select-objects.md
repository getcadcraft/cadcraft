## 배울 내용

명령이 작업할 객체를 고르는 방법입니다. CadCraft에는 두 가지 방식이 있으며 둘 다 괜찮습니다.

- **먼저 선택, 그다음 명령**(명사-동사). 객체를 선택한 뒤 `M`(이동)을 입력합니다. 명령은 선택을 받아 바로 다음 질문으로 넘어갑니다.
- **먼저 명령, 그다음 선택**(동사-명사). `M`을 입력하면 명령이 "객체 선택:"이라고 묻고, 객체를 고른 뒤 {{key:Enter}} 키를 누릅니다.

## 객체 하나씩 고르기

1. 명령이 실행 중이 아닐 때 선을 클릭합니다. 선이 강조되고 그립(작은 사각형)이 나타납니다. 오른쪽 패널에 속성이 표시됩니다.
2. 다른 객체를 클릭합니다. 선택에 추가됩니다.
3. {{key:Shift}} 키를 누른 채 선택된 객체를 클릭합니다. 선택에서 빠집니다.
4. {{key:Esc}} 키를 누릅니다. 아무것도 선택되지 않습니다.

## 윈도우와 걸침

빈 곳을 한 번 클릭하고 움직인 뒤 다시 클릭하면 사각형이 됩니다. 누른 채 끌면 대신 자유형 올가미가 그려지며, 같은 두 종류가 있습니다([올가미 선택](topic:lasso-selection) 참조. 설정에서 끌기로 사각형이 그려지도록 할 수도 있습니다). 어떤 객체가 선택되는지는 방향에 따라 달라집니다.

| 움직이는 방향 | 상자 | 선택 대상 |
|---|---|---|
| 왼쪽에서 오른쪽 | 윈도우 | 상자 안에 **완전히 들어간** 객체만 |
| 오른쪽에서 왼쪽 | 걸침 | 상자 안의 객체 **및** 상자와 닿은 객체 |

1. 겹치는 선과 원 몇 개를 그립니다.
2. 일부 객체의 왼쪽 빈 곳을 클릭하고 오른쪽으로 움직인 뒤 다시 클릭합니다. 완전히 안에 든 객체만 선택됩니다.
3. {{key:Esc}} 키를 누릅니다.
4. 오른쪽 빈 곳을 클릭하고, 일부 객체를 가로질러 왼쪽으로 움직인 뒤 다시 클릭합니다. 상자가 닿은 모든 것이 선택됩니다.
5. {{key:Shift}} 키를 누른 채 선택된 일부 객체 위에 상자나 올가미를 그립니다. 선택에서 빠집니다.

## 먼저 선택, 그다음 명령 실행

1. 원 두 개를 선택합니다.
2. `M`(이동)을 입력하고 {{key:Enter}} 키를 누릅니다.

기록에는 `2개 찾음`이 나오고, 프롬프트는 바로 `기준점 지정`으로 넘어갑니다. 이동을 마치십시오([객체 이동, 복사, 회전, 축척, 대칭](topic:modify-objects) 참조).

명령이 끝나면 선택이 해제되므로, 다음 명령은 새로 시작합니다.

이 방식으로 선택을 받는 명령은 {{cmd:ERASE}}, {{cmd:MOVE}}, {{cmd:COPY}}, {{cmd:ROTATE}}, {{cmd:SCALE}}, {{cmd:MIRROR}}, {{cmd:EXPLODE}}, {{cmd:BLOCK}} 및 {{cmd:LIST}}입니다. {{cmd:OFFSET}}, {{cmd:FILLET}}, {{cmd:CHAMFER}} 명령은 항상 객체를 하나씩 고르도록 합니다. {{cmd:TRIM}} 및 {{cmd:EXTEND}} 명령은 객체를 클릭하거나, 조각들을 지나가는 경로를 끌어서 고릅니다([자르기와 연장](topic:trim-and-extend) 참조).

## 명령 실행 후 선택

1. 아무것도 선택되어 있지 않도록 합니다({{key:Esc}} 키).
2. `E`를 입력하고 {{key:Enter}} 키를 누릅니다. 프롬프트는 "객체 선택:"이 됩니다.
3. 객체를 클릭하거나 윈도우와 걸침을 끕니다. 기록에는 고를 때마다 개수가 나옵니다(`1개 찾음`, `3개 찾음`).
4. {{key:Enter}} 키, {{key:Space}} 키 또는 마우스 오른쪽 버튼 클릭으로 선택을 마칩니다.

객체가 지워지고, 기록에 그 개수가 나옵니다.

"객체 선택:" 프롬프트에서는 다음을 입력할 수도 있습니다.

- `ALL`, 그다음 {{key:Enter}} 키: 열린 탭에서 편집할 수 있는 모든 객체.
- `L`(또는 `LAST`), 그다음 {{key:Enter}} 키: 가장 최근에 그린 객체.
- `P`(이전): 마지막 명령이 작업한 객체. 아직 있다면 선택합니다.
- `F`(울타리): 클릭하거나 선을 따라 점을 입력합니다. 선이 가로지르는 모든 객체가 추가됩니다. {{key:Enter}} 키를 눌러 울타리를 끝내고, `U`는 마지막 점을 되돌립니다.
- `W`(윈도우) 또는 `C`(걸침): 두 모서리. 끄는 방향과 관계없습니다.
- `R`(제거): 이제부터 클릭, 윈도우, 울타리가 객체를 **뺍니다**. 프롬프트는 "제거할 객체:"가 됩니다. `A`(추가)로 되돌립니다.
- `?`: 이 옵션들의 목록을 기록에 표시합니다.

AutoCAD에서와 같이, 이 옵션들은 프롬프트에 표시되지 않습니다.

## 겹친 객체 중 하나 고르기

객체가 겹치거나 닿으면 클릭은 가장 가까운 것을 고릅니다. 다른 것을 고르려면 다음과 같이 하십시오.

1. 포인터를 그 자리에 가만히 둡니다.
2. {{key:Tab}} 키를 누릅니다. 그곳의 다음 객체가 강조되고, 상태 표시줄에 어떤 것인지 나타납니다("3개 중 2: 도면층 Walls의 선").
3. 원하는 것이 강조될 때까지 {{key:Tab}} 키를 다시 누른 뒤, 움직이지 않은 채 클릭합니다.

포인터를 움직이면 처음부터 다시 시작합니다. 이것은 명령이 실행 중이 아닐 때, "객체 선택:" 프롬프트에서, 그리고 명령이 객체 하나를 고르도록 요구하는 모든 곳에서 작동합니다.

## 규칙으로 고르기: 빠른 선택

{{cmd:QSELECT}} 명령(`QS`, 또는 {{ui:Edit}} › {{ui:More}} › {{ui:Quick select}})은 규칙에 맞는 모든 객체를 선택합니다. 예를 들어 반지름이 50보다 작은 모든 원이나, DOOR-900이라는 이름의 모든 블록 참조를 고를 수 있습니다.

1. {{ui:Quick select}} 대화상자를 엽니다.
2. {{ui:Object type}} 목록에서 유형을 고릅니다(목록에 유형별 개수가 나옵니다). 그다음 {{ui:Property}} 목록에서 고릅니다. {{ui:Layer}}, {{ui:Color}}, 그리고 일부 유형의 경우 {{ui:Length}}, {{ui:Radius}}, {{ui:Area}}, {{ui:Text height}}, {{ui:Text contents}}, {{ui:Block name}} 또는 {{ui:Hatch pattern}}.
3. {{ui:Operator}} 및 {{ui:Value}} 항목을 고릅니다. `*`는 와일드카드로 맞춥니다(`DOOR-*`). {{ui:Select all}} 항목은 그 유형의 모든 객체를 고릅니다. 맨 아래의 개수는 고르는 동안 몇 개가 맞는지 보여줍니다.
4. {{ui:How to apply}}에서 맞는 객체를 포함할지, 그 밖의 모든 객체를 포함할지 정합니다. {{ui:Apply to}}에서 {{ui:Current selection}} 항목을 고르면 선택한 것을 좁히고, {{ui:Append to current selection}} 항목을 고르면 그 선택에 추가합니다.
5. {{ui:Select}} 단추를 클릭합니다. 그다음 원하는 명령을 실행하면 그 선택을 사용합니다.

## 유사 선택

객체를 하나 이상 선택하고 {{cmd:SELECTSIMILAR}}(`SIM`)을 입력하거나, {{ui:Edit}} › {{ui:More}} › {{ui:Select similar}} 항목을 고릅니다. 같은 유형, 같은 도면층, 같은 색상의 모든 객체가 선택됩니다. 블록 참조는 같은 블록을, 해치는 같은 패턴을 요구합니다. "객체 선택:" 프롬프트에서 `SE`를 입력하면 무엇이 일치해야 할지 고를 수 있습니다.

## 지금 선택하고 나중에 사용

`SELECT`를 입력하고 {{key:Enter}} 키를 누릅니다. 위의 방법 중 아무거나로 객체를 고른 뒤 {{key:Enter}} 키를 누릅니다. 객체는 다음 명령을 위해 선택된 채로 남고, 나중의 "객체 선택:" 프롬프트에서 `P`를 입력하면 다시 고릅니다.

## 모두 선택

아무 명령도 실행하지 않은 상태에서 {{key:Mod+A}}를 누르거나, 도구 모음의 {{ui:Edit}} › {{ui:More}} 메뉴에서 {{ui:Select all}}을 고르면, 열린 탭에서 편집할 수 있는 모든 객체가 선택됩니다. 명령행에 무언가 입력되어 있다면 {{key:Mod+A}}는 그 텍스트를 선택합니다. 먼저 {{key:Esc}} 키로 지우십시오. "객체 선택:" 프롬프트에서는 `ALL`을 입력합니다. 같은 메뉴의 {{ui:Select none}} 또는 {{key:Esc}} 키가 선택을 해제합니다.

:::tip
각 클릭이 선택을 대체하고 {{key:Shift}} 키가 추가하도록 하려면, [CadCraft 설정](topic:settings)에서 {{ui:Clicking objects}} 항목을 {{ui:Replaces the selection}}로 설정하십시오.
:::

## 선택할 수 없는 것

- **끄기, 동결 또는 잠금** 상태의 도면층에 있는 객체. 잠긴 객체는 계속 보이고 스냅도 할 수 있지만, 선택하거나 바꿀 수는 없습니다.
- 시트 탭에서는 뷰포트 안에 보이는 모델. 시트의 객체(표제란, 메모, 뷰포트 틀)를 선택합니다. 모델을 편집하려면 {{ui:Model}} 탭으로 가십시오.

## 빠르게 지우기

객체를 선택한 뒤 {{key:Delete}} 키를 누릅니다(명령행에 커서가 있지 않을 때는 {{key:Backspace}} 키). Mac 키보드에서는 도면을 클릭한 뒤 delete라고 적힌 키가 작동하며, 명령행에 커서가 있을 때는 fn과 delete를 함께 누릅니다. 이 키는 선택에 대해 {{cmd:ERASE}}를 실행합니다. 아무 일도 일어나지 않으면 명령행에 무언가 입력된 것이므로, {{key:Esc}} 키를 누르거나 `E`를 입력하고 {{key:Enter}} 키를 누르십시오.

## 자주 하는 실수

- **윈도우가 너무 적게 잡았습니다.** 왼쪽에서 오른쪽으로 끌었으므로 완전히 안에 든 것만 선택됩니다. 걸침을 하려면 오른쪽에서 왼쪽으로 끄십시오.
- **빈 곳 클릭이 상자를 시작했습니다.** 빈 곳을 한 번 클릭하면 윈도우가 시작되고, 두 번째 클릭이 완성합니다. {{key:Esc}} 키나 마우스 오른쪽 버튼으로 취소하십시오.
- **빈 곳 클릭이 선택을 해제했습니다.** {{key:Shift}} 키를 누르지 않는 한 그렇습니다. 이런 클릭에도 선택을 유지하고 {{key:Esc}} 키로만 지우려면, [CadCraft 설정](topic:settings#clicking-an-empty-spot)에서 {{ui:Clicking an empty spot}} 항목을 {{ui:Keeps the selection}}로 설정하십시오.
- **명령이 원치 않은 객체를 사용했습니다.** 명령을 시작할 때 무언가 아직 선택되어 있었습니다. 명령을 시작하기 전에 {{key:Esc}} 키를 눌러 아무것도 선택하지 않은 상태로 시작하십시오.
- **명령 뒤에 아무것도 선택되지 않았습니다.** 의도한 것입니다. 끝난 명령은 선택을 해제합니다.
