단축키는 사용 중인 컴퓨터를 기준으로 표시됩니다. Mac에서는 아래의 모든 {{key:Mod}} 단축키가 Command 키를 사용하며, Control 키도 작동합니다. 키 표기 방식과 Mac에서 F 키를 사용하는 방법은 [키, 마우스, 트랙패드](common:keys)를 참고하십시오.

## 명령 입력

| 키 | 기능 |
|---|---|
| 임의의 문자, 숫자 또는 기호 | 포인터 위치와 관계없이 명령행으로 입력됩니다. 단, 패널의 입력 상자에 커서가 있으면 그곳에 입력됩니다 |
| {{key:Enter}} | 입력한 내용을 전송합니다. 빈 프롬프트에서는 마지막 명령을 반복하거나, 명령을 끝내거나, 선택을 마치거나, `<…>` 안의 기본값을 적용합니다 |
| {{key:Space}} | {{key:Enter}}와 같습니다. 단, CadCraft가 문자(문자, 블록 이름, 치수 문자)를 요구할 때는 공백을 입력합니다 |
| {{key:Esc}} | 명령을 취소합니다. 실행 중인 명령이 없으면 그립 이동이나 선택 상자를 취소한 뒤 선택을 해제합니다 |
| {{key:Tab}} | 명령행 오른쪽에 표시된 추천 명령을 적용합니다. 아무것도 입력하지 않았고 포인터가 겹친 객체 위에 있으면 그 다음 객체를 강조합니다(클릭하여 선택) |
| {{key:Up}} {{key:Down}} | 이전에 입력한 줄(최근 100개)을 오가며 이동합니다 |

## 그리기와 편집

| 키 | 기능 |
|---|---|
| {{key:Mod+Z}} | 마지막 명령을 실행 취소합니다 |
| {{key:Mod+Y}} 또는 {{key:Mod+Shift+Z}} | 다시 실행 |
| {{key:Mod+A}} | 열린 탭에서 편집할 수 있는 모든 객체를 선택합니다({{cmd:SELECTALL}}). 명령행에 입력한 내용이 있으면 그 텍스트를 선택합니다 |
| {{key:Delete}} | 선택한 객체를 지웁니다({{cmd:ERASE}}). 명령행에 입력한 내용이 있으면 이 동작은 하지 않습니다 |
| {{key:Backspace}} | 명령행에 커서가 없으면 선택한 객체를 지웁니다. 명령행에 커서가 있으면 입력한 내용을 지웁니다 |
| {{key:Esc}} | 실행 중인 명령이 없으면 선택을 해제합니다({{cmd:DESELECT}}) |
| {{key:Mod+S}} | 도면의 형식(DWG 또는 DXF)으로 복사본을 저장합니다 |
| {{key:Mod+Shift+S}} | 다른 이름으로 저장: DWG 또는 DXF를 고른 뒤 복사본을 저장합니다 |
| {{key:Mod+O}} | DWG 또는 DXF를 엽니다 |
| {{key:Mod+P}} | PDF로 플롯합니다 |

명령이 실행 중이면 실행 취소, 다시 실행, 모두 선택, 플롯은 작동하지 않습니다. 먼저 {{key:Esc}} 키를 누르십시오.

## 복사, 잘라내기, 붙여넣기

| 키 | 기능 |
|---|---|
| {{key:Mod+C}} | 선택 항목을 클립보드에 복사합니다({{cmd:COPYCLIP}}). 선택한 것이 없으면 CadCraft가 객체를 요청합니다 |
| {{key:Mod+X}} | 잘라내기: 선택 항목을 복사한 뒤 지웁니다({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | 붙여넣기: 복사본이 포인터를 따라다닙니다. 클릭하거나 점을 입력하여 놓습니다({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | 제자리에 붙여넣기: 복사한 원래 좌표에 붙여넣습니다({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | 복제: 선택 항목의 복사본이 포인터를 따라 움직입니다. 클릭하여 놓으며, {{key:Esc}} 키를 누르면 아무것도 만들어지지 않습니다({{cmd:DUPLICATE}}) |

같은 동작이 도구 모음의 {{ui:편집}} 그룹({{ui:복사}}, {{ui:붙여넣기}})과 {{ui:더보기}} 메뉴에도 있습니다. 다른 명령이 실행 중이면 먼저 끝내거나 {{key:Esc}} 키를 누르십시오. 복사본이 커서를 따라다니는 동안 {{key:Mod+V}} 또는 {{key:Mod+D}}를 다시 누르면 처음부터 다시 시작합니다. 명령행에 입력한 내용이 있거나 명령이 텍스트를 요구하는 중이면, 이 키들은 그 텍스트를 복사, 잘라내기, 붙여넣기합니다. [복사, 붙여넣기, 복제](topic:copy-paste)를 참고하십시오.

## 전환

| 키 | 전환 | 상태 표시줄 버튼 |
|---|---|---|
| {{key:F3}} | 객체 스냅 켜기 또는 끄기 | {{ui:스냅}} |
| {{key:F7}} | 그리드 켜기 또는 끄기 | {{ui:그리드}} |
| {{key:F8}} | 직교 켜기 또는 끄기 | {{ui:직교}} |
| {{key:F10}} | 극좌표 추적 켜기 또는 끄기 | {{ui:극좌표}} |
| {{key:F11}} | 객체 스냅 추적 켜기 또는 끄기 | {{ui:추적}} |
| {{key:F12}} | 동적 입력 켜기 또는 끄기 | {{ui:동적}} |

:::mac
Mac에서 F3, F7, F8은 보통 Mission Control과 미디어 키 기능입니다. 이 키들을 **fn** 키와 함께 누르거나, [키, 마우스, 트랙패드](common:keys)에 설명된 대로 시스템 설정에서 표준 기능 키를 켜십시오. 상태 표시줄 버튼은 항상 작동합니다.
:::

:::firefox
Firefox에서 F7을 누르면 캐럿 브라우징을 켜겠느냐고 물을 수 있습니다. **아니요**를 선택하고, 계속 묻는다면 {{ui:그리드}} 버튼을 사용하십시오.
:::

## 도움말

| 키 | 기능 |
|---|---|
| {{key:F1}} | 작도 화면 옆에 이 도움말을 열거나 닫습니다. 명령이 실행 중에도 작동하며, 명령행으로 전달되지 않습니다. |
| {{key:Esc}} | 도움말 패널에 커서가 있을 때: 검색어를 지우거나 패널을 닫습니다 |

상단 막대의 {{ui:도움말}} 버튼은 {{key:F1}} 키와 같은 동작을 합니다. 도움말의 검색 상자에 입력하는 동안에는 키가 명령행으로 전달되지 않습니다. 도면을 클릭하면 키 입력이 CadCraft로 돌아가며, 패널은 도면 옆에 계속 열려 있습니다.

:::mac
Mac 키보드에서는 **fn** 키를 누른 채 {{key:F1}} 키를 누르거나, {{ui:도움말}}을 클릭하십시오.
:::

## 화면

| 키 | 기능 |
|---|---|
| {{key:Ctrl+Shift+F}} | 일반, 전체 화면, 막대를 숨긴 전체 화면을 차례로 전환합니다. 모든 컴퓨터(Mac 포함)에서 Control 키를 사용합니다. |
| {{key:Left}} {{key:Right}} | 도면 아래 탭에 포커스가 있을 때: 이전 또는 다음 탭 |

전체 화면에서는 브라우저가 처음 {{key:Esc}} 키를 전체 화면 종료에 사용할 수 있습니다. 명령을 취소하려면 {{key:Esc}} 키를 한 번 더 누르십시오.

## 대화상자

| 키 | 기능 |
|---|---|
| {{key:Esc}} | 대화상자를 닫습니다({{ui:PDF로 플롯}}, 또는 "저장되지 않은 변경 사항" 같은 질문에서는 {{ui:취소}}를 뜻합니다) |
| {{key:Tab}} | 대화상자의 설정과 버튼 사이를 이동합니다 |

대화상자가 열려 있는 동안에는 도면의 키 동작이 꺼집니다.

## 패널 입력란

오른쪽 또는 왼쪽 패널의 상자에서:

| 키 | 기능 |
|---|---|
| {{key:Enter}} | 값을 적용하고 상자를 떠납니다 |
| {{key:Esc}} | 이전 값으로 되돌리고 상자를 떠납니다 |
| {{key:Tab}} | 적용하고 다음 상자로 이동합니다 |

상자에 커서가 있으면 문자는 명령행이 아니라 그 상자에 입력됩니다.

## 마우스

| 동작 | 기능 |
|---|---|
| 클릭 | 명령이 점을 요구하면 점을 지정하고, 객체를 요구하면 객체를 지정합니다. 그 밖에는 객체 또는 그립을 선택합니다 |
| Shift+클릭 | 선택된 객체를 선택 집합에서 제외합니다([설정](topic:settings)에서 {{ui:객체 클릭 방식}}이 {{ui:선택을 대체}}로 설정된 경우에는 추가합니다). 점을 지정하는 중이면 그 클릭에 대해 객체 스냅을 무시합니다 |
| 빈 공간을 클릭한 뒤 다시 클릭 | 선택 상자입니다. 왼쪽에서 오른쪽으로 그으면 윈도우, 오른쪽에서 왼쪽으로 그으면 걸침입니다 |
| 빈 공간에서 드래그 | 올가미입니다. 오른쪽으로 먼저 움직이면 윈도우, 왼쪽으로 먼저 움직이면 걸침입니다. 드래그하는 동안 {{key:Space}} 키를 누르면 윈도우, 걸침, 울타리가 차례로 바뀝니다. {{key:Esc}} 키를 누르면 취소되며, LASSOMODE 0 또는 설정에서 다시 사각형 선택으로 바꿀 수 있습니다 |
| TRIM 또는 EXTEND에서 조각을 가로질러 드래그 | 경로가 지나는 모든 조각을 자르거나(연장합니다). 다른 쪽을 원하면 {{key:Shift}} 키를 누르십시오 |
| 그립 드래그 | 그립을 이동합니다(또는 그립을 클릭한 뒤 놓을 위치를 클릭합니다) |
| 문자를 두 번 클릭 | 문자를 선택하고, 오른쪽 패널의 {{ui:문자}} 상자에 커서를 놓습니다 |
| 오른쪽 클릭 | {{key:Enter}}와 같습니다. 그립 이동이나 선택 상자 중이면 이를 취소합니다 |
| 오른쪽 버튼 드래그 | 초점 이동 |
| 휠 | 십자선을 기준으로 확대/축소합니다 |
| 휠 드래그(가운데 버튼) | 초점 이동 |
| 휠 두 번 클릭 | 전체 도면(범위)으로 확대/축소합니다 |
| DWG 또는 DXF를 도면에 끌어 놓기 | 파일을 엽니다 |

트랙패드나 터치 스크린은 [마우스, 트랙패드, 터치](topic:mouse-trackpad-touch)를 참고하십시오.

## 브라우저가 가로채는 키

{{key:Mod+N}}, {{key:Mod+W}}, {{key:Mod+T}}는 항상 브라우저의 기능입니다. CadCraft는 이 키들을 사용하지 않으므로, 새 도면은 {{ui:새로 만들기}}를 사용하거나 `NEW`를 입력하십시오. CadCraft의 클립보드는 별도로 있습니다. {{key:Mod+C}}와 {{key:Mod+V}}는 CadCraft 도면과 탭 사이에서만 객체를 복사하며, 다른 프로그램과는 주고받지 않습니다.

:::mac
Mac에서 {{key:Mod+Y}}가 다시 실행 대신 브라우저의 방문 기록을 열면 {{key:Mod+Shift+Z}}를 사용하거나 {{ui:다시 실행}} 버튼을 사용하십시오.
:::

## MOVE의 위치

이동은 명령 `MOVE`(키 {{key:M}})입니다. 객체를 고른 다음 기준점과 두 번째 점 또는 입력한 거리를 지정합니다. `ALIGN`과 `DISTRIBUTE`도 있습니다. BimCraft도 같은 이름을 같은 용도로 쓰지만, BimCraft의 {{key:M}}은 측정이고 이동은 {{key:Shift+M}}입니다.
