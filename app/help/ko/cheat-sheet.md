약칭(별칭)을 입력하고 Enter를 누르거나 도구를 누릅니다. Esc는 취소입니다. 빈 줄에서 Enter를 누르면 마지막 명령을 반복합니다.

**인쇄:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (A4 한 장. Letter 용지에는 "페이지에 맞춤"으로 인쇄하십시오).

## 그리기

| 입력 | 명령 | 기능 |
|---|---|---|
| `L` | {{cmd:LINE}} | 직선을 그립니다 |
| `PL` | {{cmd:PLINE}} | 이어진 선과 호의 연속체를 그립니다 |
| `C` | {{cmd:CIRCLE}} | 원을 그립니다 (중심과 반지름) |
| `A` | {{cmd:ARC}} | 호를 그립니다 |
| `REC` | {{cmd:RECTANG}} | 두 모서리로 사각형을 그립니다 |
| `POL` | {{cmd:POLYGON}} | 정다각형을 그립니다 |
| `EL` | {{cmd:ELLIPSE}} | 타원을 그립니다 |
| `DT` | {{cmd:TEXT}} | 한 줄 문자를 씁니다 |
| `T` | {{cmd:MTEXT}} | 줄바꿈되는 문자(단락)를 씁니다 |
| `H` | {{cmd:HATCH}} | 영역을 패턴으로 채웁니다 |

## 수정

| 입력 | 명령 | 기능 |
|---|---|---|
| `M` | {{cmd:MOVE}} | 객체를 이동합니다 |
| `CO` | {{cmd:COPY}} | 객체를 복사합니다 |
| `RO` | {{cmd:ROTATE}} | 점을 중심으로 객체를 회전합니다 |
| `SC` | {{cmd:SCALE}} | 객체를 크게 또는 작게 합니다 |
| `MI` | {{cmd:MIRROR}} | 선을 기준으로 객체를 대칭시킵니다 |
| `O` | {{cmd:OFFSET}} | 일정 거리에 평행 복사본을 그립니다 |
| `TR` | {{cmd:TRIM}} | 다른 객체와 교차하는 지점까지 객체를 잘라 냅니다 |
| `EX` | {{cmd:EXTEND}} | 다른 객체까지 객체를 늘립니다 |
| `F` | {{cmd:FILLET}} | 모서리를 호로 둥글게 합니다 |
| `CHA` | {{cmd:CHAMFER}} | 모서리를 직선으로 잘라 냅니다 |
| `E` | {{cmd:ERASE}} | 객체를 삭제합니다 |
| `X` | {{cmd:EXPLODE}} | 블록이나 폴리선을 구성 요소로 분해합니다 |
| `S` | {{cmd:STRETCH}} | 걸침 윈도우 안의 끝점을 이동합니다 |
| `AR` | {{cmd:ARRAY}} | 격자나 원형으로 복사합니다 |
| `J` | {{cmd:JOIN}} | 선과 호를 하나의 객체로 결합합니다 |
| `BR` | {{cmd:BREAK}} | 객체를 둘로 자르거나 일부를 제거합니다 |

## 치수

| 입력 | 명령 | 기능 |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | 수평 또는 수직으로 치수를 기입합니다 |
| `DAL` | {{cmd:DIMALIGNED}} | 기울어진 선을 따라 치수를 기입합니다 |
| `DRA` | {{cmd:DIMRADIUS}} | 반지름 치수를 기입합니다 |
| `DAN` | {{cmd:DIMANGULAR}} | 각도 치수를 기입합니다 |

## 블록과 도면층

| 입력 | 명령 | 기능 |
|---|---|---|
| `B` | {{cmd:BLOCK}} | 객체로 블록을 만듭니다 |
| `I` | {{cmd:INSERT}} | 블록을 배치합니다 |
| `LA` | {{cmd:LAYER}} | 도면층을 엽니다 |

## 보기와 조회

| 입력 | 명령 | 기능 |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | 확대, 축소 또는 전체 보기 (E) |
| `DI` | {{cmd:DIST}} | 거리와 각도를 측정합니다 |
| `LI` | {{cmd:LIST}} | 객체의 상세 정보를 표시합니다 |
| `MA` | {{cmd:MATCHPROP}} | 한 객체의 모양을 다른 객체에 복사합니다 |

## 파일

| 입력 | 명령 | 기능 |
|---|---|---|
| `U` | {{cmd:UNDO}} | 마지막 명령을 취소합니다 |
| `SAVE` | {{cmd:SAVE}} | 도면을 저장합니다 |
| `PLOT` | {{cmd:PLOT}} | PDF로 플롯합니다 |

## 키

Ctrl (Mac에서는 Cmd): Z 실행 취소 · Y 다시 실행 · S 저장 · P 플롯.  F3 객체 스냅 · F8 직교 · F10 극좌표.  Space 또는 Enter는 마지막 명령 반복 · 휠은 확대/축소 · 휠을 끌면 초점 이동

제도가 처음이신가요? `TOUR`를 입력하면 안내에 따라 첫 도면을 그릴 수 있습니다. [시작하기](topic:getting-started)를 읽거나 [명령](topic:commands)에서 모든 명령을 확인하십시오. 다른 제도 소프트웨어를 쓰다 오신 분은 [다른 제도 소프트웨어에서 오신 경우](topic:coming-from)와 [명령 대응표](topic:command-map)를 참고하십시오.
