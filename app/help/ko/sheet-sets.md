## 배울 내용

여러 도면 파일의 시트(배치)를 모아 **시트 세트**를 만드는 방법입니다. 시트에 번호와 제목을 붙이고, 표제란을 자동으로 채우며, 세트 전체를 PDF 하나로 출력하고, 보낼 모든 것을 zip 하나로 묶습니다.

시트 세트는 도면이 든 폴더에 `<name>.ccsheets`라는 작은 파일로 저장됩니다. 세트 파일은 이 폴더를 기준으로 한 경로로 시트를 나열하므로, 폴더 전체를 옮기거나 복사할 수 있습니다.

:::note
폴더를 열어 읽고 쓰려면 Chrome 또는 Edge(사용자가 고른 폴더에서 페이지가 작업하도록 허용할 수 있습니다), 또는 데스크톱 앱이 필요합니다. 다른 브라우저에서는 세트를 읽기 전용으로 엽니다. 세트를 보고 출력할 수는 있지만, 세트 파일은 저장되지 않고 다운로드됩니다.
:::

## 세트 시작하기

1. 왼쪽 패널의 {{ui:Sheet set}} 구역을 찾아 {{ui:Set}} 메뉴를 엽니다. {{cmd:SHEETSET}}(또는 `SSM`)을 입력해도 그곳으로 갑니다.
2. {{ui:New set…}} 항목을 고릅니다. 세트 이름을 주고, 원하면 프로젝트 이름과 번호도 입력합니다.
3. 도면이 든 폴더를 고릅니다. 세트 파일이 그곳에 저장됩니다.

나중에 세트를 열려면 {{ui:Open set…}} 항목을 고르고 같은 폴더를 고릅니다. 폴더에 세트가 둘 이상 있으면 CadCraft가 어느 것인지 묻습니다.

## 시트 추가

1. {{ui:Add sheets from a drawing…}} 항목을 고르고, 폴더의 도면 하나를 고릅니다.
2. CadCraft는 그 도면을 백그라운드에서 읽고(화면에는 열지 않습니다) 시트 목록을 보여줍니다. 원하는 시트에 체크하고 {{ui:OK}} 단추를 클릭합니다.
3. 시트를 선택하고 {{key:F2}} 키를 누르거나({{ui:Rename and renumber…}} 항목을 고르거나), 번호와 제목을 줍니다. 예: `A-101`, `평면도`.

{{ui:New sheet from template…}} 항목은 다른 도면의 시트(표제란과 뷰포트)에서 새 도면을 만들고, 새 시트의 이름을 붙여 추가합니다. 세트는 템플릿으로 쓴 도면을 기억합니다.

## 세트 정리하기

- **하위 세트**는 시트를 묶습니다. 예: 건축 › 평면. 넣을 위치를 선택하고 {{ui:New subset…}} 항목을 고릅니다.
- **순서**: 시트를 끌어 목록의 다른 위치로 옮기거나, 하위 세트 위에 놓아 그곳으로 옮깁니다. 키보드로는 시트를 선택하고 {{key:Alt+Up}} 또는 {{key:Alt+Down}} 키를 누릅니다.
- **시트 열기**: 두 번 클릭하거나({{key:Enter}} 키) 누릅니다. 그 도면이 그 시트에 맞춰 자기 탭에서 열립니다.
- **제거**: 시트를 선택하고 {{key:Delete}} 키를 누릅니다. 도면 자체는 바뀌지 않습니다.
- **실행 취소**: {{ui:Undo set change}} 및 {{ui:Redo set change}} 단추는 세트에서 바꾼 것을 단계별로 되돌리거나 다시 합니다.
- **번호 다시 매기기**: {{ui:Renumber sheets…}} 항목은 모든 시트(또는 한 하위 세트의 시트)에 목록 순서대로 번호를 매깁니다. 접두어와 시작 값, 간격을 줍니다. 예: 접두어 `A-`, 시작 값 `101`이면 A-101, A-102 …

모든 변경 사항은 바로 세트 파일에 저장됩니다.

## 필드로 시트 번호 매기기

시트 번호를 손으로 매기는 대신, 규칙이 시트의 필드로 번호를 만들게 할 수 있습니다. 그러면 다른 층이나 공종으로 옮긴 시트가 저절로 새 번호를 받습니다.

1. 시트마다 필드를 주십시오. 시트를 선택하고 {{ui:Rename…}} 단추를 누른 뒤, {{ui:Fields of this sheet}}에 한 줄에 하나씩 씁니다. 예: `DISCIPLINE = A`와 `LEVEL = 1`. 세트 전체가 공유하는 필드(예: `DISCIPLINE = A`)는 대신 세트의 {{ui:특성…}}에 넣을 수 있습니다.
2. 패널의 메뉴를 열고 {{ui:Numbering rule…}} 항목을 클릭합니다.
3. 규칙을 씁니다. 예: `{DISCIPLINE}-{LEVEL}{SEQ:2}`. `{SEQ}`는 다른 필드 값이 같은 시트들 사이에서 번호를 셉니다. 그래서 층 1은 A-101, A-102를 받고, 층 2는 A-201부터 다시 시작합니다. `{SEQ:2}`는 두 자리 숫자로 씁니다. `{SUBSET}`은 시트가 든 하위 세트의 이름입니다.
4. 필드가 바뀔 때 일어날 일을 고릅니다. {{ui:Renumber the sheets}} 항목은 바뀔 때마다 번호를 규칙에 따라 유지합니다. 다른 선택지는 지금 한 번만 번호를 매깁니다.

규칙은 세트 파일에 저장됩니다. 규칙이 스스로 번호를 다시 매기는 동안에는 번호 대신 시트의 필드를 바꾸십시오.

## 필드로 표제란 채우기

표제란의 속성 태그를 필드 이름으로 붙이면, 세트에서 글자를 가져옵니다.

| 태그 | 표시 내용 |
|---|---|
| `SHEETNUMBER`(또는 `SHEET_NO`, `DWG_NO`) | 시트 번호 |
| `SHEETTITLE`(또는 `TITLE`, `SHEET_TITLE`) | 시트 제목 |
| `SHEETDESC` | 시트 설명 |
| `PROJECTNAME`(또는 `PROJECT`) | 프로젝트 이름 |
| `PROJECTNUMBER`(또는 `PROJECT_NO`, `JOB_NO`) | 프로젝트 번호 |
| `SHEETSETNAME` | 세트 이름 |
| `SHEETINDEX`, `SHEETCOUNT` | "12장 중 3", 그리고 12 |
| 직접 만든 것(예: `CLIENT`) | {{ui:Set fields…}}에 그 값으로 쓴 내용 |

{{ui:Set fields…}}에는 프로젝트 이름과 번호, 그리고 직접 만든 필드가 있습니다. 한 줄에 `NAME = value` 형식으로 하나씩 씁니다.

{{ui:Update drawings}} 단추는 세트의 모든 도면 표제란에 번호, 제목, 필드를 씁니다. 그리고 세트가 정한 대로 각 시트의 배치 탭 이름을 바꿉니다. 기본은 번호와 제목입니다(예: `A-101 평면도`). 이 방식은 {{ui:Set fields…}} › {{ui:Layout tab names}}에서 바꿀 수 있습니다. 각 도면은 자기 형식과 버전 그대로 제자리에 저장됩니다. 시트 번호나 이름을 다시 매기거나 바꾼 뒤에는 다시 실행하면 탭과 표제란이 따라갑니다.

## 표지 시트의 시트 목록

목록에서 표지 시트를 선택하고 {{ui:Put the sheet list on this sheet}} 항목을 고릅니다. 모든 시트의 표(번호와 제목, 하위 세트 아래)가 시트의 왼쪽 위 모서리에 들어갑니다. {{ui:Update drawings}}와 {{ui:Publish to PDF}} 단추가 이를 최신으로 유지합니다. 이것은 블록 `CC_SHEETLIST` 하나입니다. 다른 블록 참조처럼 옮기십시오.

## 세트 출력

{{ui:Publish to PDF}} 단추는 세트 순서대로 시트마다 한 페이지씩, 각 시트의 용지 크기로 PDF 하나를 만듭니다. 시트마다 책갈피가 달립니다("A-101 — 평면도"). 하위 세트를 선택하면 CadCraft가 그 하위 세트만 출력할지 묻습니다. PDF의 표제란은 도면을 업데이트하기 전에도 세트에서 채워집니다. 출력 자체는 도면을 바꾸지 않습니다. PDF는 다운로드됩니다.

{{ui:Publish to DWG…}} 단추는 시트마다 DWG 파일을 하나씩 씁니다(DWG 2018). 각 파일에는 모델과 그 시트 하나가 들어 있으며, 표제란은 세트에서 채워집니다. 파일 이름은 번호와 제목으로 붙습니다(예: `A-101 Level 1 floor plan.dwg`). {{ui:DWG}}를 고르거나, 세트의 PDF를 함께 두려면 {{ui:DWG + PDF}}를 고릅니다. `publish.json`은 모든 파일을 크기와 SHA-256과 함께 나열합니다. 세트 폴더에 쓸 수 있으면(CadCraft Studio, 또는 브라우저에서 고른 폴더) 파일은 `<세트 이름> - published` 폴더로 들어갑니다. 그렇지 않으면 zip 하나로 다운로드됩니다. 뷰포트 [클래스 재정의](topic:viewport-overrides)는 각 DWG에 함께 들어갑니다.

## 세트 보관

{{ui:Archive as a zip}} 단추는 세트 파일, 세트가 쓰는 모든 도면, 그 도면들이 연결한 것(연결된 도면과 그 도면이 연결한 것들, 그리고 그림)을 폴더 구조를 유지한 채 묶습니다. 모든 파일을 나열하는 `Transmittal.txt`도 함께 넣습니다. 세트 폴더 밖에 있는 링크는 여기에 누락된 것으로 표시됩니다. 링크는 도면에서 나온 경로로 찾고, 그다음 폴더 안 어디서든 파일 이름으로 찾습니다.

## 세트 파일

`.ccsheets` 파일은 아무 텍스트 편집기로나 읽을 수 있는 JSON입니다.

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

경로는 세트 폴더를 기준으로 하며, 폴더 구분자는 `/`입니다. CadCraft는 열 때 파일을 검사합니다. 절대 경로, 파일이나 배치가 없는 시트, 또는 일반 텍스트가 아닌 글자가 있으면 제외되며, 기록에 그렇게 알립니다.

## 문제 해결

| 보이는 것 | 원인 | 할 일 |
|---|---|---|
| "이 폴더는 여기서 읽기 전용입니다" | 브라우저가 이 폴더에 쓸 수 없습니다 | Chrome 또는 Edge, 또는 데스크톱 앱을 쓰십시오. 그 사이에도 {{ui:Download the set file}} 단추로 변경 사항을 보관할 수 있습니다 |
| 시트가 PDF에서 빠짐: "…배치가 없습니다" | 시트의 배치 이름이 바뀌었거나 그 도면에서 지워졌습니다 | 도면을 열어 탭을 확인하고, 시트를 제거한 뒤 다시 추가하십시오 |
| 표제란이 비어 있음 | 속성에 다른 태그가 붙어 있습니다 | 속성 태그를 위의 필드 이름으로 바꾸십시오(BEDIT) |
| "…배치가 이미 있어 그 탭의 이름을 바꾸지 않았습니다" | 한 도면의 두 시트가 같은 탭 이름을 받게 됩니다 | 둘 중 하나에 다른 번호나 제목을 주십시오 |
