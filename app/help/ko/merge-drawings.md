두 사람이 같은 도면을 편집합니다. 서로 다른 객체를 바꾸었다면 병합은 자동으로 이루어질 수 있으며, 손으로 다시 할 일은 없습니다.

## 작동 원리

CadCraft는 그리는 모든 객체에 바뀌지 않는 짧은 **키**를 줍니다. 같은 키가 두 객체에 주어지는 일은 없습니다. 키는 객체와 함께 DWG 또는 DXF 안에 저장되며(다른 프로그램이 보관하는 추가 데이터로), 병합은 파일 안의 위치가 아니라 이 키로 객체를 찾습니다. 모든 프로그램이 저장할 때 위치 번호를 다시 매기기 때문입니다. 병합을 전혀 하지 않는다면 {{ui:설정}} › CadCraft › 병합에 적합한 파일에서 끌 수 있습니다. 그러면 파일이 약 10% 작아집니다.

키가 생기기 전에 저장된 도면도 병합됩니다. 이 도면의 객체는 파일 안의 위치에서 키를 받으며, 이 도면을 여는 모든 사람에게 같은 키가 주어집니다.

## 설정 방법

Git에는 저장소마다 한 번 두 줄이 필요합니다.

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git 없이 직접 실행하려면 `cadcraft merge <base> <ours> <theirs> -o <result>`를 사용합니다. Fossil과 Mercurial은 같은 세 파일을 각자의 병합 도구 설정에서 사용합니다.

## 규칙

- 한쪽에서만 바뀐 객체는 그대로 반영됩니다. 양쪽에서 같은 변경을 했다면 한 번만 반영됩니다.
- 같은 속성이 두 가지 방식으로 바뀌면 **충돌**입니다. 내 쪽 값이 남고, 보고서에 두 값이 모두 나열됩니다. 결과 파일을 열고 해당 객체를 살펴본 뒤 직접 고치십시오.
- 어느 쪽에서든 추가된 객체는 유지됩니다. 한쪽에서 삭제되고 다른 쪽에서 건드리지 않은 객체는 삭제됩니다. 한쪽에서 삭제되고 다른 쪽에서 변경된 객체는 삭제되며 보고됩니다.
- 도면층, 블록, 문자 및 치수 스타일, 시트, 이름 있는 뷰도 같은 방식으로 병합됩니다. 구속조건은 가리키는 객체를 따라갑니다.
- 결과는 내 파일과 같은 파일 형식 및 버전으로 기록됩니다.

병합되지 않는 것: 객체가 그려지는 순서는 내 쪽의 것이며, 그다음에 상대가 추가한 객체가 옵니다. 양쪽에서 같은 블록 정의를 바꾸면 충돌이며, 섞이지 않습니다. 아무것도 업로드되지 않으며, 모든 과정은 컴퓨터에서 실행됩니다.
