## 만들 내용

6000 × 4500 크기의 L자형 방 윤곽선을 2000 × 1500 노치와 함께 정확히 그리고, 30도 벽도 하나 그립니다. 점을 입력하는 네 가지 방법을 모두 사용합니다. 단위는 밀리미터로 작업합니다. 도면 단위 하나는 1 mm입니다.

모든 형식의 빠른 참조는 [좌표 및 거리 입력](topic:coordinate-entry)에 있습니다.

## 시작하기 전에

1. CadCraft를 엽니다. 도면이 열려 있으면 먼저 {{ui:New}} 클릭.
2. {{key:Esc}} 키를 눌러 아무것도 선택하지 않은 상태로 만듭니다. 오른쪽 패널에 {{ui:Current settings}} 섹션이 표시됩니다.
3. {{ui:Units}} 설정: {{ui:Millimeters}}. 도면 크기는 바뀌지 않습니다. 이 설정은 시트와 출력에서 단위 하나가 무엇을 뜻하는지 알려 줄 뿐입니다.

## 절대 좌표: 첫 점

절대 좌표는 원점에서 잰 위치이며 `x,y` 형식으로 입력합니다.

1. `L` 입력 후 {{key:Enter}} 키를 누릅니다. 프롬프트: `첫 번째 점 지정:`
2. `0,0` 입력 후 {{key:Enter}} 키를 누릅니다.

이제 선이 원점에서 십자선까지 고무줄처럼 늘어납니다. 상태 표시줄의 좌표는 이동하는 동안 시작점까지의 거리와 각도를 보여 줍니다.

## 상대 좌표: @dx,dy

상대 좌표는 `@dx,dy` 형식으로 입력합니다. 마지막 점에서 가로로 얼마, 세로로 얼마 떨어진 곳인지 뜻합니다. 음수는 왼쪽 또는 아래쪽입니다.

3. `@6000,0` 입력 후 {{key:Enter}} 키를 누릅니다. 6000짜리 선이 오른쪽으로 그려집니다.
4. `@0,3000` 입력 후 {{key:Enter}} 키를 누릅니다.
5. `@-2000,0` 입력 후 {{key:Enter}} 키를 누릅니다.
6. `@0,1500` 입력 후 {{key:Enter}} 키를 누릅니다.

방의 오른쪽 변을 따라 올라가는 연결된 선 네 개가 보입니다.

## 직접 거리 입력: 숫자만 입력

숫자 하나만 입력하면 CadCraft는 십자선 방향으로 그 거리만큼 이동합니다. 방향을 가로 또는 세로로 맞추려면 직교를 켭니다.

7. {{key:F8}} 키를 누르거나 상태 표시줄의 {{ui:Ortho}} 버튼을 클릭합니다. 상태 표시줄에 "직교 켜짐"이 표시됩니다.
8. 마지막 점의 왼쪽으로 십자선을 옮깁니다. 고무줄 선이 수평을 유지합니다.
9. `4000` 입력 후 {{key:Enter}} 키를 누릅니다. 선이 왼쪽으로 4000만큼 그려집니다.
10. 마지막 점 아래로 십자선을 옮깁니다.
11. `4500` 입력 후 {{key:Enter}} 키를 누릅니다. 시작점으로 돌아옵니다.
12. 빈 프롬프트에서 {{key:Enter}} 키를 눌러 명령을 끝냅니다.

:::mac
Mac 키보드에서는 F8이 미디어 재생을 제어할 수 있습니다. **fn** 키를 누른 채 F8 키를 누르거나 {{ui:Ortho}} 버튼을 클릭하십시오. [키, 마우스, 트랙패드](common:keys)를 참조하십시오.
:::

이제 개별 선 여섯 개로 이루어진 닫힌 L자형 윤곽선이 있습니다.

13. {{ui:Extents}} 클릭해 전체를 확인합니다.

## 극좌표: @거리<각도

극좌표는 `@거리<각도` 형식으로 입력합니다. 각도는 도 단위이며, 양의 X 방향에서 반시계 방향으로 잽니다. 0은 오른쪽, 90은 위, 180은 왼쪽, 270(또는 -90)은 아래입니다.

14. `L` 입력 후 {{key:Enter}} 키를 누릅니다.
15. `6000,0` 입력 후 {{key:Enter}} 키를 눌러 오른쪽 아래 모서리에서 시작합니다.
16. `@2500<-30` 입력 후 {{key:Enter}} 키를 누릅니다. 모서리에서 2500짜리 선이 수평선보다 30도 아래로, 오른쪽 아래 방향으로 나갑니다.
17. {{key:Enter}} 키를 눌러 명령을 끝냅니다.

`@` 없이 입력한 극좌표(예: `2500<30`)는 마지막 점이 아니라 원점에서 측정됩니다.

## 같은 윤곽선을 폴리선 하나로

개별 선 여섯 개도 많은 작업에 충분하지만, 폴리선은 하나의 객체입니다. 간격 띄우기, 측정, 선택이 전체 단위로 이루어집니다. 같은 입력으로 {{cmd:PLINE}} 명령을 사용합니다.

1. `PL` 입력 후 {{key:Enter}} 키를 누릅니다.
2. `0,-6000` 입력 후 {{key:Enter}} 키를 눌러 첫 윤곽선 아래에서 시작합니다.
3. `@6000,0` 입력 후 {{key:Enter}} 키를 누릅니다.
4. `@0,3000` 입력 후 {{key:Enter}} 키를 누릅니다.
5. `@-2000,0` 입력 후 {{key:Enter}} 키를 누릅니다.
6. `@0,1500` 입력 후 {{key:Enter}} 키를 누릅니다.
7. `@-4000,0` 입력 후 {{key:Enter}} 키를 누릅니다.
8. `C` 입력 후 {{key:Enter}} 키를 누릅니다. 폴리선이 닫히고 명령이 끝납니다.
9. 새 윤곽선을 클릭합니다. 오른쪽 패널에 "폴리선" 항목, {{ui:Vertices}}, {{ui:Length}} 값이 표시되며, 닫혀 있으므로 {{ui:Area}} 값도 표시됩니다.

면적은 mm²로 24000000입니다. 이는 24 m²입니다.

## 그리는 중 옵션

- {{cmd:LINE}}과 {{cmd:PLINE}}에서 `U` 입력 후 {{key:Enter}} 키를 누르면 명령을 끝내지 않고 마지막 세그먼트를 취소합니다.
- {{cmd:LINE}}에서 `C`는 세그먼트가 두 개 이상이면 첫 점으로 닫습니다.
- {{cmd:PLINE}}에서 `A`는 호 세그먼트로 바꾸고(각 호는 앞 세그먼트에서 매끄럽게 이어집니다), `L`은 다시 선으로 바꿉니다. 호 모드에서 닫기 옵션은 `CL`입니다.
- {{cmd:LINE}}의 `첫 번째 점 지정:` 프롬프트에서 {{key:Enter}} 키를 누르면 마지막으로 준 점에서 시작하므로, 멈춘 곳에서 이어서 그릴 수 있습니다.

## 자주 하는 실수

- **`@`를 빼고 `6000,0` 입력.** `@`가 없으면 점은 마지막 점이 아니라 원점에서 측정되어 선이 엉뚱한 곳으로 나갑니다. CadCraft에서 `x,y`는 항상 절대 좌표입니다. `U` 입력 후 {{key:Enter}} 키를 눌러 취소합니다.
- **쉼표를 소수점으로 입력.** 소수점에는 마침표를 사용합니다: `1250.5`. 쉼표는 항상 X와 Y를 구분합니다.
- **직접 거리 방향이 틀림.** 숫자만 입력하면 십자선을 따라갑니다. {{key:Enter}} 키를 누르기 전에 원하는 쪽으로 십자선을 옮기고, 직선을 그리려면 {{ui:Ortho}} 기능을 켭니다.
- **`"점 또는 옵션 키워드가 필요합니다."`** CadCraft가 입력을 이해하지 못했습니다. 숫자 안의 공백이나 빠진 쉼표를 확인하고 다시 입력합니다.
- **피트와 인치.** CadCraft는 일반 숫자만 읽습니다. 인치 도면에서 12'-6"의 경우 `150`을, 피트 도면에서는 `12.5`를 입력합니다.
