CadCraft는 2D 제도 앱입니다. 선, 호, 폴리선, 문자, 치수, 블록을 그리고 편집하며, 표제란과 뷰포트가 있는 시트를 구성해 PDF로 플롯합니다. DWG와 DXF 도면을 열고 DWG나 DXF로 저장합니다.

웹 브라우저에서 실행됩니다. 설치할 것은 없습니다. 사이트에서 주소를 알려 주면 앱 전체가 페이지로 불러와집니다. 도면은 내 컴퓨터에서 열고 내 컴퓨터에 다시 저장합니다. **아무것도 업로드되지 않습니다.**

제도를 해 본 적이 있다면 이 페이지를 읽은 뒤 [다른 제도 소프트웨어에서 오신 경우](topic:coming-from)를 읽어 보십시오. 대부분의 습관이 그대로 통하며, 그렇지 않은 몇 가지는 거기에 정리되어 있습니다.

## 안내를 받고 싶으신가요?

`TOUR`를 입력하십시오 (또는 시작 카드의 {{ui:둘러보기 시작}}을 누르거나 {{ui:설정}} › {{ui:CadCraft}} › {{ui:둘러보기 다시 보기}}). 도면 위의 상자에서 짧은 단계 여섯 개를 진행합니다. 선과 원을 그리고, 옮기고, 자르고, 무언가를 지우고, 치수를 기입합니다. 각 단계는 직접 해 보면 끝나며, 단계 하나 또는 둘러보기 전체를 건너뛸 수 있습니다. 처음 한 번만 저절로 시작됩니다. [치트 시트](topic:cheat-sheet)에는 가장 많이 쓰는 명령 40개가, [명령 대응표](topic:command-map)에는 모든 명령이 있습니다.

## 필요한 것

- Mac, Windows 또는 Linux 컴퓨터의 최신 Chrome, Edge, Firefox 또는 Safari. [브라우저와 플랫폼](common:browsers)을 참고하십시오.
- 휠이 있는 마우스가 가장 편합니다. 트랙패드도 사용할 수 있습니다. [마우스, 트랙패드, 터치](topic:mouse-trackpad-touch)를 참고하십시오.
- 키보드. CadCraft는 대부분의 제도 프로그램처럼 입력한 명령으로 조작합니다.

## 한 단락으로 보는 원리

명령을 입력하면 (또는 버튼을 누르면) 아래쪽 명령행이 질문을 하나씩 합니다. "첫 번째 점 지정", "다음 점 지정" 같은 질문입니다. 도면을 클릭하거나 값을 입력한 다음 {{key:Enter}}를 눌러 각 질문에 답합니다. {{key:Esc}}를 누르면 취소됩니다. 이것이 조작 방식의 전부이며 나머지는 세부 사항입니다.

## 첫 도면

선으로 4000 x 3000 사각형을 그리고, 가운데에 원을 넣은 다음 파일을 저장합니다.

1. CadCraft를 엽니다. 아래쪽 명령행에 `Command:`가 표시되고 도면 영역에는 짧은 "도면 그리기 시작" 카드가 나타납니다.
2. `L`을 입력하고 {{key:Enter}}를 누릅니다. 명령행을 먼저 클릭할 필요는 없습니다. 어디서든 입력하면 그곳으로 들어갑니다.
3. 프롬프트가 `Specify first point:`로 바뀝니다. `0,0`을 입력하고 {{key:Enter}}를 누릅니다.
4. `@4000,0`을 입력하고 {{key:Enter}}를 누릅니다. 오른쪽으로 뻗은 선이 나타납니다. `@`는 "마지막 점에서"라는 뜻입니다.
5. `@0,3000`을 입력하고 {{key:Enter}}를 누릅니다.
6. `@-4000,0`을 입력하고 {{key:Enter}}를 누릅니다.
7. `C`를 입력하고 {{key:Enter}}를 누릅니다. `C`는 닫기 옵션으로, 마지막 선이 첫 점으로 돌아가고 명령이 끝납니다.
8. 도구 모음의 보기 그룹에서 {{ui:범위}}를 누릅니다. 사각형이 화면을 채웁니다.

이제 사각형을 이루는 선 네 개가 보이고, 명령행 위의 기록에 입력한 내용이 나열됩니다.

9. `C`를 입력하고 {{key:Enter}}를 눌러 원 명령을 시작합니다.
10. 중심으로 `2000,1500`을 입력하고 {{key:Enter}}를 누릅니다.
11. 반지름으로 `500`을 입력하고 {{key:Enter}}를 누릅니다.

사각형 가운데에 원이 나타납니다.

12. {{key:Mod+S}}를 누르거나 파일 그룹에서 {{ui:저장}}을 누릅니다.

브라우저가 `Drawing1.dwg`를 평소 다운로드 폴더로 내려받고, 기록에 DWG로 복사본을 저장했다고 표시됩니다. 그 파일은 CadCraft에서 다시 열 수 있고 대부분의 다른 CAD 프로그램에서도 열립니다. (이 브라우저에서 전에 {{ui:다른 이름으로 저장}}에서 DXF를 선택했다면 새 도면은 `Drawing1.dxf`로 저장됩니다.)

:::tip
빈 명령행에서 {{key:Enter}}를 누르면 마지막 명령을 반복합니다. 원한다면 {{key:Enter}} 대신 {{key:Space}}를 눌러도 됩니다. 문자 입력 중이 아니면 같은 동작입니다.
:::

## 기존 도면 열기

1. {{key:Mod+O}}를 누르거나 {{ui:열기}}를 누릅니다.
2. 파일 선택 창에서 `.dwg` 또는 `.dxf` 파일을 선택합니다.

{{pick:mac=Finder|windows=파일 탐색기|linux=파일 관리자}}에서 DWG나 DXF 파일을 끌어다 도면 영역에 놓아도 됩니다. 파일은 페이지 안에서 읽으며 컴퓨터를 벗어나지 않습니다.

유지되는 내용과 변환되는 내용은 [파일: 열 수 있는 것과 저장되는 것](topic:files)을 참고하십시오.

## 저장: 알아 둘 점

브라우저에서의 저장은 데스크톱 프로그램과 다르게 작동합니다.

- {{ui:저장}}은 항상 **새 사본을 다운로드**합니다. 연 파일을 덮어쓰지 않습니다. 같은 이름의 파일이 이미 다운로드 폴더에 있으면 브라우저가 보통 `Drawing1 (1).dwg`처럼 번호를 붙입니다.
- {{ui:저장}}은 도면의 형식을 사용합니다. DWG를 열었으면 DWG, DXF를 열었으면 DXF입니다. 직접 고르려면 {{key:Mod+Shift+S}}를 누르거나 {{ui:다른 이름으로 저장}}을 누른 다음 {{ui:DWG}} (와 버전), {{ui:DXF R12}} 또는 {{ui:DXF 2000}}을 선택합니다. [저장](topic:files#saving)을 참고하십시오.
- 연 파일은 변경되지 않습니다.
- 다른 파일을 열거나 {{ui:새로 만들기}}를 하면 도면 위에 자체 탭으로 열리므로 열려 있는 것은 닫히지 않습니다. 저장하지 않은 변경 사항이 있는 채로 도면 탭을 닫거나 페이지를 벗어나면 CadCraft가 먼저 묻습니다. {{ui:먼저 복사본 저장}}, 버리기, {{ui:취소}} 중에서 선택합니다. 브라우저 탭을 닫을 때는 대신 브라우저 자체의 "사이트를 나가시겠습니까?" 질문이 표시됩니다.

클라우드 저장은 아직 지원하지 않습니다. 파일이 어디로 가는지와 비공개로 유지되는 이유는 [내 파일과 개인정보](common:your-files)에 설명되어 있습니다.

## 다음으로 볼 곳

{{key:F1}}을 누르거나 상단 바의 {{ui:도움말}}을 누르면 언제든 도면 옆에서 이 도움말을 열 수 있습니다. 연결 없이도 작동합니다.

- [CadCraft 화면](topic:workspace)에서 모든 바와 패널의 이름을 확인할 수 있습니다.
- [좌표로 그리기](topic:draw-with-coordinates)가 가장 좋은 첫 실습입니다.
- [키보드와 마우스](topic:keyboard)에 모든 키가 나와 있습니다.
- 명령행에 `HELP`를 입력하면 모든 명령 목록이 나오며, [명령 참조](topic:commands)를 읽어도 됩니다.
