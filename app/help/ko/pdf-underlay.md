## PDF 페이지를 가져오는 두 가지 방법

- **첨부** ({{cmd:PDFATTACH}})는 PDF를 도면 아래에 그림으로 유지합니다. 페이지를 추적하고, 그 선에 스냅하고, 흐리게 하고, 클립할 수 있으며, 시트와 함께 인쇄됩니다. 도면에는 파일 이름만 남습니다.
- **가져오기** ({{cmd:PDFIMPORT}})는 페이지의 선, 곡선, 채우기와 문자를 PDF 이름을 딴 도면층의 일반 도면 객체로 바꿉니다. 이후 자유롭게 편집할 수 있으며 PDF는 더 이상 필요하지 않습니다.

{{ui:Open}} 명령으로 PDF를 열면 두 방법 중 어느 쪽을 쓸지 묻습니다.

## 페이지 첨부

1. 명령 `PDFATTACH` 입력 (또는 `PDFATT`), PDF 선택. 페이지가 여러 개이면 페이지 번호를 입력합니다.
2. 삽입점(페이지의 왼쪽 아래 모서리)을 클릭합니다.
3. {{key:Enter}} 키를 눌러 페이지의 실제 크기로 두거나, 축척을 입력합니다: PDF 포인트당 도면 단위(1포인트는 1/72인치이므로 밀리미터 도면에서는 0.3528).
4. 회전이 없으면 {{key:Enter}} 키를 누르고, 각도를 입력할 수도 있습니다.

페이지는 블록 참조와 같은 객체입니다. 이동, 회전, 축척 조정, 복사, 지우기, 도면층 배정이 가능합니다. 도면층을 끄면 페이지가 사라지며, 확대하면 페이지가 다시 그려져 선명하게 보입니다.

## 추적하기

{{ui:Snap}} 켜기 상태에서 커서는 PDF 자체 선의 끝점, 중간점, 교차점에 스냅됩니다({{ui:Nearest}} 스냅이 켜져 있으면 가장 가까운 점도 포함). 페이지에 문자로 그려진 텍스트에는 스냅되지 않습니다.

## 조정하기

- `PDFADJUST`: **흐리기** (0~80%), **대비** (0~100), **단색**, 그리고 **켜기/끄기**를 사용하면 지우지 않고 숨길 수 있습니다.
- `PDFCLIP`: 페이지의 사각형 또는 다각형 영역만 표시합니다. **삭제**는 클립을 제거합니다.
- `PDFLAYERS`: PDF에는 자체 도면층이 있을 수 있습니다. 이 명령은 도면층을 나열하며, 번호를 입력하면 이 언더레이에 대해 해당 도면층을 켜거나 끕니다. 파일에서 꺼진 도면층은 처음부터 꺼져 있습니다.

## 플롯과 저장

PLOT 명령은 페이지를 선, 채우기, 문자로 인쇄합니다(선명하고 검색 가능한 상태가 유지됨). PDF 안의 그림은 화면에 표시되지만 아직 인쇄되지 않습니다.

DWG 또는 DXF 2000은 언더레이를 링크로 보관합니다: 파일 이름, 페이지, 위치, 축척, 회전, 클립, 흐리기와 대비. PDF 파일 자체는 도면에 들어 있지 않습니다. 도면을 다시 열고 명령 `PDF`를 입력한 뒤 파일을 다시 선택합니다. 그렇게 하기 전까지 페이지는 틀로 표시되며, 다시 선택하면 실제 크기를 얻습니다. 이전 DXF(R12)에는 언더레이가 없으므로 틀과 이름만 보관합니다. 다른 프로그램이 저장된 클립과 축척을 어떻게 읽는지는 아직 확인되지 않았습니다.

## PDF 페이지 가져오기

1. 명령 `PDFIMPORT`(또는 `PDFIM`) 입력, PDF와 페이지 선택.
2. 페이지의 왼쪽 아래 모서리가 놓일 위치를 클릭합니다.
3. {{key:Enter}} 키로 실제 크기를 쓰거나, 축척을 입력하거나, **두 점**을 선택합니다. 두 점을 고르면 페이지가 실제 크기로 그려지고, 알고 있는 거리의 두 점을 클릭한 뒤 실제 거리를 입력합니다. 그러면 모든 것이 일치하도록 축척됩니다.

선은 선과 폴리선으로 바뀌고, 원과 호는 인식되며, 채워진 도형은 솔리드 해치가 됩니다. 문자는 `-TEXT`로 끝나는 도면층의 문자가 됩니다. 이 작업은 실행 취소 한 단계입니다. PDF 안의 그림은 가져오지 않으므로, 대신 페이지를 첨부하십시오. 스캔(그림으로만 이루어진 페이지)에는 가져올 선이 없습니다.

PDF는 신뢰하지 않는 파일로 읽습니다. 스크립트는 실행되지 않으며, 지나치게 큰 페이지는 잘리고 그 사실을 알려 줍니다.
