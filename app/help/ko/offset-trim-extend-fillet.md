## 만들 결과

벽 두께 200인 작은 방을 만듭니다. 안쪽 면을 그리고, 바깥쪽 면을 간격 띄우기하고, 모서리를 정리하며, 한쪽 벽에 출입구를 자릅니다.

## 안쪽 면 그리기

1. `L` 입력 후 {{key:Enter}} 키를 누릅니다.
2. `0,0` 입력 후 {{key:Enter}} 키를 누릅니다.
3. `@5000,0` 입력 후 {{key:Enter}} 키를 누릅니다.
4. `@0,4000` 입력 후 {{key:Enter}} 키를 누릅니다.
5. `@-5000,0` 입력 후 {{key:Enter}} 키를 누릅니다.
6. `C` 입력 후 {{key:Enter}} 키를 누릅니다.
7. {{ui:Extents}}를 클릭합니다.

별개의 선 네 개가 생깁니다. (닫힌 폴리선이라면 한 번에 간격 띄우기되지만, 별개의 선은 모깎기가 모서리를 정리하는 방식을 보여 줍니다.)

## 바깥쪽 면 간격 띄우기

1. `O` 입력 후 {{key:Enter}} 키를 누릅니다. 프롬프트는 `Specify offset distance [Through] <Through>:`입니다.
2. `200` 입력 후 {{key:Enter}} 키를 누릅니다.
3. `Select object to offset` 프롬프트에서 아래쪽 선을 클릭합니다.
4. `Specify point on side to offset` 프롬프트에서 선 아래 아무 곳이나 클릭합니다. 200 아래에 평행선이 나타납니다.
5. 오른쪽 선을 클릭한 다음, 그 오른쪽을 클릭합니다.
6. 위쪽 선을 클릭한 다음, 그 위를 클릭합니다.
7. 왼쪽 선을 클릭한 다음, 그 왼쪽을 클릭합니다.
8. {{key:Enter}} 키를 눌러 명령을 끝냅니다.

바깥쪽 선 네 개가 보여야 하며, 각 선은 대응하는 안쪽 선과 길이가 같으므로 바깥쪽 모서리는 만나지 않습니다.

:::tip
거리 프롬프트에서 {{key:Enter}} 키를 누르면 마지막 거리를 다시 씁니다. `T` 입력 시 Through 방식이 되어, 각 복사본은 클릭한 점을 지나며 그 거리는 그때그때 정해집니다.
:::

{{cmd:OFFSET}}은 선, 호, 원, 폴리선에서 작동합니다. 닫힌 폴리선을 간격 띄우기하면 모서리를 포함한 전체 윤곽이 간격 띄우기됩니다.

## 모깎기로 바깥 모서리 정리

{{cmd:FILLET}}은 모서리에서 두 선을 잇습니다. 두 선을 자르거나 연장하여 만나게 합니다. 반지름이 0이면 모서리는 직각입니다.

1. `F` 입력 후 {{key:Enter}} 키를 누릅니다. 프롬프트는 `Select first line [Radius]:`입니다.
2. 마지막 모깎기에서 반지름을 썼다면 `R` 입력 후 {{key:Enter}} 키를 누르고, `0` 입력 후 {{key:Enter}} 키를 누릅니다.
3. 바깥쪽 아래 선의 오른쪽 끝 근처를 클릭합니다.
4. `Select second line` 프롬프트에서 바깥쪽 오른쪽 선의 아래쪽 끝 근처를 클릭합니다.

두 선이 날카로운 모서리에서 만나며 명령이 끝납니다.

5. {{key:Enter}} 키를 눌러 {{cmd:FILLET}} 명령을 반복하고 다음 모서리를 처리합니다.
6. 바깥쪽 모서리 네 개가 모두 만날 때까지 반복합니다.

유지하려는 부분에서 각 선을 클릭하십시오. 반지름이 0보다 크면 모깎기는 선 사이에 호를 추가합니다.

:::tip
첫 프롬프트에서 `M` 입력 시 네 모서리를 한 번에 처리합니다. 또는 바깥 면을 하나의 닫힌 폴리선으로 그린 뒤 `P` 입력하십시오. 모든 모서리가 한 번에 처리됩니다. 반지름을 바꾸지 않고 날카로운 모서리를 원하면, 두 번째 선을 클릭할 때 {{key:Shift}} 키를 누르고 있으십시오.
:::

## 모따기로 모서리 베벨 처리

{{cmd:CHAMFER}}는 직선으로 모서리를 잘라 냅니다.

1. `CHA` 입력 후 {{key:Enter}} 키를 누릅니다.
2. `D` 입력 후 {{key:Enter}} 키를 누릅니다. 첫 번째 거리로 `300` 입력 후 {{key:Enter}} 키를 누르고, 두 번째에도 300을 쓰려면 {{key:Enter}} 키를 한 번 더 누릅니다.
3. 안쪽 위 선의 왼쪽 끝 근처를 클릭한 다음, 안쪽 왼쪽 선의 위쪽 끝 근처를 클릭합니다.

모서리는 각 선을 따라 300씩 잘려 나가고, 베벨 선이 둘을 잇습니다. `D` 대신 `A` 입력 시 첫 번째 선의 길이와 각도를 줄 수 있습니다.

## 자르기로 출입구 만들기

먼저 아래 벽을 가로지르는 두 개의 문설주를 그린 다음, 그 사이의 벽선을 자릅니다.

1. `L` 입력 후 {{key:Enter}} 키를 누릅니다.
2. `1000,200` 입력 후 {{key:Enter}} 키를 누릅니다.
3. `@0,-600` 입력 후 {{key:Enter}} 키를 누르고, 다시 {{key:Enter}} 키를 누릅니다.
4. {{key:Enter}} 키를 눌러 {{cmd:LINE}} 명령을 반복합니다.
5. `1900,200` 입력 후 {{key:Enter}} 키를 누릅니다.
6. `@0,-600` 입력 후 {{key:Enter}} 키를 누르고, 다시 {{key:Enter}} 키를 누릅니다.

이제 900 떨어져 아래 벽을 가로지르는 짧은 선 두 개가 있습니다.

7. `TR` 입력 후 {{key:Enter}} 키를 누릅니다. 기록에 `Current settings: Quick mode, edges: No extend`가 표시됩니다.
8. 두 문설주 사이의 안쪽 아래 선을 클릭합니다. 그 조각이 사라집니다. (먼저 포인터를 그 위에 올려 두십시오. 제거될 조각은 회색 점선으로 바뀝니다.)
9. 두 문설주 사이의 바깥쪽 아래 선을 클릭합니다. 그 조각도 사라집니다.
10. 각 문설주에서 벽 위로 튀어나온 부분과 아래 부분을 클릭합니다.
11. {{key:Enter}} 키를 눌러 명령을 끝냅니다.

아래 벽에 900 크기의 열린 부분이 보이며, 문설주가 벽의 끝을 막고 있어야 합니다.

빠른 모드(기본값)에서는 자르기가 절단 가장자리를 먼저 고르라고 묻지 않습니다. 보이는 모든 객체가 절단 가장자리입니다. 없애고 싶은 조각을 고르거나, 경로를 드래그해 여러 조각을 한 번에 자르십시오. `U` 입력 후 {{key:Enter}} 키를 누르면 명령을 벗어나지 않고 마지막 선택이나 드래그를 되돌립니다. 울타리, 걸침, 지정한 가장자리, 그리고 {{key:Shift}} 키로 연장하는 방법은 [자르기와 연장](topic:trim-and-extend)에서 다룹니다.

## 선을 다른 선까지 연장

{{cmd:EXTEND}}는 선, 호 또는 폴리선의 끝을 그 방향의 다음 객체에 닿을 때까지 늘입니다.

1. `L` 입력 후 {{key:Enter}} 키를 누릅니다.
2. `1000,2000` 입력 후 {{key:Enter}} 키를 누릅니다.
3. `@2000,0` 입력 후 {{key:Enter}} 키를 누르고, 다시 {{key:Enter}} 키를 누릅니다. 선은 오른쪽 벽에서 2000 짧게 멈춥니다.
4. `EX` 입력 후 {{key:Enter}} 키를 누릅니다.
5. 새 선의 오른쪽 끝 근처를 클릭합니다.
6. {{key:Enter}} 키를 눌러 명령을 끝냅니다.

이제 선은 오른쪽 벽의 안쪽 면까지 이어집니다. 보이는 모든 객체가 경계가 됩니다. 늘어나야 할 끝에 가까운 곳을 고르십시오. {{cmd:TRIM}} 안에서는 {{key:Shift}} 키를 누른 채 클릭하면 같은 동작을 합니다.

## 끊기와 길이 조정

{{cmd:BREAK}}(`BR`, 또는 {{ui:Modify}} › {{ui:More}} › {{ui:Break}})는 절단 가장자리 없이 틈을 만듭니다. 틈이 시작할 곳의 객체를 클릭하고(그 클릭이 첫 점입니다), 끝날 곳을 클릭합니다. 원에서는 첫 점에서 두 번째 점까지 반시계 방향인 부분이 제거됩니다. 두 번째 질문에서 `F` 입력 시 첫 점을 다시 줄 수 있습니다. {{cmd:BREAKATPOINT}} 명령은 틈 없이 한 점에서 객체를 둘로 나눕니다.

{{cmd:LENGTHEN}}(`LEN`)은 한쪽 끝의 길이를 바꿉니다.

1. `LEN` 입력 후 {{key:Enter}} 키를 누릅니다. 선을 클릭하면 현재 길이가 표시되고, 프롬프트가 다시 묻습니다.
2. 방식을 고르십시오. `DE`(Delta: 더할 양, 빼려면 음수, 호에서는 `A`로 각도를 지정), `P`(Percent: 50이면 절반), `T`(Total: 원하는 길이), 또는 `DY`(Dynamic: 끝을 끌기).
3. 바꿀 끝 근처에서 객체를 하나씩 클릭합니다. `U`는 마지막 선택을 되돌리고, {{key:Enter}} 키는 끝냅니다.

선, 호, 열린 폴리선(끝 세그먼트)의 길이를 늘일 수 있습니다.

## 흔한 실수

- **선 전체가 사라졌습니다.** 그것을 가로지르는 것이 없어 빠른 모드가 지웠습니다. `U` 입력 후 되돌리십시오. 자르는 선이 실제로 그것을 가로지르는지(확대하여 확인), 그리고 꺼진 도면층에 있지 않은지 확인하십시오.
- **"해당 방향에 경계가 없습니다."** 연장이 부딪힐 것을 찾지 못했습니다. 늘어나야 할 끝에 더 가까운 곳을 고르십시오.
- **"반지름이 너무 큽니다."** 호가 선 중 하나의 끝을 넘어갑니다. 더 작은 반지름을 쓰십시오.
- **"열린 폴리선의 첫 번째 또는 마지막 세그먼트만 잘라 낼 수 있습니다."** 서로 인접한 폴리선의 두 세그먼트를 고르거나, `P` 입력으로 모든 모서리를 둥글게 하십시오.
- **간격 띄우기가 반대쪽으로 갔습니다.** 객체를 고른 뒤 클릭하는 곳이 쪽을 정합니다. {{key:Mod+Z}} 키로 실행 취소하고 반대쪽을 클릭하십시오.
- **"그만큼 간격 띄우기할 수 없습니다."** 간격 띄우기가 호, 원, 폴리선을 안팎으로 뒤집어 버립니다. 더 작은 거리를 쓰십시오.
