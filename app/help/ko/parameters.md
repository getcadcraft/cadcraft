## 모든 치수를 위한 하나의 표

{{ui:Parameters}} 패널({{ui:Parametric}} 그룹의 {{ui:Parameters}} 버튼, 또는 {{cmd:PARAMETERS}} 명령 입력)은 모든 치수 구속(`d1`, `rad1`, `dia1`, `ang1`, 또는 직접 붙인 이름)과 여러분의 매개변수를 함께 나열합니다. 어떤 식에서든 어떤 이름이든 쓸 수 있습니다.

각 행에는 다음이 있습니다.

- **이름**: 새 이름을 입력하면 바뀌며, 그 이름을 쓰는 모든 식이 따라갑니다.
- **식**: 숫자(`40`) 또는 식(`width / 2 + gap`). 입력하고 {{key:Enter}} 키를 누르면 도면이 따라갑니다.
- **값**: 식의 계산 결과입니다. 식이 구동하는 행에서는 여기에 숫자를 입력할 수도 있습니다. CadCraft가 그 뒤의 매개변수를 계산합니다. `d1 = width / 2`일 때 d1의 값에 `30`을 입력하면 `width` 값이 60이 됩니다.

두 매개변수가 값 하나를 구동하면(`width / 2 + gap`), 어느 것을 바꿀지 대화 상자가 묻습니다. 모든 변경은 실행 취소 한 단계입니다({{key:Mod+Z}}).

## 나만의 매개변수 추가

1. {{ui:Parameters}} 패널을 엽니다.
2. 이름(`gap`)과 값(`10`)을 입력한 다음 {{ui:Add}}(추가)를 선택합니다.
3. 사용합니다. d1의 식에 `width / 2 + gap` 입력 후 {{key:Enter}} 키를 누릅니다.

이름은 문자 또는 `_`로 시작하고, 문자, 숫자, `_`로 구성됩니다. 함수 이름, `pi`, 단위 이름은 이름으로 쓸 수 없습니다.

## 식

| 입력 | 의미 |
|---|---|
| `+ - * / ^ %` | 더하기, 빼기, 곱하기, 나누기, 거듭제곱, 나머지 |
| `( )` | 묶기 |
| `sin cos tan asin acos atan atan2` | 도 단위의 삼각 함수 |
| `sqrt pow exp ln log abs sign` | 제곱근, 거듭제곱, 로그, 절댓값, 부호 |
| `ceil floor int round min max` | 반올림과 한계 |
| `if(a > b, x, y)` | 선택 |
| `pi` | 3.14159… |

숫자에는 단위를 붙일 수 있습니다: `25mm`, `1in`, `2'`, `90deg`. 단위가 있는 길이는 밀리미터로 바뀌므로, 밀리미터로 측정된 도면에서만 단위를 쓰고, 그 밖에서는 평범한 숫자를 입력하십시오.

## 명령행에서

`-PARAMETERS`는 패널 없이 같은 일을 합니다. `N` 새로 만들기, `E` 편집(치수 구속 포함), `R` 이름 바꾸기, `D` 삭제, `?` 목록.

## 거부되는 것

- 자기 자신을 직접 또는 다른 것을 거쳐 쓰는 식: "width, d1이 서로를 사용합니다."
- 치수가 가질 수 없는 값: 음수 길이, 180°를 넘는 각도.
- 다른 구속과 함께라면 도면이 가질 수 없는 값: 아무것도 바뀌지 않으며, 메시지가 방해되는 구속을 알려 줍니다.
- 사용 중인 매개변수의 삭제: 패널이 먼저 그 값을 그것들에 써 넣을지 제안합니다. 치수 구속의 이름은 구속을 삭제하면 함께 지워집니다.
