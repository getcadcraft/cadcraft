## 속성이란

속성은 블록 참조와 함께 이동하는 이름 있는 값입니다. 예를 들어 장비 태그의 품목 번호, 방 태그의 이름, 문의 방화 등급 같은 것입니다. 블록의 정의에는 그 블록이 가진 속성이 적혀 있습니다(각 속성은 **태그**, **프롬프트**, **기본값**과 문자의 위치, 크기, 각도를 가집니다). 블록을 참조할 때마다 고유한 값을 가집니다.

일부 속성은 **보이지 않음**입니다. 제조사나 모델 번호 같은 데이터를 담지만 그려지지 않습니다. 일부 속성은 **상수**입니다. 모든 참조에서 같은 값이며 블록에서 고정됩니다.

## 속성의 출처

- 열어 본 DWG와 DXF 파일의 블록은 각 참조의 값과 함께 속성을 유지합니다.
- {{cmd:INSERT}}와 {{ui:파일}} 옵션으로 가져온 블록도 속성을 유지합니다. [파일 또는 라이브러리에서 삽입](topic:insert-from-file-and-library)을 참고하세요.
- 라이브러리 항목은 속성이 있는 블록으로 들어옵니다. 보이는 품목 번호와 보이지 않는 항목 데이터가 있습니다.

- 직접 만든 블록: 먼저 {{cmd:ATTDEF}}로 속성을 정의합니다(아래 참조). 그런 다음 블록을 만들 때 다른 객체와 함께 선택합니다.

## 자체 블록의 속성 정의

1. 블록의 선을 그립니다. 예를 들어 방 태그입니다.
2. {{ui:블록}} › {{ui:더보기}} › {{ui:속성 정의}}를 선택하거나, `ATT`를 입력하고 {{key:Enter}}를 누릅니다.
3. 기록에 모드가 표시됩니다(`Invisible=No Constant=No Preset=No`). `I`, `C`, `P`를 입력하면 각각을 전환하며, 맞으면 {{key:Enter}}를 누릅니다. 보이지 않는 값은 유지되지만 그려지지 않습니다. 상수 값은 모든 참조에서 같습니다. 사전 설정 값은 블록을 삽입할 때 묻지 않습니다.
4. 태그(예: `ROOM_NO`: 대문자, 공백 없음), 프롬프트(`Room number`), 기본값(`101`)을 입력합니다.
5. 값이 들어갈 위치를 클릭하고 높이와 회전을 지정합니다. 태그가 도면에 표시됩니다.
6. {{cmd:BLOCK}}으로 블록을 만듭니다. 선과 속성 정의를 함께 선택합니다. 블록을 대신하는 참조는 기본값을 받으며, 새 {{cmd:INSERT}}마다 값을 묻습니다.

선택한 속성 정의는 {{ui:속성}}에 {{ui:태그}}, {{ui:프롬프트}}, {{ui:기본값}}과 모드를 표시합니다.

## 블록 변경: 블록 편집기

{{ui:블록}} › {{ui:더보기}} › {{ui:블록 편집}}({{cmd:BEDIT}}, `BE`)은 블록을 단독으로 엽니다. 이름을 입력하거나(먼저 참조를 선택할 수도 있습니다). 상단 막대에 편집 중인 블록이 표시됩니다. 일반 명령으로 객체를 그리고 지우고 바꾸며, 속성 정의를 추가하거나 바꿀 수 있습니다. 그런 다음 {{ui:블록 저장}}을 클릭하거나({{cmd:BCLOSE}}와 `S` 입력), 모든 참조에 변경이 반영되며 {{key:Mod+Z}} 한 번으로 전부 실행 취소됩니다. {{ui:변경 사항 버리기}}(`BCLOSE`, `D`)는 블록을 원래대로 둡니다.

속성 정의를 추가, 제거 또는 변경했다면 저장할 때 모든 참조도 맞춰집니다. 입력한 값은 유지되고, 새 속성은 기본값을 받으며, 제거된 속성은 사라지고, 각 속성은 정의가 정한 위치로 돌아갑니다. 기록에 갱신된 참조 개수가 표시됩니다.

## 표제란을 제자리에서 편집 (REFEDIT)

시트의 표제란은 종종 블록 안에 있습니다. 시트를 떠나지 않고 선이나 문자를 바꾸려면:

1. 표제란을 선택한 다음 {{ui:블록}} › {{ui:더보기}} › {{ui:현 위치 편집}}을 선택합니다(또는 {{cmd:REFEDIT}} 입력).
2. 내용이 그 자리에서 일반 객체가 됩니다. 나머지는 흐려지며 바꿀 수 없습니다.
3. 변경, 삭제 또는 그리기를 합니다. 새 객체는 블록의 일부가 됩니다.
4. 상단 막대의 {{ui:블록 저장}}을 클릭합니다(또는 {{cmd:REFCLOSE}}와 `S` 입력). 모든 참조에 변경이 반영되며, {{key:Mod+Z}} 한 번으로 편집 전체가 실행 취소됩니다. {{ui:버리기}}는 블록을 원래대로 둡니다.

연결된 도면, 동적 블록, 또는 가로세로 방향으로 다르게 축척된 참조는 제자리에서 편집할 수 없습니다. {{cmd:BEDIT}}을 사용하거나 연결된 도면을 여세요.

:::note
도면을 저장하기 전에 블록 편집기에서 저장하거나 버리세요. 편집기가 열린 상태로 저장한 파일에는 블록이 편집 전 상태로 들어갑니다.
:::

## 블록을 배치할 때 값 채우기

1. `I`를 입력하고 {{key:Enter}}를 누른 다음, 블록 이름을 입력하고 {{key:Enter}}를 누릅니다.
2. 놓을 위치를 클릭합니다.
3. CadCraft가 각 값을 묻습니다. 예: `Enter Item number (ITEM) <>`. 값을 입력하고 {{key:Enter}}를 누르거나, 꺾쇠 괄호에 표시된 기본값을 유지하려면 {{key:Enter}}만 누릅니다.

블록이 사전 설정으로 표시한 값과 상수 값은 묻지 않습니다. 기본값을 사용합니다.

## 값 보기와 변경

1. 블록 참조를 클릭합니다.
2. 오른쪽 패널의 {{ui:속성}} 아래에 각 태그와 값이 표시됩니다. 보이지 않는 값은 `hidden`이라고 표시됩니다.
3. 값을 클릭하고 새 값을 입력한 다음 {{key:Enter}}를 누릅니다.

도면에 새 값이 즉시 표시됩니다. 각 변경은 한 단계이며 {{key:Mod+Z}}로 실행 취소할 수 있습니다.

**속성 편집기.** 속성이 있는 참조를 더블 클릭하거나({{cmd:EATTEDIT}}) 하면 {{ui:속성 편집}} 대화상자에 모든 태그와 프롬프트, 값이 나열됩니다. 새 값을 입력하고, 행을 클릭해 이 참조에 한해 그 속성의 {{ui:높이}}, {{ui:회전}}, {{ui:너비 비율}}, {{ui:정렬}}, {{ui:도면층}}, {{ui:색상}}, {{ui:보이지 않음}}을 바꿀 수 있습니다. {{ui:적용}}은 대화상자를 열어 둡니다. {{ui:확인}}은 적용하고 닫습니다. {{ui:적용}}이나 {{ui:확인}}마다 실행 취소 한 단계입니다.

**명령행에서**, {{cmd:ATTEDIT}}는 각 값을 차례로 묻습니다. 새 값을 입력하거나 {{key:Enter}}를 눌러 그대로 둡니다.

## 속성 정의 변경 (BATTMAN, ATTSYNC)

{{ui:블록}} › {{ui:더보기}} › {{ui:속성 관리자}}({{cmd:BATTMAN}})는 블록의 속성을 나열합니다. 태그, 프롬프트 또는 기본값을 바꾸고, {{ui:보이지 않음}}, {{ui:상수}}, {{ui:사전 설정}}을 선택하며, 속성을 위아래로 옮길 수 있습니다(값을 묻는 순서). {{ui:참조 업데이트 (값 유지)}}를 선택하면 {{ui:적용}}이 모든 참조도 맞춥니다. 이름을 바꾼 태그는 값을 유지합니다. {{ui:적용}}마다 실행 취소 한 단계입니다.

{{cmd:ATTSYNC}}는 참조를 블록 정의에 맞게 직접 맞춥니다. `S`는 참조를 고르고, `N`은 블록 이름을 지정하며, `A`는 모든 블록을 처리합니다. 값은 유지됩니다.

라이브러리 항목 자체의 필드(ID, 버전, 라이선스, 출처 표시)는 표시만 되고 편집할 수 없습니다. 업데이트 확인이 계속 작동하도록 하기 위해서입니다. 품목 번호와 수량은 직접 바꿀 수 있습니다.

## 목록으로 보기

참조를 선택하고 `LI`(즉 {{cmd:LIST}})를 입력합니다. 기록에 각 속성이 `TAG = value` 형식으로 표시되며, 해당되는 경우 `(invisible)` 또는 `(constant)`가 함께 표시됩니다.

## 이동, 회전, 분해

- {{cmd:MOVE}}, {{cmd:ROTATE}}, {{cmd:SCALE}}, {{cmd:MIRROR}}는 값을 유지합니다. 문자는 블록과 함께 이동하며 읽을 수 있는 상태를 유지합니다.
- {{cmd:EXPLODE}}는 보이는 속성을 값이 담긴 일반 문자로 바꿉니다. 보이지 않는 속성은 사라집니다.

## 저장

저장한 DWG와 저장한 DXF는 모든 속성을 유지합니다. 각 블록의 정의(보이지 않음, 상수, 사전 설정 속성 포함)와 각 참조의 값이 포함됩니다. 다른 CAD 프로그램은 이를 일반 블록 속성으로 읽습니다.

DXF R12에서 255자를 넘는 값은 255자로 잘리며, 기록에 그 사실이 표시됩니다.

## 자주 하는 실수

- **값이 도면에 표시되지 않습니다.** 보이지 않음으로 설정되었거나 값이 비어 있습니다. 보이지 않는 값도 오른쪽 패널에는 표시됩니다.
- **입력한 값이 명령행으로 갔습니다.** 먼저 오른쪽 패널의 값 상자를 클릭하세요.
