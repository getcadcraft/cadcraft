## 작동하는 기능

동적 블록이 들어 있는 DWG는 다음 범위까지 동작하며 열립니다:

- **원래 이름.** 동적 블록은 {{ui:Blocks}} 패널에 고유 이름("Receptacle", "Sink")으로 나열되며, 이름 없는 `*U` 블록으로 나타나지 않습니다.
- **저장된 상태.** 각 참조는 다른 프로그램이 보여 준 그대로 나타납니다: 설정되어 있던 표시 상태, 저장 당시의 늘이기 또는 뒤집기 상태.
- **표시 상태 전환.** 참조 하나(또는 같은 블록 여러 개)를 선택하고 {{ui:Properties}}을 연 다음, {{ui:Custom}} 항목에서 {{ui:Visibility}} 목록의 다른 상태를 고릅니다. 참조는 즉시 그 상태를 보여 주며 속성도 함께 바뀝니다. 상태가 숨기는 속성은 사라지고, 보여 주는 속성은 값과 함께 나타납니다. 참조는 모든 값을 유지하므로 빈 값이 되는 것은 없으며, {{ui:Properties}}에는 숨겨진 속성이 "숨김"으로 표시되어 나열됩니다. {{key:Mod+Z}} 키를 누르면 이전 상태가 한 단계로 되돌아갑니다.
- **그립.** 선택한 동적 블록은 매개변수가 있는 자리에 고유 그립을 표시합니다: 표시 상태용 작은 삼각형(클릭하면 상태 목록이 열림), 거리 끝의 화살표, 뒤집기용 양방향 화살표. 현재는 표시 상태 그립만 동작하며, 나머지는 상태 표시줄에 그렇다고 알려 줍니다.
- **다른 값은 읽기 전용.** 표시 상태 목록 아래의 {{ui:Custom}}에는 도면이 가진 그대로 블록의 거리, 정렬 각도, 뒤집기 상태, 점 위치도 나타납니다.
- **표시 상태 편집.** {{cmd:BEDIT}} 명령을 사용해 블록을 엽니다. 편집기는 상태 하나를 보여 주며, 도면 위 막대에 그 이름이 표시됩니다(거기서 다른 상태를 고를 수 있습니다). {{cmd:BVSTATE}} 명령을 입력해 상태를 전환하거나, 추가(모두 숨기기, 모두 보이기, 보이는 것 유지 중에서 선택), 이름 바꾸기, 삭제합니다. {{cmd:BVHIDE}} 명령은 보이는 상태에서 선택한 객체를 숨기고, {{cmd:BVSHOW}} 명령은 숨겨진 객체를 흐리게 표시하여 다시 가져올 것을 클릭할 수 있게 합니다. 블록을 저장하면, 이름이 바뀐 상태로 설정된 참조는 새 이름을 유지하고, 삭제된 상태로 설정된 참조는 첫 번째 상태를 표시합니다.
- **동적 상태 유지.** 도면이 열렸던 버전에서 DWG를 저장하면, 블록은 선택한 상태와 함께 동적 블록으로 남습니다. 다른 프로그램은 같은 동적 블록으로 엽니다. 편집한 표시 상태도 함께 저장됩니다: 새 이름, 추가한 상태, 그리고 각 상태가 보여 주는 내용.

## 읽기 전용이거나 아직 없는 기능

| 아직 없음 | 지금은 대신 |
|---|---|
| 거리, 각도, 뒤집기 변경(늘이기, 이동, 뒤집기 동작) | {{ui:Custom}}에서 읽기 전용으로 표시됩니다. 블록을 만든 프로그램에서 편집하십시오. |
| 조회, XY, 회전, 극좌표 매개변수 | 아직 읽지 않습니다. 참조는 저장된 그대로 보입니다. |
| 거리, 뒤집기, 점 그립 끌기 | 매개변수가 있는 위치에 표시됩니다. 표시 상태 그립과 속성의 {{ui:Visibility}} 목록으로 상태를 전환합니다. |
| 동적 블록 만들기(매개변수 추가, 또는 표시 상태가 없는 블록에 상태 추가) | CadCraft에서 만든 블록은 일반 블록입니다. {{cmd:BPARAMETER}} 명령이 이를 알려 줍니다. |
| 블록 편집기에서 표시 상태가 있는 블록의 객체를 추가하거나 지우기 | 그러면 블록은 일반 블록으로 저장됩니다(편집기가 닫힐 때 그렇다고 알려 줍니다). |
| 다른 DWG 버전이나 DXF에서 동적 상태 유지 | 선택한 상태를 보여 주는 일반 블록으로 저장되며, 저장할 때 그렇다고 알려 줍니다. |

:::note
{{cmd:BEDIT}}에서 객체를 옮기거나 바꾸면 표시 상태가 있는 블록은 동적 상태를 유지합니다. 상태가 없는 블록이거나, 편집기에서 객체를 추가하거나 지운 블록은 일반 블록이 됩니다.
:::
