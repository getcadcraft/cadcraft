## 동작하는 기능

동적 블록이 들어 있는 DWG는 여기까지 동작하며 열립니다:

- **원래 이름.** 동적 블록은 {{ui:Blocks}} 패널에 `*U` 블록이 아닌 자기 이름("Receptacle", "Sink")으로 나열됩니다.
- **저장된 상태.** 각 참조는 다른 프로그램이 보여 준 그대로를 보여 줍니다: 설정된 표시 상태, 저장된 대로 늘이거나 뒤집은 모양.
- **표시 상태 전환.** 참조 하나(또는 같은 블록 여러 개)를 선택하고, {{ui:Properties}}를 열고, {{ui:Custom}} 구역에서 {{ui:Visibility}} 목록의 다른 상태를 고릅니다. 참조는 즉시 그 상태를 보여 주며, 속성도 마찬가지입니다. 그 상태가 숨기는 속성은 사라지고, 보여 주는 속성은 값과 함께 나타납니다. 참조는 모든 값을 유지하므로, 비어서 돌아오는 것은 없습니다. {{ui:Properties}}는 숨겨진 것을 "hidden"으로 표시해 나열합니다. {{key:Mod+Z}}를 누르면 이전 상태가 한 단계로 돌아옵니다.
- **그립.** 선택한 동적 블록은 자기 매개변수가 있는 곳에 자기 그립을 보여 줍니다: 표시 상태용 작은 삼각형 (클릭하면 상태 목록), 거리의 끝에 있는 화살표, 뒤집기용 이중 화살표. 지금은 표시 상태 그립만 동작하며, 나머지는 상태 표시줄에 그렇다고 나타납니다.
- **다른 값, 읽기 전용.** 표시 상태 목록 아래의 {{ui:Custom}}은 블록의 거리, 정렬 각도, 뒤집기 상태, 점을 도면이 가진 그대로 보여 줍니다.
- **표시 상태 편집.** {{cmd:BEDIT}}로 블록을 엽니다. 편집기는 상태 하나를 보여 주며, 도면 위의 막대에 그 이름이 나타납니다 (거기서 다른 상태를 고를 수 있습니다). {{cmd:BVSTATE}}를 입력하면 상태를 전환하고, 추가하고 (모든 것을 숨기기, 모든 것을 보이기, 또는 보이는 것 유지), 이름을 바꾸거나 삭제할 수 있습니다. {{cmd:BVHIDE}}는 현재 보이는 상태에서 선택한 객체를 숨깁니다. {{cmd:BVSHOW}}는 숨겨진 객체를 흐리게 보여 주므로, 되돌릴 것을 클릭할 수 있습니다. 블록을 저장하면, 이름을 바꾼 상태로 설정된 참조는 새 이름으로 유지되며, 삭제한 상태로 설정된 참조는 첫 번째 상태를 보여 줍니다.
- **동적으로 유지.** 도면이 들어온 버전의 DWG로 저장하면, 블록은 여러분이 고른 상태와 함께 동적으로 남으며, 다른 프로그램은 그것을 같은 동적 블록으로 엽니다. 편집한 표시 상태도 저장됩니다: 새 이름, 추가한 상태, 그리고 각 상태가 보여 주는 것.

## 읽기 전용이거나 아직 없는 것

| 아직 없음 | 대신, 지금은 |
|---|---|
| 거리, 각도, 뒤집기 바꾸기 (늘이기, 이동, 뒤집기 동작) | {{ui:Custom}}에서 읽기 전용으로 보입니다. 블록을 만든 프로그램에서 편집하십시오. |
| 조회, XY, 회전과 극좌표 매개변수 | 아직 읽지 않습니다. 참조는 저장된 대로 보입니다. |
| 거리, 뒤집기, 점 그립 끌기 | 매개변수가 있는 위치에 보이기만 합니다. 표시 상태 그립과 특성 패널의 {{ui:Visibility}} 목록만 상태를 전환합니다. |
| 다른 프로그램 종류의 동적 블록 만들기 (늘이기, 뒤집기, 조회) | CadCraft에서 만든 블록은 일반 블록입니다. {{cmd:BPARAMETER}}가 그렇다고 알려 줍니다. 나만의 매개변수와 여러 표시 매개변수는 매개변수 관리자에 있습니다 (아래 "나만의 매개변수와 표시 상태" 참조). |
| 블록 편집기에서 표시 상태가 있는 블록의 객체를 추가하거나 지우기 | 그러면 블록은 일반 블록으로 저장됩니다 (편집기가 닫힐 때 그렇다고 알려 줍니다). |
| 다른 DWG 버전이나 DXF에서 동적으로 유지하기 | 여러분이 고른 상태를 보여 주는 일반 블록으로 저장되며, 저장할 때 그렇다고 알려 줍니다. |

:::note
{{cmd:BEDIT}}에서 객체를 움직이거나 바꾸면 표시 상태가 있는 블록은 동적으로 남습니다. 상태가 없는 블록이나, 편집기에서 객체를 추가하거나 지운 블록은 일반 블록이 됩니다.
:::

## 나만의 매개변수와 표시 상태

CadCraft에서 만든 블록은 자기 매개변수와 **여러** 표시 매개변수를 가질 수 있으며, 각각 자기 상태를 가집니다. {{cmd:BPARAMS}} (또는 `BPM`)를 입력하면, {{cmd:BEDIT}}에서 편집 중인 블록, 선택한 참조의 블록, 또는 지정한 블록을 위한 **매개변수 관리자**가 열립니다.

- **매개변수**: 이름, 종류 (숫자, 길이, 각도, 개수, 예/아니오), 그리고 값 또는 다른 매개변수에 대한 수식 (`w * 2`, `if(n > 3, 1, 0)`). {{ui:Comes to}}는 결과를 보여 줍니다. 작동하지 않는 수식이나 종류에 맞지 않는 값 (1.5개인 개수)은 거부하며, 관리자가 이유를 말합니다. 다른 것은 바뀌지 않습니다.
- **표시 매개변수**: {{ui:Add visibility parameter}}는 첫 상태를 가진 매개변수를 만듭니다. 각 상태는 이름을 바꾸거나, 제거하거나 (마지막 것은 남습니다), "보이는 조건" 번호를 줄 수 있습니다. 수식은 매개변수로 상태를 고릅니다 (번호가 맞는 상태, 아니면 목록에서 그 자리의 상태). 수식이 없으면 각 참조가 자기 상태를 고릅니다.
- **상태에 객체 넣기**: 블록 편집기에서 객체를 고르고, {{cmd:BPARAMS}}를 입력한 뒤, 상태에서 {{ui:Put the selected objects here}}를 클릭합니다. 어떤 표시 매개변수에도 나오지 않는 객체는 항상 보입니다.
- **이 참조**: 선택한 참조에서 시작하면 관리자는 그 참조의 고유 값과 상태도 보여 줍니다.

블록 편집기 밖에서 하는 모든 변경은 실행 취소 한 단계입니다. 블록 편집기에서는 변경이 편집기의 것이며, {{ui:Save block}}이 그것을 유지합니다. `-BPARAMS`는 명령행에서 같은 것을 묻습니다.

**파일에서.** DWG와 DXF는 매개변수, 어느 객체가 어느 상태에 있는지, 그리고 각 참조의 고유 값을 CadCraft 고유 기록에 보관합니다. 파일을 CadCraft에서 다시 열면 모두 돌아옵니다. 다른 프로그램은 각 참조를 모든 객체를 가진 블록으로 봅니다. DWG는 블록마다 자기 종류의 표시 매개변수를 최대 하나만 담기 때문입니다. 다른 프로그램이 움직인 참조나 객체를 바꾼 블록은, 더 이상 맞지 않는 부분 없이 돌아옵니다 (추측하지 않습니다).
