## 만들 결과

의자 한 개를 테이블 주위에 복사하고, 회전하고, 대칭 복사하고, 크기를 바꿔 테이블을 완성합니다. 이 과정에서 {{cmd:MOVE}}, {{cmd:COPY}}, {{cmd:ROTATE}}, {{cmd:MIRROR}}, {{cmd:SCALE}}, {{cmd:UNDO}} 명령을 사용합니다.

## 도형 그리기

1. `REC` 입력 후 {{key:Enter}} 키를 누르고, `0,0` 입력 후 {{key:Enter}} 키를 누른 다음, `@1800,900` 입력 후 {{key:Enter}} 키를 누릅니다. 이것이 테이블입니다.
2. `REC` 입력 후 {{key:Enter}} 키를 누르고, `300,-700` 입력 후 {{key:Enter}} 키를 누른 다음, `@450,450` 입력 후 {{key:Enter}} 키를 누릅니다. 테이블 아래에 있는 의자입니다.
3. {{ui:Extents}}를 클릭합니다.

## 이동: 기준점, 그다음 두 번째 점

이동, 복사, 회전, 축척은 모두 **기준점**에서 시작합니다. 기준점은 함께 따라가거나 그 주위로 돌아가는 점입니다.

1. 의자를 클릭해 선택합니다.
2. `M` 입력 후 {{key:Enter}} 키를 누릅니다. 기록에 `1 found`가 표시됩니다.
3. `Specify base point` 프롬프트에서 의자의 왼쪽 위 모서리에 스냅(Endpoint)하고 클릭합니다.
4. `Specify second point` 프롬프트에서 `@0,200` 입력 후 {{key:Enter}} 키를 누릅니다.

의자가 위로 200 이동하여 테이블에 더 가까워집니다.

:::tip
`Specify base point` 프롬프트에서 `D`를 입력하면 대신 변위를 줄 수 있습니다. 그러면 CadCraft가 `Specify displacement`를 묻고, `0,200`처럼 가로와 세로로 얼마나 움직일지 입력합니다(`@`는 필요 없습니다).
:::

## 복사: 원하는 만큼 여러 번

1. 의자를 클릭합니다.
2. `CO` 입력 후 {{key:Enter}} 키를 누릅니다.
3. 의자의 왼쪽 아래 모서리에 스냅하고 클릭해 기준점으로 지정합니다.
4. `@600,0` 입력 후 {{key:Enter}} 키를 누릅니다. 오른쪽으로 600 떨어진 곳에 복사본이 생깁니다.
5. 다시 `@600,0` 입력 후 {{key:Enter}} 키를 누릅니다. 원본에서 오른쪽으로 1200 떨어진 곳에 두 번째 복사본이 생깁니다.
6. {{key:Enter}} 키를 눌러 명령을 끝냅니다.

{{cmd:COPY}}는 {{key:Enter}} 키를 누를 때까지 계속 실행됩니다. 각 복사본은 기준점에서 입력한 점까지의 거리만큼 배치됩니다. `@` 점은 마지막으로 입력한 점을 기준으로 합니다. 첫 번째 복사 후에는 그 복사본의 점이 기준이므로, `@600,0`을 두 번 입력하면 600과 1200 위치에 복사본이 생깁니다. `U` 입력 후 {{key:Enter}} 키를 누르면 명령을 벗어나지 않고 마지막 복사본을 취소합니다.

테이블 아래에 의자 세 개가 나란히 보여야 합니다.

:::tip
{{cmd:COPY}}는 기준점으로 배치하는 한 도면 안에서의 복사에 씁니다. 객체를 다른 도면이나 탭으로 옮기거나 나중에 붙여넣으려면 클립보드를 사용하십시오. {{key:Mod+C}} 키로 복사한 뒤 {{key:Mod+V}} 키로 붙여넣습니다. {{key:Mod+D}} 키는 포인터를 따라 움직이는 복사본 하나를 만듭니다. 자세한 내용은 [복사, 붙여넣기 및 복제](topic:copy-paste)를 참고하십시오.
:::

## 행을 반대쪽으로 대칭 복사

1. 오른쪽에서 왼쪽으로 걸침 선택 영역을 드래그해 세 의자를 감싸고, 테이블에는 닿지 않게 합니다.
2. `MI` 입력 후 {{key:Enter}} 키를 누릅니다.
3. `Specify first point of mirror line` 프롬프트에서 테이블 왼쪽 변의 중간점에 스냅하고 클릭합니다.
4. `Specify second point of mirror line` 프롬프트에서 테이블 오른쪽 변의 중간점에 스냅하고 클릭합니다.
5. `Erase source objects? [Yes/No] <N>` 프롬프트에서 {{key:Enter}} 키를 눌러 원본을 유지합니다.

테이블 아래에 의자 세 개, 위에 대칭 복사된 의자 세 개가 보여야 합니다. 대칭 선택 영역의 문자는 대칭된 위치에 놓이지만 뒤집혀 쓰이지 않으므로 계속 읽을 수 있습니다.

## 의자 회전

1. 테이블 아래 가장 오른쪽 의자를 클릭합니다.
2. `RO` 입력 후 {{key:Enter}} 키를 누릅니다.
3. 의자의 오른쪽 아래 모서리에 스냅하고 클릭해 기준점으로 지정합니다.
4. `90` 입력 후 {{key:Enter}} 키를 누릅니다.

의자가 기준점을 중심으로 반시계 방향으로 90도 회전합니다. 음수 각도는 시계 방향으로 회전합니다. 각도를 입력하는 대신 두 번째 점을 클릭할 수도 있습니다. 이때 각도는 기준점에서 그 점까지를 기준으로 측정됩니다.

## 테이블 축척

1. 테이블을 선택합니다.
2. `SC` 입력 후 {{key:Enter}} 키를 누릅니다.
3. 테이블의 왼쪽 아래 모서리에 스냅하고 클릭해 기준점으로 지정합니다.
4. `1.2` 입력 후 {{key:Enter}} 키를 누릅니다.

테이블이 20% 커지며, 기준점에서 멀어지는 방향으로 늘어납니다. 1보다 작은 배율은 크기를 줄입니다.

:::note
축척 배율을 입력하는 대신 점을 클릭하면, 배율은 기준점에서 그 점까지의 거리가 됩니다. 도면 단위 1만큼 떨어진 점을 클릭하면 배율은 1이 됩니다. 보통은 숫자를 입력하는 것이 원하는 결과를 줍니다.
:::

## 실행 취소와 다시 실행

- {{key:Mod+Z}} 키, {{ui:Undo}} 버튼, 또는 `U` 입력 후 {{key:Enter}} 키를 누르면 마지막 명령을 실행 취소합니다. 명령 하나가 한 단계입니다. 복사본 다섯 개를 만든 {{cmd:COPY}}를 취소하면 다섯 개가 모두 제거됩니다.
- {{key:Mod+Y}} 키, {{key:Mod+Shift+Z}} 키, {{ui:Redo}} 버튼, 또는 `REDO` 명령은 취소한 작업을 다시 실행합니다.
- 기록에는 무엇이 실행 취소되었는지 표시됩니다("Undid COPY").

CadCraft는 마지막 500단계를 보관합니다. 도면층 설정(켜기, 동결, 잠금, 색상)은 편집이 아니라 설정이므로 실행 취소되지 않습니다.

## 방을 더 넓게 늘이기

{{cmd:STRETCH}}(`S`, 또는 {{ui:Stretch}})는 걸침 윈도우 안에 있는 부분만 움직입니다. 윈도우 안에 든 모서리와 선 끝은 움직이고 나머지는 제자리에 남으므로, 방 전체가 옮겨지는 대신 넓어집니다.

1. `S` 입력 후 {{key:Enter}} 키를 누릅니다.
2. 오른쪽 벽 위로 오른쪽에서 왼쪽으로 윈도우를 드래그해, 벽의 모서리와 벽에 닿은 객체의 끝을 모두 감쌉니다.
3. {{key:Enter}} 키를 누릅니다.
4. 기준점을 클릭한 다음 `@600,0` 입력 후 {{key:Enter}} 키를 누릅니다.

사각형이 600 넓어지고, 벽에 끝이 닿아 있던 선은 여전히 벽에 닿아 있습니다. 한쪽 끝이 윈도우 안에 있는 호는 높이를 유지하고, 중심이나 삽입점이 윈도우 안에 있는 원과 문자는 함께 움직이며, 치수는 새 길이를 측정합니다. 윈도우 없이 하나씩 고른 객체는 그냥 이동합니다.

명령을 실행하지 않은 상태에서 먼저 선택할 수도 있습니다. 벽 위로 걸침 윈도우(또는 걸침 올가미)를 드래그한 다음 `S` 입력합니다. STRETCH는 그 선택 영역을 받아, 명령 프롬프트에서 직접 드래그한 것과 같이 윈도우 안의 내용을 신축합니다.

## 배열: 행과 열, 또는 중심 주위로

{{cmd:ARRAY}}(`AR`, 또는 {{ui:Array}})는 선택 영역을 격자나 원형으로 복사합니다.

1. 의자를 선택하고 `AR` 입력 후 {{key:Enter}} 키를 누릅니다. 직사각형 배열을 쓰려면 {{key:Enter}} 키를 한 번 더 누릅니다.
2. 열 4개, 행 3개의 미리 보기가 나타납니다. `COU` 입력 후 {{key:Enter}} 키를 누르고, 열 수 `5`, 행 수 `2`를 입력합니다.
3. `S` 입력 후 {{key:Enter}} 키를 누릅니다. 열 사이 간격 `600`, 행 사이 간격 `-900`을 입력합니다(음수는 아래쪽).
4. {{key:Enter}} 키를 눌러 복사본을 만듭니다.

테이블 주위에 의자를 원형으로 배치하려면 `PO`(극좌표)를 선택하고, 테이블의 중심을 클릭한 다음 `I`(개수), `F`(채울 각도: 전체는 360, 반원은 180), `ROT`(복사본이 중심을 향하도록 회전할지 여부)를 설정합니다. {{cmd:ARRAYRECT}}와 {{cmd:ARRAYPOLAR}}는 이 질문을 건너뜁니다.

## 여러 조각을 하나의 폴리선으로 결합

{{cmd:JOIN}}(`J`, 또는 {{ui:Modify}} › {{ui:More}} › {{ui:Join}}): 끝이 만나는 선, 호, 열린 폴리선을 선택하고 {{key:Enter}} 키를 누릅니다. 이들은 하나의 폴리선이 되며, 한 바퀴를 모두 돌면 닫힌 폴리선이 되어 한 번에 간격 띄우기할 수 있습니다. 한 직선 위에 놓인 선들은 사이에 틈이 있어도 하나의 선이 되며, 같은 원의 호들은 하나의 호 또는 원이 됩니다.

## 속성 일치

{{cmd:MATCHPROP}}(`MA`, 또는 {{ui:Modify}} › {{ui:More}} › {{ui:Match properties}}): 닮게 하려는 객체를 클릭한 다음, 바꿀 객체를 선택하고 {{key:Enter}} 키를 누릅니다. 이들은 그 객체의 도면층과 색상을 받으며, 문자는 높이를, 치수는 치수 크기를, 해치는 패턴을 받습니다. 두 번째 질문에서 `S`(설정)를 입력하면 이 중 어떤 항목이든 끌 수 있습니다.

## 객체 정렬

**점으로.** {{cmd:ALIGN}}(`AL`, 또는 {{ui:Modify}} › {{ui:More}} › {{ui:Align}}): 객체를 선택하고 {{key:Enter}} 키를 누른 다음, 객체 위의 점(원본)과 그 점이 가야 할 위치(대상)를 클릭합니다.

- 한 쌍이면 객체가 이동합니다. `Specify second source point` 프롬프트에서 {{key:Enter}} 키를 누르면 여기서 멈춥니다.
- 두 쌍이면 객체가 회전하기도 하여, 두 원본 점을 잇는 선이 두 대상 점을 잇는 선과 나란해집니다. 그러면 CadCraft가 `Scale objects based on alignment points?`를 묻습니다. `Y`로 답하면 객체 크기도 그만큼 키우거나 줄입니다.
- 세 번째 쌍은 두 점이 그 선의 반대쪽에 있을 때 객체를 대칭시킵니다.

**모서리와 간격.** {{ui:Modify}} › {{ui:More}} › {{ui:Align and distribute}}(또는 `ALIGNPANEL`)를 열면 도면 위에 작은 패널이 나타납니다. 객체를 선택한 다음 다음을 수행합니다.

- {{ui:Align to}}에서 맞출 기준을 고르고(전체 선택 영역, 먼저 또는 마지막으로 고른 객체, 또는 클릭한 점), {{ui:Left}}, {{ui:Center}}, {{ui:Right}}, {{ui:Top}}, {{ui:Middle}}, {{ui:Bottom}} 중 하나를 클릭합니다.
- 또는 {{ui:Equal gaps}}나 {{ui:Equal centres}}를 고르고 {{ui:Across}}나 {{ui:Up and down}}을 클릭합니다. 바깥쪽 두 객체는 그대로 두고, 나머지는 그 사이에 고르게 배치됩니다(객체 세 개 이상).

클릭할 때마다 실행 취소 단계 하나가 되며, 선택 영역은 유지되므로 다른 방법을 시도할 수 있습니다. 각 객체는 경계 상자로 계산되며, UCS가 설정되어 있으면 UCS 기준으로 계산됩니다. 명령행에서는 {{cmd:ALIGNTO}}와 {{cmd:DISTRIBUTE}}가 같은 기능을 합니다.

## 지우기와 분해

- {{cmd:ERASE}}(`E`, 또는 {{key:Delete}} 키)는 선택한 객체를 제거합니다.
- {{cmd:EXPLODE}}(`X`)는 폴리선을 선과 호로, 블록 참조를 구성 객체로, 치수를 선, 화살촉, 문자로 분해합니다. 분해된 치수는 더 이상 스스로 측정하지 않습니다.

## 흔한 실수

- **두 번째 점에 `@` 없이 거리를 입력했습니다.** `600,0`은 절대 좌표 600,0을 뜻하며, "오른쪽으로 600"이 아닙니다. `@600,0`처럼 쓰거나, 십자선이 올바른 방향을 가리키는 상태에서 `600`만 입력하십시오.
- **회전 방향이 반대입니다.** 양의 각도는 반시계 방향으로 회전합니다.
- **실행 취소로 예상보다 많이 지워졌습니다.** 실행 취소 한 번은 마지막 명령 전체를 되돌리며, 그 명령이 만든 모든 복사본도 포함됩니다.
- **명령이 객체를 선택하라고 묻지 않습니다.** 객체가 이미 선택되어 있어 그 객체를 사용했습니다. 선택 없이 시작하려면 먼저 {{key:Esc}} 키를 누르십시오.
