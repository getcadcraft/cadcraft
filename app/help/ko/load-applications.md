## 학습 내용

LISP 루틴(`.lsp` 파일)을 로드해 CadCraft에서 그 명령이 작동하게 하는 방법, 언로드하는 방법, 그리고 CadCraft를 시작할 때마다 자동으로 로드되게 하는 방법을 익힙니다.

## 루틴 로드

1. {{ui:뷰}} › {{ui:더보기}} › {{ui:응용 프로그램 로드…}}를 열거나, {{cmd:APPLOAD}}(또는 `AP`)를 입력하고 {{key:Enter}}를 누릅니다.
2. {{ui:파일 로드…}}를 클릭하고 `.lsp` 파일을 하나 이상 선택합니다. 대화 상자를 여는 루틴에는 대개 `.dcl` 파일이 함께 제공되므로, 그 파일도 선택하십시오.
3. 대화 상자에 각 파일이 만든 항목이 표시됩니다. 예: "delblocks.lsp 로드됨: 명령 1개, DELBLOCKS."
4. {{ui:닫기}}를 클릭하고, 루틴의 명령을 입력한 뒤 {{key:Enter}}를 누릅니다.

`.lsp` 및 `.dcl` 파일을 도면이나 응용 프로그램 로드 대화 상자에 끌어 놓을 수도 있습니다. 그러면 즉시 로드됩니다.

파일은 여기 브라우저에서 읽으며, 아무것도 업로드되지 않습니다.

:::tip
빈 명령행에서 {{key:Enter}}를 누르면 루틴의 명령을 다시 실행합니다. 다른 명령과 같습니다. 명령 별칭으로도 실행할 수 있습니다. "명령 별칭 편집"을 참조하십시오.
:::

## 루틴 언로드

{{ui:응용 프로그램 로드}}의 {{ui:로드된 응용 프로그램}} 아래에서 파일 옆의 {{ui:언로드}}를 클릭합니다. 루틴이 만든 명령은 다시 로드할 때까지 사라집니다.

## CadCraft 시작 때마다 루틴 로드

1. 루틴을 로드합니다.
2. {{ui:로드된 응용 프로그램}} 아래에서 해당 파일 옆의 {{ui:시작 모음에 추가}}를 클릭합니다.

이후 이 브라우저에서 CadCraft가 시작될 때마다 자동으로 로드됩니다. 중지하려면 {{ui:시작 모음}} 아래에서 해당 항목 옆의 {{ui:제거}}를 클릭합니다.

시작 모음은 각 파일의 사본을 이 브라우저의 저장소에 보관합니다. 루틴을 변경했다면 새 파일을 로드한 뒤 다시 추가하십시오.

## 지원 폴더에서 acad.lsp와 acaddoc.lsp 로드 (Studio)

CadCraft Studio에서는 {{ui:응용 프로그램 로드}} 대화 상자의 {{ui:지원 폴더}}가 컴퓨터의 폴더를 가리킵니다. {{ui:폴더 선택…}}을 클릭하십시오. CadCraft가 시작되면 그 폴더에서 `acad.lsp`를 찾아 읽고, 이어서 `acaddoc.lsp`를 읽어 로드한 뒤 시작 모음을 로드합니다. 파일 이름의 대소문자와 관계없이 찾습니다. `acaddoc.lsp`는 새 도면 탭이 열릴 때마다 다시 읽습니다. 폴더의 다른 파일은 읽지 않으며, 2 MB를 넘는 파일은 메시지와 함께 건너뜁니다.

파일이 `S::STARTUP`이라는 함수를 정의하면, 파일을 로드한 뒤(시작 모음 이후에도) 한 번 실행됩니다. {{ui:지금 로드}}는 요청할 때 같은 동작을 하며, {{ui:지우기}}는 폴더를 잊게 합니다.

브라우저에서는 페이지가 폴더를 보관할 수 없으므로 지원 폴더가 없습니다. 위의 시작 모음을 사용하십시오. 컴파일된 `.fas` 및 `.vlx` 파일과 네이티브 프로그램은 계속 거부됩니다.

## 기록에서 파일 다시 로드

{{ui:기록}}에는 이 브라우저에서 로드한 파일이 최신순으로 나열됩니다. 항목 옆의 {{ui:로드}}를 클릭하면 컴퓨터에서 찾지 않고도 다시 로드됩니다.

## CadCraft가 로드할 수 없는 파일

| 파일 | 설명 | 해결 방법 |
|---|---|---|
| `.fas`, `.vlx` | 컴파일되었거나 보호된 LISP | 대신 `.lsp` 원본을 로드하십시오 |
| `.arx`, `.crx`, `.dbx` | 네이티브 Windows 프로그램 | CadCraft에서는 실행할 방법이 없습니다 |
| `.dvb` | VBA 프로젝트 | CadCraft에서는 실행할 방법이 없습니다 |
| `.craft`, `.lua`, `.py` | CraftScript 스크립트 | PartCraft의 스크립트 작업 공간에서 여십시오 |

응용 프로그램 로드 대화 상자는 파일을 선택할 때 그것이 어떤 파일인지 알려 줍니다.

## 루틴 중지

{{key:Esc}}를 누르십시오. 루틴의 프롬프트에서 Esc는 루틴이 기대하는 방식으로 취소합니다(정리 작업이 실행됩니다). 루틴이 바쁘고 아무것도 묻지 않는 상태라면 Esc는 즉시 중지하며, 그 사실을 알려 줍니다. 로드된 루틴은 그대로 로드된 상태로 남습니다.

:::note
루틴이 도면에서 바꾼 모든 것은 한 단계입니다. {{key:Mod+Z}}를 한 번 누르면 전부 되돌아갑니다.
:::
