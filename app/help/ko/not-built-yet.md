CadCraft는 개발 중입니다. 이 페이지에는 현재 빌드에서 되지 않는 기능을 정리했으므로, 찾느라 시간을 들이지 않으셔도 됩니다. 각 항목에는 지금 대신 할 수 있는 방법을 함께 적었습니다.

## 파일 및 저장

| 아직 만들지 않은 기능 | 지금 대신 할 수 있는 방법 |
|---|---|
| AutoCAD 자체에서 검사한 CadCraft DWG | 저장한 버전은 모두 다른 프로그램 세 가지의 DWG 읽기 기능과 CadCraft로 다시 읽어 확인합니다. 자세한 내용은 [DWG가 보존하고 바꾸는 것](topic:files#what-a-dwg-keeps-and-changes)을 참조하십시오. |
| DXF 2000보다 새로운 버전으로 저장 | DXF 2000으로 저장하거나, AutoCAD 2018까지의 DWG로 저장하십시오. |
| 브라우저에서 열린 파일에 덮어쓰기 저장 | 저장할 때마다 새 복사본이 다운로드됩니다. 원하면 이전 파일을 직접 바꾸십시오. CadCraft Studio에서는 {{key:Mod+S}}로 연 파일에 다시 씁니다. |
| 클라우드 저장과 컴퓨터 간 동기화 | CadCraft는 아직 저장 파일을 클라우드로 보내지 않습니다. DWG와 DXF 파일은 직접 만든 폴더에 보관하십시오. CadCraft Studio에서는 [기록](topic:history)에서 다른 곳에서 저장된 도면의 클라우드 버전과, 이 컴퓨터에 있는 내 저장 파일의 복사본을 나열합니다. |
| 오버레이, 그리고 연결된 도면을 제자리에서 편집 | 도면을 링크로 첨부하고, 다른 도면을 바꾼 뒤 다시 로드하십시오. DWG로 저장해도 링크는 링크로 남으며, {{cmd:XCLIP}}로 잘라낼 수 있습니다. |
| DXF의 그림, 아래에 있는 것을 가리는 웨이프아웃 | DXF는 그림을 파일 이름이 적힌 테두리로 저장하고, DWG는 그림으로 저장합니다. [도면의 그림](topic:pictures)을 참조하십시오. 웨이프아웃은 테두리로 표시됩니다. |
| 곡선 지시선, 내용 양쪽의 지시선, 또는 불균등하게 회전하거나 축척한 블록이 있는 다중 지시선 편집 | 다른 프로그램이 그린 대로 그려지며 하나로 함께 움직입니다. 한 지점으로 향하는 직선 지시선이 있고 내용이 문자나 블록인 다중 지시선은 편집 가능한 상태로 열립니다 ({{cmd:MLEADEREDIT}}). |
| 다른 프로그램의 표에서: 블록을 담은 셀, 셀 안의 문자 서식, DXF 표의 셀별 테두리와 색, 여러 열로 나뉜 표 | 표는 편집 가능한 표({{cmd:TABLEDIT}})로 열리며, 편집하기 전까지는 다른 프로그램이 그린 대로 표시됩니다. 편집하면 CadCraft가 셀 내용으로 다시 그립니다: 일반 문자, `=G3*H3`이나 `=Sum(I3:I9)` 같은 수식, 정렬과 문자 높이. 그 뒤 블록 셀은 비어 있게 됩니다. 편집하지 않은 DWG 표는 가져온 셀 데이터와 함께 다시 저장됩니다. |
| 저장된 DXF의 실제 표 객체 | DWG는 표를 다른 프로그램이 편집할 수 있는 표로 보존합니다. DXF는 표를 그리는 블록으로 보존하며, CadCraft 고유의 기록을 함께 남깁니다. CadCraft는 이를 다시 표로 엽니다. 다른 프로그램에서는 블록으로 보입니다. 대칭 또는 불균등 축척된 표는 DWG에서도 그렇게 저장됩니다. |
| 다른 프로그램과 복사 및 붙여넣기 | CadCraft의 클립보드는 같은 브라우저의 CadCraft 도면과 탭 사이에서만 작동하며, 다른 프로그램과는 작동하지 않습니다. DWG 또는 DXF로 저장해 그 프로그램에서 여십시오. [복사, 붙여넣기 및 복제](topic:copy-paste)를 참조하십시오. |

## 그리기 및 편집

| 아직 만들지 않은 기능 | 지금 대신 할 수 있는 방법 |
|---|---|
| CadCraft에 없는 해치 패턴, 그리고 다른 프로그램이 칠하는 그대로의 그라데이션 채우기 | CadCraft에 없는 패턴을 가진 열린 해치는 한 가지 톤으로 표시됩니다. 그라데이션 채우기({{cmd:GRADIENT}})는 종류별로 CadCraft 고유의 방식으로 칠해집니다. 종류는 다른 프로그램과 비슷하지만 점마다 똑같지는 않습니다. DWG 2004 이후에서는 실제 그라데이션 해치로 보존됩니다. DXF 2000 또는 DWG 2000 파일에서는 CadCraft만 다시 읽을 수 있고, 다른 프로그램에는 단색 채우기로 보입니다. 패턴은 `.pat` 파일에서 불러오며, 해치를 경계에 연결하면 경계를 따라갑니다. [해치 및 채우기 영역](topic:hatch)을 참조하십시오. |
| 모양이나 문자가 들어 있는 선종류, 그리고 저장된 DXF R12의 선가중치 | 파일 선종류의 모양과 문자는 대시에서 제외됩니다. 선가중치를 유지하려면 DWG로 저장하십시오. |
| 저장된 DXF의 패턴 해치 | R12에는 해치가 없으므로 외곽선으로 저장됩니다. 패턴을 유지하려면 DWG로 저장하십시오. |
| 다른 프로그램이 만들었거나 편집할 수 있는 배열; 경로 배열과 원형 배열의 행과 레벨; 경로 곡선을 따라가는 배열 | ASsociative 옵션으로 만든 배열({{cmd:ARRAY}}, {{cmd:ARRAYPATH}}; {{cmd:ARRAYEDIT}}로 변경)은 CadCraft 고유의 개수를 가진 블록 참조로 저장됩니다. 다른 프로그램은 이를 표시하고, 이동하고, 플롯하고, 분해할 수 있지만 개수는 바꿀 수 없습니다. 다른 프로그램에서 만든 배열은 여기서 일반 블록 참조로 열립니다. 경로 배열은 경로의 사본을 보관하므로, 나중에 곡선을 편집해도 항목은 움직이지 않습니다. |
| 다른 프로그램과 주고받는 잘린 시트 뷰포트 | {{cmd:VPCLIP}}로 자르거나 {{cmd:MVIEW}}의 Polygonal 또는 Object 옵션으로 만든 뷰포트는 CadCraft 고유의 외곽선으로 저장됩니다. 다른 프로그램은 이를 둘러싼 사각형으로 열며, 다른 프로그램에서 잘린 뷰포트는 여기서 사각형으로 열립니다. DXF R12는 사각형만 보존합니다. |
| 걸침 다각형을 사용한 {{cmd:STRETCH}} | 하나 이상의 걸침 윈도우를 사용하십시오. |
| {{cmd:PEDIT}} 정점 편집(명령행에서 한 번에 정점 하나씩) | 그립, 그리고 {{ui:속성}}의 정점 목록(모든 정점, 폭, 벌지). PEDIT의 나머지 기능은 구현되어 있습니다. [스플라인 및 폴리선](topic:splines)을 참조하십시오. |
| 타원과 스플라인에 대한 {{cmd:BREAK}}, {{cmd:LENGTHEN}}, {{cmd:OFFSET}}, {{cmd:TRIM}}, {{cmd:EXTEND}}, {{cmd:FILLET}} 및 {{cmd:JOIN}} | 스플라인은 {{cmd:EXPLODE}}하거나 {{cmd:PEDIT}}로 처리하여, 이 명령들이 사용할 수 있는 폴리선으로 만드십시오. |
| 폴리선의 호 세그먼트와 바로 옆 세그먼트 사이의 모깎기 및 모따기; 선을 폴리선에 결합하는 모깎기 | 폴리선을 {{cmd:EXPLODE}}한 다음 조각들에 모깎기를 적용하십시오. 모깎기 호는 별도의 객체로 추가됩니다. |
| 자르기와 연장: 투영(Project) 옵션(3D)과 폴리선 호 끝 연장 | 도면 평면에서 자르십시오. 호 끝의 경우, 폴리선을 분해하거나 호를 다시 그리십시오. |
| OLE 객체: 삽입, 실행 또는 편집; DWG 파일에 있는 위치에 맞춘 표시; 메타파일 그림 | [그림](topic:pictures#objects-from-other-programs-ole)을 참조하십시오. DXF의 객체는 비트맵이나 이름표가 붙은 테두리로 표시됩니다. DWG의 객체는 보존되며 제자리에 그려지지는 않습니다(OLELIST는 객체를 나열하고, 지정한 곳에 그림 사본을 배치합니다). |
| 단락 문자에서 서식 코드(굵게, 쌓인 분수, 단어별 색) 입력; Helvetica 계열 글꼴 외의 글꼴; 단 구성 | 파일에서 들어온 서식은 유지, 그리기, 저장됩니다(문자 참조). 새 단락 문자는 하나의 높이와 색을 가집니다. |
| 회전된 상태에서 편집하는 단락 문자 | 편집기는 수평으로 열리며, 문자는 회전을 유지합니다. |
| DXF에 다중 지시선 객체로 저장되는 다중 지시선 | DWG는 모든 지시선과 블록을 내용으로 포함한 다중 지시선으로 보존합니다. DXF는 그려진 결과(선, 화살촉, 문자 또는 블록)를 보존합니다. |
| 표({{cmd:TABLE}})에서: 셀 안에서 줄 바꿈되는 문자, 여러 부분으로 나뉘는 표, 대화상자에서 표 스타일 자체의 문자 스타일과 행 종류별 색, 스프레드시트 파일(`.xlsx`)과의 데이터 링크 또는 파일을 스스로 읽는 링크 | 셀의 문자는 직접 줄을 나눈 곳에서만 나뉩니다({{key:Alt+Enter}}). 열을 넓히십시오. {{cmd:DATALINK}} 명령은 `.csv` 파일을 읽고, {{cmd:DATALINKUPDATE}} 명령은 파일을 다시 선택하도록 요청합니다. {{cmd:DATAEXTRACTION}} 명령과 {{cmd:COUNTTABLE}} 명령은 도면을 자동으로 따라가지 않는 표를 만듭니다. 다시 실행하십시오(실시간 개수는 {{cmd:BOMTABLE}}). |
| 저장된 파일에서 블록 밖에 따로 보존되는 속성 정의, 여러 줄 속성 | 저장하기 전에 속성 정의를 블록에 넣으십시오. 단독으로 두면 태그를 표시하는 문자로 저장됩니다. |
| 도면층 상태(어떤 도면층이 켜져 있는지 저장하고 복원) | {{cmd:LAYISO}} / {{cmd:LAYUNISO}}를 사용하거나, 도면층을 직접 켜고 끄십시오. |
| 윈도우 다각형과 걸침 다각형 선택, 그리고 저장된 선택 필터 | 울타리(`F`), 윈도우, 걸침, 제거(`R`), 규칙으로 선택하려면 {{cmd:QSELECT}}. |

## 속성 패널

| 아직 만들지 않은 기능 | 지금 대신 할 수 있는 방법 |
|---|---|
| 맞춤 선택 항목, 그리고 선형 및 정렬 치수 이외의 치수에서 문자의 수평 위치와 선 아래 문자 그리기 | 이 값은 객체에 보존되고 속성에 표시되며 저장됩니다. CadCraft는 자체 규칙으로 문자를 배치합니다. |
| 다른 프로그램이 보는 재질 | 저장된 파일에는 CadCraft용 재질 이름이 보존됩니다. 다른 프로그램은 도면층의 재질을 표시합니다. |
| DWG 2000 및 DXF 파일의 투명도 | 다른 프로그램은 해당 객체를 불투명하게 표시합니다. CadCraft는 투명도를 유지합니다. 모든 사용자를 위해서는 DWG 2004 이상으로 저장하십시오. |
| 다른 프로그램에서 만든 해치 링크 | CadCraft는 DWG와 DXF 2000 파일에 자체 링크를 저장하며, 다른 프로그램에서 만든 링크는 읽지 않습니다. `HATCHEDIT`와 링크를 사용하십시오. [해치 및 채우기 영역](topic:hatch)을 참조하십시오. |
| 속성에서 UCS 좌표 | 속성은 세계 좌표를 표시하고, 상태 표시줄과 {{cmd:ID}}는 UCS 좌표를 표시합니다. [뷰를 돌리고 자신의 좌표 사용하기](topic:ucs-and-turned-view)를 참조하십시오. |
| 주석 객체의 각 축척별 개별 위치; 다른 프로그램이 보관하는 축척별 기록 읽기 | 주석 문자나 치수는 축척 목록({{cmd:OBJECTSCALE}})을 가지며, 각 뷰포트는 같은 자리에서 그 축척에 맞는 크기로 표시합니다. 이 목록은 CadCraft 고유의 데이터로 저장됩니다. 다른 프로그램은 객체를 크기가 정해진 하나의 축척으로만 봅니다. 다른 프로그램에서 만든 목록은 읽지 않습니다. [단위, 용지 및 축척](topic:units-papers-scales#annotate-by-scale)을 참조하십시오. |
| 동적 블록의 거리, 각도 또는 뒤집기 변경; 다른 DWG 버전으로 저장하거나 DXF로 저장할 때 동적 상태를 유지하는 동적 블록 | 속성 › {{ui:사용자 정의}}에서 표시 상태를 전환하십시오. 다른 값은 그곳에 읽기 전용으로 표시됩니다. 도면이 들어온 버전의 DWG로 저장하면 동적 상태가 유지됩니다. [동적 블록](topic:dynamic-blocks)을 참조하십시오. |
| 스플라인 맞춤 허용 오차, 차수 6 이상의 스플라인, 3D 스플라인 | 맞춤점과 제어점, 1~5차, 가중치는 구현되어 있습니다. [스플라인 및 폴리선](topic:splines)을 참조하십시오. 스플라인의 높이(Z)는 보존되지 않습니다. |

## 정밀 보조 기능

| 아직 만들지 않은 기능 | 지금 대신 할 수 있는 방법 |
|---|---|
| 명령 간 점에서의 추적, 그리고 추적 설정 대화상자(상대 극좌표 각도, 추가 각도) | {{cmd:POLARANG}}에서 간격을 설정하고, 다음 명령에서 점을 다시 잡으십시오. |
| 그리드에 스냅 | 좌표를 입력하십시오. 그리드는 시각적인 안내일 뿐입니다. |
| 영역 모서리를 지정하는 동안의 호 및 길이 옵션, 그리고 MEASUREGEOM 부피 | {{cmd:PLINE}}으로 외곽선을 그린 다음(호 포함), {{cmd:AREA}} `O`를 입력하십시오. |
| 그립용 동적 입력과 그 옵션 목록(아래 화살표) | 명령행에 옵션이 표시됩니다. |
| 도·분·초 각도, 그라드 또는 측량 방위 | 십진 도로 입력하십시오: 30°30'은 `30.5`입니다. |
| 뷰 관리자 대화상자; 시트에서 저장한 이름 있는 뷰가 그 시트에 다시 나타나는 기능 | {{cmd:NAMEDVIEW}}는 뷰를 나열하고 복원합니다. 저장된 파일에는 뷰가 보존되지만, 시트의 뷰는 첫 번째 시트에 다시 나타납니다. |

## 시트, 치수 및 플롯

| 아직 만들지 않은 기능 | 지금 대신 할 수 있는 방법 |
|---|---|
| 뷰포트 축척, 도면층이나 블록 같은 이름 있는 객체, 하이퍼링크, 시트 번호와 이름을 넘어서는 시트 세트 필드; 다른 프로그램이 갱신하는 필드 객체로 작성된 필드 | {{cmd:FIELD}}는 문자, 속성 및 표 셀에서 날짜, 파일 이름, 시트 번호와 이름 및 개수, 도면 속성({{cmd:DWGPROPS}}), 객체의 면적, 길이 및 기타 속성, 수식을 제공합니다. 다른 프로그램은 CadCraft 필드를 마지막으로 읽은 문자로 표시합니다. CadCraft는 다른 프로그램의 날짜, 파일 이름, 속성, 시트 및 식 필드를 읽고, 다른 종류는 문자로 남깁니다. 뷰포트의 축척은 직접 입력합니다. |
| 현재 치수 스타일 저장 여부; 치수 문자를 자유로운 위치로 끌기 | 도면은 Standard가 현재 상태로 열립니다. 문자는 치수선 위에 놓입니다(DIMTEDIT Left / Right / Center). [치수 크기 설정](topic:dimension-settings)을 참조하십시오. |
| CadCraft가 해석할 수 없는 열린 파일의 편집 가능한 두 줄 각도 치수 | 파일에 그려진 그대로 표시됩니다. 좌표 치수, 호 길이 치수 및 꺾은 반지름 치수는 편집 가능한 치수로 열립니다. |
| 다른 프로그램의 파일로 CTB 읽기 기능 확인(구현되어 있으며, 공개된 설명서를 기준으로 함), 이름 있는 플롯 스타일(STB), 디더, 펜 번호, CTB의 회색조, 플롯 스타일의 적응형 선종류 조정 | {{ui:플롯 스타일 테이블}}에서 표를 만드십시오(색, 회색, 잉크, 선가중치, 선종류, 선 끝과 결합, 색별 채우기 스타일). [플롯 스타일 테이블](topic:plot-pdf#plot-style-tables)을 참조하십시오. |
| 페이지 설정 | {{ui:PDF로 플롯}} 대화상자에서 용지, 축척, 플롯 스타일을 선택하십시오. 시트는 자체 플롯 스타일을 유지합니다. |
| PDF에서 복잡한 글자 모양 처리가 필요한 힌디어 및 기타 문자, 그리고 희귀 표의 문자(유럽 문자, 키릴 문자, 그리스 문자, 히브리 문자, 아랍 문자, 페르시아 문자, 우르두 문자, 태국 문자, 중국어, 일본어 및 한국어 인쇄) | "?"로 인쇄됩니다. |
| 같은 플롯 PDF에 있는 아랍 문자와 중국어, 일본어 또는 한국어 문자 | 플롯에는 글꼴이 하나만 사용되므로, 두 문자 체계 중 하나는 "?"로 인쇄됩니다. |
| 문자 안의 명시적 방향 표시(임베딩, 오버라이드, 아이솔레이트) | 무시됩니다. 각 줄은 문자 자체로만 정렬됩니다. |
| 플롯에서 첨부된 PDF 페이지 안의 그림 | 페이지의 선, 채우기, 문자는 인쇄됩니다. 그림만 있는 페이지는 {{cmd:SCANATTACH}}로 추가하면 그림도 인쇄됩니다. [PDF 언더레이](topic:pdf-underlay#plot-and-save)를 참조하십시오. |
| CadCraft Studio에서 레이저로 작업 보내기(Studio에는 Web Serial이 없음) | G-code를 저장한 뒤 레이저 자체 프로그램으로 보내거나, Chrome 또는 Edge에서 보내십시오. [도면을 레이저로 보내기](topic:laser-cutting#send-from-the-browser)를 참조하십시오. |

## 구속조건과 파라미터

| 아직 만들지 않은 기능 | 지금 대신 할 수 있는 방법 |
|---|---|
| 시트, 블록, 타원, 스플라인 또는 문자에 대한 구속조건 | {{ui:모델}} 탭에서, 선, 폴리선, 원, 호, 점에 구속을 거십시오. |
| 매끄러움(G2), 그리고 폴리선 호의 벌지를 직접 구속 | 접선과 같음. 호 세그먼트는 양 끝을 따라갑니다. |
| 참조(구동되지 않는) 치수 구속조건, 그리고 {{cmd:DCANGULAR}}의 `3Point` | 일반 치수(DIMLINEAR …)는 값을 표시하기만 하고 구동하지는 않습니다. |
| 용지 기준으로 고정 크기인 치수 구속조건, 그리고 이를 플롯하는 것 | 화면에만 표시됩니다. 플롯에는 일반 치수를 추가하십시오. |
| EXPLODE, BREAK, JOIN 등 새 객체를 만드는 명령을 거쳐 유지되는 구속조건, 그리고 잘린 폴리선의 구속조건 | 다시 구속을 거십시오(AUTOCONSTRAIN이 도움이 됩니다). 선, 호, 원에 대한 {{cmd:MIRROR}} 명령과 {{cmd:TRIM}} 명령은 구속을 유지합니다. |
| CadCraft의 디자인 테이블(구성) | 패널에서 파라미터를 변경하십시오. |
| SolidWorks와의 검증된 왕복 작업 | 의존하기 전에 매크로가 만드는 스케치를 확인하십시오. |

## 3D

| 아직 만들지 않은 기능 | 지금 대신 할 수 있는 방법 |
|---|---|
| 필렛, 모따기, 쉘 및 로프트; 올라가는 경로를 따른 스윕(3D 경로) | 호가 포함된 외곽선을 돌출하고, 면을 밀기와 당기기를 하고, 평평한 경로를 따라 회전과 스윕을 하십시오. |
| 위 이외의 방향으로 돌출 | 바닥에 모양을 그린 다음 위 또는 아래로 돌출하십시오(원하면 구배나 경로를 따라). 그다음 솔리드를 회전하십시오. |

| 솔리드 복사 및 붙여넣기 | 3D 탭에서 {{cmd:COPY}}를 사용하십시오. 클립보드에는 2D 객체만 들어갑니다. |
| 단면, 솔리드의 이후 변경을 따라가는 뷰, 플롯된 시트의 음영 솔리드 | {{cmd:VIEWBASE}}는 평면 뷰(스냅샷)를 배치합니다. 솔리드를 변경한 뒤 다시 실행하십시오. |
| 재질, 텍스처 및 조명 설정 | 시각 스타일: 음영, 모서리, 숨은 선, 와이어프레임, X-ray. |
| 플롯되는 지도 레이어, 시트의 뷰포트와 3D 탭의 지도 레이어; 도면과 함께 저장된 파일의 그림; DWG 2000–2007 및 DXF R12에서 다른 프로그램용으로 기록되는 도면의 위치 | 지도 레이어는 화면에서 모델 공간 아래에 표시됩니다. 좌표계와 레이어 목록은 도면과 함께 저장됩니다. [도면 아래의 지도 레이어](topic:map-layers)를 참조하십시오 |
| 6백만 점 또는 512 MB를 넘는 E57 스캔, 스캐너 제조사 고유 파일(RCP, RCS, FLS, LGS, TZF, ZFS), 도면과 함께 저장되거나 플롯된 포인트 클라우드, 3D 탭에서 클라우드에 스냅, 모델 탭의 수직(단면) 슬라이스 | 큰 스캔이나 제조사 고유 스캔은 LAS 또는 LAZ로 내보내십시오([포인트 클라우드 형식](topic:point-cloud-formats)). 도면을 열 때마다 클라우드를 첨부하십시오. 모델 탭에서 평면 슬라이스를 따라 추적하십시오. [포인트 클라우드 위에 준공 선 추적하기](topic:point-clouds)를 참조하십시오. |
| 스캔 정합: 스캔에서 타깃(구, 체커보드)을 자동으로 찾기, 모든 스캔을 함께 풀기(번들 조정), 축척, 모델에 대한 정합 | 일치하는 점을 지정하거나 타깃 좌표를 입력한 다음, ICP로 한 번에 한 스캔씩 다듬으십시오. [여러 스캔을 하나로 정합하기](topic:register-scans)를 참조하십시오. |
