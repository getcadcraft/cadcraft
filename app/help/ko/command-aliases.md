## 배울 내용

{{cmd:LINE}}의 `LL`처럼, 명령에 나만의 짧은 이름을 추가하는 방법을 하나의 텍스트 파일에서 설명합니다.

## 별칭 추가하기

1. {{ui:뷰}} › {{ui:더보기}} › {{ui:별칭 편집…}}을 열거나, `ALIASEDIT` 명령을 입력하고 {{key:Enter}}를 누르십시오.
2. 별칭, 쉼표, 그리고 별표 뒤에 명령을 적어 한 줄을 추가하십시오:

```
LL,     *LINE
```

3. {{ui:저장}}을 누르십시오. 명령행에 사용 중인 별칭 수가 표시됩니다.
4. `LL`을 입력하고 {{key:Enter}}를 누르십시오: LINE이 시작됩니다.

별칭은 CadCraft의 기본 별칭 위에 놓입니다. 같은 이름의 기본 별칭보다 사용자의 줄이 우선합니다. 줄을 지우면 기본 별칭이 돌아옵니다.

## 거부되는 줄

편집기는 입력하는 동안 문제마다 줄 번호와 함께 목록을 표시합니다.

- 명령이 없습니다.
- 별칭이 이미 명령 이름입니다(`LINE, *CIRCLE`은 `LINE` 명령을 가립니다).
- 줄이 `ALIAS, *COMMAND` 형식이 아닙니다.
- 같은 별칭이 두 줄에 있습니다(나중 줄이 우선합니다).

`NOTEPAD, START, 1, *File to edit: ,`처럼 컴퓨터의 프로그램을 시작하는 줄은 참고 메시지와 함께 건너뜁니다. 브라우저의 앱은 프로그램을 시작할 수 없기 때문입니다.

## 다른 프로그램의 별칭 가져오기

1. 별칭 편집기에서 {{ui:가져오기 .pgp…}}를 누르고 파일을 고르십시오. `.pgp` 파일을 도면에 끌어다 놓을 수도 있습니다.
2. 나열된 문제를 확인하십시오(CadCraft에 없는 명령은 거부되고, 나머지는 작동합니다).
3. {{ui:저장}}을 누르십시오.

{{ui:내보내기 .pgp}}는 CadCraft의 별칭과 사용자 별칭을 같은 형식의 파일 하나로 저장합니다.

## 파일 다시 불러오기

`REINIT` 명령을 입력하고 {{key:Enter}}를 누르면 별칭 파일을 다시 적용합니다. 파일은 이 브라우저에 보관됩니다. 데스크톱 앱은 자체 폴더에 보관하며, 클라우드 서비스는 동기화합니다.

## 명령의 키보드 단축키

별칭은 입력하는 것이고, 단축키는 키입니다. 명령에 나만의 키를 지정하려면:

1. {{ui:뷰}} › {{ui:더보기}} › {{ui:키보드 단축키…}}를 누르거나, `KEYS` 명령을 입력하고 {{key:Enter}}를 누르십시오.
2. {{ui:키}} 입력란을 클릭하고 키를 누르십시오(예: {{key:Alt+Shift+C}}).
3. {{ui:실행}}에 명령을 쓰고, 원하면 그 뒤에 입력할 내용도 쓰십시오: `CIRCLE` 또는 `ZOOM E`.
4. {{ui:추가}}를 누르십시오.

단축키에는 글자나 숫자와 함께 {{key:Mod}} 또는 {{key:Alt}} 키를 써야 하거나, 비어 있는 기능 키({{key:F2}}, {{key:F4}}, {{key:F5}}, {{key:F6}}, {{key:F9}})를 써야 합니다. CadCraft, 앱, 또는 브라우저가 이미 쓰는 키와, 내 도구 버튼이 쓰는 키([나만의 버튼](topic:my-tools) 참조)는 거부되며, 입력란에 그 이유가 표시됩니다. 단축키는 이 브라우저(또는 데스크톱 앱)에 보관되며, {{ui:제거}}를 누르면 하나씩 지워집니다.
