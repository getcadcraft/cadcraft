## 학습 내용

명령에 나만의 짧은 이름을 추가하는 방법을 설명합니다. 예를 들어 {{cmd:LINE}}의 짧은 이름으로 `LL`을 지정할 수 있으며, 모든 설정은 텍스트 파일 하나에 보관합니다.

## 별칭 추가

1. {{ui:View}} › {{ui:More}} 메뉴에서 {{ui:Edit aliases…}} 항목을 엽니다. 또는 {{cmd:ALIASEDIT}}를 입력하고 {{key:Enter}}를 누릅니다.
2. 별칭, 쉼표, 그리고 별표 뒤의 명령을 한 줄로 입력합니다:

```
LL,     *LINE
```

3. {{ui:Save}} 버튼을 클릭합니다. 명령행에 사용 중인 나만의 별칭 개수가 표시됩니다.
4. `LL`을 입력하고 {{key:Enter}}를 누릅니다. LINE이 시작됩니다.

나만의 별칭은 CadCraft에 기본으로 들어 있는 별칭 위에 놓입니다. 같은 이름의 기본 별칭보다 내 줄이 우선하며, 내 줄을 지우면 기본 별칭이 다시 적용됩니다.

## CadCraft가 거부하는 줄

별칭 편집기는 입력하는 동안 각 문제를 줄 번호와 함께 나열합니다:

- 명령이 없는 경우;
- 별칭이 명령의 이름 자체인 경우 (`LINE, *CIRCLE`은 LINE을 가리게 됩니다);
- 줄이 `별칭, *명령` 형식이 아닌 경우;
- 같은 별칭이 두 줄에 있는 경우 (뒤의 줄이 적용됩니다).

`NOTEPAD, START, 1, *File to edit: ,`처럼 컴퓨터에서 프로그램을 시작하는 줄은 안내 메시지와 함께 건너뜁니다. 브라우저에서 실행되는 앱은 프로그램을 시작할 수 없기 때문입니다.

## 다른 프로그램의 별칭 가져오기

1. 별칭 편집기에서 {{ui:Import .pgp…}} 버튼을 클릭하고 파일을 선택합니다. `.pgp` 파일을 도면에 끌어다 놓을 수도 있습니다.
2. 나열된 문제를 확인합니다 (CadCraft에 없는 명령은 거부되며, 나머지는 작동합니다).
3. {{ui:Save}} 버튼을 클릭합니다.

{{ui:Export .pgp}}는 CadCraft의 별칭과 나만의 별칭을 같은 형식의 파일 하나로 저장합니다.

## 파일 다시 불러오기

{{cmd:REINIT}}를 입력하고 {{key:Enter}}를 누르면 별칭 파일을 다시 적용합니다. 파일은 이 브라우저에 보관되며, 데스크톱 앱은 자체 폴더에 보관하고, 클라우드 서비스는 동기화합니다.

## 명령 옵션에 쓰는 문자

별칭은 명령의 이름을 지정합니다. 명령 옵션에 답하는 문자를 바꾸려면 (예: {{cmd:ARRAY}}의 극좌표용 `P`), [명령 옵션에 고유 문자 지정하기](topic:option-letters)를 참조하십시오.

## 모든 명령의 키보드 단축키

별칭은 입력하는 것이고, 단축키는 키입니다. 명령에 나만의 키를 지정하려면:

1. {{ui:View}} › {{ui:More}} 메뉴에서 {{ui:Keyboard shortcuts…}} 항목을 클릭하거나, `KEYS`를 입력하고 {{key:Enter}}를 누릅니다.
2. {{ui:Key}} 입력란을 클릭하고 키를 누릅니다. 예: {{key:Alt+Shift+C}}.
3. {{ui:Runs}}에 명령을 입력하고, 원하면 명령 뒤에 입력할 내용도 씁니다: `CIRCLE` 또는 `ZOOM E`.
4. {{ui:Add}} 버튼을 클릭합니다.

단축키에는 {{key:Mod}} 또는 {{key:Alt}}와 문자 또는 숫자, 또는 비어 있는 기능 키({{key:F2}}, {{key:F4}}, {{key:F5}}, {{key:F6}}, {{key:F9}})가 필요합니다. CadCraft, 앱 또는 브라우저가 이미 사용하는 키와, 내 도구 버튼([나만의 버튼](topic:my-tools) 참조)이 쓰는 키는 거부되며, 입력란에 그 이유가 표시됩니다. 단축키는 이 브라우저(또는 데스크톱 앱)에 보관되며, {{ui:Remove}}를 누르면 단축키가 제거됩니다.
