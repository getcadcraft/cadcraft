AutoCAD, 또는 같은 모델을 바탕으로 한 프로그램을 써 보았다면, 여기서도 대부분의 것이 그대로 작동합니다: 명령행, `L`, `C`, `TR`, `O` 같은 별칭, 반복하려면 Enter 또는 Space, 창과 걸침 선택, F3의 객체 스냅, F8의 직교, 배치와 뷰포트가 있는 모델 공간. 이 페이지는 그대로 대응되는 것과, 사람들이 실수하기 쉬운 차이점을 나열합니다. 앞부분을 훑어보더라도 뒷부분은 꼭 읽으십시오.

## 그대로 대응되는 것

| 습관 | CadCraft에서 |
|---|---|
| `L`, `PL`, `C`, `A`, `REC`, `POL`, `EL`, `PO`, `T`, `DT` | 같은 명령, 같은 별칭 |
| `M`, `CO`, `RO`, `SC`, `MI`, `O`, `TR`, `EX`, `F`, `X`, `E` | 같음 |
| `DLI`, `DAL`, `DAN`, `DRA`, `DDI`, `DCO`, `DBA` | 같은 치수 명령 |
| 명령행에 입력한 `DIMSCALE`, `DIMTXT`, `DIMASZ`, `DIMDEC`, `DIMGAP`, `DIMEXE`, `DIMEXO` | 같음, 새 치수에 대해 |
| `B`로 블록 만들기, `I`로 삽입, `PU`로 정리 | 같음(정리는 사용되지 않은 블록만 제거) |
| `LAYOUT`, `MV`, `PLOT`, `DI`, `ID`, `LI`, `Z` 다음 `E` 또는 `W` | 같음 |
| 스크립트나 습관에서 `_LINE` 또는 `-LAYER` 입력 | 앞의 `_`, `-`, `.`, `'`는 무시됩니다 |
| 빈 프롬프트에서 Enter 또는 Space | 마지막 명령을 반복합니다. 같음 |
| Esc는 취소합니다. 다시 Esc를 누르면 선택이 해제됩니다 | 같음 |
| `@dx,dy`, `@d<a`, 동쪽에서 반시계 방향으로 입력한 각도 | 같음 |
| 왼쪽에서 오른쪽으로 창, 오른쪽에서 왼쪽으로 걸침, 클릭-클릭. 누르고 끌면 올가미. Space는 창 / 걸침 / 울타리를 순환(LASSOMODE) | 같음 |
| 명령 전에 먼저 선택(명사-동사) | 같음. 끝난 명령은 선택을 해제합니다 |
| 객체 선택 프롬프트에서 `ALL`과 `L` | 같음 |
| Shift+클릭으로 선택에서 제거 | 같음. 설정으로 클릭이 선택을 대신하게 할 수 있습니다(PICKADD 0처럼): [CadCraft 설정](topic:settings) 참조 |
| Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+Shift+V(COPYCLIP, CUTCLIP, PASTECLIP, PASTEORIG), COPYBASE | 같은 명령과 키. 붙여넣기는 PASTECLIP처럼 복사본을 왼쪽 아래 모서리 기준으로 배치합니다 |
| F3 객체 스냅, F7 격자, F8 직교 | 같은 키 |
| 휠을 두 번 클릭하여 범위로 줌 | 같음 |
| 거울 대칭된 텍스트도 읽을 수 있음 | 같음(MIRRTEXT 0처럼) |
| Ctrl+Z, Ctrl+Y, Ctrl+S, Ctrl+O, Ctrl+P, Ctrl+A | 같음. Mac에서는 Command도 작동합니다 |

[명령 참조](topic:commands)에 모든 명령과 별칭이 나열되어 있습니다.

:::tip
AutoCAD의 리본이 익숙하다면, {{ui:설정}} › {{ui:CadCraft}} › {{ui:메뉴, 키, 마우스}}에서 {{ui:제도 클래식}} 메뉴 스타일을 고르십시오. 같은 명령행 위에 홈, 삽입, 주석, 매개변수, 뷰, 관리, 출력 탭이 나타나며, 가운데 버튼은 초점 이동, 오른쪽 클릭은 Enter입니다. [메뉴, 키, 마우스](topic:menus-keys-and-mouse)를 참조하십시오.
:::

[명령 맵](topic:command-map)은 CadCraft의 모든 명령과 짧은 이름을 나열하고, [요약표](topic:cheat-sheet)는 가장 많이 쓰게 될 40개를 보여 줍니다(한 페이지 PDF로도 제공).

## 사람들이 헷갈리는 차이점

### 입력한 점은 절대 좌표입니다

동적 입력이 켜져 있으면 다른 프로그램은 두 번째 점으로 입력한 `100,0`을 상대 좌표로 취급합니다. **CadCraft의 명령행은 그렇지 않습니다**: 여기서 `x,y`는 항상 원점에서 측정됩니다. {{ui:동적}}({{key:F12}})이 켜져 있으면 대신 그 입력란을 사용하십시오: 거리, {{key:Tab}}, 각도. "마지막 점에서 오른쪽으로 100"을 뜻하려면 `@100,0`을 쓰거나, 십자선을 올바른 방향으로 옮기고 `100`만 입력하십시오.

### Shift는 스냅을 건너뛰며, 직교를 켜지 않습니다

클릭하는 동안 Shift를 누르고 있으면 그 클릭에 대해 객체 스냅을 무시합니다. 직교를 잠시 켜지는 않습니다. F8 또는 {{ui:직교}} 버튼을 사용하십시오.

### 오른쪽 클릭은 항상 Enter입니다

오른쪽 클릭 메뉴는 없습니다. 도면에서의 오른쪽 클릭은 Enter입니다. 명령을 끝내고, 선택을 마치고, 마지막 명령을 반복합니다. 그립 이동이나 선택 상자 중에는 대신 취소합니다. 오른쪽 버튼으로 끌어 초점을 이동하십시오.

### 스페이스바로 초점 이동은 안 됩니다

Space는 Enter이므로, Space를 누른 채 끌어도 초점이 이동하지 않습니다. 가운데 버튼이나 오른쪽 버튼으로 초점을 이동하거나, 휠로 축소했다가 다른 위치에서 다시 확대하십시오.

### 자르기와 연장

자르기와 연장은 빠른 모드로 시작합니다. 보이는 모든 객체가 자르기 가장자리 또는 경계가 되고, 포인터 아래의 조각이 제거될 부분을 보여 주며, 끌어서 지나간 경로는 지나가는 모든 조각을 자르고, 아무것도 교차하지 않는 객체는 지워집니다. {{key:Shift}} 키로 자르기와 연장을 전환합니다. `O`를 누르면 표준 모드로 바뀝니다(먼저 가장자리를 고르십시오). 울타리는 `F`, 걸침은 `C`입니다. `E`는 EDGEMODE이고, `R`은 지우기입니다. `P`(투영) 옵션은 없습니다: CadCraft는 도면 평면에서 자릅니다.

### 모깎기와 모따기

{{cmd:FILLET}} 및 {{cmd:CHAMFER}} 명령은 익숙한 옵션을 지원합니다: 실행 취소, 폴리선, 반지름(또는 거리, 각도, 방법), 자르기와 여러 개, 그리고 날카로운 모서리를 위한 Shift+클릭. 폴리선과 선 사이의 모깎기는 호를 폴리선에 합치지 않고 자체 객체로 추가하며, 호 세그먼트 옆의 폴리선 모서리는 그대로 둡니다.

### 단락 텍스트와 한 줄 텍스트

`T`, `MT`, `MTEXT` 명령은 제자리에 입력하는 단락 텍스트이며, 너비, 줄 간격, 정렬을 지정합니다. `DT`와 `DTEXT`는 익숙한 한 줄 텍스트입니다. 문자 스타일이나 단은 없으며, 아직 텍스트 안에 서식(굵게, 쌓인 분수)을 입력할 수 없습니다. 파일로 들어온 서식은 유지되고, 그려지고, 저장됩니다([텍스트와 레이블 추가](topic:text#formatting-inside-paragraph-text-from-other-programs) 참조). 모든 것은 Helvetica 계열 글꼴로 그려집니다.

### 저장은 "사본 내려받기"를 뜻합니다

{{key:Mod+S}}, `SAVE`, `QSAVE`는 도면의 형식으로 사본을 내려받습니다: DWG로 연 파일은 DWG로, DXF 파일은 DXF로 저장됩니다. 브라우저에서는 제자리에서 덮어쓰지 않으며, 연 파일은 결코 바뀌지 않습니다. CadCraft Studio에서는 {{key:Mod+S}}가 연 파일에 다시 씁니다.

`SAVEAS`({{key:Mod+Shift+S}})는 파일 탐색기가 아니라 작은 대화상자입니다. {{ui:DWG}}({{ui:버전}}: AutoCAD 2000부터 2018까지), {{ui:DXF R12}} 또는 {{ui:DXF 2000}}을 고르고 {{ui:저장}}을 누르십시오. 내려받기 위치는 브라우저가 정합니다. `DXFOUT`은 항상 DXF R12를 내려받습니다.

DWG로 연 파일은 들어왔던 버전으로 저장되며, 새 도면은 다른 것을 고르지 않는 한 AutoCAD 2000 형식으로 저장됩니다. 시트, 치수, 해치 패턴은 유지됩니다. [파일: 열리는 것과 저장되는 것](topic:files#saving) 참조.

### 도면층: 더 간단함

- 모든 도면층 변경(켜기, 동결, 잠금, 색상, 플롯, 선 종류, 선가중치, 현재 도면층)은 실행 취소 한 단계입니다.
- CadCraft에서 끄기와 동결은 효과가 같습니다.
- 한 뷰포트에서 동결된 도면층은 그곳에서 계속 동결된 상태로 남습니다: 화면, 플롯, 그리고 DWG 또는 DXF로 저장할 때 모두 그렇습니다.
- 뷰포트가 도면층을 자체 색상, 선 종류, 선가중치, 투명도로 보여 주면, 화면, 플롯, 저장된 DWG에서도 그대로 유지됩니다(DXF는 도면층 자체 설정을 유지하며, 저장할 때 이를 알려 줍니다). 뷰포트별로 바꾸는 기능은 아직 만들지 않았습니다.
- 도면층 속성 관리자와 도면층 상태는 없습니다. {{cmd:RENAME}}, {{cmd:LAYMRG}}, {{cmd:LAYDEL}}은 도면층의 이름을 바꾸고, 병합하고, 삭제합니다. 선 종류와 선가중치는 오른쪽 패널에서 설정합니다([선가중치와 선 종류](topic:units-papers-scales#line-weights-and-linetypes) 참조). {{cmd:LAYISO}}, {{cmd:LAYOFF}}, {{cmd:LAYFRZ}}, {{cmd:LAYMCUR}}는 고르기로 작동합니다.
- DXF R12로 저장하면 도면층 이름이 대문자로 기록됩니다. DWG는 입력한 그대로 유지합니다.

### 치수 스타일

`DIMSTYLE`은 이름 있는 스타일을 위한 관리자를 엽니다(새로 만들기, 수정, 현재로 설정, 비교, 적용). `DIMSCALE`과 다른 설정은 여전히 새 치수가 쓸 값을 바꾸며, 각 치수는 자체 크기를 유지합니다. 그 크기는 특성 패널에서도 바꿀 수 있습니다. 현재 스타일은 파일에 저장되지 않습니다. 치수는 도면의 길이 형식(십진, 또는 {{cmd:UNITS}}로 설정한 피트와 인치)을 따르거나, 자체 {{ui:형식}}을 따릅니다. [치수 크기 설정](topic:dimension-settings) 참조.

### 플롯은 더 간단함

플롯 스타일 테이블은 CTB 파일과 마찬가지로 색상 기준으로 작동합니다. 단색, 색상, 회색조가 내장되어 있으며, 직접 만들 수 있고, 각 시트가 자체 테이블을 유지합니다. CTB 파일 읽기는 공개된 명세를 바탕으로 만들었으며, 우리가 만든 파일에서만 시험했습니다. 이름 있는 플롯 스타일 테이블(STB)와 페이지 설정은 아직 만들지 않았습니다. 선은 선가중치대로, 나머지는 펜 하나의 너비로 인쇄됩니다. 시트는 자체 용지에 1:1로 플롯되며, 모델은 선택한 축척으로 또는 맞춤 축척으로 플롯됩니다. [PDF로 플롯](topic:plot-pdf) 참조.

### 뷰포트 안에서 작업하기

익숙한 방식 그대로입니다. 뷰포트 안을 두 번 클릭하거나({{cmd:MSPACE}} 명령을 입력) 뷰포트를 통해 모델에서 작업하고, 뷰포트 밖을 두 번 클릭하면({{cmd:PSPACE}}) 시트로 돌아갑니다. 뷰포트 안에서 초점 이동과 줌은 뷰포트가 보여 주는 내용을 바꿉니다. 단, 표시가 잠겨 있으면 시트가 움직입니다. 도면 아래의 탭을 클릭해도 뷰포트를 나갑니다. [뷰포트를 통해 모델에서 작업하기](topic:sheets-and-viewports#work-on-the-model-through-a-viewport) 참조.

### 추적과 동적 입력은 지원, 격자 스냅은 아직

격자는 보기 전용입니다. 점은 격자에 스냅되지 않습니다(F9 스냅 모드는 없습니다). 극좌표 추적({{key:F10}}, 단계는 {{cmd:POLARANG}}으로 설정)과 객체 스냅 추적({{key:F11}}: 스냅 점 위에 잠시 머물러 취득)은 익숙한 방식으로 작동합니다. [객체에 스냅](topic:object-snaps#polar-tracking) 참조. 동적 입력({{key:F12}})은 십자선 옆에 거리와 각도(또는 X와 Y)를 보여 줍니다. [좌표 및 거리 입력](topic:coordinate-entry#dynamic-input) 참조.

### 피트와 인치

{{ui:길이 형식}}에서 {{ui:건축}} 또는 {{ui:공학}}을 고르거나({{cmd:UNITS}} 명령을 입력), 익숙한 방식으로 길이를 입력하십시오: `12'6"`, `12'6-1/2"`. 분수 앞에는 공백이 아니라 하이픈을 쓰십시오. Space는 Enter입니다. 시트와 플롯이 건축 축척을 제공하도록 {{ui:단위}}도 {{ui:인치}}로 설정하십시오. 이 형식은 저장된 DWG와 DXF 파일에 유지됩니다. [피트와 인치](topic:units-papers-scales#feet-and-inches-and-fractions) 참조.

### 복사와 붙여넣기는 CadCraft 안에서만

{{key:Mod+C}}, {{key:Mod+X}}, {{key:Mod+V}}는 한 도면 안에서, 도면 사이에서, 같은 브라우저의 CadCraft 탭 사이에서 객체를 복사, 잘라내기, 붙여넣기 합니다. 클립보드는 CadCraft 고유의 것입니다. CadCraft 객체를 다른 프로그램에 붙여넣을 수 없고, 다른 프로그램의 객체를 CadCraft에 붙여넣을 수도 없습니다. 다른 단위의 도면에서 붙여넣어도 크기가 바뀌지 않으므로, 이후 {{cmd:SCALE}}을 사용하십시오. {{key:Mod+D}}는 포인터를 따라 움직이는 복제이며, CadCraft만의 기능입니다. [복사, 붙여넣기, 복제](topic:copy-paste) 참조.

### 사용할 수 없는 브라우저 키

웹 페이지는 브라우저의 {{key:Mod+N}}, {{key:Mod+W}}, {{key:Mod+T}}를 가져갈 수 없습니다. 이 키는 창과 탭을 열고 닫기 때문입니다. {{ui:새로 만들기}} 버튼을 쓰거나 `NEW` 명령을 입력하십시오. [키, 마우스, 트랙패드](common:keys) 참조.

## 아직 없는 명령

{{cmd:TABLE}}은 아직 만들지 않았습니다. 입력하면 "알 수 없는 명령"이라고 표시됩니다. ({{cmd:PEDIT}}, {{cmd:SPLINE}}, {{cmd:SPLINEDIT}}, {{cmd:XREF}} 명령은 만들어져 있습니다.) [아직 만들지 않은 기능](topic:not-built-yet)에서 지금 대신 할 수 있는 것을 나열합니다.
