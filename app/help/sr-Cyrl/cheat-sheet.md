Укуцајте кратки назив (алиас) и притисните Enter, или кликните алатку. Esc отказује. Enter на празном реду понавља последњу команду.

**Штампајте га:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (једна A4 страна; на папиру Леттер штампајте уз „прилагоди страници“).

## Цртање

| Унос | Команда | Шта ради |
|---|---|---|
| `L` | {{cmd:LINE}} | Цртај праве линије |
| `PL` | {{cmd:PLINE}} | Цртај повезан ланац линија и лукова |
| `C` | {{cmd:CIRCLE}} | Цртај круг (центар и полупречник) |
| `A` | {{cmd:ARC}} | Цртај лук |
| `REC` | {{cmd:RECTANG}} | Цртај правоугаоник од два угла |
| `POL` | {{cmd:POLYGON}} | Цртај правилан полигон |
| `EL` | {{cmd:ELLIPSE}} | Цртај елипсу |
| `DT` | {{cmd:TEXT}} | Напиши један ред текста |
| `T` | {{cmd:MTEXT}} | Напиши текст који се прелама (пасус) |
| `H` | {{cmd:HATCH}} | Попуни површину узорком |

| Унос | Команда | Шта ради |
|---|---|---|
| `M` | {{cmd:MOVE}} | Премести објекте |

| `RO` | {{cmd:ROTATE}} | Окрени објекте око тачке |
| `SC` | {{cmd:SCALE}} | Учини објекте већим или мањим |
| `MI` | {{cmd:MIRROR}} | Пресликај објекте преко линије |
| `O` | {{cmd:OFFSET}} | Нацртај паралелну копију на растојању |
| `TR` | {{cmd:TRIM}} | Скрати објекте до места где их секу други |
| `EX` | {{cmd:EXTEND}} | Продужи објекте до других |
| `F` | {{cmd:FILLET}} | Заобли угао луком |
| `CHA` | {{cmd:CHAMFER}} | Одсеци угао правом ивицом |
| `E` | {{cmd:ERASE}} | Избриши објекте |
| `X` | {{cmd:EXPLODE}} | Растави блок или полилиније на делове |
| `S` | {{cmd:STRETCH}} | Помери крајеве унутар прозора укрштања |
| `AR` | {{cmd:ARRAY}} | Копирај у мрежи или кругу |
| `J` | {{cmd:JOIN}} | Споји линије и лукове у један објекат |
| `BR` | {{cmd:BREAK}} | Пресеци објекат на два дела или извади део |

| `DLI` | {{cmd:DIMLINEAR}} | Котирај водоравно или усправно |

## Тастери

Ctrl (Cmd на Мац-у): З опозови · Y понови · С сачувај · П штампај.  F3 хватање објекта · F8 ортогонално · F10 поларно.  Спаце или Enter понавља последњу команду · точкић миша зумира · превлачење точкића помера поглед
