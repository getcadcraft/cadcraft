အခြားပရိုဂရမ်များမှ ပုံဆွဲများသည် ၎င်းတို့၏ text style များတွင် **SHX ဖောင့်များ** ကို အမည်ပေးလေ့ရှိပြီး DWG က ၎င်းတို့ကို မသယ်ဆောင်ပါ။ ဖောင့်မပါလျှင် CadCraft သည် ထိုစာသားကို ၎င်း၏ကိုယ်ပိုင် မျက်နှာပြင်ဖြင့် ဆွဲသည်၊ ၎င်းသည် သာမန် Latin စာသားအတွက် ကောင်းသော်လည်း ရိုးရိုး စာလုံးကုဒ်များကို အခြား စာလုံးပုံသဏ္ဍာန်များသို့ ပုံဖော်သော ဟောင်းသော ဖောင့်များ (ဥပမာ legacy Persian annotation) အတွက် မသင့်ပါ။

CadCraft သို့ ဖောင့်များ ပေးပါ၊ ထိုသို့ဆိုလျှင် စာသားကို ထိုဖောင့်များဖြင့် ဆွဲသည်။

## ဖောင့်များ load လုပ်ရန်

{{cmd:SHXFONTS}} (`SHX`) ကို ရိုက်ပြီး ရွေးပါ:

- {{ui:ဖိုင်တွဲ}} (CadCraft Studio): ဖိုင်တွဲတစ်ခု ရွေးပါ။ ၎င်းထဲရှိ `.shx` ဖိုင်တိုင်းကို ယခု ဖတ်သည်၊ CadCraft စတင်တိုင်း ထပ်ဖတ်သည်။
- {{ui:ဖိုင်များ}} (browser): `.shx` ဖိုင် တစ်ခု သို့မဟုတ် အများအပြား ရွေးပါ။ ၎င်းတို့ကို ဤ browser တွင် ထားပြီး ဘယ်တော့မှ မတင်ပါ။
- {{ui:စာရင်း}}: load ထားသော ဖောင့်များ၊ နှင့် ဖွင့်ထားသော ပုံဆွဲက အမည်ပေးထားသော်လည်း သင် မ load လုပ်ရသေးသော ဖောင့်များ။
- {{ui:ဖယ်ရှားရန်}} နှင့် {{ui:ရှင်းရန်}}: ဖောင့်တစ်ခုကို မှတ်ဉာဏ်မှ ဖယ်ရှားပါ၊ သို့မဟုတ် အားလုံး။

CadCraft သည် တတိယအစုအဖွဲ့ ဖောင့်များကို ထည့်သွင်းနိုင်သည် မဟုတ်ပါ၊ ထို့ကြောင့် ဘယ်တော့မှ မပို့ပါ: ၎င်းတို့သည် သင်ထံမှ လာသည်။ ပုံဆွဲက ၎င်း၏ ဖောင့်များကို အမည်ပေးရုံသာ ဖြစ်ပြီး ၎င်းတို့၏ မိတ္တူ မထားပါ။

## ဖြစ်ပေါ်ပုံ

text style ၏ ဖောင့်အမည်ကို load ထားသော ဖောင့်နှင့် အမည်ဖြင့် ကိုက်ညီစေသည်၊ စာလုံးအကြီးအသေး၊ ဖိုင်တွဲ နှင့် `.shx` ကို လျစ်လျူရှုပြီး (`SIMPLEX.SHX` က `simplex` ကို ရှာသည်)။ ထို style ရှိ စာသားကို မျဉ်းများအဖြစ် မျက်နှာပြင်၊ plot နှင့် PDF တွင် စာသား၏ ကိုယ်ပိုင်နေရာ၊ အမြင့်၊ လှည့်ပတ်မှု၊ width factor နှင့် oblique angle ဖြင့် ဆွဲသည်။ ၎င်း၏ အကျယ်သည် ဖောင့်၏ ကိုယ်ပိုင်ဖြစ်သောကြောင့် {{ui:Center}} နှင့် {{ui:Right}} ညှိခြင်း၊ wrap နှင့် ရွေးချယ်ခြင်းတို့ သင်မြင်သည်နှင့် ကိုက်ညီသည်။ ဖောင့် မ load ထားသော style သည် built-in မျက်နှာပြင်ကို ထိန်းသည်၊ သင် မ load လုပ်ရသေးသော ဖောင့်များကို အမည်ပေးသော ပုံဆွဲကို ဖွင့်လျှင် command line က ထိုအကြောင်း ပြောသည်။

Standard style လည်း ထည့်ရေတွက်သည်: Standard style က ၎င်း၏ကိုယ်ပိုင် ဖောင့်ကို အမည်ပေးသော ပုံဆွဲသည် ထိုဖောင့်ကို ဆက်ထိန်းသည်။

## မြင်ကွင်းအစီအစဉ်တွင် ရှိပြီးသား ဖောင့်များ

ဟောင်းသော Persian နှင့် Arabic SHX ဖောင့်များစွာသည် မျက်နှာပြင်အတွက် ပုံသွင်းပြီးသား စာလုံးများကို ဘယ်မှ ညာသို့ ဆွဲသည်၊ ထို့ကြောင့် ယုတ္တိအစီအစဉ်ဖြင့် ရိုက်သော စာသားသည် နောက်ပြန် ထွက်လာသည်။ {{cmd:SHXFONTS}} ကို ရိုက်ပြီး {{ui:Reverse}} ကို ရွေးကာ ဖောင့်အမည်ကို ပေးပါ: ထိုအခါ ၎င်း၏ စာသားကို နောက်ဆုံး စာလုံးက ဦးစွာ အစီအစဉ်ချသည်။ ပြန်ဖျက်ရန် တစ်ကြိမ်ထပ် run ပါ။ ခလုတ်သည် ဖောင့်နှင့် ဆိုင်ပြီး ဤ browser တွင် ထိန်းထားသည်၊ ပုံဆွဲတွင် မသိမ်းပါ။

## ဘာတွေ မပါသေးသလဲ

- inline format code ပါသော စာသား (အရောင်များ၊ MTEXT ထဲရှိ stack များ) သည် built-in မျက်နှာပြင်တွင် ကျန်နေသည်။
- Big font များ (double-byte အမျိုးအစား) သည် ပင်မဖောင့်မှ မပါသော code များအတွက် ဖြည့်ပေးသည်၊ သို့သော် CadCraft က Unicode သို့ ပြောင်းပြီးသား အရှေ့အာရှ code page ရှိ စာသားကို ဖောင့်၏ double-byte code များသို့ ပြန်မပြောင်းပါ။
- ဖောင့်ဖတ်စက်သည် format ၏ ထုတ်ပြန်ထားသော ဖော်ပြချက်ကို လိုက်နာပြီး CadCraft အတွက် ပြုလုပ်ထားသော ဖောင့်များဖြင့် စမ်းသပ်ထားသည်။ သင့်ဖောင့်တစ်ခုက မှားယွင်းစွာ ဆွဲလျှင် ဖောင့်နှင့် ပုံဆွဲကို ကျွန်ုပ်တို့ထံ ပို့ပါ။
