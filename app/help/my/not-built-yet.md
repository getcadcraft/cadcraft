CadCraft ကို ဖွံ့ဖြိုးဆဲဖြစ်သည်။ ဤစာမျက်နှာသည် လက်ရှိ ဗားရှင်းက မလုပ်ဆောင်သည့်အရာများကို ဖော်ပြထားပြီး သင် ရှာစရာမလိုစေရန် ဖြစ်သည်။ အချက်တစ်ခုစီတွင် ယနေ့ ဘာလုပ်ရမည်ကို ဖော်ပြထားသည်။

## ဖိုင်များနှင့် သိမ်းခြင်း

| ယနေ့ထိ မတည်ဆောက်ရသေး | ယနေ့ အစားထိုးရန် |
|---|---|
| AutoCAD ကိုယ်တိုင်တွင် စစ်ဆေးထားသော CadCraft DWG | သိမ်းထားသော ဗားရှင်းတိုင်းကို အခြားပရိုဂရမ်သုံးခုရဲ့ DWG reader များနှင့် CadCraft က ပြန်ဖတ်သည်။ [DWG တွင် ဘာတွေ ထိန်းသိမ်းပြီး ဘာတွေ ပြောင်းသလဲ](topic:files#what-a-dwg-keeps-and-changes) ကို ကြည့်ပါ။ |
| DXF 2000 ထက် အသစ်သော DXF သိမ်းခြင်း | DXF 2000 အဖြစ်၊ သို့မဟုတ် AutoCAD 2018 အထိ DWG အဖြစ် သိမ်းပါ။ |
| browser တွင် ဖွင့်ထားသော ဖိုင်ပေါ် ထပ်သိမ်းခြင်း | သိမ်းတိုင်း ဖိုင်အသစ် ဒေါင်းလုဒ်ဆွဲသည်။ လိုလျှင် ဖိုင်အဟောင်းကို သင်ကိုယ်တိုင် အစားထိုးပါ။ CadCraft Studio တွင် {{key:Mod+S}} က ဖွင့်ခဲ့သော ဖိုင်ထဲသို့ ပြန်သိမ်းသည်။ |
| ကွန်ပျူတာများကြား cloud သိမ်းခြင်းနှင့် sync | CadCraft သည် သိမ်းဆည်းချက်များကို cloud သို့ မပို့သေးပါ။ DWG နှင့် DXF ဖိုင်များကို သင့်ဖိုဒါများတွင် ထားပါ။ CadCraft Studio တွင် [သမိုင်း](topic:history) က အခြားနေရာမှ သိမ်းထားသော ပုံဆွဲ၏ cloud ဗားရှင်းများနှင့် ဤကွန်ပျူတာပေါ်ရှိ သင့်သိမ်းဆည်းချက် မိတ္တူများကို ဖော်ပြသည်။ |
| Overlays နှင့် link ထားသော ပုံဆွဲကို နေရာတွင်ပင် တည်းဖြတ်ခြင်း | ပုံဆွဲကို link အဖြစ် ချိတ်ပြီး အခြားပုံဆွဲကို ပြောင်းပြီးနောက် ပြန်ဖွင့်ပါ။ Link သည် DWG အဖြစ် သိမ်းသည့်အခါ link အဖြစ်ပင် ဆက်ရှိနေပြီး {{cmd:XCLIP}} က ၎င်းကို ဖြတ်သည်။ |
| DXF ထဲရှိ ပုံများ၊ အောက်ရှိအရာများကို ဖုံးထားသော wipeout များ | DXF သည် ပုံကို ဖိုင်အမည်ပါသော ၎င်း၏ frame အဖြစ် ထိန်းသိမ်းသည်။ DWG သည် ပုံအဖြစ် ထိန်းသိမ်းသည် — [ပုံဆွဲထဲရှိ ပုံများ](topic:pictures) ကို ကြည့်ပါ။ Wipeout သည် ၎င်း၏ frame အဖြစ် ပြသသည်။ |
| ကွေးသော leader line များပါသော multileader များ၊ အကြောင်းအရာ၏ နှစ်ဘက်လုံးတွင် leader line များပါသော multileader များ၊ သို့မဟုတ် မညီမျှစွာ လှည့်ထားသော သို့မဟုတ် အတိုင်းအတာ ချိန်ထားသော block ပါသော multileader များကို တည်းဖြတ်ခြင်း | အခြားပရိုဂရမ်က ဆွဲထားသည့်အတိုင်း ဆွဲပြီး တစ်ခုတည်းအဖြစ် ရွှေ့သည်။ Landing တစ်ခုသို့ ဖြောင့်သော leader line များပါသော multileader များနှင့် အကြောင်းအရာအဖြစ် စာသား သို့မဟုတ် block ပါသော multileader များသည် တည်းဖြတ်နိုင်သည် ({{cmd:MLEADEREDIT}})။ |
| အခြားပရိုဂရမ်များမှ table များတွင် block ပါသော cell၊ cell အတွင်း စာသား ဖော်မတ်၊ DXF table ၏ cell တစ်ခုချင်းစီ border နှင့် အရောင်များ၊ column များအဖြစ် ပိုင်းထားသော table | Table သည် တည်းဖြတ်နိုင်သော table ({{cmd:TABLEDIT}}) အဖြစ် ဖွင့်ပြီး သင်တည်းဖြတ်သည်အထိ အခြားပရိုဂရမ်ဆွဲသည့်အတိုင်း ပြသသည်။ ထို့နောက် CadCraft သည် ၎င်း၏ cell များမှ ပြန်ဆွဲသည်— ရိုးရိုးစာသား၊ `=G3*H3` နှင့် `=Sum(I3:I9)` ကဲ့သို့ ဖော်မြူလာများ၊ ချိန်ညှိမှုနှင့် စာသားအမြင့်များ။ Block cell သည် ထို့နောက် ဗလာဖြစ်သည်။ မပြောင်းလဲရသေးသော DWG table ကို ၎င်းပါလာသော cell ဒေတာဖြင့် ပြန်သိမ်းသည်။ |
| သိမ်းထားသော DXF ထဲရှိ အမှန်တကယ် table object | DWG သည် table ကို အခြားပရိုဂရမ်များ တည်းဖြတ်နိုင်သော table အဖြစ် ထိန်းသိမ်းသည်။ DXF သည် ၎င်းကို ဆွဲသော block အဖြစ်နှင့် CadCraft ၏ ကိုယ်ပိုင်မှတ်တမ်းဖြင့် ထိန်းသိမ်းသည်— CadCraft က table အဖြစ် ပြန်ဖွင့်သည်။ အခြားပရိုဂရမ်များက block အဖြစ်သာ မြင်ရသည်။ Mirror သို့မဟုတ် မညီမျှစွာ အတိုင်းအတာ ချိန်ထားသော table ကို DWG တွင်လည်း ထိုနည်းဖြင့် သိမ်းသည်။ |
| အခြားပရိုဂရမ်များနှင့် copy နှင့် paste | CadCraft ၏ clipboard သည် browser တစ်ခုတည်းရှိ CadCraft ပုံဆွဲများနှင့် tab များကြား အလုပ်လုပ်သည်၊ အခြားပရိုဂရမ်များနှင့် မဟုတ်ပါ။ DWG သို့မဟုတ် DXF အဖြစ် သိမ်းပြီး ထိုနေရာတွင် ဖွင့်ပါ။ [Copy, paste နှင့် duplicate](topic:copy-paste) ကို ကြည့်ပါ။ |

## ပုံဆွဲခြင်းနှင့် တည်းဖြတ်ခြင်း

| ယနေ့ထိ မတည်ဆောက်ရသေး | ယနေ့ အစားထိုးရန် |
|---|---|
| CadCraft မပါသော hatch pattern များနှင့် အခြားပရိုဂရမ်များ အတိအကျ ဆွဲသော gradient fill များ | CadCraft မပါသော pattern ပါသော hatch များကို ဖွင့်သောအခါ အရောင်အပြာရင့်အဖြစ် ပြသည်။ Gradient fill ({{cmd:GRADIENT}}) ကို အမျိုးအစားတစ်ခုစီအတွက် CadCraft ၏ ကိုယ်ပိုင်နည်းဖြင့် ဆွဲသည်— အခြားပရိုဂရမ်များနှင့် အမျိုးအစားအားဖြင့် တူသည်၊ အမှတ်တစ်ခုချင်းစီ တိတိကျကျ မတူပါ။ DWG 2004 နှင့် နောက်ပိုင်းက ၎င်းကို အမှန်တကယ် gradient hatch အဖြစ် ထိန်းသိမ်းသည်။ DXF 2000 သို့မဟုတ် DWG 2000 ဖိုင်တွင် CadCraft က သာ ပြန်ဖတ်နိုင်ပြီး အခြားပရိုဂရမ်များက solid fill အဖြစ်သာ မြင်ရသည်။ Pattern များကို `.pat` ဖိုင်မှ ဖတ်သည်၊ hatch ကို ၎င်း၏ boundary သို့ link လုပ်နိုင်ပြီး ထိုအခါ ၎င်းနောက်လိုက်သည်— [Hatch နှင့် fill နယ်မြေများ](topic:hatch) ကို ကြည့်ပါ။ |
| Shape သို့မဟုတ် စာသားပါသော linetype များ၊ နှင့် သိမ်းထားသော DXF R12 ထဲရှိ lineweight များ | ဖိုင်၏ linetype ထဲရှိ shape နှင့် စာသားများကို dash များမှ ချန်ထားသည်။ Lineweight ထိန်းသိမ်းရန် DWG အဖြစ် သိမ်းပါ။ |
| သိမ်းထားသော DXF ထဲရှိ pattern ပါသော hatch များ | R12 တွင် hatch မရှိပါ— ၎င်းတို့ကို outline အဖြစ် သိမ်းသည်။ Pattern ထိန်းသိမ်းရန် DWG အဖြစ် သိမ်းပါ။ |
| အခြားပရိုဂရမ်က ဆောက်သော သို့မဟုတ် တည်းဖြတ်နိုင်သော array များ၊ path နှင့် polar array များရှိ အတန်းနှင့် အထပ်များ၊ path curve ကို လိုက်သော array | ASsociative ({{cmd:ARRAY}}, {{cmd:ARRAYPATH}}; {{cmd:ARRAYEDIT}} ဖြင့် ပြောင်း) ဖြင့် ဆောက်သော array ကို CadCraft ၏ ကိုယ်ပိုင်နံပါတ်များဖြင့် block reference အဖြစ် သိမ်းသည်။ အခြားပရိုဂရမ်များက ပြသ၊ ရွှေ့၊ plot နှင့် explode လုပ်နိုင်သော်လည်း အရေအတွက်ကို ပြောင်းလဲနိုင်ခြင်းမရှိပါ။ အခြားပရိုဂရမ်တွင် ဆောက်သော array သည် ဤနေရာတွင် ရိုးရိုး block reference အဖြစ် ဖွင့်သည်။ Path array သည် ၎င်း၏ path ၏ မိတ္တူကို ထိန်းသည်— နောက်ပိုင်း curve ကို တည်းဖြတ်ခြင်းသည် အရာများကို မရွှေ့ပါ။ |
| အခြားပရိုဂရမ်များနှင့် ဆက်စပ်သော ဖြတ်ထားသော sheet viewport များ | {{cmd:VPCLIP}} ဖြင့် ဖြတ်ထားသော သို့မဟုတ် {{cmd:MVIEW}} Polygonal သို့မဟုတ် Object ဖြင့် ဆောက်ထားသော viewport ကို CadCraft ၏ ကိုယ်ပိုင် outline ဖြင့် သိမ်းသည်။ အခြားပရိုဂရမ်များက ၎င်းကို ပတ်လည်ရှိ ထောင့်မှန်စတုဂံအဖြစ် ဖွင့်သည်၊ အခြားပရိုဂရမ်တွင် ဖြတ်ထားသော viewport သည် ဤနေရာတွင် ၎င်း၏ စတုဂံအဖြစ် ဖွင့်သည်။ DXF R12 သည် စတုဂံကိုသာ ထိန်းသည်။ |
| Crossing polygon ဖြင့် {{cmd:STRETCH}} | Crossing window တစ်ခု သို့မဟုတ် တစ်ခုထက်ပို အသုံးပြုပါ။ |
| {{cmd:PEDIT}} Edit vertex (command line တွင် vertex တစ်ခုချင်းစီ) | Grip များနှင့် Properties ရှိ vertex browser (vertex အားလုံး၊ ၎င်းတို့၏ အကျယ်နှင့် bulge)။ PEDIT ၏ အခြားအရာများ ဆောက်ပြီးဖြစ်သည်— [Spline နှင့် polyline](topic:splines) ကို ကြည့်ပါ။ |
| Ellipse နှင့် spline ပေါ်ရှိ {{cmd:BREAK}}, {{cmd:LENGTHEN}}, {{cmd:OFFSET}}, {{cmd:TRIM}}, {{cmd:EXTEND}}, {{cmd:FILLET}} နှင့် {{cmd:JOIN}} | Spline ကို {{cmd:EXPLODE}} (သို့မဟုတ် {{cmd:PEDIT}}) လုပ်ပြီး ဤ command များ လက်ခံသော polyline ကို ရယူပါ။ |
