## သင်လေ့လာရမည့်အရာ

အရာများကို clipboard သို့ ကူးနည်း၊ နှိပ်သည့်နေရာတွင် ကူးထည့်နည်း၊ ၎င်းတို့၏ ကိုယ်ပိုင်ကိုဩဒိနိတ်တွင် ကူးထည့်နည်း၊ pointer ဖြင့် ပွားနည်း၊ ဖြတ်နည်း၊ နှင့် အခြားပုံဆွဲထဲ သယ်ဆောင်နည်း။ ဤအရာအားလုံးသည် toolbar ၏ {{ui:Edit}} အုပ်စုတွင်လည်း ရှိသည်: {{ui:Copy}}၊ {{ui:Paste}} နှင့် {{ui:More}} မီနူး။

## နှိပ်သည့်နေရာတွင် ကူးခြင်းနှင့် ကူးထည့်ခြင်း

1. အရာများကို ရွေးပါ: နှိပ်ပါ၊ သို့မဟုတ် window ဆွဲပါ။
2. {{key:Mod+C}} နှိပ်ပါ၊ သို့မဟုတ် {{ui:Edit}} အုပ်စုရှိ {{ui:Copy}} ကို နှိပ်ပါ။ command line က အရာမည်မျှ ကူးပြီးကြောင်း ပြသည်။ ၎င်းတို့ ရွေးထားဆဲ ရှိနေသည်။
3. {{key:Mod+V}} နှိပ်ပါ၊ သို့မဟုတ် {{ui:Paste}} ကို နှိပ်ပါ။ မိတ္တူသည် cursor ပေါ်တွင် ပေါ်ပြီး ကူးထားသော အရာများ၏ ဘယ်အောက်ထောင့်မှ ချိတ်ဆွဲနေသည်။
4. ထောင့်သည် သွားမည့်နေရာကို နှိပ်ပါ၊ သို့မဟုတ် `2000,500` ကဲ့သို့ အမှတ်ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ Object snaps နှင့် Ortho တို့ ပုံမှန်အတိုင်း အလုပ်လုပ်သည်။

ကူးထည့်ထားသော အရာများ ရွေးထားပြီးဖြစ်သောကြောင့် ချက်ချင်း ရွှေ့ သို့မဟုတ် ပြောင်းနိုင်သည်။ {{key:Mod+Z}} တစ်ကြိမ်ဖြင့် ကူးထည့်မှု တစ်ခုလုံး ဖျက်သည်။

:::tip
မိတ္တူ သင်ရွေးသော အမှတ်တစ်ခုမှ ချိတ်ဆွဲစေချင်သလား၊ ဥပမာ နံရံ၏ထောင့်? `COPYBASE` ကို ရိုက်ပါ၊ base point ကို နှိပ်ပါ၊ အရာများကို ရွေးပြီး {{key:Enter}} နှိပ်ပါ။ ထို့နောက် ကူးထည့်ခြင်းသည် ထိုအမှတ်ကို သင်နှိပ်သည့်နေရာတွင် ထားသည်။ မိတ္တူအားလုံးကို ဘယ်အောက်ထောင့်အစား ၎င်းတို့၏ ဗဟိုမှ ချိတ်ဆွဲလိုလျှင် [CadCraft ဆက်တင်များ](topic:settings) ထဲရှိ {{ui:Paste point}} ကို ပြောင်းပါ။
:::

## နေရာတွင် ကူးထည့်ခြင်း

{{key:Mod+Shift+V}} နှိပ်ပါ၊ သို့မဟုတ် {{ui:More}} မီနူးမှ {{ui:Paste in place}} ကို ရွေးပါ။ မိတ္တူသည် ကူးခဲ့သော ကိုဩဒိနိတ်အတိအကျတွင် နှိပ်စရာမလိုဘဲ ဝင်သည်။ အရာများကို အခြားပုံဆွဲထဲ တူညီနေရာတွင်၊ သို့မဟုတ် စာရွက်တစ်ရွက်မှ အခြားစာရွက်သို့ သယ်ရန် အသုံးပြုပါ။

## ပွား၍ ရွှေ့ခြင်း

1. အရာများကို ရွေးပါ။
2. {{key:Mod+D}} နှိပ်ပါ၊ သို့မဟုတ် {{ui:More}} မီနူးမှ {{ui:Duplicate and move}} ကို ရွေးပါ။
3. မိတ္တူတစ်ခုသည် မူရင်းပေါ်တွင် ရှိပြီး pointer နှင့်အတူ ရွေ့သည်။ သွားမည့်နေရာကို နှိပ်ပါ။ `@0,-600` ကဲ့သို့ displacement ရိုက်နိုင်သည်၊ သို့မဟုတ် cursor ဘက်သို့ အကွာအဝေး ရိုက်နိုင်သည်။

နှိပ်မီ {{key:Esc}} နှိပ်လျှင် ဘာမျှ မကျန်ရစ်ပါ။ ပွားထားခြင်းသည် ပြန်ဖျက်ရန် အဆင့်တစ်ခုဖြစ်ပြီး clipboard ကို မထိပါ။

## ဖြတ်ခြင်း

{{key:Mod+X}} နှိပ်ပါ၊ သို့မဟုတ် {{ui:More}} မီနူးမှ {{ui:Cut}} ကို ရွေးပါ။ အရာများသည် clipboard သို့ ရောက်ပြီး ပုံဆွဲမှ ဖျက်ထားသည်၊ ပြန်ဖျက်ရန် အဆင့်တစ်ခုတည်းဖြင့်။ {{key:Mod+V}} သို့မဟုတ် {{key:Mod+Shift+V}} ဖြင့် ပြန်ကူးထည့်ပါ။

## ပုံဆွဲများနှင့် tabs ကြား

အခြားပုံဆွဲတစ်ခု ဖွင့်သောအခါ clipboard သည် ၎င်း၏ မိတ္တူကို ဆက်ထိန်းထားသည်၊ ဤ browser ရှိ CadCraft tab အားလုံး မျှဝေသည်။ tab တစ်ခုတွင် ကူး၊ ထို့နောက် အခြား tab တွင် {{key:Mod+V}} နှိပ်ပါ။

- အရာများ သုံးထားသော blocks များသည် ၎င်းတို့နှင့်အတူ ပါလာသည်။ ကူးထည့်သည့် ပုံဆွဲတွင် အမည်တူ block ရှိပြီးသား ဖြစ်လျှင် ၎င်း၏ကိုယ်ပိုင် အဓိပ္ပါယ်ကို သုံးသည်၊ AutoCAD ကဲ့သို့။
- အရာများ သုံးထားသော လေယာများကို ၎င်းတို့၏ အရောင်နှင့် ဆက်တင်များဖြင့် ထည့်သည်။
- ပုံဆွဲနှစ်ခု ယူနစ် မတူသောအခါ မိတ္တူကို စကေး ပြန်မပြောင်းပါ: CadCraft က ထိုသို့ ပြောပြပြီး နောက်တွင် {{cmd:SCALE}} ကို သုံးနိုင်သည်။
- Viewports များသည် ၎င်းတို့၏ စာရွက်ပေါ်တွင်သာ ရှိနေပြီး မိတ္တူတွင် ထည့်မပါပါ။

:::note
clipboard သည် CadCraft ၏ ကိုယ်ပိုင်ဖြစ်သည်။ CadCraft အရာများကို အခြားပရိုဂရမ်ထဲ ကူးထည့်၍မရ၊ သို့မဟုတ် အခြားပရိုဂရမ်မှ CadCraft ထဲ ကူးထည့်၍မရပါ: အစား DWG သို့မဟုတ် DXF အဖြစ် သိမ်းပါ။ အလွန်ကြီးသော မိတ္တူသည် tabs များအကြား မျှဝေ၍ မရနိုင်ပါ; ထိုအခါ command line က ဤ tab သာ ကူးထည့်နိုင်ကြောင်း ပြသည်။
:::

## အများဆုံး မှားယွင်းမှုများ

- **{{key:Mod+V}} က စာသားကို command line ထဲ ကူးထည့်လိုက်သည်။** ထိုနေရာတွင် တစ်ခုခု ရိုက်ထားသဖြင့် ခလုတ်များက စာသားပေါ်တွင် အလုပ်လုပ်ခဲ့သည်။ ရှင်းရန် {{key:Esc}} နှိပ်ပြီး {{key:Mod+V}} ကို နောက်တစ်ကြိမ် နှိပ်ပါ။
- **ဘာမျှ မဖြစ်ပါ၊ status bar က လက်ရှိ command ကို ပြီးအောင်လုပ်ရန် ပြောသည်။** အခြား command တစ်ခု လည်ပတ်နေသည်။ ပထမ {{key:Esc}} နှိပ်ပါ။
- **ကူးထည့်ခြင်း အဝေးတစ်နေရာတွင် ရောက်သွားသည်။** ၎င်းသည် ကူးထားသော အရာ၏ ဘယ်အောက်ထောင့်မှ ချိတ်ဆွဲသည်၊ ထိုအရာသည် မတော်တဆ ရွေးမိသော အဝေးက အရာတစ်ခု ဖြစ်နိုင်သည်။ {{ui:Paste in place}} ကို သုံးပါ၊ သို့မဟုတ် `COPYBASE` ဖြင့် ကူးပါ။
- **"Nothing pasted" အကြောင်းပြချက်ဖြင့်။** အခြား tab က clipboard တွင် ထားခဲ့သည်ကို ဖတ်၍ မရနိုင်ပါ (ပျက်စီးနေ သို့မဟုတ် လက်ဖြင့် ပြောင်းထားသည်)။ အရာများကို ထပ်ကူးပါ။

ခလုတ်အပြည့်အစုံကို [Keyboard and mouse](topic:keyboard) တွင်၊ prompt အားလုံးကို [Command reference](topic:commands#clipboard) တွင် ကြည့်ပါ။
