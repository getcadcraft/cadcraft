## အခြား drawing မှ ဘလောက်တစ်ခု သွင်းခြင်း

1. `I` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်၊ သို့မဟုတ် {{ui:ဘလောက်များ}} အုပ်စုရှိ {{ui:သွင်းရန်}} ကို နှိပ်။
2. ဝင်းဒိုး အောက်ခြေရှိ command line က `Enter block name or [File/Library]` ဟု မေး။ ထိုနေရာတွင် `F` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်။
3. ဤကွန်ပျူတာရှိ DWG သို့မဟုတ် DXF ကို ရွေး။ ၎င်းကို ဤနေရာတွင် ဖတ်သည်၊ ဖွင့်ခြင်း မရှိ၊ ဘာမျှ upload မလုပ်။
4. {{ui:ဖိုင်မှ…}} dialog တွင် စာရင်းမှ ဘလောက်တစ်ခုကို ရွေး (ရှာရန် {{ui:block များကို စစ်ထုတ်ရန်}} တွင် ရိုက်)၊ သို့မဟုတ် drawing အပြည့်ကို ထား။ {{ui:သွင်းရန်}} ကို နှိပ်။
5. နေရာချလိုသည့်နေရာကို နှိပ်၊ ၎င်းမေးသော attribute များကို ဖြည့်။

{{ui:ဘလောက်များ}} panel မှလည်း စတင်နိုင်: {{ui:block များကို စစ်ထုတ်ရန်}} အကွက်တွင် `F` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်၊ သို့မဟုတ် ဘလောက်နှင့် မကိုက်သော အရာတစ်ခု ရိုက်ပြီး {{ui:ဖိုင်မှ…}} ကို နှိပ်။ `L` နှင့် {{ui:စာကြည့်တိုက်…}} က စာကြည့်တိုက်ကို အလားတူ ဖွင့်။ 0.10.1 မတိုင်မီ {{ui:block များကို စစ်ထုတ်ရန်}} တွင် ရိုက်သော အက္ခရာတစ်လုံးသည် ဤ drawing ၏ ဘလောက်များကိုသာ ရှာ၊ "No block matches the filter." ဟု ပြခဲ့သည်။

ကိုယ်ပိုင် ဘလောက်များ drawing ကို လက်လှမ်းမီအောင် ထားလိုလျှင် {{ui:ဘလောက်များ}} panel ရှိ {{ui:စာကြည့်တိုက်များ}} အောက်မှ {{ui:ပုံဆွဲ ထည့်ရန်}} ကို နှိပ်ပြီး DWG သို့မဟုတ် DXF ကို ရွေး။ ၎င်း၏ ဘလောက်များကို ပုံများနှင့်အတူ စာရင်းပြ၊ နေရာချရန် တစ်ခုကို နှိပ်။

ဝင်လာသော drawing တစ်ခုလုံးသည် ဖိုင်အမည်ဖြင့် ဘလောက်တစ်ခုအဖြစ် ရောက်။ သင်ရွေးသော ဘလောက်အတွင်းရှိ ဘလောက်များလည်း ပါ။ ၎င်းတို့ သုံးထားသော layer များကို ဤ drawing သို့ ထည့်။

အခြား drawing သည် ကွဲပြားသော unit များ (ဥပမာ လက်မနှင့် မီလီမီတာ) ဖြင့် ဖြစ်လျှင် CadCraft က reference ကို ကိုက်အောင် scale ပြောင်း၊ မှတ်တမ်းတွင် ထိုသို့ ပြော။

### အမည် ရှိပြီးဖြစ်သောအခါ

ဤ drawing တွင် အမည်တူ ဘလောက်ရှိပြီးသားဆိုလျှင် CadCraft က မေး:

- {{ui:ရှိပြီးသားကို ထားရန်}} က ထိုအမည်ရှိ ဤ drawing ၏ ဘလောက်ကို သုံး။
- {{ui:အမည်ပြောင်းရန်}} က အသစ်ကို `Name (2)` အဖြစ် သွင်း။

Insert တစ်ခုလုံးသည် အဆင့်တစ်ခု: {{key:Mod+Z}} က reference နှင့် ကူးထားသော အဓိပ္ပာယ်ဖွင့်ဆိုချက်များကို ပြန်ဖယ်။

## စာကြည့်တိုက်ကို ဖွင့်ခြင်း

{{ui:ဘလောက်များ}} panel ရှိ {{ui:စာကြည့်တိုက်…}} ကို နှိပ်၊ သို့မဟုတ် Blocks အုပ်စုရှိ {{ui:စာကြည့်တိုက်}} ကို နှိပ်၊ သို့မဟုတ် `LIB` ရိုက်။ `INSERT` prompt တွင် `L` ကလည်း ဖွင့်။

စာကြည့်တိုက်တွင် tab အဖြစ် အရင်းအမြစ်လေးခု ရှိ:

- {{ui:စာကြည့်တိုက်}}: CadCraft စာကြည့်တိုက်။ အမည်၊ ထုတ်လုပ်သူ သို့မဟုတ် မော်ဒယ်ဖြင့် ရှာ၊ အမျိုးအစားဖြင့် စစ်ထုတ်။
- {{ui:ဖိုင်များ…}}: မည်သည့်စာကြည့်တိုက်မှမဆို item ဖိုင် (`item.json`)၊ သို့မဟုတ် item ပြုလုပ်ရန် drawing၊ spreadsheet သို့မဟုတ် 3D model: DWG သို့မဟုတ် DXF (ဘလောက်တစ်ခုစီ item တစ်ခု)၊ အမည်နှင့် အရွယ်အစား ကော်လံပါသော CSV၊ သို့မဟုတ် glTF သို့မဟုတ် OBJ model။ ဘာမျှ upload မလုပ်။
- {{ui:Standard}}: ကိုယ်စားပြု steel section များ (section၊ elevation သို့မဟုတ် 3D member အဖြစ်) နှင့် bolt၊ nut နှင့် bearing ကဲ့သို့ standard part များ၊ ထုတ်ပြန်ထားသော ဇယားများမှ ဤနေရာတွင် ပြုလုပ်။ See [steel section နှင့် standard part များ နေရာချခြင်း](topic:steel-and-standard-parts)။
- {{ui:အခြား feed များ}}: Library နည်းတူ ဖြေသော အခြားစာကြည့်တိုက်များ။ လိပ်စာကို တစ်ကြိမ် ထည့်; ဤ browser က မှတ်ထား။

ကတ်တစ်ခုစီတွင် ကြိုတင်ကြည့်ရှုမှု၊ အမည်၊ ထုတ်လုပ်သူနှင့် မော်ဒယ်၊ လိုင်စင်နှင့် ဗားရှင်း ပြ။ ဖယ်ထုတ်ထားသော item ကို ၎င်း၏ အကြောင်းပြချက်နှင့်အတူ ရုပ်သိမ်းထား ဟု အမှတ်အသား; CadCraft က နေရာချမီ မေးသည်။

## Item နေရာချခြင်း

1. ကတ်ပေါ်ရှိ {{ui:နေရာချရန်}} ကို နှိပ်။
2. Item သွားရမည့်နေရာကို နှိပ်။ လှည့်ရန် ပထမ `R` ရိုက်၊ သို့မဟုတ် အရွယ်ပြောင်းရန် `S` ရိုက်။
3. `Enter Item number (CC-ITEM)` တွင် {{key:Enter}} ကို နှိပ်လျှင် နောက်ဆုံး အလွတ်နံပါတ်၊ သို့မဟုတ် သင်ကိုယ်တိုင် ရိုက်။

Item သည် `LIB_<name>_v<version>` အမည်ရှိ ဘလောက်တစ်ခု ဖြစ်လာ၊ ဤ drawing ၏ unit များဖြင့် ဆွဲ။ Drawing တွင် unit မရှိလျှင် item ကို မီလီမီတာဖြင့် ထည့်၊ မှတ်တမ်းက ထိုသို့ ပြော; ညာဘက် panel တွင် အရင် {{ui:ယူနစ်များ}} ကို သတ်မှတ်။

ဒေတာသည် မမြင်ရသော attribute များအဖြစ် ပါလာ: item ၏ id နှင့် version၊ လိုင်စင်နှင့် အသိအမှတ်ပြုချက်၊ ထုတ်လုပ်သူ၊ မော်ဒယ်၊ အမျိုးအစားနှင့် အရွယ်အစားများ။ See [ဘလောက် attribute များ](topic:attributes)။

## သင့်ဘာသာစကားဖြင့် item များ

Item တစ်ခုသည် ၎င်း၏အမည်နှင့် ဖော်ပြချက်ကို အခြားဘာသာစကားများဖြင့် ယူဆောင်နိုင်။ CadCraft ကို သတ်မှတ်ထားသော ဘာသာစကား (ဆက်တင်များ › အထွေထွေ › ဘာသာစကား) ဖြင့် ထိုအရာများ ရှိလျှင် ကတ်နှင့် နေရာချထားသော ဘလောက်၏ item အမည်သည် ထိုအရာများကို သုံး။ ဘလောက်ကိုယ်တိုင်က item ၏ ကိုယ်ပိုင်အမည်မှ ပြုလုပ်သော အမည်ကို ထိန်း၊ ထို့ကြောင့် ဘယ်ဘာသာစကားက နေရာချချင်း drawing တွင် item တစ်ခုအတွက် ဘလောက်တစ်ခုသာ ရှိ။

## Update များ စစ်ခြင်း

1. စာကြည့်တိုက်ကို ဖွင့်။
2. {{ui:အပ်ဒိတ် စစ်ရန်}} ကို နှိပ်။

Drawing ရှိ library item တစ်ခုစီကို ၎င်း၏ item နံပါတ်များနှင့်အတူ စာရင်း၊ ၎င်း update လုပ်ပြီးပြီး၊ ဗားရှင်းအသစ် ရှိ (ပြောင်းလဲမှုကိုပါ) သို့မဟုတ် ဖယ်ထုတ်ထား ဟု ပြ။ အတန်းတစ်ခုတွင် {{ui:အပ်ဒိတ်}} ကို နှိပ်၊ သို့မဟုတ် အားလုံး အပ်ဒိတ်။ Reference တိုင်း ဗားရှင်းအသစ်၏ ဘလောက်သို့ ရွေ့၊ ၎င်း၏ item နံပါတ်၊ အရေအတွက်၊ နေရာ၊ ထောင့်နှင့် layer ကို ထိန်း။ {{key:Mod+Z}} က update ကို ပြန်ဖျက်။

## အသုံးပြုထားသည်ကို အသိအမှတ်ပြု

{{ui:စာကြည့်တိုက် ကိုယ်ဖော်ပြချက်များ}} ကို နှိပ်။ Item တစ်ခုစီကို ၎င်း၏ အသိအမှတ်ပြုချက် လိုင်းနှင့် လိုင်စင်ဖြင့် စာရင်း။

- {{ui:အသိအမှတ်ပြုချက် ကူးရန်}} က item တစ်ခု၏ လိုင်းကို ကူး; {{ui:အားလုံး ကူးရန်}} က လိုင်းအားလုံးကို ကူး။
- {{ui:CSV ဒေါင်းလုဒ်ဆွဲရန်}} က item နံပါတ်များ၊ ထုတ်လုပ်သူများ၊ မော်ဒယ်များ၊ လိုင်စင်များနှင့် အသိအမှတ်ပြုချက်များပါသော စာရင်းကို သိမ်း။ ၎င်းကို spreadsheet မည်သည့်အရာတွင်မဆို ဖွင့်နိုင်။

CC BY ကဲ့သို့ လိုင်စင်များက အလုပ်ကို သုံးသည့်နေရာတွင် စာရေးဆရာကို အသိအမှတ်ပြုရန် တောင်းဆို။ လိုင်းများကို drawing၊ specification သို့မဟုတ် စီမံကိန်းမှတ်စုများတွင် ထည့်။

## သင်္ကေတများနှင့် asset များ

စာကြည့်တိုက်တွင် item အမျိုးအစား သုံးမျိုး ရှိ: Symbols (ပုံဆွဲ သဘောတူညီချက်များ၊ 2D)၊ Types (element တစ်ခု ဘာနှင့် ပြုလုပ်ထားသလဲ) နှင့် Assets (ရုပ်ပိုင်ဆိုင်မှု အရာဝတ္ထုများ)။ {{ui:စာကြည့်တိုက်}} tab တွင် {{ui:အမျိုးအစား}} စာရင်းက Symbols နှင့် Assets ကို အတူ၊ Symbols သာ၊ သို့မဟုတ် Assets သာ ပြ။ Types သည် BimCraft ပရောဂျက်ကို တည်ဆောက်သည့်အရာဖြစ်သဖြင့် CadCraft က ထိုအရာများကို မစာရင်း။

## စာကြည့်တိုက်သို့ ဝင်ခြင်း

{{ui:စာကြည့်တိုက်သို့ ဝင်ရန်}} ကို နှိပ်။ ဆိုဒ်ပေါ်တွင် အသေးစား window ဖွင့်; ထိုဆိုဒ်တွင် ဝင်ပြီးနောက် CadCraft သည် သင်၏အဖွဲ့၏ item များကို ပြနိုင်ပြီး သင်နေရာချသည့်အရာများကို မှတ်နိုင်၊ သင်သုံးထားသော item ပြောင်းလျှင် သိနိုင်။ Sign-in သည် ဤ browser tab အတွက် ကြာ၊ အကောင့်၏ security စာမျက်နှာမှ အချိန်မရွေး ပယ်ဖျက်နိုင်။

## ကိုယ်ပိုင် object များကို ကျွန်ုပ်၏ အရာဝတ္ထုများတွင် ထိန်းခြင်း

{{ui:ကျွန်ုပ်၏ အရာဝတ္ထုများ}} သည် Library ထဲရှိ သင်တစ်ဦးတည်းသာ မြင်နိုင်သော ပုဂ္ဂိုလ်ရေးစာရင်း ဖြစ်သည်။ ၎င်းသည် အများပိုင် စာကြည့်တိုက်၊ ရှာဖွေမှု သို့မဟုတ် အဖွဲ့သို့ မပြ၊ သင်ဝင်ထားသော ကွန်ပျူတာ အားလုံးသို့ သင့်အကောင့်ကို လိုက်။

1. Library panel တွင် {{ui:ဖိုင်များ…}} ကို နှိပ်ပြီး ဖိုင်တစ်ခုကို ဖတ်။
2. နောက်တစ်ကြိမ် လိုချင်သော item တွင် {{ui:ကျွန်ုပ်၏ အရာဝတ္ထုများတွင် သိမ်းရန်}} ကို နှိပ်။
3. နောက်ပိုင်း {{ui:ကျွန်ုပ်၏ အရာဝတ္ထုများ}} ကို နှိပ်ပြီး {{ui:နေရာချရန်}} ကို နှိပ်။ ၎င်းသည် library item ကဲ့သို့ နေရာချ၊ {{ui:အပ်ဒိတ် စစ်ရန်}} က ၎င်းကို ဖုံးလွှမ်း။
4. {{ui:ကျွန်ုပ်၏ အရာဝတ္ထုများမှ ဖယ်ရန်}} က စာရင်းမှ ဖယ်။ Drawing များတွင် နေရာချပြီးသား ကော်ပီများ ကျန်။

Library သို့ ဝင်ထားရန် လိုသည်။ ဖိုင်ဖတ်ခြင်းသည် ဘာမျှ upload မလုပ်; item ကို သိမ်းခြင်းသည် ထို item တစ်ခုတည်းကို သင့်အကောင့်သို့ ပို့။

:::note
ကျွန်ုပ်၏ အရာဝတ္ထုများ သည် စမ်းသပ်ဆဲဖြစ်ပြီး သင့်အကောင့်အတွက် မဖွင့်ရသေးနိုင်။ "My objects is not open for this account yet" ဟု ပြလျှင် သင့်ဖိုင်များမှ {{ui:ဖိုင်များ…}} ဖြင့် item များကို နေရာချနိုင်ဆဲ။
:::

## အမှားများ

- **"Making items from IFC types is in BimCraft."** IFC နှင့် family ဖိုင်များကို BimCraft app တွင် ဖတ်။ Item ကို ထိုနေရာ သို့မဟုတ် Library တွင် ပြုလုပ်ပြီး ၎င်း၏ `item.json` ကို ဤနေရာတွင် သုံး။
- **"The library could not be reached."** အင်တာနက်မရှိခြင်း သို့မဟုတ် စာကြည့်တိုက် ပိတ်နေခြင်း။ Drawing တွင် ရှိပြီးသား item များကို မထိခိုက်။
- **Item သည် အလွန်ကြီးသည် သို့မဟုတ် သေးသည်။** Drawing ၏ unit မှားသည် သို့မဟုတ် မသတ်မှတ်ရသေး။ ပြန်ဖျက်၊ {{ui:ယူနစ်များ}} ကို သတ်မှတ်၊ ပြန်နေရာချ။
