## အခြားပုံဆွဲမှ block တစ်ခု သွင်းရန်

1. `I` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ၊ သို့မဟုတ် ဘလောက်များ အုပ်စုရှိ {{ui:သွင်းရန်}} ကို နှိပ်ပါ။
2. `Enter block name or [File/Library]` တွင် `F` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
3. ဤကွန်ပျူတာပေါ်ရှိ DWG သို့မဟုတ် DXF ကို ရွေးပါ။ ၎င်းကို ဤနေရာတွင် ဖတ်သည်; ဖွင့်ခြင်း မဟုတ်ပါ၊ ဘာမျှ upload မလုပ်ပါ။
4. {{ui:မှ သွင်းရန်}} ဒိုင်ယာလော့ခ်တွင် စာရင်းမှ block တစ်ခုကို ရွေးပါ (ရှာရန် {{ui:ဘလောက်များကို စစ်ထုတ်ရန်}} တွင် ရိုက်ပါ)၊ သို့မဟုတ် {{ui:ပုံဆွဲတစ်ခုလုံး}} ကို ထားပါ။ {{ui:သွင်းရန်}} ကို နှိပ်ပါ။
5. နေရာသွားရမည့်နေရာကို နှိပ်ပါ၊ တောင်းဆိုသော attribute များကို ဖြည့်ပါ။

ပုံဆွဲတစ်ခုလုံးသည် ဖိုင်အမည်ဖြင့် block တစ်ခုအဖြစ် ဝင်လာသည်။ သင်ရွေးထားသော block အတွင်းရှိ block များလည်း ပါလာသည်။ ၎င်းတို့သုံးထားသော လေယာများကို ဤပုံဆွဲသို့ ထည့်သည်။

အခြား ပုံဆွဲသည် ကွဲပြားသော ယူနစ် (ဥပမာ inch နှင့် မီလီမီတာ) ဖြစ်လျှင် CadCraft က reference ကို ကိုက်ညီအောင် စကေးညှိပြီး သမိုင်းတွင် ပြောသည်။

### အမည် ရှိပြီးသား ဖြစ်လျှင်

ဤပုံဆွဲတွင် အမည်တူ block ရှိလျှင် CadCraft က မေးသည်:

- {{ui:ရှိပြီးသားကို ထားရန်}} သည် ဤပုံဆွဲရှိ ထိုအမည်ရှိ block ကို သုံးသည်။
- {{ui:အမည်ပြောင်းရန်}} သည် အသစ်ကို `Name (2)` အဖြစ် သွင်းသည်။

Insert တစ်ခုလုံးသည် အဆင့်တစ်ခုတည်း ဖြစ်သည်: {{key:Mod+Z}} သည် reference နှင့် ကူးထားသော အဓိပ္ပာယ်များကို ပြန်ဖျက်သည်။

## စာကြည့်တိုက်ကို ဖွင့်ရန်

{{ui:ဘလောက်များ}} panel ရှိ {{ui:စာကြည့်တိုက်…}} ကို နှိပ်ပါ၊ သို့မဟုတ် ဘလောက်များ အုပ်စုရှိ {{ui:စာကြည့်တိုက်}} ကို နှိပ်ပါ၊ သို့မဟုတ် `LIB` ကို ရိုက်ပါ။ `INSERT` prompt တွင် `L` သည်လည်း ဖွင့်သည်။

စာကြည့်တိုက်တွင် အရင်းအမြစ် လေးခုရှိသည်၊ tab များအဖြစ်:

- {{ui:စာကြည့်တိုက်}}: CadCraft စာကြည့်တိုက်။ အမည်၊ ထုတ်လုပ်သူ သို့မဟုတ် model ဖြင့် ရှာပြီး အမျိုးအစားဖြင့် စစ်ထုတ်ပါ။
- {{ui:ဖိုင်များ…}}: အခြား စာကြည့်တိုက်မှ item ဖိုင် (`item.json`)၊ သို့မဟုတ် item ပြုလုပ်ရန် ပုံဆွဲ၊ spreadsheet သို့မဟုတ် 3D model: DWG သို့မဟုတ် DXF (block တစ်ခုစီ item ဖြစ်သည်)၊ အမည်နှင့် size column ပါသော CSV၊ သို့မဟုတ် glTF သို့မဟုတ် OBJ model။ ဘာမျှ upload မလုပ်ပါ။
- {{ui:Standard}}: steel section များ (section၊ elevation သို့မဟုတ် 3D member အဖြစ်) နှင့် bolt၊ nut နှင့် bearing ကဲ့သို့ standard part များ၊ ထုတ်ပြန်ထားသော ဇယားများမှ ဤနေရာတွင် ပြုလုပ်ထားသည်။ ကြည့်ပါ [steel section နှင့် standard part များ နေရာချခြင်း](topic:steel-and-standard-parts)။
- {{ui:အခြား feed များ}}: Library နည်းတူ ဖြေသော အခြား စာကြည့်တိုက်များ။ ၎င်းတို့၏ လိပ်စာကို တစ်ကြိမ် ထည့်ပါ; ဤ browser က မှတ်ထားသည်။

Card တစ်ခုစီတွင် preview၊ အမည်၊ ထုတ်လုပ်သူနှင့် model၊ လိုင်စင်နှင့် ဗားရှင်း ပြသည်။ ရုပ်သိမ်းထားသော item ကို {{ui:ရုပ်သိမ်းပြီး}} ဟု အကြောင်းပြချက်ဖြင့် အမှတ်အသားပြုထားသည်; CadCraft က ထိုတစ်ခုကို နေရာချမီ မေးသည်။

## Item တစ်ခု နေရာချရန်

1. Card ပေါ်ရှိ {{ui:နေရာချရန်}} ကို နှိပ်ပါ။
2. Item သွားရမည့်နေရာကို နှိပ်ပါ။ လှည့်ရန် `R` ကို ရိုက်ပါ၊ အရွယ်အစားပြောင်းရန် `S` ကို ရိုက်ပါ။
3. `Enter Item number (CC-ITEM)` တွင် နောက်ဆုံး အလွတ် နံပါတ်အတွက် {{key:Enter}} ကို နှိပ်ပါ၊ သို့မဟုတ် ကိုယ်ပိုင် နံပါတ်ရိုက်ပါ။

Item သည် `LIB_<name>_v<version>` အမည်ရှိ block ဖြစ်လာပြီး ဤပုံဆွဲ၏ ယူနစ်ဖြင့် ဆွဲသည်။ ပုံဆွဲတွင် ယူနစ် မရှိလျှင် item ကို မီလီမီတာဖြင့် ထည့်ပြီး သမိုင်းက ပြောသည်; ညာဘက် panel တွင် {{ui:ယူနစ်များ}} ကို အရင် သတ်မှတ်ပါ။

၎င်း၏ ဒေတာသည် မမြင်ရသော attribute များအဖြစ် ပါလာသည်: item ၏ id နှင့် ဗားရှင်း၊ လိုင်စင်နှင့် အသိအမှတ်ပြုချက်၊ ထုတ်လုပ်သူ၊ model၊ အမျိုးအစားနှင့် အရွယ်အစားများ။ [Block attributes](topic:attributes) ကို ကြည့်ပါ။

## သင့်ဘာသာစကားဖြင့် Item များ

Item တွင် အခြားဘာသာစကားများဖြင့် အမည်နှင့် ဖော်ပြချက် ပါနိုင်သည်။ CadCraft ကို သတ်မှတ်ထားသော ဘာသာစကား (ဆက်တင်များ › General › Language) ဖြင့် ပါလျှင် card နှင့် နေရာချထားသော block ၏ item အမည်သည် ၎င်းတို့ကို သုံးသည်။ Block ကိုယ်တိုင်က item ၏ ကိုယ်ပိုင်အမည်မှ ပြုလုပ်ထားသော အမည်ကို ထားသည်၊ ထို့ကြောင့် မည်သည့် ဘာသာစကားဖြင့် နေရာချသည်ဖြစ်စေ ပုံဆွဲတွင် item တစ်ခုလျှင် block တစ်ခုသာ ရှိသည်။

## အပ်ဒိတ်များ စစ်ရန်

1. စာကြည့်တိုက်ကို ဖွင့်ပါ။
2. {{ui:အပ်ဒိတ် စစ်ရန်}} ကို နှိပ်ပါ။

ပုံဆွဲရှိ library item တစ်ခုစီကို item နံပါတ်များနှင့်အတူ စာရင်းပြုသည်၊ ၎င်းသည် အပ်ဒိတ်ဖြစ်/မဖြစ်၊ ဗားရှင်းအသစ် ရှိ (ပြောင်းလဲချက်ကို ပြသည်) သို့မဟုတ် ရုပ်သိမ်းခဲ့ကြောင်း ပြသည်။ အတန်းပေါ်ရှိ {{ui:အပ်ဒိတ်}} သို့မဟုတ် {{ui:အားလုံး အပ်ဒိတ်}} ကို နှိပ်ပါ။ Reference တိုင်းသည် ဗားရှင်းအသစ်၏ block သို့ ရွှေ့ပြီး item နံပါတ်၊ အရေအတွက်၊ နေရာ၊ ထောင့်နှင့် လေယာကို ထိန်းထားသည်။ {{key:Mod+Z}} သည် အပ်ဒိတ်ကို ပြန်ဖျက်သည်။

## သုံးထားသောအရာများကို ကိုယ်ဖော်ပြရန်

{{ui:Library credits}} ကို နှိပ်ပါ။ Item တစ်ခုစီကို ၎င်း၏ အသိအမှတ်ပြုချက် စာကြောင်းနှင့် လိုင်စင်ဖြင့် စာရင်းပြသည်။

- {{ui:အသိအမှတ်ပြုချက် ကူးရန်}} သည် item တစ်ခု၏ စာကြောင်းကို ကူးသည်; {{ui:အားလုံး ကူးရန်}} သည် စာကြောင်းအားလုံးကို ကူးသည်။
- {{ui:CSV ဒေါင်းလုဒ်ဆွဲရန်}} သည် item နံပါတ်များ၊ ထုတ်လုပ်သူများ၊ model များ၊ လိုင်စင်များနှင့် အသိအမှတ်ပြုချက်များပါသော စာရင်းကို သိမ်းသည်။ ၎င်းကို မည်သည့် spreadsheet တွင်မဆို ဖွင့်နိုင်သည်။

CC BY ကဲ့သို့ လိုင်စင်များသည် အလုပ်ကို သုံးသည့်နေရာတွင် စာရေးသူကို ဖော်ပြရန် တောင်းဆိုသည်။ စာကြောင်းများကို ပုံဆွဲ၊ specification သို့မဟုတ် ပရောဂျက် မှတ်စုများတွင် ထည့်ပါ။

## Symbols နှင့် assets

စာကြည့်တိုက်တွင် item အမျိုးအစား သုံးမျိုးရှိသည်: Symbols (ပုံဆွဲ သဘောတူညီချက်များ၊ 2D)၊ Types (element တစ်ခု ဘာဖြင့် ဖွဲ့စည်းထားသလဲ) နှင့် Assets (ရုပ်ပိုင်းဆိုင်ရာ အရာဝတ္ထုများ)။ {{ui:စာကြည့်တိုက်}} tab ရှိ {{ui:အမျိုးအစား}} စာရင်းက Symbols နှင့် assets ကို အတူ၊ Symbols သာ၊ သို့မဟုတ် Assets သာ ပြသည်။ Types သည် BimCraft ပရောဂျက် တည်ဆောက်ထားသည့် အရာများဖြစ်သောကြောင့် CadCraft က ၎င်းတို့ကို စာရင်းမပြပါ။

## စာကြည့်တိုက်သို့ ဝင်ရန်

{{ui:စာကြည့်တိုက်သို့ ဝင်ရန်}} ကို နှိပ်ပါ။ Site ပေါ်တွင် သေးငယ်သော window ဖွင့်သည်; ထိုတွင် ဝင်ပြီးနောက် CadCraft က သင့်အဖွဲ့၏ item များကို ပြနိုင်ပြီး သင်နေရာချသည့်အရာများကို မှတ်ပုံတင်နိုင်သည်၊ ထို့ကြောင့် သုံးထားသော item ပြောင်းလဲလျှင် သင် သိရမည်။ Sign-in သည် ဤ browser tab အတွက် တည်ရှိသည်။ အချိန်မရွေး သင့်အကောင့်၏ security စာမျက်နှာမှ ရုပ်သိမ်းနိုင်သည်။

## အများဆုံး ဖြစ်တတ်သော အမှားများ

- **"IFC type များမှ item ပြုလုပ်ခြင်းသည် BimCraft တွင်ရှိသည်။"** IFC နှင့် family ဖိုင်များကို BimCraft app တွင် ဖတ်သည်။ Item ကို ထိုနေရာ သို့မဟုတ် Library တွင် ပြုလုပ်ပြီး ၎င်း၏ `item.json` ကို ဤနေရာတွင် သုံးပါ။
- **"စာကြည့်တိုက်သို့ မဆက်သွယ်နိုင်ပါ။"** Offline ဖြစ်နေသည်၊ သို့မဟုတ် စာကြည့်တိုက် ပိတ်နေသည်။ ပုံဆွဲရှိ item များကို မထိခိုက်ပါ။
- **Item သည် အလွန်ကြီး သို့မဟုတ် သေးနေသည်။** ပုံဆွဲ၏ ယူနစ် မှားနေသည် သို့မဟုတ် သတ်မှတ်မထားပါ။ ပြန်ဖျက်ပြီး {{ui:ယူနစ်များ}} ကို သတ်မှတ်၍ ထပ်နေရာချပါ။
