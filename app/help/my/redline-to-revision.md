reviewer တစ်ဦးက MarkupCraft တွင် plan set ကို markup လုပ်ပြီး သင့်ထံ **redline package** (`.redline.json` ဖြင့် အဆုံးသတ်သော ဖိုင်) ပို့သည်။ ဤနေရာတွင် အပြောင်းအလဲတစ်ခုချင်းစီကို ကြည့်ပြီး လက်ခံသည်များသည် ပုံဆွဲပေါ်တွင် revision cloud များ ဖြစ်လာသည်။

## အပြောင်းအလဲများ ကြည့်ခြင်း

{{cmd:REDLINE}} (`RDL`) ကို ရိုက်ပြီး package ကို ရွေးပါ။ ရွေးပါ:

- {{ui:စာရင်း}}: အပြောင်းအလဲတိုင်း၊ ၎င်း၏နံပါတ်၊ အခြေအနေ၊ စာရွက်၊ အမျိုးအစား၊ မေးသူနှင့် ရေးထားသည်များ။
- {{ui:လက်ခံရန်}}, {{ui:ပယ်ချရန်}}, {{ui:ပြီးပြီ}}: နံပါတ်များ ရိုက်ပါ (`1,3-5` သို့မဟုတ် `All`) နှင့် အဖြေဖိုင်အတွက် မဖြစ်မနေမဟုတ်သော မှတ်ချက်။ {{ui:ပြန်ဖွင့်ရန်}} က အပြောင်းအလဲများကို ဖွင့်ထားသည့် အခြေအနေသို့ ပြန်ထားသည်။
- {{ui:ဘောင်}}: markup လုပ်ထားသော စာရွက်ပြသသော ပုံဆွဲ အစိတ်အပိုင်း။ ထောင့်နှစ်ခုကို နှိပ်ပါ; ပုံဆွဲ တစ်ခုလုံးအတွက် {{key:Enter}} ကို နှိပ်ပါ။ အပြောင်းအလဲများသည် စာရွက်ပေါ်တွင် မူလရှိရာနေရာအလိုက် နေရာချထားသည်၊ ထို့ကြောင့် ဤအဆင့်က ၎င်းတို့ကို ညှိပေးသည်။
- {{ui:အသုံးပြုရန်}}: လက်ခံ သို့မဟုတ် ပြီးပြီဟု အမှတ်အသားပြုထားသော အပြောင်းအလဲတိုင်းကို revision cloud (layer `REV-CLOUD`၊ revision အက္ခရာနှင့်အတူ) ဖြင့် ဝိုင်းပြီး၊ လက်ခံထားသည်များ၏ စာရင်းနှင့် သင့်မှတ်ချက်များပါသော revision log (ဇယားဘောင်ပါ၊ layer `REV-LOG`) ကို ပုံဆွဲ၏ ညာဘက်တွင် ထည့်သည်။ undo တစ်ကြိမ်။
- {{ui:သိမ်းရန်}}: `<project>-<revision>.redline-answers.json` ကို ရေးသည်။ MarkupCraft တွင် ဖွင့်လျှင် markup များ ပိတ်သည်: Accepted၊ Rejected သို့မဟုတ် Completed၊ သင့်မှတ်ချက်များကို comment အဖြစ်။

## သိထားရန်

reviewer ရေးသည့်အရာကို ရေးထားသည့်အတိုင်း ပြသသည်။ CadCraft သည် package တွင် တွေ့သော ညွှန်ကြားချက်များကို ဘယ်တော့မှ မလိုက်နာပါ; ၎င်းတို့ကို သင့်အား ပြသရုံသာ ပြသသည်။

ပယ်ချထားသည်များနှင့် ဖွင့်ထားသည် အပြောင်းအလဲများသည် ပုံဆွဲတွင် ဘာမျှ မထည့်ပါ။ package ကို သင့်ကွန်ပျူတာပေါ်တွင် ဖတ်သည်; ဘာမျှ အပ်လုဒ်မလုပ်ပါ။

သင့် assistant ချိတ်ဆက်ထားလျှင် package ကို ဖတ်ပြီး ဆုံးဖြတ်ချက်များ မှတ်တမ်းတင်ကာ ၎င်းတို့ကို `redline_read`၊ `redline_decide`၊ `redline_apply` နှင့် `redline_answers` tools ဖြင့် အသုံးပြုနိုင်သည်; ပုံဆွဲပြောင်းလဲမှုသည် undo တစ်ကြိမ်ဖြစ်ပြီး "Assistant: Redline to revision" ဟု ခေါ်သည်။
