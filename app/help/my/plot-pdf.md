## သင်ပြုလုပ်မည့်အရာ

စာရွက်တစ်ရွက်ကို မူရင်းအရွယ်အတိုင်း PDF တစ်ခု၊ ထို့နောက် မော်ဒယ်ကို 1:100 ဖြင့် အမြန် PDF တစ်ခု နှင့် ပရင့်ထွက်စာတစ်ခု ပြုလုပ်ပါမည်။

PDF ကို သင့် browser အတွင်းတွင် ပြုလုပ်ပါသည်၊ တစ်စုံတစ်ခုမျှ upload မလုပ်ပါ။ ၎င်းသည် vector PDF ဖြစ်ပြီး မည်သည့် zoom အဆင့်တွင်မဆို မျဉ်းများ ကြည်လင်ပြီး စာသားကို ရှာဖွေနိုင်ပါသည်။

## စာရွက်တစ်ရွက် ပလော့ရန်

1. ပုံဆွဲချပ်အောက်ရှိ စာရွက်၏ tab ကို နှိပ်ပါ။
2. {{key:Mod+P}} ကိုနှိပ်ပါ၊ {{ui:Plot}} ကို နှိပ်ပါ၊ သို့မဟုတ် `PLOT` ဟု ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။

{{ui:Plot to PDF}} dialog ဖွင့်လာပါမည်။ ၎င်းက မည်သည့် စာရွက်ကို မည်သည့် စက္ကူပေါ်တွင် "မူရင်းအရွယ် … သင်မြင်ရသည့်အတိုင်း" ပလော့မည်ကို ပြပါမည်။ ညာဘက်ရှိ preview တွင် စာရွက်ကို မြင်ရပါမည်။

3. {{ui:Plot style}} တွင် မျဉ်းအနက်များအတွက် {{ui:Monochrome (black)}}၊ အရောင်များကို ထိန်းသိမ်းရန် {{ui:Colour (as drawn)}}၊ {{ui:Grayscale}}၊ သို့မဟုတ် သင့်ကိုယ်ပိုင် ဇယား တစ်ခုကို ရွေးပါ (see [Plot style tables](topic:plot-pdf#plot-style-tables))။ စာရွက်သည် ဤရွေးချယ်မှုကို ထိန်းသိမ်းထားပြီး ၎င်းသည် ပုံဆွဲချပ်နှင့်အတူ သိမ်းဆည်းခံရပါသည်။
4. {{ui:Line weight}} တွင် 0.13 mm မှ 0.70 mm အထိ ကလမ်းအထူကို ရွေးပါ။ မူရင်း lineweight ရှိသော မျဉ်းများသည် ဤအထူဖြင့် ပရင့်ထွက်ပြီး၊ ကိုယ်ပိုင် lineweight ရှိသော မျဉ်းများ (layer သို့မဟုတ် object၊ ဇယားထဲရှိ ၎င်းတို့၏ အရောင် pen) သည် ထို lineweight ဖြင့် ပရင့်ထွက်ပါသည်။
5. {{ui:Download PDF}} ကို နှိပ်ပါ။

Browser က ပုံဆွဲချပ်နှင့် စာရွက်အမည်ဖြင့် PDF ကို ဒေါင်းလုဒ်ဆွဲပါမည်၊ ဥပမာ `Drawing1-A-101 Plan.pdf`။ history တွင် ၎င်း၏ အရွယ်အစားကို bytes ဖြင့်နှင့် စက္ကူအရွယ်ကို millimeters ဖြင့် ဖော်ပြပါမည်။

စာရွက်တစ်ရွက်သည် အမြဲတမ်း ကိုယ်ပိုင်စက္ကူပေါ်တွင် 1:1 ဖြင့် ပလော့ပါသည်။ စက္ကူကို ပြောင်းလိုပါက စာရွက်ပေါ်တွင်ပင် ပြောင်းပါ (see [Set up a sheet](topic:sheets-and-viewports))။ ပလော့ မလုပ်ရန် သတ်မှတ်ထားသော layer များနှင့် viewport frame များကို ချန်ထားပါမည်။

## စာရွက်အားလုံး PDF တစ်ခုတည်းတွင်

စာရွက်နှစ်ရွက် သို့မဟုတ် ထို့ထက်ပို၍ ရှိပါက {{ui:Plot to PDF}} dialog တွင် {{ui:All sheets in one PDF}} ရှိပါသည်၊ သို့မဟုတ် {{cmd:PUBLISH}} ဟု ရိုက်ပါ။ {{key:Enter}} ကို နှိပ်ပါက စာရွက်အားလုံးကို ယူပါမည်။ `S` (အချို့) ကို နှိပ်ပါက ၎င်းတို့၏ အမည်များကို ကော်မာဖြင့် ခြားပြီး ထည့်ရန် မေးပါမည်။ PDF တစ်ခု ဒေါင်းလုဒ်ဆွဲမည်ဖြစ်ပြီး စာရွက်တစ်ရွက်လျှင် စာမျက်နှာတစ်မျက်နှာ၊ tab အစဉ်လိုက်၊ စာရွက်တစ်ခုစီသည် ကိုယ်ပိုင်စက္ကူအရွယ်ဖြင့်၊ စာရွက်တစ်ရွက်လျှင် အမည်ပါသော bookmark တစ်ခု ပါဝင်ပါမည်။ စာရွက်တစ်ရွက်စီသည် ကိုယ်ပိုင် plot style ဇယားဖြင့် ပလော့ပါသည်၊ မရွေးထားသော စာရွက်သည် dialog တွင် နောက်ဆုံးရွေးထားသည့် ဇယားနှင့် နောက်ဆုံးရွေးထားသည့် pen အကျယ်ကို သုံးပါမည်။

## မော်ဒယ်ကို ပလော့ရန်

1. {{ui:Model}} tab ကို နှိပ်ပါ။
2. {{key:Mod+P}} ကို နှိပ်ပါ။

Dialog က မော်ဒယ်ကို စက္ကူတစ်ရွက်ပေါ်သို့ ပလော့မည်ဟု ပြောပြပြီး ထပ်မံ ဆက်တင်များကို ပြပါမည်:

3. {{ui:Area}} တွင် ပလော့လိုသည်ကို ရွေးပါ:
   - {{ui:Everything (extents)}}: ပုံဆွဲချပ်တစ်ခုလုံး။
   - {{ui:What is on screen}}: ယခု ပုံဆွဲချပ်တွင် သင်မြင်နေရသော နေရာ။
   - {{ui:A window…}}: ထို့နောက် {{ui:Pick}} ကို နှိပ်ပါ၊ ပုံဆွဲချပ်ပေါ်တွင် ထောင့်နှစ်ခုကို နှိပ်ပါ၊ dialog ပြန်ပေါ်လာပါမည်။
4. {{ui:Paper}} တွင် အရွယ်တစ်ခု ရွေးပါ: ISO A4 မှ A0၊ Letter၊ Legal၊ Tabloid နှင့် ANSI C နှင့် D၊ သို့မဟုတ် ARCH C၊ D နှင့် E။
5. {{ui:Orientation}} တွင် {{ui:Landscape}} သို့မဟုတ် {{ui:Portrait}} ကို ရွေးပါ။
6. {{ui:Scale}} တွင် {{ui:Fit to paper}} သို့မဟုတ် `1:100` ကဲ့သို့ အတိုင်းအတာတစ်ခု ရွေးပါ။

ဆက်တင်များအောက်တွင် အတိုင်းအတာနှင့် ဧရိယာသည် စက္ကူပေါ်တွင် ဘယ်လောက်ကြီးထွက်မည်ကို စာကြောင်းတစ်ကြောင်းက ဖော်ပြပါသည်။ စက္ကူထက် ကြီးနေပါက ၎င်းက ပြောပြပါမည်: အနားများ ဖြတ်တောက်ခံရပါမည်။ အတိုင်းအတာ ငယ်ငယ်ကို၊ စက္ကူ ကြီးကြီးကို၊ သို့မဟုတ် {{ui:Fit to paper}} ကို ရွေးပါ။

7. {{ui:Download PDF}} ကို နှိပ်ပါ။

မော်ဒယ် ပလော့တွင် ပုံနှိပ်စက်အများစုသည် အနားသို့ ပရင့်မထုတ်နိုင်သောကြောင့် အနားဘေးတစ်ဝိုက်တွင် 5 mm margin ထားပါသည်။ {{ui:Fit to paper}} သည် စံမဟုတ်သော အတိုင်းအတာ (history နှင့် info စာကြောင်းက "(fitted)" ဟု ပြပါသည်) ပေးပါသည်; ပုံဆွဲချပ်ကို အမှန်တကယ် တိုင်းတာရန် လိုပါက စံအတိုင်းအတာကို ရွေးပါ။

:::note
အတိုင်းအတာများကို အမှန်တကယ် ယူနစ်များဖြင့် ဖတ်ပါသည်။ 1:100 မှန်ကန်စေရန် {{ui:Current settings}} ရှိ {{ui:Units}} ကို ပုံဆွဲချပ်ယူနစ် တစ်ခု၏ တန်ဖိုးအဖြစ် သတ်မှတ်ပါ။ ယူနစ်မပါသော ပုံဆွဲချပ်ကို millimeters ဟု ယူဆပါသည်။
:::

## Plot style ဇယားများ

Plot style ဇယားသည် ပုံဆွဲချပ်အရောင် စံ 255 ခုစီ ပရင့်ထွက်ပုံကို ဖော်ပြပါသည်၊ အခြား CAD ပရိုဂရမ်များရှိ color-dependent plot style ဇယား (CTB) နည်းတူ ဖြစ်ပါသည်။ ဇယား သုံးခု ပါဝင်ပြီးသားဖြစ်ပါသည်:

| ဇယား | ပရင့်ထွက်ပုံ |
|---|---|
| {{ui:Colour (as drawn)}} | အရာတိုင်းကို ကိုယ်ပိုင်အရောင်ဖြင့်။ |
| {{ui:Monochrome (black)}} | အရောင်အားလုံး အနက်။ ပုံဆွဲချပ်အတွက် အများဆုံး ရွေးချယ်မှု။ |
| {{ui:Grayscale}} | အရောင်တိုင်းကို ၎င်း၏ မီးခိုးရောင်ဖြင့်၊ ထို့ကြောင့် အဖြူအမည်းပရင်တာတွင် အရောင်များ ခွဲခြားနိုင်ပါသည်။ |

ကိုယ်ပိုင်ဇယား ပြုလုပ်ရန် ဥပမာ အနီရောင် မျဉ်းများကို ထူစေပြီး အနက်ရောင် ပြုလုပ်ကာ၊ အခြားအရာများကို ပါးစေရန်:

1. {{ui:Plot to PDF}} dialog တွင် {{ui:Edit tables…}} ကို နှိပ်ပါ (သို့မဟုတ် {{cmd:PLOTSTYLES}} ဟု ရိုက်ပါ)။
2. {{ui:New}} ကို နှိပ်ပြီး {{ui:Name}} တွင် `office` ကဲ့သို့ အမည်တစ်ခု ရိုက်ပါ။ built-in ဇယားမှ စတင်လိုပါက {{ui:Table}} တွင် ရွေးပြီး {{ui:Copy}} ကို နှိပ်ပါ။
3. grid ထဲတွင် အရောင်တစ်ခုကို နှိပ်ပါ။ {{key:Shift}}+နှိပ်ခြင်းဖြင့် အရောင်အကွာအဝေးကို ရွေးပြီး၊ {{key:Mod}}+နှိပ်ခြင်းဖြင့် တစ်ခု ထပ်ထည့်ပြီး၊ {{ui:Select every colour}} ဖြင့် အားလုံးကို ယူပါ။
4. ရွေးထားသော အရောင်များ ပရင့်ထွက်ပုံကို သတ်မှတ်ပါ:
   - {{ui:Prints in}}: {{ui:Its own colour}}၊ {{ui:Black}} သို့မဟုတ် {{ui:Another colour…}}။
   - {{ui:As a gray}}: အရောင်ကို ၎င်း၏ မီးခိုးရောင်အဖြစ်။
   - {{ui:Ink (%)}}: 100 သည် မင်အပြည့်၊ 50 သည် ဖြူရောင်နှင့် တစ်ဝက် (screening)၊ နောက်ခံမျဉ်းများအတွက်။
   - {{ui:Lineweight}}: {{ui:Its own lineweight}} သည် object သို့မဟုတ် layer ၏ lineweight ကို ထိန်းသိမ်းပါသည်; တန်ဖိုးတစ်ခုသတ်မှတ်ပါက ထို အရောင်၏ မျဉ်းအားလုံးကို ထို အထူဖြင့် ပရင့်ထုတ်ပါမည်။
   - {{ui:Linetype}}: ထို အရောင်၏ မျဉ်းအားလုံးကို အခြား linetype ဖြင့် ပရင့်ထုတ်ပါ (ဥပမာ အနီရောင်အားလုံး dashed); {{ui:Use the object's linetype}} သည် မူရင်းကို ထားခဲ့ပါမည်။
   - {{ui:Line end}} နှင့် {{ui:Line join}}: butt၊ square သို့မဟုတ် round အဆုံးများ၊ နှင့် miter၊ bevel သို့မဟုတ် round ထောင့်များ (တစ်ခုမျှ မသတ်မှတ်ပါက round ဖြစ်သည်၊ ယခင်အတိုင်း)။
   - {{ui:Fill style}}: ထို အရောင်၏ solid fill သည် မင်အစား hatch မျဉ်းများ (အလျား သို့မဟုတ် ဒေါင်လိုက် ဘားများ၊ စောင်းများ၊ crosshatch၊ diamond၊ square dot များ) အဖြစ် ပရင့်ထွက်ပါသည်၊ ပြားသော မင်သည် ပြင်းလွန်းသော printer နှင့် ပုံများအတွက်ဖြစ်သည်။
   ဇယားတွင် နောက်ထပ် ဆက်တင် နှစ်ခု ရှိပါသည်: {{ui:Lineweights}}၊ ၎င်းသိသော အထူများ (ပရင့်ထွက်မျဉ်းတစ်ခုသည် အနီးဆုံးအထူသို့ ရောက်ပါသည်) နှင့် {{ui:Linetype scale}}၊ ISO မဟုတ်သော linetype အားလုံးရှိ dash များအပေါ် မြှောက်ကိန်းတစ်ခု။
5. {{ui:Done}} ကို နှိပ်ပါ။ ဇယားကို ပုံဆွဲချပ်တွင် ထိန်းသိမ်းထားပြီး စာရွက် (သို့မဟုတ် မော်ဒယ်) သည် ယခု ၎င်းဖြင့် ပလော့ပါသည်။ {{ui:Cancel}} သည် ပြောင်းလဲမှုများကို ဖျက်ပါသည်။

ကိုယ်ပိုင် pen ရှိသော အရောင်တစ်ခုသည် ထောင့်တွင် အစက်တစ်ခု ပြပြီး lineweight သတ်မှတ်ထားပါက အောက်ခြေတွင် အစက်တစ်ခု ပြပါသည်။ true color (255 ထဲမှ မဟုတ်သော) ရှိသော object သည် အနီးဆုံး စံအရောင်၏ pen ကို သုံးပါသည်။

ပုံဆွဲချပ်သည် DWG (2000 မှ 2018) သို့မဟုတ် DXF (R12 သို့မဟုတ် 2000) အဖြစ် သိမ်းသောအခါ ၎င်း၏ ဇယားများနှင့် စာရွက်တစ်ရွက်စီ၏ ရွေးချယ်မှုကို ထိန်းသိမ်းပြီး ဖွင့်သောအခါ ပြန်ပါဝင်ပါသည်။ အခြား program များက စာရွက်တစ်ရွက်စီ၏ page setup (`office.ctb`) တွင် အမည်ကိုသာ မြင်ရပြီး ဇယားကို မမြင်ပါ။ အခြား program မှ ပုံဆွဲချပ်ဖြစ်ပြီး page setup တွင် `monochrome.ctb` ကဲ့သို့ ဇယားကို အမည်ပေးထားပါက built-in ဇယား ထိုအမည်ဖြင့် ပလော့ပါသည်; အခြားအမည်များအတွက် dialog က ပုံဆွဲချပ်တွင် ထိုဇယား မရှိကြောင်း ပြပြီး ဇယားတစ်ခု ရွေးချယ်သည်အထိ သို့မဟုတ် ထိုအမည်ဖြင့် တစ်ခု ပြုလုပ်သည်အထိ ပုံဆွဲချပ်အရောင်များကို ပလော့ပါသည်။

ဇယားကို ပုံဆွဲချပ်အခြားတစ်ခုတွင် သုံးရန် {{ui:Plot style ဇယားများ}} တွင် {{ui:Export}} ကို နှိပ်ပါ (`office.plotstyle.json` ကို သိမ်းပါမည်)၊ ထို့နောက် အခြားပုံဆွဲချပ်တွင် {{ui:Import…}} ကို နှိပ်ပါ။ {{ui:Import…}} သည် အခြား program မှ `.ctb` ဖိုင်ကိုလည်း ယူပါသည်: ၎င်းကို ဖော်မတ်၏ ထုတ်ပြန်ထားသော ဖော်ပြချက်မှ ဖတ်ပြီး **အမှန်တကယ် ဖိုင်တစ်ခုနှင့် မစစ်ဆေးရသေးပါ**။ အရောင်၊ screening နှင့် အရောင်တစ်ခုစီ၏ lineweight ကို ဖတ်ပါသည်; grayscale၊ pen နံပါတ်များ၊ linetype များ၊ line end နှင့် join များနှင့် fill style များကို မဖတ်ပါ၊ အမည်ပေးထားသော ဇယား (`.stb`) ကို လက်မခံပါ။ ပထမဆုံး ပလော့ကို မျှော်လင့်ထားသည်နှင့် နှိုင်းယှဉ်ပါ၊ မှားနေပါက ဖိုင်ကို ကျွန်ုပ်တို့ထံ ပို့ပေးပါ။

## ပရင့်ထုတ်ခြင်း

**Browser တွင်** {{ui:Print…}} ကို နှိပ်ပါ။ CadCraft က PDF ကို ပြုလုပ်ပြီး ၎င်းအတွက် browser ၏ ကိုယ်ပိုင် print dialog ကို ဖွင့်ပေးပါမည်။ အတိုင်းအတာကို ထိန်းရန် ထို dialog တွင် "Actual size" သို့မဟုတ် 100% ကို ရွေးပါ (Fit မဟုတ်ပါ)။ browser က စာမျက်နှာမှ ပရင့်မထုတ်နိုင်ပါက PDF ကို tab အသစ်တွင် ဖွင့်ပေးပါမည်: ထို tab မှ {{key:Mod+P}} ဖြင့် ပရင့်ထုတ်ပါ။

{{ui:Open to print}} ကိုလည်း နှိပ်နိုင်ပါသည်: PDF သည် browser tab အသစ်တွင် ဖွင့်မည်ဖြစ်ပြီး ထိုနေရာမှ ပရင့်ထုတ်ပါ။

:::safari
Safari သည် PDF ကို ပြနိုင်ပြီး **File** ထို့နောက် **Print** ကို သင် အသုံးပြုမည်ကို စောင့်နိုင်ပါသည်။
:::

သင့် browser က tab အသစ်ကို ပိတ်ပါက CadCraft က PDF ကို အစားဒေါင်းလုဒ်ဆွဲပြီး history တွင် ထိုသို့ ပြောပါမည်။ နောက်တစ်ကြိမ် tab တွင် ဖွင့်ရန် site အတွက် pop-ups ကို ခွင့်ပြုပါ။

**CadCraft Studio တွင်** {{ui:Plot to PDF}} dialog သည် ကွန်ပျူတာ၏ ပရင်တာများကို ဖော်ပြပါသည်။ {{ui:Printer}}၊ {{ui:Paper in the printer}} နှင့် {{ui:Copies}} အရေအတွက်ကို ရွေးပြီး {{ui:Print…}} ကို နှိပ်ပါ။ {{ui:Same as the plot}} သည် ပရင်တာ၏ စက္ကူထဲမှ စာရွက်အရွယ်နှင့် တူသော (A3 စာရွက်အတွက် A3) စက္ကူကို ရွေးပေးပါသည်; ပရင်တာတွင် မရှိပါက ၎င်း၏ကိုယ်ပိုင် စက္ကူကို သုံးပြီး စာရွက်ကို ထိုနှင့် ကိုက်ညီအောင် ချိန်ပါမည်။ Windows တွင် PDF program မရှိဘဲ PDF ပရင့်ထုတ်၍ မရသောကြောင့် စာရွက်ကို 300 dpi ပုံအဖြစ် ပို့ပါသည်; Linux နှင့် macOS တွင် PDF ကိုယ်တိုင်ကို စနစ်၏ print service သို့ ပို့ပါသည်။ မည်သည့်အရာမျှ ကွန်ပျူတာမှ မထွက်ပါ။

## ပုံနှင့် SVG ဖိုင်များ

{{ui:Download PNG}} သည် ပလော့ထားသော စာရွက်ကို 300 dpi ဖြင့် ပုံအဖြစ် သိမ်းပါသည် (စာရွက်ကြီးလွန်းပြီး browser က မပြုလုပ်နိုင်လောက်အောင် ကြီးမည့်အခါမှသာ လျော့ပါမည်; history က ထိုသို့ ပြောပါမည်)။ {{ui:Download SVG}} သည် ၎င်းကို မီလီမီတာဖြင့် အတိုင်းအတာကြီးငယ်ရနိုင်သော ပုံဆွဲချပ်အဖြစ်၊ ပလော့၏ မျဉ်းနှင့် စာသားများဖြင့် သိမ်းပါသည်။ နှစ်ခုစလုံးသည် PDF နှင့် တူညီသော ပလော့မှ လာပြီး တူညီသော plot style၊ line weight နှင့် ဧရိယာကို သုံးပါသည်။ ပုံဆွဲချပ်ထဲတွင် ထည့်ထားသော ပုံများကို PDF ထဲတွင်သာ ပါဝင်ပြီး history က ချန်ထားခဲ့သော အရေအတွက်ကို ပြောပါသည်။

## ပုံများ

ပုံများကို ၎င်းတို့၏ မူရင်း resolution ဖြင့် ပရင့်ထုတ်ပြီး မျဉ်းများအောက်တွင် ထားပါသည်။ dialog ရှိ {{ui:Pictures}} သည် ဖိုင်ငယ်ရန် 600၊ 300 သို့မဟုတ် 150 dpi ဖြင့် ကန့်သတ်ပါသည်။ မျဉ်း၊ စာသားနှင့် hatch များသည် အမြဲတမ်း ကြည်လင်ပြီး (vector)၊ transparency သည် transparency အဖြစ် ဆက်ရှိပါသည်။ see [Pictures in a drawing](topic:pictures)။

## အမှတ်ရထားသော ဆက်တင်များ

Dialog သည် ဤ browser တွင် သင်၏ နောက်ဆုံး စက္ကူ၊ orientation၊ အတိုင်းအတာနှင့် line weight ကို မှတ်ထားပါသည်။ plot style ဇယားကို ပုံဆွဲချပ်တွင် စာရွက်တစ်ရွက်စီနှင့် ထိန်းသိမ်းထားပြီး၊ မရွေးထားသော စာရွက်သည် နောက်ဆုံးရွေးထားသည့်ဇယားဖြင့် စတင်ပါသည်။ ရွေးထားသော ဝင်းဒိုးကို စာမျက်နှာ reload မလုပ်မချင်း ထိန်းသိမ်းထားပြီး၊ ထို့နောက် dialog သည် {{ui:Everything (extents)}} မှ စတင်ပါသည်။

## အမှားများ အများဆုံး

- **PDF အလွတ်ဖြစ်နေသည် သို့မဟုတ် ခလုတ်များ မီးခိုးရောင်ဖြစ်နေသည်။** ပလော့စရာ မရှိပါ (မော်ဒယ် အလွတ်)၊ သို့မဟုတ် {{ui:A window…}} ကို ရွေးထားပြီး ဝင်းဒိုး မရွေးရသေးပါ ("Pick the window to plot.")။
- **PDF ထဲတွင် စာသားက "?" ပြနေသည်။** ပိုလန်၊ ချက်၊ ဆီရီလစ်၊ ဂရိနှင့် ဥရောပ၏ အခြား စာလုံးများရှိ စာသားများသည် မိမိအတိုင်း ပရင့်ထွက်ပါသည်; PDF တွင် လိုအပ်သော စာလုံးများ (Liberation Sans ဖောင့်မှ၊ Helvetica ၏ အကျယ်များရှိသော) ပါဝင်ပြီး စာသားကို ရွေးနိုင်၊ ရှာနိုင်ပါသည်။ တရုတ်၊ ဂျပန်နှင့် ကိုရီးယား စာသားများလည်း မိမိအတိုင်း ပရင့်ထွက်ပါသည်: ပုံဆွဲချပ်တွင် ပါဝင်ပါက ပလော့သည် ပိုကြီးသော ဖောင့် (~10 MB၊ တစ်ကြိမ်သာ) ကို ယူပြီး PDF တွင် သုံးထားသော စာလုံးများသာ ပါဝင်ပါသည်၊ ထို့ကြောင့် ပထမဆုံးအကြိမ်တွင် ချိတ်ဆက်မှု လိုပါသည် (အော့ဖ်လိုင်း မိတ္တူ မဟုတ်ပါ၊ ၎င်းကို ယခင်က သိမ်းထားလျှင်)။ ဟီဘရူးစာသားသည် Latin စာသားနှင့် တူညီသော embedded ဖောင့်ဖြင့် ပရင့်ထွက်ပြီး၊ အာရဗီ၊ ပါရှန်နှင့် ဥရဒူ စာသားများက ပလော့ကို ဖောင့်တစ်ခုထပ် ယူစေပါသည် (1 MB အောက်၊ တစ်ကြိမ်သာ); ညာမှ ဘယ်သို့ ဖတ်ရသော မျဉ်းများကို စီပြီး စာလုံးများကို ချိတ်ဆက်ပါသည် (see [Text](topic:text))။ ထိုဖောင့်များအပြင်ရှိ ရှားပါးသော ideograph များနှင့် Hindi ကဲ့သို့ complex shaping လိုသော စာလုံးများသည် "?" ဟု ပရင့်ထွက်ပြီး history က ရေတွက်ပါသည်။
- **မျဉ်းအားလုံး အထူတူနေသည်။** ၎င်းတို့၏ lineweight သည် မူရင်းဖြစ်ပါသည်: ညာဘက်ပန်နယ်ရှိ {{ui:Lineweight}} ကို layer သို့မဟုတ် object များအတွက် ပေးပါ (see [Line weights and linetypes](topic:units-papers-scales#line-weights-and-linetypes))၊ သို့မဟုတ် [plot style ဇယား](topic:plot-pdf#plot-style-tables) တွင် အရောင်တစ်ခုစီအလိုက် lineweight သတ်မှတ်ပါ။
- **Plot style ဘေးတွင် "(not in this drawing)"။** ပုံဆွဲချပ်သည် အခြား program မှ ဖြစ်ပြီး ၎င်းထည့်မထားသော ဇယားတစ်ခုကို အမည်ပေးထားသည်။ ဇယားတစ်ခု ရွေးပါ၊ သို့မဟုတ် ထိုအမည်ဖြင့် တစ်ခု ပြုလုပ်ပါ။
- **Construction line များ ပရင့်ထွက်သည်။** ၎င်းတို့၏ layer ကို ပလော့မလုပ်ရန် သတ်မှတ်ပါ: {{ui:Layers}} ပန်နယ်ရှိ ၎င်း၏ printer ခလုတ်ကို နှိပ်ပါ။
- **ပရင့်ထွက်ပုံ အရွယ်မှားနေသည်။** ပရင်တာက ချိန်ညှိထားသည်။ Actual size ဖြင့် ပရင့်ထုတ်ပါ။
- **{{key:Mod+P}} က browser ၏ print dialog ကို ဖွင့်သည်။** Cursor သည် ညာဘက်ပန်နယ်ရှိ အကွက်တစ်ခုတွင် ရှိနေသည်၊ သို့မဟုတ် အခြား dialog ဖွင့်ထားသည်။ {{key:Enter}} သို့မဟုတ် {{key:Esc}} ကို နှိပ်ပြီး အကွက်မှ ထွက်ပါ၊ ထို့နောက် ထပ်ကြိုးစားပါ၊ သို့မဟုတ် {{ui:Plot}} ကို နှိပ်ပါ။
- **{{key:Mod+P}} ဘာမျှ မဖြစ်ပါ။** command တစ်ခု လုပ်ဆောင်နေသည်။ ဦးစွာ {{key:Esc}} ကို နှိပ်ပါ။
