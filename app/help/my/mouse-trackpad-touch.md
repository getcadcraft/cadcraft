CadCraft ကို wheel ပါသော မောက်စ်အတွက် ဒီဇိုင်းထုတ်ထားသည်။ အရာအားလုံးသည် trackpad ဖြင့်လည်း အလုပ်လုပ်သော်လည်း လေ့လာရန် အလေ့အကျင့်အချို့ ရှိသည်။ touch screen သည် ရွေးချယ်ခြင်းအတွက် အလုပ်လုပ်သော်လည်း ကန့်သတ်ချက်များ ရှိသည်။

## Wheel မောက်စ်

- **ချဲ့ခြင်း:** wheel ကို လှိမ့်ပါ။ ပုံဆွဲသည် crosshair ၏ ဘေးပတ်လည်တွင် ချဲ့သည်၊ ထို့ကြောင့် မြင်လိုသည့်အရာကို ညွှန်ပြပါ။
- **ရွှေ့ကြည့်ခြင်း:** wheel ကို ဖိထားပြီး ဆွဲပါ၊ သို့မဟုတ် ညာခလုတ်ဖြင့် ဆွဲပါ။
- **အရာအားလုံးကို ချဲ့ခြင်း:** wheel ကို နှစ်ကြိမ်နှိပ်ပါ၊ သို့မဟုတ် {{ui:Extents}} ကို နှိပ်ပါ။
- **မတိုင်ခင် view သို့ ပြန်ခြင်း:** View အုပ်စုရှိ {{ui:Previous}} ကို နှိပ်ပါ၊ သို့မဟုတ် `Z`၊ {{key:Enter}}၊ `P`၊ {{key:Enter}} ကို ရိုက်ပါ။ wheel အဆင့်များ တစ်ကြောင်းသည် view တစ်ခုအဖြစ် ရေတွက်သည်၊ ထို့ကြောင့် {{ui:Previous}} တစ်ကြိမ်သည် ၎င်းကို ပြန်ဖျက်သည်။ ပြန်လာလိုသော view များကို {{cmd:NAMEDVIEW}} (`NV`) ဖြင့် သိမ်းပါ။
- **Enter:** ညာကလစ်နှိပ်ပါ။

## Trackpad

:::mac
- **ရွှေ့ကြည့်ခြင်း:** trackpad ပေါ်တွင် လက်နှစ်ချောင်းကို မည်သည့်ဘက်သို့မဆို ရွှေ့ပါ- ပုံဆွဲသည် သင့်လက်ကို လိုက်သည်။ လက်နှစ်ချောင်း နှိပ်ထားပြီး ဆွဲခြင်း (ညာခလုတ် ဆွဲခြင်း) ကိုလည်း သုံးနိုင်သည်။
- **ချဲ့ခြင်း:** လက်နှစ်ချောင်းဖြင့် pinch လုပ်ပါ။ ချဲ့ခြင်းသည် crosshair ကို လိုက်သည်။
- **ညာကလစ် (Enter):** လက်နှစ်ချောင်းဖြင့် နှိပ်ပါ။ မအလုပ်လုပ်ပါက **System Settings** တွင် "Secondary click" ကို ဖွင့်ပါ၊ ထို့နောက် **Trackpad**။ Control-click သည် CadCraft တွင် ညာကလစ်မဟုတ်ဘဲ ရိုးရိုး နှိပ်ခြင်းအဖြစ် ရေတွက်နိုင်သဖြင့် လက်နှစ်ချောင်း နှိပ်ခြင်းကို သုံးပါ။
- **နယ်ပယ်တစ်ခုသို့ ချဲ့ခြင်း:** View အုပ်စုရှိ {{ui:Window}} ကို နှိပ်ပြီး ထောင့်နှစ်ခု နှိပ်ပါ။
:::

:::windows linux
- **ရွှေ့ကြည့်ခြင်း:** touchpad ပေါ်တွင် လက်နှစ်ချောင်းကို မည်သည့်ဘက်သို့မဆို ရွှေ့ပါ- ပုံဆွဲသည် သင့်လက်ကို လိုက်သည်။ ညာခလုတ် နှိပ်ထားပြီး ဆွဲခြင်းဖြင့်လည်း လုပ်နိုင်သည်။
- **ချဲ့ခြင်း:** လက်နှစ်ချောင်းဖြင့် pinch လုပ်ပါ။ ချဲ့ခြင်းသည် crosshair ကို လိုက်သည်။
- **ညာကလစ် (Enter):** လက်နှစ်ချောင်းဖြင့် နှိပ်ပါ၊ သို့မဟုတ် touchpad ၏ ညာအောက်ထောင့်ကို နှိပ်ပါ၊ touchpad ဆက်တင်အပေါ် မူတည်သည်။
- **နယ်ပယ်တစ်ခုသို့ ချဲ့ခြင်း:** View အုပ်စုရှိ {{ui:Window}} ကို နှိပ်ပြီး ထောင့်နှစ်ခု နှိပ်ပါ။
:::

{{key:Space}} ကို ဖိထားပြီး ဆွဲခြင်းသည် CadCraft တွင် ရွှေ့ကြည့်**ခြင်းမဟုတ်ပါ**- {{key:Space}} သည် Enter ဖြစ်သည်။

wheel မောက်စ်သည် တစ်ဆင့်စီ ချဲ့သေးသည်။ wheel ကဲ့သို့ အဆင့်လိုက် scroll ပို့သော touchpad သည် ရွှေ့ကြည့်မည့်အစား လက်နှစ်ချောင် scroll ဖြင့် ချဲ့သည်- ချုံ့ပါ၊ သင်လိုချင်သော နေရာကို ညွှန်ပြပြီး ပြန်ချဲ့ပါ။ 3D tab သည် ၎င်း၏ trackpad လှုပ်ရှားမှုများကို ဆက်ထားသည် (see [Model in 3D](topic:3d-solids#look-around))။

## Touch screen နှင့် tablet များ

CadCraft သည် လက်ညှိုးကို မောက်စ်နှိပ်ခြင်းအဖြစ် ဖတ်သည်-

- ကြိတ်နှိပ်ခြင်းဖြင့် အမှတ် သို့မဟုတ် အရာဝတ္ထုကို ရွေးသည်။
- အလွတ်နေရာပေါ်တွင် လက်ညှိုးကို ဆွဲခြင်းသည် lasso ဆွဲသည် (ညာဘက်သို့ ပထမဆွဲလျှင် window၊ ဘယ်ဘက်သို့ ပထမဆွဲလျှင် crossing; see [Lasso selection](topic:lasso-selection))။
- {{cmd:TRIM}} နှင့် {{cmd:EXTEND}} တွင် အပိုင်းများကို လက်ညှိုးဖြင့် ဖြတ်ဆွဲလျှင် ၎င်းတို့အားလုံးကို ဖြတ်သည် သို့မဟုတ် တိုးချဲ့သည်။
- ရွေးထားသော အရာဝတ္ထု၏ grip ကို ဆွဲခြင်းသည် grip ကို ရွှေ့သည် (grip နှင့် pick box သည် လက်အတွက် ပိုကြီးသည်)။
- **Pinch** လက်နှစ်ချောင်းဖြင့် ၎င်းတို့ကြားရှိ အမှတ်ဘေးတွင် ချဲ့ရန်၊ လက်နှစ်ချောင်း အတူတကွ ရွှေ့ခြင်းဖြင့် **ရွှေ့ကြည့်**ရန်။ ဒုတိယလက်သည် ပထမလက် စတင်ထားသည့်အရာကို ဖျက်သိမ်းသည်၊ ထို့ကြောင့် pinch သည် အမှတ်အသား မချန်ထားပါ။
- **ကြာရှည်ဖိခြင်း** (ကိုယ်အပေါ်ဖိ ရပ်ထားခြင်း ဝက်ဝက်ခန့်) သည် ညာကလစ်- {{key:Enter}}။ command တစ်ခုကို အဆုံးသတ်သည်၊ ရွေးချယ်မှုကို ပြီးစီးစေသည်၊ သို့မဟုတ် နောက်ဆုံး command ကို ထပ်လုပ်သည်။

command line အောက်တွင် **ခလုတ်အတန်း** ပေါ်လာသည်- {{ui:Esc}}၊ Undo၊ Redo၊ tablet keyboard က ဖုံးထားသော စာလုံးများ (`@` `,` `<` `'` `"` `-`)၊ {{ui:Snap}}၊ {{ui:Ortho}}၊ keyboard ခလုတ်တစ်ခု၊ နှင့် ကြီးမားသော {{ui:Enter}}။ command သို့မဟုတ် ဂဏန်းရိုက်ရန် keyboard ခလုတ် (သို့မဟုတ် command line) ကို ကလစ်နှိပ်ပါ။

Hover မရှိပါ၊ ထို့ကြောင့် snap marker များသည် လက်ညှိုးရှိရာတွင်သာ ပေါ်သည်။

:::touch
သင်သည် touch screen ကို သုံးနေသည်။ အမြန်ကြည့်ခြင်းထက် ပိုလုပ်ရန်ရှိလျှင် ချိတ်ဆက်ထားသော keyboard နှင့် မောက်စ် သို့မဟုတ် trackpad က CadCraft ကို ပိုအဆင်ပြေစေသည်။
:::

## ဘရောက်ဇာများ

CadCraft သည် Chrome၊ Edge၊ Firefox နှင့် Safari၊ Mac၊ Windows နှင့် Linux တို့တွင် တူညီစွာ အလုပ်လုပ်သည်။ ကွာခြားချက်များမှာ သေးငယ်သည်-

| အကြောင်းအရာ | သိရန် |
|---|---|
| DWG ဖွင့်ခြင်း | ပုံဆွဲကြီးများသည် ဘရောက်ဇာတိုင်းတွင် စက္ကန့်အနည်းငယ် ယူသည်; status line တွင် "Reading …" ဟု ပြသည် |
| ဒေါင်းလုဒ်များ | ဘရောက်ဇာတိုင်းက ဒေါင်းလုဒ်များ မည်သည့်နေရာသို့ သွားမည်နှင့် မေးရန်ရှိမရှိကို ဆုံးဖြတ်သည်; see [Browsers and computers](common:browsers) |
| Open to print | PDF ကို tab အသစ်တွင် ဖွင့်သည်။ pop-up ကို ဘရောက်ဇာက ပိတ်ထားလျှင် CadCraft က PDF ကို ဒေါင်းလုဒ် လုပ်သည် |
| F7 | Firefox က caret browsing ကို ကမ်းလှမ်းနိုင်သည်; No ကို ရွေးပါ |
| မသိမ်းရသေးသော ပြောင်းလဲမှုများဖြင့် ထွက်ခြင်း | ဘရောက်ဇာတိုင်းသည် ၎င်းကိုယ်ပိုင် "Leave site?" မေးခွန်းကို ပြသည်၊ CadCraft က ပြောင်းလဲနိုင်ခြင်း မရှိပါ |

:::safari
Safari တွင် {{ui:Open to print}} ဖြင့် ဖွင့်ထားသော PDF သည် ပရင့်မထုတ်ဘဲ tab တွင်သာ ပြနိုင်သည်: **File** ထို့နောက် **Print** ကို သုံးပါ။
:::

:::firefox
Firefox က ဒေါင်းလုဒ်တစ်ခုစီအတွက် ဘာလုပ်ရမည်ကို မေးနိုင်သည်။ ဖိုင်ကို သိမ်းရန် ရွေးပါ၊ သို့မဟုတ် Firefox ဆက်တင်များအတွင်း Downloads အောက်တွင် တစ်ကြိမ်တည်း ပြောင်းပါ။
:::
