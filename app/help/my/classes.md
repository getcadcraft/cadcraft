လေယာများက အရာဝတ္ထု *ဘယ်နေရာ* ရှိသည်ကို ပြောပြပြီး အတန်းများက ၎င်း *ဘာ* ဖြစ်သည်ကို ပြောပြသည်။ လေယာ `Level 1` ပေါ်ရှိ နံရံတစ်ခုသည် အတန်း `Walls-Exterior` ထဲတွင် ရှိနိုင်ပြီး လေယာ `Ceiling` ပေါ်ရှိ spot မီး တစ်ခုသည် အတန်း `Lighting-Fixtures-Spot` ထဲတွင် ရှိနိုင်သည်။ လေယာတစ်ခုမှ တစ်ခုသို့ မရွှေ့ဘဲ လေယာအားလုံးရှိ မီးအားလုံးကို တစ်ပြိုင်နက် ဖုံးနိုင်သည်၊ သို့မဟုတ် ပြင်ပနံရံအားလုံးကို ပိုထူစွာ plot နိုင်သည်။

အရာဝတ္ထု တိုင်းသည် **None** အတန်းတွင် စတင်သည်။ အတန်းကိုယ်ပိုင် မရှိသော ပုံဆွဲသည် ယခင်အတိုင်း အလုပ်လုပ်သည်။

## Classes panel ကို ဖွင့်ခြင်း

`CLASSES` (သို့မဟုတ် `CLS`) ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:မြင်ကွင်း}} အုပ်စု၏ {{ui:နောက်ထပ်}} menu တွင် {{ui:ကလပ်စ်များ…}} ကို ရွေးပါ။ panel သည် ပုံဆွဲ၏ အပေါ်တွင် ပွင့်လာပြီး ဆွဲနေစဉ် ဖွင့်ထားသည်။

- **အတန်းထည့်ရန်:** အပေါ်ရှိ အကွက်တွင် အမည်ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။ `-` က အဆင့်ဖန်တီးသည်: `Lighting-Fixtures-Spot` သည် `Lighting-Fixtures` အောက်တွင်၊ ထို့နောက် `Lighting` အောက်တွင် ရှိသည်၊ ပျောက်နေသော အဆင့်များကို အလိုအလျောက် ထည့်ပေးသည်။
- **ပြခြင်း သို့မဟုတ် ဖုံးခြင်း:** အတန်းဘေးရှိ မျက်လုံး။ အတန်းတစ်ခုကို ဖုံးလျှင် ၎င်းအောက်ရှိ အတန်းအားလုံး ဖုံးသည်၊ မျက်နှာပြင်နှင့် စက္ကူ နှစ်ခုလုံးတွင်။
- **Active class:** စက်ဝိုင်း ခလုတ်။ သင်ဆွဲသော အရာသစ်များ active class ထဲသို့ ဝင်သည်။
- **အတန်းရွေးရန်:** အမည်ကို နှိပ်ပါ။ အောက်ရှိ ခလုတ်များနှင့် ဆက်တင်များသည် ထိုအတန်းပေါ်တွင် အလုပ်လုပ်သည်။

စာရင်း၏ အဆုံးရှိ ဂဏန်းတိုင်းသည် ထိုအတန်းထဲရှိ အရာဝတ္ထု အရေအတွက် ဖြစ်သည် (မော်ဒယ်၊ စာရွက်များနှင့် block definition များအတွင်း)။

## အရာဝတ္ထုများကို အတန်းထဲ ထည့်ခြင်း

အရာဝတ္ထုများကို ရွေးပြီး panel တွင် အတန်းတစ်ခု ရွေးကာ {{ui:Set class}} ကို ရွေးပါ။ ၎င်းတို့က အတန်းမှ အရောင်၊ linetype၊ lineweight၊ fill နှင့် text style ယူစေရန် {{ui:By class}} ကို အရင် ပြောင်းပါ။ အခြားနည်းများ:

- အရာဝတ္ထုများ ရွေးထားစဉ် `CLASS` ကို ရိုက်ပြီး အတန်းအမည် ထည့်ပါ (အမည်အသစ်ဆိုလျှင် အတန်းအသစ် ဖန်တီးမည်)။
- ဘာမျှ မရွေးဘဲ `CLASS` ကို ရိုက်လျှင် active class ကို သတ်မှတ်မည်; `?` က အတန်းများနှင့် အရေအတွက်များကို ပြသည်။
- Properties panel ရှိ {{ui:Class}} အပိုင်း: အတန်း၊ နှင့် အရောင်၊ linetype၊ lineweight အတွက် {{ui:… by class}} switch (hatch အတွက် fill၊ စာသားအတွက် text style)။
- `QSELECT` ဖြင့် အတန်းအလိုက် ရွေးပါ: {{ui:Class}} property ကို ရွေးပါ။

{{ui:Select its objects}} သည် ရွေးထားသော အတန်း၏ အရာဝတ္ထု အားလုံးကို ဖွင့်ထားသော စာရွက် (သို့မဟုတ် မော်ဒယ်) တွင် ရွေးပေးသည်။

## အရာဝတ္ထု ဘယ်လို ဆွဲထွက်သလဲ: အရာဝတ္ထု၊ အတန်း၊ လေယာ

အရာဝတ္ထု၏ အရောင်၊ linetype၊ lineweight၊ fill နှင့် text style သည် လေယာအတိုင်း **by class** ဖြစ်နိုင်သည်။ CadCraft က ဤအစီအစဉ်ဖြင့် ကြည့်သည်:

1. အရာဝတ္ထု၏ ကိုယ်ပိုင်တန်ဖိုး၊ ထိုတန်ဖိုးသည် by class မဟုတ်လျှင်။
2. အတန်း၏ တန်ဖိုး၊ အရာဝတ္ထုက by class ယူပြီး အတန်းတွင် ရှိလျှင်။
3. လေယာ၏ တန်ဖိုး။

အရောင် (သို့မဟုတ် linetype …) {{ui:မသတ်မှတ်ရသေး}} ဖြစ်သော အတန်းသည် အရာဝတ္ထုကို လေယာသို့ ပေးပို့သည်။ အတန်းတစ်ခုရွေးပြီး ခလုတ်များအောက်တွင် ၎င်း၏ {{ui:Color}}၊ {{ui:Linetype}}၊ {{ui:Lineweight}}၊ {{ui:Fill (hatches)}} နှင့် {{ui:Text style}} ကို သတ်မှတ်ပါ။ အတန်းတွင် ဆွဲသော အရာသစ်များ ၎င်းတို့အားလုံးကို by class ယူစေရန် {{ui:Use at creation}} ကို ရွေးပါ။

panel ရှိ ပြောင်းလဲမှု တိုင်းသည် undo အဆင့်တစ်ခုစီ ဖြစ်သည်။

## အမည်ပြောင်းခြင်းနှင့် ဖျက်ခြင်း

{{ui:Rename}} သည် အမည်ကို နေရာတွင်ပင် တည်းဖြတ်သည်: ထားရန် {{key:Enter}} ကို နှိပ်ပါ၊ ထွက်ရန် {{key:Esc}} ကို နှိပ်ပါ။ ၎င်းအောက်ရှိ အတန်းများလည်း လိုက်ပြောင်းသည် (`Lighting` ကို `Light` ဟု ပြောင်းလျှင် `Lighting-Spot` သည် `Light-Spot` ဖြစ်သည်)၊ ၎င်းတို့၏ အရာဝတ္ထုများနှင့် viewport override များလည်း လိုက်ပြောင်းသည်။

{{ui:Delete}} သည် အတန်းနှင့် ၎င်းအောက်ရှိ အတန်းအားလုံးကို ဖယ်ရှားသည်။ ၎င်းတို့၏ အရာဝတ္ထုများသည် **None** သို့ ရွှေ့သွားသည်။ {{ui:Undo}} တစ်ကြိမ်ဖြင့် အားလုံး ပြန်ရသည်။ **None** ကို အမည်ပြောင်း သို့မဟုတ် ဖျက်၍ မရပါ။

## Design layers

{{ui:Design layers}} အောက်တွင် လေယာတိုင်းတွင် စကေး (`1:50`) နှင့် elevation ထည့်နိုင်သည်။ design layer သည် ပုံမှန်လေယာ တစ်ခုဖြစ်သည်: မော်ဒယ်နေရာနှင့် စာရွက်များသည် ယခင်အတိုင်း အလုပ်လုပ်ပြီး စကေးနှင့် elevation ကို ၎င်းတို့ သုံးမည့် tool များအတွက် ပုံဆွဲနှင့်အတူ သိမ်းထားသည်။

## DWG နှင့် DXF ဖိုင်များ

အတန်းများကို CadCraft သိမ်းသော DWG ဗားရှင်းတိုင်းနှင့် DXF (R12 နှင့် 2000) တွင် ထိန်းသိမ်းသည်။ အရာဝတ္ထု တစ်ခုစီ၏ အတန်းသည် ၎င်း၏ ကိုယ်ပိုင် extended data ဖြစ်သည် (application `CADCRAFT_CLASS`)၊ ထို့ကြောင့် AutoCAD နှင့် အခြားပရိုဂရမ်များက ၎င်းကို အရာဝတ္ထုနှင့်အတူ ထိန်းသိမ်းသည်။ အတန်းစာရင်း၊ အရောင်များနှင့် မြင်ရမှုကို `CADCRAFT_CLASSES` အမည်ရှိ အသုံးမပြုသော block တစ်ခုတည်းတွင် သိမ်းသည်; အခြားပရိုဂရမ်က ထို block ကို purge လုပ်လျှင်၊ CadCraft သည် အရာဝတ္ထု တိုင်း၏ အတန်းကို ဆက်တွေ့ပြီး အတန်းများကို ပုံမှန်ဆက်တင်များဖြင့် ပြန်ပေါ်လာစေသည်။

အခြားပရိုဂရမ်များသည် အတန်းများကို မသိပါ: ၎င်းတို့သည် အရာဝတ္ထု တိုင်းကို ကိုယ်ပိုင် သို့မဟုတ် လေယာ၏ တန်ဖိုးဖြင့် ဆွဲသည်။
