လူနှစ်ယောက်က ပုံဆွဲတစ်ခုကို တည်းဖြတ်သည်။ ၎င်းတို့က မတူသော object များကို ပြောင်းလျှင် ပေါင်းခြင်းသည် အလိုအလျောက် ဖြစ်နိုင်သည်: လက်ဖြင့် ပြန်လုပ်စရာ မလိုပါ။

## အလုပ်လုပ်စေသည့်အရာ

CadCraft က သင် ဆွဲသော object တစ်ခုစီကို ဘယ်တော့မှ မပြောင်းပြီး တစ်ခုထက်ပို မပေးသော တိုတောင်းသော **key** ပေးသည်။ ၎င်းကို DWG သို့မဟုတ် DXF ထဲ object နှင့်အတူ သိမ်းသည် (အခြားပရိုဂရမ်များ ထိန်းသော အပိုဒေတာအဖြစ်)။ ပေါင်းခြင်းသည် ဖိုင်ထဲ နေရာအလိုက် မဟုတ်ဘဲ key ဖြင့် object များကို ရှာသည်၊ အကြောင်းမှာ ပရိုဂရမ်တိုင်း သိမ်းသည့်အခါ နေရာများကို နံပါတ်ပြန်ထိုးသောကြောင့် ဖြစ်သည်။ ပေါင်းခြင်း မလုပ်ပါက {{ui:Settings}} › CadCraft › Merge-friendly files တွင် ပိတ်ပါ; ဖိုင်များ ၁၀ ရာခိုင်နှုန်းခန့် ပိုသေးသည်။

Keys မရှိမီ သိမ်းထားသော ပုံဆွဲသည် ဆက်ပေါင်းနိုင်သည်: object များသည် ဖိုင်ထဲ နေရာမှ key ရသည်၊ ဖွင့်သူအားလုံးအတွက် တူညီသည်။

## တပ်ဆင်ရန်

Git သည် repository တစ်ခုအတွက် တစ်ကြိမ် စာကြောင်းနှစ်ကြောင်း လိုသည်:

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git မသုံးဘဲ ကိုယ်တိုင် run လျှင်: `cadcraft merge <base> <ours> <theirs> -o <result>`။ Fossil နှင့် Mercurial သည် ဖိုင်သုံးခုကို ၎င်းတို့၏ merge-tool setting တွင် တူညီစွာ ယူသည်။

## စည်းမျဉ်းများ

- တစ်ဘက်တည်းတွင်သာ ပြောင်းထားသော object ကို ယူသည်။ နှစ်ဘက်လုံးတွင် တူညီသော ပြောင်းလဲမှုကို တစ်ကြိမ်သာ ယူသည်။
- Property တစ်ခုကို နည်းနှစ်မျိုးဖြင့် ပြောင်းထားလျှင် **ပဋိပက္ခ** ဖြစ်သည်: သင့်ဘက်က ကျန်ပြီး အစီရင်ခံစာက တန်ဖိုးနှစ်ခုလုံးကို ဖော်ပြသည်။ ရလဒ်ကို ဖွင့်၊ ထို object ကို ကြည့်ပြီး လက်ဖြင့် ပြင်ပါ။
- တစ်ဘက်တွင် ထည့်ထားသော object ကို ထိန်းသည်။ တစ်ဘက်တွင် ဖျက်ပြီး အခြားဘက်တွင် မထိသော object ကို ဖျက်သည်။ တစ်ဘက်တွင် ဖျက်ပြီး အခြားဘက်တွင် ပြောင်းထားလျှင်: ဖျက်ပြီး အစီရင်ခံသည်။
- လေယာများ၊ block များ၊ စာသားနှင့် dimension style များ၊ စာရွက်များနှင့် အမည်ပေးထားသော မြင်ကွင်းများကို တူညီစွာ ပေါင်းသည်။ Constraint များသည် ၎င်းတို့ အမည်ပေးထားသော object များကို လိုက်သည်။
- ရလဒ်ကို သင်၏ ဖိုင်ပုံစံနှင့် ဗားရှင်းအတိုင်း ရေးသည်။

မပေါင်းသည်များ: object များ ဆွဲသည့် အစီအစဉ်သည် သင့်ဖြစ်ပြီး၊ ထို့နောက် အခြားဘက်က ထည့်ထားသော object များ ပါသည်။ နှစ်ဘက်လုံးတွင် block definition တူတူကို ပြောင်းလျှင် ပဋိပက္ခ ဖြစ်သည်၊ ဘယ်တော့မှ ရောမထားပါ။ ဘာမျှ upload မလုပ်ပါ; အားလုံး သင့်ကွန်ပျူတာပေါ်တွင် run သည်။
