မျက်နှာပြင်တွင် အပိုင်းခုနစ်ခု ရှိသည်။ အပေါ်မှ အောက်သို့: app bar၊ toolbar၊ panel တစ်ခုစီပါသော ပုံဆွဲနေရာ၊ ပုံဆွဲအောက်ရှိ tab များ၊ command လိုင်းနှင့် အခြေအနေဘား။

## App bar

အပေါ်ဆုံးရှိ ပါးလွှာသော bar သည် ပုံဆွဲနှင့် မဆိုင်ဘဲ ဆိုဒ်နှင့် ဆိုင်သည်။ CadCraft အမှတ်တံဆိပ်၊ အက်ပ်အမည်၊ သင်ဖွင့်ထားသော ဗားရှင်း၊ အက်ပ်၏စာမျက်နှာသို့ link၊ {{ui:အကူအညီ}} ခလုတ် (သို့မဟုတ် {{key:F1}})၊ {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} ခလုတ်၊ {{ui:အပြည့်မျက်နှာပြင်}} ခလုတ်နှင့် theme ခလုတ်နှစ်ခု၊ {{ui:စက္ကူ}} နှင့် {{ui:မော်ဒယ်}} ကို ပြသည်။

{{ui:ဆက်တင်များ}} ခလုတ် (ဂီယာ) တွင် CadCraft ၏ကိုယ်ပိုင် ဆက်တင်များနှင့် အက်ပ်တိုင်း မျှဝေသော ဆက်တင်များ ရှိသည်: [CadCraft ဆက်တင်များ](topic:settings) ကို ကြည့်ပါ။

{{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} သည် CadCraft ၏ မိတ္တူကို DWG reader အပါအဝင် ဤ browser တွင် ထိန်းထားသဖြင့် ချိတ်ဆက်မှုမရှိဘဲ ဖွင့်နိုင်သည်။ label က အခြေအနေကို ပြသသည်: "သိမ်းနေသည် N/M"၊ "အော့ဖ်လိုင်း အဆင်သင့်"၊ "မသိမ်းနိုင်ပါ" သို့မဟုတ် "အော့ဖ်လိုင်း မရနိုင်ပါ"။ [အော့ဖ်လိုင်းတွင် အလုပ်လုပ်ခြင်း](common:offline) ကို ကြည့်ပါ။

:::note
အက်ပ် bar ရှိ {{ui:စက္ကူ}} နှင့် {{ui:မော်ဒယ်}} ခလုတ်များသည် စခရင်အရောင်များကိုသာ ပြောင်းသည်: {{ui:စက္ကူ}} သည် အလင်း theme၊ {{ui:မော်ဒယ်}} သည် အမှောင် theme ဖြစ်သည်။ ၎င်းတို့သည် ပုံဆွဲအောက်ရှိ {{ui:မော်ဒယ်}} tab နှင့် ဘာမှ မဆိုင်ပါ၊ ထို tab က ပုံဆွဲနှင့် ၎င်း၏စာရွက်များကြား ပြောင်းသည်။
:::

{{ui:အပြည့်မျက်နှာပြင်}} ခလုတ်၊ သို့မဟုတ် {{key:Ctrl+Shift+F}} (ကွန်ပျူတာတိုင်းတွင် Control ကီး၊ Mac အပါအဝင်) သည် မုဒ်သုံးမျိုးကို လှည့်သည်: ပုံမှန်၊ အပြည့်မျက်နှာပြင်၊ နှင့် bar များ ဖျောက်ထားသော အပြည့်မျက်နှာပြင်။ bar များ ဖျောက်ထားချိန်တွင် ပြန်ပေါ်စေရန် ညွှန်တံကို စခရင်အပေါ်ဘက်အစွန်းသို့ ရွှေ့ပါ။

## Toolbar

app bar အောက်တွင် toolbar ရှိသည်။ ခလုတ်တိုင်းက command တစ်ခုကို run သည်၊ သင်ရိုက်ထားသကဲ့သို့ အတိအကျ၊ ထို့ကြောင့် command လိုင်းက နည်းနှစ်မျိုးလုံးဖြင့် တူညီသော မေးခွန်းများ မေးသည်။ command alias ကို ကြည့်ရန် ခလုတ်ပေါ် ကာဆာတင်ပါ။ အုပ်စုများမှာ:

ပြတင်းပေါက် တိုသောအခါ (ဥပမာ ဖန်သားပြင် 125 % သို့မဟုတ် ထို့ထက်မြင့်စွာ စကေးထားသော laptop) toolbar သည် ပုံဆွဲနေရာကို ဘယ်တော့မှ မယူပါ: ပုံဆွဲအမြင့် နည်းလွန်းမည်ဆိုလျှင် ခလုတ်များက သင်္ကေတအောက်ရှိ စာသားနှင့် အုပ်စုအမည်များကို ချထားပြီး (အမည်သိရန် ခလုတ်ပေါ် ကာဆာတင်ပါ)၊ ထိုအရာလည်း မလုံလောက်လျှင် toolbar သည် တစ်အတန်းတည်း ဖြစ်ပြီး ဘေးသို့ scroll လုပ်သည်။ ပြတင်းပေါက် မြင့်လျှင် စာသားများ ပြန်ပေါ်လာသည်။

## ဘယ်ဘက် panel

ဘယ်ဘက် panel တွင် အပိုင်းသုံးခု ရှိသည်။

- **{{ui:လေယာများ}}။** ပုံဆွဲရှိ လေယာတိုင်း၊ လက်ရှိတစ်ခုပေါ်တွင် အစက်ဖြည့်ထား။ အမည်ကို နှိပ်ပြီး လေယာကို လက်ရှိ ဖြစ်စေပါ။ အတန်းတစ်ခုစီတွင် အရောင်အနမူနာ (အရောင်ရွေးရန် နှိပ်ပါ) နှင့် ခလုတ်လေးခု ရှိသည်: on/off (မျက်လုံး)၊ freeze (နှင်းပွင့်)၊ lock (သော့ခတ်)၊ နှင့် plot (ပရင်တာ)။ {{ui:လေယာအသစ်}} က ထည့်ရန် အကွက်တစ်ခု ဖွင့်သည်။ [လေယာဖြင့် ပုံဆွဲကို စီစဉ်ခြင်း](topic:layers) ကို ကြည့်ပါ။
- **{{ui:ဘလောက်များ}}။** ပုံဆွဲတွင် သတ်မှတ်ထားသော ဘလောက်များ၊ တစ်ခုစီ အသုံးပြုထားသော အကြိမ်အရေအတွက်၊ နှင့် တစ်ခုစီအတွက် {{ui:သွင်းရန်}} ခလုတ်။ [ဘလောက်များ ဖန်တီးပြီး သွင်းခြင်း](topic:blocks) ကို ကြည့်ပါ။
- **{{ui:ပုံဆွဲ}}။** ဖွင့်ထားသော ဖိုင်အကြောင်း အချက်အလက်များ: အမည် (သိမ်းမထားသော တည်းဖြတ်မှုရှိလျှင် "(changed)" ဖြင့်)၊ ဖော်မတ်၊ အရွယ်အစား၊ ယူနစ်များ၊ အရာဝတ္ထု အရေအတွက်၊ လေယာများ၊ ဘလောက်များနှင့် စာရွက်များ။ ဖိုင်ဖွင့်ပြီးနောက် "ဒီဖိုင်အကြောင်း" အကွက်က CadCraft မပြနိုင်သော သို့မဟုတ် ပြောင်းရသော အရာတိုင်းကို စာရင်းပြုသည်။

## ပုံဆွဲနေရာ

စခရင်အလယ်ရှိ အရာသည် ပုံဆွဲဖြစ်သည်။ ညွှန်တံသည် crosshair ဖြစ်သည်။ CadCraft က အမှတ်တစ်ခု လိုချင်သည့်အခါ အရာဝတ္ထု snap ကျမည့်နေရာကို အမှတ်အသားငယ်နှင့် label ("အဆုံးမှတ်"၊ "အလယ်မှတ်") က ပြသည်။ အရာဝတ္ထုများ လိုချင်သည့်အခါ crosshair တွင် pick box ရှိပြီး ၎င်းအောက်ရှိ အရာဝတ္ထုများ လင်းလာသည်။

ပုံဆွဲ ဗလာဖြစ်သောအခါ "ပုံဆွဲ စတင်ရန်" ကဒ်က ပထမ command အနည်းငယ် ပြသည်။ command တစ်ခု run သို့မဟုတ် ဖိုင်တစ်ခု ဖွင့်လိုက်သည်နှင့် ပျောက်သည်။ ဤနေရာ၏ မည်သည့်နေရာမဆို DWG သို့မဟုတ် DXF ဖိုင်ကို ချ၍ ဖွင့်နိုင်သည်။

## ပုံဆွဲအောက်ရှိ tab များ

ပုံဆွဲအောက်တွင် tab များ ရှိသည်: ပထမ {{ui:မော်ဒယ်}}၊ ထို့နောက် {{ui:3D}}၊ စာရွက် (layout) တစ်ခုစီအတွက် tab တစ်ခု၊ ထို့နောက် {{ui:+}} ခလုတ်။

- {{ui:မော်ဒယ်}} သည် ပုံဆွဲကိုယ်တိုင်ဖြစ်ပြီး အပြည့်အစွမ်းဖြင့်၊ ပုံဆွဲယူနစ်ဖြင့်။
- {{ui:3D}} သည် ပုံဆွဲကို မြေပြင်ပေါ် ချထားသည့် ပုံနှင့် ၎င်းမှ ဖန်တီးထားသော solid များကို ပြသည်။ ပြနေစဉ် toolbar တွင် ပုံဆွဲအုပ်စုများအစား {{ui:3D}} အုပ်စု ရှိသည်။ [3D ဖြင့် မော်ဒယ်](topic:3d-solids) ကို ကြည့်ပါ။
- စာရွက် tab တစ်ခုစီသည် ခေါင်းစဉ်ဘလောက်နှင့် မော်ဒယ်ပေါ်သို့ viewport များပါသော စက္ကူစာရွက်ဖြစ်သည်။ ထိုနေရာတွင် ဆွဲသည်များသည် စက္ကူယူနစ် (မီလီမီတာ သို့မဟုတ် လက်မ) ဖြစ်သည်။ viewport အတွင်း နှစ်ကြိမ်နှိပ်ခြင်းဖြင့် ထိုမှတစ်ဆင့် မော်ဒယ်ကို လုပ်ဆောင်နိုင်သည် ([viewport မှတစ်ဆင့် မော်ဒယ်ပေါ် လုပ်ဆောင်ခြင်း](topic:sheets-and-viewports#work-on-the-model-through-a-viewport) ကို ကြည့်ပါ)။ စာရွက်အမည်ရှည်သည် tab တွင် တိုထားသည်; အမည်အပြည့်အစုံအတွက် tab ပေါ် ကာဆာတင်ပါ။ စာရွက်များ အများအပြားရှိလျှင် {{ui:ဆက်တင်များ}} › {{ui:CadCraft}} › {{ui:စာရွက် tab များ}} › {{ui:စာရွက်နံပါတ်များသာ}} က စာရွက်တစ်ခုစီ၏ နံပါတ် (A-101) ကိုသာ tab တွင် ပြသည်။
- {{ui:+}} သည် ဘောင်၊ ခေါင်းစဉ်ဘလောက်နှင့် viewport တစ်ခုပါသော စာရွက်အသစ် ဖန်တီးသည်။ {{cmd:LAYOUT}} command နှင့် တူသည်။

စာရွက် tab ကို နှစ်ကြိမ်နှိပ်ပြီး အမည်ပြောင်းပါ။ tab ကို အာရုံစိုက်ထားစဉ် {{key:Left}} နှင့် {{key:Right}} က tab များကြား ရွှေ့သည်။

tab တစ်ခုစီသည် ၎င်း၏ကိုယ်ပိုင် zoom နှင့် pan ကို ထိန်းသည်။ [စာရွက် စီစဉ်ခြင်း](topic:sheets-and-viewports) ကို ကြည့်ပါ။

## ညာဘက် panel: ဂုဏ်သတ္တိများ

ညာဘက် panel သည် ရွေးထားသည်နှင့်အတူ ပြောင်းသည်။

- **ဘာမှ မရွေး၊ {{ui:မော်ဒယ်}} tab တွင်:** ခေါင်းစဉ်က {{ui:လက်ရှိ ဆက်တင်များ}} ဟု ဖတ်သည်။ ဤနေရာတွင် အရာဝတ္ထုသစ်များအတွက် {{ui:လေယာ}}၊ {{ui:အရောင်}} နှင့် {{ui:စာသားအမြင့်}}၊ ပုံဆွဲ၏ {{ui:ယူနစ်များ}}၊ နှင့် အတိုင်းအတာသစ်များ၏ အရွယ်အစားများ ({{ui:စာသားအမြင့်}}၊ {{ui:မြားအရွယ်အစား}}၊ {{ui:ဒသမ}}၊ {{ui:အလုံးစုံစကေး}}) ကို သတ်မှတ်သည်။
- **ဘာမှ မရွေး၊ စာရွက်ပေါ်:** ခေါင်းစဉ်က "စာရွက်:" နှင့် စာရွက်အမည်ကို ဖတ်သည်။ စာရွက်ကို အမည်ပြောင်းနိုင်သည်၊ ၎င်း၏ {{ui:စက္ကူ}} နှင့် {{ui:ဦးတည်ချက်}} ကို ပြောင်းနိုင်သည်၊ {{ui:ဤစာရွက်ကို ပလော့ထုတ်ရန်}} သို့မဟုတ် {{ui:ဤစာရွက်ကို ဖျက်ရန်}}။ အရာဝတ္ထုသစ်များအတွက် ဆက်တင်များက အောက်တွင် လိုက်သည်။
- **အရာဝတ္ထု တစ်ခု ရွေး:** ခေါင်းစဉ်အဖြစ် ၎င်း၏အမျိုးအစား (မျဉ်း၊ စက်ဝိုင်း၊ စာသား၊ အတိုင်းအတာ၊ ဗျူးပို့တ် …)၊ ထို့နောက် လေယာ၊ အရောင်နှင့် ဂျီအိုမေတြီ။ တန်ဖိုးအသစ် ရိုက်ပြီး {{key:Enter}} ကို နှိပ်၍ ပြောင်းပါ။
- **အရာဝတ္ထုအများ ရွေး:** အရေအတွက်၊ နှင့် ၎င်းတို့၏ ဘုံ {{ui:လေယာ}} နှင့် {{ui:အရောင်}}။ တစ်ခုခု ပြောင်းလျှင် အားလုံး ပြောင်းသည်။ "အမျိုးမျိုး" ဆိုသည်မှာ ကွဲပြားခြင်းကို ဆိုလိုသည်။

[grip နှင့် ဂုဏ်သတ္တိများဖြင့် တည်းဖြတ်ခြင်း](topic:grips-and-properties) ကို ကြည့်ပါ။

ထို့အောက်တွင် {{ui:ပါရာမီတာများ}} ကို ရွေးသည့်အခါ သို့မဟုတ် {{cmd:PARAMETERS}} ကို ရိုက်သည့်အခါ {{ui:ပါရာမီတာများ}} panel ဖွင့်သည်: parameter နှင့် dimensional constraint အားလုံးကို ဇယားတစ်ခုတည်းတွင်။ [parameter နှင့် equation များ သုံးခြင်း](topic:parameters) ကို ကြည့်ပါ။

## Command လိုင်း

အောက်ဆုံးတွင် command လိုင်း ရှိသည်: သင်လုပ်ခဲ့သည့် မှတ်တမ်း၊ နောက် ၎င်းအောက်တွင် prompt။

- prompt label က ဘာမျှ မ run နေချိန်တွင် `Command:` ဟု ဖတ်သည်။ command run နေစဉ် မေးခွန်း၊ ရွေးချယ်စရာများ အမှတ်အသား [ ] တွင်နှင့် ပုံသေ < > တွင် ပြသည်၊ ဥပမာ `Specify radius of circle [Diameter] <500>:`။
- command အမည် ရိုက်နေစဉ် ညာဘက်ရှိ အရိပ်အမြွက်က ကိုက်ညီသော command များကို အကြံပြုသည်။ ပထမတစ်ခုကို လက်ခံရန် {{key:Tab}} ကို နှိပ်ပါ။ "No such command" ဆိုသည်မှာ ဘာမှ မကိုက်ညီခြင်း ဖြစ်သည်။
- {{key:Up}} နှင့် {{key:Down}} က ယခင်ရိုက်ခဲ့သော စာကြောင်းများကို ပြန်ယူသည်။
- မှတ်တမ်းက နောက်ဆုံး စာကြောင်း 400 ကို ထိန်းသည်။ command များမှ မက်ဆေ့ချ်များ၊ {{cmd:DIST}} နှင့် {{cmd:LIST}} မှ တိုင်းတာမှုများ၊ သိမ်းခြင်းနှင့် ပလော့ခြင်း အစီရင်ခံစာများ ဤနေရာတွင် ပေါ်သည်။

## အခြေအနေဘား

အောက်ဆုံးအတန်းသည် အခြေအနေဘား ဖြစ်သည်။

- **ကိုဩဒီနိတ်များ** ဘယ်ဘက်တွင်: crosshair ၏ X နှင့် Y။ command တစ်ခုတွင် base point ရှိစဉ် ၎င်းထံမှ အကွာအဝေးနှင့် ထောင့်ကိုလည်း ပြသည်၊ ဥပမာ `Δ 1200 < 90°`။
- **မက်ဆေ့ချ်များ** အလယ်တွင်၊ ဥပမာ "Ortho on" သို့မဟုတ် "Current layer: Walls"။ စက္ကန့်အနည်းငယ်အကြာတွင် မှိန်သွားသည်။
- **{{ui:Grid}}**၊ **{{ui:Ortho}}**၊ **{{ui:Polar}}**၊ **{{ui:Snap}}**၊ **{{ui:Track}}**၊ **{{ui:Dyn}}** နှင့် **{{ui:LWT}}** ညာဘက်တွင်။ တစ်ခုစီသည် toggle ဖြစ်သည်; ဖိထားသော ခလုတ်သည် ဖွင့်ထားသည်။ {{ui:LWT}} က မျဉ်းအထူများကို စခရင်ပေါ် ပြသည် ([မျဉ်းအထူနှင့် မျဉ်းပုံစံများ](topic:units-papers-scales#line-weights-and-linetypes) ကို ကြည့်ပါ)။ {{ui:Snap}} ဘေးရှိ မြားငယ်က {{ui:အရာဝတ္ထု snap များ}} ကို ဖွင့်ပြီး snap မည်သည်တို့ ဖွင့်ထားသည်ကို အမှန်ခြစ်နိုင်သည်။ [အရာဝတ္ထုပေါ် အမှတ်များသို့ snap လုပ်ခြင်း](topic:object-snaps) ကို ကြည့်ပါ။

## အကူအညီ

{{key:F1}} သို့မဟုတ် {{ui:အကူအညီ}} ခလုတ်က ဤအကူအညီကို ဘေး panel အဖြစ် ဖွင့်သည်; ပုံဆွဲကို ၎င်းဘေးတွင် ဆက်သုံးနိုင်သည်။ ချိတ်ဆက်မှုမလိုဘဲ အလုပ်လုပ်သည်။ {{key:F1}} ကို ထပ်နှိပ်ပါ၊ သို့မဟုတ် panel အတွင်း {{key:Esc}} ကို နှိပ်ပါ၊ ပိတ်သည်။ [ဤအကူအညီကို အသုံးပြုခြင်း](common:help) ကို ကြည့်ပါ။
