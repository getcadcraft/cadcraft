{{ui:ဆက်တင်များ}} ကို app bar ရှိ gear ဖြင့် သို့မဟုတ် {{key:Mod+,}} ဖြင့် ဖွင့်ပါ။ ပထမ tab ဖြစ်သော {{ui:CadCraft}} တွင် ဤ app နှင့် သက်ဆိုင်သော ဆက်တင်များ ရှိ၊ {{ui:အထွေထွေ}} တွင် family အက်ပ်အားလုံး မျှဝေသော ဆက်တင်များ (အပိုင်းအမည်၊ panel စာသား အရွယ်အစားနှင့် အကျယ်၊ toolbar ၏ ပုံစံနှင့် အစီအစဉ်) ရှိသည်။ CadCraft ဆက်တင်များသည် app တွင်သာ ရှိ: ဤနေရာတွင် ပြောင်းပြီး ဤ browser က ၎င်းတို့ကို မှတ်သည်။ CadCraft ဆက်တင်များ ပြန်သတ်မှတ်ရန်သည် ဆက်တင်တိုင်းကို စတင်ချိန်အတိုင်း ပြန်ထား။

## ကာဆာ

**Small**၊ **Medium** (စတင်ချိန်)၊ **Large** သို့မဟုတ် **Full screen**: crosshair နှင့် ပုံဆွဲထဲရှိ pick box ၏ အရွယ်အစား။ Pick box ပိုကြီးလျှင် ပိုဝေးမှ အရာဝတ္ထုများကိုလည်း ရွေးနိုင်၊ touch screen သို့မဟုတ် အလွန်နူးညံ့သော drawing တွင် ကူညီသည်။

**Full screen** က crosshair ၏ မျဉ်းနှစ်ကြောင်းကို drawing တစ်ဖက်မှ တစ်ဖက်အထိ ဆွဲ၊ command မလည်ပတ်ချိန်တွင်ပင်၊ ထို့ကြောင့် အရာနှစ်ခု drawing တစ်ခုလုံးတွင် တန်းညီမညီ မျက်စိဖြင့် စစ်နိုင်သည်။ View ကို ခွဲထားလျှင် မျဉ်းများက သင်အလုပ်လုပ်နေသော pane တွင်သာ ရှိ။ AutoCAD ၏ {{cmd:CURSORSIZE}} 100 နှင့် တူ: {{cmd:CURSORSIZE}} နှင့် 100 ရိုက်ပါ; ငယ်သော နံပါတ်က အနီးဆုံး အရွယ်ကို ရွေး (5 အောက် Small၊ 5 မှ 9 Medium၊ 10 မှ 99 Large)။

## ကူးထည့်ချိန် point

{{key:Mod+V}} ({{cmd:PASTECLIP}}) ပြီးနောက် ကူးထည့်ထားသော ကော်ပီသည် cursor မှ ချိတ်ကပ်နေသည့်နေရာ၊ နှိပ်မချင်း:

- **ဘယ်အောက်ထောင့်** (စတင်ချိန်): ကူးထားသော အရာဝတ္ထုများ extents ၏ ဘယ်အောက်ထောင့်၊ AutoCAD ကဲ့သို့။
- **Center**: ၎င်းတို့ extents ၏ အလယ်။ မျက်စိဖြင့် သင်္ကေတ နေရာချရန် အဆင်ပြေ။

`COPYBASE` ဖြင့် ကူးထားသော ကော်ပီသည် အမြဲ သင်ရွေးထားသော base point မှ ချိတ်ကပ်။ {{ui:နေရာတွင် ကူးထည့်ရန်}} ({{key:Mod+Shift+V}}) က ဤဆက်တင်ကို လျစ်လျူရှု၊ မူလ coordinate များကို ထိန်း။ See [ကူး၊ ကူးထည့်နှင့် ပွားခြင်း](topic:copy-paste)။

## အရာဝတ္ထုများကို နှိပ်ခြင်း

Command မလည်ပတ်ချိန်တွင် drawing ထဲ click က ရွေးချယ်မှုကို ဘာလုပ်သလဲ:

- **ရွေးချယ်မှုသို့ ထည့်** (စတင်ချိန်): click သို့မဟုတ် window တိုင်းက အရာဝတ္ထုများ ထည့်၊ {{key:Shift}}+click သို့မဟုတ် {{key:Shift}}+window က ဖယ်။
- **ရွေးချယ်မှုကို အစားထိုး**: click သို့မဟုတ် window က ၎င်းရွေးသည်များသာ ရွေး။ {{key:Shift}}+click က object တစ်ခု ထည့်၊ သို့မဟုတ် ရွေးပြီးသား တစ်ခုကို ဖယ်။ {{key:Shift}}+window က ထည့်။

Command အတွင်း `Select objects:` prompt တွင် click များသည် အမြဲ ထည့် ({{key:Shift}} က ဖယ်)၊ ဤဆက်တင် ဘာပြောပြောပါ။ See [အရာဝတ္ထုများ ရွေးခြင်း](topic:select-objects)။

## အလွတ်နေရာကို နှိပ်ခြင်း

Command မလည်ပတ်ချိန်တွင် အရာဝတ္ထု မရှိသော နေရာကို နှိပ်လျှင် ဘာဖြစ်သလဲ။ နည်းလမ်းနှစ်ခုစလုံးက ရွေးချယ်မှု window တစ်ခု စတင် (ဒုတိယ click က ပြီးစေ)။

- **ရွေးချယ်မှုကို ရှင်း** (စတင်ချိန်): ရွေးထားသည်များ လွှတ်လိုက်။ ထိန်းရန် {{key:Shift}} ကိုဖိ၍ နှိပ်။
- **ရွေးချယ်မှုကို ထိန်း**: ရွေးချယ်မှု ကျန်၊ အခြားဆော့ဖ်ဝဲများကဲ့သို့; window က ထိုအထဲသို့ ထည့်။ ရွေးချယ်မှုကို ရှင်းရန် {{key:Esc}} ကို နှိပ်။

## ဖိ၍ ရွေးခြင်း

အလွတ်နေရာပေါ် ဖိ၍ ဆွဲလျှင် ဘာဆွဲသလဲ:

- **Lasso** (စတင်ချိန်): လွတ်လပ်သော outline။ ညာဘက်သို့ အရင်ဆွဲလျှင် အပြည့်အဝ အတွင်းရှိသည်များ၊ ဘယ်ဘက်သို့ အရင်ဆွဲလျှင် ထိသည်များကို ရွေး၊ ဆွဲနေစဉ် {{key:Space}} က window၊ crossing နှင့် fence အကြား ပြောင်း။
- **Rectangle**: ဘောက်စ်၊ click နှင့် ဒုတိယ click က ဆွဲသကဲ့သို့။

{{cmd:LASSOMODE}} `1` သို့မဟုတ် `0` က တူညီသည်ကို သတ်မှတ်။ See [Lasso ဖြင့် ရွေးခြင်း](topic:lasso-selection)။

## ညှပ်ခြင်းနှင့် ရှည်ချဲ့ခြင်း ဆွဲခြင်း

{{cmd:TRIM}} နှင့် {{cmd:EXTEND}} တွင် အလွတ်နေရာကို နှိပ်ပြီး ဆွဲလျှင် ဘာဖြစ်သလဲ:

- **လမ်းကြောင်း** (စတင်ချိန်): လွတ်လပ်သော လမ်းကြောင်း; ဖြတ်သွားသည့် အစိတ်အပိုင်းတိုင်း ညှပ် (သို့မဟုတ် ရှည်ချဲ့)။
- **Window**: ဘောက်စ်; ထိသော အစိတ်အပိုင်းတိုင်း ညှပ်၊ `C` ရွေးချယ်မှု လုပ်သကဲ့သို့။

See [ညှပ်ခြင်းနှင့် ရှည်ချဲ့ခြင်း](topic:trim-and-extend)။

## Toolbar နေရာ

{{ui:CadCraft}} › {{ui:တူးလ်ဘား နေရာ}}: **Top** (စတင်ချိန်၊ အမြဲ ဒီလို ရှိခဲ့သည်)၊ **Bottom**၊ **Left** သို့မဟုတ် **Right**။ ဘယ် သို့မဟုတ် ညာတွင် ကိရိယာအုပ်စုများ ကော်လံတစ်ခုတွင် စီ၊ window ထက် မြင့်လျှင် ဆွဲလှိမ့်ပြီး ခလုတ်များ နှစ်ခု သို့မဟုတ် သုံးခုကို မျဉ်းတစ်ကြောင်းတွင် ခေါက်။ ရွေးချယ်မှုကို သင့်ဆက်တင်များနှင့်အတူ သိမ်း၊ {{cmd:TOOLBARDOCK}} (`TBDOCK`) က command line မှ သတ်မှတ်။ {{ui:အထွေထွေ}} › {{ui:layout ကို ပြန်ထားရန်}} က toolbar ကို ထိပ်သို့ ပြန်ထား။

အရောင်စနစ် bar များသည် toolbar အတွင်း နေပြီး၎င်းနှင့်အတူ ရွှေ့၊ သို့သော် {{ui:ရစ်ဘန်}} ပုံစံကို ထိပ်သို့ သို့မဟုတ် အောက်သို့ ပြေးရန် ပြုလုပ်ထား: ဘေးတွင် ကျဉ်းသော ကော်လံ ရ၍ ဆွဲလှိမ့်သည်။ ဖုန်းတွင် toolbar သည် ဖုန်း layout က ထားသည့်နေရာတွင် ရှိနေ။

## Toolbar အတန်းများ

CadCraft toolbar နှင့် {{ui:ရိုးရာပုံဆွဲပုံစံ}} နှင့် {{ui:ရစ်ဘန်}} ပုံစံများတွင် ကိရိယာများက drawing အပေါ်တွင် မျဉ်းဘယ်နှစ်ကြောင်း သုံးသလဲ:

- **ကိုက်အောင် ခေါက်** (စတင်ချိန်): ကိရိယာများသည် window ၏ အကျယ်သို့ ခေါက်။
- **2 အတန်း**: အများဆုံး မျဉ်းနှစ်ကြောင်း။ ဤအကျယ်တွင် ကိရိယာများ မျဉ်းနှစ်ကြောင်း သို့မဟုတ် နည်းသည်ဆိုလျှင် ခေါက်လိုက်သာ; မဟုတ်လျှင် ဘေးသို့ ဆွဲလှိမ့်နိုင်သော အတန်းနှစ်ခုတွင် ထား။
- **1 အတန်း**: ဘေးသို့ ဆွဲလှိမ့်နိုင်သော မျဉ်းတစ်ကြောင်း၊ drawing အတွက် နေရာ အများဆုံး ပေး။

{{key:Shift+Ctrl+F1}} က သုံးခုကို လှည့်၊ {{cmd:TOOLBARROWS}} က တစ်ခုကို သတ်မှတ်။ ခလုတ်များ ဘာပြမလဲ (icon နှင့် စာသား၊ icon သာ၊ စာသားသာ) သည် {{ui:အထွေထွေ}} › {{ui:ကိရိယာဘား}} ၏ ဆက်တင်တစ်ခု; {{key:Ctrl+F1}} က ၎င်းကို လှည့်၊ {{cmd:TOOLBAR}} က သတ်မှတ်။

## Command line

Command line သည် drawing အောက်တွင် ဆိုက်ထား၍ ရ၊ အရင်ကကဲ့သို့၊ သို့မဟုတ် drawing အပေါ် မျော၍ ရ၊ မျဉ်းတစ်ကြောင်းအထိ ပါးနိုင်။

- **မျောစေ။** ဘယ်ဘက်ဆုံးရှိ grip ကို drawing ထဲ ဆွဲ၊ သို့မဟုတ် ၎င်း၏ ညာဘက်ဆုံးရှိ သုံးစက်ပုံ ({{ui:အမိန့်စာကြောင်း ရွေးချယ်စရာများ}} မီနူး) မှ {{ui:ပုံဆွဲပေါ်တွင် မျောရန်}} ကို ရွေး။ Grip ကို ထပ်ဆွဲ၍ ရွှေ့; window အရွယ်ပြောင်းလျှင် နေရာ ထိန်း။ ညာဘက်အစွန်းကို ဆွဲ၍ ကျယ်ပြန် သို့မဟုတ် ကျဉ်း။ Status bar ပေါ် ချ သို့မဟုတ် {{ui:အောက်ခြေတွင် ချိတ်ရန်}} ကို ရွေး ပြန်ချိတ်။
- **ပါးစေ သို့မဟုတ် မြင့်စေ။** အပေါ်အစွန်းကို ဆွဲ: ခြေလှမ်းတစ်ခုစီသည် history မျဉ်းတစ်ကြောင်း။ သုညအထိ ဆွဲလျှင် **မျဉ်းတစ်ကြောင်း command line** ဖြစ်၊ prompt နှင့် သင်ရိုက်သည်သာ၊ မက်ဆေ့ခ်ျအသစ်က အနည်းငယ်ကြာ အပေါ်တွင် ပြ။ အပေါ်အစွန်းကို နှစ်ချက်နှိပ်လျှင် မျဉ်းတစ်ကြောင်းနှင့် သင့်ရှိပြီးသား အမြင့်ကြား ပြောင်း။
- **မှတ်တမ်း။** {{key:F2}}၊ သို့မဟုတ် command line ရှိ နာရီခလုတ် ({{ui:အမိန့်မှတ်တမ်း (F2)}}) က မှတ်တမ်းတစ်ခုလုံးကို မျဉ်း၏ အပေါ် (ပုံဆွဲ မျောနေပါက အောက်ဘက်) ဖွင့်။ ရိုက်ခြင်းသည် command line သို့ ဆက်သွား၊ {{key:PageUp}} နှင့် {{key:PageDown}} က မှတ်တမ်းကို ရွှေ့၊ {{key:Esc}}၊ {{key:F2}} သို့မဟုတ် နေရာတခြား click က ပိတ်။ F2 တွင် သင့်ကိုယ်ပိုင် ကီးရှိလျှင် ထိုအရာ နိုင်။
- **ကီးဘုတ်မှ။** Grip သည် ခလုတ်တစ်ခု: အာရုံခံထားစဉ် မြား ကီးများက မျော command line ကို ရွှေ့ ({{key:Shift}} ဖြင့် ပိုကြီးသော ခြေလှမ်း); {{key:Up}} က ချိတ်ထားသည်ကို မျောစေ၊ ထိပ်အောက်ဆုံးတွင် {{key:Down}} က ချိတ်စေ။ အပေါ်အစွန်းက ခွဲခြားသည်: {{key:Up}} နှင့် {{key:Down}} က မျဉ်းထည့်/ဖယ်၊ {{key:Home}} က မျဉ်းတစ်ကြောင်း၊ {{key:End}} က အမြင့်ဆုံး။ မျက်နှာပြင် ဖတ်စက်များက မက်ဆေ့ခ်ျအားလုံးကို မျဉ်းတစ်ကြောင်း command line တွင်ပင် ကြားရ။

{{ui:CadCraft}} › {{ui:အမိန့်စာကြောင်း}} တွင် ဤရွေးချယ်မှုများ တူညီသည်: {{ui:အောက်ခြေတွင် ချိတ်ဆက်ထား}} သို့မဟုတ် {{ui:မျောနေသည်}}၊ {{ui:ပြသသော မှတ်တမ်းစာကြောင်းများ}} (0 မှ 12) နှင့် {{ui:စံ အမြင့်}}။ {{cmd:COMMANDLINE}} (`CMDLINE`) က command line မှ သတ်မှတ်။ နေရာနှင့် အမြင့်ကို ဤ browser တွင် layout ၏ အခြားအရာများနှင့်အတူ CadCraft အတွက် ထိန်း၊ ထို့ကြောင့် သိမ်းထားသော work environment တွင် ပါလာ; {{ui:အထွေထွေ}} › {{ui:layout ကို ပြန်ထားရန်}} က command line ကို စံအမြင့်တွင် အောက်တွင် ပြန်ချိတ်။ ဖုန်းတွင် command line သည် မှတ်တမ်းမျဉ်းတစ်ကြောင်းဖြင့် အောက်တွင် ချိတ်ဆက်ထား; မှတ်တမ်းခလုတ်လည်း ရ။

{{ui:CadCraft}} › {{ui:ရွေးချယ်စရာ အက္ခရာများ}} က command options အတွက် သင်ရွေးသော အက္ခရာများကို ထိန်း: {{ui:တည်းဖြတ်…}} က ဖိုင်ကို ဖွင့်၊ {{ui:သွင်းရန်…}} က သင်ရွေးသော ဖိုင်ဖြင့် အစားထိုး၊ {{ui:ထုတ်ရန်}} က သိမ်း။ See [command ရွေးချယ်စရာများကို ကိုယ်ပိုင် အက္ခရာ ပေးရန်](topic:option-letters)။

Window တိုတိုဖြစ်ပြီး layout စစ်ဆေးမှုက ပိုတင်းသော layout ကို ကမ်းလှမ်းလျှင် ၎င်း၏ {{ui:ဟုတ်}} သည် toolbar များပြီးနောက် drawing တိုသေးလျှင် command line ကို မျဉ်းတစ်ကြောင်းသို့လည်း ပြောင်း။

## ထိပ်ဧရိယာ

{{ui:CadCraft}} › {{ui:ထိပ်ဧရိယာ}}: **Standard** (စတင်ချိန်) သို့မဟုတ် **Compact**။ Compact က drawing အပေါ်ရှိ bar များကို မီနူးပုံစံ အားလုံးတွင် သေးငယ်ထား: အုပ်စုအမည်များနှင့် icon အောက်ရှိ စာလုံးများ ပျောက် (tooltip နှင့် မျက်နှာပြင် ဖတ်စက်များတွင် ရှိနေဆဲ) ခလုတ်များ ပိုကျဉ်း။ [Toolbar အတန်းများ](topic:settings#toolbar-rows) နှင့် အလုပ်လုပ်: Compact နှင့် **1 အတန်း** က drawing အတွက် နေရာအများဆုံး ပေး။ {{cmd:TOPAREA}} က သတ်မှတ်။

## ထောင့် ညွှန်ပြချက်

Drawing ၏ ထောင့်တွင် ရှိသည်များ:

- **အလိုအလျောက်** (စတင်ချိန်): {{ui:မော်ဒယ်}} tab ပေါ်ရှိ axis icon နှင့် {{ui:3D}} tab ပေါ်ရှိ view cube။
- **Axis icon**: {{ui:မော်ဒယ်}} tab ၏ ဘယ်အောက်ထောင့်ရှိ X နှင့် Y အမှတ်အသား၊ နှင့် {{ui:3D}} tab ပေါ်ရှိ X၊ Y နှင့် Z အမှတ်အသားငယ်များ။
- **View cube**: tab နှစ်ခုစလုံး ညာဘက်ထိပ်ရှိ ကုဗ။ {{ui:မော်ဒယ်}} tab တွင် drawing ကို အပေါ်မှ ပြ၊ အခြား မျက်နှာ၊ အစွန်း သို့မဟုတ် ထောင့်ကို နှိပ်လျှင် {{ui:3D}} tab ကို ထိုနေရာမှ ကြည့်နေသည်ဖြင့် ဖွင့်။ 3D tab တွင် view နှင့်အတူ လှည့်၊ ဘက်တစ်ဖက်မှ ကြည့်ရန် click၊ ပတ်ရန် ဆွဲ၊ အိမ်ခလုတ်က iso view သို့ ပြန်။ See [3D တွင် မော်ဒယ်](topic:3d-solids)။
- **None**: ထောင့်တွင် ဘာမျှ မရှိ။

စာရွက်များတွင် နှစ်ခုစလုံး မရှိ။

## ရွေးချယ်မှု၏ အရှည်နှင့် ဧရိယာ

- **Status bar တွင်** (စတင်ချိန်): object များ ရွေးထားစဉ် status bar က ၎င်းတို့၏ စုစုပေါင်း အရှည်နှင့် ပိတ်ထားသော ရွေးချယ်မှု၏ စုစုပေါင်း ဧရိယာ ပြ။ See [ရွေးချယ်မှု၏ စုစုပေါင်း](topic:properties-panel#totals-of-a-selection)။
- **ဝှက်ထား**: status bar က ထိုအချက်များကို ထုတ်ထားသည်။ Properties က object များစွာအတွက် ဆက်ပြ။

## Grid၊ Ortho နှင့် snap များ

ဤအရာများသည် dialog တွင် မရှိ: status bar ရှိ {{ui:ဂရစ်}}၊ {{ui:Ortho}} နှင့် {{ui:Snap}} ခလုတ်များ (သို့မဟုတ် {{key:F7}}၊ {{key:F8}}၊ {{key:F3}}) နှင့် ၎င်းတို့ဘေးရှိ object snap စာရင်းကို ထားခဲ့သည့်အတိုင်း မှတ်သည်။ See [အရာဝတ္ထု ပေါ်ရှိ point များသို့ snap လုပ်ခြင်း](topic:object-snaps)။
