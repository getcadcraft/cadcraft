## သင် ဖန်တီးမည့်အရာ

လေကြောင်းပုံ သို့မဟုတ် လမ်းမြေပုံ အပေါ်တွင် ဆွဲထားသော ဆိုက်အစီအစဉ်၊ တစ်ခုစီ မှန်ကန်သော နေရာတွင်။

## ပုံဆွဲ ဘယ်နေရာတွင်ရှိသည် CadCraft အား ပြောရန်

1. {{ui:Properties}} › {{ui:Units}} တွင် ပုံဆွဲ၏ ယူနစ်ကို သတ်မှတ်ပါ (ဥပမာ feet သို့မဟုတ် meters)။
2. {{cmd:MAPLAYERS}} (သို့မဟုတ် `ML`) ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
3. {{ui:Where the drawing is}} အောက်တွင် {{ui:Find a system}} ၌ အမည် သို့မဟုတ် EPSG code ရိုက်ပါ (ဥပမာ `2277` သို့မဟုတ် `Texas Central`) ပြီး {{ui:System}} တွင် ရွေးပါ။
4. ပုံဆွဲကို ထိုစနစ်၏ ကိုယ်ပိုင် coordinate ဖြင့် ဆွဲထားလျှင် နေရာချမှုကို 0 ထားပါ။ မဟုတ်လျှင် ပုံဆွဲ အမှတ်တစ်ခု ({{ui:Drawing X}}, {{ui:Drawing Y}}) ပေးပြီး ထိုအမှတ်သည် မြေပုံ grid ပေါ်တွင် ({{ui:Easting}}, {{ui:Northing}}) ဘယ်နေရာရှိသည်ကို ပေးပါ၊ ထို့နောက် ပုံဆွဲသည် အရှေ့မှ ဘယ်လောက် လှည့်ထားသည် ({{ui:Turned (°)}}) ကို ပေးပါ။
5. {{ui:Use this system}} ကို နှိပ်ပါ။

## လေယာ ထည့်ရန်

1. Dialog ၏ အပေါ်ရှိ {{ui:Map layers from the internet}} ကို ဖွင့်ပါ။ ထိုအထိ ဘယ် server ကိုမှ မေးမည် မဟုတ်ပါ; ဖွင့်ထားချိန်တွင် သင်ထည့်သော server များက မျက်နှာပြင်ပေါ်ရှိ နေရာနှင့် သင့် internet လိပ်စာကို မြင်ရသည်၊ သင့်ပုံဆွဲကို ဘယ်တော့မှ မမြင်ပါ။
2. {{ui:Add a layer}} တွင် ၎င်း၏ ရင်းမြစ်ကို ရွေးပါ:
   - **Tiles (XYZ)**: `{z}`၊ `{x}` နှင့် `{y}` ပါသော tile လိပ်စာ၊ အမည်နှင့် ၎င်း provider တောင်းဆိုသော credit။
   - **WMS**၊ **WMTS** သို့မဟုတ် **ArcGIS**: service ၏ လိပ်စာ၊ ထို့နောက် {{ui:Get layers}} ကို နှိပ်ပြီး တစ်ခု ရွေးပါ။
   - **ပုံတစ်ခု**: world file (ရှိလျှင် `.prj` ပါ) ပါသော PNG သို့မဟုတ် JPEG။
3. လေယာသည် ပုံဆွဲအောက်တွင် ပေါ်သည်။ ၎င်း၏ credit သည် ပုံဆွဲ၏ အောက်ညာဘက်တွင် ပြသည်။

စာရင်းရှိ လေယာတစ်ခုစီကို ဖျောက်နိုင်၊ ပို ဝါး သို့မဟုတ် နည်းအောင် ပြုလုပ်နိုင်၊ အပေါ် သို့မဟုတ် အောက်သို့ ရွှေ့နိုင် သို့မဟုတ် ဖယ်ရှားနိုင်သည်။

စနစ် သို့မဟုတ် လေယာများ ပြောင်းလဲမှုတိုင်းသည် {{cmd:UNDO}} ၏ အဆင့်တစ်ခု ဖြစ်သည်။

## ပုံဆွဲနှင့်အတူ သိမ်းထားသည်

Coordinate system နှင့် လေယာစာရင်းကို DWG သို့မဟုတ် DXF အဖြစ် သိမ်းသည့်အခါ ပုံဆွဲတွင် သိမ်းပြီး ပြန်ဖွင့်သည့်အခါ ပြန်ရောက်လာသည်၊ ကွန်ပျူတာ မည်သည့်တွင်မဆို။ ဖိုင်များမှ ပုံများကို မသိမ်းပါ: ဖွင့်ပြီးနောက် ပြန်ထည့်ပါ။ {{ui:Map layers from the internet}} switch ကို ပုံဆွဲတွင် မသိမ်းပါ: ၎င်းသည် ဤ browser နှင့် သက်ဆိုင်သည်၊ ထို့ကြောင့် သင့်ထံ ပို့သော ပုံဆွဲသည် သင်ကိုယ်တိုင် မဖွင့်မချင်း ဘယ် server ကိုမှ မတောင်းဆိုပါ။

အခြား ပရိုဂရမ်များ မြင်ရသည်:

| သိမ်းသည့်ပုံစံ | ပုံဆွဲ၏ တည်နေရာ | မြေပုံလေယာများ |
|---|---|---|
| DWG 2010, 2013 သို့မဟုတ် 2018၊ DXF 2000 | ပရိုဂရမ်များ ပုံဆွဲ၏ ဘူမိပထဝီ တည်နေရာကို ဖတ်သော စံနည်းဖြင့် ရေးသည်: စနစ်၏ EPSG code၊ ပုံဆွဲ အမှတ်တစ်ခုနှင့် ၎င်းသည် မြေပုံ grid ပေါ်ရှိ နေရာ၊ ယူနစ်နှင့် မြောက်။ | CadCraft သာ |
| DWG 2000၊ 2004 သို့မဟုတ် 2007၊ DXF R12 | CadCraft သာ (သိမ်းသောအခါ CadCraft က ထိုသို့ ပြောသည်) | CadCraft သာ |

- **စစ်ဆေးပြီး:** ODA File Converter က တည်နေရာကို အမှားမရှိ ဖတ်သည်၊ DXF library (ezdxf) က EPSG code နှင့် နေရာချမှုကို တိကျစွာ ဖတ်သည်။
- **မစစ်ရသေး:** အခြား drafting ပရိုဂရမ်များက EPSG code မှ စနစ်ကို အသိအမှတ်ပြုမည်ဟု မသေချာသေးပါ။ ၎င်း၏ စနစ်စာရင်းကို အခြားအမည်များဖြင့် ထိန်းသော ပရိုဂရမ်သည် တည်နေရာမပါဘဲ ပုံဆွဲကို ပြနိုင်သည်။
- အခြား ပရိုဂရမ်များက block စာရင်းတွင် `CADCRAFT_GEO` အမည်ရှိ block ကို ပြသည်။ ၎င်းသည် CadCraft ၏ စနစ်နှင့် လေယာများ၏ ကိုယ်ပိုင် မိတ္တူဖြစ်ပြီး ပုံဆွဲတွင် ဘယ်တော့မှ မထားပါ။ ထိုနေရာတွင် ထားခဲ့ပါ။

## အခြားပရိုဂရမ်မှ ပုံဆွဲများ

အခြားပရိုဂရမ်မှ ပုံဆွဲတွင် ဘူမိပထဝီ တည်နေရာ ရှိလျှင် CadCraft က ဖတ်သည်:

- EPSG code ကို နာမည်ပေးထားလျှင် {{ui:Where the drawing is}} က ထိုစနစ်ကို ပြပြီး မြေပုံလေယာများကို ၎င်းဖြင့် နေရာချသည်။
- CadCraft က စနစ်ကို မသိလျှင် (အခြားပရိုဂရမ်၏ ကိုယ်ပိုင်အမည်၊ local grid သို့မဟုတ် scale factor)၊ တည်နေရာကို မသုံးပါ၊ သို့သော် ထိန်းထားပြီး မူလအတိုင်း ပြန်သိမ်းသဖြင့် အခြားပရိုဂရမ်က ဆက်ရှာတွေ့နိုင်သည်။ အစားထိုးရန် {{ui:Where the drawing is}} တွင် စနစ်တစ်ခု ရွေးပါ။

:::note
မြေပုံလေယာများကို မျက်နှာပြင်ပေါ်တွင်သာ ဆွဲသည်: ပုံနှိပ်မည် မဟုတ်ပါ။ ခွင့်ပြုချက်စည်းမျဉ်း ရှိသော မြေပုံ service များကိုသာ သုံးပြီး ၎င်းတို့၏ credit ကို မြင်နိုင်အောင် ထားပါ။
:::
