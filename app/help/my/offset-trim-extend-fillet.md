## သင် ဖန်တီးမည့်အရာ

အထူ 200 ရှိ နံရံများပါသော အခန်းငယ်တစ်ခု- အတွင်းမျက်နှာကို ဆွဲထားပြီး အပြင်မျက်နှာကို offset လုပ်ထားကာ ထောင့်များကို သန့်ရှင်းစေပြီး နံရံတစ်ခုတွင် တံခါးဝကို ဖြတ်ထားသည်။

## အတွင်းမျက်နှာကို ဆွဲခြင်း

1. `L` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
2. `0,0` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
3. `@5000,0` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
4. `@0,4000` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
5. `@-5000,0` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
6. `C` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
7. {{ui:Extents}} ကို နှိပ်ပါ။

လိုင်းခွဲ လေးကြောင်း ရှိသည်။ (ပိတ်ထားသော polyline ကို တစ်ကြိမ်တည်း offset လုပ်နိုင်သည်; လိုင်းခွဲများက Fillet ဖြင့် ထောင့်များ မည်သို့ သန့်ရှင်းသည်ကို ပြသည်။)

## အပြင်မျက်နှာကို Offset လုပ်ခြင်း

1. `O` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ prompt က `Specify offset distance [Through] <Through>:` ဟု ဖတ်ရသည်။
2. `200` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
3. `Select object to offset` တွင် အောက်ဘက်လိုင်းကို နှိပ်ပါ။
4. `Specify point on side to offset` တွင် ထိုလိုင်း၏ အောက်ဘက်ရာ၏ နေရာမည်သည်နေရာကိုမဆို နှိပ်ပါ။ အောက် 200 တွင် ဖြောင့်ခြားလိုင်း ပေါ်လာသည်။
5. ညာဘက်လိုင်းကို နှိပ်ပြီး ၎င်း၏ ညာဘက်ကို နှိပ်ပါ။
6. အပေါ်လိုင်းကို နှိပ်ပြီး ၎င်း၏ အပေါ်ကို နှိပ်ပါ။
7. ဘယ်ဘက်လိုင်းကို နှိပ်ပြီး ၎င်း၏ ဘယ်ဘက်ကို နှိပ်ပါ။
8. command ကို အဆုံးသတ်ရန် {{key:Enter}} နှိပ်ပါ။

အပြင်လိုင်း လေးကြောင် ပေါ်လာမည်၊ တစ်ခုစီသည် ၎င်း၏ အတွင်းလိုင်းနှင့် အရှည်တူသည်၊ ထို့ကြောင့် အပြင်ထောင့်များ မတွေ့ပါ။

:::tip
အကွာအဝေး prompt တွင် နောက်ဆုံးအကွာအဝေးကို ပြန်သုံးရန် {{key:Enter}} နှိပ်ပါ။ Through အတွက် `T` ကို ရိုက်ပါ- ထိုအခါ မိတ္တူတစ်ခုစီသည် သင်နှိပ်သော အမှတ်ကို ဖြတ်ကျော်သည်၊ ထိုအကွာအဝေး ဘယ်လောက်ဖြစ်စေ။
:::

{{cmd:OFFSET}} သည် လိုင်း၊ arc၊ စက်ဝိုင်းနှင့် polyline များပေါ် အလုပ်လုပ်သည်။ ပိတ်ထားသော polyline ကို offset လုပ်ခြင်းသည် ထောင့်များအပါအဝင် outline တစ်ခုလုံးကို offset လုပ်သည်။

## Fillet ဖြင့် အပြင်ထောင့်များကို သန့်ရှင်းခြင်း

{{cmd:FILLET}} သည် ထောင့်တစ်ခုတွင် လိုင်းနှစ်ကြောင်းကို ပေါင်းသည်: ၎င်းတို့ တွေ့ရန် နှစ်ခုလုံးကို ဖြတ်သည် သို့မဟုတ် တိုးချဲ့သည်။ radius 0 ဖြင့် ထောင့်သည် ထောင့်မှန်ဖြစ်သည်။

1. `F` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ prompt က `Select first line [Radius]:` ဟု ဖတ်ရသည်။
2. နောက်ဆုံး fillet က radius သုံးထားလျှင် `R` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ကာ `0` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
3. အပြင်အောက်လိုင်းကို ၎င်း၏ ညာဘက်အဆုံးနား နှိပ်ပါ။
4. `Select second line` တွင် အပြင်ညာဘက်လိုင်းကို ၎င်း၏ အောက်ဘက်အဆုံးနား နှိပ်ပါ။

လိုင်းနှစ်ကြောင်း ယခု ထောင့်ချွန်တွင် တွေ့သည်၊ command ပြီးသည်။

5. နောက်ထောင့်ကို လုပ်ရန် {{cmd:FILLET}} ကို ပြန်လုပ်ရန် {{key:Enter}} နှိပ်ပါ။
6. အပြင်ထောင့်လေးခုစလုံး တွေ့သည်အထိ ထပ်လုပ်ပါ။

သင် **ထားချင်သော** အပိုင်းပေါ်တွင် လိုင်းတစ်ခုစီကို နှိပ်ပါ။ radius 0 အပေါ်ရှိဆိုလျှင် Fillet က လိုင်းများကြား arc ထည့်သည်။

:::tip
ပထမ prompt တွင် `M` ကို ရိုက်လျှင် ထောင့်လေးခုကို တစ်ကြိမ်တည်း လုပ်သည်၊ သို့မဟုတ် အပြင်မျက်နှာကို polyline ပိတ်တစ်ခုအဖြစ် ဆွဲပြီး `P` ကို ရိုက်ပါ: ထောင့်တိုင်း တစ်ပြိုင်နက် ပြီးသည်။ radius မပြောင်းဘဲ ထောင့်ချွန်အတွက် ဒုတိယလိုင်းကို နှိပ်သည့်အခါ {{key:Shift}} ကို ဖိထားပါ။
:::

## Chamfer ဖြင့် ထောင့်ကို ဖြတ်ခြင်း

{{cmd:CHAMFER}} သည် ထောင့်ကို မျဉ်းဖြောင့်ဖြင့် ဖြတ်သည်။

1. `CHA` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
2. `D` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ ပထမအကွာအဝေးအတွက် `300` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ၊ ထို့နောက် ဒုတိယအတွက်လည်း 300 သုံးရန် {{key:Enter}} နှိပ်ပါ။
3. အတွင်းအပေါ်လိုင်းကို ၎င်း၏ ဘယ်ဘက်အဆုံးနား နှိပ်ပြီး ထို့နောက် အတွင်းဘယ်ဘက်လိုင်းကို ၎င်း၏ အပေါ်အဆုံးနား နှိပ်ပါ။

ထောင့်သည် လိုင်းတစ်ခုစီပေါ် 300 နောက်သို့ ဖြတ်ထားပြီး bevel လိုင်းတစ်ကြောင်းက ချိတ်ဆက်သည်။ ပထမလိုင်းပေါ် အရှည်နှင့် ထောင့်ပေးရန် `D` အစား `A` ကို ရိုက်ပါ။

## Trim ဖြင့် တံခါးဝကို ဖြတ်ခြင်း

ပထမ အောက်နံရံ ဖြတ်ကျော်သော တံခါးဘောင် နှစ်ခုကို ဦးစွာ ဆွဲပြီး ထို့နောက် ၎င်းတို့ကြား နံရံလိုင်းများကို trim လုပ်ပါ။

1. `L` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
2. `1000,200` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
3. `@0,-600` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ၊ ထို့နောက် {{key:Enter}} ကို နောက်တစ်ကြိမ် နှိပ်ပါ။
4. {{cmd:LINE}} ကို ပြန်လုပ်ရန် {{key:Enter}} နှိပ်ပါ။
5. `1900,200` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
6. `@0,-600` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ၊ ထို့နောက် {{key:Enter}} ကို နောက်တစ်ကြိမ် နှိပ်ပါ။

ယခု အောက်နံရံကို 900 ခွာပြီး ဖြတ်သော တိုလိုင်းနှစ်ကြောင်း ရှိသည်။

7. `TR` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ history က `Current settings: Quick mode, edges: No extend` ဟု ပြသည်။
8. ဘောင်နှစ်ခုကြား အတွင်းအောက်လိုင်းကို နှိပ်ပါ။ ထိုအပိုင်း ပျောက်သွားသည်။ (ဦးစွာ pointer ကို ထိုနေရာတွင် ထားပါ- ပျောက်မည့်အပိုင်းသည် မီးခိုးရောင်နှင့် အစက်ကြောင်း ဖြစ်လာသည်။)
9. ဘောင်နှစ်ခုကြား အပြင်အောက်လိုင်းကို နှိပ်ပါ။ ထိုအပိုင်းလည်း ပျောက်သွားသည်။
10. ဘောင်တစ်ခုစီ၏ နံရံအပေါ်တွင် ထွက်နေသော အပိုင်းနှင့် အောက်ရှိအပိုင်းကို နှိပ်ပါ။
11. command ကို အဆုံးသတ်ရန် {{key:Enter}} နှိပ်ပါ။

နံရံအောက်တွင် 900 အဖွင့် တစ်ခု၊ ဘောင်များက နံရံအဆုံးများကို ပိတ်ထားသည်ကို မြင်ရမည်။

Quick mode (မူလ) တွင် Trim သည် ဖြတ်မည့်ခေါင်းကြိုးများကို ဦးစွာ ရွေးခိုင်းမည် မဟုတ်ပါ- မြင်ရသော အရာတိုင်းသည် ဖြတ်ခေါင်းကြိုး ဖြစ်သည်။ ပျက်စေချင်သော အပိုင်းကို ရွေးပါ၊ သို့မဟုတ် အပိုင်းများစွာကို တစ်ပြိုင်နက် trim လုပ်ရန် လမ်းကြောင်းတစ်ခု ဆွဲပါ။ နောက်ဆုံးရွေးချယ်မှု သို့မဟုတ် ဆွဲမှုကို command မထွက်ဘဲ ပြန်ယူရန် `U` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ Fence၊ crossing၊ ရွေးထားသော ဖြတ်ခေါင်းကြိုးများနှင့် extend အတွက် {{key:Shift}} ကို [Trim and extend](topic:trim-and-extend) တွင် ကြည့်ပါ။

## လိုင်းတစ်ကြောင်းကို နောက်တစ်ခုနှင့် တွေ့အောင် Extend လုပ်ခြင်း

{{cmd:EXTEND}} သည် လိုင်း၊ arc သို့မဟုတ် polyline အဆုံးကို ထိုဦးတည်ရာရှိ နောက်အရာနှင့် တွေ့သည်အထိ ရှည်စေသည်။

1. `L` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
2. `1000,2000` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
3. `@2000,0` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ၊ ထို့နောက် {{key:Enter}} ကို နောက်တစ်ကြိမ် နှိပ်ပါ။ လိုင်းသည် ညာဘက်နံရံမှ 2000 အတိုရပ်သည်။
4. `EX` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
5. လိုင်းအသစ်ကို ၎င်း၏ ညာဘက်အဆုံးနား နှိပ်ပါ။
6. command ကို အဆုံးသတ်ရန် {{key:Enter}} နှိပ်ပါ။

လိုင်းသည် ယခု ညာဘက်နံရံ၏ အတွင်းမျက်နှာသို့ ရောက်သည်။ မြင်ရသော အရာတိုင်းသည် ဘောင်ဖြစ်သည်; ကြီးလာသင့်သော အဆုံးအနား နီးနီးတွင် ရွေးပါ။ {{cmd:TRIM}} အတွင်း {{key:Shift}}+နှိပ်ခြင်းသည် တူညီသည်။

## Break နှင့် lengthen

{{cmd:BREAK}} (`BR`၊ သို့မဟုတ် {{ui:Modify}} › {{ui:More}} › {{ui:Break}}) သည် ဖြတ်ခေါင်းကြိုးမလိုဘဲ ကွက်လပ်တစ်ခု ဖြတ်သည်: ကွက်လပ် စတင်သည့်နေရာတွင် အရာဝတ္ထုကို နှိပ်ပါ (ထိုနှိပ်ချက်သည် ပထမအမှတ် ဖြစ်သည်)၊ ထို့နောက် ပြီးဆုံးသည့်နေရာကို နှိပ်ပါ။ စက်ဝိုင်းတွင် ပထမအမှတ်မှ ဒုတိယအမှတ်အထိ နာရီလက်တံ ဆန့်ကျင်ဘက် အပိုင်း ပျောက်သည်။ ဒုတိယမေးခွန်းတွင် `F` က ပထမအမှတ်ကို ပြန်ပေးနိုင်စေပြီး {{cmd:BREAKATPOINT}} က အရာဝတ္ထုကို အမှတ်တစ်ခုတွင် ကွက်လပ်မဲ့ နှစ်ခု ခွဲသည်။

{{cmd:LENGTHEN}} (`LEN`) သည် အဆုံးတစ်ခုတွင် အရှည်ကို ပြောင်းသည်:

1. `LEN` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ လိုင်းတစ်ကြောင်းကို နှိပ်ပြီး ၎င်း၏ လက်ရှိအရှည်ကို ကြည့်ပါ; prompt က ထပ်မေးသည်။
2. နည်းလမ်း ရွေးပါ: `DE` (Delta- ထည့်ရန် ပမာဏ၊ အနုတ်ဖြင့် နုတ်သည်; arc ၏ ထောင့်အတွက် `A`)၊ `P` (Percent- 50 သည် တစ်ဝက်လုပ်သည်)၊ `T` (Total- ဖြစ်သင့်သော အရှည်) သို့မဟုတ် `DY` (Dynamic- အဆုံးကို ဆွဲပါ)။
3. ရွေ့သင့်သော အဆုံးနားတွင် အရာဝတ္ထုတစ်ခုစီကို နှိပ်ပါ။ `U` သည် နောက်ဆုံးကို ပြန်ယူသည်; {{key:Enter}} က အဆုံးသတ်သည်။

လိုင်း၊ arc နှင့် ဖွင့်ထားသော polyline (၎င်း၏ အဆုံး segment) များကို ရှည်စေနိုင်သည်။

## အမှားများ

- **လိုင်းတစ်ကြောင်းလုံး ပျောက်သွားသည်။** ဘာမှ ဖြတ်မကျော်သဖြင့် Quick mode က ဖျက်လိုက်သည်။ `U` ကို ရိုက်ပြီး ပြန်ထားပါ; ဖြတ်ကျော်မည့် လိုင်းသည် တကယ် ဖြတ်ကျော်သည်ကို (ဇူးမ်ချဲ့ပါ) နှင့် ပိတ်ထားသော layer ပေါ်တွင် မရှိကြောင်း စစ်ပါ။
- **"No boundary in that direction."** Extend သည် တိုက်ရန် ဘာမျှ မတွေ့ခဲ့ပါ။ ကြီးလာသင့်သော အဆုံးနား နီးနီးတွင် ရွေးပါ။
- **"Radius is too large."** Arc သည် လိုင်းတစ်ကြောင်း၏ အဆုံးကို ကျော်သွားမည်။ radius ငယ်ငယ် သုံးပါ။
- **"Only the first or last segment of an open polyline can be cut back."** polyline ၏ ကပ်လျက် segment နှစ်ခုကို ရွေးပါ၊ သို့မဟုတ် ၎င်း၏ ထောင့်တိုင်းကို ဝိုင်းစေရန် `P` ကို ရိုက်ပါ။
- **Offset သည် မှားသောဘက်သို့ သွားသည်။** ဘက်သည် အရာဝတ္ထုကို ရွေးပြီးနောက် သင်နှိပ်သည့်နေရာ ဖြစ်သည်။ {{key:Mod+Z}} ဖြင့် ပြန်ဖျက်ပြီး အခြားဘက်တွင် နှိပ်ပါ။
- **"Cannot offset that far."** Offset သည် arc၊ စက်ဝိုင်း သို့မဟုတ် polyline ကို အတွင်းပြင်ပြောင်းပစ်မည်။ အကွာအဝေး ငယ်ငယ် သုံးပါ။
