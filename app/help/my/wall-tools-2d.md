ဤ tools များသည် `WALL` မှ 2D နံရံများပေါ်တွင် အလုပ်လုပ်သည် (ကြည့်ပါ "စမတ် 2D နံရံများ၊ တံခါးများနှင့် ပြတင်းပေါက်များ ဆွဲခြင်း")။ ၎င်းတို့သည် BimCraft ၏ နံရံ tools များနှင့် တူညီသော စည်းမျဉ်းများကို သုံးသဖြင့် နံရံသည် နှစ်ခုစလုံးတွင် အတူတူ ပြုမူသည်။

## tools များ ရှိသည့်နေရာ

- toolbar ပေါ်တွင် {{ui:Walls}} အုပ်စုတွင် {{ui:Wall}}၊ {{ui:Rectangle}}၊ {{ui:Split}} နှင့် {{ui:Offset}} ရှိသည်။ ၎င်း၏ {{ui:More}} menu တွင် နံရံ tool အခြားအားလုံး ရှိပြီး တစ်ခုစီတွင် အိုင်ကွန် ပါသည်။
- ribbon menu style များတွင် {{ui:Walls}} tab တွင် {{ui:Draw walls}}၊ {{ui:Cut}}၊ {{ui:Set and modify}}၊ {{ui:Hold}} နှင့် {{ui:Join}} panel များ ရှိသည်။
- layout တွင် tool row များနှင့် toolbox တို့သည် တူညီသော {{ui:Walls}} အုပ်စုကို ပြသည်။
- အောက်တွင် ဖော်ပြထားသော command မည်သည့်အရာကိုမဆို ရိုက်နိုင်သည်။

## ဆက်ခြင်းများကို သိမ်းထားသည်

နံရံ၏ အဆုံးတစ်ခု အခြားနံရံပေါ်သို့ ကျရောက်သောအခါ CadCraft သည် ထိုဆက်ခြင်းကို နံရံနှစ်ခုစလုံးနှင့်အတူ သိမ်းသည်။ အဆုံးများ တည်ရှိရာနေရာမှ ဆက်ခြင်းကို ထပ်မတွက်တော့ပါ။ ထို့ကြောင့်-

- သင် ရွှေ့သော နံရံနှင့် ဆက်ထားသော နံရံများသည် ၎င်းကို လိုက်ပြီး ဆက်လက်ဆက်ထားသည်။ ၎င်းတို့၏ အဆုံးများသည် ကိုယ်ပိုင်မျဉ်းများပေါ်တွင် ဆွဲရွှေ့သဖြင့် ဘာမျှ မလှည့်ပါ။
- နံရံ၏ အဆုံးတစ်ခုကို grip ဖြင့် ဆွဲသောအခါ ထိုနေရာတွင် ဆက်ထားသော နံရံသည်လည်း ၎င်း၏ ဦးတည်ချက်ကို ထိန်းသည်။ ၎င်း၏ အဆုံးသည် ဆွဲနေသော နံရံနှင့် တွေ့ရန် ကိုယ်ပိုင်မျဉ်းပေါ်တွင် ရွှေ့ပြီး၊ ဆွဲထားသော အဆုံးသည် ထိုမျဉ်းပေါ်တွင် ကျရောက်သည်၊ cursor အောက်တွင် အမြဲမဟုတ်ပါ။ preview က နေရာကို ပြသည်။ ဆွဲနေသော နံရံထဲသို့ တိုက်ဝင်သော နံရံသည် ကိုယ်ပိုင်မျဉ်းအတိုင်း လိုက်သည်။ ဆွဲသော အဆုံးကို နံရံအတိုင်း တိုက်ရိုက် ဆွဲပါက နံရံ၏ အလျား ပြောင်းလဲပြီး ထိုနေရာတွင် ဆက်ထားသော နံရံသည် ၎င်းနှင့်အတူ ရွှေ့သည်။
- ဆက်ထားသော နံရံပေါ်တွင် `ROTATE` သည် အလားတူ လုပ်ဆောင်သည်: ပတ်ပတ်ပွ ခြင်းကြားရှိ အိမ်နီးချင်းနံရံများ၏ အဆုံးများသည် ကိုယ်ပိုင်မျဉ်းများပေါ်တွင် လှည့်ထားသော နံရံသို့ ရွှေ့သည်။
- ထောင့်တစ်ခုကို ရွှေ့ရန် ထိုနေရာတွင် တွေ့သော နံရံနှစ်ခုကို ရွေးပြီး ထောင့်ပေါ်ရှိ grip ကို ဆွဲပါ။ နံရံနှစ်ခုစလုံး ထောင့်တွင် ဆက်နေပြီး နှစ်ခုစလုံး လှည့်သည်။ ထိုမှ ဝေးသော နံရံများသည် မူလအတိုင်း ရှိနေသည်။
- ဆက်ခြင်းကို ရည်ရွယ်ချက်ရှိရှိ ဖြတ်ရန် grip ၏ အသစ်နေရာကို နှိပ်သောအခါ {{key:Alt}} ကို ဖိထားပါ: နံရံသည် သင် ထားသောနေရာသို့ သွားပြီး ဘာမျှ မလိုက်ပါ။
- ဆွဲမှုက ဆက်ထားသော နံရံကို ၎င်း၏ ကိုယ်ပိုင် အဝေးဆုံးအဆုံးမှတဆင့် လှည့်စေမည်ဆိုလျှင် ငြင်းပယ်ခံရပြီး ဘာမျှ မပြောင်းပါ။
- {{ui:Disallow joins}} (`WALL` တွင် `D`) ဖြင့် ဆွဲသော နံရံ သို့မဟုတ် Properties တွင် ပိတ်ထားသော ({{ui:Disallow join at start}}၊ {{ui:Disallow join at end}}) နံရံသည် အခြားနံရံကို ထိသော်လည်း ထိုအဆုံးတွင် လွတ်နေမည်၊ ပြန်ခွင့်ပြုသည်အထိ။
- `WALLDISJOIN` ({{ui:Walls}} အုပ်စုရှိ {{ui:Disallow join}}) သည် တစ်ချက်နှိပ်ဖြင့် အတူတူ လုပ်သည်: အဆုံးတစ်ခုနားရှိ နံရံကို နှိပ်လျှင် ထိုအဆုံးတွင် ဆက်ခြင်းကို ပိတ်သည်၊ ထပ်နှိပ်လျှင် ပြန်ခွင့်ပြုသည်။
- ဟောင်းသော drawing တွင် သိမ်းထားသော ဆက်ခြင်းမရှိသေးပါ။ သင်ပြုသော ပြောင်းလဲမှု ပထမတစ်ခုသည် ပြောင်းလဲမီ နံရံများ ရပ်နေပုံမှ ဆက်ခြင်းများကို တစ်ကြိမ်ရှာပြီး သိမ်းသည်။ `WALLJOINS` က ချက်ချင်း လုပ်ဆောင်သည်။
- DWG နှင့် DXF ဖိုင်များသည် ဆက်ခြင်းများကို နံရံတစ်ခုစီအတွင်း သယ်ဆောင်သည်။ CadCraft သည် သိမ်းထားသည့်အတိုင်း ပြန်ဖတ်သည်။ extended data မသိမ်းသော program သည် နံရံများကို ရိုးရိုး block များအဖြစ် ပြပြီး ဆက်ခြင်းများကို ဖျက်သည်၊ နံရံနှစ်ခုအနက် တစ်ခုကို အခြား program တွင် ရွှေ့ထားပါက ဆက်ခြင်းကို နောက်တစ်ကြိမ် နံရံတစ်ခုခု ပြောင်းသည့်အခါ ဖျက်သည်။

## ထောင့်တစ်ခု၏ join style

နံရံနှစ်ခု အဆုံးချင်းတွေ့သော ထောင့်ကို တခြား style မရွေးထားလျှင် mitre အဖြစ် ဆွဲသည်။

- `WALLJOINSTYLE` ({{ui:Walls}} အုပ်စုရှိ {{ui:Join style}}): ထောင့်ကို နှိပ်ပါ။ နှိပ်တိုင်း နောက် style သို့ သွားသည်: {{ui:Mitre}}၊ {{ui:Butt}}၊ {{ui:Square off}}၊ ထို့နောက် {{ui:Mitre}} ထပ်။ `T` ကို ရိုက်လျှင် နောက်ဆုံး နှိပ်ခဲ့သော ထောင့်တွင် နံရံနှစ်ခုအနက် မည်သည့်တစ်ခု ဖြတ်သွားမလဲ ပြောင်းသည်။ ပြီးဆုံးရန် {{key:Enter}} ကို နှိပ်ပါ။ command ၏ တစ်ကြိမ် run သည် ပြန်ဖျက်ရန် အဆင့် တစ်ခု ဖြစ်သည်။
- {{ui:Butt}}: နံရံတစ်ခုသည် အခြားနံရံ၏ အဝေးဘက်မျက်နှာသို့ ဖြတ်သွားပြီး အခြားနံရံက ၎င်း၏ဘေးတွင် ရပ်သည်။ {{ui:Square off}}: အတူတူပင်၊ သို့သော် ဖြတ်သွားသော နံရံသည် ကိုယ်ပိုင်အတွက် ထောင့်မှန်ဖြစ်အောင် ပြီးဆုံးသည်။ ထောင့်မှန်တွင် နှစ်ခုလုံး တူညီပုံ ပေါ်သည်။
- နံရံ၏ Properties တွင်: {{ui:Join style at start}}၊ {{ui:Join style at end}} နှင့် {{ui:Runs through at start}}၊ {{ui:Runs through at end}}။
- style ကို နံရံနှစ်ခုစလုံးနှင့်အတူ သိမ်းပြီး DWG နှင့် DXF ဖိုင်များတွင် သယ်ဆောင်သည်။ နံရံ၏ မိတ္တူသည် style မပါဘဲ စတင်သည်။
- T ဆက်ခြင်းတွင် ရွေးရန် style မရှိပါ: ထိခံရသော ဘက်ရှိ နံရံက ဖြတ်သွားသည်။ နံရံသုံးခု သို့မဟုတ် ထို့ထက်ပို တွေ့သော ထောင့်သည် mitre အဖြစ် ဆက်နေသည်။ အလွန်ထက်မြက်သော ထောင့် (၃၀ ဒီဂရီအောက် ခန့်) နှင့် မျဉ်းတစ်ကြောင်းတည်းရှိ နံရံနှစ်ခုတို့လည်း အလားတူ ဖြစ်သည်။

## နံရံ ပုံသဏ္ဌာန်များ ဆွဲခြင်း

ပုံသဏ္ဌာန်တစ်ခုစီသည် ထောင့်များ ဆက်ထားသော နံရံများကို ပြန်ဖျက်ရန် အဆင့် တစ်ခုတည်းဖြင့် ဆွဲသည်။ `WALL` တွင် `O` သည် placement offset ကို သတ်မှတ်သည် (နှိပ်ချက်များ၏ ဘယ်ဘက်ဘယ်လောက် ဝေးသည်) နှင့် `D` သည် နောက်တွင် ဆွဲမည့် နံရံများအတွက် ဆက်ခြင်းကို ပိတ်သည်။

- `WALLRECT` (`WR`): ထောင့်ဆန့်ကျင်ဘက် နှစ်ခု၊ `RECTANG` ကဲ့သို့။
- `WALLROT`: ပထမဘက်ခြမ်း၊ ထို့နောက် အခြားဘက်ခြမ်း ဘယ်လောက် ထွက်မလဲ၊ မည်သည့်ထောင့်မဆို စတုဂံအတွက်။
- `WALLPOLY` (`WP`): ဘက်အရေအတွက် (၃ မှ ၆၄)၊ ဗဟို၊ `I` (inscribed) သို့မဟုတ် `C` (circumscribed)၊ ထို့နောက် အခမ်းအနား၊ `POLYGON` ကဲ့သို့။
- `WALLARC` (`WARC`): ဗဟို၊ စတင်မှတ်၊ အဆုံးမှတ်။ `D` သည် arc ကို အခြားဘက်သို့ လှည့်သည်။
- `WALLTAN`: နံရံ၏ အဆုံးနားကို နှိပ်ပြီး ထို့နောက် arc ၏ အဆုံး၊ ထိုနံရံအတိုင်း ထွက်သည်။
- `WALLPICK`: မျဉ်း သို့မဟုတ် polyline ကို နှိပ်ပြီး ၎င်းနှင့် ဆက်ထားသော မျဉ်းများကိုပါ ယူမလား ပြောပါ။
- `WALLTRACE`: ပိတ်ထားသော မျဉ်းနှင့် နံရံများ၏ နယ်မြေအတွင်းကို နှိပ်ပြီး အသေးဆုံး တစ်ခုပတ်လည်တွင် နံရံများ ဆွဲသည်။

plan နံရံများသည် မျဉ်းဖြောင့်များ ဖြစ်သောကြောင့် arc ကို ဒီဂရီ ၁၅ စီ တိုတို မျဉ်းဖြောင့် နံရံများအဖြစ် ဆွဲသည်။ ၎င်းတို့သည် ထောင့်တိုင်း ကဲ့သို့ ဆက်သည်။

## နံရံများ ဖြတ်ခြင်း

- `WALLSPLIT` (`WS`): နံရံကို နှိပ်ပြီး နောက် အမှတ်ကို နှိပ်ပါ။ `C` သည် အခြားနံရံ ဖြတ်ကျော်သည့်နေရာတွင် ဖြတ်သည်၊ `G` သည် အပိုင်းများကြားတွင် လွတ်ကွက်ထားသည်၊ `F` သည် ဖြတ်ထားသော အဆုံးများကို ဆက်မထားဘဲ လွတ်စေသည်။ ပထမအပိုင်းသည် drawing ရှိ နံရံ၏ နေရာကို ထိန်းထားပြီး တံခါးနှင့် ပြတင်းပေါက်များသည် ၎င်းတို့၏ အပိုင်းနှင့်အတူ သွားသည်။ တံခါး သို့မဟုတ် ပြတင်းပေါက်ကို ဖြတ်ခြင်းကို ငြင်းပယ်သည်။
- `WALLSPLITGAP` ({{ui:Split with gap}}): တူညီသော ခွဲခြင်း၊ သို့သော် ပထမဆုံး လွတ်ကွက်ကို မေးသည်။
- `WALLDELSEG`: နံရံကို နှိပ်ပြီး ဖျက်ရမည့် အပိုင်း၏ အဆုံးနှစ်ခုကို နှိပ်ပါ။
- `WALLREJOIN`: တစ်ခုတည်းနံရံ၏ အပိုင်းနှစ်ခုကို နှိပ်ပြီး ပြန်တစ်ခုတည်း ဖြစ်စေသည်။

## အကွာအဝေးဖြင့် နံရံများ ရွှေ့ခြင်း

- `WALLDIM`: နံရံတစ်ခုမှ တခြားနံရံသို့ ဖြတ်သွားသော linear သို့မဟုတ် aligned dimension ကို နှိပ်ပြီး တန်ဖိုးအသစ်ကို ရိုက်ပါ။ အဝေးဆုံးအဆုံးရှိ နံရံသည် ကိုယ်ပိုင်အတွက် ထောင့်မှန်ဖြင့် ရွှေ့သည်၊ ပထမအဆုံးရှိ နံရံသည် ရပ်ထားပြီး ၎င်းနှင့် ဆက်ထားသော နံရံများ လိုက်သည်။
- `WALLOFFSET` (`WO`): နံရံကို နှိပ်ပြီး ရွှေ့ရမည့် ဘက်ကို နှိပ်ပါ (`D` သည် အကွာအဝေး ရိုက်ခြင်း၊ `C` သည် မိတ္တူ ပြုလုပ်ခြင်း)။
- `WALLSTRETCH`: နံရံ၏ အဆုံးများပတ်လည် window တစ်ခု၊ ထို့နောက် base point နှင့် ဒုတိယ point။
- Properties တွင် ရိုက်ထည့်ထားသော {{ui:Length}} သည် စတင်မှတ်ကို ထိန်းပြီး အဝေးဆုံးအဆုံးတွင် ဆက်ထားသော နံရံကိုလည်း ၎င်းနှင့်အတူ ယူသည်။ အသစ် {{ui:Thickness}} သည် သင်ရွေးထားသော {{ui:Location line}} (ဘယ်မျက်နှာ၊ ညာမျက်နှာ သို့မဟုတ် ဗဟို) မှ ကြီးထွားသည်။

## နံရံများ lock လုပ်ခြင်း

lock သည် ဖိုင်ထဲရှိ နံရံနှင့်အတူ ရှိနေသည်။ lock ထားသော နံရံတစ်ခုကို ရွှေ့လျှင် အခြားတစ်ခုက လိုက်သည်။ ပြောင်းလဲမှု တစ်ခုတည်းက နံရံနှစ်ခုကို မတူညီစွာ ရွှေ့လျှင် ငြင်းပယ်ပြီး ဘာမျှ မပြောင်းပါ။

- `WALLHOLD`: နံရံကို အခြားနံရံသို့ lock လုပ်သည်။ `A` သည် ပထမဆုံး အခြားနံရံ၏ မျဉ်းပေါ်သို့ ရွှေ့သည်၊ `K` သည် ရှိပြီးသား အကွာအဝေးကို ထိန်းသည်။
- `WALLHOLDDIM`: အပြိုင် နံရံနှစ်ခုကြား အကွာအဝေးကို lock လုပ်သည်။
- `WALLGRID`: နံရံကို grid line (grid layer ပေါ်ရှိ မျဉ်း၊ အဆုံးတစ်ခုတွင် စာသား tag ပါ) သို့ lock လုပ်သည်၊ မျဉ်းတလျှောက် သို့မဟုတ် အဆုံးတစ်ခု မျဉ်းပေါ်တွင်။ မျဉ်းတလျှောက် lock ထားသော နံရံသည် မျဉ်းနှင့် ရှိပြီးသား အကွာအဝေးကို ထိန်းသည်။ `GRIDMOVE` ဖြင့် grid line ကို ရွှေ့လျှင် နံရံသည် ဆက်ထားသော နံရံများနှင့်အတူ လုံးလုံး လိုက်သည်။ grid line တလျှောက် ရှိသော နံရံသည် lock မရှိဘဲပင် လုံးလုံး လိုက်သည်၊ မျဉ်းပေါ်တွင် အဆုံးတစ်ခုသာ ရှိသော နံရံကမူ ထိုအဆုံးဖြင့် ဆန့်သည်။
- `WALLHOLDS` သည် lock များကို စာရင်းပြုသည်။ `WALLUNHOLD` သည် နံရံမှ lock များကို ဖယ်ရှားသည်။
- lock တိုင်းသည် plan ပေါ်တွင် padlock အသေးလေး ပြသည်: lock ထားသော နံရံ၏ အလယ်ဘက်ဘေးတွင်၊ သို့မဟုတ် grid line သို့ lock ထားသော အဆုံးဘေးတွင်။ ထို lock ကို ဖယ်ရှားရန် padlock ကို နှိပ်ပါ။

## မရှိသေးသည့် အရာများ

lock များသည် နံရံများ၏ ဗဟိုမျဉ်းများကို အသုံးပြုသည်။ ဤနေရာတွင် နံရံများတွင် layer မရှိသဖြင့် ဆုံမှတ်တွင် layer ဦးစားပေးမရှိပါ၊ နံရံများလည်း မကွေးပါ (အထက်ရှိ arc ကို ကြည့်ပါ)။ ဤ tools ကို ပုံဆွဲကြီးတစ်ခုတွင် မစမ်းသပ်ရသေးပါ၊ အခြား CAD program တွင်လည်း စစ်ဆေးထားခြင်း မရှိသေးပါ။
