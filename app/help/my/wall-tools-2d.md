ဤကိရိယာများသည် `WALL` မှ 2D နံရံများပေါ် အလုပ်လုပ် ("Draw smart walls, doors and windows in 2D" ကို ကြည့်)။ BimCraft ရှိ နံရံကိရိယာများနှင့် တူညီသော စည်းမျဉ်းများ သုံး၊ ထို့ကြောင့် နံရံတစ်ခုသည် နှစ်ခုစလုံးတွင် တူညီစွာ ပြုမူ။

## ကိရိယာများ ရှိရာ

- ကိရိယာဘားတွင် {{ui:နံရံများ}} အုပ်စုတွင် {{ui:နံရံ}}၊ {{ui:စတုဂံ}}၊ {{ui:ခွဲရန်}} နှင့် {{ui:အော့ဖ်ဆက်}} ရှိ။ ၎င်း၏ {{ui:နောက်ထပ်}} မီနူးတွင် အခြား နံရံကိရိယာအားလုံး၊ icon တစ်ခုစီနှင့်အတူ။
- Ribbon မီနူးပုံစံများတွင် {{ui:နံရံများ}} tab တွင် {{ui:နံရံများ ဆွဲရန်}}၊ {{ui:ဖြတ်ရန်}}၊ {{ui:သတ်မှတ်ပြီး ပြင်ဆင်ရန်}}၊ {{ui:ထိန်းရန်}} နှင့် {{ui:ပေါင်းရန်}} panel များ ရှိ။
- Layout တွင် tool row များနှင့် toolbox တို့သည် တူညီသော {{ui:နံရံများ}} အုပ်စုကို ပြ။
- အောက်ပါ command အမည်များကို ရိုက်လည်း ရ။

## ဆက်ခြင်းများကို သိမ်း

နံရံ၏ အဆုံးတစ်ခု အခြားနံရံပေါ် ကျသောအခါ CadCraft သည် ထိုဆက်ခြင်းကို နံရံနှစ်ခုလုံးနှင့်အတူ သိမ်း။ အဆုံးများ ဘယ်နေရာ ကျသည်မှ ထပ်တွက်ခြင်း မလုပ်တော့။ ထို့ကြောင့်:

- သင် ရွှေ့သော နံရံနှင့် ဆက်ထားသော နံရံများက လိုက်ပြီး ဆက်ထားဆဲ။ ၎င်းတို့၏ အဆုံးများက ကိုယ်ပိုင် line ပေါ်တွင် ဆလိုက်၊ ဘာမျှ မလှည့်။
- နံရံတစ်ခု၏ အဆုံးကို grip ဖြင့် ဆွဲလျှင် ထိုနေရာတွင် ဆက်ထားသော နံရံက ၎င်း၏ ဦးတည်ချက်ကို ထိန်း။ ၎င်း၏အဆုံးသည် ၎င်း၏ကိုယ်ပိုင် line ပေါ်တွင် ဆလိုက်၊ ဆွဲနေသော နံရံနှင့် တွေ့အောင်၊ ထို့ကြောင့် ဆွဲထားသော အဆုံးသည် ကာဆာအောက်တွင် အမြဲ မရောက်၊ ထို line ပေါ်တွင် ရောက်။ Preview က ဘယ်နေရာ ဖြစ်မည်ကို ပြ။ ဆွဲနေသော နံရံနှင့် ထိုးဝင်သော နံရံက ၎င်း၏ကိုယ်ပိုင် line တလျှောက် လိုက်။ နံရံ၏ အဆုံးကို နံရံတလျှောက် တိုက်ရိုက် ဆွဲလျှင် အလျား ပြောင်း၊ ထိုနေရာတွင် ဆက်ထားသော နံရံက ၎င်းနှင့် အတူ ရွေ့။
- `ROTATE` ကို ဆက်ထားသော နံရံတွင် သုံးလျှင် အလားတူ ပြုမူ: ၎င်း၏ အိမ်နီးချင်းများ၏ အဆုံးများက လှည့်ထားသော နံရံဆီသို့ ကိုယ်ပိုင် line တလျှောက် ဆလိုက်။
- ထောင့်တစ်ခုကို ရွှေ့ရန် ထိုနေရာတွင် ဆုံသော နံရံ နှစ်ခုကို ရွေး၊ ထောင့်ပေါ် grip ကို ဆွဲ။ နံရံ နှစ်ခုလုံး ထောင့်တွင် ရှိနေ၍ နှစ်ခုလုံး လှည့်။ ထိုမှ ဝေးသော နံရံများသည် မူလအတိုင်း ရှိ။
- ဆက်ထားခြင်းကို ရည်ရွယ်ချက်ရှိရှိ ဖျက်ရန် grip ၏ အသစ်နေရာကို နှိပ်သည့်အခါ {{key:Alt}} ကို ဖိထား: နံရံသည် သင်ထားသည့်နေရာသို့ သွား၊ ဘာမျှ မလိုက်။
- ဆွဲမှုက ဆက်ထားသော နံရံကို ၎င်း၏ ဝေးသော အဆုံးမှတဆင့် ပြန်ကွေးစေလျှင် ငြင်းပယ်ပြီး ဘာမျှ မပြောင်း။
- {{ui:ဆက်ခြင်း ပိတ်ရန်}} (`WALL` တွင် `D`) ဖြင့် ဆွဲထားသော သို့မဟုတ် Properties တွင် ({{ui:အစတွင် ဆက်ခြင်း ခွင့်မပြုပါ}}၊ {{ui:အဆုံးတွင် ဆက်ခြင်း ခွင့်မပြုပါ}}) ပိတ်ထားသော နံရံသည် အခြားနံရံ ထိလျှင်ပင် ထိုအဆုံးတွင် လွတ်လပ်စွာ ကျန်၊ ပြန်ခွင့်ပြုမှ။
- `WALLDISJOIN` ({{ui:ဆက်ခြင်း ပိတ်ရန်}} ကို {{ui:နံရံများ}} အုပ်စုတွင်) က click ဖြင့် အတူတူ လုပ်: အဆုံးတစ်ခုအနီး နံရံကို click ၍ ထိုအဆုံးတွင် ဆက်ခြင်း ပိတ်၊ ထပ် click ပြန်ဖွင့်။
- ရှေးဟောင်း drawing တွင် သိမ်းထားသော ဆက်ခြင်းမရှိသေးပါ။ သင် ပထမ ပြောင်းလဲမှုက ၎င်းတို့ကို တစ်ကြိမ် ရှာ၊ ပြောင်းမလိုက် ရှိနေသော နံရံများ အပေါ် အခြေခံ၍ သိမ်း။ `WALLJOINS` က ချက်ချင်း လုပ်။
- DWG နှင့် DXF ဖိုင်များက ဆက်ခြင်းများကို နံရံတစ်ခုစီအတွင်း ယူဆောင်။ CadCraft က သိမ်းထားသည့်အတိုင်း ပြန်ဖတ်။ Extended data မသိမ်းသော program က နံရံများကို ရိုးရိုး block အဖြစ် ပြ၊ ဆက်ခြင်းများ ဖယ်; အခြား program တွင် ရွှေ့ထားသော နံရံများကြား ဆက်ခြင်းကို နံရံတစ်ခုခု ပြောင်းသည့်အခါ ဖယ်။

## ထောင့်တစ်ခု၏ ဆက်ပုံစံ

နံရံနှစ်ခု ဆုံးချင်းတွေ့သော ထောင့်ကို အခြားပုံစံ မရွေးလျှင် mitre အဖြစ် ဆွဲ။

- `WALLJOINSTYLE` ({{ui:ဆက်ပုံစံ}} ကို {{ui:နံရံများ}} အုပ်စုတွင်): ထောင့်ကို နှိပ်။ click တိုင်းသည် နောက်ပုံစံသို့ သွား: {{ui:Mitre}}၊ {{ui:ဖြတ်တောက်}}၊ {{ui:စတုရန်းပြုရန်}}၊ ထို့နောက် {{ui:Mitre}} ထပ်။ `T` ရိုက်၍ နောက်ဆုံး နှိပ်ခဲ့သော ထောင့်တွင် ဖြတ်သွားမည့် နံရံနှစ်ခုအနက် ဘယ်ဟာလဲ ပြော။ {{key:Enter}} ကို နှိပ်၍ ပြီးဆုံး။ Command ၏ run တစ်ခုသည် undo အဆင့် တစ်ခု။
- {{ui:ဖြတ်တောက်}}: နံရံတစ်ခုသည် အခြားနံရံ၏ ဝေးသော မျက်နှာသို့ ဖြတ်သွား၊ အခြားတစ်ခုသည် ၎င်း၏ဘေးတွင် ရပ်။ {{ui:စတုရန်းပြုရန်}}: တူညီသော်လည်း ဖြတ်သွားသော နံရံသည် ကိုယ်တိုင်နှင့် ထောင့်မှန်ဖြင့် ဆုံး။ ထောင့်မှန်တွင် နှစ်ခုလုံး တူ။
- နံရံ၏ Properties တွင်: {{ui:အစတွင် ဆက်ပုံစံ}}၊ {{ui:အဆုံးတွင် ဆက်ပုံစံ}}၊ နှင့် {{ui:အစတွင် ဖြတ်သွားသည်}}၊ {{ui:အဆုံးတွင် ဖြတ်သွားသည်}}။
- ပုံစံကို နံရံနှစ်ခုလုံးနှင့် သိမ်းပြီး DWG နှင့် DXF ဖိုင်များတွင် ခရီးသွား။ နံရံ၏ ကော်ပီသည် ပုံစံမပါဘဲ စတင်။
- T ဆက်ခြင်းတွင် ရွေးစရာ ပုံစံ မရှိ: ထိသော နံရံ၏ ဘေးရှိ နံရံက ဖြတ်သွား။ နံရံသုံးခု သို့မဟုတ် ပိုဆုံးသော ထောင့်သည် mitre ဖြစ်နေဆဲ။ ထောင့်ထက် အလွန်ထက်မြက်သော (ဒီဂရီ 30 အောက်ခန့်) ထောင့်နှင့် မျဉ်းတစ်ကြောင်းတည်းရှိ နံရံနှစ်ခုလည်း mitre ဖြစ်နေဆဲ။

## နံရံ ပုံသဏ္ဍာန်များ ဆွဲခြင်း

တစ်ခုစီသည် undo အဆင့် တစ်ခုတွင် နံရံများ ပြု၊ ထောင့်များ ဆက်ထား။ `WALL` တွင် `O` က placement offset (နံရံသည် သင်နှိပ်သည့်နေရာ၏ ဘယ်ဘက်ဘယ်လောက် ထွက်သလဲ) သတ်မှတ်၊ `D` က နောက်ဆွဲမည့် နံရံများအတွက် ဆက်ခြင်းကို ပိတ်။

- `WALLRECT` (`WR`): ထောင့်ဆန့်ကျင်ဘက် နှစ်ခု၊ `RECTANG` ကဲ့သို့။
- `WALLROT`: ပထမဘက်၊ ထို့နောက် အခြားဘက် ဘယ်လောက် ထွက်သလဲ၊ ဘယ်ထောင့်ဖြင့်မဆို လှည့်ထားသော စတုဂံအတွက်။
- `WALLPOLY` (`WP`): ဘက်အရေအတွက် (3 မှ 64)၊ center၊ `I` inscribed သို့မဟုတ် `C` circumscribed၊ ထို့နောက် radius၊ `POLYGON` ကဲ့သို့: နှိပ်ပါ၊ သို့မဟုတ် ရိုက်ပါ (ရိုက်သော radius က pointer ဆီသို့ သွား၊ သို့မဟုတ် pointer သည် center ပေါ်တွင် ရှိနေဆဲဆိုလျှင် X ဘက်သို့)။
- `WALLARC` (`WARC`): center၊ start၊ end။ `D` က arc ကို အခြားဘက် လှည့်။
- `WALLTAN`: နံရံ၏ အဆုံးအနီးကို နှိပ်၊ ထို့နောက် arc ၏ အဆုံး၊ ထိုနံရံတလျှောက် ထွက်သည်။
- `WALLPICK`: line သို့မဟုတ် polyline ကို နှိပ်ပြီး ၎င်းနှင့် ဆက်ထားသော line များကို လည်းယူမလား ပြော။
- `WALLTRACE`: ပိတ်ထားသော lines နှင့် နံရံဧရိယာ အတွင်းကို နှိပ်၊ အသေးဆုံးကို ပတ်လည် နံရံ ပြု။

Plan နံရံများ မျဉ်းဖြောင့်ဖြစ်သဖြင့် arc ကို ဒီဂရီ 15 စီ တိုတို မျဉ်းဖြောင့် နံရံများအဖြစ် ဆွဲ။ ၎င်းတို့သည် မည်သည့် ထောင့်ကဲ့သို့မဆို ဆက်။

## နံရံများ ဖြတ်ခြင်း

- `WALLSPLIT` (`WS`): နံရံကို နှိပ်၊ ထို့နောက် point။ `C` က အခြားနံရံ ဖြတ်သည့်နေရာတွင် ဖြတ်၊ `G` က အပိုင်းများကြား gap ထား၊ `F` က ဖြတ်သော အဆုံးများကို ဆက်မထား free ပြု။ ပထမအပိုင်းက နံရံ၏ နေရာကို drawing တွင် ထိန်း၊ တံခါးနှင့် ပြတင်းပေါက်များ ၎င်းတို့၏ အပိုင်းနှင့်အတူ သွား။ တံခါး သို့မဟုတ် ပြတင်းပေါက်ကို ဖြတ်လျှင် ငြင်းပယ်။
- `WALLSPLITGAP` ({{ui:လွတ်ကွက်ဖြင့် ခွဲရန်}}): တူညီသော ခွဲခြင်း၊ သို့သော် gap ကို အရင်မေး။
- `WALLDELSEG`: နံရံကို နှိပ်၊ ထို့နောက် ဖျက်မည့် အပိုင်း၏ အဆုံးနှစ်ခု။
- `WALLREJOIN`: နံရံတစ်ခု၏ အပိုင်းနှစ်ခုကို နှိပ်ပြီး နံရံတစ်ခုတည်း ပြန်ပြု။

## အကွာအဝေးဖြင့် နံရံများ ရွှေ့ခြင်း

- `WALLDIM` ({{ui:အတိုင်းအတာဖြင့် ပြင်ရန်}}): နံရံတစ်ခုမှ အခြားနံရံသို့ သွားသော အပြိုင် သို့မဟုတ် aligned dimension ကို နှိပ်၊ ထို့နောက် တန်ဖိုးအသစ် ရိုက်။ အဝေးဆုံးဘက် နံရံသည် ကိုယ်တိုင်နှင့် ထောင့်မှန် ရွှေ့၊ ပထမဆုံးဘက် နံရံ ကိုင်ထား၊ ၎င်းနှင့် ဆက်ထားသော နံရံများ လိုက်။ Dimension ၏ အဝေးဆုံး point သည် ၎င်း၏ နံရံနှင့်အတူ ရွေ့၊ dimension က သင်ရိုက်သည့်တန်ဖိုး ပြ။
- `WALLOFFSET` (`WO`): နံရံကို နှိပ်၊ ထို့နောက် ရွှေ့မည့်ဘက် (`D` က အကွာအဝေး ရိုက်၊ `C` က ကော်ပီ ပြု)။
- `WALLSTRETCH`: နံရံဆုံးများပတ်လည် window၊ ထို့နောက် base point နှင့် ဒုတိယ point။
- Properties တွင် ရိုက်သော {{ui:အလျား}} က ကြိုတင်ရှိသော အစကို ထိန်း၊ ၎င်းနှင့်အတူ အဝေးဆုံး ဆက်ထားသော နံရံကို ယူ၊ နှင့် {{ui:အထူ}} အသစ်က သင်ရွေးသော {{ui:တည်နေရာ မျဉ်း}} (ဘယ်မျက်နှာ၊ ညာမျက်နှာ သို့မဟုတ် အလယ်) မှ ထွက်ကြီး။

## နံရံ center line များကြား dimension ထည့်ခြင်း

နံရံ၏ center line ကို ဆွဲမထားသော်လည်း object snap က ရှာတွေ့။ Object snap ဖွင့်ထား ({{key:F3}}) တွင် နံရံ၏ အထူ၏ အလယ်အပေါ် ကာဆာကို ရွှေ့: marker က `Wall center: endpoint` သို့မဟုတ် `Wall center: midpoint` ဟု ဖတ်ပြီး marker ပေါ်ရှိ နေစဉ် center line က dashed line အဖြစ် ပြ။ Object snap စာရင်းတွင် {{ui:ထောင့်မတ်}} သို့မဟုတ် {{ui:အနီးဆုံး}} ကို ဖွင့်ထားလျှင် ထိုအရာများက center line ပေါ်တွင်လည်း အလုပ်လုပ်။

1. `DIMLINEAR` (သို့မဟုတ် `DIMALIGNED`) စ။
2. ပထမနံရံကို marker က `Wall center: midpoint` သို့မဟုတ် `Wall center: endpoint` ဟု ဖတ်သည့်နေရာတွင် နှိပ်။
3. ဒုတိယနံရံကို တူညီစွာ နှိပ်၊ ထို့နောက် dimension line သွားမည့်နေရာကို နှိပ်။
4. အကွာအဝေး ပြောင်းရန် `WALLDIM` စ၊ dimension ကို နှိပ်ပြီး တန်ဖိုးအသစ် ရိုက်။ ဒုတိယနံရံ ရွေ့သည်။

Centre-line snap သည် point တောင်းသော command တိုင်းတွင် အလုပ်လုပ်။

## နံရံ လော့ခ်ချခြင်း

Lock သည် ဖိုင်တွင် နံရံနှင့် ကပ်ရှိ။ လော့ခ်ချထားသော နံရံတစ်ခုကို ရွှေ့လျှင် အခြားက လိုက်။ ပြောင်းလဲမှုတစ်ခုက နံရံနှစ်ခုကို မတူညီစွာ ရွှေ့လျှင် ငြင်းပယ်ပြီး ဘာမျှ မပြောင်း။

- `WALLHOLD`: နံရံတစ်ခုကို အခြားနံရံသို့ လော့ခ်ချ။ `A` က အခြား နံရံ၏ line ပေါ်သို့ ပထမ ရွှေ့၊ `K` က ရှိသော အကွာအဝေးကို ထိန်း။
- `WALLHOLDDIM`: ပြိုင်နံရံ နှစ်ခုကြား အကွာအဝေးကို လော့ခ်ချ။
- `WALLGRID`: နံရံကို grid line သို့ လော့ခ်ချ (grid layer ပေါ်ရှိ line တစ်ခုဖြစ်ပြီး ၎င်း၏ tag ကို စာသားဖြင့် အဆုံးတစ်ခုတွင်ရှိ)၊ တလျှောက် သို့မဟုတ် ဆုံးတစ်ခုကို ထိုတွင်။ Line တလျှောက် လော့ခ်ချထားသော နံရံသည် ၎င်းနှင့် ရှိသော အကွာအဝေးကို ထိန်း။ `GRIDMOVE` ဖြင့် grid line ကို ရွှေ့လျှင် နံရံက ဆက်ထားသော နံရံများနှင့်အတူ အပြည့် လိုက်။ Grid line တလျှောက်ရှိ နံရံသည် လော့ခ် မရှိပင် ၎င်းနှင့်အတူ အပြည့် ရွေ့၊ ထို line ပေါ်တွင်သာ ဆုံးသော နံရံသည် ထိုဆုံးက ဆန့်။
- `WALLHOLDS` က လော့ခ်များကို စာရင်း။ `WALLUNHOLD` က နံရံ၏ လော့ခ်များကို ဖယ်။
- လော့ခ်တိုင်းသည် plan ပေါ်တွင် ပေါ့ပါးသော ကြိုးခလုတ်ငယ် ပြ: လော့ခ်ချထားသော နံရံ၏ အလယ်ဘေး၊ သို့မဟုတ် grid line သို့ လော့ခ်ချထားသော ဆုံး၏ ဘေး။ လော့ခ်တစ်ခုကို ဖယ်ရန် ကြိုးခလုတ်ကို နှိပ်။

## မကြာသေးမီ မရှိသေးသည်များ

လော့ခ်များသည် နံရံများ၏ center line များကို သုံး။ ဤနေရာတွင် နံရံများသည် layer မရှိ၊ ထို့ကြောင့် ဆုံနေရာတွင် layer ဦးစားပေး မရှိ၊ နံရံများသည် ကွေးသွားခြင်း မရှိ (အထက်ရှိ arc များကို ကြည့်)။ ဤကိရိယာများကို drawing ကြီးတွင် ဘယ်တော့မှ မစမ်းရသေးပြီး အခြား CAD program တွင် စစ်ဆေးခြင်း မရှိသေး။
