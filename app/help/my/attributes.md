## အက်ထရီဗျူတ်များဆိုသည်မှာ

အက်ထရီဗျူတ်ဆိုသည်မှာ ဘလောက် reference နှင့်အတူ သယ်ဆောင်သော အမည်ပေးထားသော တန်ဖိုးတစ်ခု ဖြစ်သည်။ ဥပမာ စက်ပစ္စည်း tag ၏ ပစ္စည်းနံပါတ်၊ အခန်း tag ၏ အမည်၊ တံခါး၏ မီးခံနိုင်ရည်။ ဘလောက်၏ အဓိပ္ပာယ်ဖွင့်ဆိုချက်က ၎င်းတွင် အက်ထရီဗျူတ် ဘာတွေရှိသည်ကို ပြောသည် (တစ်ခုစီတွင် **tag**၊ **prompt**၊ **default**၊ နှင့် ၎င်း၏ စာသား နေရာ၊ အရွယ်အစားနှင့် ထောင့် ရှိသည်)။ ဘလောက်၏ reference တိုင်းသည် ကိုယ်ပိုင် တန်ဖိုးများကို သယ်ဆောင်သည်။

အချို့ အက်ထရီဗျူတ်များသည် **ဝှက်ထား** ထားသည်။ ၎င်းတို့သည် ထုတ်လုပ်သူ သို့မဟုတ် မော်ဒယ် နံပါတ်ကဲ့သို့ ဒေတာကို ထိန်းသိမ်းသော်လည်း ဘယ်တော့မှ မဆွဲပါ။ အချို့သည် **ကိန်းသေ** ဖြစ်သည်။ ၎င်းတို့သည် reference တိုင်းအတွက် တူညီပြီး ဘလောက်က သတ်မှတ်သည်။

## အက်ထရီဗျူတ်များ ဘယ်ကလာသလဲ

- သင်ဖွင့်သော DWG နှင့် DXF ဖိုင်များရှိ ဘလောက်များသည် ၎င်းတို့၏ အက်ထရီဗျူတ်များကို reference တစ်ခုစီ၏ တန်ဖိုးများနှင့်အတူ ထိန်းထားသည်။
- {{cmd:INSERT}} နှင့် {{ui:File}} ရွေးချယ်မှုဖြင့် ယူလာသော ဘလောက်များသည် ၎င်းတို့ကိုလည်း ထိန်းထားသည်။ [ဖိုင် သို့မဟုတ် စာကြည့်တိုက်မှ သွင်းရန်](topic:insert-from-file-and-library) ကို ကြည့်ပါ။
- စာကြည့်တိုက် ပစ္စည်းများသည် အက်ထရီဗျူတ်ပါသော ဘလောက်များအဖြစ် ဝင်လာသည်။ မြင်ရသော ပစ္စည်းနံပါတ်နှင့် ပစ္စည်း၏ ဒေတာ (ဝှက်ထားသည်)။

- ကိုယ်တိုင်လုပ်သော ဘလောက်များ: အရင်ဆုံး {{cmd:ATTDEF}} ဖြင့် အက်ထရီဗျူတ်များ သတ်မှတ်ပါ (အောက်တွင်)၊ ထို့နောက် ဘလောက် ဖန်တီးချိန်တွင် အခြားအရာများနှင့်အတူ ရွေးပါ။

## ကိုယ်ပိုင်ဘလောက်များအတွက် အက်ထရီဗျူတ် သတ်မှတ်ရန်

1. ဘလောက်၏ မျဉ်းများကို ဆွဲပါ၊ ဥပမာ အခန်း tag။
2. {{ui:Blocks}} › {{ui:More}} › {{ui:Define attribute}} ကို ရွေးပါ၊ သို့မဟုတ် `ATT` ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
3. မှတ်တမ်းက မုဒ်များကို ပြမည် (`Invisible=No Constant=No Preset=No`)။ တစ်ခုကို ပြောင်းရန် `I`၊ `C` သို့မဟုတ် `P` ရိုက်ပါ။ မှန်ကန်သောအခါ {{key:Enter}} နှိပ်ပါ။ ဝှက်ထားသော တန်ဖိုးများကို ထိန်းထားသော်လည်း မဆွဲပါ။ ကိန်းသေတန်ဖိုးသည် reference တိုင်းတွင် တူညီသည်။ ကြိုသတ်မှတ်ထားသော တန်ဖိုးကို ဘလောက် ထည့်သောအခါ မမေးပါ။
4. tag (ဥပမာ `ROOM_NO`: အကြီးအက္ခရာ၊ space မပါ)၊ prompt (`Room number`) နှင့် default တန်ဖိုး (`101`) ရိုက်ပါ။
5. တန်ဖိုး သွားရမည့်နေရာကို နှိပ်ပြီး အမြင့်နှင့် လှည့်ပုံကို ပေးပါ။ tag သည် ပုံဆွဲပေါ်တွင် ပြသည်။
6. {{cmd:BLOCK}} ဖြင့် ဘလောက်ကို ဖန်တီးပါ။ မျဉ်းများနှင့် အက်ထရီဗျူတ် သတ်မှတ်ချက်များကို အတူတကွ ရွေးပါ။ အစားထိုးသော reference သည် default တန်ဖိုးများ ရမည်။ {{cmd:INSERT}} အသစ်တိုင်း ၎င်းတို့ကို မေးမည်။

ရွေးထားသော အက်ထရီဗျူတ် သတ်မှတ်ချက်သည် {{ui:Properties}} တွင် {{ui:Tag}}၊ {{ui:Prompt}}၊ {{ui:Default}} နှင့် မုဒ်များကို ပြသည်။

## ဘလောက်ကို ပြောင်းရန်: ဘလောက် တည်းဖြတ်သူ

{{ui:Blocks}} › {{ui:More}} › {{ui:Edit block}} ({{cmd:BEDIT}}၊ `BE`) သည် ဘလောက်ကို သီးခြား ဖွင့်သည်။ အမည်ကို ရိုက်ပါ (သို့မဟုတ် အရင် reference ကို ရွေးပါ)။ အပေါ်ရှိ ဘားက ဘယ်ဘလောက်ကို တည်းဖြတ်နေကြောင်း ပြသည်။ သာမန် command များဖြင့် ဆွဲ၊ ဖျက်၊ ပြောင်းပါ၊ အက်ထရီဗျူတ် သတ်မှတ်ချက်များကို ထည့်ပါ သို့မဟုတ် ပြောင်းပါ။ ထို့နောက် {{ui:Save block}} (သို့မဟုတ် {{cmd:BCLOSE}} ရိုက်ပြီး `S`) ကို နှိပ်ပါ။ reference တိုင်းတွင် ပြောင်းလဲမှု ပြမည်။ {{key:Mod+Z}} တစ်ကြိမ်ဖြင့် အားလုံး ပြန်ဖျက်နိုင်သည်။ {{ui:Discard changes}} ({{cmd:BCLOSE}}၊ `D`) သည် ဘလောက်ကို မူလအတိုင်း ထားခဲ့သည်။

အက်ထရီဗျူတ် သတ်မှတ်ချက်များကို ထည့်၊ ဖယ်၊ သို့မဟုတ် ပြောင်းသောအခါ သိမ်းလျှင် reference အားလုံးကိုလည်း ကိုက်ညီအောင် ပြင်မည်။ သင်ရိုက်ထားသော တန်ဖိုးများ ထိန်းထားမည်။ အသစ်သော အက်ထရီဗျူတ်သည် default ရမည်။ ဖယ်ထားသည်ကို ဖျက်မည်။ အက်ထရီဗျူတ်တိုင်း သတ်မှတ်ချက်က ပြောသည့် နေရာသို့ ပြန်ရောက်မည်။ မှတ်တမ်းက အပ်ဒိတ် လုပ်ထားသော reference အရေအတွက်ကို ပြမည်။

## ခေါင်းစဉ်ဘလောက်ကို နေရာတွင် တည်းဖြတ်ရန် (REFEDIT)

စာရွက်ပေါ်ရှိ ခေါင်းစဉ်ဘလောက်သည် ဘလောက်တစ်ခုအတွင်း ရှိနေလေ့ရှိသည်။ စာရွက်ကို မထွက်ဘဲ မျဉ်း သို့မဟုတ် စာသားများကို ပြောင်းရန်:

1. ခေါင်းစဉ်ဘလောက်ကို ရွေးပြီး {{ui:Blocks}} › {{ui:More}} › {{ui:Edit in place}} (သို့မဟုတ် {{cmd:REFEDIT}} ရိုက်ပါ)။
2. ၎င်း၏ အကြောင်းအရာများသည် နေရာတွင် ပုံမှန် အရာဝတ္ထုများ ဖြစ်လာသည်။ အခြားအရာအားလုံး မှေးသွားပြီး ပြောင်း၍မရပါ။
3. ပြောင်းပါ၊ ဖျက်ပါ သို့မဟုတ် ဆွဲပါ။ အသစ် အရာဝတ္ထုများသည် ဘလောက်၏ အစိတ်အပိုင်း ဖြစ်လာမည်။
4. အပေါ်ရှိ ဘားတွင် {{ui:Save the block}} ကို နှိပ်ပါ (သို့မဟုတ် {{cmd:REFCLOSE}} ရိုက်ပြီး `S`)။ reference တိုင်းတွင် ပြောင်းလဲမှု ပြမည်။ {{key:Mod+Z}} တစ်ကြိမ်ဖြင့် တည်းဖြတ်မှု တစ်ခုလုံးကို ပြန်ဖျက်နိုင်သည်။ {{ui:Discard}} သည် ဘလောက်ကို မူလအတိုင်း ထားခဲ့သည်။

ချိတ်ဆက်ထားသော ပုံဆွဲ၊ dynamic ဘလောက် သို့မဟုတ် အပေါ်နှင့် ဘေးမှ မတူစကေးဖြင့် scale ထားသော reference ကို နေရာတွင် တည်းဖြတ်၍ မရပါ။ {{cmd:BEDIT}} ကို သုံးပါ (သို့မဟုတ် ချိတ်ဆက်ထားသော ပုံဆွဲကို ဖွင့်ပါ)။

:::note
ပုံဆွဲကို သိမ်းမီ ဘလောက် တည်းဖြတ်သူတွင် သိမ်းပါ သို့မဟုတ် ပယ်ပါ။ တည်းဖြတ်သူ ဖွင့်ထားစဉ် သိမ်းထားသော ဖိုင်တွင် ဘလောက်သည် ယခင်အတိုင်း ရှိမည်။
:::

## ဘလောက် ထားချိန်တွင် ဖြည့်ရန်

1. `I` ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ ဘလောက်အမည်ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
2. ထားလိုသည့်နေရာကို နှိပ်ပါ။
3. CadCraft က တန်ဖိုးတစ်ခုစီကို မေးမည်၊ ဥပမာ `Enter Item number (ITEM) <>`။ တန်ဖိုးကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ၊ သို့မဟုတ် ထောင့်ကွင်းတွင် ပြထားသော default ကို ထားရန် {{key:Enter}} နှိပ်ပါ။

ဘလောက်က ကြိုသတ်မှတ်ထားသည် သို့မဟုတ် ကိန်းသေဟု အမှတ်အသားပြုထားသော တန်ဖိုးများကို မမေးပါ။ ၎င်းတို့သည် default ကို ယူမည်။

## တန်ဖိုးများကို ကြည့်ရန်နှင့် ပြောင်းရန်

1. ဘလောက် reference ကို နှိပ်ပါ။
2. ညာဘက် panel ရှိ {{ui:Attributes}} အောက်တွင် tag တစ်ခုစီမှာ တန်ဖိုးရှိသည်။ ဝှက်ထားသော တန်ဖိုးများက `hidden` ဟု ပြမည်။
3. တန်ဖိုးကို နှိပ်ပါ၊ အသစ်ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။

ပုံဆွဲက တန်ဖိုးအသစ်ကို ချက်ချင်း ပြမည်။ ပြောင်းလဲမှု တစ်ခုစီသည် တစ်ဆင့်ဖြစ်ပြီး {{key:Mod+Z}} ဖြင့် ပြန်ဖျက်နိုင်သည်။

**အက်ထရီဗျူတ် တည်းဖြတ်သူ။** အက်ထရီဗျူတ်ပါသော reference ကို နှစ်ချက်နှိပ်ပါ (သို့မဟုတ် {{cmd:EATTEDIT}})။ {{ui:Edit attributes}} dialog က tag တိုင်း၊ prompt နှင့် တန်ဖိုးကို ပြမည်။ တန်ဖိုးအသစ် ရိုက်ပါ။ အတန်းကို နှိပ်ပြီး ထို အက်ထရီဗျူတ်၏ {{ui:Height}}၊ {{ui:Rotation}}၊ {{ui:Width factor}}၊ {{ui:Justify}}၊ {{ui:Layer}}၊ {{ui:Color}} နှင့် {{ui:Invisible}} ကို ဤ reference အတွက်သာ ပြောင်းပါ။ {{ui:Apply}} က dialog ကို ဖွင့်ထားသည်။ {{ui:OK}} က ကျင့်သုံးပြီး ပိတ်သည်။ {{ui:Apply}} သို့မဟုတ် {{ui:OK}} တစ်ခုစီသည် undo တစ်ဆင့်ဖြစ်သည်။

**command line တွင်**၊ {{cmd:ATTEDIT}} က တန်ဖိုးတစ်ခုစီကို အစဉ်လိုက် မေးမည်။ အသစ် ရိုက်ပါ၊ သို့မဟုတ် ထိန်းထားရန် {{key:Enter}} နှိပ်ပါ။

## အက်ထရီဗျူတ် သတ်မှတ်ချက်များကို ပြောင်းရန် (BATTMAN၊ ATTSYNC)

{{ui:Blocks}} › {{ui:More}} › {{ui:Attribute manager}} ({{cmd:BATTMAN}}) သည် ဘလောက်၏ အက်ထရီဗျူတ်များကို စာရင်းပြုသည်။ tag၊ prompt သို့မဟုတ် default ကို ပြောင်းပါ။ {{ui:Invisible}}၊ {{ui:Constant}} သို့မဟုတ် {{ui:Preset}} ကို အမှန်ခြစ်ပါ။ အပေါ် သို့မဟုတ် အောက်သို့ ရွှေ့ပါ (တန်ဖိုးများ မေးမည့် အစဉ်)။ {{ui:Update the references (values kept)}} ကို အမှန်ခြစ်ထားလျှင် {{ui:Apply}} သည် reference အားလုံးကိုလည်း ကိုက်ညီအောင် ပြင်မည်။ အမည်ပြောင်းထားသော tag သည် တန်ဖိုးများကို ထိန်းထားမည်။ {{ui:Apply}} တစ်ကြိမ်စီသည် undo တစ်ဆင့် ဖြစ်သည်။

{{cmd:ATTSYNC}} သည် reference များကို ၎င်းတို့၏ ဘလောက် သတ်မှတ်ချက်များနှင့် လက်ဖြင့် ကိုက်ညီအောင် ပြင်သည်။ `S` က reference တစ်ခု ရွေးသည်၊ `N` က ဘလောက်အမည် ပေးသည်၊ `A` က ဘလောက် အားလုံးကို လုပ်သည်။ တန်ဖိုးများ ထိန်းထားသည်။

စာကြည့်တိုက် ပစ္စည်း၏ ကိုယ်ပိုင် အကွက်များ (id၊ version၊ လိုင်စင်နှင့် ရည်ညွှန်းချက်) သည် ပြသထားသော်လည်း ပြင်၍မရပါ။ ထို့ကြောင့် အပ်ဒိတ်စစ်ဆေးခြင်း ဆက်လုပ်နိုင်သည်။ ၎င်း၏ ပစ္စည်းနံပါတ်နှင့် ပမာဏကို သင်ပြောင်းနိုင်သည်။

## စာရင်းပြုရန်

reference များကို ရွေးပြီး `LI` (for {{cmd:LIST}}) ရိုက်ပါ။ မှတ်တမ်းက အက်ထရီဗျူတ်တိုင်းကို `TAG = value` အဖြစ် ပြမည်။ သက်ဆိုင်ရာ နေရာတွင် `(invisible)` သို့မဟုတ် `(constant)` ပါမည်။

## ရွှေ့ခြင်း၊ လှည့်ခြင်းနှင့် ခွဲခြင်း

- {{cmd:MOVE}}၊ {{cmd:ROTATE}}၊ {{cmd:SCALE}} နှင့် {{cmd:MIRROR}} သည် တန်ဖိုးများကို ထိန်းထားသည်။ စာသားသည် ဘလောက်နှင့်အတူ ရွှေ့ပြီး ဖတ်ရလွယ်နေမည်။
- {{cmd:EXPLODE}} သည် ပြသထားသော အက်ထရီဗျူတ်များကို ၎င်းတို့၏ တန်ဖိုးများပါသော ရိုးရိုးစာသား ဖြစ်စေသည်။ ဝှက်ထားသော အက်ထရီဗျူတ်များကို ဖျက်သည်။

## သိမ်းခြင်း

သိမ်းထားသော DWG နှင့် DXF နှစ်မျိုးလုံးက အက်ထရီဗျူတ်တိုင်းကို ထိန်းထားသည်။ ဘလောက်တစ်ခုစီ၏ သတ်မှတ်ချက်များ (ဝှက်ထား၊ ကိန်းသေနှင့် ကြိုသတ်မှတ်ထားသည်များ အပါအဝင်) နှင့် reference တစ်ခုစီ၏ တန်ဖိုးများ။ အခြား CAD ပရိုဂရမ်များက ၎င်းတို့ကို ရိုးရိုး ဘလောက် အက်ထရီဗျူတ်များအဖြစ် ဖတ်သည်။

DXF R12 တွင် 255 လုံးထက် ရှည်သော တန်ဖိုးကို 255 လုံးအထိ ဖြတ်မည်။ မှတ်တမ်းက ထိုသို့ ပြောမည်။

## အဖြစ်များသော အမှား

- **တန်ဖိုးက ပုံဆွဲပေါ်တွင် မပေါ်ပါ။** ဝှက်ထားသည်၊ သို့မဟုတ် လွတ်နေသည်။ ဝှက်ထားသော တန်ဖိုးများသည် ညာ panel တွင် ဆက်ပြသည်။
- **ကျွန်ုပ်ရိုက်သော တန်ဖိုးသည် command line သို့ ရောက်သွားသည်။** ညာ panel ရှိ တန်ဖိုးအကွက်ကို အရင်နှိပ်ပါ။
