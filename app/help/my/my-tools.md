## သင် လေ့လာမည့်အရာ

ကိုယ်ပိုင်ခလုတ်များကို toolbar ပေါ်တွင် မည်သို့ထားရမည်၊ AutoCAD ရေးသော ပုံစံဖြင့် ရေးထားသော macro တစ်ခုစီကို မည်သို့ run စေရမည်၊ ခလုတ်တစ်ခုကို key ပေးနည်း၊ နှင့် CUIx ဖိုင်မှ ခလုတ်များကို မည်သို့ ယူရမည်ကို လေ့လာမည်။

## ခလုတ်တစ်ခု ထည့်ခြင်း

1. {{ui:Settings}} ({{key:Mod+,}}) ကို ဖွင့်ပြီး {{ui:CadCraft}} tab တွင် ဆက်နေပါ။ {{ui:My tools}} သို့ scroll လုပ်ပါ။
2. {{ui:Add a button…}} ကို နှိပ်ပါ။
3. အကွက်ကို ဖြည့်ပါ-
   - {{ui:Group}}: ခလုတ်ဝင်မည့် toolbar အုပ်စု၊ ဥပမာ `My tools`။ အမည်အသစ်ဖြင့် အုပ်စုအသစ် ဖန်တီးသည်။
   - {{ui:Label}}: ခလုတ်ပေါ်ရှိ စာသား။
   - {{ui:Macro}}: ရိုက်မည့်အရာ၊ ဥပမာ `^C^C_rectang;0,0;@100,50;`။
   - {{ui:Shortcut key}}: အကွက်ကို နှိပ်ပြီး ခလုတ်များ နှိပ်ပါ၊ ဥပမာ {{key:Ctrl+Alt+B}}။
   - {{ui:Icon}}: အရွယ် 64 KB မကျော်သော PNG သို့မဟုတ် SVG ပုံ၊ သို့မဟုတ် မရှိ (ကြယ်တစ်ခု ပေါ်သည်)။
4. {{ui:Save}} ကို နှိပ်ပါ။

ခလုတ်သည် toolbar ၏ အဆုံးတွင် ၎င်း၏ အုပ်စုအတွင်း ပေါ်လာသည်။ run ရန် ၎င်းကို နှိပ်ပါ၊ သို့မဟုတ် ၎င်း၏ key ကို နှိပ်ပါ။ စာရင်းရှိ {{ui:Edit}} နှင့် {{ui:Delete}} သည် ပြောင်းလဲရန် သို့မဟုတ် ဖယ်ရှားရန် ဖြစ်သည်။

## Macro ရေးခြင်း

macro သည် command line တွင် ရိုက်မည့်အရာ ဖြစ်ပြီး သင်္ကေတအနည်းငယ်ပါသည်-

| သင်္ကေတ | အဓိပ္ပာယ် |
|---|---|
| `^C` | ရှိနေသမျှ အရာကို ပယ်ဖျက်သည် (`^C^C` သည် ပုံမှန် အစ) |
| `;` သို့မဟုတ် space | {{key:Enter}} |
| `\` | သင့်ကို စောင့်သည်- click တစ်ခု သို့မဟုတ် ရိုက်ထားသော အဖြေ၊ ထို့နောက် macro ဆက်လုပ်သည် |
| command ရှေ့ရှိ `_` သို့မဟုတ် `.` | လက်ခံပြီး လျစ်လျူရှုသည် (နိုင်ငံတကာနှင့် built-in အမည်များ) |
| အစရှိ `*` | အဆုံးသတ်တိုင်း ထပ် run သည်၊ {{key:Esc}} ကို မနှိပ်မချင်း |
| `^O`၊ `^G` | Ortho၊ grid ကို ဖွင့်/ပိတ် |
| `$M=` | ကျန်သည်မှာ DIESEL ဖြစ်သည်။ `$(if,…)`၊ `$(getvar,…)`၊ `$(=,…)` နှင့် `$(eq,…)` သာ ဖတ်သည်; အခြားအရာ သုံးသော ခလုတ်သည် ထိုအကြောင်း ပြပြီး ဘာမှ မလုပ်ပါ |

ဥပမာများ-

- `^C^C_line;0,0;@100,0;;` သည် မူလမှ 100 အရှည် လိုင်းတစ်ကြောင်း ဆွဲသည်။
- `^C^C_circle;\25;` သည် center ကို မေးပြီး ထိုနေရာတွင် radius 25 စက်ဝိုင်း ဆွဲသည်။
- `^C^C_turnright` သည် view ကို 90° ညာသို့ လှည့်သည်။

## Shortcut key များ

key တစ်ခုသည် {{key:Mod}} (Ctrl၊ သို့မဟုတ် Mac တွင် Cmd) သို့မဟုတ် {{key:Alt}} နှင့် အက္ခရာ သို့မဟုတ် ဂဏန်း၊ သို့မဟုတ် အခမဲ့ function key များ {{key:F2}}၊ {{key:F4}}၊ {{key:F5}}၊ {{key:F6}}၊ {{key:F9}} တစ်ခုခု လိုသည်။ အက္ခရာတစ်ခုတည်းသည် command line သို့ သွားသည်။ CadCraft၊ app သို့မဟုတ် ဘရောက်ဇာ သုံးပြီးသား key များ (ဥပမာ {{key:Ctrl+S}} သို့မဟုတ် {{key:Ctrl+Z}}) နှင့် အခြားခလုတ်တစ်ခုမှ သုံးနေသော key များကို ငြင်းပယ်ပြီး အကွက်က အကြောင်းပြသည်။

## ခလုတ်များ မျှဝေခြင်း

- {{ui:Export…}} သည် အုပ်စုနှင့် ခလုတ်အားလုံး (icon နှင့် key များအပါအဝင်) ကို `my-tools.json` အဖြစ် သိမ်းသည်။
- {{ui:Import…}} သည် ထိုသို့သော ဖိုင်၏ အုပ်စုများကို သင်၏အုပ်စုများ နောက်တွင် ထည့်သည်။ သင်သုံးပြီးသား အုပ်စုအမည်သည် "(2)" ရရှိသည်; ရန်ဖြစ်မည့် key ကို ချန်ထားပြီး panel က ထိုအကြောင်း ပြသည်။

## CUIx ဖိုင်မှ ခလုတ်များ ယူခြင်း

1. {{ui:Import CUIx…}} ကို နှိပ်ပြီး `.cuix` ဖိုင်ကို ရွေးပါ။

ထိုဖိုင်၏ toolbar များနှင့် ribbon panel များသည် အုပ်စုများ ဖြစ်လာသည်၊ ခလုတ်တစ်ခုစီသည် ၎င်း၏ macro နှင့် ပုံ (PNG၊ သို့မဟုတ် PNG အဖြစ် ပြောင်းထားသော BMP) ပါသည်။ ၎င်း၏ shortcut key များသည် ၎င်းတို့ကိုယ်ပိုင် အုပ်စုတွင် ပါလာပြီး ခလုတ်တစ်ခုစီတွင် key ရှိသည်; ၎င်းတွင် ပါနိုင်သော command alias များသည် {{ui:Aliases}} အုပ်စုတွင် ပါလာသည်။ panel က ဘာတွေ ပါလာသည်ကို ဖော်ပြသည်။

:::note
ဖိုင်ကို ဖတ်ရုံသာ ဖတ်သည်။ CadCraft တွင် မရှိသော command များကို ၎င်းတို့၏ အမည်ဖြင့် ဖော်ပြသည်၊ ခန့်မှန်းခြင်း မလုပ်ပါ- ၎င်းတို့၏ ခလုတ်များက နှိပ်သည့်အခါ ထိုအကြောင်း ပြသည်။ အထက်ပါ function အနည်းငယ်အပြင် DIESEL၊ menu များ၊ မောက်စ်ခလုတ်များနှင့် workspace များကို ဖတ်ခြင်း မရှိပါ။
:::

## သိထားသင့်သည်များ

- ခလုတ်များကို ဤဘရောက်ဇာ (သို့မဟုတ် ဤ desktop app) တွင် သိမ်းထားသည်၊ ဒရော်ဝိင်များတွင် မဟုတ်ပါ။
- ခလုတ်သည် command line မှတစ်ဆင့် run သဖြင့် ရိုက်ထည့်သည်များကဲ့သို့ ပြန်ဖျက်နိုင်သည်- run သော command တစ်ခုစီအတွက် {{key:Mod+Z}} တစ်ကြိမ်။
