## သင်လေ့လာမည့်အရာများ

LISP routine (`.lsp` ဖိုင်) ကို CadCraft တွင် command များ အလုပ်လုပ်စေရန် တင်နည်း၊ ဖြုတ်နည်းနှင့် CadCraft ဖွင့်တိုင်း အလိုအလျောက် တင်စေနည်း။

## Routine တင်ရန်

1. {{ui:View}} › {{ui:More}} › {{ui:Load application…}} ကို ဖွင့်ပါ၊ သို့မဟုတ် {{cmd:APPLOAD}} (သို့မဟုတ် `AP`) ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
2. {{ui:Load a file…}} ကို နှိပ်ပြီး `.lsp` ဖိုင် တစ်ခု သို့မဟုတ် ထို့ထက်ပို ရွေးပါ။ Dialog ဖွင့်သော routine သည် များသောအားဖြင့် `.dcl` ဖိုင်နှင့်အတူ ပါလာသည်: ၎င်းကိုလည်း ရွေးပါ။
3. Dialog က ဖိုင်တစ်ခုစီက ဖန်တီးသည့်အရာကို ပြသည်၊ ဥပမာ "delblocks.lsp တင်ပြီး: command 1 ခု, DELBLOCKS"။
4. {{ui:Close}} ကို နှိပ်ပြီး routine ၏ command ကို ရိုက်ကာ {{key:Enter}} နှိပ်ပါ။

`.lsp` နှင့် `.dcl` ဖိုင်များကို ပုံဆွဲပေါ်၊ သို့မဟုတ် Load applications dialog ပေါ်တွင် ချနိုင်ပါသည်: ချက်ချင်း တင်သည်။

ဖိုင်ကို ဤနေရာ၊ သင့် browser တွင် ဖတ်သည်။ ဘာမျှ upload မလုပ်ပါ။

:::tip
ဗလာ command line တွင် {{key:Enter}} နှိပ်ပြီး routine ၏ command ကို ထပ်လုပ်ပါ၊ အခြား command နှင့် အတူတူ။ သင့် command alias များလည်း ၎င်းသို့ ရောက်နိုင်သည်: "Command alias များ တည်းဖြတ်ခြင်း" ကို ကြည့်ပါ။
:::

## Routine ဖြုတ်ရန်

{{ui:Load applications}} တွင်၊ {{ui:Loaded applications}} အောက်၌ ဖိုင်ဘေးရှိ {{ui:Unload}} ကို နှိပ်ပါ။ ၎င်းတို့ ဖန်တီးထားသော command များသည် ပြန်တင်သည်အထိ ပျောက်နေမည်။

## CadCraft ဖွင့်တိုင်း routine တင်ရန်

1. Routine ကို တင်ပါ။
2. {{ui:Loaded applications}} အောက်၌ ဘေးရှိ {{ui:Add to Startup Suite}} ကို နှိပ်ပါ။

ထို့နောက် CadCraft ဤ browser တွင် စတင်သည့်အခါတိုင်း ၎င်းသည် အလိုအလျောက် တင်သည်။ ရပ်ရန် {{ui:Startup Suite}} အောက်ရှိ ၎င်းဘေးရှိ {{ui:Remove}} ကို နှိပ်ပါ။

Startup Suite သည် ဖိုင်တစ်ခုစီ၏ မိတ္တူကို ဤ browser ၏ သိုလှောင်မှုတွင် သိမ်းသည်။ Routine ကို ပြောင်းလျှင် ဖိုင်အသစ်ကို တင်ပြီး ပြန်ထည့်ပါ။

## ပံ့ပိုးမှု ဖိုင်တွဲမှ acad.lsp နှင့် acaddoc.lsp တင်ရန် (Studio)

CadCraft Studio တွင် {{ui:Load applications}} dialog ရှိ {{ui:Support folder}} သည် သင့်ကွန်ပျူတာရှိ ဖိုင်တွဲတစ်ခုကို ယူသည်။ {{ui:Choose folder…}} ကို နှိပ်ပါ။ CadCraft စတင်သည့်အခါ ထိုဖိုင်တွဲမှ `acad.lsp` ကို ဖတ်ပြီး ထို့နောက် `acaddoc.lsp` ကို ဖတ်ကာ (အမည်အက္ခရာ အကြီးအသေး မရွေး) တင်သည်၊ ထို့နောက် Startup Suite ကို တင်သည်။ `acaddoc.lsp` ကို drawing tab အသစ် ဖွင့်တိုင်း ထပ်ဖတ်သည်။ ဖိုင်တွဲရှိ အခြားဘာမျှ မဖတ်ပါ၊ 2 MB ကျော်သော ဖိုင်ကို မက်ဆေ့ချ်ဖြင့် ကျော်သည်။

ဖိုင်တစ်ခုက `S::STARTUP` အမည်ရှိ function ကို သတ်မှတ်လျှင် ဖိုင်များ တင်ပြီးနောက် တစ်ကြိမ် run သည် (Startup Suite ပြီးနောက်လည်း)။ {{ui:Load now}} သည် တောင်းဆိုသည့်အခါ အလားတူ လုပ်သည်; {{ui:Clear}} သည် ဖိုင်တွဲကို မှတ်ထားခြင်းကို ဖျက်သည်။

Browser တွင် စာမျက်နှာသည် ဖိုင်တွဲကို မသိမ်းနိုင်သဖြင့် ပံ့ပိုးမှု ဖိုင်တွဲ မရှိပါ: အထက်ပါ Startup Suite ကို သုံးပါ။ Compile ပြုလုပ်ထားသော `.fas` နှင့် `.vlx` ဖိုင်များနှင့် native ပရိုဂရမ်များကို ဆက်ငြင်းပယ်ထားဆဲ ဖြစ်သည်။

## မှတ်တမ်းမှ ဖိုင်ကို ပြန်တင်ရန်

{{ui:History}} သည် ဤ browser တွင် တင်ခဲ့သော ဖိုင်များကို အသစ်ဆုံးက အရင် ဖော်ပြသည်။ တစ်ခုအနား {{ui:Load}} ကို နှိပ်၍ သင့်ကွန်ပျူတာတွင် ရှာစရာမလိုဘဲ ပြန်တင်ပါ။

## CadCraft တင်၍ မရသော ဖိုင်များ

| ဖိုင် | ဘာလဲ | ဘာလုပ်ရမလဲ |
|---|---|---|
| `.fas`, `.vlx` | Compile သို့မဟုတ် ကာကွယ်ထားသော LISP | `.lsp` source ကို တင်ပါ |
| `.arx`, `.crx`, `.dbx` | Native Windows ပရိုဂရမ်များ | CadCraft တွင် ဤတို့ကို run ရန် နည်းလမ်း မရှိပါ |
| `.dvb` | VBA project | CadCraft တွင် ဤတို့ကို run ရန် နည်းလမ်း မရှိပါ |
| `.craft`, `.lua`, `.py` | CraftScript script များ | PartCraft ၏ Script workspace တွင် ဖွင့်ပါ |

Load applications dialog က ဖိုင်ကို ရွေးသည့်အခါ ၎င်းတို့ထဲမှ မည်သည့် အမျိုးအစားဖြစ်သည်ကို ပြောသည်။

## Routine ရပ်ရန်

{{key:Esc}} ကို နှိပ်ပါ။ Routine ၏ prompt တစ်ခုတွင် Esc သည် ၎င်းမျှော်လင့်သော နည်းဖြင့် ပယ်ဖျက်သည် (၎င်း၏ သန့်ရှင်းရေး လုပ်ငန်း လည်ပတ်သည်)။ အလုပ်ရှုပ်နေပြီး ဘာမျှ မမေးနေလျှင် Esc သည် တိုက်ရိုက် ရပ်စေပြီး ထိုသို့ ပြောသည်; တင်ထားသော routine များ ဆက်တင်နေဆဲ ဖြစ်သည်။

:::note
Routine က ပုံဆွဲတွင် ပြောင်းသမျှသည် အဆင့်တစ်ခုတည်း ဖြစ်သည်: {{key:Mod+Z}} တစ်ကြိမ်ဖြင့် အားလုံး ပြန်ယူနိုင်သည်။
:::
