## ဘာပြုလုပ်မလဲ

ပုံဆွဲ၏ ယခင် ဗားရှင်းတစ်ခုကို ကြည့်ခြင်း၊ ယခုနှင့် ကွာခြားချက် စာရင်း: ဘာထည့်ထားသည်၊ ဘာဖျက်ထားသည်နှင့် ဘာပြောင်းထားသည်၊ ပုံဆွဲပေါ်တွင် အရောင်ဖြင့် အမှတ်အသားပြုထား။

## သမိုင်းကို ဖွင့်ရန်

`HISTORY` (သို့မဟုတ် `HIST`) ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:အမြင်}} အုပ်စု၏ {{ui:နောက်ထပ်}} မီနူးမှ {{ui:သမိုင်း…}} ကို ရွေးပါ။ Panel သည် ပုံဆွဲ၏ ဘေးတွင် ဖွင့်ပြီး သင်အလုပ်လုပ်နေစဉ် ဖွင့်ထားသည်၊ ထို့ကြောင့် အရောင်များနှင့်အတူ ပုံဆွဲကို pan နှင့် zoom လုပ်နိုင်သည်။

သမိုင်းသည် CadCraft Studio တွင် အလုပ်လုပ်သည်။ Browser တွင် panel က ထိုသို့သာ ပြောသည်။

## ဗားရှင်းများ မည်သည့်နေရာမှ လာသလဲ

- **ဤကွန်ပျူတာပေါ်တွင်။** ဖိုင်မှ ပုံဆွဲကို Studio တွင် ဖွင့်တိုင်းနှင့် သိမ်းတိုင်း၊ Studio သည် ဤကွန်ပျူတာ၏ ကိုယ်ပိုင် သိုလှောင်မှုတွင် ဖိုင်၏ မိတ္တူတစ်ခု သိမ်းသည်။ ပထမ မိတ္တူသည် {{ui:ဖွင့်ထားသည့်အတိုင်း}} ဖြစ်သည်: သင်၏ ပထမ သိမ်းမှု မတိုင်မီ ဖိုင်၏ အခြေအနေ။ Studio သည် ပုံဆွဲတစ်ခုစီအတွက် အသစ်ဆုံး 25 ခုကို ထားပြီး မိတ္တူ စုစုပေါင်း 400 MB ကျော်သောအခါ အဟောင်းဆုံးကို အရင်ဖျက်သည်။ ပြောင်းလဲမှု မရှိသော သိမ်းမှုသည် ဘာမျှ မထားပါ။ ဘာမျှ upload မလုပ်ပါ။
- **Cloud တွင်။** Studio တွင် သင့် cloud ဖိုင်များမှ ပုံဆွဲတစ်ခုကို ဖွင့်လျှင် panel သည် {{ui:Cloud တွင်}} ကိုလည်း စာရင်းပြသည်: cloud က ထားသော ဗားရှင်းတိုင်း၊ ၎င်း၏ နံပါတ်၊ သိမ်းသူနှင့် မှတ်ချက်ဖြင့်။ Panel သည် ဖတ်ရုံသာ ဖတ်သည်။ CadCraft သည် ၎င်း၏ သိမ်းမှုများကို cloud သို့ မပို့သေးပါ၊ ထို့ကြောင့် ဤများသည် အခြားစက်များနှင့် web မှ သိမ်းထားသော ဗားရှင်းများ ဖြစ်သည်။ Studio က sign-in သက်တမ်း ကုန်သွားကြောင်း ပြလျှင် ပြန် sign in ဝင်ပါ။

သိမ်းမထားသေးသော ပုံဆွဲတွင် မိတ္တူ မရှိပါ: ပထမဆုံး သိမ်းပါ။

## ဗားရှင်းတစ်ခုကို ဖွင့်ခြင်း သို့မဟုတ် ပြန်ယူခြင်း

- {{ui:ဖွင့်ရန်}} သည် ထိုဗားရှင်းကို ကိုယ်ပိုင် tab တွင် ထားသည်။ သင့်ပုံဆွဲကို မထိပါ။
- {{ui:ပြန်ယူရန်}} သည် ဤပုံဆွဲကို ထိုဗားရှင်းဖြင့် အစားထိုးသည်။ မေးပါမည်။ မလုပ်မီ Studio သည် ယခုပုံဆွဲ၏ မိတ္တူကို သမိုင်းတွင် ({{ui:ပြန်ယူခြင်းမတိုင်မီ}} ဟု အမှတ်အသားပြုပြီး) ထားသည်၊ ဖိုင်ကို သင် သိမ်းမှသာ ဖိုင်ထဲ ရေးသည်။ ပြန်ယူခြင်းကို {{key:Mod+Z}} ဖြင့် ပြန်ဖျက်၍ မရပါ; ထိုမိတ္တူကို သုံးပါ။

## နှိုင်းယှဉ်ခြင်း

1. ဗားရှင်းတစ်ခုပေါ်ရှိ {{ui:နှိုင်းယှဉ်ရန်}} ကို နှိပ်ပါ။ ၎င်းကို {{ui:The drawing as it is now}} ဖြစ်သော {{ui:ယခုလက်ရှိ ပုံဆွဲ}} နှင့် နှိုင်းယှဉ်သည်; အခြား ဗားရှင်းနှင့် နှိုင်းယှဉ်လိုပါက အရင်ဆုံး {{ui:နှိုင်းယှဉ်ရန်}} တွင် ထိုဗားရှင်းကို ရွေးပါ။
2. စာရင်းအောက်ရှိ ရလဒ်ကို ဖတ်ပါ: ထည့်ထား၊ ဖျက်ထား နှင့် ပြောင်းထား object အရေအတွက်နှင့် စာရင်း။ စာရင်းတွင် အကြောင်းအရာတစ်ခုကို နှိပ်လျှင် view ကို ထိုနေရာသို့ ရွှေ့သည်။
3. ပုံဆွဲပေါ်တွင်:
   - **အစိမ်း** object များ ထည့်ထားသည်၊
   - **အနီ** object များ ဖျက်ထားသည် (ဗားရှင်းဟောင်းတွင်သာ ရှိသည်)၊
   - **လိမ္မော်** object များ ပြောင်းထားသည်: အသစ်ပုံသဏ္ဍာန်ကို အပြည့်ဖြင့်၊ ဟောင်းကို အစက်အပြောက်ဖြင့်။
4. {{ui:ပုံဆွဲပေါ်တွင် ပြရန်}} သည် အရောင်များကို ဖွင့်/ပိတ်ပေးသည်; {{ui:အရောင်များ ဖယ်ရန်}} သည် ရလဒ်ကို ဖယ်သည်။ Panel ကို ပိတ်လျှင်လည်း ၎င်းတို့ ပျောက်သွားသည်။

စာရင်းက ပြောင်းထားသော object တစ်ခု၏ ပြောင်းလဲမှုကို ပြောသည်: ၎င်း၏ စာသား၊ ရွှေ့ခြင်း၊ ပုံသဏ္ဍာန်၊ လေယာ၊ အရောင်၊ linetype သို့မဟုတ် lineweight။ Sheet တစ်ခုစီကို သီးခြား နှိုင်းယှဉ်သည်; အရောင်များသည် ဖွင့်ထားသော sheet တွင် ပြသည်။

:::note
ပုံဆွဲတွင် object တစ်ခုစီအတွက် အမြဲတည်သော နံပါတ် မရှိပါ၊ ထို့ကြောင့် CadCraft သည် object များကို ၎င်းတို့ဘာဖြစ်သည်ဖြင့် တွဲစပ်သည်: နှစ်ဖက်စလုံးတွင် တူသော object သည် မပြောင်းလဲ; အမျိုးအစားနှင့် လေယာတူပြီး ဟောင်း object ၏ ကိုယ်ပိုင်အရွယ်အစားအတွင်း ရှိသော object သည် ပြောင်းထားသော တူညီသည့် object ဖြစ်သည်; ကျန်သည်များကို ထည့်ထား သို့မဟုတ် ဖျက်ထားဟု သတ်မှတ်သည်။ မူလနေရာမှ အလွန်ဝေးသို့ ရွှေ့သော object သည် တစ်နေရာတွင် ဖျက်ထား၊ အခြားနေရာတွင် ထည့်ထား ဟု ပြသည်။ Block reference သည် ၎င်း၏ block အကြောင်းအရာကို ရေတွက်သည်။
:::

## အများဆုံး ဖြစ်တတ်သော အမှားများ

- **"မိတ္တူ မရှိသေးပါ။"** ဤကွန်ပျူတာပေါ်တွင် ဖိုင်ရှိသော ပုံဆွဲကို ဖွင့်တိုင်းနှင့် သိမ်းတိုင်း Studio က မိတ္တူ ထားသည်။ Browser tab မှ ဖွင့်ထားသော သို့မဟုတ် ဘယ်တော့မှ မသိမ်းဖူးသော ပုံဆွဲတွင် မိတ္တူ မရှိပါ။
- **Cloud စာရင်း မပါပါ။** Studio တွင် cloud မှ ဖွင့်ထားသော ပုံဆွဲအတွက်သာ ပေါ်သည်; disk မှ ဖွင့်သော ဖိုင်သည် cloud ပုံဆွဲ မဟုတ်ပါ။
- **အားလုံး ပြောင်းထားဟု ပေါ်သည်။** ကွဲပြားသော ပရိုဂရမ်များဖြင့် သိမ်းထားသော ဗားရှင်းနှစ်ခုသည် ပုံဆွဲကို ကွဲပြားသော နည်းဖြင့် ရေးသည် (anonymous block များ၏ အမည်များ၊ ဂဏန်းညှိခြင်း)။ CadCraft ဖြင့် သိမ်းထားသော ဗားရှင်းများကို နှိုင်းယှဉ်ပါ။
