## ဘာကို ပြုလုပ်မလဲ

နံရံဖြတ်ပုံ တစ်ခုကို ANSI31 pattern ဖြင့် ဖြည့်၊ ထိုအတွင်းရှိ ကော်လံ တစ်ခုကို ဗလာထား၊ ကော်လံအတွင်း solid fill တစ်ခု။

## အတွင်းမှ နှိပ်၍ hatch လုပ်ခြင်း

1. ထောင့်မှန်စတုဂံ (`REC`, `0,0`, `@2000,1200`) နှင့် ထိုအတွင်း စက်ဝိုင်း (`C`, `1000,600`, `300`) ဆွဲ။ {{ui:အပြည့်အစုံ}} ကို နှိပ်။
2. ကိရိယာဘားရှိ {{ui:ဆွဲရန်}} အုပ်စုမှ {{ui:ဖြည့်ရန်}} ကို နှိပ်၊ သို့မဟုတ် `H` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်။ မှတ်တမ်းက လက်ရှိ pattern ကို ပြော၊ ဥပမာ `Current hatch: ANSI31, scale 1, angle 0°`။
3. `P` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်၊ `ANSI31` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်။
4. `SC` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်၊ `20` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်။ Pattern အရွယ်အစားများသည် စာရွက်ပေါ်တွင် ဖြစ်သည်၊ ထို့ကြောင့် 1:20 ဖြင့် plot ထုတ်သော drawing သည် scale 20 ကို လိုသည်။
5. `Pick internal point` တွင် စတုဂံအတွင်း၊ စက်ဝိုင်းအပြင်ကို နှိပ်။ Hatch က preview အဖြစ် ပြ။
6. {{key:Enter}} ကို နှိပ်။ စတုဂံ hatch ဖြစ်သွား၊ အတွင်းရှိ စက်ဝိုင်းသည် ဗလာ ကျန်၊ အကြောင်းမှာ ၎င်းသည် island ဖြစ်သည်။

{{key:Enter}} မနှိပ်မီ ဧရိယာအများအပြားအတွင်း နှိပ်၍ hatch တစ်ခုတည်း ပြုလုပ်နိုင်သည်။ `U` က နောက်ဆုံး ဧရိယာကို ပြန်ယူ။

## Solid fill

1. `H` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်။
2. `P` ရိုက်၊ {{key:Enter}} ကို နှိပ်၊ `SOLID` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်။
3. စက်ဝိုင်းအတွင်း နှိပ်၊ ထို့နောက် {{key:Enter}} ကို နှိပ်။

## သင်ရွေးသော ပိတ်ထားသော ပုံသဏ္ဍာန်များကို hatch လုပ်ခြင်း

အတွင်းမှ နှိပ်မည့်အစား `Pick internal point` တွင် `S` (Select objects) ရိုက်ပြီး ပိတ်ထားသော polyline၊ စက်ဝိုင်း သို့မဟုတ် ပိတ်ထားသော ellipse များကို ရွေး၊ ထို့နောက် {{key:Enter}} ကို နှိပ်။ အခြားအတွင်းရှိ ပုံသဏ္ဍာန်များ တစ်ခုပြီးတစ်ခု ဗလာ ကျန် (အပြင်ဆုံးကို hatch၊ နောက်တစ်ခုက ဗလာ၊ စသည်ဖြင့်)။

## Pattern များ

Pattern မေးခွန်းတွင် စာရင်းအတွက် `?` ရိုက်။ စံ pattern များမှာ ANSI31 မှ ANSI38၊ LINE၊ NET၊ NET3၊ DASH၊ SQUARE၊ BRICK၊ DOTS နှင့် EARTH၊ နှင့် SOLID ဖြစ်သည်။ ပေ့ဖြင့် inch ရှိသော drawing (သို့မဟုတ် length format က feet နှင့် inch ဖြစ်သော) တွင် AutoCAD ကဲ့သို့ pattern ၏ inch အရွယ်အစားများ သုံး၊ မဟုတ်လျှင် မီလီမီတာ အရွယ်အစားများ။

{{ui:ထောင့်}} (`A`) က pattern တစ်ခုလုံးကို လှည့်: ANSI31 ကို 90° ထား၍ ဆင်ထားသောဘက် ပြောင်း။

**Pattern ဖိုင်များ။** `Pick internal point` တွင် `F` (Pattern file) ရိုက်ပြီး `.pat` ဖိုင် ရွေး။ ၎င်းထဲရှိ pattern များ စာရင်းသို့ ပေါင်းထည့်၊ တစ်ခုထက်ပိုလျှင် မည်သည့်တစ်ခု သုံးမလဲ မေးသည်။ CadCraft က ဖတ်နိုင်သော pattern မပါသော ဖိုင်ကို ပြော၊ ကျော်ခဲ့သော pattern များကို ရေတွက်ပြ။ `.pat` ဖိုင်များ၏ အရွယ်အစားများတွင် ကိုယ်ပိုင် unit မရှိ၊ ထို့ကြောင့် drawing ၏ unit များဖြင့် ဖတ်သည်။ အသုံးများသော `.pat` ပုံစံဖြင့် ရေးထားသော ဖိုင်များကိုသာ စမ်းသပ်ထားပြီး အခြား program က ရေးသောဖိုင်များ မစမ်းရသေးပါ။

## Hatch ပြောင်းခြင်း

ရေးဆွဲထားသော မျဉ်းတစ်ခုကို နှိပ်၍ ရွေး (သို့မဟုတ် ၎င်း၏ မျဉ်းတစ်ကြောင်းကို နှိပ်)။ {{ui:ဂုဏ်သတ္တိများ}} တွင် {{ui:ပုံစံ}}၊ {{ui:ပုံစံစကေး}} နှင့် {{ui:ပုံစံထောင့်}}။ ဖွင့်ထားသော drawing များမှ hatch များသည် စံ pattern တစ်ခုဖြစ်လျှင် pattern ကို ပြ၊ အခြားများသည် ၎င်း၏အရောင်၏ ပေါ့သော အရောင်အဖြစ် ပြ။

## အမှားများ

- **"ထိုအချက်ပတ်လည်တွင် ပိတ်ထားသော နယ်နိမိတ် မရှိ။"** နယ်နိမိတ်တွင် ကွက်လပ် ရှိသည် သို့မဟုတ် အစိတ်အပိုင်းတစ်ခု screen အပြင်တွင် ရှိနေသည်: CadCraft က screen ပေါ်ရှိသည်ကိုသာ ကြည့်သည်။ ကွက်လပ်ကို ပိတ် (ထောင့်များကို zoom in လုပ်ပါ) သို့မဟုတ် zoom out လုပ်ပါ။
- **"ဤ scale တွင် pattern သည် ဆွဲရန် သိပ်ထူလွန်းသည်။"** မျဉ်းများသည် drawing က ပြနိုင်သည်ထက် နီးလွန်းသည်။ ပိုကြီးသော scale သုံးပါ: plot scale ကို စမ်းပါ (1:20 အတွက် 20)။
- **Pattern သည် ကြီးလွန်း သို့မဟုတ် သေးလွန်းသည်ဟု ပေါ်။** Scale သည် pattern unit တစ်ခုအတွက် drawing unit များဖြစ်သည်; အပေါ်ရှိ အဆင့် 4 ကို ကြည့်။
- **Hatch သည် ၎င်း၏ outline ကို မလိုက်တော့။** {{cmd:HATCH}} ဖြင့် ပြုလုပ်သော hatch သည် ၎င်း၏ ဖန်တီးခဲ့သော object များနှင့် ဆက်နေသည်: outline ကို ရွှေ့၊ လှည့်၊ scale ပြောင်းလျှင် hatch လိုက်သည်; grip ဖြင့် ပုံသဏ္ဍာန် ပြောင်းလျှင် hatch ကို ပြန်တွက်။ Outline ပိတ်မနေတော့လျှင်၊ hatch ကို ကိုယ်တိုင် ပြောင်းလျှင်၊ သို့မဟုတ် ညှပ်လျှင် ချိတ်ဆက်မှု ပြီး command line က ထိုသို့ ပြော။ ဘာမျှ မဆုံးရှုံး၊ ထပ်ချိတ်ရန် ဧရိယာကို ပြန် hatch လုပ်ပါ။

## Boundary နှင့် ဆက်နေသော hatch

`HATCH` ဖြင့် သင်ပြုလုပ်သော hatch သည် ၎င်းကို ကန့်သတ်သည့်အရာကို မှတ်ထားသည်။ Boundary ကို ရွှေ့၊ လှည့်၊ scale ပြောင်းလျှင် hatch နှင့် pattern လိုက်သည်။ Grip ဖြင့် boundary ပုံသဏ္ဍာန်ပြောင်းလျှင် hatch ကို ပြန်တွက်။ Hatch ကို သီးခြား ရွှေ့လျှင် boundary လည်း လိုက်၊ ပုံဆွဲ program တွင် ဖြည့်ထားသော ပုံသဏ္ဍာန်ကဲ့သို့။

ချိတ်ဆက်မှု ကုန်ဆုံးသည်၊ command line က ထိုသို့ ပြော၊ boundary ပိတ်မနေလျှင် သို့မဟုတ် သင် hatch ကို ကိုယ်တိုင် ပြောင်းလျှင်။ Hatch ကိုယ်တိုင်ကတော့ ကျန်။ Hatch ပြုလုပ်နေစဉ် `AS` ရိုက်လျှင် သီးခြားရပ်တည်သော hatch များ ပြုလုပ်နိုင်။ Boundary ပါသော hatch ကို ကူးလျှင် ကော်ပီတွင် ကိုယ်ပိုင် ချိတ်ဆက်မှု ရှိ။

`HATCHEDIT` (`HE`) က hatch ၏ pattern၊ scale၊ ထောင့်နှင့် origin ကို ပြောင်း၊ boundary သို့ ချိတ်ဆက်ခြင်း သို့မဟုတ် ချိတ်ဆက်မှုကို ဖျက်သည်။ ချိတ်ဆက်မှုကို DWG နှင့် DXF 2000 ဖိုင်များတွင် သိမ်းသည်။ DXF R12 ဖိုင်တွင် hatch object မရှိ၊ အခြား program များက ပြုလုပ်သော ချိတ်ဆက်မှုများကို မဖတ်: ထိုအတွက် `HATCHEDIT` နှင့် Link ကို သုံး။

Boundary မရှိတော့သော hatch (boundary ကို ဖျက်ထား သို့မဟုတ် ဖိုင်ကို boundary မပါဘဲ ရခဲ့သည်) ကို ပြန်ရနိုင်: `HATCHGENERATEBOUNDARY` (`HGB`) က hatch ၏ loop တစ်ခုစီ ပတ်လည် ပိတ်ထားသော polyline ဆွဲ၊ Yes ဟု ဖြေလျှင် hatch ကို ၎င်းတို့နှင့် ချိတ်ဆက်သည်။

## Gradient fill

`GRADIENT` (`GD`) က pattern အစား gradient ဖြင့် ဧရိယာကို ဖြည့်သည်: `HATCH` နှင့် တူညီသော ရွေးချယ်မှုများ၊ ထို့နောက် အမျိုးအစား (linear၊ cylindrical၊ spherical၊ hemispherical၊ curved နှင့် ၎င်းတို့၏ ပြောင်းပြန်များ) ကို မေး၊ အရောင်တစ်ခု အရိပ်ဖြင့် သို့မဟုတ် အရောင်နှစ်ခု၊ ထောင့်နှင့် centered သို့မဟုတ် မဟုတ် ကို မေး။ `HATCH` တွင် `G` ရွေးချယ်မှုက တူညီ။ `HATCHEDIT` `G`၊ သို့မဟုတ် {{ui:ဂုဏ်သတ္တိများ}} အောက်ရှိ Gradient က gradient ကို ပြောင်း သို့မဟုတ် hatch မည်သည့်အရာကိုမဆို gradient ပြောင်း။

Gradient ကို screen နှင့် plot တွင် ပြ။ DWG 2004 သို့မဟုတ် နောက်ပိုင်းအဖြစ် သိမ်းလျှင် အခြား program များက အမှန်တကယ် gradient hatch ရ။ DXF 2000 နှင့် DWG 2000 တွင် gradient မရှိ: CadCraft က ကိုယ်တိုင်သာ သိမ်း၊ အခြား program များက ပထမအရောင်ဖြင့် solid fill ကို မြင်ရ။

## Hatch ညှပ်ခြင်း

`TRIM` က hatch ကို အခြား object များလိုပင် ညှပ်သည်။ ဖယ်ချင်သော cutting edge ဘက်ရှိ hatch ကို နှိပ်: edge များက hatch ဧရိယာကို ခွဲ၊ နှိပ်ခဲ့သော အပိုင်းကို ဖယ်ရှား။ Quick mode တွင် object တိုင်း cutting edge ဖြစ်၊ အရေအတွက်များလျှင် `T` ဖြင့် edge များကို အရင်ရွေး။ ညှပ်ထားသော hatch သည် boundary နှင့် မဆက်တော့၊ ၎င်းမှာ ဖြည့်ခြင်း မရှိတော့သောကြောင့်ဖြစ်သည်။
