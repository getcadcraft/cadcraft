{{cmd:SKETCHLIVE}} ကို စတင် (သို့မဟုတ် **ဆွဲရန် › နောက်ထပ် › ဘောပင်ဖြင့် ပုံဖော်ရန်** ကို ရွေး) ပြီး ဖိ၍ ဆွဲခြင်းဖြင့် stroke တစ်ခု ဆွဲ။ ဘောပင်ကို ထောင်လိုက်သည့်အခါ CadCraft က သင်ဆိုလိုသည်ကို ဖတ်၍ drawing ထဲ ထည့်သည်:

| သင့် stroke | ရရှိမည့်အရာ |
|---|---|
| ဆွဲဆွဲ မျဉ်းဖြောင့်နီး | Line။ အနည်းငယ် အလျား သို့မဟုတ် ဒေါင်လိုက် line ကို အတိအကျ အလျား သို့မဟုတ် ဒေါင်လိုက် ပြုသည်။ |
| ပိတ်ပြီး စက်ဝိုင်း | Circle |
| စက်ဝိုင်းပုံ၏ အစိတ်အပိုင်း | Arc |
| ထောင့်မှန်လေးခုပါ ပိတ်ထား | စတုဂံ |
| အခြား အရာအားလုံး | ထောင့်စတုရန်းပါသော polyline |

Stroke ၏ ဆုံးများကို ရှိပြီးသား ဆွဲထားသည့် အနီးဆုံး ဆုံးသို့ ဆွဲ၍ ကပ်စေသည်၊ ထို့ကြောင့် ပုံဆွဲထားသော နံရံ ဘေးရှိ နံရံနှင့် ဆုံသည်။

## အရွယ်အစားကို ထပ်ရိုက်ခြင်း

Stroke တစ်ခုပြီးတိုင်း command line က ၎င်း၏အရွယ်အစားကို default အဖြစ် ပြ (line ၏ **အလျား**၊ circle သို့မဟုတ် arc ၏ **radius**၊ စတုဂံ၏ **အကျယ်**)။ {{key:Enter}} ကို နှိပ်၍ ထိန်းရန် သို့မဟုတ် ဂဏန်း သို့မဟုတ် `12'6"` ကဲ့သို့ အရှည် ရိုက်၍ အစားထိုး။ Line က ပထမဆုံးဆုံးကို ထိန်း၊ circle က center ကို၊ စတုဂံက ပထမထောင့်ကို ထိန်း။

Prompt ကွက်လပ်ပေါ်တွင် {{key:Enter}} ကို နှိပ်၍ ပြီးဆုံး၊ သို့မဟုတ် `U` ရိုက်၍ နောက်ဆုံး stroke ကို ပြန်ယူ။ Session တစ်ခုလုံးသည် undo အဆင့် တစ်ခု။

## Stroke များစွာကို တစ်ပြိုင်နက် သန့်ရှင်းစေခြင်း

{{cmd:SKETCHFIX}} က stroke များကို စုပြီး {{key:Enter}} ကို နှိပ်သည့်အခါ အားလုံးကို တိကျစေသည်၊ မြန်မြန် ဆွဲထားသော ကြမ်းတမ်းသော layout အတွက် ကိုက်ညီ။

:::note
အားလုံးကို သင့်ကွန်ပျူတာပေါ်တွင် စည်းမျဉ်းဖြင့် တွက်ချက်၊ မော်ဒယ် မရှိ၊ ဘယ်နေရာသို့မှ မပို့။
:::

## ဖိအားက lineweight သတ်မှတ်ခြင်း

ဘောပင်ကို app များအတွက် ဖွင့်ထားသည့်နေရာ (Settings › Global › Input devices › Pen) တွင် ဘောပင်ဖြင့် ဆွဲသော stroke သည် ဘောပင်ပေးသော အမှတ်အားလုံးနှင့် ၎င်း၏ဖိအားကို ယူဆောင်။ ပေါ့ပါးသော stroke က ပါးသော အရာဝတ္ထု ဖြစ်စေ၊ ခိုင်မာသော stroke က ထူသော အရာဝတ္ထု ဖြစ်စေသည်: stroke ၏ ပျမ်းမျှဖိအားက 0.18၊ 0.25၊ 0.35 သို့မဟုတ် 0.50 mm ကို ရွေး၊ command line က ဘယ်ဟာလဲ ပြော။ မောက်စ် သို့မဟုတ် လက်ချောင်းဖြင့် ဆွဲသော stroke များသည် ယခင်အတိုင်း လက်ရှိ lineweight ကို ယူ။ {{cmd:PENPRESSURE}} က ဤအရာကို ပိတ် (သို့မဟုတ် ပြန်ဖွင့်); ရွေးချယ်မှုကို ဤ browser တွင် ထိန်း။
