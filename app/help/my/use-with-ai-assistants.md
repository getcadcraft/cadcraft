## သင် လေ့လာရမည့်အရာများ

AI အကူအညီပေးသူ (သို့မဟုတ် သင်ရေးထားသော script) အား ပုံဆွဲကို ကြည့်စေခြင်း၊ CadCraft ၏ command များကို လုပ်ဆောင်စေခြင်း၊ plot လုပ်ပြီး သိမ်းစေခြင်း၊ ၎င်း ထိတွေ့ခွင့်ရှိသော အရာများကို ဘယ်လို ဆုံးဖြတ်ရမလဲ။

CadCraft တွင် **ကိုယ်ပိုင် AI မရှိပါ** ၊ မည်သည့်နေရာသို့မျှ ဘာမျှ မပို့ပါ။ အကူအညီပေးသူကို သင်ယူလာရမည်- Model Context Protocol (MCP) ကို နားလည်သော မည်သည့် program ဖြစ်စေ။ CadCraft က tools များကိုသာ ပေးပြီး ဘာတွေ သုံးမလဲ သင် ရွေးပါ။

ဝင်ရောက်ရန် နည်းလမ်း နှစ်ခု ရှိသည်-

- **သင် ဖွင့်ထားသော ပုံဆွဲ။** အကူအညီပေးသူသည် ဤ window တွင် သင့်ဘေးမှာ၊ သင့်ကွန်ပျူတာပေါ်ရှိ CadCraft Studio မှတစ်ဆင့် အလုပ်လုပ်သည်။ ဤအတွက် ရည်ရွယ်သည်မှာ {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Assistants}} ဖြစ်သည်။
- **app ကို မဖွင့်ဘဲ ကွန်ပျူတာပေါ်ရှိ ပုံဆွဲများ။** CadCraft MCP server နှင့် `cadcraft` command line သည် သင် အမည်ပေးထားသော ဖိုဒါများရှိ DWG နှင့် DXF ဖိုင်များကို ဖတ်ပြီး ရေးသည်။ အောက်ရှိ "CadCraft ကို မဖွင့်ဘဲ ဖိုင်များဖြင့် အလုပ်လုပ်ခြင်း" ကို ကြည့်ပါ။

## ဖွင့်ခြင်း

1. {{ui:Settings}} ကို ဖွင့်ပါ (app bar ရှိ gear သို့မဟုတ် {{key:Mod+,}}) ပြီး {{ui:CadCraft}} tab သို့ သွားပါ။
2. {{ui:Assistants}} အောက်တွင် **AI အကူအညီပေးသူများနှင့် scripts များကို CadCraft သုံးခွင့်ပေးရန်** ကို အမှတ်အသားပြုပါ။ သင် မလုပ်မချင်း ၎င်း ပိတ်ထားသည်။
3. ၎င်း ဘာလုပ်ခွင့်ရှိသလဲ ရွေးပါ။ **Read** ကို အစမှာ အမှတ်အသားပြုထားသည်; အခြားများကို လိုအပ်မှသာ အမှတ်အသားပြုပါ။

| ခွင့်ပြုချက် | အကူအညီပေးသူ ဘာလုပ်နိုင်သလဲ |
|---|---|
| Read | ပုံဆွဲကို ကြည့်ခြင်း: ဖော်ပြခြင်း၊ objects များကို စာရင်းပြုစုခြင်းနှင့် ရှာခြင်း၊ ရွေးချယ်မှုကို ကြည့်ခြင်း၊ view ကို ဖော်ပြပြီး ပုံရိုက်ခြင်း၊ layer နှင့် drafting စည်းမျဉ်းများနှင့် စစ်ဆေးခြင်း |
| Edit | ပုံဆွဲပေါ်တွင် command များ လုပ်ဆောင်ခြင်းနှင့် ရွေးချယ်မှု ပြောင်းခြင်း။ လုပ်ဆောင်ချက် တစ်ခုစီသည် သင် ပြန်ဖျက်နိုင်သော အဆင့် တစ်ခု ဖြစ်သည် |
| Save | ပုံဆွဲကို သိမ်းခြင်း (desktop တွင် ၎င်း၏ဖိုင်သို့; browser တွင် download အဖြစ်) |
| Export | PDF သို့ plot လုပ်ခြင်းနှင့် အခြားဖိုင်များ ဖန်တီးခြင်း |

## သင်ရွေးသော ဖိုဒါများရှိ ဖိုင်များကို သုံးခွင့်ပေးခြင်း

CadCraft Studio တွင် အကူအညီပေးသူသည် file dialog များအစား ဖိုင်အမည်ဖြင့် ဖိုင်များကို ဖွင့်၊ သိမ်းနှင့် plot လုပ်နိုင်သည်၊ သို့သော် {{ui:Assistants}} › {{ui:Folders it may use}} အောက်တွင် သင် ထည့်ထားသော ဖိုဒါများအတွင်းသာ ဖြစ်သည်-

1. {{ui:Add a folder…}} ကို ရွေးပြီး Studio ၏ ကိုယ်ပိုင် dialog တွင် ဖိုဒါကို ရွေးပါ။
2. ယခု အကူအညီပေးသူသည် ထိုနေရာရှိ ဖိုင်များကို စာရင်းပြုနိုင် (`files_list`)၊ ပုံဆွဲတစ်ခုကို ဖွင့်နိုင် (`drawing_open`)၊ DWG version သို့မဟုတ် DXF အဖြစ် ထိုနေရာတွင် သိမ်းနိုင်၊ PDF သို့မဟုတ် SVG ဖိုင်သို့ plot လုပ်နိုင်၊ LISP ဖိုင် တင်နိုင်ပြီး command တစ်ခုကို ၎င်း တောင်းဆိုသော ဖိုင် (`INSERT` `F`, `XATTACH`, point file) ပေးနိုင်သည် သို့မဟုတ် command ၏ ဖိုင်သွားရမည့်နေရာကို ပြောနိုင်သည် (`COUNT` ၏ CSV, `PUBLISH`)။
3. {{ui:Remove}} သည် ဖိုဒါကို ချက်ချင်း ပြန်ယူသည်။ အခြားနေရာမှ လမ်းကြောင်းများကို ငြင်းပယ်ပြီး ရှိပြီးသား ဖိုင်ကို အကူအညီပေးသူက တောင်းဆိုခြင်း သို့မဟုတ် ၎င်းကိုယ်တိုင် ရေးထားခြင်းရှိမှသာ အစားထိုးသည်။

ဖွင့်ခြင်းအတွက် **Read** လိုအပ်ဆဲ; ပုံဆွဲရေးခြင်းအတွက် **Save** လိုအပ်သည်; အခြားဖိုင်များအတွက် **Export** လိုအပ်သည်။

သင် ရွေးထားသော ခွင့်ပြုချက်များ အပြင်ရှိ tools များကို အကူအညီပေးသူအား မပေးပါ၊ တောင်းဆိုပါက CadCraft က ငြင်းပြီး activity log တွင် မှတ်တမ်းတင်သည်။ switch ကို ပိတ်လိုက်ရုံဖြင့် ချိတ်ဆက်မှု အားလုံး ချက်ချင်း အဆုံးသတ်သည်။ {{ui:Reset CadCraft settings}} သည်လည်း ၎င်းကို ပိတ်သည်။

## အကူအညီပေးသူကို ချိတ်ဆက်ခြင်း

အကူအညီပေးသူများသည် ကွန်ပျူတာပေါ်ရှိ **CadCraft Studio** မှတစ်ဆင့် ချိတ်ဆက်သည်: ၎င်းသည် ဤကွန်ပျူတာသာ ဝင်နိုင်သော server ငယ်တစ်ခုကို run သည် (address `127.0.0.1`)၊ Studio က ဖွင့်တိုင်း ဖန်တီးသော token ဖြင့် ကာကွယ်ထားသည်။ Studio ကို ဖွင့်ပြီး {{ui:Connect an assistant}} ကို ရွေးကာ address နှင့် token ကို ကူးယူပါ။

- သင့်အကူအညီပေးသူတွင် HTTP type MCP server ကို address (`http://127.0.0.1:47615/mcp` ပုံစံ) နှင့် header `Authorization: Bearer <token>` ဖြင့် ထည့်ပါ။ Studio က ကူးထည့်ရန် ဆက်တင်များကို ပြသည်။

Studio ရှိ {{ui:New token}} သည် ချိတ်ဆက်ထားသော အကူအညီပေးသူအားလုံးကို token အသစ်ဖြင့် ပြန်ချိတ်စေသည်။ token ကို ဘယ်တော့မှ မမျှဝေပါနှင့်- ၎င်းရှိသူ မည်သူမဆို Studio run နေသရွေ့ သင် ဖွင့်ထားသော app များကို သုံးနိုင်သည်။

:::note
Browser tab သည် အကူအညီပေးသူအတွက် ချိတ်ဆက်မှု မဖွင့်နိုင်ပါ: browser app များတွင် ကွန်ပျူတာပေါ်ရှိ CadCraft Studio ကို မသုံးမချင်း switch သည် အကျိုးမရှိပါ။
:::

## သင်က ဆက်ထိန်းချုပ်ထားသည်

- **လုပ်ဆောင်ချက် တိုင်းသည် ပြန်ဖျက်ရန် အဆင့် တစ်ခု** ဖြစ်ပြီး အကူအညီပေးသူ၏ အမည်ဖြင့် အမှတ်အသားပြုသည်၊ ဥပမာ "Assistant: LINE"။ အကူအညီပေးသူ၏ နောက်ဆုံး လုပ်ဆောင်ချက်ကို တစ်ခုလုံး ပြန်ယူရန် {{key:Mod+Z}} ကို နှိပ်ပါ။
- **၎င်း ဘာလုပ်သလဲ သင် မြင်ရသည်။** ၎င်း၏ command များသည် command history တွင် ရှေ့တွင် **[Assistant]** ဖြင့် ပေါ်လာပြီး အလုပ်လုပ်စဉ် ပုံဆွဲကို ပြန်ဆွဲသည်။
- **၎င်းက သင့်ကို စောင့်သည်။** သင် command တစ်ခု လုပ်နေစဉ်အတွင်း အကူအညီပေးသူသည် ဖတ်နိုင်သော်လည်း ပုံဆွဲကို မပြောင်းနိုင်ပါ; သင် ပြီးသောအခါ ထပ်ကြိုးစားရန် ပြောထားသည်။
- **ချိတ်ဆက်ထားသည်ကို သင် သိသည်။** ချိတ်ဆက်နေချိန်တွင် app bar ရှိ ခလုတ်တစ်ခုက အကူအညီပေးသူ၏ အမည်ကို ပြသည်။ ၎င်း ဘာလုပ်ခွင့်ရှိသလဲ ကြည့်ရန် သို့မဟုတ် **ချိတ်ဆက်ဖြတ်ရန်** ရန် ၎င်းကို နှိပ်ပါ။
- **Activity။** {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Assistants}} › {{ui:Activity}} သည် ခေါ်ဆိုမှု တိုင်းကို စာရင်းပြုသည်- အချိန်၊ tool မည်သည်၊ ပြီးခဲ့ခြင်း သို့မဟုတ် ငြင်းပယ်ခြင်း၊ ၎င်း ပြုလုပ်သော ပြန်ဖျက်ရန် အဆင့်။ {{ui:Save the log}} သည် မိတ္တူတစ်ခု သိမ်းထားသည်။

## အကူအညီပေးသူ တောင်းဆိုနိုင်သည့် အရာများ

| Tool | ခွင့်ပြုချက် | ၎င်း ဘာလုပ်သလဲ |
|---|---|---|
| `app_info`, `drawing_describe`, `view_describe` | Read | ပုံဆွဲ၏ အမည်၊ ယူနစ်များ၊ layer များ၊ block များ၊ sheet များ; မျက်နှာပြင်ပေါ်ရှိ အရာများ |
| `files_list`, `drawing_open` | Read | Studio: သင့်ဖိုဒါများရှိ ဖိုင်များ; တစ်ခုကို ဤ window တွင် ဖွင့်ခြင်း |
| `objects_list`, `object_get`, `selection_get` | Read | objects များ၏ geometry၊ အလျားနှင့် ဧရိယာ (သို့မဟုတ် အမျိုးအစားနှင့် layer အလိုက် အရေအတွက်သာ); ရွေးချယ်မှု |
| `drawing_check` | Read | ခွင့်ပြုထားသော layer များ၊ layer 0 တွင် ဘာမျှ မရှိခြင်း၊ ByLayer အရောင်များ၊ စာသား အမြင့်များ ကဲ့သို့သော စည်းမျဉ်းများ |
| `view_screenshot` | Read | ပြထားသည့်အတိုင်း ပုံဆွဲ၏ ပုံ |
| `command_run` | Edit | command line တွင် ရိုက်သည်: `LINE 0,0 @100,0 @0,50 ` ကို သင် ရိုက်သကဲ့သို့ ဖတ်သည် (space သည် အဖြေကို အဆုံးသတ်သည်) သို့မဟုတ် အဖြေတစ်ခုစီပါသော စာရင်း။ command ကို ဖွင့်ထားပြီး ၎င်း၏ နောက်ခေါ်ဆိုမှုတွင် ဆက်လုပ်နိုင်သည် |
| `script_run` | Edit | script (`.scr`) သို့မဟုတ် LISP ဖိုင်၊ {{ui:APPLOAD}} က တင်သကဲ့သို့ |
| `block_insert` | Edit | block ကို attribute တန်ဖိုးများဖြင့် အဆင့်တစ်ဆင့်တည်း ထည့်သည် |
| `selection_set`, `undo` | Edit | နောက် command အတွက် objects များကို ရွေးချယ်သည်; ၎င်း၏ကိုယ်ပိုင် အဆင့်များကို ပြန်ဖျက်သည် |
| `drawing_save` | Save | CadCraft ၏ကိုယ်ပိုင် {{ui:Save}}၊ သို့မဟုတ် သင့်ဖိုဒါတစ်ခုထဲသို့ {{ui:Save as}} |
| `drawing_plot` | Export | sheet သို့မဟုတ် model ၏ PDF သို့မဟုတ် SVG၊ scale တစ်ခု သို့မဟုတ် ကိုက်ညီအောင် (PDF underlay များကို ဤနည်းဖြင့် မ print ရသေးပါ) |

အကူအညီပေးသူ command တစ်ခု run နေစဉ် CadCraft က မေးခွန်းများကို dialog အစား command line တွင် မေးသည် (ဥပမာ ပုံဆွဲတစ်ခုလုံး သို့မဟုတ် block တစ်ခုတည်း ထည့်ရမလား)၊ ထို့ကြောင့် အကူအညီပေးသူက ဖြေနိုင်သည်။ library နှင့် Find တို့သည် သင်လိုအပ်သေးသည်; အကူအညီပေးသူကို သင့်ကို မေးရန် ပြောထားသည်။

## CadCraft ကို မဖွင့်ဘဲ ဖိုင်များဖြင့် အလုပ်လုပ်ခြင်း

CadCraft MCP server (`cadcraft-mcp`) နှင့် command line (`cadcraft`) သည် CadCraft ၏ကိုယ်ပိုင် ပုံဆွဲကုဒ်ကို window မပါဘဲ Node.js တွင် run သည်။ Node.js 20 သို့မဟုတ် အသစ် လိုအပ်သည်။

- **MCP server** သည် သင် အမည်ပေးထားသော ဖိုဒါများအတွင်းသာ အလုပ်လုပ်ပြီး သင် ပေးသော ခွင့်ပြုချက်ဖြင့်သာ လုပ်သည်: `npx @getcadcraft/mcp --root ~/Drawings --allow read,edit`။ `--root` မပါလျှင် မည်သည့်ဖိုင်ကိုမျှ ဖွင့်နိုင်မည် မဟုတ်; `--allow` မပါလျှင် ဖတ်နိုင်သည်သာ။ IFC model များ၊ takeoff များနှင့် PDF အစုံရှိ markup များကိုလည်း ဖတ်နိုင်သည်။
- **command line** သည် သင့်ကိုယ်ပိုင် script များအတွက်ဖြစ်သည်: `cadcraft info plan.dwg`, `cadcraft run cleanup.scr plan.dwg -o plan-clean.dwg`, `cadcraft convert plan.dwg plan.dxf`, `cadcraft plot plan.dwg plan.pdf --all`, `cadcraft plot plan.dwg plan.svg`, `cadcraft check plan.dwg --rules rules.json`။ ဖိုင်အများအပြား တစ်ပြိုင်နက်: `cadcraft convert *.dwg out --to dxf`, `cadcraft plot *.dwg pdfs --to pdf`, `cadcraft check *.dwg --rules rules.json`။ program ဖတ်နိုင်သော output အတွက် `--json` ထည့်ပါ။

:::note
`npx @getcadcraft/mcp` က package မတွေ့ဟု ပြလျှင် ၎င်းကို မထုတ်ဝေရသေးပါ။ getcadcraft.com ရှိ သတင်းတွင် ထုတ်ဝေချိန်ကို ပြောပါမည်။
:::

## တစ်ခုခု အလုပ်မလုပ်လျှင်

- **အကူအညီပေးသူက CadCraft tools မမြင်ပါ:** ဤ window တွင် switch ဖွင့်ထားကြောင်းနှင့် window သည် Studio တွင် ဖွင့်ထားကြောင်း စစ်ပါ။
- **"needs the edit permission":** {{ui:Assistants}} အောက်တွင် **Edit** ကို အမှတ်အသားပြုပြီး ထပ်မေးပါ။
- **"outside the folders assistants may use":** ထိုဖိုဒါကို {{ui:Assistants}} › {{ui:Folders it may use}} အောက်တွင် ထည့်ပါ၊ သို့မဟုတ် သင် ထည့်ပြီးသား ဖိုဒါရှိ ဖိုင်ကို သုံးရန် အကူအညီပေးသူအား ပြောပါ။
- **"401" သို့မဟုတ် "token" အမှားများ:** token ပြောင်းသွားသည် (Studio ပြန်စတင်ခဲ့ခြင်း၊ သို့မဟုတ် {{ui:New token}})။ အသစ်ကို အကူအညီပေးသူ၏ ဆက်တင်တွင် ကူးထည့်ပါ။
- **၎င်း၏ ပြောင်းလဲမှု မှားသည်:** {{key:Mod+Z}} ကို နှိပ်ပါ။ တစ်ကြိမ်နှိပ်လျှင် အကူအညီပေးသူ၏ လုပ်ဆောင်ချက် တစ်ခုလုံး တစ်ခုကို ပြန်ယူသည်။
