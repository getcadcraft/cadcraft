## ဘာတွေ သိရမလဲ

ပုံဆွဲဖိုင်အများအပြားမှ စာရွက်များ (layout များ) ကို **sheet set** တစ်ခုသို့ စုဆောင်းနည်း၊ နံပါတ်နှင့် ခေါင်းစဉ်ပေးနည်း၊ title block များကို သင်အတွက် ဖြည့်ပေးစေနည်း၊ set တစ်ခုလုံးကို PDF တစ်ခုအဖြစ် ထုတ်ဝေနည်း၊ နှင့် ပို့ရန် အရာအားလုံးကို zip တစ်ခုတည်းအဖြစ် ထုပ်ပိုးနည်း။

sheet set သည် ပုံဆွဲများရှိသော ဖိုင်တွဲထဲတွင် `<name>.ccsheets` ဟု ခေါ်သော ၎င်း၏ကိုယ်ပိုင် သေးငယ်သော ဖိုင်တစ်ခုတွင် နေသည်။ set ဖိုင်သည် ထိုဖိုင်တွဲမှ path များဖြင့် စာရွက်များကို စာရင်းပြုသောကြောင့် ဖိုင်တွဲ တစ်ခုလုံးကို ရွှေ့ သို့မဟုတ် ကူးနိုင်သည်။

:::note
ဖိုင်တွဲကို ဖတ်ရန်နှင့် ရေးရန် ဖွင့်ရန် Chrome သို့မဟုတ် Edge (ရွေးထားသော ဖိုင်တွဲတွင် စာမျက်နှာ အလုပ်လုပ်ခွင့် ပေးနိုင်သည်) သို့မဟုတ် desktop app လိုသည်။ အခြား browser များက set ကို read only ဖြင့် ဖွင့်သည်: ကြည့်ရှုပြီး ထုတ်ဝေနိုင်သော်လည်း set ဖိုင်သည် သိမ်းမည့်အစား ဒေါင်းလုဒ် ဆွဲသည်။
:::

## Set စတင်ရန်

1. ဘယ်ဘက် panel ရှိ {{ui:Sheet set}} အပိုင်းကို ရှာပြီး ၎င်း၏ {{ui:Set}} မီနူးကို ဖွင့်ပါ။ {{cmd:SHEETSET}} (သို့မဟုတ် `SSM`) ကို ရိုက်လျှင်လည်း ထိုနေရာသို့ ရောက်စေသည်။
2. {{ui:Set အသစ်…}} ကို ရွေးပါ။ set အား အမည်ပေးပါ၊ နှစ်သက်လျှင် ပရောဂျက်အမည်နှင့် နံပါတ်ကိုလည်း ထည့်ပါ။
3. ပုံဆွဲများရှိသော ဖိုင်တွဲကို ရွေးပါ။ set ဖိုင်ကို ထိုနေရာတွင် သိမ်းသည်။

နောက်မှ set ကို ဖွင့်ရန် {{ui:Set ဖွင့်ရန်…}} ကို ရွေးပြီး တူညီသော ဖိုင်တွဲကို ရွေးပါ။ ဖိုင်တွဲတွင် set တစ်ခုထက်ပို၍ ရှိလျှင် CadCraft က မည်သည့်တစ်ခု ဟု မေးသည်။

## စာရွက်များ ထည့်ရန်

1. {{ui:ပုံဆွဲမှ စာရွက်များ ထည့်ရန်…}} ကို ရွေးပြီး ဖိုင်တွဲရှိ ပုံဆွဲတစ်ခုကို ရွေးပါ။
2. CadCraft က ထိုပုံဆွဲကို နောက်ခံတွင် ဖတ်သည် (မျက်နှာပြင်တွင် မဖွင့်ပါ) နှင့် ၎င်း၏ စာရွက်များကို စာရင်းပြုသည်။ လိုချင်သည်များကို အမှတ်ခြစ်ပြီး {{ui:အိုကေ}} ကို နှိပ်ပါ။
3. စာရွက်တစ်ခုကို ရွေးပြီး {{key:F2}} (သို့မဟုတ် {{ui:အမည်ပြောင်းပြီး နံပါတ်ပြန်ပေးရန်…}}) ကို နှိပ်ပါ၊ နံပါတ်နှင့် ခေါင်းစဉ် ပေးရန်၊ ဥပမာ `A-101` နှင့် `Floor plan`။

{{ui:Template မှ စာရွက်အသစ်…}} သည် အခြားပုံဆွဲ၏ စာရွက် (၎င်း၏ title block နှင့် viewport များ) မှ ပုံဆွဲအသစ် ဖန်တီးပြီး စာရွက်အသစ်၏ အမည်ဖြင့် အမည်ပေးကာ ထည့်သည်။ set က သင် template အဖြစ် သုံးခဲ့သော ပုံဆွဲကို မှတ်ထားသည်။

## set ကို စီစဉ်ရန်

- **Subset များ** သည် စာရွက်များကို အုပ်စုဖွဲ့သည်၊ ဥပမာ Architectural › Plans: ၎င်း သွားရမည့်နေရာကို ရွေးပြီး {{ui:Subset အသစ်…}} ကို ရွေးပါ။
- **အစဉ်**: စာရွက်တစ်ခုကို စာရင်းရှိ နေရာတစ်ခုသို့ ဆွဲပါ၊ သို့မဟုတ် subset တစ်ခုပေါ်သို့ ဆွဲပြီး ထိုနေရာသို့ ရွှေ့ပါ။ keyboard ဖြင့် ရွေးပြီး {{key:Alt+Up}} သို့မဟုတ် {{key:Alt+Down}} ကို နှိပ်ပါ။
- **စာရွက်ဖွင့်ရန်**: နှစ်ချက်နှိပ်ပါ (သို့မဟုတ် {{key:Enter}} ကို နှိပ်ပါ)။ ၎င်း၏ပုံဆွဲသည် ၎င်း၏ကိုယ်ပိုင် tab တွင် ထိုစာရွက်ပေါ်တွင် ဖွင့်သည်။
- **ဖယ်ရှားရန်**: ရွေးပြီး {{key:Delete}} ကို နှိပ်ပါ။ ပုံဆွဲကိုယ်တိုင် မပြောင်းပါ။
- **ပြန်ဖျက်ရန်**: {{ui:Set ပြောင်းလဲမှု ပြန်ဖျက်ရန်}} နှင့် {{ui:Set ပြောင်းလဲမှု ပြန်လုပ်ရန်}} သည် set တွင် ပြောင်းလဲခဲ့သည်များကို အဆင့်ဆင့် သွားသည်။
- **နံပါတ်ပြန်ပေးရန်**: {{ui:စာရွက်နံပါတ် ပြန်ပေးရန်…}} သည် စာရွက်အားလုံး သို့မဟုတ် subset တစ်ခု၏ စာရွက်များကို စာရင်း၏ အစဉ်အတိုင်း နံပါတ်ပေးသည်: prefix၊ စတင်တန်ဖိုးနှင့် step (`A-` နှင့် `101` က A-101, A-102 … ပေးသည်)။

ပြောင်းလဲမှု တိုင်းကို set ဖိုင်တွင် ချက်ချင်း သိမ်းသည်။

## ဖီလ်ဒ်များမှ စာရွက် နံပါတ်ပေးရန်

နံပါတ်ကို လက်ဖြင့် မပေးဘဲ၊ စည်းမျဉ်းတစ်ခုက စာရွက်၏ ဖီလ်ဒ်များမှ နံပါတ်တိုင်းကို တည်ဆောက်စေပါ၊ ထို့ကြောင့် အဆင့် သို့မဟုတ် ပညာရပ်ခွဲ သို့ ရွှေ့သော စာရွက်သည် ၎င်း၏ နံပါတ်အသစ်ကို ကိုယ်တိုင် ရရှိမည်။

1. စာရွက်တစ်ခုစီကို ဖီလ်ဒ်များ ပေးပါ: ရွေးပြီး {{ui:အမည်ပြောင်းရန်…}} ကို နှိပ်ပါ၊ ထို့နောက် {{ui:ဤစာရွက်၏ ဖီလ်ဒ်များ}} တွင် တစ်ကြောင်းလျှင် တစ်ခု ရေးပါ၊ ဥပမာ `DISCIPLINE = A` နှင့် `LEVEL = 1`။ set တစ်ခုလုံး မျှဝေသော ဖီလ်ဒ် တစ်ခု (ဥပမာ `DISCIPLINE = A`) ကို အစား set ၏ {{ui:ဂုဏ်သတ္တိများ…}} တွင် ထည့်နိုင်သည်။
2. panel ၏ မီနူးကို ဖွင့်ပြီး {{ui:နံပါတ်ပေးနည်း…}} ကို နှိပ်ပါ။
3. စည်းမျဉ်းကို ရေးပါ၊ ဥပမာ `{DISCIPLINE}-{LEVEL}{SEQ:2}`။ `{SEQ}` သည် အခြားဖီလ်ဒ်များ တူညီစွာ ဖတ်သော စာရွက်များအကြား တိုးရေတွက်သည်၊ ထို့ကြောင့် level 1 သည် A-101, A-102 ရပြီး level 2 သည် A-201 မှ ပြန်စသည်။ `{SEQ:2}` က နံပါတ်ကို ဂဏန်းနှစ်လုံးဖြင့် ရေးသည်; `{SUBSET}` သည် စာရွက်ရှိ subset ၏ အမည်ဖြစ်သည်။
4. ဖီလ်ဒ်တစ်ခု ပြောင်းသောအခါ ဖြစ်ပေါ်မည့်အရာကို ရွေးပါ: {{ui:စာရွက်များကို နံပါတ်ပြန်ပေးမည်}} သည် ပြောင်းလဲမှု တိုင်းအပြီး စည်းမျဉ်းအတိုင်း နံပါတ်များကို ထိန်းသည်; အခြား ရွေးချယ်မှုက ယခုတစ်ကြိမ်သာ နံပါတ်ပေးသည်။

စည်းမျဉ်းကို set ဖိုင်တွင် သိမ်းသည်။ အလိုအလျောက် နံပါတ်ပြန်ပေးနေချိန်တွင် စာရွက်၏ နံပါတ်ကို မပြောင်းဘဲ ဖီလ်ဒ်များကို ပြောင်းပါ။

## set မှ title block များ ဖြည့်ရန်

title block ၏ attribute များကို ဖီလ်ဒ်အမည်ဖြင့် tag လုပ်ထားလျှင် ၎င်း၏ စာသားကို set မှ ရရှိသည်:

| Tag | ပြသသည် |
|---|---|
| `SHEETNUMBER` (သို့မဟုတ် `SHEET_NO`, `DWG_NO`) | စာရွက်၏ နံပါတ် |
| `SHEETTITLE` (သို့မဟုတ် `TITLE`, `SHEET_TITLE`) | စာရွက်၏ ခေါင်းစဉ် |
| `SHEETDESC` | စာရွက်၏ ဖော်ပြချက် |
| `PROJECTNAME` (သို့မဟုတ် `PROJECT`) | ပရောဂျက်အမည် |
| `PROJECTNUMBER` (သို့မဟုတ် `PROJECT_NO`, `JOB_NO`) | ပရောဂျက် နံပါတ် |
| `SHEETSETNAME` | set ၏ အမည် |
| `SHEETINDEX`, `SHEETCOUNT` | "3 of 12" နှင့် 12 |
| သင့်ကိုယ်ပိုင် (ဥပမာ `CLIENT`) | {{ui:ဖီလ်ဒ်များ သတ်မှတ်ရန်…}} တွင် ၎င်းအတွက် ရေးထားသည် |

{{ui:ဖီလ်ဒ်များ သတ်မှတ်ရန်…}} တွင် ပရောဂျက်အမည်နှင့် နံပါတ်၊ နှင့် သင့်ကိုယ်ပိုင် ဖီလ်ဒ်များကို တစ်ကြောင်းလျှင် `NAME = value` ပုံစံဖြင့် ထားသည်။

{{ui:ပုံဆွဲများ အပ်ဒိတ်လုပ်ရန်}} သည် set ရှိ ပုံဆွဲအားလုံး၏ title block များထဲသို့ နံပါတ်များ၊ ခေါင်းစဉ်များနှင့် ဖီလ်ဒ်များကို ရေးပြီး၊ စာရွက်တစ်ခုစီ၏ layout tab ကို set က ပြောသည့်အတိုင်း အမည်ပြောင်းသည် (မူလအနေဖြင့် နံပါတ်နှင့် ခေါင်းစဉ်၊ ဥပမာ `A-101 Floor plan`; {{ui:ဖီလ်ဒ်များ သတ်မှတ်ရန်…}} › {{ui:Layout tab အမည်များ}} က ၎င်းကို ပြောင်းသည်)။ ပုံဆွဲတစ်ခုစီကို ၎င်း၏ format နှင့် version အတိုင်း နေရာတွင် သိမ်းသည်။ စာရွက်များကို နံပါတ်ပြန်ပေးသော်လည်းကောင်း၊ အမည်ပြောင်းသော်လည်းကောင်း ပြီးနောက် ထပ် run လုပ်ပါ၊ ထို့နောက် tab များနှင့် title block များ လိုက်ပါလာမည်။

## အုပ်ဖုံးစာရွက်ပေါ်ရှိ စာရွက်စာရင်း

စာရင်းထဲတွင် အုပ်ဖုံးစာရွက်ကို ရွေးပြီး {{ui:ဤစာရွက်ပေါ်တွင် စာရွက်စာရင်း ထည့်ရန်}} ကို ရွေးပါ။ စာရွက်အားလုံး၏ ဇယား (နံပါတ်နှင့် ခေါင်းစဉ်၊ ၎င်း subset အောက်တွင်) သည် စာရွက်၏ ဘယ်ဘက်အပေါ် ထောင့်တွင် ထည့်သည်။ {{ui:ပုံဆွဲများ အပ်ဒိတ်လုပ်ရန်}} နှင့် {{ui:PDF သို့ ထုတ်ဝေရန်}} က ၎င်းကို အသစ်အတိုင်း ထားသည်။ ၎င်းသည် block တစ်ခုတည်း၊ `CC_SHEETLIST`: block reference တစ်ခုကဲ့သို့ ရွှေ့ပါ။

## set ကို ထုတ်ဝေရန်

{{ui:PDF သို့ ထုတ်ဝေရန်}} သည် PDF တစ်ခုကို စာရွက်တစ်ခုလျှင် စာမျက်နှာတစ်ခုဖြင့်၊ set ၏ အစဉ်အတိုင်း၊ စာရွက်တစ်ခုစီ၏ ကိုယ်ပိုင် စက္ကူ အရွယ်အစားဖြင့်၊ စာရွက်တစ်ခုလျှင် bookmark တစ်ခုဖြင့် ဖန်တီးသည် ("A-101 — Floor plan")။ subset တစ်ခု ရွေးထားလျှင် CadCraft က ထို subset ကိုသာ ထုတ်ဝေမလား ဟု မေးသည်။ PDF ရှိ title block များကို ပုံဆွဲများ အပ်ဒိတ်မလုပ်မီကပင် set မှ ဖြည့်သည်; ထုတ်ဝေခြင်းက ပုံဆွဲများကို မပြောင်းပါ။ PDF ကို ဒေါင်းလုဒ် ဆွဲသည်။

{{ui:DWG သို့ ထုတ်ဝေရန်…}} သည် စာရွက်တစ်ခုစီကို ၎င်း၏ကိုယ်ပိုင် DWG (DWG 2018) အဖြစ် ရေးသည်: model နှင့် ထိုစာရွက်တစ်ခုတည်း၊ title block ကို set မှ ဖြည့်ထားပြီး၊ ၎င်း၏ နံပါတ်နှင့် ခေါင်းစဉ်ဖြင့် အမည်ပေးသည် (`A-101 Level 1 floor plan.dwg`)။ {{ui:DWG}} ကို ရွေးပါ၊ သို့မဟုတ် ၎င်းတို့ဘေးတွင် set ၏ PDF အတွက် {{ui:DWG + PDF}}။ `publish.json` က ဖိုင်တိုင်းကို အရွယ်အစားနှင့် SHA-256 ဖြင့် စာရင်းပြုသည်။ set ၏ ဖိုင်တွဲကို ရေးနိုင်သည့်အခါ (CadCraft Studio၊ သို့မဟုတ် browser တွင် ရွေးထားသော ဖိုင်တွဲ) ဖိုင်များသည် `<set name> - published` ဖိုင်တွဲထဲ ရောက်သည်; မဟုတ်လျှင် zip တစ်ခုအဖြစ် ဒေါင်းလုဒ် ဆွဲသည်။ Viewport [class overrides](topic:viewport-overrides) များသည် DWG တိုင်းတွင် ပါလာသည်။

## set ကို archive လုပ်ရန်

{{ui:Zip အဖြစ် သိမ်းဆည်းရန်}} သည် set ဖိုင်၊ အသုံးပြုသော ပုံဆွဲတိုင်း နှင့် ထိုပုံဆွဲများ ချိတ်ဆက်ထားသည်များ (ချိတ်ထားသော ပုံဆွဲများ၊ ၎င်းတို့၏ ချိတ်ဆက်မှုများ၊ နှင့် ပုံများ) ကို ၎င်းတို့၏ ဖိုင်တွဲများ ထိန်းထားပြီး ထုပ်ပိုးသည်၊ ထို့အပြင် ဖိုင်တိုင်းကို စာရင်းပြုသော `Transmittal.txt` ကိုလည်း ထည့်သည်။ set ၏ ဖိုင်တွဲတွင် မရှိသော link ကို ပျောက်နေသည်ဟု ထိုနေရာတွင် စာရင်းပြုသည်။ link များကို ပုံဆွဲမှ path ဖြင့်၊ ထို့နောက် ဖိုင်တွဲအတွင်း မည်သည့်နေရာမှ ဖိုင်အမည်ဖြင့် ရှာသည်။

## set ဖိုင်

`.ccsheets` ဖိုင်သည် text editor မည်သည့်တစ်ခုဖြင့်မဆို ဖတ်နိုင်သော JSON ဖြစ်သည်:

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

path များသည် set ၏ ဖိုင်တွဲနှင့် ဆက်စပ်ပြီး ဖိုင်တွဲများကြား `/` ဖြင့် ခွဲသည်။ CadCraft က ဖွင့်သည့်အခါ ဖိုင်ကို စစ်ဆေးသည်: absolute path၊ ဖိုင် သို့မဟုတ် layout မပါသော စာရွက်၊ သို့မဟုတ် ရိုးရိုး မဟုတ်သော စာသားကို ချန်ထားပြီး history က ထိုသို့ ပြောသည်။
