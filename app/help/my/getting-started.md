CadCraft သည် 2D ပုံဆွဲအက်ပ်ဖြစ်သည်။ မျဉ်း၊ လုံးပတ်အပိုင်း၊ polyline၊ စာသား၊ အတိုင်းအတာနှင့် ဘလောက်များကို ဆွဲပြီး တည်းဖြတ်သည်၊ ခေါင်းစဉ်ဘလောက်နှင့် viewport ပါသော စာရွက်များကို စီစဉ်သည်၊ ၎င်းတို့ကို PDF သို့ ပလော့သည်။ DWG နှင့် DXF ပုံဆွဲများကို ဖွင့်ပြီး DWG သို့မဟုတ် DXF အဖြစ် သိမ်းသည်။

၎င်းသည် သင့် web browser တွင် လည်ပတ်သည်။ ထည့်သွင်းစရာ မလိုပါ: ဆိုဒ်က လိပ်စာကို ပေးပြီး အက်ပ်တစ်ခုလုံး စာမျက်နှာထဲသို့ တင်သည်။ သင့်ပုံဆွဲများကို သင့်ကွန်ပျူတာမှ ဖွင့်ပြီး ပြန်သိမ်းသည်။ **ဘာမှ တင်မပို့ပါ။**

ယခင်က ပုံဆွဲဖူးလျှင် ဤစာမျက်နှာပြီးနောက် [အခြား ပုံဆွဲ software မှ ပြောင်းခြင်း](topic:coming-from) ကို ဖတ်ပါ။ အလေ့အကျင့်အများစု ဆက်ရှိနေပြီး မလိုက်သည့် အချို့ကို ထိုနေရာတွင် စာရင်းပြုထားသည်။

## လမ်းညွှန်ချက်ဖြင့် လိုချင်ပါသလား?

`TOUR` ကို ရိုက်ပါ (သို့မဟုတ် စတင်ကဒ်ပေါ်ရှိ {{ui:လမ်းညွှန်ကို ကြည့်ရန်}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:ဆက်တင်များ}} › {{ui:CadCraft}} › {{ui:လမ်းညွှန်ကို ထပ်ကြည့်ရန်}})။ ပုံဆွဲပေါ်ရှိ ဘောင်တစ်ခုအတွင်း အဆင့်ခြောက်ဆင့်: မျဉ်းနှင့် စက်ဝိုင်း ဆွဲခြင်း၊ ရွှေ့ခြင်း၊ ဖြတ်ခြင်း၊ တစ်ခုခု ဖျက်ခြင်းနှင့် အတိုင်းအတာ ယူခြင်း။ အဆင့်တစ်ခုစီသည် သင်လုပ်ပြီးသည့်အခါ ပြီးသည်၊ အဆင့်တစ်ခု သို့မဟုတ် လမ်းညွှန်တစ်ခုလုံးကို ကျော်နိုင်သည်။ ပထမအကြိမ်တွင်သာ သူ့ဘာသာ စသည်။ [cheat sheet](topic:cheat-sheet) တွင် သင်အများဆုံး သုံးမည့် command ၄၀ ရှိပြီး [command မြေပုံ](topic:command-map) တွင် command အားလုံးရှိသည်။

## လိုအပ်သည်များ

- Mac၊ Windows သို့မဟုတ် Linux ကွန်ပျူတာပေါ်ရှိ နောက်ဆုံးထွက် Chrome၊ Edge၊ Firefox သို့မဟုတ် Safari။ [Browser နှင့် platform များ](common:browsers) ကို ကြည့်ပါ။
- ဘီးပါသော မောက်စ်သည် အနားယူစေသည်ဆုံးဖြစ်သည်။ Trackpad ဖြင့်လည်း အလုပ်လုပ်သည်; [မောက်စ်၊ trackpad နှင့် touch](topic:mouse-trackpad-touch) ကို ကြည့်ပါ။
- ကီးဘုတ်။ CadCraft သည် ရိုက်ထားသော command များဖြင့် လည်ပတ်သည်၊ ပုံဆွဲပရိုဂရမ် အများစုကဲ့သို့ပင်။

## အယူအဆ တစ်ပိုဒ်တည်းဖြင့်

command တစ်ခုကို ရိုက်ပါ (သို့မဟုတ် ၎င်း၏ခလုတ်ကို နှိပ်ပါ)၊ ထို့နောက် အောက်ရှိ command လိုင်းက မေးခွန်းများကို တစ်ခုချင်းစီ မေးသည်: "Specify first point"၊ "Specify next point"။ မေးခွန်းတစ်ခုစီကို ပုံဆွဲပေါ်တွင် နှိပ်ခြင်း သို့မဟုတ် တန်ဖိုးရိုက်ခြင်းဖြင့် ဖြေပြီး {{key:Enter}} ကို နှိပ်ပါ။ {{key:Esc}} ကို နှိပ်လျှင် ပယ်ဖျက်သည်။ ဒါက အပြန်အလှန် ဆက်သွယ်မှု မော်ဒယ် တစ်ခုလုံးဖြစ်သည်; ကျန်သည်အားလုံး အသေးစိတ်ဖြစ်သည်။

## သင့်ပထမ ပုံဆွဲ

4000 နှင့် 3000 စတုဂံတစ်ခုကို မျဉ်းများဖြင့် ဆွဲ၊ အလယ်တွင် စက်ဝိုင်းတစ်ခု ထည့်ပြီး ဖိုင်ကို သိမ်းပါမည်။

1. CadCraft ကို ဖွင့်ပါ။ အောက်ရှိ command လိုင်းက `Command:` ကို ပြပြီး ပုံဆွဲနေရာက "ပုံဆွဲ စတင်ရန်" ကဒ်တိုတစ်ခု ပြသည်။
2. `L` ကို ရိုက်ပြီး Enter ကို နှိပ်ပါ။ command လိုင်းကို အရင်နှိပ်စရာ မလိုပါ: နေရာတိုင်းတွင် ရိုက်လျှင် ထိုနေရာသို့ ရောက်သည်။
3. prompt က `Specify first point:` သို့ ပြောင်းသည်။ `0,0` ကို ရိုက်ပြီး Enter ကို နှိပ်ပါ။
4. `@4000,0` ကို ရိုက်ပြီး Enter ကို နှိပ်ပါ။ မျဉ်းတစ်ကြောင်း ပေါ်လာပြီး ညာသို့ ရောက်သည်။ `@` ဆိုသည်မှာ "နောက်ဆုံးအမှတ်မှ" ဖြစ်သည်။
5. `@0,3000` ကို ရိုက်ပြီး Enter ကို နှိပ်ပါ။
6. `@-4000,0` ကို ရိုက်ပြီး Enter ကို နှိပ်ပါ။
7. `C` ကို ရိုက်ပြီး Enter ကို နှိပ်ပါ။ `C` သည် Close ရွေးချယ်မှုဖြစ်သည်: နောက်ဆုံးမျဉ်းသည် ပထမအမှတ်သို့ ပြန်ရောက်ပြီး command ပြီးသည်။
8. Toolbar ၏ {{ui:အမြင်}} အုပ်စုတွင် {{ui:အပြည့်အစုံ}} ကို နှိပ်ပါ။ စတုဂံက မျက်နှာပြင်ကို ဖြည့်သည်။

ယခု မျဉ်း လေးကြောင်းဖြင့် စတုဂံကို မြင်ရမည်၊ command လိုင်းအပေါ်ရှိ မှတ်တမ်းက သင်ရိုက်ခဲ့သည်များကို စာရင်းပြုသည်။

9. `C` ကို ရိုက်ပြီး Enter ကို နှိပ်၍ စက်ဝိုင်း command ကို စတင်ပါ။
10. `2000,1500` ကို ရိုက်ပြီး Enter ကို နှိပ်ပါ၊ ဗဟိုအတွက်။
11. `500` ကို ရိုက်ပြီး Enter ကို နှိပ်ပါ၊ အချင်းဝက်အတွက်။

စက်ဝိုင်းတစ်ခုသည် စတုဂံအလယ်တွင် ပေါ်လာသည်။

12. {{key:Mod+S}} ကို နှိပ်ပါ၊ သို့မဟုတ် ဖိုင်အုပ်စုရှိ {{ui:သိမ်းရန်}} ကို နှိပ်ပါ။

browser သည် `Drawing1.dwg` ကို သင့်ပုံမှန် ဒေါင်းလုဒ်ဖိုင်တွဲသို့ ဒေါင်းလုဒ်ဆွဲသည်၊ မှတ်တမ်းက DWG အဖြစ် မိတ္တူ သိမ်းပြီးဟု ပြောသည်။ ထိုဖိုင်ကို CadCraft တွင် ပြန်ဖွင့်နိုင်ပြီး CAD ပရိုဂရမ် အများစုတွင်လည်း ဖွင့်နိုင်သည်။ (ဤ browser တွင် အရင်က {{ui:အမည်ပြောင်း၍ သိမ်းရန်}} တွင် DXF ကို ရွေးထားလျှင် ပုံဆွဲအသစ်သည် `Drawing1.dxf` အဖြစ် သိမ်းမည်။)

:::tip
command လိုင်း အလွတ်တွင် Enter ကို နှိပ်ပြီး နောက်ဆုံး command ကို ထပ်လုပ်ပါ။ နှစ်သက်လျှင် Enter အစား Space ကို နှိပ်နိုင်သည်: စာသားအပြင်တွင် အတူတူ လုပ်သည်။
:::

## ရှိပြီးသား ပုံဆွဲကို ဖွင့်ခြင်း

1. {{key:Mod+O}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:ဖွင့်ရန်}} ကို နှိပ်ပါ။
2. ဖိုင်ရွေးကိရိယာတွင် `.dwg` သို့မဟုတ် `.dxf` ဖိုင်ကို ရွေးပါ။

DWG သို့မဟုတ် DXF ဖိုင်ကို {{pick:mac=Finder|windows=File Explorer|linux=သင့်ဖိုင်မန်နေဂျာ}} မှ ဆွဲပြီး ပုံဆွဲနေရာပေါ် ချနိုင်သည်။ ဖိုင်ကို စာမျက်နှာအတွင်း ဖတ်သည်; ၎င်းသည် သင့်ကွန်ပျူတာမှ ဘယ်တော့မှ မထွက်ပါ။

ထိန်းသိမ်းသည်နှင့် ပြောင်းလဲသည်များအတွက် [ဖိုင်များ: ဘာဖွင့်နိုင်သလဲ၊ ဘာသိမ်းနိုင်သလဲ](topic:files) ကို ကြည့်ပါ။

## သိမ်းခြင်း: ဘာမျှော်လင့်ရမလဲ

browser တွင် သိမ်းခြင်းသည် desktop ပရိုဂရမ်နှင့် ကွဲပြားစွာ အလုပ်လုပ်သည်:

- {{ui:သိမ်းရန်}} သည် အမြဲ **ဒေါင်းလုဒ်အသစ်** ဆွဲသည်။ ဖွင့်ထားသော ဖိုင်ကို အစားထိုးခြင်း မရှိပါ။ ဒေါင်းလုဒ်ဖိုင်တွဲတွင် အမည်တူဖိုင် ရှိပြီးသားဆိုလျှင် browser က များသောအားဖြင့် `Drawing1 (1).dwg` ကဲ့သို့ နံပါတ်ထည့်သည်။
- {{ui:သိမ်းရန်}} သည် ပုံဆွဲ၏ ဖော်မတ်ကို သုံးသည်: DWG ဖွင့်ထားလျှင် DWG၊ DXF ဖွင့်ထားလျှင် DXF။ ရွေးရန် {{key:Mod+Shift+S}} ကို နှိပ်ပါ သို့မဟုတ် {{ui:အမည်ပြောင်း၍ သိမ်းရန်}} ကို နှိပ်ပြီး {{ui:DWG}} (နှင့် ၎င်း၏ဗားရှင်း)၊ {{ui:DXF R12}} သို့မဟုတ် {{ui:DXF 2000}} ကို ရွေးပါ။ [သိမ်းခြင်း](topic:files#saving) ကို ကြည့်ပါ။
- သင်ဖွင့်ထားသော ဖိုင်ကို ဘယ်တော့မှ မပြောင်းလဲပါ။
- အခြားဖိုင်တစ်ခု ဖွင့်ခြင်း၊ သို့မဟုတ် {{ui:အသစ်}} သည် ပုံဆွဲနေရာပေါ်တွင် ၎င်း၏ကိုယ်ပိုင် tab ထဲ ထည့်သည်၊ ထို့ကြောင့် ဖွင့်ထားသည်တစ်ခုမှ ပိတ်မသွားပါ။ ပုံဆွဲ tab ကို ပိတ်ခြင်း သို့မဟုတ် မသိမ်းရသေးသော ပြောင်းလဲမှုများဖြင့် စာမျက်နှာမှ ထွက်ခြင်းတွင် CadCraft က အရင်မေးသည်: {{ui:ကော်ပီ အရင်သိမ်းရန်}}၊ မသိမ်းဘဲ ပယ်ရန်၊ သို့မဟုတ် {{ui:ပယ်ဖျက်ရန်}}။ browser tab ကို ပိတ်လျှင် browser ၏ကိုယ်ပိုင် "ဆိုဒ်မှ ထွက်မလား?" မေးခွန်းကို ပြသည်။

Cloud သိမ်းခြင်း ရနိုင်သေးပါ။ သင့်ဖိုင်များ ဘယ်နေရာ ရောက်သလဲနှင့် ဘာကြောင့် ကိုယ်ရေးလျှို့ဝှက်သလဲ ဆိုသည်ကို [သင့်ဖိုင်များနှင့် ကိုယ်ရေးအချက်အလက်](common:your-files) တွင် ရှင်းပြထားသည်။

## နောက်ထပ် ဘယ်သွားရမလဲ

{{key:F1}} ကို နှိပ်ပါ သို့မဟုတ် အပေါ်ဘားရှိ {{ui:အကူအညီ}} ကို နှိပ်ပါ၊ ဤအကူအညီကို ပုံဆွဲဘေးတွင် အချိန်မရွေး ဖွင့်ရန်။ ချိတ်ဆက်မှုမလိုဘဲ အလုပ်လုပ်သည်။

- [CadCraft မျက်နှာပြင်](topic:workspace) က bar နှင့် panel တိုင်းကို အမည်ပေးထားသည်။
- [ကိုဩဒီနိတ်ဖြင့် ဆွဲခြင်း](topic:draw-with-coordinates) သည် အကောင်းဆုံး ပထမလမ်းညွှန် ဖြစ်သည်။
- [ကီးဘုတ်နှင့် မောက်စ်](topic:keyboard) တွင် ကီးတိုင်းကို စာရင်းပြုထားသည်။
- command လိုင်းတွင် `HELP` ကို ရိုက်ပါ၊ command အားလုံး၏ စာရင်းအတွက်၊ သို့မဟုတ် [Command ကိုးကားချက်](topic:commands) ကို ဖတ်ပါ။
