## ဘာလုပ်မလဲ

မှတ်စုတစ်ခု ရေးပါ၊ စာလုံးတစ်လုံးကို ထူပြီး အနီရောင် ပြုလုပ်ပါ၊ အရွယ်အစား ပြောင်းပါ၊ ဒီဂရီ သင်္ကေတ ထည့်ပြီး ပြီးဆုံးပါ။

## အဆင့်များ

1. {{cmd:MTEXT}} ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ၊ သို့မဟုတ် ရှိပြီးသား စာသားကို နှစ်ချက်နှိပ်ပါ၊ သို့မဟုတ် {{cmd:TEXTEDIT}} ကို ရိုက်ပြီး ရွေးပါ။ စာသားအကွက် ဖွင့်လာပြီး အပေါ်တွင် ဖော်မတ်အတန်း ပေါ်လာပါမည်။
2. မှတ်စုကို ရိုက်ပါ။ {{key:Enter}} သည် ပုဒ်အသစ် စတင်စေသည်။
3. မောက်စ် သို့မဟုတ် {{key:Shift+Right}} ဖြင့် စာလုံးတစ်လုံး ရွေးပါ။
4. ဖော်မတ်အတန်းတွင် ဖောင့်အတွက် {{ui:ဖောင့်}}၊ ရွေးထားသည်များ၏ အရွယ်အစားအတွက် {{ui:အရွယ်အစား}}၊ ခလုတ်များ {{ui:ထူ}}၊ {{ui:စောင်း}}၊ {{ui:မျဉ်းသား}} နှင့် {{ui:မျဉ်းဖြတ်}}၊ အရောင် ရွေးရန် {{ui:အရောင်}} ကို အသုံးပြုပါ။ ဘာမျှ မရွေးထားလျှင် {{ui:အရွယ်အစား}} သည် စာသားအားလုံးကို ပြောင်းသည်။
5. အနေအထား ညှိရန် {{ui:ဘယ်ဘက် ညှိရန်}}၊ {{ui:စင်တာ}} သို့မဟုတ် {{ui:ညာဘက် ညှိရန်}} ကို အသုံးပြုပါ။
6. သင်္ကေတ ရိုက်ရန် ကာဆာကို သွားရမည့်နေရာတွင် ထားပြီး {{ui:ဒီဂရီ သင်္ကေတ}}၊ {{ui:အပေါင်း-အနုတ် သင်္ကေတ}} သို့မဟုတ် {{ui:အချင်း သင်္ကေတ}} ကို နှိပ်ပါ။
7. စာသားကို သိမ်းရန် {{ui:အိုကေ}} ကို နှိပ်ပါ သို့မဟုတ် {{key:Ctrl+Enter}} ကို နှိပ်ပါ။ {{ui:ပယ်ဖျက်ရန်}} သို့မဟုတ် {{key:Esc}} သည် မူလအတိုင်း ထားသည်။

## မှတ်ချက်များ

- အကွက်တွင် {{ui:အမြင့်}}၊ {{ui:စာကြောင်းကြား}}၊ {{ui:အကျယ်}} (0 = စာကြောင်း မခွဲ) နှင့် {{ui:ချိန်ညှိ}} လည်း ပါသည်။
- ဖော်မတ်ကို ရိုးရိုး စာလုံးများနှင့်အတူ ပုဒ်ထည့်စာသား ကုဒ်များအဖြစ် ရေးသည်၊ ထို့ကြောင့် ရှာဖွေခြင်း၊ snap၊ DXF နှင့် DWG တို့ ဆက်အလုပ်လုပ်သည်။ မှတ်စု အားလုံး၏ ဖောင့်ကို [စာသားစတိုင်](topic:text-styles) ဖြင့် သတ်မှတ်ပါ။
- ဘုံ အမှတ်အသားစာရင်း (bullet) သို့မဟုတ် နံပါတ်စဉ် စာရင်း၊ tab ruler သို့မဟုတ် ညှိထားသော ပုဒ်များ မရှိသေးပါ။
- ပလော့တ်လုပ်ထားသော PDF များတွင် စာသားကို Helvetica ဖြင့် သတ်မှတ်သည်။
