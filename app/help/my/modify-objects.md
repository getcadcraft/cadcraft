## သင် ဖန်တီးမည့်အရာ

ကုလားထိုင်တစ်လုံးပါသော စားပွဲတစ်ခု၊ ထိုကုလားထိုင်ကို စားပွဲပတ်လည် ကူးထည့်ထားခြင်း၊ လှည့်ထားခြင်း၊ ရောင်ပြန်ဟပ်ထားခြင်းနှင့် အရွယ်အစား ပြောင်းထားခြင်း။ ဤအတွင်း {{cmd:MOVE}}၊ {{cmd:COPY}}၊ {{cmd:ROTATE}}၊ {{cmd:MIRROR}}၊ {{cmd:SCALE}} နှင့် {{cmd:UNDO}} ကို သုံးမည်။

## အပိုင်းများ ဆွဲခြင်း

1. `REC` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ၊ `0,0` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ၊ ထို့နောက် `@1800,900` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ ၎င်းမှာ စားပွဲ ဖြစ်သည်။
2. `REC` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ၊ `300,-700` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ၊ ထို့နောက် `@450,450` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ ၎င်းမှာ စားပွဲအောက်ရှိ ကုလားထိုင် ဖြစ်သည်။
3. {{ui:Extents}} ကို နှိပ်ပါ။

## ရွှေ့ခြင်း- အခြေမှတ်၊ ထို့နောက် ဒုတိယအမှတ်

ရွှေ့၊ ကူး၊ လှည့်နှင့် အရွယ်အစားပြောင်းသော လုပ်ဆောင်ချက်တိုင်းသည် **အခြေမှတ်** မှ စတင်သည်- ၎င်းသည် ယူသွားမည့် သို့မဟုတ် လှည့်မည့် အမှတ် ဖြစ်သည်။

1. ကုလားထိုင်ကို ရွေးရန် နှိပ်ပါ။
2. `M` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ history တွင် `1 found` ဟု ပြသည်။
3. `Specify base point` တွင် ကုလားထိုင်၏ ဘယ်ဘက်အပေါ်ထောင့် (Endpoint) သို့ snap လုပ်ပြီး နှိပ်ပါ။
4. `Specify second point` တွင် `@0,200` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။

ကုလားထိုင်သည် 200 အပေါ်သို့ ရွေ့ပြီး စားပွဲနှင့် ပို နီးသွားသည်။

:::tip
အစားထိုး displacement ပေးရန် `Specify base point` တွင် `D` ကို ရိုက်ပါ။ ထို့နောက် CadCraft က `Specify displacement` ဟု မေးမည်ဖြစ်ပြီး ဘေးသို့နှင့် အပေါ်သို့ အဘယ်မျှဝေးသည်ကို `0,200` ကဲ့သို့ ရိုက်ထည့်ပါ (`@` မလိုပါ)။
:::

## ကူးခြင်း၊ လိုသလောက် အကြိမ်များစွာ

1. ကုလားထိုင်ကို နှိပ်ပါ။
2. `CO` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
3. ကုလားထိုင်၏ ဘယ်ဘက်အောက်ထောင့်သို့ snap လုပ်ပြီး အခြေမှတ်အဖြစ် နှိပ်ပါ။
4. `@600,0` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ မိတ္တူတစ်ခုသည် ညာဘက် 600 တွင် ပေါ်လာသည်။
5. `@600,0` ကို ထပ်ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ ဒုတိယမိတ္တူသည် မူရင်း၏ ညာဘက် 1200 တွင် ပေါ်လာသည်။
6. command ကို အဆုံးသတ်ရန် {{key:Enter}} နှိပ်ပါ။

{{cmd:COPY}} သည် {{key:Enter}} နှိပ်သည်အထိ ဆက်လုပ်ဆောင်သည်။ မိတ္တူတစ်ခုစီကို အခြေမှတ်မှ သင်ပေးသော အမှတ်အထိ အကွာအဝေးဖြင့် နေရာချသည်။ `@` အမှတ်သည် သင်နောက်ဆုံး ရိုက်ထည့်သော အမှတ်မှ ရေတွက်သည်၊ ပထမမိတ္တူပြီးနောက် ထိုမိတ္တူ၏ အမှတ် ဖြစ်သည်။ ထို့ကြောင့် `@600,0` နှစ်ကြိမ်သည် 600 နှင့် 1200 တွင် မိတ္တူများ ပေးသည်။ command မှ မထွက်ဘဲ နောက်ဆုံးမိတ္တူကို ပြန်ယူရန် `U` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။

စားပွဲအောက်တွင် ကုလားထိုင်သုံးလုံး တစ်တန်းတည်း မြင်ရမည်။

:::tip
{{cmd:COPY}} သည် အခြေမှတ်ဖြင့် နေရာချသော ပုံဆွဲတစ်ခုအတွင်း မိတ္တူများအတွက် ဖြစ်သည်။ အရာဝတ္ထုများကို အခြားပုံဆွဲ သို့မဟုတ် tab သို့ ယူသွားရန် သို့မဟုတ် နောက်မှ ကူးထည့်ရန်အတွက် clipboard ကို သုံးပါ- {{key:Mod+C}} ထို့နောက် {{key:Mod+V}}။ {{key:Mod+D}} သည် pointer နှင့်အတူ ရွေ့သော မိတ္တူတစ်ခု ဖန်တီးသည်။ See [Copy, paste and duplicate](topic:copy-paste).
:::

## တန်းကို တစ်ဖက်သို့ ရောင်ပြန်ဟပ်ခြင်း

1. စားပွဲကို မထိဘဲ ကုလားထိုင်သုံးလုံးပေါ်တွင် crossing (ညာမှ ဘယ်) ကို ဆွဲပါ။
2. `MI` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
3. `Specify first point of mirror line` တွင် စားပွဲ၏ ဘယ်ဘက်ဘေး၏ Midpoint သို့ snap လုပ်ပြီး နှိပ်ပါ။
4. `Specify second point of mirror line` တွင် စားပွဲ၏ ညာဘက်ဘေး၏ Midpoint သို့ snap လုပ်ပြီး နှိပ်ပါ။
5. `Erase source objects? [Yes/No] <N>` တွင် ထားရန် {{key:Enter}} နှိပ်ပါ။

စားပွဲအောက်တွင် ကုလားထိုင်သုံးလုံး နှင့် စားပွဲအပေါ်တွင် ရောင်ပြန်ဟပ်ထားသော ကုလားထိုင်သုံးလုံး မြင်ရမည်။ ရောင်ပြန်ဟပ်ထားသော ရွေးချယ်မှုရှိ စာသားများသည် ဖတ်ရလွယ်ဆဲ ဖြစ်သည်။ ၎င်းကို ရောင်ပြန်ဟပ်ထားသော်လည်း နောက်ပြန် မရေးထားပါ။

## ကုလားထိုင်ကို လှည့်ခြင်း

1. စားပွဲအောက်ရှိ ညာဘက်အဆုံးကုလားထိုင်ကို နှိပ်ပါ။
2. `RO` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
3. ကုလားထိုင်၏ ညာဘက်အောက်ထောင့်သို့ snap လုပ်ပြီး အခြေမှတ်အဖြစ် နှိပ်ပါ။
4. `90` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။

ကုလားထိုင်သည် အခြေမှတ်ပတ်လည် ဘယ်ဘက်လှည့် 90 ဒီဂရီ လှည့်သည်။ အနုတ်ထောင့်သည် ညာဘက်လှည့်စေသည်။ ရိုက်ခြင်းအစား ဒုတိယအမှတ်ကို နှိပ်နိုင်သည်- ထောင့်ကို အခြေမှတ်မှ ထိုအမှတ်သို့ တိုင်းတာသည်။

## စားပွဲ၏ အရွယ်အစား ပြောင်းခြင်း

1. စားပွဲကို ရွေးပါ။
2. `SC` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
3. စားပွဲ၏ ဘယ်ဘက်အောက်ထောင့်သို့ snap လုပ်ပြီး အခြေမှတ်အဖြစ် နှိပ်ပါ။
4. `1.2` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။

စားပွဲသည် 20% ပိုကြီးပြီး အခြေမှတ်မှ ဝေးရာသို့ ကြီးလာသည်။ 1 အောက်ရှိ factor သည် ပိုသေးစေသည်။

:::note
scale factor ကို ရိုက်မည့်အစား အမှတ်တစ်ခုကို နှိပ်လျှင် factor သည် အခြေမှတ်မှ ထိုအမှတ်အထိ အကွာအဝေး ဖြစ်သည်။ ပုံဆွဲယူနစ်တစ်ခု ဝေးသော အမှတ်ကို နှိပ်လျှင် factor 1 ရမည်။ ဂဏန်းကို ရိုက်ထည့်ခြင်းသည် များသောအားဖြင့် သင်လိုချင်သည့်အရာ ဖြစ်သည်။
:::

## ပြန်ဖျက်ခြင်းနှင့် ပြန်လုပ်ခြင်း

- {{key:Mod+Z}}၊ {{ui:Undo}} ခလုတ်၊ သို့မဟုတ် `U` ထို့နောက် {{key:Enter}} သည် နောက်ဆုံး command ကို ပြန်ဖျက်သည်။ command တစ်ခုလုံးသည် အဆင့်တစ်ခု ဖြစ်သည်- မိတ္တူငါးခု ဖန်တီးခဲ့သော {{cmd:COPY}} ကို ပြန်ဖျက်လျှင် ငါးခုလုံး ဖယ်ရှားသည်။
- {{key:Mod+Y}}၊ {{key:Mod+Shift+Z}}၊ {{ui:Redo}} ခလုတ် သို့မဟုတ် `REDO` သည် ၎င်းကို ပြန်ယူလာသည်။
- history တွင် ဘာကို ပြန်ဖျက်ခဲ့သည်ကို ပြသည် ("Undid COPY")။

CadCraft သည် နောက်ဆုံး အဆင့် 500 ကို သိမ်းထားသည်။ လေယာဆက်တင်များ (on၊ freeze၊ lock၊ color) သည် ဆက်တင်များဖြစ်ပြီး တည်းဖြတ်မှုများ မဟုတ်သဖြင့် ပြန်ဖျက်ခြင်း မရှိပါ။

## အခန်းကို ပိုကျယ်အောင် ဆွဲဆန့်ခြင်း

{{cmd:STRETCH}} (`S`၊ သို့မဟုတ် {{ui:Stretch}}) သည် crossing window အတွင်းရှိသာ ရွေ့သည်- ထိုအတွင်းရှိ ထောင့်များနှင့် လိုင်းအဆုံးများ ရွေ့ပြီး ကျန်တာများ နေရာတွင်ပင် ရှိနေသဖြင့် အခန်းသည် ရွေ့မသွားဘဲ ပိုကျယ်လာသည်။

1. `S` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။
2. ညာဘက်နံရံပေါ်တွင် window ကို ညာမှ ဘယ်သို့ ဆွဲပါ၊ နံရံ၏ ထောင့်များနှင့် ၎င်းနှင့် ထိတွေ့သော အရာများ၏ အဆုံးများကို ဖုံးအုပ်စေရန်။
3. {{key:Enter}} နှိပ်ပါ။
4. အခြေမှတ်ကို နှိပ်ပြီး `@600,0` ကို ရိုက်ကာ {{key:Enter}} နှိပ်ပါ။

ထောင့်မှန်ကွက်သည် 600 ပိုကျယ်သည်; နံရံပေါ်တွင် အဆုံးသတ်ခဲ့သော လိုင်းများသည် ဆက်လက် ထိုနံရံပေါ်တွင် အဆုံးသတ်သည်။ တစ်ဖက်အဆုံး အတွင်းရှိ arc သည် ၎င်း၏ အမြင့်ကို ထိန်းထားသည်၊ စက်ဝိုင်းနှင့် စာသားများသည် ၎င်းတို့၏ center သို့မဟုတ် insertion အမှတ် အတွင်းရှိလျှင် ရွေ့သည်၊ dimension သည် ၎င်း၏ အသစ် အရှည်ကို တိုင်းသည်။ window မပါဘဲ တစ်ခုချင်းစီ ရွေးထားသော အရာများသည် ရိုးရိုး ရွေ့သည်။

ရွေးချယ်မှုကို ဦးစွာလည်း လုပ်နိုင်သည်- command မလည်ပတ်ချိန်တွင် crossing window (သို့မဟုတ် crossing lasso) ကို နံရံပေါ် ဆွဲပြီး ထို့နောက် `S` ကို ရိုက်ပါ။ STRETCH သည် ထိုရွေးချယ်မှုကို ယူပြီး ၎င်း၏ window များထဲရှိ အရာများကို ဆွဲဆန့်သည်- command ၏ prompt တွင် ဆွဲခဲ့သကဲ့သို့ပင်။

## Array- အတန်းနှင့် ကော်လံများ၊ သို့မဟုတ် အလယ်ပတ်လည်

{{cmd:ARRAY}} (`AR`၊ သို့မဟုတ် {{ui:Array}}) သည် ရွေးချယ်မှုကို ဂရစ် သို့မဟုတ် စက်ဝိုင်းပုံစံဖြင့် ကူးသည်။

1. ကုလားထိုင်တစ်လုံးကို ရွေးပြီး `AR` ကို ရိုက်ကာ {{key:Enter}} နှိပ်ပါ။ Rectangular အတွက် {{key:Enter}} နှိပ်ပါ။
2. ကော်လံ 4 နှင့် အတန်း 3 ၏ preview ပေါ်လာသည်။ `COU` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ၊ ထို့နောက် ကော်လံအတွက် `5` နှင့် အတန်းအတွက် `2` ကို ရိုက်ပါ။
3. `S` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ၊ ထို့နောက် ကော်လံများကြား `600` နှင့် အတန်းများကြား `-900` ကို ရိုက်ပါ (အနုတ်သည် အောက်သို့ သွားသည်)။
4. မိတ္တူများ ဖန်တီးရန် {{key:Enter}} နှိပ်ပါ။

စားပွဲပတ်လည် ကုလားထိုင်ကွင်းအတွက် `PO` (Polar) ကို ရွေးပါ၊ စားပွဲ၏ center ကို နှိပ်ပြီး `I` (items)၊ `F` (fill angle- အပြည့်ပတ်လည်အတွက် 360၊ တစ်ဝက်အတွက် 180) နှင့် `ROT` (မိတ္တူများ center ဘက်သို့ လှည့်မလား) ကို သတ်မှတ်ပါ။ {{cmd:ARRAYRECT}} နှင့် {{cmd:ARRAYPOLAR}} သည် မေးခွန်းကို ကျော်သွားသည်။

## အပိုင်းများကို polyline တစ်ခုအဖြစ် ပေါင်းခြင်း

{{cmd:JOIN}} (`J`၊ သို့မဟုတ် {{ui:Modify}} › {{ui:More}} › {{ui:Join}}): အဆုံးများ ထိတွေ့သော လိုင်း၊ arc နှင့် ဖွင့်ထားသော polyline များကို ရွေးပြီး {{key:Enter}} နှိပ်ပါ။ ၎င်းတို့သည် polyline တစ်ခု ဖြစ်လာပြီး ပတ်လည်အပြည့် ရောက်လျှင် ပိတ်ထားသည်၊ ထို့နောက် တစ်ကြိမ်တည်းဖြင့် offset လုပ်နိုင်သည်။ လိုင်းတစ်ကြောင်းတည်းပေါ်ရှိ လိုင်းများသည် ကြားတွင် ကွက်လပ်ရှိသော်လည်း လိုင်းတစ်ကြောင်း ဖြစ်လာသည်။ စက်ဝိုင်းတစ်ခု၏ arc များသည် arc တစ်ခု သို့မဟုတ် စက်ဝိုင်း ဖြစ်လာသည်။

## ဂုဏ်သတ္တိများ တူညီအောင်ပြုခြင်း

{{cmd:MATCHPROP}} (`MA`၊ သို့မဟုတ် {{ui:Modify}} › {{ui:More}} › {{ui:Match properties}}): ပုံစံကို လိုချင်သော အရာဝတ္ထုကို နှိပ်ပါ၊ ထို့နောက် ပြောင်းလဲလိုသော အရာဝတ္ထုများကို ရွေးပြီး {{key:Enter}} နှိပ်ပါ။ ၎င်းတို့သည် ၎င်း၏ လေယာနှင့် အရောင်ကို ယူသည်; စာသားသည် ၎င်း၏ အမြင့်ကို၊ dimension သည် ၎င်း၏ အရွယ်အစားများကို၊ hatch သည် ၎င်း၏ pattern ကို ယူသည်။ ဒုတိယမေးခွန်းတွင် ထိုအရာများထဲမှ တစ်ခုခုကို ပိတ်ရန် `S` (Settings) ကို ရိုက်ပါ။

## အရာဝတ္ထုများကို ညှိခြင်း

**အမှတ်များဖြင့်။** {{cmd:ALIGN}} (`AL`၊ သို့မဟုတ် {{ui:Modify}} › {{ui:More}} › {{ui:Align}}): အရာဝတ္ထုများကို ရွေးပြီး {{key:Enter}} နှိပ်ပါ၊ ထို့နောက် ၎င်းတို့ပေါ်ရှိ အမှတ်တစ်ခု (အရင်းအမြစ်) နှင့် ၎င်း ရောက်သင့်သော နေရာ (ပန်းတိုင်) ကို နှိပ်ပါ။

- အတွဲတစ်ခုသည် ၎င်းတို့ကို ရွှေ့သည်။ ထိုနေရာတွင် ရပ်ရန် `Specify second source point` တွင် {{key:Enter}} နှိပ်ပါ။
- အတွဲနှစ်တွဲဖြင့် ၎င်းတို့ကို လှည့်သည်၊ ထို့ကြောင့် အရင်းအမြစ်အမှတ်နှစ်ခုကြား မျဉ်းသည် ပန်းတိုင်အမှတ်နှစ်ခုကြား မျဉ်းနှင့် တစ်ပြိုင်တည်း ဖြစ်သည်။ ထို့နောက် CadCraft က `Scale objects based on alignment points?` ဟု မေးသည်- `Y` သည် ၎င်းတို့ကိုလည်း ထိုမျှ ကြီး သို့မဟုတ် သေးစေသည်။
- တတိယအတွဲသည် ၎င်း၏ အမှတ်နှစ်ခု ထိုမျဉ်း၏ ဆန့်ကျင်ဘက်နှစ်ဖက်တွင် ရှိသောအခါ ၎င်းတို့ကို ရောင်ပြန်ဟပ်သည်။

**အစွန်းများနှင့် အကွာအဝေး။** {{ui:Modify}} › {{ui:More}} › {{ui:Align and distribute}} (သို့မဟုတ် `ALIGNPANEL`) သည် ပုံဆွဲပေါ်တွင် panel သေးသေးတစ်ခု ဖွင့်သည်။ အရာဝတ္ထုများကို ရွေးပြီး-

- {{ui:Align to}} တွင် ညှိရမည့် အရာကို ရွေးပါ (ရွေးချယ်မှုတစ်ခုလုံး၊ ရွေးခဲ့သော ပထမ သို့မဟုတ် နောက်ဆုံး အရာ၊ သို့မဟုတ် သင်နှိပ်သော အမှတ်) ပြီး {{ui:Left}}၊ {{ui:Center}}၊ {{ui:Right}}၊ {{ui:Top}}၊ {{ui:Middle}} သို့မဟုတ် {{ui:Bottom}} ကို နှိပ်ပါ။
- သို့မဟုတ် {{ui:Equal gaps}} သို့မဟုတ် {{ui:Equal centres}} ကို ရွေးပြီး {{ui:Across}} သို့မဟုတ် {{ui:Up and down}} ကို နှိပ်ပါ- အပြင်ဆုံး အရာနှစ်ခု နေရာတွင်ပင် ရှိနေပြီး ကျန်တာများကို ၎င်းတို့ကြား တူညီစွာ ခွာထားသည် (အရာဝတ္ထု အနည်းဆုံး သုံးခု)။

နှိပ်တိုင်း ပြန်ဖျက်ရန် အဆင့်တစ်ခု ဖြစ်ပြီး ရွေးချယ်မှု ကျန်ရှိသည်ဖြစ်၍ နောက်တစ်ခုကို စမ်းနိုင်သည်။ အရာဝတ္ထုတစ်ခုစီကို ၎င်း၏ bounding box ဖြင့် တွက်သည်၊ UCS တစ်ခု သတ်မှတ်ထားလျှင် ထို UCS တွင်။ command line တွင် တူညီသော လုပ်ဆောင်ချက်သည် {{cmd:ALIGNTO}} နှင့် {{cmd:DISTRIBUTE}} ဖြစ်သည်။

## ဖျက်ခြင်းနှင့် ခွဲခြင်း

- {{cmd:ERASE}} (`E`၊ သို့မဟုတ် {{key:Delete}}) သည် ရွေးထားသော အရာဝတ္ထုများကို ဖယ်ရှားသည်။
- {{cmd:EXPLODE}} (`X`) သည် polyline ကို လိုင်းနှင့် arc များ၊ block reference ကို ၎င်း၏ အရာဝတ္ထုများ၊ dimension ကို လိုင်း၊ မြားဦး နှင့် စာသားများအဖြစ် ခွဲသည်။ ခွဲထားသော dimension များသည် ကိုယ်တိုင် တိုင်းတာခြင်း မရှိတော့ပါ။

## အမှားများ

- **ဒုတိယအမှတ်တွင် `@` မပါဘဲ အကွာအဝေး ရိုက်ခြင်း။** `600,0` သည် အကြောင်းပြချက် အမှတ် 600,0 ဖြစ်ပြီး "ညာဘက် 600" မဟုတ်ပါ။ `@600,0` ကို သုံးပါ၊ သို့မဟုတ် crosshair ကို မှန်ကန်စွာ ညွှန်ထားသော `600` တစ်ခုတည်းကို သုံးပါ။
- **လှည့်ခြင်းသည် မှားသောဘက်သို့ သွားသည်။** အပေါင်းထောင့်များသည် ဘယ်ဘက်လှည့်သည်။
- **Undo သည် မျှော်ထားသည်ထက် ပိုဖယ်သွားသည်။** undo တစ်ကြိမ်သည် နောက်ဆုံး command တစ်ခုလုံးကို ပြန်ယူသည်၊ ၎င်းဖန်တီးခဲ့သော မိတ္တူအားလုံးအပါအဝင်။
- **Command က အရာဝတ္ထုများ ရွေးရန် မမေးခဲ့ပါ။** အရာဝတ္ထုများ ရွေးပြီးသား ဖြစ်သဖြင့် ၎င်းတို့ကို သုံးခဲ့သည်။ ဘာမှ မရွေးထားဘဲ စရန် ဦးစွာ {{key:Esc}} ကို နှိပ်ပါ။
