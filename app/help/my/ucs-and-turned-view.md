## သင် သိရမည့်အရာ

ထောင့်ဖြင့် ဆွဲထားသော အဆောက်အအုံ မျက်နှာပြင်တွင် ဒေါင်ဒေါင် ဖြစ်အောင် ပုံဆွဲကို မည်သို့ လှည့်ကြည့်ရမည်၊ ထို့နောက် ၎င်း၏ ကိုယ်ပိုင် ဝင်ရိုးများတလျှောက် အမှတ်များကို မည်သို့ ရိုက်ရမည်ကို သိရမည်။ ဤအရာများ လုပ်နေစဉ် ပုံဆွဲရှိ ဘာမျှ မရွှေ့ပါ: object များသည် ၎င်းတို့၏ coordinate များကို ထိန်းသည်၊ လှည့်ခြင်းသည် တည်းဖြတ်မှု မဟုတ်ပါ၊ ပုံဆွဲကို ပြောင်းလဲထားသည်ဟု မမှတ်ပါ။

## မြင်ကွင်းကို ၁/၄ လှည့်ခြင်း

1. {{ui:View}} › {{ui:More}} › {{ui:Turn view 90° left}} သို့မဟုတ် {{ui:Turn view 90° right}} ကို နှိပ်ပါ။

ပုံဆွဲသည် ပုံဆွဲနေရာ၏ အလယ်တွင် မျက်နှာပြင်ပေါ်တွင် လှည့်သည်။ ဆက်လှည့်လိုလျှင် ထပ်နှိပ်ပါ။

2. {{ui:View}} › {{ui:More}} › {{ui:Back to world}} ကို နှိပ်ပြီး ပြန်ညီအောင် ထားပါ။

Command များမှာ {{cmd:TURNLEFT}}၊ {{cmd:TURNRIGHT}} နှင့် {{cmd:TURNWORLD}} ဖြစ်သည်။ ၎င်းတို့တစ်ခုကို ကီးတစ်ခု ပေးလိုလျှင် {{cmd:ALIASEDIT}} ဖြင့် သင့် aliases တွင် `TL=TURNLEFT` ကဲ့သို့ စာကြောင်းတစ်ကြောင်း ထည့်ပါ။

## ထောင့်ရှိ အဆောက်အအုံနှင့် ညီညွတ်စေခြင်း

1. `UCS` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ၊ ထို့နောက် `OB` နှင့် {{key:Enter}}။
2. အမှတ် (origin) ဖြစ်သင့်သော အဆုံးနှင့် နီးသော နံရံမျဉ်းကို နှိပ်ပါ။

UCS သည် ထိုအဆုံးမှ စတင်ပြီး X ဝင်ရိုးသည် နံရံနှင့် တစ်လျှောက်တည်း ဖြစ်သည်၊ နံရံသည် မျက်နှာပြင်တွင် ဒေါင်ဒေါင် ဖြစ်အောင် မြင်ကွင်း လှည့်သည်။ ဘယ်ဘက်အောက်ထောင့်ရှိ ဝင်ရိုးအိုင်ကွန်က UCS ဝင်ရိုးများ ညွှန်ရာကို ပြသည်။

3. ပုံမှန်အတိုင်း ဆွဲပါ။ UCS သတ်မှတ်ထားလျှင်:
   - `x,y` နှင့် `@dx,dy` ကို UCS ဝင်ရိုးများတလျှောက် တိုင်းသည်; `d<a` က UCS X ဝင်ရိုးမှ ထောင့်ကို တိုင်းသည်။
   - {{ui:Ortho}}၊ polar tracking နှင့် grid တို့သည် UCS ဝင်ရိုးများကို လိုက်သည်၊ crosshair လည်း ထို့အတူ။
   - စာသားအသစ်နှင့် paragraph အသစ်များသည် UCS X ဝင်ရိုးတလျှောက် ပြေးသည်; {{cmd:DIMLINEAR}} ၏ အလျားလိုက်နှင့် ဒေါင်လိုက်လည်း လိုက်သည်။
   - Status bar ရှိ coordinate များနှင့် {{cmd:ID}} မှ coordinate များသည် UCS coordinate များ ဖြစ်သည်။
4. UCS သတ်မှတ်ထားစဉ် ကမ္ဘာ အမှတ်ကို ရိုက်ရန် ရှေ့တွင် `*` ထည့်ပါ: `*0,0` သို့မဟုတ် `@*100,0`။
5. `UCS` ကို ရိုက်ပြီး {{key:Enter}}၊ ထို့နောက် ကမ္ဘာသို့ ပြန်ရန် {{key:Enter}} ထပ်နှိပ်ပါ။

## UCS သတ်မှတ်ရန် အခြားနည်းလမ်းများ

{{cmd:UCS}} prompt တွင်:

| ရိုက်သည် | ဘာလုပ်သလဲ |
|---|---|
| အမှတ်တစ်ခု | Origin အသစ်; ထို့နောက် X ဝင်ရိုးအသစ်ပေါ်ရှိ အမှတ်တစ်ခု နှိပ်ပါ၊ သို့မဟုတ် ထောင့်ကို ထားရန် {{key:Enter}} ကို နှိပ်ပါ |
| `Z` | UCS ကို origin ၏ ပတ်လည် သင်ရိုက်သော ထောင့် (ဒီဂရီ၊ နာရီလက်တံ ဆန့်ရာ) သို့မဟုတ် ရွေးသော ထောင့်ဖြင့် လှည့်သည် |
| `3` (3point) | Origin၊ X ဝင်ရိုး အပြုသဘောဘက်ရှိ အမှတ်တစ်ခု၊ နှင့် Y အပြုသဘောဘက်ရှိ အမှတ်တစ်ခု |
| `OB` (OBject) | မျဉ်း၊ arc၊ စက်ဝိုင်း၊ polyline အပိုင်း၊ စာသား၊ block reference၊ point သို့မဟုတ် construction line မှ |
| `P` (Previous) | ဤ UCS မတိုင်ခင်က UCS (ပုံဆွဲ ဖွင့်ထားစဉ် နောက်ဆုံး ၁၀ ခု ထိန်းထားသည်) |
| `W` (World) | ကမ္ဘာသို့ ပြန်ရန် |
| `NA` (NAmed) | `S` က လက်ရှိ UCS ကို နာမည်တစ်ခုဖြင့် သိမ်းသည်၊ `R` က တစ်ခုကို ပြန်ထားသည်၊ `D` က ဖျက်သည်၊ `?` က စာရင်းပြသည် |

UCS ပြောင်းလဲမှုတိုင်းသည် မြင်ကွင်းကို လှည့်ပြီး UCS X ဝင်ရိုးအသစ်ကို ညီအောင် ထားသည်။ {{cmd:PLAN}} သည် UCS မပြောင်းဘဲ မြင်ကွင်းကို လှည့်သည်: {{key:Enter}} က လက်ရှိ UCS အတွက်၊ `U` က သိမ်းထားသော တစ်ခုအတွက်၊ `W` က ကမ္ဘာအတွက်။

## သိထားသင့်သည်များ

- Split screen ၏ pane တစ်ခုစီသည် ကိုယ်ပိုင် လှည့်ထားမှု ထားသည်။ UCS သည် ပုံဆွဲနှင့် ပါသည်။
- Sheet များသည် paper coordinate ဖြင့် အလုပ်လုပ်သည်; UCS ကို {{ui:Model}} tab တွင်၊ သို့မဟုတ် viewport အတွင်း သတ်မှတ်ပါ။
- လှည့်ထားသော မြင်ကွင်းတွင် ဆွဲသော ရွေးချယ်ရေး ဝင်းဒိုးများသည် မျက်နှာပြင်ပေါ်ရှိ ၎င်းတို့အတွင်းရှိအရာများကို ရွေးသည်။
- LISP routine များသည် `getpoint` မှ UCS အမှတ်များ ရယူနိုင်ပြီး `UCSORG`၊ `UCSXDIR`၊ `UCSYDIR` နှင့် `VIEWTWIST` ကို ဖတ်နိုင်သည်၊ `trans` က ကမ္ဘာ၊ UCS နှင့် မျက်နှာပြင် အကြား ပြောင်းသည်။

:::note
သိမ်းထားသော ဖိုင်သည် နောက်ပိုင်း build တွင် UCS နှင့် မြင်ကွင်း၏ လှည့်ထားမှုကို ထိန်းမည်; ထိုအချိန်အထိ ပုံဆွဲ ဖွင့်ထားစဉ်သာ ရှိနေမည်။
:::
