## Drawing unit များ

သင်သည် drawing unit များဖြင့် အပြည့်အစားဖြင့် ဆွဲသည်။ Drawing unit တစ်ခုက ဘာကိုကိုယ်စားပြုသလဲဆိုသည်မှာ drawing ၏ **Units** ဆက်တင်ဖြစ်သည်:

1. ဘာမျှ မရွေးထားစေရန် {{ui:မော်ဒယ်}} tab ပေါ်တွင် {{key:Esc}} ကို နှိပ်။
2. {{ui:လက်ရှိ ဆက်တင်များ}} တွင် {{ui:ယူနစ်များ}} ကို ရွေး: {{ui:ယူနစ်မဲ့}}၊ {{ui:မီလီမီတာ}}၊ {{ui:စင်တီမီတာ}}၊ {{ui:မီတာ}}၊ {{ui:လက်မ}} သို့မဟုတ် {{ui:ပေ}}။

Dimension များသည် drawing unit မည်သည်ဖြစ်စေ အရှည်ကို မီလီမီတာ၊ စင်တီမီတာ၊ မီတာ သို့မဟုတ် ကီလိုမီတာဖြင့် ရေးနိုင်သည်: [Dimension များကို mm၊ cm၊ m သို့မဟုတ် km ဖြင့်](topic:dimension-settings#dimensions-in-mm-cm-m-or-km) ကို ကြည့်ပါ။

Unit များပြောင်းခြင်းသည် ဘာကိုမျှ အရွယ်မပြောင်း။ Sheet နှင့် plot များတွင် scale များကို ဖတ်ပုံနှင့် ပေးသော scale များကိုသာ ပြောင်း။ DWG သို့မဟုတ် DXF မှ ဖွင့်သော drawing သည် ဖိုင်တွင် သိမ်းထားသော unit များကို ထိန်း၊ ဘယ်ဘက် panel ၏ {{ui:ပုံဆွဲ}} အပိုင်းက ၎င်းတို့ကို ပြ။

{{ui:ယူနစ်မဲ့}} drawing ကို စာရွက်၏ unit အဖြစ် ယူဆ: ISO စာရွက်တွင် မီလီမီတာ၊ US စာရွက်တွင် လက်မ။

## ပေနှင့် လက်မ၊ နှင့် အပိုင်းကိန်းများ

Length များကို **ရေးပုံနှင့် ရိုက်ပုံ** သည် သီးခြား ဆက်တင်တစ်ခု ဖြစ်သည်: length format။ Geometry မပြောင်း၊ ဂဏန်းများ ပုံနှင့် ရိုက်နိုင်သည်သာ ပြောင်း။

1. ဘာမျှ မရွေးထားစေရန် {{ui:မော်ဒယ်}} tab ပေါ်တွင် {{key:Esc}} ကို နှိပ်။
2. {{ui:လက်ရှိ ဆက်တင်များ}} တွင် {{ui:အရှည် ပုံစံ}} ကို ရွေး: {{ui:ဒသမ}} (`150.5`)၊ {{ui:ဗိသုကာ}} (`12'-6 1/2"`)၊ {{ui:အင်ဂျင်နီယာ}} (`12'-6.5"`)၊ {{ui:အပိုင်းကိန်း}} (`150 1/2`) သို့မဟုတ် {{ui:သိပ္ပံ}} (`1.505E+02`)။
3. {{ui:တိကျမှု}} ကို ရွေး: ဒသမနေရာများ၊ သို့မဟုတ် အသေးဆုံး အပိုင်းကိန်း (ဗိသုကာအတွက် 1/16 က သာမန်ရွေးချယ်မှု)။

သို့မဟုတ် {{cmd:UNITS}} (`UN`) ရိုက်ပြီး သူ၏ မေးခွန်းနှစ်ခုကို ဖြေ။

{{ui:ဗိသုကာ}} သို့မဟုတ် {{ui:အင်ဂျင်နီယာ}} ဖြင့် drawing unit တစ်ခုသည် လက်မတစ်ခု ဖြစ်၊ AutoCAD ကဲ့သို့: {{ui:ယူနစ်များ}} ကို {{ui:လက်မ}} သို့ ထားပါ။ ထို့နောက် အကွာအဝေး သို့မဟုတ် အတိုင်းအတာ မေးသည့် နေရာတိုင်းတွင်နှင့် {{ui:ဂုဏ်သတ္တိများ}} ကွက်များတွင် ပေနှင့် လက်မဖြင့် ရိုက်နိုင်:

| သင်ရိုက်သည် | ဆိုလိုသည် |
|---|---|
| `12'6"` သို့မဟုတ် `12'-6"` | ပေ 12 လက်မ 6 (150) |
| `12'6-1/2"` | ပေ 12 လက်မ 6½။ အပိုင်းကိန်းရှေ့တွင် hyphen သုံး: {{key:Space}} သည် command line တွင် {{key:Enter}} ဖြစ်သည်။ |
| `12'` | ပေ 12 |
| `6"` သို့မဟုတ် `6` | လက်မ 6: ရိုးရိုး ဂဏန်းသည် လက်မ ဖြစ်သည် |
| `1/2`၊ `6-1/2` | အပိုင်းကိန်းများသည် format မည်သည့်အရာမဆို အလုပ်လုပ် |

Point များသည် အလားတူ အရှည်များ ယူ: `@12'6",0` သို့မဟုတ် `@10'<90`။ ထောင့်များ ဒီဂရီအတိုင်း ရှိ။

Format သည် history ({{cmd:DIST}}၊ {{cmd:ID}}၊ {{cmd:LIST}}၊ {{cmd:AREA}}: ဧရိယာများကို စတုရန်းလက်မ နှင့် စတုရန်းပေ)၊ {{ui:ဂုဏ်သတ္တိများ}}၊ status bar ရှိ coordinate များနှင့် **dimension အသစ်များ** တွင် ပြ။ Sheet များသည် ၎င်းတို့ စာရွက် unit (မီလီမီတာ သို့မဟုတ် လက်မ) ကို ဒသမအဖြစ် ထိန်း။

:::note
Length format ကို DWG နှင့် DXF ဖိုင်များတွင် သိမ်းသည်၊ dimension တစ်ခုစီက ကိုယ်ပိုင် ထား: သိမ်းထားသော drawing သည် သင်ထားခဲ့သည့်အတိုင်း ပြန်ဖွင့်။
:::

## စာရွက် အရွယ်များ

Sheet နှင့် model plot များသည် ဤအရွယ်များကို အတိုင်း အလျား သို့မဟုတ် အကျယ် ဘက်မဆို သုံး:

| စာရွက် | အရွယ် | စာရွက်ပေါ် unit |
|---|---|---|
| ISO A4 | 297 × 210 mm | မီလီမီတာ |
| ISO A3 | 420 × 297 mm | မီလီမီတာ |
| ISO A2 | 594 × 420 mm | မီလီမီတာ |
| ISO A1 | 841 × 594 mm | မီလီမီတာ |
| ISO A0 | 1189 × 841 mm | မီလီမီတာ |
| Letter | 11 × 8.5 in | လက်မ |
| Legal | 14 × 8.5 in | လက်မ |
| Tabloid / ANSI B | 17 × 11 in | လက်မ |
| ANSI C | 22 × 17 in | လက်မ |
| ANSI D | 34 × 22 in | လက်မ |
| ARCH C | 24 × 18 in | လက်မ |
| ARCH D | 36 × 24 in | လက်မ |
| ARCH E | 48 × 36 in | လက်မ |

Sheet အသစ်များသည် metric နှင့် unitless drawing များအတွက် ISO A3 မှ စတင်၊ လက်မ သို့မဟုတ် ပေဖြင့် drawing များအတွက် Tabloid မှ စတင်။ Model plot များသည် ISO A4 သို့မဟုတ် Letter မှ တူညီစွာ စတင်ပြီး နောက်ဆုံးရွေးချယ်မှုကို မှတ်ထား။ ဖွင့်ထားသော ဖိုင်များမှ sheet များသည် ၎င်းတို့ကိုယ်ပိုင် အရွယ်ကို ထိန်း၊ ဤစာရင်းထဲမပါလျှင် "Custom" ဟု ပြ။

## Scale များ

`1:n` scale သည် စာရွက်ပေါ်ရှိ unit တစ်ခုသည် model ထဲ၌ တူညီသော unit n ခုကို ပြသည်ဆိုလိုသည်၊ ထို့ကြောင့် 1:100 သည် အဆောက်အအုံ 1 m ကို စာရွက်ပေါ် 10 mm အဖြစ် ပြ။ CadCraft က drawing unit နှင့် စာရွက် unit မှ ဤအရာကို တွက်သည်။

**Metric scale များ**၊ drawing တိုင်းအတွက် ပေးသည်: 10:1၊ 5:1၊ 2:1၊ 1:1၊ 1:2၊ 1:5၊ 1:10၊ 1:20၊ 1:25၊ 1:50၊ 1:100၊ 1:200၊ 1:250၊ 1:500၊ 1:1000၊ 1:1250၊ 1:2000၊ 1:2500၊ 1:5000၊ 1:10000။

**Architectural scale များ**၊ unit များ လက်မ သို့မဟုတ် ပေ ဖြစ်သောအခါ ပေးသည်: 3" = 1'-0"၊ 1-1/2" = 1'-0"၊ 1" = 1'-0"၊ 3/4" = 1'-0"၊ 1/2" = 1'-0"၊ 3/8" = 1'-0"၊ 1/4" = 1'-0"၊ 3/16" = 1'-0"၊ 1/8" = 1'-0"၊ 3/32" = 1'-0"၊ 1/16" = 1'-0"။

**Engineering scale များ**၊ unit များ လက်မ သို့မဟုတ် ပေ ဖြစ်သောအခါ ပေးသည်: 1" = 10'၊ 1" = 20'၊ 1" = 30'၊ 1" = 40'၊ 1" = 50'၊ 1" = 100'။

**ကိုယ်ပိုင် scale များ။** `SCALELISTEDIT` (သို့မဟုတ် `SCALELIST`) ရိုက်ပြီး သင့် scale ထည့်၊ ဥပမာ 1:75 သို့မဟုတ် site scale 2 စာရွက် : 300 drawing။ `Add` က အမည်ကို မေး၊ ထို့နောက် စာရွက် unit နှင့် drawing unit (`1:75` ကဲ့သို့ အမည်က ကိုယ်ပိုင် ဂဏန်းများ ပေးသည်; {{key:Enter}} ကို နှိပ်၍ ထိုဂဏန်းများ ယူ)။ `Edit`၊ `Delete`၊ `List` နှင့် `Reset` က တူညီသော စာရင်းပေါ်တွင် အလုပ်လုပ်; `Reset` က စံစာရင်းသို့ ပြန်။ သင့် scale များသည် Properties ၏ viewport scale စာရင်းနှင့် {{ui:PDF သို့ ပလော့ရန်}} dialog တွင် စံများ၏ နောက်တွင် ပေါ်၊ ထို scale ရှိ viewport သည် ၎င်း၏ နာမည်ဖြင့် ဖတ်၊ ၎င်းတို့ကို drawing (DWG နှင့် DXF 2000) တွင် drawing ၏ scale စာရင်းအဖြစ် သိမ်း။ အခြား program မှ ဖွင့်သော drawing သည် ၎င်း၏စာရင်းကို ယူလာ၊ စံတစ်ခုနှင့် ကိုက်သော scale များကို နှစ်ကြိမ် မပြ။

{{ui:မော်ဒယ် အားလုံး ပြရန်}} သို့မဟုတ် {{ui:မော်ဒယ်ပေါ်တွင် ဘောင်တစ်ခု ရွေးပါ…}} ဖြင့် viewport ကို ချိန်သည့်အခါ CadCraft က ကိုက်သော အကြီးဆုံး စံ scale ကို ရွေး။ {{ui:မော်ဒယ် အားလုံး ကိုက်ညီရန်}} က အတိအကျ scale ကို သတ်မှတ်၊ ၎င်းက သာမန် အချိုးအစား အဖြစ် ပြ။

## စာရွက်ပေါ်နှင့် model ထဲရှိ အရွယ်အစားများ

စာသားနှင့် dimension အရွယ်အစားများသည် သင် ဆွဲသည့် space ၏ unit များဖြစ်သည်။

| စာရွက်ပေါ်တွင် လိုချင်သည် | Sheet ပေါ်တွင် ဆွဲ | Model တွင် 1:50 (mm drawing) | Model တွင် 1/4" = 1'-0" (inch drawing) |
|---|---|---|---|
| 2.5 mm စာသား | 2.5 | 125 | — |
| 3/32" စာသား | 0.09375 | — | 4.5 |

Dimension များအတွက်၊ အရွယ်အစားများကို စာရွက်အရွယ်အဖြစ် ထိန်းပြီး overall scale ({{cmd:DIMSCALE}}) ကို plot scale သို့ သတ်မှတ်: 1:50 အတွက် 50၊ 1/4" = 1'-0" အတွက် 48။ See [dimension အရွယ်အစားများ သတ်မှတ်ခြင်း](topic:dimension-settings)။

## Scale အလိုက် မှတ်ချက်ရေးခြင်း

Model ကို အပြည့်အစားဖြင့် ဆွဲပြီး အထက်ပါ ပေါင်းခြင်းများကို CadCraft က လုပ်ပေးစေ။

1. စာရွက်ပေါ်တွင် အရွယ်ထိန်းရမည့် စာသား သို့မဟုတ် dimension များကို ရွေး။ {{ui:Properties}} တွင် ဖော်ပြ မဟုတ်ဘဲ {{ui:Annotative}} ကို အမှတ်ခြစ်။ {{ui:စာရွက်ပေါ်ရှိ အရွယ်အစား}} က ဥပမာ `2.5 mm at 1:50` ဟု ဖတ်ပြ။
2. {{cmd:ANNOSCALE}} ရိုက်ပြီး drawing ကို print ထုတ်မည့် scale ကို ရိုက်၊ ဥပမာ `1:100`။

Annotative စာသားနှင့် dimension တိုင်းကို scale အသစ်တွင် တူညီသော အရွယ်ဖြင့် print ထွက်စေရန် ပြန်ညှိ: 2.5 mm စာသားသည် မီလီမီတာ drawing တွင် 1:50 တွင် 125 အမြင့်၊ 1:100 တွင် 250 အမြင့်။ Paragraph ၏ အကျယ်လည်း ပြောင်း၊ dimension ၏ စာသား၊ မြားနှင့် gap များ အတူ ပြောင်း (၎င်းတို့၏ overall scale)။ Undo အဆင့် တစ်ခု၊ annotative မဟုတ်သော object များ ဘယ်တော့မှ မပြောင်း။

ဤဆက်တင်ကို DWG နှင့် DXF တွင် သိမ်း: အခြား program များက annotative အလံကို ဖတ်၊ CadCraft က object တစ်ခုစီ အရွယ်ညှိထားသော scale ကိုလည်း ထိန်း။

အသင့်ရုံးက Default Policies add-on (ဆက်တင်များ › Global › Default Policies › Annotation sizes on paper) တွင် စာရွက်အမြင့်များ သတ်မှတ်ထားလျှင် {{cmd:ANNOSCALE}} က ထို scale ရှိ မှတ်ချက်များအတွက် ရုံး၏ အမြင့်ကို စာသားအသစ် စတင်သော အမြင့်အဖြစ် ထား။ See [Default Policies](topic:default-policies)။

### Object တစ်ခု scale အများအပြား

Sheet တစ်ခုသည် မှတ်တမ်း အစိတ်အပိုင်းကို 1:100 နှင့် တစ်စိတ်တစ်ပိုင်းကို 1:50 ဖြင့် မကြာခဏ ပြ။ မှတ်ချက်များနှင့် dimension များကို scale နှစ်ခုလုံး ပေးပြီး viewport တစ်ခုစီက စာရွက်အရွယ်ဖြင့် ပြ:

1. Annotative စာသားနှင့် dimension များကို ရွေး၍ `OBJECTSCALE` ရိုက်။
2. `Add` ကို ရွေး၍ scale ရိုက်၊ ဥပမာ `1:50`။ (`Current scale` က drawing ၏ annotation scale ကို ထည့်၊ `List` က object တစ်ခုစီ ထိန်းသော scale များကို ပြ၊ `Delete` က တစ်ခုကို ဖယ်။)

Object ၏ စာရင်းတွင် scale ရှိသော viewport သည် ထို scale အတွက် အရွယ်ဖြင့် object ကို ပြ: 2.5 mm စာသား သည် 1:100 viewport တွင် 250 အမြင့်၊ 1:50 တွင် 125 အမြင့်၊ မျက်နှာပြင်နှင့် plot နှစ်ခုစလုံး။ Object သည် နေရာတွင် ရှိ; အရွယ်ကသာ ကွဲ။ စာရင်းတွင် မပါသော scale ရှိ viewport တွင် object သည် ၎င်း ရှိသည့် အရွယ်ဖြင့် ပြ၊ `ANNOALLVISIBLE` ရိုက်ပြီး `OFF` ကို ရွေးသည်အထိ: ထိုအခါ ထိုနေရာတွင် ချန်ထား။ {{cmd:ANNOSCALE}} က scale အသစ်ကို စာရင်းထဲထည့်ထားသော object များကို ပြောင်းပြီး အခြားတွင် မပြောင်း။

စာရင်းများကို DWG နှင့် DXF တွင် CadCraft ၏ကိုယ်ပိုင် data အဖြစ် သိမ်း။ အခြား program က object တစ်ခုစီကို annotative၊ ညှိထားသော scale တစ်ခုတည်းဖြင့် မြင်။ ANNOALLVISIBLE ခလုတ်ကို ဖိုင်တွင် မသိမ်း။

## မျဉ်းအထူနှင့် linetype များ

Layer သို့မဟုတ် object တစ်ခုတွင် **{{ui:မျဉ်းအထူ}}** (0.05 မှ 2.11 mm) နှင့် **{{ui:လိုင်းအမျိုးအစား}}** (dashed၊ hidden၊ center၊ phantom၊ dot…) ရှိနိုင်။ Right panel တွင် သတ်မှတ်: ဘာမျှ မရွေးထားလျှင် {{ui:လက်ရှိ ဆက်တင်များ}} အောက်ရှိ {{ui:လိုင်းအမျိုးအစား}} နှင့် {{ui:မျဉ်းအထူ}} က object အသစ်များ ရမည့်အရာ ({{ui:လေယာအလိုက်}} ဖြင့် layer ကို လိုက်)၊ နှင့် {{ui:လေယာ}} အောက်ရှိ နှစ်ခုက current layer ၏ ကိုယ်ပိုင်။ Object များ ရွေးထားလျှင် တူညီသော အတန်းနှစ်ခုနှင့် {{ui:လိုင်းအမျိုးအစား စကေး}} က ထို object များကို ပြောင်း။ Command များမှာ {{cmd:LINETYPE}} (`LT`)၊ {{cmd:LWEIGHT}} (`LW`) နှင့် {{cmd:LTSCALE}} (`LTS`)။

Linetype များကို မျက်နှာပြင်နှင့် plot တွင် ပြ။ ၎င်းတို့၏ dash များသည် drawing unit ဖြင့်၊ metric drawing တွင် ISO အရွယ် (DASHED: 12.7 mm dash)၊ လက်မ drawing တွင် လက်မအရွယ် (0.5")။ Dash များ သေးလွန်း သို့မဟုတ် ကြီးလွန်းလျှင် drawing ၏ {{ui:လိုင်းအမျိုးအစား စကေး}} (LTSCALE) ကို ပြောင်း: dash နှင့် gap တိုင်းကို ၎င်းဖြင့် မြှောက်; object ၏ scale ကလည်း ထပ်မြှောက်။ မမြင်နိုင်လောက်အောင် သေးသော pattern ကို မျဉ်းတစ်ကြောင်းအဖြစ် ဆွဲ။

Lineweight များကို plot တွင် ရိုက်ထုတ်၊ scale မရွေး စာရွက်ပေါ်တွင် mm ဖြင့်။ {{ui:Default}} lineweight ရှိသော လိုင်းများသည် {{ui:PDF သို့ ပလော့ရန်}} dialog တွင် ရွေးထားသော ပင်အကျယ် (0.13 မှ 0.70 mm; အစတွင် 0.25 mm) ကို သုံး; lineweight 0 က ပါးဆုံး မျဉ်းအဖြစ် ရိုက်။ Screen တွင် status bar ရှိ {{ui:LWT}} ကို နှိပ်သည်အထိ (သို့မဟုတ် {{cmd:LWDISPLAY}} ရိုက်) မျဉ်းတိုင်းသည် ပိုဆယ်ပု တစ်ပစ်ဆယ်; ထို့နောက် 0.25 mm ကျော်သော lineweight သည် model တွင် ပိုကျယ် ဆွဲ (0.5 mm = 2 pixel)၊ sheet တွင် စာရွက်ပေါ် အမှန်အထူ။ ရွေးချယ်မှုကို ဤ browser တွင် ထိန်း။

## ရုံး၏ စံ

ရုံးတစ်ခုသည် ၎င်း၏ စာရွက်ပေါ် စာသားအမြင့်များ၊ layer များ၊ title block field များနှင့် template များကို record တစ်ခုတည်းတွင် ထိန်းနိုင်၊ ရုံး၏ စံ။ CadCraft က ဤအစီအစဉ်ဖြင့် ဖတ်: drawing ၏ ကိုယ်ပိုင် record ({{cmd:OFFICESTANDARD}} › `Import` ဖြင့် သတ်မှတ်၊ ဖိုင်တွင် ထိန်း)၊ ထို့နောက် သင့်အဖွဲ့၏ မျှဝေထားသော စံ၊ နောက်ဆုံး သင့် Default Policies။ Annotative စာသားနှင့် dimension များသည် annotation scale တွင် ၎င်းမှ စာရွက်အမြင့် ယူ။ စံ ဗလာဖြစ်လျှင် ဘာမျှ မပြောင်း။ {{cmd:OFFICESTANDARD}} › `Layers` က drawing တွင် ပျောက်နေသော ရုံး layer များ ထည့်။
