စာကြည့်တိုက်၏ {{ui:Standard}} tab တွင် အမျိုးအစား နှစ်မျိုး ရှိသည်၊ ၎င်းတို့ကို ဤနေရာတွင် ထုတ်ပြန်ထားသော ဇယားများမှ တိုက်ရိုက် ဖန်တီးထားသည် (ဘာမျှ ဒေါင်းလုဒ် မဆွဲရ):

- **သံမဏိ section များ**: အရွယ် 1,335 မျိုး။ W၊ S၊ C၊ L၊ HSS နှင့် Pipe တို့သည် AISC Shapes Database v16.0 မှ; IPE၊ HEA၊ HEB နှင့် UPN တို့သည် EN 10365:2017 မှ။ DetailCraft သည် တူညီသော ဇယားကို သုံးသည်။
- **စံ အစိတ်အပိုင်းများ**: hex head screws (ISO 4017)၊ hex bolts (ISO 4014)၊ hex nuts (ISO 4032)၊ plain washers (ISO 7089)၊ inch hex bolts and nuts (ASME B18.2.1 and B18.2.2)၊ parallel pins (ISO 2338)၊ deep groove ball bearings (ISO 15)၊ parallel keys (DIN 6885-1) နှင့် spur gears (ISO 54 မှ modules)။

ဤအရာအားလုံးကို CC0 အောက်တွင် မျှဝေထားသည်: မည်သည့်အတွက်မဆို အသုံးပြုနိုင်ပြီး credit မလို။

## သံမဏိ section တစ်ခုကို နေရာချခြင်း

1. စာကြည့်တိုက် ({{ui:Library}} ကို Blocks အုပ်စုတွင်၊ သို့မဟုတ် `LIB` ကို ရိုက်ပါ) ကို ဖွင့်ပြီး {{ui:Standard}} tab ကို နှိပ်ပါ။
2. ပထမ list တွင် မိသားစုကို ရွေးပါ၊ ဥပမာ {{ui:W ပုံသဏ္ဍာန်များ}}။ အရွယ်အစားများ ကျဉ်းမြောင်းရန် search box တွင် ရိုက်ပါ: `W12` ဆိုလျှင် W12 အားလုံး ပြသသည်။
3. {{ui:ဤအဖြစ် နေရာချ}} တွင် ရွေးပါ:
   - {{ui:အပိုင်းဖြတ်}}: cross-section၊ ၎င်း၏ ဗဟိုသည် insertion point တွင် ရှိသည်။
   - {{ui:အမြင့်အဆင့်}}: အဖွဲ့ဝင်ကို ဘေးမှ မြင်ရသည့်ပုံ၊ {{ui:အလျား (mm)}} ပြသသည့် အလျားရှိပြီး ဘယ်ဘက်အဆုံး၏ အလယ်မှ စသည်။
   - {{ui:3D member}}: 3D tab (အောက်တွင်) ပေါ်ရှိ solid။
4. အရွယ်အစား card ပေါ်ရှိ {{ui:နေရာချရန်}} ကို နှိပ်ပြီး နေရာကို နှိပ်ပါ၊ library item အားလုံးနည်းတူ။

section သို့မဟုတ် elevation သည် block ဖြစ်လာသည်။ ၎င်း၏ attribute များတွင် အရွယ်အစား၊ ၎င်းမှ ဇယား၊ (elevation အတွက်) အလျားနှင့် ဖြည့်နိုင်သော material ပါဝင်သည်။

:::note
S shape၊ channel နှင့် UPN များကို ပျမ်းမျှ အထူရှိသော အပြိုင် flange များဖြင့် ဆွဲပြီး angle များကို ထောင့်မှန်ဖြင့် ဆွဲသည်: အမှန်တကယ် flange များသည် စောင်းပြီး ထောင့်များ ဝိုင်းသည်။ W၊ IPE၊ HEA နှင့် HEB တွင် root fillet ရှိပြီး HSS တွင် corner radius ရှိသည်။
:::

## 3D member ဖန်တီးခြင်း

{{ui:3D member}} ကို ရွေးပြီး {{ui:နေရာချရန်}} ကို နှိပ်ပါ၊ သို့မဟုတ် command line တွင် {{cmd:STEELMEMBER}} (`SMEMBER`) ကို ရိုက်ပါ:

1. `Section size` တွင် ပြသထားသော အရွယ်အတွက် {{key:Enter}} ကို ဖိပါ၊ သို့မဟုတ် တစ်ခု ရိုက်ပါ၊ ဥပမာ `HSS6x6x1/4` သို့မဟုတ် `IPE300`။
2. စတင်အမှတ်ကို နှိပ်ပြီး ထို့နောက် အဆုံးအမှတ်ကို နှိပ်ပါ။ အဖွဲ့ဝင်သည် ၎င်းတို့ကြားတွင် ပြေးပြီး မြေပေါ်တွင် ထိုင်သည်။
3. ကော်လံအတွက် `C` ကို ရိုက်ပြီး ၎င်း၏ base point ကို နှိပ်ကာ အမြင့်ကို ရိုက်ပါ။

member သည် 3D tab ပေါ်ရှိ ပိတ်ထားသော solid ဖြစ်သည်။ ထို tab တွင် အခြား solid ကဲ့သို့ ရွှေ့ သို့မဟုတ် ကူးနိုင်သည်။ {{key:Mod+Z}} ဖြင့် ပြန်ဖျက်နိုင်သည်။

## စံ အစိတ်အပိုင်း တစ်ခုကို နေရာချခြင်း

1. {{ui:Standard}} tab တွင် မိသားစုကို ရွေးပါ၊ ဥပမာ {{ui:ခေါင်းဟက်ဆဂွန် ဝက်အူများ}}။
2. ဝက်အူ၊ bolt၊ pin သို့မဟုတ် key အတွက် {{ui:အလျား (mm)}} ကို ရိုက်ပါ (inch မိသားစုများအတွက် inch)။ gear အတွက် {{ui:သွားများ}}၊ {{ui:မျက်နှာပြင် အကျယ် (mm)}} နှင့် {{ui:အပေါက် (mm)}} ကို ရိုက်ပါ။ အကွက်ကို ဗလာထားလျှင် ပြထားသော ပုံမှန်တန်ဖိုးကို သုံးသည်။
3. အရွယ်ပေါ်ရှိ {{ui:နေရာချရန်}} ကို နှိပ်ပြီး နေရာကို နှိပ်ပါ။

ဝက်အူ၊ bolt နှင့် pin များကို ဘေးမှ ဆွဲသည်၊ ခေါင်း၏ bearing face သည် insertion point တွင် ရှိသည်; nut၊ washer၊ bearing နှင့် gear များကို မျက်နှာချင်းဆိုင် ဆွဲသည်; key များကို အပေါ်မှ ဆွဲသည်။ Thread များကို သာမန်နည်းဖြင့် ဆွဲသည်: root ကို ပါးလွှာသော မျဉ်းအဖြစ်၊ thread ၏ အဆုံးကို ထူသော မျဉ်းအဖြစ်။ Gear များကို သွားတစ်ခုချင်းစီ မဟုတ်ဘဲ tip circle၊ pitch circle နှင့် root circle အဖြစ် ဆွဲသည်။

အစိတ်အပိုင်းတစ်ခုစီ၏ block တွင် ၎င်း၏ အမျိုးအစား၊ စံ၊ အရွယ်၊ အလျားနှင့် material ကို attribute အဖြစ် ထားရှိပြီး၊ သံမဏိအတွက် nominal ပုံသဏ္ဍာန်မှ အလေးချိန်ကို ထည့်သည်။ Material ကို {{ui:ဂုဏ်သတ္တိများ}} panel တွင် ပြောင်းပါ။

အတူတူ အစိတ်အပိုင်းများသည် Library တွင် item အဖြစ်လည်း ရှိပြီး PartCraft က ၎င်းတို့ကို parametric part အဖြစ် ဖွင့်သည် ({{ui:စံ အစိတ်အပိုင်း}} ၏ File အုပ်စုတွင်)။

## Parts list ဖန်တီးခြင်း

- စာကြည့်တိုက်တွင် {{ui:အစိတ်အပိုင်း စာရင်း}} ကို နှိပ်ပါ: ပုံဆွဲရှိ စံ အစိတ်အပိုင်းနှင့် သံမဏိ section အားလုံး၊ အမျိုးအစား၊ စံ၊ အရွယ်၊ အလျားနှင့် material အလိုက် အုပ်စုဖွဲ့ထားပြီး အရေအတွက်နှင့် item နံပါတ်များ ပါဝင်သည်။ {{ui:CSV ဒေါင်းလုဒ်ဆွဲရန်}} သည် spreadsheet အတွက် သိမ်းသည်။
- ဆွဲရန် {{cmd:PARTSLIST}} (`PLIST`) ကို ရိုက်ပြီး ဇယား၏ ဘယ်ဘက်အပေါ်ထောင့်ကို နှိပ်ကာ {{key:Enter}} ကို ဖိပါ (ပုံမှန် စာသားအမြင့်အတွက်) သို့မဟုတ် တစ်ခု ရိုက်ပါ။

စာရင်းကို block များ၏ attribute မှ ဖတ်သဖြင့် ပုံဆွဲကို DWG သို့မဟုတ် DXF အဖြစ် သိမ်းပြီး ပြန်ဖွင့်သည့်အခါတွင်လည်း မှန်ကန်နေသည်။

## အဖြစ်များသော အမှားများ

- **"No steel section is called …"**: {{ui:Standard}} tab က စာရင်းပြသထားသည့် ပုံစံအတိုင်း အရွယ်ကို ရိုက်ပါ: `W12x26`၊ `L4x4x1/2`၊ `HSS6.625x0.280`၊ `Pipe4STD`၊ `IPE300`။
- **အဖွဲ့ဝင်သည် 3D tab တွင်ရှိသည်၊ ပလန်တွင် မရှိပါ။** {{cmd:STEELMEMBER}} သည် solid ဖန်တီးသည်; မြင်ရန် 3D tab ကို ဖွင့်ပါ။ ပလန်တွင် သံမဏိကို ပြရန် {{ui:အပိုင်းဖြတ်}} သို့မဟုတ် {{ui:အမြင့်အဆင့်}} ကိုပါ နေရာချပါ။
- **အလျား နယ်ပယ်ပြင်ပ။** bolt သည် ၎င်း၏ ခေါင်းထက် ရှည်ရမည်၊ key သည် ၎င်း၏ အကျယ်ထက် ရှည်ရမည်။ ကဒ်အောက်ရှိ စာကြောင်းက ငြင်းပယ်ခံရသော တန်ဖိုးကို ပြောပြသည်။
