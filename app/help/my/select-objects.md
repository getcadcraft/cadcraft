## ဘာတွေ သိရမလဲ

command က လုပ်ဆောင်မည့် object များကို ဘယ်လို ရွေးရမလဲ။ CadCraft တွင် အလုပ်လုပ်ပုံ နည်းလမ်းနှစ်ခု ရှိပြီး နှစ်ခုလုံး သင့်တော်သည်:

- **အရင်ရွေး၊ ထို့နောက် command** (noun-verb)။ object များ ရွေးပြီး၊ ရွှေ့ရန် `M` ကို ရိုက်ပါ။ command သည် သင့်ရွေးချယ်မှုကို ယူပြီး နောက်မေးခွန်းသို့ တိုက်ရိုက် သွားသည်။
- **command အရင်၊ ထို့နောက် ရွေး** (verb-noun)။ `M` ရိုက်ပါ; command က `Select objects:` ဟု မေးသည်; ရွေးပြီး {{key:Enter}} ကို နှိပ်ပါ။

## object တစ်ခုချင်းစီ ရွေးရန်

1. command မလည်ပတ်နေချိန်တွင် မျဉ်းတစ်ကြောင်းကို နှိပ်ပါ။ ၎င်းကို အရောင်ထင်စေပြီး grip (အသေးစား စတုရန်းများ) ပေါ်လာသည်။ ညာဘက် panel တွင် ၎င်း၏ ဂုဏ်သတ္တိများကို ပြသသည်။
2. အခြား object တစ်ခုကို နှိပ်ပါ။ ၎င်းကို ရွေးချယ်မှုထဲသို့ ထည့်သည်။
3. {{key:Shift}} ကိုင်ထားပြီး ရွေးပြီးသား object ကို နှိပ်ပါ။ ၎င်းကို ရွေးချယ်မှုမှ ဖယ်သည်။
4. {{key:Esc}} ကို နှိပ်ပါ။ ဘာမျှ မရွေးတော့ပါ။

## ဘောင်နှင့် ဖြတ်ကျော်

လွတ်သောနေရာတွင် တစ်ကြိမ်နှိပ်၊ ရွှေ့၊ ထပ်နှိပ်: စတုဂံ။ နှိပ်ပြီး ဆွဲလျှင် အစား လွတ်လပ်စွာ ဆွဲသော lasso ကို ဆွဲသည်၊ အမျိုးအစား နှစ်မျိုးတူတူဖြင့် ([Lasso selection](topic:lasso-selection) ကို ကြည့်ပါ; Settings တွင် ဆွဲခြင်းကို စတုဂံဖြစ်စေနိုင်သည်)။ ရရှိမည့် object များသည် ဦးတည်ချက်ပေါ်တွင် မူတည်သည်:

| သင် ရွှေ့သည် | Box | ရွေးသည် |
|---|---|---|
| ဘယ်မှ ညာ | Window | ဘောင်အတွင်း **လုံးလုံးလျားလျား** ရှိသော object များသာ |
| ညာမှ ဘယ် | Crossing | ဘောင်အတွင်းရှိ object များ **နှင့်** ၎င်းထိသော object များ |

1. ထပ်နေသော မျဉ်းနှင့် အဝိုင်းအချို့ ဆွဲပါ။
2. object အချို့၏ ဘယ်ဘက်ရှိ လွတ်သောနေရာကို နှိပ်ပါ၊ ညာသို့ ရွှေ့ပြီး ထပ်နှိပ်ပါ။ လုံးလုံးလျားလျား အတွင်းရှိ object များသာ ရွေးချယ်သည်။
3. {{key:Esc}} ကို နှိပ်ပါ။
4. ညာဘက်ရှိ လွတ်သောနေရာကို နှိပ်ပါ၊ object အချို့ကို ဖြတ်၍ ဘယ်သို့ ရွှေ့ပြီး ထပ်နှိပ်ပါ။ ဘောင်ထိသမျှ အရာအားလုံး ရွေးချယ်သည်။
5. {{key:Shift}} ကိုင်ထား၍ ရွေးပြီးသား object အချို့အပေါ် ဘောင် သို့မဟုတ် lasso ဆွဲပါ။ ၎င်းတို့ ရွေးချယ်မှုမှ ထွက်သည်။

## ရွေးပြီး command run ရန်

1. object နှစ်ခု (အဝိုင်းနှစ်ခု) ရွေးပါ။
2. `M` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။

history တွင် `2 found` ဟု ပြသပြီး prompt သည် `Specify base point` သို့ တိုက်ရိုက် သွားသည်။ ရွှေ့ခြင်းကို ပြီးအောင် လုပ်ပါ (ကြည့်ပါ [Move, copy, rotate, scale and mirror](topic:modify-objects))။

command ပြီးသောအခါ ရွေးချယ်မှု ရှင်းသွားသောကြောင့် နောက် command သည် အသစ်စတင်သည်။

ဤနည်းဖြင့် ရွေးချယ်မှု ယူသော command များ: {{cmd:ERASE}}၊ {{cmd:MOVE}}၊ {{cmd:COPY}}၊ {{cmd:ROTATE}}၊ {{cmd:SCALE}}၊ {{cmd:MIRROR}}၊ {{cmd:EXPLODE}}၊ {{cmd:BLOCK}} နှင့် {{cmd:LIST}}။ {{cmd:OFFSET}}၊ {{cmd:FILLET}} နှင့် {{cmd:CHAMFER}} သည် အမြဲတမ်း object တစ်ခုချင်းစီ ရွေးရန် တောင်းဆိုသည်; {{cmd:TRIM}} နှင့် {{cmd:EXTEND}} သည် ရွေးချယ်ခြင်း သို့မဟုတ် အပိုင်းများကို ဖြတ်သွားသော လမ်းကြောင်း (ဆွဲ) ကို ယူသည် (ကြည့်ပါ [Trim and extend](topic:trim-and-extend))။

## command run ပြီး ရွေးရန်

1. ဘာမျှ မရွေးထားကြောင်း သေချာပါစေ ({{key:Esc}})။
2. `E` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။ prompt က `Select objects:` ဟု ဖတ်သည်။
3. object များကို နှိပ်ပါ၊ သို့မဟုတ် ဘောင်များနှင့် ဖြတ်ကျော်မှုများကို ဆွဲပါ။ history သည် ရွေးချက်တိုင်းကို ရေတွက်သည် (`1 found`, `3 found`)။
4. ရွေးချယ်မှု ပြီးဆုံးရန် {{key:Enter}}၊ {{key:Space}} သို့မဟုတ် ညာကလစ်ကို နှိပ်ပါ။

object များကို ဖျက်ပြီး history က မည်မျှဖြစ်ကြောင်း ပြောသည်။

`Select objects:` prompt တွင် ရိုက်နိုင်သည်များ:

- `ALL` ထို့နောက် {{key:Enter}}: ဖွင့်ထားသော tab တွင် တည်းဖြတ်နိုင်သော object အားလုံး။
- `L` (သို့မဟုတ် `LAST`) ထို့နောက် {{key:Enter}}: နောက်ဆုံး ဆွဲခဲ့သော object။
- `P` (Previous): နောက်ဆုံး command လုပ်ဆောင်ခဲ့သော object များ၊ ၎င်းတို့ ရှိနေဆဲ ဆိုလျှင်။
- `F` (Fence): မျဉ်းတစ်လျှောက် အမှတ်များကို နှိပ်ပါ သို့မဟုတ် ရိုက်ပါ; မျဉ်းဖြတ်သော object အားလုံး ထည့်သည်။ fence ကို ပိတ်ရန် {{key:Enter}} ကို နှိပ်ပါ; `U` သည် နောက်ဆုံးအမှတ်ကို ပြန်ယူသည်။
- `W` (Window) သို့မဟုတ် `C` (Crossing): ထောင့်နှစ်ခု၊ ဆွဲသော ဦးတည်ချက် မည်သည်ပင်ဖြစ်စေ။
- `R` (Remove): ယခုမှစ၍ နှိပ်ခြင်း၊ ဘောင်များနှင့် fence များက object များကို **ဖယ်ထုတ်သည်**။ prompt က `Remove objects:` ဟု ဖတ်သည်။ `A` (Add) ဖြင့် ပြန်ပြောင်းသည်။
- `?`: ဤအရာများ၏ စာရင်းကို history တွင် ပြသည်။

ဤရွေးချယ်စရာများကို AutoCAD ကဲ့သို့ prompt တွင် မပြပါ။

## ထပ်နေသော object များထဲမှ တစ်ခု ရွေးရန်

object များ ထပ်နေသည် သို့မဟုတ် ထိနေသောနေရာတွင် နှိပ်လျှင် အနီးဆုံးကို ယူသည်။ အခြားတစ်ခု ရရန်:

1. ညွှန်ပြကိရိယာကို နေရာပေါ်တွင် မလှုပ်ဘဲ ထားပါ။
2. {{key:Tab}} ကို နှိပ်ပါ။ ထိုနေရာရှိ နောက် object ကို အရောင်ထင်စေပြီး status bar က ၎င်းကို ပြောသည် ("2 of 3: Line on layer Walls")။
3. လိုချင်သော object အရောင်ထင်သည်အထိ {{key:Tab}} ကို ထပ်နှိပ်ပြီး၊ ထို့နောက် မရွှေ့ဘဲ နှိပ်ပါ။

ညွှန်ပြကိရိယာကို ရွှေ့လျှင် ပြန်စတင်သည်။ ဤအရာသည် command မလည်ပတ်နေချိန်၊ `Select objects:` တွင်နှင့် command က object တစ်ခု ရွေးရန် တောင်းဆိုသည့် နေရာတိုင်းတွင် အလုပ်လုပ်သည်။

## စည်းမျဉ်းဖြင့် ရွေး: အမြန်ရွေး

{{cmd:QSELECT}} (`QS`၊ သို့မဟုတ် {{ui:တည်းဖြတ်ရန်}} › {{ui:နောက်ထပ်}} › {{ui:အမြန်ရွေး}}) သည် စည်းမျဉ်းနှင့် ကိုက်ညီသော object အားလုံးကို ရွေးသည်၊ ဥပမာ အချင်းဝက် 50 အောက်ရှိ အဝိုင်းတိုင်း၊ သို့မဟုတ် DOOR-900 ဟု ခေါ်သော block reference တိုင်း။

1. {{ui:အမြန်ရွေး}} ကို ဖွင့်ပါ။
2. {{ui:အရာဝတ္ထုအမျိုးအစား}} ကို ရွေးပါ (list က အမျိုးအစားတစ်ခုစီကို ရေတွက်သည်)၊ ထို့နောက် {{ui:ဂုဏ်သတ္တိ}}: {{ui:လေယာ}}၊ {{ui:အရောင်}}၊ နှင့် အချို့အမျိုးအစားများအတွက် {{ui:အလျား}}၊ {{ui:အချင်းဝက်}}၊ {{ui:ဧရိယာ}}၊ {{ui:စာသားအမြင့်}}၊ {{ui:စာသားအကြောင်းအရာ}}၊ {{ui:ဘလောက်အမည်}} သို့မဟုတ် {{ui:ဖြည့်ပုံစံ}}။
3. {{ui:အော်ပရေတာ}} နှင့် {{ui:တန်ဖိုး}} ကို ရွေးပါ။ `*` သည် wildcard ဖြင့် ကိုက်ညီသည် (`DOOR-*`); {{ui:အားလုံးရွေးရန်}} သည် အမျိုးအစား၏ object အားလုံးကို ယူသည်။ အောက်ခြေရှိ အရေအတွက်က သင်ရွေးသည်နှင့်အမျှ ကိုက်ညီမည့် အရေအတွက်ကို ပြသည်။
4. {{ui:အသုံးပြုပုံ}}: ကိုက်ညီသည်များကို ထည့်ပါ၊ သို့မဟုတ် အခြားအရာအားလုံးကို ထည့်ပါ။ {{ui:အသုံးပြုရန်}} {{ui:လက်ရှိ ရွေးထားသည်}} သည် သင်ရွေးထားသည်ကို ကျဉ်းစေသည်; {{ui:လက်ရှိရွေးချယ်မှုသို့ ဆက်ထည့်ရန်}} သည် ၎င်းသို့ ထည့်သည်။
5. {{ui:ရွေးရန်}} ကို နှိပ်ပါ။ ထို့နောက် လိုချင်သော command ကို run ပါ: ၎င်းသည် ရွေးချယ်မှုကို သုံးသည်။

## တူသည်များ ရွေးရန်

object တစ်ခု သို့မဟုတ် ပို၍ ရွေးပြီး {{cmd:SELECTSIMILAR}} (`SIM`) ကို ရိုက်ပါ၊ သို့မဟုတ် {{ui:တည်းဖြတ်ရန်}} › {{ui:နောက်ထပ်}} › {{ui:တူသည်များ ရွေးရန်}} ကို ရွေးပါ။ အမျိုးအစားတူ၊ layer တူ၊ အရောင်တူသော object အားလုံး ရွေးသည်; block reference များသည် block တူရမည်၊ hatching များသည် pattern တူရမည်။ ကိုက်ညီရမည့်အရာကို ရွေးရန် `Select objects` prompt တွင် `SE` ရိုက်ပါ။

## ယခုရွေး၊ နောက်မှ သုံးရန်

`SELECT` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ၊ အထက်ပါနည်းလမ်းများဖြင့် object များ ရွေးပြီး {{key:Enter}} ကို နှိပ်ပါ။ ၎င်းတို့သည် နောက် command အတွက် ရွေးထားဆဲ ရှိနေမည်၊ နောက်ပိုင်း `Select objects:` prompt တွင် `P` ဖြင့် ပြန်ရွေးနိုင်သည်။

## အားလုံး ရွေးရန်

command မလည်ပတ်နေချိန်တွင် {{key:Mod+A}} ကို နှိပ်ပါ၊ သို့မဟုတ် ကိရိယာဘား၏ {{ui:တည်းဖြတ်ရန်}} › {{ui:နောက်ထပ်}} မီနူးတွင် {{ui:အားလုံးရွေးရန်}} ကို ရွေးပါ၊ ဖွင့်ထားသော tab တွင် တည်းဖြတ်နိုင်သော object အားလုံးကို ရွေးရန်။ command line တွင် တစ်စုံတစ်ခု ရိုက်ထားလျှင် {{key:Mod+A}} သည် ထိုစာသားကို ရွေးသည်: အရင် {{key:Esc}} ကို နှိပ်၍ ရှင်းပါ။ `Select objects:` prompt တွင် `ALL` ရိုက်ပါ။ တူညီသော မီနူးရှိ {{ui:မည်သည်မျှမရွေးရန်}} သို့မဟုတ် {{key:Esc}} သည် ရွေးချယ်မှုကို ရှင်းသည်။

:::tip
နှိပ်တိုင်း ရွေးချယ်မှုကို အစားထိုးစေချင်လျှင် (နှင့် {{key:Shift}} က ထည့်စေချင်လျှင်)၊ [CadCraft settings](topic:settings) တွင် {{ui:အရာဝတ္ထုများကို နှိပ်ခြင်း}} ကို {{ui:ရွေးချယ်မှုကို အစားထိုးသည်}} ဟု သတ်မှတ်ပါ။
:::

## ရွေး၍ မရသည်များ

- layer ၏ object များ **ပိတ်ထား**၊ **ခဲထား** သို့မဟုတ် **လော့ခ်ချထား**။ လော့ခ်ချထားသော object များသည် မြင်ရဆဲဖြစ်ပြီး ၎င်းတို့သို့ snap လုပ်နိုင်သော်လည်း ရွေးရန် သို့မဟုတ် ပြောင်းရန် မရနိုင်ပါ။
- စာရွက် tab ပေါ်တွင် viewport အတွင်း ပြထားသော မော်ဒယ်။ သင်သည် စာရွက်၏ ကိုယ်ပိုင် object များ (title block၊ မှတ်စုများ၊ viewport ဘောင်များ) ကို ရွေးသည်။ မော်ဒယ်ကို တည်းဖြတ်ရန် {{ui:Model}} tab သို့ သွားပါ။

## အမြန် ဖျက်ရန်

object များ ရွေးပြီး {{key:Delete}} ကို နှိပ်ပါ (command line တွင် cursor မရှိလျှင် {{key:Backspace}})။ Mac keyboard တွင် ပုံဆွဲကို နှိပ်ပြီးနောက် delete ဟု အမှတ်အသားရှိသော key က အလုပ်လုပ်သည်; command line တွင် cursor ရှိနေချိန် fn နှင့် delete ကို အတူနှိပ်ပါ။ ၎င်းသည် ရွေးချယ်မှုပေါ်တွင် {{cmd:ERASE}} ကို run သည်။ ဘာမျှ မဖြစ်လျှင် command line တွင် တစ်စုံတစ်ခု ရိုက်ထားခြင်း ဖြစ်သည်: {{key:Esc}} ကို နှိပ်ပါ၊ သို့မဟုတ် အစား `E` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။

## အများဆုံး ဖြစ်တတ်သော အမှားများ

- **ဘောင်က နည်းနည်းသာ ယူသည်။** ဘယ်မှ ညာသို့ ဆွဲခဲ့သဖြင့် လုံးလုံးလျားလျား အတွင်းရှိသာ ယူသည်။ ဖြတ်ကျော်ရန် ညာမှ ဘယ်သို့ ဆွဲပါ။
- **လွတ်သောနေရာ နှိပ်ခြင်းက ဘောက်စ်တစ်ခု စတင်သည်။** လွတ်သောနေရာ တစ်ကြိမ်နှိပ်ခြင်းက ဘောင်တစ်ခု စတင်သည်; ဒုတိယနှိပ်ခြင်းက ပြီးစီးစေသည်။ ဖျက်ရန် {{key:Esc}} သို့မဟုတ် ညာကလစ်ကို နှိပ်ပါ။
- **လွတ်သောနေရာ နှိပ်ခြင်းက ရွေးချယ်မှုကို လွှတ်လိုက်သည်။** {{key:Shift}} ကို မကိုင်ထားလျှင် ဟုတ်သည်။ ထိုနှိပ်ခြင်းတွင် ရွေးချယ်မှုကို ထိန်းပြီး {{key:Esc}} ဖြင့်သာ ရှင်းလိုလျှင် [CadCraft settings](topic:settings#clicking-an-empty-spot) တွင် {{ui:ဗလာနေရာကို နှိပ်ခြင်း}} ကို {{ui:ရွေးချယ်မှုကို ထိန်းသည်}} ဟု သတ်မှတ်ပါ။
- **command က သင်မရည်ရွယ်သော object များ သုံးခဲ့သည်။** စတင်ချိန်တွင် တစ်ခုခု ရွေးထားနေသေးသည်။ ဘာမျှ မရွေးဘဲ စတင်ရန် command မစခင် {{key:Esc}} ကို နှိပ်ပါ။
- **command ပြီးနောက် ဘာမျှ မရွေးထား။** ရည်ရွယ်ချက်ရှိသည်: ပြီးသော command သည် ရွေးချယ်မှုကို ရှင်းသည်။
