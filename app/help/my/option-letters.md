## ဘာကို သင်လေ့လာမလဲ

Command တစ်ခု၏ ရွေးချယ်စရာများကို ဖြေရန် ရိုက်သော အက္ခရာများကို ဘယ်လို ပြောင်းရမလဲ။ ဥပမာ {{cmd:ARRAY}} က `[Rectangular/POlar]` ကို မေးပြီး Polar အတွက် `PO` ကို လက်ခံ၊ `P` သို့မဟုတ် အခြားအက္ခရာများကို ထိုအလုပ်အတွက် လုပ်စေနိုင်; သင်နှစ်သက်လျှင် သင့်ဘာသာစကားဖြင့်လည်း လုပ်နိုင်။

## ရွေးချယ်စရာများ ဖြေပုံ

Command က ရွေးချယ်စရာများကို စတုရန်းကွင်းအတွင်း ပြသည့်အခါ၊ ရိုက်ရမည့် အက္ခရာများသည် အကြီးစာလုံးများ ဖြစ်သည်: `POlar` သည် `PO`၊ `eXit` သည် `X`။

အက္ခရာ အနည်းငယ်သာ ရိုက်နိုင်သည်။ ရိုက်သည်မှာ ပြထားသော ရွေးချယ်စရာ တစ်ခုတည်းနှင့် ကိုက်လျှင် CadCraft က ထိုအတိုင်း ယူ: `[Rectangular/POlar]` တွင် `P` တစ်လုံးသည် Polar ဖြစ်။ နှစ်ခုနှင့် ကိုက်လျှင် command line က ၎င်းတို့ကို ပြပြီး ထပ်မေး-

```
C could be COUnt, COLumns. Type more letters.
```

ဂဏန်းများကို ဘယ်တော့မှ ခန့်မှန်းမယူ၊ ထို့ကြောင့် ရိုက်သော အကွာအဝေး သို့မဟုတ် အရေအတွက်ကို အမြဲ ဂဏန်းအဖြစ် ဖတ်။

## ကိုယ်ပိုင် အက္ခရာ ထည့်ခြင်း

Command တိုင်းသည် built-in အက္ခရာများကို ထိန်းသည်။ သင်သည် ၎င်းတို့ အပေါ်တွင် ထပ်ထည့်သည်၊ ထို့ကြောင့် သင့်စာရင်းတွင် သင်ပြောင်းသည့်အရာများသာ ရှိ။

1. {{ui:ဆက်တင်များ}} ({{key:Mod+,}}) › {{ui:CadCraft}} › {{ui:ရွေးချယ်စရာ အက္ခရာများ}} ကို ဖွင့်ပြီး {{ui:တည်းဖြတ်…}} ကို နှိပ်။ သို့မဟုတ် `OPTIONKEYS` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်။
2. {{ui:Command}} အောက်တွင် command ကို ရွေး၊ ဥပမာ `ARRAY`။ စာရင်းတွင် ရွေးချယ်စရာ မေးသော command အားလုံး ပါပြီး နောက်ဆုံး သုံးခဲ့သော command မှ စသည်။
3. {{ui:ရွေးချယ်စရာ}} အောက်တွင် ရွေးချယ်စရာကို ရွေး။ တစ်ခုစီသည် built-in အက္ခရာများကို ကွင်းထဲ ပြ၊ ဥပမာ `POlar (PO)`။
4. {{ui:သင့်အက္ခရာများ}} တွင် လိုချင်သော အက္ခရာများ ရိုက်၊ ဥပမာ `P`၊ ထို့နောက် {{ui:ထပ်ထည့်ရန်}} ကို နှိပ်။
5. ရွေးချယ်စရာသည် {{ui:သင့်အက္ခရာများ}} အောက်တွင် built-in အက္ခရာနှင့် သင့်အက္ခရာများနှင့်အတူ ပေါ်။ {{ui:သိမ်းရန်}} ကို နှိပ်။

{{cmd:ARRAY}} ကို စတင်၊ object ရွေးပြီး {{key:Enter}} ကို နှိပ်။ Prompt က ရွေးချယ်စရာနောက်တွင် သင့်အက္ခရာများကို ပြ၊ `POlar (P)`၊ `P` က ဖြေသည်။

ဖယ်ရှားလိုလျှင် အတန်း၏ အဆုံးရှိ x ကို နှိပ်ပြီး {{ui:သိမ်းရန်}}။ ရွေးချယ်စရာသည် built-in အက္ခရာများသာ ရှိသည့် အခြေအနေသို့ ပြန်။

## သင်မသုံးနိုင်သော အက္ခရာများ

Editor က command line ရှိပြီးသား ဖတ်ထားသည်များကို ဖုံးကွယ်မည့် အက္ခရာများကို ငြင်းပယ်ပြီး အကြောင်းပြ-

- တူညီသော command ၏ အခြား ရွေးချယ်စရာ၏ built-in အက္ခရာများ (`ARRAY` တွင် `R` သည် Rectangular ဖြစ်သောကြောင့် Polar အတွက် `R`);
- Object snap စကားလုံး သုံးလုံးနှင့်အထက်၊ ဥပမာ `END`၊ `MID` သို့မဟုတ် `CEN`၊ နှင့် `ALL` နှင့် `LAST` စကားလုံးများ;
- Command တစ်ခု၏ ရွေးချယ်စရာ နှစ်ခုအတွက် အက္ခရာတူညီခြင်း။

အနီရောင်ဖြင့် မည်သည့်အရာမဆို စာရင်းပါနေစဉ် {{ui:သိမ်းရန်}} ပိတ်ထားသည်: လိုင်းကို ပြင် သို့မဟုတ် ဖယ်ရှား၊ ထိုအခါ ပြန်ဖွင့်။ Prompt ၏ built-in အက္ခရာများသည် အမြဲ သင့်ထက် ဦးစားပေး၊ ထို့ကြောင့် သင့်စာရင်းက built-in ဖြေဆိုမှုကို မတားနိုင်။ Command ၏ နာမည် ဖြစ်သော အက္ခရာများ၊ ဥပမာ `L` သို့မဟုတ် `C` တို့မှာ ရှိ။ ရွေးချယ်စရာ prompt တွင် command line က command စတင်ခြင်းမဟုတ်ဘဲ အဖြေကို ဖတ်နေသောကြောင့်ဖြစ်သည်။

Command တစ်ခုအတွက် ဖော်ပြသော ရွေးချယ်စရာများသည် prompt များကို မျှဝေသော command များမှ လာသဖြင့် တစ်ခါတစ်ရံ command တစ်ခုက တစ်ခါတစ်ရံသာ မေးသော ရွေးချယ်စရာတစ်ခုကို ဖော်ပြနိုင်။

## Command အားလုံးအတွက် ရွေးချယ်မှုတစ်ခု

{{ui:Command}} အောက်တွင် {{ui:command အားလုံး}} ကို ရွေး။ ရွေးချယ်စရာများသည် command မည်သည့်အရာမဆို ရှိသော ရွေးချယ်စရာအားလုံး ဖြစ်၊ ဥပမာ eXit သို့မဟုတ် Undo။ ထိုနေရာတွင် ထည့်သော အက္ခရာများသည် command တစ်ခုက ထိုရွေးချယ်စရာကို ပေးသည့်နေရာတိုင်း ထိုရွေးချယ်စရာကို ဖြေ။ Command တစ်ခုအတွက် ထည့်ထားသော အက္ခရာများက ဤအရာများထက် ဦးစားပေး။

## ကိုယ်ပိုင်ဘာသာစကားဖြင့် အက္ခရာများ

အက္ခရာများသည် မည်သည့်အက္ခရာစနစ်မဆို ဖြစ်နိုင်၊ ထို့ကြောင့် keyboard ပြောင်းစရာမလိုဘဲ ရွေးချယ်စရာများ ဖြေနိုင်: {{ui:command အားလုံး}} အောက်တွင် Close အတွက် `З` ကို ထည့်၊ သို့မဟုတ် `ARRAY` တွင် POlar အတွက် `П` ထည့်။

CadCraft သည် အင်္ဂလိပ်အက္ခရာများသာ ပါ၍ လာသည်။ သင့်စာရင်းသည် သင်၊ သင့်ရုံးနှင့် ဘာသာစကား တူ လူများက ကျန်တာကို သတ်မှတ်ရာ ဖြစ်ပြီး {{ui:ထုတ်ရန်}} က အခြားသူထံ ပေးနိုင်သော ဖိုင်ကို ပြုလုပ်ပေး။

## စာသားအဖြစ် တည်းဖြတ်ခြင်း

Editor ရှိ {{ui:စာသားအဖြစ် တည်းဖြတ်ရန်}} က တူညီသော စာရင်းကို ရွေးချယ်စရာတစ်ခုစီအတွက် စာကြောင်းတစ်ကြောင်းအဖြစ် ပြ၊ ၎င်းသည် {{ui:ထုတ်ရန်}} သိမ်းသည့်အရာလည်း ဖြစ်သည်-

```
ARRAY.PO,  P
*.X,       Q
```

စာကြောင်းတစ်ခုစီသည် command၊ အစက်၊ ရွေးချယ်စရာ၏ built-in အက္ခရာများ၊ ကော်မာနှင့် သင့်အက္ခရာများ ဖြစ်သည်။ Command အစား ကြယ်ပွင့်သည် command အားလုံးကို ဆိုလိုသည်။ `;` ဖြင့် စသော စာကြောင်းသည် မှတ်ချက်ဖြစ်သည်။

## အတူတူ ဆက်ထားသည်များ

- Built-in အက္ခရာများသည် သင့်အနားတွင် ဆက်အလုပ်လုပ်။
- Routine များနှင့် toolbar ခလုတ်များက built-in အက္ခရာများကို ဆက်သုံး၊ ထို့ကြောင့် သင်တင်ထားသည်များ မပျက်။ သင့်အက္ခရာများက လမ်းပိတ်လျှင် built-in အက္ခရာများကို ကိုယ်တိုင်ရိုက်ရန် ရှေ့တွင် underscore ထည့်: `_PO`။
- Command ၏ အတိုကောက်အမည်သည် အခြားအရာဖြစ်သည်: [command alias များ တည်းဖြတ်ရန်](topic:command-aliases) ကို ကြည့်ပါ။

## CadCraft ငြင်းပယ်သော အတန်းများ

စာသားအဖြစ် တည်းဖြတ်ချိန် သို့မဟုတ် ဖိုင်သွင်းချိန်တွင် editor က ပြဿနာတစ်ခုစီကို အတန်းနံပါတ်ဖြင့် ပြ-

- command မရှိခြင်း (command ၏ alias သည် ရှိသည်: `AR.PO` ကို `ARRAY.PO` အဖြစ် ဖတ်);
- အတန်းသည် `COMMAND.OPTION, LETTERS` ပုံစံ မဟုတ်ခြင်း;
- အက္ခရာများတွင် space သို့မဟုတ် သင်္ကေတ ပါခြင်း (အက္ခရာနှင့် ဂဏန်းသာ၊ အများဆုံး 16 လုံး);
- အက္ခရာတူညီသည့် ရွေးချယ်စရာ နှစ်ခုကို command တစ်ခုတည်း၌ ဖြေခြင်း။

## သွင်းရန်နှင့် ထုတ်ရန်

{{ui:ထုတ်ရန်}} သည် သင့်အက္ခရာများကို စာသားဖိုင်အဖြစ် သိမ်း၊ ထိန်းထားရန် သို့မဟုတ် အခြားသူထံ ပေးရန်။ {{ui:သွင်းရန်…}} က ထိုဖိုင်ကို ဖတ်။ နှစ်ခုစလုံးသည် editor တွင်နှင့် {{ui:ဆက်တင်များ}} › {{ui:CadCraft}} › {{ui:ရွေးချယ်စရာ အက္ခရာများ}} တွင် ရှိ။

Settings တွင် {{ui:သွင်းရန်…}} သည် သင့်ဖိုင်ကို သင်ရွေးသော ဖိုင်ဖြင့် အစားထိုး။ တိုက်နေသော သို့မဟုတ် အသုံးမပြုနိုင်သော အတန်းပါသော ဖိုင်ကို မယူ; editor ကိုဖွင့်ပြီး ထိုနေရာတွင် သွင်းမှ အတန်းများကို မြင်ရ။ Editor တွင် ၎င်းသည် ဘောက်စ်ကိုသာ ဖြည့်၊ {{ui:သိမ်းရန်}} ကို နှိပ်မှ ဘာမျှ မပြောင်း။

## ပြန်တင်ခြင်း သို့မဟုတ် ဖယ်ခြင်း

{{cmd:REINIT}} ရိုက်ပြီး {{key:Enter}} ကို နှိပ်၍ ဖိုင်ကို ထပ်အသုံးပြု။ အက္ခရာတစ်ခု ဖယ်ရန် ၎င်း၏ အတန်းကို ဖျက်ပြီး {{ui:သိမ်းရန်}} ကို နှိပ်။

## သင့်အက္ခရာများ သင့်အကောင့်ကို လိုက်

getcadcraft.com တွင် ဝင်ထားစဉ် သင့်အက္ခရာများကို သင့်အကောင့်တွင် ထိန်း။ အခြား browser သို့မဟုတ် အခြားကွန်ပျူတာတွင် တူညီသော အကောင့်ဖြင့် CadCraft ကိုဖွင့်လျှင် ၎င်းတို့သည် ကိုယ်တိုင် ရောက်လာ၊ command line က `Option letters from your account` ဟု ပြ။ နှစ်နေရာတွင် ပြောင်းထားလျှင် အသစ်ဆုံး မိတ္တူ အနိုင်ရ၊ အစားထိုးခံရသည့် မိတ္တူကို တစ်ကြိမ် ထိန်း။

{{ui:ဆက်တင်များ}} › {{ui:CadCraft}} › {{ui:ရွေးချယ်စရာ အက္ခရာများ}} က ၎င်းတို့၏ အခြေအနေကို ပြ။ အကောင့်မဝင်ခြင်း သို့မဟုတ် အွန်လိုင်းမဟုတ်ခြင်းတွင် ၎င်းတို့သည် ဤ browser တွင် ကျန်ပြီး အကောင့်ဝင်ထားစဉ် နောက်တစ်ကြိမ် သိမ်းသည့်အခါ အကောင့်သို့ သွား။
