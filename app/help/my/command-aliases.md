## သင်သိရမည့်အရာ

command များအတွက် သင့်ကိုယ်ပိုင် တိုတောင်းသော အမည်များကို ဘယ်လိုထည့်မလဲ၊ ဥပမာ {{cmd:LINE}} အတွက် `LL`၊ အားလုံးကို စာသားဖိုင်တစ်ခုတည်းတွင်။

## alias တစ်ခု ထည့်ခြင်း

1. {{ui:View}} › {{ui:More}} › {{ui:Edit aliases…}} ကို ဖွင့်ပါ၊ သို့မဟုတ် {{cmd:ALIASEDIT}} ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
2. alias၊ ကော်မာ၊ နောက်တွင် ကြယ်ပွင့်ဖြင့် command ပါသော လိုင်းတစ်ကြောင်း ထည့်ပါ:

```
LL,     *LINE
```

3. {{ui:Save}} ကို နှိပ်ပါ။ command line က သင့် alias မည်မျှ သုံးနေသည်ကို ပြောသည်။
4. `LL` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ: LINE စတင်သည်။

သင့် alias များသည် CadCraft ၏ ကိုယ်ပိုင် alias များ အပေါ်တွင် ရှိသည်။ သင့်လိုင်းသည် အမည်တူ built-in alias ကို အနိုင်ယူသည်; သင့်လိုင်းကို ဖယ်ရှားလိုက်လျှင် built-in ပြန်ရောက်လာသည်။

## CadCraft ငြင်းပယ်သော လိုင်းများ

editor က ရိုက်နေစဉ် ပြဿနာတိုင်းကို လိုင်းနံပါတ်ဖြင့် ဖော်ပြသည်:

- command ကို မရှိခြင်း;
- alias သည် command တစ်ခု၏ အမည်ဖြစ်နေခြင်း (`LINE, *CIRCLE` က LINE ကို ဖုံးမည်);
- လိုင်းသည် `ALIAS, *COMMAND` ပုံစံ မဟုတ်ခြင်း;
- alias တူညီသည် လိုင်းနှစ်ကြောင်းတွင် ရှိခြင်း (နောက်ရှိသည် အနိုင်ရမည်)။

သင့်ကွန်ပျူတာပေါ်တွင် ပရိုဂရမ် စတင်သော လိုင်းများ၊ ဥပမာ `NOTEPAD, START, 1, *File to edit: ,` ကို မှတ်ချက်ဖြင့် ကျော်သည်: browser ရှိ app သည် ပရိုဂရမ်များ စတင်၍ မရပါ။

## အခြားပရိုဂရမ်မှ သင့် alias များကို ယူခြင်း

1. alias editor တွင် {{ui:Import .pgp…}} ကို နှိပ်ပြီး ဖိုင်ကို ရွေးပါ။ `.pgp` ဖိုင်ကို ပုံဆွဲပေါ်သို့ ဆွဲချလည်း ရပါသည်။
2. စာရင်းပြုထားသော ပြဿနာများကို စစ်ပါ (CadCraft တွင် မရှိသော command များကို ငြင်းပယ်သည်၊ ကျန်များ အလုပ်လုပ်သည်)။
3. {{ui:Save}} ကို နှိပ်ပါ။

{{ui:Export .pgp}} သည် CadCraft ၏ alias များနှင့် သင်ပိုင်သည်များကို format တူသော ဖိုင်တစ်ခုတည်းအဖြစ် သိမ်းသည်။

## ဖိုင်ကို ပြန်တင်ခြင်း

{{cmd:REINIT}} ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ၊ သင့် alias ဖိုင်ကို ထပ်မံ အသုံးချရန်။ ၎င်းကို ဤ browser တွင် ထိန်းသိမ်းသည်; desktop app က ၎င်း၏ ကိုယ်ပိုင် ဖိုင်တွဲတွင် ထိန်းမည်ဖြစ်ပြီး cloud ဝန်ဆောင်မှုက sync လုပ်မည်ဖြစ်သည်။

## command မည်သည့်အတွက်မဆို ကီးဖြတ်လမ်း

alias ကို ရိုက်ရသည်; shortcut ကို ကီးဖြင့် နှိပ်ရသည်။ command တစ်ခုအတွက် သင့်ကိုယ်ပိုင် ကီးတစ်ခု ပေးရန်:

1. {{ui:View}} › {{ui:More}} › {{ui:Keyboard shortcuts…}} ကို နှိပ်ပါ၊ သို့မဟုတ် `KEYS` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
2. {{ui:Key}} အကွက်ကို နှိပ်ပြီး ကီးများကို နှိပ်ပါ၊ ဥပမာ {{key:Alt+Shift+C}}။
3. {{ui:Runs}} တွင် command ကို ရေးပါ၊ လိုလျှင် နောက်တွင် ရိုက်ရန်ကိုလည်း ရေးပါ: `CIRCLE`၊ သို့မဟုတ် `ZOOM E`။
4. {{ui:Add}} ကို နှိပ်ပါ။

ကီးတစ်ခုသည် {{key:Mod}} သို့မဟုတ် {{key:Alt}} ကို အက္ခရာ သို့မဟုတ် ဂဏန်းနှင့် တွဲရမည်၊ သို့မဟုတ် အခမဲ့ function ကီးများ ({{key:F2}}၊ {{key:F4}}၊ {{key:F5}}၊ {{key:F6}}၊ {{key:F9}}) ဖြစ်ရမည်။ CadCraft၊ app သို့မဟုတ် browser က ရှိပြီးသား သုံးနေသော ကီးများနှင့် My tools ခလုတ်တွင် ရှိပြီးသား ကီးများ ([Buttons of your own](topic:my-tools) ကို ကြည့်ပါ) ကို ငြင်းပယ်ပြီး အကွက်က အကြောင်းပြသည်။ shortcut များကို ဤ browser (သို့မဟုတ် desktop app) တွင် ထိန်းသိမ်းသည်; {{ui:Remove}} က ဖယ်ရှားသည်။
