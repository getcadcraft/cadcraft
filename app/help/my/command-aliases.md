## ဘာကို သင်လေ့လာမလဲ

ကိုယ်ပိုင် command အတိုကောက်များကို ဘယ်လို ထည့်ရမလဲ၊ ဥပမာ {{cmd:LINE}} အတွက် `LL` ကို စာသားဖိုင် တစ်ခုတည်းတွင် ဘယ်လိုထည့်ရမလဲ။

## Alias တစ်ခု ထည့်ရန်

1. {{ui:အမြင်}} › {{ui:နောက်ထပ်}} › {{ui:Alias များ တည်းဖြတ်ရန်…}} ကို ဖွင့်ပါ၊ သို့မဟုတ် {{cmd:ALIASEDIT}} ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
2. Alias ကို၊ ကော်မာ နှင့် ကြယ်ပွင့်နောက်က command ကို ပါဝင်သော အတန်းတစ်ခု ထည့်ပါ-

```
LL,     *LINE
```

3. {{ui:သိမ်းရန်}} ကို နှိပ်ပါ။ command line က သင့် alias မည်မျှ အသုံးပြုနေသည်ကို ပြောပါမည်။
4. `LL` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ- LINE စတင်ပါမည်။

သင့် alias များသည် CadCraft ၏ကိုယ်ပိုင် alias များ၏ အပေါ်တွင် ရှိပါသည်။ သင့်အတန်းသည် နာမည်တူ built-in alias ထက် ဦးစားပေးပါသည်; သင့်အတန်းကို ဖယ်ရှားလိုက်လျှင် built-in alias ပြန်ရောက်ပါမည်။

## CadCraft ငြင်းပယ်သော အတန်းများ

Editor က ရိုက်နေစဉ်တွင် ပြဿနာတစ်ခုစီကို အတန်းနံပါတ်ဖြင့် ပြပါသည်-

- command မရှိခြင်း;
- alias သည် command တစ်ခု၏ နာမည်ဖြစ်နေခြင်း (`LINE, *CIRCLE` က LINE ကို ဖုံးကွယ်မည်);
- အတန်းသည် `ALIAS, *COMMAND` ပုံစံ မဟုတ်ခြင်း;
- alias တူညီသည် အတန်းနှစ်ခုတွင် ပါဝင်နေခြင်း (နောက်ဆုံးအတန်းက နိုင်ပါသည်)။

သင့်ကွန်ပျူတာပေါ်တွင် ပရိုဂရမ် တစ်ခုကို စတင်စေသော အတန်းများ၊ ဥပမာ `NOTEPAD, START, 1, *File to edit: ,` ကို မှတ်ချက်ဖြင့် ကျော်ပါမည်၊ browser ထဲမှ app တစ်ခုက ပရိုဂရမ်များ စတင်နိုင်ခြင်း မရှိသောကြောင့် ဖြစ်ပါသည်။

## အခြားပရိုဂရမ်မှ သင့် alias များ ယူရန်

1. alias editor တွင် {{ui:ထည့်သွင်းရန် .pgp…}} ကို နှိပ်ပြီး ဖိုင်ကို ရွေးပါ။ `.pgp` ဖိုင်ကို ပုံဆွဲပေါ်သို့ ဆွဲချလည်း ရပါသည်။
2. စာရင်းပြထားသော ပြဿနာများကို စစ်ဆေးပါ (CadCraft တွင် မရှိသော command များကို ငြင်းပယ်ပါမည်၊ ကျန်များ အလုပ်လုပ်ပါမည်)။
3. {{ui:သိမ်းရန်}} ကို နှိပ်ပါ။

{{ui:ထုတ်ရန် .pgp}} က CadCraft ၏ alias များနှင့် သင့်ကိုယ်ပိုင် alias များကို တူညီသော ပုံစံဖြင့် ဖိုင်တစ်ခုတည်းအဖြစ် သိမ်းပေးပါသည်။

## ဖိုင်ကို ပြန်တင်ရန်

{{cmd:REINIT}} ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ၊ သင့် alias ဖိုင်ကို ထပ်မံ အသုံးပြုပါမည်။ ဖိုင်ကို ဤ browser တွင် ထိန်းသိမ်းထားပါသည်; desktop app က ကိုယ်ပိုင် ဖိုင်တွဲတွင် ထားပြီး cloud service က sync လုပ်ပေးပါမည်။

## Command ရွေးချယ်စရာများအတွက် အက္ခရာများ

Alias သည် command ကို အမည်ပေးပါသည်။ Command ၏ ရွေးချယ်စရာများကို ဖြေသည့် အက္ခရာများ (ဥပမာ {{cmd:ARRAY}} ရှိ Polar အတွက် `P`) ကို ပြောင်းလိုပါက [command ရွေးချယ်စရာများကို ကိုယ်ပိုင် အက္ခရာ ပေးရန်](topic:option-letters) ကို ကြည့်ပါ။

## Command မည်သည့်အတွက်မဆို ကီးဘုတ် ဖြတ်လမ်းများ

Alias ကို ရိုက်ရပါသည်; ဖြတ်လမ်းကို ကီး တစ်ခုဖြင့် နှိပ်ရပါသည်။ Command တစ်ခုကို ကိုယ်ပိုင် ကီး ပေးလိုပါက-

1. {{ui:အမြင်}} › {{ui:နောက်ထပ်}} › {{ui:ကီးဘုတ်ဖြတ်လမ်းများ…}} ကို နှိပ်ပါ၊ သို့မဟုတ် `KEYS` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
2. {{ui:ကီး}} အကွက်ကို နှိပ်ပြီး ကီးများကို နှိပ်ပါ၊ ဥပမာ {{key:Alt+Shift+C}}။
3. {{ui:လုပ်ဆောင်သည်}} တွင် command ကို ရေးပါ၊ နောက်တွင် ရိုက်လိုသည်ရှိလျှင် ထည့်ပါ- `CIRCLE` သို့မဟုတ် `ZOOM E`။
4. {{ui:ထပ်ထည့်ရန်}} ကို နှိပ်ပါ။

ကီး တစ်ခုသည် {{key:Mod}} သို့မဟုတ် {{key:Alt}} နှင့် အက္ခရာ သို့မဟုတ် ဂဏန်း၊ သို့မဟုတ် အခမဲ့ function ကီး ({{key:F2}}, {{key:F4}}, {{key:F5}}, {{key:F6}}, {{key:F9}}) နှင့် တွဲရပါမည်။ CadCraft၊ app သို့မဟုတ် browser က အသုံးပြုပြီးသား ကီးများနှင့် My tools ခလုတ် ရှိသော ကီးများ ([ကိုယ်ပိုင် ခလုတ်များ](topic:my-tools) ကို ကြည့်ပါ) ကို ငြင်းပယ်ပါသည်၊ အကွက်က အကြောင်းပြချက် ပြပါမည်။ ဖြတ်လမ်းများကို ဤ browser (သို့မဟုတ် desktop app) တွင် ထိန်းသိမ်းထားပြီး {{ui:ဖယ်ရှားရန်}} က ဖယ်ရှားပေးပါသည်။
