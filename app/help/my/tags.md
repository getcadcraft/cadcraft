**တဂ်** သည် သတ်မှတ်ချက်ပါသော block attribute တစ်ခု ဖြစ်သည်: ၎င်းသည် ဘယ်လိုအမျိုးအစား တန်ဖိုး ကိုင်ဆောင်သည်၊ ဘယ်တန်ဖိုးတွေ ခွင့်ပြုသည်၊ ဘယ် block များတွင် ကျင့်သုံးသည် ဆိုသည်ကို ဆိုသည်။ တန်ဖိုးများသည် ပုံမှန် block attribute များ ဖြစ်သဖြင့် အခြား program များက ဖတ်နိုင်ပြီး {{cmd:ATTEDIT}} က ပြသသည်။ သတ်မှတ်ချက်များသာ အသစ် ဖြစ်ပြီး ပုံဆွဲထဲတွင် သိမ်းထားသည်။

## သတ်မှတ်ပြီး သတ်မှတ်ခြင်း

{{cmd:TAGS}} ကို ရိုက်ပြီး ရွေးပါ:

- {{ui:သတ်မှတ်ရန်}}: အမည် (အက္ခရာ၊ ဂဏန်း၊ space၊ `_ . -`), အမျိုးအစား (`text`၊ `number`၊ `integer`၊ `yesno`၊ `length`၊ `angle`), `;` ဖြင့် ခွဲထားသော ခွင့်ပြုတန်ဖိုးများ (အလွတ်ထားလျှင် မည်သည့်တန်ဖိုးမဆို), နှင့် ကျင့်သုံးမည့် block အမည်များ (`DOOR*` သည် DOOR ဖြင့် စသော block အားလုံးနှင့် ကိုက်ညီသည်; အလွတ်ဆိုလျှင် block အားလုံး)။
- {{ui:Set}}: block reference များကို ရွေးထားစဉ် `FireRating=60 min; Width=850` ဟု ရိုက်ပါ။ ခွင့်ပြုစာရင်းပြင်ပ တန်ဖိုး၊ သို့မဟုတ် number တဂ်အတွက် နံပါတ်မဟုတ်သော တန်ဖိုးကို ငြင်းပယ်ပြီး ပြောပြသည်။ undo အဆင့်တစ်ခု ဖြစ်သည်။ attribute မရှိသော block သည် hidden attribute ရရှိသည်။
- {{ui:ဇယား}}: တဂ်ကျင့်သုံးသော block အမျိုးအစားရှိ reference အားလုံး၊ တဂ် သို့မဟုတ် block အမည်အလိုက် အုပ်စုဖွဲ့နိုင်ပြီး ပရင့်ထုတ်ကာ CSV အဖြစ် သိမ်းသည်။
- {{ui:ဖယ်ရှားရန်}}: သတ်မှတ်ချက်ကို မေ့သည်; တန်ဖိုးများသည် reference များပေါ်တွင် ကျန်ရှိသည်။

တဂ်အမည်ပြောင်းလျှင် reference တိုင်းပေါ်ရှိ တန်ဖိုးများကိုလည်း အမည်ပြောင်းသည်။ attribute အမည်များကဲ့သို့ တဂ်အမည်များသည် စာလုံးအကြီးအသေး မခွဲခြားပါ။
