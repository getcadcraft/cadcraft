## အမှတ်များ

အမှတ်တစ်ခု တောင်းဆိုသည့်အခါ အောက်ပါတို့မှ တစ်ခုကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။

| ရိုက်သည့်အရာ | အဓိပ္ပာယ် | ဥပမာ |
|---|---|---|
| `x,y` | ပကတိ: မူလအမှတ် 0,0 မှ တိုင်းတာသည် | `2500,1200` |
| `#x,y` | ပကတိ ဖြစ်သည် (အကျင့်အရ လက်ခံသည်) | `#2500,1200` |
| `@dx,dy` | ဆွေမျိုး: နောက်ဆုံးအမှတ်မှ ဘေးသို့နှင့် အပေါ်သို့ | `@600,0` |
| `@d<a` | ဆွေမျိုး polar: နောက်ဆုံးအမှတ်မှ အကွာအဝေးနှင့် ထောင့် | `@1500<45` |
| `d<a` | ပကတိ polar: မူလအမှတ်မှ အကွာအဝေးနှင့် ထောင့် | `3000<90` |
| ဂဏန်းတစ်လုံးတည်း | တိုက်ရိုက် အကွာအဝေး: base point မှ crosshair ဘက်သို့ ထိုအကွာအဝေး | `1200` |
| `*x,y`, `@*dx,dy` | UCS သတ်မှတ်ထားစဉ် ကမ္ဘာ သြဒိနိတ်များ | `*0,0` |

{{cmd:UCS}} ဖြင့် UCS သတ်မှတ်ထားသောအခါ `x,y`, `@dx,dy` နှင့် `d<a` ရှိ ထောင့်ကို UCS ဝင်ရိုးများနှင့်အညီ တိုင်းတာသည်။ [ကြည့်ခြင်းကို လှည့်ပြီး ကိုယ်ပိုင် သြဒိနိတ်များ သုံးခြင်း](topic:ucs-and-turned-view) ကို ကြည့်ပါ။

သို့မဟုတ် ပုံဆွဲနေရာတွင် နှိပ်နိုင်သည်၊ object snaps နှင့် Ortho တို့သည် နှိပ်ချက်များအပေါ် အလုပ်လုပ်သည်။

စည်းမျဉ်းများ:

- ကော်မာသည် X ကို Y မှ ခွဲသည်။ ဒသမများအတွက် period သုံးသည်: `1250.75,300`။
- အနုတ်တန်ဖိုးများသည် ဘယ်နှင့် အောက်သို့ သွားသည်: `@-600,0`။
- space မရိုက်ပါနှင့်။ {{key:Space}} သည် {{key:Enter}} ကဲ့သို့ လိုင်းကို ပို့သည်။
- ဂဏန်းများတွင် exponent သုံးနိုင်သည်: `1e3` သည် 1000 ဖြစ်သည်။
- ယူနစ် မရိုက်ရပါ၊ ပေနှင့်လက်မ အမှတ်အသား လည်း မသုံးရပါ။ ပုံဆွဲယူနစ်ဖြင့် ရိုးရိုး ဂဏန်းများကို ရိုက်ပါ။

## နောက်ဆုံးအမှတ်

`@` သည် **မည်သည့် command ဖြစ်ဖြစ်၊ အမှတ်တောင်းဆိုသည့် နေရာတိုင်းတွင် ပေးခဲ့သော နောက်ဆုံးအမှတ်** မှ စတွက်သည်- နှိပ်ခြင်း၊ snap သို့မဟုတ် ရိုက်ထည့်သော အမှတ်။ command များကြားတွင်လည်း မှတ်ထားသည်၊ ထို့ကြောင့် နောက်ဆုံးအမှတ် ဆုံးရာမှ `@0,500` ဝေးသော လိုင်းအသစ် စနိုင်သည်။ အမှတ် မပေးရသေးမီ `@` သည် 0,0 မှ စတွက်သည်။

ဤအချက် အရေးကြီးသော နေရာအချို့ရှိသည်-

- {{cmd:COPY}} တွင် ပထမ copy ပြီးနောက် နောက်ဆုံးအမှတ်သည် ထို copy ၏ အမှတ် ဖြစ်သည်။ `@600,0` ကို နှစ်ကြိမ် ရိုက်လျှင် မူရင်းမှ 600 နှင့် 1200 နေရာတွင် copy များ ထားသည်။
- Dimension တစ်ခု ထည့်ပြီးနောက် နောက်ဆုံးအမှတ်သည် dimension ၏ အဆုံး မဟုတ်ဘဲ dimension line ထားခဲ့သော နေရာ ဖြစ်သည်။

သံသယရှိလျှင် ပကတိအမှတ်၊ snap သို့မဟုတ် တိုက်ရိုက် အကွာအဝေး သုံးပါ။

## တိုက်ရိုက် အကွာအဝေး ထည့်သွင်းခြင်း

ဂဏန်းတစ်လုံးတည်းသည် command ၏ **base point** (rubber band စတင်သည့် အမှတ်) မှ crosshair ဘက်သို့ အကွာအဝေး ဖြစ်သည်-

1. crosshair ကို လိုချင်သည့် ဘက်သို့ ရွှေ့ပါ။
2. အကွာအဝေးကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။

{{ui:Ortho}} ဖွင့်ထားသောအခါ ဦးတည်ချက်သည် ဘေးသို့ သို့မဟုတ် အပေါ်အောက်သို့ တည့်တည့် snap ဖြစ်သည်၊ ထို့ကြောင့် လေးထောင့် နံရံ ဆွဲရာတွင် အမြန်ဆုံး နည်းလမ်း ဖြစ်သည်။ base point မရှိလျှင် သို့မဟုတ် crosshair သည် base point ပေါ်တွင် တိတိကျကျ ရှိလျှင် ဂဏန်းကို "Point or option keyword required." (အမှတ် သို့မဟုတ် ရွေးချယ်စရာ သော့ချက်စာလုံး လိုအပ်သည်) ဟု ငြင်းပယ်သည်။

## ထောင့်များ

- ဒီဂရီဖြင့် ရိုးရိုး ဂဏန်းအဖြစ်: `30`, `-45`, `112.5`။
- X ဘက် အပြုသဘော ဦးတည်ချက် (ညာဘက်ညွှန်သော) မှ နာရီလက်တံ ဆန့်ကျင်ဘက် တိုင်းတာသည်: 0 သည် ညာ၊ 90 သည် အပေါ်၊ 180 သည် ဘယ်၊ 270 သို့မဟုတ် -90 သည် အောက်။
- ထောင့် တောင်းဆိုသည့် နေရာ (လှည့်ခြင်း၊ စာသား ထောင့်) တွင် နှိပ်လည်း ရနိုင်သည်: ထောင့်ကို base point မှ နှိပ်ချက်အထိ တိုင်းသည်။ base point မရှိသေးလျှင် ပထမ နှိပ်ချက်က base point သတ်မှတ်ပြီး prompt က ဒုတိယအမှတ် တောင်းသည်။

## အကွာအဝေးများ

အကွာအဝေး တောင်းဆိုသည့် နေရာ (radius၊ offset၊ စာသားအမြင့်၊ scale factor) တွင်-

- အပြုသဘော ဂဏန်း ရိုက်ပါ (ပေနှင့်လက်မ ပုံဆွဲတွင် `12'6"` သို့မဟုတ် `6-1/2` လည်း ရသည်၊ [ပေနှင့်လက်မနှင့် အပိုင်းကိန်း](topic:units-papers-scales#feet-and-inches-and-fractions) ကို ကြည့်ပါ), သို့မဟုတ်
- အမှတ်တစ်ခု နှိပ်ပါ: command ၏ base point မှ ထိုအမှတ်အထိ အကွာအဝေး၊ သို့မဟုတ်
- base point မရှိသည့်အခါ အမှတ်နှစ်ခု နှိပ်ပါ: prompt က `Specify second point` သို့ ပြောင်းသည်။

"Requires a positive number or two points." (အပြုသဘော ဂဏန်း သို့မဟုတ် အမှတ်နှစ်ခု လိုအပ်သည်) ဆိုသည်မှာ တန်ဖိုးသည် ဂဏန်း မဟုတ်ခြင်း သို့မဟုတ် အနုတ်ဖြစ်ခြင်း ကို ဆိုလိုသည်။

## ရိုက်ထည့်သော တန်ဖိုးထဲရှိ ပေါင်းနှုတ်မြှောက်စား

အရှည်၊ သြဒိနိတ်၊ ထောင့် သို့မဟုတ် ဂဏန်း ရိုက်ထည့်နိုင်သည့် နေရာ မည်သည့်နေရာမဆို (command line၊ dynamic input၊ Properties box နှင့် dialog များ) တွင် `+`, `-`, `*`, `/` နှင့် ကွင်းများဖြင့် တွက်ချက်မှု ရိုက်နိုင်သည်၊ ကြိုတင် တွက်ရန် မလိုပါ-

| ရိုက်သည့်အရာ | ရလဒ် |
|---|---|
| `4+7/16` | 4.4375 |
| `12'6"+3/4"` | 12'-6 3/4" (ပေနှင့်လက်မ ပုံဆွဲတွင်) |
| `(24'-0")/3` | 8'-0" |
| `2*450mm` | 900 mm၊ ပုံဆွဲ၏ ယူနစ်ဖြင့် (ယူနစ် သတ်မှတ်ထားလျှင်) |
| `@4+7/16,0` | နောက်ဆုံးအမှတ်မှ ညာဘက် 4.4375 နေရာရှိ အမှတ် |
| `360/7` | 51.43 ဒီဂရီ ထောင့် |

- အရှည်ထဲ ရေးထားသော အနုတ်လက္ခဏာသည် အရှည်၏ အစိတ်အပိုင်း ဖြစ်ဆဲ ဖြစ်သည်: `4-7/16` သည် 4 7/16 ဖြစ်ပြီး `24'-6"` သည် ပေ 24 နှင့် လက်မ 6 ဖြစ်သည်။ ပေ အမှတ်အသား နောက်တွင် နုတ်ရန်၊ အရှည်ကို အရင် ပြီးအောင် ရိုက်ပါ `24'-0"-6"`၊ သို့မဟုတ် တွက်ချက်မှုကို ကွင်းထဲ ထည့်ပြီး အနုတ်လက္ခဏာ နှစ်ဖက်တွင် space ထားပါ `(24' - 6")` (ကွင်းအတွင်း space သည် space ဖြစ်သည်၊ အခြားနေရာတွင် {{key:Enter}} ကို နှိပ်ပေးသည်)။
- အရှည်တစ်ခုသို့ ပေါင်းသော ရိုးရိုး ဂဏန်းသည် ပုံဆွဲယူနစ်ဖြင့် ဖြစ်သည်၊ ဂဏန်းဖြင့် မြှောက်ခြင်း သို့မဟုတ် စားခြင်းသည် အရှည်ကို စကေးပြောင်းသည်။ အရှည်နှစ်ခု မြှောက်လျှင် ဧရိယာ ဖြစ်သည်၊ ထို့ကြောင့် `2'*3'` ကို ငြင်းပယ်သည်။
- `abs`, `round`, `ceil` နှင့် `floor` လည်း အလုပ်လုပ်သည်: `round(10/3)`။
- ဖတ်၍ မရသော တွက်ချက်မှုကို မှားရာနေရာကို ပြ၍ ငြင်းပယ်သည်၊ ဥပမာ "The calculation ends too soon (character 3): a value is missing." (တွက်ချက်မှု အရင်ဆုံး ပြီးသွားသည် (စာလုံး 3): တန်ဖိုး ပျောက်နေသည်)။ ဘာမှ 0 အဖြစ် ဖတ်ခြင်း မရှိပါ။ {{cmd:CAL}} သည် တွက်ချက်မှု၏ တန်ဖိုးကို ပြသည်။

## Dynamic input

{{ui:Dyn}} ({{key:F12}}၊ status bar တွင်) သည် command က အမှတ်တောင်းနေစဉ် crosshair ဘေးတွင် တန်ဖိုးများ ပြသည်။

- အမှတ် မရှိသေးလျှင် (လိုင်း၏ ပထမအမှတ်) အကွက်နှစ်ခုသည် **X** နှင့် **Y** ဖြစ်သည်။
- ထို့နောက်တွင် ၎င်းတို့သည် နောက်ဆုံးအမှတ်မှ **အကွာအဝေး** နှင့် **ထောင့်** ဖြစ်သည်။

ရိုက်ခြင်းသည် command line သို့ ဆက်သွားသေးသည်၊ crosshair ဘေးရှိ အကွက်က ပြသပြီး rubber band က နောက်လိုက်သည်။

1. တန်ဖိုး ရိုက်ပါ: မီးမောင်းထားသော အကွက်ထဲ ဝင်သည်။
2. {{key:Tab}} ကို နှိပ်ပါ (သို့မဟုတ် X ပြီးနောက် ကော်မာ)။ တန်ဖိုးသည် သော့ခတ် (မဲမဲ ပြသ) ပြီး နောက်အကွက် မီးမောင်းထားသည်။ သော့ခတ်ထားသော အကွာအဝေးသည် မောက်စ်ဖြင့် ချိန်နေစဉ် rubber band ကို ထိုအရှည်အတိုင်း ထိန်းထားသည်။
3. ဒုတိယတန်ဖိုး ရိုက်ပါ၊ သို့မဟုတ် ချိန်ပြီး {{key:Enter}} ကို နှိပ်ပါ။ `50`၊ {{key:Tab}}၊ `90`၊ {{key:Enter}} ဆိုလျှင် နောက်ဆုံးအမှတ်မှ အပေါ်သို့ 50 ဆွဲသည်။

{{key:Tab}} မပါဘဲ တန်ဖိုးတစ်ခုပြီးနောက် {{key:Enter}} ကို နှိပ်ပါက တိုက်ရိုက် အကွာအဝေး ထည့်သွင်းခြင်းအဖြစ် အလုပ်လုပ်သည်။ ပေနှင့်လက်မ အကွက်များတွင်လည်း အလုပ်လုပ်သည် (`12'6"`)။ အကွာအဝေးနှင့် ထောင့် prompt များ (စက်ဝိုင်း radius၊ လှည့်ခြင်း) သည်လည်း crosshair ဘေးတွင် တန်ဖိုးကို ပြသည်။

## ရွေးချယ်စရာများနှင့် ပုံသေများ

- ရွေးချယ်စရာများသည် စတုရန်းကွင်းများအတွင်း ပေါ်သည်။ ရွေးချယ်စရာ၏ စာလုံးကြီးများကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ (`[Diameter]` အတွက် `D`၊ `CLose` အတွက် `CL`)။ စကားလုံး၏ ရှေ့ပိုင်း ရှည်ရှည်လည်း အလုပ်လုပ်သည် (`DIA`)။
- ပုံသေတန်ဖိုးသည် `<500>` ကဲ့သို့ ထောင့်ကွင်းများအတွင်း ပေါ်သည်။ ၎င်းကို သုံးရန် {{key:Enter}} သို့မဟုတ် ညာကလစ်နှိပ်ပါ။

## အခြား keyboard layout များနှင့် keypad

Command အမည်များ၊ အတိုအမည်များနှင့် ရွေးချယ်စရာ စာလုံးများသည် Latin စာလုံးများ ဖြစ်သည်။ Greek၊ Cyrillic (Russian၊ Ukrainian၊ Belarusian၊ Serbian၊ Macedonian၊ Bulgarian)၊ Hebrew၊ Arabic၊ Persian၊ Thai သို့မဟုတ် Korean layout ဖွင့်ထားစဉ် layout ပြောင်းစရာ မလိုပါ- ရိုက်ထားသော စကားလုံးသည် ထိုအတိုင်း command၊ အတိုအမည် သို့မဟုတ် ရွေးချယ်စရာ မဟုတ်သည့်အခါ CadCraft က နှိပ်ခဲ့သော ကီးများအတိုင်း ဖတ်သည်။ Latin keyboard ပေါ်ရှိ `L` ကီးသည် `LINE` ကို စတင်ဆဲ ဖြစ်ပြီး `C` ကီးသည် layout က ဘယ်စာလုံး ပေးထားသည် ဖြစ်စေ `Close` ကို ဖြေဆဲ ဖြစ်သည်။ အထက်ရှိ command စာရင်းသည်လည်း ဤစည်းမျဉ်းကို လိုက်နာသည်။ command က စာသား တောင်းဆိုသည့် နေရာ (အကြောင်းအရာ {{cmd:TEXT}}၊ အမည်) တွင် ရိုက်သော စာသားကို ဘယ်တော့မှ မပြောင်းပါ။

Decimal ကီး ကော်မာ ပေးသော layout များတွင် ထိုကီးသည် command line နှင့် ဂဏန်းအကွက်များတွင် အမှတ်တစ်ခု ရိုက်ပေးသည်၊ ထို့ကြောင့် keypad ဖြင့် `12.5` ရိုက်နိုင်သည်။ Main keyboard ၏ ကော်မာကီးသည် `x,y` ကို ခွဲဆဲ ဖြစ်သည်။

နှစ်ခုလုံးကို {{ui:Settings}} တွင် ပိတ်နိုင်သည်: {{ui:Commands on a non-Latin keyboard layout}} နှင့် {{ui:Keypad decimal key}}။


## သြဒိနိတ် ပြသခြင်း

Status bar သည် crosshair ၏ X နှင့် Y ကို ပြသသည် (UCS သတ်မှတ်ထားလျှင် UCS အတွင်း)၊ snap နှင့် Ortho ပြီးနောက်။ command တွင် base point ရှိစဉ် ထို point မှ အကွာအဝေးနှင့် ထောင့်ကို `Δ` ဖြင့် ထပ်ထည့်သည်၊ ဥပမာ `Δ 1500 < 30°`: ရိုက်ရမည့် `@1500<30` ဖြင့် တူသော ဂဏန်းများ ဖြစ်သည်။

အမှတ်တစ်ခု၏ သြဒိနိတ်ကို ပုံနှိပ်ရန် {{cmd:ID}} ကို သုံးပြီး အမှတ်နှစ်ခု ကြား တိုင်းရန် {{cmd:DIST}} ကို သုံးပါ။
