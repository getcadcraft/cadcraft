## သင်လုပ်မည့်အရာ

အခြားရုံးမှ DWG ကို ဖွင့်ပါ၊ ဝင်လာသည်များနှင့် CadCraft က ပြနိုင်ခဲ့သည်နှင့် မပြနိုင်ခဲ့သည်များကို စစ်ဆေးပါ၊ မှတ်ချက် ထည့်ပါ၊ sheet ကို PDF အဖြစ် plot ထုတ်ပြီး DWG သို့မဟုတ် DXF အဖြစ် ပြန်ပို့ရန် မိတ္တူ သိမ်းပါ။

## ဖိုင်ကို ဖွင့်ခြင်း

1. {{key:Mod+O}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:Open}} ကို နှိပ်ပါ။
2. `.dwg` ဖိုင်ကို ရွေးပါ။

ပုံဆွဲ ဖတ်နေစဉ် status line တွင် "Reading …" ဟု ပြသည်။ ပြီးလျှင် ပုံဆွဲက မျက်နှာပြင်ကို ဖြည့်ပြီး သမိုင်းတွင် ဥပမာ "Opened plan.dwg: 18,240 objects on 64 layers" ဟု ပြသကာ ကြာချိန်ကိုလည်း ပြသည်။

:::offline
သင် offline ဖြစ်နေသည်။ {{ui:Save for offline}} ခလုတ်က "အော့ဖ်လိုင်း အဆင်သင့်" ဟု ဖတ်ရလျှင် DWG ဖိုင်များ ပုံမှန်ဖွင့်သည်။ မဟုတ်ဘဲ ဤ tab တွင် DWG တစ်ခုမှ မဖွင့်ရသေးလျှင် DWG ဖွင့်ခြင်း မအောင်မြင်နိုင်ပါ— CadCraft ၏ DWG reader ကို ပထမ DWG နှင့်အတူ ယူသည်- DXF ကို ဖွင့်ပါ၊ သို့မဟုတ် နောက်တစ်ကြိမ် online ဖြစ်သောအခါ CadCraft ကို offline အသုံးပြုရန် သိမ်းပါ။ [Offline အလုပ်လုပ်ခြင်း](common:offline) ကို ကြည့်ပါ။
:::

## ဝင်လာသည်များကို စစ်ဆေးခြင်း

1. ပုံဆွဲအောက်ရှိ ဘယ်ဘက် panel ၏ {{ui:Drawing}} အပိုင်းကို ကြည့်ပါ— ဖော်မတ်နှင့် ဗားရှင်း၊ ယူနစ်များ၊ object နှင့် layer အရေအတွက်၊ နှင့် sheet များ။
2. ၎င်းအောက်ရှိ "About this file" အကွက်ကို ဖတ်ပါ၊ ရှိလျှင်။

အကွက်တွင် ဖော်ပြသည်များ-

- **Not shown yet:** CadCraft ယခုဆွဲ၍မရသေးသော object များ၊ အမျိုးအစားနှင့် အရေအတွက်အလိုက်။ ၎င်းတို့ကို ချန်ထားပြီး ခန့်မှန်းမထားပါ။
- **Layouts (sheets) came in:** ပုံဆွဲအောက်ရှိ tab များဖြင့် ဖွင့်ပါ။
- **Dimensions that could only be read as drawn:** ဆွဲထားသည့်အတိုင်းသာ ဖတ်နိုင်သော dimension များ။

3. ပုံဆွဲအောက်ရှိ tab များကို နှိပ်ပြီး sheet တစ်ခုချင်းစီကို ကြည့်ပါ။
4. {{ui:Current settings}} ထဲရှိ {{ui:Units}} ကို စစ်ပါ (ဘာမှ ရွေးမထားဘဲ၊ {{ui:Model}} tab)။ {{ui:Unitless}} ဟု ပြလျှင် ပုံဆွဲသည် မီလီမီတာဖြစ်ကြောင်း သင်သိလျှင် ၎င်းကို သတ်မှတ်ပါ၊ ထို့ကြောင့် sheet နှင့် plot scale များ မှန်ကန်စွာ ဖတ်သည်။

:::tip
ပုံဆွဲ၏ အပိုင်းတစ်ခုကို မြင်ရန် မျှော်လင့်ပြီး မမြင်ရလျှင် {{ui:Layers}} panel ကို စစ်ပါ— layer သည် ဖိုင်ထဲတွင် ပိတ်ထားသို့မဟုတ် ခဲထားနိုင်သည်။ ၎င်း၏ အမည်ကို နှိပ်ပြီး လက်ရှိ ဖြစ်အောင်လုပ်ပါ; ထိုအခါ ဖွင့်သွားမည်။
:::

## သင့်ပြောင်းလဲမှု ပြုလုပ်ခြင်း

1. သင့်မှတ်ချက်များအတွက် layer တစ်ခု ဆောက်ပါ— {{ui:New layer}} ကို နှိပ်ပြီး `NOTES` ရိုက်ကာ {{key:Enter}} ကို နှိပ်ပါ။
2. `DT` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
3. မှတ်ချက် သွားမည့်နေရာကို နှိပ်ပါ။
4. ပုံဆွဲနှင့် ကိုက်ညီသော စာသားအမြင့်ကို ရိုက်ပါ (ကြည့်ရန် [စာသားနှင့် label များ ထည့်ခြင်း](topic:text)) ထို့နောက် {{key:Enter}} ကို နှိပ်ပါ။
5. Rotation 0 ကို ထိန်းရန် {{key:Enter}} ကို နှိပ်ပါ။
6. မှတ်ချက်ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
7. ပြီးဆုံးရန် {{key:Enter}} ကို ထပ်နှိပ်ပါ။

ဝင်လာသော dimension များကို တည်းဖြတ်ခြင်းသည် ရပါသည်- ပြောင်းလိုက်သည်နှင့် CadCraft က ၎င်းကို ၎င်း၏ ကိုယ်ပိုင် style ဖြင့် ပြန်ဆွဲသည်။

## ပြန်လည်စစ်ဆေးရန် sheet ကို plot ထုတ်ခြင်း

1. Sheet ၏ tab ကို နှိပ်ပါ။
2. {{key:Mod+P}} ကို နှိပ်ပါ။
3. {{ui:Download PDF}} ကို နှိပ်ပါ။

[PDF သို့ plot ထုတ်ခြင်း](topic:plot-pdf) ကို ကြည့်ပါ။

## မိတ္တူ သိမ်းခြင်း

1. {{key:Mod+S}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:Save}} ကို နှိပ်ပါ။

သင်သည် DWG ကို ဖွင့်ထားသဖြင့် browser က DWG ၏ ဝင်လာသော ဗားရှင်းဖြင့် `<name>.dwg` ကို ဒေါင်းလုဒ်ဆွဲသည်။ သမိုင်းတွင် ဥပမာ "Saved a copy as Plan.dwg (DWG (AutoCAD 2018))." ဟု ပြပြီး ၎င်းအောက်ရှိ လိုင်းများတွင် လမ်းကြောင်းအတွင်း ပြောင်းလဲသွားသည်များကို ဖော်ပြသည်။

2. ဖိုင်ကို မပို့မီ ထိုလိုင်းများကို ဖတ်ပါ။ [DWG တွင် ဘာတွေ ထိန်းသိမ်းပြီး ဘာတွေ ပြောင်းသလဲ](topic:files#what-a-dwg-keeps-and-changes) က တစ်ခုချင်းစီကို ရှင်းပြသည်။

သင်၏ မူရင်း DWG ကို ဘယ်တော့မှ မပြောင်းပါ။ သိမ်းတိုင်း ဒေါင်းလုဒ် အသစ်ဖြစ်သည်။

## DWG သို့မဟုတ် DXF အဖြစ် သိမ်းခြင်း

ဖော်မတ်ကို ကိုယ်တိုင် ရွေးရန်-

1. {{key:Mod+Shift+S}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:Save as}} ကို နှိပ်ပါ။

{{ui:Save a copy as}} dialog က ရွေးချယ်စရာ လေးခုဖြင့် ဖွင့်ပြီး တစ်ခုစီတွင် ပေးမည့် ဖိုင်အမည် ပါသည်- {{ui:DWG}} ၎င်း၏ {{ui:Version}} စာရင်းဖြင့်၊ {{ui:DXF R12}}၊ {{ui:DXF 2000}} နှင့် {{ui:DXF 2000 (binary)}}။ ပုံဆွဲ၏ လက်ရှိ ဖော်မတ်နှင့် ဗားရှင်းကို ရွေးပြီးသားဖြစ်သည်။

2. လိုချင်သော ဖော်မတ်ကို နှိပ်ပါ။ DWG အတွက် အခြား office က သုံးသော ဗားရှင်း သို့မဟုတ် ပိုဟောင်းတစ်ခုကို ရွေးပါ— AutoCAD 2018၊ 2013၊ 2010၊ 2007၊ 2004 သို့မဟုတ် 2000။
3. {{ui:Save}} ကို နှိပ်ပါ။

မိတ္တူ ဒေါင်းလုဒ်ဆွဲသည်။ ထို့နောက် {{key:Mod+S}} သည် ဤပုံဆွဲကို ထိုဖော်မတ်ဖြင့် သိမ်းသည်၊ ဤ browser တွင် ပုံဆွဲအသစ်များလည်း ထိုဖော်မတ်ဖြင့် စတင်သည်။ {{ui:Cancel}} သို့မဟုတ် {{key:Esc}} က ဘာမှ မသိမ်းဘဲ သမိုင်းတွင် "မသိမ်းရသေး။" ဟု ပြသည်။

ဘာရွေးရမည်ကို-

- **DWG** သည် အများဆုံး ထိန်းသည်- viewport များပါသော sheet များ၊ အမှန်တကယ် dimension များ၊ hatch pattern များ၊ သင်ရိုက်ထားသည့်အတိုင်း layer နှင့် block အမည်များ၊ နှင့် စာကြောင်းများစွာ စာသားကို စာကြောင်းများစွာ စာသားအဖြစ်။ AutoCAD 2000 ဗားရှင်းသည် အစီအစဉ်အများဆုံးတွင် ဖွင့်သည်; 2004 နှင့် နောက်ပိုင်းက အမှန်တကယ် အရောင်များကိုလည်း ထိန်းသည်။
- **DXF 2000** သည် စာသားဖိုင်ဖြစ်ပြီး DWG က ထိန်းသည့်အရာနီးပါးကို ထိန်းသည်- sheet တစ်ခုချင်းစီကို viewport များနှင့်တကွ layout အဖြစ်၊ အမှန်တကယ် dimension များ၊ hatch pattern များ၊ အမှန်အရောင်များ၊ lineweight များ၊ linetype များနှင့် သင်ရိုက်ထားသည့်အတိုင်း အမည်များ။ AutoCAD 2000 နှင့် နောက်ပိုင်းနှင့် CAD ပရိုဂရမ်အများစုတွင် ဖွင့်သည်။ Multileader များသည် ၎င်းတို့ဆွဲသော line များ၊ arrowhead များနှင့် စာသားဖြစ်လာသည်။ ဗားရှင်း 2000 သို့မဟုတ် နောက်ပိုင်းတွင် ဖွင့်ထားသော DXF သည် DXF 2000 အဖြစ် သိမ်းသည်။
- **DXF 2000 (binary)** သည် DXF 2000 နှင့် တူညီသော အကြောင်းအရာကို ဖော်မတ်၏ binary ပုံစံဖြင့် ထိန်းသည်: ဖိုင်ငယ်ပြီး နံပါတ်တိုင်းကို တိတိကျကျ ထိန်းသည်။ အခြားပရိုဂရမ်များမှ binary DXF ဖိုင်များသည် စာသားဖိုင်များကဲ့သို့ ဖွင့်သည်၊ binary DXF မှ ဖွင့်ထားသော ပုံဆွဲသည် binary အဖြစ် ပြန်သိမ်းသည်။
- **DXF R12** သည် CAD ပရိုဂရမ် နီးပါးလုံးတွင် ဖွင့်သည်။ ပထမ sheet ကို viewport များဖြင့် ထိန်းပြီး CadCraft ၏ အခြား sheet များကိုလည်း ထိန်းသည်။ Multi-line စာသားနှင့် hatch ကဲ့သို့ အသစ်သော အရာများကို ရိုးရှင်းအောင်လုပ်သည်။

## အခြား office က ဘာတွေ မြင်မလဲ

DWG တွင်-

- Line၊ arc၊ circle၊ ellipse၊ polyline၊ စာသား၊ multi-line စာသား၊ attribute ပါသော block များ၊ solid fill များ၊ hatch pattern များနှင့် layer များကို သင်မြင်သည့်အတိုင်း။
- အမှန်တကယ် dimension များ— ဆန့်ထားသောအခါ အခြားပရိုဂရမ်က ပြန်တိုင်းသည်။
- Sheet တိုင်း၊ ၎င်း၏ စက္ကူနှင့် viewport များနှင့်တကွ။
- Multileader များသည် multileader အဖြစ်။ AutoCAD 2000 ဗားရှင်းတွင် အမှန်အရောင်များသည် အနီးဆုံး စံအရောင်ဖြစ်လာသည်။

DXF R12 တွင်-

- Line၊ arc၊ circle၊ polyline၊ စာသား၊ block reference နှင့် dimension များကို သင်မြင်သည့်အတိုင်း။ Dimension များသည် အမှန်တကယ် dimension အဖြစ် ဆက်နေသည်။
- Layer အမည်များ အကြီးဖြင့်၊ space များကို `_` ဖြင့် ပြောင်းသည်။
- ပထမ sheet ကို ပုံဆွဲ၏ paper space အဖြစ် viewport များနှင့်တကွ။ နောက်ထပ် sheet များသည် `CCLAYOUT_1` စသည်ဖြင့် အမည်ပေးသော block များအဖြစ် ရောက်သည်; sheet တိုင်းကို layout အဖြစ် လိုချင်လျှင် sheet တစ်ခုစီ၏ PDF များကိုလည်း ထပ်ပို့ပါ။
- Multi-line စာသားကို သီးခြား line များအဖြစ်၊ ellipse များကို polyline များအဖြစ်၊ hatch များကို outline များအဖြစ်။

နည်းလမ်းနှစ်ခုစလုံးတွင် DWG ကို ဖွင့်စဉ် "Not shown yet" ဟု စာရင်းပြခဲ့သော အရာများသည် မိတ္တူတွင် **မပါ** ပါ၊ သမိုင်းက ထိန်းထားကြောင်း မပြသလျှင် မဟုတ်လျှင်— DWG ၏ OLE object များနှင့် model space ရှိ 3D solid များကို DWG အဖြစ် သိမ်းသည့်အခါ ပြန်ရေးသည်။ ထိုအကြောင်း ပြောပြပြီး PDF ကိုလည်း ပို့ပါ။

## အများဆုံး မှားတတ်သော အချက်များ

- **"CadCraft opens DWG and DXF drawings."** ဖိုင်က အခြား extension ရှိသည်။ `.dwg` သို့မဟုတ် `.dxf` ဖြစ်ကြောင်း စစ်ပါ။
- **"This drawing could not be read."** DWG ပျက်နေသည် သို့မဟုတ် reader က မကိုင်တွယ်နိုင်သော ဗားရှင်းဖြစ်သည်။ DXF သို့မဟုတ် ပိုဟောင်းဗားရှင်းဖြင့် သိမ်းထားသော DWG ကို တောင်းပါ။
- **"This binary DXF ends in the middle of an object."** ဖိုင်သည် ဖြတ်တောက်ထားသည် သို့မဟုတ် ပျက်နေသည်။ RECOVER ဟု ရိုက်ပြီး ဖတ်နိုင်သည်ကို ဖွင့်ပါ၊ သို့မဟုတ် ဖိုင်ကို ထပ်တောင်းပါ။
- **သိမ်းထားသော ဖိုင်ကို `name (1).dwg` သို့မဟုတ် `name (1).dxf` ဟု ခေါ်သည်။** ဖိုဒါတွင် အမည်တူဖိုင် ရှိပြီးသားဖြစ်လို့ browser က ထိုသို့ လုပ်သည်။
- **DWG ကို ဖွင့်နိုင်သော ပရိုဂရမ်အဟောင်းရှိသည်။** DWG ကို {{ui:Version}} {{ui:AutoCAD 2000}} ဖြင့် သိမ်းပါ၊ သို့မဟုတ် {{ui:DXF R12}} ဖြင့်ထားပါ— CAD ပရိုဂရမ် နီးပါးလုံးက ဖွင့်နိုင်သည်။
- **ပုံဆွဲ၏ အပိုင်းများ ပျောက်နေသည်။** Link ထားသော ပုံဆွဲများ (xref) သည် သင်ဖိုင်များကို ရွေးမချင်း မဖွင့်ပါ ({{cmd:XREF}}၊ `R`)၊ ပုံများကို ဖိုင်အမည်ပါသော frame အဖြစ် ပြသည်။
