## အကျဉ်းချုပ်

| ဖော်မတ် | ဖွင့်ခြင်း | သိမ်းခြင်း | မှတ်ချက်များ |
|---|---|---|---|
| DXF (စာသား၊ မည်သည့်ဗားရှင်းမဆို) | ရသည် | ရသည်၊ DXF R12 သို့မဟုတ် DXF 2000 အဖြစ် | Binary DXF ကို လက်မခံပါ။ အရင်ဆုံး စာသား DXF အဖြစ် သိမ်းပါ။ |
| DWG | ရသည် | ရသည်၊ DWG အဖြစ် (AutoCAD 2000၊ 2004၊ 2007၊ 2010၊ 2013 သို့မဟုတ် 2018) | CadCraft ၏ကိုယ်ပိုင် DWG library ဖြင့် ဖတ်ပြီး ရေးသည် (AutoCAD R13 မှ 2018 ဖိုင်များ)။ သင့် DWG ကို ဘယ်တော့မှ မပြောင်းလဲပါ။ ပျက်စီးနေသော ဖိုင်များ၊ သို့မဟုတ် ဖတ်၍မရသော ဗားရှင်းများကို မက်ဆေ့ချ်ဖြင့် ပယ်ချသည်။ |
| PDF | စာမျက်နှာတစ်ခုကို ယူသွင်းသည်: underlay အဖြစ် သို့မဟုတ် အရာဝတ္ထုများအဖြစ် ([PDF underlay များ](topic:pdf-underlay)) | ရသည်၊ ပလော့ခြင်းဖြင့် | စာရွက်တစ်ရွက်၏ vector PDF၊ သို့မဟုတ် စကေးဖြင့် မော်ဒယ်၏ vector PDF။ |

ဖွင့်သော ပုံဆွဲတိုင်း (သို့မဟုတ် {{ui:အသစ်}} ဖြင့် စသည့်တိုင်း) သည် ပုံဆွဲနေရာပေါ်တွင် ကိုယ်ပိုင် tab ရရှိသည်၊ မည်သူမျှ မထိသေးသော ပုံဆွဲအသစ်ကို tab ထည့်မည့်အစား အသုံးပြုသည်။ tab ကို နှိပ်ပြီး ပြောင်းပါ၊ ပိတ်ရန် {{ui:×}} ကို နှိပ်ပါ (သိမ်းမထားသော ပြောင်းလဲမှုများရှိလျှင် CadCraft က အရင်မေးသည်)၊ သို့မဟုတ် ဖွင့်ထားသော ပုံဆွဲများကို ဘေးချင်းကပ် ခင်းပါ: [မျက်နှာပြင် ခွဲခြင်း](topic:split-screen) ကို ကြည့်ပါ။

## ပုံဆွဲတစ်ခု ဖွင့်ခြင်း

- {{key:Mod+O}} ကို နှိပ်ပါ၊ {{ui:ဖွင့်ရန်}} ကို နှိပ်ပါ၊ သို့မဟုတ် `OPEN` ကို ရိုက်ပြီး ဖိုင်ကို ရွေးပါ။
- သို့မဟုတ် `.dwg` သို့မဟုတ် `.dxf` ဖိုင်ကို ပုံဆွဲနေရာပေါ်သို့ ဆွဲချပါ။

ဖိုင်ကို သင့် browser အတွင်းမှာပဲ ဖတ်သည်။ မည်သည့်နေရာသို့မှ တင်မပို့ပါ။ မှတ်တမ်းက ဝင်လာသော အရာဝတ္ထုနှင့် လေယာအရေအတွက်နှင့် ကြာချိန်ကို ဖော်ပြပြီး၊ ဘယ်ဘက် panel ၏ {{ui:ပုံဆွဲ}} အပိုင်းတွင် ဖော်မတ်ကို ပြသသည်၊ ဥပမာ "DWG 2018 (AC1032)"။

DWG reader သည် CadCraft ၏ အစိတ်အပိုင်းဖြစ်ပြီး စာမျက်နှာ တင်ပြီးနောက် ဖွင့်သော ပထမ DWG နှင့်အတူ ဆွဲယူသည် (KB ရာဂဏန်းအနည်းငယ်)၊ ထို့ကြောင့် စောင့်စရာ သီးခြား ဒေါင်းလုဒ် မရှိပါ။ နောက်ခံတွင် ဖတ်သဖြင့် ကြီးမားသော DWG ဖွင့်နေစဉ်တွင်လည်း စာမျက်နှာ ဆက်တုံ့ပြန်နေသည်။

### ဝင်လာသည်များ

- မျဉ်းများ၊ လုံးပတ်အပိုင်းများ၊ စက်ဝိုင်းများ၊ polyline များ (လုံးပတ်အပိုင်းအပိုင်းများပါ)၊ ဧလီပ်စ်များ၊ အမှတ်များ၊ စာသားနှင့် စာသားအများ၊ solid များ၊ hatch များ (စံပုံစံများကို မျဉ်းအဖြစ် ဆွဲသည်၊ အခြားများကို အရောင်တူတစ်ခုတည်းဖြင့်)၊ ဘလောက်ရည်ညွှန်းချက်များနှင့် ၎င်းတို့၏ attribute များ (တည်းဖြတ်နိုင်သော တန်ဖိုးများ; [ဘလောက် attribute များ](topic:attributes) ကို ကြည့်ပါ)၊ အတိုင်းအတာများ၊ နှင့် viewport များပါသော layout များ။
- Spline များကို spline အဖြစ် ဝင်လာသည် (ဒီဂရီ၊ ထိန်းချုပ်အမှတ်များ၊ knot များ၊ အလေးချိန်များ၊ ကိုက်ညီအမှတ်များ); [Spline နှင့် polyline များ](topic:splines) ကို ကြည့်ပါ။
- လီဒါမျဉ်းတစ်ကြောင်းနှင့် စာသားပါသော multileader များကို တည်းဖြတ်နိုင်သော CadCraft multileader များအဖြစ် ဝင်လာသည် (ကို {{cmd:MLEADER}} တွင် ကြည့်ပါ)။ အခြားများ (ဘလောက်၊ လီဒါမျဉ်းများစွာ သို့မဟုတ် ကွေးမျဉ်းများပါသော) ကို အခြားပရိုဂရမ်က ဆွဲခဲ့သည့်အတိုင်း ဆွဲပြီး တစ်ခုတည်းအဖြစ် ရွေ့သည်; မှတ်တမ်းက အရေအတွက်ကို ပြောသည်။
- ပုံများ (images) ကို ပုံ၏ ဖိုင်အမည်ပါသော ဘောင်အဖြစ် ပြသသည်၊ {{cmd:IMAGE}} ဖြင့် CadCraft ကို ဖိုင်ပေးသည်အထိ: [ပုံဆွဲထဲရှိ ပုံများ](topic:pictures#show-the-pictures-a-dwg-uses) ကို ကြည့်ပါ။ Wipeout များကို ၎င်းတို့၏ ဘောင်အဖြစ် ပြသပြီး အောက်တွင်ရှိသည်များ မြင်ရဆဲ ဖြစ်သည်။
- DWG ထဲရှိ ဇယားများကို အခြားပရိုဂရမ်က ဆွဲခဲ့သည့်အတိုင်း ဝင်လာသည်။
- မော်ဒယ်နေရာရှိ 3D မျက်နှာများကို 2D အရာဝတ္ထုများအဖြစ် မဟုတ်ဘဲ {{ui:3D}} tab တွင် ဝင်လာသည်၊ ဘလောက်အတွင်းရှိ မျက်နှာများလည်း မော်ဒယ်ရှိ ဘလောက်ရည်ညွှန်းချက်တစ်ခုစီအတွက် တစ်ကြိမ်စီ ဝင်လာသည်။ ဘလောက်နှင့် စာရွက်ပေါ်တွင် ၎င်းတို့ကို ပြင်ပ ဘောင်များအဖြစ် ပြန့်ပြန့် ဆွဲသည်။ [3D ဖြင့် မော်ဒယ်](topic:3d-solids) ကို ကြည့်ပါ။
- လေယာများသည် ၎င်းတို့၏ အရောင်၊ on၊ freeze၊ lock နှင့် plot ဆက်တင်များကို ထိန်းသိမ်းသည်။ DEFPOINTS ကို ဘယ်တော့မှ ပလော့မခံပါ။
- အတိုင်းအတာများသည် ၎င်းတို့၏ အမှတ်များ ဖတ်နိုင်သည့်နေရာတွင် တကယ့် တည်းဖြတ်နိုင်သော CadCraft အတိုင်းအတာများ ဖြစ်လာသည်။ ပထမဆုံး အခြားပရိုဂရမ်က ဆွဲခဲ့သည့်အတိုင်း ပြသသည်၊ တစ်ခုကို ပြောင်းလိုက်သည်နှင့် CadCraft က ၎င်းကို ကိုယ်ပိုင်ပုံစံဖြင့် ပြန်ဆွဲသည်။
- layout တစ်ခုစီသည် စာရွက် tab ဖြစ်လာသည်။ အခြားပရိုဂရမ်တွင် layout တိုင်းတွင် စာရွက်ကိုယ်တိုင်ဖြစ်သော ဝှက်ထားသည့် viewport ပထမတစ်ခုရှိပြီး CadCraft က ထိုတစ်ခုကို ထားခဲ့သည်။

### မဝင်လာသေးသည်များ

CadCraft ဆွဲ၍မရသည့် အရာတိုင်းကို ရေတွက်သည်၊ ခန့်မှန်းခြင်း မလုပ်ပါ။ ဘယ်ဘက် panel ရှိ "About this file" အကွက်က "Not shown yet:" ဟု ဖော်ပြပြီး အရာဝတ္ထုအမျိုးအစားတစ်ခုစီနှင့် အရေအတွက်ကို စာရင်းပြုသည်။ ပုံမှန်ဖြစ်စဉ်များမှာ DXF ထဲရှိ ဇယားများ၊ mesh များနှင့် ဘလောက်အတွင်းရှိ 3D solid များ ဖြစ်သည်။ မော်ဒယ်နေရာရှိ 3D solid၊ region နှင့် body များကို 3D tab တွင် ပြသည် ([3D solid များ အခြားပရိုဂရမ်မှ](topic:3d-solids#solids-from-other-programs) ကို ကြည့်ပါ)။ ဖိုင်တွင် လှည့်ထားသော viewport များကို မူရင်းအတိုင်း လှည့်ပြပြီး သိမ်းသည့်အခါ ၎င်းတို့၏ လှည့်ထားမှုကို ထိန်းသိမ်းသည်; လက်ရှိ UCS၊ အမည်ပေးထားသော UCS များနှင့် လှည့်ထားသော မြင်ကွင်းကိုလည်း ထိုနည်းအတိုင်း ထိန်းသိမ်းသည်။

စာသားကို Helvetica ပုံစံ ဖောင့်တစ်မျိုးတည်းဖြင့် ဆွဲသည်။ မူရင်းပရိုဂရမ်၏ ကျဉ်းသော ဖောင့်တွင် တစ်ကြောင်းတည်းတွင် ထိုင်သော label သည် CadCraft တွင် စာကြောင်းနှစ်ကြောင်းအဖြစ် ခွဲနိုင်သည်။

## သိမ်းခြင်း

သိမ်းရန် နည်းလမ်း သုံးမျိုး ရှိသည်။ တစ်ခုစီက မိတ္တူတစ်ခုကို ဒေါင်းလုဒ်ဆွဲသည်။

- **သိမ်းရန်**: {{key:Mod+S}} ကို နှိပ်ပါ၊ {{ui:သိမ်းရန်}} ကို နှိပ်ပါ၊ သို့မဟုတ် `SAVE` ကို ရိုက်ပါ (`QSAVE` လည်း ရသည်)။ ပုံဆွဲ၏ ဖော်မတ်ဖြင့် သိမ်းသည်: DWG ဖွင့်ထားလျှင် DWG၊ DXF ဖွင့်ထားလျှင် DXF။ DWG သည် ၎င်းဝင်လာသော ဗားရှင်းကို ထိန်းသိမ်းသည် (2018 ဖိုင်သည် 2018 အဖြစ် သိမ်းသည်)။ ပုံဆွဲအသစ်သည် ဤ browser ရှိ {{ui:အမည်ပြောင်း၍ သိမ်းရန်}} တွင် နောက်ဆုံး ရွေးထားသော ဖော်မတ်နှင့် DWG ဗားရှင်းကို သုံးသည်; မရွေးဖူးလျှင် AutoCAD 2000 ဖော်မတ်ရှိ DWG ဖြစ်သည်။
- **အမည်ပြောင်း၍ သိမ်းရန်**: {{key:Mod+Shift+S}} ကို နှိပ်ပါ၊ {{ui:အမည်ပြောင်း၍ သိမ်းရန်}} ကို နှိပ်ပါ၊ သို့မဟုတ် `SAVEAS` ကို ရိုက်ပါ။ {{ui:မိတ္တူအဖြစ် သိမ်းရန်}} dialog တွင် {{ui:DWG}} ကို ပေးသည်၊ {{ui:ဗားရှင်း}} စာရင်း (AutoCAD 2018၊ 2013၊ 2010၊ 2007၊ 2004 သို့မဟုတ် 2000)၊ {{ui:DXF R12}} နှင့် {{ui:DXF 2000}}၊ တစ်ခုစီတွင် ပေးမည့် ဖိုင်အမည်နှင့် ပုံဆွဲ၏ လက်ရှိ ဖော်မတ်နှင့် ဗားရှင်းကို ရွေးပြီးသား ပြသည်။ ဒေါင်းလုဒ်ဆွဲရန် {{ui:သိမ်းရန်}} ကို နှိပ်ပါ၊ ဘာမှ မသိမ်းရန် {{ui:ပယ်ဖျက်ရန်}} (သို့မဟုတ် {{key:Esc}}) ကို နှိပ်ပါ; ထိုအခါ မှတ်တမ်းက "မသိမ်းရသေးပါ။" ဟု ပြောသည်။ သင်ရွေးသည်များ ကပ်နေသည်: {{key:Mod+S}} သည် ထိုနောက်မှ ဤပုံဆွဲအတွက် ၎င်းကို သုံးပြီး ဤ browser ရှိ ပုံဆွဲအသစ်များသည် ၎င်းဖြင့် စတင်သည်။
- **DXFOUT**: `DXFOUT` ကို ရိုက်ပါ။ အမြဲတမ်း DXF R12 မိတ္တူကို ဒေါင်းလုဒ်ဆွဲသည်၊ နောက် {{key:Mod+S}} သည် ပုံဆွဲ၏ ကိုယ်ပိုင်ဖော်မတ်ဖြင့် ဆက်သိမ်းသည်။

browser သည် `<drawing name>.dwg` သို့မဟုတ် `<drawing name>.dxf` ကို ဒေါင်းလုဒ်ဆွဲသည်။ သိမ်းတိုင်းသည် **ဒေါင်းလုဒ်အသစ်** ဖြစ်သည်; သင်ဖွင့်ထားသော ဖိုင်ကို ဘယ်တော့မှ အစားထိုး သို့မဟုတ် ပြောင်းလဲခြင်း မခံရပါ။ မှတ်တမ်းက အတည်ပြုသည်၊ ဥပမာ "Plan.dwg (DWG (AutoCAD 2018)) အဖြစ် မိတ္တူ သိမ်းပြီးပြီ။ မူရင်း Plan.dxf မပြောင်းလဲပါ။" DXF အတွက် "(DXF R12၊ မည်သည့် CAD program တွင်မဆို ဖွင့်နိုင်သည်)" ဟု ပြောသည်။ အောက်ရှိ စာကြောင်းများက လမ်းတွင် ပြောင်းလဲသွားသော အရာတိုင်းကို စာရင်းပြုသည်။

CadCraft ကို desktop အက်ပ်တွင် လည်ပတ်သောအခါ သိမ်းခြင်းသည် အခြား desktop ပရိုဂရမ်များကဲ့သို့ အလုပ်လုပ်သည်: {{key:Mod+S}} သည် ပုံဆွဲကို သင်ဖွင့်ထားသော ဖိုင်သို့ ၎င်း၏ကိုယ်ပိုင်ဖော်မတ်နှင့် ဗားရှင်းဖြင့် ပြန်ရေးသည်၊ မှတ်တမ်းက ဘယ်နေရာတွင် သိမ်းပြီးသည်ကို ပြောသည်။ {{ui:အမည်ပြောင်း၍ သိမ်းရန်}} နှင့် တင်ပို့ခြင်းများက စနစ်၏ သိမ်းဆည်းရန် dialog ကို ပြသည်၊ နှစ်ကြိမ်နှိပ်သော `.dwg`၊ `.dxf` သို့မဟုတ် `.ccsheets` ဖိုင်သည် CadCraft တွင် ဖွင့်သည်။

PDF အတွက်မူ ပလော့ပါ (အောက်တွင် ကြည့်ပါ)။

## DWG ထိန်းသိမ်းသည်နှင့် ပြောင်းလဲသည်များ

CadCraft သည် DWG ကို ကိုယ်တိုင် ရေးသည်၊ သင့် browser အတွင်းတွင်၊ ဖတ်သည့် DWG library တူတူဖြင့်။ အမည်ပြောင်း၍ သိမ်းရန်တွင် ဗားရှင်းကို ရွေးပါ: AutoCAD 2000 ဖော်မတ် (ဖိုင်ဗားရှင်း AC1015) သည် အဟောင်းများအပါအဝင် ပရိုဂရမ်အများဆုံးတွင် ဖွင့်နိုင်သည်; ပိုသစ်သော ဖော်မတ်များ (2004၊ AC1018၊ 2018 အထိ၊ AC1032) သည် အမှန်အရောင်များကိုလည်း ထိန်းသိမ်းသည်။ ဘာမှ မတင်ပို့ဘဲ DWG သိမ်းခြင်းသည် အော့ဖ်လိုင်းတွင်လည်း အလုပ်လုပ်သည်။

ဗားရှင်းတစ်ခုစီကို သိမ်းထားသော ဖိုင်များကို အခြားပရိုဂရမ် သုံးခု၏ DWG reader များနှင့် CadCraft ကိုယ်တိုင်ဖြင့် ပြန်ဖတ်၍ စစ်ဆေးသည်။ CadCraft DWG ကို AutoCAD ကိုယ်တိုင်တွင် မဖွင့်ရသေးပါ။

### DWG ထိန်းသိမ်းသည်များ

- မျဉ်းများ၊ လုံးပတ်အပိုင်းများ၊ စက်ဝိုင်းများ၊ ဧလီပ်စ်များ၊ အမှတ်များနှင့် လုံးပတ်အပိုင်းများပါသော polyline များ။
- တစ်ကြောင်းတည်း စာသားကို ၎င်း၏ ချိန်ညှိမှုနှင့် အကျယ်အချိန်ဖြင့်။
- စာကြောင်းများစွာနှင့် ဝဲသွားသော စာသားကို multi-line စာသားအဖြစ်။ အခြားပရိုဂရမ်က တူညီသော အကျယ်ဖြင့် ထပ်ဝဲစေသည်။
- အရာဝတ္ထု အရောင်များ: လေယာအလိုက်၊ ဘလောက်အလိုက်၊ စံအရောင် 255 ခု၊ နှင့် 2004 ဖော်မတ်နှင့် နောက်ပိုင်းရှိ အမှန်အရောင်များ။
- လေယာများ၏ အရောင်၊ မျဉ်းပုံစံ၊ မျဉ်းအထူနှင့် on၊ freeze၊ lock၊ plot ဆက်တင်များ; အရာဝတ္ထု၏ ကိုယ်ပိုင် မျဉ်းပုံစံများ၊ မျဉ်းအထူများနှင့် မျဉ်းပုံစံစကေးများ၊ မျဉ်းပုံစံ ပုံစံများနှင့် ပုံဆွဲ၏ မျဉ်းပုံစံစကေး။
- ပုံဆွဲ၏ ယူနစ်များနှင့် အလျား ဖော်မတ် (ဒဿမ၊ ပေနှင့် လက်မ၊ အပိုင်းကိန်းများ…)။
- ဘလောက်များကို ၎င်းတို့၏ base point နှင့် attribute အဓိပ္ပာယ်ဖွင့်ချက်များဖြင့်၊ မမြင်ရ၊ ပုံသေနှင့် ကြိုသတ်မှတ်ထားသည်များအပါအဝင်။
- ဘလောက်ရည်ညွှန်းချက်များ၊ ၎င်းတို့၏ စကေး၊ လှည့်ပတ်မှုနှင့် attribute တန်ဖိုးများ။
- Solid ဖြည့်ခြင်းများနှင့် ပုံစံပါ hatch များ၊ ၎င်းတို့၏ ပုံစံ၊ စကေးနှင့် ထောင့်ဖြင့် (ပုံစံ၏ ကိုယ်ပိုင်မျဉ်းများ၊ ထို့ကြောင့် အခြားပရိုဂရမ်များက CadCraft ဆွဲသည့် မျဉ်းများကို တူညီစွာ ဆွဲသည်)။
- အတိုင်းအတာများ၊ တကယ့် အတိုင်းအတာများအဖြစ်: ဆွဲဆန့်သည့်အခါ အခြားပရိုဂရမ်များက ပြန်တိုင်းသည်။ တစ်ခုစီက ၎င်း၏ကိုယ်ပိုင် ဆက်တင်များ (စာသားအမြင့်၊ မြားအရွယ်အစား၊ ဒဿမ၊ အလျားဖော်မတ်) နှင့် ၎င်း၏စာသားကို ထိန်းသိမ်းပြီး DWG အတိုင်းအတာတိုင်းတွင်ရှိသော ဆွဲထားသည့် မိတ္တူကို ဆောင်သည်။
- စာရွက်များ (layout များ): စာရွက်တစ်ရွက်စီကို ၎င်း၏ စက္ကူအရွယ်အစားနှင့် ယူနစ်၊ ၎င်းပေါ်တွင် ဆွဲထားသည်များ၊ နှင့် ၎င်း၏ မြင်ကွင်းနှင့် စကေးပါသော viewport များ။
- အမည်ပေးထားသော မြင်ကွင်းများ။
- Multileader များကို multileader အဖြစ်။
- လေယာနှင့် ဘလောက်အမည်များကို သင်ရိုက်ထားသည့်အတိုင်း အကြီး အသေးဖြင့်။ (DXF R12 က အကြီးဖြင့် ရေးသည်။)

### DWG ပြောင်းလဲသည်များ

ဤတစ်ခုစီကို သိမ်းပြီးနောက် မှတ်တမ်းတွင် စာရင်းပြုသည်၊ ၎င်းသည် သင့်ပုံဆွဲအပေါ် သက်ရောက်သည့်အခါ။

| CadCraft တွင် | သိမ်းထားသော DWG တွင် |
|---|---|
| အမှန်အရောင်များ (အရောင်ရွေးကိရိယာဖြင့် ရွေးထားသည်)၊ 2000 ဖော်မတ်တွင် | အနီးဆုံး စံအရောင်: 2000 ဖော်မတ်တွင် 255 ခုသာ ရှိသည်။ အရောင်များ ထိန်းလိုလျှင် 2004 သို့မဟုတ် နောက်ပိုင်းအဖြစ် သိမ်းပါ |
| စာရွက်၏ အမည်ပေးထားသော မြင်ကွင်းများ | Paper-space မြင်ကွင်းများ: DWG က မည်သည့် စာရွက်ဖြစ်သည်ကို မပြောသဖြင့် CadCraft ဖိုင်ကို ပြန်ဖွင့်သည့်အခါ ပထမစာရွက်နှင့် သက်ဆိုင်သည် |
| အကျယ်အချိန်ပါသော multi-line စာသား | ပုံမှန် စာလုံးအကျယ်: DWG တွင် အကျယ်အချိန်သည် တစ်ကြောင်းတည်း စာသားအတွက်သာ သက်ရောက်သည် |
| DWG က မခွင့်ပြုသော စရိုက်များပါသော လေယာ သို့မဟုတ် ဘလောက်အမည်များ | ပြောင်းလဲထားသည်: `Base\|Walls` ကဲ့သို့ ချိတ်ဆက်ထားသော ပုံဆွဲမှ အမည်သည် `Base$0$Walls` ဖြစ်လာသည် (ချိတ်ဆက်ထားသော ပုံဆွဲကို bind လုပ်သည့်နည်းအတိုင်း)၊ အခြား စရိုက်များသည် `_` ဖြစ်သည် |

## ချိတ်ဆက်ထားသော ပုံဆွဲများ (ပြင်ပ ရည်ညွှန်းချက်များ)

{{cmd:XATTACH}} (`XA`၊ သို့မဟုတ် {{ui:ဘလောက်များ}} › {{ui:နောက်ထပ်}} › {{ui:ပုံဆွဲတစ်ခု ချိတ်ရန် (xref)}}) သည် အခြား DWG သို့မဟုတ် DXF ကို ချိတ်သည်: ဖိုင်ကို ရွေးပါ၊ ထို့နောက် ၎င်းသွားမည့်နေရာကို နှိပ်ပါ ({{key:Enter}} က 0,0 တွင် ထားသည်)။ ၎င်းသည် ဖိုင်အမည်ဖြင့် ဘလောက်တစ်ခုအဖြစ် ဝင်လာသည်၊ ပုံဆွဲနှစ်ခု၏ ယူနစ်များ ကွဲပြားသည့်အခါ မှန်ကန်သော စကေးဖြင့်။ ၎င်း၏ လေယာနှင့် ဘလောက်များသည် ချိတ်ဆက်မှု၏ အမည်ကို ရှေ့ထားပြီး ၎င်းတို့၏ အမည်များကို ထိန်းသိမ်းသည် — `Plan|Walls`၊ `Plan|Door` — ထို့ကြောင့် သင့်အရာများနှင့် ဘယ်တော့မှ မရောပါ: ချိတ်ထားသော လေယာများကို သင့်ကိုယ်ပိုင်ကဲ့သို့ on နှင့် off လုပ်ပါ၊ freeze သို့မဟုတ် lock လုပ်ပါ။ ချိတ်ဆက်မှုကို ဖတ်ရုံသာ ခွင့်ပြုသည်: အခြားပုံဆွဲကို ပြောင်းပြီး ပြန်တင်ပါ။ ချိတ်ထားသော လေယာများတွင် သင်သတ်မှတ်သည်များ (အရောင်၊ မျဉ်းပုံစံ၊ မျဉ်းအထူ၊ on/off၊ freeze၊ lock၊ plot) ကို ပြန်တင်သည့်အခါ၊ ချိတ်ဆက်မှုသည် ချိတ်ဆက်မှုအဖြစ် ရှိနေစဉ် ပုံဆွဲကို DWG အဖြစ် သိမ်းသည့်အခါ၊ နှင့် အခြားပုံဆွဲတစ်ခုက ဤတစ်ခုကို ချိတ်သည့်အခါ ထိန်းသိမ်းသည်။

{{cmd:XREF}} (`XR`): `?` က ချိတ်ဆက်မှုများကို စာရင်းပြုသည် (ဖွင့်ထားသည် သို့မဟုတ် မဟုတ်၊ မည်သည့်ဖိုင်၊ ရည်ညွှန်းချက်အရေအတွက်); `A` ချိတ်သည်; `R` ၎င်း၏ဖိုင်မှ တစ်ခုကို ပြန်တင်သည် (ဖိုင်ကို ထပ်ရွေးပါ: browser က သင့်ဖိုင်တွဲများကို ကိုယ်တိုင် မရောက်နိုင်ပါ); `B` တစ်ခုကို bind လုပ်သည် (၎င်းသည် `Plan$0$Walls` အမည်ရှိ ပုံမှန် ဘလောက်နှင့် လေယာများ ဖြစ်လာသည်); `D` တစ်ခုကို ဖယ်သည် (၎င်း၏ ရည်ညွှန်းချက်များနှင့် လေယာများ ပျောက်သွားသည်)။ တစ်ခုစီသည် undo အဆင့်တစ်ခု ဖြစ်သည်။

{{cmd:XCLIP}} (`XC`) သည် ဘလောက်ရည်ညွှန်းချက်များနှင့် ချိတ်ဆက်မှုများကို clip လုပ်သည်: ၎င်းတို့ကို ရွေးပါ၊ နယ်နိမိတ်အသစ်အတွက် `N`၊ ထို့နောက် `R` နှင့် ထောင့်နှစ်ခု သို့မဟုတ် `P` နှင့် polygon ၏ အမှတ်များ ({{key:Enter}} က ပိတ်သည်); `D` က clip ကို ဖယ်သည်။ အတွင်းရှိသာ ပြသပြီး ပလော့သည်၊ clip သည် ရည်ညွှန်းချက်နှင့်အတူ ရွေ့သည်။ DWG နှင့် DXF 2000 က clip များကို ထိန်းသိမ်းသည်; DXF R12 က ရည်ညွှန်းချက်ကို အပြည့်အစုံ သိမ်းပြီး ထိုသို့ ပြောသည်။ clip ထားသော ရည်ညွှန်းချက်များ ပါသော ချိတ်ဆက်မှုကို bind လုပ်သည့်အခါ {{cmd:XREF}} `B` က မေးသည်: `A` က အားလုံးကို bind လုပ်သည်၊ `C` က ရည်ညွှန်းချက်တစ်ခုစီ၏ clip ထားသော အပိုင်းကိုသာ ထိန်းသည် (မျဉ်းနှင့် လုံးပတ်အပိုင်းများကို နယ်နိမိတ်တွင် ဖြတ်သည်; စာသားနှင့် အသိုက်ဘလောက်များသည် ၎င်းတို့၏ insertion အမှတ် အတွင်းရှိလျှင် ကျန်သည်)။

သင်ဖွင့်သော ပုံဆွဲသည် CadCraft မမြင်နိုင်သော ဖိုင်များကို ချိတ်ထားနိုင်သည်: မဖွင့်ရသေးသော အရေအတွက်ကို ပြောသည်။ ၎င်းတို့ကို မြင်ရန် {{cmd:XREF}}၊ `R` ကို သုံးပြီး ဖိုင်တစ်ခုစီကို ရွေးပါ။

သိမ်းသည့်အခါ ဖွင့်ထားသော ချိတ်ဆက်မှုကို ဖိုင်ထဲသို့ **bind** လုပ်သည် (အခြားပရိုဂရမ်များက `Plan$0$…` အမည်ရှိ ပုံမှန် ဘလောက်နှင့် လေယာများကို မြင်သည်), မှတ်တမ်းက ထိုသို့ ပြောသည်။ မဖွင့်ထားသော ချိတ်ဆက်မှုသည် DWG နှင့် DXF တွင် ၎င်း၏ဖိုင်သို့ ချိတ်ဆက်မှုအဖြစ် ဆက်ရှိသည်။

## 3D တွင် ဖွင့်ခြင်း

{{ui:အမြင်}} › {{ui:နောက်ထပ်}} › {{ui:ModelCraft တွင် ဖွင့်ရန်}} ({{cmd:OPENIN3D}}) က ပုံဆွဲကို 3D modeling အက်ပ်တွင် tab အသစ်တစ်ခုအဖြစ် DWG အဖြစ် ဖွင့်သည်၊ တင်မပို့ဘဲ။ ထိုနေရာတွင် ပြုလုပ်သော ပြောင်းလဲမှုများ ထိုနေရာတွင်သာ ရှိနေသည်; ထိုနေရာတွင် သိမ်းပါ။ မီနူးအကြောင်းအရာသည် ထို အက်ပ်က ပေးထားသော ပုံဆွဲကို လက်ခံနိုင်သည့်နေရာတွင်သာ ပြသသည်။

## PDF ပလော့ခြင်း

{{key:Mod+P}} ကို နှိပ်ပါ၊ {{ui:ပလော့တ်}} ကို နှိပ်ပါ၊ သို့မဟုတ် `PLOT` ကို ရိုက်ပါ။ PDF ကို browser အတွင်း ပြုလုပ်ပြီး ဒေါင်းလုဒ်ဆွဲသည်၊ သို့မဟုတ် ပရင့်ထုတ်ရန် tab အသစ်တွင် ဖွင့်သည်။ [PDF သို့ ပလော့ခြင်း](topic:plot-pdf) ကို ကြည့်ပါ။

## ဖိုင်များ သွားရောက်သည့်နေရာ

သိမ်းတိုင်းနှင့် ပလော့တိုင်းသည် ဒေါင်းလုဒ်ဖြစ်သဖြင့် ဖိုင်များသည် သင့် browser က ဒေါင်းလုဒ်ထားသည့်နေရာသို့ ရောက်သည်: ပုံမှန်အားဖြင့် ဒေါင်းလုဒ်ဖိုင်တွဲ။ အခါတိုင်း ဖိုင်တွဲရွေးလိုလျှင် browser ၏ ဒေါင်းလုဒ် ဆက်တင်ကို ပြောင်းပါ; [Browser နှင့် ကွန်ပျူတာများ](common:browsers) က နေရာကို ပြသသည်။

ဖွင့်သို့မဟုတ် သိမ်းသည့် မည်သည့်အရာမျှ ကျွန်ုပ်တို့ဆီ မပို့ပါ။ [သင့်ဖိုင်များ ဘယ်နေရာ ရောက်သလဲ](common:your-files) ကို ကြည့်ပါ။

## PLN နှင့် PLA ပရောဂျက်ဖိုင်များ

CadCraft သည် DWG နှင့် DXF ပုံဆွဲများကို ဖွင့်သည်၊ Archicad ၏ကိုယ်ပိုင်ဖိုင်များ (`.pln`၊ `.pla`၊ `.tpl`၊ `.bpn`) မဟုတ်ပါ။ ဖွင့်ရန်ကြိုးစားလျှင် ၎င်းက ဘာဖြစ်သည်ကို ပြောပြသည်။ Archicad တွင် လိုအပ်သော မြင်ကွင်းများ သို့မဟုတ် layout များကို DWG အဖြစ် သိမ်းပြီး ဤနေရာတွင် ဖွင့်ပါ၊ သို့မဟုတ် မော်ဒယ်ကို IFC အဖြစ် တင်ပို့ပြီး BimCraft တွင် ဖွင့်ပါ။ BimCraft က ဖိုင်ကို လက်ခံနိုင်သည့်နေရာတွင် CadCraft က {{ui:BimCraft တွင် ဖွင့်ရန်}} ကို ပေးသည်။

## စာမျက်နှာ သိမ်းမီ ပိတ်လျှင်

CadCraft သည် သင်ပြောင်းသော ပုံဆွဲတိုင်း၏ မိတ္တူကို ဤ browser တွင်သာ၊ တည်းဖြတ်ခြင်း ရပ်ပြီးနောက် ခဏအကြာတွင် ထိန်းသိမ်းထားသည်။ tab ပိတ်သွားလျှင်၊ သိမ်းမီ browser ရပ်သွားလျှင် သို့မဟုတ် ကွန်ပျူတာ ပြန်စလျှင်၊ CadCraft သည် နောက်တစ်ကြိမ် စတင်သည့်အခါ **သင့်အလုပ်ကို ပြန်ရယူမလား?** ဟု မေးသည်: {{ui:ပြန်ရယူရန်}} က ပုံဆွဲကို သိမ်းမထားဘဲ ၎င်း၏ကိုယ်ပိုင် tab တွင် ထပ်ဖွင့်သည်။ ပုံဆွဲကို သိမ်းလျှင် ၎င်း၏ မိတ္တူကို ဖယ်ရှားသည်။ [သင့်အလုပ်ကို ပြန်ရယူခြင်း](common:recover) ကို ကြည့်ပါ။

## အွန်လိုင်းနှင့် အော့ဖ်လိုင်း

ဖွင့်ခြင်း၊ ပုံဆွဲခြင်း၊ သိမ်းခြင်း (DWG နှင့် DXF) နှင့် ပလော့ခြင်း အားလုံးသည် သင့်ကွန်ပျူတာပေါ်တွင် ဖြစ်ပေါ်သဖြင့် CadCraft တင်ပြီးနောက် ချိတ်ဆက်မှု မလိုဘဲ အလုပ်လုပ်သည်။

CadCraft ကို ချိတ်ဆက်မှု လုံးဝမရှိဘဲ သုံးရန် အွန်လိုင်းရှိစဉ် အပေါ်ဘားရှိ {{ui:အော့ဖ်လိုင်းအတွက် သိမ်းရန်}} ကို နှိပ်ပါ။ label က တိုးလာသည် ("သိမ်းနေသည် 40/212") နှင့် "အော့ဖ်လိုင်း အဆင်သင့်" ဖြင့် ပြီးသည်။ သိမ်းထားသော မိတ္တူတွင် DWG reader ပါဝင်ပြီး စုစုပေါင်း 5 MB ခန့်ရှိသည်၊ ထို့ကြောင့် သိမ်းပြီးသည့်အခါ **DWG ဖိုင်များကိုလည်း အော့ဖ်လိုင်းတွင် ဖွင့်နိုင်သည်**။ ခလုတ်ကို ထပ်နှိပ်လျှင် {{ui:ထပ်သိမ်းရန် (နောက်ဆုံးဗားရှင်း ယူရန်)}} သို့မဟုတ် {{ui:အော့ဖ်လိုင်းမိတ္တူကို ဖယ်ရှားရန်}} ရှိသည်။ "မသိမ်းနိုင်ပါ" ဆိုသည်မှာ ဖိုင်အချို့ ဒေါင်းလုဒ်မဆွဲနိုင်ခြင်းဖြစ်သည်: ချိတ်ဆက်မှုကို စစ်ပြီး ပြန်နှိပ်ပါ။ "အော့ဖ်လိုင်း မရနိုင်ပါ" ဆိုသည်မှာ ဤ browser window က မိတ္တူ ထိန်းသိမ်းနိုင်ခြင်း မရှိဘူးဖြစ်သည် (private window များနှင့် စီမံထားသော ကွန်ပျူတာအချို့)။

သိမ်းထားသော မိတ္တူမရှိဘဲ DWG reader ကို စာမျက်နှာ တင်ပြီးနောက် ပထမဆုံး DWG ဖွင့်သည့်အခါ ဆွဲယူသဖြင့် အော့ဖ်လိုင်းတွင် DWG ဖွင့်ခြင်း မအောင်မြင်နိုင်ပါ; DXF ဖိုင်များက ၎င်းကို ဘယ်တော့မှ မလိုပါ။ CadCraft သိမ်းထားမှသာ မဟုတ်လျှင် အော့ဖ်လိုင်းတွင် စာမျက်နှာကို ပြန်မတင်ပါနှင့်။

အသေးစိတ်အတွက် [အော့ဖ်လိုင်းတွင် အလုပ်လုပ်ခြင်း](common:offline) ကို ကြည့်ပါ။

:::offline
ယခု သင်သည် အော့ဖ်လိုင်းဖြစ်နေသည်။ ပုံဆွဲများသည် DWG သို့မဟုတ် DXF အဖြစ် သိမ်းပြီး ပုံမှန် ပလော့သည်၊ DXF ဖိုင်များ ဖွင့်သည်။ CadCraft က "အော့ဖ်လိုင်း အဆင်သင့်" ပြလျှင် သို့မဟုတ် DWG reader ကို ဤ tab တွင် တင်ပြီးသား ဖြစ်လျှင် DWG ဖိုင်များ ဖွင့်သည်။
:::

## ဖိုင်များထဲရှိ constraint များ

Constraint နှင့် parameter များ ([ပုံဆွဲကို constrain လုပ်ခြင်း](topic:constraints) ကို ကြည့်ပါ) ကို DWG နှင့် DXF နှစ်မျိုးလုံးတွင် သိမ်းသည်။ constrain လုပ်ထားသော အရာဝတ္ထုတိုင်းတွင် CadCraft မှတ်စု (extended data) အသေးလေး ပါသည်၊ နှင့် `CADCRAFT_PARAMETRIC` အမည်ရှိ အသုံးမပြုသော ဘလောက်တစ်ခုက constraint များနှင့် parameter ဇယားကို ထိန်းထားသည်။ အခြားပရိုဂရမ်များက ပုံဆွဲကို ပုံမှန်ဖွင့်ပြီး နှစ်ခုလုံးကို လျစ်လျူရှုသည်; purge လုပ်သည့်အခါ အသုံးမပြုသော ဘလောက်ကို ဖျက်နိုင်သည်။ မှတ်စုများသည် အရာဝတ္ထုများကို ၎င်းတို့၏ကိုယ်ပိုင် key ဖြင့် ရည်ညွှန်းသည်၊ ဖိုင်၏ handle ဖြင့် မဟုတ်ပါ၊ ထို့ကြောင့် handle များကို နံပါတ်ပြန်ပေးသော ပရိုဂရမ်က ၎င်းတို့ကို မပျက်စီးစေပါ။ အခြားပရိုဂရမ်က constrain လုပ်ထားသော အရာဝတ္ထုကို ဖျက်ခဲ့ သို့မဟုတ် ပြောင်းခဲ့လျှင် CadCraft က ဖိုင်ဖွင့်သည့်အခါ ၎င်းပေါ်ရှိ constraint များကို ဖယ်ပြီး အရေအတွက်ကို ပြောသည်။ ၎င်းတို့မပါသော ဖိုင်သည် constraint မပါဘဲ ဖွင့်သည်။

အစိတ်အပိုင်း modeler မှ တင်ပို့ထားသော sketch (`.json`) ကိုလည်း ဖွင့်သည်: [အခြား part modeler များသို့ နှင့် မှ sketch များ ရွှေ့ခြင်း](topic:solidworks-sketches) ကို ကြည့်ပါ။

## မရနိုင်သေးသည်များ

- သိမ်းထားသော DXF တွင် multileader အရာဝတ္ထုအဖြစ် Multileader များ (R12 တွင် မရှိ: ၎င်းတို့ ဆွဲသည့်အရာအဖြစ် သိမ်းသည်)။
- သိမ်းထားသော DXF တွင် ပုံများ (၎င်းတို့ ဘောင်များအဖြစ် သိမ်းသည်; DWG က ပုံအဖြစ် ထိန်းသည်)၊ နှင့် အောက်ရှိအရာများကို ဖုံးသော wipeout များ။
- 2000 ထက် သစ်သော DXF ဗားရှင်းအဖြစ် သိမ်းခြင်း။
- Cloud သိမ်းခြင်းနှင့် ကွန်ပျူတာများကြား sync။

အပြည့်အစုံစာရင်းအတွက် [မတည်ဆောက်ရသေးသည်များ](topic:not-built-yet) ကို ကြည့်ပါ။
