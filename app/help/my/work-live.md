## သင် လေ့လာရမည့်အရာများ

လူအများ တစ်ပြိုင်နက် ပုံဆွဲတစ်ခုပေါ်တွင် အလုပ်လုပ်စဉ် သင်မြင်ရသည်များနှင့် သင့်ပြင်ဆင်မှုများ ဘာဖြစ်သလဲ။ CadCraft Studio သည် Live TeamWork session ကို စတင်ပြီး ပါဝင်သည် (Share live၊ Join); ဤစာမျက်နှာသည် ပုံဆွဲကိုယ်တိုင် အကြောင်းဖြစ်သည်။

## အားလုံး တစ်ပြိုင်နက် ဆွဲခြင်း

သာမန်အတိုင်း ဆွဲပြီး တည်းဖြတ်ပါ။ သင်၏ ကိုယ်ပိုင် ပြင်ဆင်မှုများ ချက်ချင်း ပေါ်သည်၊ အခြားသူများ မရောက်ရှိသေးပင် ဖြစ်စေ၊ အခြားသူတို့၏ ပြင်ဆင်မှုများ သူတို့ ပြုလုပ်ပြီး အနည်းငယ်အကြာတွင် သင့်မျက်နှာပြင်ပေါ် ပေါ်လာသည်။ command အားလုံး အလုပ်လုပ်သည်: ဆွဲခြင်း၊ ပြင်ဆင်ခြင်း၊ layer များ၊ block များ၊ sheet များ၊ dimension များ၊ constraint များ။

object တစ်ခုကို လူနှစ်ယောက်က ပြောင်းနိုင်သည်။ မတူညီသောအရာများကို ပြောင်းလျှင် ဥပမာ မျဉ်းတစ်ခု၏ အရောင်နှင့် အဆုံး point တို့ကို နှစ်ခုစလုံး ထိန်းထားသည်။ တူညီသောအရာကို ပြောင်းလျှင် နောက်ပြောင်းသောအရာ နိုင်သည်။

ကိုယ်တိုင်သာ ရှိသည်များ: လက်ရှိ layer၊ အရောင်နှင့် စာသားအမြင့် အသစ် objects အတွက်၊ သင်၏ dimension ဆက်တင်များ၊ သင်၏ view၊ split screen နှင့် UCS။ ပုံဆွဲသည် မျှဝေသည်; သင်ကြည့်ပုံသည် မျှဝေခြင်းမဟုတ်ပါ။

## ပုံဆွဲပေါ်ရှိ အခြားသူများ

- **Cursor များ:** လူတစ်ဦးချင်း၏ pointer သည် သူတို့၏အမည်နှင့် ကိုယ်ပိုင်အရောင်ဖြင့်၊ နှင့် ၎င်းတို့ run နေသော command ကို ပြသည်။ သင့်မျက်နှာပြင်ပေါ်ရှိ အရာများနားတွင် အလုပ်လုပ်နေသူများ၏ cursor များကို သင် မြင်ရသည်။
- **ရွေးချယ်မှုများ:** တစ်စုံတစ်ဦး ရွေးထားသည်များကို သူတို့၏အရောင်ဖြင့် ဘောင်ခတ်ထားသည်။
- **တည်းဖြတ်နေခြင်း:** တစ်စုံတစ်ဦး ရွေးထားသော object တွင် "Ana တည်းဖြတ်နေသည်" ကဲ့သို့ အမှတ်အသား ရှိသည်။ သင် ၎င်း၏ အရောင် သို့မဟုတ် နေရာကို ပြောင်းနိုင်သော်လည်း သူတို့ လွှတ်လိုက်သည်အထိ ဖျက်၊ ခွဲ သို့မဟုတ် ပြန်ရိုက်၍ မရပါ။ ၎င်းကို ရွေးလိုက်လျှင် ဘယ်သူ ထိန်းထားသည်ကို ပြောသည်။
- **နောက်ဆုံး ဘယ်သူပြောင်းသလဲ:** ဤ session တွင် တစ်စုံတစ်ဦးက ပြောင်းထားသော object တစ်ခုကို ရွေးလျှင် command line က ဘယ်သူနှင့် ပြောင်းလဲမှု ဘာလဲဆိုတာ ပြောသည် ("Ben changed that last: CIRCLE.")။ Studio ၏ Live panel သည် {{ui:Recent edits}} အောက်တွင် မကြာသေးမီ ပြင်ဆင်မှုတိုင်းကို စာရင်းပြုသည်။ ဤအရာအားလုံးကို ပုံဆွဲတွင် မသိမ်းပါ: session ကြာသည်အထိသာ ရှိသည်။

## လုပ်ဆောင်နေစဉ် layer သို့မဟုတ် နေရာကို ထိန်းထားခြင်း

လူများစွာနှင့် ကြီးမားသော ပုံဆွဲတွင် ယခုအချိန်အတွက် သင့်အပိုင်းကို ပြောပါ:

1. `LIVEHOLD` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
2. `L` ကို ရွေးပြီး layer အမည်ကို ရိုက်ပါ ({{key:Enter}} က လက်ရှိ layer ကို ထိန်းသည်)၊ သို့မဟုတ် `A` ကို ရွေးပြီး နေရာတစ်ခု၏ ထောင့်နှစ်ခုကို ရွေးပါ။
3. ထို layer ပေါ်ရှိ သို့မဟုတ် ထိုနေရာရှိ objects များအပေါ် အခြားသူများ၏ ပြင်ဆင်မှုများကို ပြန်ယူပြီး သူတို့အား သင် ထိုနေရာတွင် အလုပ်လုပ်နေကြောင်း အသိပေးသည်။ သင့်နေရာကို ဒက်ရှ်ဘောင်အဖြစ် မြင်ရသည်; အခြားသူများက သင့်အရောင်နှင့် သင့်အမည်ဖြင့် မြင်ရပြီး သင် ထိန်းထားသော layer များကို ၎င်းတို့ပုံဆွဲ၏ ဘယ်ဘက်အပေါ်ထောင့်တွင် စာရင်းပြသည်။
4. `LIVEHOLD` ပြီး `R` သည် သင် ထိန်းထားသည်အားလုံးကို လွှတ်သည်။ session မှ ထွက်လျှင်လည်း လွှတ်သည်။

session ရှိ မည်သူမဆို ထိန်းနိုင်သည်၊ host အပါအဝင်; host ၏ lock များက အပေါ်မှ ဆက်လုပ်သည်။ hold ကို ဖိုင်တွင် ဘယ်တော့မှ မသိမ်းပါ။

## ပြင်ဆင်မှု ပြန်ယူခံရသည့်အခါ

host ၏ ပုံဆွဲ မိတ္တူသည် ပြင်ဆင်မှု တိုင်းကို စစ်ဆေးသည်။ အချို့ဝင်ခွင့်မရပါ၊ CadCraft က သင့်မျက်နှာပြင်တွင် ပြန်ယူပြီး command line တွင် အကြောင်းပြသည်၊ ဥပမာ:

- သင့်ရှေ့မှ တစ်စုံတစ်ဦးက object၊ ၎င်းလိုအပ်သော layer သို့မဟုတ် block ကို ဖျက်ထားခဲ့သည်။
- တစ်စုံတစ်ဦးက ထို object ကို တည်းဖြတ်နေသည်၊ သို့မဟုတ် ၎င်း၏ layer သို့မဟုတ် ၎င်းရှိ နေရာကို ထိန်းထားသည်။
- host က lock ချထားသည်။
- သင် ထည့်သော block ကို purge လုပ်ထားသည်၊ သို့မဟုတ် သင် ဖျက်သော layer တွင် objects ကျန်နေသေးသည်။

## Undo သည် သင့်ကိုယ်ပိုင်အလုပ်ကိုသာ ပြန်ဖျက်သည်

{{key:Mod+Z}} နှင့် {{ui:Undo}} သည် သင်၏ နောက်ဆုံး command အားလုံးကို ပြန်ဖျက်ပြီး အခြားသူများ၏ အလုပ်ကို မထိပါ။ နောက်ပိုင်း တစ်စုံတစ်ဦးက တူညီသော အရာကို ပြောင်းထားလျှင် ဘာမျှ မပြန်ဖျက်ပါ၊ command line က ဘယ်သူ ပြောင်းသလဲ ပြောသည်။ {{key:Mod+Y}} သည် ပြန်လုပ်သည်။

## Lock များ (host)

host သည် objects များ သို့မဟုတ် layer တစ်ခုလုံးကို ကာကွယ်နိုင်သည်၊ ဘယ်သူမျှ ပြောင်းမရအောင်၊ host ကိုယ်တိုင်အပါအဝင်၊ ဖွင့်မချင်း:

1. objects များကို ရွေးပြီး `LIVELOCK` ကို ရိုက်ကာ {{key:Enter}} ကို နှိပ်ပါ။ သို့မဟုတ် ဘာမျှ မရွေးဘဲ `LIVELOCK` ကို ရိုက်ပြီး `L` ကို ရွေးကာ layer အမည်ဖြင့် lock ချပါ: ထို layer သို့ နောက်ပိုင်း ထည့်သော objects များကိုလည်း lock ချသည်။
2. lock ထားသော objects များကို ဒက်ရှ်ဖြင့် ဆွဲပြီး "Host က သော့ခတ်ထားသည်" အမှတ်အသားကို လူတိုင်း၏ မျက်နှာပြင်တွင် ပြသည်။
3. `LIVEUNLOCK` သည် ထိုနည်းလမ်းဖြင့် ပြန်ဖွင့်သည်။

lock များသည် session နှင့်အတူ ရှိပြီး session ပြီးဆုံးသည်နှင့် အဆုံးသတ်သည်၊ ဖိုင်တွင် ဘယ်တော့မှ မသိမ်းပါ။

## တူညီသော ဖိုင်ဖြင့် ပေါင်းခြင်း

host ဖွင့်ထားသော ဖိုင်အတိအကျကို သင် ဖွင့်ထားလျှင် (ဝေမျှထားသော ဖိုဒါ သို့မဟုတ် တူညီသော မိတ္တူမှ) သင့် CadCraft window မှ Studio တွင် ပေါင်းပါ: {{ui:Live (အသုံးပြုမှုအလေး)}} panel ကို ဖွင့်ပြီး host ၏ code ဖြင့် {{ui:ဤနေရာသို့ ပေါင်းရန်}} ကို သုံးပါ။ host ဖွင့်ပြီးကတည်းက ပြောင်းထားသော ပြောင်းလဲမှုများသာ သွားသဖြင့် ပုံဆွဲကြီးဖြစ်လည်း ချက်ချင်း အဆင်သင့်ဖြစ်သည်။ သင့်ဖိုင်က တခြား ဖိုင်ဖြစ်လျှင် host ၏ ပုံဆွဲသည် သင့်မျက်နှာပြင်ပေါ် ၎င်းကို အစားထိုးသည် (သင့်ဖိုင်သည် ယင်းအတိုင်း ရှိနေသည်)။ ဤအလုပ်သည် သင်ဖွင့်ပြီးကတည်းက ပုံဆွဲ မပြောင်းထားသည့် အခါတွင်သာ အလုပ်လုပ်သည်။

## Session ထဲရှိ အကူအညီပေးသူများ

သင့် CadCraft window သို့ ချိတ်ဆက်ထားသော အကူအညီပေးသူ (AI အကူအညီပေးသူများနှင့် အလုပ်လုပ်ခြင်း ဆိုင်ရာ အကူအညီကို ကြည့်ပါ) သည် ကိုယ်ပိုင် ပါဝင်သူ အဖြစ် session သို့ ဝင်သည်၊ လူအားလုံးအတွက် "Assistant (via <သင့်အမည်>)" ဟု ပြသည်။ host က လူတစ်ဦးကဲ့သို့ ခွင့်ပြုသည်; host ၏ကိုယ်ပိုင် အကူအညီပေးသူ ချက်ချင်း ဝင်သည်။ ၎င်း၏ ပြောင်းလဲမှုများတွင် ကိုယ်ပိုင် undo ရှိသည်: သင်၏ {{key:Mod+Z}} က သင့်အလုပ်ကို ပြန်ဖျက်သည်၊ အကူအညီပေးသူ၏ undo က ၎င်း၏ကိုယ်ပိုင်အရာကိုသာ ပြန်ဖျက်သည်။ သင် ချိတ်ဆက်ဖြတ်လျှင် သို့မဟုတ် ထွက်လျှင် session မှ ထွက်သည်၊ သင် တည်းဖြတ်နိုင်နေချိန်တွင်သာ session တွင် အလုပ်လုပ်နိုင်သည်။

## browser မှ ပေါင်းခြင်း

Studio မရှိသော အဖွဲ့ဝင်တစ်ဦးက host ၏ code အောက်ရှိ ပုံကို ဖုန်း၊ tablet သို့မဟုတ် ကွန်ပျူတာဖြင့် တူညီသော network ပေါ်တွင် scan လုပ်နိုင်သည်။ CadCraft သည် browser တွင် ဖွင့်ပြီး command line တွင် သင့်အမည်ကို မေးသည်၊ host က ခွင့်ပြုလိုက်သည်နှင့် host ၏ ပုံဆွဲဖြင့် ဖြည့်သည်။ invite link က အခြား network မှ ပေါင်းနိုင်စေသည်: host သည် app အတွက် Team Cloud Plan နေရာတစ်ခု လိုအပ်သည်၊ အခြားသူများ အခမဲ့ ပေါင်းသည်၊ link သည် host ၏ session ဖွင့်နေချိန်တွင်သာ အလုပ်လုပ်သည်။

## လူများစွာ ပုံဆွဲတစ်ခုတွင်

ပြင်ဆင်မှု တိုင်းသည် session ရှိ လူအားလုံးထံ ရောက်သည်၊ ထို့ကြောင့် လူ ပိုများလေ ပြောင်းလဲမှု တိုင်းသည် လူတစ်ဦးချင်းထံ ရောက်ရန် ပိုကြာလေ ဖြစ်ပြီး၊ ကွန်ပျူတာ နှေးသူနှင့် connection နှေးသူတို့သည် ပထမ နောက်ကျသည်။ session ၏ ပုံမှန်အရွယ်အစားသည် လူ ၂၀ ဖြစ်ပြီး host က session တစ်ခုအတွက် ပိုခွင့်ပြုနိုင်သည် (အတူတကွ live ဆိုင်ရာ အကူအညီကို ကြည့်ပါ)။ လူများစွာဖြင့် ပုံဆွဲနှေးလျှင် လူနည်းခြင်း၊ တစ်ချိန်တည်း တည်းဖြတ်သူနည်းခြင်း၊ သို့မဟုတ် connection ကောင်းခြင်းက ကူညီသည်။

## session ပြီးဆုံးသည့်အခါ

host ကသာ ပုံဆွဲကို သိမ်းသည်။ host က session ကို အဆုံးသတ်သောအခါ အခြားသူအားလုံးသည် မသိမ်းရသေးသော မိတ္တူကို ထားရှိသည်: ထိန်းထားလိုလျှင် သိမ်းပါ။

:::note
ပြန်ယူခံရသော အရာကို သင့်ကိုယ်တိုင် မျက်နှာပြင်ပေါ်တွင် ပတ်ဝန်းကျင် objects များ၏ အပေါ်တွင် ဆွဲထားသည်၊ ပုံဆွဲကို ပြန်ဖွင့်သည်အထိ။ ထပ်နေသော hatch များနှင့် အရောင်ဖြည့်ထားသော objects များသည် host ၏ မိတ္တူနှင့် ကွဲပြားစွာ ပေါ်နိုင်သည်; ပုံဆွဲ ကိုယ်တိုင်မှာ တူညီသည်။
:::
