## အရွယ်အစားတိုင်းအတွက် ဇယားတစ်ခု

{{ui:Parameters}} panel ({{ui:Parametric}} အုပ်စုရှိ {{ui:Parameters}} ခလုတ်၊ သို့မဟုတ် {{cmd:PARAMETERS}} ကို ရိုက်ပါ) သည် dimensional constraint အားလုံး (`d1`၊ `rad1`၊ `dia1`၊ `ang1`၊ သို့မဟုတ် သင်ပေးထားသော အမည်) နှင့် သင့်ကိုယ်ပိုင် parameter များကို အတူတကွ စာရင်းပြုစုသည်။ မည်သည့်အမည်ကိုမဆို မည်သည့် expression တွင်မဆို သုံးနိုင်သည်။

အတန်းတစ်ခုစီတွင်-

- **Name**: အမည်အသစ် ရိုက်၍ ပြောင်းပါ၊ ၎င်းကို သုံးသော expression အားလုံး လိုက်ပြောင်းသည်။
- **Expression**: ဂဏန်း (`40`) သို့မဟုတ် expression (`width / 2 + gap`)။ ထိုအထဲတွင် ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ- ပုံဆွဲက လိုက်သည်။
- **Value**: ၎င်း တွက်ထွက်သော တန်ဖိုး။ expression မောင်းနေသော အတန်းတွင် ဤနေရာ၌လည်း ဂဏန်းရိုက်နိုင်သည်: CadCraft က ၎င်းနောက်ကွယ်ရှိ parameter ကို တွက်သည်။ `d1 = width / 2` ဖြင့် d1 ၏ value တွင် `30` ရိုက်လျှင် `width` ကို 60 သို့ သတ်မှတ်သည်။

parameter နှစ်ခုက တန်ဖိုးတစ်ခုကို မောင်းနေသောအခါ (`width / 2 + gap`)၊ dialog က မေးသည် မည်သည့်တစ်ခုကို ပြောင်းမည်ဟု။ ပြောင်းလဲမှု တစ်ခုစီသည် ပြန်ဖျက်ရန် အဆင့်တစ်ခု ({{key:Mod+Z}}) ဖြစ်သည်။

## သင့်ကိုယ်ပိုင် ထည့်ခြင်း

1. {{ui:Parameters}} panel ကို ဖွင့်ပါ။
2. အမည် (`gap`) နှင့် တန်ဖိုး (`10`) ကို ရိုက်ပြီး {{ui:Add}} ကို ရွေးပါ။
3. သုံးပါ- d1 ၏ expression တွင် `width / 2 + gap` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။

အမည်များသည် အက္ခရာ သို့မဟုတ် `_` ဖြင့် စပြီး အက္ခရာ၊ ဂဏန်းနှင့် `_` ကို ထည့်နိုင်သည်။ Function အမည်များ၊ `pi` နှင့် ယူနစ်အမည်များသည် အမည် မဖြစ်နိုင်ပါ။

## Expression များ

| ရေးပုံ | အဓိပ္ပာယ် |
|---|---|
| `+ - * / ^ %` | ပေါင်း၊ နုတ်၊ မြှောက်၊ စား၊ ထပ်ကိန်း၊ ကျန်ကိန်း |
| `( )` | အုပ်စုဖွဲ့ခြင်း |
| `sin cos tan asin acos atan atan2` | ထောင့်သိပ္ပံ (ဒီဂရီဖြင့်) |
| `sqrt pow exp ln log abs sign` | အမြစ်များ၊ ထပ်ကိန်းများ၊ logarithm များ |
| `ceil floor int round min max` | ဝိုင်းခြင်းနှင့် ကန့်သတ်ချက်များ |
| `if(a > b, x, y)` | ရွေးချယ်မှု |
| `pi` | 3.14159… |

ဂဏန်းများတွင် ယူနစ်ပါနိုင်သည်- `25mm`၊ `1in`၊ `2'`၊ `90deg`။ ယူနစ်ပါသော အလျားများကို မီလီမီတာသို့ ပြောင်းသည်၊ ထို့ကြောင့် မီလီမီတာဖြင့် တိုင်းထားသော ပုံဆွဲများတွင်သာ ယူနစ်သုံးပါ၊ အခြားတွင် ရိုးရိုး ဂဏန်းများ ရိုက်ပါ။

## Command line တွင်

`-PARAMETERS` သည် panel မပါဘဲ အလုပ်တူ လုပ်သည်- `N` အသစ်၊ `E` တည်းဖြတ် (dimensional constraint အပါအဝင်)၊ `R` နာမည်ပြောင်း၊ `D` ဖျက်၊ `?` စာရင်း။

## ငြင်းပယ်သည်များ

- ကိုယ်တိုင် သို့မဟုတ် အခြားများမှတစ်ဆင့် ကိုယ်ကို အသုံးပြုသော expression- "width, d1 use each other."
- အရွယ်အစားက ယူနိုင်မည်မဟုတ်သော တန်ဖိုး- အနုတ်အလျား၊ 180° ထက်ကြီးသော ထောင့်။
- ပုံဆွဲက ၎င်း၏ အခြား constraint များနှင့်အတူ မယူနိုင်သော တန်ဖိုး- ဘာမျှ မပြောင်းပါ၊ စာသားက ဟန့်တားနေသော constraint များကို အမည်ဖြင့် ပြသည်။
- အသုံးပြုနေသော parameter ကို ဖျက်ခြင်း- panel က ၎င်း၏ တန်ဖိုးကို ၎င်းတို့ထဲသို့ ဦးစွာ ရေးရန် ကမ်းလှမ်းသည်။ dimensional constraint ၏ အမည်ကို constraint ဖျက်ခြင်းဖြင့်သာ ဖျက်သည်။
