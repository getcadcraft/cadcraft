## လုပ်ဆောင်နိုင်သည်များ

dynamic block များပါသော DWG ကို ဖွင့်သောအခါ အောက်ပါအတိုင်း အလုပ်လုပ်သည်:

- **အစစ်အမှန်အမည်များ။** dynamic block သည် {{ui:Blocks}} panel တွင် ၎င်း၏ကိုယ်ပိုင်အမည် ("Receptacle"၊ "Sink") ဖြင့် ပါဝင်သည်၊ အမည်မရှိသော `*U` block အဖြစ် မဟုတ်ပါ။
- **သိမ်းထားသော အခြေအနေ။** reference တစ်ခုစီက အခြား program ပြခဲ့သည့်အတိုင်း ပြသည်: သတ်မှတ်ထားသော visibility state၊ သိမ်းစဉ်က ဆန့်ထားခြင်း သို့မဟုတ် လှန်ထားခြင်း။
- **Visibility state ပြောင်းခြင်း။** reference တစ်ခု (သို့မဟုတ် block တူတူ အများအပြား) ကို ရွေး၊ {{ui:Properties}} ကို ဖွင့်ပြီး {{ui:Custom}} အပိုင်းတွင် {{ui:Visibility}} စာရင်းမှ အခြား state တစ်ခုကို ရွေးပါ။ reference သည် ထို state ကို ချက်ချင်း ပြသည်၊ attribute များလည်း အတူ: state က ဝှက်ထားသည်များ ပျောက်သွားပြီး ပြသသည်များ တန်ဖိုးများနှင့်အတူ ပေါ်လာသည်။ reference သည် တန်ဖိုးအားလုံးကို ထိန်းထားသဖြင့် ဘာမျှ ဗလာ မဖြစ်ပါ; {{ui:Properties}} က ဝှက်ထားသည်များကို "hidden" ဟု အမှတ်အသားဖြင့် ပြသည်။ {{key:Mod+Z}} သည် အဟောင်း state ကို တစ်ဆင့်တည်းဖြင့် ပြန်ထားသည်။
- **Grip များ။** ရွေးထားသော dynamic block သည် ၎င်း၏ parameter များရှိရာနေရာတွင် ကိုယ်ပိုင် grip များကို ပြသည်: visibility state အတွက် သေးငယ်သော တြိဂံ (ကလစ်နှိပ်ပါက state စာရင်း)၊ အကွာအဝေး အစွန်းတွင် မြားများ၊ flip အတွက် မြားနှစ်ခု။ visibility grip သာ ယခု လုပ်ဆောင်သည်; အခြားများက ၎င်းကို status bar တွင် ပြောသည်။
- **အခြားတန်ဖိုးများ၊ ဖတ်ရုံသာ။** {{ui:Custom}} တွင် visibility စာရင်းအောက်၌ block ၏ အကွာအဝေးများ၊ alignment ထောင့်များ၊ flip အခြေအနေများနှင့် အမှတ်များကို ပုံဆွဲက ထားသည့်အတိုင်း ပြသည်။
- **Visibility state များ တည်းဖြတ်ခြင်း။** {{cmd:BEDIT}} ဖြင့် block ကို ဖွင့်ပါ: editor သည် state တစ်ခုကို ပြသည်၊ ပုံဆွဲအပေါ်ရှိ bar တွင် အမည်ဖြင့် (ထိုနေရာတွင် အခြားတစ်ခု ရွေးနိုင်သည်)။ {{cmd:BVSTATE}} ကို ရိုက်၍ ပြောင်းပါ၊ state ထည့် (အားလုံးကို ဝှက်ခြင်း၊ အားလုံးကို ပြခြင်း သို့မဟုတ် ပြနေသည်ကို ထိန်းခြင်း)၊ အမည်ပြောင်း သို့မဟုတ် ဖျက်ပါ။ {{cmd:BVHIDE}} သည် ရွေးထားသော အရာများကို ပြနေသော state တွင် ဝှက်သည်; {{cmd:BVSHOW}} သည် ဝှက်ထားသည်များကို မှေးမှိန်ပြပြီး ပြန်ယူရန် နှိပ်နိုင်သည်။ block ကို သိမ်းပါ: အမည်ပြောင်းထားသော state သို့ သတ်မှတ်ထားသော reference များက ၎င်းကို အမည်အသစ်ဖြင့် ထိန်းထားမည်၊ ဖျက်ထားသော state သို့ သတ်မှတ်ထားသောများကတော့ ပထမ state ကို ပြမည်။
- **Dynamic အဖြစ် ထိန်းထားခြင်း။** ပုံဆွဲဝင်လာသော version တွင် DWG အဖြစ် သိမ်းသောအခါ block များသည် dynamic ဖြစ်ဆဲ ဖြစ်ပြီး သင်ရွေးထားသော state ဖြင့် ရှိနေမည်: အခြား program က ၎င်းတို့ကို တူညီသော dynamic block များအဖြစ် ဖွင့်သည်။ သင်တည်းဖြတ်ထားသော visibility state များကိုလည်း သိမ်းသည်: အသစ်အမည်များ၊ သင်ထည့်ထားသော state များနှင့် တစ်ခုစီက ပြသသည်များ။

## ဖတ်ရုံသာ သို့မဟုတ် ယခုမရှိသေးသည်များ

| ယခုမရှိသေးသည် | အစားထိုး၊ ယခုအချိန်တွင် |
|---|---|
| အကွာအဝေး၊ ထောင့်၊ သို့မဟုတ် flip များ ပြောင်းခြင်း (stretch၊ move၊ flip လုပ်ဆောင်ချက်များ) | {{ui:Custom}} တွင် ဖတ်ရုံသာ ပြသည်; block ကို ဖန်တီးခဲ့သော program တွင် တည်းဖြတ်ပါ။ |
| Lookup၊ XY၊ rotation နှင့် polar parameter များ | ဖတ်ထားခြင်းမရှိသေး: reference သည် သိမ်းထားသည့်အတိုင်း ပြသည်။ |
| Distance၊ flip နှင့် point grip များကို ဆွဲခြင်း | ၎င်းတို့၏ parameter များရှိရာနေရာတွင် ပြသည်; visibility grip နှင့် Properties ရှိ {{ui:Visibility}} စာရင်းသာ state များကို ပြောင်းသည်။ |
| Dynamic block များ ဖန်တီးခြင်း (parameter ထည့်ခြင်း၊ သို့မဟုတ် မရှိသော block တွင် visibility state ထည့်ခြင်း) | CadCraft တွင် ဖန်တီးသော block များသည် ရိုးရိုး block များ ဖြစ်သည်; {{cmd:BPARAMETER}} က ထိုသို့ ပြောပြသည်။ |
| Block editor တွင် visibility state ပါသော block ၏ အရာများကို ထည့်ခြင်း သို့မဟုတ် ဖျက်ခြင်း | ထို block ကို ရိုးရိုး block အဖြစ် သိမ်းသည် (editor က ပိတ်သောအခါ ထိုသို့ ပြောသည်)။ |
| DWG အခြား version သို့မဟုတ် DXF တွင် dynamic အဖြစ် ထိန်းခြင်း | ရွေးထားသော state ကို ပြသော ရိုးရိုး block များအဖြစ် သိမ်းပြီး သိမ်းခြင်းက ထိုသို့ ပြောသည်။ |

:::note
{{cmd:BEDIT}} တွင် အရာဝတ္ထုများကို ရွှေ့ခြင်း သို့မဟုတ် ပြောင်းခြင်းသည် visibility state ပါသော block ကို dynamic အဖြစ် ထားသည်။ state မရှိသော block၊ သို့မဟုတ် editor တွင် အရာဝတ္ထုများ ထည့်ခြင်း သို့မဟုတ် ဖျက်ခြင်း ပြုလုပ်ခံရသော block သည် ရိုးရိုး block ဖြစ်သွားသည်။
:::
