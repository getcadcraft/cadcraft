ဖြတ်လမ်းလင့်များကို သင့်ကွန်ပျူတာအတွက် ပြသသည်။ Mac တွင် အောက်ပါ {{key:Mod}} ဖြတ်လမ်းလင့် အားလုံးသည် Command key ကို သုံးသည်၊ Control key ကလည်း အလုပ်လုပ်သည်။ ကီးများကို မည်သို့ ရေးသလဲနှင့် Mac တွင် F-key များကို မည်သို့ သုံးသလဲ ဆိုသည်ကို [ကီးများ၊ မောက်စ်များနှင့် trackpad များ](common:keys) တွင် ကြည့်ပါ။

## အမိန့်များ ရိုက်ခြင်း

| ကီး | ဘာလုပ်သလဲ |
|---|---|
| မည်သည့် အက္ခရာ၊ ဂဏန်း သို့မဟုတ် သင်္ကေတ | Pointer ဘယ်နေရာရှိနေသည်ဖြစ်စေ command line သို့ ရောက်သည်၊ panel ရှိ အကွက်တစ်ခုတွင် ကာဆာ မရှိလျှင် |
| {{key:Enter}} | ရိုက်ထားသည်ကို ပို့သည်။ Prompt အလွတ်ဖြစ်လျှင်: နောက်ဆုံး အမိန့်ကို ပြန်လုပ်သည်၊ အမိန့်ကို အဆုံးသတ်သည်၊ ရွေးချယ်မှုကို ပြီးစီးသည်၊ သို့မဟုတ် `<…>` အတွင်းရှိ မူလတန်ဖိုးကို လက်ခံသည် |
| {{key:Space}} | {{key:Enter}} နှင့် တူသည်၊ CadCraft က စာသား (စာသား၊ block အမည်၊ dimension စာသား) တောင်းနေချိန်မှလွဲ၍ ထိုနေရာတွင် space ရိုက်သည် |
| {{key:Esc}} | အမိန့်ကို ပယ်ဖျက်သည်။ အမိန့် မလည်ပတ်နေချိန်တွင်: grip ရွှေ့ခြင်း သို့မဟုတ် ရွေးချယ်ခြင်း အကွက်ကို ပယ်ဖျက်ပြီး ရွေးချယ်မှုကို ရှင်းသည် |
| {{key:Tab}} | Command line ၏ ညာဘက်တွင် ပြသထားသော အကြံပြုအမိန့်ကို လက်ခံသည်။ ဘာမျှ မရိုက်ထားဘဲ pointer သည် ထပ်နေသော အရာဝတ္ထုများပေါ်တွင် ရှိလျှင်: ထိုနေရာရှိ နောက်တစ်ခုကို မီးမောင်းထိုးသည် (ရွေးရန် နှိပ်ပါ) |
| {{key:Up}} {{key:Down}} | ယခင် ရိုက်ခဲ့သော လိုင်းများကို လှန်ကြည့်သည် (နောက်ဆုံး 100) |

## ပုံဆွဲခြင်းနှင့် တည်းဖြတ်ခြင်း

| ကီး | ဘာလုပ်သလဲ |
|---|---|
| {{key:Mod+Z}} | နောက်ဆုံး အမိန့်ကို ပြန်ဖျက်သည် |
| {{key:Mod+Y}} သို့မဟုတ် {{key:Mod+Shift+Z}} | ပြန်လုပ်သည် |
| {{key:Mod+A}} | ဖွင့်ထားသော tab ပေါ်တွင် တည်းဖြတ်နိုင်သော အရာဝတ္ထု အားလုံးကို ရွေးသည် ({{cmd:SELECTALL}})။ Command line တွင် တစ်ခုခု ရိုက်ထားလျှင် ထိုစာသားကို ရွေးသည် |
| {{key:Delete}} | ရွေးထားသော အရာဝတ္ထုများကို ဖျက်သည် ({{cmd:ERASE}})၊ command line တွင် တစ်ခုခု ရိုက်ထားလျှင် မဟုတ် |
| {{key:Backspace}} | Command line တွင် ကာဆာ မရှိသောအခါ ရွေးထားသော အရာဝတ္ထုများကို ဖျက်သည်; command line တွင် ရိုက်ထားသည်ကို ဖျက်သည် |
| {{key:Esc}} | အမိန့် မလည်ပတ်နေချိန်တွင်: ရွေးချယ်မှုကို ရှင်းသည် ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | ပုံဆွဲ၏ ဖော်မတ် (DWG သို့မဟုတ် DXF) ဖြင့် မိတ္တူ သိမ်းသည် |
| {{key:Mod+Shift+S}} | အမည်ပြောင်း၍ သိမ်းရန်: DWG သို့မဟုတ် DXF ကို ရွေး၍ မိတ္တူ သိမ်းသည် |
| {{key:Mod+O}} | DWG သို့မဟုတ် DXF ကို ဖွင့်သည် |
| {{key:Mod+P}} | PDF သို့ ပလော့တ်လုပ်သည် |

အမိန့် လည်ပတ်နေစဉ် ပြန်ဖျက်ခြင်း၊ ပြန်လုပ်ခြင်း၊ အားလုံးရွေးခြင်းနှင့် ပလော့တ်လုပ်ခြင်း မလုပ်ဆောင်ပါ: {{key:Esc}} ကို အရင်နှိပ်ပါ။

## ကူးခြင်း၊ ဖြတ်ခြင်းနှင့် ကူးထည့်ခြင်း

| ကီး | ဘာလုပ်သလဲ |
|---|---|
| {{key:Mod+C}} | ရွေးချယ်မှုကို clipboard သို့ ကူးသည် ({{cmd:COPYCLIP}})။ ဘာမျှ မရွေးထားလျှင် CadCraft က အရာဝတ္ထုများကို မေးသည် |
| {{key:Mod+X}} | ဖြတ်ရန်: ရွေးချယ်မှုကို ကူးပြီး ဖျက်သည် ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | ကူးထည့်ရန်: မိတ္တူသည် ကာဆာကို လိုက်သည်; နေရာချရန် နှိပ်ပါ၊ သို့မဟုတ် အမှတ်တစ်ခု ရိုက်ပါ ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | နေရာတွင် ကူးထည့်ရန်: ကူးခဲ့သော ကိုဩဒိနိတ်နေရာတွင် ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | ပွားရန်: ရွေးချယ်မှု၏ မိတ္တူသည် pointer နှင့်အတူ ရွေ့သည်; နေရာချရန် နှိပ်ပါ၊ {{key:Esc}} သည် ဘာမျှ မထားပါ ({{cmd:DUPLICATE}}) |

အလားတူ လုပ်ဆောင်ချက်များသည် toolbar ၏ {{ui:တည်းဖြတ်ရန်}} အုပ်စု ({{ui:ကူးရန်}}၊ {{ui:ကူးထည့်ရန်}}) နှင့် ၎င်း၏ {{ui:နောက်ထပ်}} မီနူးတွင် ရှိသည်။ အခြား အမိန့် လည်ပတ်နေစဉ် ၎င်းကို အရင်ပြီးဆုံးစေပါ သို့မဟုတ် {{key:Esc}} ကို နှိပ်ပါ; မိတ္တူသည် ကာဆာကို လိုက်နေစဉ် {{key:Mod+V}} သို့မဟုတ် {{key:Mod+D}} ကို ထပ်နှိပ်လျှင် အစမှ ပြန်စသည်။ Command line တွင် တစ်ခုခု ရိုက်ထားလျှင် သို့မဟုတ် အမိန့်က စာသား တောင်းနေလျှင် ဤကီးများသည် ထိုစာသားကို ကူး၊ ဖြတ်နှင့် ကူးထည့်သည်။ ကြည့်ရန် [ကူး၊ ကူးထည့်နှင့် ပွားခြင်း](topic:copy-paste)။

| ကီး | ပြောင်းခလုတ် | Status bar ခလုတ် |
|---|---|---|
| {{key:F3}} | Object snaps ဖွင့်/ပိတ် | {{ui:Snap}} |
| {{key:F7}} | Grid ဖွင့်/ပိတ် | {{ui:ဂရစ်}} |
| {{key:F8}} | Ortho ဖွင့်/ပိတ် | {{ui:Ortho}} |
| {{key:F10}} | Polar tracking ဖွင့်/ပိတ် | {{ui:Polar}} |
| {{key:F11}} | Object snap tracking ဖွင့်/ပိတ် | {{ui:Track}} |
| {{key:F12}} | Dynamic input ဖွင့်/ပိတ် | {{ui:Dyn}} |

:::mac
Mac တွင် F3၊ F7 နှင့် F8 သည် များသောအားဖြင့် Mission Control နှင့် media key များ ဖြစ်သည်။ **fn** ကို ၎င်းတို့နှင့်အတူ ဖိထားပါ၊ သို့မဟုတ် System Settings တွင် standard function keys ကို ဖွင့်ပါ၊ [ကီးများ၊ မောက်စ်များနှင့် trackpad များ](common:keys) တွင် ဖော်ပြထားသည့်အတိုင်း။ Status bar ခလုတ်များသည် အမြဲ အလုပ်လုပ်သည်။
:::

:::firefox
Firefox ရှိ F7 သည် caret browsing ဖွင့်ရန် မေးနိုင်သည်။ **ဟင့်အင်း** ကို ရွေးပါ၊ ထပ်မေးနေလျှင် {{ui:ဂရစ်}} ခလုတ်ကို သုံးပါ။
:::

## အကူအညီ

| ကီး | ဘာလုပ်သလဲ |
|---|---|
| {{key:F1}} | ဤအကူအညီကို ပုံဆွဲဘေးတွင် ဖွင့်သည် သို့မဟုတ် ပိတ်သည်။ အမိန့် လည်ပတ်နေစဉ်လည်း အလုပ်လုပ်သည်၊ command line သို့ ဘယ်တော့မှ မရောက်ပါ။ |
| {{key:Esc}} | အကူအညီ panel တွင် ကာဆာရှိစဉ်: ရှာဖွေမှုကို ရှင်းသည်၊ သို့မဟုတ် panel ကို ပိတ်သည် |

ဘားအပေါ်ရှိ {{ui:အကူအညီ}} ခလုတ်သည် {{key:F1}} နှင့် တူသည်ကို လုပ်သည်။ အကူအညီ၏ ရှာဖွေရေးအကွက်တွင် ရိုက်နေစဉ် command line သို့ ဘာမျှ မရောက်ပါ။ ကီးများကို CadCraft သို့ ပြန်ပေးရန် ပုံဆွဲပေါ်တွင် နှိပ်ပါ; panel သည် ဘေးတွင် ဖွင့်ထားဆဲ ဖြစ်သည်။

:::mac
Mac keyboard တွင် **fn** ကို ဖိထားပြီး F1 ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:အကူအညီ}} ကို နှိပ်ပါ။
:::

## မျက်နှာပြင်

| ကီး | ဘာလုပ်သလဲ |
|---|---|
| {{key:Ctrl+Shift+F}} | ပုံမှန်၊ full screen နှင့် ဘားများ ဖျောက်ထားသော full screen အကြား လည်ပတ်သည်။ ၎င်းသည် Mac အပါအဝင် ကွန်ပျူတာတိုင်းတွင် Control key ကို သုံးသည်။ |
| {{key:Left}} {{key:Right}} | ပုံဆွဲအောက်ရှိ tab ကို ဖိုကပ်ထားစဉ်: ယခင် သို့မဟုတ် နောက် tab |

Full screen တွင် browser က ပထမ {{key:Esc}} ကို full screen မှ ထွက်ရန် သုံးနိုင်သည်။ အမိန့်ကို ပယ်ဖျက်ရန် {{key:Esc}} ကို ထပ်နှိပ်ပါ။

## ဒိုင်ယာလော့ခ်များ

| ကီး | ဘာလုပ်သလဲ |
|---|---|
| {{key:Esc}} | ဒိုင်ယာလော့ခ်ကို ပိတ်သည် ({{ui:PDF သို့ ပလော့ရန်}}၊ သို့မဟုတ် "မသိမ်းရသေးသော ပြောင်းလဲမှုများ" ကဲ့သို့ မေးခွန်းတွင် {{ui:ပယ်ဖျက်ရန်}} ကို ဆိုလိုသည်) |
| {{key:Tab}} | ဒိုင်ယာလော့ခ်၏ ဆက်တင်များနှင့် ခလုတ်များကြား ရွှေ့သည် |

ဒိုင်ယာလော့ခ် ဖွင့်ထားစဉ် ပုံဆွဲ၏ ကီးများ ပိတ်ထားသည်။

## Panel အကွက်များ

ညာဘက် သို့မဟုတ် ဘယ်ဘက် panel ရှိ အကွက်တစ်ခုတွင်:

| ကီး | ဘာလုပ်သလဲ |
|---|---|
| {{key:Enter}} | တန်ဖိုးကို အသုံးချပြီး အကွက်မှ ထွက်သည် |
| {{key:Esc}} | ဟောင်းတန်ဖိုးကို ပြန်ထားပြီး အကွက်မှ ထွက်သည် |
| {{key:Tab}} | အသုံးချပြီး နောက်အကွက်သို့ ရွှေ့သည် |

အကွက်တွင် ကာဆာရှိစဉ် အက္ခရာများသည် command line သို့ မဟုတ်ဘဲ ထိုအကွက်ထဲ ရိုက်သည်။

## မောက်စ်

| လုပ်ဆောင်ချက် | ဘာလုပ်သလဲ |

## Browser က ထားသော ကီးများ

{{key:Mod+N}}၊ {{key:Mod+W}} နှင့် {{key:Mod+T}} သည် အမြဲ browser ၏ ဖြစ်သည်။ CadCraft သည် ၎င်းတို့ကို မသုံးပါ: ပုံဆွဲအသစ်အတွက် {{ui:အသစ်}} ကို သုံးပါ သို့မဟုတ် `NEW` ကို ရိုက်ပါ။ CadCraft ၏ clipboard သည် ကိုယ်ပိုင်ဖြစ်သည်: {{key:Mod+C}} နှင့် {{key:Mod+V}} သည် CadCraft ပုံဆွဲများနှင့် tab များကြား အရာဝတ္ထုများကို ကူးသည်၊ အခြားပရိုဂရမ်များသို့ သို့မဟုတ် မှ မဟုတ်ပါ။

## Move ရှိရာနေရာ

Move သည် `MOVE` အမိန့် ({{key:M}} ကီး) ဖြစ်သည်: အရာဝတ္ထုများကို ရွေး၊ ထို့နောက် base point နှင့် ဒုတိယအမှတ် သို့မဟုတ် ရိုက်ထားသော အကွာအဝေးကို ရွေးပါ။ ALIGN နှင့် DISTRIBUTE လည်း ထိုမှာ ရှိသည်။ BimCraft သည် building element များပေါ်တွင် အလုပ်တူအတွက် အမည်တူများကို သုံးသော်လည်း ၎င်း၏ {{key:M}} သည် Measure ဖြစ်ပြီး ၎င်း၏ Move သည် {{key:Shift+M}} ဖြစ်သည်။
