## သင်ပြုလုပ်မည့်အရာ

`Notes` ဟု အမည်ပေးထားသော text style တစ်ခုကို ကိုယ်ပိုင် font နှင့် အမြင့်ဖြင့် ဖန်တီးပြီး၊ အသစ်စာသားအတွက် သုံးကာ နောက်ပိုင်းတွင် style ကို ပြောင်းလျှင် ၎င်းကို သုံးထားသော မှတ်ချက်အားလုံး တစ်ပြိုင်နက် ပြောင်းသည်။

## အဆင့်များ

1. {{cmd:STYLE}} (`ST`) ကို ရိုက်ပြီး {{key:Enter}} ကို ဖိပါ၊ သို့မဟုတ် {{ui:ဆွဲရန်}} toolbar ပေါ်ရှိ {{ui:စာသားပုံစံ}} ကို နှိပ်ပါ။ {{ui:စာသားပုံစံ}} dialog သည် ပုံဆွဲထဲရှိ style များကို စာရင်းပြသည်။ ပုံဆွဲတိုင်းတွင် `Standard` ရှိသည်။
2. {{ui:အသစ်…}} ကို နှိပ်ပြီး style အသစ်၏ အမည်အဖြစ် `Notes` ကို ရိုက်ကာ {{ui:အိုကေ}} ကို နှိပ်ပါ။ Status line က "Text style Notes made and set current." ဟု ပြသည်။
3. {{ui:ဖောင့်}} တွင် font အမည်ကို ရွေးပါ သို့မဟုတ် ရိုက်ပါ။ {{ui:အမြင့် (0 = အခါတိုင်း မေးရန်)}} ကို `2.5` ကဲ့သို့ နံပါတ်တစ်ခုသို့ သတ်မှတ်ပါ၊ ထို့ကြောင့် စာသားအသစ်တိုင်း ထိုအမြင့်ရမည်။ `0` ထားလျှင် အခါတိုင်း မေးသည်။
4. ပိုကျဉ်းသော၊ ပိုကျယ်သော သို့မဟုတ် စောင်းသော စာလုံးများ လိုချင်လျှင် {{ui:အကျယ်အချိုး}} နှင့် {{ui:စောင်းထောင့် (°)}} ကို သတ်မှတ်ပါ။ နမူနာစာကြောင်းက ရလဒ်ကို ပြသည်။
5. {{ui:ပိတ်ရန်}} ကို နှိပ်ပါ။ {{cmd:TEXT}} သို့မဟုတ် {{cmd:MTEXT}} ဖြင့် စာသား ဆွဲပါ: စာသားအသစ်သည် လက်ရှိ style ကို ယူသည်။
6. သင် ဖန်တီးပြီးသား style ကို သုံးလိုလျှင် dialog ကို ပြန်ဖွင့်ပြီး စာရင်းမှ ရွေးကာ {{ui:လက်ရှိအဖြစ် သတ်မှတ်ရန်}} ကို နှိပ်ပါ။
7. ဆွဲပြီးသား စာသားတွင် style ထည့်လိုလျှင် စာသားကို ရွေးပါ၊ dialog ကို ဖွင့်ပြီး style ကို ရွေးကာ {{ui:ရွေးထားသော စာသားတွင် အသုံးပြုရန်}} ကို နှိပ်ပါ။

## နောက်ပိုင်း style ပြောင်းခြင်း

style ၏ font၊ အမြင့်၊ အကျယ် သို့မဟုတ် စောင်းမှုကို dialog တွင် ပြောင်းလျှင် ၎င်းကို သုံးသော စာသားအားလုံး လိုက်ပြောင်းသည်၊ undo အဆင့်တစ်ခုတည်းဖြင့် ({{key:Mod+Z}})။ status line က စာသား မည်မျှ လိုက်ပြောင်းသည်ကို ပြသည်။

## မှတ်ချက်များ

- {{ui:ဖျက်ရန်}} သည် `Standard` ကို ငြင်းပယ်သည်၊ စာသားက ဆက်သုံးနေသော style ကိုလည်း ငြင်းပယ်သည်: ထို စာသားကို အခြား style သို့ အရင်ပြောင်းပါ။
- Style များကို ပုံဆွဲ၏ STYLE ဇယားတွင် သိမ်းသဖြင့် DXF နှင့် DWG ဖိုင်များက ၎င်းတို့ကို ထိန်းသိမ်းထားသည်။
- Command line တွင် `-STYLE` သည် options (Current၊ New၊ Font၊ Height၊ Width၊ Oblique၊ Delete၊ List) ဖြင့် အလားတူ လုပ်သည်။
- ပုံဆွဲကို ဖတ်သော ကွန်ပျူတာတွင် မရှိသော font ကို အခြား မျက်နှာပြင်ဖြင့် ပြသသည်။
