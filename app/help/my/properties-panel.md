## သင်လေ့လာရမည့်အရာများ

Properties panel ကို ဘယ်လိုဖွင့်သလဲ၊ အရာဝတ္ထု တစ်ခု သို့မဟုတ် တစ်ရာကို တစ်ဆင့်တည်း ဘယ်လိုပြောင်းသလဲ၊ Z ပါသော တိကျသော coordinate များ ဘယ်လိုရိုက်သလဲ၊ နံပါတ်အကွက် မည်သည့်တစ်ခုတွင်မဆို expression နှင့် ယူနစ်များကို ဘယ်လိုသုံးသလဲ၊ အရာဝတ္ထုအမျိုးအစားတစ်ခုစီက ဘာကို ပြသသလဲဆိုတာ သင်ယူရမည်။

## ဖွင့်ခြင်း

panel သည် ညာဘက်တွင် ရှိသည်။ ၎င်းကို ရှေ့သို့ ယူရန်:

- {{key:Mod+1}} ကို နှိပ်ပါ၊ သို့မဟုတ် {{cmd:PROPERTIES}} (သို့မဟုတ် `PR`၊ `CH`၊ `MO`) ကို ရိုက်ပါ။
- အရာဝတ္ထုကို နှစ်ချက်နှိပ်ပါ (စာသားနှင့် multileader များသည် ၎င်းတို့၏ စာသား editor ကို ဖွင့်သည်)။

panel သည် အခြား panel များကဲ့သို့ ရွှေ့နိုင်သော panel ဖြစ်သည်: ၎င်း၏ grip ကို ဆွဲ၍ ဘယ်၊ ညာ သို့မဟုတ် အောက်ခြေတွင် ချိတ်နိုင်သည်၊ သို့မဟုတ် ပုံဆွဲပေါ်သို့ ချ၍ မျောနိုင်သည် ([panel များကို စီစဉ်ခြင်းနှင့် ဒုတိယ monitor သုံးခြင်း](common:arrange-panels) ကို ကြည့်ပါ)။

### ခေါက်သိမ်းခြင်း

panel ၏ ညာဘက်ထိပ်ရှိ pin ခလုတ်သည် **auto-hide** ကို ဖွင့်သည်: panel သည် ညာဘက်အစွန်းတွင် အနားသတ်အဖြစ် ခေါက်သိမ်းပြီး ပုံဆွဲသည် နေရာ ရရှိသည်။ အနားသတ်ကို ညွှန်ပြလျှင် (သို့မဟုတ် {{key:Mod+1}} နှိပ်လျှင်) ၎င်းသည် ပုံဆွဲပေါ်တွင် ဖွင့်သည်; ဝေးသွားလျှင် ပြန်ခေါက်သည်။ pin ကို ထပ်နှိပ်လျှင် ဖွင့်ထားသည်။ {{cmd:PROPERTIESCLOSE}} လည်း ခေါက်သိမ်းသည်။

## အပိုင်းများ

ဂုဏ်သတ္တိများကို ခေါက်နိုင်သော အပိုင်းများအဖြစ် စုထားသည်: **General**၊ **Geometry**၊ **Text**၊ **Lines and arrows**၊ **Fit**၊ **Primary units**၊ **Alternate units**၊ **Tolerances**၊ **Pattern**၊ **Misc**၊ ပြီးတော့ block များအတွက် **Attributes** နှင့် **Library item**။ အပိုင်းအမည်ကို နှိပ်ပြီး ခေါက်သိမ်း သို့မဟုတ် ဖွင့်ပါ; CadCraft က ခေါက်ထားသည်များကို မှတ်ထားသည်။

အမည်များနှင့် တန်ဖိုးများကြား မျဉ်းပါးကို ဆွဲ၍ အမည်များကို ကျယ်ရန် သို့မဟုတ် ကျဉ်းရန် ပြုလုပ်နိုင်သည်။ နှစ်ချက်နှိပ်လျှင် မူလအတိုင်း ပြန်ရောက်သည်။ keyboard ဖြင့် ၎င်းကို focus ပြုလုပ်ပြီး arrow key များ သုံးပါ။

## တန်ဖိုးပြောင်းခြင်း

1. မျဉ်းတစ်ခုကို နှိပ်ပါ။ ခေါင်းစဉ်က "Line" ဟု ဖတ်ရသည်။
2. {{ui:Length}} ကို နှိပ်ပါ။ တည်းဖြတ်နေစဉ် အကွက်သည် ပိတ်ထားသော တန်ဖိုးမဟုတ်ဘဲ အပြည့်အစုံ တန်ဖိုးကို ပြသည်။
3. `2500` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။ မျဉ်းသည် ယခု 2500 ရှည်ပြီး ၎င်း၏ စတင်အမှတ်နှင့် ထောင့်ကို ထိန်းထားသည်။

{{key:Enter}} သို့မဟုတ် အခြားနေရာကို နှိပ်လျှင် တန်ဖိုးကို အသုံးပြုသည်; {{key:Esc}} က အဟောင်းတန်ဖိုးကို ပြန်ထားသည်။ ပြောင်းလဲမှုတိုင်းသည် undo တစ်ကြိမ်ဖြစ်သည်။

### Expression နှင့် ယူနစ်များ

နံပါတ်အကွက်တိုင်းသည် ရိုးရိုးနံပါတ်ထက် ပိုလက်ခံသည်:

| သင်ရိုက်သည် | သင်ရသည် |
|---|---|
| `=2*45` | 90 |
| `=sqrt(2)*100` | 141.4214 |
| `1/4`, `6-1/2` | 0.25, 6.5 |
| `12'6"`, `12'-6 1/2"` | 150, 150.5 (လက်မ၊ ပေနှင့် လက်မဖြင့် ပုံဆွဲတွင်) |
| `900mm`, `3.5m`, `2ft` | ပုံဆွဲ၏ ယူနစ်သို့ ပြောင်းသည် |
| `45d30'`, `45°30'15"` | 45.5°, 45.5042° (ထောင့်အကွက်များ) |
| `0.5r`, `100g` | Radian နှင့် grad၊ ဒီဂရီအဖြစ် |

ယူနစ်ပါသော အရှည်သည် ပုံဆွဲတွင် ယူနစ်ရှိရမည်: ဘာမျှ မရွေးဘဲ {{ui:New objects}} အောက်ရှိ {{ui:Units}} ကို ဦးစွာ သတ်မှတ်ပါ။ မှားသော ထည့်သွင်းမှုကို panel အောက်ရှိ မှတ်ချက်ဖြင့် ငြင်းပယ်ပြီး ဘာမျှ မပြောင်းပါ; 0 အဖြစ် ဘယ်တော့မှ မသိမ်းပါ။ Function များ: sin, cos, tan, asin, acos, atan, atan2, sqrt, pow, exp, ln, log, abs, round, ceil, floor, min, max, if; ထောင့်များကို ဒီဂရီဖြင့်။

## အရာဝတ္ထုများစွာ တစ်ပြိုင်နက် ပြောင်းခြင်း

1. အရာဝတ္ထုများစွာကို ရွေးပါ၊ ဥပမာ မျဉ်း 8 ခုနှင့် dimension 4 ခု။
2. ခေါင်းစဉ်က "12 objects" ဟု ဖတ်ပြီး ထိပ်ရှိ စာရင်းက **All (12)**၊ **Line (8)** နှင့် **Dimension (4)** ကို ပေးသည်။
3. **All** က အရာဝတ္ထု တိုင်း၏ ရှိသည်များ (လေယာ၊ အရောင်၊ လိုင်းအမျိုးအစား…) ကို ပြသည်။ dimension ဆက်တင်များကို ကြည့်ရန် **Dimension (4)** ကို ရွေးပါ။
4. တန်ဖိုးတစ်ခု ပြောင်းပါ၊ ဥပမာ {{ui:Decimals}} ကို `1` ထားပါ။

dimension လေးခုစလုံး ပြောင်းသည်၊ undo တစ်ကြိမ်တည်း။ **Varies** ဟု ဖတ်ရသော အကွက်သည် အရာဝတ္ထုများ ကွဲပြားကြောင်း ဆိုလိုသည်; တန်ဖိုးတစ်ခု ရိုက်လျှင် အားလုံးတွင် သတ်မှတ်သည်။ လော့ခ်ချထားသော လေယာပေါ်ရှိ အရာဝတ္ထုများကို မပြောင်းဘဲ ထားပြီး မှတ်ချက်က ဘယ်နှစ်ခုဖြစ်သလဲ ပြောသည်။

## ရွေးထားသော အရာများ၏ စုစုပေါင်း

အရာဝတ္ထုများစွာ ရွေးထားလျှင် ထိပ်ရှိ {{ui:Totals}} အပိုင်းက ပြောသည်:

- **Objects**: အမျိုးအစားတစ်ခုစီ ဘယ်နှစ်ခု၊ ဥပမာ "8 lines, 2 polylines, 1 circle"။
- **Total length**: မျဉ်း၊ ထောင့်ကွေးနှင့် polyline များ ပေါင်းထားသည် (spline များလည်း ပါသည်)၊ နှင့် အရာဝတ္ထု ဘယ်နှစ်ခု ပါသလဲ။
- **Total area**: ပိတ်ထားသော အရာများ ပေါင်းထားသည်: စက်ဝိုင်း၊ အပြည့်ellipse၊ ပိတ်ထားသော polyline နှင့် hatch များ (hatch ၏ အပေါက်များကို နုတ်သည်)။

ဤတန်ဖိုးများသည် ပုံဆွဲ၏ အရှည်ဖော်မတ်ဖြင့် ဖြစ်သည် (အသုံးပြုထားလျှင် ပေနှင့် လက်မ; ဧရိယာသည် ထိုအခါ စတုရန်းလက်မနှင့် စတုရန်းပေ)။ status bar က အရာဝတ္ထုများ ရွေးထားချိန်တိုင်း တူညီသော အရှည်နှင့် ဧရိယာကို ပြသည်; {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Length and area of the selection}} › {{ui:Hidden}} က ထိုအရာကို ပိတ်သည်။ အရာဝတ္ထုတစ်ခုအတွက် {{ui:Geometry}} က ၎င်း၏ကိုယ်ပိုင် အရှည်နှင့် ဧရိယာကို ယခင်အတိုင်း ပြသည်။

## Coordinate များ

အမှတ်တိုင်းသည် **X**၊ **Y** နှင့် **Z** ကို ပြသည်: မျဉ်း၏ စတင်နှင့် အဆုံး၊ ဗဟိုများ၊ insertion point များ၊ စာသား နေရာများ၊ လက်ရှိ polyline vertex။ မျဉ်းများက **Delta X**၊ **Delta Y** နှင့် **Delta Z** (ဖတ်သာ) ကိုလည်း ပြသည်။ Polyline နှင့် hatch များတွင် **Elevation** (အရာဝတ္ထုတစ်ခုလုံးအတွက် Z တစ်ခု) ရှိသည်။

အမှတ်အမည်ဘေးရှိ crosshair ခလုတ်ဖြင့် ပုံဆွဲပေါ်တွင် ရွေးနိုင်သည်: ၎င်းကို နှိပ်ပြီး နေရာသစ်ကို နှိပ်ပါ (snap များ အလုပ်လုပ်သည်)။ တန်ဖိုးများသည် world coordinate များ ဖြစ်သည်။

| Text | အကြောင်းအရာ; style; justify; အမြင့်; လှည့်ခြင်း; အကျယ် အချိုး; ထောင့်စောင်း; သတ်မှတ်ထားသော အကျယ်; လိုင်းအကွာအဝေး; annotative; နေရာ |
| Block reference | Insertion point; လှည့်ခြင်း; အတိုင်းအတာ X၊ Y၊ Z နှင့် တူညီသော အတိုင်းအတာ; attribute တန်ဖိုးများ |

| Multileader | စာသား; အမြင့်; အကျယ်; စာသားဘက်; မြားခေါင်းအရွယ်; landing အကွာအဝေး; မြားခေါင်း အမှတ် |
| Viewport | အတိုင်းအတာ; စာရွက်ပေါ်ရှိ ဗဟိုနှင့် အရွယ်; မော်ဒယ်ရှိ view ဗဟို; on; display locked |

### Polyline vertex များ

{{ui:Current vertex}} က အောက်ရှိ အကွက်များ မည်သည့် vertex နှင့် ဆိုင်သလဲ ပြသည်။ arrow ခလုတ်များ သုံးပါ၊ သို့မဟုတ် နံပါတ်ရိုက်ပြီး အခြား vertex သို့ သွားပါ; ကန့်သတ်ချက် မရှိပါ။ vertex တစ်ခုစီတွင် X၊ Y၊ စတင်နှင့် အဆုံး segment အကျယ်၊ နှင့် ထို vertex မှ စတင်သော segment ၏ bulge (0 = ဖြောင့်) ရှိသည်။

## Dimension များ

dimension တစ်ခုသည် ၎င်း၏ **Dimension style**၊ ၎င်း တိုင်းတာသည့်အရာ၊ ၎င်း၏အမှတ်များနှင့် ဆက်တင်အားလုံးကို ပြသည်:

- **Lines and arrows:** အဆုံးတစ်ခုစီအတွက် မြားခေါင်း၊ မြားအရွယ်၊ tick အရွယ်၊ dimension နှင့် extension မျဉ်းများ၏ အရောင်နှင့် မျဉ်းအထူ၊ တစ်ဝက် သို့မဟုတ် extension မျဉ်းတစ်ခုစီကို ဖျောက်ခြင်း၊ extension မျဉ်း အဖယ် (offset) နှင့် extension။
- **Text:** override (တိုင်းတာသော တန်ဖိုးအတွက် ဗလာထား; `<>` က ၎င်းကို ကိုယ်ပိုင်စာသားအတွင်း ကိုယ်စားပြုသည်), style, အရောင်, အမြင့်, offset, ဒေါင်လိုက်နှင့် အလျားလိုက် နေရာ၊ အမြဲ အလျားလိုက်၊ လှည့်ခြင်း၊ နောက်ခံ fill။
- **Fit:** စုစုပေါင်း အတိုင်းအတာ၊ baseline အကွာအဝေး၊ နေရာ လိုသောအခါ ရွေ့သည့်အရာ၊ စာသား ရွေ့ခြင်း။
- **Primary units:** ဖော်မတ်၊ ဒသမ၊ round off၊ ရှေ့ဆက် (prefix)၊ နောက်ဆက် (suffix)၊ တိုင်းတာမှု အတိုင်းအတာ၊ ဒသမ ခြားနိုင်သည်၊ ရှေ့နှင့် နောက် သုည ဖျက်ခြင်း; ထောင့်များအတွက် ထောင့်ဖော်မတ်နှင့် ဒသမ။
- **Alternate units:** ဖွင့်/ပိတ်၊ ဖော်မတ်၊ ဒသမ၊ မြှောက်ကိန်း (25.4 က လက်မကို မီလီမီတာသို့ ပြောင်းသည်)၊ round off၊ ရှေ့ဆက်နှင့် နောက်ဆက်။
- **Tolerances:** မရှိ၊ ညီမျှ၊ သွေဖည်မှု၊ ကန့်သတ်ချက် သို့မဟုတ် အခြေခံ၊ အထက်နှင့် အောက်တန်ဖိုးများ၊ ဒသမ၊ အမြင့်နှင့် နေရာဖြင့်။

ဖွင့်ထားသော dimension ပေါ်တွင် ၎င်းတို့ထဲမှ တစ်ခုခုကို ပြောင်းလျှင် အခြားပရိုဂရမ် ဆွဲထားသော ပုံစံကို ဖျက်ပြီး CadCraft က ပြန်ဆွဲသည်။

:::note
အလျားလိုက် စာသား နေရာ (ပထမ သို့မဟုတ် ဒုတိယ extension မျဉ်း ဘေး) နှင့် မျဉ်းအောက်ရှိ စာသားကို မျဉ်းနှင့် ညွှန်ပြ dimension များတွင် ဆွဲသည်; အခြား dimension များတွင် ၎င်းတို့ကို သိမ်းထားပြီး သိမ်းသော်လည်း ယခုအထိ မဆွဲရသေးပါ။ Fit ရွေးချယ်မှုများကို သိမ်းထားသော်လည်း ယခုအထိ မဆွဲရသေးပါ: CadCraft က စာသားကို ကိုယ်ပိုင်စည်းမျဉ်း (မျဉ်းအပေါ်၊ မကိုက်ညီလျှင် အပြင်) ဖြင့် နေရာချသည်။
:::

## ဘာမျှ မရွေးထားသောအခါ

ဘာမျှ မရွေးထားသောအခါ panel က ပြသသည်:

- **New objects:** အရာဝတ္ထုအသစ်များ ရရှိမည့် လေယာ၊ အရောင်၊ လိုင်းအမျိုးအစား၊ မျဉ်းအထူနှင့် စာသားအမြင့်; ပုံဆွဲ၏ ယူနစ်နှင့် အရှည်ဖော်မတ်; လက်ရှိလေယာ၏ လိုင်းအမျိုးအစားနှင့် မျဉ်းအထူ; dimension အသစ်များအတွက် အရွယ်အစားများ။ စာရွက်ပေါ်တွင် စာရွက်၏ အမည်၊ စက္ကူနှင့် ဦးတည်ချက် ရှေ့ဆုံးတွင် ရှိသည်။
- **View:** မျက်နှာပြင်ပေါ်ရှိအရာ၏ ဗဟို၊ အမြင့်နှင့် အကျယ်။ ထိုနေရာသို့ view ရွှေ့ရန် တန်ဖိုး ရိုက်ပါ။
- **Misc:** UCS icon ဖွင့်/ပိတ်၊ UCS (အမြဲ World: CadCraft တွင် user coordinate system မရှိသေးပါ) နှင့် annotation အတိုင်းအတာ။

## အမှားများ အများဆုံး

- **အကွက်တစ်ခုတွင် ရိုက်ထားသည်ကို မဖြစ်ပါ။** {{key:Enter}} သို့မဟုတ် အခြားနေရာကို နှိပ်ပြီး အသုံးပြုပါ။ အနီရောင်အကွက်နှင့် မှတ်ချက်ဆိုလျှင် ထည့်သွင်းမှု ငြင်းပယ်ခံရသည်။
- **ယူနစ်ပါသော အရှည်ကို ငြင်းပယ်သည်။** ပုံဆွဲတွင် ယူနစ် မရှိပါ။ ဘာမျှ မရွေးဘဲ {{ui:Units}} ကို သတ်မှတ်ပါ။
- **Layer နှင့် Color သာ ပေါ်သည်။** အရာဝတ္ထု အမျိုးအစားများစွာ ရွေးထားပြီး **All** ကို ရွေးထားသည်။ ထိပ်ရှိ စာရင်းမှ အမျိုးအစားတစ်ခုကို ရွေးပါ။
- **အရာဝတ္ထု အချို့ မပြောင်းပါ။** ၎င်းတို့သည် လော့ခ်ချထားသော လေယာပေါ်တွင် ရှိသည်။ လေယာ panel တွင် လေယာကို လော့ခ်ဖွင့်ပါ။
- **ရိုက်ထားသော အက္ခရာများ အကွက်ထဲ ဝင်သွားသည်။** အကွက်တွင် cursor ရှိချိန် ကီးများသည် ထိုနေရာသို့ ရိုက်သည်။ {{key:Enter}} သို့မဟုတ် {{key:Esc}} ကို နှိပ်ပြီး command ကို ရိုက်ပါ။
