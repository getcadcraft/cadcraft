## သင်လေ့လာမည့်အရာ

ပုံဆွဲတစ်ခုကို pane များစွာဖြင့် တစ်ပြိုင်နက် ကြည့်နည်း၊ pane တစ်ခုစီသည် ၎င်း၏ ကိုယ်ပိုင် zoom ရှိသည်; ပုံဆွဲများစွာ ဖွင့်ပြီး ဘေးချင်းကပ် ကြည့်နည်း။

## ပုံဆွဲတစ်ခုကို pane များသို့ ခွဲခြင်း

1. ပုံဆွဲတစ်ခု ဖွင့်ပါ၊ သို့မဟုတ် မျဉ်းနှင့် စက်ဝိုင်းအနည်းငယ် ဆွဲပါ။
2. {{ui:View}} › {{ui:More}} ကို ဖွင့်ပြီး {{ui:Split side by side}} ကို ရွေးပါ (သို့မဟုတ် {{cmd:VPORTS}} ကို ရိုက်ပြီး `2` ကို ရိုက်ကာ {{key:Enter}} ကို ဖိပါ)။

ပုံဆွဲနေရာသည် pane နှစ်ခုအဖြစ် ခွဲသည်၊ နှစ်ခုစလုံးက တူညီသော view ကို ပြသည်။ active pane တွင် အပြာရောင် frame ရှိပြီး crosshair ရသည်။

3. အခြား pane ကို နှိပ်ပါ။ ၎င်း active ဖြစ်သွားသည်။ (ပထမ နှိပ်ချက်သည် pane ပြောင်းရုံသာ ဖြစ်သည်; ရွေးရန် ထပ်နှိပ်ပါ။)
4. Wheel ဖြင့် zoom လုပ်ပါ။ ထို pane သာ zoom ဖြစ်သည်။
5. Pane များကြား မျဉ်းကို ဆွဲ၍ တစ်ခုကို ပိုကျယ်အောင် လုပ်ပါ။ divider ပေါ်တွင် focus ရှိစဉ် {{key:Home}} သည် အလယ်သို့ ပြန်ထားသည်။

{{cmd:VPORTS}} သည် `3` (တစ်ဘက်တွင် pane နှစ်ခု၊ အခြားဘက်တွင် ကြီးသော pane တစ်ခု: `L` သို့မဟုတ် `R`)၊ `4`၊ နှင့် pane တစ်ခုတည်းသို့ ပြန်ရန် `SI` ကိုလည်း လက်ခံသည်။ active pane ၏ view သည် ထိုအခါ နေရာအပြည့် ဖြစ်သည်။ sheet ပေါ်တွင် {{cmd:VPORTS}} သည် sheet သို့ viewport တစ်ခု ထည့်သည် (AutoCAD ကဲ့သို့); ထိုနေရာတွင် {{cmd:SPLIT}} ကို ရိုက်ပါ၊ သို့မဟုတ် View menu ကို သုံးပါ။

## Pane တစ်ခုမှ အခြားတစ်ခုသို့ ဆွဲခြင်း

1. Split side by side ပြုလုပ်ပြီး pane တစ်ခုစီကို ပုံဆွဲ၏ မတူသော ထောင့်တစ်ခုသို့ zoom လုပ်ပါ။
2. `L` ကို ရိုက်ပြီး {{key:Enter}} ကို ဖိပါ၊ ထို့နောက် ဘယ် pane တွင် ပထမအမှတ်ကို နှိပ်ပါ။
3. ညာ pane တွင် တစ်ကြိမ် နှိပ်၍ ၎င်းကို active ဖြစ်စေပြီး ထိုနေရာတွင် ဒုတိယအမှတ်ကို နှိပ်ပါ။

မျဉ်းသည် နေရာနှစ်ခုကြား ဆွဲသည်။ pane များပြောင်းနေစဉ်လည်း command ဆက်လုပ်သည်၊ rubber band သည် pane တိုင်းတွင် ပြသည်။

## မော်ဒယ်နှင့် sheet ကို ဘေးချင်းကပ်ခြင်း

1. Split side by side ပြုလုပ်ပါ။
2. ညာ pane ကို နှိပ်ပြီး ပုံဆွဲအောက်ရှိ sheet tab ကို နှိပ်ပါ။

ညာ pane သည် sheet ကို ပြသည်; ဘယ်ဘက်က မော်ဒယ်ကို ဆက်ပြသည်။ pane တစ်ခုစီသည် ၎င်း၏ ကိုယ်ပိုင် space ကို ထိန်းသည်၊ ထို့ကြောင့် မော်ဒယ်ပေါ်တွင် ဆွဲနိုင်ပြီး sheet ၏ viewport ကို လိုက်ကြည့်နိုင်သည်။

## ပုံဆွဲများစွာ ဝင်းဒိုးတစ်ခုတည်းတွင်

1. ပုံဆွဲတစ်ခု ဖွင့်ပါ။ ထို့နောက် အခြားတစ်ခု ဖွင့်ပါ (သို့မဟုတ် {{ui:New}} ကို နှိပ်ပါ)။

ပုံဆွဲတစ်ခုစီသည် ပုံဆွဲနေရာအပေါ်ရှိ ၎င်း၏ကိုယ်ပိုင် tab တွင် ဖွင့်သည်။ tab ကို နှိပ်၍ ပြောင်းပါ; command line၊ panel များနှင့် undo သည် ပြောင်းလဲသော ပုံဆွဲကို လိုက်သည်။ ပုံဆွဲတစ်ခုတွင် {{key:Mod+C}} နှင့် အခြားတစ်ခုတွင် {{key:Mod+V}} သည် object များကို ၎င်းတို့ကြား ကူးသည်။

2. {{ui:ဖွင့်ထားသော ပုံဆွဲများကို ဘေးချင်းကပ် ခင်းရန်}} (tab များ အဆုံးရှိ split အိုင်ကွန်) ကို နှိပ်ပါ၊ သို့မဟုတ် ၎င်းဘေးရှိ stacked အိုင်ကွန်ကို နှိပ်ပါ။

pane တစ်ခုစီသည် ဖွင့်ထားသော ပုံဆွဲတစ်ခုကို ပြသည်၊ လေးခုအထိ။ ထိုပုံဆွဲတွင် အလုပ်လုပ်ရန် pane ကို နှိပ်ပါ။

3. tab ပေါ်ရှိ {{ui:×}} ကို နှိပ်၍ ထိုပုံဆွဲကို ပိတ်ပါ။ သိမ်းမထားသော ပြောင်းလဲမှု ရှိလျှင် CadCraft က အရင်မေးသည်။

:::tip
ဝင်းဒိုးတွင် အသစ်၊ မထိသေးသော ပုံဆွဲတစ်ခုသာ ရှိနေချိန်တွင် ပုံဆွဲဖွင့်ခြင်းသည် tab အသစ် ထည့်မည့်အစား ထို tab ကို အသုံးပြုသည်။
:::

## Pan နှင့် zoom အတူတကွ

ပုံဆွဲ revision နှစ်ခုကို နှိုင်းယှဉ်ရန် ၎င်းတို့ကို ဘေးချင်းကပ်ပြီး {{ui:အပိုင်းများ၏ မြင်ကွင်းကို ချိတ်ဆက်ရန်}} (tab များ အဆုံးရှိ link အိုင်ကွန်) ကို နှိပ်ပါ၊ သို့မဟုတ် {{ui:View}} › {{ui:More}} တွင် ရွေးပါ၊ သို့မဟုတ် {{cmd:LINKVIEWS}} ကို ရိုက်ပြီး `ON` ကို ရိုက်ပါ။ ယခု pane တစ်ခုတွင် pan သို့မဟုတ် zoom လုပ်လျှင် မော်ဒယ်ကို ပြသနေသော pane အားလုံး (သို့မဟုတ် sheet ကို ပြသနေသော pane အားလုံး) သည် တူညီသောနေရာသို့ ရောက်သည်၊ ထို့ကြောင့် ပုံဆွဲနှစ်ခုသည် တစ်ညီတည်း ကျန်ရှိသည်။ {{cmd:LINKVIEWS}} `OFF` သည် pane တစ်ခုစီကို ကိုယ်ပိုင် ရွေ့ခွင့် ပြန်ပေးသည်။

## အဖြစ်များသော အမှားများ

- **နှိပ်ချက်က ဘာမှ မဖြစ်ခဲ့ပါ။** ထို pane ကို active ဖြစ်စေခဲ့သည်။ ရွေးရန် သို့မဟုတ် ဆွဲရန် ထပ်နှိပ်ပါ။
- **Wheel က မှားသော pane ကို zoom လုပ်သည်။** Wheel သည် pointer အောက်ရှိ pane ကို zoom လုပ်ပြီး active ဖြစ်စေသည်။
- **Pane များ တစ်ခုသို့ ပြန်ရောက်သွားသည်။** ပုံဆွဲဖွင့်ခြင်းသည် သိမ်းထားသည့်အတိုင်း ပြသသည်; pane မပါဘဲ သိမ်းထားသော ပုံဆွဲသည် pane တစ်ခုတည်းဖြင့် ဖွင့်သည်။
- **မမြင်ရသော မသိမ်းရသေးသော ပြောင်းလဲမှုအတွက် စာမျက်နှာမှ ထွက်လျှင် သတိပေးသည်။** အခြား tab တွင် ပြောင်းလဲမှု ရှိသော ပုံဆွဲ ရှိနေသည်။ ထို tab သို့ ပြောင်းပြီး သိမ်းပါ၊ သို့မဟုတ် မသိမ်းဘဲ ထွက်ပါ။
