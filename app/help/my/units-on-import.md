## သင် လုပ်မည့်အရာ

ဖိုင်တစ်ခုကို ပုံဆွဲထဲ ယူလာပြီး မှန်ကန်သော အရွယ်ဖြင့် ဝင်လာစေရန် သေချာပါ။

## အဆင့်များ

1. ပုံမှန်အတိုင်း ဖိုင်ကို ယူလာပါ: `INSERT` › File၊ `XATTACH`၊ `POINTCLOUDATTACH`၊ သို့မဟုတ် Library panel ရှိ {{ui:Files}}။
2. ဖိုင်က ယူနစ်ကို ဖော်ပြလျှင် ဘာမျှ မမေးပါ။ Command line က ဖိုင်က ဖော်ပြသော ယူနစ်ကို ပြောပြပြီး ပုံဆွဲနှင့် ကွဲပြားလျှင် အသုံးပြုသော scale ကို ပြသည်။
3. မဖော်ပြလျှင် ဒိုင်ယာလော့ခ်က ဖိုင်၏ **Units of** ကို မေးသည်။ ဖိုင်ထဲရှိ ယူနစ်တစ်ခုသည် ဘာဖြစ်သည်ကို ရွေးပြီး {{ui:Use these units}} ကို နှိပ်ပါ။ အဖြေမပေးမီ ဘာမျှ မထားပါ။
4. {{ui:Cancel}} (သို့မဟုတ် {{key:Esc}}) က ဘာမျှ မယူလာပါ။

## မည်သည့် ဖိုင်များက ယူနစ်ကို ဖော်ပြသနည်း

- **DWG နှင့် DXF**: ပုံဆွဲ၏ insertion ယူနစ် (`$INSUNITS`)။ ၎င်းမပါသော ဖိုင်ကို မေးသည်။
- **Point cloud များ**: coordinate system ပါသော LAS နှင့် LAZ၊ E57၊ PTX နှင့် PLY က ၎င်းတို့၏ ယူနစ်ကို ဖော်ပြသည်။ အခြားများကို မေးသည်။
- **OBJ**: ယူနစ်ကို ဘယ်တော့မှ မဖော်ပြပါ။ သင့်ကို မေးသည်။
- **glTF နှင့် GLB**: မီတာ၊ format ၏ ကိုယ်ပိုင် စည်းမျဉ်းအရ။
- **ပုံများ**: ကိုယ်ပိုင် အရွယ် မရှိပါ။ `IMAGEATTACH` က အကျယ်ကို မေးပြီး ထိုဖိုင်အတွက် အရင်ပေးခဲ့သော အကျယ်ကို ကမ်းပေးသည်။
- **Scan များ**: DPI (dots per inch) ကို ဖော်ပြသော scan သည် ပုံဆွဲ၏ ယူနစ်ဖြင့် မှန်ကန်သော အရွယ်ဖြင့် ဝင်လာသည်; `SCANATTACH` က အကျယ်ကို မေးဆဲ ဖြစ်သည်။
- **Point clouds add-on**: ယူနစ် မပါသော ဖိုင်ဖြင့် cloud ကို တည်ဆောက်သည့်အခါ မေးပြီး၊ cloud ၏ ဂဏန်းများကို ယူထားသော ယူနစ်ဖြင့် အမှတ်အသား ပြုသည်။

## သိထားသင့်သည်များ

- DWG သို့မဟုတ် DXF ကို ကိုယ်ပိုင် ပုံဆွဲအဖြစ် ဖွင့်လျှင် ဘာမျှ မမေးပါ: command line က ဖိုင်က ဖော်ပြသော ယူနစ် သို့မဟုတ် ဘာမျှ မဖော်ပြကြောင်း ပြောသည်။ Properties က ပုံဆွဲ၏ ယူနစ်ကို သတ်မှတ်သည်။
- ဤပုံဆွဲတွင်လည်း ယူနစ် မရှိလျှင် ဖိုင်ကို ပြောင်း၍ မရပါ: နံပါတ်အတိုင်း ထားပြီး command line က ထိုအကြောင်း ပြောသည်။
- အဖြေကို ဤကွန်ပျူတာပေါ်ရှိ ထိုဖိုင်အတွက် မှတ်ထားပြီး CadCraft app အားလုံးတွင် ရှိသည်။ နောက်တစ်ကြိမ် ယူလာချိန်တွင် မမေးတော့ပါ၊ command line က မှတ်ထားသော ယူနစ်များ အသုံးပြုခဲ့ကြောင်း ပြောသည်။
- ပြန်မေးစေလိုလျှင်: command palette ({{key:Mod+K}}) › **ယူလာသော ဖိုင်များ၏ ယူနစ်ကို ထပ်မေးရန်**။
