## ဘာကို ပြုလုပ်မလဲ

Layer သုံးခု၊ Walls၊ Doors နှင့် Notes၊ တစ်ခုစီ ကိုယ်ပိုင်အရောင်ဖြင့်၊ တစ်ခုစီပေါ် object များ ဆွဲပြီး layer များကြား ရွှေ့။

## Layers panel

Layer များသည် ဘယ်ဘက်ရှိ {{ui:လေယာများ}} အောက်ရှိ panel တွင် ရှိသည်။ အတန်းတစ်ခုစီသည် ဘယ်မှ ညာသို့ အောက်ပါအတိုင်း ပြ-

- အစက်တစ်ခု: **current** layer အတွက် ဖြည့်ထား၊ အသစ် object များ ရောက်မည့်နေရာ;
- အရောင် swatch;
- layer နာမည်;
- ခလုတ်လေးခု: on/off (မျက်လုံး)၊ freeze (ရေခဲ)၊ lock (ကြိုး)၊ plot (ပရင်တာ)။

Drawing တိုင်းတွင် `0` အမည်ရှိ layer ရှိသည်။ `LA` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်လျှင် panel သို့ ရောက်သည်။

## Layer များ ဖန်တီးခြင်း

1. စာရင်းအပေါ်ရှိ {{ui:လေယာအသစ်}} ကို နှိပ်။ နာမည်ကွက် ဖွင့်လာသည်။
2. `Walls` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ (သို့မဟုတ် {{ui:ထပ်ထည့်ရန်}} ကို နှိပ်)။

Status bar က "Added layer Walls and made it current" ဟု ပြ။ Layer အသစ်သည် အရောင် 7 (light theme တွင် အနက်၊ dark တွင် အဖြူ) ရ။

3. {{ui:လေယာအသစ်}} ကို ထပ်နှိပ်၊ `Doors` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်။
4. {{ui:လေယာအသစ်}} ကို ထပ်နှိပ်၊ `Notes` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်။

Notes သည် ယခု current ဖြစ်သည်။

## Layer တစ်ခုစီကို အရောင်ပေးခြင်း

1. Walls row ရှိ အရောင် swatch ကို နှိပ်။ သင့်စနစ်၏ အရောင်ရွေးကိရိယာ ဖွင့်သည်။
2. အရောင်ရွေးပြီး အတည်ပြု။

Swatch နှင့် Walls ပေါ်ရှိ {{ui:လေယာအလိုက်}} အရောင်ရှိ အရာအားလုံး ပြောင်းသည်။

:::note
ရွေးသော အရောင်သည် CAD အရောင် စံ 255 ခုထဲမှ တစ်ခုနှင့် ကိုက်ညီလျှင် ထိုနံပါတ်အဖြစ် သိမ်း။ အခြားအရောင်များကို CadCraft တွင် တိတိကျကျ ထိန်း၊ သို့သော် DWG သို့မဟုတ် DXF ဖိုင်တွင် အနီးဆုံး စံအရောင်အဖြစ် သိမ်းသည်။
:::

## Layer တစ်ခုပေါ်တွင် ဆွဲခြင်း

1. စာရင်းရှိ **Walls** နာမည်ကို နှိပ်။ ၎င်း၏ အစက် ဖြည့်သွား၊ status bar က "Current layer: Walls" ဟု ပြ။
2. စတုဂံ (`REC`) ဆွဲ။ ၎င်းသည် Walls ပေါ်ရောက်သည်။
3. **Doors** ကို နှိပ်ပြီး arc (`A`) ဆွဲ။ ၎င်းသည် Doors ပေါ်ရောက်သည်။

ရွေးထားသော အရာမရှိသောအခါ ညာဘက်ရှိ {{ui:လက်ရှိ ဆက်တင်များ}} တွင် {{ui:လေယာ}} အောက်မှလည်း current layer ကို ရွေးနိုင်သည်။

## Object များကို layer အခြားသို့ ရွှေ့ခြင်း

1. Object များကို ရွေး။
2. ညာဘက် panel ရှိ {{ui:လေယာ}} တွင် layer အသစ်ကို ရွေး။

ထို object များ ထို layer သို့ ရောက်ပြီး အရောင်သည် {{ui:လေယာအလိုက်}} ဖြစ်လျှင် layer ၏ အရောင်ကို ယူသည်။

## ပိတ်ခြင်း၊ freeze၊ lock နှင့် plot

| ခလုတ် | ဘာလုပ်သလဲ |
|---|---|
| On/off (မျက်လုံး) | Layer ၏ object များကို ဝှက်။ မမြင်နိုင်၊ မရွေးနိုင်၊ snap မလုပ်နိုင်။ |
| Freeze (ရေခဲ) | CadCraft တွင် off နှင့် တူ။ အခြား program များက ကွဲပြားစွာ ကိုင်တွယ်သဖြင့် သီးခြား ထား၊ ဆက်တင်ကို သိမ်း။ |
| Lock (ကြိုး) | Object များ မြင်ရဆဲ၊ snap လုပ်နိုင်သော်လည်း ရွေး သို့မဟုတ် ပြောင်းမရ။ လိုက်ခြေရာခံရန် နောက်ခံအတွက် ကောင်း။ |
| Plot (ပရင်တာ) | ဖိထားလျှင် layer ကို မျက်နှာပြင်တွင် ပြသော်လည်း plot နှင့် PDF မှ **ဖယ်ထား**။ Construction line များနှင့် သင့်ကိုယ်ပိုင် မှတ်ချက်များအတွက် သုံး။ |

ခလုတ်ပေါ် hover လုပ်လျှင် ၎င်းပြုလုပ်မည့်အရာကို ပြ ("Turn off"၊ "Freeze"၊ "Lock"၊ "Do not plot this layer")။

Current layer ကို ပိတ်၍ မရ: status bar က "That is the current layer. Make another layer current first." ဟု ပြ။ Layer နာမည်ကို နှိပ်၍ current ပြုလျှင် ၎င်းကို ဖွင့်ပြီး thaw လည်း လုပ်သည်။

Panel တွင် ဖြစ်စေ command ဖြင့် ဖြစ်စေ layer ပြောင်းလဲမှုတိုင်း undo အဆင့် တစ်ခု: {{key:Mod+Z}} က ပြန်ထား။

## Object များကို ရွေး၍ layer များ လုပ်ခြင်း

Layer နာမည် သိစရာမလို၊ ထို layer ပေါ်ရှိ object တစ်ခုကို ရွေး။ Command ရိုက်၊ သို့မဟုတ် {{ui:Layers}} panel ၏ ထိပ်ရှိ {{ui:ကိရိယာများ}} ကို ဖွင့်။

| Command | ဘာလုပ်သလဲ |
|---|---|
| {{cmd:LAYISO}} | Object များ ရွေး၊ {{key:Enter}} ကို နှိပ်: ၎င်းတို့၏ layer များသာ ဖွင့်ထား၊ အခြား layer အားလုံး ပိတ်။ Current layer ပိတ်ထားလျှင် ခွဲထုတ်ထားသော layer တစ်ခု current ဖြစ်လာ။ |
| {{cmd:LAYUNISO}} | နောက်ဆုံး {{cmd:LAYISO}} ပိတ်ခဲ့သော layer များကို ပြန်ဖွင့်၊ ၎င်းပြောင်းခဲ့သော current layer ကိုလည်း ပြန်ပေး။ |
| {{cmd:LAYOFF}} | Object များကို တစ်ခုပြီးတစ်ခု နှိပ်: အရာတစ်ခုစီ၏ layer ကို ပိတ်။ နောက်ဆုံးကို ပြန်ယူရန် `U` ရိုက်၊ ပြီးဆုံးရန် {{key:Enter}} ကို နှိပ်။ |
| {{cmd:LAYFRZ}} | အတူတူ၊ layer တစ်ခုစီကို freeze လုပ်။ |
| {{cmd:LAYMCUR}} | Object တစ်ခုကို နှိပ်: ၎င်း၏ layer သည် current ဖြစ်၊ ဖွင့်ပြီး thaw လည်း။ Object တစ်ခု ရွေးပြီးသားဆိုလျှင် ထိုအရာကို သုံး။ |
| {{cmd:LAYON}} | Layer အားလုံးကို ဖွင့်။ |
| {{cmd:LAYTHW}} | Layer အားလုံးကို thaw။ |

Current layer ကို ဤနည်းဖြင့် ဘယ်တော့မှ ပိတ်ခြင်း၊ freeze လုပ်ခြင်း မရှိ: မှတ်တမ်းက ထိုသို့ ပြော၊ {{cmd:LAYMCUR}} ဖြင့် အခြား layer ကို အရင် current ပြု။ ဘလောက်ကိုးကားချက်ကို ရွေးလျှင် reference ၏ ကိုယ်ပိုင် layer ကို သုံး။

## Layer များ ပြောင်း၊ ပေါင်းနှင့် ဖျက်ခြင်း

- {{cmd:RENAME}}: `LA` ရိုက်၊ ဟောင်းနာမည်နှင့် အသစ်နာမည်။ Layer ပေါ်ရှိ object အားလုံး လိုက်။ (`B` က ဘလောက်ကို ၎င်း၏ reference အားလုံးနှင့်အတူ ထိုနည်းဖြင့် အမည်ပြောင်း။)
- {{cmd:LAYMRG}}: ပေါင်းမည့် layer တစ်ခုစီပေါ်ရှိ object တစ်ခုကို နှိပ် (သို့မဟုတ် `N` နှင့် နာမည် ရိုက်)၊ {{key:Enter}} ကို နှိပ်၊ ထို့နောက် target layer ကို ရွေး၍ `Y` ဖြေ။ Object များ target သို့ ရောက် (model၊ sheet နှင့် block အတွင်း) နှင့် ပေါင်းထားသော layer များ ပျောက်။
- {{cmd:LAYDEL}}: layer ပေါ်ရှိ object တစ်ခုကို ရွေး (သို့မဟုတ် `N` နှင့် နာမည်) ပြီး `Y` ဖြေ။ Layer သည် ၎င်းပေါ်ရှိ **object အားလုံးနှင့်အတူ** ပျောက်၊ နေရာတိုင်း။ Layer 0၊ DEFPOINTS နှင့် current layer ကို ဖျက်၍ မရ။

တစ်ခုစီသည် undo အဆင့် တစ်ခု။ သုံးခုစလုံးသည် layers panel ၏ ထိပ်ရှိ {{ui:ကိရိယာများ}} တွင် ရှိ။

1. နံရံမျဉ်းတစ်ကြောင်းကို နှိပ်၊ ထို့နောက် `LAYISO` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်။ Walls သာ ဖွင့်ကျန်။
2. Walls ပေါ်တွင် လိုသည်များ ဆွဲ သို့မဟုတ် ပြောင်း။
3. `LAYUNISO` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်။ Doors နှင့် Notes ပြန်ပေါ်။

## အမှားများ

- **မျဉ်းအသစ်များ မှားသော layer ပေါ် ရောက်။** ဆွဲမီ ဖြည့်ထားသော အစက်ကို စစ်။ Layer အသစ်ကို ထည့်သည်နှင့် ၎င်း current ဖြစ်သည်။
- **Object ရွေး၍ မရ။** ၎င်း၏ layer သည် lock၊ ပိတ်၊ သို့မဟုတ် freeze ဖြစ်နေ။
- **Layer သည် အခြား program တွင် ရိုက်ထုတ်ဆဲ။** DXF R12 သည် "do not plot" ကို သိမ်း၍ မရ။ Drawing တွင် sheet ရှိလျှင် CadCraft က ထိုဆက်တင်ကို ကိုယ်တိုင်ထိန်းသော်လည်း အခြား program များက ထို layer ကို plot ထုတ်မည်။
- **သိမ်းပြီးနောက် layer နာမည်များ အကြီးစာလုံးဖြစ်နေ။** DXF R12 က နာမည်များကို အကြီးစာလုံး သိမ်း၊ ထို့ကြောင့် `Walls` သည် `WALLS` ဖြစ်လာ၊ နေရာလွတ်များသည် `_` ဖြစ်လာ။ DWG ကို သိမ်းလျှင် နာမည်များကို ရိုက်ထားသည့်အတိုင်း ထိန်း။
- **Layer ကို အမည်ပြောင်း၊ ပေါင်း သို့မဟုတ် ဖျက်ခြင်း။** {{cmd:RENAME}}၊ {{cmd:LAYMRG}} သို့မဟုတ် {{cmd:LAYDEL}} ကို သုံး (ထို့အပြင် {{ui:ကိရိယာများ}} တွင်လည်း): အောက်တွင် ကြည့်ပါ။

## Layer များ အုပ်စုဖွဲ့ခြင်း

Layer များကို ဖိုင်တွဲများ (ဥပမာ Existing၊ Proposed နှင့် Services) တွင် ထားခြင်းဖြင့် စာရင်းကို တိုစေ။ ဖိုင်တွဲတစ်ခုစီ ခေါက်နိုင်၊ ၎င်း၏ ခလုတ်များက layer အားလုံးကို အတူ ဖွင့်/ပိတ်၊ freeze သို့မဟုတ် lock လုပ်သည်။ Current layer ကို ဘယ်တော့မှ မပိတ်။

Layers panel ၏ {{ui:ကိရိယာများ}} တွင် ရိုးရှင်းသော အိမ်ယာအလုပ်အတွက် ပြင်ဆင်ထားသော အုပ်စုများအတွက် {{ui:အဆင်သင့် အုပ်စုများ ထည့်ရန်}}၊ အရှေ့ဆက်တူသော layer များ (`E-Walls`၊ `E-Doors`) ကို အုပ်စုဖွဲ့ရန် {{ui:အမည်ဖြင့် အုပ်စုဖွဲ့ရန်}}၊ သို့မဟုတ် {{ui:အုပ်စုအသစ်}} ကို ရွေး။ Layer တစ်ခုကို ဖိုင်တွဲပေါ် ဆွဲချ၊ သို့မဟုတ် current layer အတွက် စာရင်းအပေါ်ရှိ ကိရိယာကို သုံး။ စာရင်းကို ကျဉ်းစေရန် {{ui:လေယာ ရှာရန်}} တွင် ရိုက်။ `LAYGROUP` (`LG`) က command line တွင် အတူတူ လုပ်သည်။

အုပ်စုအမည်ကို ပြောင်းရန် အမည်ကို နှစ်ချက်နှိပ် (သို့မဟုတ် ရွေး၍ {{key:F2}} ကို နှိပ်)၊ အမည်အသစ်ရိုက်၍ {{key:Enter}} ကို နှိပ်; {{key:Esc}} က ဟောင်းကို ထိန်း၊ {{cmd:UNDO}} က ပြန်ထား။ {{ui:အုပ်စုအသစ်}} သည် Layers panel ၏ {{ui:ကိရိယာများ}} တွင် ရှိ။

Layer များ ကိုယ်တိုင်မပြောင်းသဖြင့် အခြား CAD program များက ၎င်းတို့ကို ပုံမှန် ညီညီ စာရင်းအဖြစ် မြင်။ CadCraft က အုပ်စုများကို ဖိုင်တွင် ထိန်းသည်။
