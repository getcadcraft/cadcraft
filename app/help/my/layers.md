## သင် ဖန်တီးမည့်အရာ

Walls၊ Doors နှင့် Notes ဟူ၍ လေယာသုံးခု၊ တစ်ခုစီတွင် ကိုယ်ပိုင်အရောင်ရှိ၊ အရာဝတ္ထုများကို တစ်ခုစီပေါ် ဆွဲပြီး လေယာများကြား ရွှေ့ထားသည်။

## Layers panel

လေယာများသည် ဘယ်ဘက်ရှိ panel ထဲ၊ {{ui:Layers}} အောက်တွင် ရှိသည်။ အတန်းတစ်ခုစီသည် ဘယ်မှ ညာသို့ ဖော်ပြသည်-

- အစက်တစ်ခု: **လက်ရှိ** လေယာအတွက် ဖြည့်ထား၊ အသစ် အရာဝတ္ထုများ ရောက်ရာနေရာ;
- အရောင်အကွက်;
- လေယာအမည်;
- ခလုတ်လေး လေးခု: on/off (မျက်လုံး)၊ freeze (ဆနိုဖလိတ်)၊ lock (သော့ခတ်)၊ plot (ပရင်တာ)။

ပုံဆွဲတိုင်းတွင် `0` ဟု ခေါ်သော လေယာတစ်ခု ရှိသည်။ `LA` ရိုက်ပြီး {{key:Enter}} နှိပ်လျှင် panel သို့ ရောက်သွားသည်။

## လေယာများ ဖန်တီးရန်

1. စာရင်း၏ အပေါ်ရှိ {{ui:New layer}} ကို နှိပ်ပါ။ အမည်အကွက် ဖွင့်လာသည်။
2. `Walls` ကို ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ (သို့မဟုတ် {{ui:Add}} ကို နှိပ်ပါ)။

Status bar က "လေယာ Walls ထည့်ပြီး လက်ရှိအဖြစ် ပြုလုပ်ပြီးပါပြီ။" ဟု ပြသည်။ လေယာအသစ်သည် အရောင် 7 ရသည် (အလင်း theme တွင် အမည်း၊ အမှောင် theme တွင် အဖြူ)။

3. {{ui:New layer}} ကို ထပ်နှိပ်ပြီး `Doors` ရိုက်ကာ {{key:Enter}} နှိပ်ပါ။
4. {{ui:New layer}} ကို ထပ်နှိပ်ပြီး `Notes` ရိုက်ကာ {{key:Enter}} နှိပ်ပါ။

Notes သည် ယခု လက်ရှိ ဖြစ်သည်။

## လေယာတစ်ခုစီကို အရောင်ပေးရန်

1. Walls အတန်းရှိ အရောင်အကွက်ကို နှိပ်ပါ။ သင့်စနစ်၏ အရောင်ရွေးကိရိယာ ဖွင့်လာသည်။
2. အရောင်တစ်ခု ရွေးပြီး အတည်ပြုပါ။

အကွက်နှင့် Walls ပေါ်ရှိ {{ui:By layer}} အရောင်ဖြစ်သည် အရာအားလုံး ပြောင်းသွားသည်။

:::note
ရွေးထားသော အရောင်သည် CAD စံအရောင် 255 ခုထဲမှ တစ်ခုနှင့် ကိုက်ညီလျှင် ထိုနံပါတ်အဖြစ် သိမ်းသည်။ အခြားအရောင်များကို CadCraft တွင် တိကျစွာ ထိန်းထားသော်လည်း DWG သို့မဟုတ် DXF ဖိုင်တွင် အနီးဆုံး စံအရောင်အဖြစ် သိမ်းသည်။
:::

## လေယာပေါ်တွင် ဆွဲရန်

1. စာရင်းရှိ **Walls** အမည်ကို နှိပ်ပါ။ အစက် ဖြည့်သွားပြီး status bar က "လက်ရှိ လေယာ: Walls" ဟု ပြသည်။
2. စတုဂံတစ်ခု ဆွဲပါ (`REC`)။ ၎င်းသည် Walls ပေါ်သို့ ရောက်သည်။
3. **Doors** ကို နှိပ်ပြီး arc တစ်ခု ဆွဲပါ (`A`)။ ၎င်းသည် Doors ပေါ်သို့ ရောက်သည်။

ညာဘက်ရှိ {{ui:Current settings}} တွင် (ဘာမျှ မရွေးထားချိန်) {{ui:Layer}} အောက်၌ လက်ရှိ လေယာကို ရွေးနိုင်သည်။

## အရာဝတ္ထုများကို အခြားလေယာသို့ ရွှေ့ရန်

1. အရာဝတ္ထုများကို ရွေးပါ။
2. ညာဘက် panel ရှိ {{ui:Layer}} တွင် လေယာအသစ်ကို ရွေးပါ။

ထိုအရာများသည် ထိုလေယာသို့ ရောက်ပြီး၊ ၎င်းတို့၏ အရောင်သည် {{ui:By layer}} ဖြစ်ပါက ထိုလေယာ၏ အရောင်ကို ယူသည်။

## Off၊ freeze၊ lock နှင့် plot

| ခလုတ် | ဘာလုပ်သလဲ |
|---|---|
| On/off (မျက်လုံး) | လေယာ၏ အရာဝတ္ထုများကို ဝှက်သည်။ မြင်ရခြင်း၊ ရွေးခြင်း သို့မဟုတ် snap လုပ်ခြင်း မရှိနိုင်ပါ။ |
| Freeze (ဆနိုဖလိတ်) | CadCraft တွင် off နှင့် အတူတူ။ အခြားပရိုဂရမ်များက ကွဲပြားစွာ ကိုင်တွယ်သောကြောင့် ခွဲထားပြီး ဆက်တင်ကို သိမ်းသည်။ |
| Lock (သော့ခတ်) | အရာဝတ္ထုများ မြင်ရဆဲ၊ snap လုပ်နိုင်သော်လည်း ရွေး၍ သို့မဟုတ် ပြောင်း၍ မရပါ။ သင် ခြေရာခံသော နောက်ခံအတွက် ကောင်းသည်။ |
| Plot (ပရင်တာ) | နှိပ်ထားသည့်အခါ လေယာကို မျက်နှာပြင်ပေါ် ပြသော်လည်း plot နှင့် PDF များမှ **ဖယ်ထုတ်သည်**။ Construction မျဉ်းများနှင့် ကိုယ်တိုင် မှတ်ချက်များအတွက် သုံးပါ။ |

ခလုတ်ပေါ် ကာဆာတင်လျှင် ၎င်းလုပ်မည့်အရာ ပေါ်လာသည် ("ပိတ်ရန်", "ရပ်ထားရန်", "သော့ခတ်ရန်", "ဤလေယာကို plot မလုပ်ပါနှင့်")။

လက်ရှိ လေယာကို ပိတ်၍ မရပါ: status bar က "ထိုလေယာသည် လက်ရှိ လေယာ ဖြစ်သည်။ ဦးစွာ အခြားလေယာကို လက်ရှိ ပြုလုပ်ပါ။" ဟု ပြသည်။ လေယာ၏ အမည်ကို နှိပ်၍ လက်ရှိ ပြုလုပ်ခြင်းသည် ၎င်းကို ဖွင့်ပြီး freeze ကိုလည်း ဖြုတ်သည်။

Panel တွင် ဖြစ်စေ command ဖြင့် ဖြစ်စေ လေယာပြောင်းလဲမှုတိုင်းသည် undo အဆင့်တစ်ခု ဖြစ်သည်: {{key:Mod+Z}} က ပြန်ထားသည်။

## အရာဝတ္ထု ရွေး၍ လေယာများဖြင့် အလုပ်လုပ်ရန်

လေယာ၏ အမည်ကို သိစရာ မလိုပါ: ထိုလေယာပေါ်ရှိ အရာဝတ္ထုတစ်ခုကို ရွေးပါ။ Command ကို ရိုက်ပါ၊ သို့မဟုတ် {{ui:Layers}} panel ၏ အပေါ်ရှိ {{ui:Tools}} ကို ဖွင့်ပါ။

| Command | ဘာလုပ်သလဲ |
|---|---|
| {{cmd:LAYISO}} | အရာဝတ္ထုများ ရွေးပြီး {{key:Enter}} နှိပ်ပါ: ၎င်းတို့၏ လေယာများသာ ဖွင့်ထား၊ အခြားလေယာအားလုံး ပိတ်သည်။ လက်ရှိ လေယာ ပိတ်သွားလျှင် သီးခြားခွဲထားသော လေယာတစ်ခုသည် လက်ရှိ ဖြစ်လာသည်။ |
| {{cmd:LAYUNISO}} | နောက်ဆုံး {{cmd:LAYISO}} ပိတ်ခဲ့သော လေယာများကို ပြန်ဖွင့်ပြီး ၎င်းပြောင်းခဲ့သော လက်ရှိ လေယာကို ပြန်ပေးသည်။ |
| {{cmd:LAYOFF}} | အရာဝတ္ထုများကို တစ်ခုပြီးတစ်ခု နှိပ်ပါ: တစ်ခုစီ၏ လေယာ ပိတ်သည်။ နောက်ဆုံးကို ပြန်ယူရန် `U` ရိုက်ပါ၊ ပြီးရန် {{key:Enter}}။ |
| {{cmd:LAYFRZ}} | အတူတူ၊ လေယာတစ်ခုစီကို freeze လုပ်သည်။ |
| {{cmd:LAYMCUR}} | အရာဝတ္ထုတစ်ခုကို နှိပ်ပါ: ၎င်း၏ လေယာ လက်ရှိ ဖြစ်လာသည် (ဖွင့်ပြီး freeze ဖြုတ်သည်)။ အရာတစ်ခု ရွေးပြီးသား ဖြစ်လျှင် ထိုအရာကို သုံးသည်။ |
| {{cmd:LAYON}} | လေယာအားလုံးကို ဖွင့်သည်။ |
| {{cmd:LAYTHW}} | လေယာအားလုံး၏ freeze ကို ဖြုတ်သည်။ |

လက်ရှိ လေယာကို ဤနည်းဖြင့် ပိတ်ခြင်း သို့မဟုတ် freeze လုပ်ခြင်း မရှိပါ: history က ထိုသို့ ပြောသည်၊ ဦးစွာ {{cmd:LAYMCUR}} ဖြင့် အခြားလေယာကို လက်ရှိ ပြုလုပ်နိုင်သည်။ Block reference ကို ရွေးလျှင် reference ၏ ကိုယ်ပိုင် လေယာကို သုံးသည်။

## လေယာများ ပြောင်းအမည်၊ ပေါင်းရန်နှင့် ဖျက်ရန်

- {{cmd:RENAME}}: `LA`၊ အမည်ဟောင်းနှင့် အသစ်ကို ရိုက်ပါ။ လေယာပေါ်ရှိ အရာဝတ္ထုအားလုံး လိုက်ပြောင်းသည်။ (`B` ဖြင့် block ကို အလားတူ ပြောင်းသည်၊ ၎င်းကို ရည်ညွှန်းသော reference အားလုံးနှင့်အတူ။)
- {{cmd:LAYMRG}}: ပေါင်းရန် လေယာတစ်ခုစီပေါ်ရှိ အရာဝတ္ထုတစ်ခုကို နှိပ်ပါ (သို့မဟုတ် `N` နှင့် အမည်ရိုက်ပါ)၊ {{key:Enter}} နှိပ်ပါ၊ ထို့နောက် ပန်းတိုင်လေယာကို ရွေးပြီး `Y` ဖြေပါ။ အရာဝတ္ထုများသည် ပန်းတိုင်သို့ ရွှေ့သည် — မော်ဒယ်၊ စာရွက်များနှင့် block များအတွင်း — ပေါင်းထားသော လေယာများ ပျောက်သည်။
- {{cmd:LAYDEL}}: လေယာပေါ်ရှိ အရာဝတ္ထုတစ်ခုကို ရွေး (သို့မဟုတ် `N` နှင့် အမည်) ပြီး `Y` ဖြေပါ။ လေယာသည် ၎င်းပေါ်ရှိ **အရာဝတ္ထု အားလုံးနှင့်အတူ** ပျောက်သည်၊ နေရာတိုင်းမှ။ Layer 0၊ DEFPOINTS နှင့် လက်ရှိ လေယာကို ဖျက်၍ မရပါ။

သုံးခုစလုံးသည် undo အဆင့်တစ်ခုစီ ဖြစ်သည်။ သုံးခုစလုံးကို {{ui:Layers}} panel ၏ အပေါ်ရှိ {{ui:Tools}} တွင် တွေ့ရသည်။

1. Wall မျဉ်းတစ်ခုကို နှိပ်ပြီး `LAYISO` ရိုက်ကာ {{key:Enter}} နှိပ်ပါ။ Walls သာ ဖွင့်ထားသည်။
2. Walls ပေါ်တွင် လိုအပ်သည်များကို ဆွဲ သို့မဟုတ် ပြောင်းပါ။
3. `LAYUNISO` ရိုက်ပြီး {{key:Enter}} နှိပ်ပါ။ Doors နှင့် Notes ပြန်ပေါ်လာသည်။

## အမှားများ

- **လိုင်းအသစ်များ မှားသော လေယာပေါ် ရောက်သည်။** ဆွဲမည်မတိုင်မီ ဘယ်အစက် ဖြည့်ထားသလဲ စစ်ပါ။ လေယာအသစ်ကို ထည့်သည်နှင့် ၎င်းသည် လက်ရှိ ဖြစ်လာသည်။
- **အရာဝတ္ထု ရွေး၍ မရပါ။** ၎င်း၏ လေယာသည် lock၊ ပိတ် သို့မဟုတ် freeze ဖြစ်နေသည်။
- **လေယာသည် အခြားပရိုဂရမ်တွင် ပုံနှိပ်ဆဲ ဖြစ်သည်။** DXF R12 သည် "plot မလုပ်ရ" ကို သိမ်း၍ မရပါ။ ပုံဆွဲတွင် စာရွက်ရှိလျှင် CadCraft က ဆက်တင်ကို ကိုယ်တိုင် သိမ်းထားသော်လည်း အခြားပရိုဂရမ်များက ထိုလေယာကို ပုံနှိပ်မည်။
- **သိမ်းပြီးနောက် လေယာအမည်များ အကြီးဖြစ်နေသည်။** DXF R12 သည် အမည်များကို အကြီးဖြင့် သိမ်းသည်၊ ထို့ကြောင့် `Walls` သည် `WALLS` ဖြစ်လာပြီး space များသည် `_` ဖြစ်သည်။ သိမ်းထားသော DWG သည် အမည်များကို သင်ရိုက်ခဲ့သည့်အတိုင်း ထိန်းသည်။
- **လေယာကို ပြောင်းအမည်၊ ပေါင်း သို့မဟုတ် ဖျက်ခြင်း။** {{cmd:RENAME}}၊ {{cmd:LAYMRG}} သို့မဟုတ် {{cmd:LAYDEL}} (ထို့အပြင် {{ui:Tools}} တွင်) ကို သုံးပါ: အောက်တွင် ကြည့်ပါ။

## လေယာများ အုပ်စုဖွဲ့ရန်

Existing၊ Proposed နှင့် Services ကဲ့သို့ folder များထဲ လေယာများ ထည့်၍ စာရင်းကို တိုစေပါ။ Folder တစ်ခုစီ ခေါက်နိုင်ပြီး ၎င်း၏ switch များက လေယာအားလုံးကို အတူ ဖွင့်/ပိတ်၊ freeze သို့မဟုတ် lock လုပ်သည်။ လက်ရှိ လေယာကို ဘယ်တော့မှ မပိတ်ပါ။

Layers panel ရှိ {{ui:Tools}} တွင် အသင့်သုံး အုပ်စုတစ်ခု (အိမ်ယာ အလုပ်ငယ်အတွက် ပြင်ဆင်ထားသည်) အတွက် {{ui:Add ready-made groups}}၊ ရှေ့ဆက်တူသော လေယာများကို အုပ်စုဖွဲ့ရန် (`E-Walls`၊ `E-Doors`) {{ui:Group by name}}၊ သို့မဟုတ် {{ui:New group}} ကို ရွေးပါ။ လေယာကို folder ပေါ် ဆွဲချပါ၊ သို့မဟုတ် လက်ရှိ လေယာအတွက် လေယာစာရင်းအပေါ်ရှိ အစုကို သုံးပါ။ စာရင်းကို ကျဉ်းစေရန် {{ui:Find a layer}} တွင် ရိုက်ပါ။ `LAYGROUP` (`LG`) သည် command line တွင် အလားတူ လုပ်သည်။

လေယာများ ကိုယ်တိုင် မပြောင်းပါ၊ ထို့ကြောင့် အခြား CAD ပရိုဂရမ်များက ၎င်းတို့ကို ပုံမှန် ညီညာ စာရင်းအဖြစ် မြင်သည်။ CadCraft က အုပ်စုများကို ဖိုင်တွင် သိမ်းသည်။
