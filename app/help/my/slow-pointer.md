CadCraft သည် browser တွင် အလုပ်လုပ်သည် (CadCraft Studio သည်လည်း browser view ဖြစ်သည်)၊ ထို့ကြောင့် ၎င်းတွင် graphics card တစ်ခု သို့မဟုတ် အခြားတစ်ခုအတွက် တည်ဆောက်ထားသော အရာ မရှိပါ။ crosshair ကို app က ဆွဲသည်၊ ထို့ကြောင့် app က frame တစ်ခုကို ဆွဲနိုင်သလောက်သာ ရွေ့နိုင်သည်။

## CadCraft ကို အပို အရာများ လျှော့ချခိုင်းပါ

1. ညာဘက်အပေါ်ရှိ gear ဖြစ်သော {{ui:Settings}} ကို ဖွင့်ပြီး {{ui:CadCraft}} tab တွင် ဆက်နေပါ။
2. {{ui:Smoother pointer on slower computers}} ကို ရွေးပါ။
3. {{ui:On}} ကို ရွေးပါ။

ဖွင့်ထားသည့်အခါ ကွန်ပျူတာ၏ ကိုယ်ပိုင် crosshair ညွှန်ပြချက်ကို ဆွဲထားသော crosshair နှင့် pick box (full-screen crosshair ပါ) အစား အသုံးပြုသည်၊ ညွှန်ပြချက်အောက်ရှိ object သည် ညွှန်ပြချက် ရွေ့နေချိန်အစား ရပ်နေချိန်တွင် မီးလင်းသည်။ Object snaps၊ tracking နှင့် rubber band တို့သည် ယခင်အတိုင်း အလုပ်လုပ်သည်။

{{ui:Automatic}} သည် CadCraft စတင်သည့် ပုံစံဖြစ်သည်။ ညွှန်ပြချက် ရွေ့နေစဉ် frame ကြာချိန်ကို စောင့်ကြည့်ပြီး စက္ကန့်အနည်းငယ် နှေးနေလျှင် ၎င်းကို အလိုအလျောက် ဖွင့်သည်။ ဖွင့်သည့်အခါ တစ်ကြိမ် အကြောင်းကြားသည်။ {{ui:Off}} သည် အမြန်နှုန်း မည်သို့ပင် ဖြစ်စေ ဆွဲထားသော crosshair ကို ထားရှိသည်။

## နှေးနေဆဲ ဖြစ်လျှင်

- Browser တွင် hardware acceleration ဖွင့်ထားခြင်း ရှိမရှိ စစ်ပါ: tab အသစ်တွင် `chrome://gpu` (သို့မဟုတ် `edge://gpu`) ကို ဖွင့်ပါ။ ပထမစာကြောင်းများတွင် "Software only" သို့မဟုတ် "Disabled" ဟု ပါလျှင် browser သည် graphics card မပါဘဲ ဆွဲနေသည်။ graphics driver ကို အပ်ဒိတ်လုပ်ခြင်းက ပြန်ကောင်းလာစေတတ်သည်။
- အခြား ကြီးလေးသော tab နှင့် program များကို ပိတ်ပါ၊ browser window ကို ပိုသေးအောင် စမ်းကြည့်ပါ။
- {{ui:Help}}၊ {{ui:Report a problem}} မှတစ်ဆင့် ကျွန်ုပ်တို့ကို အကြောင်းကြားပါ: browser သို့မဟုတ် CadCraft Studio သုံးနေခြင်း ရှိမရှိ၊ ၎င်း၏ ဗားရှင်း၊ နှင့် gpu စာမျက်နှာက ပြောသည့်အရာကို ပြောပြပါ။
