## ဘာတွေ ဖန်တီးမလဲ

စတုဂံတစ်ခုနှင့် ၎င်း၏ ထောင့်ဆက်နှစ်ခု၊ ထောင့်ဆက်များ ဖြတ်သည့်နေရာတွင် ဗဟိုပြုထားသော စက်ဝိုင်းတစ်ခု၊ နှင့် ဘေးတစ်ဖက်၏ အလယ်မှ စက်ဝိုင်းပေါ်သို့ မျဉ်းတစ်ကြောင်းကို ဆွဲမည်။ အမှတ်တိုင်းကို မောက်စ်ဖြင့် ရွေးမည်၊ အမှတ်တိုင်းသည် တိကျသည်။

## Snap လုပ်ပုံ

Command တစ်ခုက အမှတ်ကို မေးနေစဉ် CadCraft သည် ကော်ဆင်မှ ပိုင်းခြားထားသော 10 pixel ခန့်အတွင်း snap အမှတ်များကို ရှာသည်။ တွေ့သောအခါ အမှတ်အမည် (marker) နှင့် အညွှန်း ("Endpoint", "Intersection") ပေါ်လာပြီး၊ နှိပ်သည့်အခါ ကော်ဆင်ရှိနေရာ မဟုတ်ဘဲ **တိကျစွာ** ထိုအမှတ်ပေါ်သို့ ကျသည်။

Status bar ရှိ {{ui:Snap}} ကို နှိပ်ထားသောအခါ snap များ ဖွင့်ထားသည်။ {{key:F3}} သည် ဖွင့်/ပိတ် လုပ်သည်။

သင်အသုံးပြုနိုင်သော snap များမှာ:

| Snap | ကျရောက်သည့်နေရာ |
|---|---|
| Endpoint | မျဉ်း၊ arc နှင့် polyline အပိုင်းများ၏ အဆုံးများ |
| Midpoint | မျဉ်း၊ arc နှင့် polyline အပိုင်းများ၏ အလယ် |
| Center | စက်ဝိုင်းနှင့် arc များ၏ ဗဟို၊ နှင့် polyline arc အပိုင်းများ၏ ဗဟို |
| Quadrant | စက်ဝိုင်းနှင့် arc များ၏ 0၊ 90၊ 180 နှင့် 270 ဒီဂရီ အမှတ်များ |
| Intersection | အရာဝတ္ထုနှစ်ခု ဖြတ်သည့်နေရာ |
| Perpendicular | နောက်ဆုံးအမှတ်နှင့် ထောင့်မှန်ကျသော အရာဝတ္ထု၏ အမှတ် (အခြေခံအမှတ် လိုသည်) |
| Tangent | နောက်ဆုံးအမှတ်မှ မျဉ်းတစ်ကြောင်းက စက်ဝိုင် သို့မဟုတ် arc ကို ထိသည့် အမှတ်။ နောက်ဆုံးအမှတ် မရှိသေးသည့်အခါ (မျဉ်း၏ ပထမအမှတ်) အမှတ်အမည်က "deferred" ဟု ပြမည်: ထိသည့်အမှတ်ကို နောက်အမှတ် သိရှိပြီးမှ တွက်သည်၊ ထို့ကြောင့် Tangent မှ Tangent သို့ မျဉ်းသည် စက်ဝိုင်းနှစ်ခုလုံးကို ထိသည် |
| Nearest | အရာဝတ္ထုတစ်ခုခုပေါ်ရှိ အနီးဆုံးအမှတ် |
| Node | Point အရာဝတ္ထုများ |
| Insertion | စာသားနှင့် ဘလောက်ရည်ညွှန်းချက်များ၏ insertion အမှတ် |

Tangent နှင့် Nearest မှလွဲ၍ အားလုံးသည် မူလအနေဖြင့် ဖွင့်ထားသည်။ Nearest က အခြားတစ်ခုကို ရွေးချင်သော်လည်း အမြဲအနိုင်ရလေ့ရှိသည်; Tangent လိုအပ်သောအခါ ၎င်းကို ဖွင့်ပါ။

## Snap များကို ရွေးခြင်း

1. Status bar ရှိ {{ui:Snap}} ဘေးရှိ အသေးစား မြားကို နှိပ်ပါ။ {{ui:Object snaps}} စာရင်း ဖွင့်မည်။
2. Snap များကို အမှန်ခြစ်ခြင်း သို့မဟုတ် ဖျက်ခြင်း ပြုလုပ်ပါ။ ပြောင်းလဲမှုများ ချက်ချင်း အသက်ဝင်မည်။
3. စာရင်းကို ပိတ်ရန် မြားကို ထပ်နှိပ်ပါ။

CadCraft သည် သင်၏ ရွေးချယ်မှုနှင့် browser အတွင်းရှိ {{ui:Grid}}, {{ui:Ortho}} နှင့် {{ui:Snap}} ဆက်တင်များကို မှတ်ထားသည်။

## အဆင့်များ

1. `REC` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
2. `0,0` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
3. `@4000,3000` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။ စတုဂံ ပေါ်လာမည်။
4. {{ui:အပြည့်အစုံ}} ကို နှိပ်ပါ။
5. `L` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
6. ကော်ဆင်ကို ဘယ်အောက်ထောင့်သို့ ရွှေ့ပါ။ Marker က "Endpoint" ဟု ပြမည်။ နှိပ်ပါ။
7. ညာအထက်ထောင့်သို့ "Endpoint" ပေါ်သည်အထိ ရွှေ့ပါ။ နှိပ်ပါ။
8. မျဉ်းကို အဆုံးသတ်ရန် {{key:Enter}} ကို နှိပ်ပါ။
9. {{cmd:LINE}} ကို ထပ်လုပ်ရန် {{key:Enter}} ကို ထပ်နှိပ်ပြီး၊ ညာအောက်ထောင့်မှ ဘယ်အထက်ထောင့်သို့ ထောင့်ဆက်ကို အလားတူ ဆွဲပါ။
10. စက်ဝိုင်း စတင်ရန် `C` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
11. ထောင့်ဆက်များ ဖြတ်သည့်နေရာသို့ ကော်ဆင်ကို ရွှေ့ပါ။ Marker က "Intersection" ဟု ပြမည်။ နှိပ်ပါ။
12. `800` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။

ဖြတ်ကျော်သည့်နေရာတွင် တိကျစွာ ဗဟိုပြုထားသော စက်ဝိုင်းကို မြင်ရမည်။

13. `L` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
14. စတုဂံ၏ ဘယ်ဘက်ဘေးအလယ်သို့ "Midpoint" ပေါ်သည်အထိ ရွှေ့ပါ။ နှိပ်ပါ။
15. ကော်ဆင်ကို စက်ဝိုင်းပေါ်သို့၊ ၎င်း၏ ဘယ်ဘက်ခြမ်းသို့ ရွှေ့ပါ။ Marker က "Perpendicular" သို့မဟုတ် "Quadrant" ဟု ပြမည်; ဤနေရာတွင် အမှတ်တူ ဖြစ်သည်။ နှိပ်ပါ။
16. {{key:Enter}} ကို နှိပ်ပါ။

မျဉ်းအသစ်သည် ဘယ်ဘက်ဘေး အလယ်မှ စတင်ပြီး စက်ဝိုင်းပေါ်တွင် တိကျစွာ ရပ်သည်။

## Snap တစ်ကြိမ်ကို ကျော်ခြင်း

နှိပ်နေစဉ် {{key:Shift}} ကို ဖိထားပါ။ ထိုတစ်ကြိမ်အတွက် object snap များကို လျစ်လျူရှုပြီး၊ အမှတ်သည် ကော်ဆင်ရှိ နေရာ (သို့မဟုတ် Ortho ဖွင့်ထားလျှင် Ortho ဦးတည်ချက်) တွင် တိကျစွာ ကျမည်။

## Ortho

{{ui:Ortho}} ({{key:F8}}) သည် နောက်အမှတ်ကို အခြေခံအမှတ်မှ ဘေးသို့ သို့မဟုတ် အပေါ်အောက်သို့ ဖြောင့်စွာ ထားသည်။ ၎င်းသည် နှိပ်ခြင်းနှင့် တိုက်ရိုက် အကွာအဝေး ထည့်ခြင်း (prompt တွင် ရိုက်သော ဂဏန်းတစ်ခုတည်း) နှစ်ခုလုံးတွင် သက်ရောက်သည်။ Object snap များသည် Ortho ထက် အနိုင်ရသည်: snap marker ပေါ်နေလျှင် နှိပ်ချက်သည် snap သို့ သွားသည်။

## Polar tracking

{{ui:Polar}} ({{key:F10}}) သည် ထောင့်ပိုများစွာတွင် Ortho ဖြစ်သည်။ Command တစ်ခုတွင် အခြေခံအမှတ် (မျဉ်း၏ နောက်ဆုံးအမှတ်၊ ရွှေ့ခြင်း၏ အခြေခံအမှတ်) ရှိစဉ်၊ မောက်စ်ညွှန်မှာ polar step ၏ အဆ တစ်ခုဖြင့် ထိုအမှတ်မှ ray နှင့် နီးကပ်လာသောအခါ ချိန်ညှိသည်: အစက်ပြ မျဉ်းတစ်ကြောင်း ပေါ်ပြီး ကော်ဆင်ဘေးရှိ အညွှန်းက `Polar: 1200 < 30°` ဟု ဖတ်ရမည်။ ထိုအမှတ်ကို သုံးရန် နှိပ်ပါ၊ သို့မဟုတ် အကွာအဝေး ရိုက်ပါ: `1200` သည် ray ပေါ်တွင် တိကျစွာ 1200 သွားမည်။

Step မူလအနေဖြင့် 90° ဖြစ်ပြီး ပြောင်းမချင်း ထိုအတိုင်းဖြစ်သည်: {{cmd:POLARANG}} ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ကာ `30` (သို့မဟုတ် 45, 22.5, 15 …) ကို ရိုက်ပါ။ Polar နှင့် Ortho သည် တစ်ခုနှင့်တစ်ခု ဆန့်ကျင်သည်: တစ်ခုကို ဖွင့်လျှင် အခြားတစ်ခု ပိတ်သွားသည်။

## Object snap tracking

{{ui:Track}} ({{key:F11}}) သည် သင်ရပ်ထားခဲ့သော snap အမှတ်များနှင့် မောက်စ်ညွှန်ကို ညီအောင်လုပ်ပေးသည်၊ ထို့ကြောင့် အကူမျဉ်းများ မဆွဲဘဲ ထောင့်တစ်ခုနှင့် ညီပြီး အခြားတစ်ခုအထက်ရှိ အမှတ်ကို ရွေးနိုင်သည်။

1. {{ui:Snap}} နှင့် {{ui:Track}} ကို ဖွင့်ပြီး အမှတ်မေးသော command (`L`) ကို စပါ။
2. ထောင့်ကဲ့သို့ snap အမှတ်ပေါ်တွင် မောက်စ်ကို ဝက်ဝက်ခန့် (တစ်ဝက်စက္ကန့်) ဖြင့် မနှိပ်ဘဲ ရပ်ထားပါ။ အသေးစား လက်ကမ်းပုံ ပေါ်လာမည်: ၎င်းကို ရယူပြီးပြီ။ ပြန်ဖျက်ရန် ထပ်ရပ်ထားပါ။
3. ထိုအမှတ်မှ ဘေးတိုက် သို့မဟုတ် ဒေါင်လိုက် ဖြောင့်ဖြောင့် မောက်စ်ကို ရွှေ့ပါ။ အစက်ပြ မျဉ်းတစ်ကြောင်း မောက်စ်ကို လိုက်မည်၊ အညွှန်းက `Track: 600 < 90°` ဟု ဖတ်ရမည်။ နှိပ်ပါ၊ သို့မဟုတ် အကွာအဝေး ရိုက်ပါ။
4. ဒုတိယအမှတ်ကို ရယူပြီး၊ တစ်ခု၏ ဒေါင်လိုက်နှင့် အခြားတစ်ခု၏ ပန်းလိုက်ဖြတ်သည့်နေရာသို့ ရွှေ့ပါ: မောက်စ်သည် ထိုဖြတ်ကျော်မှုသို့ snap လုပ်မည် (`Track: where two lines meet`)။

{{ui:Polar}} ကိုလည်း ဖွင့်ထားလျှင် ရယူထားသော အမှတ်များသည် polar ထောင့်တိုင်းတွင် ခြေရာခံသည်။ Command ပြီးသည်အထိ အမှတ် ခုနစ်ခုအထိ ထိန်းထားသည်။ {{key:Shift}} သည် snap များကဲ့သို့ တစ်ကြိမ်နှိပ်ချက်အတွက် tracking ကို ပိတ်သည်။

## ဂရစ်

{{ui:Grid}} ({{key:F7}}) သည် ပုံဆွဲနောက်ကွယ်တွင် မျဉ်းဂရစ်ကို ပြသည်၊ ငါးကြောင်းတိုင်း အထူ မျဉ်းများဖြင့်; ကြီးထွားလာပုံသည် zoom နှင့်အတူ ပြောင်းသည်။ {{ui:Grid snap}} ({{key:F9}}) ကို မဖွင့်မချင်း ၎င်းသည် လမ်းညွှန်သာ ဖြစ်သည်: ထိုအခါ နှိပ်ချက်များသည် အနီးဆုံး ဂရစ်အမှတ်သို့ ကျမည်၊ object snap က အမှတ်ကို ဦးစွာ မယူလျှင်။

## ကွန်ပျူတာပေါ်ရှိ function key များ

{{key:F9}} သည် Grid snap၊ {{key:F10}} သည် Polar၊ {{key:F11}} သည် Track ဖြစ်သည်။

:::mac
Mac တွင် F3၊ F7၊ F8 နှင့် F9 သည် Mission Control နှင့် media ကို များသောအားဖြင့် ထိန်းချုပ်သည်။ ခလုတ်ကို **fn** ဖြင့် ဖိထားပါ၊ သို့မဟုတ် [Keys, mice and trackpads](common:keys) တွင် ဖော်ပြထားသည့်အတိုင်း standard function key များကို ဖွင့်ပါ။ Status bar ခလုတ်များသည် အမြဲ အလုပ်လုပ်သည်။
:::

:::firefox
Firefox တွင် F7 သည် caret browsing အတွက် key ဖြစ်သည်။ Firefox က caret browsing ကို ဖွင့်မလားဟု မေးလျှင် **No** ကို ရွေးပါ။ မေးခွန်းက ပြန်ပေါ်နေလျှင် {{ui:Grid}} ခလုတ်ကို သုံးပါ။
:::

:::touch
Touch screen တွင် hover မရှိသောကြောင့် snap marker သည် သင်၏ လက်ထိသည့်နေရာတွင်သာ ပေါ်သည်။ သေးငယ်သော ပစ်မှတ်များအတွက် အနီးကပ် zoom ဝင်ပါ၊ သို့မဟုတ် သြဒိနိတ်များ ရိုက်ပါ။
:::

## အဖြစ်များသော အမှားများ

- **နှိပ်ချက်သည် မှားသောအမှတ်သို့ သွားသည်။** နှိပ်မီ marker အညွှန်းကို ကြည့်ပါ: နှစ်ခုလုံး နီးသောအခါ Endpoint သည် Midpoint ထက် အနိုင်ရသည်။ Zoom ဝင်ပါ၊ သို့မဟုတ် မလိုအပ်သော snap များကို ဖျက်ပါ။
- **Marker မပေါ်ပါ။** {{ui:Snap}} ပိတ်နေသည်၊ သို့မဟုတ် လိုချင်သော snap ကို အမှန်ခြစ်မထားပါ၊ သို့မဟုတ် အရာဝတ္ထုသည် ပိတ်ထားသော သို့မဟုတ် frozen လေယာပေါ်တွင် ရှိသည်။
- **ပုံဆွဲ ရှုပ်ထွေးနေစဉ် snap များက မှားသည်ကို ဖမ်းသည်။** Zoom ဝင်ပါ။ Snap အကွာအဝေးကို မျက်နှာပြင် pixel ဖြင့် တိုင်းသဖြင့် zoom ဝင်လျှင် ပုံဆွဲပေါ်တွင် ပိုသေးသွားသည်။
- **Shift က မျဉ်းဖြောင့် ပေးမည်ဟု မျှော်လင့်ခြင်း။** CadCraft တွင် Shift သည် တစ်ကြိမ်နှိပ်ချက်အတွက် snap များကို ပိတ်သည်။ မျဉ်းဖြောင့်အတွက် {{ui:Ortho}} ကို သုံးပါ။
- **အမှတ်များ ဂရစ်အမှတ်များပေါ်သို့ ကျမည်ဟု မျှော်လင့်ခြင်း။** {{ui:Grid snap}} ({{key:F9}}) ကို ဖွင့်ပါ၊ သို့မဟုတ် ဂဏန်းပြည့်များအတွက် သြဒိနိတ်များ ရိုက်ပါ။
