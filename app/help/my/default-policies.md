## သင်လုပ်ရမည့်အရာ

CadCraft အား ပုံဆွဲအသစ် ဘာနှင့် စတင်သင့်သည်ကို ပြောပါ၊ ထို့ကြောင့် ရုံးတွင် မည်သူမျှ UNITS ကို အမြဲ run ပြီး တူညီသော အရာများကို ပြောင်းစရာ မလိုပါ။ ဤသည်မှာ add-on တစ်ခု ဖြစ်သည်: ဖွင့်မချင်း ပိတ်ထားသည်၊ မသတ်မှတ်သော မူဝါဒသည် CadCraft ၏ ကိုယ်ပိုင် ပုံသေအတိုင်း ကျန်ရှိသည်။

:::note
ဤသည်များမှာ **အသစ်** ပုံဆွဲများနှင့် **အသစ်** စာရွက်များအတွက် ပုံသေများ ဖြစ်သည်။ သင်စတင်ပြီးသား ပုံဆွဲကို မပြောင်းပါ၊ ဖွင့်ထားသော ပုံဆွဲကိုလည်း မပြောင်းပါ။
:::

## အဆင့်များ

1. ဆက်တင်များ ဖွင့်ပါ၊ {{ui:Add-ons}} သို့ သွားပြီး {{ui:Default Policies}} ကို ဖွင့်ပါ။
2. ဆက်တင်များတွင် **CadCraft** tab ကို ဖွင့်ပြီး ဘယ်ဘက်ရှိ စာရင်းမှ {{ui:Default Policies}} ကို ရွေးပါ။
3. လိုချင်သော မူဝါဒများကို သတ်မှတ်ပါ။ တစ်ခုစီသည် **CadCraft ၏ ကိုယ်ပိုင်** တွင် စတင်သည်။ **Metric** နှင့် **Imperial** အကွက်ပါသော မူဝါဒသည် ပုံဆွဲအမျိုးအစား တစ်ခုစီအတွက် တန်ဖိုးတစ်ခု ယူသည်; လိုအပ်သည်များကိုသာ ဖြည့်ပါ။
4. Save ခလုတ် မရှိပါ: ပြောင်းလဲမှု တစ်ခုစီကို ပြုလုပ်သည်နှင့် သိမ်းပြီးသား ဖြစ်သည်။
5. ပုံဆွဲအသစ် စတင်ပါ။ သင်သတ်မှတ်ထားသော ယူနစ်များ၊ အရှည် ပုံစံ၊ တိကျမှုနှင့် စာသားအမြင့် ရှိပြီး ပထမ စာရွက်အသစ်သည် သင်ရွေးသော paper ပေါ်တွင် ရှိသည်။

## မူဝါဒများ

- **ပုံဆွဲအသစ်၏ ယူနစ်များ**: none၊ millimeters၊ centimeters၊ meters၊ inches သို့မဟုတ် feet။
- **အရှည် ပုံစံ** နှင့် **အရှည် တိကျမှု**: UNITS command က ပုံဆွဲအသစ်အတွက် သတ်မှတ်သည့်အရာ။
- **အသစ် စာသား အမြင့်**၊ ပုံဆွဲယူနစ်ဖြင့်။
- **စာရွက်အသစ်၏ paper**: New sheet သုံးသော paper။
- **Annotation sizes on paper** (ဆက်တင်များ › ကမ္ဘာလုံးဆိုင်ရာ › ပုံသေ မူဝါဒများ): ရုံး၏ အမြင့်များကို ပုံနှိပ်ထားသည့်အတိုင်း millimetres ဖြင့်။ CadCraft က မှတ်ချက်နှင့် တံဆိပ်များအတွက် တစ်ခုကို သုံးသည်: {{cmd:ANNOSCALE}} က အသစ် စာသား စတင်အမြင့်ကို annotation scale တွင် ထိုအမြင့်သို့ သတ်မှတ်သည်။ ကြည့်ပါ [ယူနစ်၊ စာရွက်များနှင့် စကေးများ](topic:units-papers-scales#annotate-by-scale)။

လက်မ သို့မဟုတ် ပေဖြင့် ပုံဆွဲသည် Imperial တန်ဖိုးများကို သုံးသည်; အခြား ပုံဆွဲအားလုံးက Metric တန်ဖိုးများ သုံးသည်။ ယူနစ် မရှိသော ပုံဆွဲသည် ဆက်တင်များ › ကမ္ဘာလုံးဆိုင်ရာ › ပုံသေ မူဝါဒများ တွင် သတ်မှတ်ထားသော ယူနစ်စနစ်ကို သုံးသည်၊ သို့မဟုတ် မသတ်မှတ်ထားလျှင် Metric။

## ရုံးတစ်ခုလုံးအတွက် မျှဝေခြင်း

1. ဆက်တင်များတွင် **ကမ္ဘာလုံးဆိုင်ရာ** tab ကို ဖွင့်ပြီး {{ui:Default Policies}} ကို ရွေးပါ။
2. {{ui:Save to a file}} ကို နှိပ်ပါ။ `.ccdefaults.json` ဖြင့် အဆုံးသတ်သော ဖိုင်ငယ်တစ်ခု ရမည်။
3. အခြားကွန်ပျူတာတွင် add-on ကို ဖွင့်ပြီး တူညီသော နေရာကို ဖွင့်ကာ {{ui:Load from a file}} ကို နှိပ်ပါ။ ဖိုင်၏ မူဝါဒများက ထိုကွန်ပျူတာ၏ မူဝါဒများကို အစားထိုးသည်။

ဖိုင်တစ်ခုတွင် CadCraft အက်ပ်အားလုံး၏ မူဝါဒများ ပါသောကြောင့် တူညီသော ဖိုင်သည် BimCraft တွင်လည်း အလုပ်လုပ်သည်။

## သိထားသင့်သည်များ

- စာရွက်တစ်ရွက်၏ စကေးအတွက် မူဝါဒ မရှိပါ: စာရွက်အသစ်၏ view သည် ပုံဆွဲနှင့် ကိုက်ညီအောင် ပြင်ဆင်ပြီး စကေးကို စာရွက်ပေါ်တွင် သတ်မှတ်ပါ။
- အတိုင်းအတာ ပုံစံအတွက် မူဝါဒ မရှိပါ: ပုံဆွဲအသစ်တွင် အမည်ပေးထားသော အတိုင်းအတာ ပုံစံများ မရှိပါ။ DIMSTYLE ဖြင့် အတိုင်းအတာများ ထည့်ပါ၊ သို့မဟုတ် သင့်ပုံစံပါသော ပုံဆွဲမှ စပါ။
- ဖိုင်သည် ရိုးရှင်းပြီး ဖတ်လို့ရသော JSON ဖြစ်သည်။ ဤဗားရှင်းက မသိသော ဖိုင်ထဲရှိ မူဝါဒကို ချန်ထားပြီး မက်ဆေ့ချ်တွင် အမည်ဖြင့် ဖော်ပြသည်; ကျန်သည်များက ဆက်လက် တင်သည်။
- မူဝါဒများကို ဤ browser တွင် ထိန်းသိမ်းထားပြီး ပုံဆွဲတွင် မဟုတ်ပါ။ add-on ကို ပိတ်လိုက်လျှင် အရာအားလုံး CadCraft ၏ ကိုယ်ပိုင် ပြန်ဖြစ်သည်။
