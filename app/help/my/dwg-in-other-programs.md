## CadCraft ရေးသည့်အရာ

{{ui:Save}} သည် အစစ်အမှန် DWG ကို ရေးသည်၊ ပုံဆွဲဝင်လာခဲ့သော version သို့မဟုတ် {{ui:Save as}} တွင် သင်ရွေးသော version ဖြင့်: AutoCAD 2000၊ 2004၊ 2007၊ 2010၊ 2013 သို့မဟုတ် 2018။ နောက်ကွယ်တွင် ဘာမျှ ပြောင်းလဲမည်မဟုတ်ပါ: ကြားတွင် ပြောင်းလဲခဲ့သော အရာများကို မှတ်တမ်းက ပြသည် (ဥပမာ 2000 DWG တွင် true colour ကို အနီးဆုံး စံအရောင်အဖြစ် ရေးခြင်း)။

## ဘယ်မှာ ဖွင့်ခဲ့သလဲ

CadCraft ရေးသော DWG တိုင်းကို version အားလုံးတွင်၊ CadCraft မဟုတ်သော program သုံးခုက ဖွင့်သည်: ODA File Converter (ဖိုင်ကို စစ်ဆေးသော်လည်း ဘာကိုမျှ မပြင်ပါ)၊ LibreDWG နှင့် libdxfrw။ ၎င်းတို့၏ ဖတ်ပုံကို CadCraft နှင့် နှိုင်းယှဉ်သည်: အရာဝတ္ထုများ၊ layer များ၊ block များနှင့် attribute များ၊ dimension များ၊ hatch များ၊ sheet များနှင့် ၎င်းတို့၏ viewport များ။

CadCraft ၏ DWG ဖိုင်များကို AutoCAD နှင့် အခမဲ့ DWG TrueView တွင် ဖွင့်ခြင်းကို Windows ပေါ်တွင် အရာဝတ္ထုအမျိုးအစား တစ်ခုချင်းစီအလိုက် စစ်ဆေးနေသည် (AUDIT၊ layer များ၊ sheet များ၊ dimension များ၊ hatch များ၊ attribute များ၊ dynamic block များ၊ clipped reference များ၊ ပုံများ)။ ရလဒ်များ ရောက်လာသောအခါ ဤနေရာတွင် ဖော်ပြမည်။

## Program တစ်ခု ညည်းညူသောအခါ

1. DXF အဖြစ် ထပ်သိမ်းပါ ({{ui:Save as}} › {{ui:DXF 2000}}) ပြီး ထိုအတိုင်း ဖွင့်ပါ: program အများစုက DXF ကို ဖတ်နိုင်သည်။
2. DWG ကို ပိုဟောင်းသော version (2013 သို့မဟုတ် 2010) ဖြင့် သိမ်းပါ။
3. ဘယ် program နှင့် version၊ ဘာပြောသလဲ ကို Discord တွင် ကျွန်ုပ်တို့အား ပြောပါ; ဖိုင်ကို ပေးပါက အထောက်အကူ ပိုဖြစ်သည်။
