## ဘာတွေ သင်ယူမလဲ

အမိန့်မပါဘဲ အရာဝတ္ထုတစ်ခုကို ပြောင်းရန် နည်းနှစ်ခု: **grips** ကို ဆွဲခြင်း၊ သို့မဟုတ် ညာဘက်ရှိ **Properties** panel တွင် တန်ဖိုးအသစ်များ ရိုက်ခြင်း။

## Grips

အမိန့် မလည်ပတ်နေချိန်တွင် အရာဝတ္ထုများကို (တစ်ကြိမ် 200 အထိ) ရွေးလျှင် သေးငယ်သော စတုရန်းများ ပေါ်လာသည်။ ဤတို့မှာ grips ဖြစ်သည်:

| အရာဝတ္ထု | Grips |
|---|---|
| မျဉ်းကြောင်း | အဆုံးနှစ်ဖက်စလုံးနှင့် အလယ် (မျဉ်းတစ်ခုလုံးကို ရွှေ့သည်) |
| စက်ဝိုင်း | စင်တာ (ရွှေ့သည်) နှင့် စက်ဝိုင်းပေါ်ရှိ အမှတ်လေးခု (radius ပြောင်းသည်) |
| Arc | စင်တာနှင့် အဆုံးနှစ်ဖက်စလုံး (စတင်ရာနှင့် ရပ်ရာ နေရာကို ပြောင်းသည်) |
| Polyline | ထောင့်အမှတ် (vertex) တိုင်း |
| စာသား၊ point၊ block reference | ထည့်သွင်းသော အမှတ် |
| Ellipse | စင်တာ |
| Dimension | ၎င်း၏ သတ်မှတ်အမှတ်များနှင့် dimension line ၏ နေရာ |
| Viewport | စင်တာ (ရွှေ့သည်) နှင့် ထောင့်လေးခု (အရွယ်အစား ပြောင်းသည်) |

### Grip ကို ရွှေ့ရန်

1. မျဉ်းတစ်ကြောင်း ဆွဲပြီး ၎င်းကို နှိပ်ပါ။ Grip သုံးခု ပေါ်လာသည်။
2. အဆုံးတစ်ဖက်ရှိ grip ကို နှိပ်ပါ။ Status bar က "ဤ grip သွားမည့်နေရာကို နှိပ်ပါ (ပယ်ဖျက်ရန် Esc)။ Snaps နှင့် Ortho အကျိုးသက်ရောက်သည်။" ဟု ပြသသည်။
3. Crosshair ကို ရွှေ့ပါ။ နမူနာ ပါလာသည်။
4. နေရာသစ်ကို နှိပ်ပါ၊ သို့မဟုတ် အခြားအရာဝတ္ထုပေါ်ရှိ အမှတ်ကို snap လုပ်ပြီး နှိပ်ပါ။

အဆုံးသည် ရွှေ့သွားပြီး ကျန်မျဉ်းကြောင်းသည် နေရာတွင် ရှိနေသည်။ Grip ပေါ်တွင် နှိပ်ထားပြီး ဆွဲကာ နေရာတွင် လွှတ်လည်း ရနိုင်သည်။

:::note
Grip အတွက် ကိုဩဒိနိတ် ရိုက်၍ မရပါ။ တိကျသော နေရာအတွက် အမှတ်ကို snap လုပ်ပါ၊ သို့မဟုတ် Properties တွင် တန်ဖိုးကို ရိုက်ပါ။
:::

Grip ရွှေ့ခြင်းကို ပယ်ဖျက်ရန် {{key:Esc}} ကို နှိပ်ပါ သို့မဟုတ် right-click လုပ်ပါ။

## Properties

ညာဘက် panel တွင် ရွေးထားသည့်အရာ၏ ဂုဏ်သတ္တိများ ပြသသည်။

1. မျဉ်းတစ်ကြောင်းကို နှိပ်ပါ။ Panel ခေါင်းစဉ်တွင် "မျဉ်းကြောင်း" ဟု ဖတ်ရမည်။
2. {{ui:အလျား}} အတွင်းသို့ နှိပ်ပါ၊ `2500` ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။

မျဉ်းသည် ယခု အတိအကျ 2500 အလျား ရှိပြီး စတင်အမှတ်နှင့် ထောင့်ကို ထိန်းထားသည်။ {{key:Enter}} သို့မဟုတ် အခြားနေရာကို နှိပ်ခြင်းဖြင့် တန်ဖိုးကို အသုံးချသည်; {{key:Esc}} သည် ဟောင်းသော တန်ဖိုးကို ပြန်ထားသည်။ ပြောင်းလဲမှု တစ်ခုစီသည် undo တစ်ဆင့် ဖြစ်ပြီး အရာဝတ္ထုများစွာ တစ်ပြိုင်နက် ပြောင်းလျှင်လည်း ဤအတိုင်း ဖြစ်သည်။

အကွက်များတွင် ဖော်ပြချက်များ (`=2*45`) နှင့် ယူနစ်ပါသော အလျားများ (`3'6"`, `900mm`) ကို လက်ခံသည်၊ အမှတ်တိုင်းတွင် X၊ Y နှင့် Z ရှိသည်၊ အရာဝတ္ထုများစွာကို အတူတကွ ပြောင်းနိုင်သည်။ ဤအရာအားလုံးကို [Properties panel](topic:properties-panel) တွင် ဖော်ပြထားသည်။

## အများဆုံး ဖြစ်တတ်သော အမှားများ

- **Grips မပေါ်ပါ။** အမိန့် လည်ပတ်နေခြင်း (ပြုလုပ်ရန် {{key:Esc}} ကို နှိပ်ပါ)၊ သို့မဟုတ် အရာဝတ္ထု 200 ကျော် ရွေးထားခြင်း၊ သို့မဟုတ် အရာဝတ္ထုသည် လော့ခ်ချထားသော လေယာပေါ်တွင် ရှိခြင်း ဖြစ်နိုင်သည်။
- **Grip သည် မှားသောနေရာ ရောက်သွားသည်။** Snap တစ်ခုက ဖမ်းမိခဲ့သည်။ Snap ကို လျစ်လျူရှုရန် နှိပ်စဉ် {{key:Shift}} ကို ဖိထားပါ။
- **Properties တွင် ရိုက်သော်လည်း ဘာမျှ မဖြစ်ပါ။** အသုံးချရန် {{key:Enter}} ကို နှိပ်ပါ သို့မဟုတ် အခြားနေရာကို နှိပ်ပါ။ လက်မခံသော ထည့်သွင်းမှု (သုည သို့မဟုတ် အနုတ် အလျားနှင့် radius၊ တန်ဖိုး မဟုတ်သော စာသား) ဖြစ်လျှင် အကွက်သည် အနီရောင် ပြောင်းပြီး အကြောင်းပြချက် ပြသသည်။
- **ရိုက်သော အက္ခရာများ Properties အကွက်ထဲ ဝင်သွားသည်။** အကွက်တွင် ကာဆာရှိနေချိန်တွင် ကီးများသည် ထိုနေရာတွင် ရိုက်သည်။ {{key:Enter}} သို့မဟုတ် {{key:Esc}} ကို နှိပ်ပြီးမှ အမိန့်ကို ရိုက်ပါ။
