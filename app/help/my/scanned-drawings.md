## စက္ကူစာရွက်မှ ပုံဆွဲ object များအထိ

စကင်ဖတ်ထားသော ပုံဆွဲသည် ပုံတစ်ပုံဖြစ်သည်။ CadCraft သည် သင်ပေးသော ပုံကို ထိန်းသိမ်းထားပြီး ဘယ်တော့မှ မပြောင်းပါ: သန့်စင်မှု အဆင့်တစ်ခုစီသည် ပုံအသစ်တစ်ပုံ ဖန်တီးပြီး၊ ပြန်ဖျက်ရန် အဆင့်တစ်ခုစီ ရှိသည်၊ {{cmd:SCANINFO}} သည် မူရင်းဖိုင်နှင့် ၎င်းနောက်ပိုင်း ယူခဲ့သော အဆင့်များကို စာရင်းပြုသည်။ တစ်နေရာရာသို့ ဘာမျှ မပို့ပါ၊ လေ့ကျင့်ထားသော မော်ဒယ်က ခန့်မှန်းခြင်းလည်း မလုပ်ပါ: သန့်စင်ခြင်းနှင့် trace သည် ပုံ processing ပုံမှန်များ ဖြစ်ပြီး သင့်ကွန်ပျူတာပေါ်တွင် run သည်။

1. **ထည့်ပါ။** {{cmd:SCANATTACH}} သည် PNG၊ JPEG၊ TIFF (စာမျက်နှာတစ်ခု၊ သို့မဟုတ် စာမျက်နှာများစွာပါဝင်သော ဖိုင်၏ စာမျက်နှာအားလုံး) သို့မဟုတ် ပုံဖြစ်သော PDF စာမျက်နှာကို ဖတ်သည်။ စာမျက်နှာ၊ ဘယ်အောက်ထောင့်နှင့် အကျယ်ကို မေးသည်။ PDF စာမျက်နှာအတွက် စာမျက်နှာကို လက်မတစ်လက်မလျှင် ဘယ်နှစ် pixel ဖြင့် ဆွဲမည်ကိုလည်း မေးသည်။
2. **အတိုင်းအတာချပါ။** {{cmd:SCANSCALE}}: စကင်ပေါ်တွင် အမှတ်နှစ်ခု ရွေးပြီး ၎င်းတို့ကြား အမှန်အကွာအဝေးကို ရိုက်ထည့်ပါ။ စာရွက်ကို ပထမအမှတ်ကို ဗဟိုပြု၍ အတိုင်းအတာချသည်။
3. **ညှိပါ။** {{cmd:SCANALIGN}}: စကင်ပေါ်တွင် အမှတ်နှစ်ခုနှင့် ၎င်းတို့ သက်ဆိုင်ရာ နေရာနှစ်ခု ရွေးပါ; စာရွက်သည် ကိုက်ညီအောင် ရွှေ့ပြီး လှည့်သည်၊ သင် No ဟု မဖြေလျှင် အတိုင်းအတာလည်း ချိန်သည်။
4. **စတုရန်းဖြစ်အောင်ပြင်ပါ။** {{cmd:SCANDESKEW}} သည် စာရွက်၏ ရှည်သောမျဉ်းများ တည်နေသော ထောင့်ကို တိုင်းပြီး ၎င်းကို မည်မျှ သေချာသည်ဟု ပြသသည်။ လက်ခံပါ၊ သို့မဟုတ် ကိုယ်ပိုင်တန်ဖိုး ရိုက်ထည့်ပါ၊ စာရွက်ကို လှည့်မည်။ ရှည်သောမျဉ်း အနည်းငယ်သာ ပါသော စာရွက်သည် သတိပေးချက် ရရှိသည်: မလက်ခံမီ ထောင့်ကို စစ်ဆေးပါ။
5. **သန့်စင်ပါ။** {{cmd:SCANCLEAN}} သည် စာရွက်ကို အဖြူအမည်း ပြုလုပ်သည် (Auto သည် ဦးစွာ စက္ကူကို ညီညာစေသည်; Adaptive သည် စက္ကူ၏ ပြောင်းလဲမှုများကို ပိုနီးကပ်စွာ လိုက်သည်; Level သည် စာရွက်တစ်ခုလုံးအတွက် ဂဏန်းတစ်ခု ဖြစ်သည်) နှင့် သင်သတ်မှတ်ထားသော အရွယ်အစားအထိ အစက်အပြောက်များကို ဖယ်ရှားသည်။
6. **ဖြတ်ပြီး ဖျက်ပါ။** {{cmd:SCANCROP}} သည် ဘောင်တစ်ခုကို ထိန်းထားသည်။ {{cmd:SCANERASE}} သည် ထောင့်စတုဂံ၊ polygon သို့မဟုတ် lasso (နှိပ်ပြီး ဆွဲပါ) ကို ဖျက်သည်: တံဆိပ်များ၊ မှတ်စုများ၊ ကော်ဖီခွက်ရာ။

သန့်စင်ပြီးသော ပုံသည် သိမ်းထားသော DWG ထဲတွင် ရှိသည် (IMAGE နှင့် IMAGEDEF, ပုံ၏ ဖိုင်သည် ပုံဆွဲ၏ ဘေးတွင်၊ မည်သည့်ပုံအတွက်မဆို ကဲ့သို့)။

## စကင်၏ မျဉ်းများသို့ snap လုပ်ရန်

{{cmd:RASTERSNAP}} ဖွင့်ထားလျှင် (မူလသတ်မှတ်ချက်)၊ object snap များသည် အဖြူအမည်း စကင်၏ မျဉ်းများကိုလည်း ရှာသည်: မျဉ်းများ၏ အဆုံးများ၊ အလယ်များ၊ ထောင့်များနှင့် ဖြတ်ကျော်နေရာများ၊ ပုံမှန် snap အမှတ်အသားများဖြင့် ပြသည်။ ညွှန်ပြကိရိယာအောက်ရှိ စာရွက်အပိုင်းကို သင် ရွှေ့သည်နှင့်အမျှ trace လုပ်သည်; pixel တစ်ခုသည် မျက်နှာပြင် pixel အနည်းငယ် ဖြစ်အောင် ချဲ့ပါ။ trace လုပ်နေသော အပိုင်းထက် ရှည်သော မျဉ်းကို ၎င်း၏ အဆုံးများအထိ လိုက်သည်။

## Trace

{{cmd:SCANTRACE}} သည် စာရွက်၏ မျဉ်းများကို layer အသစ် (SCAN-TRACE) ပေါ်တွင် မျဉ်းနှင့် အဝိုင်းများအဖြစ် ပြောင်းသည်၊ ပြန်ဖျက်ရန် အဆင့်တစ်ခုအဖြစ်၊ စကင်သည် အောက်တွင် ဆက်ရှိနေသည်။ သင် သတ်မှတ်သည်:

- **ခွင့်ပြုအကွာအဝေး:** trace လုပ်ထားသော မျဉ်း သို့မဟုတ် အဝိုင်းသည် စကင်ပေါ်ရှိ မျဉ်းများထံမှ ဘယ်လောက်ဝေးနိုင်သလဲ၊ ပုံဆွဲယူနစ်ဖြင့် (အစီရင်ခံစာတွင် pixel ကိုလည်း ပေးသည်)။ တင်းသော ခွင့်ပြုအကွာအဝေးသည် တုန်ခါမှုတိုင်းကို လိုက်သည်; လျော့ရဲသော တစ်ခုသည် အပိုင်းနည်းပြီး ပိုဖြောင့်သော အပိုင်းများ ပေးသည်။
- **Window:** စာရွက်၏ ထောင့်တစ်ခု၊ သို့မဟုတ် စာရွက်တစ်ခုလုံး။
- **Arc များ:** ပိတ်လျှင် မျဉ်းများသာ ဖန်တီးသည်။
- **ကျန်နေသည်များ:** trace မလုပ်ခဲ့သော အရာများကို ပိတ်နိုင်သော layer ပေါ်တွင် ဘောင်များအဖြစ် ဆွဲသည်၊ သို့မဟုတ် မဆွဲပါ။

trace သည် အရိုက်တစ်ခုစီ၏ အလယ်ကို ရှာသည်၊ လိုက်သည်၊ မျဉ်းဖြောင့်များနှင့် စက်ဝိုင်း arc များကို ကိုက်ညီအောင် ထည့်သည်၊ အခြားမျဉ်းတစ်ကြောင်း ဖြတ်သွားသဖြင့် ဖြတ်ခံရသော အပြေးများကို ပြန်ဆက်သည်၊ အနည်းငယ် level ဖြစ်သော နှင့် အနည်းငယ် ဒေါင်လိုက် ဖြစ်သော မျဉ်းများကို အတိအကျ level နှင့် ဒေါင်လိုက် ဖြစ်စေသည်၊ ထောင့်များကို ပိတ်သည်။ **စာသားနှင့် hatching သည် raster အဖြစ် ကျန်သည်:** စာလုံးအရွယ်အစား အပိုင်းများကို ဖယ်ထားသည်၊ တိုသော အပြိုင်မျဉ်းများ အစုအဝေးကို hatching အဖြစ် ယူပြီး ဖယ်ထားသည်။

trace ပြီးသောအခါ မျဉ်းနှင့် အဝိုင်း အရေအတွက်၊ ခွင့်ပြုအကွာအဝေးနှင့် raster အဖြစ် ထားခဲ့သော အပိုင်းအရေအတွက်ကို ပြောသည်။ **ဤသည်မှာ pixel များက ထို ခွင့်ပြုအကွာအဝေးဖြင့် ပေးသည့်အရာဖြစ်ပြီး ရလဒ် မှန်ကန်ကြောင်း အတည်ပြုချက် မဟုတ်ပါ။** စာရွက်နှင့် နှိုင်းယှဉ်ပါ: trace သည် မှိန်ပျောင်းသော မျဉ်းကို လွတ်သွားနိုင်သည်၊ အလွန်နီးသော မျဉ်းနှစ်ကြောင်းကို ဆက်နိုင်သည်၊ သို့မဟုတ် အမည်းစက်တစ်ခုအတွက် မျဉ်းတစ်ကြောင်း ဆွဲနိုင်သည်။ စကင်ကို အရင် သန့်စင်ပါ (စတုရန်းဖြစ်အောင်၊ အဖြူအမည်း၊ အစက်များ ဖယ်ထားပြီး) ဆိုလျှင် ရလဒ် ပိုကောင်းသည်။

## မဖတ်နိုင်သည်များ

tile များဖြင့် သိမ်းထားသော TIFF ဖိုင်များ၊ BigTIFF၊ JPEG သို့မဟုတ် deflate compression ပါသော TIFF၊ Group 3 fax coding နှင့် အရောင်များကို သီးခြား plane များတွင် ထားသည်များကို မက်ဆေ့ချ်ဖြင့် ငြင်းပယ်သည်; LZW၊ PackBits၊ Group 4 သို့မဟုတ် compression မပါဘဲ strip များအဖြစ် ပြန်သိမ်းပါ။ Interlaced PNG ဖိုင်များကိုလည်း ငြင်းပယ်သည်။ 128 MB သို့မဟုတ် 100 million pixel ကျော်သော ဖိုင်များကို ငြင်းပယ်ပြီး trace window တွင် အများဆုံး 64 million pixel သာ ထည့်နိုင်သည်။
