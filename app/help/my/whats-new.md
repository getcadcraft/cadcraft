ဤသည်မှာ CadCraft 0.9 တွင် 0.8.1 နှင့်နှိုင်းယှဉ်လျှင် ပြောင်းလဲခဲ့သည်များ ဖြစ်သည်။ CadCraft သည် CadCraft Studio 0.9 ၏ 2D နှင့် 3D ပုံဆွဲ app ဖြစ်ပြီး app ရှစ်ခု ပါသည်။ 0.9 သည် plan drafting ကို ပြီးစီးစေပြီး စာသား style များနှင့် အစစ်အမှန် စာသား editor ကို ထည့်ပြီး မျက်နှာပြင်ပေါ် နေရာ ပိုပေးသည်။

## အသစ်

### Plan drafting

- **ဘောင်ခြေအတိုင်း ကိုက်ညီသော hatch များ။** {{cmd:HATCH}} သည် ၎င်းကို ဘောင်သတ်သော အရာနှင့် ချိတ်သည်။ ဘောင်ကို ရွှေ့၊ လှည့်၊ သို့မဟုတ် scale လုပ်လျှင် hatch နှင့် ၎င်း၏ pattern လိုက်သည်; ပုံသဏ္ဌာန် ပြောင်းလျှင် hatch ကို ပြန်တွက်သည်။ {{cmd:HATCHEDIT}} (`HE`) သည် နောက်မှ hatch ကို ပြောင်းပြီး ချိတ်ဆက်မှုကို ဖန်တီး သို့မဟုတ် ပြီးဆုံးစေသည်။ [Hatch နှင့် fill နယ်မြေများ](topic:hatch) ကို ကြည့်ပါ။
- **Hatch pattern ဖိုင်များ။** {{cmd:HATCH}} မေးခွန်း `Pick internal point` တွင် `F` (Pattern file) ကို ရိုက်ပြီး `.pat` ဖိုင်ကို ရွေးပါ။ ပုံမှန်ဖော်မတ်ဖြင့် ရေးထားသော ဖိုင်များကိုသာ စမ်းပြီးဖြစ်သည်။
- **Layer အုပ်စုများ။** {{ui:Layers}} panel ရှိ {{ui:Tools}} တွင်: {{ui:New group}}၊ {{ui:Add ready-made groups}}၊ {{ui:Group by name}}၊ နှင့် {{ui:Find a layer}}; သို့မဟုတ် {{cmd:LAYGROUP}} (`LG`) ကို ရိုက်ပါ။ [Layer များဖြင့် ပုံဆွဲကို စီစဉ်ခြင်း](topic:layers#group-layers) ကို ကြည့်ပါ။
- **အထပ်ပေါင်းများ။** {{cmd:FLOORS}} (`FLR`)၊ သို့မဟုတ် {{ui:View}} အုပ်စု၏ {{ui:More}} menu မှ {{ui:Floors…}}။ sheet ပေါ်ရှိ viewport တစ်ခုသည် Properties ရှိ {{ui:Floor shown}} အောက်တွင် အထပ်တစ်ထပ်ကို ပြနိုင်သည်။ {{cmd:FLOORLAYERS}} သည် အထပ်များကို အခြားသူထံ ပို့မည့်ဖိုင်အတွက် layer များအဖြစ် ပြောင်းသည်။ [ပုံဆွဲတစ်ခုတွင် အထပ်များ စီထားခြင်း](topic:floors) ကို ကြည့်ပါ။
- **2D စမတ်နံရံများ၊ တံခါးများနှင့် ပြတင်းပေါက်များ။** {{cmd:WALL}} (`WA`)၊ {{cmd:DOOR}} (`DR`)၊ {{cmd:WINDOW}} (`WN`) နှင့် {{cmd:DELOPENING}}။ ထောင့်များ၊ T ဆက်ခြင်းများနှင့် ဖြတ်ကျော်မှုများကို သင့်အတွက် တွက်သည်။ နံရံများသည် ၎င်းတို့ ဘယ်လို ဆက်သည်ကို မှတ်တမ်းထားသည်၊ Properties တွင် Disallow join at start / at end၊ Location line နှင့် တည်းဖြတ်နိုင်သော Length ရှိသည်။ [2D နံရံများ၊ တံခါးများနှင့် ပြတင်းပေါက်များ ဆွဲခြင်း](topic:walls-2d) ကို ကြည့်ပါ။
- **Plan နံရံများပေါ်ရှိ wall tools။** {{cmd:WALLRECT}}၊ {{cmd:WALLPOLY}}၊ {{cmd:WALLARC}}၊ {{cmd:WALLTRACE}}၊ {{cmd:WALLDIM}}၊ {{cmd:WALLOFFSET}}၊ {{cmd:WALLSPLIT}}၊ {{cmd:WALLGRID}} နှင့် အခြားအရာများကို ရိုက်ပါ။ ၎င်းတို့တွင် toolbar ခလုတ်များ မရှိသေးပါ။ [2D နံရံများအတွက် ပုံသဏ္ဌာန်များ၊ ဖြတ်ခြင်းများ၊ offset များနှင့် lock များ](topic:wall-tools-2d) ကို ကြည့်ပါ။

### စာသား

- **စာသား style များ။** {{cmd:STYLE}} (`ST`)၊ သို့မဟုတ် {{ui:Draw}} toolbar ရှိ {{ui:Text style}}: font၊ အမြင့်၊ အကျယ်အချိုး နှင့် စောင်းမှုပါသော အမည်ပေးထားသော style များ။ [Text style များဖြင့် စာသား၏ font နှင့် အရွယ်အစား သတ်မှတ်ခြင်း](topic:text-styles) ကို ကြည့်ပါ။
- **ဖော်မတ်ပါသော paragraph စာသား editor။** {{cmd:MTEXT}}၊ {{cmd:TEXTEDIT}} သို့မဟုတ် စာသားပေါ်တွင် နှစ်ချက်နှိပ်ခြင်းဖြင့် font၊ အရွယ်၊ bold၊ italic၊ underline၊ strike-through၊ အရောင်၊ ညှိနှိုင်းမှု နှင့် ဒီဂရီ၊ plus-minus နှင့် diameter သင်္ကေတများပါသော အကွက်ကို ဖွင့်ပြီး {{ui:OK}} နှင့် {{ui:Cancel}} ရှိသည်။ [Paragraph စာသားကို ဖော်မတ်ခြင်း](topic:format-paragraph-text) ကို ကြည့်ပါ။
- **draw.io XML မှ diagram။** {{cmd:DIAGRAM}} (`T2D`) သည် ကူးထည့်ထားသော draw.io XML ကိုလည်း ဖတ်သည်။ [စာသားမှ diagram ဆွဲခြင်း](topic:text-to-diagram) ကို ကြည့်ပါ။
- **PDF plot ရှိ ထိုင်းစာသား။** ယခင် မေးခွန်းပုံများအဖြစ် ပရင့်ထွက်ခဲ့သည်။

### နေရာပိုမို နှင့် ပုံဆွဲကူညီမှုများ

- **မျောနေသော၊ ပါးလွှာသော command line နှင့် ကျစ်သော အပေါ်ဧရိယာ။** command line ၏ grip ကို ဆွဲ၍ မျောစေပါ၊ ထိပ်ဘောင်ကို ဆွဲ၍ လိုင်းနည်းနည်းထားပါ၊ {{key:F2}} သည် history ကို ဖွင့်သည်။ {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Command line}} နှင့် အပေါ်ဧရိယာ ရွေးချယ်မှုများတွင် တူညီသော ဆက်တင်များ ရှိသည်။ [ဆက်တင်များ](topic:settings#command-line) ကို ကြည့်ပါ။
- **Object snap menu။** status bar ရှိ {{ui:Snap}} ကို right-click လုပ်ပါ၊ သို့မဟုတ် {{cmd:OSNAP}} ကို ရိုက်ပါ။
- **Grid သို့ snap။** status bar ရှိ {{ui:Grid snap}} ခလုတ်၊ သို့မဟုတ် {{key:F9}}: object snap က point ကို မယူသောအခါ ရွေးထားသော point များသည် အနီးဆုံး grid point သို့ သွားသည်။
- **Arc ၁၀ နည်းနှင့် Continue။** {{ui:Draw}} toolbar ရှိ {{ui:Arc}} သို့မဟုတ် {{cmd:ARC}}: 3-point၊ Start/Center/End မိသားစု နှင့် Center/Start/End မိသားစု၊ နှင့် Continue (စတင်မှတ်တွင် {{key:Enter}} ကို နှိပ်ပါ) ကို နောက်ဆုံး မျဉ်း၊ arc သို့မဟုတ် polyline မှ။
- **Documents panel။** {{cmd:DOCUMENTS}} (`DOCS`) သို့မဟုတ် {{ui:View}} အုပ်စု၏ {{ui:More}} menu မှ {{ui:Documents…}}: project ဖိုဒါရှိ ပုံဆွဲတိုင်း၏ revision၊ state နှင့် check-out။ အလယ်တွင် ဗဟိုထားသော dialog အဖြစ် ဖွင့်သည်။ [Documents](topic:documents) ကို ကြည့်ပါ။

### ဖိုင်များ

- **UK steel အရွယ်အစားများ။** Standard panel တွင် အပိုင်း ၉၇၆ ခု၊ ပုံဆွဲတွင် ရေးသလို ရိုက်ထည့်နိုင်သည် (ဥပမာ `305x165x40 UB`)။
- **တောင်အာဖရိကပက်ကေ့ချ်များ** (ပုံဆွဲလေ့ကျင့်မှုနှင့် အဆောက်အအုံ စည်းကမ်းများ) ကို Building regulations add-on ၏ pack များအဖြစ်။ ကိန်းဂဏန်းများကို အတည်မပြုရသေးပါ။
- **CadCraft အတွက် add-on များ**၊ လိုအပ်သောအခါ ထည့်ပြီး ပုံမှန်ပိတ်ထားသည်: အတွင်းပိုင်း မီးရောင်ဒီဇိုင်း၊ chip ဒီဇိုင်း (HDL မှ layout)၊ router carving၊ circuit simulation၊ roller chain sprocket များ နှင့် Building regulations နိုင်ငံ pack များ။

## ပြင်ဆင်ထားသည်

- hatch ကို ရွှေ့၊ လှည့်၊ သို့မဟုတ် scale လုပ်ခြင်းသည် ၎င်း၏ pattern ကို နောက်တွင် ထားခဲ့သည်။
- {{cmd:GRIDMOVE}} သည် grid line တွင်သာ စတင်သော နံရံတစ်ခုလုံးကို သယ်ဆောင်ခဲ့သည်။ ယခု နံရံကို ၎င်း၏ အဆုံးများဖြင့် ဆုံးဖြတ်သည်။
- ကန့်သတ်ချက် ပိတ်ထားသော်လည်း grid သည် ပုံဆွဲကန့်သတ်ချက်အတွင်းတွင်သာ ပြခဲ့သည်။
- ဘေးဘက် panel ရှိ block စာရင်းသည် scroll လုပ်ပြီး၊ block မဟုတ်သော အမည်တစ်ခုသည် ထိုအက္ခရာဖြင့် စတင်သော block များကို စာရင်းပြသည် ("Did you mean")။
- AutoCAD က "Unknown group 1001 for table" ဖြင့် ငြင်းသော DXF R12 ဖိုင်များ ယခု ထိုနေရာတွင် ဖွင့်နိုင်သည်။
- အရွယ်အလွန်ကြီးသော ဖိုင်များ (ခန့်မှန်း entity ၇၀,၀၀၀ နှင့် အထက်) သည် "Maximum call stack size exceeded" ဖြင့် ဖွင့်မရခဲ့ပါ။
- AutoCAD 2018 နှင့် နောက်ပိုင်း maintenance version မြင့်သော DWG ဖိုင်များသည် "bad BITLONG code 11" ဖြင့် ဖွင့်မရခဲ့ပါ။
- paragraph စာသား အကွက်တွင် ရွေးထားသော အစိတ်အပိုင်းအတွက် အရွယ်အသစ်ရိုက်လျှင် ရွေးချယ်မှု ကျန်ခဲ့သည်။

## app တိုင်းတွင်

tooltip များကို hint ပါသော ထိန်းချုပ်မှုတိုင်းတွင် Bootstrap ဖြင့် ပြသည်၊ ပိတ်နိုင်သော စတင်အကြံပြုချက်၊ မကိုက်ညီသောအခါ scroll လုပ်သော tab strip များ၊ နှင့် browser tab ခေါင်းစဉ်က ဖွင့်ထားသော ပုံဆွဲကို လိုက်သည် (`<drawing> - CadCraft | CadCraft`)။ {{ui:Settings}} › {{ui:Layout}} သည်ယခု နှစ်တန်းပါ ရွေးချယ်မှု drop-down ဖြစ်သည်။ {{ui:Settings}} ရှိ ဘာသာစကားစာရင်းသည် 0.8 ထက် ရှည်သည်။ Live ပူးတွဲတည်းဖြတ်ခြင်း၊ Library စုစည်းမှုများနှင့် အလေးချိန်နှင့် အပူချိန် ယူနစ်များကို Studio မှတ်စုများတွင် ဖော်ပြထားသည်။

## ရိုးရှင်းသော ကန့်သတ်ချက်များ

- ပိုဒ်စာသားတွင် bullet သို့မဟုတ် နံပါတ်စာရင်း၊ tab ruler သို့မဟုတ် justify မရှိပါ။ plot လုပ်ထားသော PDF များသည် စာသားကို Helvetica ဖြင့် သတ်မှတ်သည်။
- Plan နံရံများသည် မျဉ်းဖြောင့် ဖြစ်သဖြင့် arc ကို တိုတောင်းသော နံရံများအဖြစ် ဆွဲသည်။ wall tool ၏ အသိုင်းအဝိုင်း လက်ဖြင့် စစ်ဆေးမှု ဆိုင်းငံ့ထားသည်။
- Layer အုပ်စုများကို AutoCAD ၏ ကိုယ်ပိုင်ဖော်မတ်ဖြင့် မရေးပါ၊ ထို့ကြောင့် AutoCAD က ပြားသော စာရင်းအဖြစ် ပြသည်။ အခြား program များက {{cmd:FLOORLAYERS}} ကို မဖွင့်ပါက အထပ်အားလုံး အတူတကွ ပြသည်။
- Documents panel ကို လူနှစ်ဦးက အစစ်အမှန် share တွင် မစမ်းရသေးပါ။ Router carving ကို စက်အစစ်အမှန်တွင် မစမ်းရသေးပါ။ မီးရောင် ခန့်မှန်းချက်ကို photon trace နှင့် စစ်ဆေးထားပြီး အခြား program နှင့် မဟုတ်ပါ။ အင်ဂျင်နီယာ add-on များသည် စစ်ဆေးမှု ကိရိယာများဖြစ်ပြီး အင်ဂျင်နီယာ၏ သုံးသပ်ချက်ကို အစားထိုးခြင်း မဟုတ်ပါ။
- အင်္ဂလိပ်မဟုတ်သော ဘာသာစကားများသည် စက်ဖြင့် ရေးထားသော မူကြမ်းများ ဖြစ်ပြီး အသစ်စကားလုံး အချို့သည် အင်္ဂလိပ်သာ ဖြစ်သည်။

## 0.8 နှင့် 0.8.1 ယခင်

ဤသည်မှာ CadCraft 0.8 နှင့် 0.8.1 တွင် 0.7 နှင့်နှိုင်းယှဉ်လျှင် ပြောင်းလဲခဲ့သည်များ ဖြစ်သည်။ 0.8 (2026 နိုဝင်ဘာ 1) သည် သင့်ပုံဆွဲမှ အလုပ်လုပ်သော၊ သင့်ကွန်ပျူတာပေါ်ရှိ စည်းမျဉ်းများဖြင့် ပုံစံမရှိဘဲ ပုံဆွဲကူညီသူများကို ထည့်သည်၊ 0.8.1 (2026 နိုဝင်ဘာ 2) သည် ထို့နောက် အစီရင်ခံသော ချို့ယွင်းချက်များကို ပြင်သည်။

### အသစ်

**သင်၏ အတွေးကို ပြီးဆုံးပေးသော ပုံဆွဲ**

- **Ghost သည် နောက်လာမည့်အရာကို ပြသည်။** command မလုပ်နေချိန်တွင် မီးခိုးရောင် အစင်းကြောင်းပါသော ghost က သင့်ပုံဆွဲ၏ ကိုယ်ပိုင် pattern များက နောက်လာမည်ဟု ပြောသည့်အရာကို ပြသည်: အရှိန်တူ နောက်တစ်ခု တိုင်၊ လှေကားနောက်တစ်ဆင့်၊ အခန်းပျောက်နေသော နံရံ။ **Tab** ကို နှိပ်ပါက တစ်ဆင့်တည်းဖြင့် ဆွဲမည်၊ **Esc** ဖြင့် ဖယ်ရှားသည်။ အသစ်ဆုံး object များကိုသာ ကြည့်သဖြင့် ပုံဆွဲကြီးတွင်ပင် ချောမွေ့သည်။ {{ui:Settings}} › {{ui:CadCraft}} တွင် သို့မဟုတ် {{cmd:AUTOCOMPLETE}} `Off` ဖြင့် ပိတ်နိုင်သည်။
- **မျဉ်းဆွဲစဉ် နောက် point။** {{cmd:LINE}} သို့မဟုတ် {{cmd:PLINE}} အလယ်တွင် ghost သည် နောက် point ဖြစ်သည်: လှေကား၏ နောက်တစ်ဆင့်၊ စတုဂံ၏ စတုတ္ထထောင့်၊ သို့မဟုတ် ၎င်းကို ပိတ်သော point။ cursor ကို အနီးသို့ ယူပြီး {{key:Tab}} ကို နှိပ်ပါ၊ ထိုနေရာကို နှိပ်ထားသကဲ့သို့။
- **ကလောင်ပုံဆွဲများ တိကျသော ဂျီဩမေတြီ ဖြစ်လာသည်။** {{cmd:SKETCHFIX}}: ကလောင်၊ မောက်စ် သို့မဟုတ် လက်ဖြင့် ကြမ်းကြမ်း အစင်းများ ဆွဲပါ၊ တစ်ခုစီသည် သန့်ရှင်းသော မျဉ်း၊ စက်ဝိုင်း၊ arc၊ စတုဂံ သို့မဟုတ် polyline ဖြစ်လာပြီး ရှိပြီးသား ဆွဲထားသည်များနှင့် snap လုပ်သည်။ [ကလောင်ဖြင့် ပုံဆွဲပြီး တိကျသော ဂျီဩမေတြီ ရယူခြင်း](topic:sketch-with-a-pen) ကို ကြည့်ပါ။
- **ပုံဆွဲ၏ ဓာတ်ပုံသည် ပုံဆွဲဖြစ်လာသည်။** {{cmd:PHOTOSKETCH}} (`PSK`) သည် ဓာတ်ပုံထဲရှိ စက္ကူကို ရှာ၊ perspective ကို ဖြောင့်စေ၊ သင်ပေးသော စက္ကူအရွယ်နှင့် scale ကို သတ်မှတ်ပြီး ကလောင်အစင်းများကို ကလောင်အရောင်တစ်ခုစီအတွက် layer တစ်ခုပေါ်သို့ trace လုပ်သည်။ စာလုံးများကို trace မလုပ်ပါ။
- **စည်းမျဉ်းဖြင့် dimension ပေးသည်။** {{cmd:AUTODIM}} (`ADIM`) သည် သင်ရွေးသော ဘက်များတလျှောက် dimension ကွင်းဆက်များ၊ အပြင်ဘက် အရွယ်အစား၊ ပွင့်ရာအကျယ်၊ အပေါက် အချင်း နှင့် `Grid` ဖြင့် grid အကွာအဝေးတို့ကို ဖန်တီးသည်။ ရှိပြီးသား dimension ကို ထပ်မလုပ်ပါ။
- **Grid line ကို ရွှေ့လျှင် အစုံ လိုက်သည်။** {{cmd:GRIDMOVE}} (`GM`): grid line တွင် ဆုံးသော နံရံများ ၎င်းနှင့်အတူ ဆန့်သည်၊ grid line တလျှောက် နံရံများ၊ ကော်လံများ၊ ၎င်း၏ bubble နှင့် tag များ ရွှေ့သည်၊ ထိုတွင် dimension များသည် အကွာအဝေးအသစ်ကို တိုင်းသည်။ ပြန်ဖျက်ရန် အဆင့် တစ်ခု။

**Sheet များ၊ အသေးစိတ်များနှင့် tag များ**

- **Sheet များ ကိုယ်တိုင် စီသည်။** {{cmd:AUTOSHEET}} သည် သင့်အမည်ပေးထားသော view များ (သို့မဟုတ် model ၏ သီးခြား အပိုင်းများ) ကို ယူ၊ စက္ကူအရွယ်နှင့် စံ scale ရွေး၊ view များကို title block နှင့် အမည်-နှင့်-scale caption ပါသော sheet အသစ်များပေါ်သို့ ထားသည်။ အရာအားလုံး တည်းဖြတ်နိုင်သည်။ [Sheet များကို ကျွန်ုပ်အတွက် စီပါ](topic:lay-out-sheets-for-me) ကို ကြည့်ပါ။
- **သင့်ကုမ္ပဏီ၏ အသေးစိတ်များ၊ ရေးဆွဲစဉ် ကမ်းလှမ်းသည်။** {{cmd:DETAILS}} (`DET`) သည် သင့်ကိုယ်ပိုင် အသေးစိတ် block များကို သိမ်းသည်။ သင်ရွေးထားသည်က layer များ၊ block အမည်များနှင့် မှတ်စုများပေါ်ရှိ စကားလုံးများဖြင့် ကိုက်ညီလျှင် status bar က ပြောသည်; ရွေးပြီး ထည့်ပါ။ {{cmd:DETAILS}} › Share သည် သင့်စာရင်းကို Documents ဖိုဒါတွင် ထားပြီး သင့်အဖွဲ့ ထည့်ထားသည်များကို ယူသည်။ Settings က ကမ်းလှမ်းချက်များကို ပိတ်သည်။
- **Block များပေါ်ရှိ tag များ။** {{cmd:TAGS}} သည် tag တစ်ခု (အမျိုးအစား၊ ယူနိုင်သော တန်ဖိုးများ၊ သက်ဆိုင်သော block များ) ကို သတ်မှတ်သည်၊ သင်ရွေးသော block reference များတွင် သတ်မှတ်ပြီး CSV အဖြစ် သိမ်းနိုင်သော schedule အဖြစ် ဖော်ပြသည်။ သတ်မှတ်ချက်များကို DWG တွင် ထိန်းသည်။ [Tag များ](topic:tags) ကို ကြည့်ပါ။
- **ပုံဆွဲကန့်သတ်ချက်များ။** {{cmd:LIMITS}} သည် ပုံဆွဲအတွက် ညာထောင့်စတုဂံ သတ်မှတ်သည်: grid က ဖြည့်ပြီး zoom All က ပြသည်။ ကန့်သတ်ချက်များသည် outline အဖြစ် ပြပြီး DWG နှင့် DXF တွင် paper ကန့်သတ်ချက်များနှင့်အတူ သိမ်းသည်။ [ပုံဆွဲကန့်သတ်ချက်များ သတ်မှတ်ခြင်း](topic:drawing-limits) ကို ကြည့်ပါ။

**အခြားသူများနှင့်နှင့် အခြား program များနှင့် အလုပ်လုပ်ခြင်း**

- **Markup ကို ပြန်လည်ပြင်ဆင်ချက် အဖြစ်ပြောင်းပါ။** {{cmd:REDLINE}} သည် MarkupCraft ရေးသော package ကို ဖတ်ပြီး ပြောင်းလဲမှု တိုင်းကို စာရင်းပြုသည်။ တစ်ခုစီကို မှတ်ချက်ဖြင့် လက်ခံ သို့မဟုတ် ငြင်း; လက်ခံထားသည်များသည် revision cloud နှင့် revision log ကို ပြန်ဖျက်ရန် အဆင့် တစ်ခုတည်းဖြင့် ရရှိသည်၊ MarkupCraft တွင် markup များကို ပိတ်သော အဖြေဖိုင်ကို သိမ်းသည်။ [Markup ကို ပြင်ဆင်ချက် အဖြစ်ပြောင်းခြင်း](topic:redline-to-revision) ကို ကြည့်ပါ။
- **git နှင့် Fossil က ပေါင်းနိုင်သော ပုံဆွဲများ။** {{ui:Settings}} › {{ui:CadCraft}} တွင် {{ui:Merge-friendly files}} ဖွင့်ထားလျှင် object တိုင်းသည် ဘယ်တော့မှ မပြောင်းသော key ရရှိသည် (ဖိုင်များ ၁၀ ရာခိုင်နှုန်းခန့် ကြီးသည်)။ `cadcraft merge base ours theirs` သည် လူနှစ်ယောက်၏ DWG သို့မဟုတ် DXF object တစ်ခု၏ တည်းဖြတ်မှုများကို object အလိုက် ပေါင်းပြီး တူညီသော အရာကို ပြောင်းလဲထားသော နေရာကိုသာ အစီရင်ခံသည်။ [ပုံဆွဲတစ်ခု၏ လူနှစ်ယောက် တည်းဖြတ်မှုများကို ပေါင်းခြင်း](topic:merge-drawings) ကို ကြည့်ပါ။
- **ဘာပြောင်းသလဲ၊ စကားဖြင့်။** History တွင် Compare သည် ရိုးရှင်းသော စာရင်း ပေးသည်: အရာများ ပြောင်းသောနေရာ၊ နေရာများ ဘယ်လောက်ကြီးသလဲ၊ ထည့်ထား၊ ဖျက်ထားနှင့် ပြောင်းထားသည်များ၊ နှင့် တည်းဖြတ်ထားသော စာသား။ [စကားဖြင့် ပြောင်းလဲမှုကို ပြောခြင်း](topic:changes-in-words) ကို ကြည့်ပါ။
- **Bearing နှင့် angle။** အတိုင်းအတာ ဆိုသည်မှာ N45°23'30"E ကဲ့သို့ စာရင်းကိုင် bearing အဖြစ်၊ သို့မဟုတ် ဒီဂရီ၊ မိနစ်နှင့် စက္ကန့်ဖြင့် ရိုက်နိုင်သည်၊ angle တောင်းသည့်နေရာတိုင်း; AUNITS သည် angle များကို ပြသပုံကို သတ်မှတ်သည်။ [Bearing နှင့် angle များကို ရိုက်ထည့်ပြီး ပြခြင်း](topic:bearings-and-angles) ကို ကြည့်ပါ။
- **သင်၏ကိုယ်ပိုင် SHX font များ။** CadCraft ကို SHX font ဖိုဒါတစ်ခု ပေးပါ၊ ၎င်းတို့ကို အမည်ပေးသော စာသား style များကို မျက်နှာပြင်နှင့် plot များတွင် ထို font ဖြင့် ဆွဲသည်။ [သင်၏ကိုယ်ပိုင် SHX font များဖြင့် စာသား ဆွဲခြင်း](topic:shx-fonts) ကို ကြည့်ပါ။
- **စာသားမှ diagram။** {{cmd:DIAGRAM}} သည် Mermaid flowchart၊ PlantUML component diagram၊ D2 သို့မဟုတ် from-to စာရင်းကို ဖတ်ပြီး တည်းဖြတ်နိုင်သော block များနှင့် connector များ ဆွဲသည်။ [စာသားမှ diagram ဆွဲခြင်း](topic:text-to-diagram) ကို ကြည့်ပါ။
- **DWG ရှိ OLE object များ။** {{cmd:OLELIST}} သည် DWG တွင်ပါပြီး CadCraft က ကိုယ်တိုင် မနေရာချနိုင်သော OLE object များကို စာရင်းပြုပြီး ပုံ၏ မိတ္တူကို သင်ပြောသော နေရာတွင် ထားသည်။ [ပုံများ](topic:pictures#objects-from-other-programs-ole) ကို ကြည့်ပါ။
- **သင်၏ တွက်ချက်မှုများ ပုံဆွဲနှင့်အတူ ရှိနေသည်။** တွက်ချက်ပြားများနှင့် ဒီဇိုင်းအကြောင်းရင်းများကို class table နှင့်အတူ DWG တွင် သိမ်းသည်။

**ပုံဆွဲမမြင်ဘဲ ဆွဲခြင်း**

- {{ui:Settings}} တွင် {{ui:Drafting without sight}} ကို ဖွင့်ပါ (သို့မဟုတ် {{cmd:ACCESS}} ရိုက်ပြီး `On` ဟု ဖြေပါ)။ CadCraft သည် command နှင့် ရလဒ်အားလုံးကို သင်၏ screen reader မှတစ်ဆင့် ပြောပြသည်၊ ပုံဆွဲနှင့် cursor အနီးရှိ အရာများကို ဖော်ပြသည်၊ cursor ကို ရွှေ့ခြင်းနှင့် keyboard ဖြင့် point ရွေးခြင်းကို ခွင့်ပြုသည်၊ snap နှင့် grip တိုင်းအတွက် အသံဖွင့်သည်။ သင့်ဘရောက်ဆာက ကွန်ပျူတာပေါ်တွင် အသံအသိအမှတ်ပြုနိုင်သည့်နေရာ၌ command များကို ပြောနိုင်သည်။ [ပုံဆွဲမမြင်ဘဲ ဆွဲခြင်း](topic:draft-without-sight) ကို ကြည့်ပါ။

**app တိုင်းတွင်**

- **ဘာသာစကားများ။** ၅၄ ခု; ၁၀ ခုသည် အသစ် ဖြစ်သည် (လစ်သူအေးနီးယား၊ လတ်ဗီးယား၊ ဘော့စနီး၊ မာရသီ၊ တဲလူဂူ၊ အယ်လ်ဘေးနီးယား၊ အာဖရိကန်၊ ဖိလစ်ပိုင်၊ ဆွာဟီလီ၊ ဥဇဘက်)။ အင်္ဂလိပ်မှ အခြား ဘာသာစကားများသည် မိခင်ဘာသာစကား ဖတ်ပြီးမချင်း စက်မူကြမ်းများ ဖြစ်သည်။
- **Input device များ။** Trackpad၊ ကလောင်၊ 3D mouse၊ game controller နှင့် MIDI control များ။
- **Toolbar အတန်းများနှင့် property grid။** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} သည် အခြား app များတွင် Wrap၊ 2 rows သို့မဟုတ် 1 row ကို ပေးသည်။ CadCraft သည် ကိုယ်ပိုင် ဆက်တင်ကို {{ui:Settings}} › {{ui:CadCraft}} တွင် ထိန်းသည် (ကြည့်ပါ [Toolbar အတန်းများ](topic:settings#toolbar-rows))။ မျှဝေသော property grid သည် အခြား app သုံးခုတွင် ရှိပြီး CadCraft တွင် မရှိပါ။
- **Problems၊ Live နှင့် add-on များ။** app အားလုံးတွင် သတိပေးသော မျှဝေသော Problems panel၊ CadCraft Studio တွင် ဘယ်သူ ဘယ်မှာရှိသည်ကို ပြသော Live view (ကြည့်ပါ [ပုံဆွဲတစ်ခုကို အတူတကွ လုပ်ခြင်း](topic:work-live))၊ နှင့် add-on စာရင်း။
- **သင့် AI ကို ချိတ်ဆက်ပါ။** CadCraft Studio မှ app ရှစ်ခုအားလုံးသို့ ချိတ်ဆက်မှု တစ်ခု၊ app တစ်ခုစီအတွက် read-only၊ suggest သို့မဟုတ် edit အဆင့်နှင့် အကူအညီပေးသူ ပြုလုပ်ခဲ့သည်များ၏ ရိုးရှင်းသော စကားဖြင့် မှတ်တမ်း။ CadCraft တွင် ကိုယ်ပိုင် AI မရှိပါ၊ app တိုင်းတွင် မေးခြင်းသည် သင်ချိတ်ဆက်သော AI ကို သုံးသည်။

### ဤဗားရှင်းတွင် မပါသေးသည်များ

- **0.8 နှင့် 0.8.1 ကို code-sign မလုပ်ရသေးပါ။** Windows က သတိပေးနိုင်သည် ({{ui:More info}} ကို ရွေးပြီး {{ui:Run anyway}}); Mac တွင် CadCraft Studio ကို right-click လုပ်ပြီး {{ui:Open}} ကို ရွေးပါ။ Store build များကို ရပ်ထားသည်၊ iPad နှင့် iPhone build ကို 0.8.1 အတွက် ပြန်မတည်ဆောက်ရသေးပါ။
- **ကလောင် ပုံဆွဲများနှင့် ပုံဆွဲဓာတ်ပုံများ** ကို အတု ဓာတ်ပုံများနှင့် မောက်စ်ဖြင့်သာ စမ်းပြီးဖြစ်သည်၊ အစစ်အမှန် ကလောင်၊ touch screen သို့မဟုတ် စက္ကူပေါ် လက်ဖြင့် ပုံဆွဲဖြင့် မစမ်းရသေးပါ။
- **ပုံဆွဲမမြင်ဘဲ ဆွဲခြင်း** ကို အလိုအလျောက် စစ်ဆေးမှုများဖြင့်သာ စမ်းပြီးဖြစ်သည်၊ screen reader သို့မဟုတ် မျက်မမြင် စမ်းသပ်သူဖြင့် မစမ်းရသေးပါ။
- **ပုံဆွဲများ မျှဝေခြင်း** တွင် လူနှစ်ဦး စစ်ဆေးမှု မရှိသေးပါ၊ Documents ဖိုဒါအဖြစ် Team Cloud Plan ဖိုဒါကို မတည်ဆောက်ရသေးပါ။
- **ပေါင်းခြင်း** သည် CadCraft ၏ DWG နှင့် DXF ဖိုင်များအတွက် အလုပ်လုပ်သည်; အခြား app များ၏ ဖိုင်များအတွက် မတည်ဆောက်ရသေးပါ။
- **Window များကြား Undo:** CadCraft သည် ပြီးသွားသော အဆင့်တိုင်းကို အစီရင်ခံသော်လည်း Studio တွင် app အားလုံးအတွက် Undo တစ်ခုတည်း မရှိသေးပါ; app တစ်ခုစီက ကိုယ်ပိုင်အဆင့်များကို ပြန်ဖျက်သည်။

- **AI ကို ချိတ်ဆက်ပါ:** Studio တွင် တစ်ချက်နှိပ် ချိတ်ဆက်ခြင်း၊ browser AI အတွက် hosted connector၊ Studio အတွင်း သင်၏ကိုယ်ပိုင် API key နှင့် ထုတ်ဝေထားသော MCP package တို့ကို ဤထုတ်ပြန်မှုတွင် ကတိမပေးပါ။
