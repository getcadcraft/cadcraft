## သင် သိရမည့်အရာ

{{cmd:TRIM}} နှင့် {{cmd:EXTEND}} မည်ကဲ့သို့ အလုပ်လုပ်သည်၊ အမြန်နည်းလမ်းများ: အများအပြားကို လမ်းကြောင်းဖြင့် တစ်ကြိမ်တည်း ဆွဲဖြတ်ခြင်း၊ {{key:Shift}} ကိုင်ထားပြီး ဖြတ်ခြင်းနှင့် တိုးခြင်းကြား ပြောင်းခြင်း၊ နှိပ်မီ ဘာပျောက်မည်ကို မြင်ခြင်း။

## အပိုင်းတစ်ခု ဖြတ်ခြင်း

1. အလျားလိုက် မျဉ်းရှည်တစ်ကြောင်းနှင့် ၎င်းကို ဖြတ်သော တိုသော မျဉ်းနှစ်ကြောင်း ဆွဲပါ။
2. `TR` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။ History က `Current settings: Quick mode, edges: No extend` ဟု ပြောသည်။
3. တိုသော မျဉ်းနှစ်ကြောင်းကြားရှိ မျဉ်းရှည်ပေါ်တွင် pointer ကို ထားပါ။ ထိုအပိုင်း မီးခိုးရောင်နှင့် dashed ဖြစ်သည်: ၎င်းသည် ပျောက်မည့်အရာ ဖြစ်သည်။
4. နှိပ်ပါ။ အပိုင်းပျောက်သွားမည်။
5. Command ကို အဆုံးသတ်ရန် {{key:Enter}} ကို နှိပ်ပါ။

Quick mode (မူရင်း) တွင် မြင်ရသော object တိုင်းသည် ဖြတ်မည့် အစွန်း ဖြစ်သဖြင့် အရင် အစွန်းများ ရွေးစရာ မလိုပါ။ ပျောက်စေလိုသော အပိုင်းကို နှိပ်ပါ။ ဘာနှင့်မှ မဖြတ်သော object ကို တစ်ခုလုံး ဖျက်ပြီး history က ထိုအကြောင်း ပြောသည်။

## အပိုင်းများစွာကို ဆွဲ၍ တစ်ကြိမ်တည်း ဖြတ်ခြင်း

1. အလျားလိုက် မျဉ်းရှည်တစ်ကြောင်းနှင့် အတိုဒေါင်လိုက် မျဉ်းဆယ်ကြောင်း ဆွဲပါ။
2. `TR` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
3. ပထမ ဒေါင်လိုက်မျဉ်း၏ ဘယ်ဘက်၊ မျဉ်းရှည်အပေါ်ရှိ နေရာတွင် mouse ခလုတ်ကို ဖိပြီး ဒေါင်လိုက်မျဉ်း ဆယ်ကြောင်းအားလုံးကို ဖြတ်၍ မျဉ်းရှည်အပေါ်တွင် ဆွဲပါ။

ဆွဲနေစဉ် လမ်းကြောင်းကို dashed မျဉ်းအဖြစ် ပြပြီး ဖြတ်ခဲ့သော အပိုင်းတိုင်း မီးခိုးရောင် ဖြစ်သည်။ လွှတ်လိုက်လျှင် အပေါ်ပိုင်း ဆယ်ခုလုံး တစ်ဆင့်တည်း ဖြတ်သည်။ `U` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်လျှင် အားလုံး တစ်ကြိမ်တည်း ပြန်ရမည်။

:::tip
ဆွဲခြင်းအစား အလွတ်နေရာ နှစ်နေရာကို နှိပ်နိုင်သည်: ၎င်းတို့ကြားရှိ မျဉ်းသည် ဆွဲထားသော လမ်းကြောင်းကဲ့သို့ အလုပ်လုပ်သည်။ အမှတ်များကို အစဉ်လိုက် နှိပ်ရန် `F` (Fence) ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
:::

:::touch
လက်ချောင်းဖြင့် အလားတူ ဆွဲပါ။ အပိုင်းတစ်ခုကို တို့လျှင် ထိုအပိုင်း ဖြတ်သည်။
:::

## Shift ဖြင့် တိုးခြင်း

1. ဒေါင်လိုက်မျဉ်းတစ်ကြောင်းနှင့် ၎င်း၏ ဘယ်ဘက်တွင် ရပ်နေသော အတိုအလျားလိုက် မျဉ်း ငါးကြောင်း ဆွဲပါ။
2. `TR` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
3. {{key:Shift}} ကို ကိုင်ထားပါ။ တိုသော မျဉ်းတစ်ကြောင်းပေါ်တွင် pointer ကို ထားပါ: ၎င်း ရှည်လာမည့် အပိုင်းသည် မီးခိုးရောင်နှင့် dashed ဖြစ်သည်။
4. {{key:Shift}} ကို ဆက်ကိုင်ထားပြီး တိုသော မျဉ်း ငါးကြောင်းကို ဖြတ်၍ အောက်သို့ ဆွဲပါ။

ငါးကြောင်းလုံး ဒေါင်လိုက်မျဉ်းသို့ ရောက်သွားသည်။ {{key:Shift}} သည် {{cmd:EXTEND}} (`EX`) တွင် ပြောင်းပြန် အလုပ်လုပ်သည်: နှိပ်ခြင်းက တိုးပြီး {{key:Shift}}+နှိပ်ခြင်းက ဖြတ်သည်။ Extend က သင်နှိပ်သော သို့မဟုတ် လမ်းကြောင်း ဖြတ်သော နေရာနှင့် အနီးဆုံး အဆုံးကို ရှည်စေသည်။

## ဝင်းဒိုးအတွင်း ဖြတ်ခြင်း

1. `TR` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
2. `C` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
3. ဖယ်ရမည့် အပိုင်းများ ပတ်လည် ထောင့်နှစ်ခု နှိပ်ပါ။

အနည်းဆုံး တစ်စိတ်တစ်ပိုင်း ဝင်းဒိုးထဲရှိ အပိုင်းတိုင်း ဖြတ်သည်။

`C` မရိုက်ဘဲ ဆွဲ၍သာ ဝင်းဒိုး ရယူရန်: {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Dragging to trim and extend}} › {{ui:A window}}။ ထို့နောက် အလွတ်နေရာကို ဖိထား၍ ဆွဲလျှင် ဘောက်စ် ဆွဲမည်၊ ထိသော အပိုင်းတိုင်း ဖြတ်မည် (သို့မဟုတ် {{cmd:EXTEND}} တွင် တိုး၊ သို့မဟုတ် {{key:Shift}} ဖြင့်)။ {{ui:A path}} (မူရင်း) က လွတ်လပ်စွာ ဆွဲသော လမ်းကြောင်းကို ပြန်ပေးသည်။ TRIM ၏ အစတွင် settings စာကြောင်းက မည်သည်ကို ဖွင့်ထားသည်ဆိုသည်ကို ပြသည်။

## ဖြတ်မည့် အစွန်းများ ရွေးခြင်း (Standard မုဒ်)

တစ်ခုသာ ဖြတ်သင့်သော အခါ ရှိသည်၊ ဥပမာ အခြားမျဉ်းများ အများအပြား ဖြတ်ကျော်နေသော နံရံမျက်နှာ။

1. `TR` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
2. `O` (mOde) ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ၊ ထို့နောက် `S` (Standard) ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
3. `Select cutting edges` တွင် အစွန်းမျဉ်းများကို နှိပ်ပါ (သို့မဟုတ် ဝင်းဒိုး ဆွဲပါ)၊ ထို့နောက် {{key:Enter}} ကို နှိပ်ပါ။ ဘာမျှ မရွေးထားစဉ် {{key:Enter}} ကို နှိပ်လျှင် object တိုင်း အစွန်း ဖြစ်သည်။
4. ဖယ်ရမည့် အပိုင်းများကို နှိပ်ပါ သို့မဟုတ် ဆွဲပါ။

ရွေးထားသော အစွန်းများသာ ဖြတ်ပြီး အစွန်းနှင့် မတွေ့သော object ကို မထိပါ။ မုဒ်သည် စာမျက်နှာ ပိတ်သည်အထိ ကျန်နေသည်; `O` ကို ရိုက်ပြီး `Q` ဖြင့် Quick သို့ ပြန်သွားပါ။ {{cmd:TRIMEXTENDMODE}} သည် စတင်မီ မုဒ်ကို သတ်မှတ်သည်၊ အခြားနေရာတွင် ထိုအမည်ရှိ variable ကဲ့သို့: `0` Standard၊ `1` Quick။ `T` (cuTting edges) က မည်သည့်အချိန်မဆို အစွန်းအသစ် ရွေးသည်; {{cmd:EXTEND}} တွင် ၎င်းသည် `B` (Boundary edges) ဖြစ်သည်။

## တွေ့မည့် အစွန်းများ

1. `TR` ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။
2. `E` (Edge) ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ၊ ထို့နောက် `E` (Extend) ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ။

ယခု ရပ်နေသော ဖြတ်မည့် မျဉ်း သို့မဟုတ် arc သည် ရှည်လျားသွားသည်ဟု ယူဆသည်: တိုသော မျဉ်းသည် ရှည်လျားပါက ဖြတ်မည့်နေရာတွင် ဖြတ်သည်။ ပြန်ပြောင်းရန် `E` ၊ ထို့နောက် `N` (No extend) ကို ရိုက်ပါ။ ၎င်းသည် EDGEMODE 1 နှင့် 0 နှင့် တူသည်။

## မထွက်ဘဲ ဖျက်ခြင်း

`R` (eRase) ကို ရိုက်ပြီး {{key:Enter}} ကို နှိပ်ပါ၊ ဖျက်မည့် object များ ရွေးပြီး {{key:Enter}} ကို နှိပ်ပါ။ TRIM ဆက်လုပ်မည်။

## အဖြစ်များသော အမှားများ

- **မျဉ်းတစ်ကြောင်း လုံးဝ ပျောက်သွားသည်။** Quick မုဒ်တွင် ဘာနှင့်မှ မဖြတ်သော object ကို ဖျက်သည်။ `U` ကို ရိုက်ပြီး ပြန်ထားပါ၊ သို့မဟုတ် Standard မုဒ်သို့ ပြောင်းပါ (`O`, `S`)။
- **"ဤနေရာတွင် ဖြတ်စရာ မရှိ: ရွေးထားသော အစွန်းမျိုး ထို object ကို ဖြတ်မထားပါ။"** Standard မုဒ်သည် သင်ရွေးထားသော အစွန်းများတွင်သာ ဖြတ်သည်။ `T` ကို ရိုက်ပြီး ပြန်ရွေးပါ။
- **"ထိုဦးတည်ချက်တွင် နယ်နမိတ် မရှိပါ။"** ရှေ့တွင် တိုးရန် မတွေ့ပါ။ ကြီးလာသင့်သော အဆုံးနှင့် နီးသော နေရာကို နှိပ်ပါ၊ သို့မဟုတ် တိုသော နယ်နမိတ်များအတွက် `E` (Edge, Extend) ကို ဖွင့်ပါ။
- **ဆွဲခြင်းက lasso ဖြစ်သွားသည်။** ဆွဲခြင်းသည် TRIM သို့မဟုတ် EXTEND က object တောင်းနေချိန်တွင်သာ ဖြတ်သည်။ Command မလုပ်နေစဉ် ဆွဲခြင်းက ရွေးသည် (ကြည့်ပါ [Lasso ဖြင့် ရွေးခြင်း](topic:lasso-selection))။
- **မျဉ်း၊ arc၊ စက်ဝိုင်းနှင့် polyline များသာ ဖြတ်နိုင်သည်။** Block ၏ မျဉ်းများကို ဖြတ်ရန် အရင် explode လုပ်ပါ။
