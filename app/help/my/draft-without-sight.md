**Access** သည် မြင်ကွင်းကို မကြည့်ဘဲ ပုံဆွဲနိုင်စေသည်။ သင်ဖွင့်မှသာ ဖွင့်ထားမည် ဖြစ်သဖြင့် မသိဘဲ မည်သူမျှ ရရှိမည် မဟုတ်ပါ။

## ဖွင့်ရန်

**Settings** (ဂီယာအိုင်ကွန်၊ သို့မဟုတ် Ctrl+,) ကို ဖွင့်ပြီး **Drafting without sight** ကို ရှာကာ **On** ကို ရွေးပါ။ သို့မဟုတ် ကွန်မန်းလိုင်းတွင် `ACCESS` ကို ရိုက်ပြီး `On` ဟု ဖြေပါ။ ဤကွန်ပျူတာတွင် မှတ်ထားမည်။

Access ဖွင့်ထားစဉ်:

- **ကွန်မန်းလိုင်းပြသသမျှအားလုံးကို** သင့် screen reader မှတစ်ဆင့် ပြောပြသည်: သင်ရိုက်သောစာ၊ မေးသော prompt၊ အဖြေနှင့် အမှားတိုင်း။ CadCraft သည် ကိုယ်ပိုင် ယဉ်ကျေးသော နှင့် အရေးပေါ် live region များကို သုံးသဖြင့် live region ကို ဖတ်သော screen reader အတွက် ဘာမျှ ထပ်ပြင်စရာ မလိုပါ။ အမှားနှင့် ပယ်ဖျက်မှုများသည် အခြားအရာများကို ရပ်စေပြီး ကျန်အရာများက အလှည့်ကို စောင့်သည်။
- **ပုံဆွဲနေရာသို့ ရောက်နိုင်သည်။** "Drawing" ကို ကြားရသည်အထိ Tab ကို နှိပ်ပါ၊ သို့မဟုတ် ကွန်မန်းလိုင်းမှ Shift+Tab ကို နှိပ်ပါ။ ၎င်းသည် ကီးများကို CadCraft သို့ ဖြတ်ပေးသော ဒေသဖြစ်သည်။

## ပုံဆွဲပေါ်ရှိ ကီးများ

| ကီး | ဘာလုပ်သလဲ |
|---|---|
| Arrow ကီးများ | ကီးဘုတ် cursor ကို ရွှေ့သည်။ တစ်ဆင့်သည် ပြသထားသော မျက်နှာပြင်၏ ရာခိုင်နှုန်း တစ်ခုခန့် ဖြစ်ပြီး 1၊ 2 သို့မဟုတ် 5 သို့ ဝန်းကျင်ပြုလုပ်သည်။ Shift က ဆယ်ဆ ပိုရွှေ့ပြီး Ctrl က ဆယ်ပုံတစ်ပုံ ရွှေ့သည်။ |
| Enter | Cursor ရှိအမှတ်ကို ရွေးသည်၊ နှိပ်ခြင်းကဲ့သို့ အတိအကျ။ |
| Space | ကွန်မန်းလိုင်းတွင် Enter ကို နှိပ်ခြင်း: LINE ကို ပြီးစီးစေပြီး မူလတန်ဖိုးကို ယူသည်။ |
| Tab၊ Shift+Tab | cursor အနီးရှိ နောက် သို့မဟုတ် ယခင် snap အမှတ်သို့ ခုန်သွားသည်၊ အနီးဆုံးကို ရှေ့ဆုံးတွင်ထားသည်။ |
| G | ရွေးထားသော အရာများ၏ grip များကို တစ်ခုချင်း သွားသည်။ |
| D | ပုံဆွဲကို ဖော်ပြသည်: အရာ ဘယ်နှစ်ခု၊ ဘာအမျိုးအစား၊ ဘယ်လောက်ကြီးသလဲ၊ ဘာ ရွေးထားသလဲ။ |
| W | Cursor ဘယ်မှာရှိသလဲနှင့် နောက်ဆုံးအမှတ်မှ ဘယ်လောက်ဝေးသလဲ ပြောသည်။ |
| N | Cursor အနီးရှိ အရာများကို အနီးဆုံးမှ စ၍ အကွာအဝေးနှင့် ဘယ်ဘက်/ညာဘက်ဖြင့် ပြောသည်။ |
| S | ရွေးထားသော အရာများကို ဖော်ပြသည်။ |
| R | နောက်ဆုံး ပြောခဲ့သည်ကို ထပ်ပြောသည်။ |
| V | အသံ ဖွင့်/ပိတ်။ |
| / | ကွန်မန်းလိုင်းသို့ သွားသည်။ |
| ? | ဤကီးများကို စာရင်းပြသည်။ |

ကီးများဖြင့် ရွှေ့သောအခါ ရောက်ရှိရာနေရာကို ပြောသည်။ ကွန်မန်းတစ်ခုက အမှတ်ကို စောင့်နေစဉ် နောက်ဆုံးအမှတ်မှ ဘယ်လောက်ဝေးပြီး ဘယ်ဘက်ညွှန်ပြနေသည်ကိုလည်း ပြောသည်။ ဥပမာ "နောက်ဆုံးအမှတ်မှ 2400၊ ညာဘက်သို့၊ 0 ဒီဂရီတွင်"။

## ကွန်မန်းများ

- {{cmd:ACCESS}} သည် Access၊ snap အသံနှင့် အသံဖြင့် ကွန်မန်းကို ဖွင့်/ပိတ်ပြီး အခြေအနေကို ပြောသည်။
- {{cmd:DESCRIBE}} သည် ပုံဆွဲတွင် ပါဝင်သည်များကို ပြောသည်။
- {{cmd:WHEREAMI}} သည် cursor ဘယ်မှာရှိသည်ကို ပြောသည်။
- {{cmd:NEARBY}} သည် cursor အနီးရှိ အရာများကို ပြောသည်။
- {{cmd:SAYSEL}} သည် ရွေးထားသည်များကို အရာတစ်ခုလျှင် စာကြောင်းတစ်ကြောင်းဖြင့် ပြောသည်။
- {{cmd:VOICE}} သည် အသံဖြင့် ကွန်မန်းကို ဖွင့်/ပိတ်သည်။

ဤငါးခုသည် ပုံဆွဲကို ဖတ်ပြီး အဖြေကို ပြသသည်၊ ဘာမျှ မပြောင်းလဲပါ။

## Snap နှင့် grip အသံများ

**Settings** တွင် **Snap and grip sounds** ကို ဖွင့်ပါ။ snap အမျိုးအစားတစ်ခုစီတွင် ကိုယ်ပိုင် အသံအမြင့်နှင့် အသံရှိသည်။ ထို့ကြောင့် endpoint၊ midpoint၊ center၊ intersection နှင့် အခြားများကို ခွဲခြားနိုင်သည်။ grip တွင် နှစ်ချက်တီးသံ ရှိသည်။ အသံသည် cursor ကို မျက်နှာပြင်ပေါ်တွင် လိုက်၍ ဘယ်ဘက် သို့မဟုတ် ညာဘက်သို့ ပြောင်းသည်။ အသံများကို သင့်ကွန်ပျူတာပေါ်တွင် ဖန်တီးသည်၊ ဘာမျှ download မလုပ်ပါ။

## အသံဖြင့် ကွန်မန်းများ

**Settings** တွင် **Commands by voice** ကို ဖွင့်ပါ။ ကွန်မန်းအမည် ("line"၊ "circle"၊ "move") ကို ပြောပါ၊ ထို့နောက် ဂဏန်းများကို ဖတ်သလို ပြောပါ: "point three hundred comma four hundred"၊ "distance twelve hundred"၊ "angle forty five"။ "Enter"၊ "cancel"၊ "undo" နှင့် "redo" သည် ပြောသည့်အတိုင်း လုပ်သည်။ ကြားရသောစကားကို ပြန်ပြောပြမည်။ ကွန်မန်းမဟုတ်သော စကားကို ခန့်မှန်းမပေးဘဲ အစီရင်ခံမည်။

**စကားပြောကို ဘယ်မှာ မှတ်ယူသလဲ။** CadCraft တွင် ကိုယ်ပိုင် speech service မရှိပြီး အသံကို ဘယ်ကိုမှ မပို့ပါ။ ဤကွန်ပျူတာပေါ်တွင် စကားကို မှတ်ယူရန် သင့် browser ကို တောင်းဆိုသည်။ browser က လုပ်နိုင်ပါက ရွေးချယ်မှုသည် **On this computer** ဖြစ်ပြီး အသံ ဘာမျှ ထွက်မသွားပါ။ မလုပ်နိုင်ပါက **Browser online service** ကို သင်ရွေးမှသာ အသံဖြင့် ဖွင့်မည်ဖြစ်ပြီး ၎င်းသည် browser ထုတ်လုပ်သူ၏ speech service သို့ အသံကို ပို့နိုင်သည်။ သင်မဆုံးဖြတ်မီ Settings က မည်သည့်ရွေးချယ်ချက် သက်ရောက်သည်ကို ပြောပြမည်။

## ယခုထိ မလုပ်နိုင်သေးသည်များ

- CadCraft တွင်သာ Access ရှိသည်။ အခြား app ခုနစ်ခုကို ထို့နောက် တူညီသော ကီးနှင့် အသံများဖြင့် ထည့်မည်။
- ပုံဆွဲရှိ စာသား (မှတ်ချက်၊ block အမည်) ကို ရေးထားသည့်အတိုင်း ဖတ်ပြသည်၊ ညွှန်ကြားချက်အဖြစ် ဘယ်တော့မျှ မယူပါ။
- synthetic စစ်ဆေးမှုနှင့် browser test များဖြင့် စမ်းသပ်ပြီးဖြစ်သည်။ NVDA၊ VoiceOver နှင့် မျက်မမြင် သို့မဟုတ် အမြင်အာရုံ အားနည်းသော စမ်းသပ်သူဖြင့် လက်ဖြင့် စစ်ဆေးမှု ကျန်ပါသေးသည်။ စမ်းကြည့်ပါက ဘာများ ပျောက်နေသလဲ ကျွန်ုပ်တို့ကို ပြောပြပါ။
