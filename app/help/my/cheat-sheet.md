အတိုနာမည် (alias) ကို ရိုက်ပြီး Enter ကို နှိပ်ပါ၊ သို့မဟုတ် ကိရိယာကို နှိပ်ပါ။ Esc ဖြင့် ပယ်ဖျက်သည်။ command လိုင်း အလွတ်တွင် Enter ကို နှိပ်လျှင် နောက်ဆုံး command ကို ထပ်လုပ်သည်။

**ပရင့်ထုတ်ရန်:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (A4 စာမျက်နှာ တစ်ရွက်၊ Letter စက္ကူတွင် ပရင့်ထုတ်လျှင် "စာမျက်နှာသို့ ကိုက်ညီအောင်" ဖြင့် ပရင့်ထုတ်ပါ။)

## ဆွဲခြင်း

| အတိုနာမည် | Command | ဘာလုပ်သလဲ |
|---|---|---|
| `L` | {{cmd:LINE}} | မျဉ်းဖြောင့်များ ဆွဲရန် |
| `PL` | {{cmd:PLINE}} | ဆက်နေသော မျဉ်းနှင့် လုံးပတ်အပိုင်းများ ဆွဲရန် |
| `C` | {{cmd:CIRCLE}} | စက်ဝိုင်း ဆွဲရန် (ဗဟိုနှင့် အချင်းဝက်) |
| `A` | {{cmd:ARC}} | လုံးပတ်အပိုင်း ဆွဲရန် |
| `REC` | {{cmd:RECTANG}} | ထောင့်နှစ်ခုမှ စတုဂံ ဆွဲရန် |
| `POL` | {{cmd:POLYGON}} | ညီမျှသော ပေါ်လီဂွန် ဆွဲရန် |
| `EL` | {{cmd:ELLIPSE}} | ဧလီပ်စ် ဆွဲရန် |
| `DT` | {{cmd:TEXT}} | စာသား တစ်ကြောင် ရေးရန် |
| `T` | {{cmd:MTEXT}} | ဝဲသွားသော စာသား (စာပိုဒ်) ရေးရန် |
| `H` | {{cmd:HATCH}} | ပုံစံဖြင့် နယ်ပယ်ကို ဖြည့်ရန် |

## ပြင်ဆင်ခြင်း

| အတိုနာမည် | Command | ဘာလုပ်သလဲ |
|---|---|---|
| `M` | {{cmd:MOVE}} | အရာဝတ္ထုများ ရွှေ့ရန် |
| `CO` | {{cmd:COPY}} | အရာဝတ္ထုများ ကူးရန် |
| `RO` | {{cmd:ROTATE}} | အမှတ်တစ်ခုပတ်လည် အရာဝတ္ထုများ လှည့်ရန် |
| `SC` | {{cmd:SCALE}} | အရာဝတ္ထုများကို ပိုကြီး သို့မဟုတ် ပိုသေးအောင် လုပ်ရန် |
| `MI` | {{cmd:MIRROR}} | မျဉ်းတစ်ကြောင်းဖက်သို့ အရာဝတ္ထုများ လှန်ရန် |
| `O` | {{cmd:OFFSET}} | အကွာအဝေးတစ်ခုတွင် အပြိုင် မိတ္တူ ဆွဲရန် |
| `TR` | {{cmd:TRIM}} | အခြားတစ်ခု ဖြတ်ကျော်သည့်နေရာသို့ အရာဝတ္ထုများ ဖြတ်ရန် |
| `EX` | {{cmd:EXTEND}} | အခြားတစ်ခုအထိ အရာဝတ္ထုများ ရှည်စေရန် |
| `F` | {{cmd:FILLET}} | လုံးပတ်အပိုင်းဖြင့် ထောင့်ကို ဝိုင်းရန် |
| `CHA` | {{cmd:CHAMFER}} | မျဉ်းဖြောင့်ဖြင့် ထောင့်ကို ဖြတ်ရန် |
| `E` | {{cmd:ERASE}} | အရာဝတ္ထုများ ဖျက်ရန် |
| `X` | {{cmd:EXPLODE}} | ဘလောက် သို့မဟုတ် polyline ကို အပိုင်းများအဖြစ် ခွဲရန် |
| `S` | {{cmd:STRETCH}} | ဖြတ်ကျော်ဝင်းဒိုးအတွင်းရှိ အဆုံးများကို ရွှေ့ရန် |
| `AR` | {{cmd:ARRAY}} | grid သို့မဟုတ် စက်ဝိုင်းပုံစံဖြင့် ကူးရန် |
| `J` | {{cmd:JOIN}} | မျဉ်းနှင့် လုံးပတ်အပိုင်းများကို အရာဝတ္ထုတစ်ခုတည်းသို့ ပေါင်းရန် |
| `BR` | {{cmd:BREAK}} | အရာဝတ္ထုကို နှစ်ပိုင်းဖြတ်ရန် သို့မဟုတ် အပိုင်းတစ်ခု ဖယ်ရန် |
