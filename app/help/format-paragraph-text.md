## What you'll do

Write a note, make one word bold and red, change its size, add a degree sign, and finish.

## Steps

1. Type {{cmd:MTEXT}} and press {{key:Enter}}, or double-click an existing text, or type {{cmd:TEXTEDIT}} and pick it. The text box opens with a formatting row above it.
2. Type your note. {{key:Enter}} starts a new paragraph.
3. Select a word with the mouse or {{key:Shift+Right}}.
4. In the formatting row use {{ui:Font}} for the font, {{ui:Size}} for the size of the selection, and the buttons {{ui:Bold}}, {{ui:Italic}}, {{ui:Underline}} and {{ui:Strike-through}}, and {{ui:Colour}} to pick a colour. With nothing selected, {{ui:Size}} changes all of the text.
5. Use {{ui:Align left}}, {{ui:Centre}} or {{ui:Align right}} for the alignment.
6. To type a symbol, put the cursor where it goes and click {{ui:Degree sign}}, {{ui:Plus-minus sign}} or {{ui:Diameter sign}}.
7. Click {{ui:OK}} or press {{key:Ctrl+Enter}} to save the text. {{ui:Cancel}} or {{key:Esc}} leaves it as it was.

## Notes

- The box also has {{ui:Height}}, {{ui:Line spacing}}, {{ui:Width}} (0 = no wrapping) and {{ui:Justify}}.
- The formatting is written as paragraph text codes together with the plain words, so find, snap, DXF and DWG keep working. Set the font of whole notes with a [text style](topic:text-styles).
- There are no bullet or numbered lists, tab ruler or justified paragraphs yet.
- Plotted PDFs set text in Helvetica.
