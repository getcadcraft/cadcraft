Tastați numele scurt (aliasul) și apăsați Enter sau faceți clic pe unealtă. Esc anulează. Enter pe o linie goală repetă ultima comandă.

**Imprimați-o:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (o pagină A4; pe hârtie Letter imprimați cu „potrivire la pagină”).

## Desenare

| Tip | Comandă | Ce face |
|---|---|---|
| `L` | {{cmd:LINE}} | Desenează linii drepte |
| `PL` | {{cmd:PLINE}} | Desenează un lanț de linii și arce conectate |
| `C` | {{cmd:CIRCLE}} | Desenează un cerc (centru și rază) |
| `A` | {{cmd:ARC}} | Desenează un arc |
| `REC` | {{cmd:RECTANG}} | Desenează un dreptunghi din două colțuri |
| `POL` | {{cmd:POLYGON}} | Desenează un poligon regulat |
| `EL` | {{cmd:ELLIPSE}} | Desenează o elipsă |
| `DT` | {{cmd:TEXT}} | Scrie o linie de text |
| `T` | {{cmd:MTEXT}} | Scrie text care se încadrează pe rânduri (paragraf) |
| `H` | {{cmd:HATCH}} | Umple o zonă cu un model |

## Modificare

| Tip | Comandă | Ce face |
|---|---|---|
| `M` | {{cmd:MOVE}} | Mută obiectele |
| `CO` | {{cmd:COPY}} | Copiază obiectele |
| `RO` | {{cmd:ROTATE}} | Rotește obiectele în jurul unui punct |
| `SC` | {{cmd:SCALE}} | Mărește sau micșorează obiectele |
| `MI` | {{cmd:MIRROR}} | Răsturnează obiectele peste o linie |
| `O` | {{cmd:OFFSET}} | Desenează o copie paralelă la o distanță |
| `TR` | {{cmd:TRIM}} | Taie obiectele până la locul unde le intersectează altele |
| `EX` | {{cmd:EXTEND}} | Prelungește obiectele până la altele |
| `F` | {{cmd:FILLET}} | Rotunjește un colț cu un arc |
| `CHA` | {{cmd:CHAMFER}} | Taie un colț cu o muchie dreaptă |
| `E` | {{cmd:ERASE}} | Șterge obiecte |
| `X` | {{cmd:EXPLODE}} | Descompune un bloc sau o polilinie în părțile sale |
| `S` | {{cmd:STRETCH}} | Mută capetele din interiorul unei ferestre de intersectare |
| `AR` | {{cmd:ARRAY}} | Copiază într-o grilă sau într-un cerc |
| `J` | {{cmd:JOIN}} | Unește linii și arce într-un singur obiect |
| `BR` | {{cmd:BREAK}} | Taie un obiect în două sau scoate o porțiune din el |

## Cotare

| Tip | Comandă | Ce face |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Cotează orizontal sau vertical |
| `DAL` | {{cmd:DIMALIGNED}} | Cotează de-a lungul unei linii înclinate |
| `DRA` | {{cmd:DIMRADIUS}} | Cotează o rază |
| `DAN` | {{cmd:DIMANGULAR}} | Cotează un unghi |

## Blocuri și straturi

| Tip | Comandă | Ce face |
|---|---|---|
| `B` | {{cmd:BLOCK}} | Creează un bloc din obiecte |
| `I` | {{cmd:INSERT}} | Plasează un bloc |
| `LA` | {{cmd:LAYER}} | Deschide straturile |

## Vizualizare și interogare

| Tip | Comandă | Ce face |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | Mărește, micșorează sau la tot (E) |
| `DI` | {{cmd:DIST}} | Măsoară o distanță și un unghi |
| `LI` | {{cmd:LIST}} | Afișează detaliile unui obiect |
| `MA` | {{cmd:MATCHPROP}} | Copiază aspectul unui obiect pe altele |

## Fișier

| Tip | Comandă | Ce face |
|---|---|---|
| `U` | {{cmd:UNDO}} | Anulează ultima comandă |
| `SAVE` | {{cmd:SAVE}} | Salvează desenul |
| `PLOT` | {{cmd:PLOT}} | Trasează în PDF |

## Taste

Ctrl (Cmd pe Mac): Z anulare · Y refacere · S salvare · P trasare. F3 agățare la obiect · F8 ortogonal · F10 polar. Space sau Enter repetă ultima comandă · rotița mărește · trăgând rotița se deplasează vederea.
