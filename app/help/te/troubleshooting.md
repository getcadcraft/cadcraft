## ఫైళ్లు తెరవడం

| సందేశం లేదా లక్షణం | కారణం | పరిష్కారం |
|---|---|---|
| "CadCraft opens DWG and DXF drawings. "…" is neither." | ఫైల్ `.dwg` లేదా `.dxf` కాదు. | డ్రాయింగ్ ఫైల్‌ను నేరుగా తెరవండి. PDF ను తీసుకురావచ్చు (Open అడుగుతుంది: import లేదా attach, చూడండి [PDF underlays](topic:pdf-underlay)); చిత్రాలు `IMAGEATTACH` తో వస్తాయి. |
| "This binary DXF ends in the middle of an object: the file is cut short or damaged." | బైనరీ DXF దాని ముగింపుకు ముందే ఆగిపోతుంది. | చదవగలిగింది తెరవడానికి RECOVER అని టైప్ చేయండి, లేదా ఫైల్‌ను మళ్ళీ అడగండి. |
| "This file is not a readable DXF (bad group code on line …)." | DXF పాడైంది లేదా నిజంగా DXF కాదు. | ఫైల్‌ను మళ్ళీ అడగండి, లేదా DWG అడగండి. |
| "This drawing could not be read. It may be damaged, or saved in a version the reader does not handle yet (…)." | DWG రీడర్ దానిని చదవలేకపోయింది. | పాత వెర్షన్‌లో సేవ్ చేసిన DWG అడగండి, లేదా DXF. |
| "This drawing is from AutoCAD R11 / R12 (DWG AC1009), older than CadCraft reads …" | Release 12 మరియు అంతకు ముందు DWG ఫైళ్లు CadCraft చదవని ఫార్మాట్‌ను ఉపయోగిస్తాయి. | దానిని తయారు చేసిన ప్రోగ్రామ్‌లో DXF (ఏ వెర్షన్ అయినా) లేదా కొత్త DWG గా సేవ్ చేసి, దానిని తెరవండి. CadCraft యొక్క స్వంత Save as ఆ పాత ఫార్మాట్ కోరే ప్రోగ్రామ్‌ల కోసం DXF R12 ఇస్తుంది. |
| "Could not open …" తర్వాత నెట్‌వర్క్ సందేశం, మొదటి DWG పై | DWG రీడర్ డౌన్‌లోడ్ కాలేదు: మీరు ఆఫ్‌లైన్‌లో ఉన్నారు మరియు CadCraft ఆఫ్‌లైన్ వాడకానికి సేవ్ కాలేదు, లేదా కనెక్షన్ తెగిపోయింది. | ఆన్‌లైన్‌కు వెళ్లి మళ్ళీ ప్రయత్నించండి, లేదా DXF తెరవండి. {{ui:Save for offline}} క్లిక్ చేసి "Offline ready" వచ్చే వరకు వేచి ఉండండి, తర్వాతిసారి DWG ఫైళ్లు ఆఫ్‌లైన్‌లో తెరుచుకునేలా. చూడండి [ఆఫ్‌లైన్‌లో పని](common:offline). |
| ఆఫ్‌లైన్ బటన్ "Could not save" అంటుంది | కొన్ని ఫైళ్లు డౌన్‌లోడ్ కాలేదు. | కనెక్షన్ తనిఖీ చేసి, మళ్ళీ ప్రయత్నించడానికి బటన్ క్లిక్ చేయండి. |
| ఆఫ్‌లైన్ బటన్ "Offline not available" అంటుంది | ప్రైవేట్ విండోలు మరియు కొన్ని నిర్వహించబడే కంప్యూటర్‌లు ఆఫ్‌లైన్ కాపీని ఉంచలేవు. | సాధారణ విండో వాడండి, లేదా ఆన్‌లైన్‌లో ఉండండి. |
| కనెక్షన్ లేకుండా CadCraft తెరుచుకోదు | ఈ బ్రౌజర్‌లో ఆఫ్‌లైన్ వాడకానికి సేవ్ కాలేదు, లేదా బ్రౌజర్ దానిని తొలగించింది. | తర్వాతిసారి ఆన్‌లైన్‌లో ఉన్నప్పుడు {{ui:Save for offline}} క్లిక్ చేసి "Offline ready" వచ్చే వరకు వేచి ఉండండి. |
| డ్రాయింగ్ తెరుచుకుంటుంది, కానీ భాగాలు లేవు | CadCraft ఇంకా గీయలేని వస్తువులు, లేదా ఫైల్‌లో ఆఫ్ లేదా ఫ్రీజ్ అయిన లేయర్‌లు. | ఎడమ ప్యానెల్‌లోని "About this file" చదవండి. {{ui:Layers}} ప్యానెల్ తనిఖీ చేయండి. |
| టెక్స్ట్ రెండు లైన్‌లుగా చుట్టుకుంటుంది | CadCraft టెక్స్ట్‌ను Helvetica-శైలి ఫాంట్‌లో గీస్తుంది, కొన్ని CAD ఫాంట్‌ల కంటే ఇది వెడల్పుగా ఉంటుంది. | Properties లో టెక్స్ట్ తగ్గించండి, లేదా అదనపు లైన్‌ను అంగీకరించండి. |
| వృత్తం దీర్ఘవృత్తంగా కనిపిస్తుంది, లేదా ప్రతిబింబించిన టెక్స్ట్ సరైన వైపు చదవబడుతుంది | ఫైల్ తయారు చేసిన ప్రోగ్రామ్‌లో వస్తువు వంగిన తలంలో, లేదా కింది నుండి చూసినట్లు గీయబడింది. CadCraft దానిని పైనుండి చూసినట్లు చూపిస్తుంది, ఆ ప్రోగ్రామ్ ప్లాన్ వీక్షణ వలె; టెక్స్ట్ చదవగలిగేలా ఉంచబడుతుంది. | సరిచేయాల్సింది ఏమీ లేదు. ఇతర ప్రోగ్రామ్ పద్ధతిలో చూడటానికి, డ్రాయింగ్‌ను ఫ్లాట్ చేయమని లేదా వస్తువులను పైనుండి గీయమని అడగండి. |
| బ్లాక్, వృత్తం లేదా డైమెన్షన్ ఫైల్ తయారు చేసిన ప్రోగ్రామ్‌లోని స్థానం కాకుండా వేరే చోట ఉంది | CadCraft తప్పుగా చదివిన డ్రాయింగ్ కేసు. | Discord లో మాకు చెప్పండి, వీలైతే ఫైల్‌తో. |

| "Unknown command "…". Type HELP for the list." | ఆ పేరుతో కమాండ్ లేదా ఆలియాస్ లేదు. | `HELP` టైప్ చేయండి, లేదా [Command reference](topic:commands) చూడండి. కొన్ని తెలిసిన కమాండ్‌లు [ఇంకా లేవు](topic:not-built-yet). |
| కమాండ్ లైన్ పక్కన టైప్ చేస్తున్నప్పుడు "No such command" | మీరు టైప్ చేసినది ఇంకా దేనితోనూ సరిపోలదు. | టైప్ చేస్తూ ఉండండి, లేదా స్పెల్లింగ్ తనిఖీ చేయండి. |
| "Point or option keyword required." | మీరు టైప్ చేసినది బిందువు లేదా ఎంపిక కాదు. | ఫార్మాట్ తనిఖీ చేయండి: `x,y`, `@dx,dy`, `@d<a`, లేదా ఒకే సంఖ్య. చూడండి [Coordinate and distance entry](topic:coordinate-entry). |
| "Requires a positive number or two points." | దూరం ప్రతికూలంగా ఉంది లేదా సంఖ్య కాదు. | ఒక ధనాత్మక సంఖ్య టైప్ చేయండి, లేదా రెండు బిందువులపై క్లిక్ చేయండి. |
| "Requires an angle in degrees or two points." | కోణం సంఖ్య కాదు. | డిగ్రీలను సాదా సంఖ్యగా టైప్ చేయండి. |
| "Requires a number." | సంఖ్య ఆశించబడింది. | అంకెలు మాత్రమే టైప్ చేయండి. |
| "Invalid option keyword." | అక్షరాలు ఏ ఎంపికతోనూ సరిపోలవు. | చతురస్ర బ్రాకెట్లలో చూపిన పెద్ద అక్షరాలు టైప్ చేయండి. |
| `*Cancel*` | మీరు {{key:Esc}} నొక్కారు, లేదా బిందువు అవసరమైన చోట {{key:Enter}} నొక్కారు. | కమాండ్ మళ్ళీ మొదలుపెట్టండి. |
| టైప్ చేసినది కమాండ్ లైన్‌కు చేరదు | ప్యానెల్ లేదా డైలాగ్‌లోని బాక్స్‌లో కర్సర్ ఉంది. | {{key:Enter}} లేదా {{key:Esc}} నొక్కండి, లేదా డ్రాయింగ్‌పై క్లిక్ చేయండి. |
| కమాండ్ మీరు ఎంచుకోని వస్తువులను ఉపయోగిస్తుంది | అది మొదలుపెట్టే ముందే అవి ఎంచుకోబడ్డాయి. | కమాండ్ ముందు {{key:Esc}} నొక్కండి. |
| ఒక గీత ఊహించని చోటికి వెళ్ళింది | `x,y` సంపూర్ణమైనది. | సాపేక్ష బిందువుల కోసం `@dx,dy` వాడండి. |
| "Finish or cancel the current command first (Esc)." | కమాండ్ నడుస్తుండగా మీరు {{key:Mod+S}} నొక్కారు. | {{key:Esc}} నొక్కి, ఆపై సేవ్ చేయండి. |

## సవరణ

| సందేశం లేదా లక్షణం | కారణం | పరిష్కారం |
|---|---|---|
| ఒక వస్తువు ఎంపిక కాదు | దాని లేయర్ లాక్ చేయబడింది, ఆఫ్ లేదా ఫ్రీజ్ చేయబడింది; లేదా మీరు షీట్‌పై ఉన్నారు మరియు అది వ్యూపోర్ట్ లోపలి మోడల్. | లేయర్ అన్‌లాక్ చేయండి, లేదా {{ui:Model}} ట్యాబ్‌కు వెళ్లండి. |
| "Nothing found there." | ఆ క్లిక్ కింద ఏ వస్తువూ లేదు. | జూమ్ చేసి గీతపైనే క్లిక్ చేయండి. |
| "Nothing crosses that object there." | {{cmd:TRIM}} మీరు ఎంచుకున్న ముక్కను దాటే ఏ వస్తువునూ కనుగొనలేదు. | కత్తిరించే గీత నిజంగా దానిని దాటుతుందో తనిఖీ చేయండి. |
| "Cannot trim that object." | Trim లైన్‌లు, ఆర్క్‌లు, వృత్తాలు మరియు పాలీలైన్‌లపై పనిచేస్తుంది. | ముందుగా బ్లాక్‌లను ఎక్స్‌ప్లోడ్ చేయండి, లేదా తొలగించి మళ్ళీ గీయండి. |
| "No boundary in that direction." | {{cmd:EXTEND}} కలవడానికి ఏమీ కనుగొనలేదు. | పెరగాల్సిన చివరకు దగ్గరగా ఎంచుకోండి. |
| "Cannot offset that object." | Offset లైన్‌లు, ఆర్క్‌లు, వృత్తాలు మరియు పాలీలైన్‌లపై పనిచేస్తుంది. | ముందుగా ఎక్స్‌ప్లోడ్ చేయండి, లేదా సమాంతర గీత గీయండి. |
| "Cannot offset that far." | ఆఫ్‌సెట్ ఆకారాన్ని లోపలికి-బయటకు తిప్పుతుంది. | చిన్న దూరం వాడండి. |
| "Radius is too large." లేదా "Distance is too large." | ఫిల్లెట్ లేదా చాంఫర్ ఒక లైన్ చివరను దాటి వెళ్తుంది. | `R` తో చిన్న వ్యాసార్థం, లేదా `D` తో చిన్న దూరాలు సెట్ చేయండి. |
| "Only the first or last segment of an open polyline can be cut back." | మూలలో ఒక పాలీలైన్ మధ్యలోకి కత్తిరించబడుతుంది. | పాలీలైన్ యొక్క ఒకదానికొకటి పక్కనున్న రెండు విభాగాలు ఎంచుకోండి, లేదా ప్రతి మూలకు `P` వాడండి. |

| "No objects selected; nothing made." | ఎంచుకోవడానికి ముందు మీరు {{key:Enter}} నొక్కారు. | {{cmd:BLOCK}} మళ్ళీ నడపండి మరియు వస్తువులను ఎంచుకోండి. |
