ఆదేశం యొక్క చిన్న పేరు (ఏలియాస్) టైప్ చేసి {{key:Enter}} నొక్కండి, లేదా టూల్ పై క్లిక్ చేయండి. {{key:Esc}} రద్దు చేస్తుంది. ఖాళీ లైన్ పై {{key:Enter}} నొక్కితే చివరి ఆదేశం మళ్ళీ జరుగుతుంది.

**ప్రింట్ చేయడానికి:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (ఒక A4 పేజీ; Letter కాగితంపై "పేజీకి సరిపోయేలా" ఎంపికతో ప్రింట్ చేయండి).

## గీయి

| టైప్ | ఆదేశం | ఏమి చేస్తుంది |
|---|---|---|
| `L` | {{cmd:LINE}} | సరళ రేఖలు గీయి |
| `PL` | {{cmd:PLINE}} | కనెక్ట్ చేసిన రేఖ మరియు చాపం గొలుసు గీయి |
| `C` | {{cmd:CIRCLE}} | వృత్తం గీయి (కేంద్రం మరియు వ్యాసార్థం) |
| `A` | {{cmd:ARC}} | చాపం గీయి |
| `REC` | {{cmd:RECTANG}} | రెండు మూలల నుండి దీర్ఘచతురస్రం గీయి |
| `POL` | {{cmd:POLYGON}} | సమాన బహుభుజి గీయి |
| `EL` | {{cmd:ELLIPSE}} | దీర్ఘవృత్తం గీయి |
| `DT` | {{cmd:TEXT}} | ఒక లైన్ పాఠ్యం రాయి |
| `T` | {{cmd:MTEXT}} | చుట్టుకునే పాఠ్యం (పేరా) రాయి |
| `H` | {{cmd:HATCH}} | ఒక నమూనాతో ప్రాంతాన్ని నింపు |

## మార్పు

| టైప్ | ఆదేశం | ఏమి చేస్తుంది |

| `RO` | {{cmd:ROTATE}} | వస్తువులను ఒక బిందువు చుట్టూ తిప్పు |
| `SC` | {{cmd:SCALE}} | వస్తువులను పెద్దవి లేదా చిన్నవి చేయి |
| `MI` | {{cmd:MIRROR}} | ఒక రేఖకు అడ్డంగా వస్తువులను తిప్పు |
| `O` | {{cmd:OFFSET}} | ఒక దూరంలో సమాంతర కాపీ గీయి |
| `TR` | {{cmd:TRIM}} | ఇతర వస్తువులు దాటే చోటు వరకు వస్తువులను కత్తిరించు |
| `EX` | {{cmd:EXTEND}} | ఇతర వస్తువుల వరకు వస్తువులను పొడిగించు |
| `F` | {{cmd:FILLET}} | ఒక మూలను చాపంతో గుండ్రంగా చేయి |
| `CHA` | {{cmd:CHAMFER}} | ఒక మూలను సరళ అంచుతో కత్తిరించు |
| `E` | {{cmd:ERASE}} | వస్తువులను తొలగించు |
| `X` | {{cmd:EXPLODE}} | ఒక బ్లాక్ లేదా పాలిలైన్‌ను దాని భాగాలుగా విడదీయి |
| `S` | {{cmd:STRETCH}} | దాటే విండోలో ఉన్న చివరలను కదుపు |
| `AR` | {{cmd:ARRAY}} | గ్రిడ్ లేదా వృత్తంలో కాపీ చేయి |
| `J` | {{cmd:JOIN}} | రేఖలు మరియు చాపాలను ఒకే వస్తువుగా కలుపు |
| `BR` | {{cmd:BREAK}} | ఒక వస్తువును రెండుగా విరుచు, లేదా ఒక భాగాన్ని తీసివేయి |

## కీలు

Ctrl (Mac లో Cmd): Z చర్య రద్దు · Y మళ్ళీ చేయి · S సేవ్ చేయి · P ప్లాట్.  F3 ఆబ్జెక్ట్ స్నాప్ · F8 ఆర్థో · F10 పోలార్.  Space లేదా Enter చివరి ఆదేశాన్ని మళ్ళీ చేస్తుంది · వీల్ జూమ్ చేస్తుంది · వీల్‌ను లాగితే ప్యాన్ అవుతుంది
