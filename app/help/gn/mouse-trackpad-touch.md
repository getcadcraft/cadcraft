CadCraft ojapo mouse rueda-gui. Todo ojeporu trackpad-pe avave, peteĩ ojehai'ỹ jeporu. Pantalla táctil oiporu elección-pe, peteĩ límite-pe.

## Mouse rueda

- **Zoom:** eroll rueda. Plano zoom ojapo crosshair ryguépe, upéi ehecha mba'e ndehecháva.
- **Desplazar:** eñongatu rueda ha ehai, térã ehai clic derecho-pe.
- **Zoom todo:** doble clic rueda-pe, térã eclikea {{ui:Extensiones}}.
- **Vista anterior:** eclikea {{ui:Anterior [P]}} grupo {{ui:Vista}} ryépe, térã ehai `Z`, {{key:Enter}}, `P`, {{key:Enter}}. Rueda paso peteĩ vista oikuaaiva, peteĩ {{ui:Anterior [P]}} oheja opa. Vista oikuaaiva guardá hag̃ua ojeporu {{cmd:NAMEDVIEW}} (`NV`).
- **Enter:** clic derecho.

## Trackpad

:::mac
- **Desplazar:** ehai dos dedo trackpad-pe, ojehai hag̃ua: plano oho dedo ndive. Ojeporu ehai dos dedo clic oñongatuva (clic derecho ehai).
- **Zoom:** pellizcá dos dedo ndive. Zoom crosshair-pe ojeguereko.
- **Clic derecho (Enter):** clic dos dedo ndive. Omoĩ "Clic secundario" **Configuración del sistema**-pe, upéi **Trackpad**-pe, ndaporãi ramo. Control-clic ojapo ordinario clic CadCraft-pe, clic derecho ndaha; ojeporu dos dedo clic.
- **Zoom área:** eclikea {{ui:Ventana [W]}} grupo {{ui:Vista}} ryépe ha eclikea mokõi esquina.
:::

:::windows linux
- **Desplazar:** ehai dos dedo touchpad-pe, ojehai hag̃ua: plano oho dedo ndive. Clic derecho oñongatuva ehai ojeporu.
- **Zoom:** pellizcá dos dedo ndive. Zoom crosshair-pe ojeguereko.
- **Clic derecho (Enter):** clic dos dedo ndive, térã touchpad esquina yvate-izquierda rupi, touchpad configuración-pe oúva.
- **Zoom área:** eclikea {{ui:Ventana [W]}} grupo {{ui:Vista}} ryépe ha eclikea mokõi esquina.
:::

{{key:Space}} oñongatuva ehai **ndojerrovia** CadCraft-pe: {{key:Space}} ha'e Enter.

Rueda mouse oiko zoom peteĩ paso. Touchpad ojapóva scroll paso-pe, rueda-gui, dos dedo scroll-pe zoom ojapo, ndaha desplazar: zoom out, ehecha área, upéi zoom in. Pestaña 3D-pe trackpad movimiento mboyve (ehecha [Modelo 3D](topic:3d-solids#look-around)).

## Pantalla táctil y tableta

CadCraft dedo ojereko mouse clic-icha:

- Tocar elige punto térã objeto, térã selecciona.
- Dedo arrastra tenonde vacío-pe ojapo lazo (derecha-izquierda primero ventana; izquierda-derecha primero crossing; ehecha [Selección con lazo](topic:lasso-selection)).
- {{cmd:TRIM}} ha {{cmd:EXTEND}}-pe, dedo oñongatu pedazo rupi ojapo recorte térã extensión opa.
- Objeto selección agarre arrastra: agarre ojeruva (agarre ha cuadro de selección tamaño mayor dedo-pe).
- **Pellizcar** dos dedo ndive zoom ojapo mokõi dedo apytépe punto ryguépe; dos dedo juntos ojehai **desplazar**. Segundo dedo oñemboguejy ohechakuaa primer dedo ojapo, pellizcar ndokoi marca.
- **Presión larga** (ehai quieto unos medio segundo) clic derecho: {{key:Enter}}. Comando oñeguejy, selección oñemoĩ, térã último comando ojapo jey.

Línea de comando debajo peteĩ **fila de teclas** ohechauka: {{ui:Esc}}, {{ui:Deshacer}}, {{ui:Rehacer}}, tablet teclado ndohechaʼỹ caracteres (`@` `,` `<` `'` `"` `-`), {{ui:Ajustar}}, {{ui:Ortogonal}}, teclado botón, ha tuichavéva {{ui:Enter}}. Tocar teclado botón (térã línea de comando) ehai comando térã número.

Hover ndaiporiva, ajuste marcador solo dedo oĩvape ohechauka.

:::touch
Pantalla táctil ojeporu. Análisis tuichave ojapo, teclado mouse térã trackpad ojeguereko CadCraft ojeporuvéva.
:::

## Navegadores

CadCraft ojapo mokõi Chrome, Edge, Firefox ha Safari-pe, Mac, Windows ha Linux-pe. Diferencia michĩ:

| Tema | Mba'e ikuaáva |
|---|---|
| Abrir DWG | Plano tuichave lee segundos cada navegador-pe; línea estado ohechauka "Leyendo …" |
| Descargas | Cada navegador omoĩ mba'épe ojeguerekóta descarga ha ohepyhy mboyve; ehecha [Navegadores y computadoras](common:browsers) |
| Abrir para imprimir | Abre PDF pestaña pyahúpe. Navegador emergente oheja, CadCraft descarga PDF |
| F7 | Firefox ohai caret browsing; eroja No |
| Salir sin guardar | Cada navegador ohechauka "¿Salir del sitio?", CadCraft ndoiporiri cambia |

:::safari
Safari-pe, PDF {{ui:Abrir para imprimir}} ojeporu tab-pe ohechauka, imprimirá ndaha: ojeporu **Archivo**, upéi **Imprimir**.
:::

:::firefox
Firefox ohai mba'e ojapóta cada descarga-pe. Eroja guardar archivo, térã peteĩ jey ojapo Firefox configuración-pe Descargas ryépe.
:::
