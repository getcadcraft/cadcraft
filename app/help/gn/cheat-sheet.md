Emoñe'ẽ nombre corto (alias) ha ejapo Enter, térã ejapo clic herramienta-pe. Esc ombotyre. Enter línea vacía-pe ombohasa último comando.

**Imprimilo:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (peteĩ página A4; papel Letter-pe imprimi "ajustar a la página" ndive).

## Dibujar

| Tipo | Comando | Ojapóva |
|---|---|---|
| `L` | {{cmd:LINE}} | Ojoaju línea recta |
| `PL` | {{cmd:PLINE}} | Ojoaju línea ha arco ojoaporã |
| `C` | {{cmd:CIRCLE}} | Ojoaju círculo (centro ha radio) |
| `A` | {{cmd:ARC}} | Ojoaju arco |
| `REC` | {{cmd:RECTANG}} | Ojoaju rectángulo mokõi esquina rupive |
| `POL` | {{cmd:POLYGON}} | Ojoaju polígono regular |
| `EL` | {{cmd:ELLIPSE}} | Ojoaju elipse |
| `DT` | {{cmd:TEXT}} | Ohaiha peteĩ línea texto |
| `T` | {{cmd:MTEXT}} | Ohaiha texto ojeheja (párrafo) |
| `H` | {{cmd:HATCH}} | Ojehe área patrón rupive |
