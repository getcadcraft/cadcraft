छोटा नाम (उपनाम) टाइप करें और Enter दबाएँ, या टूल पर क्लिक करें. Esc रद्द करता है. खाली पंक्ति पर Enter पिछला कमांड दोहराता है.

**इसे प्रिंट करें:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (एक A4 पन्ना; Letter काग़ज़ पर "fit to page" के साथ प्रिंट करें).

## ड्रॉ

| टाइप करें | कमांड | यह क्या करता है |
|---|---|---|
| `L` | {{cmd:LINE}} | सीधी लाइनें ड्रॉ करें |
| `PL` | {{cmd:PLINE}} | जुड़ी हुई लाइन और चाप की कड़ी ड्रॉ करें |
| `C` | {{cmd:CIRCLE}} | वृत्त ड्रॉ करें (केंद्र और त्रिज्या) |
| `A` | {{cmd:ARC}} | चाप ड्रॉ करें |
| `REC` | {{cmd:RECTANG}} | दो कोनों से आयत ड्रॉ करें |
| `POL` | {{cmd:POLYGON}} | नियमित बहुभुज ड्रॉ करें |
| `EL` | {{cmd:ELLIPSE}} | दीर्घवृत्त ड्रॉ करें |
| `DT` | {{cmd:TEXT}} | टेक्स्ट की एक पंक्ति लिखें |
| `T` | {{cmd:MTEXT}} | लिपटने वाला टेक्स्ट (अनुच्छेद) लिखें |
| `H` | {{cmd:HATCH}} | क्षेत्र को पैटर्न से भरें |

## संशोधित करें

| टाइप करें | कमांड | यह क्या करता है |
|---|---|---|
| `M` | {{cmd:MOVE}} | ऑब्जेक्ट स्थानांतरित करें |
| `CO` | {{cmd:COPY}} | ऑब्जेक्ट कॉपी करें |
| `RO` | {{cmd:ROTATE}} | ऑब्जेक्ट को एक बिंदु के चारों ओर घुमाएँ |
| `SC` | {{cmd:SCALE}} | ऑब्जेक्ट बड़े या छोटे करें |
| `MI` | {{cmd:MIRROR}} | ऑब्जेक्ट को किसी लाइन के आर-पार पलटें |
| `O` | {{cmd:OFFSET}} | एक दूरी पर समांतर प्रति ड्रॉ करें |
| `TR` | {{cmd:TRIM}} | ऑब्जेक्ट को वहाँ तक काटें जहाँ दूसरे उन्हें पार करते हैं |
| `EX` | {{cmd:EXTEND}} | ऑब्जेक्ट को दूसरों तक बढ़ाएँ |
| `F` | {{cmd:FILLET}} | कोने को चाप से गोल करें |
| `CHA` | {{cmd:CHAMFER}} | कोने को सीधे किनारे से काटें |
| `E` | {{cmd:ERASE}} | ऑब्जेक्ट हटाएँ |
| `X` | {{cmd:EXPLODE}} | ब्लॉक या पॉलीलाइन को उसके हिस्सों में तोड़ें |
| `S` | {{cmd:STRETCH}} | क्रॉसिंग विंडो के भीतर के सिरे हिलाएँ |
| `AR` | {{cmd:ARRAY}} | ग्रिड या वृत्त में कॉपी करें |
| `J` | {{cmd:JOIN}} | लाइनों और चापों को एक ऑब्जेक्ट में जोड़ें |
| `BR` | {{cmd:BREAK}} | ऑब्जेक्ट को दो में काटें, या एक टुकड़ा निकालें |

## डाइमेंशन

| टाइप करें | कमांड | यह क्या करता है |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | क्षैतिज या ऊर्ध्वाधर डाइमेंशन दें |
| `DAL` | {{cmd:DIMALIGNED}} | तिरछी लाइन के साथ-साथ डाइमेंशन दें |
| `DRA` | {{cmd:DIMRADIUS}} | त्रिज्या का डाइमेंशन दें |
| `DAN` | {{cmd:DIMANGULAR}} | कोण का डाइमेंशन दें |

| टाइप करें | कमांड | यह क्या करता है |

## व्यू और जाँच

| टाइप करें | कमांड | यह क्या करता है |

| `DI` | {{cmd:DIST}} | दूरी और कोण मापें |

| `MA` | {{cmd:MATCHPROP}} | एक ऑब्जेक्ट का रूप दूसरों पर कॉपी करें |

| टाइप करें | कमांड | यह क्या करता है |

| `SAVE` | {{cmd:SAVE}} | ड्रॉइंग सहेजें |
| `PLOT` | {{cmd:PLOT}} | PDF में प्लॉट करें |

## कुंजियाँ

Ctrl (Mac पर Cmd): Z पूर्ववत · Y फिर से करें · S सहेजें · P प्लॉट.  F3 ऑब्जेक्ट स्नैप · F8 ऑर्थो · F10 पोलर.  Space या Enter पिछला कमांड दोहराता है · पहिया ज़ूम करता है · पहिया दबाकर खींचने से पैन होता है
