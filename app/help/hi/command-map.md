CadCraft वही कमांड नाम और छोटे नाम लेता है जो लोग दूसरे ड्राफ़्टिंग प्रोग्रामों से जानते हैं: एक लाइन के लिए `L`, ट्रिम के लिए `TR`, मिटाने के लिए `E` टाइप करें। इसलिए ज़्यादातर कमांड के लिए कोई अनुवाद तालिका सीखनी नहीं पड़ती: जो नाम आप जानते हैं, वही यहाँ है। नीचे की सूची CadCraft के हर कमांड की है, जो प्रोग्राम से ही बनी है। {{key:Enter}} आखिरी कमांड दोहराता है; कमांड लाइन में `HELP` वही सूची छापता है।

कुछ ही कमांड ऐसे हैं जो वैसे नहीं हैं, या अभी बने नहीं हैं:

- **सहेजें** (Save) ब्राउज़र में एक प्रति डाउनलोड करता है ({{cmd:SAVE}}, {{cmd:SAVEAS}}); CadCraft Studio में यह फ़ाइल लिखता है। देखें [दूसरे ड्राफ़्टिंग सॉफ़्टवेयर से आना](topic:coming-from)।
- **PLOT** एक PDF बनाता है (PNG और SVG भी), प्लॉट स्टाइल टेबल के साथ; इसमें पेज सेटअप मैनेजर नहीं है।
- **DIMSTYLE** और **PEDIT** बने हुए हैं; **PEDIT** में Edit-vertex विकल्प नहीं है (यह काम ग्रिप करते हैं)।
- **TABLE** अभी बना नहीं है; {{cmd:XREF}}, {{cmd:SPLINE}} और {{cmd:WBLOCK}} बने हुए हैं।
- किसी रूटीन के अपने कमांड (AutoLISP `C:NAME`) {{cmd:APPLOAD}} से उसे लोड करने के बाद दिखते हैं; वे यहाँ सूचीबद्ध नहीं हैं।

| `WALLJOINSTYLE` |  | एक कोना क्लिक करें जहाँ दो दीवारें सिरे से सिरे मिलती हैं, उसे बनाने का तरीका बदलने के लिए: मिटर, सपाट, स्क्वेयर ऑफ़। T बताता है कि कौन-सी दीवार उस कोने से आर-पार चलेगी। |

| `WALLPICK` |  | ड्रॉइंग की एक लाइन या पॉलीलाइन पर दीवारें बनाएँ, और अगर आप हाँ कहें तो उससे जुड़ी लाइनें भी। |
| `WALLPOLY` | `WP` | 3 से 64 भुजाओं वाले नियमित बहुभुज के चारों ओर दीवारें बनाएँ, POLYGON की तरह। |
| `WALLRECT` | `WR` | दो आमने-सामने के कोनों से चार जुड़ी दीवारें बनाएँ, RECTANG की तरह। |
| `WALLREJOIN` |  | एक दीवार के दो भागों को फिर एक दीवार बनाएँ। पहला अपनी जगह ड्रॉइंग में रखता है। |
| `WALLROT` |  | चार जुड़ी दीवारें किसी भी कोण पर घूमे आयत के रूप में बनाएँ: पहली भुजा, फिर दूसरी कितनी दूर। |
| `WALLSPLIT` | `WS` | एक दीवार को एक बिंदु पर, या जहाँ दूसरी दीवार उसे पार करे, दो भागों में बाँटें। भाग जुड़े रहते हैं जब तक आप अंतर या मुक्त सिरे न माँगें। दरवाज़े और खिड़कियाँ अपने भाग के साथ जाते हैं। |
| `WALLSPLITGAP` |  | एक दीवार को अंतर छोड़कर बाँटें: अंतर टाइप करें, दीवार चुनें, फिर बिंदु। भाग मुक्त सिरे रखते हैं और फिर जोड़े जा सकते हैं। |
| `WALLSTRETCH` |  | एक खिड़की से खींचें: उसके भीतर के दीवार-सिरे हिलते हैं, पूरी तरह भीतर की दीवारें पूरी हिलती हैं, और जो दीवारें उनके किनारों से टकराती हैं वे उनके साथ सरकती हैं। |
| `WALLTAN` |  | एक दीवार को एक चाप से आगे बढ़ाएँ जो उसे दीवार के अनुदिश छोड़ता है (छोटी सीधी दीवारों के रूप में बनता है)। |
| `WALLTRACE` |  | आपके क्लिक किए बिंदु के आसपास रेखाओं और दीवारों के सबसे छोटे बंद क्षेत्र के चारों ओर दीवारें बनाएँ। |
| `WALLUNHOLD` |  | एक दीवार से लॉक हटाएँ (और उससे जुड़ी दूसरी दीवारों के लॉक भी)। |

| `WEDGE` | `WE` | एक वेज: दो कोने और एक ऊँचाई; वह पहले कोने से दूर ढलता है (3D) |
