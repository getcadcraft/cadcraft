Escriviu el nom curt (l'àlies) i premeu Enter, o feu clic a l'eina. Esc cancel·la. Enter en una línia buida repeteix l'última ordre.

**Imprimiu-la:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (una pàgina A4; en paper Letter, imprimiu-la amb "ajusta a la pàgina").

## Dibuixa

| Tipus | Ordre | Què fa |
|---|---|---|
| `L` | {{cmd:LINE}} | Dibuixa línies rectes |
| `PL` | {{cmd:PLINE}} | Dibuixa una cadena de línies i arcs connectats |
| `C` | {{cmd:CIRCLE}} | Dibuixa un cercle (centre i radi) |
| `A` | {{cmd:ARC}} | Dibuixa un arc |
| `REC` | {{cmd:RECTANG}} | Dibuixa un rectangle a partir de dues cantonades |
| `POL` | {{cmd:POLYGON}} | Dibuixa un polígon regular |
| `EL` | {{cmd:ELLIPSE}} | Dibuixa una el·lipse |
| `DT` | {{cmd:TEXT}} | Escriu una línia de text |
| `T` | {{cmd:MTEXT}} | Escriu text que es reparteix en línies (paràgraf) |
| `H` | {{cmd:HATCH}} | Omple una àrea amb un patró |

## Modifica

| Tipus | Ordre | Què fa |
|---|---|---|
| `M` | {{cmd:MOVE}} | Mou objectes |
| `CO` | {{cmd:COPY}} | Copia objectes |
| `RO` | {{cmd:ROTATE}} | Gira objectes al voltant d'un punt |
| `SC` | {{cmd:SCALE}} | Fa els objectes més grans o més petits |
| `MI` | {{cmd:MIRROR}} | Inverteix objectes respecte d'una línia |
| `O` | {{cmd:OFFSET}} | Dibuixa una còpia paral·lela a una distància |
| `TR` | {{cmd:TRIM}} | Retalla objectes fins on els creuen altres |
| `EX` | {{cmd:EXTEND}} | Allarga objectes fins a d'altres |
| `F` | {{cmd:FILLET}} | Arrodoneix una cantonada amb un arc |
| `CHA` | {{cmd:CHAMFER}} | Retalla una cantonada amb una línia recta |
| `E` | {{cmd:ERASE}} | Suprimeix objectes |
| `X` | {{cmd:EXPLODE}} | Descompon un bloc o una polilínia en les seves parts |
| `S` | {{cmd:STRETCH}} | Mou els extrems dins d'una finestra d'intersecció |
| `AR` | {{cmd:ARRAY}} | Copia en una quadrícula o un cercle |
| `J` | {{cmd:JOIN}} | Uneix línies i arcs en un sol objecte |
| `BR` | {{cmd:BREAK}} | Talla un objecte en dos, o n'extreu un tros |

## Cota

| Tipus | Ordre | Què fa |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Acota en horitzontal o en vertical |
| `DAL` | {{cmd:DIMALIGNED}} | Acota al llarg d'una línia inclinada |
| `DRA` | {{cmd:DIMRADIUS}} | Acota un radi |
| `DAN` | {{cmd:DIMANGULAR}} | Acota un angle |

## Blocs i capes

| Tipus | Ordre | Què fa |
|---|---|---|
| `B` | {{cmd:BLOCK}} | Crea un bloc a partir d'objectes |
| `I` | {{cmd:INSERT}} | Col·loca un bloc |
| `LA` | {{cmd:LAYER}} | Obre les capes |

## Vista i consulta

| Tipus | Ordre | Què fa |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | Amplia, redueix o mostra-ho tot (E) |
| `DI` | {{cmd:DIST}} | Mesura una distància i un angle |
| `LI` | {{cmd:LIST}} | Mostra els detalls d'un objecte |
| `MA` | {{cmd:MATCHPROP}} | Copia l'aspecte d'un objecte sobre d'altres |

## Fitxer

| Tipus | Ordre | Què fa |
|---|---|---|
| `U` | {{cmd:UNDO}} | Desfà l'última ordre |
| `SAVE` | {{cmd:SAVE}} | Desa el dibuix |
| `PLOT` | {{cmd:PLOT}} | Traça a PDF |

## Tecles

Ctrl (Cmd en un Mac): Z desfés · Y refés · S desa · P traça.  F3 referència a objectes · F8 orto · F10 polar.  Space o Enter repeteix l'última ordre · la roda fa zoom · arrossegar la roda desplaça

Nou en el dibuix? Escriviu `TOUR` per fer un primer dibuix guiat, llegiu [Primers passos amb CadCraft](topic:getting-started), o consulteu totes les ordres a [Referència d'ordres](topic:commands). Si veniu d'altres programes de dibuix: [Venint d'altres programes de dibuix](topic:coming-from) i el [mapa d'ordres](topic:command-map).
