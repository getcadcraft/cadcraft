Ku qor magaca gaaban (alias) oo taabo Enter, ama guji qalabka. Esc waa joojiyaa. Enter sadar madhan ku riix wuxuu ku celinayaa amarkii ugu dambeeyay.

**Daabac:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (hal bog oo A4; warqadda Letter, daabac "ku habee bogga").

## Sawir

| Qor | Amarka | Waxa uu sameeyo |
|---|---|---|
| `L` | {{cmd:LINE}} | Sawir xariiqyo toosan |
| `PL` | {{cmd:PLINE}} | Sawir silsilad xariiq iyo qaanso isku xidhan |
| `C` | {{cmd:CIRCLE}} | Sawir goobo (dhexda iyo radius) |
| `A` | {{cmd:ARC}} | Sawir qaanso |
| `REC` | {{cmd:RECTANG}} | Sawir afar-geesle laba geesood |
| `POL` | {{cmd:POLYGON}} | Sawir poligon joogto ah |
| `EL` | {{cmd:ELLIPSE}} | Sawir ellipse |
| `DT` | {{cmd:TEXT}} | Qor hal xariiq qoraal |
| `T` | {{cmd:MTEXT}} | Qor qoraal lafo-lafo ah (faqrad) |
| `H` | {{cmd:HATCH}} | Buuxi meel naqshad ah |

## Furayaasha

Ctrl (Cmd Mac-ka): Z ka noqo · Y samee mar kale · S kaydi · P daabac. F3 qabashada walxaha · F8 ortho · F10 polar. Space ama Enter wuxuu ku celinayaa amarkii ugu dambeeyay · gudbiyaha wheel-ka wuxuu weynaynayaa · jiidista wheel-ka wuxuu guuriyaa goobta

Cusub naqshadaynta? Ku qor `TOUR` si aad u hagto naqshadda koowaad, akhri [Bilow](topic:getting-started), ama eeg dhammaan amarrada [Amarrada](topic:commands). Ka yimid software naqshadeed kale: [Ka yimid software naqshadeed kale](topic:coming-from) iyo [khariidadda amarrada](topic:command-map).
