## 學習內容

如何變更你輸入以回答指令選項的字母。例如，{{cmd:ARRAY}} 會詢問 `[Rectangular/POlar]`，並以 `PO` 代表 Polar；你可以讓 `P` 或任何其他字母做到相同的事，如果你願意，也可以使用你自己的語言。

## 如何回答選項

當指令在方括號中顯示選項時，大寫字母就是你要輸入的字母：`POlar` 是 `PO`，`eXit` 是 `X`。

你也可以輸入較少的字母。若你輸入的內容只符合顯示的其中一個選項，CadCraft 就會採用它：在 `[Rectangular/POlar]` 中，單獨的 `P` 即為 Polar。若符合兩個，指令列會列出它們並再次詢問：

```
C could be COUnt, COLumns. Type more letters.
```

數字永遠不會被猜測，因此你輸入的距離或數量一律會被讀取為數字。

## 新增你自己的字母

每個指令都保留其內建字母。你的字母會疊加在其上，因此你的清單只包含你更改過的內容。

1. 開啟 {{ui:設定}}（{{key:Mod+,}}）› {{ui:CadCraft}} › {{ui:選項字母}}，然後按一下 {{ui:編輯…}}。或輸入 {{cmd:OPTIONKEYS}} 後按{{key:Enter}}鍵。
2. 在 {{ui:指令}} 下，選擇指令，例如 `ARRAY`。清單會列出所有會詢問選項的指令，並從你最近使用的指令開始。
3. 在 {{ui:選項}} 下，選擇選項。每個選項會以方括號顯示其內建字母，例如 `POlar (PO)`。
4. 在 {{ui:自訂字母}} 中，輸入你想要的字母，例如 `P`，然後按一下 {{ui:加入}}。
5. 該選項會出現在 {{ui:自訂字母}} 之下，同時顯示其內建字母與你的字母。按一下 {{ui:儲存}}。

啟動 {{cmd:ARRAY}}，選取一個物件並按{{key:Enter}}鍵。提示會在選項之後顯示你的字母，`POlar (P)`，而 `P` 即可回答它。

若要移除某個字母，請按一下其列末端的 x，然後按一下 {{ui:儲存}}。該選項會恢復為只有內建字母。

## 無法使用的字母

編輯器會拒絕那些會遮蔽指令列已能讀取之內容的字母，並說明原因：

- 同一指令中另一個選項的內建字母（在 `ARRAY` 中，`R` 是 Rectangular，因此不能用於 Polar）；
- 三個字母或更多的物件鎖點字詞，例如 `END`、`MID` 或 `CEN`，以及 `ALL` 與 `LAST` 這兩個字詞；
- 同一指令的兩個不同選項使用相同的字母。

任何以紅色列出的項目存在時，{{ui:儲存}} 會停用：修正該行或將其移除，它就會再次啟用。提示的內建字母永遠優先於你的字母，因此你的清單不會阻止內建的回答運作。像 `L` 或 `C` 這樣恰好是指令名稱的字母是可以的：在選項提示處，指令列讀取的是回答，而不是啟動指令。

{{ui:指令}} 下列出的選項，來自與其提示共用的指令，因此偶爾某個指令會列出它只在某些情況下才詢問的選項。

## 適用於每個指令的一組字母

在 {{ui:指令}} 下，選擇 {{ui:所有指令}}。此時的選項是任何指令都有的每個選項，例如 eXit 或 Undo。你在此加入的字母，會在任何指令提供該選項時作為回答。針對某一指令加入的字母優先於這些字母。

## 你自己語言中的字母

字母可以來自任何字母表，因此你不必切換鍵盤即可回答選項：在 {{ui:所有指令}} 下加入 `З` 作為 Close，或在 `ARRAY` 中加入 `П` 作為 POlar。

CadCraft 只附帶英文字母。你的清單是你、你的事務所或使用你語言的人設定其餘字母的方式，而 {{ui:匯出}} 會產生可交給他人的檔案。

## 以文字編輯

編輯器中的 {{ui:以文字編輯}} 會以文字行的形式顯示相同的清單，每個選項一行，這也正是 {{ui:匯出}} 所儲存的內容：

```
ARRAY.PO,  P
*.X,       Q
```

每一行包括指令、一個點、選項的內建字母、一個逗號，以及你的字母。以星號取代指令，表示每個指令。以 `;` 開頭的行為附註。

## 保持不變的部分

- 內建字母與你的字母並存運作。
- 常式與工具列按鈕繼續使用內建字母，因此你載入的內容不會失效。若你的字母會造成妨礙，而你想自己輸入內建字母，請在前面加上底線：`_PO`。
- 指令的短名稱是另一回事：請參閱[編輯指令別名](topic:command-aliases)。

## CadCraft 拒絕的行

當你以文字編輯或匯入檔案時，編輯器會以行號列出每個問題：

- 指令不存在（指令的別名是可以的：`AR.PO` 會被讀取為 `ARRAY.PO`）；
- 該行不是 `COMMAND.OPTION, LETTERS` 格式；
- 字母含有空格或符號（僅限字母與數字，最多 16 個）；
- 同一指令的兩個不同選項使用相同的字母。

## 匯入與匯出

{{ui:匯出}} 會將你的字母儲存為文字檔，以便保存或交給他人。{{ui:匯入…}} 會讀取這類檔案。兩者都位於編輯器中，以及 {{ui:設定}} › {{ui:CadCraft}} › {{ui:選項字母}} 中。

在設定中，{{ui:匯入…}} 會以你選擇的檔案取代你的檔案。若檔案中有某行發生衝突或無法使用，則整個檔案不會被採用；請在編輯器中開啟並在那裡匯入，以查看各行。在編輯器中，匯入只會填入方塊：在你按一下 {{ui:儲存}} 之前，不會有任何改變。

## 重新載入或移除

輸入 {{cmd:REINIT}} 後按{{key:Enter}}鍵，即可再次套用你的檔案。若要移除某個字母，請刪除其所在的行，然後按一下 {{ui:儲存}}。

## 你的字母跟隨你的帳戶

當你登入 getcadcraft.com 時，你的字母會保存在你的帳戶中。在另一個瀏覽器或另一台以相同帳戶登入的電腦上開啟 CadCraft，它們會自動出現；指令列會顯示「來自你帳戶的選項字母」。若你在兩個地方變更了它們，則以最新的副本為準，被取代的那份會保留一次。

{{ui:設定}} › {{ui:CadCraft}} › {{ui:選項字母}} 會說明它們目前的狀態。未登入或離線時，它們會保留在此瀏覽器中，並在你登入時下次儲存時，送到你的帳戶。
