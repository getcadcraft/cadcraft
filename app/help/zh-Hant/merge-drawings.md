兩人同時編輯同一個圖形。若他們變更的是不同物件，合併便可自動完成：無需手動重做。

## 運作原理

CadCraft 會為你繪製的每個物件指定一個簡短的**金鑰**，該金鑰永不變更，且不會指派給兩個物件。它會與物件一起儲存在 DWG 或 DXF 中（作為其他程式會保留的額外資料）。合併時會依此金鑰尋找物件，而非依其在檔案中的位置，因為每個程式在儲存時都會重新編號位置。若從不合併，可在 {{ui:設定}} › CadCraft › 合併友善檔案 中關閉此功能；檔案會小約 10%。

在金鑰功能出現前儲存的圖形仍可合併：其物件會依其在檔案中的位置取得金鑰，對所有開啟該檔案的人都相同。

## 設定

Git 每個儲存庫需要設定一次以下兩行：

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# 每部電腦各設定一次
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

若不使用 git，請手動執行：`cadcraft merge <base> <ours> <theirs> -o <result>`。Fossil 與 Mercurial 在各自的合併工具設定中，同樣使用這三個檔案。

## 規則

- 只有一方變更的物件會被採用。雙方做出相同變更時，只採用一次。
- 同一屬性被以兩種方式變更即為**衝突**：保留本方版本，報告會列出兩個值。開啟結果檔，檢視該物件，並手動修正。
- 任一方新增的物件都會保留。一方刪除而另一方未變更的物件會被刪除。一方刪除而另一方有變更：則刪除並回報。
- 圖層、區塊、文字與標註樣式、圖紙與命名視圖的合併方式相同。限制條件會跟隨其所指的物件。
- 結果以與原檔相同的檔案格式與版本寫入。

不會合併的部分：物件的繪製順序以本方為準，之後才是另一方新增的物件。雙方對同一區塊定義的變更視為衝突，絕不會混合。不會上傳任何內容；全部都在本機執行。
