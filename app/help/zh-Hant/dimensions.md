## 你將繪製什麼

一個已加上標註的房間：總寬度與高度、沿一面牆的標註串、一面傾斜的牆、一個彎曲的轉角，以及一個角度。

開始之前，若你的圖形很大，請先閱讀[設定標註尺寸](topic:dimension-settings)：預設的標註文字高度為 2.5 圖形單位，在以毫米量測的圖形中會非常小。以下步驟中，請先輸入`DIMSCALE`、按{{key:Enter}}、輸入`50`，然後按{{key:Enter}}。

## 標註工具的位置

使用 CadCraft 功能表樣式（CadCraft 初始使用的樣式）時，標註工具位於圖形上方的工具列中，屬於{{ui:註解}}群組：{{ui:線性}}、{{ui:對齊}}、{{ui:角度}}、{{ui:半徑}}與{{ui:直徑}}。該群組的{{ui:更多}}功能表包含{{ui:連續標註}}與{{ui:基線標註}}。將指標停留在按鈕上，即可看到它的功能。

- 使用{{ui:經典繪圖}}或{{ui:功能區}}功能表樣式時，請開啟{{ui:註解}}索引標籤：工具位於其{{ui:標註}}面板中。{{ui:經典繪圖}}在{{ui:常用}}索引標籤下的{{ui:註記}}中也有{{ui:線性}}。參見[功能表、按鍵與滑鼠](topic:menus-keys-and-mouse)。
- 或在圖形下方的指令列中輸入指令，然後按{{key:Enter}}：`DLI`（線性）、`DAL`（對齊）、`DAN`（角度）、`DRA`（半徑）、`DDI`（直徑）、`DCO`（連續）、`DBA`（基線）。
- 在窄螢幕上，工具列只有一列：左右滑動即可找到{{ui:註解}}。

要以毫米、公分、公尺或公里顯示長度，請參見[以毫米、公分、公尺或公里計的標註](topic:dimension-settings#dimensions-in-mm-cm-m-or-km)。

## 繪製要加上標註的物件

1. 輸入`PL`後按{{key:Enter}}。
2. 輸入`0,0`後按{{key:Enter}}。
3. 輸入`@6000,0`後按{{key:Enter}}。
4. 輸入`@1500<60`後按{{key:Enter}}。
5. 輸入`@0,2700`後按{{key:Enter}}。
6. 輸入`@-6750,0`後按{{key:Enter}}。
7. 輸入`C`後按{{key:Enter}}。輪廓會閉合。
8. 輸入`C`後按{{key:Enter}}，開始繪製圓。
9. 在房間內，遠離牆壁處按一下，作為圓心。
10. 輸入`600`後按{{key:Enter}}。這是一根柱子。
11. 按一下{{ui:範圍}}。

## 線性：水平或垂直

1. 輸入`DLI`後按{{key:Enter}}。
2. 在`Specify first extension line origin`處，鎖定至左下角（端點）並按一下。
3. 在`Specify second extension line origin`處，鎖定至右下角並按一下。
4. 將十字游標移到房間下方。標註會跟著移動，且為水平。
5. 按一下，以放置標註線。

歷程會顯示`Dimension text = 6000`。

放置標註線的位置決定方向：在下方或上方會得到水平標註，在左側或右側則為垂直標註。若要強制指定，請在放置前輸入`H`（水平）、`V`（垂直）或`R`（旋轉，然後輸入角度）。

:::tip
在第一個提示處按{{key:Enter}}，而非點選一點，然後按一下直線、圓弧、圓或聚合線的線段。CadCraft 會為你取得兩端。
:::

## 連續：一串標註

{{cmd:DIMCONTINUE}}（{{ui:註解}} › {{ui:更多}} › {{ui:連續標註}}，或`DCO`）會從你上一個線性或對齊標註延續，每個新標註都從上一個標註的終點開始。

1. 輸入`DLI`後按{{key:Enter}}。
2. 輸入`0,0`後按{{key:Enter}}，作為第一個原點。
3. 輸入`2000,0`後按{{key:Enter}}，作為第二個原點。
4. 在房間下方按一下，以放置它。
5. 輸入`DCO`後按{{key:Enter}}。
6. 輸入`4500,0`後按{{key:Enter}}。第二個標註會接續第一個，位於同一條線上。
7. 鎖定至右下角並按一下。第三個標註會完成這一串。
8. 按{{key:Enter}}結束指令。

:::note
此處刻意以絕對座標輸入點。`@` 點是從你上一次給出的點計算，而上一點是你放置前一個標註線的位置，而非標註的終點。在標註串中，絕對點、鎖點，或開啟{{ui:正交}}時的直接距離，會比較安全。
:::

輸入`U`後按{{key:Enter}}，即可在不離開指令的情況下撤銷標註串中的最後一個標註。

## 基線：從同一條線堆疊的標註

{{cmd:DIMBASELINE}}（{{ui:註解}} › {{ui:更多}} › {{ui:基線標註}}，或`DBA`）會以上一個標註的第一個原點為基準量測每個新標註，並將每個標註再往外堆疊一個間距。

1. 輸入`DLI`後按{{key:Enter}}。
2. 鎖定至左下角並按一下。
3. 鎖定至左上角並按一下。
4. 將十字游標移到房間左側並按一下。會出現一個垂直標註。
5. 輸入`DBA`後按{{key:Enter}}。
6. 鎖定至 60 度牆的上端（端點）並按一下。會出現第二個垂直標註，比第一個再往外一步。
7. 按{{key:Enter}}結束。

## 對齊：傾斜線的實際長度

1. 輸入`DAL`後按{{key:Enter}}。
2. 按{{key:Enter}}以選取物件。
3. 按一下 60 度的牆。
4. 向外移動，然後按一下以放置。

文字會顯示 1500：沿牆量測的實際長度。

## 半徑與直徑

1. 輸入`DRA`後按{{key:Enter}}。
2. 按一下柱子的圓。
3. 移動十字游標。引線會從圓心指向十字游標。
4. 按一下，以放置文字。

文字會顯示`R600`。{{cmd:DIMDIAMETER}}（`DDI`）做同樣的事，但使用 ⌀ 符號與直徑。

## 角度

此處的牆是一條聚合線，因此請以其頂點量測轉角。（若是兩條獨立的直線，你可以改為按一下這兩條直線。）

1. 輸入`DAN`後按{{key:Enter}}。
2. 在`Select arc, circle or line, or Enter for a vertex`處，按{{key:Enter}}。
3. 在`Specify angle vertex`處，鎖定至右下角並按一下。
4. 在`Specify first angle endpoint`處，鎖定至左下角並按一下。
5. 在`Specify second angle endpoint`處，鎖定至 60 度牆的上端並按一下。
6. 在房間內、靠近轉角處移動十字游標，然後按一下。

文字會顯示`120°`，即轉角的內角。若放在轉角的另一側，標註會改為量測那一側的角度。在第一個提示處按一下圓弧，即可標註該圓弧所夾的角度；或按一下兩條直線，即可標註它們之間的角度。

## 變更文字

若要輸入你自己的文字，請在放置標註前輸入`T`並按{{key:Enter}}，然後輸入文字。在你的文字中，`<>` 代表量測值：`<> TYP.`會顯示為`6000 TYP.`。在空白行按{{key:Enter}}即可保留量測值。

要變更既有的標註：

1. 按一下它。
2. 在右側面板的{{ui:文字}}欄位中輸入。留空即代表量測值。
3. 按{{key:Enter}}。

## 標註會跟隨幾何

標註會記住它的點。拖曳其中一個夾點，或與它所量測的物件一起移動、旋轉或縮放，它就會重新量測。若你拉伸幾何而未移動標註，標註就不會跟隨：它會保留自己的點。

## 常見錯誤

- **文字與箭頭小到看不見，或大到出界。** 請設定整體比例：參見[設定標註尺寸](topic:dimension-settings)。
- **「請在要量測的角度內選取一點。」** 你為角度標註按的點位於其中一條邊上。請將它移入該角之內。
- **連續從錯誤的標註開始。** 它總是從本次工作階段中你最後建立的線性或對齊標註延續。請先建立（或重新建立）要延續的那一個。
- **標註變成垂直。** 你把它放在側邊了。請在放置前輸入`H`。
- **英尺與英寸。** 請先將圖形的長度格式設為{{ui:建築}}，或在{{ui:屬性}}中設定標註的{{ui:格式}}：參見[標註中的英尺與英寸](topic:dimension-settings#feet-and-inches-in-dimensions)。
- **數字不是你想要的單位。** 請選擇{{ui:文字中的單位}}：參見[以毫米、公分、公尺或公里計的標註](topic:dimension-settings#dimensions-in-mm-cm-m-or-km)。
