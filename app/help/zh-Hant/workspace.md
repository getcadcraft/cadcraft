畫面有七個部分。由上到下依序為：應用程式列、工具列、兩側各有一個面板的繪圖區、圖形下方的索引標籤、指令列與狀態列。

## 應用程式列

最頂端的細列屬於網站，而不是圖形。它顯示 CadCraft 標誌、應用程式名稱、正在執行的版本、該應用程式頁面的連結、{{ui:說明}} 按鈕（或 {{key:F1}}）、{{ui:儲存供離線使用}} 按鈕、{{ui:全螢幕}} 按鈕，以及兩個佈景主題按鈕：{{ui:圖紙}} 與 {{ui:模型}}。

{{ui:設定}} 按鈕（齒輪）包含 CadCraft 本身的設定，以及所有應用程式共用的設定：參閱 [CadCraft 設定](topic:settings)。

{{ui:儲存供離線使用}} 會在此瀏覽器中保留一份 CadCraft 的副本（含其 DWG 讀取器），使其無需連線即可開啟。其標籤顯示狀態：「正在儲存 N／M」、「可離線使用」、「無法儲存」或「無法離線使用」。參閱[離線工作](common:offline)。

:::note
應用程式列中的 {{ui:圖紙}} 與 {{ui:模型}} 按鈕只會改變畫面的色彩：{{ui:圖紙}} 是淺色佈景主題，{{ui:模型}} 是深色佈景主題。它們與圖形下方的 {{ui:模型}} 索引標籤無關，後者用於在圖形與其圖紙之間切換。
:::

{{ui:全螢幕}} 按鈕，或 {{key:Ctrl+Shift+F}}（在所有電腦上都是 Control 鍵，Mac 也一樣），會循環切換三種畫面模式：一般、全螢幕，以及隱藏列的全螢幕。列隱藏時，將指標移到畫面頂端邊緣即可叫回。

## 工具列

應用程式列下方是工具列。每個按鈕執行一個指令，與輸入該指令完全相同，因此兩種方式下指令列提出的問題一樣。將指標停在按鈕上可看到其指令別名。群組如下：

| 群組 | 按鈕 |
|---|---|
| 檔案 | {{ui:新增}}、{{ui:開啟}}、{{ui:儲存}}、{{ui:另存新檔}}、{{ui:列印}} |
| 繪製 | {{ui:直線}}、{{ui:聚合線}}、{{ui:圓}}、{{ui:圓弧}}、{{ui:矩形}}、{{ui:多邊形}}、{{ui:橢圓}}、{{ui:文字}}、{{ui:段落}}、{{ui:填滿}}，以及 {{ui:更多}}：{{ui:點}}、{{ui:構造線}} 與 {{ui:射線}}（參閱[構造線與射線](topic:construction-lines)） |
| 修改 | {{ui:移動}}、{{ui:複製}}、{{ui:旋轉}}、{{ui:縮放}}、{{ui:鏡射}}、{{ui:拉伸}}、{{ui:偏移}}、{{ui:修剪}}、{{ui:延伸}}、{{ui:圓角}}、{{ui:倒角}}、{{ui:分解}}、{{ui:刪除}}，以及 {{ui:更多}}：{{ui:陣列}}、{{ui:接合}}、{{ui:對應特性}}、{{ui:打斷}} 與 {{ui:延長}} |
| 註解 | {{ui:線性}}、{{ui:對齊}}、{{ui:角度}}、{{ui:半徑}}、{{ui:直徑}}（標註）、{{ui:引線}}（多重引線），以及 {{ui:更多}}：{{ui:連續標註}}、{{ui:基線標註}} 與 {{ui:修訂雲形}} |
| 參數式 | {{ui:自動}}、{{ui:限制}}、{{ui:標註}}、{{ui:參數}}，以及含各種限制條件的 {{ui:更多}}（參閱[限制圖形](topic:constraints)） |
| 區塊 | {{ui:建立}}、{{ui:插入}}、{{ui:程式庫}}，以及 {{ui:更多}}：{{ui:編輯區塊}} 與 {{ui:定義屬性}} |
| 圖紙 | {{ui:新增圖紙}}、{{ui:視埠}} |
| 編輯 | {{ui:復原}}、{{ui:取消復原}}、{{ui:複製}}（到剪貼簿）、{{ui:貼上}}，以及 {{ui:更多}}：含 {{ui:剪下}}、{{ui:複製}}、{{ui:貼上}}、{{ui:原位貼上}}、{{ui:建立副本並移動}}、{{ui:刪除}}、{{ui:全選}}、{{ui:取消全選}}、{{ui:快速選取}}、{{ui:選取相似物件}} 與 {{ui:尋找與取代}} 的功能表，每項都附有其按鍵 |
| 檢視 | {{ui:範圍}}、{{ui:視窗}}、{{ui:上一個}}，以及 {{ui:更多}}：{{ui:量測距離}}、{{ui:面積}}、{{ui:量測（半徑、角度…）}}，以及分割畫面：{{ui:左右分割}}、{{ui:上下分割}}、{{ui:四個窗格}}、{{ui:一個窗格}}（參閱[分割畫面](topic:split-screen)），還有 {{ui:將視圖向左轉 90°}}、{{ui:將視圖向右轉 90°}}、{{ui:回到世界座標}}（參閱[旋轉檢視](topic:ucs-and-turned-view)） |

「修改」群組中的 {{ui:複製}} 是 {{cmd:COPY}} 指令（基點，然後指定每個副本的位置）；「編輯」群組中的 {{ui:複製}} 則是將物件放到剪貼簿，供 {{ui:貼上}} 使用。參閱[複製、貼上與建立副本](topic:copy-paste)。正在執行的指令的按鈕會保持反白，直到指令結束。工具提示會標示 Windows 快速鍵（「Ctrl+O」）；在 Mac 上，{{key:Mod+O}} 同樣有效。

在較矮的視窗中（例如顯示縮放比例為 125% 以上的筆記型電腦），工具列絕不會占用圖形的位置：當圖形可用的高度太少時，按鈕會省略圖示下方的文字與群組名稱（將指標停在按鈕上可看到名稱）；若仍然不夠，工具列會變成可左右捲動的單列。視窗變高之後，文字便會回來。

## 左側面板

左側的面板有三個區段。

- **{{ui:圖層}}。** 圖形中的每個圖層，目前圖層以實心圓點標示。按一下名稱可將該圖層設為目前圖層。每一列有色彩樣本（按一下可選擇色彩）與四個按鈕：開／關（眼睛）、凍結（雪花）、鎖定（掛鎖）與列印（印表機）。{{ui:新圖層}} 會開啟方塊以新增圖層。參閱[以圖層整理圖形](topic:layers)。
- **{{ui:區塊}}。** 圖形中定義的區塊、每個區塊的使用次數，以及每個區塊的 {{ui:插入}} 按鈕。參閱[建立與插入區塊](topic:blocks)。
- **{{ui:圖形}}。** 已開啟檔案的資訊：名稱（有尚未儲存的編輯時附上「（已變更）」）、格式、大小、單位，以及物件、圖層、區塊與圖紙的數量。開啟檔案後，「關於此檔案」方塊會列出 CadCraft 無法顯示或必須轉換的任何內容。

## 繪圖區

畫面中間是圖形。指標是十字準星。CadCraft 需要點時，小標記與標籤（「端點」、「中點」）會顯示物件鎖點將落在何處。需要物件時，十字準星帶有選取方塊，其下的物件會亮起。

圖形為空時，會有「開始繪圖」卡片顯示幾個最初的指令。一執行指令或開啟檔案，它便會消失。可以將 DWG 或 DXF 檔案放到此區域的任何位置來開啟。

## 圖形下方的索引標籤

圖形下方是索引標籤：先是 {{ui:模型}}，接著是 {{ui:3D}}，然後是每張圖紙（配置）各一個索引標籤，最後是 {{ui:+}} 按鈕。

- {{ui:模型}} 是圖形本身，以實際大小、圖形單位呈現。
- {{ui:3D}} 顯示平放在地面上的圖形，以及由它建立的實體。顯示時，工具列會以 {{ui:3D}} 群組取代圖形群組。參閱[以 3D 建模](topic:3d-solids)。
- 每個圖紙索引標籤是一張紙，含標題欄與通往模型的視埠。在那裡繪製的內容使用圖紙單位（公釐或英寸）。在視埠內按兩下，即可透過它處理模型（參閱[透過視埠處理模型](topic:sheets-and-viewports#work-on-the-model-through-a-viewport)）。過長的圖紙名稱在索引標籤上會被截短；將指標停在索引標籤上可看到完整名稱。圖紙很多時，{{ui:設定}} › {{ui:CadCraft}} › {{ui:圖紙索引標籤}} › {{ui:僅顯示圖紙編號}} 會在索引標籤上只顯示每張圖紙的編號（A-101）。
- {{ui:+}} 會建立含圖框、標題欄與一個視埠的新圖紙。與 {{cmd:LAYOUT}} 指令相同。
- 在圖紙索引標籤上按兩下可重新命名。索引標籤取得焦點時，{{key:Left}} 與 {{key:Right}} 可在索引標籤之間移動。

每個索引標籤各自保留自己的縮放與平移。參閱[設定圖紙](topic:sheets-and-viewports)。

## 右側面板：屬性

右側的面板會隨選取的內容而改變。

- **未選取任何物件，位於 {{ui:模型}} 索引標籤：**標題為 {{ui:目前設定}}。在這裡設定新物件的 {{ui:圖層}}、{{ui:色彩}} 與 {{ui:文字高度}}、圖形的 {{ui:單位}}，以及新標註的大小（{{ui:文字高度}}、{{ui:箭頭大小}}、{{ui:小數位數}}、{{ui:整體比例}}）。
- **未選取任何物件，位於圖紙上：**標題為「圖紙：」加上圖紙名稱。可以重新命名圖紙、變更其 {{ui:紙張}} 與 {{ui:方向}}、{{ui:列印此圖紙}} 或 {{ui:刪除此圖紙}}。下方接著是新物件的設定。
- **選取一個物件：**以其類型為標題（直線、圓、文字、標註、視埠……），接著是其圖層、色彩與幾何。輸入新值並按 {{key:Enter}} 即可變更。
- **選取多個物件：**顯示數量，以及它們共同的 {{ui:圖層}} 與 {{ui:色彩}}。變更任一項會變更全部。「不同」表示它們各不相同。

參閱[以夾點與屬性編輯](topic:grips-and-properties)。

其下，選擇 {{ui:參數}} 或輸入 {{cmd:PARAMETERS}} 時會開啟 {{ui:參數}} 面板：在一張表格中列出每個參數與標註限制條件。參閱[使用參數與方程式](topic:parameters)。

## 指令列

底部是指令列：上方是所做操作的歷程，其下是提示。

- 沒有指令執行時，提示標籤顯示 `Command:`。指令執行時，它會顯示問題、方括號中的選項與角括號中的預設值，例如 `Specify radius of circle [Diameter] <500>:`。
- 輸入指令名稱時，右側的提示會建議相符的指令。按 {{key:Tab}} 可接受第一個。「無此指令」表示沒有任何相符項。
- {{key:Up}} 與 {{key:Down}} 可叫回先前輸入的行。
- 歷程保留最後 400 行。指令的訊息、{{cmd:DIST}} 與 {{cmd:LIST}} 的量測結果，以及儲存與列印的報告都會顯示在這裡。

## 狀態列

最底下的一列是狀態列。

- 左側的**座標**：十字準星的 X 與 Y。指令有基點時，還會顯示從基點起算的距離與角度，例如 `Δ 1200 < 90°`。
- 中間的**訊息**，例如「正交已開啟」或「目前圖層：Walls」。它們會在幾秒後淡出。
- 右側的 **{{ui:格點}}**、**{{ui:正交}}**、**{{ui:極軸}}**、**{{ui:鎖點}}**、**{{ui:追蹤}}**、**{{ui:動態}}** 與 **{{ui:LWT}}**。每一個都是切換開關；按下的按鈕表示開啟。{{ui:LWT}} 在畫面上顯示線寬（參閱[線寬與線型](topic:units-papers-scales#line-weights-and-linetypes)）。{{ui:鎖點}} 旁的小箭頭會開啟 {{ui:物件鎖點}}，在那裡勾選要啟用哪些鎖點。參閱[鎖點到物件上的點](topic:object-snaps)。

## 列印為 PDF 對話方塊

{{ui:列印}}（或 {{key:Mod+P}}）會開啟 {{ui:列印為 PDF}} 對話方塊，左側是設定，右側是即時預覽。參閱[列印為 PDF](topic:plot-pdf)。

## 說明

{{key:F1}} 或 {{ui:說明}} 按鈕會以側面板開啟本說明；圖形在旁邊仍可使用。無需連線也可使用。再按一次 {{key:F1}}，或在面板內按 {{key:Esc}}，即可關閉。參閱[使用本說明](common:help)。
