若曾使用 AutoCAD，或使用基於相同模型的程式，大部分熟悉的操作在此都可以使用：指令列、`L`、`C`、`TR` 與 `O` 等別名、按 Enter 或 Space 重複指令、視窗與交叉選取、F3 物件鎖點、F8 正交、搭配配置與視埠的模型空間。本頁列出可直接對應的項目，接著列出容易造成困擾的差異。即使只略讀前半部，也請閱讀後半部。

## 可直接對應的項目

| 習慣 | 在 CadCraft 中 |
|---|---|
| `L`、`PL`、`C`、`A`、`REC`、`POL`、`EL`、`PO`、`T`、`DT` | 指令相同，別名相同 |
| `M`、`CO`、`RO`、`SC`、`MI`、`O`、`TR`、`EX`、`F`、`X`、`E` | 相同 |
| `DLI`、`DAL`、`DAN`、`DRA`、`DDI`、`DCO`、`DBA` | 標註指令相同 |
| 在指令列輸入 `DIMSCALE`、`DIMTXT`、`DIMASZ`、`DIMDEC`、`DIMGAP`、`DIMEXE`、`DIMEXO` | 相同，適用於新標註 |
| `B` 建立區塊、`I` 插入、`PU` 清除 | 相同（清除僅移除未使用的區塊） |
| `LAYOUT`、`MV`、`PLOT`、`DI`、`ID`、`LI`、`Z` 接 `E` 或 `W` | 相同 |
| 從腳本或習慣輸入 `_LINE` 或 `-LAYER` | 開頭的 `_`、`-`、`.` 或 `'` 會被忽略 |
| 在空白提示時按 Enter 或 Space | 重複上一個指令，相同 |
| Esc 取消；再按一次 Esc 清除選取 | 相同 |
| `@dx,dy`、`@d<a`，以及從東方逆時針輸入角度 | 相同 |
| 由左至右為視窗，由右至左為交叉，點擊兩下；按住拖曳為套索，Space 在視窗／交叉／圍籬之間切換（LASSOMODE） | 相同 |
| 先選取，後執行指令（名詞－動詞） | 相同；完成的指令會清除選取 |
| 在選取物件提示中輸入 `ALL` 與 `L` | 相同 |
| Shift+點選會從選取中移除 | 相同。設定可讓點選改為取代選取，如同 PICKADD 0：請參閱[CadCraft 設定](topic:settings) |
| Ctrl+C、Ctrl+X、Ctrl+V、Ctrl+Shift+V（COPYCLIP、CUTCLIP、PASTECLIP、PASTEORIG），COPYBASE | 指令與按鍵相同；貼上時會以左下角定位副本，如同 PASTECLIP |
| F3 物件鎖點、F7 格點、F8 正交 | 按鍵相同 |
| 在滾輪上按兩下以縮放至範圍 | 相同 |
| 鏡像文字仍可閱讀 | 相同（如同 MIRRTEXT 0） |
| Ctrl+Z、Ctrl+Y、Ctrl+S、Ctrl+O、Ctrl+P、Ctrl+A | 相同；在 Mac 上也可使用 Command 鍵 |

## 容易造成困擾的差異

### 輸入的點為絕對座標

開啟動態輸入時，其他程式會將第二點輸入的 `100,0` 視為相對座標。**CadCraft 的指令列則不會：**在此，`x,y` 永遠以原點量測。開啟{{ui:動態}}（{{key:F12}}）時，請改用其欄位：距離、{{key:Tab}}、角度。若要表示「上一點右方 100」，請使用 `@100,0`，或將十字游標移至正確方向後輸入單一 `100`。

### Shift 略過鎖點，但不會開啟正交

點選時按住 Shift，會忽略該次點選的物件鎖點。它不會暫時切換正交。請使用 F8 或{{ui:正交}}按鈕。

### 右鍵一律為 Enter

沒有右鍵功能表。在圖形中按右鍵即為 Enter：會結束指令、完成選取，或重複上一個指令。在夾點移動或選取框進行中，右鍵則改為取消。以右鍵拖曳即可平移。

### 無法以空白鍵平移

空白鍵即為 Enter，因此按住空白鍵拖曳不會平移。請使用中鍵或右鍵平移，或以滾輪縮小後，在其他位置再放大。

### 修剪與延伸

修剪與延伸以快速模式啟動：每個可見物件都是剪切邊或邊界，指標下的片段會顯示將被移除的部分，拖曳的路徑會修剪其經過的每個片段，而未與任何物件交叉的物件會被刪除。{{key:Shift}} 可在修剪與延伸之間切換。`O` 切換至標準模式（需先選取邊界），`F` 與 `C` 分別為圍籬與交叉，`E` 為 EDGEMODE，`R` 為刪除。沒有 `P`（投影）選項：CadCraft 會在圖形平面中修剪。

### 圓角與倒角

{{cmd:FILLET}} 與 {{cmd:CHAMFER}} 提供熟悉的選項：放棄(U)、聚合線(P)、半徑(R)（或距離(D)、角度(A)與方法(E)）、修剪(T)與多個(M)，並可按住 {{key:Shift}} 點選以建立銳角。聚合線與直線之間的圓角會將圓弧加入為獨立物件，而不會合併到聚合線中；與圓弧段相鄰的聚合線角點則維持不變。

### 段落文字與單行文字

`T`、`MT` 與 `MTEXT` 為就地輸入的段落文字，可設定寬度、行距與對齊；`DT` 與 `DTEXT` 為單行文字，與熟悉的用法相同。目前沒有文字樣式或欄位，且尚無法在文字中輸入格式（粗體、堆疊分數）；從檔案帶入的格式會被保留、繪製並儲存（請參閱[新增文字與標註](topic:text#formatting-inside-paragraph-text-from-other-programs)）。所有文字皆以類似 Helvetica 的字型繪製。

### 儲存即為「下載副本」

{{key:Mod+S}}、`SAVE` 與 `QSAVE` 會以圖形的格式下載一份副本：開啟的 DWG 會儲存為 DWG，DXF 則儲存為 DXF。在瀏覽器中不會原地覆寫任何檔案，已開啟的檔案也絕不會被變更。在 CadCraft Studio 中，{{key:Mod+S}} 會寫回所開啟的檔案。

`SAVEAS`（{{key:Mod+Shift+S}}）為小型對話方塊，而非檔案瀏覽器：選擇{{ui:DWG}}（及其{{ui:版本}}，AutoCAD 2000 至 2018）、{{ui:DXF R12}}或{{ui:DXF 2000}}，然後按一下{{ui:儲存}}。下載位置由瀏覽器決定。`DXFOUT` 一律下載 DXF R12。

開啟的 DWG 會以其原有版本儲存；新圖形除非另行選擇，否則以 AutoCAD 2000 格式儲存。配置、標註與填滿圖案皆會保留。請參閱[檔案：可開啟與可儲存的格式](topic:files#saving)。

### 圖層：較簡單

- 每項圖層變更（開啟、凍結、鎖定、色彩、列印、線型、線寬、目前圖層）都是一個復原步驟。
- 在 CadCraft 中，關閉與凍結的效果相同。
- 圖形在某一視埠中凍結的圖層，會在該視埠中保持凍結：包括螢幕顯示、列印，以及另存為 DWG 或 DXF 時。
- 若視埠以自身的色彩、線型、線寬或透明度顯示某圖層，則會在螢幕、列印及儲存的 DWG 中維持該設定（DXF 則保留圖層本身的設定；儲存時會提示）。目前尚未實作依視埠變更這些設定。
- 沒有圖層屬性管理員，也沒有圖層狀態；{{cmd:RENAME}}、{{cmd:LAYMRG}} 與 {{cmd:LAYDEL}} 分別用於重新命名、合併與刪除圖層。線型與線寬在右側面板中設定（請參閱[線寬與線型](topic:units-papers-scales#line-weights-and-linetypes)）；{{cmd:LAYISO}}、{{cmd:LAYOFF}}、{{cmd:LAYFRZ}} 與 {{cmd:LAYMCUR}} 則以點選方式運作。
- 儲存為 DXF R12 時，圖層名稱會寫成大寫。DWG 則保留輸入時的大小寫。

### 標註樣式

`DIMSTYLE` 會開啟已命名樣式的管理員（新增、修改、設為目前、比較、套用）。`DIMSCALE` 及其他設定仍會改變新標註所使用的數值，且每個標註都保有自己的尺寸，也可在屬性面板中變更。目前樣式不會儲存於檔案中。標註會依圖形的長度格式（小數，或以 {{cmd:UNITS}} 設定的英尺與英寸）或其自身的{{ui:格式}}顯示。請參閱[設定標註尺寸](topic:dimension-settings)。

### 列印較簡單

列印樣式表依色彩運作，與 CTB 檔案相同：內建單色、彩色與灰階，也可以自行建立，且每個配置都保留其表格。讀取 CTB 檔案是依據公開的規格建置，且僅在我們製作的檔案上測試過；具名列印樣式表（STB）與頁面設定目前尚未實作。線條以其線寬列印，其他物件則以一個筆寬列印。配置以 1:1 列印於其自身的圖紙上；模型則以選定比例或符合頁面列印。請參閱[列印為 PDF](topic:plot-pdf)。

### 在視埠內工作

與熟悉的操作相同：在視埠內按兩下（或輸入 {{cmd:MSPACE}}）即可透過視埠編輯模型，在視埠外按兩下（或輸入 {{cmd:PSPACE}}）則返回配置。在視埠內平移與縮放會改變視埠所顯示的內容，除非其顯示已鎖定；此時則會移動配置。按一下圖形下方的索引標籤也會離開視埠。請參閱[透過視埠編輯模型](topic:sheets-and-viewports#work-on-the-model-through-a-viewport)。

### 支援追蹤與動態輸入，尚未支援格點鎖點

格點僅供檢視；點不會鎖定至格點（沒有 F9 鎖點模式）。極軸追蹤（{{key:F10}}，角度間隔以 {{cmd:POLARANG}} 設定）與物件鎖點追蹤（{{key:F11}}：停留於鎖點上即可取得）的運作方式與熟悉的相同；請參閱[鎖點至物件](topic:object-snaps#polar-tracking)。動態輸入（{{key:F12}}）會在十字游標旁顯示距離與角度（或 X 與 Y）；請參閱[座標與距離輸入](topic:coordinate-entry#dynamic-input)。

### 英尺與英寸

選擇{{ui:長度格式}}的{{ui:建築}}或{{ui:工程}}（或輸入 {{cmd:UNITS}}），並以熟悉的方式輸入長度：`12'6"`、`12'6-1/2"`。分數前應使用連字號而非空格：{{key:Space}} 即為 {{key:Enter}}。同時將{{ui:單位}}設為{{ui:英寸}}，使配置與列印可提供建築比例。此格式會保留在儲存的 DWG 與 DXF 檔案中。請參閱[英尺與英寸](topic:units-papers-scales#feet-and-inches-and-fractions)。

### 複製與貼上僅限於 CadCraft 內

{{key:Mod+C}}、{{key:Mod+X}} 與 {{key:Mod+V}} 可在同一圖形內、不同圖形之間，以及同一瀏覽器中的 CadCraft 索引標籤之間，複製、剪下與貼上物件。剪貼簿為 CadCraft 專用：無法將 CadCraft 物件貼到其他程式，也無法將其他程式的物件貼到 CadCraft。從使用其他單位的圖形貼上時不會重新縮放：之後請使用 {{cmd:SCALE}}。{{key:Mod+D}} 為跟隨指標移動的建立副本，屬於 CadCraft 的新增功能。請參閱[複製、貼上與建立副本](topic:copy-paste)。

### 無法使用的瀏覽器按鍵

網頁無法接管瀏覽器的 {{key:Mod+N}}、{{key:Mod+W}} 或 {{key:Mod+T}}：這些按鍵用於開啟與關閉視窗及索引標籤。請使用{{ui:新增}}按鈕或輸入 `NEW`。請參閱[按鍵、滑鼠與觸控板](common:keys)。
