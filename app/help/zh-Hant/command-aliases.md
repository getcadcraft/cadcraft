## 學習內容

如何為指令新增自訂簡稱，例如以 `LL` 代表 {{cmd:LINE}}，且全部保存在一個文字檔中。

## 新增別名

1. 開啟{{ui:視圖}} › {{ui:更多}} › {{ui:編輯別名…}}，或輸入 {{cmd:ALIASEDIT}} 並按 {{key:Enter}}。
2. 新增一行，依序包含別名、逗號，以及星號後的指令：

```
LL,     *LINE
```

3. 按一下{{ui:儲存}}。指令列會顯示目前使用中的別名數量。
4. 輸入 `LL` 並按 {{key:Enter}}：LINE 即會啟動。

自訂別名會優先於 CadCraft 內建的別名。若某行與內建別名同名，則以自訂的為準；刪除該行後，內建別名即會恢復。

## CadCraft 拒絕的行

編輯器會在輸入時，列出每個問題及其行號：

- 指令不存在；
- 別名本身即為某指令的名稱（`LINE, *CIRCLE` 會隱藏 LINE）；
- 該行不是 `ALIAS, *COMMAND` 格式；
- 同一別名出現在兩行（以較後面的為準）。

會在電腦上啟動程式的行（如 `NOTEPAD, START, 1, *File to edit: ,`），會被略過並附上附註：瀏覽器中的應用程式無法啟動程式。

## 從其他程式匯入別名

1. 在別名編輯器中，按一下{{ui:匯入 .pgp…}}並選擇檔案。也可以將 `.pgp` 檔案拖曳到圖形上。
2. 檢查列出的問題（CadCraft 沒有的指令會被拒絕，其餘則可正常運作）。
3. 按一下{{ui:儲存}}。

{{ui:匯出 .pgp}}會將 CadCraft 的別名與自訂別名合併為一個檔案，格式相同。

## 重新載入檔案

輸入 {{cmd:REINIT}} 並按 {{key:Enter}}，即可重新套用別名檔案。檔案保存於此瀏覽器中；桌面應用程式會將其保存於自身的資料夾，而雲端服務則會同步該檔案。

## 為任何指令設定鍵盤快速鍵

別名是輸入的；快速鍵則是按鍵。若要為指令指定自訂按鍵：

1. 按一下{{ui:視圖}} › {{ui:更多}} › {{ui:鍵盤快速鍵…}}，或輸入 `KEYS` 並按 {{key:Enter}}。
2. 按一下{{ui:按鍵}}方框並按下按鍵，例如 {{key:Alt+Shift+C}}。
3. 在{{ui:執行}}中輸入指令，並可選擇在其後輸入內容：`CIRCLE` 或 `ZOOM E`。
4. 按一下{{ui:加入}}。

按鍵需搭配 {{key:Mod}} 或 {{key:Alt}} 加上字母或數字，或使用未被占用的功能鍵（{{key:F2}}、{{key:F4}}、{{key:F5}}、{{key:F6}}、{{key:F9}}）。已被 CadCraft、應用程式或瀏覽器使用的按鍵，以及「我的工具」按鈕所使用的按鍵（請參閱[自訂按鈕](topic:my-tools)），都會被拒絕，且方框會說明原因。快速鍵保存於此瀏覽器（或桌面應用程式）中；{{ui:移除}}可刪除快速鍵。
