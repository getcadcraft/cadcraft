CadCraft 仍在開發中。本頁列出目前版本尚未提供的功能，以免花時間尋找。每一項都說明目前可改用的方法。

## 檔案與儲存

| 尚未實作 | 目前可改用的方法 |
|---|---|
| 在 AutoCAD 本身中檢查 CadCraft 的 DWG | 每個已儲存的版本都會由三個其他程式的 DWG 讀取器以及 CadCraft 讀回檢查。請參閱[DWG 保留與變更的內容](topic:files#what-a-dwg-keeps-and-changes)。 |
| 儲存比 2000 更新的 DXF | 儲存為 DXF 2000，或儲存為最高至 AutoCAD 2018 的 DWG。 |
| 在瀏覽器中覆寫已開啟的檔案 | 每次儲存都會下載新的副本；若想取代舊檔，請自行替換。在 CadCraft Studio 中，{{key:Mod+S}}會寫回已開啟的檔案。 |
| 電腦之間的雲端儲存與同步 | CadCraft 尚未將儲存內容傳送到雲端：請將 DWG 與 DXF 檔案保存在自己的資料夾中。在 CadCraft Studio 中，[歷程記錄](topic:history)會列出從其他地方儲存的圖形之雲端版本，以及本機電腦上已儲存的副本。 |
| 覆疊參考與在原位編輯外部參考 | 將圖形附加為連結，並在變更另一份圖形後重新載入。另存為 DWG 時連結仍保持為連結，{{cmd:XCLIP}}可裁剪連結。 |
| DXF 中的影像；會遮住其下方內容的遮罩 | DXF 會以影像外框加上檔案名稱保存影像；DWG 則保留為影像，請參閱[圖形中的影像](topic:pictures)。遮罩會顯示為其外框。 |
| 編輯具彎曲引線的多重引線，或引線位於內容兩側，或區塊以不均勻方式旋轉或縮放的多重引線 | 它們會以另一程式繪製的方式呈現，並且一起移動。具直線引線指向單一落點，且內容為文字或區塊的多重引線則可編輯（{{cmd:MLEADEREDIT}}）。 |
| 其他程式表格中：儲存區塊的儲存格、儲存格內的文字格式、DXF 表格每個儲存格的框線與顏色，或分割為欄的表格 | 表格會以可編輯表格（{{cmd:TABLEDIT}}）開啟，在編輯前依其他程式的繪製方式顯示；之後 CadCraft 會依其儲存格重新繪製：純文字、如`=G3*H3`與`=Sum(I3:I9)`的公式、對齊方式與文字高度。區塊儲存格則會變為空白。未修改的 DWG 表格會依其原始儲存格資料儲存。 |
| 已儲存 DXF 中的實際表格物件 | DWG 會將表格保存為其他程式可編輯的表格。DXF 會將其保存為繪製該表格的區塊，並附上 CadCraft 自己的記錄：CadCraft 會將其重新開啟為表格；其他程式則只看到區塊。在 DWG 中，鏡像或不均勻縮放的表格也會以此方式儲存。 |
| 與其他程式的複製與貼上 | CadCraft 的剪貼簿僅能在同一瀏覽器中的 CadCraft 圖形與索引標籤之間使用，無法與其他程式互通。請另存為 DWG 或 DXF，再於該程式中開啟。請參閱[複製、貼上與建立副本](topic:copy-paste)。 |

## 繪圖與編輯

| 尚未實作 | 目前可改用的方法 |
|---|---|
| CadCraft 沒有的填滿圖案，以及其他程式精確繪製的漸層填滿 | 開啟的填滿若使用 CadCraft 沒有的圖案，會以色調顯示。漸層填滿（{{cmd:GRADIENT}}）會依各類型以 CadCraft 自己的方式繪製：在類型上與其他程式相似，但並非逐點相同。DWG 2004 及更新版本會將其保留為真正的漸層填滿；在 DXF 2000 或 DWG 2000 檔案中，只有 CadCraft 能讀回，其他程式會看到實心填滿。圖案可從`.pat`檔載入，填滿也可連結至其邊界並隨之移動：請參閱[填滿與填滿區域](topic:hatch)。 |
| 含有形狀或文字的線型，以及儲存 DXF R12 中的線寬 | 檔案線型中的形狀與文字會被略去，不納入虛線；若要保留線寬，請另存為 DWG。 |
| 已儲存 DXF 中的圖案填滿 | R12 沒有填滿功能：這些填滿會以其外框儲存。若要保留圖案，請另存為 DWG。 |
| 其他程式製作或可編輯的陣列；路徑與環形陣列中的列與層；跟隨路徑曲線的陣列 | 以 ASsociative 方式製作的陣列（{{cmd:ARRAY}}、{{cmd:ARRAYPATH}}；以{{cmd:ARRAYEDIT}}變更）會以區塊參照儲存，並附上 CadCraft 自己的數值：其他程式可顯示、移動、列印與分解，但無法變更其數量；在其他程式中製作的陣列開啟後則為一般區塊參照。路徑陣列會保留一份路徑副本：之後編輯曲線不會移動項目。 |
| 與其他程式互通的已裁剪配置視埠 | 以{{cmd:VPCLIP}}裁剪，或以{{cmd:MVIEW}}的多邊形（Polygonal）或物件（Object）選項製作的視埠，會以 CadCraft 自己的外框儲存：其他程式會將其開為包圍它的矩形，而在其他程式中裁剪的視埠開啟後則為其矩形。DXF R12 只保留矩形。 |
| {{cmd:STRETCH}}搭配交叉多邊形 | 請使用一個或多個交叉視窗。 |
| {{cmd:PEDIT}}編輯頂點（指令列上一次一個頂點） | 夾點，以及「屬性」面板中的頂點瀏覽器（每個頂點、其寬度與凸度）。PEDIT 的其餘功能均已實作：請參閱[雲形線與聚合線](topic:splines)。 |
| 橢圓與雲形線上的{{cmd:BREAK}}、{{cmd:LENGTHEN}}、{{cmd:OFFSET}}、{{cmd:TRIM}}、{{cmd:EXTEND}}、{{cmd:FILLET}}與{{cmd:JOIN}} | 先以{{cmd:EXPLODE}}分解雲形線（或以{{cmd:PEDIT}}處理），取得這些指令可用的聚合線。 |
| 聚合線圓弧段與相鄰線段之間的圓角與倒角；將直線倒圓角接合成聚合線 | 先以{{cmd:EXPLODE}}分解聚合線，再對各段進行圓角。圓角圓弧會成為獨立物件。 |
| 修剪與延伸：投影選項（3D），以及延伸聚合線的圓弧端點 | 在圖形平面中修剪；若是圓弧端點，請先分解聚合線或重新繪製圓弧。 |
| OLE 物件：插入、執行或編輯；顯示 DWG 中檔案所放置的 OLE 物件；中繼檔影像 | 請參閱[影像](topic:pictures#objects-from-other-programs-ole)。DXF 的物件會以其點陣圖或附有標籤的外框顯示；DWG 的物件會被保留，但不會在原位繪製（OLELIST 會列出這些物件，並在指定的位置放置一份影像副本）。 |
| 在段落文字中輸入格式代碼（粗體、堆疊分數、每個字的顏色）；Helvetica 風格字型以外的字型；分欄 | 檔案中已有的格式會被保留、繪製並儲存（請參閱文字）；新的段落文字則只有一種高度與顏色。 |
| 在段落文字的旋轉角度下編輯 | 編輯器會以水平方式開啟；文字保持其旋轉角度。 |
| 在 DXF 中儲存為多重引線物件的多重引線 | DWG 會將其保留為多重引線，包含每條引線與作為內容的區塊；DXF 則保留其繪製的內容（直線、箭頭以及文字或區塊）。 |
| 表格（{{cmd:TABLE}}）中：儲存格內自動換行的文字、分成多個部分的表格、對話方塊中表格樣式自有的文字樣式與各列類型的顏色、與試算表檔案（`.xlsx`）的資料連結，或自行讀取檔案的資料連結 | 儲存格的文字只會在手動換行的位置斷開（{{key:Alt+Enter}}）；請加寬欄位。{{cmd:DATALINK}}會讀取`.csv`檔案，{{cmd:DATALINKUPDATE}}會要求重新選擇檔案。{{cmd:DATAEXTRACTION}}與{{cmd:COUNTTABLE}}所製作的表格不會自動跟隨圖形：請重新執行（即時計數：{{cmd:BOMTABLE}}）。 |
| 儲存檔案時獨立保存的屬性定義（區塊外），多行屬性 | 儲存前請將屬性定義放入區塊中：若獨立存在，儲存後會成為顯示標記的文字。 |
| 儲存檔案中的圖層狀態（儲存與還原哪些圖層開啟） | 使用{{cmd:LAYISO}}／{{cmd:LAYUNISO}}，或手動開啟與關閉圖層。 |
| 視窗多邊形與交叉多邊形選取，以及已儲存的選取過濾器 | 圍籬（`F`）、視窗、交叉、移除（`R`），以及依規則使用{{cmd:QSELECT}}。 |

## 屬性面板

| 尚未實作 | 目前可改用的方法 |
|---|---|
| 繪製 Fit 選項，以及除線性與對齊標註以外的標註之水平文字位置及線下文字 | 這些設定會保留在物件上，並在屬性中顯示且會被儲存；CadCraft 依其自身規則放置文字。 |
| 其他程式可看到的材質 | 已儲存的檔案會為 CadCraft 保留材質名稱；其他程式則顯示圖層的材質。 |
| DWG 2000 與 DXF 檔案中的透明度 | 其他程式會將這些物件顯示為實心；CadCraft 會保留透明度。若要讓所有人都能看到，請另存為 DWG 2004 或更新版本。 |
| 在其他程式中製作的填滿連結 | CadCraft 會以 DWG 與 DXF 2000 檔案儲存其自己的連結；其他程式製作的連結不會被讀取。請使用`HATCHEDIT`並選擇連結：請參閱[填滿與填滿區域](topic:hatch)。 |
| 屬性中 UCS 的座標 | 屬性顯示世界座標；狀態列與{{cmd:ID}}顯示 UCS 座標。請參閱[旋轉檢視與使用自訂座標](topic:ucs-and-turned-view)。 |
| 註解性物件在每一個比例下的獨立位置；讀取其他程式保存的各比例記錄 | 註解性文字或標註會保留一份比例清單（{{cmd:OBJECTSCALE}}），每個視埠會以其比例對應的大小、在同一位置顯示該物件。此清單會以 CadCraft 自己的資料儲存：其他程式只會看到該物件為其所設定的一個比例；在其他程式中製作的清單則不會被讀取。請參閱[單位、圖紙與比例](topic:units-papers-scales#annotate-by-scale)。 |
| 變更動態區塊的距離、角度或翻轉；另存為其他 DWG 版本或 DXF 時仍保持動態的動態區塊 | 在「屬性」› {{ui:自訂}}中切換其可見性狀態；其他數值會以唯讀方式顯示。以圖形原本的版本另存為 DWG 時，它仍保持動態。請參閱[動態區塊](topic:dynamic-blocks)。 |
| 雲形線的擬合容差、6 次及以上的雲形線、3D 雲形線 | 擬合點與控制點、1 至 5 次的次數與權重已實作：請參閱[雲形線與聚合線](topic:splines)。雲形線的高度（Z）不會被保留。 |

## 精確輔助工具

| 尚未實作 | 目前可改用的方法 |
|---|---|
| 跨指令的點追蹤，以及追蹤設定對話方塊（相對極座標角度、額外角度） | {{cmd:POLARANG}}設定步長；在下一個指令中重新取得點。 |
| 鎖點至格點 | 請輸入座標；格點僅為視覺參考。 |
| 選取區域角點時的圓弧與長度選項，以及 MEASUREGEOM 體積 | 以{{cmd:PLINE}}繪製輪廓（包含圓弧），然後使用{{cmd:AREA}}`O`。 |
| 夾點的動態輸入，及其選項清單（下箭頭） | 指令列會顯示選項。 |
| 度分秒、百分度或測量方位角 | 輸入十進位角度：例如`30.5`代表 30°30'。 |
| 檢視管理員對話方塊；圖紙上的命名檢視會回到該圖紙 | {{cmd:NAMEDVIEW}}可列出並還原檢視。已儲存的檔案會保留這些檢視，但圖紙的檢視會回到第一張圖紙。 |

## 配置、標註與列印

| 尚未實作 | 目前可改用的方法 |
|---|---|
| 視埠比例、具名物件（如圖層或區塊）、超連結，以及除圖紙編號與名稱以外的圖紙集欄位；以欄位物件形式寫入、由其他程式更新的欄位 | {{cmd:FIELD}}提供日期、檔案名稱、圖紙編號、名稱與數量、圖形特性（{{cmd:DWGPROPS}}）、物件的面積、長度與其他特性，以及文字、屬性與表格儲存格中的公式。其他程式會將 CadCraft 的欄位顯示為其上次讀取的文字；CadCraft 會讀取其他程式的日期、檔案名稱、特性、圖紙與運算式欄位，其他類型則以文字保留。視埠比例需手動輸入。 |
| 儲存目前使用的標註樣式；拖曳到任意位置的標註文字 | 圖形開啟時目前樣式為 Standard。文字會位於標註線上（DIMTEDIT Left / Right / Center）。請參閱[設定標註尺寸](topic:dimension-settings)。 |
| CadCraft 無法判斷的已開啟檔案中之可編輯雙行角度標註 | 它們會依檔案中的繪製方式顯示。序數、弧長與折彎半徑標註會開啟為可編輯的標註。 |
| CTB 讀取器與其他程式檔案的核對（已依公開規格建置）、具名列印樣式（STB）、抖動、筆號、CTB 的灰階，以及列印樣式中的自適應線型調整 | 在{{ui:列印樣式表}}中製作表格（顏色、灰階、墨水、線寬、線型、線端與接合，以及每種顏色的填滿樣式）：請參閱[列印樣式表](topic:plot-pdf#plot-style-tables)。 |
| 圖紙設定（Page setups） | 在{{ui:列印為 PDF}}對話方塊中選擇紙張、比例與列印樣式；圖紙會保留其列印樣式。 |
| 需要複雜字形處理的印地文及其他文字，以及罕用的表意文字（歐洲文字、西里爾文、希臘文、希伯來文、阿拉伯文、波斯文、烏爾都文、泰文、中文、日文與韓文的列印） | 會列印為「?」。 |
| 同一份列印 PDF 中的阿拉伯文字與中文、日文或韓文文字 | 一次列印只使用一種字型：兩種文字中會有一種列印為「?」。 |
| 文字中的明確方向標記（嵌入、覆寫、隔離） | 它們會被忽略：每一行僅依其字母排序。 |
| 列印中附加 PDF 頁面內的影像 | 頁面的線條、填滿與文字會被列印。若頁面僅為影像，請以{{cmd:SCANATTACH}}載入，影像即會被列印。請參閱[PDF 底圖](topic:pdf-underlay#plot-and-save)。 |
| 從 CadCraft Studio 將工作送至雷射（Studio 沒有 Web Serial） | 儲存 G-code，並以雷射本身的程式傳送，或從 Chrome 或 Edge 傳送。請參閱[將圖形送至雷射](topic:laser-cutting#send-from-the-browser)。 |

## 限制條件與參數

| 尚未實作 | 目前可改用的方法 |
|---|---|
| 配置上、區塊中、橢圓、雲形線或文字上的限制條件 | 在{{ui:模型}}索引標籤中，對直線、聚合線、圓、圓弧及點施加限制條件。 |
| 平滑（G2），以及直接限制聚合線的圓弧凸度 | 相切與相等；圓弧段會跟隨其兩端。 |
| 參考（驅動）尺寸限制條件，以及{{cmd:DCANGULAR}}中的`3Point` | 一般標註（DIMLINEAR 等）只顯示數值，不會驅動圖形。 |
| 紙上固定尺寸的尺寸限制條件，以及其列印 | 它們僅在螢幕上顯示；若需列印，請加上一般標註。 |
| 透過 EXPLODE、BREAK、JOIN 及其他會製作新物件的指令保留限制條件，以及修剪後聚合線上的限制條件 | 請重新施加限制條件（AUTOCONSTRAIN 可協助）。{{cmd:MIRROR}}與{{cmd:TRIM}}對直線、圓弧與圓則會保留限制條件。 |
| CadCraft 中的設計表（組態） | 請在面板中變更參數。 |
| 與 SolidWorks 的完整來回測試 | 依賴巨集前，請先檢查其建立的草圖。 |

## 3D

| 尚未實作 | 目前可改用的方法 |
|---|---|
| 圓角、倒角、抽殼與放樣；沿上升路徑（3D 路徑）的掃出 | 以圓弧輪廓拉伸，推拉面，沿平面路徑旋轉與掃出。 |
| 朝向上方以外方向拉伸 | 在地面上繪製形狀，然後向上或向下拉伸（如需要，可加上錐度或沿路徑）；之後再旋轉實體。 |
| 2D 物件的高度與厚度 | 圖形平放於地面（高度 0），位於 3D 索引標籤上。 |
| 編輯其他程式的實體、區域與本體；顯示區塊內的實體；位於掃出、放樣或其他自由曲面上的面；多面體網格與多邊形網格 | 模型空間中的實體會依原樣顯示在 3D 索引標籤上，並在 DWG 中原封不動地儲存；未繪出的內容會在 3D 索引標籤開啟時列出。請以 3D 面的方式在模型空間中要求網格。請參閱[其他程式的實體](topic:3d-solids#solids-from-other-programs)。 |
| 實體的複製與貼上 | 在 3D 索引標籤中使用{{cmd:COPY}}。剪貼簿只保存 2D 物件。 |
| 剖面、會跟隨實體後續變更的檢視，以及列印圖紙上的著色實體 | {{cmd:VIEWBASE}}會放置平面檢視（快照）；變更實體後請重新執行。 |
