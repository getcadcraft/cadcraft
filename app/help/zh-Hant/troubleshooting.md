## 開啟檔案

| 訊息或現象 | 原因 | 修正方法 |
|---|---|---|
| 「CadCraft 開啟 DWG 與 DXF 圖形。「…」不是這兩種格式。」 | 檔案不是 `.dwg` 或 `.dxf`。 | 請開啟圖形檔本身。可以匯入 PDF（開啟時會詢問：匯入或附加，請見 [PDF 底圖](topic:pdf-underlay)）；圖片請使用 `IMAGEATTACH` 插入。 |
| 「此二進位 DXF 在某個物件的中途結束：檔案被截斷或已損毀。」 | 二進位 DXF 在結尾之前停止。 | 輸入 RECOVER 以開啟可讀取的內容，或重新索取檔案。 |
| 「此檔案不是可讀取的 DXF（第 … 行的群組代碼錯誤）。」 | DXF 已損毀，或其實不是 DXF。 | 重新索取檔案，或改用 DWG。 |
| 「無法讀取此圖形。它可能已損毀，或是以讀取器尚不支援的版本儲存（…）。」 | DWG 讀取器無法讀取它。 | 索取較舊版本儲存的 DWG，或 DXF。 |
| 「此圖形來自 AutoCAD R11／R12（DWG AC1009），比 CadCraft 可讀取的版本更舊 …」 | Release 12 及更早版本的 DWG 使用 CadCraft 不支援讀取的格式。 | 在製作該檔案的程式中，將其另存為 DXF（任一版本）或較新的 DWG，然後開啟。CadCraft 自己的「另存新檔」為需要舊格式的程式提供 DXF R12。 |
| 「無法開啟 …」，後接網路訊息，出現在第一個 DWG | 無法下載 DWG 讀取器：你處於離線狀態，且 CadCraft 未儲存供離線使用，或連線中斷。 | 連線後重試，或開啟 DXF。點選{{ui:儲存供離線使用}}，並等待「離線已就緒」，下次離線時 DWG 檔案即可開啟。請參閱[離線工作](common:offline)。 |
| 離線按鈕顯示「無法儲存」 | 部分檔案未能下載。 | 檢查連線，然後點選按鈕重試。 |
| 離線按鈕顯示「無法使用離線功能」 | 私密瀏覽視窗與部分受管理的電腦無法保存離線副本。 | 使用一般視窗，或保持線上。 |
| 沒有連線時 CadCraft 無法開啟 | 在此瀏覽器中未儲存供離線使用，或瀏覽器已將其清除。 | 下次連線時，點選{{ui:儲存供離線使用}}，並等待「離線已就緒」。 |
| 圖形可以開啟，但部分內容遺失 | 物件是 CadCraft 尚無法繪製的，或檔案中的圖層已關閉或凍結。 | 閱讀左側面板中的「關於此檔案」。檢查{{ui:圖層}}面板。 |
| 文字換行成兩行 | CadCraft 以類似 Helvetica 的字型繪製文字，比某些 CAD 字型寬。 | 在屬性中縮短文字，或接受多出的一行。 |
| 圓顯示為橢圓，或鏡像文字的方向正確 | 物件在製作該檔案的程式中，是繪製在傾斜平面上，或由下方檢視。CadCraft 會以由上方檢視的方式顯示，即該程式平面視圖的方式；文字保持可讀。 | 無需修正。若要以另一程式的方式查看，請要求將圖形攤平，或要求從上方繪製的物件。 |
| 區塊、圓或標註出現在製作該檔案的程式中所在位置以外的地方 | CadCraft 誤讀了某種圖形情況。 | 請在 Discord 上告訴我們，若可以分享檔案，請一併附上。 |

## 指令列

| 訊息或現象 | 原因 | 修正方法 |
|---|---|---|
| 「未知指令 "…"。輸入 HELP 以查看清單。」 | 沒有此名稱的指令或別名。 | 輸入 `HELP`，或參閱[指令參考](topic:commands)。部分常見指令[尚未實作](topic:not-built-yet)。 |
| 輸入時指令列旁顯示「沒有此指令」 | 你所輸入的內容尚未符合任何指令。 | 繼續輸入，或檢查拼字。 |
| 「需要點或選項關鍵字。」 | 你輸入的內容不是點或選項。 | 檢查格式：`x,y`、`@dx,dy`、`@d<a`，或單一數字。請參閱[座標與距離輸入](topic:coordinate-entry)。 |
| 「需要正數或兩個點。」 | 距離為負數或不是數字。 | 輸入正數，或點選兩個點。 |
| 「需要以度為單位的角度或兩個點。」 | 角度不是數字。 | 將度數以純數字輸入。 |
| 「需要數字。」 | 需要輸入數字。 | 只輸入數字。 |
| 「選項關鍵字無效。」 | 所輸入的字母與任何選項都不符。 | 輸入方括號中顯示的大寫字母。 |
| `*Cancel*` | 你按了 {{key:Esc}}，或在需要點的地方按了 {{key:Enter}}。 | 重新開始指令。 |
| 輸入的內容無法進入指令列 | 面板或對話方塊中的方塊有游標。 | 按 {{key:Enter}} 或 {{key:Esc}}，或點選圖形。 |
| 指令使用了你未選取的物件 | 在開始指令前已選取它們。 | 在執行指令前按 {{key:Esc}}。 |
| 線條跑到了意料之外的地方 | `x,y` 是絕對座標。 | 使用 `@dx,dy` 表示相對點。 |
| 「請先完成或取消目前的指令（Esc）。」 | 你在指令執行中按了 {{key:Mod+S}}。 | 按 {{key:Esc}}，然後儲存。 |
| 「無法另存為 DWG（AutoCAD 2000）：… 請嘗試另存新檔，然後選 DXF。」 | 圖形中有內容無法寫成 DWG。 | 按 {{key:Mod+Shift+S}}，選擇{{ui:DXF R12}}，然後點選{{ui:儲存}}。 |
| 「未儲存。」 | 你以{{ui:取消}}或 {{key:Esc}} 關閉了{{ui:另存副本為}}對話方塊。 | 再次按 {{key:Mod+Shift+S}}，然後點選{{ui:儲存}}。 |

## 編輯

| 訊息或現象 | 原因 | 修正方法 |
|---|---|---|
| 物件無法選取 | 其圖層已鎖定、關閉或凍結；或你位於配置上，而它是視埠內的模型。 | 解除圖層鎖定，或前往{{ui:模型}}索引標籤。 |
| 「該處沒有找到任何內容。」 | 點選處沒有物件。 | 放大並點選線條本身。 |
| 「該處沒有任何物件與該物件交叉。」 | {{cmd:TRIM}} 未找到與你所選部分交叉的物件。 | 確認剪切線確實與它交叉。 |
| 「無法修剪該物件。」 | 修剪僅適用於線、圓弧、圓與聚合線。 | 先分解區塊，或刪除後重新繪製。 |
| 「該方向沒有邊界。」 | {{cmd:EXTEND}} 找不到可接合的對象。 | 請點選靠近應該延長那一端的位置。 |
| 「無法偏移該物件。」 | 偏移僅適用於線、圓弧、圓與聚合線。 | 先將其分解，或繪製平行線。 |
| 「偏移距離太遠。」 | 偏移會使形狀翻轉。 | 使用較小的距離。 |
| 「半徑太大。」或「距離太大。」 | 圓角或倒角會超出線條的末端。 | 以 `R` 設定較小的半徑，或以 `D` 設定較小的距離。 |
| 「只能修剪開放聚合線的第一段或最後一段。」 | 轉角會切入聚合線的中間。 | 選取聚合線中相鄰的兩段，或對每個轉角使用 `P`。 |
| 「請選取第二條不同的線。」 | 第二次選取的是同一條線，或不是線。 | 選取另一條線。 |
| 「只有聚合線、區塊參照與標註可以分解。」 | 所選內容中沒有可分解的項目。 | 選取聚合線、區塊參照或標註。 |
| 「這是目前圖層。請先將另一個圖層設為目前。」 | 你嘗試關閉目前圖層。 | 點選另一個圖層的名稱，然後關閉此圖層。 |
| 「已有名為 … 的圖層」 | 圖層名稱必須唯一。 | 選擇其他名稱。 |
| 「沒有可復原的內容。」 | 沒有剩餘可復原的項目，或你開啟或開始了新圖形（這會清除歷程）。 | — |

## 標註與區塊

| 訊息或現象 | 原因 | 修正方法 |
|---|---|---|
| 標註文字與箭頭非常小或非常大 | 尺寸以繪圖單位計；整體比例與圖形不符。 | 將{{cmd:DIMSCALE}}設為列印比例；請參閱[設定標註尺寸](topic:dimension-settings)。 |
| 「請點選要量測角度內的一點。」 | 角度標註的位置位於某一條邊上。 | 點選角度內部。 |
| 「這些線條平行。」 | 平行線之間沒有角度。 | 選取兩條相交的線。 |
| 「請選取線性或對齊標註。」 | {{cmd:DIMCONTINUE}} 或 {{cmd:DIMBASELINE}} 需要以它為起點。 | 選取線性或對齊標註。 |
| 「此圖形尚無區塊：F 會從檔案插入，L 會從程式庫插入 …」 | 圖形沒有屬於自己的區塊。 | 輸入 `F` 或 `L`，或使用 {{cmd:BLOCK}} 建立區塊。 |
| 「沒有名為 "…" 的區塊。」 | 名稱錯誤。 | 訊息會列出現有的區塊。 |
| 「區塊名稱不可以 * 開頭，或使用 …」後接字元清單 | 名稱包含區塊不可使用的字元。 | 使用字母、數字、`-` 與 `_`。 |
| 「區塊不能包含自己。」 | 所選內容包含對正在建立之區塊的參照。 | 將該參照排除在外。 |
| 「未選取任何物件，未建立。」 | 你在選取前按了 {{key:Enter}}。 | 重新執行 {{cmd:BLOCK}} 並選取物件。 |

## 配置與列印

| 訊息或現象 | 原因 | 修正方法 |
|---|---|---|
| 「視埠要放在配置上。請先開啟配置索引標籤（或使用 LAYOUT 建立一個）。」 | 在{{ui:模型}}索引標籤上執行 {{cmd:MVIEW}}。 | 先點選配置索引標籤。 |
| 「請先在視埠中開啟配置。」 | 在{{ui:模型}}索引標籤上執行 {{cmd:VPVIEW}}。 | 先點選配置索引標籤。 |
| 視埠比例看起來錯了十倍 | 圖形單位錯誤。 | 在{{ui:目前設定}}中設定{{ui:單位}}。 |
| 「尚無可列印的內容。」 | 模型是空的。 | 繪製一些內容，或開啟圖形。 |
| 「請選取要列印的視窗。」 | 已選擇{{ui:一個視窗…}}，但未選取視窗。 | 點選{{ui:選取}}，然後點選兩個角落。 |
| 「…比紙張大：邊緣被切掉。」 | 在該比例下，範圍無法放入。 | 選擇較小的比例、較大的紙張，或{{ui:符合紙張}}。 |
| 「瀏覽器已封鎖新分頁，因此改為下載 PDF。」 | 網站已封鎖彈出式視窗。 | 開啟已下載的 PDF，或允許此網站的彈出式視窗。 |
| 字元以「?」列印 | PDF 的字型沒有這些字元的字母（罕見的表意文字、印地文及其他需要複雜字形處理的文字…），或無法下載較大的字型（離線）。歐洲文字、西里爾字母、希臘字母、希伯來文、阿拉伯文、波斯文、烏爾都文、泰文、中文、日文與韓文會以原樣列印。 | 阿拉伯字母系、泰文、中文、日文或韓文，請在連線狀態下重新列印。其他文字尚未實作。 |
| 構造線出現在 PDF 中 | 其圖層會被列印。 | 點選該圖層的列印按鈕。 |
| 所有線條粗細相同 | 其線寬為{{ui:預設值}}，因此會以對話方塊中的筆寬列印。 | 在右側面板中為圖層或物件設定{{ui:線寬}}，或在對話方塊中選擇{{ui:線寬}}。若要在螢幕上看見線寬，請按狀態列中的{{ui:LWT}}。 |

## 按鍵與螢幕

| 現象 | 原因 | 修正方法 |
|---|---|---|
| F3、F7 或 F8 改變音量或開啟 Mission Control | Mac 的功能鍵。 | 按住 **fn**，或使用狀態列按鈕。請參閱[按鍵、滑鼠與觸控板](common:keys)。 |
| F7 詢問是否使用瀏覽游標 | Firefox 自己使用 F7。 | 選擇「否」；改用{{ui:格點}}按鈕。 |
| {{key:Mod+N}} 開啟了瀏覽器視窗 | 瀏覽器保留了此按鍵。 | 點選{{ui:新增}}，或輸入 `NEW`。 |
| {{key:Mod+A}} 選取了指令列的文字 | 指令列有游標。 | 先點選一個物件，或在 `Select objects` 提示處輸入 `ALL`。 |
| {{key:Delete}} 無法刪除 | 指令列有游標。 | 輸入 `E` 並按 {{key:Enter}}。 |
| 在 Mac 觸控板上按右鍵沒有反應 | Control+點選可能被視為一般點選。 | 以兩指點選。 |
| 觸控板無法平移 | 沒有中鍵，且空白鍵無法平移。 | 以兩指滑動：2D 視圖會平移（捏合與滑鼠滾輪可縮放）。或按住右鍵拖曳。 |
| 第一次按 {{key:Esc}} 離開了全螢幕 | 瀏覽器使用 Esc 離開全螢幕。 | 再按一次 {{key:Esc}} 以取消指令。 |
| {{key:F1}} 在 Mac 上沒有反應 | F1 是亮度鍵。 | 按住 **fn**，或點選{{ui:說明}}。 |
| 輸入的文字進入了說明的搜尋方塊 | 說明面板有游標。 | 點選圖形。 |
| 圖形變成空白 | 你縮放得太遠。 | 點選{{ui:範圍}}，或連按兩下滾輪。 |
| 關閉分頁時出現「要離開此網站嗎？」 | 有未儲存的變更。 | 按「取消」留下，以 {{key:Mod+S}} 儲存，然後關閉。 |
