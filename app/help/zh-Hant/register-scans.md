## 你會做什麼

在同一處拍攝的多份掃描（每份都來自各自的掃描儀位置）一開始各自使用自己的座標。進行對位時，為每份掃描指定一次放置位置，讓它們全部位於同一座標系統中，接著將結果儲存為專案，並把對位後的點雲寫入一個 LAS 或 E57 檔案。

## 放置掃描

1. 開啟對話方塊（輸入 `REGISTERSCANS`（或 `REGSCAN`））。{{ui:Add scans…}} 可接受 LAS、LAZ、E57、PLY、PCD、PTX、PTS 或 XYZ 檔案，也可以將檔案拖放到對話方塊上。使用不同單位的掃描會被拒絕，並顯示注意訊息：請先轉換其中一份。
2. 選擇 {{ui:Scan to move}} 與 {{ui:Place against}}。圖片會顯示目前位於座標系統中的每份掃描，每份各以一種顏色呈現。檢視可選 {{ui:Plan}}、{{ui:Front}} 或 {{ui:Side}}；拖曳可平移，使用滾輪可縮放。
3. **依點組對位。** 按一下 {{ui:Pick a pair}}，接著在要移動的掃描上點選一點，然後在另一份掃描上點選同一位置（一個角點、一個目標、一根柱子的底部）。這樣的操作至少要做三次，所選的點不能位於同一直線上，且彼此要分散。按一下 {{ui:Place by pairs}}：掃描會以最小平方擬合的方式放置，**剩餘誤差** 會顯示每組點仍相差多少。數值很大的一組表示點選不當：以叉號將它移除，然後重新放置。
4. **依目標對位。** 若某點的真實座標已知（測量目標），按一下 {{ui:Pick, then type target}}，在其掃描上點選該點，然後在該列中輸入目標的 X、Y 與 Z。點組與輸入的目標可以任意混合使用。

## 以 ICP 精修

點組只會提供粗略的放置。{{ui:Refine}} 會移動掃描，直到其表面貼合另一份掃描的表面：先以**點對點**，然後以**點對平面**。表格列出每個步驟的誤差與相符點數；表格上方的線條顯示誤差逐步下降。{{ui:Stop}} 會在目前步驟完成後結束執行，並保留已達到的結果。{{ui:Undo}} 會取消整個執行（或最後一次放置）；{{ui:Reset}} 會將掃描還原為其檔案座標。

為了讓筆電也能快速運作，ICP 會使用抽稀後的部分點（{{ui:Points used}}，5,000至60,000），並忽略超過 {{ui:Largest match distance}} 的比對（預設為掃描大小的 5%，隨著收斂而縮小）。它需要先有粗略的放置：幾乎沒有重疊的掃描會回報無法比對。僅為平面或僅為直線的表面，無法沿其自身方向修正位置；此時請加入點組。

## 儲存與匯出

- {{ui:Save project}} 會寫入一個小型的 `.ccscans.json` 檔案：包含每份掃描的名稱、大小，以及其前 64 KB 的指紋，並附上其轉換資訊。它不包含任何點。{{ui:Open project…}} 會依這些參照找到掃描檔案（檔案必須先新增），並還原每一項轉換。
- {{ui:Export LAS}} 與 {{ui:Export E57}} 會寫入一個檔案，其中每份掃描都位於其對位後的位置。原始檔案中的點永遠不會被改寫；轉換會在輸出時套用。若開啟 {{ui:Read every point from the files}}（從檔案讀取所有點），每個檔案會為每個點重新讀取（每份掃描最多 2,000 萬點）；關閉時，則只寫入檢視器中顯示的點。
- {{ui:Show registered cloud}}（CadCraft）會寫入 LAS，並以其自身座標將它附加在圖形下方，與任何點雲相同。

:::note
不會上傳任何內容。對位會以檔案本身的單位進行，並保留毫米精度：LAS 會以能容納的比例寫入（最細至 0.1 mm），E57 則以雙精度浮點數寫入。只有當每份掃描都標示同一個 EPSG 代碼時，座標系統才會帶入 LAS。E57 寫入器為我們自行開發；其檔案已以本讀取器與 libE57Format 讀回驗證。
:::
