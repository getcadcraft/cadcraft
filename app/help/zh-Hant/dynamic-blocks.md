## 可用的功能

包含動態區塊的 DWG 開啟後，以下功能可以正常運作：

- **原始名稱。** 動態區塊會以其自身名稱（「Receptacle」、「Sink」）列在{{ui:區塊}}面板中，而不是以未命名的 `*U` 區塊顯示。
- **儲存時的狀態。** 每個參照都會準確顯示另一個程式所顯示的內容：設定的可見性狀態、儲存時的拉伸或翻轉。
- **切換可見性狀態。** 選取一個參照（或同一區塊的多個參照），開啟{{ui:屬性}}，並在{{ui:自訂}}區段中，從{{ui:可見性}}清單選擇另一個狀態。參照會立即顯示該狀態，其屬性也會跟著變化：被該狀態隱藏的屬性會消失，被該狀態顯示的屬性會出現並帶有其數值。參照會保留每個數值，因此不會有空白的內容；{{ui:屬性}}會列出被隱藏的項目，並標示為「隱藏」。{{key:Mod+Z}} 可在一個步驟中將舊狀態還原。
- **夾點。** 選取的動態區塊會在其參數所在位置顯示自己的夾點：可見性狀態為一個小三角形（點擊可顯示狀態清單），距離的兩端為箭頭，翻轉則為雙箭頭。目前只有可見性夾點會生效；其他夾點會在狀態列中說明。
- **其他數值，唯讀。** 在可見性清單下方，{{ui:自訂}}也會顯示圖形中區塊的距離、對齊角度、翻轉狀態與點。
- **編輯可見性狀態。** 以{{cmd:BEDIT}}開啟區塊：編輯器會顯示一個狀態，名稱顯示在圖形上方的列中（可在該處選擇另一個狀態）。輸入{{cmd:BVSTATE}}以切換、新增（隱藏全部、顯示全部或保留目前顯示的內容）、重新命名或刪除狀態；{{cmd:BVHIDE}}會在目前顯示的狀態中隱藏所選物件；{{cmd:BVSHOW}}會以淡色顯示隱藏的物件，讓你點選要還原的物件。儲存區塊時：設定為已重新命名狀態的參照會以新名稱保留該狀態，設定為已刪除狀態的參照則會顯示第一個狀態。
- **保持動態。** 以圖形原本的版本儲存為 DWG 時，區塊會保持動態，並保留你選擇的狀態：其他程式會將它們開啟為相同的動態區塊。你編輯過的可見性狀態也會一併儲存：包括新名稱、你新增的狀態，以及每個狀態所顯示的內容。

## 唯讀，或尚未實作

| 尚未實作 | 目前的替代做法 |
|---|---|
| 變更距離、角度或翻轉（拉伸、移動、翻轉動作） | 它們在{{ui:自訂}}中以唯讀方式顯示；請在建立該區塊的程式中編輯。 |
| 查閱、XY、旋轉與極座標參數 | 尚未讀取：參照會依儲存時的樣子顯示。 |
| 拖曳距離、翻轉與點夾點 | 它們會顯示參數所在的位置；可見性夾點與屬性中的{{ui:可見性}}清單可切換狀態。 |
| 建立動態區塊（新增參數，或為沒有狀態的區塊新增可見性狀態） | 你在 CadCraft 中建立的區塊是一般區塊；{{cmd:BPARAMETER}} 會說明這一點。 |
| 在區塊編輯器中，新增或刪除具有可見性狀態之區塊的物件 | 該區塊會儲存為一般區塊（編輯器在關閉時會說明）。 |
| 在其他 DWG 版本或 DXF 中保持動態 | 它們會以一般區塊儲存，並顯示你選擇的狀態，儲存時會說明此情況。 |

:::note
在{{cmd:BEDIT}}中移動或變更物件，會讓具有可見性狀態的區塊保持動態。沒有狀態的區塊，或在編輯器中新增或刪除過物件的區塊，會變成一般區塊。
:::
