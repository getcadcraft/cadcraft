## 可用的功能

一個含有動態區塊的 DWG 開啟後，以下功能可以運作：

- **真正的名稱。** 動態區塊會以自己的名稱列在 {{ui:區塊}} 面板中（「Receptacle」、「Sink」），而不是以未命名的 `*U` 區塊列出。
- **它們保存時的狀態。** 每個參照都會顯示另一個程式所顯示的確切內容：設定的可見性狀態，以及保存時的拉伸或翻轉。
- **切換可見性狀態。** 選取一個參照（或同一區塊的數個參照），開啟 {{ui:特性}}，在 {{ui:自訂}} 區段中，從 {{ui:可見性}} 清單選擇另一個狀態。參照會立即顯示該狀態，其屬性也一併切換：被該狀態隱藏的屬性會消失，被顯示的屬性則會帶著其值出現。參照會保留每個值，因此不會有空白的值；{{ui:特性}} 會列出被隱藏的項目並標示為「隱藏」。{{key:Mod+Z}} 可在一個步驟中回到原本的狀態。
- **夾點。** 選取動態區塊時，會在其參數所在處顯示自己的夾點：可見性狀態的小三角形（按一下即可列出各狀態）、距離兩端的箭頭、翻轉用的雙箭頭。目前只有可見性夾點會作用；其他夾點會在狀態列中說明。
- **其他數值，唯讀。** 在可見性清單下方，{{ui:自訂}} 也會以圖形所保存的內容顯示區塊的距離、對齊角度、翻轉狀態與點。
- **編輯可見性狀態。** 以 {{cmd:BEDIT}} 開啟區塊：編輯器會顯示一個狀態，其名稱顯示在圖形上方的列中（可在該處切換為另一個狀態）。輸入 {{cmd:BVSTATE}} 可切換、新增（隱藏全部、顯示全部，或保留目前可見的內容）、重新命名或刪除狀態；{{cmd:BVHIDE}} 會在目前可見的狀態中隱藏所選物件；{{cmd:BVSHOW}} 會以淡色顯示被隱藏的物件，讓你點選要恢復的物件。儲存區塊時，設為已重新命名狀態的參照會以新名稱保留該狀態；設為已刪除狀態的參照會顯示第一個狀態。
- **保留為動態。** 以圖形進入時的 DWG 版本保存時，區塊會維持動態，並保留你選擇的狀態；另一個程式會將它們開啟為相同的動態區塊。你編輯過的可見性狀態也會一併保存：其新名稱、你新增的狀態，以及每個狀態所顯示的內容。

## 唯讀或尚未具備的功能

| 尚未具備 | 目前的替代方式 |
|---|---|
| 變更距離、角度或翻轉（拉伸、移動、翻轉動作） | 它們在 {{ui:自訂}} 中以唯讀顯示；請在製作該區塊的程式中編輯。 |
| 查閱、XY、旋轉與極座標參數 | 尚未讀取：參照會依保存時的樣子顯示。 |
| 拖曳距離、翻轉與點的夾點 | 它們會顯示參數所在的位置；可見性夾點與 {{ui:特性}} 中的 {{ui:可見性}} 清單可切換狀態。 |
| 製作另一個程式類型的動態區塊（拉伸、翻轉、查閱） | 你在 CadCraft 中製作的區塊是一般區塊；{{cmd:BPARAMETER}} 會說明這一點。你自己的參數與多個可見性參數，位於參數管理員中（請參閱下方「你自己的參數與可見性狀態」）。 |
| 在區塊編輯器中加入或刪除具有可見性狀態之區塊的物件 | 該區塊會保存為一般區塊（編輯器在關閉時會說明）。 |
| 在另一個 DWG 版本或 DXF 中保持動態 | 它們會保存為一般區塊，並顯示你選擇的狀態；保存時會說明此情況。 |

:::note
在 {{cmd:BEDIT}} 中移動或變更物件，會使具有可見性狀態的區塊維持動態。沒有狀態的區塊，或在編輯器中加入或刪除了物件的區塊，會變成一般區塊。
:::

## 你自己的參數與可見性狀態

你在 CadCraft 中製作的區塊，可以帶有自己的參數，以及**數個**可見性參數，每個都有自己的狀態。輸入 {{cmd:BPARAMS}}（或 `BPM`），即可開啟你在 {{cmd:BEDIT}} 中正在編輯的區塊、所選參照的區塊，或你指定之區塊的**參數管理員**。

- **參數**：一個名稱、一個類型（數字、長度、角度、計數、是／否），以及一個值，或一個以其他參數構成的公式（`w * 2`、`if(n > 3, 1, 0)`）。{{ui:合計}} 會顯示結果。無法運作的公式，或不符合其類型的值（例如 1.5 個），會被拒絕，且管理員會說明原因；其他內容都不會改變。
- **可見性參數**：{{ui:新增可見性參數}} 會建立一個含有第一個狀態的參數。每個狀態都可以重新命名、移除（最後一個會保留），或指定「何時顯示」的數字。公式會依參數挑選狀態（數字符合的狀態，否則為清單中該位置的狀態）；沒有公式時，每個參照各自選擇。
- **將物件放入某狀態**：在區塊編輯器中選取物件，輸入 {{cmd:BPARAMS}}，然後在該狀態上按一下 {{ui:將所選物件放在此處}}。沒有任何可見性參數列出的物件會一直顯示。
- **此參照**：從所選參照開始時，管理員也會顯示該參照自己的數值與狀態。

在區塊編輯器之外，每一項變更都是一個復原步驟。在區塊編輯器中，變更由編輯器管理：{{ui:儲存區塊}} 會保留它們。`-BPARAMS` 會在指令列中提出相同的問題。

**在檔案中。** DWG 與 DXF 會保存參數、哪些物件屬於哪個狀態，以及每個參照自己的數值，並存放在 CadCraft 自己的記錄中；在 CadCraft 中再次開啟檔案，一切都會恢復。另一個程式會將每個參照視為包含其所有物件的區塊，因為 DWG 中每個同類區塊最多只能有一個可見性參數。被另一個程式移動的參照，或其物件被另一個程式變更的區塊，會在失去對齊的部分不被恢復（不會猜測）。
