## 從另一個圖形插入區塊

1. 輸入`I`後按{{key:Enter}}，或在{{ui:區塊}}群組中點按{{ui:插入}}。
2. 在`Enter block name or [File/Library]`提示下，輸入`F`後按{{key:Enter}}。
3. 選擇本機上的 DWG 或 DXF。檔案會在此讀取，不會開啟，也不會上傳任何內容。
4. 在{{ui:插入自}}對話方塊中，從清單選取一個區塊（在{{ui:篩選區塊}}中輸入即可搜尋），或保留{{ui:整個圖形}}。點按{{ui:插入}}。
5. 點按要放置的位置，並填入它要求的任何屬性。

整個圖形會以檔案名稱命名的單一區塊引入。你所選區塊內的區塊也會一併引入，它們所使用的圖層會加入此圖形。

若另一個圖形使用不同的單位（例如英吋與毫米），CadCraft 會縮放參照以符合，並在歷程中說明。

### 名稱已被使用時

若此圖形已有同名的區塊，CadCraft 會詢問：

- {{ui:保留現有的}}會使用此圖形中同名的區塊。
- {{ui:重新命名}}會將新的區塊以`Name (2)`的名稱引入。

整個插入是一個步驟：{{key:Mod+Z}}會同時移除參照與複製的定義。

## 開啟程式庫

點按{{ui:區塊}}面板中的{{ui:程式庫…}}，或{{ui:區塊}}群組中的{{ui:程式庫}}，或輸入`LIB`。在`INSERT`提示下，輸入`L`也能開啟。

程式庫有四個來源，以索引標籤呈現：

- {{ui:程式庫}}：CadCraft 程式庫。可依名稱、製造商或型號搜尋，並依類別篩選。
- {{ui:檔案…}}：來自任何程式庫的項目檔（`item.json`），或可用來製作項目的圖形、試算表或 3D 模型：DWG 或 DXF（每個區塊都會成為一個項目）、含名稱與尺寸欄位的 CSV，或 glTF 或 OBJ 模型。不會上傳任何內容。
- {{ui:標準}}：依已公開的表格在此製作的鋼料斷面（作為斷面、立面或 3D 構件），以及螺栓、螺帽與軸承等標準零件。請參閱[放置鋼料斷面與標準零件](topic:steel-and-standard-parts)。
- {{ui:其他來源}}：以與程式庫相同方式回應的其他程式庫。只需加入一次其位址，此瀏覽器就會記住它。

每張卡片會顯示預覽、名稱、製造商與型號、授權與版本。已撤回的項目會標示為{{ui:已撤回}}並附上原因；放置前，CadCraft 會先詢問。

## 放置項目

1. 點按卡片上的{{ui:放置}}。
2. 點按項目要放置的位置。若要先旋轉，請輸入`R`；若要先縮放，請輸入`S`。
3. 在`Enter Item number (CC-ITEM)`提示下，按{{key:Enter}}使用下一個可用的編號，或輸入自訂的編號。

項目會成為名為`LIB_<name>_v<version>`的區塊，並以此圖形的單位繪製。若圖形沒有設定單位，項目會以毫米放入，歷程也會說明此情況；請先在右側面板中設定{{ui:單位}}。

其資料會以不可見的屬性一併帶入：項目的 ID 與版本、授權與標示來源、製造商、型號、類別與尺寸。請參閱[區塊屬性](topic:attributes)。

## 項目的語言版本

項目可附上其他語言的名稱與描述。當項目具有 CadCraft 所設定語言的內容時，卡片與放置的區塊項目名稱會使用該內容（設定 › 一般 › 語言）。區塊本身仍以項目本身的名稱命名，因此無論以哪種語言放置，圖形中每個項目都只有一個區塊。

## 檢查更新

1. 開啟程式庫。
2. 點按{{ui:檢查更新}}。

圖形中的每個程式庫項目都會列出其項目編號，以及它是否為最新版本、是否有較新的版本（與其變更內容），或已被撤回。點按某一列的{{ui:更新}}，或點按{{ui:全部更新}}。每個參照都會移到新版本的區塊，並保留其項目編號、數量、位置、角度與圖層。{{key:Mod+Z}}可復原更新。

## 標示所使用的項目

點按{{ui:程式庫標示}}。每個項目都會列出其標示來源行與授權。

- {{ui:複製標示來源}}會複製一個項目的標示行；{{ui:全部複製}}會複製所有標示行。
- {{ui:下載 CSV}}會儲存包含項目編號、製造商、型號、授權與標示來源的清單。可用任何試算表開啟。

CC BY 等授權要求你在使用作品時標示作者。請將這些標示行放在圖形、規格書或專案附註中。

## 符號與資產

程式庫有三種項目：符號（2D 繪圖慣例）、類型（元素由什麼組成），以及資產（實體物件）。在{{ui:程式庫}}索引標籤中，{{ui:項目類型}}清單可顯示符號與資產、僅顯示符號，或僅顯示資產。類型是建構 BimCraft 專案的組成，因此 CadCraft 不會列出它們。

## 登入程式庫

點按{{ui:登入程式庫}}。會開啟一個小視窗前往網站；登入後，CadCraft 可顯示團隊的項目，並登錄已放置的項目，使所用的項目有變更時能收到通知。登入狀態僅限此瀏覽器分頁，可隨時於帳戶的安全性頁面中撤銷。

## 常見錯誤

- **「以 IFC 類型製作項目的功能位於 BimCraft 中。」** IFC 與族檔是在 BimCraft 應用程式中讀取。請在該處或程式庫中製作項目，然後在此使用其`item.json`。
- **「無法連線至程式庫。」** 可能是離線，或程式庫無法使用。圖形中已有的項目不受影響。
- **項目過大或過小。** 圖形的單位錯誤或未設定。請復原、設定{{ui:單位}}後重新放置。
