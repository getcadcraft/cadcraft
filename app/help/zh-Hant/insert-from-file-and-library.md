## 從另一個圖形插入區塊

1. 輸入 `I` 後按{{key:Enter}}鍵，或按一下 {{ui:插入}}（位於「區塊」群組中）。
2. 視窗底部的指令列會詢問 `Enter block name or [File/Library]`。在此輸入 `F` 後按{{key:Enter}}鍵。
3. 選擇此電腦上的 DWG 或 DXF。它會在此被讀取，但不會開啟，也不會上傳任何內容。
4. 在 {{ui:插入自}} 對話方塊中，從清單中選擇一個區塊（在 {{ui:篩選區塊}} 中輸入文字即可找到它），或保留 {{ui:整個圖形}}。按一下 {{ui:插入}}。
5. 按一下放置的位置，並填入它要求的任何屬性。

你也可以從 {{ui:區塊}} 面板開始：在其 {{ui:篩選區塊}} 方塊中輸入 `F` 後按{{key:Enter}}鍵，或輸入與任何區塊都不相符的文字，然後按一下 {{ui:從檔案…}}。`L` 與 {{ui:程式庫…}} 會以相同方式開啟程式庫。在 0.10.1 版之前，在 {{ui:篩選區塊}} 中輸入的字母只會搜尋此圖形的區塊，並回答「沒有區塊符合篩選條件。」

若要隨手取用你自己的區塊圖形，請在 {{ui:區塊}} 面板的 {{ui:程式庫}} 下按一下 {{ui:新增圖形}}，然後選擇 DWG 或 DXF。其區塊會附圖片列出；按一下即可放置。

整個圖形會以檔案名稱命名的一個區塊引入。你所選區塊內的區塊也會一併引入。它們所使用的圖層會加入此圖形。

若另一個圖形使用不同的單位（例如英寸與毫米），CadCraft 會將參照縮放以配合，並在歷史記錄中說明。

### 名稱已被使用時

若此圖形已經有相同名稱的區塊，CadCraft 會詢問：

- {{ui:保留現有的}} 會使用此圖形中該名稱的區塊。
- {{ui:重新命名}} 會以 `Name (2)` 的名稱引入新的區塊。

整個插入是一個步驟：{{key:Mod+Z}} 會一併移除參照與複製的定義。

## 開啟程式庫

按一下 {{ui:區塊}} 面板中的 {{ui:程式庫…}}，或「區塊」群組中的 {{ui:程式庫}}，或輸入 `LIB`。在 `INSERT` 的提示處，`L` 也會開啟它。

程式庫有四個來源，以分頁顯示：

- {{ui:程式庫}}：CadCraft 程式庫。可依名稱、製造商或型號搜尋，並依類別篩選。
- {{ui:檔案…}}：任何程式庫的項目檔（`item.json`），或用來製作項目的圖形、試算表或 3D 模型：DWG 或 DXF（每個區塊成為一個項目）、含名稱與尺寸欄位的 CSV，或 glTF 或 OBJ 模型。不會上傳任何內容。
- {{ui:標準}}：鋼材斷面（以斷面、立面或 3D 構件呈現），以及螺栓、螺帽與軸承等標準零件，依已發佈的表格在此製作。請參閱[放置鋼材斷面與標準零件](topic:steel-and-standard-parts)。
- {{ui:其他來源}}：以與程式庫相同方式回應的其他程式庫。只需一次加入其位址；此瀏覽器會記住它。

每張卡片會顯示預覽、名稱、製造商與型號、授權與版本。已撤回的項目會以 {{ui:已撤回}} 標示，並附上原因；放置前 CadCraft 會先詢問。

## 放置項目

1. 在卡片上按一下 {{ui:放置}}。
2. 按一下項目放置的位置。先輸入 `R` 可旋轉，或輸入 `S` 可縮放。
3. 在 `Enter Item number (CC-ITEM)` 處，按{{key:Enter}}鍵使用下一個空閒編號，或輸入你自己的編號。

項目會成為名為 `LIB_<name>_v<version>` 的區塊，並以此圖形的單位繪製。若圖形沒有單位，項目會以毫米放入，並在歷史記錄中說明；請先在右側面板中設定 {{ui:單位}}。

其資料會以不可見的屬性一併帶入：項目的 ID 與版本、授權與標示來源、製造商、型號、類別與尺寸。請參閱[區塊屬性](topic:attributes)。

## 你的語言中的項目

項目可以帶有其他語言的名稱與說明。當 CadCraft 設定的語言（設定 › 一般 › 語言）存在時，卡片與放置區塊的項目名稱會使用它們。區塊本身會保留由項目自身名稱產生的名稱，因此無論哪種語言放置，一個圖形中每個項目只會有一個區塊。

## 檢查更新

1. 開啟程式庫。
2. 按一下 {{ui:檢查更新}}。

圖形中的每個程式庫項目都會列出其項目編號，以及它是否為最新、是否有較新的版本（並說明變更內容），或是否已撤回。在某一列上按一下 {{ui:更新}}，或按一下 {{ui:全部更新}}。每個參照都會移到新版本的區塊，並保留其項目編號、數量、位置、角度與圖層。{{key:Mod+Z}} 可復原更新。

## 標示你使用的來源

按一下 {{ui:程式庫標示}}。每個項目都會列出其標示來源行與授權。

- {{ui:複製標示來源}} 會複製一個項目的那一行；{{ui:全部複製}} 會複製每一行。
- {{ui:下載 CSV}} 會儲存包含項目編號、製造商、型號、授權與標示來源的清單。它可在任何試算表程式中開啟。

CC BY 等授權要求你在使用作品的地方標示作者。請將這些行放在圖形、規格書或專案說明中。

## 符號與資產

程式庫有三種項目：符號（製圖慣例，2D）、類型（元素由什麼組成）與資產（實體物件）。在 {{ui:程式庫}} 分頁中，{{ui:項目類型}} 清單會顯示符號與資產、僅符號，或僅資產。類型是 BimCraft 專案所建構的內容，因此 CadCraft 不會列出它們。

## 登入程式庫

按一下 {{ui:登入程式庫}}。會在網站上開啟一個小視窗；登入後，CadCraft 可以顯示你團隊的項目，並記錄你放置的內容，因此當你所用的項目有所變更時，你會收到通知。登入狀態在此瀏覽器分頁中有效。你可隨時在帳戶的安全性頁面中撤銷它。

## 在「我的物件」中保存你自己的物件

{{ui:我的物件}} 是程式庫中只有你自己看得到的私人清單。它不在公開程式庫中，不會出現在搜尋中，也不會顯示給你的團隊，並會跟隨你的帳戶，出現在你登入程式庫的每台電腦上。

1. 在程式庫面板中，按一下 {{ui:檔案…}} 並讀取一個檔案。
2. 在你想再次使用的項目上，按一下 {{ui:儲存至我的物件}}。
3. 稍後，按一下 {{ui:我的物件}}，然後按一下 {{ui:放置}}。它與任何程式庫項目的放置方式相同，{{ui:檢查更新}} 也會涵蓋它。
4. {{ui:從我的物件移除}} 會將它從清單中移除。已放入圖形的複本仍會保留。

你必須登入程式庫。讀取檔案不會上傳任何內容；保存項目只會將該單一項目傳送到你的帳戶。

:::note
「我的物件」仍在測試中，可能尚未對你的帳戶開放。若它顯示「我的物件尚未對此帳戶開放」，你仍可以使用 {{ui:檔案…}} 放置你自己檔案中的項目。
:::

## 常見錯誤

- **「由 IFC 類型製作項目屬於 BimCraft。」** IFC 與族檔是在 BimCraft 應用程式中讀取的。請在該處或程式庫中製作項目，然後在此使用其 `item.json`。
- **「無法連線到程式庫。」** 你處於離線狀態，或程式庫無法使用。圖形中已有的項目不受影響。
- **項目太大或太小。** 圖形的單位錯誤或尚未設定。請復原，設定 {{ui:單位}}，然後重新放置。
