快速鍵會依目前電腦的按鍵顯示。在 Mac 上，下方每個{{key:Mod}}快速鍵都使用 Command 鍵，Control 鍵同樣有效。按鍵的寫法，以及在 Mac 上如何使用 F 鍵，請見[鍵盤、滑鼠與觸控板](common:keys)。

## 輸入指令

| 按鍵 | 功能 |
|---|---|
| 任何字母、數字或符號 | 送至指令列，不論滑鼠指標位於何處，除非面板中的輸入方塊有游標 |
| {{key:Enter}} | 送出已輸入的內容。在空白提示時：重複上一個指令、結束指令、完成選取，或接受`<…>`中的預設值 |
| {{key:Space}} | 與{{key:Enter}}相同，但在 CadCraft 要求輸入文字時（文字、區塊名稱、標註文字）會輸入空格 |
| {{key:Esc}} | 取消指令。沒有執行指令時：取消夾點移動或選取框，然後清除選取 |
| {{key:Tab}} | 接受指令列右側顯示的建議指令。若未輸入任何內容，且滑鼠指標位於重疊的物件上：反白顯示該處的下一個物件（點按即可選取） |
| {{key:Up}} {{key:Down}} | 逐一瀏覽先前輸入的指令列（最近 100 行） |

## 繪圖與編輯

| 按鍵 | 功能 |
|---|---|
| {{key:Mod+Z}} | 復原上一個指令 |
| {{key:Mod+Y}}或{{key:Mod+Shift+Z}} | 取消復原 |
| {{key:Mod+A}} | 在開啟的索引標籤中選取所有可編輯的物件（{{cmd:SELECTALL}}）。若指令列中已輸入文字，則改為選取該文字 |
| {{key:Delete}} | 刪除所選物件（{{cmd:ERASE}}），但指令列中已輸入內容時除外 |
| {{key:Backspace}} | 指令列沒有游標時，刪除所選物件；在指令列中則刪除已輸入的內容 |
| {{key:Esc}} | 沒有執行指令時：清除選取（{{cmd:DESELECT}}） |
| {{key:Mod+S}} | 以圖形的格式（DWG 或 DXF）另存副本 |
| {{key:Mod+Shift+S}} | 另存新檔：選擇 DWG 或 DXF，然後另存副本 |
| {{key:Mod+O}} | 開啟 DWG 或 DXF |
| {{key:Mod+P}} | 列印為 PDF |

執行指令時，復原、取消復原、全選與列印都不會作用：請先按{{key:Esc}}。

## 複製、剪下與貼上

| 按鍵 | 功能 |
|---|---|
| {{key:Mod+C}} | 將所選內容複製到剪貼簿（{{cmd:COPYCLIP}}）。未選取任何物件時：CadCraft 會要求選取物件 |
| {{key:Mod+X}} | 剪下：先複製所選內容，再刪除（{{cmd:CUTCLIP}}） |
| {{key:Mod+V}} | 貼上：副本會跟隨游標；點按或輸入一個點即可放下（{{cmd:PASTECLIP}}） |
| {{key:Mod+Shift+V}} | 原位貼上：貼在複製時的座標位置（{{cmd:PASTEORIG}}） |
| {{key:Mod+D}} | 建立副本：所選內容的副本跟隨指標移動；點按即可放下，按{{key:Esc}}則不留下任何內容（{{cmd:DUPLICATE}}） |

工具列的{{ui:編輯}}群組（{{ui:複製}}、{{ui:貼上}}）與其{{ui:更多}}功能表中也有相同的動作。執行其他指令時，請先完成該指令或按{{key:Esc}}。副本跟隨游標時再次按下{{key:Mod+V}}或{{key:Mod+D}}，會重新開始。在指令列中已輸入文字，或指令正在要求輸入文字時，這些按鍵會改為複製、剪下與貼上該文字。請見[複製、貼上與建立副本](topic:copy-paste)。

## 切換

| 按鍵 | 切換 | 狀態列按鈕 |
|---|---|---|
| {{key:F3}} | 開啟或關閉物件鎖點 | {{ui:鎖點}} |
| {{key:F7}} | 開啟或關閉格點 | {{ui:格點}} |
| {{key:F8}} | 開啟或關閉正交 | {{ui:正交}} |
| {{key:F10}} | 開啟或關閉極軸追蹤 | {{ui:極軸}} |
| {{key:F11}} | 開啟或關閉物件鎖點追蹤 | {{ui:追蹤}} |
| {{key:F12}} | 開啟或關閉動態輸入 | {{ui:動態}} |

:::mac
在 Mac 上，F3、F7 與 F8 通常是 Mission Control 與媒體鍵。請按住 **fn** 再按這些鍵，或在系統設定中開啟標準功能鍵，說明見[鍵盤、滑鼠與觸控板](common:keys)。狀態列按鈕一律可用。
:::

:::firefox
Firefox 中的 F7 也可能詢問是否開啟插入點瀏覽。請選擇**否**；若仍持續詢問，請使用{{ui:格點}}按鈕。
:::

## 說明

| 按鍵 | 功能 |
|---|---|
| {{key:F1}} | 在圖形旁開啟或關閉此說明。即使指令正在執行也能使用，且絕不會送到指令列。 |
| {{key:Esc}} | 游標位於說明面板時：清除搜尋，或關閉面板 |

頂端列中的{{ui:說明}}按鈕與{{key:F1}}功能相同。在說明的搜尋方塊中輸入時，內容不會送到指令列。在圖形上點按即可將按鍵交還 CadCraft；面板會保持開啟在圖形旁。

:::mac
在 Mac 鍵盤上，請按住 **fn** 再按 F1，或點按{{ui:說明}}。
:::

## 畫面

| 按鍵 | 功能 |
|---|---|
| {{key:Ctrl+Shift+F}} | 循環切換一般、全螢幕，以及隱藏列的全螢幕。所有電腦（包括 Mac）都使用 Control 鍵。 |
| {{key:Left}} {{key:Right}} | 圖形下方的索引標籤取得焦點時：前一個或下一個索引標籤 |

全螢幕時，瀏覽器可能會以第一次{{key:Esc}}離開全螢幕。再按一次{{key:Esc}}可取消指令。

## 對話方塊

| 按鍵 | 功能 |
|---|---|
| {{key:Esc}} | 關閉對話方塊（{{ui:列印為 PDF}}，或「尚未儲存的變更」等詢問，此時表示{{ui:取消}}） |
| {{key:Tab}} | 在對話方塊的設定與按鈕之間移動 |

對話方塊開啟時，圖形的按鍵會停用。

## 面板欄位

在右側或左側面板的輸入方塊中：

| 按鍵 | 功能 |
|---|---|
| {{key:Enter}} | 套用數值並離開方塊 |
| {{key:Esc}} | 還原舊數值並離開方塊 |
| {{key:Tab}} | 套用並移到下一個方塊 |

方塊有游標時，字母會輸入到方塊中，而不是指令列。

## 滑鼠

| 操作 | 功能 |
|---|---|
| 點按 | 指令要求指定點時，指定該點；要求選取物件時，選取物件；其他情況下，選取物件或夾點 |
| {{key:Shift}}+點按 | 從選取內容中移除已選取的物件（若在[設定](topic:settings)中將{{ui:點按物件}}設為{{ui:取代選取}}，則為加入）。指定點時：該次點按忽略物件鎖點 |
| 在空白處點按，然後再點按一次 | 選取框：由左至右為視窗選取，由右至左為交叉選取 |
| 在空白處拖曳 | 套索：先向右移動為視窗選取，先向左為交叉選取；拖曳時按{{key:Space}}會循環切換視窗、交叉與圍籬；按{{key:Esc}}可放棄（LASSOMODE 0 或設定，可使其恢復為矩形） |
| 在 TRIM 或 EXTEND 中拖過各段 | 修剪（或延伸）路徑經過的每一段；按住{{key:Shift}}則執行另一種操作 |
| 拖曳夾點 | 移動夾點（或點按夾點後，再點按要放置的位置） |
| 連按兩下文字 | 選取文字，並將游標放入右側面板的{{ui:文字}}方塊中 |
| 點按滑鼠右鍵 | 相當於 Enter。在夾點移動或選取框期間：取消該操作 |
| 以右鍵拖曳 | 平移 |
| 滾輪 | 以十字游標為中心放大與縮小 |
| 以滾輪（中鍵）拖曳 | 平移 |
| 連按兩下滾輪 | 縮放至整個圖形（範圍） |
| 將 DWG 或 DXF 拖放到圖形上 | 開啟該檔案 |

在觸控板或觸控螢幕上的操作，請見[滑鼠、觸控板與觸控](topic:mouse-trackpad-touch)。

## 瀏覽器保留的按鍵

{{key:Mod+N}}、{{key:Mod+W}}與{{key:Mod+T}}一律屬於瀏覽器，CadCraft 不會使用它們：如需新圖形，請使用{{ui:新增}}或輸入`NEW`。CadCraft 的剪貼簿是獨立的：{{key:Mod+C}}與{{key:Mod+V}}只會在 CadCraft 圖形與索引標籤之間複製物件，不會與其他程式互相複製。

:::mac
若{{key:Mod+Y}}開啟的是瀏覽器的歷程記錄而非取消復原，請使用{{key:Mod+Shift+Z}}或{{ui:取消復原}}按鈕。
:::

## 移動指令的位置

移動是指令`MOVE`（按鍵{{key:M}}）：先選取物件，然後指定基點與第二點，或輸入距離。`ALIGN`與`DISTRIBUTE`也在這裡。BimCraft 對建築元素的相同工作使用相同名稱，但其{{key:M}}為量測，其移動則為{{key:Shift+M}}。
