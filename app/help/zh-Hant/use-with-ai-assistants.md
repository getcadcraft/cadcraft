## 學習內容

說明如何讓 AI 助理（或自行撰寫的指令稿）檢視圖形、執行 CadCraft 指令、列印與儲存，以及決定它可以變更的範圍。

CadCraft **本身沒有 AI**，也不會將任何內容傳送到外部。助理需由使用者自行提供：任何能使用模型內容協定（MCP）的程式都可以。CadCraft 只提供工具，由使用者選擇要開放哪些工具。

使用方式有兩種：

- **開啟中的圖形。** 助理會透過電腦上的 CadCraft Studio，在此視窗中與使用者並行作業。這正是 {{ui:設定}} › {{ui:CadCraft}} › {{ui:助理}} 的用途。
- **電腦上的圖形，不必開啟應用程式。** CadCraft MCP 伺服器與 `cadcraft` 指令列可讀寫指定資料夾中的 DWG 與 DXF 檔案。參閱下方的「不開啟 CadCraft 即可處理檔案」。

## 開啟功能

1. 開啟 {{ui:設定}}（應用程式列上的齒輪，或 {{key:Mod+,}}），切換到 {{ui:CadCraft}} 索引標籤。
2. 在 {{ui:助理}} 下勾選 **允許 AI 助理與指令稿使用 CadCraft**。在勾選之前，此功能會保持關閉。
3. 選擇助理可執行的動作。**讀取** 預設已勾選；其他權限僅在需要時再勾選。

| 權限 | 助理可以做的事 |
|---|---|
| 讀取 | 檢視圖形：描述圖形、列出與尋找物件、查看選取集、描述視圖並擷取其畫面，依圖層與製圖規則檢查圖形 |
| 編輯 | 在圖形上執行指令並變更選取集。每個動作都是一個可復原的步驟 |
| 儲存 | 儲存圖形（在桌面版中儲存至其檔案；在瀏覽器中則以下載方式儲存） |
| 匯出 | 列印為 PDF 並產生其他檔案 |

## 讓助理使用指定資料夾中的檔案

在 CadCraft Studio 中，助理可以依檔案名稱開啟、儲存與列印檔案，而非使用檔案對話方塊，但僅限於在 {{ui:助理}} › {{ui:助理可使用的資料夾}} 下新增的資料夾中：

1. 選擇 {{ui:新增資料夾…}}，並在 Studio 自己的對話方塊中選取資料夾。
2. 助理現在可以列出該資料夾中的檔案（`files_list`）、開啟圖形（`drawing_open`）、以 DWG 版本或 DXF 格式儲存至該資料夾、列印為 PDF 或 SVG 檔案、載入 LISP 檔案，並為指令提供其所需的檔案（`INSERT` `F`、`XATTACH`、點檔案），或指定指令檔案的輸出位置（`COUNT` 的 CSV、`PUBLISH`）。
3. {{ui:移除}} 會立即收回該資料夾。其他位置的路徑一律拒絕，而既有的檔案只有在助理要求覆寫，或由助理自己寫入時才會被取代。

開啟檔案仍需要 **讀取** 權限；寫入圖形需要 **儲存** 權限；其他任何檔案都需要 **匯出** 權限。

未勾選之權限所對應的工具，完全不會提供給助理；即使助理仍要求使用，CadCraft 也會拒絕，並將該紀錄寫入活動紀錄中。關閉此開關會立即結束所有連線。{{ui:重設 CadCraft 設定}} 也會將其關閉。

## 連接助理

助理透過電腦上的 **CadCraft Studio** 連線：Studio 會執行一個小型伺服器，只有本機電腦可以連線（位址 `127.0.0.1`），並由 Studio 每次啟動時產生的權杖加以保護。開啟 Studio，選擇 {{ui:連接助理}}，然後複製位址與權杖。

- 在助理中新增類型為 HTTP 的 MCP 伺服器，填入位址（格式如 `http://127.0.0.1:47615/mcp`）與標頭 `Authorization: Bearer <token>`。Studio 會顯示可供貼上的設定。

Studio 中的 {{ui:新增權杖}} 會讓所有已連線的助理以新權杖重新連線。切勿分享權杖：只要 Studio 仍在執行，持有權杖的任何人都能使用已開啟的應用程式。

:::note
瀏覽器分頁無法為助理開啟連線：在瀏覽器版應用程式中，此開關在改用電腦上的 CadCraft Studio 之前不會有任何作用。
:::

## 保持掌控

- **每個動作都是一個復原步驟**，並以助理的名稱標示，例如「助理：LINE」。按 {{key:Mod+Z}} 可將助理的上一個動作整體復原。
- **可以看到助理的操作。** 其指令會出現在指令歷程記錄中，前面標示 **[助理]**，圖形會在作業時重新繪製。
- **助理會等待使用者。** 在指令執行途中，助理只能讀取而不能變更圖形；完成後會被告知再試一次。
- **可以知道何時已連線。** 應用程式列上的按鈕會在助理連線時顯示其名稱。按一下即可查看其可執行的操作，或**中斷連線**。
- **活動。** {{ui:設定}} › {{ui:CadCraft}} › {{ui:助理}} › {{ui:活動}} 會列出每次呼叫：時間、使用的工具、是否完成或遭拒，以及其所產生的復原步驟。{{ui:儲存紀錄}} 會保留一份副本。

## 助理可以要求的功能

| 工具 | 權限 | 功能 |
|---|---|---|
| `app_info`, `drawing_describe`, `view_describe` | 讀取 | 圖形的名稱、單位、圖層、區塊、配置；畫面上顯示的內容 |
| `files_list`, `drawing_open` | 讀取 | Studio：資料夾中的檔案；在此視窗中開啟圖形 |
| `objects_list`, `object_get`, `selection_get` | 讀取 | 物件及其幾何、長度與面積（或僅依類型與圖層列出數量）；選取集 |
| `drawing_check` | 讀取 | 規則，例如允許的圖層、圖層 0 上不得有物件、顏色為隨圖層、文字高度 |
| `view_screenshot` | 讀取 | 圖形目前顯示的畫面 |
| `command_run` | 編輯 | 在指令列中輸入：`LINE 0,0 @100,0 @0,50 `（讀取方式與人工輸入相同，空格代表一個回答結束），或是每個回答一項的清單。它可讓指令保持開啟，並在下一次呼叫時繼續執行 |
| `script_run` | 編輯 | 指令稿（`.scr`）或 LISP 檔案，即 {{ui:APPLOAD}} 的載入方式 |
| `block_insert` | 編輯 | 一步放置區塊並帶入其屬性值 |
| `selection_set`, `undo` | 編輯 | 為下一個指令選取物件；復原其自身的步驟 |
| `drawing_save` | 儲存 | CadCraft 自己的 {{ui:儲存}}，或 {{ui:另存新檔}} 至已新增的資料夾之一 |
| `drawing_plot` | 匯出 | 圖紙或模型的 PDF 或 SVG，依比例或符合視窗大小（PDF 底圖目前尚不會以此方式列印） |

助理執行指令時，CadCraft 會在指令列而非對話方塊中提出問題（例如是否插入整個圖形或單一區塊），以便助理回答。程式庫與尋找仍需要使用者操作；助理會被告知要請使用者處理。

## 不開啟 CadCraft 即可處理檔案

CadCraft MCP 伺服器（`cadcraft-mcp`）與指令列（`cadcraft`）會在 Node.js 中執行 CadCraft 自己的圖形程式碼，不需要視窗。需要 Node.js 20 或更新版本。

- **MCP 伺服器**只在指定的資料夾內作業，且僅限於授予的權限：`npx @getcadcraft/mcp --root ~/Drawings --allow read,edit`。若沒有 `--root`，即無法開啟任何檔案；若沒有 `--allow`，則只能讀取。它也可以讀取 IFC 模型、數量計算與 PDF 圖紙集中的標記。
- **指令列**供自行撰寫的指令稿使用：`cadcraft info plan.dwg`、`cadcraft run cleanup.scr plan.dwg -o plan-clean.dwg`、`cadcraft convert plan.dwg plan.dxf`、`cadcraft plot plan.dwg plan.pdf --all`、`cadcraft plot plan.dwg plan.svg`、`cadcraft check plan.dwg --rules rules.json`。一次處理多個檔案：`cadcraft convert *.dwg out --to dxf`、`cadcraft plot *.dwg pdfs --to pdf`、`cadcraft check *.dwg --rules rules.json`。加上 `--json` 即可取得程式可讀取的輸出。

:::note
若 `npx @getcadcraft/mcp` 顯示找不到套件，表示尚未發佈。getcadcraft.com 上的最新消息會說明發佈時間。
:::

## 如果功能無法運作

- **助理看不到任何 CadCraft 工具：**請確認此視窗中的開關已開啟，且該視窗已在 Studio 中開啟。
- **「需要編輯權限」：**在 {{ui:助理}} 下勾選 **編輯**，然後再次要求。
- **「不在助理可使用的資料夾之內」：**請在 {{ui:助理}} › {{ui:助理可使用的資料夾}} 下新增該資料夾，或要求助理使用已新增之資料夾中的檔案。
- **「401」或「權杖」錯誤：**權杖已變更（Studio 已重新啟動，或使用了 {{ui:新增權杖}}）。請將新權杖複製到助理的設定中。
- **助理的變更有誤：**按 {{key:Mod+Z}}。每按一次即可復原助理的一個完整動作。
