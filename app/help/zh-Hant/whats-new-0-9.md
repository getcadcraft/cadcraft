這是 CadCraft 0.9 相較於 0.8.1 的變更內容。CadCraft 是 CadCraft Studio 0.9 及其八個應用程式中的 2D 與 3D 繪圖應用程式。0.9 完成了平面繪圖，加入文字樣式與真正的文字編輯器，並為螢幕提供更多空間。

## 新增

### 平面繪圖

- **隨邊界連動的填滿。** {{cmd:HATCH}} 會連結到界定它的內容。移動、旋轉或縮放邊界，填滿與其圖案會隨之移動；重塑邊界，填滿會重新計算。{{cmd:HATCHEDIT}}（`HE`）可事後變更填滿，並建立或結束連結。請參閱[填滿圖案與填滿區域](topic:hatch)。
- **填滿圖案檔。** 在 {{cmd:HATCH}} 的 `Pick internal point` 提問處，輸入 `F`（圖案檔）並選擇 `.pat` 檔。只測試過依一般格式寫出的檔案。
- **圖層群組。** 在 {{ui:圖層}} 面板的 {{ui:工具}} 中：{{ui:新增群組}}、{{ui:加入現成群組}}、{{ui:依名稱分組}}，以及 {{ui:尋找圖層}}；或輸入 {{cmd:LAYGROUP}}（`LG`）。請參閱[以圖層整理圖形](topic:layers#group-layers)。
- **堆疊樓層。** {{cmd:FLOORS}}（`FLR`），或 {{ui:視圖}} 群組的 {{ui:更多}} 功能表中的 {{ui:樓層…}}。配置上的視埠可在特性中的 {{ui:顯示的樓層}} 下顯示某一樓層。{{cmd:FLOORLAYERS}} 會將樓層轉為圖層，供交給他人的檔案使用。請參閱[在一個圖形中堆疊樓層](topic:floors)。
- **2D 智慧牆、門與窗。** {{cmd:WALL}}（`WA`）、{{cmd:DOOR}}（`DR`）、{{cmd:WINDOW}}（`WN`）與 {{cmd:DELOPENING}}。轉角、T 形接合與交叉會自動計算。牆會保存其接合的記錄，特性中新增了 {{ui:起點不允許接合}} / {{ui:終點不允許接合}}、{{ui:定位線}}，以及可編輯的 {{ui:長度}}。請參閱[繪製 2D 牆、門與窗](topic:walls-2d)。
- **平面牆的牆工具。** 輸入 {{cmd:WALLRECT}}、{{cmd:WALLPOLY}}、{{cmd:WALLARC}}、{{cmd:WALLTRACE}}、{{cmd:WALLDIM}}、{{cmd:WALLOFFSET}}、{{cmd:WALLSPLIT}}、{{cmd:WALLGRID}} 以及其餘指令。它們目前尚無工具列按鈕。請參閱[2D 牆的形狀、切割、偏移與鎖定](topic:wall-tools-2d)。

### 文字

- **文字樣式。** {{cmd:STYLE}}（`ST`），或 {{ui:繪製}} 工具列上的 {{ui:文字樣式}}：具名樣式，包含字型、高度、寬度比例與傾斜。請參閱[以文字樣式設定文字的字型與大小](topic:text-styles)。
- **格式化的段落文字編輯器。** {{cmd:MTEXT}}、{{cmd:TEXTEDIT}}，或在文字上按兩下，會開啟一個方塊，可設定字型、大小、粗體、斜體、底線、刪除線、顏色、對齊方式，以及度數、正負號與直徑符號，並附有 {{ui:確定}} 與 {{ui:取消}}。請參閱[格式化段落文字](topic:format-paragraph-text)。
- **以 draw.io XML 繪製圖表。** {{cmd:DIAGRAM}}（`T2D`）也會讀取貼上的 draw.io XML。請參閱[由文字繪製圖表](topic:text-to-diagram)。
- **PDF 列印中的泰文。** 過去會列印為問號。

### 更多空間與繪圖輔助

- **可浮動、更薄的指令列與精簡的上方區域。** 拖曳指令列的把手即可使其浮動，拖曳其上緣可減少行數，{{key:F2}} 會開啟歷史記錄。{{ui:設定}} › {{ui:CadCraft}} › {{ui:指令列}} 與上方區域的選項提供相同的設定。請參閱[設定](topic:settings#command-line)。
- **物件鎖點功能表。** 在狀態列的 {{ui:鎖點}} 上按一下右鍵，或輸入 {{cmd:OSNAP}}。
- **貼齊格點。** 狀態列的 {{ui:格點鎖點}} 按鈕，或 {{key:F9}}：當沒有物件鎖點捕捉到點時，點選的點會貼齊最近的格點。
- **十種繪製圓弧的方式，以及延續。** {{ui:繪製}} 工具列上的 {{ui:圓弧}} 或 {{cmd:ARC}}：三點、起點/圓心/終點系列、圓心/起點/終點系列，以及延續（在起點按{{key:Enter}}鍵），從最後一條直線、圓弧或聚合線繼續。
- **文件面板。** {{cmd:DOCUMENTS}}（`DOCS`），或 {{ui:視圖}} 群組的 {{ui:更多}} 功能表中的 {{ui:文件…}}：專案資料夾中每個圖形的修訂、狀態與簽出。它會以置中的對話方塊開啟。請參閱[文件](topic:documents)。

### 檔案

- **英國鋼材尺寸。** 「標準」面板中的 976 種斷面，以圖紙上的方式輸入（例如 `305x165x40 UB`）。
- **南非套件**（繪圖慣例與建築法規），以建築法規附加功能的套件形式提供。數字尚未經過驗證。
- **CadCraft 附加功能**，依需求加入，預設為關閉：室內照明設計、晶片設計（HDL 轉配置）、路由器雕刻、電路模擬、滾子鏈鏈輪，以及建築法規的國家套件。

## 修正

- 移動、旋轉或縮放填滿時，會遺留其圖案。
- {{cmd:GRIDMOVE}} 會帶動僅從格線開始的整道平面牆。現在會依牆的端點判斷。
- 即使界限關閉，格線仍只顯示在圖形界限之內。
- 側邊面板中的區塊清單可以捲動，且與任何區塊名稱都不相符的名稱，會列出以它開頭的區塊（「您是否要找」）。
- AutoCAD 拒絕（「表格的未知群組 1001」）的 DXF R12 檔，現在可以在此開啟。
- 非常大的檔案（約 70,000 個實體以上）曾因「超出最大呼叫堆疊大小」而無法開啟。
- 來自 AutoCAD 2018 及更新版本、且維護版本較高的 DWG 檔，曾因「bad BITLONG code 11」而無法開啟。
- 在段落文字方塊中，為所選部分輸入的新大小會保留選取內容。

## 在所有應用程式中

Bootstrap 工具提示適用於每個具有提示的控制項、可關閉的入門提示、無法容納時可捲動的分頁列，以及會跟隨開啟圖形的瀏覽器分頁標題（`<drawing> - CadCraft | CadCraft`）。{{ui:設定}} › {{ui:版面}} 現在是兩行選項的下拉式清單。{{ui:設定}} 中的語言清單比 0.8 更長。即時共同編輯、程式庫集合，以及重量與溫度單位，都在 Studio 附註中說明。

## 誠實的限制

- 段落文字沒有項目符號或編號清單、定位標尺或對齊方式。列印的 PDF 以 Helvetica 排版文字。
- 平面牆為直線，因此圓弧會以短牆繪製。牆工具的社群手動檢查仍在進行中。
- 圖層群組不以 AutoCAD 本身的格式寫入，因此 AutoCAD 會顯示為平面清單。除非你執行 {{cmd:FLOORLAYERS}}，其他程式會將所有樓層一起顯示。
- 文件面板尚未有兩人在真實的共用資料夾上測試。路由器雕刻尚未在任何真實機器上執行。照明估算是以光子追蹤來檢查，而非以另一個程式。工程附加功能是檢查輔助工具，不能取代工程師的審查。
- 英文以外的語言為機器草稿，且部分新的詞彙僅有英文。
