CadCraft 採用你在其他製圖程式中熟悉的指令名稱與短名稱：輸入 `L` 畫直線、`TR` 修剪、`E` 刪除。因此大多數指令不需要另外學習對照表：你認得的名稱，就是這裡的名稱。下方列表是 CadCraft 的每個指令，由程式本身產生。按{{key:Enter}}鍵會重複上一個指令；在指令列中輸入 `HELP` 會印出相同的清單。

少數不同或尚未實作的指令：

- **儲存**（{{cmd:SAVE}}、{{cmd:SAVEAS}}）在瀏覽器中會下載一份副本；在 CadCraft Studio 中則會寫入檔案。請參閱[從其他製圖軟體遷移](topic:coming-from)。
- **PLOT** 會產生 PDF（也可產生 PNG 與 SVG），使用列印樣式表；沒有頁面設定管理員。
- **DIMSTYLE** 與 **PEDIT** 已實作；**PEDIT** 沒有編輯頂點選項（請改用夾點）。
- **TABLE** 尚未實作；{{cmd:XREF}}、{{cmd:SPLINE}} 與 {{cmd:WBLOCK}} 已實作。
- 常式自己的指令（AutoLISP `C:NAME`）會在你以 {{cmd:APPLOAD}} 載入後出現；它們不會列在此處。

| `WHEREAMI` | `WHERE` | 說明游標所在的位置。 |
| `WHOHAS` |  | 說明誰開啟了某個圖形。CadCraft Studio 會在每個開啟的圖形旁保存一個小型鎖定檔（Plan.dwg.cclock：誰、自何時、哪個版本），並於關閉時移除。選項：Current（目前開啟的圖形）、File（點選一個）、FOlder（某資料夾中有人開啟的所有圖形）、Path（輸入完整路徑）、Name（他人看到的名稱）。超過五分鐘未更新的鎖定會被視為過期。瀏覽器中無法使用。 |
| `WINDOW` | `WN` | 在牆上放置窗。 |
| `XATTACH` | `XA` | 將另一個 DWG 或 DXF 連結至此圖形，以唯讀方式顯示（XREF 可列出並重新載入它們） |
| `XCLIP` | `XC` | 將區塊參照與外部參考圖形裁切為矩形或多邊形，或移除其裁切。 |
| `XLINE` | `XL` | 參考線，兩端皆無限延伸：通過兩點、水平、垂直、以某角度、等分某角，或自直線偏移。 |
| `XREF` | `XR`, `-XREF` | 外部參考圖形：列出、附加、重新載入、繫結、分離 |
| `ZOOM` | `Z` | 範圍，或視窗 |
