這是 CadCraft 0.9 與 0.8.1 相比的變更內容。CadCraft 是 CadCraft Studio 0.9 及其八個應用程式中的 2D 與 3D 繪圖應用程式。0.9 完成平面製圖，新增文字樣式與真正的文字編輯器，並讓畫面有更多空間。

## 新增

### 平面製圖

- **依邊界變動的填滿。** {{cmd:HATCH}} 會連結到界定它的邊界。移動、旋轉或縮放邊界時，填滿與其圖案會跟著變動；重新調整邊界形狀時，填滿會重新計算。{{cmd:HATCHEDIT}} (`HE`) 可在之後變更填滿，並建立或結束此連結。請見[填滿與填充區域](topic:hatch)。
- **填滿圖案檔。** 在 {{cmd:HATCH}} 的提示 `Pick internal point` 中，輸入 `F`（圖案檔），然後選擇 `.pat` 檔。僅測試過依一般格式寫成的檔案。
- **圖層群組。** 在{{ui:圖層}}面板的{{ui:工具}}中：{{ui:新增群組}}、{{ui:加入現成群組}}、{{ui:依名稱分組}}與{{ui:尋找圖層}}；或輸入 {{cmd:LAYGROUP}} (`LG`)。請見[用圖層整理圖形](topic:layers#group-layers)。
- **堆疊樓層。** {{cmd:FLOORS}} (`FLR`)，或{{ui:視圖}}群組的{{ui:更多}}功能表中的{{ui:樓層…}}。圖紙上的視埠可在特性中以{{ui:顯示的樓層}}顯示某一樓層。{{cmd:FLOORLAYERS}} 會將樓層轉為圖層，供要傳給他人的檔案使用。請見[在同一圖形中堆疊樓層](topic:floors)。
- **2D 智慧牆、門與窗。** {{cmd:WALL}} (`WA`)、{{cmd:DOOR}} (`DR`)、{{cmd:WINDOW}} (`WN`) 與 {{cmd:DELOPENING}}。轉角、T 形接合與交叉處會自動計算。牆會記錄其接合方式，特性中新增「於起點／終點禁止接合」、位置列，以及可編輯的長度。請見[繪製 2D 牆、門與窗](topic:walls-2d)。
- **平面牆的牆工具。** 輸入 {{cmd:WALLRECT}}、{{cmd:WALLPOLY}}、{{cmd:WALLARC}}、{{cmd:WALLTRACE}}、{{cmd:WALLDIM}}、{{cmd:WALLOFFSET}}、{{cmd:WALLSPLIT}}、{{cmd:WALLGRID}} 等其餘指令。目前尚未有工具列按鈕。請見[2D 牆的形狀、切割、偏移與鎖定](topic:wall-tools-2d)。

### 文字

- **文字樣式。** {{cmd:STYLE}} (`ST`)，或{{ui:繪製}}工具列上的{{ui:文字樣式}}：具名樣式，包含字型、高度、寬度比例與傾斜。請見[以文字樣式設定文字的字型與大小](topic:text-styles)。
- **格式化段落文字編輯器。** {{cmd:MTEXT}}、{{cmd:TEXTEDIT}}，或在文字上連按兩下，會開啟一個方塊，可設定字型、大小、粗體、斜體、底線、刪除線、顏色與對齊，以及度、正負與直徑符號，另有{{ui:確定}}與{{ui:取消}}。請見[設定段落文字格式](topic:format-paragraph-text)。
- **由 draw.io XML 產生圖表。** {{cmd:DIAGRAM}} (`T2D`) 也能讀取貼上的 draw.io XML。請見[從文字繪製圖表](topic:text-to-diagram)。
- **PDF 列印中的泰文。** 先前會以問號列印。

### 更多空間與繪圖輔助

- **浮動且較細的指令列與精簡的頂部區域。** 拖曳指令列的夾點即可浮動，拖曳其上緣可減少行數，按 {{key:F2}} 開啟歷程記錄。{{ui:設定}} › {{ui:CadCraft}} › {{ui:指令列}}及頂部區域的選項中也有相同設定。請見[設定](topic:settings#command-line)。
- **物件鎖點選單。** 在狀態列中以滑鼠右鍵按一下{{ui:鎖點}}，或輸入 {{cmd:OSNAP}}。
- **貼齊格點。** 狀態列中的{{ui:格點鎖點}}按鈕，或 {{key:F9}}：當物件鎖點未捕捉到點時，所選的點會移到最近的格點。
- **十種畫弧方式，以及接續。** 繪製工具列的{{ui:圓弧}}或 {{cmd:ARC}}：三點、起點／圓心／端點系列，以及圓心／起點／端點系列，另有接續（在起點按 {{key:Enter}}），可接續上一條直線、圓弧或聚合線。
- **文件面板。** {{cmd:DOCUMENTS}} (`DOCS`)，或{{ui:視圖}}群組的{{ui:更多}}功能表中的{{ui:文件…}}：顯示專案資料夾中每個圖形的修訂、狀態與簽出。以置中的對話方塊開啟。請見[文件](topic:documents)。

### 檔案

- **英國鋼材尺寸。** 標準面板中有 976 種斷面，可依圖紙上的寫法輸入（例如 `305x165x40 UB`）。
- **南非套件**（製圖做法與建築法規）以建築法規外掛的套件形式提供。數字尚未驗證。
- **CadCraft 外掛**，依需求加入，預設關閉：室內照明設計、晶片設計（HDL 至佈局）、路由器雕刻、電路模擬、滾子鏈輪，以及建築法規國家套件。

## 已修正

- 移動、旋轉或縮放填滿時，會留下其圖案。
- {{cmd:GRIDMOVE}} 會帶動只從格線開始的整段平面牆。現在依牆的端點判斷。
- 即使關閉界限，格線仍只顯示在圖形界限之內。
- 側邊面板中的區塊清單可捲動；名稱不是區塊時，會列出以該名稱開頭的區塊（「是否要找」）。
- AutoCAD 拒絕開啟的 DXF R12 檔案（"Unknown group 1001 for table"）現可在此開啟。
- 約 70,000 個物件以上的大型檔案，開啟時曾出現 "Maximum call stack size exceeded" 而失敗。
- AutoCAD 2018 及之後、維護版本較高的 DWG 檔案，曾出現 "bad BITLONG code 11" 而無法開啟。
- 段落文字方塊中，為已選取的部分輸入新大小時，會保留選取狀態。

## 所有應用程式中

所有有提示的控制項皆有 Bootstrap 工具提示，另有可關閉的開始提示；索引標籤列在放不下時可捲動；瀏覽器分頁標題會跟隨開啟的圖形（`<drawing> - CadCraft | CadCraft`）。{{ui:設定}} › {{ui:版面}}現為含兩行選項的下拉式清單。{{ui:設定}}中的語言清單比 0.8 更長。即時協作、程式庫集合，以及重量與溫度單位，則在 Studio 說明中描述。

## 目前的限制

- 段落文字沒有項目符號或編號清單、定位點標尺或對齊。列印的 PDF 會以 Helvetica 字型排版文字。
- 平面牆為直線，因此圓弧會以短牆繪製。牆工具的社群手動檢查尚未完成。
- 圖層群組不以 AutoCAD 原生格式寫入，因此 AutoCAD 會顯示為平面清單。其他程式會將所有樓層一起顯示，除非執行 {{cmd:FLOORLAYERS}}。
- 文件面板尚未有兩人在真實的共用資料夾上測試。路由器雕刻尚未在任何真實機器上執行。照明估算是以光子追蹤檢查，而非以其他程式檢查。工程外掛是檢查輔助工具，並非工程師審查的替代品。
- 英文以外的語言為機器草稿，部分新詞僅有英文。

## 較早版本：0.8 與 0.8.1

本節為 CadCraft 0.8 與 0.8.1 相較於 0.7 的變更內容。0.8（2026 年 11 月 1 日）新增可依圖形本身運作的繪圖輔助工具，依電腦上的規則運作，不需模型；0.8.1（2026 年 11 月 2 日）修正發布後回報的錯誤。

### 新增

**圖形會接續思路**

- **幽靈顯示接下來的內容。** 未執行指令時，灰色虛線幽靈會依圖形既有的圖樣顯示接下來的內容：同間距的下一根柱、樓梯的下一階、房間缺少的那面牆。按 {{key:Tab}} 可將其繪製為一個復原步驟，按 {{key:Esc}} 則關閉。它只檢查最新的物件，因此大型圖形上仍保持流暢。可在{{ui:設定}} › {{ui:CadCraft}}中關閉，或以 {{cmd:AUTOCOMPLETE}} `Off` 關閉。
- **繪製直線時的下一點。** 在 {{cmd:LINE}} 或 {{cmd:PLINE}} 過程中，幽靈會顯示下一點：樓梯的下一階、矩形的第四個角，或將其封閉的點。將游標靠近它並按 {{key:Tab}}，就如同在該處點選一下。
- **筆繪草圖變為精確幾何。** {{cmd:SKETCHFIX}}：以筆、滑鼠或手指畫出粗略線條，每一筆都會變成整齊的直線、圓、圓弧、矩形或聚合線，並貼齊既有的圖形。請見[以筆繪草圖並取得精確幾何](topic:sketch-with-a-pen)。
- **草圖照片變為圖形。** {{cmd:PHOTOSKETCH}} (`PSK`) 會在照片中找出紙張、校正透視，套用指定的紙張尺寸與比例，並為每種筆色將筆線描繪到一個圖層上。文字不會被描繪。
- **依規則標註尺寸。** {{cmd:AUTODIM}} (`ADIM`) 會沿所選的邊建立連續標註、整體尺寸、開口寬度與孔徑，並可搭配 `Grid` 標註格線間距。它不會重複已存在的標註。
- **移動格線，整組跟著移動。** {{cmd:GRIDMOVE}} (`GM`)：終止於格線的牆會隨之延伸，沿格線的牆、柱、格線泡泡與標籤會一起移動，而格線上的標註會量測新的間距。為一個復原步驟。

**圖紙、詳圖與標籤**

- **圖紙自動排版。** {{cmd:AUTOSHEET}} 會取用已命名的視圖（或模型中各自獨立的部分），選擇紙張尺寸與標準比例，並將視圖放到新圖紙上，附上標題欄與名稱及比例的標題文字。一切皆可編輯。請見[自動排版圖紙](topic:lay-out-sheets-for-me)。
- **公司自有的詳圖，於繪製時提供。** {{cmd:DETAILS}} (`DET`) 會保存公司自有的詳圖區塊。當所選內容與某個詳圖的圖層名稱、區塊名稱或註記中的文字相符時，狀態列會提示；選取它並放置即可。{{cmd:DETAILS}} › 分享會將清單放入文件資料夾，並納入團隊新增的內容。設定可關閉這些提示。
- **區塊上的標籤。** {{cmd:TAGS}} 定義標籤（其種類、可用的值、套用的區塊），將其設定到所選的區塊參照上，並列為可另存為 CSV 的明細表。定義保存在 DWG 中。請見[標籤](topic:tags)。
- **圖形範圍限制。** {{cmd:LIMITS}} 為圖形設定一個矩形：格線會填滿此範圍，範圍縮放會顯示它。界限以輪廓顯示，並與紙張界限一同儲存於 DWG 與 DXF 中。請見[設定圖形界限](topic:drawing-limits)。

**與他人及其他程式合作**

- **將標記轉為修訂。** {{cmd:REDLINE}} 會讀取 MarkupCraft 寫出的套件，並列出每一項變更。逐項接受或拒絕並附註；接受的項目會在一個復原步驟中取得修訂雲形與修訂紀錄，並儲存用來關閉 MarkupCraft 中標記的回覆檔。請見[將標記轉為修訂](topic:redline-to-revision)。
- **git 與 Fossil 可合併的圖形。** 在{{ui:設定}} › {{ui:CadCraft}}中開啟{{ui:適合合併的檔案}}後，每個物件都會取得永不變更的鍵值（檔案約大 10%）。`cadcraft merge base ours theirs` 會逐物件合併兩人對同一個 DWG 或 DXF 的編輯，且只回報兩人改動同一處的地方。請見[合併兩人對同一圖形的編輯](topic:merge-drawings)。
- **以文字說明變更內容。** 在歷程記錄中，比較會提供純文字清單：變更位置、範圍大小、新增、刪除或修改的內容，以及被編輯的文字。請見[以文字說明變更](topic:changes-in-words)。
- **方位角與角度。** 在任何需要輸入角度的地方，可輸入測量員的方位角（例如 N45°23'30"E），或以度、分、秒輸入方向；AUNITS 設定角度的顯示方式。請見[輸入與顯示方位角及角度](topic:bearings-and-angles)。
- **自有的 SHX 字型。** 給 CadCraft 一個 SHX 字型資料夾，以這些字型命名的文字樣式會以其繪製，包含螢幕與列印。請見[以自有的 SHX 字型繪製文字](topic:shx-fonts)。
- **由文字產生圖表。** {{cmd:DIAGRAM}} 會讀取 Mermaid 流程圖、PlantUML 元件圖、D2 或「從至」清單，並繪製可編輯的區塊與連接器。請見[從文字繪製圖表](topic:text-to-diagram)。
- **DWG 中的 OLE 物件。** {{cmd:OLELIST}} 會列出 DWG 中 CadCraft 無法自行放置的 OLE 物件，並可依指定的位置放置圖片副本。請見[圖片](topic:pictures#objects-from-other-programs-ole)。
- **計算保留在圖形中。** 計算表與設計理由會與類別表一同保存於 DWG 中。

**無需視力的製圖**

- 在{{ui:設定}}中開啟{{ui:無需視力的製圖}}（或輸入 {{cmd:ACCESS}} 並回答 `On`）。CadCraft 會透過螢幕閱讀器朗讀每個指令與結果，描述圖形與游標附近的內容，可用鍵盤移動游標並選點，每次捕捉與夾點都會播放聲音。若瀏覽器能在電腦上辨識語音，即可以語音下達指令。請見[無需視力製圖](topic:draft-without-sight)。

**所有應用程式中**

- **語言。** 共 54 種語言；其中十種為新增（立陶宛語、拉脫維亞語、波士尼亞語、馬拉地語、泰盧固語、阿爾巴尼亞語、南非荷蘭語、菲律賓語、史瓦希里語、烏茲別克語）。英文以外的語言在母語人士審閱前皆為機器草稿。
- **輸入裝置。** 觸控板、筆、3D 滑鼠、遊戲控制器與 MIDI 控制。
- **工具列列數與屬性格線。** {{ui:設定}} › {{ui:一般}} › {{ui:工具列列數}}在其他應用程式中提供換行、2 列或 1 列。CadCraft 在{{ui:設定}} › {{ui:CadCraft}}中保有自己的設定（請見[工具列列數](topic:settings#toolbar-rows)）。共用的屬性格線位於其他三個應用程式中，不在 CadCraft 中。
- **問題、Live 與外掛。** 一個在每個應用程式中都會提出警告的共用{{ui:問題}}面板、CadCraft Studio 中顯示成員所在位置的 Live 檢視（請見[與他人一同編輯圖形](topic:work-live)），以及外掛清單。
- **連接 AI。** 從 CadCraft Studio 一次連接八個應用程式，每個應用程式可設定唯讀、建議或編輯等級，並有以淺白文字記錄助理所做事項的日誌。CadCraft 本身沒有 AI，而每個應用程式中的詢問會使用所連接的 AI。

### 0.8.1 已修正

- **在英尺與英吋圖形中，特性曾顯示 150 而非 12'-6"。** 應用程式自行讀取的欄位會再次保留其文字。
- **類別區段被以錯誤類型讀取的 DWG 檔案**（GitHub cadcraft#5）現可正確開啟。
- **十字游標不再顯示於彈出視窗後方。**
- **Studio 與打包版可於執行時切換語言。** 先前僅提供英文。尚未在每個平台測試：若語言未改變，請回報。
- **直向的平板**會將多餘的格線高度讓給畫布，而圖紙模式在 760 px 或以下時啟動。
- **含交叉視窗的 STRETCH 與 LIMITS** 曾在 Studio 0.8.0 被回報，但在 0.8 網頁版中本已正確；回報者的安裝程式較舊。Studio 0.8.1 已包含修正。

### 本版尚未提供

- **0.8 與 0.8.1 未經程式碼簽章。** Windows 可能會發出警告（選擇{{ui:更多資訊}}，然後{{ui:仍要執行}}）；在 Mac 上，以右鍵按一下 CadCraft Studio 並選擇{{ui:開啟}}。商店版本暫緩發佈，且 iPad 與 iPhone 版本未為 0.8.1 重新建置。
- **筆繪草圖與草圖照片**僅以模擬照片與滑鼠測試，尚未以真正的筆、觸控螢幕或紙上手繪草圖測試。
- **無需視力的製圖**已以自動化檢查測試，尚未以螢幕閱讀器或視障測試人員測試。
- **分享詳圖**尚未經過兩人檢查，且以 Team Cloud Plan 資料夾作為文件資料夾的功能尚未建置。
- **合併**適用於 CadCraft 的 DWG 與 DXF 檔案；其他應用程式檔案的合併尚未建置。

- **讀取其他程式的列印樣式表（CTB 檔）**已建置，但尚未以其他程式的檔案核對。
- **連接 AI：**Studio 中的一鍵連接、供瀏覽器 AI 使用的託管連接器、Studio 內自備的 API 金鑰，以及已發佈的 MCP 套件，皆未承諾於本版提供。
