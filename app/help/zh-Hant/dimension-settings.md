## 你將學到什麼

標註的文字與箭頭有多大、如何為以 1:50 或 1:100 出圖的圖形設定它們，以及如何變更你已經建立的標註。

## 標註尺寸如何運作

每個標註都帶有自己的一組尺寸：文字高度、箭頭大小、小數位數、文字周圍的間距、延伸線超出標註線的距離，以及延伸線與物件的起始距離。預設值接近常見的 ISO 樣式：

| 設定 | 預設值 | 指令 |
|---|---|---|
| 文字高度 | 2.5 | {{cmd:DIMTXT}} |
| 箭頭大小 | 2.5 | {{cmd:DIMASZ}} |
| 小數位數 | 2（捨去末尾的零） | {{cmd:DIMDEC}} |
| 文字周圍間距 | 0.625 | {{cmd:DIMGAP}} |
| 超出標註線的延伸 | 1.25 | {{cmd:DIMEXE}} |
| 與物件的偏移 | 0.625 | {{cmd:DIMEXO}} |
| 整體比例 | 1 | {{cmd:DIMSCALE}} |

每個尺寸都會乘以**整體比例**。請依你想在圖紙上呈現的大小設定尺寸（2.5 毫米文字），並將整體比例設為出圖比例（1:50 則為 50）。如此，文字高度為 2.5 × 50 = 125 圖形單位，出圖時即為 2.5 毫米。

:::note
具名標註樣式以{{cmd:DIMSTYLE}}管理：參見下方章節。每個標註也會保留它建立時的設定，因此你仍可在{{ui:屬性}}中單獨變更某一個標註。
:::

## 設定新標註的尺寸

以下任一方式都只會變更你之後建立的標註。

### 在「目前設定」面板中

1. 按{{key:Esc}}，使沒有任何物件被選取。在{{ui:模型}}索引標籤上，右側面板會顯示{{ui:目前設定}}。
2. 將面板向下捲動至{{ui:新標註}}，越過圖層、顏色、單位與{{ui:圖層 0}}列（在小螢幕上，它會從底部邊緣之下開始）。按一下{{ui:整體比例}}，輸入`50`後按{{key:Enter}}。
3. 若要其他值，請以相同方式設定{{ui:文字高度}}、{{ui:箭頭大小}}與{{ui:小數位數}}。

狀態列會確認每一項，例如「新標註的整體比例：50」。

### 在指令列中

1. 輸入`DIMSCALE`後按{{key:Enter}}。
2. 在`Enter new value for DIMSCALE <1>`提示中，輸入`50`後按{{key:Enter}}。

歷程會確認「DIMSCALE = 50。新標註會使用它；請選取既有的標註以變更其比例。」{{cmd:DIMTXT}}、{{cmd:DIMASZ}}、{{cmd:DIMDEC}}、{{cmd:DIMGAP}}、{{cmd:DIMEXE}}與{{cmd:DIMEXO}}的運作方式相同。在提示中按{{key:Enter}}即可保留目前的值。

### 標註中的英尺與英寸

新標註會使用圖形的長度格式：可在{{ui:目前設定}}中的{{ui:長度格式}}或以{{cmd:UNITS}}設定（參見[英尺與英寸](topic:units-papers-scales#feet-and-inches-and-fractions)），下一個標註會顯示為`12'-6 1/2"`。{{cmd:DIMLUNIT}}只設定標註的格式（2 為小數、3 為工程、4 為建築、5 為分數）。對於你已建立的標註，請選取它，並在{{ui:屬性}}中選擇{{ui:格式}}；若為分數格式，其{{ui:分數}}方塊接受 2 的冪次（4 = 1/16）。

## 以毫米、公分、公尺或公里計的標註

標註以圖形單位量測。它可以改用毫米、公分、公尺或公里書寫該長度，單位接在數字後面：1250 毫米的牆會顯示為`1250 mm`、`125 cm`、`1.25 m`或`0.00125 km`。

1. 先在{{ui:目前設定}}中設定圖形的{{ui:單位}}（參見[單位、紙張尺寸與比例](topic:units-papers-scales#drawing-units)），讓 CadCraft 知道一個圖形單位代表什麼。沒有單位的圖形會被讀為毫米，{{cmd:DIMTEXTUNIT}}會說明這一點。
2. 對於新標註：按{{key:Esc}}使沒有任何物件被選取，然後在{{ui:新標註}}下選擇{{ui:文字中的單位}}：{{ui:圖形單位}}、`mm`、`cm`、`m`或`km`。
3. 對於你已建立的標註：選取它們，然後在{{ui:屬性}} › {{ui:主要單位}}中選擇{{ui:文字中的單位}}。

或輸入{{cmd:DIMTEXTUNIT}}（`DTU`），並回答`D`、`MM`、`CM`、`M`或`KM`：若已選取標註，會變更它們（為一個復原步驟）；若沒有選取任何物件，則設定新標註。

{{ui:小數位數}}（{{cmd:DIMDEC}}）仍會設定顯示的小數位數：以公尺且 3 位小數時，1234 毫米顯示為`1.234 m`。文字以小數數字書寫。在配置上，標註會以配置的紙張單位（毫米或英寸）量測。

已儲存的 DWG 或 DXF 會將此選擇保留為標註的量測比例（DIMLFAC）與後綴（DIMPOST，` m`），因此其他程式顯示的文字相同。若你之後變更圖形的{{ui:單位}}，以毫米、公分、公尺或公里書寫的標註會被重新調整，因此它們仍會正確顯示長度。{{ui:手動設定（比例或後綴）}}表示該標註的{{ui:量測比例}}或後綴是以其他方式設定的；選擇一個單位即可取代它們。

## 變更你已建立的標註

1. 按一下一個標註。右側面板的標題會顯示{{ui:標註}}。
2. 設定項目分為多個區段；向下捲動面板以找到後面的區段：
   - {{ui:一般}}：{{ui:標註樣式}}
   - {{ui:幾何}}：{{ui:類型}}與{{ui:量測值}}（唯讀）
   - {{ui:文字}}：{{ui:文字覆寫}}與{{ui:文字高度}}
   - {{ui:線條與箭頭}}：{{ui:箭頭大小}}
   - {{ui:配合}}：{{ui:整體比例}}
   - {{ui:主要單位}}：{{ui:小數位數}}
3. 輸入新值，然後按{{key:Enter}}。

標註會立即重新繪製。對於角度標註，{{ui:小數位數 (°)}}會設定角度的小數位數。

:::note
選取多個標註時，面板會顯示它們共用的列；若它們之間的值不同，則會顯示{{ui:各異}}。你輸入的值會在一個步驟中變更所有已選取的標註，因此一次{{key:Mod+Z}}即可全部還原。
:::

## 來自已開啟圖形的標註

從已開啟的 DWG 或 DXF 而來的標註，會完全依照另一個程式的繪製方式顯示。其面板會說明「依建立它的程式所繪製的方式顯示。變更後，CadCraft 會以其自身的樣式重新繪製。」一旦你變更任何值、移動夾點或移動該標註，CadCraft 就會以其自身的箭頭與字型重新繪製，並使用從檔案中讀取的尺寸。

有些標註只能以繪製的樣子讀取，而無法作為可編輯的標註；此時面板會顯示「繪製自」與區塊名稱，而「關於此檔案」方塊會計算它們的數量。

## 常見錯誤

- **變更 DIMSCALE 沒有改變螢幕上的任何東西。** 此設定是針對新標註。請選取既有的標註，並在面板中變更{{ui:整體比例}}。
- **小數位數顯示的位數比設定少。** 末尾的零會被捨去：2 位小數時顯示`1250`與`1250.5`，而非`1250.00`。
- **視埠中的文字在圖紙上的高度正確，但在模型出圖時錯誤。** 整體比例必須與你出圖的比例相符。若以「符合紙張」出圖會得到奇怪的比例；請在列印對話方塊中選擇標準比例。
- **文字中出現 mm 或 m 等單位。** 請選擇{{ui:文字中的單位}}（參見[以毫米、公分、公尺或公里計的標註](topic:dimension-settings#dimensions-in-mm-cm-m-or-km)）。若數字後要接其他文字，請在覆寫中輸入，例如`<> TYP.`。

## 具名標註樣式

輸入`DIMSTYLE`（`D`）以開啟{{ui:標註樣式管理員}}。它會列出圖形的樣式、每個樣式被多少標註使用，以及哪一個是目前樣式。**標準** 一律存在。

- {{ui:設為目前}}：新標註會使用該樣式的設定，並帶有其名稱。
- {{ui:新增…}}：新樣式，最初為你所選樣式的複本。
- {{ui:修改…}}：與{{ui:屬性}}中標註區段相同的欄位（線條與箭頭、文字、配合、單位、替代單位、公差）。按{{ui:確定}}後，樣式會變更，**且每個使用它的標註也會隨之變更**，逐一套用設定。你只對某個標註變更的設定會保持不變，除非該樣式也變更了該設定。
- {{ui:重新命名…}}與{{ui:刪除}}：無法重新命名或刪除**標準**樣式，也無法刪除目前樣式，或被標註使用中的樣式。
- {{ui:比較…}}：兩個樣式之間的差異。
- {{ui:套用至選取項目}}：先選取標註；它們會採用該樣式的設定與名稱。

`-DIMSTYLE`在指令列中做同樣的事：`Restore`、`Save`（目前的設定，包括你以{{cmd:DIMTXT}}等指令輸入的內容，以一個名稱儲存）、`Delete`、`Apply`、`Compare`、`reName`、`List`。

樣式會儲存在 DWG 或 DXF 中（其標註樣式表），並從你開啟的檔案中讀取。**目前**樣式不會被儲存：圖形開啟時，目前樣式為標準。當其他樣式為目前樣式時，標準仍保留它自己的設定。

## 變更標註文字與延伸線

{{cmd:DIMEDIT}}（`DED`）會作用於你選取的標註：**原位**會將文字放回樣式所定的位置，**新增**會輸入其他文字（`<>` 代表量測值），**旋轉**會旋轉文字，**傾斜**會將線性與對齊標註的延伸線傾斜到你輸入的角度（按{{key:Enter}}表示不傾斜）。{{cmd:DIMTEDIT}}會將文字移到標註線的**左**、**右**或**置中**，或將其旋轉（**角度**），或送回**原位**。文字始終位於標註線上：它無法被拖曳到任意位置。
