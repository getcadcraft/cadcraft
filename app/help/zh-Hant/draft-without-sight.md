**無障礙模式**讓你不必看螢幕也能繪圖。預設為關閉，因此不會有人誤開啟。

## 開啟

開啟**設定**（齒輪圖示，或按 Ctrl+,），找到**無視覺製圖**並選擇**開啟**。或在指令列輸入 `ACCESS`，並回答 `On`。此設定會記錄在這台電腦上。

開啟無障礙模式後：

- **指令列的所有內容都會透過螢幕閱讀器朗讀**：你輸入的內容、它詢問的提示、你的回答，以及每個錯誤。CadCraft 使用自己的禮貌與緊急即時區域，因此支援即時區域的螢幕閱讀器無需額外設定。錯誤與取消會立即中斷朗讀；其他內容則依序等待。
- **可以到達繪圖區域**：按 Tab 直到聽見「圖形」，或在指令列按 Shift+Tab。這是一個會將按鍵傳送給 CadCraft 的區域。

## 圖形上的按鍵

| 按鍵 | 功能 |
|---|---|
| 方向鍵 | 移動鍵盤游標。每一步約為螢幕所示範圍的百分之一，四捨五入為 1、2 或 5。按 Shift 移動十倍距離，按 Ctrl 移動十分之一。 |
| Enter | 選取游標下的點，與點擊的效果相同。 |
| Space | 在指令列按 Enter：結束 LINE，採用預設值。 |
| Tab、Shift+Tab | 跳到游標附近的下一個或上一個鎖點，依距離由近到遠。 |
| G | 逐一切換所選物件的夾點。 |
| D | 描述圖形：物件數量、類型、大小，以及選取的內容。 |
| W | 說明游標位置，以及它與上一個點的距離。 |
| N | 說明游標附近的內容，依距離由近到遠，並附上距離與方位。 |
| S | 描述所選物件。 |
| R | 重複朗讀上一次的內容。 |
| V | 開啟或關閉語音。 |
| / | 移到指令列。 |
| ? | 列出這些按鍵。 |

用按鍵移動時，會說明你移到的位置。當指令正在等待一個點時，也會說明你與上一個點相距多遠、位於哪個方向，例如「距上一點 2400，朝右，角度 0 度」。

## 指令

- {{cmd:ACCESS}} 開啟或關閉無障礙模式、鎖點音效與語音，並說明目前狀態。
- {{cmd:DESCRIBE}} 說明圖形包含的內容。
- {{cmd:WHEREAMI}} 說明游標位置。
- {{cmd:NEARBY}} 說明游標附近的內容。
- {{cmd:SAYSEL}} 說明目前選取的內容，每個物件一句。
- {{cmd:VOICE}} 開啟或關閉語音指令。

這五個指令會讀取圖形並輸出回答；它們不會變更任何內容。

## 鎖點與夾點的音效

在**設定**中開啟**鎖點與夾點音效**。每種鎖點類型都有自己的音高與聲音，讓你能分辨端點、中點、圓心、交點等其他類型；夾點則會發出雙重滴答聲。音效會依游標在螢幕上的位置，左右移動。音效由你的電腦產生；不會下載任何內容。

## 語音指令

在**設定**中開啟**語音指令**。說出指令名稱（「line」、「circle」、「move」），然後像唸出來一樣說出數字：「點 三百 逗號 四百」、「距離 一千二百」、「角度 四十五」。「Enter」、「取消」、「復原」與「取消復原」會執行它們所說的動作。系統會將聽到的內容唸回給你；不是指令的語句會被回報，而不會被猜測。

**語音辨識的地點。** CadCraft 沒有自己的語音服務，也不會將任何音訊傳送到他處。它會要求你的瀏覽器在這台電腦上辨識語音。若瀏覽器支援，選項為**在此電腦上**，音訊不會離開電腦。若不支援，語音會保持關閉，除非你選擇**瀏覽器線上服務**，那會讓瀏覽器將音訊傳送給其廠商的語音服務。在你決定之前，設定會說明適用哪一種情況。

## 尚未實作的部分

- 只有 CadCraft 具備無障礙模式。其他八個應用程式會依照相同的按鍵與音效陸續跟上。
- 圖形中的文字（註解、區塊名稱）會依書寫的內容朗讀；絕不會被當作指令。
- 目前已透過合成檢查與瀏覽器測試進行驗證；使用 NVDA、VoiceOver 以及盲人或低視力測試人員進行的實際檢查尚未完成。如果你試用，請告訴我們缺少了什麼。
