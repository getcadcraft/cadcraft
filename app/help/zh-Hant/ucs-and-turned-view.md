## 你將學到的內容

如何轉動檢視圖形，使以斜角繪製的建築物在螢幕上呈現為正交，以及如何沿其自身的軸線輸入點。進行這些操作時，圖形中的任何內容都不會移動：物件保留其座標，轉動不是編輯，圖形也不會被標記為已變更。

## 將視圖轉動四分之一圈

1. 點選{{ui:視圖}} › {{ui:更多}} › {{ui:將視圖向左轉 90°}}或{{ui:將視圖向右轉 90°}}。

圖形會以繪圖區的中心在螢幕上轉動。再次執行即可繼續轉動。

2. 點選{{ui:視圖}} › {{ui:更多}} › {{ui:回到世界座標}}，將其重新調整為水平。

它們背後的指令是 {{cmd:TURNLEFT}}、{{cmd:TURNRIGHT}} 與 {{cmd:TURNWORLD}}。若要為其指定按鍵，請使用 {{cmd:ALIASEDIT}} 在別名中加入如 `TL=TURNLEFT` 的一行。

## 與斜向建築物對齊

1. 輸入 `UCS` 並按 {{key:Enter}}，然後輸入 `OB` 並按 {{key:Enter}}。
2. 點選應作為原點的那一端附近的牆線。

UCS 現在會從該端開始，其 X 軸沿著牆，且視圖會轉動，使牆在螢幕上呈水平。左下角的座標軸圖示顯示 UCS 各軸的指向。

3. 照常繪圖。設定 UCS 後：
   - `x,y` 與 `@dx,dy` 是沿 UCS 軸量測的；`d<a` 是從 UCS X 軸量測的角度。
   - {{ui:正交}}、極軸追蹤與格點會依 UCS 軸定向，十字游標亦然。
   - 新文字與新段落沿 UCS X 軸排列；{{cmd:DIMLINEAR}} 的水平與垂直標註也會跟隨它。
   - 狀態列與 {{cmd:ID}} 顯示的座標為 UCS 座標。
4. 若要在設定 UCS 時輸入世界座標的點，請在前面加上 `*`：`*0,0` 或 `@*100,0`。
5. 輸入 `UCS`，按 {{key:Enter}}，然後再按一次 {{key:Enter}}，即可回到世界座標。

## 其他設定 UCS 的方式

在 {{cmd:UCS}} 提示下：

| 你輸入的內容 | 作用 |
|---|---|
| 一個點 | 新的原點；然後點選新 X 軸上的一點，或按 {{key:Enter}} 保留角度 |
| `Z` | 以你輸入（以度為單位，逆時針）或點選的角度，繞其原點轉動 UCS |
| `3`（3point） | 一個原點、正 X 軸上的一點，以及正 Y 側的一點 |
| `OB`（OBject） | 由線、圓弧、圓、聚合線線段、文字、區塊參照、點或構造線定義 |
| `P`（Previous） | 此 UCS 之前的 UCS（在圖形開啟期間保留最近十個） |
| `W`（World） | 回到世界座標 |
| `NA`（NAmed） | `S` 以名稱儲存目前的 UCS，`R` 還原一個，`D` 刪除一個，`?` 列出所有 |

每次變更都會轉動視圖，使新的 UCS X 軸呈水平。{{cmd:PLAN}} 會在不變更 UCS 的情況下轉動視圖：{{key:Enter}} 為目前的 UCS，`U` 為已儲存的 UCS，`W` 為世界座標。

## 補充說明

- 分割畫面中的每個窗格各自保留其轉動角度。UCS 屬於圖形。
- 配置以圖紙座標運作；請在{{ui:模型}}索引標籤上，或在視埠內設定 UCS。
- 在轉動後的視圖中拖曳的選取視窗，會選取螢幕上位於其中的內容。
- LISP 常式透過 `getpoint` 取得 UCS 中的點，可讀取 `UCSORG`、`UCSXDIR`、`UCSYDIR` 與 `VIEWTWIST`，而 `trans` 可在世界座標、UCS 與顯示之間轉換。

:::note
儲存的檔案會在之後的版本中保留 UCS 與視圖的轉動角度；在此之前，它們只在圖形開啟期間有效。
:::
