## 點

當提示要求輸入點時，輸入以下其中一種，然後按{{key:Enter}}：

| 輸入 | 意義 | 範例 |
|---|---|---|
| `x,y` | 絕對座標：從原點 0,0 量測 | `2500,1200` |
| `#x,y` | 同樣為絕對座標（為相容習慣而接受） | `#2500,1200` |
| `@dx,dy` | 相對座標：從上一點向右及向上 | `@600,0` |
| `@d<a` | 相對極座標：從上一點的距離與角度 | `@1500<45` |
| `d<a` | 絕對極座標：從原點的距離與角度 | `3000<90` |
| 單一數字 | 直接距離：從基點朝十字游標方向量取該距離 | `1200` |
| `*x,y`、`@*dx,dy` | 設定 UCS 時的世界座標 | `*0,0` |

設定 UCS（{{cmd:UCS}}）時，`x,y`、`@dx,dy` 與 `d<a` 中的角度，都是沿 UCS 軸量測。參見[旋轉檢視與使用自訂座標](topic:ucs-and-turned-view)。

你也可以在圖面中按一下；物件鎖點與正交對按一下同樣有效。

規則：

- 逗號分隔 X 與 Y。小數點使用句點：`1250.75,300`。
- 負值向左及向下：`@-600,0`。
- 不要輸入空白：{{key:Space}} 會送出該行，如同{{key:Enter}}。
- 數字可使用指數：`1e3` 即 1000。
- 不需輸入單位，也不能使用英尺與英寸的表示法。請以圖形單位輸入純數字。

## 上一點

`@` 從**你在任何點提示中最後給出的點**計算，適用於任何指令：按一下、鎖點或輸入的點都算。它會在指令之間被記住，因此你可以從上一條線的終點，以`@0,500`開始新的直線。在你給出任何點之前，`@` 從 0,0 計算。

以下幾種情況特別需要注意：

- 在{{cmd:COPY}}中，第一次複製之後，上一點就是該複本的點。兩次`@600,0`會將複本放在距原物件 600 與 1200 處。
- 放置標註後，上一點是你放置標註線的位置，而非標註的終點。

有疑問時，請使用絕對點、鎖點或直接距離。

## 直接距離輸入

單一數字是從指令的**基點**（橡皮筋線的起點）朝十字游標方向量取的距離：

1. 將十字游標移向你要的方向。
2. 輸入距離，然後按{{key:Enter}}。

開啟{{ui:正交}}時，方向會對齊為水平或垂直，因此這是繪製方形牆最快的方式。若沒有基點，或十字游標恰好位於基點上，該數字會被拒絕，並顯示「需要點或選項關鍵字。」

## 角度

- 以度為單位的純數字：`30`、`-45`、`112.5`。
- 從正 X 方向（指向右）逆時針量測：0 為右，90 為上，180 為左，270 或 -90 為下。
- 在要求角度的地方（旋轉、文字角度），你也可以按一下：角度是從基點量到該點。在基點建立之前，第一次按一下會設定基點，而提示會要求第二點。

## 距離

在要求距離的地方（半徑、偏移、文字高度、縮放比例）：

- 輸入正數（在英尺與英寸的圖形中，也可輸入`12'6"`或`6-1/2`：參見[英尺與英寸](topic:units-papers-scales#feet-and-inches-and-fractions)），或
- 按一下一點：從指令的基點到該點的距離，或
- 當沒有基點時，按兩點：提示會變為`Specify second point`。

「需要正數或兩點。」表示輸入的值不是數字，或為負數。

## 輸入值中的算術

在任何需要輸入長度、座標、角度或數字的地方（指令列、動態輸入、{{ui:屬性}}方塊與對話方塊），你可以用`+`、`-`、`*`、`/`與括號輸入計算式，而不必先自行算出結果：

| 輸入 | 結果 |
|---|---|
| `4+7/16` | 4.4375 |
| `12'6"+3/4"` | 12'-6 3/4"（在英尺與英寸的圖形中） |
| `(24'-0")/3` | 8'-0" |
| `2*450mm` | 900 mm，以圖形單位表示（當其單位已設定時） |
| `@4+7/16,0` | 位於上一點右側 4.4375 處的點 |
| `360/7` | 51.43 度的角度 |

- 寫入長度中的破折號仍屬於該長度：`4-7/16` 為 4 又 7/16，`24'-6"` 為 24 英尺 6 英寸。若要在英尺符號後做減法，請先完成長度再減，例如`24'-0"-6"`，或將計算式放入括號，並在破折號前後加上空格，例如`(24' - 6")`（在括號內，空格即為空格；在其他地方，則會按下{{key:Enter}}）。
- 加在長度上的純數字以圖形單位計；乘以或除以一個數字則會縮放該長度。兩個長度相乘會成為面積，因此`2'*3'`會被拒絕。
- `abs`、`round`、`ceil` 與 `floor` 也可使用：`round(10/3)`。
- 無法讀取的計算式會被拒絕，並指出錯誤位置，例如「計算式過早結束（第 3 個字元）：缺少一個值。」絕不會被當作 0 讀取。{{cmd:CAL}} 會顯示計算式的值。

## 動態輸入

{{ui:動態}}（{{key:F12}}，位於狀態列）會在指令要求點時，將數值顯示在十字游標旁。

- 尚未有基點時（直線的第一點），兩個欄位為 **X** 與 **Y**。
- 之後，欄位為從上一點量得的**距離**與**角度**。

輸入仍會進入指令列；十字游標旁的欄位會顯示輸入內容，橡皮筋線也會跟著它移動。

1. 輸入一個值：它會進入反白的欄位。
2. 按{{key:Tab}}（或在 X 後輸入逗號）。該值會被鎖定（以粗體顯示），下一個欄位會反白。鎖定的距離會在你以滑鼠瞄準時，讓橡皮筋線保持該長度。
3. 輸入第二個值，或只需瞄準，然後按{{key:Enter}}。`50`、{{key:Tab}}、`90`、{{key:Enter}} 會從上一點向上繪製 50。

若在輸入一個值後不按{{key:Tab}}直接按{{key:Enter}}，其作用與直接距離輸入相同。英尺與英寸在欄位中同樣適用（`12'6"`）。距離與角度提示（圓的半徑、旋轉）也會在十字游標旁顯示其值。

## 選項與預設值

- 選項會以方括號顯示。輸入選項的大寫字母（`D`對應`[Diameter]`，`CL`對應`CLose`）後按{{key:Enter}}。選項單字較長的開頭也可使用（`DIA`）。
- 預設值會以角括號顯示，例如`<500>`。按{{key:Enter}}或按右鍵即可使用。

## 其他鍵盤配置與數字鍵台

指令名稱、簡稱與選項字母都是拉丁字母。當你使用希臘文、西里爾文（俄文、烏克蘭文、白俄羅斯文、塞爾維亞文、馬其頓文、保加利亞文）、希伯來文、阿拉伯文、波斯文、泰文或韓文鍵盤配置時，不需要切換配置：當你輸入的字詞按原樣不是指令、簡稱或選項時，CadCraft 會依你按下的按鍵來讀取它。標示為`L`的拉丁鍵盤按鍵仍會啟動`LINE`，而`C`鍵仍會回答`Close`，不論該配置在它上面印的是什麼字母。上方指令列的相符指令清單也遵循同樣的規則。在指令要求文字的地方所輸入的文字（{{cmd:TEXT}} 的內容、名稱）絕不會被更改。

在數字鍵台的小數點鍵會輸入逗號的配置上，該鍵會在指令列與數字方塊中輸入一個點，因此可以用數字鍵台輸入`12.5`。主鍵盤上的逗號鍵仍用來分隔`x,y`。

這兩項都可以在{{ui:設定}}中關閉：{{ui:Commands on a non-Latin keyboard layout}} 與 {{ui:Keypad decimal key}}。

## 座標顯示

狀態列會顯示十字游標的 X 與 Y（若已設定 UCS，則為 UCS 中的座標），已套用鎖點與正交。當指令具有基點時，會加上`Δ`，並顯示距該點的距離與角度，例如`Δ 1500 < 30°`：即你會輸入為`@1500<30`的數字。

使用{{cmd:ID}}列印點的座標，並使用{{cmd:DIST}}量測兩點之間的距離。
