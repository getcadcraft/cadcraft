## 學習目標

如何開啟屬性面板、一次變更一個或一百個物件、輸入含 Z 的精確座標、在任何數字欄位中使用運算式與單位，以及每種物件會顯示的內容。

## 開啟

面板位於右側。要將其移至前方：

- 按{{key:Mod+1}}，或輸入{{cmd:PROPERTIES}}（或 `PR`、`CH`、`MO`）。
- 按兩下物件（文字與多重引線會開啟其文字編輯器）。

面板與其他面板一樣可以移動：拖曳其把手可將其停駐於左側、右側或底部，或將其放在圖形上方使其浮動（請參閱[排列面板與使用第二個螢幕](common:arrange-panels)）。

### 收合

面板右上角的圖釘按鈕會開啟**自動隱藏**：面板會收合為右側邊緣的一條狀列，圖形則獲得更多空間。將指標移至該狀列（或按{{key:Mod+1}}）即可在圖形上方開啟；移開後會再次收合。再按一次圖釘即可保持開啟。{{cmd:PROPERTIESCLOSE}}也會收合它。

## 區段

屬性依可收合的區段分組：**一般**、**幾何**、**文字**、**線條與箭頭**、**調整**、**主要單位**、**替代單位**、**公差**、**圖樣**、**其他**，以及區塊的**屬性**與**程式庫項目**。按一下區段名稱即可收合或展開；CadCraft 會記住你收合了哪些區段。

拖曳名稱與數值之間的細線，可加寬或縮窄名稱欄。按兩下可還原。以鍵盤操作時，請讓其取得焦點，然後使用方向鍵。

## 變更數值

1. 按一下某一行。標題會顯示「直線」。
2. 按一下{{ui:長度}}。編輯時，欄位會顯示完整的數值，而非四捨五入的數值。
3. 輸入 `2500` 並按Enter鍵。該直線現在長度為 2500，並保留其起點與角度。

按Enter鍵或點選其他位置會套用數值；按{{key:Esc}}鍵會還原舊的數值。每項變更都是一個復原步驟。

### 運算式與單位

每個數字欄位都接受的內容不只是一般數字：

| 輸入內容 | 結果 |
|---|---|
| `=2*45` | 90 |
| `=sqrt(2)*100` | 141.4214 |
| `1/4`, `6-1/2` | 0.25, 6.5 |
| `12'6"`, `12'-6 1/2"` | 150, 150.5（英吋，在以英尺與英吋為單位的圖形中） |
| `900mm`, `3.5m`, `2ft` | 轉換為圖形的單位 |
| `45d30'`, `45°30'15"` | 45.5°, 45.5042°（角度欄位） |
| `0.5r`, `100g` | 弧度與百分度，以度數表示 |

帶單位的長度需要圖形已設定單位：請先在未選取任何物件的情況下，於{{ui:新物件}}下設定{{ui:單位}}。錯誤的輸入會被拒絕，面板下方會顯示附註，且不會有任何變更；它絕不會被儲存為 0。函式：sin、cos、tan、asin、acos、atan、atan2、sqrt、pow、exp、ln、log、abs、round、ceil、floor、min、max、if；角度以度為單位。

## 一次變更多個物件

1. 選取多個物件，例如 8 條直線與 4 個標註。
2. 標題會顯示「12 個物件」，頂端的清單會提供**全部（12）**、**直線（8）**與**標註（4）**。
3. **全部**會顯示每個物件所具有的內容（圖層、色彩、線型等）。選擇**標註（4）**可查看標註設定。
4. 變更一個數值，例如將{{ui:小數位數}}改為 `1`。

四個標註會在一個復原步驟中全部變更。顯示**各不相同**的欄位表示物件之間有差異；輸入數值會將其設定到所有物件上。位於鎖定圖層上的物件會保持不變，附註會說明有多少個。

## 所選物件的總計

選取多個物件時，頂端的{{ui:合計}}區段會說明：

- **物件**：每種類型的數量，例如「8 條直線、2 條聚合線、1 個圓」。
- **總長度**：直線、圓弧與聚合線的總和（雲形線也計入），以及共有多少個物件。
- **總面積**：封閉物件的總和：圓、完整橢圓、封閉聚合線與填滿（填滿的孔會被扣除）。

它們會以圖形的長度格式顯示（若圖形使用英尺與英吋，則以其顯示；面積則為平方英吋與平方英尺）。只要選取了物件，狀態列即會顯示相同的長度與面積；{{ui:設定}} › {{ui:CadCraft}} › {{ui:選取範圍的長度與面積}} › {{ui:隱藏}}可將其關閉。對於單一物件，{{ui:幾何}}會如以前一樣顯示其自身的長度與面積。

## 座標

每個點都會顯示 **X**、**Y** 與 **Z**：直線的起點與終點、圓心、插入點、文字位置、目前的聚合線頂點。直線還會顯示 **Delta X**、**Delta Y** 與 **Delta Z**（唯讀）。聚合線與填滿具有 **Elevation**（整個物件的一個 Z）。

點名稱旁的十字按鈕可讓你改為在圖形中選取它：按一下它，然後按一下新位置（鎖點可用）。數值為世界座標。

## 各類型顯示的內容

| 所選物件 | 可變更的內容 |
|---|---|
| 直線 | 起點與終點的 X、Y、Z；長度；角度 |
| 圓 | 圓心；半徑；直徑；周長；面積（各自會設定半徑） |
| 圓弧 | 圓心；半徑；起點與終點角度；總角度；弦長（顯示圓弧長度與面積） |
| 橢圓 | 圓心；長軸與短軸半徑；半徑比；長軸角度；起點與終點角度 |
| 聚合線 | 頂點瀏覽器（如下）；整體寬度；高程；封閉；封閉時的面積（以其中心縮放） |
| 文字 | 內容；樣式；對正；高度；旋轉；寬度係數；傾斜角；定義寬度；行距；註解；位置 |
| 區塊參照 | 插入點；旋轉；比例 X、Y、Z 與統一比例；屬性值 |
| 填滿 | 圖樣；比例；角度；原點；關聯；孤島偵測；背景色彩；高程 |
| 標註 | 見下方 |
| 多重引線 | 文字；高度；寬度；文字側；箭頭大小；落點距離；箭頭點 |
| 視埠 | 比例；圖紙上的中心與大小；模型中的視圖中心；開啟；鎖定顯示 |

### 聚合線頂點

{{ui:目前頂點}}會顯示下方的欄位屬於哪個頂點。使用箭頭按鈕，或輸入數字，即可移至其他頂點；頂點數量沒有上限。每個頂點具有 X、Y、起點與終點的線段寬度，以及從該點開始之線段的凸度（0 表示直線）。

## 標註

標註會顯示其**標註樣式**、它所量測的內容、其點，以及所有設定：

- **線條與箭頭：**每端的箭頭、箭頭大小、刻度大小、標註線與延伸線的色彩與線寬、隱藏任一半或任一延伸線、延伸線偏移與延伸量。
- **文字：**覆寫（留空則使用量測值；在你自己的文字中，`<>` 代表該值）、樣式、色彩、高度、偏移、垂直與水平位置、永遠水平、旋轉、背景填滿。
- **調整：**整體比例、基線間距、空間不足時移動的內容，以及文字移動。
- **主要單位：**格式、小數位數、捨入、前綴、字尾、量測比例、小數點符號、隱藏前導與尾隨零；角度則為角度格式與小數位數。
- **替代單位：**開啟或關閉、格式、小數位數、倍數（25.4 會將英吋轉為毫米）、捨入、前綴與字尾。
- **公差：**無、對稱、偏差、極限或基本，並包含上限與下限值、小數位數、高度與位置。

在已開啟的標註上變更其中任何設定，會捨棄其他程式為其製作的繪製結果，CadCraft 會重新繪製。

:::note
線性與對齊標註會繪製水平的文字位置（位於第一或第二延伸線旁）以及位於線下方的文字；其他標註則會保留並儲存這些設定，但尚未繪製。調整的選項會保留並儲存，但尚未繪製：CadCraft 會依其自身的規則放置文字（在線上方，若放不下則在外側）。
:::

## 未選取任何物件

未選取任何物件時，面板會顯示：

- **新物件：**新物件會取得的圖層、色彩、線型、線寬與文字高度；圖形的單位與長度格式；目前圖層的線型與線寬；新標註的大小。在配置上，圖紙名稱、紙張與方向會優先顯示。
- **視圖：**螢幕上所見內容的中心、高度與寬度。輸入數值即可將視圖移至該處。
- **其他：**UCS 圖示開啟或關閉、UCS（永遠為世界座標：CadCraft 尚無使用者座標系統），以及註解比例。

## 常見錯誤

- **在欄位中輸入內容沒有作用。** 按Enter鍵或點選其他位置以套用。欄位變紅並出現附註，表示該輸入被拒絕。
- **帶單位的長度被拒絕。** 圖形沒有單位。在未選取任何物件的情況下設定{{ui:單位}}。
- **只顯示圖層與色彩。** 已選取多種類型的物件，且選擇了**全部**。請在頂端清單中選取一種類型。
- **部分物件沒有變更。** 它們位於鎖定的圖層上。請在圖層面板中解除該圖層的鎖定。
- **輸入的字母進入了欄位。** 欄位取得游標時，按鍵會輸入至該處。按Enter鍵或{{key:Esc}}鍵，然後再輸入指令。
