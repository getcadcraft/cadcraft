## 學習內容

用兩種快速方式變更物件，且不需輸入指令：拖曳其**夾點**，或在右側的**屬性**面板中輸入新值。

## 夾點

在沒有執行任何指令時選取物件（一次最多 200 個），物件上會出現小方塊，這些就是夾點：

| 物件 | 夾點 |
|---|---|
| 直線 | 兩端，以及中點（移動整條直線） |
| 圓 | 圓心（移動它），以及圓周上的四個點（變更半徑） |
| 圓弧 | 圓心，以及兩端（變更起點與終點） |
| 聚合線 | 每個頂點 |
| 文字、點、區塊參照 | 插入點 |
| 橢圓 | 圓心 |
| 標註 | 定義點與標註線位置 |
| 視埠 | 圓心（移動它），以及四個角（調整大小） |

### 移動夾點

1. 繪製一條直線並點按它。會出現三個夾點。
2. 點按其中一端的夾點。狀態列會顯示「點按此夾點的新位置（按 Esc 可取消）。鎖點與正交皆會套用。」
3. 移動十字游標，會顯示預覽。
4. 點按新位置，或鎖點到另一個物件上的點後再點按。

直線的端點會移動，其餘部分保持不動。也可以在夾點上按住並拖曳，放開即為新位置。

:::note
無法為夾點輸入座標。若要精確定位，請使用鎖點對齊某個點，或在屬性面板中輸入數值。
:::

按{{key:Esc}}或點按滑鼠右鍵，即可取消夾點移動。

## 屬性

右側面板會顯示所選物件的屬性。

1. 點按一條直線。面板標題會顯示「直線」。
2. 在{{ui:長度}}中按一下，輸入`2500`後按{{key:Enter}}。

此直線現在精確為 2500 長，起點與角度保持不變。按{{key:Enter}}或點按其他位置會套用數值；按{{key:Esc}}則會還原舊值。每次變更都是一個復原步驟，即使同時變更多個物件也一樣。

欄位可輸入運算式（`=2*45`）與附單位的長度（`3'6"`、`900mm`），每個點都有 X、Y 與 Z，且可同時變更多個物件。以上內容皆見於[屬性面板](topic:properties-panel)。

## 常見錯誤

- **沒有出現夾點。** 正在執行指令（請按{{key:Esc}}），或選取了超過 200 個物件，或物件位於已鎖定的圖層上。
- **夾點跑到錯誤的位置。** 鎖點抓取了該點。點按時按住{{key:Shift}}即可忽略鎖點。
- **在屬性面板中輸入後沒有作用。** 按{{key:Enter}}或點按其他位置以套用。遭拒的輸入（零或負的長度與半徑，或不是數值的文字）會使欄位變紅，並說明原因。
- **輸入的字母跑進屬性欄位。** 欄位有游標時，按鍵會輸入到該欄位中。請按{{key:Enter}}或{{key:Esc}}，然後再輸入指令。
