## 所有尺寸共用一個表格

{{ui:參數}}面板（位於{{ui:參數化}}群組中的{{ui:參數}}按鈕，或輸入{{cmd:PARAMETERS}}）會同時列出所有尺寸限制條件（`d1`、`rad1`、`dia1`、`ang1`，或指定的名稱）以及使用者自訂的參數。任何名稱都可用於任何運算式。

每一列包含：

- **名稱**：輸入新名稱即可重新命名；所有使用它的運算式都會隨之更新。
- **運算式**：數字（`40`）或運算式（`width / 2 + gap`）。在其中輸入並按{{key:Enter}}，圖形即會跟隨變化。
- **值**：運算式計算出的結果。在由運算式驅動的列上，也可以在此輸入數字：CadCraft 會推算出其背後的參數。若`d1 = width / 2`，在 d1 的值中輸入`30`，會將`width`設為 60。

當兩個參數驅動同一個值（`width / 2 + gap`）時，對話方塊會詢問要變更哪一個。每次變更都是一個復原步驟（{{key:Mod+Z}}）。

## 新增參數

1. 開啟{{ui:參數}}面板。
2. 輸入名稱（`gap`）與值（`10`），然後選擇{{ui:加入}}。
3. 使用它：在 d1 的運算式中輸入`width / 2 + gap`，然後按{{key:Enter}}。

名稱必須以字母或`_`開頭，且只能包含字母、數字與`_`。函式名稱、`pi`與單位名稱不可作為名稱使用。

## 運算式

| 寫法 | 意義 |
|---|---|
| `+ - * / ^ %` | 加、減、乘、除、次方、餘數 |
| `( )` | 分組 |
| `sin cos tan asin acos atan atan2` | 以度為單位的三角函數 |
| `sqrt pow exp ln log abs sign` | 開方、次方、對數、絕對值、符號 |
| `ceil floor int round min max` | 進位、捨去、取整數、四捨五入、最小值與最大值 |
| `if(a > b, x, y)` | 條件選擇 |
| `pi` | 3.14159… |

數字可附帶單位：`25mm`、`1in`、`2'`、`90deg`。帶單位的長度會換算為毫米，因此僅在以毫米量測的圖形中使用單位；其他情況請輸入純數字。

## 在指令列中

`-PARAMETERS`可在不使用面板的情況下執行相同的功能：`N` 新增、`E` 編輯（也包括尺寸限制條件）、`R` 重新命名、`D` 刪除、`?` 列出。

## 會被拒絕的操作

- 運算式直接或透過其他參數而參照自身：「width、d1 互相使用。」
- 尺寸無法接受的值：負的長度，或超過 180° 的角度。
- 圖形因其他限制條件而無法接受的值：不會有任何變更，訊息會指出阻礙的限制條件。
- 刪除正被使用的參數：面板會提供先將其值寫入使用處的選項。尺寸限制條件的名稱是透過刪除該限制條件來移除。
