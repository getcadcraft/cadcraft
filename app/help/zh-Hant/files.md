## 概覽

| 格式 | 開啟 | 儲存 | 備註 |
|---|---|---|---|
| DXF（文字或二進位，任何版本） | 是 | 是，可儲存為DXF R12、DXF 2000或DXF 2000（二進位） | 二進位DXF的開啟方式與文字DXF相同，儲存時仍為二進位。 |
| DWG | 是 | 是，可儲存為DWG（AutoCAD 2000、2004、2007、2010、2013或2018） | 由CadCraft自有的DWG程式庫讀寫（AutoCAD R13至2018的檔案）。原始DWG永遠不會被變更。損壞的檔案，或讀取器無法處理的版本，會被拒絕並顯示訊息。 |
| PDF | 匯入一頁：作為底圖或作為物件（[PDF底圖](topic:pdf-underlay)） | 是，透過列印 | 圖紙或模型依比例列印的向量PDF。 |

每個開啟的圖形（或以{{ui:New}}新增的圖形）會在繪圖區上方各自擁有一個索引標籤；尚未被修改的新圖形會被直接使用，而不會再新增索引標籤。按一下索引標籤即可切換，按一下其{{ui:×}}即可關閉（若有尚未儲存的變更，CadCraft會先詢問）。或將已開啟的圖形並排顯示：請參閱[分割螢幕](topic:split-screen)。

## 開啟圖形

- 按{{key:Mod+O}}、按一下{{ui:Open}}，或輸入`OPEN`，然後選擇檔案。
- 或將`.dwg`或`.dxf`檔案拖曳到繪圖區。

檔案會在瀏覽器中讀取，不會上傳到任何地方。歷史記錄會回報匯入的物件與圖層數量，以及所花的時間；左側面板的{{ui:Drawing}}區段會顯示格式，例如「DWG 2018 (AC1032)」。

DWG讀取器是CadCraft的一部分，會在頁面載入後開啟第一個DWG時一併取得（約數百KB），因此不需要另外下載。它會在背景讀取檔案，所以開啟大型DWG時頁面仍可回應。

DXF會以約4 MB的區塊分批讀取，從不一次讀入整段文字，因此超過512 MB的DXF也能開啟。真正的限制是電腦記憶體：開啟DXF時，預計會使用約為檔案大小16至20倍的記憶體（在我們的測試中，一個約690,000個物件、100 MB的DXF使用了約1.5 GB）。

### 匯入的內容

- 直線、圓弧、圓、聚合線（含圓弧段）、橢圓、點、文字與多行文字、實體、填滿（標準圖案會以其線條繪製，其他則為單一平面色調）、含屬性的區塊參照（可編輯的值；請參閱[區塊屬性](topic:attributes)）、標註，以及圖紙與其視埠。
- 樣條曲線會以樣條曲線匯入（次數、控制點、節點、權值、通過點）；請參閱[樣條曲線與聚合線](topic:splines)。
- 只有一條引線與文字的多重引線，會以可編輯的CadCraft多重引線匯入（請參閱{{cmd:MLEADER}}）。其他（含區塊、多條引線或曲線）會依其他程式的繪製方式呈現，並作為一個整體移動；歷史記錄會顯示數量。
- 圖片（影像）會顯示為帶有圖片檔名的外框，直到您以{{cmd:IMAGE}}提供檔案為止：請參閱[圖形中的圖片](topic:pictures#show-the-pictures-a-dwg-uses)。遮除區域會顯示為其外框，且其下方的內容仍保持可見。
- DWG中的表格會依其他程式的繪製方式匯入。
- 模型空間中的3D面會匯入「3D」索引標籤，而不是作為2D物件；區塊內的3D面也是如此，每個模型中的區塊參照各匯入一次。在區塊與圖紙上，它們也會以平面輪廓繪製。請參閱[3D模型](topic:3d-solids)。
- 圖層會保留其顏色、開啟、凍結、鎖定與列印設定。DEFPOINTS永不列印。
- 若能讀取其端點，標註會成為真正可編輯的CadCraft標註。它們一開始會依其他程式的繪製方式顯示；一旦變更其中之一，CadCraft就會以自己的樣式重新繪製。
- 每個圖紙配置會成為一個圖紙索引標籤。在其他程式中，每個配置都有一個隱藏的第一個視埠，即圖紙本身；CadCraft會將其排除。

### 尚未匯入的內容

CadCraft無法繪製的任何內容都會被計數，而不是猜測。左側面板中的「關於此檔案」方塊會將其列為「尚未顯示：」，後接每種物件類型及其數量。典型情況包括DXF中的表格、網格，以及區塊內的3D實體。模型空間中的3D實體、區域與實體會顯示在3D索引標籤上（請參閱[3D模型](topic:3d-solids#solids-from-other-programs)）。檔案中扭轉的視埠會依原樣顯示為扭轉，並在儲存時保留扭轉；目前的UCS、命名UCS與旋轉的視圖同樣會保留。

文字以單一Helvetica風格字型繪製。在原始程式較窄的字型中能放進一行的標籤，在CadCraft中可能會換成兩行。

## 儲存

有三種儲存方式。每一種都會下載一份副本。

- **儲存**：按{{key:Mod+S}}、按一下{{ui:Save}}，或輸入`SAVE`（也可輸入`QSAVE`）。會以圖形的格式儲存：若開啟的是DWG，就儲存為DWG；若開啟的是DXF，就儲存為DXF。DWG會保留其原本的版本（2018檔案會儲存為2018）。新圖形會使用您在此瀏覽器中最後於「另存新檔」中選擇的格式與DWG版本；若從未選擇，則使用AutoCAD 2000格式的DWG。
- **另存新檔**：按{{key:Mod+Shift+S}}、按一下{{ui:Save as}}，或輸入`SAVEAS`。{{ui:Save a copy as}}對話方塊會提供{{ui:DWG}}，並有{{ui:Version}}清單（AutoCAD 2018、2013、2010、2007、2004或2000）、{{ui:DXF R12}}與{{ui:DXF 2000}}，每一項都會顯示將使用的檔名，並預先選取圖形目前的格式與版本。按一下{{ui:Save}}以下載，或按一下{{ui:Cancel}}（或按{{key:Esc}}）以不儲存任何內容；歷史記錄隨後會顯示「未儲存。」您的選擇會被記住：{{key:Mod+S}}之後會對此圖形使用該選擇，此瀏覽器中的新圖形也會以此開始。
- **DXFOUT**：輸入`DXFOUT`。它一律會下載一份DXF R12副本，且下一次按{{key:Mod+S}}仍會以圖形本身的格式儲存。

瀏覽器會下載`<drawing name>.dwg`或`<drawing name>.dxf`。每次儲存都是**新的下載**；開啟的原始檔案永遠不會被覆寫或變更。歷史記錄會加以確認，例如「已另存副本為 Plan.dwg（DWG (AutoCAD 2018)）。原始檔案 Plan.dxf 未變更。」若為DXF，則會顯示「（DXF R12，可在任何CAD程式中開啟）」。其下方的各行會列出過程中有變更的任何內容。

在桌面應用程式中執行CadCraft時，儲存的運作方式與其他桌面程式相同：{{key:Mod+S}}會將圖形寫回原本開啟的檔案，並保留其自身的格式與版本，歷史記錄會顯示儲存的位置。{{ui:Save as}}與匯出會顯示系統的儲存對話方塊，而雙擊的`.dwg`、`.dxf`或`.ccsheets`檔案會在CadCraft中開啟。

PDF請改用列印（見下文）。

## DWG會保留與變更的內容

CadCraft會在瀏覽器中自行寫入DWG，使用讀取時相同的DWG程式庫。在「另存新檔」中選擇版本：AutoCAD 2000格式（檔案版本AC1015）能在最多程式中開啟，包括較舊的程式；較新的格式（2004、AC1018，至2018、AC1032）也會保留真彩色。不會上傳任何內容，儲存DWG也可在離線時進行。

每個版本都已以三個其他程式的DWG讀取器，以及CadCraft本身，讀回已儲存的檔案加以檢查。CadCraft產生的DWG尚未在AutoCAD本身中開啟過。

### DWG會保留的內容

- 直線、圓弧、圓、橢圓、點，以及含圓弧段的聚合線。
- 單行文字，含其對齊方式與寬度係數。
- 多行與換行文字，以多行文字保存。其他程式會依相同寬度再次換行。
- 物件顏色：隨圖層、隨區塊、255種標準顏色；2004格式及之後的版本會保留真彩色。
- 圖層的顏色、線型、線寬，以及其開啟、凍結、鎖定與列印設定；物件自身的線型、線寬與線型比例，線型圖樣，以及圖形的線型比例。
- 圖形單位與長度格式（小數、英尺與英寸、分數……）。
- 區塊，含其基點與屬性定義，包括不可見、固定與預設的屬性。
- 區塊參照，含其縮放、旋轉與屬性值。
- 實心填滿，以及具圖案、比例與角度的圖案填滿（圖案本身的線條，因此其他程式繪製的線條與CadCraft相同）。
- 標註，保留為真正的標註：其他程式在拉伸時會重新計算。每個標註保留自己的設定（文字高度、箭頭大小、小數位數、長度格式）及其文字，並帶有每個DWG標註都具有的繪製副本。
- 圖紙：每個圖紙保留其紙張尺寸與單位、其上繪製的內容，以及其視埠與視圖及比例。
- 命名視圖。
- 多重引線，保留為多重引線。
- 圖層與區塊名稱，保留輸入時的大小寫。（DXF R12會以大寫寫入。）

### DWG會變更的內容

若適用於此圖形，每一項都會在儲存後列於歷史記錄中。

| 在CadCraft中 | 在儲存的DWG中 |
|---|---|
| 真彩色（以顏色選取器挑選），2000格式 | 最接近的標準顏色：2000格式只有255色。儲存為2004或更新格式即可保留 |
| 圖紙的命名視圖 | 配置中的視圖：DWG不會記錄是哪一張圖紙，因此CadCraft再次開啟檔案時，它們會屬於第一張圖紙 |
| 具寬度係數的多行文字 | 一般字寬：在DWG中，寬度係數只套用於單行文字 |
| 含DWG不允許字元的圖層或區塊名稱 | 已變更：來自連結圖形的名稱如`Base\|Walls`會變成`Base$0$Walls`（與綁定連結圖形的命名方式相同），其他字元則變成`_` |

### 為何使用R12，以及會轉換哪些內容

另存為DXF時，CadCraft會寫入DXF R12，這是每個CAD程式都能開啟的版本。它比某些功能舊，因此部分內容會以較簡單的形式寫入：

| 在CadCraft中 | 在儲存的R12檔案中 |
|---|---|
| 多行文字 | 每行一個文字物件 |
| 橢圓 | 沿橢圓的聚合線 |
| 填滿（來自已開啟的檔案） | 僅保留其輪廓 |
| 真彩色（以顏色選取器挑選） | 最接近的標準顏色 |
| 線寬，以及物件自身的線型比例 | 捨棄：R12兩者皆不支援（線型會保留） |
| 圖層與區塊名稱 | 以大寫寫入；空格與其他字元變成`_`，名稱截短為31個字元（「Title block」會變成`TITLE_BLOCK`） |
| 設定為不列印的圖層 | 其他程式會列印它們（當圖形有圖紙時，CadCraft會記住此設定） |
| 標註 | 真正的標註，附帶自身繪製的區塊，因此其他程式會依所見方式顯示 |
| 多重引線 | 其繪製的線條、箭頭與文字 |
| 命名視圖 | 保留，名稱以大寫寫入；圖紙的視圖會回到第一張圖紙 |
| 多張圖紙 | 第一張圖紙是每個程式都會顯示的紙張空間；其他圖紙會保留為名為`CCLAYOUT_1`、`CCLAYOUT_2`……的區塊，CadCraft開啟檔案時會將其轉回圖紙 |

歷史記錄會列出適用於此圖形的每一項。

:::tip
若要連續數日處理同一個圖形，請另存為DXF，下次再開啟該DXF。CadCraft能繪製的所有內容，都能在往返轉換後保留，包括標註、區塊與所有圖紙。
:::

## 連結圖形（外部參考）

{{cmd:XATTACH}}（`XA`，或{{ui:Blocks}} › {{ui:More}} › {{ui:Link a drawing (xref)}}）會連結另一個DWG或DXF：選擇檔案，然後按一下其要放置的位置（按{{key:Enter}}會放在0,0）。它會以檔名為名，匯入為一個區塊；若兩個圖形的單位不同，會以正確的比例匯入。其圖層與區塊會保留其名稱，並在前面加上連結的名稱，例如`Plan|Walls`、`Plan|Door`，因此永遠不會與您的內容混在一起：可如同自己的圖層一樣開啟與關閉連結的圖層，或凍結、鎖定它們。連結是唯讀的：若變更了另一個圖形，請重新載入。在連結的圖層上所設定的內容（顏色、線型、線寬、開啟／關閉、凍結、鎖定、列印），會在重新載入時保留，在連結仍為連結時另存為DWG時保留，以及在另一個圖形連結此圖形時保留。

{{cmd:XREF}}（`XR`）：`?`會列出連結（已載入或未載入、檔案為何、有多少參照）；`A`附加；`R`從其檔案重新載入一個（再次選擇檔案：瀏覽器無法自行存取資料夾）；`B`綁定一個（它會成為一般的區塊與圖層，名稱為`Plan$0$Walls`）；`D`分離一個（其參照與圖層會一併移除）。每一項都是一個復原步驟。

{{cmd:XCLIP}}（`XC`）會裁剪區塊參照與連結：選取它們，`N`建立新邊界，然後`R`加兩個角點，或`P`加多邊形的各點（按{{key:Enter}}會封閉），`D`則會移除裁剪。只有位於邊界內的內容會顯示與列印，且裁剪會隨參照移動。DWG與DXF 2000會保留裁剪；DXF R12會整體儲存參照，並告知此事。綁定含有裁剪參照的連結時，{{cmd:XREF}}`B`會詢問：`A`綁定全部，`C`僅保留每個參照的裁剪部分（線條與圓弧會在邊界處切斷；文字與巢狀區塊若其插入點位於內部則會保留）。

開啟的圖形可能連結了CadCraft無法存取的檔案，並會顯示未載入的數量。使用{{cmd:XREF}}、`R`並選取每個檔案，即可查看這些檔案。

儲存時，已載入的連結會被**綁定**到檔案中（其他程式會看到名為`Plan$0$…`的一般區塊與圖層），歷史記錄會說明此事。未載入的連結，在DWG與DXF中都會保持為指向其檔案的連結。

## 在3D中開啟

{{ui:View}} › {{ui:More}} › {{ui:Open in ModelCraft}}（{{cmd:OPENIN3D}}）會在新索引標籤中，以DWG的形式於3D建模應用程式中開啟圖形，不會上傳。在該處所做的變更會留在該處；請在該處儲存。此功能表項目只會在該應用程式能接收交接的圖形時顯示。

## 列印PDF

按{{key:Mod+P}}、按一下{{ui:Plot}}，或輸入`PLOT`。PDF會在瀏覽器中製作，然後下載，或在新索引標籤中開啟以便列印。請參閱[列印為PDF](topic:plot-pdf)。

## 檔案的存放位置

每次儲存與列印都是下載，因此檔案會存放在瀏覽器下載的位置，通常是下載資料夾。若要每次選擇資料夾，請變更瀏覽器的下載設定；[瀏覽器與電腦](common:browsers)說明了位置。

開啟或儲存的任何內容都不會傳送給我們。請參閱[檔案的存放位置](common:your-files)。

## PLN與PLA專案檔案

CadCraft可開啟DWG與DXF圖形，但不能開啟Archicad本身的檔案（`.pln`、`.pla`、`.tpl`、`.bpn`）。開啟時會告知該檔案是什麼。在Archicad中，請將所需的視圖或圖紙以DWG儲存，然後在此開啟；或將模型匯出為IFC，並在BimCraft中開啟。若BimCraft可接手該檔案，CadCraft會提供{{ui:Open in BimCraft}}。

## 若頁面在儲存前關閉

CadCraft會在停止編輯後片刻，為每個已變更的圖形保留一份副本，且僅存放於此瀏覽器中。若分頁關閉、瀏覽器停止，或電腦在儲存前重新啟動，CadCraft下次啟動時會詢問**復原尚未儲存的內容？**：{{ui:Recover}}會在其自己的索引標籤中，以未儲存的狀態重新開啟該圖形。儲存圖形會移除其副本。請參閱[復原尚未儲存的內容](common:recover)。

## 線上與離線

開啟、繪圖、儲存（DWG與DXF）及列印都在電腦上完成，因此CadCraft載入後，即使沒有連線也能運作。

要在完全沒有連線時使用CadCraft，請在線上時按一下頂部列中的{{ui:Save for offline}}。按鈕文字會計數（「正在儲存 40 / 212」），最後顯示「已可離線使用」。已儲存的副本包含DWG讀取器，總計約5 MB，因此**儲存後，DWG檔案也能離線開啟**。再按一次按鈕即可使用{{ui:Save again (get the newest version)}}或{{ui:Remove the offline copy}}。「無法儲存」表示部分檔案未能下載：請檢查連線，然後再按一下以重試。「無法離線使用」表示此瀏覽器視窗無法保留副本（私密視窗與部分受管理的電腦即是如此）。

若沒有已儲存的副本，則在頁面載入後第一次開啟DWG時，會下載DWG讀取器，因此離線開啟DWG可能會失敗；DXF檔案從不需要它。若CadCraft尚未儲存，請勿在離線時重新整理頁面。

詳情請參閱[離線工作](common:offline)。

:::offline
目前處於離線狀態。圖形可儲存為DWG或DXF，並正常列印；DXF檔案也可開啟。若CadCraft顯示「已可離線使用」，或此索引標籤中已載入DWG讀取器，則DWG檔案也可開啟。
:::

## 檔案中的限制條件

限制條件與參數（請參閱[為圖形加上限制條件](topic:constraints)）會以DWG與DXF兩種格式儲存。每個受限制的物件都會攜帶一個小型CadCraft附註（擴充資料），而名為`CADCRAFT_PARAMETRIC`的未使用區塊則保存限制條件與參數表。其他程式會正常開啟圖形並忽略兩者；清除時，它們可能會刪除該未使用的區塊。附註是以物件自身的鍵值而非檔案的控制代碼來參照物件，因此會重新編號控制代碼的程式不會使其失效。當其他程式刪除或變更了受限制的物件時，CadCraft會在開啟檔案時移除該物件上的限制條件，並告知數量。沒有這些資料的檔案會在無限制條件的情況下開啟。

從零件建模程式匯出的草圖（`.json`）也能開啟：請參閱[在其他零件建模程式之間移動草圖](topic:solidworks-sketches)。

## 尚未提供

- 儲存的DXF中，多重引線不會以多重引線物件保存（R12沒有此功能：它們會以其繪製的內容儲存）。
- 儲存的DXF中的圖片（它們會以外框儲存；DWG會將其保留為圖片），以及會遮住下方內容的遮除區域。
- 儲存為比2000更新的DXF版本。
- 雲端儲存與電腦之間的同步。

完整清單請參閱[尚未實作](topic:not-built-yet)。
