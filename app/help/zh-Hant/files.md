## 概覽

| 格式 | 開啟 | 儲存 | 備註 |
|---|---|---|---|
| DXF（文字格式，任何版本） | 是 | 是，存為 DXF R12 或 DXF 2000 | 二進位 DXF 會被拒絕：請先存成文字格式的 DXF。 |
| DWG | 是 | 是，存為 DWG（AutoCAD 2000、2004、2007、2010、2013 或 2018） | 由 CadCraft 自己的 DWG 程式庫讀取與寫入（AutoCAD R13 至 2018 的檔案）。原始 DWG 絕不會被變更。損毀的檔案，或讀取器無法處理的版本，會被拒絕並顯示訊息。 |
| PDF | 帶入一頁：作為底圖或作為物件（[PDF 底圖](topic:pdf-underlay)） | 是，透過列印 | 圖紙或依比例的模型的向量 PDF。 |

每個開啟的圖形（或以 {{ui:新增}} 開始的圖形）都會在繪圖區上方有自己的索引標籤；尚無人動過的新圖形會被直接使用，而不是新增索引標籤。按一下索引標籤可切換，按其 {{ui:×}} 可關閉（有尚未儲存的變更時，CadCraft 會先詢問），也可將已開啟的圖形並排顯示：參閱[分割畫面](topic:split-screen)。

## 開啟圖形

- 按 {{key:Mod+O}}、按一下 {{ui:開啟}}，或輸入 `OPEN`，然後選擇檔案。
- 或將 `.dwg` 或 `.dxf` 檔案拖曳到繪圖區上。

檔案是在瀏覽器內讀取，不會上傳到任何地方。歷程會報告帶入了多少物件與圖層、花了多少時間，左側面板的 {{ui:圖形}} 區段則顯示格式，例如「DWG 2018 (AC1032)」。

DWG 讀取器是 CadCraft 的一部分，會在頁面載入後第一次開啟 DWG 時一併取得（幾百 KB），因此不需要另外等待下載。它在背景讀取檔案，所以開啟大型 DWG 時頁面仍會有回應。

### 會帶入的內容

- 直線、圓弧、圓、聚合線（含圓弧線段）、橢圓、點、文字與多行文字、實心區域、填滿（標準圖案以其線條繪製，其他以單一色調繪製）、含屬性的區塊參照（可編輯的值；參閱[區塊屬性](topic:attributes)）、標註，以及含視埠的配置。
- 雲形線會以雲形線帶入（次數、控制點、節點、權重、擬合點）；參閱[雲形線與聚合線](topic:splines)。
- 具有單一引線與文字的多重引線，會以可編輯的 CadCraft 多重引線帶入（參閱 {{cmd:MLEADER}}）。其他的（含區塊、多條引線或曲線）則依另一個程式繪製的方式呈現，並一起移動；歷程會說明有多少個。
- 圖片（影像）會顯示為帶有圖片檔名的框，直到以 {{cmd:IMAGE}} 提供檔案給 CadCraft 為止：參閱[圖形中的圖片](topic:pictures#show-the-pictures-a-dwg-uses)。遮蔽物（wipeout）顯示為其外框，其下的內容仍可見。
- DWG 中的表格會依另一個程式繪製的方式帶入。
- 模型空間中的 3D 面會出現在 {{ui:3D}} 索引標籤上，而不是 2D 物件；區塊內的也是，且在模型中每個區塊參照各一次。在區塊內與圖紙上，它們也會以輪廓平面繪製。參閱[以 3D 建模](topic:3d-solids)。
- 圖層保留其色彩、開啟、凍結、鎖定與列印設定。DEFPOINTS 絕不列印。
- 標註在能讀出其點的情況下，會成為真正可編輯的 CadCraft 標註。一開始會完全依另一個程式繪製的方式顯示；一旦變更其中一個，CadCraft 就會以自己的樣式重新繪製。
- 每個配置成為一個圖紙索引標籤。在另一個程式中，每個配置都有一個隱藏的第一個視埠，即圖紙本身；CadCraft 會略過它。

### 尚不會帶入的內容

CadCraft 無法繪製的任何內容都會被計數，而不是猜測。左側面板的「關於此檔案」方塊會以「尚未顯示：」列出，後面接每種物件及其數量。典型的情況是 DXF 中的表格、網格，以及區塊內的 3D 實體。模型空間中的 3D 實體、區域與本體會顯示在 3D 索引標籤上（參閱[以 3D 建模](topic:3d-solids#solids-from-other-programs)）。檔案中被扭轉的視埠會如原樣扭轉顯示，儲存時也保留其扭轉；目前的 UCS、命名的 UCS 與旋轉的檢視也一樣。

文字以單一的 Helvetica 風格字型繪製。在原程式較窄的字型下可放進一行的標籤，在 CadCraft 中可能會折成兩行。

## 儲存

有三種儲存方式。每一種都會下載一份副本。

- **儲存**：按 {{key:Mod+S}}、按一下 {{ui:儲存}}，或輸入 `SAVE`（也可輸入 `QSAVE`）。它以圖形的格式儲存：開啟 DWG 就存為 DWG，開啟 DXF 就存為 DXF。DWG 會保留帶入時的版本（2018 的檔案存為 2018）。新圖形使用此瀏覽器中最近一次在「另存新檔」選擇的格式與 DWG 版本；若從未選擇過，則使用 AutoCAD 2000 格式的 DWG。
- **另存新檔**：按 {{key:Mod+Shift+S}}、按一下 {{ui:另存新檔}}，或輸入 `SAVEAS`。{{ui:另存副本為}} 對話方塊提供 {{ui:DWG}}（含 {{ui:版本}} 清單：AutoCAD 2018、2013、2010、2007、2004 或 2000）、{{ui:DXF R12}} 與 {{ui:DXF 2000}}，每一項都附有它會使用的檔名，並已選好圖形目前的格式與版本。按一下 {{ui:儲存}} 下載，或按 {{ui:取消}}（或 {{key:Esc}}）不儲存任何東西；此時歷程會顯示「未儲存。」所做的選擇會被記住：之後 {{key:Mod+S}} 對此圖形就使用它，此瀏覽器中的新圖形也以它起始。
- **DXFOUT**：輸入 `DXFOUT`。它一律下載 DXF R12 副本，下一次 {{key:Mod+S}} 仍以圖形本身的格式儲存。

瀏覽器會下載 `<圖形名稱>.dwg` 或 `<圖形名稱>.dxf`。每次儲存都是**新的下載**；已開啟的檔案絕不會被覆寫或變更。歷程會加以確認，例如「已將副本儲存為 Plan.dwg（DWG (AutoCAD 2018)）。原始的 Plan.dxf 未變更。」DXF 則顯示「（DXF R12，可在任何 CAD 程式中開啟）」。其下的各行會列出過程中改變的任何內容。

CadCraft 在桌面應用程式中執行時，儲存的方式與其他桌面程式相同：{{key:Mod+S}} 會將圖形以其本身的格式與版本寫回已開啟的檔案，歷程會說明儲存在哪裡。{{ui:另存新檔}} 與匯出會顯示系統的儲存對話方塊，按兩下 `.dwg`、`.dxf` 或 `.ccsheets` 檔案則會在 CadCraft 中開啟。

PDF 則改用列印（見下文）。

## DWG 保留與改變的內容

CadCraft 在瀏覽器內自行寫出 DWG，使用與讀取時相同的 DWG 程式庫。請在「另存新檔」中選擇版本：AutoCAD 2000 格式（檔案版本 AC1015）能在最多程式中開啟，包括舊的程式；較新的格式（2004、AC1018，直到 2018、AC1032）還會保留 True Color。不會上傳任何內容，儲存 DWG 也可離線進行。

每個版本都經過檢查：以另外三個程式的 DWG 讀取器及 CadCraft 本身讀回儲存的檔案。CadCraft 的 DWG 尚未在 AutoCAD 本身中開啟過。

### DWG 保留的內容

- 直線、圓弧、圓、橢圓、點，以及含圓弧線段的聚合線。
- 單行文字及其對齊與寬度係數。
- 多行與自動換行的文字，以多行文字保存。另一個程式會依相同寬度重新換行。
- 物件色彩：隨圖層、隨區塊、255 種標準色彩，以及 2004 格式以後的 True Color。
- 圖層及其色彩、線型、線寬，以及開啟、凍結、鎖定與列印設定；物件自己的線型、線寬與線型比例、線型圖案，以及圖形的線型比例。
- 圖形單位與長度格式（小數、英尺與英寸、分數……）。
- 含基點與屬性定義的區塊，包括隱藏、固定與預設的屬性。
- 含比例、旋轉與屬性值的區塊參照。
- 實心填滿，以及含圖案、比例與角度的圖案填滿（圖案本身的線條，使其他程式繪出與 CadCraft 相同的線條）。
- 標註，以真正的標註保存：其他程式在拉伸時會重新量測。每個標註保留自己的設定（文字高度、箭頭大小、小數位數、長度格式）與文字，並帶有每個 DWG 標註都有的繪製副本。
- 圖紙（配置）：每張圖紙連同其紙張大小與單位、其上繪製的內容，以及含檢視與比例的視埠。
- 命名視圖。
- 多重引線，以多重引線保存。
- 圖層與區塊名稱依輸入時的大小寫保存。（DXF R12 則以大寫寫出。）

### DWG 改變的內容

當適用於圖形時，以下每一項在儲存後都會列在歷程中。

| 在 CadCraft 中 | 在儲存的 DWG 中 |
|---|---|
| True Color（以色彩選擇器選取），2000 格式 | 最接近的標準色彩：2000 格式只有那 255 種。請存為 2004 或更新的格式以保留 |
| 圖紙的命名視圖 | 圖紙空間視圖：DWG 並不記錄是哪一張圖紙，因此 CadCraft 再次開啟檔案時，它們屬於第一張圖紙 |
| 含寬度係數的多行文字 | 一般的字寬：在 DWG 中，寬度係數僅適用於單行文字 |
| 含 DWG 不允許字元的圖層或區塊名稱 | 會被改變：來自連結圖形的名稱如 `Base\|Walls` 會變成 `Base$0$Walls`（綁定連結圖形時的命名方式），其他字元則變成 `_` |

### 為何用 R12，以及哪些會轉換

存為 DXF 時，CadCraft 寫出 DXF R12，這是每個 CAD 程式都能開啟的版本。它比某些功能還舊，因此有些內容會以較簡單的形式寫出：

| 在 CadCraft 中 | 在儲存的 R12 檔案中 |
|---|---|
| 多行文字 | 每行一個文字物件 |
| 橢圓 | 沿著橢圓的聚合線 |
| 填滿（來自開啟的檔案） | 僅輪廓 |
| True Color（以色彩選擇器選取） | 最接近的標準色彩 |
| 線寬，以及物件自己的線型比例 | 省略：R12 兩者都沒有（線型會保留） |
| 圖層與區塊名稱 | 以大寫寫出；空格與其他字元變成 `_`，名稱截短為 31 個字元（「Title block」變成 `TITLE_BLOCK`） |
| 設為不列印的圖層 | 其他程式會列印它們（圖形含有圖紙時，CadCraft 會記住該設定） |
| 標註 | 附有自己繪製區塊的真正標註，因此其他程式顯示的樣子與這裡所見相同 |
| 多重引線 | 它們所繪製的線條、箭頭與文字 |
| 命名視圖 | 保留，名稱為大寫；圖紙的視圖會回到第一張圖紙 |
| 多張圖紙 | 第一張圖紙是每個程式都會顯示的圖紙空間；其他的則保留為名為 `CCLAYOUT_1`、`CCLAYOUT_2` ……的區塊，CadCraft 開啟檔案時會將它們轉回圖紙 |

歷程會列出適用於圖形的每一項。

:::tip
若要連續幾天持續處理一張圖形，請存為 DXF，下次開啟那個 DXF。CadCraft 能繪製的一切內容都能經得起往返，包括標註、區塊與所有圖紙。
:::

## 連結的圖形（外部參考）

{{cmd:XATTACH}}（`XA`，或 {{ui:區塊}} › {{ui:更多}} › {{ui:連結圖形（外部參考）}}）會連結另一個 DWG 或 DXF：選取檔案，再按一下放置的位置（{{key:Enter}} 會放在 0,0）。它會作為一個以檔名命名的區塊帶入，兩張圖形單位不同時會使用正確的比例。其圖層與區塊保留名稱，並在前面加上連結的名稱，例如 `Plan|Walls`、`Plan|Door`，因此絕不會與自己的混在一起：可以像自己的圖層一樣開啟與關閉、凍結或鎖定連結的圖層。連結是唯讀的：請變更另一張圖形後重新載入。在連結的圖層上設定的內容（色彩、線型、線寬、開／關、凍結、鎖定、列印），會在重新載入時、在連結仍為連結狀態而將圖形存為 DWG 時，以及另一張圖形連結這一張時保留。

{{cmd:XREF}}（`XR`）：`?` 列出連結（是否已載入、哪個檔案、有多少個參照）；`A` 附加；`R` 從其檔案重新載入一個（請再次選取檔案：瀏覽器無法自行存取資料夾）；`B` 綁定一個（它會成為名為 `Plan$0$Walls` 的一般區塊與圖層）；`D` 卸離一個（其參照與圖層會消失）。每項都是一個復原步驟。

{{cmd:XCLIP}}（`XC`）可裁剪區塊參照與連結：選取它們，`N` 表示新邊界，然後 `R` 加兩個角點，或 `P` 加多邊形的各點（{{key:Enter}} 封閉）；`D` 移除裁剪。只有位於內部的內容會顯示與列印，裁剪會隨參照移動。DWG 與 DXF 2000 會保留裁剪；DXF R12 則儲存完整的參照並加以說明。綁定含有裁剪參照的連結時，{{cmd:XREF}} `B` 會詢問：`A` 綁定所有內容，`C` 只保留每個參照被裁剪的部分（直線與圓弧在邊界處被切斷；插入點在內部的文字與巢狀區塊會保留）。

開啟的圖形可能連結了 CadCraft 看不到的檔案：它會說明有多少個未載入。請使用 {{cmd:XREF}}、`R` 並選取每個檔案來查看。

儲存時，已載入的連結會被**綁定**到檔案中（其他程式看到的是名為 `Plan$0$…` 的一般區塊與圖層），歷程會加以說明。未載入的連結則在 DWG 與 DXF 中仍是指向其檔案的連結。

## 以 3D 開啟

{{ui:檢視}} › {{ui:更多}} › {{ui:在 ModelCraft 中開啟}}（{{cmd:OPENIN3D}}）會以 DWG 在新的索引標籤中，於 3D 建模應用程式開啟圖形，不會上傳。在那裡所做的變更留在那裡，請在那裡儲存。此功能表項目只會出現在該應用程式能接手圖形的地方。

## 列印 PDF

按 {{key:Mod+P}}、按一下 {{ui:列印}}，或輸入 `PLOT`。PDF 在瀏覽器內製作並下載，或在新索引標籤中開啟以供列印。參閱[列印為 PDF](topic:plot-pdf)。

## 檔案的去向

每次儲存與每次列印都是下載，因此檔案會出現在瀏覽器存放下載內容的位置：通常是「下載」資料夾。若要每次選擇資料夾，請變更瀏覽器中的下載設定；[瀏覽器與電腦](common:browsers)說明在哪裡設定。

開啟或儲存的任何內容都不會傳送給我們。參閱[檔案的去向](common:your-files)。

## PLN 與 PLA 專案檔案

CadCraft 開啟 DWG 與 DXF 圖形，不開啟 Archicad 本身的檔案（`.pln`、`.pla`、`.tpl`、`.bpn`）。開啟時會說明它是什麼。請在 Archicad 中將需要的視圖或配置儲存為 DWG，再在這裡開啟，或將模型匯出為 IFC，在 BimCraft 中開啟。BimCraft 能接手檔案的地方，CadCraft 會提供 {{ui:在 BimCraft 中開啟}}。

## 若頁面在儲存前關閉

CadCraft 會在停止編輯後片刻，於此瀏覽器中保留每個已變更圖形的副本（僅限此瀏覽器）。若分頁關閉、瀏覽器停止或電腦在儲存前重新啟動，CadCraft 下次啟動時會詢問**要復原尚未儲存的內容嗎？**：{{ui:復原}} 會在自己的索引標籤中再次開啟該圖形（尚未儲存）。儲存圖形會移除其副本。參閱[復原尚未儲存的內容](common:recover)。

## 線上與離線

開啟、繪圖、儲存（DWG 與 DXF）和列印全都在電腦上進行，因此 CadCraft 載入後無需連線即可使用。

若要完全沒有連線也能使用 CadCraft，請在線上時按一下頂端列中的 {{ui:儲存供離線使用}}。標籤會向上計數（「正在儲存 212 個中的 40 個」），最後顯示「可離線使用」。儲存的副本包含 DWG 讀取器，總計約 5 MB，因此儲存之後 **DWG 檔案也能離線開啟**。再按一次按鈕可選擇 {{ui:重新儲存（取得最新版本）}} 或 {{ui:移除離線副本}}。「無法儲存」表示有些檔案沒有下載：請檢查連線並按一下重試。「無法離線使用」表示此瀏覽器視窗無法保留副本（私密視窗與某些受管理的電腦）。

沒有儲存的副本時，DWG 讀取器會在頁面載入後第一次開啟 DWG 時取得，因此離線開啟 DWG 可能會失敗；DXF 檔案從不需要它。除非已儲存 CadCraft，否則離線時請勿重新載入頁面。

詳情請參閱[離線工作](common:offline)。

## 檔案中的限制條件

限制條件與參數（參閱[限制圖形](topic:constraints)）同時儲存在 DWG 與 DXF 中。每個受限制的物件帶有一則小小的 CadCraft 附註（擴充資料），一個名為 `CADCRAFT_PARAMETRIC` 的未使用區塊則保存限制條件與參數表。其他程式會正常開啟圖形，並忽略這兩者；清除（purge）時，它們可能會刪除該未使用的區塊。附註是以物件自己的鍵值而非檔案的控制代碼（handle）來參照物件，因此重新編號控制代碼的程式不會破壞它們。當另一個程式刪除或變更了受限制的物件時，CadCraft 開啟檔案時會移除它的限制條件並說明有多少個。沒有限制條件的檔案則不帶限制條件開啟。

從零件建模程式匯出的草圖（`.json`）也能開啟：參閱[在零件建模程式之間移動草圖](topic:solidworks-sketches)。
