## 此處可附加的檔案

使用{{cmd:POINTCLOUDATTACH}}、{{ui:開啟}}附加這些檔案，或將其拖放至頁面上（請參閱關於在點雲上描繪竣工線條的主題）：

| 格式 | 副檔名 | 讀取的內容 |
|---|---|---|
| LAS, LAZ | `.las`, `.laz` | LAS 1.0–1.4：點、色彩、強度、LiDAR 類別、座標系統及其單位。LAZ 最大 1 GB。 |
| E57 | `.e57` | 檔案中的每個掃描，依其姿態放置；色彩，若檔案沒有色彩則為強度；單位為公尺。檔案中的影像會被省略（會加以說明）。目前最多 600 萬個點與 512 MB：較大的掃描請匯出為 LAS 或 LAZ。 |
| PLY | `.ply` | 文字與二進位（兩種位元組順序）：頂點的 x y z、色彩與強度。面會被省略（會加以說明）。 |
| PCD | `.pcd` | 文字與二進位：x y z、打包或分開的色彩、強度。壓縮的 PCD 檔案尚無法讀取：請儲存為二進位或文字格式。 |
| PTX | `.ptx` | 一個或多個掃描，各依其自身的變換放置；掃描儀未量測的點會被省略。單位為公尺。 |
| PTS, XYZ | `.pts`, `.xyz` | 文字：x y z，若有相應的欄位，則包含強度與色彩。 |

## 僅掃描儀軟體可讀取的檔案

某些掃描檔案是掃描儀廠商自有的格式，沒有公開的描述，也沒有開放的讀取程式。CadCraft 無法讀取它們：附加其中一個時，指令列會顯示它是什麼格式，以及應如何處理。請從廠商的軟體將掃描匯出為 E57 或 LAS（或 PTX、PTS），然後附加匯出的檔案。

| 檔案 | 副檔名 | 匯出來源 |
|---|---|---|
| ReCap 專案 | `.rcp` | ReCap：開啟專案並匯出。專案只會指向其掃描，因此單獨複製 `.rcp` 不會得到任何點。 |
| ReCap 掃描 | `.rcs` | ReCap：開啟該掃描所屬的專案並匯出。 |
| FARO 掃描 | `.fls` | FARO SCENE。 |
| Leica 掃描 | `.lgs` | Leica Cyclone REGISTER 360。 |
| Trimble 掃描 | `.tzf` | Trimble RealWorks 或 Trimble Business Center。 |
| Z+F 掃描 | `.zfs` | Z+F LaserControl。 |

:::tip
當匯出要求選擇格式時，LAS 或 LAZ 能以最小的檔案保留 CadCraft 所使用的一切（色彩、強度、類別、座標系統及其單位）。
:::

## 這些檔案無法讀取的原因

這些格式並未公開，唯一的讀取方式是各廠商自己的軟體程式庫，且受其各自的條款約束。CadCraft 只讀取它能以電腦上自身程式碼讀取的格式，因此附加掃描時，掃描永遠不必傳送到任何地方。
