## 學習內容

如何將自己的按鈕放到工具列上，每個按鈕執行以 AutoCAD 寫法撰寫的巨集，如何為按鈕指定按鍵，以及如何匯入 CUIx 檔案中的按鈕。

## 新增按鈕

1. 開啟{{ui:設定}}（{{key:Mod+,}}），停留在{{ui:CadCraft}}索引標籤。捲動至{{ui:我的工具}}。
2. 按一下{{ui:新增按鈕…}}。
3. 填寫方塊：
   - {{ui:群組}}：按鈕所屬的工具列群組，例如`我的工具`。輸入新名稱會建立新群組。
   - {{ui:標籤}}：按鈕上的文字。
   - {{ui:巨集}}：按鈕會輸入的內容，例如`^C^C_rectang;0,0;@100,50;`。
   - {{ui:快速鍵}}：按一下方塊後按下按鍵，例如{{key:Ctrl+Alt+B}}。
   - {{ui:圖示}}：PNG 或 SVG 圖片，大小不超過 64 KB，或不設定（會顯示星形）。
4. 按一下{{ui:儲存}}。

按鈕會出現在工具列的末端，位於其所屬群組中。按一下它或按下其快速鍵即可執行。清單中的{{ui:編輯}}與{{ui:刪除}}可用來變更或移除按鈕。

## 撰寫巨集

巨集就是在指令列中會輸入的內容，只是多了幾個符號：

| 符號 | 意義 |
|---|---|
| `^C` | 取消目前執行的內容（`^C^C` 為常用的開頭） |
| `;` 或空格 | {{key:Enter}} |
| `\` | 等待輸入：點按或輸入答案後，巨集才會繼續執行 |
| `_` 或 `.`（放在指令前） | 會被接受並忽略（用於國際化與內建名稱） |
| `*`（位於最開頭） | 每次結束後重新執行，直到按下{{key:Esc}}為止 |
| `^O`、`^G` | 開啟或關閉正交、格點 |
| `$M=` | 其後內容為 DIESEL。只會讀取`$(if,…)`、`$(getvar,…)`、`$(=,…)`與`$(eq,…)`；使用其他內容的按鈕會顯示說明，且不執行任何動作 |

範例：

- `^C^C_line;0,0;@100,0;;` 會從原點繪製一條長 100 的直線。
- `^C^C_circle;\25;` 會要求指定圓心，然後在該處繪製半徑 25 的圓。
- `^C^C_turnright` 會將檢視向右旋轉 90°。

## 快速鍵

快速鍵必須搭配{{key:Mod}}（Ctrl，在 Mac 上為 Cmd）或{{key:Alt}}加上字母或數字，或使用未被佔用的功能鍵{{key:F2}}、{{key:F4}}、{{key:F5}}、{{key:F6}}、{{key:F9}}之一。單獨的字母會直接送到指令列。CadCraft、應用程式或瀏覽器已在使用的按鍵（例如{{key:Ctrl+S}}或{{key:Ctrl+Z}}），以及其他按鈕已使用的按鍵，都會被拒絕，方塊中會說明原因。

## 分享按鈕

- {{ui:匯出…}}會將每個群組與按鈕（含圖示與快速鍵）儲存為`my-tools.json`。
- {{ui:匯入…}}會將此類檔案中的群組加到現有群組之後。已使用的群組名稱會加上「(2)」；會與現有快速鍵衝突的按鍵將被略過，面板中會說明。

## 從 CUIx 檔案匯入按鈕

1. 按一下{{ui:匯入 CUIx…}}，然後選擇`.cuix`檔案。

其工具列與功能區面板會成為群組，每個按鈕都會帶著其巨集與圖片（PNG，或已轉為 PNG 的 BMP）。其快速鍵會集中在一個獨立的群組中，每個按鈕附帶其按鍵；檔案可能包含的指令別名會放在{{ui:別名}}群組中。面板會列出已匯入的內容。

:::note
此檔案僅會被讀取。CadCraft 沒有的指令會以名稱列出，不會猜測其用途：這些按鈕被按一下時會顯示說明。除上述少數函式以外的 DIESEL、功能表、滑鼠按鈕與工作區均不會被讀取。
:::

## 須知

- 按鈕會保存在此瀏覽器（或此桌面應用程式）中，而非圖形檔中。
- 按鈕透過指令列執行，因此和輸入的指令一樣可被復原：每個執行的指令都需要一次{{key:Mod+Z}}。
