CadCraft 是為有滾輪的滑鼠所設計的。觸控板也能完成所有操作，只是需要養成一些習慣。觸控螢幕可用於點選，但有其限制。

## 滾輪滑鼠

- **縮放：**滾動滾輪。圖形會以十字游標為中心縮放，因此指向想看的位置即可。
- **平移：**按住滾輪並拖曳，或以右鍵拖曳。
- **縮放至全部：**連按兩下滾輪，或按一下{{ui:範圍}}。
- **回到上一個檢視：**按一下「檢視」群組中的{{ui:上一個}}，或輸入`Z`後按{{key:Enter}}、`P`後按{{key:Enter}}。連續的滾輪步進會算作同一個檢視，因此一次{{ui:上一個}}即可全部復原。常回到的檢視可以用{{cmd:NAMEDVIEW}}（`NV`）儲存。
- **{{key:Enter}}：**按滑鼠右鍵。

## 觸控板

:::mac
- **平移：**以雙指在觸控板上朝任一方向移動，圖形會跟隨手指移動。也可以用雙指按住不放（右鍵拖曳）來拖曳。
- **縮放：**以雙指捏合。縮放會以十字游標為中心。
- **右鍵（{{key:Enter}}）：**以雙指按一下。若沒有反應，請在 **系統設定** 的 **觸控板** 中開啟「輔助點按」。在 CadCraft 中，Control 鍵加按一下可能被當作一般點按而非右鍵，因此請使用雙指按一下。
- **縮放至區域：**按一下「檢視」群組中的{{ui:視窗}}，再按一下兩個角點。
:::

:::windows linux
- **平移：**以雙指在觸控板上朝任一方向移動，圖形會跟隨手指移動。也可以按住右鍵拖曳。
- **縮放：**以雙指捏合。縮放會以十字游標為中心。
- **右鍵（{{key:Enter}}）：**以雙指按一下，或按一下觸控板右下角，視觸控板設定而定。
- **縮放至區域：**按一下「檢視」群組中的{{ui:視窗}}，再按一下兩個角點。
:::

在 CadCraft 中按住{{key:Space}}並拖曳**不會**平移，因為{{key:Space}}等同於{{key:Enter}}。

滑鼠滾輪仍會逐步縮放。若觸控板像滾輪一樣以整段步進送出捲動量，則雙指捲動會縮放而非平移：先縮小，指向想看的區域，再放大即可。「3D」索引標籤保有其自己的觸控板移動方式（請參閱[在 3D 中建模](topic:3d-solids#look-around)）。

## 觸控螢幕與平板

CadCraft 會將手指視為滑鼠點按：

- 輕觸會點選一個點或物件，或進行選取。
- 在空白處拖曳手指會繪製套索（先向右移動為視窗，先向左移動為交叉；請參閱[套索選取](topic:lasso-selection)）。
- 在{{cmd:TRIM}}與{{cmd:EXTEND}}中，以手指拖過多個物件即可一次修剪或延伸它們。
- 拖曳已選取物件的夾點會移動該夾點（夾點與拾取框對手指而言會較大）。
- **捏合**：以雙指捏合，可以兩指之間的點為中心縮放；雙指一起移動即可**平移**。第二根手指會取消第一根手指已開始的操作，因此捏合不會造成誤動作。
- **長按**（靜止不動約半秒）即為右鍵點按：{{key:Enter}}。它會結束指令、完成選取，或重複上一個指令。

在指令列下方會出現一列**按鍵列**：{{ui:Esc}}、{{ui:放棄}}、{{ui:取消復原}}、平板鍵盤隱藏的字元（`@` `,` `<` `'` `"` `-`）、{{ui:鎖點}}、{{ui:正交}}、鍵盤按鈕，以及一個大型的{{ui:Enter}}。點按鍵盤按鈕（或指令列）即可輸入指令或數字。

沒有懸停功能，因此鎖點標記只會在手指所在位置顯示。

:::touch
目前使用的是觸控螢幕。若不只是快速檢視，外接鍵盤與滑鼠或觸控板會讓 CadCraft 更容易使用。
:::

## 瀏覽器

CadCraft 在 Chrome、Edge、Firefox 與 Safari 上的運作方式相同，同樣適用於 Mac、Windows 與 Linux。差異很小：

| 主題 | 注意事項 |
|---|---|
| 開啟 DWG | 大型圖形在各瀏覽器中讀取都需要數秒；讀取期間狀態列會顯示「讀取中 …」 |
| 下載 | 每個瀏覽器自行決定下載位置及是否先詢問；請參閱[瀏覽器與電腦](common:browsers) |
| 開啟以列印 | 會在新索引標籤中開啟 PDF。若瀏覽器封鎖彈出式視窗，CadCraft 會改為下載 PDF |
| F7 | Firefox 可能提供游標瀏覽；請選擇「否」 |
| 離開且有未儲存的變更 | 每個瀏覽器都會顯示自己的「離開網站？」詢問，CadCraft 無法變更此設定 |

:::safari
在 Safari 中，以{{ui:開啟以列印}}開啟的 PDF 可能會顯示在索引標籤中但不會列印：請依序選擇 **檔案** 與 **列印**。
:::

:::firefox
Firefox 可能會詢問每個下載要如何處理。請選擇儲存檔案，或在 Firefox 的設定中，於「下載」底下一次變更此設定。
:::
