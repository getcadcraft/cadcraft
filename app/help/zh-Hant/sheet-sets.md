## 你將學到的

如何從多個圖形檔收集圖紙（即配置），為它們編號並命名，讓它們的標題欄自動填入，將整組圖紙發佈為一個 PDF，並把所有內容打包成一個 zip 以便傳送。

圖紙集存放在它自己的小檔案中，名稱為 `<name>.ccsheets`，位於存放圖形的資料夾內。圖紙集檔案會以相對於該資料夾的路徑列出圖紙，因此你可以移動或複製整個資料夾。

:::note
要在資料夾中讀寫，需要 Chrome 或 Edge（它們可讓網頁在你選擇的資料夾中運作），或使用桌面應用程式。其他瀏覽器會以唯讀方式開啟圖紙集：你可以檢視與發佈，而圖紙集檔案會以下載方式取得，而非直接儲存。
:::

## 建立圖紙集

1. 在左側面板中找到 {{ui:Sheet set}} 區段，並開啟其 {{ui:Set}} 功能表。輸入 {{cmd:SHEETSET}}（或 `SSM`）也可以到達這裡。
2. 選擇 {{ui:New set…}}。為圖紙集命名；如果你願意，也可以填入專案名稱與編號。
3. 選取存放圖形的資料夾。圖紙集檔案會儲存在那裡。

稍後要開啟圖紙集，請選擇 {{ui:Open set…}} 並選取同一個資料夾。若該資料夾中有多個圖紙集，CadCraft 會詢問要開啟哪一個。

## 新增圖紙

1. 選擇 {{ui:Add sheets from a drawing…}}，並選取資料夾中的一個圖形。
2. CadCraft 會在背景讀取該圖形（不會在螢幕上開啟），並列出其圖紙。勾選你要的項目，然後按 {{ui:OK}}。
3. 選取一張圖紙並按 {{key:F2}}（或 {{ui:Rename and renumber…}}），為它指定編號與標題，例如 `A-101` 與 `Floor plan`。

{{ui:New sheet from template…}} 會以另一個圖形的一張圖紙（其標題欄與視埠）建立新圖形，並以新圖紙命名，然後將它加入。圖紙集會記住你用作範本的圖形。

## 整理圖紙集

- **子集**會將圖紙分組，例如 建築 › 平面：選取其應放置的位置，然後選擇 {{ui:New subset…}}。
- **順序**：將圖紙拖曳到清單中的另一個位置，或拖到子集上以移入該子集。使用鍵盤時，選取它並按 {{key:Alt+Up}} 或 {{key:Alt+Down}}。
- **開啟圖紙**：按兩下它（或按 {{key:Enter}}）。其圖形會在自己的索引標籤中開啟，並位於該圖紙上。
- **移除**：選取它並按 {{key:Delete}}。圖形本身不會被變更。
- **復原**：{{ui:Undo set change}} 與 {{ui:Redo set change}} 會逐步套用你在圖紙集中所做的變更。
- **重新編號**：{{ui:Renumber sheets…}} 會依清單順序為每張圖紙（或某個子集的圖紙）編號：一個前綴、起始值與步進（`A-` 與 `101` 會得到 A-101、A-102 …）。

每項變更都會立即儲存到圖紙集檔案中。

## 依欄位為圖紙編號

不必手動為圖紙編號，而是讓規則依圖紙的欄位組成編號，如此一來，當圖紙移到另一個樓層或專業時，就會自動取得新的編號。

1. 為每張圖紙設定欄位：選取它，按一下 {{ui:Rename…}}，然後在 {{ui:Fields of this sheet}} 中每行寫一個欄位，例如 `DISCIPLINE = A` 與 `LEVEL = 1`。整組圖紙共用的欄位（例如 `DISCIPLINE = A`）可以改放在圖紙集的 {{ui:Properties…}} 中。
2. 開啟面板的功能表，並按一下 {{ui:Numbering rule…}}。
3. 撰寫規則，例如 `{DISCIPLINE}-{LEVEL}{SEQ:2}`。`{SEQ}` 會在其他欄位值相同的圖紙之間遞增，因此樓層 1 會得到 A-101、A-102，而樓層 2 會從 A-201 重新開始。`{SEQ:2}` 會以兩位數寫出；`{SUBSET}` 則是圖紙所在子集的名稱。
4. 選擇欄位變更時會發生什麼：{{ui:Renumber the sheets}} 會在每次變更後，讓編號持續遵循規則；另一個選項則只在當下為它們編號一次。

規則會儲存在圖紙集檔案中。當系統自動重新編號時，請變更圖紙的欄位，而不要直接變更其編號。

## 從圖紙集填入標題欄

當標題欄的屬性以欄位名稱標記時，其文字會從圖紙集取得：

| 標記 | 顯示內容 |
|---|---|
| `SHEETNUMBER`（或 `SHEET_NO`、`DWG_NO`） | 圖紙的編號 |
| `SHEETTITLE`（或 `TITLE`、`SHEET_TITLE`） | 圖紙的標題 |
| `SHEETDESC` | 圖紙的說明 |
| `PROJECTNAME`（或 `PROJECT`） | 專案名稱 |
| `PROJECTNUMBER`（或 `PROJECT_NO`、`JOB_NO`） | 專案編號 |
| `SHEETSETNAME` | 圖紙集的名稱 |
| `SHEETINDEX`、`SHEETCOUNT` | 「第 3 張，共 12 張」，以及 12 |
| 你自訂的欄位，例如 `CLIENT` | 你在 {{ui:Set fields…}} 中為它填寫的內容 |

{{ui:Set fields…}} 會保存專案名稱與編號，以及你自訂的欄位，每行一個，格式為 `NAME = value`。

{{ui:Update drawings}} 會將編號、標題與欄位寫入圖紙集中每個圖形的標題欄，並依圖紙集的設定為每張圖紙的配置索引標籤重新命名（預設為編號與標題，例如 `A-101 Floor plan`；{{ui:Set fields…}} › {{ui:Layout tab names}} 可變更此設定）。每個圖形都會在原位置、以其自身的格式與版本儲存。在你重新編號或重新命名圖紙後，再執行一次，索引標籤與標題欄就會跟上。

## 封面圖紙上的圖紙清單

在清單中選取封面圖紙，然後選擇 {{ui:Put the sheet list on this sheet}}。一個包含每張圖紙（編號與標題，列於其子集之下）的表格，會放在該圖紙的左上角。{{ui:Update drawings}} 與 {{ui:Publish to PDF}} 會讓它保持最新。它是一個區塊，名稱為 `CC_SHEETLIST`：像任何區塊參照一樣移動它即可。

## 發佈圖紙集

{{ui:Publish to PDF}} 會製作一份 PDF，每張圖紙一頁，依圖紙集的順序排列，並使用每張圖紙自己的紙張大小，每張圖紙都有一個書籤（`A-101 — Floor plan`）。選取子集時，CadCraft 會詢問是否只發佈該子集。即使你尚未更新圖形，PDF 中的標題欄也會從圖紙集填入；發佈並不會變更圖形本身。PDF 會以下載方式取得。

{{ui:Publish to DWG…}} 會將每張圖紙寫成各自的 DWG（DWG 2018）：包含模型與該張圖紙，其標題欄從圖紙集填入，並以其編號與標題命名（`A-101 Level 1 floor plan.dwg`）。選擇 {{ui:DWG}}，或選擇 {{ui:DWG + PDF}} 以在其旁一併加入圖紙集的 PDF。`publish.json` 會列出每個檔案及其大小與 SHA-256。當圖紙集的資料夾可寫入時（CadCraft Studio，或你在瀏覽器中選取的資料夾），檔案會放入名為 `<set name> - published` 的資料夾；否則會以一個 zip 的形式下載。每個 DWG 都會保留視埠的 [類別覆寫](topic:viewport-overrides)。

## 封存圖紙集

{{ui:Archive as a zip}} 會將圖紙集檔案、它所使用的每個圖形，以及那些圖形所連結的內容（連結的圖形，以及其再連結的圖形，還有圖片）打包在一起，保留其資料夾結構，並加入一個 `Transmittal.txt`，列出每一個檔案。不在圖紙集資料夾中的連結，會在此列為遺失。連結是依圖形中的路徑找到，接著依資料夾中任何位置的檔案名稱尋找。

## 圖紙集檔案

`.ccsheets` 檔案是 JSON，可以用任何文字編輯器讀取：

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

路徑相對於圖紙集的資料夾，並以 `/` 分隔各資料夾。CadCraft 在開啟檔案時會進行檢查：絕對路徑、沒有檔案或配置的圖紙，或非純文字的內容，都會被排除，並在記錄中說明。

## 疑難排解

| 你看到的 | 原因 | 該怎麼做 |
|---|---|---|
| 「此資料夾在此處為唯讀」 | 瀏覽器無法寫入此資料夾 | 使用 Chrome 或 Edge，或桌面應用程式；在此期間，{{ui:Download the set file}} 會保留你的變更 |
| 圖紙從 PDF 中被排除：「沒有名為 … 的配置」 | 該圖紙的配置在其圖形中已被重新命名或移除 | 開啟該圖形並檢查其索引標籤；移除該圖紙後再重新新增 |
| 標題欄保持空白 | 其屬性使用了其他標記 | 將屬性標記重新命名為上述欄位名稱（BEDIT） |
| 「已有名為 … 的配置，因此未重新命名該索引標籤」 | 同一圖形的兩張圖紙會得到相同的索引標籤名稱 | 為其中一張指定另一個編號或標題 |
