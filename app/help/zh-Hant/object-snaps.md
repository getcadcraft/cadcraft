## 完成後的內容

一個矩形與其兩條對角線、一個以對角線交點為圓心的圓，以及一條從矩形某一邊的中點延伸到圓上的直線。每個點都以滑鼠選取，且每個點都精確無誤。

## 鎖點如何運作

當指令要求一個點時，CadCraft會在十字游標約10像素範圍內尋找鎖點。找到時，會出現標記與標籤（例如「端點」、「交點」），而按一下會**精確**落在該點上，而非十字游標所在之處。

當狀態列中的{{ui:Snap}}為按下狀態時，鎖點即為開啟。{{key:F3}}可開啟與關閉鎖點。

可用的鎖點如下：

| 鎖點 | 會落在 |
|---|---|
| 端點 | 直線、圓弧與聚合線段的端點 |
| 中點 | 直線、圓弧與聚合線段的中點 |
| 圓心 | 圓與圓弧的圓心，以及聚合線圓弧段的圓心 |
| 象限點 | 圓與圓弧的0、90、180與270度點 |
| 交點 | 兩個物件相交之處 |
| 垂足 | 物件上與最後一點成直角的點（需要基點） |
| 切點 | 圓或圓弧上，從最後一點出發的直線恰好與其相切之處。若尚無最後一點（直線的第一點），標記會顯示「延後」：切點會在下一點已知後才計算，因此從切點到切點的直線會同時與兩個圓相切 |
| 最近點 | 任何物件上最近的點 |
| 節點 | 點物件 |
| 插入點 | 文字與區塊參照的插入點 |

除切點與最近點外，其餘預設皆為開啟。最近點常會搶先勝出，因此若想要其他點，可能需要關閉它；需要時請開啟切點。

## 選擇鎖點

1. 按一下狀態列中{{ui:Snap}}旁的小箭頭。會開啟{{ui:Object snaps}}清單。
2. 勾選或取消勾選鎖點。變更會立即生效。
3. 再按一下箭頭，以關閉清單。

CadCraft會在此瀏覽器中記住您的選擇，以及{{ui:Grid}}、{{ui:Ortho}}與{{ui:Snap}}設定。

## 步驟

1. 輸入`REC`後按{{key:Enter}}。
2. 輸入`0,0`後按{{key:Enter}}。
3. 輸入`@4000,3000`後按{{key:Enter}}。會出現一個矩形。
4. 按一下{{ui:Extents}}。
5. 輸入`L`後按{{key:Enter}}。
6. 將十字游標移到左下角。標記會顯示「端點」。按一下。
7. 移到右上角，直到出現「端點」。按一下。
8. 按{{key:Enter}}，以結束直線。
9. 再按一次{{key:Enter}}，以重複{{cmd:LINE}}，並以同樣方式從右下角到左上角繪製另一條對角線。
10. 輸入`C`後按{{key:Enter}}，以開始繪製圓。
11. 將十字游標移到兩條對角線相交之處。標記會顯示「交點」。按一下。
12. 輸入`800`後按{{key:Enter}}。

會看到一個圓心精確位於交叉點上的圓。

13. 輸入`L`後按{{key:Enter}}。
14. 移到矩形左邊的中點，直到出現「中點」。按一下。
15. 將十字游標移到圓上、位於其左側。標記會顯示「垂足」或「象限點」；在這裡兩者是同一個點。按一下。
16. 按{{key:Enter}}。

新的直線會從左邊的中點出發，並精確止於圓上。

## 單次點選略過鎖點

按住{{key:Shift}}再按一下。該次點選會忽略物件鎖點，點的位置就是十字游標所在之處（若{{ui:Ortho}}開啟，則沿正交方向）。

## 正交

{{ui:Ortho}}（{{key:F8}}）會讓下一點從基點出發，保持水平或垂直。它適用於點選，以及直接距離輸入（在提示下輸入的單一數字）。物件鎖點優先於正交：若出現鎖點標記，點選會落在鎖點上。

## 極軸追蹤

{{ui:Polar}}（{{key:F10}}）是在更多角度上的正交。當指令具有基點（直線的最後一點，或移動的基點）時，只要指標接近從基點出發、且為極軸步距倍數的射線，指標就會對齊：會顯示一條虛線，十字游標旁的標籤會顯示`Polar: 1200 < 30°`。按一下即可使用該點，或輸入距離：`1200`會精確沿射線前進1200。

步距預設為90°。要變更時，請輸入{{cmd:POLARANG}}，按{{key:Enter}}，然後輸入`30`（或45、22.5、15……）。極軸與正交互斥：開啟其中一個會關閉另一個。

## 物件鎖點追蹤

{{ui:Track}}（{{key:F11}}）會讓指標與您停留過的鎖點對齊，因此可以在與某個角點同高、且與另一點同垂直的位置取點，無需繪製輔助線。

1. 開啟{{ui:Snap}}與{{ui:Track}}，並啟動一個要求點的指令（`L`）。
2. 將指標停留在鎖點上（例如角點）約半秒，不要按一下。會出現一個小十字標記，表示已擷取它。再次停留即可捨棄它。
3. 將指標沿水平或垂直方向直接移開。一條虛線會跟隨指標，標籤會顯示`Track: 600 < 90°`。按一下，或輸入距離。
4. 擷取第二個點，並移動到一個點的垂直線與另一個點的水平線相交之處：指標會鎖到該交點（`Track: where two lines meet`）。

同時開啟{{ui:Polar}}時，已擷取的點會沿每個極軸角追蹤。最多會保留七個點，直到指令結束。{{key:Shift}}會為單次點選關閉追蹤，與鎖點相同。

## 格點

{{ui:Grid}}（{{key:F7}}）會在圖形後方顯示格線，每五條線有較粗的線；間距會隨縮放改變。它只是參考，直到開啟{{ui:Grid snap}}（{{key:F9}}）為止：此時點選會落在最近的格點上，除非物件鎖點先取得該點。

## 電腦上的功能鍵

{{key:F9}}為格點鎖點，{{key:F10}}為極軸，{{key:F11}}為追蹤。

:::mac
在Mac上，F3、F7、F8與F9通常會控制Mission Control與媒體。請按住**fn**鍵再按下該鍵，或開啟標準功能鍵，如[按鍵、滑鼠與觸控板](common:keys)所述。狀態列按鈕隨時都能使用。
:::

:::firefox
在Firefox中，F7也是「游標瀏覽」的快速鍵。若Firefox詢問是否開啟游標瀏覽，請選擇**否**。如果一直出現此詢問，請改用{{ui:Grid}}按鈕。
:::

:::touch
在觸控螢幕上沒有懸停，因此鎖點標記只會在手指觸碰的位置出現。請放大到足夠近以選取小目標，或改為輸入座標。
:::

## 常見問題

- **點選落在錯誤的點上。** 點選前請先查看標記標籤：兩者都接近時，端點會優先於中點。請放大，或取消勾選不需要的鎖點。
- **沒有出現標記。** {{ui:Snap}}為關閉，或所需的鎖點未勾選，或該物件位於關閉或凍結的圖層上。
- **複雜的圖形中，鎖點抓到錯的物件。** 請放大。鎖點距離以螢幕像素計算，因此放大後，鎖點在圖形上的範圍會變小。
- **以為Shift能畫出直線。** 在CadCraft中，Shift只會為單次點選關閉鎖點。要畫直線，請使用{{ui:Ortho}}。
- **以為點會落在格點上。** 請開啟{{ui:Grid snap}}（{{key:F9}}），或輸入座標以取得整數值。
