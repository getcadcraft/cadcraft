Escreva o nome curto (o alias) e prima Enter, ou clique na ferramenta. Esc cancela. Enter numa linha vazia repete o último comando.

**Imprima-a:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (uma página A4; em papel Letter, imprima com "ajustar à página").

## Desenhar

| Escrever | Comando | O que faz |
|---|---|---|
| `L` | {{cmd:LINE}} | Desenhar linhas retas |
| `PL` | {{cmd:PLINE}} | Desenhar uma cadeia ligada de linhas e arcos |
| `C` | {{cmd:CIRCLE}} | Desenhar um círculo (centro e raio) |
| `A` | {{cmd:ARC}} | Desenhar um arco |
| `REC` | {{cmd:RECTANG}} | Desenhar um retângulo a partir de dois cantos |
| `POL` | {{cmd:POLYGON}} | Desenhar um polígono regular |
| `EL` | {{cmd:ELLIPSE}} | Desenhar uma elipse |
| `DT` | {{cmd:TEXT}} | Escrever uma linha de texto |
| `T` | {{cmd:MTEXT}} | Escrever texto que quebra linha (parágrafo) |
| `H` | {{cmd:HATCH}} | Preencher uma área com um padrão |

## Modificar

| Escrever | Comando | O que faz |
|---|---|---|
| `M` | {{cmd:MOVE}} | Mover objetos |
| `CO` | {{cmd:COPY}} | Copiar objetos |
| `RO` | {{cmd:ROTATE}} | Rodar objetos em torno de um ponto |
| `SC` | {{cmd:SCALE}} | Tornar objetos maiores ou mais pequenos |
| `MI` | {{cmd:MIRROR}} | Espelhar objetos em relação a uma linha |
| `O` | {{cmd:OFFSET}} | Desenhar uma cópia paralela a uma distância |
| `TR` | {{cmd:TRIM}} | Cortar objetos até onde outros os cruzam |
| `EX` | {{cmd:EXTEND}} | Prolongar objetos até outros |
| `F` | {{cmd:FILLET}} | Arredondar um canto com um arco |
| `CHA` | {{cmd:CHAMFER}} | Cortar um canto com uma aresta reta |
| `E` | {{cmd:ERASE}} | Eliminar objetos |
| `X` | {{cmd:EXPLODE}} | Decompor um bloco ou uma polilinha nas suas partes |
| `S` | {{cmd:STRETCH}} | Mover as pontas dentro de uma janela de cruzamento |
| `AR` | {{cmd:ARRAY}} | Copiar numa grelha ou num círculo |
| `J` | {{cmd:JOIN}} | Unir linhas e arcos num só objeto |
| `BR` | {{cmd:BREAK}} | Cortar um objeto em dois, ou retirar-lhe um troço |

## Cotagem

| Escrever | Comando | O que faz |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Cotar na horizontal ou na vertical |
| `DAL` | {{cmd:DIMALIGNED}} | Cotar ao longo de uma linha inclinada |
| `DRA` | {{cmd:DIMRADIUS}} | Cotar um raio |
| `DAN` | {{cmd:DIMANGULAR}} | Cotar um ângulo |

## Blocos e camadas

| Escrever | Comando | O que faz |
|---|---|---|
| `B` | {{cmd:BLOCK}} | Criar um bloco a partir de objetos |
| `I` | {{cmd:INSERT}} | Colocar um bloco |
| `LA` | {{cmd:LAYER}} | Abrir as camadas |

## Ver e consultar

| Escrever | Comando | O que faz |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | Zoom para aproximar, afastar ou ver tudo (E) |
| `DI` | {{cmd:DIST}} | Medir uma distância e um ângulo |
| `LI` | {{cmd:LIST}} | Mostrar os detalhes de um objeto |
| `MA` | {{cmd:MATCHPROP}} | Copiar o aspeto de um objeto para outros |

## Ficheiro

| Escrever | Comando | O que faz |
|---|---|---|
| `U` | {{cmd:UNDO}} | Anular o último comando |
| `SAVE` | {{cmd:SAVE}} | Guardar o desenho |
| `PLOT` | {{cmd:PLOT}} | Imprimir para PDF |

## Teclas

Ctrl (Cmd num Mac): Z anular · Y refazer · S guardar · P imprimir.  F3 snap a objetos · F8 orto · F10 polar.  Space ou Enter repete o último comando · a roda faz zoom · arrastar com a roda desloca a vista

É novo no desenho técnico? Escreva `TOUR` para um primeiro desenho guiado, leia [Primeiros passos](topic:getting-started), ou veja todos os comandos em [Comandos](topic:commands). Se vem de outro programa de desenho: [Vindo de outro programa de desenho](topic:coming-from) e o [mapa de comandos](topic:command-map).
