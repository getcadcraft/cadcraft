## Барлық өлшемдерге бір кесте

{{ui:Параметрлер}} панелі ({{ui:Параметрлер}} түймесі {{ui:Параметрлік}} тобында, немесе {{cmd:PARAMETERS}} теріңіз) әр өлшемдік шектеуді (`d1`, `rad1`, `dia1`, `ang1`, немесе сіз берген атау) және өз параметрлеріңізді бірге тізімдейді. Кез келген атау кез келген өрнекте қолданылады.

Әр жолда мыналар бар:

- **Атауы**: жаңасын теріп, атын өзгертіңіз; оны пайдаланатын әр өрнек соны ілеседі.
- **Өрнек**: сан (`40`) немесе өрнек (`width / 2 + gap`). Оған теріп, {{key:Enter}} басыңыз: сызба соны ілеседі.
- **Мән**: ол нәтижесінде шыққан. Өрнек басқаратын жолда осы жерге де сан теруге болады: CadCraft оның артындағы параметрді есептейді. `d1 = width / 2` болса, d1-дің мәніне `30` теру `width` мәнін 60-қа орнатады.

Екі параметр мән басқарғанда (`width / 2 + gap`), диалог қайсысын өзгерту керектігін сұрайды. Әр өзгеріс — бір болдырмау қадамы ({{key:Mod+Z}}).

## Өзіңіздікін қосу

1. {{ui:Параметрлер}} панелін ашыңыз.
2. Атауын (`gap`) және мәнін (`10`) теріңіз, содан соң {{ui:Қосу}} таңдаңыз.
3. Оны пайдаланыңыз: d1-дің өрнегінде `width / 2 + gap` теріп, {{key:Enter}} басыңыз.

Атаулар әріптен немесе `_`-ден басталады және әріптер, сандар және `_` тұрады. Функция атаулары, `pi` және өлшем бірлігі атаулары атау бола алмайды.

## Өрнектер

| Жазу | Мағынасы |
|---|---|
| `+ - * / ^ %` | қосу, азайту, көбейту, бөлу, дәреже, қалдық |
| `( )` | топтау |
| `sin cos tan asin acos atan atan2` | градуспен тригонометрия |
| `sqrt pow exp ln log abs sign` | түбірлер, дәрежелер, логарифмдер |
| `ceil floor int round min max` | дөңгелектеу және шектеулер |
| `if(a > b, x, y)` | таңдау |
| `pi` | 3.14159… |

Сандарда өлшем бірлігі болуы мүмкін: `25mm`, `1in`, `2'`, `90deg`. Өлшем бірлігі бар ұзындықтар миллиметрге айналады, сондықтан бірліктерді тек миллиметрмен өлшенген сызбаларда пайдаланыңыз; басқаларда жай сандарды теріңіз.

## Команда жолында

`-PARAMETERS` панельсіз дәл осыны жасайды: `N` жаңа, `E` өңдеу (өлшемдік шектеу де), `R` атын өзгерту, `D` жою, `?` тізімдеу.

## Не қабылданбайды

- Өзін, тікелей немесе басқалар арқылы пайдаланатын өрнек: "width, d1 use each other."
- Өлшем қабылдай алмайтын мән: теріс ұзындық, 180°-тан асатын бұрыш.
- Сызба басқа шектеулерімен қабылдай алмайтын мән: ешнәрсе өзгермейді, және хабарлама оның жолындағы шектеулерді атайды.
- Пайдаланылатын параметрді жою: панель алдымен оның мәнін оларға жазуды ұсынады. Өлшемдік шектеудің атауы шектеуді жою арқылы жойылады.
