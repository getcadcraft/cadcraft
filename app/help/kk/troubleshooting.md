## Файлдарды ашу

| Хабар немесе белгі | Себебі | Түзету |
|---|---|---|
| «CadCraft DWG және DXF сызбаларын ашады. "…" ешқайсысы емес.» | Файл `.dwg` немесе `.dxf` емес. | Сызба файлының өзін ашыңыз. PDF-ті енгізуге болады (Ашу сұрайды: импорттау немесе тіркеу, қараңыз [PDF астыңғы қабаты](topic:pdf-underlay)); суреттер `IMAGEATTACH` арқылы енгізіледі. |
| «Бұл екілік DXF объектінің ортасында аяқталады: файл қысқарған немесе зақымдалған.» | Екілік DXF соңына жетпей тоқтайды. | Оқуға болатынын ашу үшін RECOVER теріңіз, немесе файлды қайта сұраңыз. |
| «Бұл файл оқылатын DXF емес (жол нөміріндегі топ коды дұрыс емес …).» | DXF зақымдалған немесе шынымен DXF емес. | Файлды қайта сұраңыз, немесе DWG сұраңыз. |
| «Бұл сызбаны оқу мүмкін болмады. Ол зақымдалған болуы мүмкін, немесе оқу құралы әлі қолдамайтын нұсқада сақталған (…).» | DWG оқу құралы оны оқи алмады. | Ескі нұсқада сақталған DWG сұраңыз, немесе DXF. |
| «Бұл сызба AutoCAD R11 / R12 нұсқасынан (DWG AC1009), ол CadCraft оқитыннан ескі …» | Release 12 және одан ертедегі DWG файлдары CadCraft оқымайтын пішімді қолданады. | Оны жасаған бағдарламада DXF (кез келген нұсқа) немесе жаңа DWG ретінде сақтап, соны ашыңыз. CadCraft-тың өз «Басқаша сақтау» опциясы сол ескі пішімді қажет ететін бағдарламалар үшін DXF R12 ұсынады. |
| Бірінші DWG-де желі хабарымен бірге «Ашу мүмкін болмады …» | DWG оқу құралын жүктеу мүмкін болмады: сіз желіден тыссыз, ал CadCraft желіден тыс пайдалануға сақталмаған, немесе байланыс үзілді. | Желіге қосылып, қайта көріңіз, немесе DXF ашыңыз. {{ui:Желіден тыс сақтау}} батырмасын басып, «Желіден тыс дайын» хабарын күтіңіз, сонда DWG файлдары келесі жолы желіден тыс ашылады. Қараңыз [Желіден тыс жұмыс](common:offline). |
| Желіден тыс батырмасы «Сақтау мүмкін болмады» дейді | Кейбір файлдар жүктелмеген. | Байланысты тексеріңіз де, қайта көру үшін батырманы басыңыз. |
| Желіден тыс батырмасы «Желіден тыс қол жетімсіз» дейді | Жеке терезелер мен кейбір басқарылатын компьютерлер желіден тыс көшірмені сақтай алмайды. | Қалыпты терезені пайдаланыңыз, немесе желіде қалыңыз. |
| Желі жоқ кезде CadCraft ашылмайды | Бұл браузерде желіден тыс пайдалануға сақталмаған, немесе браузер оны тазалап тастаған. | Келесі жолы желіге қосылғанда {{ui:Желіден тыс сақтау}} батырмасын басып, «Желіден тыс дайын» хабарын күтіңіз. |
| Сызба ашылады, бірақ кейбір бөліктері жоқ | CadCraft әлі сыза алмайтын объектілер, немесе файлда өшірілген немесе қатырылған қабаттар. | Сол жақ панельдегі «Бұл файл туралы» бөлімін оқыңыз. {{ui:Қабаттар}} панелін тексеріңіз. |
| Мәтін екі жолға оралады | CadCraft мәтінді Helvetica тәрізді қаріппен сызады, ол кейбір CAD қаріптерінен енірек. | Қасиеттерде мәтінді қысқартыңыз, немесе қосымша жолға келісіңіз. |
| Шеңбер эллипс болып көрінеді, немесе айналы мәтін дұрыс оқылады | Объект бағдарламада көлбеу жазықтықта салынған, немесе төменнен қаралған. CadCraft оны жоғарыдан қараған қалыпта көрсетеді, бұл сол бағдарламаның жоспар көрінісі сияқты; мәтін оқылатын күйде қалады. | Түзетудің қажеті жоқ. Оны басқа бағдарламаның көзқарасымен көру үшін сызбаны жазықтыққа айналдыруды немесе объектілерді жоғарыдан салынған етіп сұраңыз. |
| Блок, шеңбер немесе өлшем файлды жасаған бағдарламадағыдай жерде емес | CadCraft дұрыс оқымаған сызба жағдайы. | Discord арқылы хабарлаңыз, мүмкін болса файлды да тіркеңіз. |

## Пәрмен жолы

| Хабар немесе белгі | Себебі | Түзету |
|---|---|---|
| «Белгісіз пәрмен "…". Тізімді көру үшін HELP теріңіз.» | Осындай атпен пәрмен немесе бүркеншік ат жоқ. | `HELP` теріңіз, немесе [Пәрмендер анықтамалығын](topic:commands) қараңыз. Кейбір таныс пәрмендер [әлі жасалмаған](topic:not-built-yet). |
| Теру барысында пәрмен жолының жанында «Мұндай пәрмен жоқ» | Теріп жатқаныңыз әлі ешқандай пәрменге сәйкес келмейді. | Теруді жалғастырыңыз, немесе емлені тексеріңіз. |
| «Нүкте немесе опция кілт сөзі қажет.» | Теріп жатқаныңыз нүкте де, опция да емес. | Пішімді тексеріңіз: `x,y`, `@dx,dy`, `@d<a`, немесе бір сан. Қараңыз [Координат пен қашықтық енгізу](topic:coordinate-entry). |
| «Оң сан немесе екі нүкте қажет.» | Қашықтық теріс немесе сан емес еді. | Оң сан теріңіз, немесе екі нүктені басыңыз. |
| «Градуспен берілген бұрыш немесе екі нүкте қажет.» | Бұрыш сан емес еді. | Градусты қарапайым сан ретінде теріңіз. |
| «Сан қажет.» | Сан күтілді. | Тек цифрлар теріңіз. |
| «Опция кілт сөзі жарамсыз.» | Теріп жатқан әріптер опцияға сәйкес келмейді. | Шаршы жақшаларда көрсетілген бас әріптерді теріңіз. |
| `*Cancel*` | Сіз {{key:Esc}} бастыңыз, немесе нүкте керек болған жерде {{key:Enter}} бастыңыз. | Пәрменді қайта бастаңыз. |
| Теру пәрмен жолына жетпейді | Панельдегі немесе диалогтағы бір жолақта курсор бар. | {{key:Enter}} немесе {{key:Esc}} басыңыз, немесе сызбаны басыңыз. |
| Пәрмен сіз таңдамаған объектілерді пайдаланады | Олар пәрмен басталғанға дейін таңдалған болатын. | Пәрменнен бұрын {{key:Esc}} басыңыз. |
| Сызық күтпеген жерге барды | `x,y` абсолютті координат. | Салыстырмалы нүктелер үшін `@dx,dy` қолданыңыз. |
| «Алдымен ағымдағы пәрменді аяқтаңыз немесе болдырмаңыз (Esc).» | Пәрмен орындалып тұрғанда {{key:Mod+S}} бастыңыз. | {{key:Esc}} басып, содан кейін сақтаңыз. |
| «DWG (AutoCAD 2000) ретінде сақтау мүмкін болмады: … «Басқаша сақтау» опциясын, содан кейін DXF көріңіз.» | Сызбадағы бірдеңені DWG ретінде жазу мүмкін болмады. | {{key:Mod+Shift+S}} басыңыз, {{ui:DXF R12}} таңдап, {{ui:Сақтау}} батырмасын басыңыз. |
| «Сақталмады.» | Сіз {{ui:Көшірмесін сақтау}} диалогын {{ui:Бас тарту}} немесе {{key:Esc}} арқылы жаптыңыз. | {{key:Mod+Shift+S}} қайта басып, {{ui:Сақтау}} батырмасын басыңыз. |

## Өңдеу

| Хабар немесе белгі | Себебі | Түзету |
|---|---|---|
| Объект таңдалмайды | Оның қабаты құлыпталған, өшірілген немесе қатырылған; немесе парақта отырсыз және ол көріну ұяшығының ішіндегі модель. | Қабатты ашыңыз, немесе {{ui:Модель}} қойындысына өтіңіз. |
| «Ол жерде ештеңе табылмады.» | Басқан жерде объект жоқ. | Үлкейтіп, сызықтың өзін басыңыз. |
| «Ол объектпен сол жерде қиылысатын ештеңе жоқ.» | {{cmd:TRIM}} таңдаған бөлікпен қиылысатын объект таппады. | Кескіш сызықтың оны шынымен қиып өтетінін тексеріңіз. |
| «Бұл объектіні кесу мүмкін емес.» | Trim сызықтармен, доғалармен, шеңберлермен және полисызықтармен жұмыс істейді. | Алдымен блоктарды жарып алыңыз, немесе өшіріп, қайта салыңыз. |
| «Бұл бағытта шекара жоқ.» | {{cmd:EXTEND}} ұласатын ештеңе таппады. | Ұзартқыңыз келетін ұшқа жақынырақ басыңыз. |
| «Бұл объектіні ығыстыру мүмкін емес.» | Offset сызықтармен, доғалармен, шеңберлермен және полисызықтармен жұмыс істейді. | Алдымен жарып алыңыз, немесе параллель сызық салыңыз. |
| «Бұл объектіні тым алысқа ығыстыру мүмкін емес.» | Ығыстыру пішінді ішкі-сыртқа аударар еді. | Кішірек қашықтық қолданыңыз. |
| «Радиус тым үлкен.» немесе «Қашықтық тым үлкен.» | Fillet немесе chamfer сызық ұшынан асып кетер еді. | `R` арқылы кішірек радиус, немесе `D` арқылы кішірек қашықтықтар орнатыңыз. |
| «Ашық полисызықтың тек бірінші немесе соңғы сегментін кесуге болады.» | Бұрыш полисызықтың ортасына кіріп кетер еді. | Полисызықтың қатар тұрған екі сегментін таңдаңыз, немесе әр бұрыш үшін `P` қолданыңыз. |
| «Екінші, басқа сызықты таңдаңыз.» | Екінші таңдау сол сызық болды, немесе сызық емес еді. | Басқа сызықты таңдаңыз. |
| «Тек полисызықтар, блок сілтемелері және өлшемдер жарылады.» | Таңдауда жару үшін ештеңе жоқ еді. | Полисызық, блок сілтемесі немесе өлшем таңдаңыз. |
| «Бұл ағымдағы қабат. Алдымен басқа қабатты ағымдағы етіңіз.» | Ағымдағы қабатты өшіруге тырыстыңыз. | Басқа қабаттың атын басыңыз, содан кейін бұл қабатты өшіріңіз. |
| «… атты қабат бұрыннан бар» | Қабат атаулары бірегей болуы керек. | Басқа ат таңдаңыз. |
| «Болдырмайтын ештеңе жоқ.» | Болдырмайтын ештеңе қалмады, немесе сіз сызбаны ашып не жаңа бастадыңыз (бұл тарихты тазалайды). | — |
