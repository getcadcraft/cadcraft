Қысқа атауын (бүркеншік атын) теріп, {{key:Enter}} басыңыз немесе құралды басыңыз. {{key:Esc}} бас тартады. Бос жолда {{key:Enter}} соңғы команданы қайталайды.

**Басып шығару:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (бір A4 беті; Letter қағазында «бетке сыйғызу» арқылы басып шығарыңыз).

## Сызу

| Теру | Команда | Не істейді |
|---|---|---|
| `L` | {{cmd:LINE}} | Түзу сызықтар сызу |
| `PL` | {{cmd:PLINE}} | Жалғасқан сызық пен доға тізбегін сызу |
| `C` | {{cmd:CIRCLE}} | Шеңбер сызу (орталығы мен радиусы бойынша) |
| `A` | {{cmd:ARC}} | Доға сызу |
| `REC` | {{cmd:RECTANG}} | Екі бұрыш бойынша тіктөртбұрыш сызу |
| `POL` | {{cmd:POLYGON}} | Дұрыс көпбұрыш сызу |
| `EL` | {{cmd:ELLIPSE}} | Эллипс сызу |
| `DT` | {{cmd:TEXT}} | Мәтіннің бір жолын жазу |
| `T` | {{cmd:MTEXT}} | Жолдарға автоматты бөлінетін мәтін жазу (абзац) |
| `H` | {{cmd:HATCH}} | Ауданды үлгі бойынша штрихтау |

## Өзгерту

| Теру | Команда | Не істейді |
|---|---|---|
| `M` | {{cmd:MOVE}} | Нысандарды жылжыту |
| `CO` | {{cmd:COPY}} | Нысандарды көшіру |
| `RO` | {{cmd:ROTATE}} | Нысандарды нүкте айналасында бұру |
| `SC` | {{cmd:SCALE}} | Нысандарды үлкейту немесе кішірейту |
| `MI` | {{cmd:MIRROR}} | Нысандарды сызық арқылы айна бейнесіне аудару |
| `O` | {{cmd:OFFSET}} | Қашықтықта параллель көшірме салу |
| `TR` | {{cmd:TRIM}} | Басқа нысандар қиылысқан жерге дейін кесу |
| `EX` | {{cmd:EXTEND}} | Нысандарды басқаларға дейін ұзарту |
| `F` | {{cmd:FILLET}} | Бұрышты доғамен дөңгелектеу |
| `CHA` | {{cmd:CHAMFER}} | Бұрышты түзу жиекпен кесу |
| `E` | {{cmd:ERASE}} | Нысандарды жою |
| `X` | {{cmd:EXPLODE}} | Блокты немесе полисызықты бөліктерге ыдырату |
| `S` | {{cmd:STRETCH}} | Қиылысатын терезенің ішіндегі ұштарды жылжыту |
| `AR` | {{cmd:ARRAY}} | Торда немесе шеңберде көшіру |
| `J` | {{cmd:JOIN}} | Түзулер мен доғаларды бір нысанға біріктіру |
| `BR` | {{cmd:BREAK}} | Нысанды екіге бөлу немесе бір бөлігін алып тастау |

## Өлшем

| Теру | Команда | Не істейді |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Көлденең немесе тік өлшеу |

| `DRA` | {{cmd:DIMRADIUS}} | Радиусты өлшеу |

## Блоктар мен қабаттар

| Теру | Команда | Не істейді |
|---|---|---|
| `B` | {{cmd:BLOCK}} | Нысандардан блок жасау |
| `I` | {{cmd:INSERT}} | Блокты орналастыру |

## Көрініс және ақпарат алу

| Теру | Команда | Не істейді |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | Ұлғайту, кішірейту немесе барлығына масштабтау (E) |
| `DI` | {{cmd:DIST}} | Қашықтықты және бұрышты өлшеу |
| `LI` | {{cmd:LIST}} | Нысанның мәліметтерін көрсету |
| `MA` | {{cmd:MATCHPROP}} | Бір нысанның көрінісін басқаларына көшіру |

## Файл

| Теру | Команда | Не істейді |
|---|---|---|
| `U` | {{cmd:UNDO}} | Соңғы команданы болдырмау |
| `SAVE` | {{cmd:SAVE}} | Сызбаны сақтау |
| `PLOT` | {{cmd:PLOT}} | PDF-ке басып шығару |

## Пернелер

Ctrl (Mac-та Cmd): Z — болдырмау · Y — қайтару · S — сақтау · P — басып шығару.  F3 — нысандық ілулер · F8 — ортогональ · F10 — полярлық.  Space немесе Enter соңғы команданы қайталайды · дөңгелек масштабтайды · дөңгелекті сүйрегенде көрініс жылжиды
