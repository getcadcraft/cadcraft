Жарлықтар сіздің компьютеріңізге көрсетіледі. Mac-та әр {{key:Mod}} жарлығы Command пернесін пайдаланады, Control пернесі де жұмыс істейді. Пернелер қалай жазылатыны және Mac-та F-пернелерін қалай пайдалану керектігі [Пернелер, тінтуірлер және трекпадтар](common:keys) бөлімінде.

## Командаларды теру

| Перне | Не істейді |
|---|---|
| Кез келген әріп, цифр немесе таңба | Командалар жолына барады, тінтуір қай жерде тұрса да, панельдегі өріске курсор тұрмаса |
| {{key:Enter}} | Терген нәрсеңізді жібереді. Бос сұрауда: соңғы команданы қайталайды, команданы аяқтайды, таңдауды аяқтайды немесе `<…>` ішіндегі әдепкі мәнді қабылдайды |
| {{key:Space}} | {{key:Enter}}-мен бірдей, тек CadCraft мәтін сұрағанда (мәтін, блок атаулары, өлшем мәтіні), онда бос орын теріледі |
| {{key:Esc}} | Команданы болдырмайды. Команда орындалмаса: тұтқаны жылжытуды немесе таңдау терезесін болдырмайды, содан кейін таңдауды тазартады |
| {{key:Tab}} | Команда жолының оң жағында көрсетілген ұсынылған команданы қабылдайды. Ештеңе терілмеген және тінтуір қабаттасқан нысандардың үстінде болса: сол жердегі келесі нысанды бөлектейді (таңдау үшін басыңыз) |
| {{key:Up}} {{key:Down}} | Бұрын терген жолдар арасында өтеді (соңғы 100) |

## Сызу және өңдеу

| Перне | Не істейді |
|---|---|
| {{key:Mod+Z}} | Соңғы команданы болдырмайды |
| {{key:Mod+Y}} немесе {{key:Mod+Shift+Z}} | Қайтару |
| {{key:Mod+A}} | Ашық қойындыдағы өңдеуге болатын барлық нысанды таңдайды ({{cmd:SELECTALL}}). Команда жолына бірдеңе терілген болса, сол мәтінді таңдайды |
| {{key:Delete}} | Таңдалған нысандарды өшіреді ({{cmd:ERASE}}), команда жолында бірдеңе терілмеген болса |
| {{key:Backspace}} | Команда жолында курсор жоқ болса таңдалған нысандарды өшіреді; команда жолында терген нәрсесін жояды |
| {{key:Esc}} | Команда орындалмаса: таңдауды тазартады ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | Сызбаның пішімінде көшірме сақтайды (DWG немесе DXF) |
| {{key:Mod+Shift+S}} | Басқаша сақтау: DWG немесе DXF таңдап, көшірме сақтайды |
| {{key:Mod+O}} | DWG немесе DXF ашады |
| {{key:Mod+P}} | PDF-ке басып шығарады |

Болдырмау, қайтару, барлығын таңдау және басып шығару команда орындалып жатқанда ештеңе істемейді: алдымен {{key:Esc}} басыңыз.

## Көшіру, кесу және қою

| Перне | Не істейді |
|---|---|
| {{key:Mod+C}} | Таңдауды буферге көшіреді ({{cmd:COPYCLIP}}). Ештеңе таңдалмаса: CadCraft нысандарды сұрайды |
| {{key:Mod+X}} | Кесу: таңдауды көшіреді, сонан соң өшіреді ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | Қою: көшірме курсордың соңынан жүреді; оны қою үшін басыңыз немесе нүктені теріңіз ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | Орнында қою: көшірілген координаталарда ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | Көшірмесін жасау: таңдаудың көшірмесі тінтуірмен бірге жүреді; қою үшін басыңыз, {{key:Esc}} ештеңе қалдырмайды ({{cmd:DUPLICATE}}) |

Дәл осы әрекеттер құрал жолағындағы {{ui:Өңдеу}} тобында ({{ui:Көшіру}}, {{ui:Қою}}) және оның {{ui:Көбірек}} мәзірінде бар. Басқа команда орындалып жатқанда, оны аяқтаңыз немесе алдымен {{key:Esc}} басыңыз; көшірме курсордың соңынан жүріп тұрғанда {{key:Mod+V}} немесе {{key:Mod+D}} қайта басылса, бастаудан басталады. Команда жолында бірдеңе терілсе немесе команда мәтін сұраса, бұл пернелер сол мәтінді көшіреді, кеседі және қояды. Қараңыз: [Көшіру, қою және көшірме жасау](topic:copy-paste).

:::mac
Mac-та F3, F7 және F8 әдетте Mission Control және медиа пернелері. Олармен бірге **fn** ұстаңыз, немесе жүйелік баптауларда стандартты F-пернелерді қосыңыз, бұл [Пернелер, тінтуірлер және трекпадтар](common:keys) бөлімінде сипатталған. Күй жолағының түймелері әрқашан жұмыс істейді.
:::

:::firefox
Firefox-та F7 каретка браузерін қосуды ұсынуы мүмкін. **Жоқ** таңдаңыз, ал ол сұрай берсе, {{ui:Тор}} түймесін пайдаланыңыз.
:::

## Анықтама

| Перне | Не істейді |
|---|---|
| {{key:F1}} | Осы анықтаманы сызбаның жанында ашады немесе жабады. Команда орындалып жатқанда да жұмыс істейді және командалар жолына жетпейді. |
| {{key:Esc}} | Курсор анықтама панелінде болса: іздеуді тазартады немесе панельді жабады |

Жоғарғы жолақтағы {{ui:Анықтама}} түймесі {{key:F1}} сияқты істейді. Анықтаманың іздеу жолағына теріп жатқанда, ештеңе командалар жолына жетпейді. CadCraft-қа пернелерді қайтару үшін сызбаны басыңыз; панель соның жанында ашық қалады.

:::mac
Mac пернетақтасында **fn** ұстап, F1 басыңыз, немесе {{ui:Анықтама}} түймесін басыңыз.
:::

## Экран

| Перне | Не істейді |

| {{key:Ctrl+Shift+F}} | Қалыпты, толық экран және жолақтары жасырылған толық экран арасында ауысады. Бұл барлық компьютерде, соның ішінде Mac-та, Control пернесін пайдаланады. |

| Әрекет | Не істейді |

| Тұтқаны сүйреу | Тұтқаны жылжытады (немесе тұтқаны басып, содан кейін қай жерге барғанын басыңыз) |
| Мәтінді екі рет басу | Оны таңдайды және курсорды оң панельдегі {{ui:Мәтін}} өрісіне қояды |
| Оң түймемен басу | Enter. Тұтқаны жылжыту немесе таңдау терезесі кезінде: соны болдырмайды |
| Оң түймемен сүйреу | Жылжытады |
| Дөңгелек | Айқыш бағытында масштабтайды |

Сенсорлы тақтада немесе сенсорлы экранда: [Тінтуір, трекпад және сенсор](topic:mouse-trackpad-touch) бөлімін қараңыз.

## Браузер сақтайтын пернелер

{{key:Mod+N}}, {{key:Mod+W}} және {{key:Mod+T}} әрқашан браузерге тиесілі. CadCraft оларды пайдаланбайды: жаңа сызба үшін {{ui:Жаңа}} түймесін басыңыз немесе `NEW` теріңіз. CadCraft-тың буфері өз буфері: {{key:Mod+C}} және {{key:Mod+V}} нысандарды CadCraft сызбалары мен қойындылары арасында көшіреді, басқа бағдарламаларға немесе бағдарламалардан емес.

:::mac
Егер {{key:Mod+Y}} қайтарудың орнына браузердің тарихын ашса, {{key:Mod+Shift+Z}} немесе {{ui:Қайтару}} түймесін пайдаланыңыз.
:::

## Move қайда орналасқан

Move — `MOVE` командасы ({{key:M}} пернесі): нысандарды таңдаңыз, содан кейін базалық нүктені және екінші нүктені немесе терілген қашықтықты. `ALIGN` және `DISTRIBUTE` де бар. BimCraft осы аттарды бірдей жұмыстарға пайдаланады, бірақ оның {{key:M}} пернесі — Өлшеу: оның Move-і {{key:Shift+M}}.
