පුද්ගලයන් දෙදෙනෙක් එකම ඇඳීම සංස්කරණය කරයි. ඔවුන් වෙනස් වස්තූන් වෙනස් කළේ නම්, ඒකාබද්ධ කිරීම ස්වයංක්‍රීය විය හැක: අතින් නැවත කිරීමට කිසිවක් නැත.

## එය ක්‍රියා කරවන්නේ කුමක්ද

CadCraft ඔබ ඇඳි සෑම වස්තුවකටම කෙටි **යතුරක්** දෙයි, එය කිසිවිටෙක වෙනස් නොවන අතර කිසිවිටෙක වෙනත් වස්තුවකට නොදේ. එය DWG හෝ DXF හි වස්තුව සමග සුරැකේ (අනෙකුත් වැඩසටහන් තබා ගන්නා අමතර දත්ත ලෙස). ඒකාබද්ධ කිරීම වස්තූන් සොයන්නේ ගොනුවේ ඒවායේ පිහිටීම අනුව නොව, එම යතුර අනුවයි, මන්ද සෑම වැඩසටහනක්ම සුරකින විට පිහිටීම් නැවත අංකනය කරයි. ඔබ කිසිවිටෙක ඒකාබද්ධ නොකරන්නේ නම්, {{ui:Settings}} › CadCraft › ඒකාබද්ධ කිරීමට හිතකර ගොනු තුළ මෙය ක්‍රියාවිරහිත කරන්න; ගොනු සියයට 10 ක් පමණ කුඩා වේ.

යතුරු පැවතීමට පෙර සුරකින ලද ඇඳීමක් තවමත් ඒකාබද්ධ වේ: එහි වස්තූන් ගොනුවේ ඒවායේ ස්ථානය අනුව යතුරක් ලබා ගනී, එය විවෘත කරන සෑම කෙනෙකුටම එකම ආකාරයෙන්.

## එය සකසන්න

Git සඳහා, සෑම repository එකකටම වරක් රේඛා දෙකක් අවශ්‍යයි:

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git නොමැතිව, එය අතින් ධාවනය කරන්න: `cadcraft merge <base> <ours> <theirs> -o <result>`. Fossil සහ Mercurial එම ගොනු තුනම ඔවුන්ගේම merge-tool සැකසුමේ ගනී.

## රීති

- වෙනස් වූ වස්තුවක් එක් පැත්තක පමණක් නම්, එය ගනී. දෙපැත්තේම එකම වෙනස එක් වරක් ගනී.
- එක් ගුණාංගයක් දෙආකාරයකින් වෙනස් වූ විට **ගැටුමකි**: ඔබේ පැත්ත පවතී සහ වාර්තාව දෙකම අගයන් ලැයිස්තුගත කරයි. ප්‍රතිඵලය විවෘත කර, එම වස්තුව බලා, අතින් නිවැරදි කරන්න.
- ඕනෑම පැත්තක එක් කළ වස්තුවක් තබයි. එක් පැත්තක ඉවත් කළ සහ අනෙක් පැත්තේ නොවෙනස් වස්තුව ඉවත් වේ. එක් පැත්තක ඉවත් කර අනෙක් පැත්තේ වෙනස් කළ විට: ඉවත් කර, එය වාර්තා කරයි.
- ලේයර, බ්ලොක්, පෙළ සහ මාන ශෛලි, පත්‍ර සහ නම් කළ දසුන් එලෙසම ඒකාබද්ධ වේ. බාධක ඒවා නම් කරන වස්තූන් අනුගමනය කරයි.
- ප්‍රතිඵලය ඔබේ ගොනු ආකෘතියෙන් සහ අනුවාදයෙන්ම ලියා ඇත.

ඒකාබද්ධ නොවේ: වස්තූන් ඇඳෙන අනුපිළිවෙල ඔබට අයත් වේ, ඉන්පසු අනෙක් පැත්ත එක් කළ වස්තූන්. දෙපැත්තේම එකම බ්ලොක් නිර්වචනය වෙනස් කිරීම ගැටුමකි, කිසිවිටෙක මිශ්‍ර නොවේ. කිසිවක් උඩුගත නොවේ; ඒ සියල්ල ඔබේ පරිගණකයේ ක්‍රියා කරයි.
