Πληκτρολογήστε το σύντομο όνομα (το ψευδώνυμο) και πατήστε Enter ή κάντε κλικ στο εργαλείο. Το Esc ακυρώνει. Το Enter σε κενή γραμμή επαναλαμβάνει την τελευταία εντολή.

**Εκτυπώστε το:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (μία σελίδα A4· σε χαρτί Letter εκτυπώστε με «προσαρμογή στη σελίδα»).

## Σχεδίαση

| Πληκτρολογήστε | Εντολή | Τι κάνει |
|---|---|---|
| `L` | {{cmd:LINE}} | Σχεδιάζει ευθείες γραμμές |
| `PL` | {{cmd:PLINE}} | Σχεδιάζει μια συνεχή αλυσίδα γραμμών και τόξων |
| `C` | {{cmd:CIRCLE}} | Σχεδιάζει κύκλο (κέντρο και ακτίνα) |
| `A` | {{cmd:ARC}} | Σχεδιάζει τόξο |
| `REC` | {{cmd:RECTANG}} | Σχεδιάζει ορθογώνιο από δύο γωνίες |
| `POL` | {{cmd:POLYGON}} | Σχεδιάζει κανονικό πολύγωνο |
| `EL` | {{cmd:ELLIPSE}} | Σχεδιάζει έλλειψη |
| `DT` | {{cmd:TEXT}} | Γράφει μία γραμμή κειμένου |
| `T` | {{cmd:MTEXT}} | Γράφει κείμενο που αναδιπλώνεται (παράγραφος) |
| `H` | {{cmd:HATCH}} | Γεμίζει μια περιοχή με μοτίβο |

| Πληκτρολογήστε | Εντολή | Τι κάνει |
|---|---|---|

| `CO` | {{cmd:COPY}} | Αντιγράφει αντικείμενα |
| `RO` | {{cmd:ROTATE}} | Περιστρέφει αντικείμενα γύρω από ένα σημείο |
| `SC` | {{cmd:SCALE}} | Μεγαλώνει ή μικραίνει αντικείμενα |
| `MI` | {{cmd:MIRROR}} | Αναστρέφει αντικείμενα ως προς μια γραμμή |
| `O` | {{cmd:OFFSET}} | Σχεδιάζει παράλληλο αντίγραφο σε απόσταση |
| `TR` | {{cmd:TRIM}} | Κόβει αντικείμενα μέχρι το σημείο που τα τέμνουν άλλα |
| `EX` | {{cmd:EXTEND}} | Επεκτείνει αντικείμενα μέχρι άλλα |
| `F` | {{cmd:FILLET}} | Στρογγυλεύει μια γωνία με τόξο |
| `CHA` | {{cmd:CHAMFER}} | Κόβει μια γωνία με ευθεία ακμή |
| `E` | {{cmd:ERASE}} | Διαγράφει αντικείμενα |
| `X` | {{cmd:EXPLODE}} | Αναλύει ένα μπλοκ ή μια πολυγραμμή στα μέρη της |
| `S` | {{cmd:STRETCH}} | Μετακινεί τα άκρα μέσα σε παράθυρο διασταύρωσης |
| `AR` | {{cmd:ARRAY}} | Αντιγράφει σε πλέγμα ή σε κύκλο |
| `J` | {{cmd:JOIN}} | Ενώνει γραμμές και τόξα σε ένα αντικείμενο |
| `BR` | {{cmd:BREAK}} | Κόβει ένα αντικείμενο στα δύο ή αφαιρεί ένα κομμάτι |

## Πλήκτρα

Ctrl (Cmd σε Mac): Z αναίρεση · Y επανάληψη · S αποθήκευση · P σχεδίαση.  F3 αιχμαλώτιση αντικειμένου · F8 ortho · F10 πολική.  Το Space ή το Enter επαναλαμβάνει την τελευταία εντολή · ο τροχός κάνει ζουμ · σύροντας τον τροχό γίνεται μετατόπιση

Είστε νέοι στη σχεδίαση; Πληκτρολογήστε `TOUR` για ένα καθοδηγούμενο πρώτο σχέδιο, διαβάστε το [Ξεκινώντας](topic:getting-started) ή δείτε όλες τις εντολές στις [Εντολές](topic:commands). Αν έρχεστε από άλλο λογισμικό σχεδίασης: [Αν έρχεστε από άλλο λογισμικό σχεδίασης](topic:coming-from) και ο [χάρτης εντολών](topic:command-map).
