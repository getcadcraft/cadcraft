## Τι θα μάθετε

Πώς να προσθέσετε δικά σας σύντομα ονόματα για εντολές, για παράδειγμα `LL` για {{cmd:LINE}}, όλα σε ένα αρχείο κειμένου.

## Προσθήκη ψευδωνύμου

1. Ανοίξτε {{ui:Όψη}} › {{ui:Περισσότερα}} › {{ui:Επεξεργασία ψευδωνύμων…}}, ή πληκτρολογήστε {{cmd:ALIASEDIT}} και πατήστε {{key:Enter}}.
2. Προσθέστε μια γραμμή με το ψευδώνυμο, ένα κόμμα και την εντολή μετά από ένα αστέρι:

```
LL,     *LINE
```

3. Κάντε κλικ στο {{ui:Αποθήκευση}}. Η γραμμή εντολών λέει πόσα από τα ψευδώνυμά σας είναι σε χρήση.
4. Πληκτρολογήστε `LL` και πατήστε {{key:Enter}}: ξεκινά η LINE.

Τα ψευδώνυμά σας βρίσκονται πάνω από τα ενσωματωμένα του CadCraft. Μια γραμμή δική σας υπερισχύει ενός ενσωματωμένου ψευδωνύμου με το ίδιο όνομα· αφαιρέστε τη γραμμή σας και το ενσωματωμένο επανέρχεται.

## Γραμμές που δεν δέχεται το CadCraft

Ο επεξεργαστής αναφέρει κάθε πρόβλημα με τον αριθμό γραμμής του καθώς πληκτρολογείτε:

- η εντολή δεν υπάρχει·
- το ψευδώνυμο είναι το ίδιο όνομα εντολής (το `LINE, *CIRCLE` θα έκρυβε τη LINE);
- η γραμμή δεν έχει τη μορφή `ALIAS, *COMMAND`;
- το ίδιο ψευδώνυμο βρίσκεται σε δύο γραμμές (υπερισχύει η τελευταία).

Οι γραμμές που εκκινούν ένα πρόγραμμα στον υπολογιστή σας, όπως η `NOTEPAD, START, 1, *File to edit: ,`, παραλείπονται με μια σημείωση: μια εφαρμογή στον περιηγητή δεν μπορεί να εκκινήσει προγράμματα.

## Εισαγωγή ψευδωνύμων από άλλο πρόγραμμα

1. Στον επεξεργαστή ψευδωνύμων, κάντε κλικ στο {{ui:Εισαγωγή .pgp…}} και επιλέξτε το αρχείο. Μπορείτε επίσης να σύρετε ένα αρχείο `.pgp` πάνω στο σχέδιο.
2. Ελέγξτε τα προβλήματα που αναφέρονται (οι εντολές που δεν έχει το CadCraft απορρίπτονται, οι υπόλοιπες λειτουργούν).
3. Κάντε κλικ στο {{ui:Αποθήκευση}}.

Το {{ui:Εξαγωγή .pgp}} αποθηκεύει τα ψευδώνυμα του CadCraft και τα δικά σας ως ένα αρχείο στην ίδια μορφή.

## Επαναφόρτωση του αρχείου

Πληκτρολογήστε {{cmd:REINIT}} και πατήστε {{key:Enter}} για να εφαρμόσετε ξανά το αρχείο ψευδωνύμων σας. Διατηρείται σε αυτό το πρόγραμμα περιήγησης· η εφαρμογή για επιτραπέζιο υπολογιστή θα το κρατά στον δικό της φάκελο, και η υπηρεσία cloud θα το συγχρονίζει.

## Γράμματα για τις επιλογές μιας εντολής

Ένα ψευδώνυμο ονομάζει μια εντολή. Για να αλλάξετε τα γράμματα που απαντούν στις επιλογές μιας εντολής (`P` για την Πολική στην {{cmd:ARRAY}}), δείτε [Δώστε στις επιλογές εντολών δικά σας γράμματα](topic:option-letters).

## Συντομεύσεις πληκτρολογίου για οποιαδήποτε εντολή

Ένα ψευδώνυμο πληκτρολογείται· μια συντόμευση είναι ένα πλήκτρο. Για να δώσετε σε μια εντολή δικό σας πλήκτρο:

1. Κάντε κλικ στο {{ui:Όψη}} › {{ui:Περισσότερα}} › {{ui:Συντομεύσεις πληκτρολογίου…}}, ή πληκτρολογήστε `KEYS` και πατήστε {{key:Enter}}.
2. Κάντε κλικ στο πλαίσιο {{ui:Πλήκτρο}} και πατήστε τα πλήκτρα, για παράδειγμα {{key:Alt+Shift+C}}.
3. Στο {{ui:Εκτελεί}}, γράψτε την εντολή και, αν θέλετε, ό,τι πρέπει να πληκτρολογηθεί μετά από αυτήν: `CIRCLE`, ή `ZOOM E`.
4. Κάντε κλικ στο {{ui:Προσθήκη}}.

Ένα πλήκτρο χρειάζεται {{key:Mod}} ή {{key:Alt}} με ένα γράμμα ή ψηφίο, ή ένα ελεύθερο πλήκτρο συνάρτησης ({{key:F2}}, {{key:F4}}, {{key:F5}}, {{key:F6}}, {{key:F9}}). Τα πλήκτρα που ήδη χρησιμοποιούν το CadCraft, η εφαρμογή ή το πρόγραμμα περιήγησης, και τα πλήκτρα ενός κουμπιού «Τα εργαλεία μου» (δείτε [Κουμπιά δικά σας](topic:my-tools)), απορρίπτονται, και το πλαίσιο λέει γιατί. Οι συντομεύσεις κρατιούνται σε αυτό το πρόγραμμα περιήγησης (ή στην εφαρμογή για επιτραπέζιο υπολογιστή)· το {{ui:Αφαίρεση}} τις αφαιρεί.
