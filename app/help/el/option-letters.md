## Τι θα μάθετε

Πώς να αλλάξετε τα γράμματα που πληκτρολογείτε για να απαντήσετε στις επιλογές μιας εντολής. Για παράδειγμα, η {{cmd:ARRAY}} ρωτά `[Rectangular/POlar]` και δέχεται `PO` για Πολική· μπορείτε να κάνετε το `P` ή άλλα γράμματα να κάνουν το ίδιο, στη γλώσσα σας αν θέλετε.

## Πώς απαντιούνται οι επιλογές

Όταν μια εντολή δείχνει επιλογές σε τετράγωνες αγκύλες, τα κεφαλαία γράμματα είναι αυτά που πληκτρολογείτε: το `POlar` είναι `PO`, το `eXit` είναι `X`.

Μπορείτε επίσης να πληκτρολογείτε λιγότερα γράμματα. Αν αυτό που πληκτρολογείτε ταιριάζει μόνο σε μία από τις επιλογές, το CadCraft την παίρνει: με `[Rectangular/POlar]`, ένα μόνο `P` είναι η Πολική. Αν ταιριάζει σε δύο, η γραμμή εντολών τις ονομάζει και ξαναρωτά:

```
C could be COUnt, COLumns. Type more letters.
```

Οι αριθμοί δεν μαντεύονται ποτέ, οπότε μια πληκτρολογημένη απόσταση ή πλήθος διαβάζεται πάντα ως αριθμός.

## Προσθήκη δικών σας γραμμάτων

Κάθε εντολή κρατά τα ενσωματωμένα γράμματά της. Προσθέτετε τα δικά σας από πάνω, άρα η λίστα σας περιέχει μόνο όσα αλλάξατε.

1. Ανοίξτε τις {{ui:Ρυθμίσεις}} ({{key:Mod+,}}) › {{ui:CadCraft}} › {{ui:Γράμματα επιλογών}} και κάντε κλικ στο {{ui:Επεξεργασία…}}. Ή πληκτρολογήστε {{cmd:OPTIONKEYS}} και πατήστε {{key:Enter}}.
2. Στο {{ui:Εντολή}}, επιλέξτε την εντολή, για παράδειγμα `ARRAY`. Η λίστα έχει κάθε εντολή που ζητά επιλογές, και ξεκινά από την τελευταία εντολή που χρησιμοποιήσατε.
3. Στο {{ui:Επιλογή}}, επιλέξτε την επιλογή. Καθεμία δείχνει τα ενσωματωμένα γράμματά της σε αγκύλες, για παράδειγμα `POlar (PO)`.
4. Στο {{ui:Τα γράμματά σας}}, πληκτρολογήστε τα γράμματα που θέλετε, για παράδειγμα `P`, και κάντε κλικ στο {{ui:Προσθήκη}}.
5. Η επιλογή εμφανίζεται τώρα στο {{ui:Τα γράμματά σας}} με τα ενσωματωμένα γράμματά της και τα δικά σας. Κάντε κλικ στο {{ui:Αποθήκευση}}.

Ξεκινήστε την {{cmd:ARRAY}}, επιλέξτε ένα αντικείμενο και πατήστε {{key:Enter}}. Η προτροπή δείχνει τα δικά σας γράμματα μετά την επιλογή, `POlar (P)`, και το `P` απαντά σε αυτήν.

Για να αφαιρέσετε μία, κάντε κλικ στο x στο τέλος της γραμμής της και μετά στο {{ui:Αποθήκευση}}. Η επιλογή επιστρέφει στα ενσωματωμένα γράμματά της μόνο.

## Γράμματα που δεν μπορείτε να χρησιμοποιήσετε

Ο επεξεργαστής αρνείται γράμματα που θα έκρυβαν κάτι που η γραμμή εντολών ήδη διαβάζει, και λέει γιατί:

- τα ενσωματωμένα γράμματα μιας άλλης επιλογής της ίδιας εντολής (το `R` για την Πολική στην `ARRAY`, όπου το `R` είναι η Ορθογώνια)·
- μια λέξη αιχμαλώτισης αντικειμένου τριών γραμμάτων ή περισσότερων, όπως `END`, `MID` ή `CEN`, και οι λέξεις `ALL` και `LAST`·
- τα ίδια γράμματα για δύο διαφορετικές επιλογές μιας εντολής.

Όσο κάτι είναι γραμμένο με κόκκινο, το {{ui:Αποθήκευση}} είναι ανενεργό: διορθώστε τη γραμμή ή αφαιρέστε την, και θα ξαναενεργοποιηθεί. Τα ενσωματωμένα γράμματα μιας προτροπής υπερισχύουν πάντα των δικών σας, άρα η λίστα σας δεν μπορεί να εμποδίσει μια ενσωματωμένη απάντηση να λειτουργήσει. Γράμματα που τυχαίνει να είναι όνομα εντολής, όπως το `L` ή το `C`, επιτρέπονται: σε προτροπή επιλογής η γραμμή εντολών διαβάζει μια απάντηση, όχι μια εντολή.

Οι επιλογές που εμφανίζονται για μια εντολή προέρχονται από τις εντολές που μοιράζονται τις προτροπές της, οπότε κάποτε μια εντολή εμφανίζει μια επιλογή που ζητά μόνο σε ορισμένες περιπτώσεις.

## Μία επιλογή για κάθε εντολή

Στο {{ui:Εντολή}}, επιλέξτε {{ui:Κάθε εντολή}}. Οι επιλογές είναι τότε όλες όσες έχει οποιαδήποτε εντολή, όπως το eXit ή το Undo. Τα γράμματα που προσθέτετε εκεί απαντούν σε εκείνη την επιλογή όπου κι αν την προσφέρει μια εντολή. Τα γράμματα που προσθέσατε για μία εντολή υπερισχύουν αυτών.

## Γράμματα στη γλώσσα σας

Τα γράμματα μπορούν να είναι από οποιοδήποτε αλφάβητο, άρα μπορείτε να απαντάτε στις επιλογές χωρίς να αλλάζετε πληκτρολόγιο: προσθέστε `Ζ` για το Close στο {{ui:Κάθε εντολή}}, ή `Π` για το POlar στην `ARRAY`.

Το CadCraft έρχεται μόνο με τα αγγλικά γράμματα. Η δική σας λίστα είναι ο τρόπος που εσείς, το γραφείο σας ή όσοι μιλάτε τη γλώσσα σας ρυθμίζετε τα υπόλοιπα, και το {{ui:Εξαγωγή}} φτιάχνει ένα αρχείο που μπορείτε να μοιραστείτε.

## Επεξεργασία ως κείμενο

Το {{ui:Επεξεργασία ως κείμενο}} στον επεξεργαστή δείχνει την ίδια λίστα ως γραμμές κειμένου, μία για κάθε επιλογή, και αυτό ακριβώς αποθηκεύει το {{ui:Εξαγωγή}}:

```
ARRAY.PO,  P
*.X,       Q
```

Κάθε γραμμή είναι η εντολή, μια τελεία, τα ενσωματωμένα γράμματα της επιλογής, ένα κόμμα και τα δικά σας γράμματα. Ένας αστερίσκος στη θέση της εντολής σημαίνει κάθε εντολή. Μια γραμμή που αρχίζει με `;` είναι σημείωση.

## Τι μένει ίδιο

- Τα ενσωματωμένα γράμματα συνεχίζουν να λειτουργούν δίπλα στα δικά σας.
- Οι ρουτίνες και τα κουμπιά της γραμμής εργαλείων συνεχίζουν να χρησιμοποιούν τα ενσωματωμένα γράμματα, άρα τίποτα που έχετε φορτώσει δεν σπάει. Για να πληκτρολογήσετε εσείς τα ενσωματωμένα γράμματα όπου τα δικά σας θα έμπαιναν εμπόδιο, βάλτε μια κάτω παύλα μπροστά: `_PO`.
- Το σύντομο όνομα μιας εντολής είναι άλλο πράγμα: δείτε [Επεξεργασία ψευδωνύμων εντολών](topic:command-aliases).

## Γραμμές που δεν δέχεται το CadCraft

Όταν επεξεργάζεστε ως κείμενο ή εισάγετε ένα αρχείο, ο επεξεργαστής αναφέρει κάθε πρόβλημα με τον αριθμό γραμμής του:

- η εντολή δεν υπάρχει (το σύντομο όνομα εντολής είναι εντάξει: το `AR.PO` διαβάζεται ως `ARRAY.PO`)·
- η γραμμή δεν είναι της μορφής `COMMAND.OPTION, LETTERS`·
- τα γράμματα έχουν κενό ή σύμβολο (μόνο γράμματα και ψηφία, το πολύ 16)·
- τα ίδια γράμματα απαντούν σε δύο διαφορετικές επιλογές μιας εντολής.

## Εισαγωγή και εξαγωγή

Το {{ui:Εξαγωγή}} αποθηκεύει τα γράμματά σας ως αρχείο κειμένου, για να τα κρατήσετε ή να τα δώσετε σε κάποιον άλλον. Το {{ui:Εισαγωγή…}} διαβάζει ένα τέτοιο αρχείο. Και τα δύο βρίσκονται στον επεξεργαστή και στις {{ui:Ρυθμίσεις}} › {{ui:CadCraft}} › {{ui:Γράμματα επιλογών}}.

Στις Ρυθμίσεις, το {{ui:Εισαγωγή…}} αντικαθιστά το αρχείο σας με εκείνο που επιλέγετε. Ένα αρχείο με γραμμή που συγκρούεται ή δεν μπορεί να χρησιμοποιηθεί δεν γίνεται δεκτό· ανοίξτε τον επεξεργαστή και εισάγετε εκεί για να δείτε τις γραμμές. Στον επεξεργαστή, απλώς γεμίζει το πλαίσιο: τίποτα δεν αλλάζει μέχρι να κάνετε κλικ στο {{ui:Αποθήκευση}}.

## Επαναφόρτωση ή αφαίρεση

Πληκτρολογήστε {{cmd:REINIT}} και πατήστε {{key:Enter}} για να εφαρμόσετε ξανά το αρχείο σας. Για να αφαιρέσετε ένα γράμμα, διαγράψτε τη γραμμή του και κάντε κλικ στο {{ui:Αποθήκευση}}.

## Τα γράμματά σας ακολουθούν τον λογαριασμό σας

Όταν είστε συνδεδεμένοι στο getcadcraft.com, τα γράμματά σας κρατιούνται με τον λογαριασμό σας. Ανοίξτε το CadCraft σε άλλο πρόγραμμα περιήγησης ή σε άλλον υπολογιστή με τον ίδιο λογαριασμό, και φτάνουν μόνα τους· η γραμμή εντολών γράφει `Option letters from your account`. Αν τα αλλάξατε σε δύο μέρη, ισχύει το πιο πρόσφατο αντίγραφο και το αντικατασταθέν κρατιέται μία φορά.

Το {{ui:Ρυθμίσεις}} › {{ui:CadCraft}} › {{ui:Γράμματα επιλογών}} δείχνει πού βρίσκονται. Χωρίς σύνδεση ή εκτός δικτύου, μένουν σε αυτό το πρόγραμμα περιήγησης, και πηγαίνουν στον λογαριασμό σας την επόμενη φορά που θα τα αποθηκεύσετε ενώ είστε συνδεδεμένοι.
