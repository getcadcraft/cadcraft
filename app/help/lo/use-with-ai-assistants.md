## ສິ່ງທີ່ທ່ານຈະໄດ້ຮຽນຮູ້

ວິທີໃຫ້ຜູ້ຊ່ວຍ AI (ຫຼືສະຄຣິບທີ່ທ່ານຂຽນ) ເບິ່ງແບບແຕ້ມ, ເອີ້ນໃຊ້ຄຳສັ່ງຂອງ CadCraft, ພິມ ແລະບັນທຶກ, ແລະວິທີຕັດສິນໃຈວ່າມັນສາມາດແຕະຕ້ອງຫຍັງໄດ້ແດ່.

CadCraft **ບໍ່ມີ AI ຂອງຕົນເອງ** ແລະບໍ່ສົ່ງຫຍັງໄປບ່ອນໃດ. ທ່ານນຳຜູ້ຊ່ວຍມາເອງ: ໂປຣແກຣມໃດກໍໄດ້ທີ່ໃຊ້ Model Context Protocol (MCP) ໄດ້. CadCraft ພຽງແຕ່ໃຫ້ເຄື່ອງມືແກ່ມັນ, ແລະທ່ານເປັນຜູ້ເລືອກວ່າຈະໃຫ້ເຄື່ອງມືໃດ.

ມີສອງວິທີເຂົ້າໃຊ້:

- **ແບບແຕ້ມທີ່ທ່ານເປີດຢູ່.** ຜູ້ຊ່ວຍເຮັດວຽກໃນໜ້າຕ່າງນີ້, ຢູ່ຂ້າງທ່ານ, ຜ່ານ CadCraft Studio ໃນຄອມພິວເຕີຂອງທ່ານ. ນີ້ແມ່ນສິ່ງທີ່ {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Assistants}} ໃຊ້ສຳລັບ.
- **ແບບແຕ້ມໃນຄອມພິວເຕີຂອງທ່ານ, ໂດຍບໍ່ເປີດແອັບ.** ເຊີບເວີ CadCraft MCP ແລະແຖວຄຳສັ່ງ `cadcraft` ອ່ານ ແລະຂຽນໄຟລ໌ DWG ແລະ DXF ໃນໂຟນເດີທີ່ທ່ານລະບຸ. ເບິ່ງ "ເຮັດວຽກກັບໄຟລ໌ໂດຍບໍ່ເປີດ CadCraft" ດ້ານລຸ່ມ.

## ເປີດໃຊ້

1. ເປີດ {{ui:Settings}} (ຮູບເຟືອງໃນແຖບແອັບ, ຫຼື {{key:Mod+,}}) ແລ້ວໄປທີ່ແຖບ {{ui:CadCraft}}.
2. ພາຍໃຕ້ {{ui:Assistants}}, ໝາຍ **ອະນຸຍາດໃຫ້ຜູ້ຊ່ວຍ AI ແລະສະຄຣິບໃຊ້ CadCraft**. ມັນປິດຢູ່ຈົນກວ່າທ່ານຈະເປີດມັນ.
3. ເລືອກສິ່ງທີ່ມັນເຮັດໄດ້. **ອ່ານ** ຖືກໝາຍໄວ້ຕັ້ງແຕ່ຕົ້ນ; ໝາຍອັນອື່ນພຽງເມື່ອທ່ານຕ້ອງການ.

| ສິດອະນຸຍາດ | ຜູ້ຊ່ວຍເຮັດຫຍັງໄດ້ |
|---|---|
| ອ່ານ | ເບິ່ງແບບແຕ້ມ: ອະທິບາຍ, ລາຍການ ແລະຊອກຫາວັດຖຸ, ເບິ່ງການເລືອກ, ອະທິບາຍມຸມມອງ ແລະຖ່າຍຮູບມັນ, ກວດກັບກົດຂອງເລເຢີ ແລະການແຕ້ມ |
| ແກ້ໄຂ | ເອີ້ນຄຳສັ່ງໃນແບບແຕ້ມ ແລະປ່ຽນການເລືອກ. ແຕ່ລະການກະທຳແມ່ນໜຶ່ງຂັ້ນທີ່ທ່ານຍ້ອນກັບໄດ້ |
| ບັນທຶກ | ບັນທຶກແບບແຕ້ມ (ເທິງເດັສທັອບ, ໃສ່ໄຟລ໌ຂອງມັນ; ໃນບຣາວເຊີ, ເປັນການດາວໂຫຼດ) |
| ສົ່ງອອກ | ພິມເປັນ PDF ແລະສ້າງໄຟລ໌ອື່ນ |

## ໃຫ້ມັນໃຊ້ໄຟລ໌ໃນໂຟນເດີທີ່ທ່ານເລືອກ

ໃນ CadCraft Studio ຜູ້ຊ່ວຍສາມາດເປີດ, ບັນທຶກ ແລະພິມໄຟລ໌ດ້ວຍຊື່ ແທນທີ່ຈະໃຊ້ກ່ອງໂຕ້ຕອບໄຟລ໌, ແຕ່ພຽງພາຍໃນໂຟນເດີທີ່ທ່ານເພີ່ມພາຍໃຕ້ {{ui:Assistants}} › {{ui:Folders it may use}}:

1. ເລືອກ {{ui:Add a folder…}} ແລ້ວເລືອກໂຟນເດີໃນກ່ອງໂຕ້ຕອບຂອງ Studio ເອງ.
2. ຕອນນີ້ຜູ້ຊ່ວຍສາມາດລາຍການໄຟລ໌ໃນນັ້ນ (`files_list`), ເປີດແບບແຕ້ມ (`drawing_open`), ບັນທຶກມັນໃນນັ້ນເປັນເວີຊັນ DWG ໃດໜຶ່ງ ຫຼືເປັນ DXF, ພິມເປັນໄຟລ໌ PDF ຫຼື SVG, ໂຫຼດໄຟລ໌ LISP, ແລະໃຫ້ຄຳສັ່ງໄຟລ໌ທີ່ມັນຂໍ (`INSERT` `F`, `XATTACH`, ໄຟລ໌ຈຸດ) ຫຼືບອກວ່າໄຟລ໌ຂອງຄຳສັ່ງໄປຢູ່ໃສ (CSV ຂອງ `COUNT`, `PUBLISH`).
3. {{ui:Remove}} ເອົາໂຟນເດີຄືນທັນທີ. ເສັ້ນທາງໃດນອກນັ້ນຖືກປະຕິເສດ, ແລະໄຟລ໌ທີ່ມີຢູ່ແລ້ວຈະຖືກແທນທີ່ພຽງແຕ່ເມື່ອຜູ້ຊ່ວຍຂໍໃຫ້ເຮັດ ຫຼືເມື່ອມັນເປັນຜູ້ຂຽນໄຟລ໌ນັ້ນເອງ.

ການເປີດຍັງຕ້ອງການ **ອ່ານ**; ການບັນທຶກແບບແຕ້ມຕ້ອງການ **ບັນທຶກ**; ໄຟລ໌ອື່ນຕ້ອງການ **ສົ່ງອອກ**.

ເຄື່ອງມືທີ່ຢູ່ນອກສິດອະນຸຍາດທີ່ທ່ານໝາຍໄວ້ຈະບໍ່ຖືກສະເໜີໃຫ້ຜູ້ຊ່ວຍເລີຍ, ແລະຖ້າມັນຂໍຢ່າງໃດກໍຕາມ, CadCraft ຈະປະຕິເສດ ແລະບັນທຶກມັນໄວ້ໃນບັນທຶກກິດຈະກຳ. ການປິດສະວິດຈະຕັດທຸກການເຊື່ອມຕໍ່ພ້ອມກັນ. {{ui:Reset CadCraft settings}} ກໍປິດມັນເຊັ່ນກັນ.

## ເຊື່ອມຕໍ່ຜູ້ຊ່ວຍຂອງທ່ານ

ຜູ້ຊ່ວຍເຊື່ອມຕໍ່ຜ່ານ **CadCraft Studio** ໃນຄອມພິວເຕີຂອງທ່ານ: ມັນເປີດເຊີບເວີນ້ອຍໆທີ່ມີແຕ່ຄອມພິວເຕີເຄື່ອງນີ້ເຂົ້າເຖິງໄດ້ (ທີ່ຢູ່ `127.0.0.1`), ປ້ອງກັນດ້ວຍໂທເຄັນທີ່ Studio ສ້າງທຸກຄັ້ງທີ່ມັນເລີ່ມເຮັດວຽກ. ເປີດ Studio, ເລືອກ {{ui:Connect an assistant}}, ແລ້ວສຳເນົາທີ່ຢູ່ ແລະໂທເຄັນ.

- ໃນຜູ້ຊ່ວຍຂອງທ່ານ, ເພີ່ມເຊີບເວີ MCP ປະເພດ HTTP ດ້ວຍທີ່ຢູ່ (ມັນຄ້າຍ `http://127.0.0.1:47615/mcp`) ແລະ header `Authorization: Bearer <token>`. Studio ສະແດງການຕັ້ງຄ່າໃຫ້ວາງ.

{{ui:New token}} ໃນ Studio ເຮັດໃຫ້ທຸກຜູ້ຊ່ວຍທີ່ເຊື່ອມຕໍ່ຢູ່ເຊື່ອມຕໍ່ໃໝ່ດ້ວຍໂທເຄັນໃໝ່. ຢ່າແບ່ງປັນໂທເຄັນເດັດຂາດ: ໃຜກໍຕາມທີ່ມີມັນສາມາດໃຊ້ແອັບທີ່ທ່ານເປີດໄວ້ໄດ້, ຕາບໃດທີ່ Studio ກຳລັງເຮັດວຽກ.

:::note
ແທັບບຣາວເຊີບໍ່ສາມາດເປີດການເຊື່ອມຕໍ່ໃຫ້ຜູ້ຊ່ວຍໄດ້: ໃນແອັບບຣາວເຊີ ສະວິດບໍ່ມີຜົນ ຈົນກວ່າທ່ານຈະໃຊ້ CadCraft Studio ໃນຄອມພິວເຕີຂອງທ່ານ.
:::

## ທ່ານຍັງຄວບຄຸມຢູ່

- **ທຸກການກະທຳແມ່ນໜຶ່ງຂັ້ນຍ້ອນກັບ**, ຕິດປ້າຍດ້ວຍຊື່ຂອງຜູ້ຊ່ວຍສຳລັບມັນ, ຕົວຢ່າງ "Assistant: LINE". ກົດ {{key:Mod+Z}} ເພື່ອຍ້ອນກັບການກະທຳຫຼ້າສຸດຂອງຜູ້ຊ່ວຍທັງໝົດໃນຄັ້ງດຽວ.
- **ທ່ານເຫັນມັນເຮັດຫຍັງ.** ຄຳສັ່ງຂອງມັນປາກົດໃນປະຫວັດຄຳສັ່ງ ໂດຍມີ **[Assistant]** ຢູ່ໜ້າ, ແລະແບບແຕ້ມຈະແຕ້ມໃໝ່ຕາມທີ່ມັນເຮັດວຽກ.
- **ມັນລໍຖ້າທ່ານ.** ໃນຂະນະທີ່ທ່ານຢູ່ກາງຄຳສັ່ງ, ຜູ້ຊ່ວຍສາມາດອ່ານໄດ້ແຕ່ບໍ່ສາມາດປ່ຽນແບບແຕ້ມໄດ້; ມັນຖືກບອກໃຫ້ລອງໃໝ່ເມື່ອທ່ານສຳເລັດແລ້ວ.
- **ທ່ານຮູ້ເມື່ອມີການເຊື່ອມຕໍ່.** ປຸ່ມໃນແຖບແອັບຊື່ຜູ້ຊ່ວຍໃນຂະນະທີ່ມັນເຊື່ອມຕໍ່ຢູ່. ຄລິກມັນເພື່ອເບິ່ງວ່າມັນເຮັດໄດ້ຫຍັງ, ຫຼືເພື່ອ **ຕັດການເຊື່ອມຕໍ່** ມັນ.
- **ກິດຈະກຳ.** {{ui:Settings}} › {{ui:CadCraft}} › {{ui:Assistants}} › {{ui:Activity}} ລາຍການທຸກການເອີ້ນ: ເວລາ, ເຄື່ອງມືໃດ, ສຳເລັດ ຫຼືຖືກປະຕິເສດ, ແລະຂັ້ນຍ້ອນກັບທີ່ມັນສ້າງ. {{ui:Save the log}} ເກັບສຳເນົາໄວ້.

## ເຮັດວຽກກັບໄຟລ໌ໂດຍບໍ່ເປີດ CadCraft

ເຊີບເວີ CadCraft MCP (`cadcraft-mcp`) ແລະແຖວຄຳສັ່ງ (`cadcraft`) ເຮັດວຽກກັບໂຄດແບບແຕ້ມຂອງ CadCraft ເອງໃນ Node.js, ບໍ່ມີໜ້າຕ່າງ. ພວກມັນຕ້ອງການ Node.js 20 ຫຼືໃໝ່ກວ່າ.

- **ເຊີບເວີ MCP** ເຮັດວຽກພາຍໃນໂຟນເດີທີ່ທ່ານລະບຸເທົ່ານັ້ນ, ແລະພຽງດ້ວຍສິດອະນຸຍາດທີ່ທ່ານໃຫ້ມັນ: `npx @getcadcraft/mcp --root ~/Drawings --allow read,edit`. ບໍ່ມີ `--root` ມັນເປີດໄຟລ໌ໃດບໍ່ໄດ້; ບໍ່ມີ `--allow` ມັນອ່ານໄດ້ພຽງຢ່າງດຽວ. ມັນຍັງອ່ານແບບ IFC, ການຖອດປະລິມານ ແລະການໝາຍໃນຊຸດ PDF ໄດ້ອີກ.
- **ແຖວຄຳສັ່ງ** ແມ່ນສຳລັບສະຄຣິບຂອງທ່ານເອງ: `cadcraft info plan.dwg`, `cadcraft run cleanup.scr plan.dwg -o plan-clean.dwg`, `cadcraft convert plan.dwg plan.dxf`, `cadcraft plot plan.dwg plan.pdf --all`, `cadcraft plot plan.dwg plan.svg`, `cadcraft check plan.dwg --rules rules.json`. ຫຼາຍໄຟລ໌ພ້ອມກັນ: `cadcraft convert *.dwg out --to dxf`, `cadcraft plot *.dwg pdfs --to pdf`, `cadcraft check *.dwg --rules rules.json`. ເພີ່ມ `--json` ສຳລັບຜົນໃຫ້ໂປຣແກຣມອ່ານໄດ້.

:::note
ຖ້າ `npx @getcadcraft/mcp` ບອກວ່າບໍ່ພົບແພັກເກັດ, ມັນຍັງບໍ່ໄດ້ເຜີຍແຜ່. ຂ່າວໃນ getcadcraft.com ຈະບອກເມື່ອມັນພ້ອມ.
:::

## ຖ້າມີບາງຢ່າງບໍ່ເຮັດວຽກ

- **ຜູ້ຊ່ວຍບໍ່ເຫັນເຄື່ອງມື CadCraft:** ກວດວ່າສະວິດເປີດຢູ່ໃນໜ້າຕ່າງນີ້, ແລະໜ້າຕ່າງເປີດຢູ່ໃນ Studio.
- **"needs the edit permission":** ໝາຍ **ແກ້ໄຂ** ພາຍໃຕ້ {{ui:Assistants}}, ແລ້ວຂໍອີກຄັ້ງ.
- **"outside the folders assistants may use":** ເພີ່ມໂຟນເດີນັ້ນພາຍໃຕ້ {{ui:Assistants}} › {{ui:Folders it may use}}, ຫຼືຂໍໃຫ້ຜູ້ຊ່ວຍໃຊ້ໄຟລ໌ໃນໂຟນເດີທີ່ທ່ານເພີ່ມແລ້ວ.
- **ຂໍ້ຜິດພາດ "401" ຫຼື "token":** ໂທເຄັນປ່ຽນແລ້ວ (Studio ເລີ່ມໃໝ່, ຫຼື {{ui:New token}}). ສຳເນົາໂທເຄັນໃໝ່ໄປໃສ່ການຕັ້ງຄ່າຂອງຜູ້ຊ່ວຍ.
- **ການປ່ຽນແປງຂອງມັນຜິດ:** ກົດ {{key:Mod+Z}}. ການກົດໜຶ່ງຄັ້ງຍ້ອນກັບການກະທຳທັງໝົດຂອງຜູ້ຊ່ວຍໜຶ່ງອັນ.
