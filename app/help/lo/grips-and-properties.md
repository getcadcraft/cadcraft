## ສິ່ງທີ່ທ່ານຈະໄດ້ຮຽນ

ສອງວິທີດ່ວນເພື່ອປ່ຽນວັດຖຸໂດຍບໍ່ຕ້ອງໃຊ້ຄຳສັ່ງ: ລາກ **grips** ຂອງມັນ, ຫຼື ພິມຄ່າໃໝ່ໃນແຜງ **Properties** ທາງຂວາ.

## Grips

ເມື່ອທ່ານເລືອກວັດຖຸ (ສູງສຸດ 200 ອັນໃນເວລາດຽວ) ໂດຍບໍ່ມີຄຳສັ່ງເຮັດວຽກຢູ່, ຈະມີສີ່ຫຼ່ຽມນ້ອຍປາກົດຢູ່ເທິງວັດຖຸ. ນີ້ຄື grips:

| ວັດຖຸ | Grips |
|---|---|
| ເສັ້ນ | ປາຍທັງສອງ, ແລະ ຈຸດກາງ (ຍ້າຍທັງເສັ້ນ) |
| ວົງມົນ | ຈຸດສູນກາງ (ຍ້າຍມັນ) ແລະ ສີ່ຈຸດເທິງວົງມົນ (ປ່ຽນລັດສະໝີ) |
| ເສັ້ນໂຄ້ງ | ຈຸດສູນກາງ, ແລະ ປາຍທັງສອງ (ປ່ຽນບ່ອນເລີ່ມ ແລະ ບ່ອນສິ້ນສຸດ) |
| ໂພລີລາຍ | ທຸກຈຸດຍອດ |
| ຂໍ້ຄວາມ, ຈຸດ, ການອ້າງອີງບລັອກ | ຈຸດແຊກ |
| ວົງຮີ | ຈຸດສູນກາງ |
| ຂະຫນາດ | ຈຸດກຳນົດ ແລະ ຕຳແໜ່ງເສັ້ນຂະໜາດ |
| Viewport | ຈຸດສູນກາງ (ຍ້າຍມັນ) ແລະ ສີ່ມຸມ (ປັບຂະໜາດ) |

### ຍ້າຍ grip

1. ແຕ້ມເສັ້ນ ແລ້ວຄລິກໃສ່ມັນ. ຈະມີ grip ສາມອັນປາກົດ.
2. ຄລິກ grip ທີ່ປາຍດ້ານໜຶ່ງ. ແຖບສະຖານະຈະບອກວ່າ "ຄລິກບ່ອນທີ່ grip ນີ້ຈະໄປ (Esc ເພື່ອຍົກເລີກ). Snaps ແລະ Ortho ໃຊ້ໄດ້."
3. ຍ້າຍເຄີເຊີ. ຈະມີຕົວຢ່າງຕາມມາ.
4. ຄລິກຕຳແໜ່ງໃໝ່, ຫຼື ຈັບໃສ່ຈຸດຂອງວັດຖຸອື່ນ ແລ້ວຄລິກ.

ປາຍຈະຍ້າຍ ແລະ ສ່ວນທີ່ເຫຼືອຂອງເສັ້ນຈະຢູ່ເດີມ. ທ່ານຍັງສາມາດກົດໃສ່ grip ແລ້ວລາກ, ຈາກນັ້ນປ່ອຍໃນບ່ອນທີ່ຄວນຈະໄປ.

:::note
ທ່ານບໍ່ສາມາດພິມພິກັດສຳລັບ grip ໄດ້. ເພື່ອຕຳແໜ່ງທີ່ແນ່ນອນ, ໃຫ້ຈັບໃສ່ຈຸດ ຫຼື ພິມຄ່ານັ້ນໃນ Properties.
:::

ກົດ {{key:Esc}} ຫຼື ຄລິກຂວາ ເພື່ອຍົກເລີກການຍ້າຍ grip.

## Properties

ແຜງທາງຂວາສະແດງຄຸນສົມບັດຂອງສິ່ງທີ່ຖືກເລືອກ.

1. ຄລິກເສັ້ນ. ຫົວແຜງຈະອ່ານວ່າ "Line".
2. ຄລິກໃນ {{ui:Length}}, ພິມ `2500` ແລ້ວກົດ {{key:Enter}}.

ຕອນນີ້ເສັ້ນຈະຍາວ 2500 ພໍດີ, ໂດຍຮັກສາຈຸດເລີ່ມ ແລະ ມຸມຂອງມັນ. {{key:Enter}} ຫຼື ຄລິກບ່ອນອື່ນຈະນຳໃຊ້ຄ່າ; {{key:Esc}} ຈະໃສ່ຄ່າເກົ່າກັບຄືນ. ທຸກການປ່ຽນແປງເປັນ ຂັ້ນຕອນ Undo ໜຶ່ງຂັ້ນ, ເຖິງແມ່ນວ່າຫຼາຍວັດຖຸຈະປ່ຽນພ້ອມກັນ.

ຊ່ອງຕ່າງໆຮັບນິພົດ (`=2*45`) ແລະ ຄວາມຍາວພ້ອມໜ່ວຍ (`3'6"`, `900mm`), ທຸກຈຸດມີ X, Y ແລະ Z, ແລະ ສາມາດປ່ຽນຫຼາຍວັດຖຸພ້ອມກັນໄດ້. ທັງໝົດນີ້ຢູ່ໃນ [ແຜງ Properties](topic:properties-panel).

## ຂໍ້ຜິດພາດທົ່ວໄປ

- **ບໍ່ມີ grips ປາກົດ.** ມີຄຳສັ່ງເຮັດວຽກຢູ່ (ກົດ {{key:Esc}}), ຫຼື ມີວັດຖຸເກີນ 200 ອັນຖືກເລືອກ, ຫຼື ວັດຖຸຢູ່ໃນ layer ທີ່ລັອກ.
- **Grip ໄປຜິດບ່ອນ.** ການຈັບໄດ້ຈັບມັນໄວ້. ກົດ {{key:Shift}} ຄ້າງໄວ້ຂະນະຄລິກ ເພື່ອບໍ່ໃຫ້ສົນໃຈການຈັບ.
- **ພິມໃນ Properties ແລ້ວບໍ່ມີຫຍັງເກີດຂຶ້ນ.** ກົດ {{key:Enter}} ຫຼື ຄລິກບ່ອນອື່ນເພື່ອນຳໃຊ້. ຄ່າທີ່ບໍ່ຖືກຕ້ອງ (ຄວາມຍາວ ຫຼື ລັດສະໝີເປັນສູນ ຫຼື ລົບ, ຂໍ້ຄວາມທີ່ບໍ່ແມ່ນຕົວເລກ) ຈະເຮັດໃຫ້ຊ່ອງເປັນສີແດງ ແລະ ບອກເຫດຜົນ.
- **ຕົວອັກສອນທີ່ພິມຢູ່ໃນຊ່ອງ Properties.** ໃນຂະນະທີ່ຊ່ອງມີເຄີເຊີ, ການກົດປຸ່ມຈະພິມເຂົ້າໃນຊ່ອງນັ້ນ. ກົດ {{key:Enter}} ຫຼື {{key:Esc}} ກ່ອນ, ແລ້ວຈຶ່ງພິມຄຳສັ່ງ.
