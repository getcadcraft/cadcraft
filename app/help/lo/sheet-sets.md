## ສິ່ງທີ່ທ່ານຈະໄດ້ຮຽນຮູ້

ວິທີລວບລວມແຜ່ນ (ໜ້າຈັດວາງ) ຈາກຫຼາຍໄຟລ໌ແບບແຕ້ມເຂົ້າເປັນ **ຊຸດແຜ່ນ**, ໃສ່ເລກ ແລະ ຕັ້ງຊື່ໃຫ້ພວກມັນ, ໃຫ້ບລັອກຊື່ຂອງພວກມັນຖືກຕື່ມໃຫ້ອັດຕະໂນມັດ, ເຜີຍແຜ່ຊຸດທັງໝົດເປັນ PDF ດຽວ, ແລະ ບັນຈຸທຸກຢ່າງເຂົ້າ zip ດຽວເພື່ອສົ່ງ.

ໄຟລ໌ຊຸດແຜ່ນຢູ່ໃນໄຟລ໌ນ້ອຍຂອງມັນເອງ, `<name>.ccsheets`, ໃນໂຟນເດີທີ່ມີແບບແຕ້ມ. ໄຟລ໌ຊຸດລາຍຊື່ແຜ່ນດ້ວຍເສັ້ນທາງຈາກໂຟນເດີນັ້ນ, ດັ່ງນັ້ນທ່ານສາມາດຍ້າຍ ຫຼື ສຳເນົາທັງໂຟນເດີໄດ້.

:::note
ການເປີດໂຟນເດີເພື່ອອ່ານ ແລະ ຂຽນຕ້ອງການ Chrome ຫຼື Edge (ພວກມັນສາມາດໃຫ້ໜ້າເຮັດວຽກໃນໂຟນເດີທີ່ທ່ານເລືອກໄດ້), ຫຼື ແອັບເດັສທັອບ. ບຣາວເຊີອື່ນເປີດຊຸດແບບອ່ານຢ່າງດຽວ: ທ່ານເບິ່ງ ແລະ ເຜີຍແຜ່ໄດ້, ແລະ ໄຟລ໌ຊຸດດາວໂຫລດແທນທີ່ຈະບັນທຶກ.
:::

## ເລີ່ມຊຸດ

1. ຊອກຫາພາກ {{ui:Sheet set}} ໃນແຜງຊ້າຍ, ແລະ ເປີດເມນູ {{ui:Set}} ຂອງມັນ. ການພິມ {{cmd:SHEETSET}} (ຫຼື `SSM`) ກໍພາທ່ານໄປທີ່ນັ້ນເຊັ່ນກັນ.
2. ເລືອກ {{ui:New set…}}. ໃຫ້ຊຸດຊື່, ແລະ ຖ້າທ່ານຕ້ອງການ ຊື່ໂປຣເຈັກ ແລະ ເລກ.
3. ເລືອກໂຟນເດີທີ່ມີແບບແຕ້ມ. ໄຟລ໌ຊຸດຖືກບັນທຶກໄວ້ທີ່ນັ້ນ.

ເພື່ອເປີດຊຸດໃນພາຍຫຼັງ, ເລືອກ {{ui:Open set…}} ແລະ ເລືອກໂຟນເດີດຽວກັນ. ຖ້າໂຟນເດີມີຫຼາຍກວ່າໜຶ່ງຊຸດ, CadCraft ຈະຖາມວ່າອັນໃດ.

## ເພີ່ມແຜ່ນ

1. ເລືອກ {{ui:Add sheets from a drawing…}} ແລະ ເລືອກແບບແຕ້ມໜຶ່ງໃນໂຟນເດີ.
2. CadCraft ອ່ານແບບແຕ້ມນັ້ນໃນພື້ນຫຼັງ (ມັນບໍ່ເປີດໃນໜ້າຈໍ) ແລະ ລາຍການແຜ່ນຂອງມັນ. ໝາຍແຜ່ນທີ່ທ່ານຕ້ອງການ ແລະ ຄລິກ {{ui:OK}}.
3. ເລືອກແຜ່ນ ແລະ ກົດ {{key:F2}} (ຫຼື {{ui:Rename and renumber…}}) ເພື່ອໃຫ້ມັນເລກ ແລະ ຫົວຂໍ້, ເຊັ່ນ `A-101` ແລະ `ແຜນຜັງຊັ້ນ`.

{{ui:New sheet from template…}} ສ້າງແບບແຕ້ມໃໝ່ຈາກແຜ່ນຂອງແບບແຕ້ມອື່ນ (ບລັອກຊື່ ແລະ ວິວພອດຂອງມັນ), ຕັ້ງຊື່ຕາມແຜ່ນໃໝ່, ແລ້ວເພີ່ມມັນ. ຊຸດຈື່ແບບແຕ້ມທີ່ທ່ານໃຊ້ເປັນແມ່ແບບ.

## ຈັດຊຸດ

- **ຊຸດຍ່ອຍ** ຈັດກຸ່ມແຜ່ນ, ເຊັ່ນ Architectural › Plans: ເລືອກບ່ອນທີ່ມັນຄວນໄປ ແລະ ເລືອກ {{ui:New subset…}}.
- **ລຳດັບ**: ລາກແຜ່ນໄປບ່ອນອື່ນໃນລາຍການ, ຫຼື ໄປໃສ່ຊຸດຍ່ອຍເພື່ອຍ້າຍມັນໄປທີ່ນັ້ນ. ດ້ວຍແປ້ນພິມ, ເລືອກມັນ ແລ້ວກົດ {{key:Alt+Up}} ຫຼື {{key:Alt+Down}}.
- **ເປີດແຜ່ນ**: ດັບເບີ້ນຄລິກມັນ (ຫຼື ກົດ {{key:Enter}}). ແບບແຕ້ມຂອງມັນເປີດໃນແຖບຂອງຕົນເອງ, ຢູ່ແຜ່ນນັ້ນ.
- **ລຶບອອກ**: ເລືອກມັນ ແລ້ວກົດ {{key:Delete}}. ແບບແຕ້ມເອງບໍ່ຖືກປ່ຽນແປງ.
- **ຍ້ອນກັບ**: {{ui:Undo set change}} ແລະ {{ui:Redo set change}} ສະຫຼັບຜ່ານສິ່ງທີ່ທ່ານປ່ຽນແປງໃນຊຸດ.
- **ໃສ່ເລກໃໝ່**: {{ui:Renumber sheets…}} ໃສ່ເລກໃຫ້ທຸກແຜ່ນ, ຫຼື ຂອງຊຸດຍ່ອຍໜຶ່ງ, ຕາມລຳດັບຂອງລາຍການ: ຄຳນຳໜ້າ, ເລີ່ມຕົ້ນ ແລະ ຂັ້ນ (`A-` ແລະ `101` ໃຫ້ A-101, A-102 …).

ທຸກການປ່ຽນແປງຖືກບັນທຶກໃນໄຟລ໌ຊຸດທັນທີ.

## ໃສ່ເລກແຜ່ນຈາກຊ່ອງຂໍ້ມູນຂອງມັນ

ແທນທີ່ຈະໃສ່ເລກແຜ່ນດ້ວຍມື, ໃຫ້ກົດສ້າງແຕ່ລະເລກຈາກຊ່ອງຂໍ້ມູນຂອງແຜ່ນ, ດັ່ງນັ້ນແຜ່ນທີ່ຍ້າຍໄປຊັ້ນ ຫຼື ສາຂາອື່ນຈະໄດ້ເລກໃໝ່ຂອງມັນເອງ.

1. ໃຫ້ແຕ່ລະແຜ່ນມີຊ່ອງຂໍ້ມູນຂອງມັນ: ເລືອກແຜ່ນ, ຄລິກ {{ui:Rename…}} ແລະ, ໃນ {{ui:Fields of this sheet}}, ຂຽນໜຶ່ງຕໍ່ແຖວ, ເຊັ່ນ `DISCIPLINE = A` ແລະ `LEVEL = 1`. ຊ່ອງທີ່ທັງຊຸດໃຊ້ຮ່ວມກັນ (ເຊັ່ນ `DISCIPLINE = A`) ສາມາດໃສ່ໃນ {{ui:Properties…}} ຂອງຊຸດແທນໄດ້.
2. ເປີດເມນູຂອງແຜງ ແລະ ຄລິກ {{ui:Numbering rule…}}.
3. ຂຽນກົດ, ເຊັ່ນ `{DISCIPLINE}-{LEVEL}{SEQ:2}`. `{SEQ}` ນັບເພີ່ມໃນບັນດາແຜ່ນທີ່ຊ່ອງອື່ນຂອງພວກມັນອ່ານຄືກັນ, ດັ່ງນັ້ນຊັ້ນ 1 ໄດ້ A-101, A-102 ແລະ ຊັ້ນ 2 ເລີ່ມໃໝ່ທີ່ A-201. `{SEQ:2}` ຂຽນມັນດ້ວຍສອງຫຼັກ; `{SUBSET}` ແມ່ນຊື່ຂອງຊຸດຍ່ອຍທີ່ແຜ່ນຢູ່.
4. ເລືອກວ່າຈະເກີດຫຍັງເມື່ອຊ່ອງປ່ຽນ: {{ui:Renumber the sheets}} ຮັກສາເລກໃຫ້ຕາມກົດຫຼັງຈາກທຸກການປ່ຽນແປງ; ທາງເລືອກອື່ນໃສ່ເລກພຽງຄັ້ງດຽວ, ດຽວນີ້.

ກົດຖືກບັນທຶກໃນໄຟລ໌ຊຸດ. ໃນຂະນະທີ່ມັນໃສ່ເລກໃໝ່ດ້ວຍຕົນເອງ, ໃຫ້ປ່ຽນຊ່ອງຂອງແຜ່ນແທນທີ່ຈະປ່ຽນເລກຂອງມັນ.

## ຕື່ມບລັອກຊື່ຈາກຊຸດ

ບລັອກຊື່ໄດ້ຂໍ້ຄວາມຈາກຊຸດເມື່ອແອັດຕິບິວຂອງມັນຖືກໝາຍດ້ວຍຊື່ຂອງຊ່ອງ:

| ແທັກ | ສິ່ງທີ່ສະແດງ |
|---|---|
| `SHEETNUMBER` (ຫຼື `SHEET_NO`, `DWG_NO`) | ເລກຂອງແຜ່ນ |
| `SHEETTITLE` (ຫຼື `TITLE`, `SHEET_TITLE`) | ຫົວຂໍ້ຂອງແຜ່ນ |
| `SHEETDESC` | ຄຳອະທິບາຍຂອງແຜ່ນ |
| `PROJECTNAME` (ຫຼື `PROJECT`) | ຊື່ໂປຣເຈັກ |
| `PROJECTNUMBER` (ຫຼື `PROJECT_NO`, `JOB_NO`) | ເລກໂປຣເຈັກ |
| `SHEETSETNAME` | ຊື່ຂອງຊຸດ |
| `SHEETINDEX`, `SHEETCOUNT` | "3 ຈາກ 12", ແລະ 12 |
| ຂອງທ່ານເອງ, ເຊັ່ນ `CLIENT` | ສິ່ງທີ່ທ່ານຂຽນໃຫ້ມັນໃນ {{ui:Set fields…}} |

{{ui:Set fields…}} ຖືຊື່ ແລະ ເລກໂປຣເຈັກ ແລະ ຊ່ອງຂອງທ່ານເອງ, ໜຶ່ງຕໍ່ແຖວ ໃນຮູບແບບ `NAME = value`.

{{ui:Update drawings}} ຂຽນເລກ, ຫົວຂໍ້ ແລະ ຊ່ອງເຂົ້າໃນບລັອກຊື່ຂອງທຸກແບບແຕ້ມໃນຊຸດ, ແລະ ປ່ຽນຊື່ແຖບໜ້າຈັດວາງຂອງແຕ່ລະແຜ່ນຕາມທີ່ຊຸດກຳນົດ (ຄ່າເລີ່ມຕົ້ນແມ່ນເລກ ແລະ ຫົວຂໍ້, ເຊັ່ນ `A-101 ແຜນຜັງຊັ້ນ`; {{ui:Set fields…}} › {{ui:Layout tab names}} ປ່ຽນສິ່ງນັ້ນ). ແຕ່ລະແບບແຕ້ມຖືກບັນທຶກໃນບ່ອນເດີມ, ໃນຮູບແບບ ແລະ ເວີຊັນຂອງມັນເອງ. ຫຼັງຈາກທ່ານໃສ່ເລກໃໝ່ ຫຼື ປ່ຽນຊື່ແຜ່ນ, ໃຫ້ແລ່ນມັນອີກຄັ້ງ ແລະ ແຖບ ແລະ ບລັອກຊື່ຈະຕາມ.

## ລາຍການແຜ່ນໃນແຜ່ນປົກ

ເລືອກແຜ່ນປົກໃນລາຍການ ແລ້ວເລືອກ {{ui:Put the sheet list on this sheet}}. ຕາຕະລາງຂອງທຸກແຜ່ນ (ເລກ ແລະ ຫົວຂໍ້, ພາຍໃຕ້ຊຸດຍ່ອຍຂອງມັນ) ຖືກໃສ່ໃນມຸມເທິງຊ້າຍຂອງແຜ່ນ. {{ui:Update drawings}} ແລະ {{ui:Publish to PDF}} ຮັກສາມັນໃຫ້ທັນສະໄໝ. ມັນເປັນບລັອກດຽວ, `CC_SHEETLIST`: ຍ້າຍມັນຄືກັບການອ້າງອີງບລັອກອື່ນ.

## ເຜີຍແຜ່ຊຸດ

{{ui:Publish to PDF}} ສ້າງ PDF ໜຶ່ງໄຟລ໌ ທີ່ມີໜ້າໜຶ່ງຕໍ່ແຜ່ນ, ຕາມລຳດັບຂອງຊຸດ, ໃນຂະໜາດເຈ້ຍຂອງແຕ່ລະແຜ່ນ, ພ້ອມບຸກມາກໜຶ່ງຕໍ່ແຜ່ນ ("A-101 — ແຜນຜັງຊັ້ນ"). ເມື່ອເລືອກຊຸດຍ່ອຍ, CadCraft ຈະຖາມວ່າຈະເຜີຍແຜ່ແຕ່ຊຸດຍ່ອຍນັ້ນບໍ. ບລັອກຊື່ໃນ PDF ຖືກຕື່ມຈາກຊຸດແມ່ນແຕ່ກ່ອນທີ່ທ່ານຈະອັບເດດແບບແຕ້ມ; ແບບແຕ້ມເອງບໍ່ຖືກປ່ຽນໂດຍການເຜີຍແຜ່. PDF ດາວໂຫລດ.

{{ui:Publish to DWG…}} ຂຽນແຕ່ລະແຜ່ນເປັນ DWG ຂອງຕົນເອງ (DWG 2018): ໂມເດວ ແລະ ແຜ່ນນັ້ນ, ພ້ອມບລັອກຊື່ທີ່ຖືກຕື່ມຈາກຊຸດ, ຕັ້ງຊື່ຕາມເລກ ແລະ ຫົວຂໍ້ (`A-101 Level 1 floor plan.dwg`). ເລືອກ {{ui:DWG}}, ຫຼື {{ui:DWG + PDF}} ເພື່ອໃຫ້ PDF ຂອງຊຸດຢູ່ຂ້າງພວກມັນ. `publish.json` ລາຍການທຸກໄຟລ໌ພ້ອມຂະໜາດ ແລະ SHA-256 ຂອງມັນ. ເມື່ອໂຟນເດີຂອງຊຸດສາມາດຂຽນໄດ້ (CadCraft Studio, ຫຼື ໂຟນເດີທີ່ທ່ານເລືອກໃນບຣາວເຊີ) ໄຟລ໌ຈະເຂົ້າໄປໃນໂຟນເດີ `<set name> - published`; ບໍ່ດັ່ງນັ້ນ ມັນດາວໂຫລດເປັນ zip ດຽວ. [ການແທນທີ່ class ຂອງວິວພອດ](topic:viewport-overrides) ຕິດໄປກັບແຕ່ລະ DWG.

## ເກັບຊຸດ

{{ui:Archive as a zip}} ບັນຈຸໄຟລ໌ຊຸດ, ທຸກແບບແຕ້ມທີ່ມັນໃຊ້ ແລະ ສິ່ງທີ່ແບບແຕ້ມເຫຼົ່ານັ້ນເຊື່ອມໂຍງ (ແບບແຕ້ມທີ່ເຊື່ອມ, ແລະ ຂອງພວກມັນໃນທາງກັບກັນ, ແລະ ຮູບ), ຮັກສາໂຟນເດີຂອງພວກມັນ, ພ້ອມ `Transmittal.txt` ທີ່ລາຍການທຸກໄຟລ໌. ການເຊື່ອມໂຍງທີ່ບໍ່ຢູ່ໃນໂຟນເດີຂອງຊຸດຖືກລາຍການວ່າຫາຍໄປ. ການເຊື່ອມໂຍງຖືກພົບດ້ວຍເສັ້ນທາງຈາກແບບແຕ້ມ, ແລ້ວດ້ວຍຊື່ໄຟລ໌ຂອງມັນຢູ່ບ່ອນໃດກໍໄດ້ໃນໂຟນເດີ.

## ໄຟລ໌ຊຸດ

ໄຟລ໌ `.ccsheets` ເປັນ JSON ທີ່ທ່ານອ່ານໄດ້ໃນໂປຣແກຣມແກ້ໄຂຂໍ້ຄວາມໃດກໍໄດ້:

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

ເສັ້ນທາງສຳພັນກັບໂຟນເດີຂອງຊຸດ, ດ້ວຍ `/` ລະຫວ່າງໂຟນເດີ. CadCraft ກວດໄຟລ໌ເມື່ອເປີດມັນ: ເສັ້ນທາງເຕັມ, ແຜ່ນທີ່ບໍ່ມີໄຟລ໌ ຫຼື ການຈັດວາງ, ຫຼື ຂໍ້ຄວາມທີ່ບໍ່ແມ່ນຂໍ້ຄວາມທຳມະດາ ຈະຖືກຕັດອອກ, ແລະ ປະຫວັດບອກເຖິງສິ່ງນັ້ນ.
