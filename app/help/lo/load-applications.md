## ສິ່ງທີ່ທ່ານຈະໄດ້ຮຽນຮູ້

ວິທີໂຫຼດຣູທີນ LISP (ໄຟລ໌ `.lsp`) ເພື່ອໃຫ້ຄຳສັ່ງຂອງມັນເຮັດວຽກໃນ CadCraft, ວິທີຖອນໂຫຼດມັນ, ແລະ ວິທີໃຫ້ມັນໂຫຼດທຸກຄັ້ງທີ່ CadCraft ເລີ່ມ.

## ໂຫຼດຣູທີນ

1. ເປີດ {{ui:ມຸມມອງ}} › {{ui:ເພີ່ມເຕີມ}} › {{ui:ໂລດແອັບພລິເຄຊັນ…}}, ຫຼື ພິມ {{cmd:APPLOAD}} (ຫຼື `AP`) ແລະ ກົດ {{key:Enter}}.
2. ກົດ {{ui:ໂຫຼດໄຟລ໌…}} ແລ້ວເລືອກໄຟລ໌ `.lsp` ໜຶ່ງ ຫຼື ຫຼາຍອັນ. ຣູທີນທີ່ເປີດກ່ອງໂຕ້ຕອບ ປົກກະຕິມາພ້ອມໄຟລ໌ `.dcl`: ເລືອກມັນນຳ.
3. ກ່ອງໂຕ້ຕອບບອກວ່າແຕ່ລະໄຟລ໌ສ້າງຫຍັງ, ຕົວຢ່າງ "ໂຫຼດ delblocks.lsp ແລ້ວ: 1 ຄຳສັ່ງ, DELBLOCKS."
4. ກົດ {{ui:ປິດ}}, ພິມຄຳສັ່ງຂອງຣູທີນ ແລະ ກົດ {{key:Enter}}.

ທ່ານຍັງສາມາດວາງໄຟລ໌ `.lsp` ແລະ `.dcl` ໃສ່ແບບແຕ້ມ, ຫຼື ໃສ່ໃນກ່ອງໂຕ້ຕອບ {{ui:Load applications}}: ພວກມັນຖືກໂຫຼດທັນທີ.

ໄຟລ໌ຖືກອ່ານຢູ່ນີ້, ໃນບຣາວເຊີຂອງທ່ານ. ບໍ່ມີຫຍັງຖືກອັບໂຫຼດ.

:::tip
ກົດ {{key:Enter}} ໃນບັນທັດຄຳສັ່ງທີ່ວ່າງເພື່ອແລ່ນຄຳສັ່ງຂອງຣູທີນອີກຄັ້ງ, ຄືກັນກັບຄຳສັ່ງອື່ນ. ນາມແຝງຄຳສັ່ງຂອງທ່ານກໍເຂົ້າເຖິງມັນໄດ້ເຊັ່ນກັນ: ເບິ່ງ "ແກ້ໄຂນາມແຝງຄຳສັ່ງ".
:::

## ຖອນໂຫຼດຣູທີນ

ໃນ {{ui:Load applications}}, ພາຍໃຕ້ {{ui:Loaded applications}}, ກົດ {{ui:ຖອນໂຫຼດ}} ຂ້າງໄຟລ໌. ຄຳສັ່ງທີ່ມັນສ້າງຈະຫາຍໄປຈົນກວ່າທ່ານຈະໂຫຼດມັນອີກຄັ້ງ.

## ໂຫຼດຣູທີນທຸກຄັ້ງທີ່ CadCraft ເລີ່ມ

1. ໂຫຼດຣູທີນ.
2. ພາຍໃຕ້ {{ui:Loaded applications}}, ກົດ {{ui:Add to Startup Suite}} ຂ້າງມັນ.

ຈາກນີ້ໄປ ມັນຈະໂຫຼດເອງທຸກຄັ້ງທີ່ CadCraft ເລີ່ມໃນບຣາວເຊີນີ້. ເພື່ອຢຸດ, ກົດ {{ui:ລຶບອອກ (R)}} ຂ້າງມັນພາຍໃຕ້ {{ui:Startup Suite}}.

ຊຸດເລີ່ມຕົ້ນເກັບສຳເນົາຂອງແຕ່ລະໄຟລ໌ໄວ້ໃນບ່ອນເກັບຂໍ້ມູນຂອງບຣາວເຊີນີ້. ຖ້າທ່ານປ່ຽນຣູທີນ, ໃຫ້ໂຫຼດໄຟລ໌ໃໝ່ ແລ້ວເພີ່ມມັນອີກຄັ້ງ.

## ໂຫຼດ acad.lsp ແລະ acaddoc.lsp ຈາກໂຟນເດີສະໜັບສະໜູນ (Studio)

ໃນ CadCraft Studio, {{ui:Support folder}} ໃນກ່ອງໂຕ້ຕອບ {{ui:Load applications}} ຮັບໂຟນເດີໜຶ່ງໃນຄອມພິວເຕີຂອງທ່ານ. ກົດ {{ui:Choose folder…}}. ເມື່ອ CadCraft ເລີ່ມ ມັນອ່ານ `acad.lsp` ແລ້ວຈາກນັ້ນ `acaddoc.lsp` ຈາກໂຟນເດີນັ້ນ (ບໍ່ວ່າຕົວພິມໃຫຍ່ນ້ອຍຂອງຊື່ໃດ), ໂຫຼດພວກມັນ, ແລະ ຈາກນັ້ນໂຫຼດຊຸດເລີ່ມຕົ້ນ. `acaddoc.lsp` ຖືກອ່ານຄືນທຸກຄັ້ງທີ່ແທັບແບບແຕ້ມໃໝ່ເປີດ. ບໍ່ມີໄຟລ໌ອື່ນໃນໂຟນເດີຖືກອ່ານ, ແລະ ໄຟລ໌ທີ່ໃຫຍ່ກວ່າ 2 MB ຈະຖືກຂ້າມພ້ອມຂໍ້ຄວາມແຈ້ງ.

ຖ້າໄຟລ໌ກຳນົດຟັງຊັນຊື່ `S::STARTUP`, ມັນແລ່ນໜຶ່ງຄັ້ງຫຼັງຈາກໄຟລ໌ຖືກໂຫຼດ (ຫຼັງຊຸດເລີ່ມຕົ້ນເຊັ່ນກັນ). {{ui:ໂຫຼດດຽວນີ້}} ເຮັດແບບດຽວກັນເມື່ອຖືກຂໍ; {{ui:ລຶບ}} ລືມໂຟນເດີ.

ໃນບຣາວເຊີ ໜ້າເວັບບໍ່ສາມາດເກັບໂຟນເດີໄວ້ໄດ້, ສະນັ້ນບໍ່ມີໂຟນເດີສະໜັບສະໜູນ: ໃຊ້ຊຸດເລີ່ມຕົ້ນຂ້າງເທິງແທນ. ໄຟລ໌ `.fas` ແລະ `.vlx` ທີ່ compile ແລ້ວ ແລະ ໂປຣແກຣມ native ຍັງຖືກປະຕິເສດ.

## ໂຫຼດໄຟລ໌ຄືນຈາກປະຫວັດ

{{ui:ປະຫວັດ}} ລາຍຊື່ໄຟລ໌ທີ່ທ່ານໄດ້ໂຫຼດໃນບຣາວເຊີນີ້, ໃໝ່ສຸດກ່ອນ. ກົດ {{ui:ໂຫຼດ}} ຂ້າງໄຟລ໌ໜຶ່ງເພື່ອໂຫຼດມັນອີກຄັ້ງ, ໂດຍບໍ່ຕ້ອງຊອກຫາໃນຄອມພິວເຕີຂອງທ່ານ.

## ໄຟລ໌ທີ່ CadCraft ໂຫຼດບໍ່ໄດ້

| ໄຟລ໌ | ມັນແມ່ນຫຍັງ | ຈະເຮັດແນວໃດ |
|---|---|---|
| `.fas`, `.vlx` | LISP ທີ່ compile ແລ້ວ ຫຼື ປ້ອງກັນ | ໂຫຼດໄຟລ໌ຕົ້ນສະບັບ `.lsp` ແທນ |
| `.arx`, `.crx`, `.dbx` | ໂປຣແກຣມ native ຂອງ Windows | ບໍ່ມີວິທີແລ່ນສິ່ງເຫຼົ່ານີ້ໃນ CadCraft |
| `.dvb` | ໂປຣເຈັກ VBA | ບໍ່ມີວິທີແລ່ນສິ່ງເຫຼົ່ານີ້ໃນ CadCraft |
| `.craft`, `.lua`, `.py` | ສະຄຣິບ CraftScript | ເປີດພວກມັນໃນ Script workspace ຂອງ PartCraft |

ກ່ອງໂຕ້ຕອບ Load applications ບອກວ່າໄຟລ໌ໃດເປັນແບບໃດ ເມື່ອທ່ານເລືອກມັນ.

## ຢຸດຣູທີນ

ກົດ {{key:Esc}}. ຢູ່ໜຶ່ງໃນ prompt ຂອງຣູທີນ, Esc ຍົກເລີກມັນຕາມທີ່ຣູທີນຄາດຫວັງ (ການເຮັດຄວາມສະອາດຂອງມັນເຮັດວຽກ). ຖ້າມັນກຳລັງຍຸ່ງ ແລະ ບໍ່ໄດ້ຖາມຫຍັງ, Esc ຢຸດມັນທັນທີ ແລະ ແຈ້ງໃຫ້ຮູ້; ຣູທີນທີ່ໂຫຼດແລ້ວຍັງຢູ່ໂຫຼດຢູ່.

:::note
ທຸກສິ່ງທີ່ຣູທີນປ່ຽນໃນແບບແຕ້ມແມ່ນໜຶ່ງຂັ້ນ: {{key:Mod+Z}} ໜຶ່ງຄັ້ງຍ້ອນກັບທັງໝົດ.
:::
