## ສິ່ງທີ່ທ່ານຈະເຮັດ

ນຳໄຟລ໌ເຂົ້າໃນແບບແຕ້ມ ແລະ ແນ່ໃຈວ່າມັນເຂົ້າມາໃນຂະໜາດທີ່ຖືກຕ້ອງ.

## ຂັ້ນຕອນ

1. ນຳໄຟລ໌ເຂົ້າຕາມປົກກະຕິ: `INSERT` › ໄຟລ໌, `XATTACH`, `POINTCLOUDATTACH`, ຫຼື {{ui:ໄຟລ໌}} ໃນແຜງຄັງ.
2. ຖ້າໄຟລ໌ລະບຸໜ່ວຍຂອງມັນ, ຈະບໍ່ມີການຖາມ. ແຖວຄຳສັ່ງຈະບອກໜ່ວຍທີ່ໄຟລ໌ລະບຸ, ແລະ ມາດຕາສ່ວນທີ່ໃຊ້ເມື່ອພວກມັນແຕກຕ່າງຈາກແບບແຕ້ມ.
3. ຖ້າບໍ່ລະບຸ, ກ່ອງສົນທະນາຈະຖາມ **ໜ່ວຍຂອງ** ໄຟລ໌. ເລືອກວ່າໜຶ່ງໜ່ວຍໃນໄຟລ໌ເປັນຫຍັງ ແລ້ວຄລິກ {{ui:ໃຊ້ໜ່ວຍເຫຼົ່ານີ້}}. ຈະບໍ່ມີການວາງອັນໃດກ່ອນທ່ານຕອບ.
4. {{ui:ຍົກເລີກ}} (ຫຼື {{key:Esc}}) ຈະບໍ່ນຳອັນໃດເຂົ້າມາ.

## ໄຟລ໌ໃດລະບຸໜ່ວຍຂອງມັນ

- **DWG ແລະ DXF**: ໜ່ວຍແທຣກຂອງແບບແຕ້ມ (`$INSUNITS`). ໄຟລ໌ທີ່ບໍ່ມີມັນຈະຖືກຖາມ.
- **Point cloud**: LAS ແລະ LAZ ທີ່ມີລະບົບພິກັດ, E57, PTX ແລະ PLY ລະບຸໜ່ວຍຂອງພວກມັນ. ອື່ນໆຈະຖືກຖາມ.
- **OBJ**: ບໍ່ເຄີຍລະບຸໜ່ວຍ. ທ່ານຈະຖືກຖາມ.
- **glTF ແລະ GLB**: ແມັດ, ຕາມກົດຂອງຮູບແບບເອງ.
- **ຮູບພາບ**: ບໍ່ມີຂະໜາດຂອງຕົນເອງ. `IMAGEATTACH` ຖາມຄວາມກວ້າງ, ແລະ ສະເໜີຄວາມກວ້າງທີ່ທ່ານໃຫ້ກັບໄຟລ໌ນັ້ນກ່ອນໜ້າ.
- **ການສະແກນ**: ການສະແກນທີ່ລະບຸຄວາມໜາແໜ້ນ (ຈຸດຕໍ່ນິ້ວ) ຈະເຂົ້າມາໃນຂະໜາດຈິງໃນໜ່ວຍແບບແຕ້ມ; `SCANATTACH` ຍັງຖາມຄວາມກວ້າງ.
- **ສ່ວນເສີມ Point clouds**: ຖາມເມື່ອທ່ານສ້າງກຸ່ມຈຸດທີ່ໄຟລ໌ບໍ່ລະບຸໜ່ວຍ, ແລະ ໃສ່ປ້າຍໃຫ້ຕົວເລກຂອງກຸ່ມຈຸດໃນໜ່ວຍທີ່ມັນບັນຈຸ.

## ຄວນຮູ້

- ການເປີດ DWG ຫຼື DXF ເປັນແບບແຕ້ມຂອງມັນເອງຈະບໍ່ຖາມອັນໃດ: ແຖວຄຳສັ່ງຈະບອກໜ່ວຍທີ່ໄຟລ໌ລະບຸ, ຫຼື ວ່າບໍ່ລະບຸເລີຍ. {{ui:ຄຸນສົມບັດ}} ຕັ້ງໜ່ວຍຂອງແບບແຕ້ມ.
- ເມື່ອແບບແຕ້ມນີ້ກໍບໍ່ມີໜ່ວຍເຊັ່ນກັນ, ໄຟລ໌ຈະບໍ່ສາມາດແປງໄດ້: ມັນຈະຖືກວາງຕາມຕົວເລກຕໍ່ຕົວເລກ ແລະ ແຖວຄຳສັ່ງຈະບອກແບບນັ້ນ.
- ຄຳຕອບຖືກຈື່ສຳລັບໄຟລ໌ນັ້ນໃນຄອມພິວເຕີນີ້, ໃນທຸກແອັບ CadCraft. ຄັ້ງຕໍ່ໄປທີ່ມັນເຂົ້າມາ ທ່ານຈະບໍ່ຖືກຖາມ, ແລະ ແຖວຄຳສັ່ງຈະບອກວ່າໃຊ້ໜ່ວຍທີ່ຈື່ໄວ້.
- ເພື່ອໃຫ້ຖາມອີກ: ແຖບຄຳສັ່ງ ({{key:Mod+K}}) › **ຖາມອີກສຳລັບໜ່ວຍຂອງໄຟລ໌ທີ່ນຳເຂົ້າ**.
