## ສິ່ງທີ່ຈະສ້າງ

ສີ່ແຈດ້ວຍເສັ້ນທະແຍງສອງເສັ້ນ, ວົງມົນທີ່ມີຈຸດສູນກາງຢູ່ບ່ອນທີ່ມັນຕັດກັນ, ແລະ ເສັ້ນຈາກກາງດ້ານໜຶ່ງໄປຫາວົງມົນ. ທຸກຈຸດຖືກເລືອກດ້ວຍເມົ້າ, ແລະ ທຸກຈຸດແມ່ນແນ່ນອນ.

## ການຈັບເຮັດວຽກແນວໃດ

ໃນຂະນະທີ່ຄຳສັ່ງຂໍຈຸດ, CadCraft ຊອກຈຸດຈັບໃນລະຍະປະມານ 10 pixel ຈາກເສັ້ນເລັງ. ເມື່ອພົບ, ເຄື່ອງໝາຍ ແລະ ປ້າຍປາກົດ ("ປາຍຈຸດ", "ຈຸດຕັດ"), ແລະ ການກົດຈະລົງ **ແນ່ນອນ** ທີ່ຈຸດນັ້ນ, ບໍ່ແມ່ນບ່ອນທີ່ເສັ້ນເລັງຢູ່.

ການຈັບເປີດເມື່ອ {{ui:Snap}} ໃນແຖບສະຖານະຖືກກົດຄ້າງໄວ້. {{key:F3}} ເປີດ ແລະ ປິດມັນ.

ການຈັບທີ່ທ່ານໃຊ້ໄດ້ແມ່ນ:

| ການຈັບ | ລົງທີ່ |
|---|---|
| ປາຍຈຸດ | ປາຍຂອງເສັ້ນ, ເສັ້ນໂຄ້ງ ແລະ ສ່ວນຂອງໂພລີລາຍ |
| ຈຸດກາງ | ກາງຂອງເສັ້ນ, ເສັ້ນໂຄ້ງ ແລະ ສ່ວນຂອງໂພລີລາຍ |
| ຈຸດສູນກາງ | ຈຸດສູນກາງຂອງວົງມົນ ແລະ ເສັ້ນໂຄ້ງ, ແລະ ຂອງສ່ວນເສັ້ນໂຄ້ງໂພລີລາຍ |
| ຈຸດຄວາດ | ຈຸດ 0, 90, 180 ແລະ 270 ອົງສາຂອງວົງມົນ ແລະ ເສັ້ນໂຄ້ງ |
| ຈຸດຕັດ | ບ່ອນທີ່ສອງວັດຖຸຕັດກັນ |
| ຕັ້ງສາກ | ຈຸດເທິງວັດຖຸທີ່ຕັ້ງສາກກັບຈຸດສຸດທ້າຍ (ຕ້ອງການຈຸດອ້າງອີງ) |
| ສຳຜັດ | ຈຸດເທິງວົງມົນ ຫຼື ເສັ້ນໂຄ້ງ ທີ່ເສັ້ນຈາກຈຸດສຸດທ້າຍພຽງແຕ່ແຕະ. ເມື່ອຍັງບໍ່ມີຈຸດສຸດທ້າຍ (ຈຸດທຳອິດຂອງເສັ້ນ), ເຄື່ອງໝາຍບອກ "deferred": ຈຸດສຳຜັດຖືກຄິດໄລ່ເມື່ອຮູ້ຈຸດຕໍ່ໄປ, ດັ່ງນັ້ນເສັ້ນຈາກສຳຜັດຫາສຳຜັດຈະແຕະທັງສອງວົງມົນ |
| ໃກ້ທີ່ສຸດ | ຈຸດທີ່ໃກ້ທີ່ສຸດເທິງວັດຖຸໃດກໍໄດ້ |
| node | ວັດຖຸຈຸດ |
| ການແຊກ | ຈຸດແຊກຂອງຂໍ້ຄວາມ ແລະ ການອ້າງອີງບລັອກ |

ທັງໝົດເປີດໂດຍຄ່າເລີ່ມຕົ້ນ ຍົກເວັ້ນ ສຳຜັດ ແລະ ໃກ້ທີ່ສຸດ. ໃກ້ທີ່ສຸດມັກຊະນະເມື່ອທ່ານຕ້ອງການສິ່ງອື່ນ; ເປີດສຳຜັດເມື່ອທ່ານຕ້ອງການມັນ.

## ເລືອກການຈັບຂອງທ່ານ

1. ກົດລູກສອນນ້ອຍຂ້າງ {{ui:Snap}} ໃນແຖບສະຖານະ. ລາຍການ {{ui:Object snaps}} ເປີດ.
2. ໝາຍ ຫຼື ເອົາເຄື່ອງໝາຍອອກ. ການປ່ຽນແປງມີຜົນທັນທີ.
3. ກົດລູກສອນອີກຄັ້ງເພື່ອປິດລາຍການ.

CadCraft ຈື່ການເລືອກຂອງທ່ານ, ແລະ ການຕັ້ງຄ່າ {{ui:Grid}}, {{ui:Ortho}} ແລະ {{ui:Snap}}, ໃນບຣາວເຊີນີ້.

## ຂັ້ນຕອນ

1. ພິມ `REC` ແລ້ວກົດ {{key:Enter}}.
2. ພິມ `0,0` ແລ້ວກົດ {{key:Enter}}.
3. ພິມ `@4000,3000` ແລ້ວກົດ {{key:Enter}}. ສີ່ແຈປາກົດ.
4. ກົດ {{ui:Extents}}.
5. ພິມ `L` ແລ້ວກົດ {{key:Enter}}.
6. ຍ້າຍເສັ້ນເລັງໄປມຸມລຸ່ມຊ້າຍ. ເຄື່ອງໝາຍບອກ "ປາຍຈຸດ". ກົດ.
7. ຍ້າຍໄປມຸມຂວາເທິງຈົນ "ປາຍຈຸດ" ປາກົດ. ກົດ.
8. ກົດ {{key:Enter}} ເພື່ອຈົບເສັ້ນ.
9. ກົດ {{key:Enter}} ອີກຄັ້ງເພື່ອເຮັດຊ້ຳ {{cmd:LINE}}, ແລະ ແຕ້ມເສັ້ນທະແຍງອີກເສັ້ນ ຈາກມຸມຂວາລຸ່ມໄປມຸມຊ້າຍເທິງໃນລັກສະນະດຽວກັນ.
10. ພິມ `C` ແລ້ວກົດ {{key:Enter}} ເພື່ອເລີ່ມວົງມົນ.
11. ຍ້າຍເສັ້ນເລັງໄປບ່ອນທີ່ເສັ້ນທະແຍງຕັດກັນ. ເຄື່ອງໝາຍບອກ "ຈຸດຕັດ". ກົດ.
12. ພິມ `800` ແລ້ວກົດ {{key:Enter}}.

ທ່ານຄວນເຫັນວົງມົນທີ່ມີຈຸດສູນກາງຢູ່ຈຸດຕັດພໍດີ.

13. ພິມ `L` ແລ້ວກົດ {{key:Enter}}.
14. ຍ້າຍໄປກາງດ້ານຊ້າຍຂອງສີ່ແຈຈົນ "ຈຸດກາງ" ປາກົດ. ກົດ.
15. ຍ້າຍເສັ້ນເລັງໄປເທິງວົງມົນ, ດ້ານຊ້າຍຂອງມັນ. ເຄື່ອງໝາຍບອກ "ຕັ້ງສາກ" ຫຼື "ຈຸດຄວາດ"; ທັງສອງແມ່ນຈຸດດຽວກັນທີ່ນີ້. ກົດ.
16. ກົດ {{key:Enter}}.

ເສັ້ນໃໝ່ແລ່ນຈາກກາງດ້ານຊ້າຍ ແລະ ຢຸດພໍດີຢູ່ວົງມົນ.

## ຂ້າມການຈັບໃນການກົດດຽວ

ກົດຄ້າງ {{key:Shift}} ໃນຂະນະກົດ. ການຈັບວັດຖຸຖືກບໍ່ສົນໃຈສຳລັບການກົດນັ້ນ, ແລະ ຈຸດໄປບ່ອນທີ່ເສັ້ນເລັງຢູ່ພໍດີ (ຫຼື ຕາມທິດ Ortho, ຖ້າ Ortho ເປີດ).

## Ortho

{{ui:Ortho}} ({{key:F8}}) ຮັກສາຈຸດຕໍ່ໄປໃຫ້ຊື່ໆຕາມແນວນອນ ຫຼື ແນວຕັ້ງຈາກຈຸດອ້າງອີງ. ມັນໃຊ້ກັບການກົດ ແລະ ການປ້ອນໄລຍະໂດຍກົງ (ຕົວເລກດຽວທີ່ພິມຢູ່ແຖວຄຳສັ່ງ). ການຈັບວັດຖຸຊະນະ Ortho: ຖ້າເຄື່ອງໝາຍການຈັບປາກົດ, ການກົດໄປຫາການຈັບ.

## ການຕິດຕາມໂພລາ

{{ui:Polar}} ({{key:F10}}) ແມ່ນ Ortho ທີ່ມີຫຼາຍມຸມ. ໃນຂະນະທີ່ຄຳສັ່ງມີຈຸດອ້າງອີງ (ຈຸດສຸດທ້າຍຂອງເສັ້ນ, ຈຸດອ້າງອີງຂອງການຍ້າຍ), ເຄື່ອງຊີ້ຈະຈັດແນວເມື່ອມັນເຂົ້າໃກ້ລຳແສຈາກຈຸດນັ້ນທີ່ເປັນຜົນຄູນຂອງຂັ້ນໂພລາ: ເສັ້ນຈຸດຈຸດສະແດງ, ແລະ ປ້າຍຂ້າງເສັ້ນເລັງອ່ານ `Polar: 1200 < 30°`. ກົດເພື່ອໃຊ້ຈຸດນັ້ນ, ຫຼື ພິມໄລຍະ: `1200` ໄປຕາມລຳແສ 1200 ພໍດີ.

ຂັ້ນໂພລາແມ່ນ 90° ຈົນກວ່າທ່ານຈະປ່ຽນ: ພິມ {{cmd:POLARANG}}, ກົດ {{key:Enter}}, ແລ້ວພິມ `30` (ຫຼື 45, 22.5, 15 …). Polar ແລະ Ortho ຍົກເວັ້ນກັນ: ເປີດອັນໜຶ່ງຈະປິດອີກອັນໜຶ່ງ.

## ການຕິດຕາມວັດຖຸຈັບ

{{ui:Track}} ({{key:F11}}) ຈັດເຄື່ອງຊີ້ໃຫ້ແນວດຽວກັນກັບຈຸດຈັບທີ່ທ່ານພັກຢູ່, ດັ່ງນັ້ນທ່ານສາມາດເລືອກຈຸດໃຫ້ລະດັບດຽວກັບມຸມໜຶ່ງ ແລະ ເໜືອອີກມຸມໜຶ່ງ ໂດຍບໍ່ຕ້ອງແຕ້ມເສັ້ນຊ່ວຍ.

1. ເປີດ {{ui:Snap}} ແລະ {{ui:Track}}, ແລ້ວເລີ່ມຄຳສັ່ງທີ່ຂໍຈຸດ (`L`).
2. ພັກເຄື່ອງຊີ້ເທິງຈຸດຈັບ, ເຊັ່ນມຸມ, ປະມານເຄິ່ງວິນາທີ, ໂດຍບໍ່ກົດ. ເຄື່ອງໝາຍກາກບາດນ້ອຍໝາຍມັນ: ມັນຖືກຈັບໄວ້. ພັກເທິງມັນອີກຄັ້ງເພື່ອປ່ອຍ.
3. ຍ້າຍເຄື່ອງຊີ້ອອກຈາກມັນຕາມແນວນອນ ຫຼື ແນວຕັ້ງ. ເສັ້ນຈຸດຕິດຕາມເຄື່ອງຊີ້, ແລະ ປ້າຍອ່ານ `Track: 600 < 90°`. ກົດ, ຫຼື ພິມໄລຍະ.
4. ຈັບຈຸດທີສອງ, ແລະ ຍ້າຍໄປບ່ອນທີ່ແນວຕັ້ງຜ່ານໜຶ່ງ ແລະ ແນວນອນຜ່ານອີກອັນພົບກັນ: ເຄື່ອງຊີ້ຈະຈັບໃສ່ຈຸດຕັດນັ້ນ (`Track: where two lines meet`).

ເມື່ອ {{ui:Polar}} ເປີດນຳ, ຈຸດທີ່ຈັບຕິດຕາມທຸກມຸມໂພລາ. ສູງສຸດເຈັດຈຸດຖືກເກັບ, ຈົນກວ່າຄຳສັ່ງຈະຈົບ. {{key:Shift}} ປິດການຕິດຕາມສຳລັບການກົດໜຶ່ງເທື່ອ, ຄືກັບການຈັບ.

## ກຣິດ

{{ui:Grid}} ({{key:F7}}) ສະແດງຕາຕະລາງເສັ້ນຢູ່ດ້ານຫຼັງແບບແຕ້ມ, ໂດຍເສັ້ນທຶບທຸກເສັ້ນທີ່ຫ້າ; ໄລຍະຫ່າງປ່ຽນເມື່ອທ່ານຊູມ. ມັນເປັນພຽງຄູ່ມືຊ່ວຍຈົນກວ່າທ່ານຈະເປີດ {{ui:Grid snap}} ({{key:F9}}): ຈາກນັ້ນການກົດຈະລົງທີ່ຈຸດກຣິດທີ່ໃກ້ທີ່ສຸດ, ເວັ້ນເສຍແຕ່ການຈັບວັດຖຸຈະເອົາຈຸດກ່ອນ.

## ປຸ່ມຟັງຊັນໃນຄອມພິວເຕີຂອງທ່ານ

{{key:F9}} ແມ່ນ Grid snap, {{key:F10}} ແມ່ນ Polar ແລະ {{key:F11}} ແມ່ນ Track.

:::mac
ໃນ Mac, F3, F7, F8 ແລະ F9 ມັກຄວບຄຸມ Mission Control ແລະ ມີເດຍ. ກົດ **fn** ຄ້າງໄວ້ກັບປຸ່ມ, ຫຼື ເປີດປຸ່ມຟັງຊັນມາດຕະຖານ, ຕາມທີ່ອະທິບາຍໃນ [ປຸ່ມ, ເມົ້າ ແລະ ແທັດແພດ](common:keys). ປຸ່ມແຖບສະຖານະເຮັດວຽກສະເໝີ.
:::

:::firefox
ໃນ Firefox, F7 ເປັນປຸ່ມສຳລັບໂໝດເລືອກຂໍ້ຄວາມ (caret browsing) ນຳ. ຖ້າ Firefox ຖາມວ່າຈະເປີດໂໝດນີ້ຫຼືບໍ່, ເລືອກ **ບໍ່**. ໃຊ້ປຸ່ມ {{ui:Grid}} ຖ້າຄຳຖາມນີ້ກັບມາເລື້ອຍໆ.
:::

:::touch
ໃນໜ້າຈໍສຳຜັດ ບໍ່ມີການລອຍເມົ້າ, ສະນັ້ນເຄື່ອງໝາຍການຈັບປາກົດສະເພາະບ່ອນທີ່ນິ້ວສຳຜັດ. ຊູມເຂົ້າໃກ້ສຳລັບເປົ້າໝາຍນ້ອຍ, ຫຼື ພິມພິກັດແທນ.
:::

## ຄວາມຜິດພາດທົ່ວໄປ

- **ການກົດໄປຈຸດຜິດ.** ເບິ່ງປ້າຍເຄື່ອງໝາຍກ່ອນກົດ: ປາຍຈຸດຊະນະຈຸດກາງເມື່ອທັງສອງໃກ້. ຊູມເຂົ້າ, ຫຼື ເອົາການຈັບທີ່ທ່ານບໍ່ຕ້ອງການອອກ.
- **ບໍ່ມີເຄື່ອງໝາຍປາກົດ.** {{ui:Snap}} ປິດ, ຫຼື ການຈັບທີ່ທ່ານຕ້ອງການບໍ່ໄດ້ໝາຍ, ຫຼື ວັດຖຸຢູ່ເລເຢີທີ່ປິດ ຫຼື ຄ້າງ.
- **ການຈັບເອົາສິ່ງຜິດໃນແບບແຕ້ມທີ່ໜາແໜ້ນ.** ຊູມເຂົ້າ. ໄລຍະການຈັບວັດເປັນ pixel ໃນຈໍ, ດັ່ງນັ້ນການຊູມເຂົ້າເຮັດໃຫ້ມັນນ້ອຍລົງເທິງແບບແຕ້ມ.
- **ຄາດວ່າ Shift ຈະໃຫ້ເສັ້ນຊື່.** ໃນ CadCraft, Shift ປິດການຈັບສຳລັບການກົດໜຶ່ງເທື່ອ. ໃຊ້ {{ui:Ortho}} ສຳລັບເສັ້ນຊື່.
- **ຄາດວ່າຈຸດຈະລົງທີ່ຈຸດກຣິດ.** ເປີດ {{ui:Grid snap}} ({{key:F9}}), ຫຼື ພິມພິກັດສຳລັບຕົວເລກກົມ.
