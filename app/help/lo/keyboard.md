ປຸ່ມລັດຖືກສະແດງສຳລັບຄອມພິວເຕີຂອງທ່ານ. ໃນ Mac, ທຸກປຸ່ມລັດ {{key:Mod}} ຂ້າງລຸ່ມໃຊ້ປຸ່ມ Command, ແລະ ປຸ່ມ Control ກໍໃຊ້ໄດ້ເຊັ່ນກັນ. ວິທີຂຽນປຸ່ມ ແລະ ວິທີໃຊ້ປຸ່ມ F ໃນ Mac ຢູ່ໃນ [ປຸ່ມ, ເມົ້າ ແລະ ແທັກແພັດ](common:keys).

## ການພິມຄຳສັ່ງ

| ປຸ່ມ | ມັນເຮັດຫຍັງ |
|---|---|
| ຕົວອັກສອນ, ຕົວເລກ ຫຼື ສັນຍາລັກໃດ | ໄປທີ່ແຖວຄຳສັ່ງ, ບໍ່ວ່າຕົວຊີ້ຢູ່ໃສ, ນອກຈາກກ່ອງໃນແຜງທີ່ມີເຄີເຊີ |
| {{key:Enter}} | ສົ່ງສິ່ງທີ່ທ່ານພິມ. ໃນພຣອມປ໊ອດທີ່ຫວ່າງ: ເຮັດຊ້ຳຄຳສັ່ງສຸດທ້າຍ, ຈົບຄຳສັ່ງ, ສຳເລັດການເລືອກ, ຫຼື ຍອມຮັບຄ່າເລີ່ມຕົ້ນໃນ `<…>` |
| {{key:Space}} | ຄືກັນກັບ {{key:Enter}}, ຍົກເວັ້ນເວລາ CadCraft ຖາມຂໍ້ຄວາມ (ຂໍ້ຄວາມ, ຊື່ບລັອກ, ຂໍ້ຄວາມຂະໜາດ), ບ່ອນນັ້ນຈະພິມຊ່ອງວ່າງ |
| {{key:Esc}} | ຍົກເລີກຄຳສັ່ງ. ເມື່ອບໍ່ມີຄຳສັ່ງເຮັດວຽກ: ຍົກເລີກການຍ້າຍ grip ຫຼື ກ່ອງເລືອກ, ແລ້ວລຶບການເລືອກ |
| {{key:Tab}} | ຍອມຮັບຄຳສັ່ງແນະນຳທີ່ສະແດງທາງຂວາຂອງແຖວຄຳສັ່ງ. ເມື່ອບໍ່ໄດ້ພິມຫຍັງ ແລະ ຕົວຊີ້ຢູ່ເທິງວັດຖຸທີ່ທັບກັນ: ໄຮໄລ້ວັດຖຸຖັດໄປຢູ່ບ່ອນນັ້ນ (ຄລິກເພື່ອເລືອກມັນ) |
| {{key:Up}} {{key:Down}} | ເລື່ອນໄປມາລະຫວ່າງແຖວທີ່ທ່ານພິມກ່ອນໜ້າ (100 ອັນສຸດທ້າຍ) |

## ການແຕ້ມ ແລະ ແກ້ໄຂ

| ປຸ່ມ | ມັນເຮັດຫຍັງ |
|---|---|
| {{key:Mod+Z}} | ຍ້ອນກັບຄຳສັ່ງສຸດທ້າຍ |
| {{key:Mod+Y}} ຫຼື {{key:Mod+Shift+Z}} | ເຮັດຊ້ຳ |
| {{key:Mod+A}} | ເລືອກທຸກວັດຖຸທີ່ທ່ານແກ້ໄຂໄດ້ໃນແຖບທີ່ເປີດ ({{cmd:SELECTALL}}). ຖ້າທ່ານພິມບາງຢ່າງໃນແຖວຄຳສັ່ງ, ມັນຈະເລືອກຂໍ້ຄວາມນັ້ນແທນ |
| {{key:Delete}} | ລຶບວັດຖຸທີ່ເລືອກ ({{cmd:ERASE}}), ນອກຈາກທ່ານຈະພິມບາງຢ່າງໄວ້ໃນແຖວຄຳສັ່ງ |
| {{key:Backspace}} | ລຶບວັດຖຸທີ່ເລືອກເມື່ອແຖວຄຳສັ່ງບໍ່ມີເຄີເຊີ; ຢູ່ແຖວຄຳສັ່ງ ມັນຈະລຶບສິ່ງທີ່ທ່ານພິມ |
| {{key:Esc}} | ເມື່ອບໍ່ມີຄຳສັ່ງເຮັດວຽກ: ລຶບການເລືອກ ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | ບັນທຶກສຳເນົາໃນຮູບແບບຂອງແບບແຕ້ມ (DWG ຫຼື DXF) |
| {{key:Mod+Shift+S}} | ບັນທຶກເປັນ: ເລືອກ DWG ຫຼື DXF, ແລ້ວບັນທຶກສຳເນົາ |
| {{key:Mod+O}} | ເປີດ DWG ຫຼື DXF |
| {{key:Mod+P}} | ພິມອອກເປັນ PDF |

ການຍ້ອນກັບ, ເຮັດຊ້ຳ, ເລືອກທັງໝົດ ແລະ ການພິມ ຈະບໍ່ເຮັດຫຍັງ ໃນຂະນະທີ່ຄຳສັ່ງເຮັດວຽກຢູ່: ກົດ {{key:Esc}} ກ່ອນ.

## ສຳເນົາ, ຕັດ ແລະ ວາງ

| ປຸ່ມ | ມັນເຮັດຫຍັງ |
|---|---|
| {{key:Mod+C}} | ສຳເນົາການເລືອກໄປທີ່ clipboard ({{cmd:COPYCLIP}}). ຖ້າບໍ່ໄດ້ເລືອກຫຍັງ: CadCraft ຈະຂໍໃຫ້ເລືອກວັດຖຸ |
| {{key:Mod+X}} | ຕັດ: ສຳເນົາການເລືອກ, ແລ້ວລຶບມັນ ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | ວາງ: ສຳເນົາຈະຕາມຕົວຊີ້; ຄລິກ, ຫຼື ພິມຈຸດ, ເພື່ອວາງມັນ ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | ວາງໃນບ່ອນເດີມ: ຢູ່ພິກັດທີ່ມັນຖືກສຳເນົາມາຈາກ ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | ສຳເນົາຊ້ຳ: ສຳເນົາຂອງການເລືອກຈະເຄື່ອນໄປກັບຕົວຊີ້; ຄລິກເພື່ອວາງມັນ, {{key:Esc}} ຈະບໍ່ເຫຼືອຫຍັງ ({{cmd:DUPLICATE}}) |

ການກະທຳດຽວກັນຢູ່ໃນກຸ່ມ {{ui:Edit}} ຂອງແຖບເຄື່ອງມື( {{ui:Copy}}, {{ui:Paste}}) ແລະ ເມນູ {{ui:More}} ຂອງມັນ. ໃນຂະນະທີ່ຄຳສັ່ງອື່ນເຮັດວຽກຢູ່, ໃຫ້ສຳເລັດມັນ ຫຼື ກົດ {{key:Esc}} ກ່ອນ; ການກົດ {{key:Mod+V}} ຫຼື {{key:Mod+D}} ອີກຄັ້ງໃນຂະນະທີ່ສຳເນົາກຳລັງຕາມຕົວຊີ້ຈະເລີ່ມໃໝ່. ເມື່ອທ່ານພິມບາງຢ່າງໃນແຖວຄຳສັ່ງ, ຫຼື ເມື່ອຄຳສັ່ງກຳລັງຂໍຂໍ້ຄວາມ, ປຸ່ມເຫຼົ່ານີ້ຈະສຳເນົາ, ຕັດ ແລະ ວາງຂໍ້ຄວາມນັ້ນແທນ. ເບິ່ງ [ສຳເນົາ, ວາງ ແລະ ສຳເນົາຊ້ຳ](topic:copy-paste).

:::

## ຊ່ວຍເຫຼືອ

| ປຸ່ມ | ມັນເຮັດຫຍັງ |
|---|---|
| {{key:F1}} | ເປີດ ຫຼື ປິດຄູ່ມືນີ້, ຢູ່ຂ້າງແບບແຕ້ມ. ມັນເຮັດວຽກເຖິງແມ່ນໃນຂະນະທີ່ຄຳສັ່ງເຮັດວຽກຢູ່, ແລະ ບໍ່ເຄີຍໄປຮອດແຖວຄຳສັ່ງ. |
| {{key:Esc}} | ເມື່ອເຄີເຊີຢູ່ໃນແຜງຊ່ວຍເຫຼືອ: ລຶບການຄົ້ນຫາ, ຫຼື ປິດແຜງ |

ປຸ່ມ {{ui:Help}} ໃນແຖບດ້ານເທິງເຮັດຄືກັບ {{key:F1}}. ໃນຂະນະທີ່ທ່ານພິມໃນກ່ອງຄົ້ນຫາຂອງຊ່ວຍເຫຼືອ, ບໍ່ມີຫຍັງໄປຮອດແຖວຄຳສັ່ງ. ໃຫ້ຄລິກໃສ່ແບບແຕ້ມເພື່ອສົ່ງປຸ່ມຄືນໃຫ້ CadCraft; ແຜງຈະຢູ່ເປີດຂ້າງມັນ.

:::mac
ໃນແປ້ນພິມ Mac, ກົດ **fn** ຄ້າງໄວ້ ແລະ ກົດ F1, ຫຼື ຄລິກ {{ui:Help}}.
:::

## ໜ້າຈໍ

| ປຸ່ມ | ມັນເຮັດຫຍັງ |
|---|---|
| {{key:Ctrl+Shift+F}} | ສະຫຼັບລະຫວ່າງປົກກະຕິ, ເຕັມໜ້າຈໍ, ແລະ ເຕັມໜ້າຈໍທີ່ເຊື່ອງແຖບ. ນີ້ໃຊ້ປຸ່ມ Control ໃນທຸກຄອມພິວເຕີ, ລວມທັງ Mac |
| {{key:Left}} {{key:Right}} | ເມື່ອແຖບໃຕ້ແບບແຕ້ມຖືກເລືອກ: ແຖບກ່ອນໜ້າ ຫຼື ແຖບຕໍ່ໄປ |

ໃນໂໝດເຕັມໜ້າຈໍ, ບຣາວເຊີອາດໃຊ້ {{key:Esc}} ທຳອິດເພື່ອອອກຈາກເຕັມໜ້າຈໍ. ກົດ {{key:Esc}} ອີກຄັ້ງເພື່ອຍົກເລີກຄຳສັ່ງ.

## ກ່ອງໂຕ້ຕອບ

| ປຸ່ມ | ມັນເຮັດຫຍັງ |
|---|---|
| {{key:Esc}} | ປິດກ່ອງໂຕ້ຕອບ ({{ui:Plot to PDF}}, ຫຼື ຄຳຖາມເຊັ່ນ "Unsaved changes", ບ່ອນທີ່ມັນໝາຍເຖິງ {{ui:Cancel}}) |
| {{key:Tab}} | ຍ້າຍລະຫວ່າງການຕັ້ງຄ່າ ແລະ ປຸ່ມຂອງກ່ອງໂຕ້ຕອບ |

ໃນຂະນະທີ່ກ່ອງໂຕ້ຕອບເປີດຢູ່, ປຸ່ມຂອງແບບແຕ້ມຈະປິດ.

## ຊ່ອງໃນແຜງ

ໃນກ່ອງຂອງແຜງດ້ານຂວາ ຫຼື ດ້ານຊ້າຍ:

| ປຸ່ມ | ມັນເຮັດຫຍັງ |
|---|---|
| {{key:Enter}} | ນຳໃຊ້ຄ່າ ແລະ ອອກຈາກກ່ອງ |
| {{key:Esc}} | ໃສ່ຄ່າເກົ່າກັບຄືນ ແລະ ອອກຈາກກ່ອງ |
| {{key:Tab}} | ນຳໃຊ້ ແລະ ຍ້າຍໄປກ່ອງຖັດໄປ |

ໃນຂະນະທີ່ກ່ອງມີເຄີເຊີ, ຕົວອັກສອນຈະພິມເຂົ້າໃນກ່ອງ, ບໍ່ແມ່ນແຖວຄຳສັ່ງ.

## ປຸ່ມທີ່ບຣາວເຊີເກັບໄວ້

{{key:Mod+N}}, {{key:Mod+W}} ແລະ {{key:Mod+T}} ເປັນຂອງບຣາວເຊີສະເໝີ. CadCraft ບໍ່ໃຊ້ມັນ: ໃຫ້ໃຊ້ {{ui:New}} ຫຼື ພິມ `NEW` ສຳລັບແບບແຕ້ມໃໝ່. Clipboard ຂອງ CadCraft ເປັນຂອງມັນເອງ: {{key:Mod+C}} ແລະ {{key:Mod+V}} ສຳເນົາວັດຖຸລະຫວ່າງແບບແຕ້ມ ແລະ ແຖບຂອງ CadCraft, ບໍ່ແມ່ນໄປ ຫຼື ມາຈາກໂປຣແກຣມອື່ນ.

ຖ້າ {{key:Mod+Y}} ເປີດປະຫວັດຂອງບຣາວເຊີແທນທີ່ຈະເຮັດຊ້ຳ, ໃຫ້ໃຊ້ {{key:Mod+Shift+Z}} ຫຼື ປຸ່ມ {{ui:Redo}}.

## ບ່ອນທີ່ Move ຢູ່

Move ແມ່ນຄຳສັ່ງ `MOVE` (ປຸ່ມ {{key:M}}): ເລືອກວັດຖຸ, ແລ້ວຈຸດຖານ ແລະ ຈຸດທີ່ສອງ ຫຼື ໄລຍະທີ່ພິມ. `ALIGN` ແລະ `DISTRIBUTE` ກໍມີຢູ່ເຊັ່ນກັນ. BimCraft ໃຊ້ຊື່ດຽວກັນສຳລັບວຽກດຽວກັນໃນອົງປະກອບອາຄານ, ແຕ່ປຸ່ມ {{key:M}} ຂອງມັນແມ່ນ Measure: Move ຂອງມັນແມ່ນ {{key:Shift+M}}.
