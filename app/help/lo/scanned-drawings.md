## ຈາກແຜ່ນເຈ້ຍ ໄປເປັນວັດຖຸແບບແຕ້ມ

ແບບແຕ້ມທີ່ສະແກນແມ່ນຮູບພາບ. CadCraft ເກັບຮູບທີ່ທ່ານໃຫ້ໄວ້ ແລະ ບໍ່ເຄີຍປ່ຽນແປງມັນ: ແຕ່ລະຂັ້ນຕອນເຮັດຄວາມສະອາດສ້າງຮູບໃໝ່, ໂດຍມີການຍ້ອນກັບໜຶ່ງຂັ້ນຕໍ່ໜຶ່ງຂັ້ນຕອນ, ແລະ {{cmd:SCANINFO}} ລາຍການໄຟລ໌ຕົ້ນສະບັບ ແລະ ຂັ້ນຕອນທີ່ເຮັດນັບຕັ້ງແຕ່ນັ້ນມາ. ບໍ່ມີຫຍັງຖືກສົ່ງໄປບ່ອນໃດ ແລະ ບໍ່ມີການເດົາໂດຍໂມເດວທີ່ຝຶກໄວ້: ການເຮັດຄວາມສະອາດ ແລະ ການ trace ແມ່ນການປະມວນຜົນຮູບພາບທຳມະດາ, ແລະ ເຮັດວຽກຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ.

1. **ໃສ່ເຂົ້າ.** {{cmd:SCANATTACH}} ອ່ານໄຟລ໌ PNG, JPEG, TIFF (ໜ້າດຽວ, ຫຼື ທຸກໜ້າຂອງໄຟລ໌ຫຼາຍໜ້າ) ຫຼື ໜ້າ PDF ທີ່ເປັນຮູບ. ມັນຖາມຫາໜ້າ, ມຸມລຸ່ມຊ້າຍ ແລະ ຄວາມກວ້າງ. ສຳລັບໜ້າ PDF ມັນຍັງຖາມວ່າຈະແຕ້ມໜ້ານັ້ນດ້ວຍກີ່ຈຸດຕໍ່ນິ້ວ (pixels per inch).
2. **ປັບມາດຕາສ່ວນ.** {{cmd:SCANSCALE}}: ເລືອກສອງຈຸດໃນການສະແກນ, ແລ້ວພິມໄລຍະຫ່າງຈິງລະຫວ່າງມັນ. ແຜ່ນຖືກປັບມາດຕາສ່ວນຮອບຈຸດທຳອິດ.
3. **ຈັດແນວ.** {{cmd:SCANALIGN}}: ເລືອກສອງຈຸດໃນການສະແກນ ແລະ ສອງບ່ອນທີ່ມັນຄວນຢູ່; ແຜ່ນຈະຍ້າຍ ແລະ ຫັນເພື່ອໃຫ້ພໍດີ, ແລະ ຈະປັບມາດຕາສ່ວນນຳ ເວັ້ນແຕ່ທ່ານຕອບ ບໍ່ແມ່ນ.
4. **ຈັດໃຫ້ຕັ້ງສາກ.** {{cmd:SCANDESKEW}} ວັດມຸມທີ່ເສັ້ນຍາວຂອງແຜ່ນຢູ່ ແລະ ສະແດງມັນ, ພ້ອມຄວາມໝັ້ນໃຈ. ຍອມຮັບ, ຫຼື ພິມມຸມຂອງທ່ານເອງ, ແລ້ວແຜ່ນຈະຖືກຫັນ. ແຜ່ນທີ່ມີເສັ້ນຍາວໜ້ອຍຈະໄດ້ຄຳເຕືອນ: ໃຫ້ກວດມຸມກ່ອນຍອມຮັບ.
5. **ເຮັດຄວາມສະອາດ.** {{cmd:SCANCLEAN}} ເຮັດໃຫ້ແຜ່ນເປັນຂາວດຳ (Auto ປັບສີພື້ນເຈ້ຍກ່ອນ; Adaptive ຕິດຕາມການປ່ຽນແປງຂອງເຈ້ຍໃກ້ຊິດກວ່າ; Level ເປັນຕົວເລກດຽວສຳລັບທັງແຜ່ນ) ແລະ ລຶບຈຸດເປື້ອນຂະໜາດທີ່ທ່ານຕັ້ງ.
6. **ຕັດ ແລະ ລຶບ.** {{cmd:SCANCROP}} ຮັກສາກອບໜຶ່ງໄວ້. {{cmd:SCANERASE}} ລຶບສີ່ຫຼ່ຽມ, ຮູບຫຼາຍແຈ ຫຼື lasso (ກົດ ແລະ ລາກ): ຕາປະທັບ, ໝາຍເຫດ, ຮອຍວົງກາເຟ.

ຮູບທີ່ເຮັດຄວາມສະອາດແລ້ວແມ່ນສິ່ງທີ່ DWG ທີ່ບັນທຶກໄວ້ເກັບ (IMAGE ແລະ IMAGEDEF, ໂດຍມີໄຟລ໌ຮູບຢູ່ຂ້າງແບບແຕ້ມ, ຄືກັບຮູບອື່ນ).

## ຈັບເສັ້ນຂອງການສະແກນ

ດ້ວຍ {{cmd:RASTERSNAP}} ເປີດ (ຄ່າເລີ່ມຕົ້ນ), ການຈັບວັດຖຸກໍຊອກຫາເສັ້ນຂອງການສະແກນຂາວດຳເຊັ່ນກັນ: ປາຍເສັ້ນ, ກາງຂອງມັນ, ມຸມ ແລະ ຈຸດຕັດ, ສະແດງດ້ວຍເຄື່ອງໝາຍການຈັບທີ່ໃຊ້ທົ່ວໄປ. ສ່ວນຂອງແຜ່ນທີ່ຢູ່ໃຕ້ຕົວຊີ້ຖືກ trace ໃນຂະນະທີ່ທ່ານເຄື່ອນໄຫວ; ຊູມເຂົ້າພໍທີ່ພິກເຊວໜຶ່ງເປັນຫຼາຍພິກເຊວຂອງໜ້າຈໍ. ເສັ້ນທີ່ຍາວກວ່າສ່ວນທີ່ກຳລັງ trace ຈະຖືກຕິດຕາມຈົນເຖິງປາຍ.

## ການ trace

{{cmd:SCANTRACE}} ປ່ຽນເສັ້ນຂອງແຜ່ນເປັນເສັ້ນ ແລະ ເສັ້ນໂຄ້ງໃນເລເຢີໃໝ່ (SCAN-TRACE), ເປັນຂັ້ນຕອນການຍ້ອນກັບໜຶ່ງຄັ້ງ, ໂດຍການສະແກນຍັງຢູ່ຂ້າງລຸ່ມ. ທ່ານຕັ້ງ:

- **ຄວາມເບ່ຍເບນທີ່ອະນຸຍາດ:** ເສັ້ນ ຫຼື ເສັ້ນໂຄ້ງທີ່ຖືກ trace ອາດຢູ່ຫ່າງຈາກເສັ້ນໃນການສະແກນໄດ້ເທົ່າໃດ, ເປັນໜ່ວຍແບບແຕ້ມ (ລາຍງານຍັງໃຫ້ພິກເຊວ). ຄ່າທີ່ແໜ້ນຈະຕາມທຸກການເຄື່ອນໄຫວເລັກໆ; ຄ່າທີ່ຫຼວມຈະໄດ້ຊິ້ນໜ້ອຍກວ່າ ແລະ ຊື່ກວ່າ.
- **ກອບ:** ມຸມຂອງແຜ່ນ ຫຼື ແຜ່ນທັງໝົດ.
- **ເສັ້ນໂຄ້ງ:** ປິດຈະໄດ້ເສັ້ນເທົ່ານັ້ນ.
- **ສ່ວນທີ່ເຫຼືອ:** ສິ່ງທີ່ການ trace ບໍ່ໄດ້ແຕະຕ້ອງຈະຖືກແຕ້ມເປັນກ່ອງໃນເລເຢີທີ່ທ່ານປິດໄດ້, ຫຼື ບໍ່ແຕ້ມເລີຍ.

ການ trace ຊອກຫາຈຸດກາງຂອງແຕ່ລະເສັ້ນ, ຕິດຕາມມັນ, ປະກອບເສັ້ນຊື່ ແລະ ເສັ້ນໂຄ້ງວົງມົນໃສ່ມັນ, ເຊື່ອມຊ່ວງທີ່ຖືກຕັດຢູ່ບ່ອນທີ່ເສັ້ນອື່ນຂ້າມ, ເຮັດໃຫ້ເສັ້ນທີ່ເກືອບລະດັບ ແລະ ເກືອບຕັ້ງສາກກາຍເປັນລະດັບ ແລະ ຕັ້ງສາກຢ່າງແທ້ຈິງ, ແລະ ປິດມຸມ. **ຂໍ້ຄວາມ ແລະ ການແຮັດຍັງຄົງເປັນ raster:** ຊິ້ນທີ່ມີຂະໜາດເທົ່າຕົວໜັງສືຈະຖືກແຍກອອກໄວ້, ແລະ ກຸ່ມຂອງເສັ້ນຂະໜານສັ້ນໆຈະຖືກຖືວ່າເປັນການແຮັດ ແລະ ຖືກແຍກອອກໄວ້.

ເມື່ອສຳເລັດ ມັນບອກຈຳນວນເສັ້ນ ແລະ ເສັ້ນໂຄ້ງທີ່ສ້າງ, ຄວາມເບ່ຍເບນທີ່ອະນຸຍາດ, ແລະ ມີຈັກຊິ້ນທີ່ເຫຼືອເປັນ raster. **ນັ້ນແມ່ນສິ່ງທີ່ພິກເຊວໃຫ້, ໃນຄວາມເບ່ຍເບນນັ້ນ, ແລະ ບໍ່ແມ່ນການຢັ້ງຢືນວ່າຜົນຖືກຕ້ອງ.** ໃຫ້ປຽບທຽບກັບແຜ່ນ: ການ trace ອາດພາດເສັ້ນທີ່ຈາງ, ເຊື່ອມສອງເສັ້ນທີ່ຢູ່ໃກ້ກັນຫຼາຍ, ຫຼື ແຕ້ມເສັ້ນຢູ່ບ່ອນທີ່ມີແຕ່ຮອຍເປື້ອນ. ເຮັດຄວາມສະອາດການສະແກນກ່ອນ (ຕັ້ງສາກ, ຂາວດຳ, ຈຸດເປື້ອນຫາຍໄປ) ແລ້ວຜົນຈະດີຂຶ້ນຫຼາຍ.

## ສິ່ງທີ່ມັນບໍ່ອ່ານ

ໄຟລ໌ TIFF ທີ່ເກັບເປັນ tile, BigTIFF, TIFF ທີ່ບີບອັດດ້ວຍ JPEG ຫຼື deflate, ການເຂົ້າລະຫັດ fax Group 3 ແລະ ສີທີ່ເກັບແຍກເປັນ plane ຈະຖືກປະຕິເສດພ້ອມຂໍ້ຄວາມ; ໃຫ້ບັນທຶກຄືນເປັນ strip ດ້ວຍ LZW, PackBits, Group 4 ຫຼື ບໍ່ບີບອັດ. ໄຟລ໌ PNG ແບບ interlaced ກໍຖືກປະຕິເສດເຊັ່ນກັນ. ໄຟລ໌ທີ່ໃຫຍ່ກວ່າ 128 MB ຫຼື 100 ລ້ານພິກເຊວຖືກປະຕິເສດ, ແລະ ກອບ trace ສາມາດມີໄດ້ສູງສຸດ 64 ລ້ານພິກເຊວ.
