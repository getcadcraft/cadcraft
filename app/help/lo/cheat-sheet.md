ພິມຊື່ຫຍໍ້ (ຊື່ຫຍໍ້ຂອງຄຳສັ່ງ) ແລ້ວກົດ Enter, ຫຼື ຄລິກເຄື່ອງມື. Esc ຍົກເລີກ. Enter ໃນແຖວວ່າງຈະເຮັດຄຳສັ່ງສຸດທ້າຍຊ້ຳ.

**ພິມ:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (ໜ້າ A4 ໜ້າດຽວ; ໃນເຈ້ຍ Letter ໃຫ້ພິມດ້ວຍ "fit to page").

## ແຕ້ມ

| ພິມ | ຄຳສັ່ງ | ໜ້າທີ່ |
|---|---|---|
| `L` | {{cmd:LINE}} | ແຕ້ມເສັ້ນຊື່ |
| `PL` | {{cmd:PLINE}} | ແຕ້ມເສັ້ນ ແລະ ເສັ້ນໂຄ້ງທີ່ຕໍ່ກັນ |
| `C` | {{cmd:CIRCLE}} | ແຕ້ມວົງມົນ (ຈຸດສູນກາງ ແລະ ລັດສະໝີ) |
| `A` | {{cmd:ARC}} | ແຕ້ມເສັ້ນໂຄ້ງ |
| `REC` | {{cmd:RECTANG}} | ແຕ້ມສີ່ຫຼ່ຽມຈາກສອງມຸມ |
| `POL` | {{cmd:POLYGON}} | ແຕ້ມຫຼາຍຫຼ່ຽມປົກກະຕິ |
| `EL` | {{cmd:ELLIPSE}} | ແຕ້ມວົງຮີ |
| `DT` | {{cmd:TEXT}} | ຂຽນຂໍ້ຄວາມໜຶ່ງບັນທັດ |
| `T` | {{cmd:MTEXT}} | ຂຽນຂໍ້ຄວາມທີ່ຂຶ້ນບັນທັດໃໝ່ອັດຕະໂນມັດ (ຫຍໍ້ໜ້າ) |
| `H` | {{cmd:HATCH}} | ເຕີມພື້ນທີ່ດ້ວຍລາຍແບບ |
