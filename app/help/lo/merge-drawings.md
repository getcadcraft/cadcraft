ສອງຄົນແກ້ໄຂແບບແຕ້ມດຽວກັນ. ຖ້າພວກເຂົາປ່ຽນວັດຖຸຕ່າງກັນ, ການລວມສາມາດເປັນອັດຕະໂນມັດ: ບໍ່ມີຫຍັງຕ້ອງເຮັດດ້ວຍມື.

## ສິ່ງທີ່ເຮັດໃຫ້ມັນເຮັດວຽກ

CadCraft ໃຫ້ທຸກວັດຖຸທີ່ທ່ານແຕ້ມ **ລະຫັດ** ສັ້ນໜຶ່ງອັນທີ່ບໍ່ປ່ຽນ ແລະ ບໍ່ເຄີຍໃຫ້ແກ່ສອງວັດຖຸ. ມັນຖືກບັນທຶກພ້ອມວັດຖຸໃນ DWG ຫຼື DXF (ເປັນຂໍ້ມູນເພີ່ມເຕີມທີ່ໂປຣແກຣມອື່ນເກັບໄວ້). ການລວມຊອກຫາວັດຖຸດ້ວຍລະຫັດນັ້ນ, ບໍ່ແມ່ນດ້ວຍຕຳແໜ່ງຂອງມັນໃນໄຟລ໌, ເພາະທຸກໂປຣແກຣມກຳນົດເລກຕຳແໜ່ງໃໝ່ເມື່ອບັນທຶກ. ປິດມັນໄດ້ໃນ {{ui:ການຕັ້ງຄ່າ}} › CadCraft › ໄຟລ໌ທີ່ເໝາະກັບການລວມ ຖ້າທ່ານບໍ່ເຄີຍລວມ; ໄຟລ໌ຈະນ້ອຍລົງປະມານ 10 ເປີເຊັນ.

ແບບແຕ້ມທີ່ບັນທຶກກ່ອນລະຫັດມີຢູ່ຍັງລວມໄດ້: ວັດຖຸຂອງມັນຈະໄດ້ລະຫັດຈາກຕຳແໜ່ງໃນໄຟລ໌, ຄືກັນສຳລັບທຸກຄົນທີ່ເປີດມັນ.

## ຕັ້ງຄ່າ

Git ຕ້ອງການສອງບັນທັດຄັ້ງດຽວຕໍ່ repository:

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

ບໍ່ມີ git, ໃຫ້ແລ່ນດ້ວຍມື: `cadcraft merge <base> <ours> <theirs> -o <result>`. Fossil ແລະ Mercurial ໃຊ້ໄຟລ໌ສາມອັນດຽວກັນໃນການຕັ້ງຄ່າ merge-tool ຂອງພວກມັນເອງ.

## ກົດ

- ວັດຖຸທີ່ປ່ຽນແປງດ້ານດຽວເທົ່ານັ້ນຈະຖືກເອົາ. ການປ່ຽນແປງແບບດຽວກັນທັງສອງດ້ານຖືກເອົາຄັ້ງດຽວ.
- ຄຸນສົມບັດດຽວກັນທີ່ປ່ຽນສອງວິທີແມ່ນ **ຂໍ້ຂັດແຍ່ງ**: ດ້ານຂອງທ່ານຍັງຢູ່ ແລະ ລາຍງານລາຍຊື່ທັງສອງຄ່າ. ເປີດຜົນລັບ, ເບິ່ງວັດຖຸນັ້ນ, ແລ້ວແກ້ດ້ວຍມື.
- ວັດຖຸທີ່ເພີ່ມດ້ານໃດກໍໄດ້ຈະຖືກເກັບໄວ້. ວັດຖຸທີ່ຖືກລຶບດ້ານໜຶ່ງ ແລະ ບໍ່ໄດ້ແຕະຕ້ອງອີກດ້ານ ຈະຖືກລຶບ. ຖືກລຶບດ້ານໜຶ່ງ ແລະ ປ່ຽນແປງອີກດ້ານ: ຖືກລຶບ, ແລະ ລາຍງານ.
- ເລເຢີ, ບລັອກ, ຂໍ້ຄວາມ ແລະ ຮູບແບບຂະໜາດ, ແຜ່ນ ແລະ ມຸມມອງທີ່ມີຊື່ລວມແບບດຽວກັນ. ຂໍ້ຈຳກັດຕິດຕາມວັດຖຸທີ່ມັນລະບຸ.
- ຜົນລັບຖືກຂຽນໃນຮູບແບບໄຟລ໌ ແລະ ເວີຊັນດຽວກັນກັບຂອງທ່ານ.

ບໍ່ໄດ້ລວມ: ລຳດັບການແຕ້ມວັດຖຸແມ່ນຂອງທ່ານ, ຈາກນັ້ນວັດຖຸທີ່ອີກດ້ານເພີ່ມ. ການປ່ຽນແປງນິຍາມບລັອກດຽວກັນທັງສອງດ້ານແມ່ນຂໍ້ຂັດແຍ່ງ, ບໍ່ເຄີຍປະສົມ. ບໍ່ມີຫຍັງຖືກອັບໂຫຼດ; ທຸກຢ່າງເຮັດວຽກໃນຄອມພິວເຕີຂອງທ່ານ.
