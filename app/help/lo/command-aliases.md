## ສິ່ງທີ່ທ່ານຈະໄດ້ຮຽນຮູ້

ວິທີເພີ່ມຊື່ສັ້ນຂອງທ່ານເອງສຳລັບຄຳສັ່ງ ຕົວຢ່າງ `LL` ສຳລັບ {{cmd:LINE}} ທັງໝົດໃນໄຟລ໌ຂໍ້ຄວາມດຽວ.

## ເພີ່ມຊື່ຫຍໍ້

1. ເປີດ {{ui:ມຸມມອງ}} › {{ui:ເພີ່ມເຕີມ}} › {{ui:ແກ້ໄຂຊື່ຫຍໍ້ຄຳສັ່ງ…}}, ຫຼື ພິມ {{cmd:ALIASEDIT}} ແລ້ວກົດ {{key:Enter}}.
2. ເພີ່ມແຖວໃໝ່ທີ່ມີຊື່ຫຍໍ້, ເຄື່ອງໝາຍຈຸດ ແລະ ຄຳສັ່ງຫຼັງເຄື່ອງໝາຍດາວ:

```
LL,     *LINE
```

3. ຄລິກ {{ui:ບັນທຶກ}}. ແຖວຄຳສັ່ງຈະບອກວ່າມີຊື່ຫຍໍ້ຂອງທ່ານກຳລັງໃຊ້ຢູ່ຈັກອັນ.
4. ພິມ `LL` ແລ້ວກົດ {{key:Enter}}: LINE ຈະເລີ່ມ.

ຊື່ຫຍໍ້ຂອງທ່ານຈະຢູ່ເໜືອຊື່ຫຍໍ້ຂອງ CadCraft. ແຖວຂອງທ່ານຈະຊະນະຊື່ຫຍໍ້ໃນຕົວທີ່ມີຊື່ດຽວກັນ; ຖ້າລຶບແຖວຂອງທ່ານອອກ ຊື່ຫຍໍ້ໃນຕົວຈະກັບມາ.

## ແຖວທີ່ CadCraft ປະຕິເສດ

ຕົວແກ້ໄຂຈະລາຍການແຕ່ລະບັນຫາພ້ອມເລກແຖວ ໃນຂະນະທີ່ທ່ານພິມ:

- ບໍ່ມີຄຳສັ່ງນັ້ນ;
- ຊື່ຫຍໍ້ນັ້ນເປັນຊື່ຂອງຄຳສັ່ງເອງ (`LINE, *CIRCLE` ຈະເຊື່ອງ LINE);
- ແຖວນັ້ນບໍ່ແມ່ນຮູບແບບ `ALIAS, *COMMAND`;
- ຊື່ຫຍໍ້ດຽວກັນຢູ່ສອງແຖວ (ແຖວຫຼັງຈະຊະນະ).

ແຖວທີ່ເລີ່ມໂປຣແກຣມໃນຄອມພິວເຕີຂອງທ່ານ, ເຊັ່ນ `NOTEPAD, START, 1, *File to edit: ,`, ຈະຖືກຂ້າມພ້ອມໝາຍເຫດ: ແອັບໃນບຣາວເຊີບໍ່ສາມາດເລີ່ມໂປຣແກຣມໄດ້.

## ນຳເຂົ້າຊື່ຫຍໍ້ຈາກໂປຣແກຣມອື່ນ

1. ໃນຕົວແກ້ໄຂຊື່ຫຍໍ້, ຄລິກ {{ui:ນຳເຂົ້າ .pgp…}} ແລ້ວເລືອກໄຟລ໌. ທ່ານຍັງສາມາດລາກໄຟລ໌ `.pgp` ມາວາງໃສ່ແບບແຕ້ມໄດ້.
2. ກວດສອບບັນຫາທີ່ລາຍການໄວ້ (ຄຳສັ່ງທີ່ CadCraft ບໍ່ມີຈະຖືກປະຕິເສດ, ສ່ວນທີ່ເຫຼືອຈະໃຊ້ໄດ້).
3. ຄລິກ {{ui:ບັນທຶກ}}.

{{ui:ສົ່ງອອກ .pgp}} ຈະບັນທຶກຊື່ຫຍໍ້ຂອງ CadCraft ແລະ ຂອງທ່ານເປັນໄຟລ໌ດຽວໃນຮູບແບບດຽວກັນ.

## ໂຫຼດໄຟລ໌ຄືນ

ພິມ {{cmd:REINIT}} ແລ້ວກົດ {{key:Enter}} ເພື່ອໃຊ້ໄຟລ໌ຊື່ຫຍໍ້ຂອງທ່ານອີກຄັ້ງ. ໄຟລ໌ນີ້ຖືກເກັບໄວ້ໃນບຣາວເຊີນີ້; ແອັບເດັສທັອບຈະເກັບໄວ້ໃນໂຟນເດີຂອງມັນເອງ, ແລະ ບໍລິການຄລາວດ໌ຈະ sync ໃຫ້.

## ຕົວອັກສອນສຳລັບຕົວເລືອກຂອງຄຳສັ່ງ

ຊື່ຫຍໍ້ໃຊ້ເພື່ອເອີ້ນຄຳສັ່ງ. ເພື່ອປ່ຽນຕົວອັກສອນທີ່ໃຊ້ຕອບຕົວເລືອກຂອງຄຳສັ່ງ (`P` ສຳລັບ Polar ໃນ {{cmd:ARRAY}}), ເບິ່ງ [ຕັ້ງຕົວອັກສອນຂອງຕົນເອງໃຫ້ຕົວເລືອກຄຳສັ່ງ](topic:option-letters).

## ປຸ່ມລັດແປ້ນພິມສຳລັບຄຳສັ່ງໃດກໍໄດ້

ຊື່ຫຍໍ້ຖືກພິມ; ທາງລັດແມ່ນປຸ່ມ. ເພື່ອໃຫ້ຄຳສັ່ງມີປຸ່ມຂອງທ່ານເອງ:

1. ຄລິກ {{ui:ມຸມມອງ}} › {{ui:ເພີ່ມເຕີມ}} › {{ui:ປຸ່ມລັດແປ້ນພິມ…}}, ຫຼື ພິມ `KEYS` ແລ້ວກົດ {{key:Enter}}.
2. ຄລິກຊ່ອງ {{ui:ປຸ່ມ}} ແລ້ວກົດປຸ່ມ, ຕົວຢ່າງ {{key:Alt+Shift+C}}.
3. ໃນ {{ui:ຮຽກໃຊ້}}, ຂຽນຄຳສັ່ງ ແລະ ຖ້າຕ້ອງການ ສິ່ງທີ່ຈະພິມຕໍ່ຫຼັງຄຳສັ່ງ: `CIRCLE`, ຫຼື `ZOOM E`.
4. ຄລິກ {{ui:ເພີ່ມ}}.

ປຸ່ມຕ້ອງມີ {{key:Mod}} ຫຼື {{key:Alt}} ຄູ່ກັບຕົວອັກສອນ ຫຼື ຕົວເລກ, ຫຼື ປຸ່ມຟັງຊັນທີ່ວ່າງ ({{key:F2}}, {{key:F4}}, {{key:F5}}, {{key:F6}}, {{key:F9}}). ປຸ່ມທີ່ CadCraft, ແອັບ ຫຼື ບຣາວເຊີໃຊ້ຢູ່ແລ້ວ, ແລະ ປຸ່ມທີ່ປຸ່ມ My tools ໃຊ້ (ເບິ່ງ [ປຸ່ມຂອງທ່ານເອງ](topic:my-tools)), ຖືກປະຕິເສດ ແລະ ກ່ອງຈະບອກເຫດຜົນ. ທາງລັດຖືກເກັບໄວ້ໃນບຣາວເຊີນີ້ (ຫຼື ແອັບເດັສທັອບ); {{ui:ເອົາອອກ}} ຈະລຶບອັນໜຶ່ງອອກ.
