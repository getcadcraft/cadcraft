## ສິ່ງທີ່ທ່ານຈະໄດ້ຮຽນ

ວິທີເພີ່ມຊື່ສັ້ນຂອງທ່ານເອງສຳລັບຄຳສັ່ງ, ຕົວຢ່າງ `LL` ສຳລັບ {{cmd:LINE}}, ທັງໝົດໃນໄຟລ໌ຂໍ້ຄວາມດຽວ.

## ເພີ່ມນາມແຝງ

1. ເປີດ {{ui:View}} › {{ui:More}} › {{ui:Edit aliases…}}, ຫຼື ພິມ {{cmd:ALIASEDIT}} ແລ້ວກົດ {{key:Enter}}.
2. ເພີ່ມແຖວໜຶ່ງທີ່ມີນາມແຝງ, ເຄື່ອງໝາຍຈຸດຄອມມາ ແລະ ຄຳສັ່ງຫຼັງເຄື່ອງໝາຍດາວ:

```
LL,     *LINE
```

3. ຄລິກ {{ui:Save}}. ແຖວຄຳສັ່ງຈະບອກວ່ານາມແຝງຂອງທ່ານຖືກໃຊ້ຈັກອັນ.
4. ພິມ `LL` ແລ້ວກົດ {{key:Enter}}: LINE ຈະເລີ່ມ.

ນາມແຝງຂອງທ່ານຢູ່ເໜືອນາມແຝງຂອງ CadCraft ເອງ. ແຖວຂອງທ່ານຊະນະນາມແຝງໃນຕົວທີ່ມີຊື່ດຽວກັນ; ລຶບແຖວຂອງທ່ານອອກ ແລ້ວອັນໃນຕົວຈະກັບມາ.

## ແຖວທີ່ CadCraft ປະຕິເສດ

ຕົວແກ້ໄຂຈະລາຍການແຕ່ລະບັນຫາພ້ອມເລກແຖວ ໃນຂະນະທີ່ທ່ານພິມ:

- ບໍ່ມີຄຳສັ່ງນັ້ນ;
- ນາມແຝງເປັນຊື່ຂອງຄຳສັ່ງເອງ (`LINE, *CIRCLE` ຈະເຊື່ອງ LINE);
- ແຖວບໍ່ແມ່ນ `ALIAS, *COMMAND`;
- ນາມແຝງດຽວກັນຢູ່ສອງແຖວ (ແຖວທີ່ຢູ່ຫຼັງຈະຊະນະ).

ແຖວທີ່ເລີ່ມໂປຣແກຣມໃນຄອມພິວເຕີຂອງທ່ານ, ເຊັ່ນ `NOTEPAD, START, 1, *File to edit: ,`, ຈະຖືກຂ້າມພ້ອມໝາຍເຫດ: ແອັບໃນເບຣາວເຊີບໍ່ສາມາດເລີ່ມໂປຣແກຣມໄດ້.

## ນຳນາມແຝງຈາກໂປຣແກຣມອື່ນ

1. ໃນຕົວແກ້ໄຂນາມແຝງ, ຄລິກ {{ui:Import .pgp…}} ແລ້ວເລືອກໄຟລ໌. ທ່ານຍັງສາມາດລາກໄຟລ໌ `.pgp` ມາວາງໃສ່ແບບແຕ້ມໄດ້.
2. ກວດບັນຫາທີ່ຖືກລາຍການ (ຄຳສັ່ງທີ່ CadCraft ບໍ່ມີຈະຖືກປະຕິເສດ, ອັນອື່ນໃຊ້ໄດ້).
3. ຄລິກ {{ui:Save}}.

{{ui:Export .pgp}} ບັນທຶກນາມແຝງຂອງ CadCraft ແລະ ຂອງທ່ານເປັນໄຟລ໌ດຽວໃນຮູບແບບດຽວກັນ.

## ໂຫຼດໄຟລ໌ຄືນ

ພິມ {{cmd:REINIT}} ແລ້ວກົດ {{key:Enter}} ເພື່ອນຳໃຊ້ໄຟລ໌ນາມແຝງຂອງທ່ານອີກຄັ້ງ. ມັນຖືກເກັບໄວ້ໃນເບຣາວເຊີນີ້; ແອັບເດັສທັອບຈະເກັບມັນໄວ້ໃນໂຟນເດີຂອງມັນເອງ, ແລະ ບໍລິການຄລາວດ໌ຈະ sync ມັນ.

## ທາງລັດແປ້ນພິມສຳລັບຄຳສັ່ງໃດກໍໄດ້

ນາມແຝງຖືກພິມ; ທາງລັດແມ່ນປຸ່ມ. ເພື່ອໃຫ້ຄຳສັ່ງມີປຸ່ມຂອງຕົນເອງ:

1. ຄລິກ {{ui:View}} › {{ui:More}} › {{ui:Keyboard shortcuts…}}, ຫຼື ພິມ `KEYS` ແລ້ວກົດ {{key:Enter}}.
2. ຄລິກກ່ອງ {{ui:Key}} ແລ້ວກົດປຸ່ມ, ຕົວຢ່າງ {{key:Alt+Shift+C}}.
3. ໃນ {{ui:Runs}}, ຂຽນຄຳສັ່ງ, ແລະ ຖ້າຕ້ອງການ, ສິ່ງທີ່ຈະພິມຕາມຫຼັງມັນ: `CIRCLE`, ຫຼື `ZOOM E`.
4. ຄລິກ {{ui:Add}}.

ປຸ່ມຕ້ອງມີ {{key:Mod}} ຫຼື {{key:Alt}} ກັບຕົວອັກສອນ ຫຼື ຕົວເລກ, ຫຼື ປຸ່ມຟັງຊັນທີ່ວ່າງ ({{key:F2}}, {{key:F4}}, {{key:F5}}, {{key:F6}}, {{key:F9}}). ປຸ່ມທີ່ CadCraft, ແອັບ ຫຼື ເບຣາວເຊີໃຊ້ແລ້ວ, ແລະ ປຸ່ມທີ່ປຸ່ມ My tools ມີ (ເບິ່ງ [ປຸ່ມຂອງທ່ານເອງ](topic:my-tools)), ຈະຖືກປະຕິເສດ, ແລະ ກ່ອງຈະບອກເຫດຜົນ. ທາງລັດຖືກເກັບໄວ້ໃນເບຣາວເຊີນີ້ (ຫຼື ແອັບເດັສທັອບ); {{ui:Remove}} ເອົາອອກ.
