## ອັນໃດແນບໄດ້ທີ່ນີ້

ແນບເຫຼົ່ານີ້ດ້ວຍ {{cmd:POINTCLOUDATTACH}}, {{ui:Open}} ຫຼື ໂດຍວາງໃສ່ໜ້າ (ເບິ່ງຫົວຂໍ້ກ່ຽວກັບການຕາມຮອຍເສັ້ນຕາມສະພາບຈິງເທິງ point cloud):

| ຮູບແບບ | ນາມສະກຸນ | ສິ່ງທີ່ຖືກອ່ານ |
|---|---|---|
| LAS, LAZ | `.las`, `.laz` | LAS 1.0–1.4: ຈຸດ, ສີ, intensity, ປະເພດ LiDAR, ລະບົບພິກັດ ແລະ ໜ່ວຍຂອງມັນ. LAZ ເຖິງ 1 GB. |
| E57 | `.e57` | ທຸກການສະແກນໃນໄຟລ໌, ແຕ່ລະອັນຖືກວາງດ້ວຍ pose ຂອງມັນ; ສີ, ຫຼື intensity ເມື່ອໄຟລ໌ບໍ່ມີສີ; ແມັດ. ຮູບພາບໃນໄຟລ໌ຖືກຕັດອອກ (ມີການແຈ້ງ). ຕອນນີ້ເຖິງ 6 ລ້ານຈຸດ ແລະ 512 MB: ໃຫ້ສົ່ງອອກການສະແກນທີ່ໃຫຍ່ກວ່ານັ້ນເປັນ LAS ຫຼື LAZ. |
| PLY | `.ply` | ຂໍ້ຄວາມ ແລະ binary (ທັງສອງ byte order): x y z ຂອງ vertex, ສີ ແລະ intensity. Face ຖືກຕັດອອກ (ມີການແຈ້ງ). |
| PCD | `.pcd` | ຂໍ້ຄວາມ ແລະ binary: x y z, ສີແບບ packed ຫຼື ແຍກ, intensity. ໄຟລ໌ PCD ທີ່ຖືກບີບອັດຍັງບໍ່ຖືກອ່ານ: ໃຫ້ບັນທຶກເປັນ binary ຫຼື ຂໍ້ຄວາມ. |
| PTX | `.ptx` | ໜຶ່ງ ຫຼື ຫຼາຍການສະແກນ, ແຕ່ລະອັນຖືກວາງດ້ວຍ transform ຂອງມັນເອງ; ຈຸດທີ່ເຄື່ອງສະແກນບໍ່ໄດ້ວັດຈະຖືກຕັດອອກ. ແມັດ. |
| PTS, XYZ | `.pts`, `.xyz` | ຂໍ້ຄວາມ: x y z, ພ້ອມ intensity ແລະ ສີເມື່ອມີຖັນເຫຼົ່ານັ້ນ. |

## ໄຟລ໌ທີ່ມີແຕ່ຊອບແວຂອງເຄື່ອງສະແກນອ່ານໄດ້

ໄຟລ໌ສະແກນບາງອັນເປັນຮູບແບບຂອງຜູ້ຜະລິດເຄື່ອງສະແກນເອງ, ບໍ່ມີລາຍລະອຽດທີ່ເຜີຍແຜ່ ແລະ ບໍ່ມີ reader ແບບເປີດ. CadCraft ອ່ານພວກມັນບໍ່ໄດ້: ເມື່ອແນບໜຶ່ງ ມັນຈະບອກວ່າມັນແມ່ນຫຍັງ ແລະ ຕ້ອງເຮັດຫຍັງໃນເສັ້ນຄຳສັ່ງ. ໃຫ້ສົ່ງອອກການສະແກນຈາກຊອບແວຂອງຜູ້ຜະລິດເປັນ E57 ຫຼື LAS (ຫຼື PTX, PTS), ແລ້ວແນບໄຟລ໌ທີ່ສົ່ງອອກນັ້ນ.

| ໄຟລ໌ | ນາມສະກຸນ | ສົ່ງອອກຈາກ |
|---|---|---|
| ReCap project | `.rcp` | ReCap: ເປີດໂປຣເຈັກ ແລ້ວສົ່ງອອກມັນ. ໂປຣເຈັກພຽງແຕ່ຊີ້ໄປທີ່ການສະແກນຂອງມັນ, ສະນັ້ນການຄັດລອກ `.rcp` ດ້ວຍຕົວມັນເອງບໍ່ໃຫ້ຈຸດໃດເລີຍ. |
| ReCap scan | `.rcs` | ReCap: ເປີດໂປຣເຈັກທີ່ການສະແກນນັ້ນຢູ່ ແລ້ວສົ່ງອອກມັນ. |
| FARO scan | `.fls` | FARO SCENE. |
| Leica scan | `.lgs` | Leica Cyclone REGISTER 360. |
| Trimble scan | `.tzf` | Trimble RealWorks ຫຼື Trimble Business Center. |
| Z+F scan | `.zfs` | Z+F LaserControl. |

:::tip
ເມື່ອການສົ່ງອອກຖາມຮູບແບບ, LAS ຫຼື LAZ ເກັບທຸກຢ່າງທີ່ CadCraft ໃຊ້ (ສີ, intensity, ປະເພດ, ລະບົບພິກັດ ແລະ ໜ່ວຍຂອງມັນ) ໃນໄຟລ໌ທີ່ນ້ອຍທີ່ສຸດ.
:::

## ເປັນຫຍັງໄຟລ໌ເຫຼົ່ານີ້ຈຶ່ງບໍ່ຖືກອ່ານ

ຮູບແບບເຫຼົ່ານັ້ນບໍ່ໄດ້ເຜີຍແຜ່, ແລະ ວິທີດຽວທີ່ຈະອ່ານພວກມັນແມ່ນໂດຍ library ຊອບແວຂອງຜູ້ຜະລິດແຕ່ລະຄົນ, ພາຍໃຕ້ເງື່ອນໄຂຂອງມັນເອງ. CadCraft ອ່ານພຽງຮູບແບບທີ່ມັນອ່ານໄດ້ດ້ວຍໂຄດຂອງມັນເອງຢູ່ໃນຄອມພິວເຕີຂອງທ່ານ, ດັ່ງນັ້ນການສະແກນບໍ່ຕ້ອງຖືກສົ່ງໄປບ່ອນໃດເພື່ອແນບ.
