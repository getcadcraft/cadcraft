ພິມ {{cmd:DIAGRAM}} (`TEXTDIAGRAM`, `T2D`). ກ່ອງໜຶ່ງຈະເປີດ: ວາງຂໍ້ຄວາມ, ເລືອກ {{ui:ແຕ້ມ}}, ຄລິກມຸມເບື້ອງເທິງຊ້າຍຂອງໄດອະແກຣມ ແລ້ວລະບຸຄວາມສູງຂໍ້ຄວາມ. CadCraft ອ່ານຂໍ້ຄວາມ, ຈັດວາງບລັອກເປັນຊັ້ນໆ ພ້ອມຕົວເຊື່ອມມຸມສາກ, ແລ້ວແຕ້ມພວກມັນໄວ້ໃນເລເຢີຊື່ `Diagram`. ວັດຖຸໃໝ່ຈະຖືກເລືອກ ເພື່ອໃຫ້ທ່ານຍ້າຍມັນໄດ້ທັນທີ. ມັນເປັນວັດຖຸທຳມະດາ: ປ່ຽນຂໍ້ຄວາມຂອງບລັອກດ້ວຍ {{cmd:TEXTEDIT}}, ດຶງຕົວເຊື່ອມດ້ວຍຈຸດຈັບ, ລຶບບລັອກ, ຫຼື ເພີ່ມເສັ້ນຂອງທ່ານເອງ. {{cmd:UNDO}} ໜຶ່ງຄັ້ງຈະເອົາໄດອະແກຣມທັງໝົດອອກ.

ຖ້າພິມໃນແຖວຄຳສັ່ງໂດຍບໍ່ໃຊ້ກ່ອງ, ຂໍ້ຄວາມສາມາດເປັນແຖວດຽວ ໂດຍໃຊ້ `;` ຄັ່ນລະຫວ່າງຄຳສັ່ງ: `flowchart LR; A[Pump] --> B[Tank]`.

## ສິ່ງທີ່ມັນອ່ານ

| ຂໍ້ຄວາມ | ສິ່ງທີ່ຖືກອ່ານ |
|---|---|
| **Mermaid** `flowchart` ຫຼື `graph` ດ້ວຍ `TD`, `TB`, `BT`, `LR` ຫຼື `RL` | `A`, `A[text]`, `A(text)`, `A([text])`, `A{text}` (ການຕັດສິນໃຈ ແຕ້ມເປັນຮູບເພັດ), ຂໍ້ຄວາມໃນເຄື່ອງໝາຍ, `-->`, `---`, `-.->`, `==>`, `--x`, `<-->`, ປ້າຍຊື່ເປັນ `-->|text|` ຫຼື `-- text -->`, ລຳດັບຕໍ່ກັນ `A --> B --> C`, ກຸ່ມ `A & B --> C`, `<br/>` ສຳລັບຂຶ້ນແຖວໃໝ່, ໝາຍເຫດ `%%` |
| **PlantUML** ລະຫວ່າງ `@startuml` ແລະ `@enduml` (ຄອມໂພເນນ ແລະ ການນຳໃຊ້) | `[Component]`, `component`, `node`, `database`, `cloud`, `actor`, `rectangle` ແລະອື່ນໆ ທີ່ມີຊື່ `as`, `A --> B : label`, `->`, `..>`, `--`, `left to right direction` |
| **D2** | `a -> b: label`, `a <- b`, `a <-> b`, `a -- b`, ລຳດັບຕໍ່ກັນ, `a: Label`, `direction: right`, ຊື່ໃນເຄື່ອງໝາຍຄຳ, ໝາຍເຫດ `#` |
| **ລາຍການຈາກ-ໄປ** (ຕາຕະລາງທີ່ວາງເປັນຂໍ້ຄວາມ ຫຼື CSV) | ຄໍລຳ `from`, `to` ແລະ ທາງເລືອກ `label` ກັບ `type` (`dashed` ແຕ້ມຕົວເຊື່ອມເສັ້ນປະ), ຈັດລຽງໃດກໍໄດ້, ຄັ່ນດ້ວຍຈຸລະພາກ, ຈຸດຈຸລະພາກ ຫຼື ແທັບ; ຖ້າບໍ່ມີແຖວຫົວ ສາມຄໍລຳທຳອິດແມ່ນ from, to, label |

| **draw.io XML** (ຂໍ້ຄວາມຂອງໄຟລ໌ `.drawio`, `<mxfile>` ຫຼື `<mxGraphModel>`) | ກ່ອງ, ກ່ອງມົນ, ຮູບວົງຮີ, ຮູບເພັດການຕັດສິນໃຈ ແລະ ຂໍ້ຄວາມທຳມະດາ; ກ່ອງຄອນເທນເນີ ແລະ ກ່ອງເລນ (ແຕ້ມເສັ້ນປະພ້ອມຫົວຂໍ້); ຕົວເຊື່ອມພ້ອມຈຸດຜ່ານ, ປາຍລູກສອນ (`endArrow`, `startArrow`) ແລະ `dashed=1`; ປ້າຍ HTML ກາຍເປັນຂໍ້ຄວາມທຳມະດາ, `<UserObject label>` ແລະ `<object label>` ໃຊ້ໄດ້ |

ສິ່ງອື່ນໃນແຕ່ລະແຖວ (ສະໄຕລ໌, ໝາຍເຫດ, ກອບວົງຮອບ) ຈະຖືກຂ້າມ ແລະ ແຖວຄຳສັ່ງຈະບອກວ່າຂ້າມໄປຈັກແຖວ. ໄດອະແກຣມໜຶ່ງມີໄດ້ສູງສຸດ 400 ບລັອກ ແລະ 1200 ຕົວເຊື່ອມ.

## ໄຟລ໌ draw.io XML ຮັກສາຕຳແໜ່ງຂອງມັນ

ພາສາອື່ນບອກພຽງວ່າອັນໃດເຊື່ອມກັບອັນໃດ, ດັ່ງນັ້ນ CadCraft ຈຶ່ງຈັດວາງໃຫ້. Draw.io XML ບອກຕຳແໜ່ງຂອງທຸກຢ່າງຢູ່ແລ້ວ, ດັ່ງນັ້ນ CadCraft ຈຶ່ງຮັກສາມັນໄວ້: ແຕ່ລະບລັອກຢູ່ບ່ອນທີ່ໄຟລ໌ກຳນົດ, ປັບຂະໜາດໃຫ້ຟອນ 12 ພິກເຊວກາຍເປັນຄວາມສູງຂໍ້ຄວາມທີ່ທ່ານລະບຸ (ກ່ອງ 120 × 60 ພິກເຊວ ແມ່ນ 60 × 30 ໜ່ວຍແບບແຕ້ມທີ່ຄວາມສູງ 6), ແລະ ມຸມເບື້ອງເທິງຊ້າຍຂອງໄດອະແກຣມຈະຢູ່ທີ່ມຸມທີ່ທ່ານຄລິກ. ຕົວເຊື່ອມແລ່ນຈາກຂອບຂອງບລັອກໜຶ່ງໄປຫາຂອບຂອງບລັອກຕໍ່ໄປ ຜ່ານຈຸດຜ່ານຂອງມັນ; ຕົວເຊື່ອມທີ່ມີ `orthogonalEdgeStyle` ແລະ ບໍ່ມີຈຸດຜ່ານຈະໄດ້ການຫັກມຸມສາກໜຶ່ງຄັ້ງ.

ການບັນທຶກເລີ່ມຕົ້ນຂອງ Draw.io ຖືກບີບອັດ. ກ່ອງ ແລະ ແຖວຄຳສັ່ງຈະເປີດມັນໃຫ້ທ່ານ; ເຄື່ອງມືຜູ້ຊ່ວຍໃນໜ້າຕ່າງທີ່ບໍ່ມີສາຍການບີບອັດຈະບອກແບບນັ້ນ, ແລະ `File › Export as › XML` ໂດຍເອົາເຄື່ອງໝາຍ *Compressed* ອອກຈະໄດ້ XML ທຳມະດາ. ຮູບພາບ, ຕົວເຊື່ອມທີ່ປາຍໜຶ່ງຫຼຸດ ແລະ ໜ້າທີສອງຈະຖືກຂ້າມ ແລະ ນັບໄວ້.

## ການຂຽນດ້ວຍໂມເດວໃນຄອມພິວເຕີຂອງທ່ານ

ໂມເດວໃນເຄື່ອງ (Ollama, LM Studio, llama.cpp, Jan) ສາມາດຂຽນ XML ຫຼື ຂໍ້ຄວາມ Mermaid ຈາກເນື້ອຫາຂອງໄຟລ໌ PDF ຫຼື SVG ໄດ້, ແລະ ຜົນລັບຈະເຂົ້າມາຜ່ານກ່ອງດຽວກັນ, ຫຼື ເຂົ້າໄປໃນແບບແຕ້ມໂດຍກົງເມື່ອໂມເດວເຊື່ອມເປັນຜູ້ຊ່ວຍ: `diagram_from_text` ຮັບ `format` ເປັນ `drawio`. ໂມເດວຂະໜາດນ້ອຍຜິດພາດໃນ XML ຫຼາຍກວ່າໃນ Mermaid ຫຼື ລາຍການຈາກ-ໄປ, ດັ່ງນັ້ນການລອງຄັ້ງທຳອິດດ້ວຍ Mermaid ຈະປະຢັດກວ່າ; ສິ່ງທີ່ຕົວອ່ານໃຊ້ບໍ່ໄດ້ຈະຖືກຂ້າມ ແລະ ນັບໄວ້, ບໍ່ໄດ້ຖືກຄາດເດົາ. ເບິ່ງ ການເຊື່ອມ AI ຂອງທ່ານ ສຳລັບສູດຂອງໂມເດວ.

## ການຈັດວາງ

ບລັອກຖືກຈັດເປັນຊັ້ນຕາມຕົວເຊື່ອມ (ຕົວເຊື່ອມທີ່ວົນກັບຈະແຕ້ມຂຶ້ນໄປດ້ານເທິງ), ຈັດລຳດັບເພື່ອຫຼຸດການຕັດກັນ, ດ້ວຍຕົວເຊື່ອມມຸມສາກທີ່ອອກຈາກດ້ານລຸ່ມຂອງບລັອກ ແລະ ເຂົ້າດ້ານເທິງຂອງບລັອກຖັດໄປ; `LR` ແລະ `RL` ປ່ຽນຊັ້ນເປັນຖັນ. ຄວາມສູງຂໍ້ຄວາມທີ່ທ່ານລະບຸຈະກຳນົດຂະໜາດຂອງທຸກຢ່າງ.

## ກຣາຟຍ່ອຍ ແລະ ໄດອະແກຣມລຳດັບ

- `subgraph name [Title]` ຂອງ Mermaid … `end` ແຕ້ມກ່ອງເສັ້ນປະພ້ອມຫົວຂໍ້ອ້ອມບລັອກຂອງມັນ; ກຣາຟຍ່ອຍສາມາດຊ້ອນກັນໄດ້. ການຈັດວາງບໍ່ໄດ້ກັນບລັອກອື່ນອອກຈາກກ່ອງ, ດັ່ງນັ້ນໃຫ້ຍ້າຍບລັອກທີ່ຫຼຸດອອກມາດ້ວຍຈຸດຈັບຂອງມັນ.
- `sequenceDiagram` ຂອງ Mermaid, ຫຼື ຂໍ້ຄວາມ PlantUML ທີ່ມີແຖວ `participant` ແລະ ຂໍ້ຄວາມ `->`, ຖືກແຕ້ມເປັນບລັອກຕາມດ້ານເທິງ, ມີເສັ້ນຊີວິດເສັ້ນປະໃຕ້ແຕ່ລະອັນ ແລະ ໜຶ່ງແຖວຕໍ່ຂໍ້ຄວາມໜຶ່ງ. `-->` ແລະ `-->>` ເປັນເສັ້ນປະ, `->>` ແລະ `-)` ມີຫົວລູກສອນ, `autonumber` ໃສ່ເລກໃຫ້ຂໍ້ຄວາມ, ຂໍ້ຄວາມຫາຕົວເອງຈະວົນ. ໝາຍເຫດ ແລະ ກອບ `loop` / `alt` ຈະຖືກຂ້າມ.

## ສັນຍາລັກສຳລັບໄດອະແກຣມເສັ້ນດຽວ ແລະ ການວາງທໍ່

ບລັອກສາມາດເປັນສັນຍາລັກທີ່ແຕ້ມໄວ້, ມີຊື່ຢູ່ລຸ່ມ, ແທນກ່ອງ. ລະບຸສັນຍາລັກໃນຂໍ້ຄວາມ:

| ຂໍ້ຄວາມ | ວິທີ |
|---|---|
| Mermaid | `P1[Feed pump]:::pump-cf` ຫຼື ແຖວ `class P1 pump-cf` |
| D2 | `P1.shape: pump-cf` ຫຼື `P1: Feed pump { shape: pump-cf }` |
