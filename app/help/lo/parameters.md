## ຕາຕະລາງດຽວສຳລັບທຸກຂະໜາດ

ແຜງ {{ui:Parameters}} (ປຸ່ມ {{ui:Parameters}} ໃນກຸ່ມ {{ui:Parametric}}, ຫຼື ພິມ {{cmd:PARAMETERS}}) ລາຍຊື່ທຸກຂໍ້ຈຳກັດຂະໜາດ (`d1`, `rad1`, `dia1`, `ang1`, ຫຼື ຊື່ທີ່ທ່ານຕັ້ງ) ແລະ ພາລາມິເຕີຂອງທ່ານເອງຮ່ວມກັນ. ຊື່ໃດກໍໄດ້ສາມາດໃຊ້ໃນນິພະຈົນໃດກໍໄດ້.

ແຕ່ລະແຖວມີ:

- **ຊື່**: ພິມຊື່ໃໝ່ເພື່ອປ່ຽນຊື່; ທຸກນິພະຈົນທີ່ໃຊ້ມັນຈະຕາມ.
- **Expression**: ຕົວເລກ (`40`) ຫຼື ນິພະຈົນ (`width / 2 + gap`). ພິມໃນມັນ ແລ້ວກົດ {{key:Enter}}: ແບບແຕ້ມຈະຕາມ.
- **Value**: ສິ່ງທີ່ມັນຄິດໄລ່ອອກມາ. ໃນແຖວທີ່ນິພະຈົນຄວບຄຸມ, ທ່ານສາມາດພິມຕົວເລກໃສ່ບ່ອນນີ້ໄດ້ເຊັ່ນກັນ: CadCraft ຈະຄິດໄລ່ພາລາມິເຕີທີ່ຢູ່ເບື້ອງຫຼັງ. ດ້ວຍ `d1 = width / 2`, ການພິມ `30` ໃນ value ຂອງ d1 ຈະຕັ້ງ `width` ເປັນ 60.

ເມື່ອພາລາມິເຕີສອງຕົວຄວບຄຸມຄ່າ (`width / 2 + gap`), ກ່ອງຈະຖາມວ່າຈະປ່ຽນອັນໃດ. ທຸກການປ່ຽນແປງແມ່ນໜຶ່ງຂັ້ນຕອນການຍ້ອນກັບ ({{key:Mod+Z}}).

## ເພີ່ມຂອງທ່ານເອງ

1. ເປີດແຜງ {{ui:Parameters}}.
2. ພິມຊື່ (`gap`) ແລະ ຄ່າ (`10`), ແລ້ວເລືອກ {{ui:Add}}.
3. ໃຊ້ມັນ: ໃນ expression ຂອງ d1, ພິມ `width / 2 + gap` ແລ້ວກົດ {{key:Enter}}.

ຊື່ເລີ່ມດ້ວຍຕົວອັກສອນ ຫຼື `_` ແລະ ມີຕົວອັກສອນ, ຕົວເລກ ແລະ `_`. ຊື່ຟັງຊັນ, `pi` ແລະ ຊື່ໜ່ວຍບໍ່ສາມາດເປັນຊື່ໄດ້.

## ນິພະຈົນ

| ຂຽນ | ໝາຍເຖິງ |
|---|---|
| `+ - * / ^ %` | ບວກ, ລົບ, ຄູນ, ຫານ, ຍົກກຳລັງ, ເສດ (ສ່ວນທີ່ເຫຼືອ) |
| `( )` | ການຈັດກຸ່ມ |
| `sin cos tan asin acos atan atan2` | ຕີໂກນໂມຕຣີ ເປັນອົງສາ |
| `sqrt pow exp ln log abs sign` | ຮາກ, ກຳລັງ, ລອກາຣິດ |
| `ceil floor int round min max` | ການປັດເລກ ແລະ ຂອບເຂດ |
| `if(a > b, x, y)` | ການເລືອກ |
| `pi` | 3.14159… |

ຕົວເລກອາດມີໜ່ວຍ: `25mm`, `1in`, `2'`, `90deg`. ຄວາມຍາວທີ່ມີໜ່ວຍຈະຖືກປ່ຽນເປັນມິລລິແມັດ, ດັ່ງນັ້ນໃຫ້ໃຊ້ໜ່ວຍເທົ່ານັ້ນໃນແບບແຕ້ມທີ່ວັດເປັນມິລລິແມັດ; ໃນກໍລະນີອື່ນ ໃຫ້ພິມຕົວເລກທຳມະດາ.

## ໃນແຖວຄຳສັ່ງ

`-PARAMETERS` ເຮັດຄືກັນໂດຍບໍ່ມີແຜງ: `N` ໃໝ່, `E` ແກ້ໄຂ (ລວມທັງຂໍ້ຈຳກັດຂະໜາດ), `R` ປ່ຽນຊື່, `D` ລຶບ, `?` ລາຍຊື່.

## ສິ່ງທີ່ຖືກປະຕິເສດ

- ນິພະຈົນທີ່ໃຊ້ຕົວມັນເອງ, ໂດຍກົງ ຫຼື ຜ່ານອີກຕົວ: **"width, d1 ໃຊ້ເຊິ່ງກັນແລະກັນ."**
- ຄ່າທີ່ຂະໜາດບໍ່ສາມາດຮັບໄດ້: ຄວາມຍາວລົບ, ມຸມເກີນ 180°.
- ຄ່າທີ່ແບບແຕ້ມບໍ່ສາມາດຮັບໄດ້ດ້ວຍຂໍ້ຈຳກັດອື່ນ: ບໍ່ມີຫຍັງປ່ຽນ, ແລະ ຂໍ້ຄວາມຈະລະບຸຂໍ້ຈຳກັດທີ່ຂັດຂວາງ.
- ການລຶບພາລາມິເຕີທີ່ມີສິ່ງໃດໃຊ້ຢູ່: ແຜງຈະສະເໜີໃຫ້ຂຽນຄ່າຂອງມັນລົງໃນສິ່ງເຫຼົ່ານັ້ນກ່ອນ. ຊື່ຂອງຂໍ້ຈຳກັດຂະໜາດຈະຖືກລຶບໂດຍການລຶບຂໍ້ຈຳກັດນັ້ນ.
