ແຜງ {{ui:Laser}} ປ່ຽນ layer ຂອງແບບແຕ້ມໃຫ້ເປັນໂປຣແກຣມສຳລັບເລເຊີທີ່ໃຊ້ GRBL (ສ່ວນໃຫຍ່ຂອງຕົວຄວບຄຸມເລເຊີ diode ແລະ CO2 ສຳລັບງານອະດິເລກ ແລະ ໂຮງງານຂະໜາດນ້ອຍ). ພິມ `LASER` (ຫຼື `LASERCUT`) ແລ້ວກົດ {{key:Enter}}, ຫຼື ເລືອກ {{ui:Laser…}} ໃນເມນູ {{ui:More}} ຂອງກຸ່ມ {{ui:View}}. ໃນຮູບແບບ ribbon, ມັນຢູ່ໃນເມນູ {{ui:File}} ແລະ ຂ້າງ {{ui:Plot}}. ແຜງຈະເປີດຢູ່ເທິງແບບແຕ້ມ ແລະ ຄົງເປີດໄວ້ໃນຂະນະທີ່ທ່ານແຕ້ມ: ຕົວຢ່າງຈະຕາມທຸກການປ່ຽນແປງ.

:::warning
ທົດສອບທຸກການຕັ້ງຄ່າກັບເສດວັດສະດຸກ່ອນ, ໃສ່ແວ່ນປ້ອງກັນຕາທີ່ເໝາະກັບເລເຊີຂອງທ່ານ, ຮັກສາຝາປິດໄວ້ບ່ອນທີ່ມີ, ແລະ ຢ່າປ່ອຍເລເຊີທີ່ກຳລັງເຮັດວຽກໄວ້ຄົນດຽວ. ຕົວເລກເລີ່ມຕົ້ນຂອງ layer ເປັນຕົວຢ່າງ, ບໍ່ແມ່ນຄຳແນະນຳສຳລັບວັດສະດຸໃດໆ.
:::

## ສິ່ງທີ່ຖືກສົ່ງ

ແຜງອ່ານແບບຈຳລອງ (ບໍ່ແມ່ນແຜ່ນ), ໃນ layer ທີ່ເປີດແລະບໍ່ຖືກ freeze:

- ເສັ້ນ, ເສັ້ນໂຄ້ງ, ວົງມົນ, ໂພລີລາຍ (ສ່ວນເສັ້ນໂຄ້ງຍັງເປັນເສັ້ນໂຄ້ງ), ວົງຮີ ແລະ spline. ຮູບຊົງທີ່ສິ້ນສຸດຢູ່ບ່ອນທີ່ມັນເລີ່ມຕົ້ນ ຖືວ່າປິດ.
- ບລັອກຖືກແຍກອອກ: ວັດຖຸໃນ layer 0 ທີ່ຢູ່ໃນບລັອກຈະໄປກັບ layer ຂອງການອ້າງອີງບລັອກ.
- ແຮັດສົ່ງເສັ້ນຂອບຂອງມັນ, ດັ່ງນັ້ນໂລໂກ້ທີ່ແຮັດຢູ່ໃນ layer **Fill** ຈະຖືກເຕີມ.
- ຮູບພາບ (`IMAGEATTACH`) ຈະຖືກແກະສະຫຼັກໃສ່ layer ທີ່ຕັ້ງເປັນ **Engrave picture**, ເມື່ອມັນຢູ່ໃນແນວຕັ້ງສາກ (ບໍ່ໝຸນ ຫຼື ລາດ) ແລະ ໄຟລ໌ຂອງມັນເປີດຢູ່ໃນ CadCraft.
- ຂໍ້ຄວາມ, ຂະໜາດ, leader, ຈຸດ ແລະ ເສັ້ນກໍ່ສ້າງ ຈະບໍ່ຖືກສົ່ງ; ແຜງບອກວ່າມີຈັກອັນທີ່ຖືກຂ້າມໄປ. ເພື່ອແກະສະຫຼັກຂໍ້ຄວາມ, ໃຫ້ແຕ້ມຕົວອັກສອນເປັນຮູບຊົງ ຫຼື ແຮັດມັນ.

ຂະໜາດຖືກສົ່ງເປັນມິນລີແມັດຈາກໜ່ວຍຂອງແບບແຕ້ມ (`UNITS`): ແບບແຕ້ມເປັນນິ້ວຈະຖືກຄູນດ້ວຍ 25.4. ແບບແຕ້ມທີ່ບໍ່ໄດ້ຕັ້ງໜ່ວຍຈະຖືກສົ່ງໃນອັດຕາ 1 ໜ່ວຍຕໍ່ 1 ມິນລີແມັດ. ໃຫ້ໝາຍ {{ui:Only the selected objects}} ເພື່ອສົ່ງບາງສ່ວນຂອງແບບແຕ້ມ.

## ເລືອກສິ່ງທີ່ແຕ່ລະ layer ຈະເຮັດ

ທຸກ layer ທີ່ມີບາງຢ່າງຈະເປັນແຖວໜຶ່ງ. {{ui:Does}} ຕັ້ງມັນເປັນ **Cut**, **Score**, **Engrave lines**, **Fill shapes**, **Engrave picture** ຫຼື **Not sent**, ພ້ອມ {{ui:Power %}}, {{ui:Speed mm/min}} ແລະ ຈຳນວນ {{ui:Passes}}. ທຸກການປ່ຽນແປງເປັນຂັ້ນຕອນ undo ໜຶ່ງຂັ້ນ ແລະ ຖືກບັນທຶກໄວ້ໃນແບບແຕ້ມ: DWG (ທຸກເວີຊັນທີ່ CadCraft ບັນທຶກ) ແລະ DXF ຮັກສາການຕັ້ງຄ່າ, ດັ່ງນັ້ນແບບແຕ້ມຈະເປີດພ້ອມມັນໃນຄັ້ງຕໍ່ໄປ. ໂປຣແກຣມອື່ນຈະເປີດໄຟລ໌ຄືເກົ່າ; ພວກມັນຈະເຫັນບລັອກທີ່ບໍ່ໄດ້ໃຊ້ໜຶ່ງອັນຊື່ CADCRAFT_LASER (ການລຶບມັນອອກທີ່ນັ້ນຈະເອົາການຕັ້ງຄ່າອອກ).

- **Fill** ແກະສະຫຼັກພາຍໃນຮູບຊົງປິດດ້ວຍເສັ້ນ, ຫ່າງກັນ {{ui:Line spacing}}, ທີ່ {{ui:Angle}}, ທັງສອງທິດທາງ ຫຼື ທິດທາງດຽວ, ພ້ອມ overscan ເພື່ອໃຫ້ຫົວຢູ່ໃນຄວາມໄວເມື່ອເລເຊີເປີດ; cross-hatch ເພີ່ມການຜ່ານທີສອງທີ່ 90°. ຮູບຊົງທີ່ມີຮູຈະຢູ່ເປີດທີ່ຮູນັ້ນ.
- **Engrave picture** ປ່ຽນຮູບພາບເປັນຈຸດ (Floyd–Steinberg, Atkinson, ordered, ຫຼື ສີດຳ ແລະ ຂາວທຳມະດາທີ່ຄ່າເກນ) ຫຼື, ດ້ວຍ *Grey levels*, ເປັນກຳລັງທີ່ປ່ຽນແປງໄດ້.
- ລຳດັບ: ຮູບພາບ ແລະ ການເຕີມກ່ອນ, ແລ້ວການແກະສະຫຼັກເສັ້ນ, ແລ້ວການຂີດ, ແລ້ວການຕັດ, ເພື່ອໃຫ້ຊິ້ນສ່ວນທີ່ຖືກຕັດອອກບໍ່ຍ້າຍໃນຂະນະທີ່ຖືກແກະສະຫຼັກ. ພາຍໃນ layer ໜຶ່ງ, ເສັ້ນທາງຈະແລ່ນ **ພາຍໃນກ່ອນ** (ຮູກ່ອນແຜ່ນທີ່ມັນຢູ່ໃນ), ໄປຫາອັນທີ່ໃກ້ທີ່ສຸດຕໍ່ໄປ.

## ເບິ່ງຕົວຢ່າງ, ແລ້ວບັນທຶກ

ຕົວຢ່າງສະແດງສິ່ງທີ່ຫົວເຮັດ: ເສັ້ນທີ່ກຳລັງເຜົາໄໝ້ເປັນສີ, ການເຄື່ອນທີ່ໄວເປັນສີເທົາ, ແລະ ກ່ອງສີຂຽວອ້ອມທຸກສິ່ງທີ່ຈະເຜົາໄໝ້. ຂ້າງລຸ່ມມັນແມ່ນຂະໜາດ, ຄວາມຍາວຂອງການເຜົາໄໝ້ ແລະ ການປະເມີນເວລາ (ບໍ່ລວມຄວາມເລັ່ງ; ເຄື່ອງຈິງຈະໃຊ້ເວລາດົນກວ່າ). {{ui:Save G-code…}} ຂຽນ G-code ໂໝດເລເຊີ GRBL: `$32=1`, `M4` (ຫຼື `M3`) ພ້ອມຄ່າ S, ການເຄື່ອນທີ່ `G0` ແລະ `G1`, ແລະ `M5` ໃນຕອນທ້າຍ. X0 Y0 ແມ່ນມຸມລຸ່ມຊ້າຍຂອງວຽກ, ນອກຈາກທ່ານຈະເລືອກຈຸດກຳເນີດຂອງແບບແຕ້ມ: ຕັ້ງ work zero ຂອງເຄື່ອງທ່ານໄວ້ບ່ອນນັ້ນ.

## ສົ່ງຈາກບຣາວເຊີ

ໃນ Chrome ແລະ Edge, {{ui:Connect…}} ຈະຂໍໃຫ້ທ່ານເລືອກພອດ USB ຂອງເລເຊີ. ຈະບໍ່ມີການເຊື່ອມຕໍ່ ຫຼື ສົ່ງຫຍັງຈົນກວ່າທ່ານຈະກົດປຸ່ມ. ກົດ {{ui:Frame the job}} ກ່ອນ: ຫົວຈະວາດກ່ອງຂອງວຽກດ້ວຍເລເຊີ **ປິດ** (ຫຼື ດ້ວຍກຳລັງຕໍ່າທີ່ທ່ານຕັ້ງສຳລັບໄມ້ຊີ້) ເພື່ອໃຫ້ທ່ານເຫັນບ່ອນທີ່ມັນຈະເຜົາໄໝ້. ຫຼັງຈາກນັ້ນ {{ui:Send job}} ຈຶ່ງເປີດໃຊ້ໄດ້, ແລະ ມັນຈະປິດອີກຄັ້ງຖ້າທ່ານປ່ຽນແປງຫຍັງ. {{ui:Pause}} ຢຸດຫົວໄວ້, {{ui:Stop}} ກໍຢຸດມັນເຊັ່ນກັນ, ຣີເຊັດຕົວຄວບຄຸມ (ເລເຊີປິດ) ແລະ ສົ່ງ `M5`. ບ່ອນທີ່ບໍ່ມີ Web Serial (Firefox, Safari, ແລະ CadCraft Studio ທີ່ຍັງບໍ່ມີ Web Serial) ແຜງຈະສະເໜີໃຫ້ບັນທຶກເທົ່ານັ້ນ: ບັນທຶກ G-code ແລ້ວສົ່ງມັນດ້ວຍໂປຣແກຣມຂອງເລເຊີທ່ານເອງ.

## ຍັງບໍ່ໄດ້ສ້າງ

ຍັງບໍ່ໄດ້ສ້າງ: ຮູບແບບຂອງຕົວຄວບຄຸມອື່ນ (Ruida, ເລເຊີ Marlin, ໄຟລ໌ຂອງຜູ້ຜະລິດ), tabs ແລະ lead-ins, kerf offset, ຄັງວັດສະດຸ, ແກນ rotary ແລະ Z, ການຈັດວາງດ້ວຍກ້ອງ, ແລະ ຕົວອັກສອນເປັນເສັ້ນຂອບ.
