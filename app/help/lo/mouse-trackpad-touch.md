CadCraft ຖືກອອກແບບສຳລັບເມົ້າທີ່ມີລໍ້. ທຸກຢ່າງກໍໃຊ້ໄດ້ກັບແທຣັກແພດເຊັ່ນກັນ, ໂດຍມີນິໄສບາງຢ່າງທີ່ຕ້ອງຮຽນຮູ້. ໜ້າຈໍສຳຜັດໃຊ້ໄດ້ສຳລັບການເລືອກ, ແຕ່ມີຂໍ້ຈຳກັດ.

## ເມົ້າມີລໍ້

- **ຊູມ:** ໝຸນລໍ້. ແບບແຕ້ມຈະຊູມອ້ອມເຄີເຊີ, ດັ່ງນັ້ນໃຫ້ຊີ້ໄປທີ່ສິ່ງທີ່ທ່ານຢາກເຫັນ.
- **ເລື່ອນມຸມມອງ:** ກົດຄ້າງລໍ້ໄວ້ ແລ້ວລາກ, ຫຼື ລາກດ້ວຍປຸ່ມຂວາ.
- **ຊູມເພື່ອເຫັນທຸກຢ່າງ:** double-click ລໍ້, ຫຼື ຄລິກ {{ui:Extents}}.
- **ກັບໄປມຸມມອງກ່ອນໜ້າ:** ຄລິກ {{ui:Previous}} ໃນກຸ່ມມຸມມອງ, ຫຼື ພິມ `Z`, {{key:Enter}}, `P`, {{key:Enter}}. ການໝຸນລໍ້ຕໍ່ເນື່ອງນັບເປັນໜຶ່ງມຸມມອງ, ດັ່ງນັ້ນ {{ui:Previous}} ໜຶ່ງຄັ້ງຈະຍ້ອນກັບມັນທັງໝົດ. ບັນທຶກມຸມມອງທີ່ທ່ານຈະກັບມາຫາອີກດ້ວຍ {{cmd:NAMEDVIEW}} (`NV`).
- **Enter:** ຄລິກຂວາ.

## ແທຣັກແພດ

:::mac
- **ເລື່ອນມຸມມອງ:** ເລື່ອນສອງນິ້ວເທິງແທຣັກແພດ ໄປທິດທາງໃດກໍໄດ້: ແບບແຕ້ມຈະຕາມນິ້ວຂອງທ່ານ. ທ່ານຍັງສາມາດລາກດ້ວຍການກົດສອງນິ້ວຄ້າງໄວ້ (ການລາກປຸ່ມຂວາ).
- **ຊູມ:** ບີບດ້ວຍສອງນິ້ວ. ການຊູມຈະຕາມເຄີເຊີ.
- **ຄລິກຂວາ (Enter):** ຄລິກດ້ວຍສອງນິ້ວ. ເປີດ "Secondary click" ໃນ **System Settings**, ແລ້ວ **Trackpad**, ຖ້າມັນບໍ່ເຮັດຫຍັງ. Control-click ອາດນັບເປັນການຄລິກທຳມະດາໃນ CadCraft ແທນທີ່ຈະເປັນຄລິກຂວາ, ດັ່ງນັ້ນໃຫ້ໃຊ້ການຄລິກສອງນິ້ວ.
- **ຊູມໄປຫາພື້ນທີ່:** ຄລິກ {{ui:Window}} ໃນກຸ່ມມຸມມອງ ແລ້ວຄລິກສອງມຸມ.
:::

:::windows linux
- **ເລື່ອນມຸມມອງ:** ເລື່ອນສອງນິ້ວເທິງທັດແພດ ໄປທິດທາງໃດກໍໄດ້: ແບບແຕ້ມຈະຕາມນິ້ວຂອງທ່ານ. ທ່ານຍັງສາມາດລາກດ້ວຍປຸ່ມຂວາທີ່ກົດຄ້າງໄວ້.
- **ຊູມ:** ບີບດ້ວຍສອງນິ້ວ. ການຊູມຈະຕາມເຄີເຊີ.
- **ຄລິກຂວາ (Enter):** ຄລິກດ້ວຍສອງນິ້ວ, ຫຼື ຄລິກມຸມລຸ່ມຂວາຂອງທັດແພດ, ຂຶ້ນກັບການຕັ້ງຄ່າທັດແພດຂອງທ່ານ.
- **ຊູມໄປຫາພື້ນທີ່:** ຄລິກ {{ui:Window}} ໃນກຸ່ມມຸມມອງ ແລ້ວຄລິກສອງມຸມ.
:::

ການກົດ {{key:Space}} ແລ້ວລາກ **ບໍ່** ເລື່ອນມຸມມອງໃນ CadCraft: {{key:Space}} ແມ່ນ Enter.

ລໍ້ເມົ້າຍັງຊູມ, ເທື່ອລະຂັ້ນ. ແທຣັກແພດທີ່ສົ່ງການເລື່ອນເປັນຂັ້ນເຕັມ ເໝືອນລໍ້, ຈະຊູມດ້ວຍການເລື່ອນສອງນິ້ວແທນທີ່ຈະເລື່ອນມຸມມອງ: ຊູມອອກ, ຊີ້ໄປທີ່ພື້ນທີ່ທີ່ທ່ານຕ້ອງການ ແລ້ວຊູມກັບເຂົ້າ. ແຖບ 3D ຍັງຮັກສາການເຄື່ອນໄຫວແທຣັກແພດຂອງມັນເອງ (ເບິ່ງ [ເບິ່ງແບບໃນ 3D](topic:3d-solids#look-around)).

## ໜ້າຈໍສຳຜັດ ແລະ ແທັບເລັດ

CadCraft ອ່ານນິ້ວເປັນການຄລິກເມົ້າ:

- ການແຕະເລືອກຈຸດ ຫຼື ວັດຖຸ, ຫຼື ເລືອກ.
- ການລາກນິ້ວໃນພື້ນທີ່ຫວ່າງຈະແຕ້ມເຊືອກບ່ວງ (ເລື່ອນໄປທາງຂວາກ່ອນ ເປັນກອບ, ເລື່ອນໄປທາງຊ້າຍກ່ອນ ເປັນກອບຂ້າມ; ເບິ່ງ [ການເລືອກດ້ວຍເຊືອກບ່ວງ](topic:lasso-selection)).
- ໃນ {{cmd:TRIM}} ແລະ {{cmd:EXTEND}}, ການລາກນິ້ວຜ່ານຊິ້ນສ່ວນຈະຕັດ ຫຼື ຂະຫຍາຍພວກມັນທັງໝົດ.
- ການລາກຈຸດຈັບຂອງວັດຖຸທີ່ເລືອກຈະຍ້າຍຈຸດຈັບ (ຈຸດຈັບ ແລະ ກ່ອງເລືອກຈະໃຫຍ່ຂຶ້ນສຳລັບນິ້ວ).
- **ບີບ** ດ້ວຍສອງນິ້ວເພື່ອຊູມຮອບຈຸດລະຫວ່າງພວກມັນ; ເລື່ອນສອງນິ້ວພ້ອມກັນເພື່ອ **ເລື່ອນມຸມມອງ**. ນິ້ວທີສອງຈະຍົກເລີກສິ່ງທີ່ນິ້ວທຳອິດເລີ່ມ, ດັ່ງນັ້ນການບີບຈະບໍ່ທິ້ງຮອຍໄວ້.
- **ກົດຄ້າງ** (ນິ່ງປະມານເຄິ່ງວິນາທີ) ແມ່ນຄລິກຂວາ: {{key:Enter}}. ມັນຈົບຄຳສັ່ງ, ສຳເລັດການເລືອກ, ຫຼື ເຮັດຊ້ຳຄຳສັ່ງສຸດທ້າຍ.

ລຸ່ມແຖວຄຳສັ່ງຈະມີ **ແຖວປຸ່ມ** ປາກົດຂຶ້ນ: {{ui:Esc}}, ຍ້ອນກັບ, ເຮັດຊ້ຳ, ຕົວອັກສອນທີ່ແປ້ນພິມແທັບເລັດຊ່ອນໄວ້ (`@` `,` `<` `'` `"` `-`), {{ui:Snap}}, {{ui:Ortho}}, ປຸ່ມແປ້ນພິມ, ແລະ ປຸ່ມ {{ui:Enter}} ໃຫຍ່. ແຕະປຸ່ມແປ້ນພິມ (ຫຼື ແຖວຄຳສັ່ງ) ເພື່ອພິມຄຳສັ່ງ ຫຼື ຕົວເລກ.

ບໍ່ມີການວາງເມົ້າ (hover), ດັ່ງນັ້ນເຄື່ອງໝາຍຈັບຈະສະແດງສະເພາະບ່ອນທີ່ນິ້ວຂອງທ່ານຢູ່.

:::touch
ທ່ານກຳລັງໃຊ້ໜ້າຈໍສຳຜັດ. ສຳລັບການເບິ່ງຢ່າງວ່ອງໄວ ໃຊ້ໄດ້, ແຕ່ສຳລັບງານທີ່ຫຼາຍກວ່ານັ້ນ ແປ້ນພິມທີ່ຕໍ່ຢູ່ ແລະ ເມົ້າ ຫຼື ແທຣັກແພດ ເຮັດໃຫ້ CadCraft ໃຊ້ງ່າຍຂຶ້ນຫຼາຍ.
:::

## ບຣາວເຊີ

CadCraft ເຮັດວຽກຄືກັນໃນ Chrome, Edge, Firefox ແລະ Safari, ໃນ Mac, Windows ແລະ Linux. ຄວາມແຕກຕ່າງມີໜ້ອຍ:

| ຫົວຂໍ້ | ສິ່ງທີ່ຄວນຮູ້ |
|---|---|
| ການເປີດ DWG | ແບບແຕ້ມຂະໜາດໃຫຍ່ໃຊ້ເວລາອ່ານສອງສາມວິນາທີໃນທຸກບຣາວເຊີ; ແຖວສະຖານະຈະສະແດງ "ກຳລັງອ່ານ …" ໃນຂະນະນັ້ນ |
| ການດາວໂຫຼດ | ແຕ່ລະບຣາວເຊີຕັດສິນໃຈວ່າການດາວໂຫຼດຈະໄປໄວ້ໃສ ແລະ ຈະຖາມກ່ອນຫຼືບໍ່; ເບິ່ງ [ບຣາວເຊີ ແລະ ຄອມພິວເຕີ](common:browsers) |
| ເປີດເພື່ອພິມ | ເປີດ PDF ໃນແຖບໃໝ່. ຖ້າບຣາວເຊີບລັອກປ໊ອບອັບ, CadCraft ຈະດາວໂຫຼດ PDF ແທນ |
| F7 | Firefox ອາດສະເໜີການທ່ອງເວັບດ້ວຍເຄີເຊີ; ເລືອກ ບໍ່ |
| ອອກໂດຍມີການປ່ຽນແປງທີ່ຍັງບໍ່ໄດ້ບັນທຶກ | ທຸກບຣາວເຊີຈະສະແດງຄຳຖາມ "Leave site?" ຂອງຕົນເອງ, ເຊິ່ງ CadCraft ບໍ່ສາມາດປ່ຽນໄດ້ |

:::safari
ໃນ Safari, PDF ທີ່ເປີດດ້ວຍ {{ui:Open to print}} ອາດສະແດງໃນແຖບໂດຍບໍ່ພິມ: ໃຊ້ **File**, ແລ້ວ **Print**.
:::

:::firefox
Firefox ອາດຖາມວ່າຈະເຮັດຫຍັງກັບແຕ່ລະການດາວໂຫຼດ. ເລືອກບັນທຶກໄຟລ໌, ຫຼື ປ່ຽນຄັ້ງດຽວໃນການຕັ້ງຄ່າຂອງ Firefox ພາຍໃຕ້ Downloads.
:::
