## Ֆայլերի բացում

| «Այս գծագիրը AutoCAD R11 / R12 (DWG AC1009)-ից է, ավելի հին, քան CadCraft-ը կարդում է …» | DWG ֆայլերը Release 12-ից և ավելի վաղ օգտագործում են ձևաչափ, որը CadCraft-ը չի կարդում։ | Այն ծրագրում, որտեղ ստեղծվել է, պահեք DXF (ցանկացած տարբերակ) կամ ավելի նոր DWG, և բացեք այն։ CadCraft-ի սեփական {{ui:Save a copy as}}-ը առաջարկում է DXF R12՝ այդ հին ձևաչափ պահանջող ծրագրերի համար։ |
| «Չհաջողվեց բացել …», որին հաջորդում է ցանցային հաղորդագրություն, առաջին DWG-ի վրա | DWG ընթերցողը չէր կարող ներբեռնվել. դուք օֆլայն եք, և CadCraft-ը պահված չէ օֆլայն օգտագործման համար, կամ կապը ընդհատվեց։ | Անցեք առցանց և փորձեք նորից, կամ բացեք DXF։ Սեղմեք {{ui:Save for offline}} և սպասեք «Անցանց պատրաստ»-ին, որպեսզի DWG ֆայլերը հաջորդ անգամ բացվեն օֆլայն։ Տես [Working offline](common:offline)։ |
| Անցանց կոճակը ասում է «Չհաջողվեց պահել» | Որոշ ֆայլեր չեն ներբեռնվել։ | Ստուգեք կապը և սեղմեք կոճակը՝ նորից փորձելու համար։ |
| Անցանց կոճակը ասում է «Անցանց անհասանելի է» | Մասնավոր պատուհանները և որոշ կառավարվող համակարգիչներ չեն կարող պահել օֆլայն պատճեն։ | Օգտագործեք սովորական պատուհան, կամ մնացեք առցանց։ |
| CadCraft-ը չի բացվում առանց կապի | Այն չի պահվել օֆլայն օգտագործման համար այս դիտարկիչում, կամ դիտարկիչը այն մաքրել է։ | Հաջորդ անգամ, երբ առցանց լինեք, սեղմեք {{ui:Save for offline}} և սպասեք «Անցանց պատրաստ»-ին։ |
| Գծագիրը բացվում է, բայց որոշ մասեր բացակայում են | CadCraft-ը դեռ չի կարող նկարել որոշ օբյեկտներ, կամ ֆայլում որոշ շերտեր անջատված կամ սառեցված են։ | Կարդացեք ձախ վահանակի «Այս ֆայլի մասին»-ը։ Ստուգեք {{ui:Layers}} վահանակը։ |
| Տեքստը երկու տողի է փաթաթվում | CadCraft-ը տեքստը նկարում է Helvetica տիպի տառատեսակով, որը ավելի լայն է, քան որոշ CAD տառատեսակներ։ | Կարճացրեք տեքստը {{ui:Properties}}-ում, կամ ընդունեք լրացուցիչ տողը։ |
| Շրջանը երևում է որպես էլիպս, կամ հայելային տեքստը ճիշտ կողմով է կարդացվում | Օբյեկտը նկարված էր թեք հարթության մեջ, կամ նայված էր ներքևից՝ այն ծրագրում, որտեղ ստեղծվել է ֆայլը։ CadCraft-ը այն ցուցադրում է վերևից նայված, ինչպես այդ ծրագրի պլան տեսքն է. տեքստը պահվում է ընթեռնելի։ | Շտկելու բան չկա։ Եթե ուզում եք տեսնել այն այդ ծրագրի ձևով, խնդրեք գծագիրը հարթեցված, կամ օբյեկտները նկարված վերևից։ |
| Բլոկը, շրջանը կամ չափը գտնվում է ոչ այնտեղ, որտեղ գտնվում է այն ծրագրում, որտեղ ստեղծվել է ֆայլը | CadCraft-ը սխալ է կարդում գծագրի այդ դեպքը։ | Տեղեկացրեք մեզ Discord-ում, ֆայլի հետ, եթե կարող եք այն կիսել։ |

## Հրամանի տող

| Հաղորդագրություն կամ նշան | Պատճառ | Շտկում |
|---|---|---|
| «Անհայտ հրաման "…"։ Գրեք HELP՝ ցանկի համար։» | Այդ անունով հրաման կամ փոխանուն չկա։ | Գրեք `HELP`, կամ տես [Command reference](topic:commands)։ Որոշ ծանոթ հրամաններ [դեռ չեն ստեղծվել](topic:not-built-yet)։ |
| «Նման հրաման չկա» հրամանի տողի կողքին, երբ գրում եք | Ինչ որ գրել եք, դեռ ոչինչ չի համապատասխանում։ | Շարունակեք գրել, կամ ստուգեք ուղղագրությունը։ |
| «Պահանջվում է կետ կամ տարբերակի բանալի։» | Ինչ գրել եք, կետ կամ տարբերակ չէ։ | Ստուգեք ձևաչափը. `x,y`, `@dx,dy`, `@d<a` կամ մեկ թիվ։ Տես [Coordinate and distance entry](topic:coordinate-entry)։ |
| «Պահանջվում է դրական թիվ կամ երկու կետ։» | Հեռավորությունը բացասական էր կամ թիվ չէր։ | Մուտքագրեք դրական թիվ, կամ սեղմեք երկու կետ։ |
| «Պահանջվում է անկյուն աստիճաններով կամ երկու կետ։» | Անկյունը թիվ չէր։ | Մուտքագրեք աստիճանները պարզ թվով։ |
| «Պահանջվում է թիվ։» | Թիվ էր սպասվում։ | Մուտքագրեք միայն թվանշաններ։ |
| «Անվավեր տարբերակի բանալի։» | Տառերը չեն համապատասխանում տարբերակին։ | Մուտքագրեք մեծ տառերը, որոնք ցուցադրված են քառակուսի փակագծերում։ |
| `*Cancel*` | Սեղմել եք {{key:Esc}}, կամ {{key:Enter}}՝ այնտեղ, որտեղ կետ էր պահանջվում։ | Նորից սկսեք հրամանը։ |
| Մուտքագրումը չի հասնում հրամանի տող | Վահանակի կամ երկխոսության տուփն ունի կուրսոր։ | Սեղմեք {{key:Enter}} կամ {{key:Esc}}, կամ սեղմեք գծագրի վրա։ |
| Հրամանն օգտագործում է այն օբյեկտները, որոնք չեք ընտրել | Դրանք ընտրված էին նախքան հրամանը սկսելը։ | Սեղմեք {{key:Esc}} հրամանից առաջ։ |
| Գիծը գնաց անսպասելի տեղ | `x,y`-ը բացարձակ է։ | Օգտագործեք `@dx,dy` հարաբերական կետերի համար։ |
| «Նախ ավարտեք կամ չեղարկեք ընթացիկ հրամանը (Esc)։» | Սեղմել եք {{key:Mod+S}}, երբ հրաման էր աշխատում։ | Սեղմեք {{key:Esc}}, ապա պահեք։ |
| «Չհաջողվեց պահել որպես DWG (AutoCAD 2000)՝ … Փորձեք Պահել որպես, ապա DXF։» | Գծագրի ինչ-որ բան չէր կարող գրվել DWG-ով։ | Սեղմեք {{key:Mod+Shift+S}}, ընտրեք {{ui:DXF R12}} և սեղմեք {{ui:Save}}։ |
| «Չպահված է։» | Դուք փակել եք {{ui:Save a copy as}} երկխոսությունը {{ui:Cancel}}-ով կամ {{key:Esc}}-ով։ | Նորից սեղմեք {{key:Mod+Shift+S}} և սեղմեք {{ui:Save}}։ |

## Խմբագրում

| Հաղորդագրություն կամ նշան | Պատճառ | Շտկում |
|---|---|---|
| Օբյեկտը չի ընտրվում | Նրա շերտը կողպված է, անջատված կամ սառեցված է. կամ թերթի վրա եք, և այն տեսապատուհանի մեջ գտնվող մոդելն է։ | Ապակողպեք շերտը, կամ գնացեք {{ui:Model}} ներդիր։ |
| «Այնտեղ ոչինչ չի գտնվել։» | Սեղմման տակ օբյեկտ չկա։ | Մեծացրեք և սեղմեք գծի վրա։ |
| «Այնտեղ ոչինչ չի հատում այդ օբյեկտը։» | {{cmd:TRIM}}-ը չգտավ օբյեկտ, որը հատում է ձեր ընտրած հատվածը։ | Ստուգեք, որ կտրող գիծը իրոք հատում է այն։ |
| «Այդ օբյեկտը հնարավոր չէ կտրել։» | Կտրելը աշխատում է գծերի, աղեղների, շրջանների և բազմագծերի վրա։ | Նախ քանդեք բլոկները, կամ ջնջեք և նորից նկարեք։ |
| «Այդ ուղղությամբ սահման չկա։» | {{cmd:EXTEND}}-ը ոչինչ չգտավ, որին հասնել։ | Սեղմեք այն ծայրին ավելի մոտ, որը պետք է երկարացնել։ |
| «Այդ օբյեկտը հնարավոր չէ տեղափոխել զուգահեռաբար։» | Զուգահեռ տեղափոխումը աշխատում է գծերի, աղեղների, շրջանների և բազմագծերի վրա։ | Նախ քանդեք այն, կամ նկարեք զուգահեռ գիծ։ |
