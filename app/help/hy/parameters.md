## Մեկ աղյուսակ բոլոր չափերի համար

{{ui:Parameters}} վահանակը ({{ui:Parameters}} կոճակը {{ui:Parametric}} խմբում, կամ մուտքագրեք {{cmd:PARAMETERS}}) թվարկում է յուրաքանչյուր չափային սահմանափակում (`d1`, `rad1`, `dia1`, `ang1`, կամ ձեր տված անունը) և ձեր սեփական պարամետրերը միասին։ Ցանկացած անուն կարելի է օգտագործել ցանկացած արտահայտության մեջ։

Յուրաքանչյուր տող ունի՝

- **Անուն**․ մուտքագրեք նորը՝ վերանվանելու համար․ յուրաքանչյուր արտահայտություն, որ այն օգտագործում է, հետևում է։
- **Արտահայտություն**․ թիվ (`40`) կամ արտահայտություն (`width / 2 + gap`)։ Մուտքագրեք այնտեղ և սեղմեք {{key:Enter}}․ գծագիրը հետևում է։
- **Արժեք**․ այն, ինչ հաշվվում է։ Տողի վրա, որը վարվում է արտահայտությամբ, կարող եք մուտքագրել թիվ նաև այստեղ․ CadCraft-ը հաշվում է դրա հետևում գտնվող պարամետրը։ `d1 = width / 2`-ի դեպքում d1-ի արժեքում `30` մուտքագրելը `width`-ը դարձնում է 60։

Երբ երկու պարամետր վարում է մի արժեք (`width / 2 + gap`), երկխոսությունը հարցնում է, թե որ մեկը փոխել։ Յուրաքանչյուր փոփոխություն մեկ հետարկման քայլ է ({{key:Mod+Z}})։

## Ավելացնել ձեր սեփականը

1. Բացեք {{ui:Parameters}} վահանակը։
2. Մուտքագրեք անուն (`gap`) և արժեք (`10`), ապա ընտրեք {{ui:Add}}։
3. Օգտագործեք այն․ d1-ի արտահայտության մեջ մուտքագրեք `width / 2 + gap` և սեղմեք {{key:Enter}}։

Անունները սկսվում են տառով կամ `_`-ով և պարունակում են տառեր, թվեր և `_`։ Ֆունկցիաների անունները, `pi`-ն և միավորների անունները չեն կարող լինել անուններ։

## Արտահայտություններ

| Գրել | Նշանակում |
|---|---|
| `+ - * / ^ %` | գումարում, հանում, բազմապատկում, բաժանում, աստիճան, մնացորդ |
| `( )` | խմբավորում |
| `sin cos tan asin acos atan atan2` | եռանկյունաչափություն աստիճաններով |
| `sqrt pow exp ln log abs sign` | արմատներ, աստիճաններ, լոգարիթմներ |
| `ceil floor int round min max` | կլորացում և սահմաններ |
| `if(a > b, x, y)` | ընտրություն |
| `pi` | 3.14159… |

Թվերը կարող են ունենալ միավոր՝ `25mm`, `1in`, `2'`, `90deg`։ Միավորով երկարությունները վերածվում են միլիմետրերի, ուստի միավորներն օգտագործեք միայն միլիմետրերով չափված գծագրերում․ այլուր գրեք պարզ թվեր։

## Հրամանների տողում

`-PARAMETERS`-ը նույնն է անում առանց վահանակի․ `N` նոր, `E` խմբագրել (նաև չափային սահմանափակում), `R` վերանվանել, `D` ջնջել, `?` ցուցակ։

## Ինչ է մերժվում

- Արտահայտություն, որ օգտագործում է իրեն՝ ուղղակիորեն կամ այլոց միջոցով․ «width, d1 օգտագործում են միմյանց»։
- Արժեք, որ չափը չի կարող ընդունել․ բացասական երկարություն, 180°-ից մեծ անկյուն։
- Արժեք, որ գծագիրը չի կարող ընդունել իր մյուս սահմանափակումներով․ ոչինչ չի փոխվում, և հաղորդագրությունը անվանում է խանգարող սահմանափակումները։
- Պարամետրի ջնջում, որը ինչ-որ բան օգտագործում է․ վահանակը առաջարկում է նախ դրա արժեքը գրել դրանց մեջ։ Չափային սահմանափակման անունը ջնջվում է սահմանափակումը ջնջելով։
