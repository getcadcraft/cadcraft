Մուտքագրեք կարճ անունը (փոխանունը) և սեղմեք Enter, կամ սեղմեք գործիքը։ Esc-ը չեղարկում է։ Դատարկ տողում Enter-ը կրկնում է վերջին հրամանը։

**Տպել այն՝** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (մեկ A4 էջ․ Letter թղթի վրա տպեք՝ «տեղավորել էջում» ընտրանքով)։

## Գծել

| Գրել | Հրաման | Ինչ է անում |
|---|---|---|
| `L` | {{cmd:LINE}} | Գծել ուղիղ գծեր |
| `PL` | {{cmd:PLINE}} | Գծել միացված գծերի և աղեղների շղթա |
| `C` | {{cmd:CIRCLE}} | Գծել շրջան (կենտրոնով և շառավղով) |
| `A` | {{cmd:ARC}} | Գծել աղեղ |
| `REC` | {{cmd:RECTANG}} | Գծել ուղղանկյուն երկու անկյունից |
| `POL` | {{cmd:POLYGON}} | Գծել կանոնավոր բազմանկյուն |
| `EL` | {{cmd:ELLIPSE}} | Գծել էլիպս |
| `DT` | {{cmd:TEXT}} | Գրել տեքստի մեկ տող |
| `T` | {{cmd:MTEXT}} | Գրել փաթաթվող տեքստ (պարբերություն) |
| `H` | {{cmd:HATCH}} | Լցնել տարածքը նախշով |

## Փոփոխել

| Գրել | Հրաման | Ինչ է անում |
|---|---|---|
| `M` | {{cmd:MOVE}} | Տեղափոխել օբյեկտները |
| `CO` | {{cmd:COPY}} | Պատճենել օբյեկտները |
| `RO` | {{cmd:ROTATE}} | Պտտել օբյեկտները կետի շուրջ |
| `SC` | {{cmd:SCALE}} | Մեծացնել կամ փոքրացնել օբյեկտները |
| `MI` | {{cmd:MIRROR}} | Հայելապատկել օբյեկտները գծի նկատմամբ |
| `O` | {{cmd:OFFSET}} | Գծել զուգահեռ պատճեն որոշակի հեռավորության վրա |
| `TR` | {{cmd:TRIM}} | Կտրել օբյեկտները մինչև այն տեղը, որտեղ դրանք հատում են մյուսները |
| `EX` | {{cmd:EXTEND}} | Երկարացնել օբյեկտները մինչև մյուսները |
| `F` | {{cmd:FILLET}} | Կլորացնել անկյունը աղեղով |
| `CHA` | {{cmd:CHAMFER}} | Կտրել անկյունը ուղիղ եզրով |
| `E` | {{cmd:ERASE}} | Ջնջել օբյեկտները |
| `X` | {{cmd:EXPLODE}} | Բաժանել բլոկը կամ բազմագիծը իր մասերի |
| `S` | {{cmd:STRETCH}} | Տեղափոխել ծայրերը հատվող պատուհանի ներսում |
| `AR` | {{cmd:ARRAY}} | Պատճենել ցանցով կամ շրջանով |
| `J` | {{cmd:JOIN}} | Միացնել գծերն ու աղեղները մեկ օբյեկտի մեջ |
| `BR` | {{cmd:BREAK}} | Կտրել օբյեկտը երկու մասի կամ հանել մի կտոր |

## Ստեղներ

Ctrl (Mac-ում՝ Cmd)՝ Z՝ հետարկել · Y՝ կրկնել · S՝ պահել · P՝ տպել։  F3՝ օբյեկտային կապում · F8՝ օրտո · F10՝ բևեռային։  Space կամ Enter՝ կրկնում է վերջին հրամանը · անիվը մասշտաբավորում է · անիվով քաշելը տեղաշարժում է։

Գծագրության մեջ նոր եք։ Մուտքագրեք `TOUR`՝ ուղեցույցով առաջին գծագրի համար, կարդացեք [Սկսել աշխատանքը](topic:getting-started), կամ տեսեք բոլոր հրամանները [Հրամաններում](topic:commands)։ Եթե գալիս եք այլ գծագրական ծրագրից՝ [Այլ գծագրական ծրագրերից անցում](topic:coming-from) և [հրամանների քարտեզը](topic:command-map)։
