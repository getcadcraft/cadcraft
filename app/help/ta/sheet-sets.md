## இதில் நீங்கள் அறிவது

பல வரைபடக் கோப்புகளிலிருந்து தாள்களை (லேஅவுட்கள்) ஒரு **தாள் தொகுப்பில்** எவ்வாறு சேகரிப்பது, அவற்றை எண்ணிட்டுத் தலைப்பிடுவது, அவற்றின் தலைப்புப் பெட்டிகளை உங்களுக்காக நிரப்புவது, முழு தொகுப்பையும் ஒரு PDF ஆக வெளியிடுவது, அனுப்ப அனைத்தையும் ஒரு zip இல் அடைப்பது.

தாள் தொகுப்பு `<name>.ccsheets` என்ற தனிச் சிறிய கோப்பில் வாழ்கிறது, வரைபடங்கள் உள்ள கோப்புறையில். தொகுப்புக் கோப்பு அந்தக் கோப்புறையிலிருந்து பாதைகளுடன் தாள்களைப் பட்டியலிடுகிறது, எனவே முழு கோப்புறையையும் நகர்த்தலாம் அல்லது நகலெடுக்கலாம்.

:::note
ஒரு கோப்புறையைப் படிக்கவும் எழுதவும் திறக்க Chrome அல்லது Edge தேவை (அவை ஒரு பக்கம் நீங்கள் தேர்ந்தெடுத்த கோப்புறையில் வேலை செய்ய அனுமதிக்கலாம்), அல்லது டெஸ்க்டாப் பயன்பாடு. பிற உலாவிகள் தொகுப்பைப் படிக்க மட்டும் திறக்கும்: நீங்கள் அதைப் பார்க்கலாம், வெளியிடலாம்; ஆனால் தொகுப்புக் கோப்பு சேமிக்கப்படாமல் பதிவிறக்கமாகும்.
:::

## தொகுப்பைத் தொடங்கு

1. இடது பலகத்தில் {{ui:Sheet set}} பிரிவைக் கண்டறிந்து அதன் {{ui:Set}} பட்டியைத் திறக்கவும். {{cmd:SHEETSET}} (அல்லது `SSM`) என உள்ளிட்டாலும் நீங்கள் அங்கு செல்வீர்கள்.
2. {{ui:New set…}} ஐத் தேர்ந்தெடுக்கவும். தொகுப்புக்கு ஒரு பெயர் கொடுக்கவும், விரும்பினால் திட்டப் பெயரையும் எண்ணையும் கொடுக்கவும்.
3. வரைபடங்களைக் கொண்ட கோப்புறையைத் தேர்ந்தெடுக்கவும். தொகுப்புக் கோப்பு அங்கே சேமிக்கப்படும்.

பின்னர் ஒரு தொகுப்பைத் திறக்க, {{ui:Open set…}} ஐத் தேர்ந்தெடுத்து அதே கோப்புறையைத் தேர்ந்தெடுக்கவும். கோப்புறையில் ஒன்றுக்கு மேற்பட்ட தொகுப்புகள் இருந்தால், CadCraft எதுவென்று கேட்கும்.

## தாள்களைச் சேர்

1. {{ui:Add sheets from a drawing…}} ஐத் தேர்ந்தெடுத்து, கோப்புறையிலுள்ள வரைபடங்களில் ஒன்றைத் தேர்வு செய்யவும்.
2. CadCraft அந்த வரைபடத்தைப் பின்னணியில் படிக்கும் (திரையில் திறக்காது), அதன் தாள்களைப் பட்டியலிடும். நீங்கள் விரும்புபவற்றைக் குறியிட்டு {{ui:OK}} ஐச் சொடுக்கவும்.
3. ஒரு தாளைத் தேர்ந்தெடுத்து {{key:F2}} ஐ அழுத்தவும் (அல்லது {{ui:Rename and renumber…}}), அதற்கு `A-101` மற்றும் `தரைத் திட்டம்` போன்ற ஓர் எண்ணையும் தலைப்பையும் கொடுக்க.

{{ui:New sheet from template…}} வேறொரு வரைபடத்தின் தாளிலிருந்து (அதன் தலைப்புப் பெட்டியும் காட்சிச் சாளரங்களும்) ஒரு புதிய வரைபடத்தை உருவாக்கி, அதைப் புதிய தாளின் பெயரால் பெயரிட்டு, சேர்க்கும். நீங்கள் வார்ப்புருவாகப் பயன்படுத்திய வரைபடத்தை தொகுப்பு நினைவில் வைத்திருக்கும்.

## தொகுப்பை ஒழுங்கமை

- **துணைத் தொகுப்புகள்** தாள்களைக் குழுவாக்குகின்றன, உதாரணமாக Architectural › Plans: அது எங்கு போக வேண்டும் என்பதைத் தேர்ந்தெடுத்து {{ui:New subset…}} ஐத் தேர்ந்தெடுக்கவும்.
- **வரிசை**: ஒரு தாளைப் பட்டியலில் வேறோர் இடத்துக்கு இழுக்கவும், அல்லது அதை ஒரு துணைத் தொகுப்பின் மீது இழுத்து அங்கு நகர்த்தவும். விசைப்பலகையில், அதைத் தேர்ந்தெடுத்து {{key:Alt+Up}} அல்லது {{key:Alt+Down}} ஐ அழுத்தவும்.
- **ஒரு தாளைத் திறக்க**: இருமுறை சொடுக்கவும் (அல்லது {{key:Enter}} ஐ அழுத்தவும்). அதன் வரைபடம் அதன் சொந்தத் தாவலில், அந்தத் தாளில் திறக்கும்.
- **நீக்கு**: அதைத் தேர்ந்தெடுத்து {{key:Delete}} ஐ அழுத்தவும். வரைபடம் தானே மாற்றப்படாது.
- **செயல்தவிர்**: {{ui:Undo set change}} மற்றும் {{ui:Redo set change}} தொகுப்பில் நீங்கள் மாற்றியவற்றில் படிப்படியாகச் செல்லும்.
- **மறுஎண்ணிடு**: {{ui:Renumber sheets…}} பட்டியலின் வரிசையில் ஒவ்வொரு தாளையும், அல்லது ஒரு துணைத் தொகுப்பின் தாள்களையும் எண்ணிடுகிறது: ஒரு முன்னொட்டு, ஒரு தொடக்கம் மற்றும் ஒரு படி (`A-` மற்றும் `101` A-101, A-102 … தரும்).

ஒவ்வொரு மாற்றமும் உடனடியாகத் தொகுப்புக் கோப்பில் சேமிக்கப்படும்.

## புலங்களிலிருந்து தாள் எண்களைத் தரவும்

ஒவ்வொரு எண்ணையும் கையால் கொடுப்பதற்குப் பதிலாக, ஒரு விதி தாளின் புலங்களிலிருந்து ஒவ்வொரு எண்ணையும் உருவாக்கட்டும்; அதனால் வேறொரு நிலைக்கோ துறைக்கோ நகரும் தாள் தானாகவே அதன் புதிய எண்ணைப் பெறும்.

1. ஒவ்வொரு தாளுக்கும் அதன் புலங்களைக் கொடுக்கவும்: அதைத் தேர்ந்தெடுத்து {{ui:Rename…}} ஐச் சொடுக்கி, {{ui:Fields of this sheet}} இல், ஒரு வரிக்கு ஒன்றாக எழுதவும், உதாரணமாக `DISCIPLINE = A` மற்றும் `LEVEL = 1`. தொகுப்பு முழுவதும் பகிரும் ஒரு புலம் (உதாரணமாக `DISCIPLINE = A`) அதற்குப் பதிலாக தொகுப்பின் பண்புகளில் போகலாம்.
2. பலகத்தின் பட்டியைத் திறந்து {{ui:Numbering rule…}} ஐச் சொடுக்கவும்.
3. விதியை எழுதவும், உதாரணமாக `{DISCIPLINE}-{LEVEL}{SEQ:2}`. `{SEQ}` மற்ற புலங்கள் ஒரே மாதிரி படிக்கும் தாள்களுக்குள் எண்ணிக்கொண்டே போகும்; அதனால் நிலை 1 A-101, A-102 பெறும், நிலை 2 A-201 இலிருந்து மீண்டும் தொடங்கும். `{SEQ:2}` அதை இரண்டு இலக்கங்களில் எழுதும்; `{SUBSET}` தாள் உள்ள துணைத் தொகுப்பின் பெயர்.
4. ஒரு புலம் மாறும்போது என்ன நடக்கும் என்பதைத் தேர்ந்தெடுக்கவும்: {{ui:Renumber the sheets}} ஒவ்வொரு மாற்றத்துக்குப் பின்னும் எண்கள் விதியைத் தொடர்ந்து வைத்திருக்கும்; மற்ற தேர்வு அவற்றை ஒருமுறை, இப்போதே எண்ணிடும்.

விதி தொகுப்புக் கோப்பில் சேமிக்கப்படுகிறது. அது தானாக மறுஎண்ணிடும்போது, தாளின் எண்ணை அல்ல, அதன் புலங்களை மாற்றவும்.

## தலைப்புப் பெட்டிகளைத் தொகுப்பிலிருந்து நிரப்பு

ஒரு தலைப்புப் பெட்டி தனது உரையை தொகுப்பிலிருந்து பெறுகிறது, அதன் பண்புக்கூறுகள் ஒரு புலத்தின் பெயருடன் குறிக்கப்பட்டிருக்கும்போது:

| குறி | அது காட்டுவது |
|---|---|
| `SHEETNUMBER` (அல்லது `SHEET_NO`, `DWG_NO`) | தாளின் எண் |
| `SHEETTITLE` (அல்லது `TITLE`, `SHEET_TITLE`) | தாளின் தலைப்பு |
| `SHEETDESC` | தாளின் விளக்கம் |
| `PROJECTNAME` (அல்லது `PROJECT`) | திட்டப் பெயர் |
| `PROJECTNUMBER` (அல்லது `PROJECT_NO`, `JOB_NO`) | திட்ட எண் |
| `SHEETSETNAME` | தொகுப்பின் பெயர் |
| `SHEETINDEX`, `SHEETCOUNT` | "12 இல் 3", மற்றும் 12 |
| உங்களுடையது, உதாரணமாக `CLIENT` | {{ui:Set fields…}} இல் அதற்காக நீங்கள் எழுதியது |

{{ui:Set fields…}} திட்டப் பெயரையும் எண்ணையும், மற்றும் உங்கள் சொந்தப் புலங்களையும், ஒரு வரிக்கு ஒன்றாக `NAME = value` என வைத்திருக்கிறது.

{{ui:Update drawings}} தொகுப்பில் உள்ள ஒவ்வொரு வரைபடத்தின் தலைப்புப் பெட்டிகளிலும் எண்களையும் தலைப்புகளையும் புலங்களையும் எழுதுகிறது, மேலும் ஒவ்வொரு தாளின் அமைப்புத் தாவலையும் தொகுப்பு சொல்வது போல் மறுபெயரிடுகிறது (இயல்பாக எண்ணும் தலைப்பும், உதாரணமாக `A-101 தரைத் திட்டம்`; {{ui:Set fields…}} › {{ui:Layout tab names}} அதை மாற்றும்). ஒவ்வொரு வரைபடமும் அதே இடத்தில், அதன் சொந்த வடிவத்திலும் பதிப்பிலும் சேமிக்கப்படுகிறது. எண்களையோ தலைப்புகளையோ மறுபெயரிட்ட பிறகு, மீண்டும் இயக்கவும்; தாவல்களும் தலைப்புப் பெட்டிகளும் பின்தொடரும்.

## அட்டைத் தாளில் ஒரு தாள் பட்டியல்

பட்டியலில் அட்டைத் தாளைத் தேர்ந்தெடுத்து {{ui:Put the sheet list on this sheet}} ஐத் தேர்ந்தெடுக்கவும். ஒவ்வொரு தாளின் அட்டவணை (எண்ணும் தலைப்பும், அதன் துணைத் தொகுப்பின் கீழ்) தாளின் மேல் இடது மூலையில் போகும். {{ui:Update drawings}} மற்றும் {{ui:Publish to PDF}} அதை புதுப்பித்து வைக்கும். அது ஒரே தொகுதி, `CC_SHEETLIST`: எந்தத் தொகுதிக் குறிப்பையும் போல நகர்த்தவும்.

## தொகுப்பை வெளியிடு

{{ui:Publish to PDF}} ஒரு PDF ஐ உருவாக்குகிறது: ஒவ்வொரு தாளுக்கும் ஒரு பக்கம், தொகுப்பின் வரிசையில், ஒவ்வொரு தாளின் சொந்தக் காகித அளவில், ஒவ்வொரு தாளுக்கும் ஒரு புத்தகக்குறி ("A-101 — தரைத் திட்டம்"). ஒரு துணைத் தொகுப்பு தேர்ந்தெடுக்கப்பட்டிருந்தால், CadCraft அந்தத் துணைத் தொகுப்பை மட்டும் வெளியிடலாமா என்று கேட்கும். PDF இல் உள்ள தலைப்புப் பெட்டிகள், நீங்கள் வரைபடங்களைப் புதுப்பிக்கும் முன்பே தொகுப்பிலிருந்து நிரப்பப்படும்; வெளியிடுவதால் வரைபடங்கள் மாறாது. PDF பதிவிறக்கமாகும்.

{{ui:Publish to DWG…}} ஒவ்வொரு தாளையும் அதற்கென ஒரு DWG ஆக எழுதுகிறது (DWG 2018): மாதிரியும் அந்த ஒரு தாளும், அதன் தலைப்புப் பெட்டி தொகுப்பிலிருந்து நிரப்பப்பட்டு, அதன் எண்ணாலும் தலைப்பாலும் பெயரிடப்பட்டு (`A-101 Level 1 floor plan.dwg`). {{ui:DWG}} ஐத் தேர்ந்தெடுக்கவும், அல்லது அருகிலுள்ள தொகுப்பின் PDF க்கு {{ui:DWG + PDF}}. `publish.json` ஒவ்வொரு கோப்பையும் அதன் அளவு மற்றும் SHA-256 உடன் பட்டியலிடுகிறது. தொகுப்பின் கோப்புறை எழுதக்கூடியதாக இருக்கும்போது (CadCraft Studio, அல்லது உலாவியில் நீங்கள் தேர்ந்தெடுத்த கோப்புறை) கோப்புகள் `<set name> - published` என்ற கோப்புறைக்குள் போகும்; இல்லையெனில் ஒரு zip ஆகப் பதிவிறக்கமாகும். [காட்சிச் சாளர வகுப்பு மேலெழுதல்கள்](topic:viewport-overrides) ஒவ்வொரு DWG உடனும் வரும்.

## தொகுப்பைக் காப்பகப்படுத்து

{{ui:Archive as a zip}} தொகுப்புக் கோப்பை, அது பயன்படுத்தும் ஒவ்வொரு வரைபடத்தையும், அந்த வரைபடங்கள் இணைக்கும் அனைத்தையும் (இணைக்கப்பட்ட வரைபடங்கள், அவற்றின் இணைப்புகள், மற்றும் படங்கள்) அவற்றின் கோப்புறைகளை வைத்தபடி அடைக்கிறது, மேலும் ஒவ்வொரு கோப்பையும் பட்டியலிடும் ஒரு `Transmittal.txt` ஐச் சேர்க்கிறது. தொகுப்பின் கோப்புறையில் இல்லாத இணைப்பு அங்கு விடுபட்டதாகப் பட்டியலிடப்படும். இணைப்புகள் வரைபடத்திலிருந்து அவற்றின் பாதையால் முதலில், பின்னர் கோப்புறையில் எங்கேனும் அவற்றின் கோப்புப் பெயரால் கண்டறியப்படுகின்றன.

## தொகுப்புக் கோப்பு

`.ccsheets` கோப்பு எந்த உரை திருத்தியிலும் படிக்கக்கூடிய JSON ஆகும்:

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

பாதைகள் தொகுப்பின் கோப்புறையுடன் தொடர்புடையவை, கோப்புறைகளுக்கு இடையே `/`. CadCraft அதைத் திறக்கும்போது கோப்பைச் சரிபார்க்கிறது: ஒரு முழுமையான பாதை, கோப்பு அல்லது அமைப்பு இல்லாத ஒரு தாள், அல்லது எளிய உரை அல்லாத உரை விடப்படும், வரலாறு அதைச் சொல்லும்.
