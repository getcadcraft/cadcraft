CadCraft வளர்ச்சியில் உள்ளது. இந்தப் பக்கம் தற்போதைய பதிப்பு என்ன செய்யாது என்பதைப் பட்டியலிடுகிறது, அதனால் அதைத் தேட வேண்டியதில்லை. ஒவ்வொரு உருப்படியும் இன்று அதற்குப் பதிலாக என்ன செய்வது என்பதைச் சொல்லும்.

| உலாவியில் திறந்த கோப்பின் மேல் சேமித்தல் | ஒவ்வொரு சேமிப்பும் ஒரு புதிய நகலைப் பதிவிறக்கும்; நீங்கள் விரும்பினால் பழைய கோப்பைத் தானே மாற்றவும். CadCraft Studio இல், {{key:Mod+S}} நீங்கள் திறந்த கோப்புக்கு மீண்டும் எழுதும். |
| கணினிகளுக்கிடையே மேகச் சேமிப்பும் ஒத்திசைவும் | CadCraft இன்னும் தனது சேமிப்புகளை மேகத்துக்கு அனுப்பவில்லை: உங்கள் DWG மற்றும் DXF கோப்புகளை உங்கள் சொந்தக் கோப்புறைகளில் வைக்கவும். CadCraft Studio இல், [வரலாறு](topic:history) வேறிடத்திலிருந்து சேமிக்கப்பட்ட வரைபடத்தின் மேகப் பதிப்புகளையும், இந்தக் கணினியில் உங்கள் சொந்தச் சேமிப்புகளின் நகல்களையும் பட்டியலிடும். |
| மேலடுக்குகள், மற்றும் இணைக்கப்பட்ட வரைபடத்தை அதே இடத்தில் திருத்துதல் | வரைபடத்தை இணைப்பாக இணைத்து, மற்ற வரைபடத்தை மாற்றிய பிறகு மீண்டும் ஏற்றவும். DWG ஆகச் சேமிக்கும்போது இணைப்பு இணைப்பாகவே இருக்கும், {{cmd:XCLIP}} அதைக் கத்தரிக்கும். |
| DXF இல் படங்கள்; அடியில் உள்ளதை மறைக்கும் wipeout-கள் | DXF ஒரு படத்தை அதன் சட்டமாகவும் கோப்புப் பெயருடனும் வைத்திருக்கும்; DWG அதைப் படமாக வைத்திருக்கும் — பார்க்கவும் [வரைபடத்தில் உள்ள படங்கள்](topic:pictures). ஒரு wipeout அதன் சட்டமாகக் காட்டப்படும். |
| வளைந்த வழிகாட்டிக் கோடுகளுடன் பல-வழிகாட்டிகளைத் திருத்துதல், உள்ளடக்கத்தின் இரு பக்கங்களிலும் வழிகாட்டிக் கோடுகளுடன், அல்லது சீரற்ற முறையில் திருப்பப்பட்ட அல்லது அளவிடப்பட்ட தொகுதியுடன் | அவை மற்ற நிரல் வரைந்தது போலவே வரையப்பட்டு ஒன்றாக நகரும். ஒரே முனைக்கு நேரான வழிகாட்டிக் கோடுகளும், உள்ளடக்கமாக உரை அல்லது தொகுதியும் கொண்ட பல-வழிகாட்டிகள் திருத்தக்கூடியதாக வரும் ({{cmd:MLEADEREDIT}}). |
| பிற நிரல்களின் அட்டவணைகளில்: தொகுதியைக் கொண்ட கலம், கலத்தின் உள்ளே உரை வடிவமைப்பு, DXF அட்டவணையின் ஒவ்வொரு கலத்தின் எல்லைகளும் நிறங்களும், நெடுவரிசைகளாகப் பிரிந்த அட்டவணை | அட்டவணை திருத்தக்கூடிய அட்டவணையாகத் திறக்கும் ({{cmd:TABLEDIT}}) மேலும் நீங்கள் திருத்தும் வரை மற்ற நிரல் வரைந்தவாறு காட்டப்படும்; பிறகு CadCraft அதை அதன் கலங்களிலிருந்து மீண்டும் வரையும்: சாதாரண உரை, `=G3*H3` மற்றும் `=Sum(I3:I9)` போன்ற சூத்திரங்கள், சீரமைப்பு மற்றும் உரை உயரங்கள். தொகுதிக் கலம் பின்னர் காலியாக இருக்கும். திருத்தப்படாத DWG அட்டவணை அது வந்த கலத் தரவுடனேயே மீண்டும் சேமிக்கப்படும். |
| சேமிக்கப்பட்ட DXF இல் ஓர் உண்மையான அட்டவணைப் பொருள் | DWG ஓர் அட்டவணையை மற்ற நிரல்கள் திருத்தக்கூடிய அட்டவணையாக வைத்திருக்கும். DXF அதை அதை வரையும் தொகுதியாக CadCraft இன் சொந்தப் பதிவுடன் வைத்திருக்கும்: CadCraft அதை மீண்டும் அட்டவணையாகத் திறக்கும்; மற்ற நிரல்கள் ஒரு தொகுதியைக் காணும். கண்ணாடி பிரதிபலித்த அல்லது சீரற்ற முறையில் அளவிடப்பட்ட அட்டவணை DWG இலும் அப்படியே சேமிக்கப்படும். |
| பிற நிரல்களுடன் நகலெடுத்து ஒட்டுதல் | CadCraft இன் கிளிப்போர்டு அதே உலாவியில் உள்ள CadCraft வரைபடங்களுக்கும் தாவல்களுக்கும் இடையே வேலை செய்யும், பிற நிரல்களுடன் அல்ல. DWG அல்லது DXF ஆகச் சேமித்து அங்கே திறக்கவும். பார்க்கவும் [நகலெடு, ஒட்டு மற்றும் நகலாக்கு](topic:copy-paste). |

## வரைதலும் திருத்தலும்

|---|---|
| CadCraft இல் இல்லாத ஹேட்ச் வடிவங்கள், மற்றும் மற்ற நிரல்கள் வரைவது போலவே சரியாக வரையப்படும் சாய்வு நிரப்புகள் | CadCraft இல் இல்லாத வடிவங்களைக் கொண்ட திறந்த ஹேட்ச்கள் ஒரு தொனியாகக் காட்டப்படும். ஒரு சாய்வு நிரப்பு ({{cmd:GRADIENT}}) ஒவ்வொரு வகைக்கும் CadCraft இன் சொந்த முறையில் வரையப்படுகிறது: வகையில் மற்ற நிரல்களைப் போல, புள்ளிக்குப் புள்ளியாக அல்ல. DWG 2004 மற்றும் பின்னர் அதை உண்மையான சாய்வு ஹேட்ச்சாக வைத்திருக்கும்; DXF 2000 அல்லது DWG 2000 கோப்பில் CadCraft மட்டுமே அதை மீண்டும் படிக்கும், மற்ற நிரல்கள் ஒரு திட நிரப்பாகக் காணும். வடிவங்கள் ஒரு `.pat` கோப்பிலிருந்து ஏற்றப்படும், ஒரு ஹேட்ச்சை அதன் எல்லையுடன் இணைக்கலாம், அதன் பிறகு அது அதைப் பின்தொடரும்: பார்க்கவும் [ஹேட்ச் மற்றும் நிரப்பு பகுதிகள்](topic:hatch). |
| வடிவங்கள் அல்லது உரை கொண்ட கோட்டு வகைகள், மற்றும் சேமிக்கப்பட்ட DXF R12 இல் கோட்டு தடிமன்கள் | ஒரு கோப்பின் கோட்டு வகையில் உள்ள வடிவங்களும் உரையும் அதன் கோடுகளிலிருந்து விடப்படும்; கோட்டு தடிமன்களை வைத்திருக்க DWG ஆகச் சேமிக்கவும். |
| சேமிக்கப்பட்ட DXF இல் வடிவ ஹேட்ச்கள் | R12 இல் ஹேட்ச் இல்லை: அவை அவற்றின் வெளிக்கோடுகளாகச் சேமிக்கப்படும். வடிவத்தை வைத்திருக்க DWG ஆகச் சேமிக்கவும். |
| பிற நிரல் உருவாக்கிய அல்லது திருத்தக்கூடிய அணிகள்; பாதை மற்றும் துருவ அணிகளில் வரிசைகளும் மட்டங்களும்; அதன் பாதை வளைவைப் பின்தொடரும் அணி | ASsociative ({{cmd:ARRAY}}, {{cmd:ARRAYPATH}}; {{cmd:ARRAYEDIT}} மூலம் மாற்றப்படும்) மூலம் உருவாக்கப்பட்ட அணி CadCraft இன் சொந்த எண்களுடன் ஒரு தொகுதிக் குறிப்பாகச் சேமிக்கப்படும்: மற்ற நிரல்கள் அதைக் காட்டும், நகர்த்தும், அச்சிடும் மற்றும் பிரிக்கும், ஆனால் அதன் எண்ணிக்கைகளை மாற்ற முடியாது; மற்ற நிரலில் உருவாக்கிய அணி இங்கே ஒரு சாதாரணத் தொகுதிக் குறிப்பாகத் திறக்கும். பாதை அணி அதன் பாதையின் நகலை வைத்திருக்கும்: பின்னர் வளைவைத் திருத்துவது உருப்படிகளை நகர்த்தாது. |
| பிற நிரல்களுக்கும் பிற நிரல்களிலிருந்தும் கத்தரிக்கப்பட்ட தாள் காட்சிச் சாளரங்கள் | {{cmd:VPCLIP}} மூலம் கத்தரிக்கப்பட்ட அல்லது {{cmd:MVIEW}} Polygonal அல்லது Object ஆக உருவாக்கப்பட்ட காட்சிச் சாளரம் CadCraft இன் சொந்த வெளிக்கோட்டுடன் சேமிக்கப்படும்: மற்ற நிரல்கள் அதைச் சுற்றியுள்ள செவ்வகமாகத் திறக்கும்; மற்ற நிரலில் கத்தரிக்கப்பட்ட காட்சிச் சாளரம் இங்கே அதன் செவ்வகமாகத் திறக்கும். ## உதவி

உதவி இந்தப் பதிப்பை விவரிக்கிறது. ஏதாவது சேர்க்கப்படும்போது, அது இந்தப் பக்கத்திலிருந்து நகர்ந்து வழிகாட்டிகளுக்குள் செல்லும்.
