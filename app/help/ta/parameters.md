## ஒவ்வொரு அளவுக்கும் ஒரே அட்டவணை

{{ui:Parameters}} பலகம் ({{ui:Parametric}} குழுவிலுள்ள {{ui:Parameters}} பொத்தான், அல்லது {{cmd:PARAMETERS}} என தட்டச்சு செய்யவும்) ஒவ்வொரு பரிமாணக் கட்டுப்பாட்டையும் (`d1`, `rad1`, `dia1`, `ang1`, அல்லது நீங்கள் கொடுத்த பெயர்) மற்றும் உங்கள் சொந்த அளபுருக்களையும் ஒன்றாகப் பட்டியலிடுகிறது. எந்தப் பெயரையும் எந்த வெளிப்பாட்டிலும் பயன்படுத்தலாம்.

ஒவ்வொரு வரியிலும்:

- **பெயர்**: புதியதைத் தட்டச்சு செய்து மறுபெயரிடவும்; அதைப் பயன்படுத்தும் ஒவ்வொரு வெளிப்பாடும் பின்தொடரும்.
- **வெளிப்பாடு**: ஓர் எண் (`40`) அல்லது ஒரு வெளிப்பாடு (`width / 2 + gap`). அதில் தட்டச்சு செய்து {{key:Enter}} அழுத்தவும்: வரைபடம் பின்தொடரும்.
- **மதிப்பு**: அது கணக்கிடுவது. ஒரு வெளிப்பாடு இயக்கும் வரியில், இங்கேயும் ஓர் எண்ணைத் தட்டச்சு செய்யலாம்: CadCraft அதற்குப் பின்னால் உள்ள அளபுருவைக் கணக்கிடும். `d1 = width / 2` எனில், d1 இன் மதிப்பில் `30` தட்டச்சு செய்தால் `width` 60 ஆகும்.

இரண்டு அளபுருக்கள் ஒரு மதிப்பை இயக்கும்போது (`width / 2 + gap`), எதை மாற்றுவது என ஓர் உரையாடல் கேட்கும். ஒவ்வொரு மாற்றமும் ஒரு செயல்தவிர் படி ({{key:Mod+Z}}).

## உங்களுடையதைச் சேர்

1. {{ui:Parameters}} பலகத்தைத் திறக்கவும்.
2. ஒரு பெயரை (`gap`) மற்றும் ஒரு மதிப்பை (`10`) தட்டச்சு செய்து, {{ui:Add}} ஐத் தேர்ந்தெடுக்கவும்.
3. அதைப் பயன்படுத்தவும்: d1 இன் வெளிப்பாட்டில், `width / 2 + gap` எனத் தட்டச்சு செய்து {{key:Enter}} அழுத்தவும்.

பெயர்கள் ஓர் எழுத்து அல்லது `_` இல் தொடங்கும், மற்றும் எழுத்துகள், இலக்கங்கள் மற்றும் `_` ஐக் கொண்டிருக்கும். செயல்பாட்டுப் பெயர்கள், `pi` மற்றும் அலகுப் பெயர்கள் பெயர்களாக இருக்க முடியாது.

## வெளிப்பாடுகள்

| எழுது | பொருள் |
|---|---|
| `+ - * / ^ %` | கூட்டு, கழி, பெருக்கு, வகு, அடுக்கு, மீதம் |
| `( )` | தொகுத்தல் |
| `sin cos tan asin acos atan atan2` | டிகிரியில் முக்கோணவியல் |
| `sqrt pow exp ln log abs sign` | வேர்கள், அடுக்குகள், மடக்கைகள் |
| `ceil floor int round min max` | முழுமையாக்கல் மற்றும் எல்லைகள் |
| `if(a > b, x, y)` | ஒரு தேர்வு |
| `pi` | 3.14159… |

எண்களில் ஓர் அலகு இருக்கலாம்: `25mm`, `1in`, `2'`, `90deg`. அலகுகளுடன் கூடிய நீளங்கள் மில்லிமீட்டராக மாற்றப்படும், எனவே அலகுகளை மில்லிமீட்டரில் அளக்கப்பட்ட வரைபடங்களில் மட்டும் பயன்படுத்தவும்; மற்றவற்றில் சாதாரண எண்களைத் தட்டச்சு செய்யவும்.

## கட்டளை வரியில்

`-PARAMETERS` பலகம் இல்லாமல் அதையே செய்யும்: `N` புதியது, `E` திருத்து (பரிமாணக் கட்டுப்பாடும் கூட), `R` மறுபெயரிடு, `D` நீக்கு, `?` பட்டியல்.

## மறுக்கப்படுவது

- தன்னைத் தானே பயன்படுத்தும் ஒரு வெளிப்பாடு, நேரடியாகவோ மற்றவை வழியாகவோ: "width, d1 ஒன்றையொன்று பயன்படுத்துகின்றன."
- ஓர் அளவு எடுக்க முடியாத மதிப்பு: எதிர்மறை நீளம், 180° ஐ விட அதிகமான கோணம்.
- அதன் மற்ற கட்டுப்பாடுகளுடன் வரைபடம் எடுக்க முடியாத ஒரு மதிப்பு: எதுவும் மாறாது, மற்றும் செய்தி வழியில் உள்ள கட்டுப்பாடுகளின் பெயரைச் சொல்லும்.
- எதுவோ பயன்படுத்தும் ஓர் அளபுருவை நீக்குதல்: பலகம் முதலில் அதன் மதிப்பை அவற்றில் எழுத வழங்கும். ஒரு பரிமாணக் கட்டுப்பாட்டின் பெயர் கட்டுப்பாட்டை நீக்குவதால் நீக்கப்படும்.
