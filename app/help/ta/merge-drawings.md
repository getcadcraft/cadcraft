இருவர் ஒரே வரைபடத்தைத் திருத்துகின்றனர். அவர்கள் வெவ்வேறு பொருட்களை மாற்றியிருந்தால், இணைப்பு தானாக நடக்கலாம்: கையால் மீண்டும் செய்ய எதுவுமில்லை.

## இது எப்படி வேலை செய்கிறது

CadCraft நீங்கள் வரையும் ஒவ்வொரு பொருளுக்கும் ஒரு குறுகிய **விசையை** கொடுக்கிறது, அது ஒருபோதும் மாறாது, இரண்டு பொருட்களுக்கு ஒருபோதும் கொடுக்கப்படாது. அது DWG அல்லது DXF இல் பொருளுடன் சேமிக்கப்படுகிறது (பிற நிரல்கள் வைத்திருக்கும் கூடுதல் தரவாக). இணைப்பு பொருட்களை அவற்றின் நிலையால் அல்ல, அந்த விசையால் தேடுகிறது, ஏனெனில் ஒவ்வொரு நிரலும் சேமிக்கும்போது நிலைகளை மறுஎண்ணிடுகிறது. நீங்கள் ஒருபோதும் இணைக்காவிட்டால், {{ui:Settings}} › {{ui:CadCraft}} › இணைப்புக்கு ஏற்ற கோப்புகள் இல் இதை அணைக்கலாம்; கோப்புகள் சுமார் 10 சதவீதம் சிறியதாகும்.

விசைகள் இருப்பதற்கு முன் சேமிக்கப்பட்ட வரைபடம் இன்னும் இணையும்: அதன் பொருட்கள் கோப்பில் அவற்றின் இடத்திலிருந்து ஒரு விசையைப் பெறும், அதை அதைத் திறக்கும் அனைவருக்கும் அதே விசை கிடைக்கும்.

## அமைக்கவும்

Git க்கு ஒரு repository க்கு ஒருமுறை இரண்டு வரிகள் தேவை:

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# one time, on each computer
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

Git இல்லாமல், கையால் இயக்கவும்: `cadcraft merge <base> <ours> <theirs> -o <result>`. Fossil மற்றும் Mercurial அதே மூன்று கோப்புகளை அவற்றின் சொந்த இணைப்புக் கருவி அமைப்பில் எடுத்துக்கொள்ளும்.

## விதிகள்

- ஒரு பக்கம் மட்டும் மாற்றப்பட்ட பொருள் எடுத்துக்கொள்ளப்படும். இரு பக்கங்களிலும் ஒரே மாற்றம் ஒருமுறை எடுத்துக்கொள்ளப்படும்.
- ஒரு பண்பு இரண்டு வழிகளில் மாற்றப்பட்டால் அது **முரண்பாடு**: உங்கள் பக்கம் இருக்கும், அறிக்கை இரண்டு மதிப்புகளையும் பட்டியலிடும். முடிவைத் திறந்து, அந்தப் பொருளைப் பார்த்து, கைமுறையாக சரிசெய்யவும்.
- எந்தப் பக்கத்திலாவது சேர்க்கப்பட்ட பொருள் வைக்கப்படும். ஒரு பக்கத்தில் நீக்கப்பட்டு மறுபக்கம் மாறாத பொருள் நீக்கப்படும். ஒரு பக்கத்தில் நீக்கப்பட்டு மறுபக்கம் மாற்றப்பட்டால்: நீக்கப்பட்டு அறிக்கை செய்யப்படும்.
- அடுக்குகள், தொகுதிகள், உரை மற்றும் பரிமாணப் பாணிகள், தாள்கள் மற்றும் பெயரிட்ட காட்சிகள் அதே வழியில் இணையும். கட்டுப்பாடுகள் அவை பெயரிடும் பொருட்களைப் பின்பற்றும்.
- முடிவு உங்கள் கோப்பின் அதே கோப்பு வடிவத்திலும் பதிப்பிலும் எழுதப்படும்.

இணைக்கப்படாதவை: பொருட்கள் வரையப்படும் வரிசை உங்களுடையது, பின்னர் மறுபக்கம் சேர்த்த பொருட்கள். இரு பக்கங்களிலும் ஒரே தொகுதி வரையறையின் மாற்றங்கள் ஒரு முரண்பாடு, ஒருபோதும் கலக்கப்படாது. எதுவும் பதிவேற்றப்படுவதில்லை; எல்லாம் உங்கள் கணினியிலேயே இயங்கும்.
