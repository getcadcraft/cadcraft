CadCraft வீல் உள்ள சுட்டிக்காக வடிவமைக்கப்பட்டுள்ளது. எல்லாமே டிராக்பேடுடனும் வேலை செய்யும், சில பழக்கங்களைக் கற்க வேண்டும். தொடுதிரைகள் தேர்ந்தெடுப்பதற்கு வேலை செய்யும், சில வரம்புகளுடன்.

## வீல் சுட்டி

- **பெரிதாக்கு:** வீலை உருட்டவும். வரைபடம் குறுக்குக் குறியைச் சுற்றிப் பெரிதாகும், எனவே நீங்கள் பார்க்க விரும்புவதைச் சுட்டிக் காட்டவும்.
- **நகர்த்து:** வீலை அழுத்திப் பிடித்து இழுக்கவும், அல்லது வலது பொத்தானால் இழுக்கவும்.
- **எல்லாவற்றுக்கும் பெரிதாக்கு:** வீலை இருமுறை கிளிக் செய்யவும், அல்லது {{ui:Extents}} ஐக் கிளிக் செய்யவும்.
- **முந்தைய காட்சிக்குத் திரும்பு:** காட்சிக் குழுவில் {{ui:Previous}} ஐக் கிளிக் செய்யவும், அல்லது `Z`, {{key:Enter}}, `P`, {{key:Enter}} தட்டச்சு செய்யவும். வீல் படிகளின் தொடர் ஒரு காட்சியாகக் கணக்கிடப்படும், எனவே ஒரு {{ui:Previous}} அதைச் செயல்தவிர்க்கும். நீங்கள் திரும்பும் காட்சிகளை {{cmd:NAMEDVIEW}} (`NV`) மூலம் சேமிக்கவும்.
- **Enter:** வலது-கிளிக் செய்யவும்.

## டிராக்பேடு

:::mac
- **நகர்த்து:** டிராக்பேடில் இரண்டு விரல்களை எந்தத் திசையிலும் நகர்த்தவும்: வரைபடம் உங்கள் விரல்களைப் பின்தொடரும். இரண்டு விரல் கிளிக்கை அழுத்திப் பிடித்தும் இழுக்கலாம் (வலது-பொத்தான் இழுப்பு).
- **பெரிதாக்கு:** இரண்டு விரல்களால் கிள்ளவும். பெரிதாக்கம் குறுக்குக் குறியைப் பின்தொடரும்.
- **வலது-கிளிக் (Enter):** இரண்டு விரல்களால் கிளிக் செய்யவும். எதுவும் நடக்கவில்லை என்றால் **System Settings** இல், பிறகு **Trackpad** இல் "Secondary click" ஐ இயக்கவும். Control-கிளிக் CadCraft இல் வலது-கிளிக்குப் பதிலாக சாதாரணக் கிளிக்காகக் கருதப்படலாம், எனவே இரண்டு விரல் கிளிக்கைப் பயன்படுத்தவும்.
- **ஒரு பகுதிக்குப் பெரிதாக்கு:** காட்சிக் குழுவில் {{ui:Window}} ஐக் கிளிக் செய்து இரண்டு மூலைகளைக் கிளிக் செய்யவும்.
:::

:::windows linux
- **நகர்த்து:** டச்பேடில் இரண்டு விரல்களை எந்தத் திசையிலும் நகர்த்தவும்: வரைபடம் உங்கள் விரல்களைப் பின்தொடரும். வலது பொத்தானை அழுத்திப் பிடித்தும் இழுக்கலாம்.
- **பெரிதாக்கு:** இரண்டு விரல்களால் கிள்ளவும். பெரிதாக்கம் குறுக்குக் குறியைப் பின்தொடரும்.
- **வலது-கிளிக் (Enter):** இரண்டு விரல்களால் கிளிக் செய்யவும், அல்லது உங்கள் டச்பேடு அமைப்புகளைப் பொறுத்து டச்பேடின் கீழ்-வலது மூலையைக் கிளிக் செய்யவும்.
- **ஒரு பகுதிக்குப் பெரிதாக்கு:** காட்சிக் குழுவில் {{ui:Window}} ஐக் கிளிக் செய்து இரண்டு மூலைகளைக் கிளிக் செய்யவும்.
:::

{{key:Space}} ஐ அழுத்திப் பிடித்து இழுப்பது CadCraft இல் **நகர்த்தாது**: {{key:Space}} என்பது Enter.

வீல் சுட்டி இன்னும் ஒரு படியாகப் பெரிதாக்கும். வீல் போலவே முழுப் படிகளில் உருட்டலை அனுப்பும் டச்பேடு, நகர்த்துவதற்குப் பதிலாக இரண்டு-விரல் உருட்டலால் பெரிதாக்கும்: சிறிது வெளியே பெரிதாக்கு, நீங்கள் விரும்பும் பகுதியைச் சுட்டிக் காட்டு, பிறகு மீண்டும் உள்ளே பெரிதாக்கு. 3D தாவல் அதன் சொந்த டிராக்பேடு நகர்வுகளை வைத்திருக்கும் (பார்க்கவும் [3D இல் மாதிரி](topic:3d-solids#look-around)).

## தொடுதிரைகளும் டேப்லெட்களும்

CadCraft ஒரு விரலை சுட்டிக் கிளிக்காகப் படிக்கும்:

- ஒரு தொடுதல் ஒரு புள்ளியை அல்லது பொருளைத் தேர்ந்தெடுக்கும், அல்லது தேர்வு செய்யும்.
- வெற்று இடத்தில் ஒரு விரலை இழுத்தால் லாஸ்ஸோ வரையப்படும் (வலதுபுறம் முதலில் நகர்த்தினால் சாளரம், இடதுபுறம் முதலில் நகர்த்தினால் குறுக்குத் தேர்வு; பார்க்கவும் [லாஸ்ஸோ தேர்வு](topic:lasso-selection)).
- {{cmd:TRIM}} மற்றும் {{cmd:EXTEND}} இல், துண்டுகளின் வழியாக ஒரு விரலை இழுத்தால் அவை அனைத்தும் வெட்டப்படும் அல்லது நீட்டப்படும்.
- தேர்ந்தெடுக்கப்பட்ட பொருளின் பிடியை ஒரு விரலால் இழுத்தால் பிடி நகரும் (ஒரு விரலுக்காகப் பிடிகளும் தேர்வுப் பெட்டியும் பெரிதாக்கப்பட்டுள்ளன).
- **கிள்ளு:** இரண்டு விரல்களால் அவற்றுக்கு இடையேயுள்ள புள்ளியைச் சுற்றிப் பெரிதாக்கும்; இரண்டு விரல்களையும் ஒன்றாக நகர்த்தினால் **நகர்த்தும்**. இரண்டாவது விரல் முதல் விரல் தொடங்கியதை ரத்துசெய்யும், எனவே கிள்ளல் ஒருபோதும் குறி விடாது.
- **நீண்ட அழுத்தம்** (சுமார் அரை வினாடி அசையாமல் பிடித்தல்) ஒரு வலது-கிளிக்: {{key:Enter}}. அது ஒரு கட்டளையை முடிக்கும், ஒரு தேர்வை நிறைவு செய்யும், அல்லது கடைசிக் கட்டளையை மீண்டும் இயக்கும்.

கட்டளை வரிக்குக் கீழே ஒரு விசை வரிசை தோன்றும்: {{ui:Esc}}, {{ui:Undo}}, {{ui:Redo}}, டேப்லெட் விசைப்பலகை மறைக்கும் எழுத்துகள் (`@` `,` `<` `'` `"` `-`), {{ui:Snap}}, {{ui:Ortho}}, ஒரு விசைப்பலகைப் பொத்தான், மற்றும் பெரிய {{ui:Enter}}. கட்டளை அல்லது எண்ணைத் தட்டச்சு செய்ய விசைப்பலகைப் பொத்தானை (அல்லது கட்டளை வரியை) தட்டவும்.

தொடுதிரையில் சுட்டி மேல்-வட்டமிடல் இல்லை, எனவே ஒட்டுக் குறிகள் உங்கள் விரல் இருக்கும் இடத்தில் மட்டுமே தெரியும்.

:::touch
நீங்கள் ஒரு தொடுதிரையைப் பயன்படுத்துகிறீர்கள். விரைவுப் பார்வையைவிட அதிகமாக ஏதாவது செய்ய, இணைக்கப்பட்ட விசைப்பலகையும் சுட்டியோ டச்பேடோ CadCraft ஐ மிக எளிதாக்கும்.
:::

## உலாவிகள்

CadCraft Chrome, Edge, Firefox மற்றும் Safari இல், Mac, Windows மற்றும் Linux இல், ஒரே மாதிரி வேலை செய்யும். வேறுபாடுகள் சிறியவை:

| தலைப்பு | தெரிந்துகொள்ள வேண்டியது |
|---|---|
| DWG ஐத் திறத்தல் | பெரிய வரைபடங்கள் ஒவ்வொரு உலாவியிலும் படிக்க சில வினாடிகள் ஆகும்; அதுவரை நிலைப்பட்டை "படிக்கிறது …" எனக் காட்டும் |
| பதிவிறக்கங்கள் | ஒவ்வொரு உலாவியும் பதிவிறக்கங்கள் எங்கே செல்லும், முதலில் கேட்குமா என்பதை முடிவு செய்கிறது; பார்க்கவும் [உலாவிகளும் கணினிகளும்](common:browsers) |
| அச்சிடத் திற | PDF ஐ ஒரு புதிய தாவலில் திறக்கும். உலாவி பாப்-அப்களைத் தடுத்தால், CadCraft அதற்குப் பதிலாக PDF ஐப் பதிவிறக்கும் |
| F7 | Firefox கர்சர் உலாவலை வழங்கலாம்; இல்லை எனத் தேர்ந்தெடுக்கவும் |
| சேமிக்காத மாற்றங்களுடன் வெளியேறுதல் | ஒவ்வொரு உலாவியும் தனது சொந்த "தளத்திலிருந்து வெளியேறவா?" கேள்வியைக் காட்டும், அதை CadCraft மாற்ற முடியாது |

:::safari
Safari இல், {{ui:Open to print}} உடன் திறக்கப்பட்ட PDF தாவலில் காட்டப்படலாம், ஆனால் அச்சிடாது: **File**, பிறகு **Print** ஐப் பயன்படுத்தவும்.
:::

:::firefox
Firefox ஒவ்வொரு பதிவிறக்கத்திலும் என்ன செய்வது என்று கேட்கலாம். கோப்பைச் சேமிக்கத் தேர்ந்தெடுக்கவும், அல்லது Firefox அமைப்புகளில் Downloads கீழ் ஒருமுறை இதை மாற்றவும்.
:::
