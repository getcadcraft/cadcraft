குறுக்குவழிகள் உங்கள் கணினிக்காகக் காட்டப்படுகின்றன. Mac இல், கீழே உள்ள ஒவ்வொரு {{key:Mod}} குறுக்குவழியும் Command விசையைப் பயன்படுத்தும், Control விசையும் வேலை செய்யும். விசைகள் எப்படி எழுதப்படுகின்றன, Mac இல் F-விசைகளை எப்படிப் பயன்படுத்துவது என்பது [விசைகள், சுட்டிகள் மற்றும் டிராக்பேடுகள்](common:keys) இல் உள்ளது.

## கட்டளைகளைத் தட்டச்சு செய்தல்

| விசை | என்ன செய்கிறது |
|---|---|
| எந்த எழுத்து, இலக்கம் அல்லது குறியீடு | சுட்டி எங்கிருந்தாலும் கட்டளை வரிக்குச் செல்லும், பலகத்தில் உள்ள ஒரு பெட்டியில் கர்சர் இல்லாவிட்டால் |
| {{key:Enter}} | தட்டச்சு செய்ததை அனுப்புகிறது. வெற்று வரியில்: கடைசி கட்டளையை மீண்டும் இயக்கும், ஒரு கட்டளையை முடிக்கும், ஒரு தேர்வை முடிக்கும், அல்லது `<…>` இல் உள்ள இயல்புநிலையை ஏற்கும் |
| {{key:Space}} | {{key:Enter}} போலவே, CadCraft உரை கேட்கும்போது தவிர (உரை, தொகுதிப் பெயர்கள், பரிமாண உரை); அங்கே அது ஓர் இடைவெளியைத் தட்டச்சு செய்யும் |
| {{key:Esc}} | கட்டளையை ரத்துசெய்கிறது. கட்டளை இயங்காதபோது: பிடிப்பு நகர்த்தலை அல்லது தேர்வுப் பெட்டியை ரத்துசெய்கிறது, பின்னர் தேர்வை நீக்குகிறது |
| {{key:Tab}} | கட்டளை வரியின் வலதுபுறம் காட்டப்படும் பரிந்துரைக்கப்பட்ட கட்டளையை ஏற்கிறது. எதுவும் தட்டச்சு செய்யாமல், சுட்டி ஒன்றின்மேல் ஒன்று மேலிருக்கும் பொருட்களின் மீது இருந்தால்: அடுத்ததை அங்கே முன்னிலைப்படுத்துகிறது (அதைத் தேர்ந்தெடுக்க கிளிக் செய்யவும்) |
| {{key:Up}} {{key:Down}} | முன்பு நீங்கள் தட்டச்சு செய்த வரிகளின் வழியே செல்கிறது (கடைசி 100) |

## வரைதல் மற்றும் திருத்துதல்

| விசை | என்ன செய்கிறது |
|---|---|
| {{key:Mod+Z}} | கடைசி கட்டளையைச் செயல்தவிர்க்கிறது |
| {{key:Mod+Y}} அல்லது {{key:Mod+Shift+Z}} | மீண்டும்செய் |
| {{key:Mod+A}} | திறந்த தாவலில் நீங்கள் திருத்தக்கூடிய ஒவ்வொரு பொருளையும் தேர்ந்தெடுக்கிறது ({{cmd:SELECTALL}}). கட்டளை வரியில் நீங்கள் எதையாவது தட்டச்சு செய்திருந்தால், அது அந்த உரையைத் தேர்ந்தெடுக்கிறது |
| {{key:Delete}} | தேர்ந்தெடுத்த பொருட்களை அழிக்கிறது ({{cmd:ERASE}}), கட்டளை வரியில் நீங்கள் எதையாவது தட்டச்சு செய்யாவிட்டால் |
| {{key:Backspace}} | கட்டளை வரியில் கர்சர் இல்லாதபோது தேர்ந்தெடுத்த பொருட்களை அழிக்கிறது; கட்டளை வரியில் நீங்கள் தட்டச்சு செய்ததை நீக்குகிறது |
| {{key:Esc}} | கட்டளை இயங்காதபோது: தேர்வை நீக்குகிறது ({{cmd:DESELECT}}) |
| {{key:Mod+S}} | வரைபடத்தின் வடிவத்தில் (DWG அல்லது DXF) ஒரு நகலைச் சேமிக்கிறது |
| {{key:Mod+Shift+S}} | இவ்வாறு சேமி: DWG அல்லது DXF ஐத் தேர்ந்தெடுக்கவும், பின்னர் ஒரு நகலைச் சேமிக்கவும் |
| {{key:Mod+O}} | DWG அல்லது DXF ஐத் திறக்கிறது |
| {{key:Mod+P}} | PDF க்கு அச்சிடுகிறது |

செயல்தவிர், மீண்டும்செய், அனைத்தையும் தேர்ந்தெடு மற்றும் அச்சிடு ஒரு கட்டளை இயங்கும்போது எதையும் செய்யாது: முதலில் {{key:Esc}} ஐ அழுத்தவும்.

## நகலெடு, வெட்டு மற்றும் ஒட்டு

| விசை | என்ன செய்கிறது |
|---|---|
| {{key:Mod+C}} | தேர்வை இடைநிலைப் பலகைக்கு நகலெடுக்கிறது ({{cmd:COPYCLIP}}). எதுவும் தேர்ந்தெடுக்கப்படாவிட்டால்: CadCraft பொருட்களைக் கேட்கும் |
| {{key:Mod+X}} | வெட்டு: தேர்வை நகலெடுத்து, பின்னர் அழிக்கிறது ({{cmd:CUTCLIP}}) |
| {{key:Mod+V}} | ஒட்டு: நகல் கர்சரைப் பின்தொடரும்; அதை வைக்க கிளிக் செய்யவும் அல்லது ஒரு புள்ளியைத் தட்டச்சு செய்யவும் ({{cmd:PASTECLIP}}) |
| {{key:Mod+Shift+V}} | அதே இடத்தில் ஒட்டு: அது நகலெடுக்கப்பட்ட ஒருங்கிணைப்புகளில் ({{cmd:PASTEORIG}}) |
| {{key:Mod+D}} | நகலாக்கு: தேர்வின் நகல் சுட்டியுடன் நகரும்; வைக்க கிளிக் செய்யவும், {{key:Esc}} எதையும் விடாது ({{cmd:DUPLICATE}}) |

அதே செயல்கள் கருவிப்பட்டியின் {{ui:திருத்து}} குழுவிலும் ({{ui:நகலெடு}}, {{ui:ஒட்டு}}) அதன் {{ui:மேலும்}} பட்டியலிலும் உள்ளன. வேறொரு கட்டளை இயங்கும்போது, அதை முடிக்கவும் அல்லது முதலில் {{key:Esc}} ஐ அழுத்தவும்; நகல் கர்சரைப் பின்தொடரும்போது {{key:Mod+V}} அல்லது {{key:Mod+D}} ஐ மீண்டும் அழுத்தினால் மீண்டும் தொடங்கும். கட்டளை வரியில் நீங்கள் ஏதாவது தட்டச்சு செய்திருந்தால், அல்லது ஒரு கட்டளை உரை கேட்டால், இந்த விசைகள் அந்த உரையை நகலெடுக்கும், வெட்டும், ஒட்டும். [நகலெடு, ஒட்டு மற்றும் நகலாக்கு](topic:copy-paste) ஐப் பார்க்கவும்.

## நிலைமாற்றங்கள்

| விசை | நிலைமாற்றம் | நிலைப்பட்டைப் பொத்தான் |
|---|---|---|
| {{key:F3}} | பொருள் ஒட்டுகளை இயக்கு அல்லது அணை | {{ui:ஒட்டு}} |
| {{key:F7}} | கட்டத்தை இயக்கு அல்லது அணை | {{ui:கட்டம்}} |
| {{key:F8}} | செங்குத்து-கிடையை இயக்கு அல்லது அணை | {{ui:செங்குத்து-கிடை}} |
| {{key:F10}} | துருவப் பின்தொடரை இயக்கு அல்லது அணை | {{ui:துருவம்}} |
| {{key:F11}} | பொருள் ஒட்டு பின்தொடரை இயக்கு அல்லது அணை | {{ui:தடம்}} |
| {{key:F12}} | இயக்கவியல் உள்ளீட்டை இயக்கு அல்லது அணை | {{ui:Dyn}} |

:::mac
Mac இல், F3, F7 மற்றும் F8 பொதுவாக Mission Control மற்றும் ஊடக விசைகள். அவற்றுடன் **fn** ஐப் பிடிக்கவும், அல்லது System Settings இல் நிலையான செயல்பாட்டு விசைகளை இயக்கவும், [விசைகள், சுட்டிகள் மற்றும் டிராக்பேடுகள்](common:keys) இல் விவரிக்கப்பட்டபடி. நிலைப்பட்டைப் பொத்தான்கள் எப்போதும் வேலை செய்யும்.
:::

:::firefox
Firefox இல் F7 கேரட் உலாவலை இயக்கக் கேட்கலாம். **இல்லை** ஐத் தேர்ந்தெடுக்கவும், அது தொடர்ந்து கேட்டால் {{ui:கட்டம்}} பொத்தானைப் பயன்படுத்தவும்.
:::

## உதவி

| விசை | என்ன செய்கிறது |
|---|---|
| {{key:F1}} | இந்த உதவியைத் திறக்கிறது அல்லது மூடுகிறது, வரைபடத்தின் அருகே. கட்டளை இயங்கும்போதும் வேலை செய்யும், கட்டளை வரியை ஒருபோதும் அடையாது. |
| {{key:Esc}} | உதவிப் பலகத்தில் கர்சருடன்: தேடலை அழிக்கிறது, அல்லது பலகத்தை மூடுகிறது |

மேலே உள்ள பட்டியில் உள்ள {{ui:உதவி}} பொத்தான் {{key:F1}} போலவே செய்யும். உதவித் தேடல் பெட்டியில் நீங்கள் தட்டச்சு செய்யும்போது, எதுவும் கட்டளை வரியை அடையாது. CadCraft க்கு விசைகளைத் திருப்பித் தர வரைபடத்தில் கிளிக் செய்யவும்; பலகம் அருகே திறந்தே இருக்கும்.

:::mac
Mac விசைப்பலகையில், **fn** ஐப் பிடித்து F1 ஐ அழுத்தவும், அல்லது {{ui:உதவி}} ஐக் கிளிக் செய்யவும்.
:::

## திரை

| விசை | என்ன செய்கிறது |
|---|---|
| {{key:Ctrl+Shift+F}} | சாதாரண, முழுத்திரை, மற்றும் பட்டைகள் மறைக்கப்பட்ட முழுத்திரை ஆகியவற்றுக்கு இடையே சுழல்கிறது. இது ஒவ்வொரு கணினியிலும், Mac உட்பட, Control விசையைப் பயன்படுத்தும். |
| {{key:Left}} {{key:Right}} | வரைபடத்தின் கீழுள்ள ஒரு தாவல் கவனம் பெற்றிருந்தால்: முந்தைய அல்லது அடுத்த தாவல் |

முழுத்திரையில், உலாவி முதல் {{key:Esc}} ஐ முழுத்திரையிலிருந்து வெளியேற பயன்படுத்தலாம். கட்டளையை ரத்துசெய்ய {{key:Esc}} ஐ மீண்டும் அழுத்தவும்.

## உரையாடல்கள்

| விசை | என்ன செய்கிறது |
|---|---|
| {{key:Esc}} | உரையாடலை மூடுகிறது ({{ui:PDF க்கு அச்சிடு}}, அல்லது "சேமிக்காத மாற்றங்கள்" போன்ற கேள்வி, அங்கே அது {{ui:ரத்துசெய்}} ஐக் குறிக்கும்) |
| {{key:Tab}} | உரையாடலின் அமைப்புகளுக்கும் பொத்தான்களுக்கும் இடையே நகர்கிறது |

உரையாடல் திறந்திருக்கும்போது, வரைபடத்தின் விசைகள் அணைக்கப்படும்.

## பலகப் புலங்கள்

வலது அல்லது இடது பலகத்தில் உள்ள ஒரு பெட்டியில்:

| விசை | என்ன செய்கிறது |
|---|---|
| {{key:Enter}} | மதிப்பைப் பயன்படுத்தி பெட்டியை விட்டு வெளியேறுகிறது |
| {{key:Esc}} | பழைய மதிப்பை மீட்டெடுத்து பெட்டியை விட்டு வெளியேறுகிறது |
| {{key:Tab}} | பயன்படுத்தி அடுத்த பெட்டிக்கு நகர்கிறது |

ஒரு பெட்டியில் கர்சர் இருக்கும்போது, எழுத்துகள் கட்டளை வரிக்குப் பதிலாக அதிலேயே தட்டச்சு ஆகும்.

## உலாவி வைத்திருக்கும் விசைகள்

{{key:Mod+N}}, {{key:Mod+W}} மற்றும் {{key:Mod+T}} எப்போதும் உலாவிக்குச் சொந்தமானவை. CadCraft அவற்றைப் பயன்படுத்தாது: புதிய வரைபடத்திற்கு {{ui:புதிய}} ஐப் பயன்படுத்தவும் அல்லது `NEW` எனத் தட்டச்சு செய்யவும். CadCraft இன் இடைநிலைப் பலகை அதன் சொந்தம்: {{key:Mod+C}} மற்றும் {{key:Mod+V}} பொருட்களை CadCraft வரைபடங்களுக்கும் தாவல்களுக்கும் இடையே நகலெடுக்கும், மற்ற நிரல்களுக்கோ அவற்றிலிருந்தோ அல்ல.

:::mac
{{key:Mod+Y}} மீண்டும்செய்வதற்குப் பதிலாக உங்கள் உலாவியின் வரலாற்றைத் திறந்தால், {{key:Mod+Shift+Z}} அல்லது {{ui:மீண்டும்செய்}} பொத்தானைப் பயன்படுத்தவும்.
:::

## நகர்த்து எங்கே உள்ளது

நகர்த்து என்பது `MOVE` கட்டளை ({{key:M}} விசை): பொருட்களைத் தேர்ந்தெடுக்கவும், பின்னர் ஓர் அடிப்படைப் புள்ளியையும் இரண்டாவது புள்ளியையோ தட்டச்சு செய்த தூரத்தையோ கொடுக்கவும். `ALIGN` மற்றும் `DISTRIBUTE` இங்கும் உள்ளன. BimCraft கட்டிடக் கூறுகளில் அதே வேலைகளுக்கு அதே பெயர்களைப் பயன்படுத்துகிறது, ஆனால் அதன் {{key:M}} அளவிடு ஆகும்: அதன் நகர்த்து {{key:Shift+M}} ஆகும்.
