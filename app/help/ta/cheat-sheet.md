குறுகிய பெயரை (மாற்றுப்பெயரை) தட்டச்சு செய்து Enter ஐ அழுத்துங்கள், அல்லது கருவியைச் சொடுக்குங்கள். Esc ரத்து செய்யும். காலி வரியில் Enter, கடைசிக் கட்டளையை மீண்டும் செய்யும்.

**அச்சிட:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (ஒரு A4 பக்கம்; Letter தாளில் "fit to page" உடன் அச்சிடுங்கள்).

## வரைதல்

| தட்டச்சு | கட்டளை | செய்வது |
|---|---|---|
| `L` | {{cmd:LINE}} | நேர்க்கோடுகளை வரையும் |
| `PL` | {{cmd:PLINE}} | இணைந்த கோடு, வில் சங்கிலியை வரையும் |
| `C` | {{cmd:CIRCLE}} | வட்டத்தை வரையும் (மையமும் ஆரமும்) |
| `A` | {{cmd:ARC}} | வில்லை வரையும் |
| `REC` | {{cmd:RECTANG}} | இரு மூலைகளிலிருந்து செவ்வகத்தை வரையும் |
| `POL` | {{cmd:POLYGON}} | சீரான பலகோணத்தை வரையும் |
| `EL` | {{cmd:ELLIPSE}} | நீள்வட்டத்தை வரையும் |
| `DT` | {{cmd:TEXT}} | ஒரு வரி உரையை எழுதும் |
| `T` | {{cmd:MTEXT}} | மடிந்து செல்லும் உரையை (பத்தி) எழுதும் |
| `H` | {{cmd:HATCH}} | ஒரு பகுதியை வடிவத்தால் நிரப்பும் |

## மாற்றுதல்

| தட்டச்சு | கட்டளை | செய்வது |
|---|---|---|
| `M` | {{cmd:MOVE}} | பொருட்களை நகர்த்தும் |
| `CO` | {{cmd:COPY}} | பொருட்களை நகலெடுக்கும் |
| `RO` | {{cmd:ROTATE}} | பொருட்களை ஒரு புள்ளியைச் சுற்றித் திருப்பும் |
| `SC` | {{cmd:SCALE}} | பொருட்களைப் பெரிதாக்கும் அல்லது சிறிதாக்கும் |
| `MI` | {{cmd:MIRROR}} | பொருட்களை ஒரு கோட்டின் குறுக்கே புரட்டும் |
| `O` | {{cmd:OFFSET}} | ஒரு தூரத்தில் இணையான நகலை வரையும் |
| `TR` | {{cmd:TRIM}} | பொருட்களை மற்றவை குறுக்கிடும் இடம் வரை வெட்டும் |
| `EX` | {{cmd:EXTEND}} | பொருட்களை மற்றவை வரை நீட்டும் |
| `F` | {{cmd:FILLET}} | மூலையை வில்லால் வட்டமாக்கும் |
| `CHA` | {{cmd:CHAMFER}} | மூலையை நேர்விளிம்பால் வெட்டும் |
| `E` | {{cmd:ERASE}} | பொருட்களை நீக்கும் |
| `X` | {{cmd:EXPLODE}} | தொகுதி அல்லது பலகோட்டை அதன் பாகங்களாகப் பிரிக்கும் |
| `S` | {{cmd:STRETCH}} | குறுக்குத் தேர்வுச் சாளரத்துக்குள் உள்ள முனைகளை நகர்த்தும் |
| `AR` | {{cmd:ARRAY}} | கட்டமாக அல்லது வட்டமாக நகலெடுக்கும் |
| `J` | {{cmd:JOIN}} | கோடுகளையும் வில்களையும் ஒரே பொருளாக இணைக்கும் |
| `BR` | {{cmd:BREAK}} | பொருளை இரண்டாக வெட்டும், அல்லது ஒரு துண்டை எடுக்கும் |

## பரிமாணம்

|---|---|---|

| `DAL` | {{cmd:DIMALIGNED}} | சாய்ந்த கோடு வழியே பரிமாணமிடும் |
| `DRA` | {{cmd:DIMRADIUS}} | ஆரத்தைப் பரிமாணமிடும் |
| `DAN` | {{cmd:DIMANGULAR}} | கோணத்தைப் பரிமாணமிடும் |

## காட்சியும் விசாரணையும்

| தட்டச்சு | கட்டளை | செய்வது |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | பெரிதாக்கும், சிறிதாக்கும், அல்லது அனைத்தையும் காட்டும் (E) |
| `DI` | {{cmd:DIST}} | தூரத்தையும் கோணத்தையும் அளவிடும் |
| `LI` | {{cmd:LIST}} | ஒரு பொருளின் விவரங்களைக் காட்டும் |
| `MA` | {{cmd:MATCHPROP}} | ஒரு பொருளின் தோற்றத்தை மற்றவற்றுக்கு நகலெடுக்கும் |

| `SAVE` | {{cmd:SAVE}} | வரைபடத்தைச் சேமிக்கும் |

## விசைகள்

Ctrl (Mac இல் Cmd): Z செயல்தவிர் · Y மீண்டும்செய் · S சேமி · P அச்சிடு.  F3 பொருள் ஒட்டு · F8 செங்குத்து-கிடை · F10 துருவம்.  Space அல்லது Enter கடைசிக் கட்டளையை மீண்டும் செய்யும் · சக்கரம் பெரிதாக்கும் · சக்கரத்தை இழுத்தால் நகர்த்தும்
