## Адкрыццё файлаў

| Паведамленне або праяўленне | Прычына | Выпраўленне |
|---|---|---|
| «CadCraft адкрывае чарцяжы DWG і DXF. «…» — гэта не адно і не другое.» | Файл не з’яўляецца `.dwg` або `.dxf`. | Адкрыйце сам файл чарцяжа. PDF можна імпартаваць (Адкрыць запытае: імпарт або прымацаванне, гл. [PDF underlays](topic:pdf-underlay)); малюнкі дадаюцца з `IMAGEATTACH`. |
| «Гэты бінарны DXF абрываецца ў сярэдзіне аб’екта: файл абрэзаны або пашкоджаны.» | Бінарны DXF заканчваецца раней свайго канца. | Увядзіце RECOVER, каб адкрыць тое, што можна прачытаць, або папрасіце файл зноў. |
| «Гэта не чытальны DXF (хібны код групы ў радку …).» | DXF пашкоджаны або насамрэч не DXF. | Папрасіце файл зноў або DWG. |
| «Гэты чарцёж не ўдалося прачытаць. Ён можа быць пашкоджаны або захаваны ў версіі, якую чытач пакуль не падтрымлівае (…).» | Чытач DWG не змог яго прачытаць. | Папрасіце DWG, захаваны ў больш ранняй версіі, або DXF. |
| «Гэты чарцёж створаны ў AutoCAD R11 / R12 (DWG AC1009), старэйшы, чым CadCraft умее чытаць …» | Файлы DWG з Release 12 і ранейшых выкарыстоўваюць фармат, які CadCraft не чытае. | У праграме, у якой ён створаны, захавайце яго як DXF (любая версія) або як больш новы DWG і адкрыйце яго. Уласны {{ui:Save as}} у CadCraft прапануе DXF R12 для праграм, якія патрабуюць гэты стары фармат. |
| «Не ўдалося адкрыць …», за якім ідзе паведамленне пра сетку, пры першым DWG | Чытач DWG не змог загрузіцца: вы па-за сеткай, і CadCraft не захаваны для працы па-за сеткай, або злучэнне перарвалася. | Падключыцеся да сеткі і паўтарыце спробу або адкрыйце DXF. Пстрыкніце {{ui:Save for offline}} і дачакайцеся «Offline ready», каб DWG-файлы адкрываліся па-за сеткай у наступны раз. Гл. [Working offline](common:offline). |
| Кнопка па-за сеткай паказвае «Не ўдалося захаваць» | Некаторыя файлы не загрузіліся. | Праверце злучэнне і пстрыкніце кнопку, каб паўтарыць спробу. |
| Кнопка па-за сеткай паказвае «Па-за сеткай недаступна» | Прыватныя вокны і некаторыя кіраваныя камп’ютары не могуць захоўваць копію для працы па-за сеткай. | Выкарыстоўвайце звычайнае акно або працуйце ў сетцы. |
| CadCraft не адкрываецца без злучэння | Ён не быў захаваны для працы па-за сеткай у гэтым браўзеры, або браўзер яго ачысціў. | Калі будзеце ў сетцы наступным разам, пстрыкніце {{ui:Save for offline}} і дачакайцеся «Offline ready». |
| Чарцёж адкрыўся, але часткі адсутнічаюць | Аб’екты, якія CadCraft пакуль не можа намаляваць, або пласты, якія ў файле выключаны ці замарожаны. | Прачытайце «About this file» у левай панэлі. Праверце панэль {{ui:Layers}}. |
| Тэкст пераносіцца на два радкі | CadCraft малюе тэкст шрыфтам у стылі Helvetica, які шырэйшы за некаторыя шрыфты CAD. | Скараціце тэкст у {{ui:Properties}} або змірыцеся з дадатковым радком. |
| Круг паказваецца як эліпс, або люстраваны тэкст чытаецца правільна | Аб’ект быў намаляваны ў нахіленай плоскасці або гледжаны знізу ў праграме, якая стварыла файл. CadCraft паказвае яго гледжаным зверху, як у плане гэтай праграмы; тэкст застаецца чытэльным. | Нічога выпраўляць не трэба. Каб убачыць яго так, як у іншай праграме, папрасіце спрошчаны чарцёж або чарцёж з аб’ектамі, намаляванымі зверху. |
| Блок, круг або памер знаходзіцца не там, дзе ў праграме, якая стварыла файл | Выпадак у чарцяжы, які CadCraft чытае няправільна. | Паведаміце нам у Discord, з файлам, калі можаце яго падзяліцца. |

## Камандны радок

| Паведамленне або праяўленне | Прычына | Выпраўленне |
|---|---|---|
| «Невядомая каманда "…". Увядзіце HELP для спісу.» | Няма каманды або псеўданіма з такой назвай. | Увядзіце `HELP` або гл. [Command reference](topic:commands). Некаторыя знаёмыя каманды [пакуль не створаны](topic:not-built-yet). |
| «Няма такой каманды» побач з камандным радком пры наборы | Тое, што вы ўвялі, пакуль нічога не адпавядае. | Працягвайце набіраць або праверце напісанне. |
| «Патрабуецца кропка або ключавое слова параметра.» | Тое, што вы ўвялі, не з’яўляецца кропкай або параметрам. | Праверце фармат: `x,y`, `@dx,dy`, `@d<a` або адзін лік. Гл. [Coordinate and distance entry](topic:coordinate-entry). |
| «Патрабуецца дадатны лік або дзве кропкі.» | Адлегласць была адмоўнай або не лікам. | Увядзіце дадатны лік або пстрыкніце дзве кропкі. |
| «Патрабуецца вугал у градусах або дзве кропкі.» | Вугал не быў лікам. | Увядзіце градусы простым лікам. |
| «Патрабуецца лік.» | Чакаўся лік. | Увядзіце толькі лічбы. |
| «Няправільнае ключавое слова параметра.» | Літары не супадаюць з параметрам. | Увядзіце вялікія літары, паказаныя ў квадратных дужках. |
| `*Cancel*` | Вы націснулі {{key:Esc}} або {{key:Enter}} там, дзе патрабавалася кропка. | Запусціце каманду зноў. |
| Набор не даходзіць да каманднага радка | Поле ў панэлі або дыялогу мае курсор. | Націсніце {{key:Enter}} або {{key:Esc}}, або пстрыкніце па чарцяжы. |
| Каманда выкарыстоўвае аб’екты, якія вы не выбіралі | Яны былі выбраны перад яе запускам. | Націсніце {{key:Esc}} перад камандай. |
| Лінія пайшла не туды | `x,y` — абсалютная кропка. | Выкарыстоўвайце `@dx,dy` для адносных кропак. |
| «Спачатку завершыце або скасуйце бягучую каманду (Esc).» | Вы націснулі {{key:Mod+S}}, пакуль каманда выконвалася. | Націсніце {{key:Esc}}, затым захавайце. |
| «Не ўдалося захаваць як DWG (AutoCAD 2000): … Паспрабуйце «Захаваць як», затым DXF.» | Нешта ў чарцяжы не магло быць запісана як DWG. | Націсніце {{key:Mod+Shift+S}}, абярыце {{ui:DXF R12}} і пстрыкніце {{ui:Save}}. |
| «Не захавана.» | Вы закрылі дыялог {{ui:Save a copy as}} з {{ui:Cancel}} або {{key:Esc}}. | Націсніце {{key:Mod+Shift+S}} яшчэ раз і пстрыкніце {{ui:Save}}. |

## Рэдагаванне

| Паведамленне або праяўленне | Прычына | Выпраўленне |
|---|---|---|
| Аб’ект не выбіраецца | Яго пласт заблакаваны, выключаны або замарожаны; або вы на аркушы, і гэта мадэль унутры відавога акна. | Разблакіруйце пласт або перайдзіце на ўкладку {{ui:Model}}. |
| «Нічога не знойдзена там.» | Пад пстрыканнем няма аб’екта. | Павялічце і пстрыкніце па самой лініі. |
| «Нічога не перасякае той аб’ект у гэтым месцы.» | {{cmd:TRIM}} не знайшла аб’екта, які перасякае кавалак, які вы выбралі. | Праверце, ці сапраўды лінія абрэзкі яго перасякае. |
| «Не магу абрэзаць гэты аб’ект.» | Абрэзка працуе з лініямі, дугамі, акружнасцямі і палінямі. | Спачатку разбярыце блокі або сатрыце і намалюйце зноў. |
| «Няма мяжы ў гэтым напрамку.» | {{cmd:EXTEND}} не знайшла, да чаго дацягнуць. | Пстрыкніце бліжэй да канца, які павінен вырасці. |
| «Не магу зрушыць гэты аб’ект.» | Зрушэнне працуе з лініямі, дугамі, акружнасцямі і палінямі. | Спачатку разбярыце яго або намалюйце паралельную лінію. |
| «Не магу зрушыць так далёка.» | Зрушэнне перавярне фігуру наадварот. | Выкарыстоўвайце меншую адлегласць. |
| «Радыус занадта вялікі.» або «Адлегласць занадта вялікая.» | Скругленне або фаска выйдуць за канец лініі. | Задайце меншы радыус з `R` або меншыя адлегласці з `D`. |
| «Абрэзаць назад можна толькі першы або апошні сегмент адкрытай паліні.» | Вугал уразаўся б у сярэдзіну паліні. | Выберыце два сегменты паліні побач адзін з адным або выкарыстоўвайце `P` для кожнага вугла. |
| «Выберыце другую, іншую лінію.» | Другі выбар быў той жа лініяй або не лініяй. | Выберыце іншую лінію. |
| «Разбіць можна толькі паліні, блокавыя спасылкі і памеры.» | У выбары не было чаго разбіваць. | Выберыце паліню, блокавую спасылку або памер. |
| «Гэта бягучы пласт. Спачатку зрабіце бягучым іншы пласт.» | Вы спрабавалі выключыць бягучы пласт. | Пстрыкніце назву іншага пласта, затым выключыце гэты. |
| «Пласт з назвай … ужо існуе» | Назвы пластоў павінны быць унікальнымі. | Абярыце іншую назву. |
| «Няма чаго адрабіць.» | Больш няма чаго адмяняць, або вы адкрылі ці пачалі чарцёж (гэта ачышчае гісторыю). | — |

## Памеры і блокі

| Паведамленне або праяўленне | Прычына | Выпраўленне |
|---|---|---|
| Тэкст і стрэлкі памераў маленькія або вялікія | Памеры задаюцца ў адзінках чарцяжа; агульны маштаб не падыходзіць да чарцяжа. | Задайце {{cmd:DIMSCALE}} роўным маштабу вываду; гл. [Set dimension sizes](topic:dimension-settings). |
| «Пстрыкніце кропку ўнутры вугла, які хочаце вымераць.» | Месца вуглавога памеру ляжыць на адной з бакавых ліній. | Пстрыкніце ўнутры вугла. |
| «Гэтыя лініі паралельныя.» | У паралельных ліній няма вугла паміж імі. | Выберыце дзве лініі, якія сыходзяцца. |
| «Выберыце лінейны або выраўнаваны памер.» | {{cmd:DIMCONTINUE}} або {{cmd:DIMBASELINE}} патрабуе адпраўной кропкі. | Выберыце лінейны або выраўнаваны памер. |
| «У гэтым чарцяжы пакуль няма блокаў: F устаўляе з файла, L — з бібліятэкі …» | У чарцяжы няма ўласных блокаў. | Увядзіце `F` або `L` або стварыце блок з {{cmd:BLOCK}}. |
| «Няма блока з назвай "…".» | Назва няправільная. | Паведамленне пералічвае блокі, якія ёсць. |
| «Назва блока не можа пачынацца з * або выкарыстоўваць …» з пералікам знакаў | У назве ёсць знак, які блокі не могуць выкарыстоўваць. | Выкарыстоўвайце літары, лічбы, `-` і `_`. |
| «Блок не можа ўтрымліваць сам сябе.» | Выбар змяшчае спасылку на блок, які вы ствараеце. | Выключыце гэтую спасылку. |
| «Аб’екты не выбраны; нічога не створана.» | Вы націснулі {{key:Enter}} перад выбарам. | Запусціце {{cmd:BLOCK}} зноў і выберыце аб’екты. |
