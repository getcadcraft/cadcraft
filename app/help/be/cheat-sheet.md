Набярыце кароткую назву (псеўданім) і націсніце Enter, або націсніце інструмент. Esc скасоўвае. Enter на пустым радку паўтарае апошнюю каманду.

**Друкаваць:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (адна старонка A4; на паперы Letter друкуйце з «умясціць у старонку»).

## Чарчэнне

| Набраць | Каманда | Што робіць |
|---|---|---|
| `L` | {{cmd:LINE}} | Чарціць прамыя лініі |
| `PL` | {{cmd:PLINE}} | Чарціць злучаны ланцужок ліній і дуг |
| `C` | {{cmd:CIRCLE}} | Чарціць акружнасць (цэнтр і радыус) |
| `A` | {{cmd:ARC}} | Чарціць дугу |
| `REC` | {{cmd:RECTANG}} | Чарціць прамавугольнік па двух вуглах |
| `POL` | {{cmd:POLYGON}} | Чарціць правільны мнагавугольнік |
| `EL` | {{cmd:ELLIPSE}} | Чарціць эліпс |
| `DT` | {{cmd:TEXT}} | Напісаць адзін радок тэксту |
| `T` | {{cmd:MTEXT}} | Напісаць тэкст з пераносам (абзац) |
| `H` | {{cmd:HATCH}} | Запоўніць плошчу штрыхоўкай |

## Змяненне

| Набраць | Каманда | Што робіць |
|---|---|---|
| `M` | {{cmd:MOVE}} | Перамясціць аб’екты |
| `CO` | {{cmd:COPY}} | Капіяваць аб’екты |
| `RO` | {{cmd:ROTATE}} | Павярнуць аб’екты вакол кропкі |
| `SC` | {{cmd:SCALE}} | Зрабіць аб’екты большымі або меншымі |
| `MI` | {{cmd:MIRROR}} | Адлюстраваць аб’екты праз лінію |
| `O` | {{cmd:OFFSET}} | Чарціць паралельную копію на адлегласці |
| `TR` | {{cmd:TRIM}} | Абрэзаць аб’екты да месца перасячэння з іншымі |
| `EX` | {{cmd:EXTEND}} | Падоўжыць аб’екты да іншых |
| `F` | {{cmd:FILLET}} | Скруглiць вугал дугой |
| `CHA` | {{cmd:CHAMFER}} | Зрэзаць вугал прамой лініяй |
| `E` | {{cmd:ERASE}} | Выдаліць аб’екты |
| `X` | {{cmd:EXPLODE}} | Раскласці блок або паліналінію на часткі |

| `AR` | {{cmd:ARRAY}} | Капіяваць па сетцы або па крузе |
| `J` | {{cmd:JOIN}} | Злучыць лініі і дугі ў адзін аб’ект |
| `BR` | {{cmd:BREAK}} | Падзяліць аб’ект на дзве часткі або выдаліць кавалак |

## Клавішы

Ctrl (Cmd на Mac): Z адрабіць · Y паўтарыць · S захаваць · P друк. F3 прывязкі аб’ектаў · F8 ортарэжым · F10 палярны. Space або Enter паўтарае апошнюю каманду · кола змяняе маштаб · перацягванне кола панарамуе

Упершыню чарцяжыце? Увядзіце `TOUR` для кіраванага першага чарцяжа, прачытайце [Пачатак працы](topic:getting-started) або паглядзіце ўсе каманды ў [Камандах](topic:commands). Пераходзіце з іншага праграмнага забеспячэння для чарцяжоў? Гл. [Пераход з іншага праграмнага забеспячэння для чарцяжоў](topic:coming-from) і [карту команд](topic:command-map).
