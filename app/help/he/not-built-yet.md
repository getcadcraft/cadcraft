CadCraft נמצא בפיתוח. דף זה מפרט מה הגרסה הנוכחית אינה עושה, כדי שלא תצטרכו לחפש את זה. בכל פריט נכתב מה לעשות במקום זאת היום.

## קבצים ושמירה

| טרם נבנה | במקום זאת, היום |
|---|---|
| DWG של CadCraft שנבדק ב-AutoCAD עצמו | כל גרסה שנשמרה נקראת בחזרה על ידי שלוש תוכנות אחרות עם קוראי ה-DWG שלהן, וגם על ידי CadCraft. ראו [מה ה-DWG שומר ומה משתנה](topic:files#what-a-dwg-keeps-and-changes). |
| שמירת DXF חדש מגרסה 2000 | שמרו כ-DXF 2000, או כ-DWG עד AutoCAD 2018. |
| שמירה מעל הקובץ הפתוח בדפדפן | כל שמירה מורידה עותק חדש; החליפו את הקובץ הישן בעצמכם אם תרצו בכך. ב-CadCraft Studio, {{key:Mod+S}} כותב בחזרה אל הקובץ שפתחתם. |
| שמירה בענן וסנכרון בין מחשבים | CadCraft עדיין אינה שולחת את השמירות שלה לענן: שמרו את קובצי ה-DWG וה-DXF שלכם בתיקיות שלכם. ב-CadCraft Studio, [היסטוריה](topic:history) מציגה את גרסאות הענן של שרטוט שנשמר ממקום אחר, ואת עותקי השמירות שלכם במחשב הזה. |
| שכבות-על, ועריכה של שרטוט מקושר במקומו | צרפו את השרטוט כקישור וטענו אותו מחדש לאחר שינוי השרטוט האחר. קישור נשאר קישור כששומרים כ-DWG, ו-{{cmd:XCLIP}} חותך אותו. |
| תמונות ב-DXF; wipeout שמסתיר את מה שמתחתיו | DXF שומר תמונה כמסגרת שלה עם שם הקובץ; DWG שומר אותה כתמונה — ראו [תמונות בשרטוט](topic:pictures). wipeout מוצג כמסגרת שלו. |
| עריכת קווי הפניה מרובים עם קווי הפניה מעוקלים, עם קווי הפניה משני צדי התוכן, או עם בלוק שמסובב או מוקטן באופן לא אחיד | הם מצוירים כפי שהתוכנה האחרת ציירה אותם, ונעים כיחידה אחת. קווי הפניה מרובים עם קווי הפניה ישרים לנחיתה אחת, וטקסט או בלוק כתוכן, נכנסים לעריכה ({{cmd:MLEADEREDIT}}). |
| בטבלאות מתוכנות אחרות: תא שמכיל בלוק, עיצוב טקסט בתוך תא, גבולות וצבעים לכל תא בטבלת DXF, טבלה שמחולקת לעמודות | הטבלה נפתחת כטבלה הניתנת לעריכה ({{cmd:TABLEDIT}}) ומוצגת כפי שהתוכנה האחרת ציירה אותה עד שתערכו אותה; לאחר מכן CadCraft מצייר אותה מחדש מהתאים שלה: טקסט רגיל, נוסחאות כמו `=G3*H3` ו-`=Sum(I3:I9)`, יישור וגבהי טקסט. תא בלוק מתרוקן אז. טבלת DWG שלא נגעתם בה נשמרת בחזרה עם נתוני התאים שהגיעו איתה. |
| אובייקט טבלה אמיתי בקובץ DXF שנשמר | DWG שומר טבלה כטבלה שתוכנות אחרות יכולות לערוך. DXF שומר אותה כבלוק שמצייר אותה, עם הרשומה של CadCraft: CadCraft פותחת אותה שוב כטבלה; תוכנות אחרות רואות בלוק. טבלה שהוטה או הוקטנה באופן לא אחיד נשמרת כך גם ב-DWG. |
| העתקה והדבקה עם תוכנות אחרות | הלוח של CadCraft פועל בין שרטוטים ולשוניות של CadCraft באותו דפדפן, ולא עם תוכנות אחרות. שמרו כ-DWG או DXF ופתחו שם. ראו [העתקה, הדבקה ושכפול](topic:copy-paste). |

## שרטוט ועריכה

| טרם נבנה | במקום זאת, היום |
|---|---|
| דוגמאות קווקוו ש-CadCraft אינה מכילה, ומילויי מעבר צבעים בדיוק כפי שתוכנות אחרות צובעות אותם | קווקוו שנפתחו עם דוגמאות ש-CadCraft אינה מכילה מוצגים כגוון אחיד. מילוי מעבר צבעים ({{cmd:GRADIENT}}) מצויר בדרך של CadCraft לכל סוג: דומה לזו של תוכנות אחרות בסוגו, לא נקודה לנקודה. DWG 2004 ומאוחר יותר שומרים אותו כקווקוו מעבר צבעים אמיתי; בקובץ DXF 2000 או DWG 2000 רק CadCraft קוראת אותו בחזרה, ותוכנות אחרות רואות מילוי אחיד. דוגמאות נטענות מקובץ `.pat`, וקווקוו יכול להיות מקושר לגבולו ואז הוא עוקב אחריו: ראו [קווקוו ואזורי מילוי](topic:hatch). |
| סוגי קווים עם צורות או טקסט בתוכם, ועובי קו בקובץ DXF R12 שנשמר | צורות וטקסט בסוג הקו של קובץ מושמטים מהקווקווים שלו; שמרו כ-DWG כדי לשמור על עובי קו. |
| קווקוו עם דוגמה בקובץ DXF שנשמר | ל-R12 אין קווקוו: הם נשמרים כמתארים שלהם. שמרו כ-DWG כדי לשמור על הדוגמה. |
| מערכים שתוכנה אחרת יצרה או יכולה לערוך; שורות ורמות במערכי מסלול וקוטביים; מערך שעוקב אחרי עקומת המסלול שלו | מערך שנוצר עם ASsociative ({{cmd:ARRAY}}, {{cmd:ARRAYPATH}}; משתנה עם {{cmd:ARRAYEDIT}}) נשמר כהפניה לבלוק עם המספרים של CadCraft: תוכנות אחרות מציגות, מזיזות, מדפיסות ומפרקות אותו, אך אינן יכולות לשנות את הספירות שלו; ומערך שנוצר בתוכנה אחרת נפתח כאן כהפניה רגילה לבלוק. מערך מסלול שומר עותק של המסלול שלו: עריכת העקומה לאחר מכן אינה מזיזה את הפריטים. |
| חלונות תצוגה של גיליונות שנחתכו, מהתוכנות האחרות ואליהן | חלון תצוגה שנחתך עם {{cmd:VPCLIP}} או שנוצר עם {{cmd:MVIEW}} Polygonal או Object נשמר עם המתאר של CadCraft: תוכנות אחרות פותחות אותו כמלבן שמסביבו, וחלון תצוגה שנחתך בתוכנה אחרת נפתח כאן כמלבן שלו. DXF R12 שומר את המלבן בלבד. |
| {{cmd:STRETCH}} עם מצולע חוצה | השתמשו בחלון חוצה אחד או יותר. |
| {{cmd:PEDIT}} Edit vertex (קודקוד אחד בכל פעם בשורת הפקודה) | ידיות, ודפדפן הקודקודים בתוך מאפיינים (כל קודקוד, רוחבו והטיתו). שאר PEDIT כבר נבנה: ראו [ספליינים ופוליליינים](topic:splines). |
| {{cmd:BREAK}}, {{cmd:LENGTHEN}}, {{cmd:OFFSET}}, {{cmd:TRIM}}, {{cmd:EXTEND}}, {{cmd:FILLET}} ו-{{cmd:JOIN}} על אליפסות וספליינים | הפעילו {{cmd:EXPLODE}} על ספליין (או {{cmd:PEDIT}} עליו) כדי לקבל פוליליין שהפקודות האלה מקבלות. |
| עיגול פינה ושיפוע פינה בין מקטע קשת של פוליליין לבין המקטע הסמוך לו; עיגול פינה שמחבר קו לתוך פוליליין | הפעילו {{cmd:EXPLODE}} על הפוליליין, ואז עגלו את החלקים. קשת העיגול נוספת כאובייקט משלה. |
| חיתוך והארכה: אפשרות הפרויקט (3D) והארכת קצה קשת של פוליליין | חתכו במישור השרטוט; לקצה קשת, פרקו את הפוליליין או צירו את הקשת מחדש. |
| אובייקטי OLE: הכנסתם, הפעלתם או עריכתם; הצגת אלה שב-DWG במקום שבו הקובץ מציב אותם; תמונות metafile | ראו [תמונות](topic:pictures#objects-from-other-programs-ole). אובייקטים של DXF מוצגים כתמונת הביטמפ שלהם או כמסגרת עם תווית; אובייקטים של DWG נשמרים ולא מצוירים במקומם (OLELIST מפרט אותם ומציב עותק של תמונה במקום שתציינו). |
| הקלדת קודי עיצוב (מודגש, שברים מוערמים, צבעים לכל מילה) בטקסט פסקה; גופנים אחרים מלבד הגופן מסוג Helvetica; עמודות | עיצוב שהגיע בקובץ נשמר, מצויר ונשמר (ראו טקסט); טקסט פסקה חדש הוא בגובה ובצבע אחידים. |
| עריכת טקסט פסקה בזמן הסיבוב שלו | העורך נפתח ישר; הטקסט שומר על הסיבוב שלו. |
| קווי הפניה מרובים שנשמרים כאובייקטי קו הפניה מרובה ב-DXF | DWG שומר אותם כקווי הפניה מרובים, עם כל קו הפניה ובלוק כתוכן; DXF שומר את מה שהם מציירים (קווים, ראשי חץ, והטקסט או הבלוק). |
| בטבלאות ({{cmd:TABLE}}): טקסט שנשבר בתוך תא, טבלאות שמתפצלות לחלקים, סגנון טקסט משלו של סגנון טבלה וצבעים לכל סוג שורה בתיבת דו-שיח, קישור נתונים לגיליון אלקטרוני (`.xlsx`) או קישור שקורא את הקובץ בעצמו | טקסט של תא נשבר רק במקום שאתם שוברים אותו ({{key:Alt+Enter}}); הרחיבו את העמודה. {{cmd:DATALINK}} קורא קובץ `.csv`, ו-{{cmd:DATALINKUPDATE}} מבקש ממכם לבחור את הקובץ שוב. {{cmd:DATAEXTRACTION}} ו-{{cmd:COUNTTABLE}} יוצרים טבלה שאינה עוקבת אחרי השרטוט מעצמה: הפעילו אותם שוב (ספירה חיה: {{cmd:BOMTABLE}}). |
| הגדרות תכונה שנשמרות בנפרד בקובץ שנשמר (מחוץ לבלוק), תכונות בכמה שורות | שימו הגדרות תכונה בבלוק לפני השמירה: כשהן לבדן הן נשמרות כטקסט שמציג את התג. |
| שמירה ושחזור של מצבי שכבות (איזה שכבות דולקות) | השתמשו ב-{{cmd:LAYISO}} / {{cmd:LAYUNISO}}, או הדליקו וכבו שכבות ידנית. |
| בחירה בחלון ובמצולע חוצה, ומסנני בחירה שמורים | גדר (`F`), חלון, חוצה, הסרה (`R`), {{cmd:QSELECT}} לפי כלל. |

## גיליונות, מידות והדפסה

| טרם נבנה | במקום זאת, היום |
|---|---|
| שדות לקנה מידה של חלון תצוגה, לאובייקט בשם כמו שכבה או בלוק, לקישור (hyperlink), ולשדות של ערכת גיליונות מעבר למספר הגיליון ולשמו; שדות שנכתבים כאובייקטי שדה שתוכנות אחרות מעדכנות | {{cmd:FIELD}} כולל את התאריך, שם הקובץ, מספר הגיליון, שם וספירה, מאפייני השרטוט ({{cmd:DWGPROPS}}), שטח, אורך ומאפיינים אחרים של אובייקט, ונוסחאות, בטקסט, בתכונות ובתאי טבלה. תוכנה אחרת מציגה שדה של CadCraft כטקסט שקראה לאחרונה; CadCraft קוראת שדות תאריך, שם קובץ, מאפיין, גיליון וביטוי של תוכנה אחרת, ומשאירה את סוגי השדות האחרים כטקסט. קנה המידה של חלון תצוגה מוקלד ידנית. |
