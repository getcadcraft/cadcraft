## מה תלמדו

איך לתת לעוזר AI (או לסקריפט שכתבתם) להסתכל על שרטוט, להפעיל את הפקודות של CadCraft, להדפיס ולשמור, ואיך להחליט על מה מותר לו לגעת.

ל-CadCraft **אין AI משלה**, והתוכנה אינה שולחת דבר לשום מקום. אתם מביאים את העוזר: כל תוכנה שמדברת בפרוטוקול Model Context Protocol (MCP). CadCraft רק מעניקה לו כלים, ואתם בוחרים אילו.

יש שתי דרכים להיכנס:

- **השרטוט שפתוח לכם.** העוזר עובד בחלון הזה, לצדכם, דרך CadCraft Studio במחשב שלכם. זה התפקיד של {{ui:הגדרות}} › {{ui:CadCraft}} › {{ui:עוזרים}}.
- **שרטוטים במחשב שלכם, בלי לפתוח את התוכנה.** שרת ה-MCP של CadCraft ושורת הפקודה `cadcraft` קוראות וכותבות קבצי DWG ו-DXF בתיקיות שאתם מציינים. ראו "עבודה על קבצים בלי לפתוח את CadCraft" להלן.

## הפעלה

1. פתחו את {{ui:הגדרות}} (גלגל ההגדרות בשורת היישום, או {{key:Mod+,}}) ועברו לכרטיסייה {{ui:CadCraft}}.
2. תחת {{ui:עוזרים}}, סמנו **לאפשר לעוזרי AI ולסקריפטים להשתמש ב-CadCraft**. המתג כבוי עד שתפעילו אותו.
3. בחרו מה מותר לו לעשות. **קריאה** מסומנת בהתחלה; סמנו את האחרות רק כשאתם צריכים אותן.

| הרשאה | מה העוזר יכול לעשות |
|---|---|
| קריאה | לראות את השרטוט: לתאר אותו, להציג ולמצוא אובייקטים, לראות את הבחירה, לתאר את התצוגה ולצלם אותה, ולבדוק אותה מול כללי שכבות וכללי שרטוט |
| עריכה | להפעיל פקודות על השרטוט ולשנות את הבחירה. כל פעולה היא צעד אחד שאפשר לבטל |
| שמירה | לשמור את השרטוט (בשולחן העבודה, לקובץ שלו; בדפדפן, כהורדה) |
| ייצוא | להדפיס ל-PDF וליצור קבצים אחרים |

## לתת לו לעבוד עם קבצים בתיקיות שתבחרו

ב-CadCraft Studio עוזר יכול לפתוח, לשמור ולהדפיס קבצים לפי שם במקום להשתמש בחלונות הקבצים, אך רק בתוך התיקיות שתוסיפו תחת {{ui:עוזרים}} › {{ui:תיקיות שרשאים להשתמש בהן}}:

1. בחרו {{ui:הוספת תיקייה…}} ובחרו את התיקייה בתיבת הדו-שיח של Studio.
2. העוזר יכול עכשיו להציג את הקבצים שבה (`files_list`), לפתוח שרטוט (`drawing_open`), לשמור אותו שם בגרסת DWG או כ-DXF, להדפיס ל-PDF או לקובץ SVG, לטעון קובץ LISP, ולתת לפקודה את הקובץ שהיא מבקשת (`INSERT` `F`, `XATTACH`, קובץ נקודות), או לציין לאן הולך הקובץ של פקודה (ה-CSV של `COUNT`, `PUBLISH`).
3. {{ui:הסרה}} מסיר תיקייה מיד. נתיבים מחוץ לתיקיות האלה נדחים, וקובץ שכבר קיים מוחלף רק אם העוזר מבקש זאת או אם הוא עצמו כתב אותו.

פתיחה עדיין דורשת **קריאה**; כתיבת שרטוט דורשת **שמירה**; כל קובץ אחר דורש **ייצוא**.

כלים שמחוץ להרשאות שסימנתם אינם מוצעים לעוזר כלל. אם הוא מבקש אחד בכל זאת, CadCraft דוחה את הבקשה וכותבת אותה ביומן הפעילות. כיבוי המתג מנתק את כל החיבורים בבת אחת. {{ui:איפוס הגדרות CadCraft}} מכבה אותו גם כן.

## חיבור העוזר שלכם

העוזרים מתחברים דרך **CadCraft Studio** במחשב שלכם. Studio מפעילה שרת קטן שרק המחשב הזה יכול להגיע אליו (כתובת `127.0.0.1`), ושמוגן באסימון ש-Studio יוצרת בכל הפעלה. פתחו את Studio, בחרו {{ui:חיבור עוזר}}, והעתיקו את הכתובת ואת האסימון.

- בעוזר שלכם, הוסיפו שרת MCP מסוג HTTP עם הכתובת (היא נראית כך: `http://127.0.0.1:47615/mcp`) והכותרת `Authorization: Bearer <token>`. Studio מציגה את ההגדרות להדבקה.

{{ui:אסימון חדש}} ב-Studio גורם לכל עוזר מחובר להתחבר מחדש עם האסימון החדש. לעולם אל תשתפו את האסימון: מי שמחזיק בו יכול להשתמש באפליקציות שהפעלתם, כל זמן ש-Studio פועלת.

:::note
לשונית דפדפן אינה יכולה לפתוח חיבור לעוזר. באפליקציות שפועלות בדפדפן, המתג אינו משפיע עד שתשתמשו ב-CadCraft Studio במחשב שלכם.
:::

## אתם נשארים בשליטה

- **כל פעולה היא צעד ביטול אחד**, עם שם העוזר לפעולה, למשל "Assistant: LINE". לחצו {{key:Mod+Z}} כדי לבטל את הפעולה האחרונה של העוזר כולה.
- **אתם רואים מה הוא עושה.** הפקודות שלו מופיעות בהיסטוריית הפקודות עם **[Assistant]** לפניהן, והשרטוט מתצייר מחדש תוך כדי העבודה.
- **הוא ממתין לכם.** בזמן שאתם באמצע פקודה, העוזר יכול לקרוא אך לא לשנות את השרטוט; הוא מקבל הוראה לנסות שוב כשתסיימו.
- **אתם יודעים מתי הוא מחובר.** לחצן בשורת היישום מציג את שם העוזר כל עוד הוא מחובר. לחצו עליו כדי לראות מה מותר לו, או כדי **לנתק** אותו.
- **פעילות.** {{ui:הגדרות}} › {{ui:CadCraft}} › {{ui:עוזרים}} › {{ui:פעילות}} מציג כל קריאה: מתי, איזה כלי, אם בוצעה או נדחתה, וצעד הביטול שיצרה. {{ui:שמירת היומן}} שומר עותק.

## מה עוזר יכול לבקש

| כלי | הרשאה | מה הוא עושה |
|---|---|---|
| `app_info`, `drawing_describe`, `view_describe` | קריאה | שם השרטוט, יחידות, שכבות, בלוקים, גיליונות; מה מוצג על המסך |
| `files_list`, `drawing_open` | קריאה | Studio: הקבצים בתיקיות שלכם; פתיחת אחד מהם בחלון הזה |
| `objects_list`, `object_get`, `selection_get` | קריאה | אובייקטים עם הגיאומטריה, האורך והשטח שלהם (או רק כמה, לפי סוג ושכבה); הבחירה |
| `drawing_check` | קריאה | כללים כמו שכבות מותרות, שום דבר בשכבה 0, צבעים ByLayer, גבהי טקסט |
| `view_screenshot` | קריאה | תמונה של השרטוט כפי שהוא מוצג |
| `command_run` | עריכה | מקליד בשורת הפקודה: `LINE 0,0 @100,0 @0,50 ` נקרא כמו שהייתם מקלידים (רווח מסיים תשובה), או רשימה עם תשובה לכל שורה. אפשר להשאיר פקודה פתוחה ולהמשיך בקריאה הבאה |
| `script_run` | עריכה | סקריפט (`.scr`) או קובץ LISP, כפי ש-{{cmd:APPLOAD}} טוען אותם |
| `block_insert` | עריכה | מציב בלוק עם ערכי התכונות שלו בצעד אחד |
| `selection_set`, `undo` | עריכה | בוחר אובייקטים לפקודה הבאה; מבטל את הצעדים שלו בלבד |
| `drawing_save` | שמירה | {{ui:שמירה}} של CadCraft, או {{ui:שמירה בשם}} לתוך אחת התיקיות שלכם |
| `drawing_plot` | ייצוא | PDF או SVG של גיליון או של המודל, בקנה מידה או מותאם לדף (מצעי PDF עדיין אינם מודפסים בדרך זו) |

בזמן שעוזר מפעיל פקודה, CadCraft שואלת את שאלותיה בשורת הפקודה ולא בתיבת דו-שיח (למשל אם להוסיף שרטוט שלם או בלוק אחד), כך שהעוזר יכול לענות להן. הספרייה והחיפוש עדיין דורשים אתכם; העוזר מקבל הוראה לשאול אתכם.

## עבודה על קבצים בלי לפתוח את CadCraft

שרת ה-MCP של CadCraft (`cadcraft-mcp`) ושורת הפקודה (`cadcraft`) מפעילים את קוד השרטוט של CadCraft עצמו ב-Node.js, בלי חלון. הם דורשים Node.js בגרסה 20 ומעלה.

- **שרת ה-MCP** פועל רק בתוך התיקיות שתציינו, ורק עם ההרשאות שתיתנו לו: `npx @getcadcraft/mcp --root ~/Drawings --allow read,edit`. בלי `--root` הוא לא יכול לפתוח שום קובץ; בלי `--allow` הוא יכול רק לקרוא. הוא יכול גם לקרוא מודלים של IFC, כתבי כמויות והסימונים בסטים של PDF.
- **שורת הפקודה** מיועדת לסקריפטים שלכם: `cadcraft info plan.dwg`, `cadcraft run cleanup.scr plan.dwg -o plan-clean.dwg`, `cadcraft convert plan.dwg plan.dxf`, `cadcraft plot plan.dwg plan.pdf --all`, `cadcraft plot plan.dwg plan.svg`, `cadcraft check plan.dwg --rules rules.json`. כמה קבצים בבת אחת: `cadcraft convert *.dwg out --to dxf`, `cadcraft plot *.dwg pdfs --to pdf`, `cadcraft check *.dwg --rules rules.json`. הוסיפו `--json` לפלט שתוכנה יכולה לקרוא.

:::note
אם `npx @getcadcraft/mcp` מדווח שהחבילה לא נמצאה, היא עדיין לא פורסמה. החדשות ב-getcadcraft.com יאמרו מתי.
:::

## אם משהו לא עובד

- **לעוזר אין כלי CadCraft:** בדקו שהמתג דלוק בחלון הזה, ושהחלון פתוח ב-Studio.
- **"נדרשת הרשאת עריכה":** סמנו **עריכה** תחת {{ui:עוזרים}}, ואז בקשו שוב.
- **"מחוץ לתיקיות שעוזרים רשאים להשתמש בהן":** הוסיפו את התיקייה תחת {{ui:עוזרים}} › {{ui:תיקיות שרשאים להשתמש בהן}}, או בקשו מהעוזר להשתמש בקובץ שבתיקייה שכבר הוספתם.
- **שגיאות "401" או "token":** האסימון השתנה (Studio הופעלה מחדש, או {{ui:אסימון חדש}}). העתיקו את האסימון החדש להגדרות של העוזר.
- **השינוי שלו שגוי:** לחצו {{key:Mod+Z}}. לחיצה אחת מבטלת פעולה אחת שלמה של העוזר.
