## מה תלמדו

איך לאסוף גיליונות (פריסות) מכמה קובצי שרטוט לתוך **ערכת גיליונות**, לתת להם מספר וכותרת, לדאוג שבלוקי הכותרת שלהם ימולאו עבורכם, לפרסם את הערכה כולה כ-PDF אחד, ולארוז הכול לקובץ zip אחד לשליחה.

ערכת גיליונות שוכנת בקובץ קטן משלה, `<name>.ccsheets`, בתיקייה שמכילה את השרטוטים. קובץ הערכה מפרט את הגיליונות עם נתיבים מתיקייה זו, כך שאפשר להזיז או להעתיק את כל התיקייה.

:::note
פתיחת תיקייה לקריאה וכתיבה דורשת Chrome או Edge (הם יכולים לתת לדף לעבוד בתיקייה שבחרתם), או את אפליקציית שולחן העבודה. דפדפנים אחרים פותחים ערכה לקריאה בלבד: אפשר לעיין בה ולפרסם אותה, וקובץ הערכה מתורד במקום להישמר.
:::

## יצירת ערכה

1. מצאו את הסעיף {{ui:סט גיליונות}} בחלונית השמאלית, ופתחו את התפריט {{ui:סט}} שלו. הקלדת {{cmd:SHEETSET}} (או `SSM`) מביאה אתכם לשם גם כן.
2. בחרו {{ui:סט חדש…}}. תנו לערכה שם, ואם תרצו גם את שם הפרויקט ואת מספרו.
3. בחרו את התיקייה שמחזיקה את השרטוטים. קובץ הערכה נשמר שם.

כדי לפתוח ערכה מאוחר יותר, בחרו {{ui:פתיחת סט…}} ובחרו את אותה תיקייה. אם בתיקייה יש יותר מערכה אחת, CadCraft שואלת איזו.

## הוספת גיליונות

1. בחרו {{ui:הוספת גיליונות משרטוט…}} ובחרו אחד מהשרטוטים שבתיקייה.
2. CadCraft קוראת את השרטוט ברקע (הוא אינו נפתח על המסך) ומציגה את הגיליונות שלו. סמנו את אלה שתרצו ולחצו {{ui:אישור}}.
3. בחרו גיליון ולחצו {{key:F2}} (או {{ui:שינוי שם ומספור מחדש…}}) כדי לתת לו מספר וכותרת, כמו `A-101` ו-`תוכנית קומה`.

{{ui:גיליון חדש מתבנית…}} יוצר שרטוט חדש מגיליון של שרטוט אחר (בלוק הכותרת וחלונות התצוגה שלו), בשם הגיליון החדש, ומוסיף אותו. הערכה זוכרת את השרטוט שבו השתמשתם כתבנית.

## סידור הערכה

- **תת-קבוצות** מקבצות גיליונות, כגון אדריכלות › תוכניות: בחרו את המקום שאליו זה הולך ובחרו {{ui:תת-קבוצה חדשה…}}.
- **סדר**: גררו גיליון למקום אחר ברשימה, או אל תת-קבוצה כדי להעביר אותו לשם. במקלדת, בחרו אותו והקישו {{key:Alt+Up}} או {{key:Alt+Down}}.
- **פתיחת גיליון**: לחצו עליו פעמיים (או הקישו {{key:Enter}}). השרטוט שלו נפתח בלשונית משלו, על הגיליון הזה.
- **הסרה**: בחרו אותו והקישו {{key:Delete}}. השרטוט עצמו אינו משתנה.
- **ביטול**: {{ui:ביטול שינוי בסט}} ו-{{ui:ביצוע חוזר של שינוי בסט}} עוברים בין מה ששיניתם בערכה.
- **מספור מחדש**: {{ui:מספור מחדש של גיליונות…}} ממספר כל גיליון, או של תת-קבוצה אחת, לפי הסדר ברשימה: קידומת, התחלה וצעד (`A-` ו-`101` נותנים A-101, A-102 …).

כל שינוי נשמר בקובץ הערכה מיד.

## מספור גיליונות לפי השדות שלהם

במקום למספר גיליונות ביד, תנו לכלל לבנות כל מספר משדות הגיליון, כך שגיליון שעובר לקומה אחרת או לדיסציפלינה אחרת יקבל את המספר החדש שלו בעצמו.

1. תנו לכל גיליון את השדות שלו: בחרו אותו, לחצו על {{ui:שינוי שם…}} וכתבו ב-{{ui:שדות של הגיליון הזה}}, שורה לכל שדה, לדוגמה `DISCIPLINE = A` ו-`LEVEL = 1`. שדה שהערכה כולה חולקת (למשל `DISCIPLINE = A`) יכול להיכנס ל-{{ui:מאפיינים…}} של הערכה במקום.
2. פתחו את התפריט של החלונית ולחצו על {{ui:כלל מספור…}}.
3. כתבו את הכלל, לדוגמה `{DISCIPLINE}-{LEVEL}{SEQ:2}`. `{SEQ}` סופר בין הגיליונות ששאר השדות שלהם זהים, כך שקומה 1 מקבלת A-101, A-102, וקומה 2 מתחילה שוב ב-A-201. `{SEQ:2}` כותב אותו בשתי ספרות; `{SUBSET}` הוא שם תת-הקבוצה שבה נמצא הגיליון.
4. בחרו מה קורה כאשר שדה משתנה: {{ui:מספור מחדש של הגיליונות}} שומר את המספרים לפי הכלל אחרי כל שינוי; הבחירה האחרת ממספרת אותם פעם אחת, עכשיו.

הכלל נשמר בקובץ הערכה. בזמן שהוא ממספר מחדש בעצמו, שנו את השדות של גיליון ולא את המספר שלו.

## מילוי בלוקי הכותרת מהערכה

בלוק כותרת מקבל את הטקסט שלו מהערכה כאשר התכונות שלו מתויגות בשם של שדה:

| תג | מה הוא מציג |
|---|---|
| `SHEETNUMBER` (או `SHEET_NO`, `DWG_NO`) | מספר הגיליון |
| `SHEETTITLE` (או `TITLE`, `SHEET_TITLE`) | כותרת הגיליון |
| `SHEETDESC` | תיאור הגיליון |
| `PROJECTNAME` (או `PROJECT`) | שם הפרויקט |
| `PROJECTNUMBER` (או `PROJECT_NO`, `JOB_NO`) | מספר הפרויקט |
| `SHEETSETNAME` | שם הערכה |
| `SHEETINDEX`, `SHEETCOUNT` | "3 מתוך 12", ו-12 |
| שלכם, כמו `CLIENT` | מה שכתבתם עבורו ב-{{ui:הגדרת שדות…}} |

{{ui:הגדרת שדות…}} מכיל את שם הפרויקט ואת מספרו ואת השדות שלכם, שורה לכל אחד, כ-`NAME = value`.

{{ui:עדכון שרטוטים}} כותב את המספרים, הכותרות והשדות לבלוקי הכותרת של כל שרטוט בערכה, ומשנה את שם לשונית הפריסה של כל גיליון כפי שהערכה קובעת (כברירת מחדל מספר וכותרת, כמו `A-101 תוכנית קומה`; {{ui:הגדרת שדות…}} › {{ui:שמות כרטיסיות הפריסה}} משנה זאת). כל שרטוט נשמר במקומו, בפורמט ובגרסה שלו. לאחר שמספרים או משנים שם לגיליונות, הריצו שוב, והלשוניות ובלוקי הכותרת יתעדכנו.

## רשימת גיליונות בגיליון השער

בחרו את גיליון השער ברשימה, ובחרו {{ui:הוספת רשימת הגיליונות לגיליון זה}}. טבלה של כל גיליון (מספר וכותרת, תחת תת-הקבוצה שלו) נכנסת לפינה השמאלית העליונה של הגיליון. {{ui:עדכון שרטוטים}} ו-{{ui:פרסום ל-PDF}} שומרים אותה מעודכנת. זוהי בלוק אחד, `CC_SHEETLIST`: הזיזו אותו כמו כל הפניה לבלוק.

## פרסום הערכה

{{ui:פרסום ל-PDF}} יוצר PDF אחד עם עמוד לכל גיליון, לפי הסדר בערכה, בגודל הנייר של כל גיליון, עם סימנייה לכל גיליון ("A-101 — תוכנית קומה"). כאשר תת-קבוצה נבחרה, CadCraft שואלת אם לפרסם רק אותה. בלוקי הכותרת ב-PDF מתמלאים מהערכה עוד לפני שמעדכנים את השרטוטים; השרטוטים עצמם אינם משתנים בפרסום. ה-PDF מתורד.

{{ui:פרסום ל-DWG…}} כותב כל גיליון כ-DWG משלו (DWG 2018): המודל וגיליון אחד זה, עם בלוק הכותרת שלו מלא מהערכה, ושמו לפי מספרו וכותרתו (`A-101 Level 1 floor plan.dwg`). בחרו {{ui:DWG}}, או {{ui:DWG + PDF}} כדי לקבל גם את ה-PDF של הערכה לצידם. קובץ `publish.json` מפרט כל קובץ עם גודלו ו-SHA-256. כאשר אפשר לכתוב לתיקיית הערכה (CadCraft Studio, או תיקייה שבחרתם בדפדפן), הקבצים נכנסים לתיקייה `<set name> - published`; אחרת הם יורדים כ-zip אחד. [עקיפות מחלקה](topic:viewport-overrides) של חלונות התצוגה עוברות לכל DWG.

## ארכיון הערכה

{{ui:ארכיון כ-zip}} ארוז את קובץ הערכה, כל שרטוט בה ומה שהשרטוטים האלה מקושרים אליו (שרטוטים מקושרים, ושל אלה בתורם, ותמונות), תוך שמירה על התיקיות שלהם, יחד עם `Transmittal.txt` שמפרט כל קובץ. קישור שאינו נמצא בתיקייה של הערכה מופיע שם כחסר. קישורים נמצאים לפי הנתיב שלהם מהשרטוט, ואחר כך לפי שם הקובץ בכל מקום בתיקייה.

## קובץ הערכה

קובץ `.ccsheets` הוא JSON שאפשר לקרוא בכל עורך טקסט:

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "מרפאת ריברסייד",
  "properties": { "PROJECTNAME": "מרפאת ריברסייד", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "תוכניות", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 תוכנית קומה", "number": "A-101", "title": "תוכנית קומה" }
  ] } ]
}
```

הנתיבים הם יחסיים לתיקיית הערכה, עם `/` בין תיקיות. CadCraft בודקת את הקובץ כאשר היא פותחת אותו: נתיב מוחלט, גיליון בלי קובץ או בלי לשונית, או טקסט שאינו טקסט פשוט מושמטים, וההיסטוריה אומרת זאת.

## פתרון בעיות

| מה רואים | למה | מה לעשות |
|---|---|---|
| "התיקייה הזו לקריאה בלבד כאן" | הדפדפן אינו יכול לכתוב בתיקייה | השתמשו ב-Chrome או ב-Edge, או באפליקציית שולחן העבודה; בינתיים {{ui:הורדת קובץ הסט}} שומר את השינויים שלכם |
| גיליון מושמט מה-PDF: "אין לו לשונית בשם …" | הלשונית של הגיליון שונתה או הוסרה בשרטוט שלו | פתחו את השרטוט ובדקו את הלשוניות שלו; הסירו את הגיליון והוסיפו אותו שוב |
| בלוק כותרת נשאר ריק | לתכונות שלו יש תגיות אחרות | שנו את תגיות התכונות לשמות השדות שלמעלה (BEDIT) |
| "כבר יש לו לשונית בשם … לכן הלשונית לא שונתה" | שני גיליונות של שרטוט אחד היו מקבלים את אותו שם לשונית | תנו לאחד מהם מספר או כותרת אחרים |
