קיצורי הדרך מוצגים עבור המחשב שלכם. ב-Mac, כל קיצור {{key:Mod}} שלהלן משתמש במקש Command, ומקש Control עובד גם הוא. אופן כתיבת המקשים, ושימוש במקשי F ב-Mac, מופיעים ב[מקשים, עכברים ומשטחי מגע](common:keys).

## הקלדת פקודות

| מקש | מה הוא עושה |
|---|---|
| כל אות, ספרה או סימן | מועבר לשורת הפקודה, איפה שלא יהיה הסמן, אלא אם תיבה בחלונית מחזיקה בסמן |
| ‏{{key:Enter}} | שולח את מה שהקלדתם. בשורה ריקה: חוזר על הפקודה האחרונה, מסיים פקודה, מסיים בחירה, או מקבל את ברירת המחדל ב-`<…>` |
| ‏{{key:Space}} | כמו {{key:Enter}}, אלא כש-CadCraft מבקש טקסט (טקסט, שמות בלוקים, טקסט מידה), שאז הוא מקליד רווח |
| ‏{{key:Esc}} | מבטל את הפקודה. ללא פקודה פעילה: מבטל הזזת נקודת אחיזה או תיבת בחירה, ואז מנקה את הבחירה |
| ‏{{key:Tab}} | מקבל את הפקודה המוצעת שמופיעה מימין לשורת הפקודה. בלי הקלדה, וכשהעכבר מעל אובייקטים חופפים: מדגיש את האובייקט הבא שם (לחצו כדי לבחור בו) |
| ‏{{key:Up}} {{key:Down}} | מדפדף בשורות שהקלדתם קודם (100 האחרונות) |

## שרטוט ועריכה

| מקש | מה הוא עושה |
|---|---|
| ‏{{key:Mod+Z}} | ביטול הפקודה האחרונה |
| ‏{{key:Mod+Y}} או {{key:Mod+Shift+Z}} | ביצוע חוזר |
| ‏{{key:Mod+A}} | בחירת כל האובייקטים שניתנים לעריכה בלשונית הפתוחה ({{cmd:SELECTALL}}). אם הקלדתם משהו בשורת הפקודה, הפעולה בוחרת את הטקסט הזה |
| ‏{{key:Delete}} | מחיקת האובייקטים הנבחרים ({{cmd:ERASE}}), אלא אם הקלדתם משהו בשורת הפקודה |
| ‏{{key:Backspace}} | מחיקת האובייקטים הנבחרים כשלשורת הפקודה אין סמן; בשורת הפקודה הוא מוחק את מה שהקלדתם |
| ‏{{key:Esc}} | ללא פקודה פעילה: ביטול הבחירה ({{cmd:DESELECT}}) |
| ‏{{key:Mod+S}} | שמירת עותק בפורמט של השרטוט (DWG או DXF) |
| ‏{{key:Mod+Shift+S}} | שמירה בשם: בחירה בין DWG ל-DXF, ואז שמירת עותק |
| ‏{{key:Mod+O}} | פתיחת DWG או DXF |
| ‏{{key:Mod+P}} | {{ui:הדפסה ל-PDF}} |

ביטול, ביצוע חוזר, בחירת הכול והדפסה אינם פועלים כשפקודה רצה: לחצו קודם על {{key:Esc}}.

## העתקה, גזירה והדבקה

| מקש | מה הוא עושה |
|---|---|
| ‏{{key:Mod+C}} | העתקת הבחירה ללוח ({{cmd:COPYCLIP}}). אם לא נבחר דבר, CadCraft מבקש אובייקטים |
| ‏{{key:Mod+X}} | גזירה: העתקת הבחירה ואז מחיקתה ({{cmd:CUTCLIP}}) |
| ‏{{key:Mod+V}} | הדבקה: העותק עוקב אחרי הסמן; לחצו, או הקלידו נקודה, כדי להניח אותו ({{cmd:PASTECLIP}}) |
| ‏{{key:Mod+Shift+V}} | הדבקה במקום: בקואורדינטות שממנן הועתק ({{cmd:PASTEORIG}}) |
| ‏{{key:Mod+D}} | שכפול: עותק של הבחירה נע עם הסמן; לחצו כדי להניח אותו. {{key:Esc}} לא משאיר דבר ({{cmd:DUPLICATE}}) |

אותן פעולות נמצאות בקבוצה {{ui:עריכה}} בסרגל הכלים ({{ui:העתקה}}, {{ui:הדבקה}}) ובתפריט {{ui:עוד}} שלו. כשפקודה אחרת פועלת, סיימו אותה או לחצו {{key:Esc}} קודם; לחיצה נוספת על {{key:Mod+V}} או {{key:Mod+D}} כשעותק עוקב אחרי הסמן מתחילה מההתחלה. כשהקלדתם משהו בשורת הפקודה, או כשפקודה מבקשת טקסט, המקשים האלה מעתיקים, גוזרים ומדביקים את הטקסט הזה. ראו [העתקה, הדבקה ושכפול](topic:copy-paste).

## מתגים

| מקש | מתג | לחצן בשורת המצב |
|---|---|---|
| ‏{{key:F3}} | נעיצה לאובייקטים פעילה או כבויה | {{ui:נעיצה}} |
| ‏{{key:F7}} | רשת פעילה או כבויה | {{ui:רשת}} |
| ‏{{key:F8}} | אורתו פעיל או כבוי | {{ui:אורתו}} |
| ‏{{key:F10}} | מעקב קוטבי פעיל או כבוי | {{ui:קוטבי}} |
| ‏{{key:F11}} | מעקב נעיצה לאובייקטים פעיל או כבוי | {{ui:מעקב}} |
| ‏{{key:F12}} | קלט דינמי פעיל או כבוי | {{ui:דינמי}} |

:::mac
ב-Mac, F3, F7 ו-F8 הם בדרך כלל מקשי Mission Control ומדיה. החזיקו את **fn** יחד איתם, או הפעילו מקשי פונקציה סטנדרטיים בהגדרות המערכת, כמתואר ב[מקשים, עכברים ומשטחי מגע](common:keys). לחצני שורת המצב פועלים תמיד.
:::

:::firefox
F7 ב-Firefox יכול גם לבקש להפעיל גלישה עם סמן (caret browsing). בחרו **לא**, והשתמשו בלחצן {{ui:רשת}} אם זה ממשיך לשאול.
:::

## עזרה

| מקש | מה הוא עושה |
|---|---|
| ‏{{key:F1}} | פתיחה או סגירה של עזרה זו, לצד השרטוט. פועלת גם כשפקודה רצה, ולעולם לא מגיעה לשורת הפקודה. |
| ‏{{key:Esc}} | כשהסמן בחלונית העזרה: מנקה את החיפוש, או סוגר את החלונית |

הלחצן {{ui:עזרה}} בשורה שבחלק העליון עושה את אותו הדבר כמו {{key:F1}}. בזמן שאתם מקלידים בתיבת החיפוש של העזרה, שום דבר אינו מגיע לשורת הפקודה. לחצו על השרטוט כדי להחזיר את המקשים ל-CadCraft; החלונית נשארת פתוחה לצדו.

:::mac
במקלדת Mac, החזיקו **fn** ולחצו F1, או לחצו על {{ui:עזרה}}.
:::

## מסך

| מקש | מה הוא עושה |
|---|---|
| ‏{{key:Ctrl+Shift+F}} | מחזר בין מצב רגיל, מסך מלא, ומסך מלא עם הסרגלים מוסתרים. זה משתמש במקש Control בכל מחשב, כולל Mac. |
| ‏{{key:Left}} {{key:Right}} | כשלשונית מתחת לשרטוט בפוקוס: הלשונית הקודמת או הבאה |

במסך מלא, הדפדפן עשוי להשתמש בלחיצה הראשונה על {{key:Esc}} כדי לצאת ממסך מלא. לחצו {{key:Esc}} שוב כדי לבטל פקודה.

## תיבות דו-שיח

| מקש | מה הוא עושה |
|---|---|
| ‏{{key:Esc}} | סוגר את תיבת הדו-שיח ({{ui:הדפסה ל-PDF}}, או שאלה כמו "שינויים שלא נשמרו", שבה הוא פירושו {{ui:ביטול}}) |
| ‏{{key:Tab}} | עובר בין ההגדרות והלחצנים של תיבת הדו-שיח |

בזמן שתיבת דו-שיח פתוחה, מקשי השרטוט כבויים.

## שדות בחלונית

בתיבה בחלונית הימנית או השמאלית:

| מקש | מה הוא עושה |
|---|---|
| ‏{{key:Enter}} | מחיל את הערך ויוצא מהתיבה |
| ‏{{key:Esc}} | מחזיר את הערך הישן ויוצא מהתיבה |
| ‏{{key:Tab}} | מחיל ועובר לתיבה הבאה |

בזמן שלתיבה יש סמן, האותיות נכתבות בתוכה, לא בשורת הפקודה.

## עכבר

| פעולה | מה היא עושה |
|---|---|
| לחיצה | בוחרת נקודה כשפקודה מבקשת נקודה; בוחרת אובייקט כשהיא מבקשת אובייקטים; אחרת בוחרת אובייקט או נקודת אחיזה |
| Shift+לחיצה | מסירה אובייקט שנבחר מהבחירה (כש-{{ui:לחיצה על אובייקטים}} מוגדר ל-{{ui:מחליף את הבחירה}} ב[הגדרות](topic:settings): מוסיפה אותו). בזמן בחירת נקודה: מתעלמת מנעיצות לאובייקטים בלחיצה הזו |
| לחיצה על מקום ריק, ואז לחיצה נוספת | תיבת בחירה: משמאל לימין היא חלון, מימין לשמאל היא חוצה |
| גרירה על מקום ריק | לאסו: גרירה ימינה קודם היא חלון, שמאלה קודם היא חוצה; {{key:Space}} בזמן הגרירה מחזר בין חלון, חוצה וגדר; {{key:Esc}} משחרר אותו (LASSOMODE 0, או הגדרות, מחזירים את המלבן) |
| גרירה דרך חלקים ב-TRIM או EXTEND | חותכת (או מאריכה) כל חלק שהנתיב חוצה; החזיקו {{key:Shift}} לפעולה השנייה |
| גרירת נקודת אחיזה | מזיזה את נקודת האחיזה (או לחצו עליה, ואז לחצו היכן שתגיע) |
| לחיצה כפולה על טקסט | בוחרת אותו ומעבירה את הסמן לתיבת {{ui:טקסט}} בחלונית הימנית |
| לחיצה ימנית | {{key:Enter}}. במהלך הזזת נקודת אחיזה או תיבת בחירה: מבטלת אותן |
| גרירה בלחצן הימני | הזזה |
| גלגלת | זום פנימה והחוצה סביב הצלב |
| גרירה בגלגלת (לחצן אמצעי) | הזזה |
| לחיצה כפולה על הגלגלת | זום לכל השרטוט (גבולות) |
| גרירת DWG או DXF אל השרטוט | פותחת אותו |

במשטח מגע או במסך מגע, ראו [עכבר, משטח מגע ומסך מגע](topic:mouse-trackpad-touch).

## מקשים ששייכים לדפדפן

{{key:Mod+N}}, {{key:Mod+W}} ו-{{key:Mod+T}} תמיד שייכים לדפדפן. CadCraft אינו משתמש בהם: השתמשו ב-{{ui:חדש}} או הקלידו `NEW` לשרטוט חדש. הלוח של CadCraft הוא משלו: {{key:Mod+C}} ו-{{key:Mod+V}} מעתיקים אובייקטים בין שרטוטים ולשוניות של CadCraft, ולא אל תוכנות אחרות או ממנן.

:::mac
אם {{key:Mod+Y}} פותח את היסטוריית הדפדפן במקום לבצע שוב, השתמשו ב-{{key:Mod+Shift+Z}} או בלחצן {{ui:ביצוע חוזר}}.
:::

## היכן נמצאת הזזה

הזזה היא הפקודה `MOVE` (מקש {{key:M}}): בחרו את האובייקטים, ואז נקודת בסיס ונקודה שנייה או מרחק שהוקלד. `ALIGN` ו-`DISTRIBUTE` קיימים גם הם. BimCraft משתמש באותם שמות לאותן עבודות על אלמנטים של בניין, אבל ה-{{key:M}} שלו הוא מדידה (Measure), והזזה שלו היא {{key:Shift+M}}.
