## 你将学到的内容

标注文字和箭头有多大，如何为以 1:50 或 1:100 出图的图形进行设置，以及如何修改你已经绘制的标注。

## 标注尺寸的工作方式

每个标注都带有自己的一组尺寸：文字高度、箭头大小、小数位数、文字周围的间距、尺寸界线超出尺寸线的长度，以及尺寸界线与对象的起点距离。默认值接近常见的 ISO 样式：

| 设置 | 默认值 | 命令 |
|---|---|---|
| 文字高度 | 2.5 | {{cmd:DIMTXT}} |
| 箭头大小 | 2.5 | {{cmd:DIMASZ}} |
| 小数位数 | 2（去掉末尾的零） | {{cmd:DIMDEC}} |
| 文字周围的间距 | 0.625 | {{cmd:DIMGAP}} |
| 尺寸界线超出尺寸线的长度 | 1.25 | {{cmd:DIMEXE}} |
| 尺寸界线与对象的偏移 | 0.625 | {{cmd:DIMEXO}} |
| 总比例 | 1 | {{cmd:DIMSCALE}} |

每个尺寸都会乘以**总比例**。按图纸上你想要的尺寸设置（2.5 毫米文字），并将总比例设为出图比例（1:50 则为 50）。文字高度则为 2.5 × 50 = 125 个图形单位，以 2.5 毫米出图。

:::note
命名标注样式用{{cmd:DIMSTYLE}}管理：见下文一节。每个标注也保留其绘制时所使用的设置，因此你仍可在{{ui:特性}}中单独更改某一个标注。
:::

## 设置新标注的尺寸

以下两种方式都只会更改之后你绘制的标注。

### 在“当前设置”面板中

1. 按{{key:Esc}}，使任何对象都不被选中。在{{ui:模型}}选项卡上，右侧面板显示{{ui:当前设置}}。
2. 向下滚动面板至{{ui:新标注}}，越过图层、颜色、单位以及{{ui:图层 0}}等行（在小屏幕上，它会从底边以下开始）。单击{{ui:总比例}}，输入 `50` 并按{{key:Enter}}。
3. 如果需要其他值，可以用同样的方式设置{{ui:文字高度}}、{{ui:箭头大小}}和{{ui:小数位数}}。

状态栏会确认每一项，例如“新标注的总比例：50”。

### 在命令行中

1. 输入 `DIMSCALE` 并按{{key:Enter}}。
2. 在 `Enter new value for DIMSCALE <1>` 提示下，输入 `50` 并按{{key:Enter}}。

历史记录会确认“DIMSCALE = 50。新标注将使用该值；选择已有标注可更改其值。”{{cmd:DIMTXT}}、{{cmd:DIMASZ}}、{{cmd:DIMDEC}}、{{cmd:DIMGAP}}、{{cmd:DIMEXE}}和{{cmd:DIMEXO}}的操作方式相同。在提示下按{{key:Enter}}即可保留当前值。

### 标注中的英尺和英寸

新标注使用图形的长度格式：在“当前设置”中的{{ui:长度格式}}或使用{{cmd:UNITS}}进行设置（参见[英尺和英寸](topic:units-papers-scales#feet-and-inches-and-fractions)），之后的标注会显示为 `12'-6 1/2"`。{{cmd:DIMLUNIT}}仅设置标注的格式（2 为小数，3 为工程，4 为建筑，5 为分数）。对于你已经绘制的标注，请选中它，并在{{ui:特性}}中选择{{ui:格式}}；使用分数格式时，其{{ui:分数}}框取 2 的幂（4 = 1/16）。

## 以毫米、厘米、米或千米计的标注

标注以图形单位测量。它可以将该长度改写为毫米、厘米、米或千米，单位跟在数字之后：一段 1250 毫米的墙会显示为 `1250 mm`、`125 cm`、`1.25 m` 或 `0.00125 km`。

1. 首先在“当前设置”中设置图形的{{ui:单位}}（参见[单位、图纸尺寸和比例](topic:units-papers-scales#drawing-units)），以便 CadCraft 知道一个图形单位代表什么。没有单位的图形按毫米读取，{{cmd:DIMTEXTUNIT}}会说明这一点。
2. 对于新标注：按{{key:Esc}}使任何对象都不被选中，然后在{{ui:新标注}}下选择{{ui:文字中的单位}}：{{ui:图形单位}}、`mm`、`cm`、`m` 或 `km`。
3. 对于你已经绘制的标注：选中它们，然后在{{ui:特性}} › {{ui:主单位}}中选择{{ui:文字中的单位}}。

或者输入{{cmd:DIMTEXTUNIT}}（`DTU`），并回答 `D`、`MM`、`CM`、`M` 或 `KM`：若选中了标注，则更改这些标注（一步撤销）；若未选中任何对象，则设置新标注。

{{ui:小数位数}}（{{cmd:DIMDEC}}）仍然设置显示多少位小数：以米为单位且小数为 3 位时，1234 毫米显示为 `1.234 m`。文字以十进制数字写出。在布局上，标注以布局的图纸单位（毫米或英寸）测量。

保存的 DWG 或 DXF 会将该选择保存为标注的测量比例（DIMLFAC）和后缀（DIMPOST，即 ` m`），以便其他程序显示相同的文字。如果你之后更改图形的{{ui:单位}}，以毫米、厘米、米或千米书写的标注会被重新调整，从而始终显示正确的长度。{{ui:手动设置（比例或后缀）}}表示标注的{{ui:测量比例}}或后缀是以其他方式设置的；选择一个单位即可替换它们。

## 更改已绘制的标注

1. 单击一个标注。右侧面板的标题显示{{ui:标注}}。
2. 设置分为若干部分；向下滚动面板以找到后面的部分：
   - {{ui:常规}}：{{ui:标注样式}}
   - {{ui:几何}}：{{ui:类型}}和{{ui:测量值}}（只读）
   - {{ui:文字}}：{{ui:文字替代}}和{{ui:文字高度}}
   - {{ui:线与箭头}}：{{ui:箭头大小}}
   - {{ui:调整}}：{{ui:总比例}}
   - {{ui:主单位}}：{{ui:小数位数}}
3. 输入新值，并按{{key:Enter}}。

标注会立即重绘。对于角度标注，{{ui:小数位数 (°)}}设置角度的小数位数。

:::note
选中多个标注时，面板显示它们共有的行；彼此不同的值显示为{{ui:各不相同}}。你输入的一个值会在一步中更改所有选中的标注，因此按一次{{key:Mod+Z}}即可将它们全部恢复。
:::

## 来自已打开图形的标注

从已打开的 DWG 或 DXF 中读取的标注，会按另一个程序绘制的原样显示。其面板会显示“按创建该文件的程序所绘制的样子显示。若更改它，CadCraft 会以其自身样式重新绘制。” 一旦你更改任何值、移动夹点或移动标注，CadCraft 就会用其自身的箭头和字体重新绘制它，所用尺寸取自文件。

有些标注只能按原样读取，而无法作为可编辑的标注；此时面板会显示“绘制来源”及一个块名称，“关于此文件”框会统计它们的数量。

## 常见错误

- **更改 DIMSCALE 后屏幕上没有变化。** 该设置针对新标注。请选择已有的标注，并在面板中更改{{ui:总比例}}。
- **小数位数显示的位数少于设定值。** 末尾的零会被去掉：小数位数为 2 时显示 `1250` 和 `1250.5`，而不是 `1250.00`。
- **在视口中的图纸上文字高度正确，但在模型出图时错误。** 总比例必须与你出图的比例一致。按“适合图纸”出图会得到一个不规则的比例；请在打印对话框中选择标准比例。
- **文字中出现 mm 或 m 之类的单位。** 请选择{{ui:文字中的单位}}（参见[以毫米、厘米、米或千米计的标注](topic:dimension-settings#dimensions-in-mm-cm-m-or-km)）。对于数字之后的任何其他文字，请在替代中输入：`<> TYP.`。

## 命名标注样式

输入 `DIMSTYLE`（`D`）以打开{{ui:标注样式管理器}}。它列出图形中的样式、每种样式被多少个标注使用，以及哪一种是当前样式。**Standard** 始终存在。

- {{ui:设为当前}}：新标注使用该样式的设置，并带有其名称。
- {{ui:新建…}}：一个新样式，起始为你所选样式的副本。
- {{ui:修改…}}：与{{ui:特性}}中标注部分相同的字段（线与箭头、文字、调整、单位、替代单位、公差）。按{{ui:确定}}后，样式会更改，**且使用它的每一个标注都会随之更改**，逐项设置。若你仅在某一个标注上更改过的设置，除非样式更改了该设置，否则保持不变。
- {{ui:重命名…}}和{{ui:删除}}：Standard 不能重命名或删除，当前样式或正被标注使用的样式也不能。
- {{ui:比较…}}：两种样式之间有何不同。
- {{ui:应用到所选}}：先选择标注；它们会采用该样式的设置及其名称。

`-DIMSTYLE` 在命令行中执行相同的操作：`Restore`、`Save`（当前设置，包括你用 {{cmd:DIMTXT}} 等输入的内容，以一个名称保存）、`Delete`、`Apply`、`Compare`、`reName`、`List`。

样式保存在 DWG 或 DXF 中（其标注样式表内），并从你打开的文件中读取。当前样式不会被保存：图形打开时以 Standard 为当前样式。当另一种样式为当前样式时，Standard 保留其自身的设置。

## 更改标注文字和尺寸界线

{{cmd:DIMEDIT}}（`DED`）作用于你选中的标注：**Home** 将文字恢复为样式所设定的位置，**New** 输入其他文字（`<>` 代表测量值），**Rotate** 旋转文字，**Oblique** 将线性和对齐标注的尺寸界线倾斜为你输入的角度（按{{key:Enter}}表示不倾斜）。{{cmd:DIMTEDIT}} 将文字移至尺寸线的**左侧**、**右侧**或**中间**，或将其旋转（**Angle**），或使其回到 **Home** 位置。文字始终位于尺寸线上：它无法被拖到任意位置。
