## 将要绘制的内容

一个矩形及其两条对角线、一个以对角线交点为圆心的圆，以及一条从某一边中点垂直连到圆上的直线。每个点都用鼠标拾取，且每个点都是精确的。

## 捕捉的工作方式

命令请求点时，CadCraft 会在十字光标附近约 10 像素范围内查找捕捉点。找到后，会出现一个标记和标签（“端点”“交点”），单击将**精确**落在该点上，而不是十字光标所在的位置。

状态栏中的{{ui:捕捉}}按下时，捕捉即处于开启状态。{{key:F3}}可开启和关闭捕捉。

可用的捕捉有：

| 捕捉 | 落在 |
|---|---|
| 端点 | 直线、圆弧和多段线线段的端点 |
| 中点 | 直线、圆弧和多段线线段的中点 |
| 圆心 | 圆和圆弧的圆心，以及多段线圆弧段的圆心 |
| 象限点 | 圆和圆弧的 0、90、180 和 270 度点 |
| 交点 | 两个对象相交之处 |
| 垂足 | 对象上与上一点垂直的点（需要基点） |
| 切点 | 圆或圆弧上，从上一点引出的直线恰好与之相切的点。若尚无上一点（直线的第一点），标记会显示“延迟”：切点会在知道下一点后计算，因此从切点到切点的直线会与两个圆都相切 |
| 最近点 | 任意对象上最近的点 |
| 节点 | 点对象 |
| 插入点 | 文字和块参照的插入点 |

除切点和最近点外，所有捕捉默认均为开启。需要其他捕捉时，最近点往往会优先生效；需要时请开启切点。

## 选择捕捉

1. 单击{{ui:捕捉}}旁边的小箭头。{{ui:对象捕捉}}列表会打开。
2. 勾选或取消勾选捕捉。更改立即生效。
3. 再次单击箭头以关闭列表。

CadCraft 会在本浏览器中记住你的选择，以及{{ui:栅格}}、{{ui:正交}}和{{ui:捕捉}}设置。

## 步骤

1. 输入 `REC`，然后按{{key:Enter}}。
2. 输入 `0,0`，然后按{{key:Enter}}。
3. 输入 `@4000,3000`，然后按{{key:Enter}}。出现一个矩形。
4. 单击{{ui:范围}}。
5. 输入 `L`，然后按{{key:Enter}}。
6. 将十字光标移到左下角。标记显示“端点”。单击。
7. 移到右上角，直到显示“端点”。单击。
8. 按{{key:Enter}}结束直线。
9. 再按一次{{key:Enter}}以重复{{cmd:LINE}}，并以相同方式从右下角到左上角绘制另一条对角线。
10. 输入 `C`，然后按{{key:Enter}}开始绘制圆。
11. 将十字光标移到两条对角线相交处。标记显示“交点”。单击。
12. 输入 `800`，然后按{{key:Enter}}。

应能看到一个圆，其圆心精确位于交叉点上。

13. 输入 `L`，然后按{{key:Enter}}。
14. 移到矩形左边中点，直到显示“中点”。单击。
15. 将十字光标移到圆上，位于其左侧。标记显示“垂足”或“象限点”；在此处两者是同一点。单击。
16. 按{{key:Enter}}。

新直线从左边中点开始，并精确止于圆上。

## 单次单击跳过捕捉

单击时按住{{key:Shift}}。该次单击将忽略对象捕捉，点将精确落在十字光标位置（若{{ui:正交}}已开启，则沿正交方向）。

## 正交

{{ui:正交}}（{{key:F8}}）使下一点从基点出发保持水平或竖直。它适用于单击以及直接距离输入（在提示处输入的纯数字）。对象捕捉优先于正交：若显示了捕捉标记，单击将落在该捕捉点上。

## 极轴追踪

{{ui:极轴}}（{{key:F10}}）是在更多角度上的正交。命令具有基点时（直线的上一点、移动的基点），指针靠近以基点出发、角度为极轴步长整数倍的射线时会对齐：显示虚线，十字光标旁的标签显示 `极轴：1200 < 30°`。单击即可使用该点，或输入距离：`1200` 会精确沿射线移动 1200。

在更改之前，步长为 90°：输入{{cmd:POLARANG}}，按{{key:Enter}}，然后输入 `30`（或 45、22.5、15 …）。极轴与正交互斥：开启其中一个会关闭另一个。

## 对象捕捉追踪

{{ui:追踪}}（{{key:F11}}）会将指针与你停留过的捕捉点对齐，因此无需绘制辅助线，即可拾取与一个角点水平对齐、并位于另一个角点之上的点。

1. 开启{{ui:捕捉}}和{{ui:追踪}}，然后启动一个请求点的命令（`L`）。
2. 在捕捉点（例如角点）上停留指针半秒，不单击。会出现一个小十字标记：已获取。再次停留在其上即可取消。
3. 沿水平或竖直方向直接远离该点移动指针。虚线跟随指针，标签显示 `追踪：600 < 90°`。单击，或输入距离。
4. 获取第二个点，并移动到经过第一点的竖线与经过第二点的横线相交处：指针会捕捉到该交点（`追踪：两线相交处`）。

同时开启{{ui:极轴}}时，已获取的点会在每个极轴角度上追踪。最多保留七个点，直至命令结束。{{key:Shift}}与捕捉一样，可在单次单击中关闭追踪。

## 栅格

{{ui:栅格}}（{{key:F7}}）在图形后方显示网格线，每第五条线加粗；间距随缩放而变化。在开启{{ui:栅格捕捉}}（{{key:F9}}）之前，它仅作为参考线：此时单击将落在最近的栅格点上，除非对象捕捉先获取该点。

## 计算机上的功能键

{{key:F9}}为{{ui:栅格捕捉}}，{{key:F10}}为{{ui:极轴}}，{{key:F11}}为{{ui:追踪}}。

:::mac
在 Mac 上，F3、F7、F8 和 F9 通常控制 Mission Control 和媒体。按住 **fn** 与该键，或开启标准功能键，参见[键盘、鼠标和触控板](common:keys)。状态栏按钮始终有效。
:::

:::firefox
在 Firefox 中，F7 也是用于光标浏览的键。如果 Firefox 询问是否开启光标浏览，请选择**否**。若该询问反复出现，请使用{{ui:栅格}}按钮。
:::

:::touch
在触摸屏上没有悬停，因此捕捉标记仅在手指触碰处出现。对于小目标，请放大视图，或改为输入坐标。
:::

## 常见错误

- **单击落到了错误的点。** 单击前请查看标记标签：当两者都很近时，端点优先于中点。请放大视图，或取消勾选不需要的捕捉。
- **没有出现标记。** {{ui:捕捉}}已关闭，或所需的捕捉未勾选，或对象位于已关闭或已冻结的图层上。
- **在复杂图形中，捕捉抓取了错误的对象。** 放大视图。捕捉距离以屏幕像素计量，因此放大后，它在图形上的范围会变小。
- **以为 Shift 会得到直线。** 在 CadCraft 中，Shift 仅在一次单击中关闭捕捉。绘制直线请使用{{ui:正交}}。
- **以为点会落在栅格点上。** 请开启{{ui:栅格捕捉}}（{{key:F9}}），或输入坐标以获得整数值。
