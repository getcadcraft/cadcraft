## 打开文件

| 消息或现象 | 原因 | 解决方法 |
|---|---|---|
| “CadCraft 打开 DWG 和 DXF 图形。“…”两者都不是。” | 文件不是`.dwg`或`.dxf`。 | 请打开图形文件本身。PDF 可以导入（打开时会询问：导入或附着，见[PDF 底图](topic:pdf-underlay)）；图片可使用`IMAGEATTACH`插入。 |
| “此二进制 DXF 在某个对象中间结束：文件被截断或已损坏。” | 二进制 DXF 在其结尾之前停止。 | 输入RECOVER以打开可读取的部分，或重新获取文件。 |
| “此文件不是可读取的 DXF（第 … 行的组代码有误）。” | DXF 已损坏，或实际上不是 DXF。 | 重新获取文件，或获取 DWG。 |
| “无法读取此图形。它可能已损坏，或保存为读取器尚不支持的版本（…）。” | DWG 读取器无法读取它。 | 请获取以较旧版本保存的 DWG，或 DXF。 |
| “此图形来自 AutoCAD R11 / R12（DWG AC1009），比 CadCraft 可读取的版本更旧……” | Release 12 及更早版本的 DWG 文件使用 CadCraft 无法读取的格式。 | 在生成该文件的程序中，将其另存为 DXF（任何版本）或较新版本的 DWG，然后打开该文件。CadCraft 自身的“另存为”提供 DXF R12，供需要该旧格式的程序使用。 |
| 首次打开 DWG 时出现“无法打开 …”，后跟网络消息 | 无法下载 DWG 读取器：当前处于离线状态，且 CadCraft 未保存供离线使用，或连接中断。 | 恢复联网后重试，或打开 DXF。单击{{ui:保存以供离线使用}}，等待出现“离线就绪”，以便下次离线时也能打开 DWG 文件。见[离线工作](common:offline)。 |
| 离线按钮显示“无法保存” | 部分文件未能下载。 | 检查连接，然后单击该按钮重试。 |
| 离线按钮显示“无法离线使用” | 隐私窗口和某些受管理的计算机无法保存离线副本。 | 使用普通窗口，或保持联网。 |
| 无网络连接时 CadCraft 无法打开 | 它未在此浏览器中保存供离线使用，或浏览器已将其清除。 | 下次联网时，单击{{ui:保存以供离线使用}}，等待出现“离线就绪”。 |
| 图形已打开，但部分内容缺失 | CadCraft 尚无法绘制的对象，或文件中关闭或冻结的图层。 | 阅读左侧面板中的“关于此文件”。检查{{ui:图层}}面板。 |
| 文字换行成两行 | CadCraft 以类似 Helvetica 的字体绘制文字，比某些 CAD 字体更宽。 | 在{{ui:特性}}中缩短文字，或接受多出的一行。 |
| 圆显示为椭圆，或镜像文字可正确阅读 | 对象在生成该文件的程序中绘制于倾斜平面，或从下方观看。CadCraft 按从上方观看的方式显示，与该程序的平面视图相同；文字保持可读。 | 无需修复。若要按其他程序的方式查看，请要求将图形拍平，或将对象从上方绘制。 |
| 块、圆或标注的位置与生成该文件的程序中不一致 | CadCraft 读取错误的一种图形情况。 | 请在 Discord 上告诉我们，如可以分享文件，请一并提供。 |

## 命令行

| 消息或现象 | 原因 | 解决方法 |
|---|---|---|
| “未知命令 “…”。输入HELP查看列表。” | 没有该名称的命令或别名。 | 输入`HELP`，或查看[命令参考](topic:commands)。部分常用命令[尚未实现](topic:not-built-yet)。 |
| 输入时命令行旁显示“没有此命令” | 输入的内容与任何命令都不匹配。 | 继续输入，或检查拼写。 |
| “需要点或选项关键字。” | 输入的内容不是点或选项。 | 检查格式：`x,y`、`@dx,dy`、`@d<a`，或单个数字。见[坐标与距离输入](topic:coordinate-entry)。 |
| “需要一个正数或两个点。” | 距离为负数或不是数字。 | 输入正数，或单击两个点。 |
| “需要以度为单位的角度或两个点。” | 角度不是数字。 | 以纯数字输入度数。 |
| “需要数字。” | 需要输入数字。 | 只输入数字。 |
| “选项关键字无效。” | 输入的字母与任何选项都不匹配。 | 输入方括号中所示的大写字母。 |
| `*Cancel*` | 按了{{key:Esc}}，或在需要指定点时按了{{key:Enter}}。 | 重新开始命令。 |
| 输入内容无法进入命令行 | 面板或对话框中的文本框有光标。 | 按{{key:Enter}}或{{key:Esc}}，或在图形上单击。 |
| 命令使用了未选择的对象 | 它们在开始命令之前已被选中。 | 在执行命令前按{{key:Esc}}。 |
| 线条出现在意外的位置 | `x,y`为绝对坐标。 | 使用`@dx,dy`表示相对点。 |
| “请先完成或取消当前命令（Esc）。” | 命令运行时按了{{key:Mod+S}}。 | 按{{key:Esc}}，然后保存。 |
| “无法另存为 DWG（AutoCAD 2000）：…请尝试“另存为”，然后选择 DXF。” | 图形中有内容无法写入 DWG 格式。 | 按{{key:Mod+Shift+S}}，选择{{ui:DXF R12}}，然后单击{{ui:保存}}。 |
| “未保存。” | 用{{ui:取消}}或{{key:Esc}}关闭了{{ui:将副本另存为}}对话框。 | 再次按{{key:Mod+Shift+S}}并单击{{ui:保存}}。 |

## 编辑

| 消息或现象 | 原因 | 解决方法 |
|---|---|---|
| 对象无法选中 | 其图层已锁定、关闭或冻结；或当前位于布局上，且它是视口中的模型。 | 解锁图层，或切换到{{ui:模型}}标签页。 |
| “该处未找到任何内容。” | 单击处没有对象。 | 放大视图，并单击线条本身。 |
| “该处没有线条与该对象相交。” | {{cmd:TRIM}}未找到与所选段相交的对象。 | 检查剪切线是否确实与之相交。 |
| “无法修剪该对象。” | 修剪仅适用于直线、圆弧、圆和多段线。 | 先分解块，或删除后重新绘制。 |
| “该方向没有边界。” | {{cmd:EXTEND}}找不到可延伸至的边界。 | 请在应延长的一端附近单击。 |
| “无法偏移该对象。” | 偏移仅适用于直线、圆弧、圆和多段线。 | 先分解它，或绘制一条平行线。 |
| “无法偏移到该距离。” | 偏移会使图形翻转到内侧。 | 使用较小的距离。 |
| “半径过大。”或“距离过大。” | 圆角或倒角会超出线条的端点。 | 使用`R`设置较小的半径，或使用`D`设置较小的距离。 |
| “只能剪回开放多段线的第一段或最后一段。” | 拐角会切入多段线的中间。 | 选择相邻的两段多段线，或对每个拐角使用`P`。 |
| “请选择另一条不同的线。” | 第二次选择的是同一条线，或不是线。 | 选择另一条线。 |
| “只有多段线、块参照和标注可以分解。” | 所选内容中没有可分解的对象。 | 选择多段线、块参照或标注。 |
| “这是当前图层。请先将另一个图层设为当前图层。” | 试图关闭当前图层。 | 单击另一个图层的名称，然后关闭此图层。 |
| “已存在名为 … 的图层。” | 图层名称必须唯一。 | 选择其他名称。 |
| “没有可撤销的内容。” | 没有剩余可撤销的内容，或已打开或新建图形（这会清除历史记录）。 | — |

## 标注和块

| 消息或现象 | 原因 | 解决方法 |
|---|---|---|
| 标注文字和箭头过小或过大 | 尺寸以绘图单位计；整体比例与图形不匹配。 | 将{{cmd:DIMSCALE}}设为打印比例；见[设置标注尺寸](topic:dimension-settings)。 |
| “请在要测量的角内选择一个点。” | 角度标注的位置位于某条边上。 | 在角内单击。 |
| “这些线平行。” | 平行线之间没有夹角。 | 选择两条相交的线。 |
| “请选择线性或对齐标注。” | {{cmd:DIMCONTINUE}}或{{cmd:DIMBASELINE}}需要一个起始标注。 | 选择线性或对齐标注。 |
| “此图形尚无块：F 从文件插入，L 从库中插入……” | 图形本身没有块。 | 输入`F`或`L`，或使用{{cmd:BLOCK}}创建块。 |
| “没有名为 “…” 的块。” | 名称错误。 | 消息会列出现有的块。 |
| “块名称不能以 * 开头，或使用……”，后接字符列表 | 名称包含块无法使用的字符。 | 使用字母、数字、`-` 和 `_`。 |
| “块不能包含其自身。” | 所选内容包含对正在创建的块的引用。 | 去掉该引用。 |
| “未选择对象；未创建任何内容。” | 在选择对象前按了{{key:Enter}}。 | 再次运行{{cmd:BLOCK}}并选择对象。 |

## 布局和打印

| 消息或现象 | 原因 | 解决方法 |
|---|---|---|
| “视口需放在布局上。请先打开布局标签页（或使用LAYOUT创建一个）。” | 在{{ui:模型}}标签页上使用{{cmd:MVIEW}}。 | 先单击布局标签页。 |
| “请先打开含有视口的布局。” | 在{{ui:模型}}标签页上使用{{cmd:VPVIEW}}。 | 先单击布局标签页。 |
| 视口比例看起来错了十倍 | 图形单位有误。 | 在{{ui:当前设置}}中设置{{ui:单位}}。 |
| “尚无可打印的内容。” | 模型为空。 | 绘制某些内容，或打开图形。 |
| “请选择要打印的窗口。” | 已选择{{ui:一个窗口…}}，但未选择窗口。 | 单击{{ui:拾取}}并选择两个角点。 |
| “……大于纸张：边缘被裁切。” | 该区域在该比例下无法放入。 | 选择较小的比例、较大的纸张，或{{ui:适合纸张}}。 |
| “浏览器阻止了新标签页，因此改为下载 PDF。” | 该网站已阻止弹出窗口。 | 打开已下载的 PDF，或允许该网站弹出窗口。 |
| 字符打印为“?” | PDF 的字体中没有这些字符的字母（罕见的表意字、印地语及其他需要复杂排版的文字……），或无法获取较大的字体（离线）。欧洲文字、西里尔字母、希腊字母、希伯来文、阿拉伯文、波斯文、乌尔都文、泰文、中文、日文和韩文均按原样打印。 | 对于阿拉伯文、泰文、中文、日文或韩文，请在联网后重新打印。其他文字尚未实现。 |
| 辅助线显示在 PDF 中 | 其所在图层会打印。 | 单击该图层的打印按钮。 |
| 所有线条粗细相同 | 其线宽为{{ui:默认值}}，因此以对话框中的笔宽打印。 | 在右侧面板中为图层或对象设置{{ui:线宽}}，或在对话框中选择{{ui:线宽}}。要在屏幕上查看线宽，请按状态栏中的{{ui:LWT}}。 |

## 按键和屏幕

| 现象 | 原因 | 解决方法 |
|---|---|---|
| F3、F7 或 F8 更改音量或打开 Mission Control | Mac 功能键。 | 按住**fn**，或使用状态栏按钮。见[键盘、鼠标和触控板](common:keys)。 |
| F7 询问是否启用插入点浏览 | Firefox 自身对 F7 的使用。 | 选择否；使用{{ui:栅格}}按钮。 |
| {{key:Mod+N}}打开了浏览器窗口 | 浏览器保留了该按键。 | 单击{{ui:新建}}或输入`NEW`。 |
| {{key:Mod+A}}选中了命令行中的文字 | 命令行中有光标。 | 先单击一个对象，或在`Select objects`提示处输入`ALL`。 |
| {{key:Delete}}无法删除 | 命令行中有光标。 | 输入`E`并按{{key:Enter}}。 |
| Mac 触控板上右键无反应 | Control-单击可能被视为普通单击。 | 用两指单击。 |
| 触控板无法平移 | 没有中键，空格键不能平移。 | 用两指滑动：2D 视图会平移（捏合和鼠标滚轮可缩放）。或在按住右键时拖动。 |
| 第一次{{key:Esc}}退出了全屏 | 浏览器使用 Esc 退出全屏。 | 再次按{{key:Esc}}以取消命令。 |
| {{key:F1}}在 Mac 上无反应 | F1 是亮度键。 | 按住**fn**，或单击{{ui:帮助}}。 |
| 输入的内容进入了帮助的搜索框 | 帮助面板有光标。 | 在图形上单击。 |
| 图形变空白 | 缩放得太远。 | 单击{{ui:范围}}，或双击滚轮。 |
| 关闭标签页时出现“离开此网站？” | 有未保存的更改。 | 选择“留在此页”，使用{{key:Mod+S}}保存，然后关闭。 |
