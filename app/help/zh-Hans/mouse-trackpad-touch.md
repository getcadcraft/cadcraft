CadCraft 专为带滚轮的鼠标而设计。所有功能也都可以通过触控板使用，只是需要养成一些新的操作习惯。触摸屏可用于拾取，但有一定限制。

## 滚轮鼠标

- **缩放：** 滚动滚轮。图形会以十字光标为中心缩放，因此请将光标指向你想查看的位置。
- **平移：** 按住滚轮并拖动，或用右键拖动。
- **缩放到全部内容：** 双击滚轮，或单击{{ui:范围}}。
- **返回上一视图：** 在视图组中单击{{ui:上一个}}，或输入`Z`、{{key:Enter}}、`P`、{{key:Enter}}。连续的滚轮步进算作一个视图，因此一次{{ui:上一个}}即可撤销它。对于经常要返回的视图，请使用{{cmd:NAMEDVIEW}}（`NV`）保存。
- **Enter：** 右键单击。

## 触控板

:::mac
- **平移：** 用两根手指在触控板上朝任意方向移动：图形会随手指移动。你也可以按住双指点击进行拖动（即右键拖动）。
- **缩放：** 用两根手指捏合。缩放以十字光标为中心。
- **右键单击（Enter）：** 用两根手指点击。如果无反应，请在“系统设置”中依次选择“触控板”，并打开“辅助点按”。在 CadCraft 中，Control 点击可能被视为普通单击而非右键单击，因此请使用双指点击。
- **缩放到某一区域：** 在视图组中单击{{ui:窗口}}，然后单击两个角点。
:::

:::windows linux
- **平移：** 用两根手指在触摸板上朝任意方向移动：图形会随手指移动。你也可以按住右键进行拖动。
- **缩放：** 用两根手指捏合。缩放以十字光标为中心。
- **右键单击（Enter）：** 用两根手指点击，或点击触摸板的右下角，取决于你的触摸板设置。
- **缩放到某一区域：** 在视图组中单击{{ui:窗口}}，然后单击两个角点。
:::

在 CadCraft 中按住{{key:Space}}并拖动**不会**平移：{{key:Space}}相当于{{key:Enter}}。

鼠标滚轮仍然逐步缩放。若触控板像滚轮一样以整步方式发送滚动信号，则双指滚动会执行缩放而非平移：请缩小视图，将光标指向想要的区域，然后再放大。三维选项卡保留其自身的触控板操作（参见 [在三维中查看模型](topic:3d-solids#look-around)）。

## 触摸屏和平板

CadCraft 将手指视为鼠标单击：

- 轻触可拾取一个点或对象，或进行选择。
- 在空白处拖动手指会绘制套索（向右先拖动为窗口，向左先拖动为窗交；参见 [套索选择](topic:lasso-selection)）。
- 在{{cmd:TRIM}}和{{cmd:EXTEND}}中，拖动手指经过多个图元即可一次性修剪或延伸它们。
- 拖动所选对象的夹点即可移动该夹点（夹点和拾取框对手指来说更大）。
- 用两根手指**捏合**可以以两指之间的点为中心进行缩放；两根手指一起移动即可**平移**。第二根手指会取消第一根手指所开始的操作，因此捏合不会留下任何痕迹。
- **长按**（保持静止约半秒）即为右键单击：{{key:Enter}}。它会结束命令、完成选择，或重复上一个命令。

在命令行下方会出现一个**按键行**：{{ui:Esc}}、{{ui:放弃}}、{{ui:重做}}、平板键盘会隐藏的字符（`@` `,` `<` `'` `"` `-`）、{{ui:捕捉}}、{{ui:正交}}、键盘按钮，以及一个大的{{ui:Enter}}。点按键盘按钮（或命令行）即可输入命令或数字。

没有悬停功能，因此捕捉标记仅在手指所在位置显示。

:::touch
你正在使用触摸屏。若需要进行较复杂的操作，连接键盘以及鼠标或触控板会让 CadCraft 的使用更加便捷。
:::

## 浏览器

CadCraft 在 Chrome、Edge、Firefox 和 Safari 中的表现相同，适用于 Mac、Windows 和 Linux。差异很小：

| 主题 | 需要了解的内容 |
|---|---|
| 打开 DWG | 大型图形在各浏览器中读取都需要几秒钟；此期间状态栏会显示“正在读取…” |
| 下载 | 每个浏览器决定下载的存放位置以及是否先询问；参见 [浏览器和计算机](common:browsers) |
| 打开以打印 | 在新标签页中打开 PDF。若浏览器阻止弹出窗口，CadCraft 会改为下载 PDF |
| F7 | Firefox 可能会提示开启插入符浏览；请选择“否” |
| 在有未保存的更改时离开 | 每个浏览器都会显示其自己的“离开网站？”提示，CadCraft 无法更改此提示 |

:::safari
在 Safari 中，使用{{ui:打开以打印}}打开的 PDF 可能会在标签页中显示而不进行打印：请使用**文件**，然后选择**打印**。
:::

:::firefox
Firefox 可能会询问每次下载的处理方式。请选择保存文件，或在 Firefox 设置的“下载”中一次性更改此选项。
:::
