## 从其他图形插入块

1. 输入`I`并按{{key:Enter}}，或在{{ui:块}}组中单击{{ui:插入}}。
2. 在提示`输入块名或 [文件/图库]`处，输入`F`并按{{key:Enter}}。
3. 选择本计算机上的 DWG 或 DXF 文件。该文件会被读取，但不会被打开，也不会上传任何内容。
4. 在{{ui:插入自}}对话框中，从列表中选择一个块（可在{{ui:筛选块}}中输入以查找），或保留{{ui:整个图形}}。单击{{ui:插入}}。
5. 单击放置位置，并填写其要求的任何属性。

整个图形会作为一个以文件名命名的块导入。所选块内部的块也会一并导入。它们所用的图层会添加到当前图形中。

若另一图形使用不同的单位（例如英寸和毫米），CadCraft 会缩放该参照以匹配，并在历史记录中说明。

### 名称已被使用时

若当前图形中已有同名的块，CadCraft 会询问：

- {{ui:保留现有的}}使用当前图形中该名称的块。
- {{ui:重命名}}将新块导入为`名称 (2)`。

整个插入操作为一个步骤：{{key:Mod+Z}}会同时撤销参照及复制的块定义。

## 打开图库

单击{{ui:块}}面板中的{{ui:图库…}}，或块组中的{{ui:图库}}，或输入`LIB`。在`INSERT`提示下，输入`L`同样可以打开图库。

图库有四个来源，以选项卡形式显示：

- {{ui:图库}}：CadCraft 图库。可按名称、制造商或型号搜索，并按类别筛选。
- {{ui:文件…}}：任意图库中的项目文件（`item.json`），或用于创建项目的图形、电子表格或三维模型：DWG 或 DXF（每个块成为一个项目）、包含名称和尺寸列的 CSV，或 glTF 或 OBJ 模型。不会上传任何内容。
- {{ui:标准}}：以截面、立面或三维构件形式呈现的型钢，以及螺栓、螺母和轴承等标准件，依据公开表格在此生成。请参阅[放置型钢和标准件](topic:steel-and-standard-parts)。
- {{ui:其他源}}：以与图库相同方式响应的其他图库。输入其地址一次即可；本浏览器会记住该地址。

每张卡片显示预览、名称、制造商和型号、许可证以及版本。已撤回的项目会标记为{{ui:已撤回}}并注明原因；放置前 CadCraft 会先询问。

## 放置项目

1. 单击卡片上的{{ui:放置}}。
2. 单击项目的放置位置。先输入`R`可旋转，或输入`S`可缩放。
3. 在`输入项目编号 (CC-ITEM)`提示处，按{{key:Enter}}使用下一个可用编号，或输入自定义编号。

该项目会成为名为`LIB_<name>_v<version>`的块，并按本图形的单位绘制。若图形未设置单位，项目将以毫米插入，并在历史记录中说明；请先在右侧面板中设置{{ui:单位}}。

其数据以不可见属性的形式随之保存：项目的 ID 和版本、许可证和署名、制造商、型号、类别及尺寸。请参阅[块属性](topic:attributes)。

## 使用当前语言的项目

项目可以附带其他语言的名称和说明。当项目具有 CadCraft 所设置语言的名称和说明时（设置 › 常规 › 语言），卡片和已放置块的项目名称将使用这些内容。块本身使用根据项目自身名称生成的名称，因此无论以哪种语言放置，同一项目在图形中只对应一个块。

## 检查更新

1. 打开图库。
2. 单击{{ui:检查更新}}。

图形中的每个图库项目都会列出其项目编号，并显示其是否为最新版本、是否有较新版本（并列出更改内容），或已被撤回。单击某一行的{{ui:更新}}，或单击{{ui:全部更新}}。每个引用都会移至新版本的块，并保留其项目编号、数量、位置、角度和图层。{{key:Mod+Z}}可撤销更新。

## 注明所用内容的署名

单击{{ui:图库致谢}}。每个项目都会列出其署名行和许可证。

- {{ui:复制署名}}复制单个项目的署名行；{{ui:全部复制}}复制所有署名行。
- {{ui:下载CSV}}保存包含项目编号、制造商、型号、许可证和署名的列表。可在任何电子表格中打开。

CC BY 等许可证要求在使用作品处注明作者。请将署名行放在图形上、说明书中或项目备注中。

## 符号与资产

图库包含三类项目：符号（2D 图纸约定）、类型（元素的构成）和资产（实体对象）。在{{ui:图库}}选项卡中，{{ui:项目类型}}列表可选择显示符号和资产、仅显示符号，或仅显示资产。类型是 BimCraft 项目的构建基础，因此 CadCraft 不会列出它们。

## 登录图库

单击{{ui:登录图库}}。站点会打开一个小窗口；在站点登录后，CadCraft 可以显示团队的项目，并记录放置的内容，以便在所用项目发生变化时收到通知。登录状态仅在本浏览器标签页中有效。可随时在账户的安全页面中撤销。

## 常见错误

- **“从 IFC 类型创建项目请在 BimCraft 中完成。”** IFC 和族文件在 BimCraft 应用中读取。请在该应用或图库中创建项目，然后在此处使用其 `item.json`。
- **“无法连接到图库。”** 您所在的计算机处于离线状态，或图库暂时不可用。图形中已有的项目不受影响。
- **项目过大或过小。** 图形的单位设置错误或未设置。撤销操作，设置{{ui:单位}}，然后重新放置。
