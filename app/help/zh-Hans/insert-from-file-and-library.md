## 从其他图形插入块

1. 输入 `I` 并按 {{key:Enter}}，或单击“块”组中的 {{ui:插入}}。
2. 窗口底部的命令行询问 `输入块名或 [文件(F)/库(L)]`。在此输入 `F` 并按 {{key:Enter}}。
3. 选择本计算机上的 DWG 或 DXF。它在此处被读取，但不会被打开，也不会上传任何内容。
4. 在 {{ui:从…插入}} 对话框中，从列表中选择一个块（在 {{ui:筛选块}} 中输入以查找），或保持 {{ui:整个图形}} 选中。单击 {{ui:插入}}。
5. 单击放置位置，并填写其要求的任何属性。

你也可以从 {{ui:块}} 面板开始：在其 {{ui:筛选块}} 框中输入 `F` 并按 {{key:Enter}}，或输入一个没有任何块匹配的内容，然后单击 {{ui:从文件…}}。`L` 和 {{ui:图库…}} 以同样的方式打开图库。0.10.1 版之前，在 {{ui:筛选块}} 中输入字母只会搜索本图形的块，并回答“没有块与筛选条件匹配。”

若要随手保存你自己的块图形，请在 {{ui:块}} 面板的 {{ui:库}} 下单击 {{ui:添加图形}}，并选择 DWG 或 DXF。其块会以图片列出；单击其中一个即可放置。

整张图形会作为一个块导入，以该文件命名。所选块内部嵌套的块也会一并导入。它们所用的图层会被添加到本图形中。

若另一图形的单位不同（例如英寸与毫米），CadCraft 会缩放参照以使其匹配，并在历史记录中予以说明。

### 名称已被使用时

若本图形中已存在同名的块，CadCraft 会询问：

- {{ui:保留现有的}} 使用本图形中该名称的块。
- {{ui:重命名}} 将新块以 `名称 (2)` 的形式导入。

整个插入为一步：{{key:Mod+Z}} 会将该参照及复制的定义一并删除。

## 打开图库

单击 {{ui:块}} 面板中的 {{ui:图库…}}，或“块”组中的 {{ui:图库}}，或输入 `LIB`。在 `INSERT` 提示处，`L` 同样会打开图库。

图库有四个来源，以选项卡形式呈现：

- {{ui:图库}}：CadCraft 图库。可按名称、制造商或型号搜索，并按类别筛选。
- {{ui:文件…}}：来自任何图库的项目文件（`item.json`），或用于制作项目的图形、电子表格或三维模型：DWG 或 DXF（每个块成为一个项目），带有名称和尺寸列的 CSV，或 glTF 或 OBJ 模型。不会上传任何内容。
- {{ui:标准}}：型钢截面（作为截面、立面或三维构件）以及螺栓、螺母和轴承等标准件，依据已发布的表格在此生成。参见 [放置钢型材与标准件](topic:steel-and-standard-parts)。
- {{ui:其他源}}：以与图库相同方式应答的其他图库。添加其地址一次即可；此浏览器会记住它。

每张卡片显示预览、名称、制造商和型号、许可证以及版本。已撤回的项目会标记 {{ui:已撤回}} 及其原因；放置前 CadCraft 会先询问。

## 放置项目

1. 单击卡片上的 {{ui:放置}}。
2. 单击项目的放置位置。先输入 `R` 可旋转它，或输入 `S` 可缩放它。
3. 在 `输入项目编号 (CC-ITEM)` 处，按 {{key:Enter}} 使用下一个可用编号，或输入你自己的编号。

该项目会成为名为 `LIB_<名称>_v<版本>` 的块，并以本图形的单位绘制。若图形没有单位，项目将以毫米放置，历史记录会予以说明；请先在右侧面板中设置 {{ui:单位}}。

其数据以不可见属性的形式附带：项目的编号和版本、许可证和署名、制造商、型号、类别以及尺寸。参见 [块属性](topic:attributes)。

## 你所用语言的项目

项目可以包含其他语言的名称和说明。当其包含 CadCraft 所设语言（设置 › 常规 › 语言）的内容时，卡片和所放置块的项目名称会使用它们。块本身保留由项目自身名称生成的名称，因此无论由哪种语言放置，一个图形中每个项目只有一个块。

## 检查更新

1. 打开图库。
2. 单击 {{ui:检查更新}}。

图形中的每个图库项目都会列出其项目编号，以及它是否为最新版本、是否有较新的版本（及其变化内容），或是否已被撤回。单击某行上的 {{ui:更新}}，或单击 {{ui:全部更新}}。每个参照都会移到新版本的块，并保留其项目编号、数量、位置、角度和图层。{{key:Mod+Z}} 可撤销更新。

## 为你所用的内容署名

单击 {{ui:图库致谢}}。每个项目都会以其署名行和许可证列出。

- {{ui:复制署名}} 复制一个项目的署名行；{{ui:全部复制}} 复制每一行。
- {{ui:下载CSV}} 保存包含项目编号、制造商、型号、许可证和署名的列表。它可在任何电子表格中打开。

CC BY 等许可证要求你在使用作品的地方注明作者。请将这些署名行放在图形、说明书或项目备注中。

## 符号与资产

图库有三类项目：符号（图纸约定，二维）、类型（元素由什么构成）和资产（实物对象）。在 {{ui:图库}} 选项卡中，{{ui:项目类型}} 列表可显示符号和资产，仅显示符号，或仅显示资产。类型是 BimCraft 项目的组成部分，因此 CadCraft 不列出它们。

## 登录图库

单击 {{ui:登录图库}}。站点上会打开一个小窗口；在那里登录后，CadCraft 即可显示你团队的项目，并记录你放置的内容，以便你所用的项目发生变化时得到通知。登录在此浏览器标签页中有效。可随时在你的账户安全页面中撤销。

## 在“我的对象”中保存你自己的对象

{{ui:我的对象}} 是图库中仅你自己可见的私人列表。它不在公共图库中，不出现在搜索结果中，也不向你的团队显示；登录图库的每台计算机上它都会随你的账户同步。

1. 在图库面板中，单击 {{ui:文件…}} 并读取一个文件。
2. 在你想再次使用的项目上，单击 {{ui:保存到我的对象}}。
3. 之后单击 {{ui:我的对象}}，再单击 {{ui:放置}}。它的放置方式与任何图库项目相同，{{ui:检查更新}} 也适用于它。
4. {{ui:从我的对象中移除}} 将其从列表中删除。已放入图形的副本保持不变。

你需要登录图库。读取文件不会上传任何内容；保存项目只会将该项目发送到你的账户。

:::note
“我的对象”仍在测试中，可能尚未对你的账户开放。若显示“我的对象尚未对此账户开放”，你仍可以通过 {{ui:文件…}} 放置你自己文件中的项目。
:::

## 常见错误

- **“从 IFC 类型制作项目属于 BimCraft。”** IFC 和族文件在 BimCraft 应用中读取。请在那里或图库中制作项目，然后在此使用其 `item.json`。
- **“无法连接图库。”** 你处于离线状态，或图库暂时不可用。图形中已有的项目不受影响。
- **项目过大或过小。** 图形的单位错误或未设置。请撤销，设置 {{ui:单位}}，然后重新放置。
