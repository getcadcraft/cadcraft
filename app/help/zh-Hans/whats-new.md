以下是 CadCraft 0.8 和 0.8.1 相对于 0.7 的变更。0.8（2026 年 11 月 1 日）新增了基于图形本身的绘图辅助功能，依据计算机上的规则运行，无需模型；0.8.1（2026 年 11 月 2 日）修复了发布后反馈的问题。

## 新增

### 让绘图自动补全

- **虚影显示接下来的内容。** 没有命令运行时，灰色虚线虚影会根据图形自身的规律显示接下来的内容：同样间距的下一根龙骨、楼梯的下一级台阶、房间缺少的那面墙。按{{key:Tab}}可将其作为一步撤销绘制出来，按{{key:Esc}}则取消。它只分析最新的对象，因此在大型图形上依然流畅。可在{{ui:设置}} › {{ui:CadCraft}}中关闭，或输入{{cmd:AUTOCOMPLETE}} `Off`。
- **绘制直线时的下一个点。** 在{{cmd:LINE}}或{{cmd:PLINE}}命令执行过程中，虚影显示下一个点：楼梯的下一级台阶、矩形的第四个角，或使其闭合的点。将光标靠近该点后按{{key:Tab}}，效果如同在那里单击。
- **手绘草图转为精确几何图形。** {{cmd:SKETCHFIX}}：用笔、鼠标或手指绘制粗略的线条，每一条都会变为整洁的直线、圆、圆弧、矩形或多段线，并与已有图形对齐。参见[用笔绘草图并得到精确几何图形](topic:sketch-with-a-pen)。
- **草图照片转为图形。** {{cmd:PHOTOSKETCH}}（`PSK`）在照片中找到纸张，校正透视，应用你指定的图纸尺寸和比例，并为每种笔的颜色将笔迹描摹到一个图层上。文字不会被描摹。
- **按规则标注。** {{cmd:AUTODIM}}（`ADIM`）沿你选择的边生成连续标注链、总体尺寸、洞口宽度、孔径，以及使用`Grid`时的网格间距。已存在的标注不会重复添加。
- **移动轴网线，相关图形随之调整。** {{cmd:GRIDMOVE}}（`GM`）：止于轴网线的墙随之拉伸，沿轴网线的墙、柱、轴号及标记一并移动，位于其上的标注测量新的间距。只需一步撤销。

### 布局、详图和标记

- **自动排布的布局。** {{cmd:AUTOSHEET}}会采用你的命名视图（或模型中各个独立部分），选定图纸尺寸和标准比例，并将视图放到新布局上，附带标题栏和名称及比例说明。所有内容仍可编辑。参见[自动排布布局](topic:lay-out-sheets-for-me)。
- **在绘制时提供你的详图。** {{cmd:DETAILS}}（`DET`）保存你自己的详图块。当所选内容与某个详图块的图层名、块名或注释中的文字相符时，状态栏会予以提示，选择后即可放置。{{cmd:DETAILS}} › 共享会将你的列表放入“文档”文件夹，并引入团队新增的内容。在设置中可关闭这些提示。
- **块上的标记。** {{cmd:TAGS}}定义标记（其类型、可取的值、适用的块），将其设置到你所选的块参照上，并将它们列为可保存为 CSV 的明细表。标记的定义保存在 DWG 中。参见[标记](topic:tags)。
- **图形界限。** {{cmd:LIMITS}}为图形设定一个矩形范围：网格覆盖该范围，“全部缩放”会显示该范围。界限以轮廓线显示，并与图纸界限一起保存在 DWG 和 DXF 中。参见[设置图形界限](topic:drawing-limits)。

### 与他人及其他程序协作

- **将批注转为修订。** {{cmd:REDLINE}}读取 MarkupCraft 生成的包，并列出每一项变更。逐项接受或拒绝并附加注释；接受的项目会在一步撤销中生成修订云线和修订日志，你还需保存答复文件，以便在 MarkupCraft 中关闭批注。参见[将批注转为修订](topic:redline-to-revision)。
- **可由 git 和 Fossil 合并的图形。** 在{{ui:设置}} › {{ui:CadCraft}}中开启{{ui:便于合并的文件}}后，每个对象都会获得一个永不改变的键（文件约大10%）。`cadcraft merge base ours theirs`随后会按对象合并两人对同一 DWG 或 DXF 的编辑，并且只报告两人修改了同一内容的位置。参见[合并一张图形的两人编辑](topic:merge-drawings)。
- **以文字说明变更。** 在“历史”中，“比较”会给出简明列表：哪些位置发生了变化、这些区域有多大、新增、删除或修改了什么，以及被编辑的文字。参见[以文字说明变更](topic:changes-in-words)。
- **象限角和角度。** 在任何要求输入角度的地方，都可以将方向输入为测量员的象限角，如 N45°23'30"E，也可以用度、分、秒表示；AUNITS 设置角度的显示方式。参见[输入和显示象限角与角度](topic:bearings-and-angles)。
- **你自己的 SHX 字体。** 为 CadCraft 指定一个 SHX 字体文件夹后，引用这些字体的文字样式会在屏幕和打印输出中使用它们绘制。参见[用你自己的 SHX 字体绘制文字](topic:shx-fonts)。
- **根据文本绘制图表。** {{cmd:DIAGRAM}}读取 Mermaid 流程图、PlantUML 组件图、D2 或“从-到”列表，并绘制可编辑的块和连接线。参见[根据文本绘制图表](topic:text-to-diagram)。
- **DWG 中的 OLE 对象。** {{cmd:OLELIST}}列出 DWG 中 CadCraft 无法自行放置的 OLE 对象，并可在你指定的位置放置一份图片副本。参见[图片](topic:pictures#objects-from-other-programs-ole)。
- **计算结果随图形保存。** 计算表和设计依据与类别表一起保存在 DWG 中。

### 无视力绘图

- 在{{ui:设置}}中开启{{ui:无视力绘图}}（或输入{{cmd:ACCESS}}并回答`On`）。CadCraft 会通过屏幕阅读器播报每条命令和结果，描述图形以及光标附近的内容，允许你用键盘移动光标并拾取点，并为每个捕捉和夹点播放提示音。如果你的浏览器能在本机识别语音，还可以用语音输入命令。参见[无视力绘图](topic:draft-without-sight)。

### 所有应用中的功能

- **语言。** 支持54种语言，其中10种为新增（立陶宛语、拉脱维亚语、波斯尼亚语、马拉地语、泰卢固语、阿尔巴尼亚语、南非荷兰语、菲律宾语、斯瓦希里语、乌兹别克语）。英语以外的语言在母语者审校之前均为机器草稿。
- **输入设备。** 触控板、手写笔、3D 鼠标、游戏手柄和 MIDI 控制器。
- **工具栏行数和属性表。** {{ui:设置}} › {{ui:常规}} › {{ui:工具栏行数}}在其他应用中提供换行、2 行或 1 行选项。CadCraft 在{{ui:设置}} › {{ui:CadCraft}}中保留自己的设置（参见[工具栏行数](topic:settings#toolbar-rows)）。共享属性表位于其他三个应用中，不在 CadCraft 中。
- **问题、Live 和插件。** 所有应用共用的问题面板会在每个应用中发出警告；CadCraft Studio 中的 Live 视图显示每个人所在的位置（参见[共同编辑一张图形](topic:work-live)）；此外还有插件列表。
- **连接 AI。** 从 CadCraft Studio 一次连接全部八个应用，每个应用可设置只读、建议或编辑级别，并提供以简明文字记录助手操作的日志。CadCraft 本身不含 AI，“在每个应用中提问”功能使用你所连接的 AI。

## 0.8.1 中的修复

- **在英尺和英寸图形中，属性显示为 150 而非 12'-6"。** 应用自行读取的字段现在恢复显示其文字。
- **类别部分被误读为其他类型的 DWG 文件**（GitHub cadcraft#5）现已能正确打开。
- **十字光标不再显示在弹出窗口后面。**
- **Studio 和打包版可在运行时切换语言。** 此前仅支持英语。尚未在所有平台上测试：如果语言未能切换，请告知我们。
- **竖屏平板**会将多余的网格高度让给绘图区，布局模式在 760 px 或更小时启动。
- **使用窗交窗口的 STRETCH，以及 LIMITS**，曾在 Studio 0.8.0 上有人报告，但在 0.8 网页版中已是正确的；报告人使用的安装程序较旧。Studio 0.8.1 已包含这些修复。

## 本版本尚未实现的内容

- **0.8 和 0.8.1 未进行代码签名。** Windows 可能会发出警告（请选择{{ui:更多信息}}，然后{{ui:仍然运行}}）；在 Mac 上，请右键点击 CadCraft Studio 并选择{{ui:打开}}。应用商店版本暂缓发布，iPad 和 iPhone 版未为 0.8.1 重新构建。
- **手绘草图和草图照片**仅在模拟照片和鼠标上测试过，尚未使用真实的笔、触摸屏或纸上手绘草图进行测试。
- **无视力绘图**已通过自动化检查测试，尚未使用屏幕阅读器或盲人测试人员进行测试。
- **共享详图**尚未经过两人核对，并且将 Team Cloud Plan 文件夹作为“文档”文件夹的功能尚未实现。
- **合并**适用于 CadCraft 的 DWG 和 DXF 文件；其他应用的文件尚未支持。
- **跨窗口撤销：** CadCraft 会报告每个已完成的步骤，但 Studio 尚无适用于所有应用的统一撤销；每个应用各自撤销自己的步骤。
- **DWG 中的 OLE 对象**会被保留，但不会在原位置绘制。
- **读取打印样式表（CTB 文件）**的功能已完成，但尚未用其他程序生成的文件进行检查。
- **连接 AI：** Studio 中的一键连接、面向浏览器 AI 的托管连接器、Studio 内使用你自己的 API 密钥，以及已发布的 MCP 包均未包含在本版本中。

上一版本的内容，请参阅[0.7 新增功能](topic:whats-new-0-7)。
