以下是 CadCraft 0.9 相对于 0.8.1 的变化。CadCraft 是 CadCraft Studio 0.9 及其八个应用中的 2D 和 3D 绘图应用。0.9 完善了平面绘图，新增了文字样式和真正的文字编辑器，并为屏幕提供了更多空间。

## 新增

### 平面绘图

- **填充跟随其边界。** {{cmd:HATCH}} 会与其边界相关联。移动、旋转或缩放边界时，填充及其图案随之变化；修改边界形状时，填充会重新计算。{{cmd:HATCHEDIT}}（`HE`）可在之后修改填充，并建立或解除这种关联。参见 [填充和填充区域](topic:hatch)。
- **填充图案文件。** 在 {{cmd:HATCH}} 的提示 `Pick internal point` 处，输入 `F`（图案文件），然后选择一个 `.pat` 文件。仅测试过符合常用格式的文件。
- **图层组。** 在{{ui:Tools}}中的{{ui:Layers}}面板上：{{ui:New group}}、{{ui:Add ready-made groups}}、{{ui:Group by name}}和{{ui:Find a layer}}；或输入 {{cmd:LAYGROUP}}（`LG`）。参见 [用图层组织图形](topic:layers#group-layers)。
- **叠放楼层。** {{cmd:FLOORS}}（`FLR`），或{{ui:View}}组中{{ui:More}}菜单里的{{ui:Floors…}}。布局上的视口可在特性中通过{{ui:Floor shown}}显示某一层。{{cmd:FLOORLAYERS}}可将楼层转为图层，适用于要发送给他人的文件。参见 [在一个图形中叠放楼层](topic:floors)。
- **2D 智能墙、门和窗。** {{cmd:WALL}}（`WA`）、{{cmd:DOOR}}（`DR`）、{{cmd:WINDOW}}（`WN`）和 {{cmd:DELOPENING}}。转角、T 形连接和交叉处会自动计算。墙会记录自己的连接方式；特性中新增了“禁止在起点连接”、“禁止在终点连接”、“位置”行以及可编辑的“长度”。参见 [绘制 2D 墙、门和窗](topic:walls-2d)。
- **平面墙的墙工具。** 输入 {{cmd:WALLRECT}}、{{cmd:WALLPOLY}}、{{cmd:WALLARC}}、{{cmd:WALLTRACE}}、{{cmd:WALLDIM}}、{{cmd:WALLOFFSET}}、{{cmd:WALLSPLIT}}、{{cmd:WALLGRID}} 等命令。它们目前还没有工具栏按钮。参见 [2D 墙的形状、剪切、偏移和锁定](topic:wall-tools-2d)。

### 文字

- **文字样式。** {{cmd:STYLE}}（`ST`），或{{ui:Draw}}工具栏上的{{ui:Text style}}：可命名的样式，包含字体、高度、宽度比例和倾斜度。参见 [用文字样式设置文字的字体和大小](topic:text-styles)。
- **格式化的段落文字编辑器。** {{cmd:MTEXT}}、{{cmd:TEXTEDIT}}，或双击文字，都会打开一个方框，可设置字体、大小、粗体、斜体、下划线、删除线、颜色、对齐方式，以及度数、正负号和直径符号，并带有{{ui:OK}}和{{ui:Cancel}}按钮。参见 [设置段落文字格式](topic:format-paragraph-text)。
- **从 draw.io XML 生成图表。** {{cmd:DIAGRAM}}（`T2D`）也可读取粘贴的 draw.io XML。参见 [从文字绘制图表](topic:text-to-diagram)。
- **PDF 打印中的泰文。** 以前打印出来是问号。

### 更多空间与绘图辅助

- **浮动且更薄的命令行，以及更紧凑的顶部区域。** 拖动命令行的夹点可使其浮动，拖动其顶边可减少行数，{{key:F2}}打开历史记录。{{ui:Settings}} › {{ui:CadCraft}} › {{ui:Command line}}以及顶部区域的选项提供相同的设置。参见 [设置](topic:settings#command-line)。
- **对象捕捉菜单。** 在状态栏中右键单击{{ui:Snap}}，或输入 {{cmd:OSNAP}}。
- **捕捉到栅格。** 状态栏中的{{ui:Grid snap}}按钮，或{{key:F9}}：当没有对象捕捉命中时，拾取的点会移到最近的栅格点。
- **十种方式绘制圆弧，以及“继续”。** 绘图工具栏上的{{ui:Arc}}或 {{cmd:ARC}}：三点、起点/圆心/端点系列、圆心/起点/端点系列，以及“继续”（在起点处按{{key:Enter}}），可从上一条直线、圆弧或多段线继续绘制。
- **文档面板。** {{cmd:DOCUMENTS}}（`DOCS`），或{{ui:View}}组中{{ui:More}}菜单里的{{ui:Documents…}}：显示项目文件夹中每个图形的修订、状态和签出情况。它以居中对话框的形式打开。参见 [文档](topic:documents)。

### 文件

- **英国钢型材规格。** “标准”面板中有 976 种截面，按图纸上的写法输入（例如 `305x165x40 UB`）。
- **南非规范包**（制图惯例和建筑法规），以“建筑法规”插件的规范包形式提供。数值尚未核实。
- **CadCraft 插件**，按需添加，默认关闭：室内照明设计、芯片设计（从 HDL 到版图）、雕刻机雕刻、电路仿真、滚子链链轮，以及建筑法规国家规范包。

## 修复

- 移动、旋转或缩放填充时，其图案会留在原处。
- {{cmd:GRIDMOVE}} 会带动只从栅格线开始的整段平面墙。现在按墙的两端判断。
- 即使关闭了图形界限，栅格仍只显示在图形界限之内。
- 侧边面板中的块列表可以滚动；名称不是块的，会列出以它开头的块（“是否要找”）。
- AutoCAD 拒绝的 DXF R12 文件（“Unknown group 1001 for table”）现在可以在此打开。
- 非常大的文件（约 70,000 个对象及以上）打开时报错“Maximum call stack size exceeded”。
- 高维护版本的 AutoCAD 2018 及更高版本 DWG 文件打开时报错“bad BITLONG code 11”。
- 在段落文字框中，为选中部分输入的新字号会保留选择。

## 所有应用

所有带提示的控件都有 Bootstrap 工具提示，有一个可关闭的起始提示，选项卡放不下时可以滚动，浏览器标签页的标题会跟随当前打开的图形（`<drawing> - CadCraft | CadCraft`）。{{ui:Settings}} › {{ui:Layout}}现在是双行选项的下拉列表。{{ui:Settings}}中的语言列表比 0.8 更长。实时协作、库集合以及重量和温度单位，在 Studio 说明中介绍。

## 已知局限

- 段落文字不支持项目符号或编号列表、制表位标尺或两端对齐。打印的 PDF 中文字使用 Helvetica 字体。
- 平面墙是直的，因此圆弧会画成多段短墙。墙工具的社区人工检查仍在进行中。
- 图层组不以 AutoCAD 自身的格式保存，因此 AutoCAD 显示为平面列表。除非运行 {{cmd:FLOORLAYERS}}，其他程序会将所有楼层显示在一起。
- 文档面板尚未在真实的共享文件夹上由两人测试。雕刻机雕刻尚未在任何真实机器上运行。照明估算是用光子追踪检验的，并未与其他程序对比。工程类插件只是检查辅助工具，不能替代工程师的审查。
- 英语以外的语言都是机器草稿，部分新词仅有英文。

## 更早版本：0.8 和 0.8.1

以下是 CadCraft 0.8 和 0.8.1 相对于 0.7 的变化。0.8（2026 年 11 月 1 日）新增了绘图辅助功能，它们基于图形本身，通过计算机上的规则工作，无需模型；0.8.1（2026 年 11 月 2 日）修复了发布后报告的错误。

### 新增

**绘图时会自动补全下一步**

- **幽灵提示显示接下来的内容。** 在没有命令运行时，一个灰色虚线的幽灵提示会根据图形自身的图案显示接下来可能的内容：同一间距的下一根柱子、楼梯的下一级、房间缺失的那面墙。按{{key:Tab}}将其绘制为一步撤销操作，或按{{key:Esc}}取消。它只分析最新的对象，因此在大图上依然流畅。可在{{ui:Settings}} › {{ui:CadCraft}}中关闭，或输入 {{cmd:AUTOCOMPLETE}} `Off`。
- **画线时的下一个点。** 在{{cmd:LINE}}或{{cmd:PLINE}}过程中，幽灵提示就是下一个点：楼梯的下一级、矩形的第四个角，或使其闭合的点。将光标移到附近并按{{key:Tab}}，就如同在那里点击了一样。
- **手绘草图变为精确几何。** {{cmd:SKETCHFIX}}：用笔、鼠标或手指画出粗略的线条，每一条都会变成干净的直线、圆、圆弧、矩形或多段线，并与已有图形对齐。参见 [用笔草图获得精确几何](topic:sketch-with-a-pen)。
- **草图照片变为图形。** {{cmd:PHOTOSKETCH}}（`PSK`）在照片中找到纸张，校正透视，应用你给定的图纸尺寸和比例，并将笔迹按每种笔色分别描到一个图层上。文字不会被描摹。
- **按规则自动标注尺寸。** {{cmd:AUTODIM}}（`ADIM`）沿你选择的边生成连续尺寸链、总尺寸、开口宽度、孔径，以及使用 `Grid` 时的栅格间距。它不会重复已有的尺寸。
- **移动一条栅格线，整组随之变化。** {{cmd:GRIDMOVE}}（`GM`）：止于栅格线的墙随之拉伸，沿栅格线的墙、柱子、轴线标头和标签都会移动，位于其上的尺寸会测量新的间距。一步撤销。

**布局、详图和标记**

- **自动排布的布局。** {{cmd:AUTOSHEET}}会获取你的命名视图（或模型的各个独立部分），选择图纸尺寸和标准比例，并将视图放到带有标题栏以及名称和比例说明的新布局上。所有内容仍可编辑。参见 [为我自动创建布局](topic:lay-out-sheets-for-me)。
- **事务所的详图，绘制时即时提供。** {{cmd:DETAILS}}（`DET`）保存你自己的详图块。当所选内容与某个块的图层名称、块名或注释中的文字相符时，状态栏会提示；选择并放置即可。{{cmd:DETAILS}} › 共享会将你的列表放入“文档”文件夹，并引入团队新增的内容。在设置中可以关闭这些提示。
- **块上的标记。** {{cmd:TAGS}}定义标记（其类型、可取的值、适用的块），将其设置到你选中的块参照上，并将它们列为可保存为 CSV 的明细表。标记的定义保存在 DWG 中。参见 [标记](topic:tags)。
- **图形界限。** {{cmd:LIMITS}}为图形设置一个矩形：栅格填满它，全部缩放会显示它。界限以轮廓显示，并与图纸界限一起保存在 DWG 和 DXF 中。参见 [设置图形界限](topic:drawing-limits)。

**与他人及其他程序协作**

- **将批注转换为修订。** {{cmd:REDLINE}}读取 MarkupCraft 写出的包，并列出每一项更改。对每一项可接受或拒绝并附上注释；被接受的项会在一步撤销中获得修订云线和修订日志，并保存用于在 MarkupCraft 中关闭这些批注的答复文件。参见 [将批注转换为修订](topic:redline-to-revision)。
- **可由 git 和 Fossil 合并的图形。** 在{{ui:Settings}} › {{ui:CadCraft}}中开启{{ui:Merge-friendly files}}后，每个对象都会获得一个永不改变的键（文件约大 10%）。`cadcraft merge base ours theirs` 会按对象合并两人对同一个 DWG 或 DXF 的编辑，并且只报告两人改动了同一内容的地方。参见 [合并两人对同一图形的编辑](topic:merge-drawings)。
- **用文字描述变化。** 在历史记录中，“比较”会给出一份通俗的列表：哪些地方发生了变化、变化区域有多大、增加、删除或修改了什么，以及被编辑的文字。参见 [用文字说明变化](topic:changes-in-words)。
- **方位角与角度。** 在任何需要输入角度的地方，都可以将方向输入为测量员的方位角，例如 N45°23'30"E，或以度、分、秒输入；AUNITS 设置角度的显示方式。参见 [输入和显示方位角与角度](topic:bearings-and-angles)。
- **自定义 SHX 字体。** 为 CadCraft 指定一个 SHX 字体文件夹后，以它们命名的文字样式会用这些字体绘制，屏幕显示和打印都是如此。参见 [使用自定义 SHX 字体绘制文字](topic:shx-fonts)。
- **文字形式的图表。** {{cmd:DIAGRAM}}读取 Mermaid 流程图、PlantUML 组件图、D2 或“从-到”列表，并绘制可编辑的块和连接线。参见 [从文字绘制图表](topic:text-to-diagram)。
- **DWG 中的 OLE 对象。** {{cmd:OLELIST}}列出 DWG 中 CadCraft 无法自行放置的 OLE 对象，并在你指定的位置放置一份图片副本。参见 [图片](topic:pictures#objects-from-other-programs-ole)。
- **计算书与设计依据随图形保存。** 计算表和设计依据与类表一起保存在 DWG 中。

**无视力绘图**

- 在{{ui:Settings}}中开启{{ui:Drafting without sight}}（或输入 {{cmd:ACCESS}} 并回答 `On`）。CadCraft 会通过屏幕阅读器朗读每个命令和结果，描述图形以及光标附近的内容，允许用键盘移动光标并选取点，并为每次捕捉和夹点播放声音。若浏览器能在计算机上识别语音，则可以用语音下达命令。参见 [无视力绘图](topic:draft-without-sight)。

**所有应用**

- **语言。** 54 种语言；其中十种是新增的（立陶宛语、拉脱维亚语、波斯尼亚语、马拉地语、泰卢固语、阿尔巴尼亚语、南非荷兰语、菲律宾语、斯瓦希里语、乌兹别克语）。英语以外的语言在母语者审阅之前都是机器草稿。
- **输入设备。** 触控板、手写笔、3D 鼠标、游戏手柄和 MIDI 控制器。
- **工具栏行数与属性表。** {{ui:Settings}} › {{ui:General}} › {{ui:Toolbar rows}} 在其他应用中提供“换行”、2 行或 1 行。CadCraft 在{{ui:Settings}} › {{ui:CadCraft}}中保留自己的设置（参见 [工具栏行数](topic:settings#toolbar-rows)）。共享的属性表位于其他三个应用中，不在 CadCraft 中。
- **问题、实时协作与插件。** 一个在所有应用中发出警告的共享“问题”面板，CadCraft Studio 中显示每个人所在位置的 Live 视图（参见 [与他人共同编辑一个图形](topic:work-live)），以及插件列表。
- **连接 AI。** 在 CadCraft Studio 中一次连接全部八个应用，每个应用可设置只读、建议或编辑级别，并提供用通俗文字记录助手所做操作的日志。CadCraft 自身不包含 AI，所有应用中的“提问”都使用你所连接的 AI。

### 0.8.1 修复

- **英尺英寸图形中，特性显示 150 而不是 12'-6"。** 应用自己读取的字段重新保留其文字。
- **类节被当作错误类型读取的 DWG 文件**（GitHub cadcraft#5）现在可以正确打开。
- **十字光标不再显示在弹出窗口后面。**
- **Studio 和打包版可在运行时切换语言。** 之前仅支持英文。尚未在所有平台测试：如果语言没有切换，请告知我们。
- **竖屏平板**会将多余的高度让给画布，布局模式在 760 px 或更小时启动。
- **带交叉窗口的 STRETCH 以及 LIMITS**，曾在 Studio 0.8.0 上被报告有问题，而在 0.8 网页版中已经正确；报告者使用的安装程序较旧。Studio 0.8.1 已包含这些修复。

### 本版本尚未包含

- **0.8 和 0.8.1 未进行代码签名。** Windows 可能会发出警告（选择{{ui:More info}}，然后{{ui:Run anyway}}）；在 Mac 上，右键单击 CadCraft Studio 并选择{{ui:Open}}。应用商店版本暂缓发布，iPad 和 iPhone 版本未针对 0.8.1 重新构建。
- **手绘草图和草图照片**仅在模拟照片和鼠标上测试过，尚未使用真实的笔、触摸屏或纸上的手绘草图测试。
- **无视力绘图**仅通过自动检查测试，尚未由屏幕阅读器或盲人测试者测试。
- **共享详图**尚未经过两人检查，且尚未实现将 Team Cloud Plan 文件夹用作“文档”文件夹。
- **合并**仅适用于 CadCraft 的 DWG 和 DXF 文件；其他应用的文件尚未支持。
- **跨窗口撤销：** CadCraft 会报告每个完成的步骤，但 Studio 尚无适用于所有应用的统一撤销；每个应用只撤销各自的步骤。
- **DWG 的 OLE 对象**会被保留，但不会在原位绘制。
- **读取打印样式表（CTB 文件）**已实现，但尚未用其他程序的文件检验。
- **连接 AI：** Studio 中的一键连接、用于浏览器 AI 的托管连接器、Studio 内自有的 API 密钥，以及已发布的 MCP 包，均未在本版本中承诺。

有关上一版本，参见 [0.7 新增功能](topic:whats-new-0-7)。
