以下是 CadCraft 0.9 相对于 0.8.1 的变化。CadCraft 是 CadCraft Studio 0.9 及其八个应用中的二维和三维绘图应用。0.9 完成了平面绘图功能，增加了文字样式和真正的文字编辑器，并为屏幕提供了更多空间。

## 新增

### 平面绘图

- **随边界保持关联的填充。** {{cmd:HATCH}} 与限定它的边界相关联。移动、旋转或缩放边界时，填充及其图案会随之变化；重塑边界时，填充会重新计算。{{cmd:HATCHEDIT}}（`HE`）可在之后修改填充，并建立或结束关联。参见 [填充与填充区域](topic:hatch)。
- **填充图案文件。** 在 {{cmd:HATCH}} 的 `指定内部点` 提示处，输入 `F`（图案文件），然后选择一个 `.pat` 文件。仅测试过符合常用格式的文件。
- **图层分组。** 在 {{ui:图层}} 面板的 {{ui:工具}} 中：{{ui:新建组}}、{{ui:添加预设组}}、{{ui:按名称分组}}，以及 {{ui:查找图层}}；或输入 {{cmd:LAYGROUP}}（`LG`）。参见 [用图层组织图形](topic:layers#group-layers)。
- **分层楼层。** {{cmd:FLOORS}}（`FLR`），或 {{ui:视图}} 组中 {{ui:更多}} 菜单里的 {{ui:楼层…}}。图纸上的视口可在“特性”的 {{ui:显示的楼层}} 下显示某一楼层。{{cmd:FLOORLAYERS}} 可将楼层转换为图层，用于发给他人的文件。参见 [在一个图形中堆叠楼层](topic:floors)。
- **二维智能墙、门和窗。** {{cmd:WALL}}（`WA`）、{{cmd:DOOR}}（`DR`）、{{cmd:WINDOW}}（`WN`）以及 {{cmd:DELOPENING}}。拐角、T 形连接和交叉会自动计算。墙会保存其连接记录，“特性”中增加了 {{ui:起点禁止连接}} / {{ui:终点禁止连接}}、{{ui:定位线}}，以及可编辑的 {{ui:长度}}。参见 [绘制二维墙、门和窗](topic:walls-2d)。
- **平面墙的墙体工具。** 输入 {{cmd:WALLRECT}}、{{cmd:WALLPOLY}}、{{cmd:WALLARC}}、{{cmd:WALLTRACE}}、{{cmd:WALLDIM}}、{{cmd:WALLOFFSET}}、{{cmd:WALLSPLIT}}、{{cmd:WALLGRID}} 及其他命令。它们暂时还没有工具栏按钮。参见 [二维墙体的形状、切割、偏移与锁定](topic:wall-tools-2d)。

### 文字

- **文字样式。** {{cmd:STYLE}}（`ST`），或 {{ui:绘图}} 工具栏上的 {{ui:文字样式}}：带有字体、高度、宽度系数和倾斜的命名样式。参见 [使用文字样式设置文字的字体和大小](topic:text-styles)。
- **格式化的段落文字编辑器。** {{cmd:MTEXT}}、{{cmd:TEXTEDIT}}，或双击文字，会打开一个框，其中包含字体、大小、粗体、斜体、下划线、删除线、颜色、对齐方式，以及度数、正负号和直径符号，并带有 {{ui:确定}} 和 {{ui:取消}}。参见 [设置段落文字格式](topic:format-paragraph-text)。
- **从 draw.io XML 生成图表。** {{cmd:DIAGRAM}}（`T2D`）也可读取粘贴的 draw.io XML。参见 [从文本绘制图表](topic:text-to-diagram)。
- **PDF 打印中的泰文文字。** 此前会打印为问号。

### 更多空间和绘图辅助

- **可浮动、更薄的命令行和紧凑的顶部区域。** 拖动命令行的把手使其浮动，拖动其上边缘可减少行数，{{key:F2}} 打开历史记录。{{ui:设置}} › {{ui:CadCraft}} › {{ui:命令行}} 以及顶部区域选项提供相同的设置。参见 [设置](topic:settings#command-line)。
- **对象捕捉菜单。** 在状态栏中右键单击 {{ui:捕捉}}，或输入 {{cmd:OSNAP}}。
- **捕捉到栅格。** 状态栏中的 {{ui:栅格捕捉}} 按钮，或 {{key:F9}}：当没有对象捕捉命中该点时，拾取的点会移到最近的栅格点。
- **十种绘制圆弧的方法，以及继续。** {{ui:绘图}} 工具栏上的 {{ui:圆弧}} 或 {{cmd:ARC}}：三点、起点/圆心/终点系列和圆心/起点/终点系列，以及继续（在起点处按 {{key:Enter}}），从上一条直线、圆弧或多段线继续绘制。
- **“文档”面板。** {{cmd:DOCUMENTS}}（`DOCS`），或 {{ui:视图}} 组中 {{ui:更多}} 菜单里的 {{ui:文档…}}：为项目文件夹中的每个图形提供修订、状态和签出功能。它以居中的对话框打开。参见 [文档](topic:documents)。

### 文件

- **英国钢材尺寸。** “标准”面板中有 976 种截面，可按图纸上的写法输入（例如 `305x165x40 UB`）。
- **南非工具包**（绘图做法和建筑规范），作为“建筑规范”插件的工具包提供。数据尚未核实。
- **CadCraft 插件**，按需添加，默认关闭：室内照明设计、芯片设计（从 HDL 到版图）、路由器雕刻、电路仿真、滚子链链轮，以及“建筑规范”国家工具包。

## 已修复

- 移动、旋转或缩放填充时，其图案残留。
- {{cmd:GRIDMOVE}} 会带动仅从栅格线处开始的整面平面墙。现在根据墙的端点判断。
- 即使关闭界限，栅格也只显示在图形界限之内。
- 侧边面板中的块列表可以滚动；若名称不是块，则列出以其开头的块（“您是指”）。
- 原本被 AutoCAD 拒绝（“Unknown group 1001 for table”）的 DXF R12 文件，现在可以在此打开。
- 非常大的文件（约 70,000 个实体及以上）打开时出现“Maximum call stack size exceeded”。
- 来自 AutoCAD 2018 及更高版本、维护版本号较高的 DWG 文件，打开时出现“bad BITLONG code 11”。
- 在段落文字框中，为所选部分输入的新尺寸会保持所选内容。

## 所有应用中

浏览器工具提示覆盖所有带提示的控件，有一个可关闭的入门提示，选项卡栏在放不下时可以滚动，浏览器标签页标题会跟随打开的图形（`<图形> - CadCraft | CadCraft`）。{{ui:设置}} › {{ui:布局}} 现在是一个包含两行选项的下拉列表。{{ui:设置}} 中的语言列表比 0.8 更长。实时协作、图库集合以及重量和温度单位在 Studio 说明中有所描述。

## 已知局限

- 段落文字没有项目符号或编号列表、制表位标尺或两端对齐。打印的 PDF 中文字使用 Helvetica 字体。
- 平面墙是直的，因此圆弧以短墙绘制。墙体工具的社区人工检查尚未完成。
- 图层分组不以 AutoCAD 自身的格式写出，因此 AutoCAD 显示为平面列表。除非运行 {{cmd:FLOORLAYERS}}，其他程序会将所有楼层一并显示。
- “文档”面板尚未由两人在真实共享文件夹上测试。路由器雕刻尚未在任何真实机器上运行。照明估算已与光子追踪结果比对，而非其他程序。工程类插件是校核辅助工具，不能替代工程师的审查。
- 英语以外的语言为机器译稿，部分新词仅有英文。

## 更早版本：0.8 和 0.8.1

以下是 CadCraft 0.8 和 0.8.1 相对于 0.7 的变化。0.8（2026 年 11 月 1 日）增加了基于你自己图形的绘图辅助功能，这些功能依据你计算机上的规则运行，不使用模型；0.8.1（2026 年 11 月 2 日）修复了其发布后报告的错误。

### 新增

**完成你思路的绘图**

- **幻影显示接下来的内容。** 在没有命令运行时，灰色虚线幻影会显示你图形自身的图案所表明的接下来的内容：同样间距的下一根立柱、楼梯的下一级、房间缺失的墙。按 {{key:Tab}} 将其绘制为一步撤销，或按 {{key:Esc}} 将其隐藏。它只查看最新的对象，因此在大型图形上依然流畅。在 {{ui:设置}} › {{ui:CadCraft}} 中关闭，或使用 {{cmd:AUTOCOMPLETE}} `Off`。
- **绘制线条时的下一个点。** 在 {{cmd:LINE}} 或 {{cmd:PLINE}} 进行中，幻影即为下一个点：楼梯的下一级、矩形的第四个角点，或闭合它的点。将光标靠近它并按 {{key:Tab}}，就像你在那里单击了一样。
- **笔迹变为精确几何。** {{cmd:SKETCHFIX}}：用笔、鼠标或手指绘制粗略的笔画，每一笔都会变为整洁的直线、圆、圆弧、矩形或多段线，并与已有图形对齐。参见 [用笔徒手绘制并获得精确几何图形](topic:sketch-with-a-pen)。
- **照片中的草图变为图形。** {{cmd:PHOTOSKETCH}}（`PSK`）在照片中找到纸张，校正透视，应用你给出的纸张尺寸和比例，并将笔迹为每种笔色描摹到一个图层上。文字不会被描摹。
- **按规则标注尺寸。** {{cmd:AUTODIM}}（`ADIM`）沿你选择的边生成链式标注、总尺寸、开口宽度、孔径，以及（使用 `Grid` 时）栅格间距。它从不重复已经存在的标注。
- **移动栅格线，整组随之变化。** {{cmd:GRIDMOVE}}（`GM`）：止于栅格线的墙随之拉伸，沿其布置的墙、柱子、其气泡和标记一同移动，位于其上的标注按新的间距测量。一步撤销。

**图纸、详图和标记**

- **自动布局的图纸。** {{cmd:AUTOSHEET}} 获取你命名的视图（或模型的各个独立部分），选择纸张尺寸和标准比例，并将视图放在带有标题栏以及名称和比例说明的新图纸上。所有内容保持可编辑。参见 [为我布置图纸](topic:lay-out-sheets-for-me)。
- **你公司的详图，在绘制时提供。** {{cmd:DETAILS}}（`DET`）保存你自己的详图块。当你所选的内容与某个详图的图层词、块名和注释相符时，状态栏会予以说明；选择它并放置即可。{{cmd:DETAILS}} › Share 会将你的列表放入你的文档文件夹，并引入你的团队所添加的内容。设置可关闭这些提示。
- **块上的标记。** {{cmd:TAGS}} 定义一个标记（其类型、可取的值、适用的块），将其设置到你所选的块参照上，并将它们列为可保存为 CSV 的明细表。标记定义保存在 DWG 中。参见 [标记](topic:tags)。
- **图形界限。** {{cmd:LIMITS}} 为图形设置一个矩形：栅格填满它，“全部缩放”会显示它。界限显示为轮廓，并与纸张界限一起保存在 DWG 和 DXF 中。参见 [设置图形界限](topic:drawing-limits)。

**与他人和其他程序协作**

- **将批注转为修订。** {{cmd:REDLINE}} 读取 MarkupCraft 写出的包，并列出每项更改。逐一接受或拒绝并附上说明；被接受的更改会获得修订云线和修订日志，并在一步撤销中完成，然后你保存答复文件，以在 MarkupCraft 中关闭批注。参见 [将批注转为修订](topic:redline-to-revision)。
- **git 和 Fossil 可以合并的图形。** 在 {{ui:设置}} › {{ui:CadCraft}} 中开启 {{ui:便于合并的文件}} 后，每个对象都会获得一个永不改变的键（文件约大 10%）。`cadcraft merge base ours theirs` 会逐对象合并两人对同一 DWG 或 DXF 的编辑，并且只报告两人更改了同一内容的地方。参见 [合并两人对同一图形的编辑](topic:merge-drawings)。
- **用文字说明更改。** 在 {{ui:历史}} 中，比较会给出一份简明列表：更改的位置、区域大小、添加、删除或更改的内容，以及被编辑的文字。参见 [用文字说明更改内容](topic:changes-in-words)。
- **方位角和角度。** 在需要输入角度的任何地方，都可以以测量员的方位角（如 N45°23'30"E）或以度、分、秒输入方向；AUNITS 设置角度的显示方式。参见 [输入和显示方位角与角度](topic:bearings-and-angles)。
- **你自己的 SHX 字体。** 为 CadCraft 提供一个 SHX 字体文件夹，指定它们的文字样式即会以这些字体在屏幕和打印中绘制。参见 [用自己的 SHX 字体绘制文字](topic:shx-fonts)。
- **文本生成的图表。** {{cmd:DIAGRAM}} 读取 Mermaid 流程图、PlantUML 组件图、D2 或起止列表，并绘制可编辑的块和连接线。参见 [从文本绘制图表](topic:text-to-diagram)。
- **DWG 中的 OLE 对象。** {{cmd:OLELIST}} 列出 CadCraft 无法自行放置的 DWG 所携带的 OLE 对象，并在你指定的位置放置图片副本。参见 [图片](topic:pictures#objects-from-other-programs-ole)。
- **你的计算保存在图形中。** 计算表和设计依据随 DWG 和图层表一起保存。

**无视力绘图**

- 在 {{ui:设置}} 中开启 {{ui:无视力绘图}}（或输入 {{cmd:ACCESS}} 并回答 `On`）。CadCraft 会通过屏幕阅读器播报每个命令和结果，描述图形以及光标附近的内容，允许你用键盘移动光标并拾取点，并为每次捕捉和夹点播放声音。在浏览器能够在你的计算机上识别语音的地方，可以用语音输入命令。参见 [无视力绘图](topic:draft-without-sight)。

**在所有应用中**

- **语言。** 54 种语言；其中十种为新增（立陶宛语、拉脱维亚语、波斯尼亚语、马拉地语、泰卢固语、阿尔巴尼亚语、南非荷兰语、菲律宾语、斯瓦希里语、乌兹别克语）。除英语外的语言在母语者审读之前均为机器译稿。
- **输入设备。** 触控板、笔、3D 鼠标、游戏手柄和 MIDI 控制器。
- **工具栏行数和属性网格。** {{ui:设置}} › {{ui:常规}} › {{ui:工具栏行数}} 在其他应用中提供自动换行、2 行或 1 行。CadCraft 在 {{ui:设置}} › {{ui:CadCraft}} 中保留其自身的设置（参见 [工具栏行数](topic:settings#toolbar-rows)）。共享的属性网格位于其他三个应用中，而不在 CadCraft 中。
- **问题、实时协作与插件。** 一个共享的“问题”面板，在每个应用中给出警告；CadCraft Studio 中的实时视图，显示每个人在哪里（参见 [一起处理同一图形](topic:work-live)），以及插件列表。
- **连接你的 AI。** 从 CadCraft Studio 连接到全部八个应用，每个应用可设为只读、建议或编辑级别，并附有以通俗文字记录助手所做操作的日志。CadCraft 本身没有 AI，各应用中的“提问”使用你所连接的 AI。

### 0.8.1 修复

- **在英尺和英寸图形中，属性显示为 150 而非 12'-6"。** 由应用自行读取的字段恢复其文字显示。
- **DWG 文件的类表被读成了错误的类型**（GitHub cadcraft#5）现在可以正确打开。
- **十字光标不再显示在弹出窗口后面。**
- **Studio 和打包版本可以在运行时切换语言。** 此前仅支持英语。尚未在所有平台上测试：如果语言没有改变，请告诉我们。
- **竖屏平板**将多余的网格高度让给画布，图纸模式在 760 px 或更小时启动。
- **带交叉窗口的 STRETCH 以及 LIMITS**曾在 Studio 0.8.0 上被报告，在 0.8 网页版中已经正确；报告者使用的是较旧的安装程序。Studio 0.8.1 已包含修复。

### 本版本尚未包含的内容

- **0.8 和 0.8.1 未进行代码签名。** Windows 可能会发出警告（选择 {{ui:更多信息}}，然后 {{ui:仍然运行}}）；在 Mac 上，右键单击 CadCraft Studio 并选择 {{ui:打开}}。应用商店版本暂缓，iPad 和 iPhone 版本未针对 0.8.1 重新构建。
- **笔绘草图和草图照片**仅在模拟照片和鼠标上测试过，尚未用真实的笔、触摸屏或纸上的手绘草图测试。
- **无视力绘图**仅经过自动化检查，尚未用屏幕阅读器或盲人测试者进行测试。
- **共享详图**尚未经过两人检验，且尚未支持将 Team Cloud Plan 文件夹用作文档文件夹。
- **合并**适用于 CadCraft 的 DWG 和 DXF 文件；其他应用的文件尚未支持。
- **跨窗口撤销：** CadCraft 会报告每个已完成的步骤，但 Studio 尚未提供覆盖所有应用的单一撤销；每个应用只撤销自己的步骤。
- **DWG 的 OLE 对象**会被保留，但不会在原位绘制。
- **读取其他程序的打印样式表（CTB 文件）**已实现，但尚未用其他程序生成的文件检验。
- **连接你的 AI：** Studio 中的一键连接、面向浏览器 AI 的托管连接器、Studio 内你自己的 API 密钥，以及已发布的 MCP 包，均未在本版本中承诺提供。

有关上一版本，请参见 [0.7 版新增内容](topic:whats-new-0-7)。
