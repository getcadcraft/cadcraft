## 将要绘制的内容

一个 L 形房间的轮廓，尺寸为 6000 × 4500，并带有 2000 × 1500 的缺口，精确绘制，外加一段 30 度的墙。你将使用输入点的全部四种方式。以毫米为单位工作：一个图形单位代表一毫米。

各种格式的快速参考见[坐标与距离输入](topic:coordinate-entry)。

## 开始之前

1. 打开 CadCraft。如果已打开图形，请先单击{{ui:新建}}。
2. 按{{key:Esc}}，使未选择任何对象。右侧面板显示{{ui:当前设置}}。
3. 将{{ui:单位}}设为{{ui:毫米}}。这不会调整任何尺寸；它只是告知布局和打印，一个单位代表什么。

## 绝对坐标：第一点

绝对坐标是从原点度量的位置，以 `x,y` 形式输入。

1. 输入 `L`，然后按{{key:Enter}}。提示显示 `指定第一个点：`。
2. 输入 `0,0`，然后按{{key:Enter}}。

此时直线从原点橡皮筋式地连接到十字光标。移动时，状态栏中的坐标会显示与起点的距离和角度。

## 相对坐标：@dx,dy

相对坐标以 `@dx,dy` 形式输入：从上一点出发，水平方向移动多少、竖直方向移动多少。负数表示向左或向下。

3. 输入 `@6000,0`，然后按{{key:Enter}}。向右绘制一条 6000 的直线。
4. 输入 `@0,3000`，然后按{{key:Enter}}。
5. 输入 `@-2000,0`，然后按{{key:Enter}}。
6. 输入 `@0,1500`，然后按{{key:Enter}}。

应能看到四条相连的直线沿房间右侧向上延伸。

## 直接距离输入：纯数字

输入单个数字时，CadCraft 会沿十字光标方向移动该距离。打开{{ui:正交}}，使方向捕捉到水平或竖直方向。

7. 按{{key:F8}}，或单击状态栏中的{{ui:正交}}。状态栏显示“正交已开启”。
8. 将十字光标移到上一点的左侧。橡皮筋保持水平。
9. 输入 `4000`，然后按{{key:Enter}}。直线向左延伸 4000。
10. 将十字光标移到上一点下方。
11. 输入 `4500`，然后按{{key:Enter}}。回到起点。
12. 在空提示下按{{key:Enter}}结束命令。

:::mac
在 Mac 键盘上，F8 可能控制媒体播放。按住**fn**并按 F8，或单击{{ui:正交}}。参见[键盘、鼠标和触控板](common:keys)。
:::

现在已得到由六条独立直线组成的闭合 L 形轮廓。

13. 单击{{ui:范围}}以查看全部图形。

## 极坐标：@距离<角度

极坐标以 `@距离<角度` 形式输入。角度以度为单位，从 X 正方向逆时针度量：0 为右，90 为上，180 为左，270（或 -90）为下。

14. 输入 `L`，然后按{{key:Enter}}。
15. 输入 `6000,0`，然后按{{key:Enter}}，从右下角开始。
16. 输入 `@2500<-30`，然后按{{key:Enter}}。一条 2500 的直线从角点射出，朝右下方向，与水平线成 30 度向下。
17. 按{{key:Enter}}结束命令。

不带 `@` 的极坐标（如 `2500<30`）从原点度量，而不是从上一点度量。

## 将相同轮廓绘制为一条多段线

对于许多工作，六条独立直线已足够，但多段线是一个对象：它作为整体进行偏移、测量和选择。使用相同输入的{{cmd:PLINE}}。

1. 输入 `PL`，然后按{{key:Enter}}。
2. 输入 `0,-6000`，然后按{{key:Enter}}，从第一条轮廓下方开始。
3. 输入 `@6000,0`，然后按{{key:Enter}}。
4. 输入 `@0,3000`，然后按{{key:Enter}}。
5. 输入 `@-2000,0`，然后按{{key:Enter}}。
6. 输入 `@0,1500`，然后按{{key:Enter}}。
7. 输入 `@-4000,0`，然后按{{key:Enter}}。
8. 输入 `C`，然后按{{key:Enter}}。多段线闭合，命令结束。
9. 单击新轮廓。右侧面板显示“多段线”、其{{ui:顶点数}}、{{ui:长度}}，以及由于它是闭合的，其{{ui:面积}}。

面积应显示为 24000000（平方毫米，即 24 平方米）。

## 绘制时的选项

- 在{{cmd:LINE}}和{{cmd:PLINE}}中，输入 `U` 并按{{key:Enter}}，可撤回最后一段，而不退出命令。
- 在{{cmd:LINE}}中，至少有两段后，`C` 会闭合回到第一点。
- 在{{cmd:PLINE}}中，`A` 切换为圆弧段（每段圆弧与前一段平滑衔接），`L` 切换回直线。在圆弧模式下，闭合选项为 `CL`。
- 在{{cmd:LINE}}的 `指定第一个点：` 提示处按{{key:Enter}}，将从上次给出的点开始，以便接着中断处继续。

## 常见错误

- **输入 `6000,0` 而本意是 `@6000,0`。** 没有 `@` 时，该点从原点度量，而不是从上一点度量，因此直线会射向意想不到的位置。在 CadCraft 中，`x,y` 始终为绝对坐标。按 `U` 和{{key:Enter}}即可撤回。
- **将逗号输入为小数点。** 小数使用句点：`1250.5`。逗号始终用于分隔 X 和 Y。
- **直接距离方向错误。** 单个数字沿十字光标方向。按{{key:Enter}}前，先将十字光标移到所需的一侧，并打开{{ui:正交}}以绘制直线。
- **"需要点或选项关键字。"** CadCraft 无法识别输入内容。检查数字内是否有空格或是否缺少逗号，然后重新输入。
- **英尺和英寸。** CadCraft 只识别纯数字。在英寸图形中，输入 `150` 表示 12'-6"；在英尺图形中，输入 `12.5`。
