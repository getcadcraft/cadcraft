## 学习内容

如何以旋转方式查看图形，使成角度绘制的建筑在屏幕上正对显示，以及如何沿其自身的轴线输入点。执行这些操作时图形中的任何内容都不会移动：对象保持其坐标，旋转视图不是编辑，图形也不会被标记为已更改。

## 旋转视图四分之一圈

1. 单击{{ui:视图}} › {{ui:更多}} › {{ui:将视图向左转90°}}或{{ui:将视图向右转90°}}。

图形会围绕绘图区域的中心在屏幕上旋转。再次执行即可继续旋转。

2. 单击{{ui:视图}} › {{ui:更多}} › {{ui:回到世界坐标}}以将其恢复水平。

对应的命令为{{cmd:TURNLEFT}}、{{cmd:TURNRIGHT}}和{{cmd:TURNWORLD}}。若要为其设置快捷键，请使用{{cmd:ALIASEDIT}}添加一行，例如`TL=TURNLEFT`。

## 对齐成角度的建筑

1. 输入`UCS`并按{{key:Enter}}，然后输入`OB`并按{{key:Enter}}。
2. 在应作为原点的一端附近单击墙线。

UCS 现在从该端点开始，其 X 轴沿墙线方向，视图旋转，使墙在屏幕上保持水平。左下角的坐标轴图标显示 UCS 轴的指向。

3. 像平常一样绘制。设置 UCS 后：
   - `x,y` 和 `@dx,dy` 沿 UCS 轴测量；`d<a` 从 UCS 的 X 轴测量角度。
   - {{ui:正交}}、极轴追踪和栅格均沿 UCS 轴，十字光标也是如此。
   - 新文字和新段落沿 UCS 的 X 轴排列；{{cmd:DIMLINEAR}} 的水平和竖直方向也随之变化。
   - 状态栏中以及来自{{cmd:ID}}的坐标均为 UCS 坐标。
4. 在设置 UCS 时要输入世界坐标点，请在前面加上`*`：`*0,0`或`@*100,0`。
5. 输入`UCS`，按{{key:Enter}}，然后再按{{key:Enter}}即可返回世界坐标。

## 设置 UCS 的其他方法

在{{cmd:UCS}}提示下：

| 输入 | 作用 |
|---|---|
| 一个点 | 新原点；然后单击新 X 轴上的一个点，或按{{key:Enter}}保持当前角度 |
| `Z` | 绕原点旋转 UCS，角度可输入（以度为单位，逆时针）或拾取 |
| `3`（3point，三点） | 一个原点、正 X 轴上的一个点，以及正 Y 侧的一个点 |
| `OB`（OBject，对象） | 由直线、圆弧、圆、多段线线段、文字、块参照、点或构造线确定 |
| `P`（Previous，上一个） | 此 UCS 之前的 UCS（打开图形期间保留最近十个） |
| `W`（World，世界） | 返回世界坐标 |
| `NA`（NAmed，命名） | `S` 以名称保存当前 UCS，`R` 恢复一个，`D` 删除一个，`?` 列出它们 |

每次更改都会旋转视图，使新的 UCS X 轴保持水平。{{cmd:PLAN}}会在不更改 UCS 的情况下旋转视图：{{key:Enter}}用于当前 UCS，`U`用于已保存的 UCS，`W`用于世界坐标。

## 注意事项

- 分割屏幕的每个窗格都保留其各自的旋转。UCS 属于图形。
- 布局使用图纸坐标；请在{{ui:模型}}标签页中或在视口内设置 UCS。
- 在旋转视图中拖动的选择窗口会选择屏幕上位于其中的对象。
- LISP 例程从`getpoint`获取 UCS 中的点，可以读取`UCSORG`、`UCSXDIR`、`UCSYDIR`和`VIEWTWIST`，`trans`可在世界坐标、UCS 和显示之间转换。

:::note
在以后的版本中，保存的文件将保留 UCS 和视图的旋转；在此之前，它们仅在图形打开期间有效。
:::
