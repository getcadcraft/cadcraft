两人编辑同一图形。如果他们修改的是不同的对象，合并可以自动完成：无需手动重做。

## 工作原理

CadCraft 会为您绘制的每个对象分配一个简短的**标识键**，该键永不改变，且不会分配给两个对象。它与对象一起保存在 DWG 或 DXF 中（作为其他程序保留的额外数据）。合并时按该标识键查找对象，而不是按其在文件中的位置，因为每个程序在保存时都会重新编号位置。如果从不合并，可在{{ui:设置}} › CadCraft › 合并友好文件中关闭此功能；文件大约会缩小 10%。

保存于标识键出现之前的图形仍可合并：其对象会根据它们在文件中的位置获得标识键，对所有打开它的人来说都相同。

## 设置

Git 每个仓库需要两行设置一次：

```
# .gitattributes
*.dwg merge=cadcraft
*.dxf merge=cadcraft

# 一次性设置，每台计算机上执行一次
git config merge.cadcraft.driver "node /path/to/tools/cli/merge.mjs %O %A %B"
```

不使用 git 时，手动运行：`cadcraft merge <base> <ours> <theirs> -o <result>`。Fossil 和 Mercurial 在各自的合并工具设置中使用相同的三个文件。

## 规则

- 只在一侧修改的对象会被采用。两侧做出相同修改的，只采用一次。
- 同一属性在两侧以不同方式修改即为**冲突**：保留本侧的值，报告中列出两个值。打开结果文件，查看该对象，并手动修正。
- 任何一侧新增的对象都会保留。在一侧被删除、另一侧未改动的对象会被删除。在一侧被删除、另一侧被修改的对象：删除并报告。
- 图层、块、文字和标注样式、布局以及命名视图的合并方式相同。约束会跟随它们所指定的对象。
- 结果以与原文件相同的格式和版本写入。

不参与合并的内容：对象的绘制顺序以本侧为准，然后是另一侧新增的对象。两侧对同一块定义的修改为冲突，绝不会混合。不会上传任何内容；全部在本地计算机上运行。
