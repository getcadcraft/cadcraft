## 你将制作的内容

三个图层：墙体、门和备注，各有各自的颜色；在每个图层上绘制对象，并将对象在图层之间移动。

## 图层面板

图层位于左侧面板中的 {{ui:图层}} 下。每一行从左到右显示：

- 一个圆点：实心表示**当前**图层，新对象会放在其上；
- 一个颜色块；
- 图层名称；
- 四个按钮：开/关（眼睛）、冻结（雪花）、锁定（挂锁）和打印（打印机）。

每个图形都有一个名为 `0` 的图层。输入 `LA` 并按 {{key:Enter}} 可跳到该面板。

## 创建图层

1. 单击列表上方的 {{ui:新建图层}}。会打开一个名称框。
2. 输入 `墙体` 并按 {{key:Enter}}（或单击 {{ui:添加}}）。

状态栏会显示“已添加图层“墙体”并将其设为当前图层。”新图层的颜色为 7（浅色主题下为黑色，深色主题下为白色）。

3. 再次单击 {{ui:新建图层}}，输入 `门` 并按 {{key:Enter}}。
4. 再次单击 {{ui:新建图层}}，输入 `备注` 并按 {{key:Enter}}。

“备注”现在是当前图层。

## 为每个图层设置颜色

1. 单击“墙体”行上的颜色块。你的系统颜色选择器会打开。
2. 选择一种颜色并确认。

颜色块以及“墙体”上所有设为 {{ui:随层}} 颜色的对象都会随之变化。

:::note
与 255 种标准 CAD 颜色之一相符的颜色会以该编号保存。其他颜色在 CadCraft 中按原样保留，但在 DWG 或 DXF 文件中会保存为最接近的标准颜色。
:::

## 在图层上绘制

1. 单击列表中的 **墙体** 名称。其圆点变为实心，状态栏显示“当前图层：墙体”。
2. 绘制一个矩形（`REC`）。它会放在“墙体”上。
3. 单击 **门**，并绘制一段圆弧（`A`）。它会放在“门”上。

你也可以在右侧的 {{ui:当前设置}} 中选择当前图层（未选中任何对象时），位于 {{ui:图层}} 之下。

## 将对象移到另一个图层

1. 选择对象。
2. 在右侧面板的 {{ui:图层}} 中选择新图层。

对象会移到该图层，并且若其颜色为 {{ui:随层}}，则采用该图层的颜色。

## 关闭、冻结、锁定和打印

| 按钮 | 作用 |
|---|---|
| 开/关（眼睛） | 隐藏图层上的对象。它们无法被看到、选中或捕捉。 |
| 冻结（雪花） | 在 CadCraft 中与关闭效果相同。之所以分开，是因为其他程序对它们的处理不同，且该设置会被保存。 |
| 锁定（挂锁） | 对象保持可见，且可以捕捉，但无法被选中或更改。适用于你要描摹的底图。 |
| 打印（打印机） | 按下时，该图层在屏幕上可见，但**不参与打印**和 PDF 输出。适用于构造线和给自己的备注。 |

将鼠标悬停在按钮上可查看其作用（“关闭”、“冻结”、“锁定”、“不打印此图层”）。

你无法关闭当前图层：状态栏会显示“这是当前图层。请先将其他图层设为当前图层。”单击图层名称将其设为当前图层，也会同时打开并解冻它。

面板中或通过命令进行的每次图层更改，都是一步撤销：{{key:Mod+Z}} 可将其恢复。

## 通过拾取对象操作图层

你无需知道图层的名称：拾取图层上的一个对象即可。输入命令，或打开 {{ui:图层}} 面板顶部的 {{ui:工具}}。

| 命令 | 作用 |
|---|---|
| {{cmd:LAYISO}} | 选择对象，然后按 {{key:Enter}}：只保留它们所在的图层打开，其他所有图层都会关闭。若当前图层被关闭，则其中一个被隔离的图层会成为当前图层。 |
| {{cmd:LAYUNISO}} | 重新打开上一次 {{cmd:LAYISO}} 关闭的图层，并恢复其更改过的当前图层。 |
| {{cmd:LAYOFF}} | 依次单击对象：每个对象所在的图层都会关闭。输入 `U` 撤销最后一个，按 {{key:Enter}} 结束。 |
| {{cmd:LAYFRZ}} | 相同，但改为冻结每个图层。 |
| {{cmd:LAYMCUR}} | 单击一个对象：其图层成为当前图层（并会被打开和解冻）。若已选中一个对象，则使用该对象。 |
| {{cmd:LAYON}} | 打开所有图层。 |
| {{cmd:LAYTHW}} | 解冻所有图层。 |

当前图层不会通过这些方式被关闭或冻结：历史记录会予以说明，你可以先用 {{cmd:LAYMCUR}} 将其他图层设为当前图层。拾取块参照时，使用该参照自身的图层。

## 重命名、合并和删除图层

- {{cmd:RENAME}}：输入 `LA`、旧名称和新名称。图层上的每个对象都会随之变化。（`B` 以同样的方式重命名块，并更新其所有参照。）
- {{cmd:LAYMRG}}：在每个要合并的图层上单击一个对象（或输入 `N` 及一个名称），按 {{key:Enter}}，然后拾取目标图层并回答 `Y`。对象会移到目标图层——在模型、图纸和块中均如此——被合并的图层则被删除。
- {{cmd:LAYDEL}}：拾取图层上的一个对象（或输入 `N` 及其名称），并回答 `Y`。该图层**及其上的每个对象**都会被删除，无论位于何处。图层 0、DEFPOINTS 和当前图层无法删除。

以上每项都是一步撤销。三者都位于 {{ui:图层}} 面板顶部的 {{ui:工具}} 中。

1. 单击一条墙线，然后输入 `LAYISO` 并按 {{key:Enter}}。只有“墙体”保持打开。
2. 在“墙体”上绘制或修改所需内容。
3. 输入 `LAYUNISO` 并按 {{key:Enter}}。“门”和“备注”会恢复显示。

## 常见错误

- **新线条画在了错误的图层上。** 绘制之前请检查哪个圆点是实心的。新图层一经添加即成为当前图层。
- **对象无法选中。** 其图层已锁定、关闭或冻结。
- **该图层在其他程序中仍然会被打印。** DXF R12 无法保存“不打印”设置。当图形带有图纸时，CadCraft 会自行保存该设置，但其他程序仍会打印该图层。
- **保存后图层名称变为大写。** DXF R12 以大写保存名称，因此 `墙体` 会变为 `墙体`（不变），而空格会变为 `_`。保存的 DWG 会按你输入的方式保留名称。
- **重命名、合并或删除图层。** 使用 {{cmd:RENAME}}、{{cmd:LAYMRG}} 或 {{cmd:LAYDEL}}（也位于 {{ui:工具}} 中）：参见下文。

## 图层分组

将图层放入文件夹中，可以使列表保持简短，例如“既有”、“拟建”和“管线”。每个文件夹都可以折叠，其开关可一起打开或关闭所有图层、冻结它们或将它们锁定。当前图层永远不会被关闭。

在图层面板的 {{ui:工具}} 中，可选择 {{ui:添加预设组}}（为小型住宅工程准备的一组）、{{ui:按名称分组}}（将具有相同前缀的图层分组，例如 `E-墙体`、`E-门`），或 {{ui:新建组}}。将图层拖到文件夹上，或使用图层列表上方的当前图层选项。在 {{ui:查找图层}} 中输入以缩小列表范围。`LAYGROUP`（`LG`）在命令行中执行相同的操作。

要重命名某个组，请双击其名称（或选中它并按 {{key:F2}}），输入新名称并按 {{key:Enter}}；按 {{key:Esc}} 则保留旧名称，{{cmd:UNDO}} 可将其恢复。{{ui:新建组}} 位于图层面板的 {{ui:工具}} 中。

图层本身不会因此改变，因此其他 CAD 程序会将它们视为普通的平面列表。CadCraft 会将分组保存在文件中。
