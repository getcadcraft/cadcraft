## 将要制作的内容

三个图层：Walls、Doors 和 Notes，各有自己的颜色，并在每个图层上绘制对象，再将对象在图层之间移动。

## 图层面板

图层位于左侧面板中的{{ui:图层}}下方。每一行从左到右显示：

- 一个圆点：实心表示**当前**图层，新对象将绘制在此图层上；
- 一个颜色色块；
- 图层名称；
- 四个按钮：开/关（眼睛）、冻结（雪花）、锁定（挂锁）和打印（打印机）。

每个图形都有一个名为`0`的图层。输入`LA`并按{{key:Enter}}键可跳转到该面板。

## 创建图层

1. 点击列表上方的{{ui:新建图层}}。随即打开名称输入框。
2. 输入`Walls`并按{{key:Enter}}键（或点击{{ui:添加}}）。

状态栏显示“已添加图层 Walls，并已将其设为当前图层。”新图层的颜色为 7（浅色主题下为黑色，深色主题下为白色）。

3. 再次点击{{ui:新建图层}}，输入`Doors`并按{{key:Enter}}键。
4. 再次点击{{ui:新建图层}}，输入`Notes`并按{{key:Enter}}键。

现在 Notes 为当前图层。

## 为每个图层设置颜色

1. 点击 Walls 行的颜色色块。系统的颜色选择器随即打开。
2. 选择一种颜色并确认。

色块以及 Walls 上所有颜色为{{ui:随层}}的对象都会随之改变。

:::note
与 255 种标准 CAD 颜色之一相符的所选颜色，会以该编号保存。其他颜色在 CadCraft 中按原样保留，但在 DWG 或 DXF 文件中会保存为最接近的标准颜色。
:::

## 在图层上绘图

1. 在列表中点击名称**Walls**。其圆点变为实心，状态栏显示“当前图层：Walls”。
2. 绘制一个矩形（`REC`）。它将绘制在 Walls 上。
3. 点击**Doors**，并绘制一条圆弧（`A`）。它将绘制在 Doors 上。

也可以在右侧的{{ui:当前设置}}中（未选中任何对象时），在{{ui:图层}}下选择当前图层。

## 将对象移动到其他图层

1. 选择对象。
2. 在右侧面板中，于{{ui:图层}}下选择新图层。

对象会移动到该图层；如果其颜色为{{ui:随层}}，还会采用该图层的颜色。

## 关闭、冻结、锁定和打印

| 按钮 | 作用 |
|---|---|
| 开/关（眼睛） | 隐藏该图层上的对象。这些对象无法被看到、选中或捕捉。 |
| 冻结（雪花） | 在 CadCraft 中与关闭效果相同。之所以单独保留，是因为其他程序对两者的处理不同，且该设置会被保存。 |
| 锁定（挂锁） | 对象保持可见，并且可以捕捉到它们，但无法被选中或修改。适合用作描图时的背景。 |
| 打印（打印机） | 按下时，该图层在屏幕上仍然显示，但**不会包含在打印和 PDF 中**。用于构造线和给自己的注释。 |

将鼠标悬停在按钮上可查看其作用（“关闭”、“冻结”、“锁定”、“不打印此图层”）。

无法关闭当前图层：状态栏会显示“这是当前图层。请先将其他图层设为当前图层。”点击图层名称将其设为当前图层时，该图层也会被打开并解冻。

面板中或通过命令进行的每次图层更改都是一个撤销步骤：按{{key:Mod+Z}}可将其恢复。

## 通过选择对象来操作图层

不需要知道图层名称：选择该图层上的一个对象即可。输入命令，或打开{{ui:图层}}面板顶部的{{ui:工具}}。

| 命令 | 作用 |
|---|---|
| {{cmd:LAYISO}} | 选择对象，然后按{{key:Enter}}键：仅保留其图层为开启，其他所有图层都会关闭。如果当前图层被关闭，则隔离的图层之一会成为当前图层。 |
| {{cmd:LAYUNISO}} | 恢复上一次{{cmd:LAYISO}}关闭的图层，并还原它所更改的当前图层。 |
| {{cmd:LAYOFF}} | 依次单击对象：每个对象所在的图层都会被关闭。输入`U`撤销上一个对象，按{{key:Enter}}键结束。 |
| {{cmd:LAYFRZ}} | 相同，但改为冻结每个图层。 |
| {{cmd:LAYMCUR}} | 单击一个对象：其图层成为当前图层（并被打开和解冻）。如果已选中一个对象，则使用该对象。 |
| {{cmd:LAYON}} | 打开所有图层。 |
| {{cmd:LAYTHW}} | 解冻所有图层。 |

当前图层不会通过上述方式被关闭或冻结：历史记录中会说明此点，可先用{{cmd:LAYMCUR}}将其他图层设为当前图层。选择块参照时，使用该参照自身的图层。

## 重命名、合并和删除图层

- {{cmd:RENAME}}：输入`LA`、旧名称和新名称。图层上的所有对象都会随之更新。（`B`以同样方式重命名块，并更新对它的所有引用。）
- {{cmd:LAYMRG}}：在要合并的每个图层上各单击一个对象（或输入`N`及名称），按{{key:Enter}}键，然后选择目标图层并回答`Y`。对象会移动到目标图层，包括模型中、布局上和块内的对象，而被合并的图层会被删除。
- {{cmd:LAYDEL}}：选择图层上的一个对象（或输入`N`及其名称）并回答`Y`。该图层会连同其上的**所有对象**一起删除，在任何位置都是如此。图层 0、DEFPOINTS 和当前图层无法删除。

每项操作都是一个撤销步骤。三者都位于{{ui:图层}}面板顶部的{{ui:工具}}中。

1. 单击一条墙线，然后输入`LAYISO`并按{{key:Enter}}键。只保留 Walls 为开启。
2. 在 Walls 上绘制或修改所需内容。
3. 输入`LAYUNISO`并按{{key:Enter}}键。Doors 和 Notes 会恢复显示。

## 常见错误

- **新线条绘制到了错误的图层上。** 绘制前请检查哪个圆点为实心。新图层一经添加即成为当前图层。
- **对象无法选中。** 其图层已锁定、关闭或冻结。
- **图层在其他程序中仍被打印。** DXF R12 无法保存“不打印”设置。当图形包含布局时，CadCraft 会自行保存该设置，但其他程序仍会打印该图层。
- **保存后图层名称变为大写。** DXF R12 以大写形式保存名称，因此`Walls`会变为`WALLS`，空格会变为`_`。保存为 DWG 时会保留输入时的名称。
- **重命名、合并或删除图层。** 使用{{cmd:RENAME}}、{{cmd:LAYMRG}}或{{cmd:LAYDEL}}（同样位于{{ui:工具}}中）：见下文。

## 图层分组

为保持列表简短，可将图层放入文件夹，例如 Existing、Proposed 和 Services。每个文件夹可折叠，其开关可同时打开或关闭其所有图层、冻结它们或将其一并锁定。当前图层永远不会被关闭。

在图层面板的{{ui:工具}}中，选择{{ui:添加预设组}}可获得为小型住宅工程准备的一组图层组；选择{{ui:按名称分组}}可将带相同前缀的图层归为一组（`E-Walls`、`E-Doors`）；或选择{{ui:新建组}}。将图层拖到文件夹上，或使用图层上方的列表设置当前图层。在{{ui:查找图层}}中输入内容可缩小列表范围。`LAYGROUP`（`LG`）在命令行中执行相同的操作。

图层本身不会改变，因此其他 CAD 程序会将其视为普通的平面列表。CadCraft 会在文件中保存分组。
