## 可用的功能

包含动态块的 DWG 打开后，以下功能可以正常工作：

- **真实名称。** 动态块在 {{ui:Blocks}} 面板中以其自身的名称列出（"Receptacle"、"Sink"），而不是作为未命名的 `*U` 块。
- **保存时的状态。** 每个参照都会精确显示其他程序所显示的内容：设置的可见性状态，以及保存时的拉伸或翻转状态。
- **切换可见性状态。** 选择一个参照（或同一块的多个参照），打开 {{ui:Properties}}，然后在 {{ui:Custom}} 部分的 {{ui:Visibility}} 列表中选择另一个状态。参照会立即显示该状态，其属性也一并变化：该状态隐藏的属性会消失，显示的属性会带着它们的值出现。参照会保留每一个值，因此不会有任何内容变为空白；{{ui:Properties}} 会将隐藏的项目列出并标记为"hidden"。{{key:Mod+Z}} 可以一步恢复之前的状态。
- **夹点。** 选中的动态块会在其参数所在的位置显示自己的夹点：可见性状态为一个小三角（单击可查看状态列表），距离两端为箭头，翻转为双向箭头。目前只有可见性夹点起作用；其他夹点会在状态栏中说明。
- **其他值，只读。** 在可见性列表下方，{{ui:Custom}} 还会显示图形中保存的块距离、对齐角度、翻转状态和点。
- **编辑可见性状态。** 使用 {{cmd:BEDIT}} 打开块：编辑器显示一个状态，其名称显示在绘图上方的栏中（可在那里选择其他状态）。输入 {{cmd:BVSTATE}} 可以切换、添加（隐藏全部、显示全部，或保留当前可见的内容）、重命名或删除状态；{{cmd:BVHIDE}} 会在当前显示的状态中隐藏所选对象；{{cmd:BVSHOW}} 会以淡化方式显示隐藏的对象，以便你单击需要恢复的对象。保存块后：设为已重命名状态的参照会以新名称保留该状态，设为已删除状态的参照则显示第一个状态。
- **保持动态。** 以图形原有版本保存为 DWG 时，块会保持动态，并保留你选择的状态：其他程序会将它们作为相同的动态块打开。你编辑过的可见性状态也会一并保存：包括它们的新名称、你添加的状态以及每个状态所显示的内容。

## 只读或尚未实现的内容

| 尚未实现 | 目前的替代方式 |
|---|---|
| 更改距离、角度或翻转（拉伸、移动、翻转动作） | 在 {{ui:Custom}} 中以只读方式显示；请在创建该块的程序中编辑。 |
| 查找、XY、旋转和极坐标参数 | 尚未读取：参照按保存时的状态显示。 |
| 拖动距离、翻转和点夹点 | 它们显示参数所在的位置；可见性夹点和"特性"中的 {{ui:Visibility}} 列表用于切换状态。 |
| 创建动态块（添加参数，或为没有状态的块添加可见性状态） | 在 CadCraft 中创建的块是普通块；{{cmd:BPARAMETER}} 会说明这一点。 |
| 在块编辑器中添加或删除带可见性状态的块的对象 | 此时该块会保存为普通块（编辑器关闭时会说明）。 |
| 在其他 DWG 版本或 DXF 中保持动态 | 它们会保存为普通块，显示你选择的状态，保存时会对此作出说明。 |

:::note
在 {{cmd:BEDIT}} 中移动或更改对象，会使带有可见性状态的块保持动态。没有状态的块，或在编辑器中添加或删除了对象的块，会变为普通块。
:::
