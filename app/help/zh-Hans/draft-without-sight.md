**无障碍**让你无需看屏幕即可绘图。它默认关闭，因此不会被他人意外开启。

## 开启

打开**设置**（齿轮图标，或按 Ctrl+,），找到**无视觉绘图**，然后选择**开**。或者在命令行中输入 `ACCESS`，并回答 `On`。此设置会记录在这台计算机上。

开启无障碍后：

- **命令行上的所有内容都会通过屏幕阅读器朗读**：你输入的内容、命令所提出的提示、你的回答以及每一条错误信息。CadCraft 使用自己的礼貌和紧急实时区域，因此支持读取实时区域的屏幕阅读器无需额外设置。错误和取消会打断朗读；其他内容则依次等待。
- **可以进入绘图区域**。按 Tab 直到听到“绘图”，或在命令行中按 Shift+Tab。它是一个会将按键传递给 CadCraft 的区域。

## 图形上的按键

| 按键 | 作用 |
|---|---|
| 方向键 | 移动键盘光标。每一步约为屏幕所示范围的百分之一，并取整为 1、2 或 5。Shift 的移动距离为十倍，Ctrl 为十分之一。 |
| Enter | 拾取光标下的点，与单击完全相同。 |
| Space | 在命令行按 Enter：结束 LINE，采用默认值。 |
| Tab、Shift+Tab | 跳转到光标附近的下一个或上一个捕捉点，最近的优先。 |
| G | 依次查看所选对象的夹点。 |
| D | 描述图形：对象数量、类型、大小以及所选内容。 |
| W | 说明光标所在位置，以及它与上一点的距离。 |
| N | 按距离由近到远说明光标附近的内容，并给出距离和方位。 |
| S | 描述所选对象。 |
| R | 重复上一次朗读的内容。 |
| V | 开启或关闭语音。 |
| / | 转到命令行。 |
| ? | 列出这些按键。 |

使用按键移动时，会朗读光标落在何处。当命令正在等待一个点时，还会朗读光标与上一点的距离和方向，例如“距上一点 2400，向右，0 度”。

## 命令

- {{cmd:ACCESS}} 开启或关闭无障碍、捕捉声音和语音，并朗读其状态。
- {{cmd:DESCRIBE}} 朗读图形中包含的内容。
- {{cmd:WHEREAMI}} 朗读光标所在的位置。
- {{cmd:NEARBY}} 朗读光标附近的内容。
- {{cmd:SAYSEL}} 朗读所选内容，每个对象一句。
- {{cmd:VOICE}} 开启或关闭语音命令。

这五个只读取图形并输出结果，不做任何更改。

## 捕捉和夹点声音

在“设置”中开启**捕捉和夹点声音**。每种捕捉类型都有各自的音高和声音，因此你可以分辨端点、中点、圆心、交点等；夹点则发出双击声。声音会随光标在屏幕上的位置向左或向右移动。声音在你的计算机上生成，不会下载任何内容。

## 语音命令

在“设置”中开启**语音命令**。说出命令名称（"line"、"circle"、"move"），然后像朗读一样说出数字："point three hundred comma four hundred"、"distance twelve hundred"、"angle forty five"。"Enter"、"cancel"、"undo" 和 "redo" 会执行它们字面上的操作。系统会朗读识别到的内容，无法识别为命令的短语会被报告，而不会被猜测。

**语音识别的位置。** CadCraft 没有自己的语音服务，也不会向任何地方发送音频。它会请求你的浏览器在这台计算机上识别语音。如果浏览器能够做到，选择**在此计算机上**，音频就不会离开设备。如果不能，除非你选择**浏览器在线服务**（允许浏览器将音频发送给其制造商的语音服务），否则语音保持关闭。在你做出决定之前，设置中会说明适用的情况。

## 尚未实现的内容

- 只有 CadCraft 具备无障碍功能。其他七个应用将随后推出，并采用相同的按键和声音。
- 图形中的文字（注释、块名称）会按其原样朗读；绝不会被当作指令执行。
- 目前已通过合成检查和浏览器测试；使用 NVDA、VoiceOver 以及盲人或低视力测试人员进行的人工检查尚未完成。如果你试用，请告诉我们缺少什么。
