## 学习内容

如何更改你键入的字母，以回答命令的选项。例如，{{cmd:ARRAY}} 询问 `[矩形(R)/极轴(PO)]`，并以 `PO` 表示极轴；你可以让 `P` 或其他任何字母做同样的事，如果你愿意，也可以使用你自己的语言。

## 选项如何回答

当命令在方括号中显示选项时，应键入其中的大写字母：`POlar` 为 `PO`，`eXit` 为 `X`。

你也可以键入较少的字母。若你键入的字母只符合所显示选项中的一个，CadCraft 就会采用它：在 `[矩形(R)/极轴(PO)]` 中，单独的 `P` 即为极轴。若符合两个，命令行会列出它们并再次询问：

```
C could be COUnt, COLumns. Type more letters.
```

数字永远不会被猜测，因此你键入的距离或数量始终按数字读取。

## 添加你自己的字母

每个命令都保留其内置字母。你在其之上添加自己的字母，因此你的列表只包含你更改过的内容。

1. 打开 {{ui:设置}}（{{key:Mod+,}}）› {{ui:CadCraft}} › {{ui:选项字母}}，并单击 {{ui:编辑…}}。或输入 {{cmd:OPTIONKEYS}} 并按 {{key:Enter}}。
2. 在 {{ui:命令}} 下选择命令，例如 `ARRAY`。列表包含所有会询问选项的命令，并从你上次使用的命令开始。
3. 在 {{ui:选项}} 下选择选项。每个选项都会在括号中显示其内置字母，例如 `POlar (PO)`。
4. 在 {{ui:自定义字母}} 中输入你想要的字母，例如 `P`，然后单击 {{ui:添加}}。
5. 该选项现在会出现在 {{ui:自定义字母}} 之下，同时显示其内置字母和你的字母。单击 {{ui:保存}}。

启动 {{cmd:ARRAY}}，选择一个对象并按 {{key:Enter}}。提示会在选项之后显示你的字母，即 `POlar (P)`，而 `P` 即可回答它。

若要删除一个字母，请单击其所在行末尾的 x，然后单击 {{ui:保存}}。该选项将恢复为仅使用其内置字母。

## 你不能使用的字母

编辑器会拒绝那些会遮盖命令行已经识别内容的字母，并说明原因：

- 同一命令中另一选项的内置字母（在 `ARRAY` 中，`R` 是矩形，因此不能用于极轴）；
- 三个或更多字母的对象捕捉词，例如 `END`、`MID` 或 `CEN`，以及 `ALL` 和 `LAST` 两个词；
- 同一命令的两个不同选项使用相同的字母。

只要列表中有任何一行显示为红色，{{ui:保存}} 就会被禁用：修正该行或将其删除，即可再次启用。提示中的内置字母始终优先于你的字母，因此你的列表永远不会阻止内置的回答生效。与命令名称相同的字母，例如 `L` 或 `C`，也是允许的：在选项提示处，命令行是在读取回答，而不是启动命令。

某个命令所列的选项来自与其共享提示的命令，因此有时命令会列出某个仅在特定情况下才会询问的选项。

## 适用于所有命令的选择

在 {{ui:命令}} 下，选择 {{ui:所有命令}}。此时选项是所有命令都具有的选项，例如 eXit 或 Undo。在此添加的字母会在任何命令提供该选项时对其作出回答。为某个命令添加的字母优先于这些通用字母。

## 你自己语言的字母

字母可以来自任何字母表，因此你无需切换键盘即可回答选项：在 {{ui:所有命令}} 下添加 `З` 作为 Close（闭合），或在 `ARRAY` 中添加 `П` 作为 POlar（极轴）。

CadCraft 只附带英文字母。你自己的列表是你、你的办公室或使用同一语言的人为其他部分进行设置的方式，而 {{ui:导出}} 可生成一个文件，供你转交他人。

## 以文本编辑

编辑器中的 {{ui:以文本编辑}} 会以文本行的形式显示同一列表，每个选项一行，这也是 {{ui:导出}} 所保存的内容：

```
ARRAY.PO,  P
*.X,       Q
```

每行包含命令、一个点、该选项的内置字母、一个逗号以及你的字母。以星号代替命令表示所有命令。以 `;` 开头的行为注释。

## 保持不变的内容

- 内置字母与你的字母并存，继续有效。
- 例程和工具栏按钮继续使用内置字母，因此你加载的内容不会出错。若你自己的字母会造成干扰，而你想手动键入内置字母，请在前面加一个下划线：`_PO`。
- 命令的简称是另一回事：参见 [编辑命令别名](topic:command-aliases)。

## 被拒绝的行

在以文本编辑或导入文件时，编辑器会按行号列出每个问题：

- 命令不存在（命令的别名可以使用：`AR.PO` 被读作 `ARRAY.PO`）；
- 该行不是 `COMMAND.OPTION, LETTERS` 格式；
- 字母中含有空格或符号（仅允许字母和数字，最多 16 个）；
- 同一命令的两个不同选项使用相同的字母。

## 导入和导出

{{ui:导出}} 将你的字母保存为文本文件，以便保留或交给他人。{{ui:导入…}} 读取此类文件。两者都位于编辑器中，以及 {{ui:设置}} › {{ui:CadCraft}} › {{ui:选项字母}} 中。

在设置中，{{ui:导入…}} 会用你选择的文件替换你现有的文件。若文件中有某行冲突或无法使用，则不会被采用；请打开编辑器并在那里导入，以查看具体的行。在编辑器中，导入只会填充文本框：在你单击 {{ui:保存}} 之前，不会有任何变化。

## 重新加载或移除

输入 {{cmd:REINIT}} 并按 {{key:Enter}}，以再次应用你的文件。若要移除一个字母，请删除其所在的行，然后单击 {{ui:保存}}。

## 你的字母跟随你的账户

当你登录 getcadcraft.com 时，你的字母会保存在你的账户中。在其他浏览器或其他计算机上以同一账户打开 CadCraft，它们会自动同步过来；命令行会显示 `来自您账户的选项字母`。若你在两处更改了它们，则以最新的副本为准，被替换的副本会保留一次。

{{ui:设置}} › {{ui:CadCraft}} › {{ui:选项字母}} 会说明它们的状态。未登录或离线时，它们保存在此浏览器中，并会在你登录时再次保存时同步到你的账户。
