界面分为七个部分。从上到下依次是：应用栏、工具栏、两侧各有一个面板的绘图区、绘图区下方的选项卡、命令行和状态栏。

## 应用栏

最顶部的细长栏属于网站，而不属于图形。它显示 CadCraft 标志、应用名称、你正在运行的版本、指向应用页面的链接、{{ui:帮助}}按钮（或{{key:F1}}）、{{ui:保存以供离线使用}}按钮、{{ui:全屏}}按钮，以及两个主题按钮{{ui:图纸}}和{{ui:模型}}。

{{ui:设置}}按钮（齿轮）包含 CadCraft 自己的设置以及各应用共用的设置：参见 [CadCraft 设置](topic:settings)。

{{ui:保存以供离线使用}}会在此浏览器中保留一份 CadCraft 的副本（包括其DWG读取器），使其无需网络连接即可打开。它的标签显示状态：“正在保存N/M”、“离线可用”、“无法保存”或“无法离线使用”。参见[离线工作](common:offline)。

:::note
应用栏中的{{ui:图纸}}和{{ui:模型}}按钮只改变屏幕的颜色：{{ui:图纸}}是浅色主题，{{ui:模型}}是深色主题。它们与绘图区下方的{{ui:模型}}选项卡无关，后者用于在图形及其图纸之间切换。
:::

{{ui:全屏}}按钮，或{{key:Ctrl+Shift+F}}（所有电脑上都是 Control 键，包括 Mac），循环切换三种屏幕模式：正常、全屏，以及隐藏各栏的全屏。各栏隐藏时，将指针移到屏幕顶部边缘即可使其重新出现。

## 工具栏

应用栏下方是工具栏。每个按钮都运行一个命令，与你输入该命令完全一样，因此命令行提出的问题也相同。将指针悬停在按钮上可看到其命令别名。分组如下：

| 分组 | 按钮 |
|---|---|
| 文件 | {{ui:新建}}、{{ui:打开}}、{{ui:保存}}、{{ui:另存为}}、{{ui:打印}} |
| 绘图 | {{ui:直线}}、{{ui:多段线}}、{{ui:圆}}、{{ui:圆弧}}、{{ui:矩形}}、{{ui:多边形}}、{{ui:椭圆}}、{{ui:文字}}、{{ui:段落}}、{{ui:填充}}，以及{{ui:更多}}：{{ui:点}}、{{ui:构造线}}和{{ui:射线}}（参见[构造线和射线](topic:construction-lines)） |
| 修改 | {{ui:移动}}、{{ui:复制}}、{{ui:旋转}}、{{ui:比例}}、{{ui:镜像}}、{{ui:拉伸}}、{{ui:偏移}}、{{ui:修剪}}、{{ui:延伸}}、{{ui:圆角}}、{{ui:倒角}}、{{ui:分解}}、{{ui:擦除}}，以及{{ui:更多}}：{{ui:阵列}}、{{ui:合并}}、{{ui:特性匹配}}、{{ui:打断}}和{{ui:拉长}} |
| 注释 | {{ui:线性}}、{{ui:对齐}}、{{ui:角度}}、{{ui:半径}}、{{ui:直径}}（标注）、{{ui:引线}}（多重引线），以及{{ui:更多}}：{{ui:连续标注}}、{{ui:基线标注}}和{{ui:修订云线}} |
| 参数化 | {{ui:自动}}、{{ui:约束}}、{{ui:标注}}、{{ui:参数}}，以及包含各个约束的{{ui:更多}}（参见[约束图形](topic:constraints)） |
| 块 | {{ui:创建}}、{{ui:插入}}、{{ui:图库}}，以及{{ui:更多}}：{{ui:编辑块}}和{{ui:定义属性}} |
| 图纸 | {{ui:新建图纸}}、{{ui:视口}} |
| 编辑 | {{ui:撤销}}、{{ui:重做}}、{{ui:复制}}（到剪贴板）、{{ui:粘贴}}，以及{{ui:更多}}：一个包含{{ui:剪切}}、{{ui:复制}}、{{ui:粘贴}}、{{ui:原位粘贴}}、{{ui:创建副本并移动}}、{{ui:删除}}、{{ui:全选}}、{{ui:取消选择}}、{{ui:快速选择}}、{{ui:选择相似对象}}和{{ui:查找和替换}}的菜单，每项都带有其按键 |
| 视图 | {{ui:范围}}、{{ui:窗口}}、{{ui:上一个}}，以及{{ui:更多}}：{{ui:测量距离}}、{{ui:面积}}、{{ui:测量（半径、角度…）}}，以及分割屏幕：{{ui:左右分割}}、{{ui:上下分割}}、{{ui:四个窗格}}、{{ui:单个窗格}}（参见[分割屏幕](topic:split-screen)），还有{{ui:将视图向左转90°}}、{{ui:将视图向右转90°}}、{{ui:回到世界坐标}}（参见[旋转视图](topic:ucs-and-turned-view)） |

“修改”组中的{{ui:复制}}是{{cmd:COPY}}命令（基点，然后是每个副本的位置）；“编辑”组中的{{ui:复制}}把对象放到剪贴板上供{{ui:粘贴}}使用。参见[复制、粘贴和创建副本](topic:copy-paste)。正在运行的命令的按钮会一直高亮，直到命令结束。工具提示会给出Windows快捷键（“Ctrl+O”）；在Mac上，{{key:Mod+O}}同样有效。

在较矮的窗口中（例如显示缩放到125%或更高的笔记本电脑），工具栏永远不会占用绘图区的位置：当绘图区的高度太小时，按钮会去掉图标下方的文字和分组名称（悬停在按钮上可看到名称），如果仍然不够，工具栏会变成可横向滚动的一行。更高的窗口会让文字重新出现。

## 左侧面板

左侧面板有三个部分。

- **{{ui:图层}}。**图形中的每个图层，当前图层前有一个实心圆点。单击名称可使该图层成为当前图层。每行有一个颜色色块（单击可选择颜色）和四个按钮：开/关（眼睛）、冻结（雪花）、锁定（挂锁）和打印（打印机）。{{ui:新建图层}}会打开一个框以添加图层。参见[用图层组织图形](topic:layers)。
- **{{ui:块}}。**图形中定义的块、每个块的使用次数，以及每个块的{{ui:插入}}按钮。参见[创建和插入块](topic:blocks)。
- **{{ui:图形}}。**关于打开的文件的信息：名称（有未保存的编辑时带“（已更改）”）、格式、大小、单位，以及对象、图层、块和图纸的数量。打开文件后，“关于此文件”框会列出 CadCraft 无法显示或必须转换的任何内容。

## 绘图区

屏幕中间是图形。指针是十字光标。当 CadCraft 需要一个点时，一个小标记和一个标签（“端点”、“中点”）会显示对象捕捉将落在哪里。当它需要对象时，十字光标带有拾取框，其下的对象会亮起。

图形为空时，“开始绘图”卡片会显示几个入门命令。你一运行命令或打开文件，它就会消失。你可以把DWG或DXF文件拖放到此区域的任何位置来打开它。

## 绘图区下方的选项卡

绘图区下方是选项卡：首先是{{ui:模型}}，然后是{{ui:3D}}，接着是每张图纸（布局）一个选项卡，最后是{{ui:+}}按钮。

- {{ui:模型}}是图形本身，按实际大小，使用图形单位。
- {{ui:3D}}显示平放在地面上的图形以及由它生成的实体。显示时，工具栏里有一个{{ui:3D}}组取代绘图分组。参见[三维建模](topic:3d-solids)。
- 每个图纸选项卡是一张带标题栏和指向模型的视口的纸。你在那里绘制的内容使用图纸单位（毫米或英寸）。在视口内双击可通过它处理模型（参见[通过视口处理模型](topic:sheets-and-viewports#work-on-the-model-through-a-viewport)）。过长的图纸名称在其选项卡上会被截短；悬停在选项卡上可看到完整名称。图纸很多时，{{ui:设置}} › {{ui:CadCraft}} › {{ui:图纸标签}} › {{ui:仅图纸编号}}只在选项卡上显示每张图纸的编号（A-101）。
- {{ui:+}}会新建一张带边框、标题栏和一个视口的图纸。它与{{cmd:LAYOUT}}命令相同。
- 双击图纸选项卡可重命名。选项卡获得焦点时，{{key:Left}}和{{key:Right}}可在选项卡之间移动。

每个选项卡都保留自己的缩放和平移。参见[设置图纸](topic:sheets-and-viewports)。

## 右侧面板：特性

右侧面板随所选内容而变化。

- **在{{ui:模型}}选项卡上未选择任何内容：**标题为{{ui:当前设置}}。在这里设置新对象的{{ui:图层}}、颜色和{{ui:文字高度}}、图形{{ui:单位}}，以及新标注的尺寸（{{ui:文字高度}}、{{ui:箭头大小}}、{{ui:小数位数}}、{{ui:总比例}}）。
- **在图纸上未选择任何内容：**标题为“图纸：”加图纸名称。你可以重命名图纸，更改其{{ui:图纸}}和{{ui:方向}}，{{ui:打印此图纸}}或{{ui:删除此图纸}}。新对象的设置在下面。
- **选择了一个对象：**标题为其类型（直线、圆、文字、标注、视口……），然后是其图层、颜色和几何数据。输入新值并按{{key:Enter}}即可更改。
- **选择了多个对象：**显示数量，以及它们共同的{{ui:图层}}和颜色。更改其中任何一项会更改全部对象。“各不相同”表示它们不同。

参见[用夹点和特性编辑](topic:grips-and-properties)。

其下方，当你选择{{ui:参数}}或输入{{cmd:PARAMETERS}}时，会打开{{ui:参数}}面板：在一张表中列出每个参数和标注约束。参见[使用参数和方程](topic:parameters)。

## 命令行

底部是命令行：上方是你操作的历史记录，下方是提示。

- 没有命令运行时，提示标签显示 `命令：`。命令运行时，它显示问题，方括号中是其选项，尖括号中是默认值，例如 `指定圆的半径 [直径(D)] <500>：`。
- 输入命令名称时，右侧的提示会建议匹配的命令。按{{key:Tab}}接受第一个。“没有此命令”表示没有任何匹配项。
- {{key:Up}}和{{key:Down}}可调回你之前输入的行。
- 历史记录保留最近400行。命令的消息、来自{{cmd:DIST}}和{{cmd:LIST}}的测量结果，以及保存和打印的报告都显示在这里。

## 状态栏

最底部一行是状态栏。

- 左侧的**坐标**：十字光标的X和Y。当命令有基点时，它还显示与基点之间的距离和角度，例如 `Δ 1200 < 90°`。
- 中间的**消息**，例如“正交开”或“当前图层：Walls”。它们几秒钟后消失。
- 右侧的**{{ui:栅格}}**、**{{ui:正交}}**、**{{ui:极轴}}**、**{{ui:捕捉}}**、**{{ui:追踪}}**、**{{ui:动态}}**和**{{ui:LWT}}**。每个都是开关；按下的按钮表示开启。{{ui:LWT}}在屏幕上显示线宽（参见[线宽和线型](topic:units-papers-scales#line-weights-and-linetypes)）。{{ui:捕捉}}旁边的小箭头打开{{ui:对象捕捉}}，你可以在那里勾选启用哪些捕捉。参见[捕捉到对象上的点](topic:object-snaps)。

## 打印为 PDF 对话框

{{ui:打印}}（或{{key:Mod+P}}）打开{{ui:打印为PDF}}对话框，左侧是设置，右侧是实时预览。参见[打印为 PDF](topic:plot-pdf)。

## 帮助

{{key:F1}}或{{ui:帮助}}按钮会以侧面板形式打开此帮助；图形在旁边仍可使用。它无需网络连接即可使用。再次按{{key:F1}}，或在面板内按{{key:Esc}}，即可关闭。参见[使用本帮助](common:help)。
