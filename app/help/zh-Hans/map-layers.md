## 将要制作的内容

在航拍图像或街道地图之上绘制的总平面图，每一部分都位于正确的位置。

## 告诉 CadCraft 图形的位置

1. 在{{ui:特性}} › {{ui:单位}}中设置图形单位（例如英尺或米）。
2. 输入{{cmd:MAPLAYERS}}（或`ML`）并按{{key:Enter}}键。
3. 在{{ui:图形所在位置}}下，于{{ui:查找坐标系}}中输入名称或 EPSG 代码（例如`2277`或`Texas Central`），并在{{ui:坐标系}}中选择它。
4. 如果图形是以该坐标系自身的坐标绘制的，请将放置参数保持为 0。否则，请给出一个图形点（{{ui:图形X}}、{{ui:图形Y}}），说明该点在地图网格上的位置（{{ui:东向}}、{{ui:北向}}），以及图形相对于东向旋转的角度（{{ui:旋转（°）}}）。
5. 点击{{ui:使用此坐标系}}。

## 添加图层

1. 打开对话框顶部的{{ui:来自互联网的地图图层}}。在此之前，不会向任何服务器请求任何内容；开启后，所添加的服务器只会看到屏幕上的区域和互联网地址，绝不会看到图形。
2. 在{{ui:添加图层}}中，选择其来源：
   - **瓦片（XYZ）**：带有`{z}`、`{x}`和`{y}`的瓦片地址，一个名称，以及提供方要求的署名。
   - **WMS**、**WMTS**或**ArcGIS**：服务地址，然后点击{{ui:获取图层}}并选择一个图层。
   - **图片**：带有其世界文件的 PNG 或 JPEG（如有，还需其`.prj`文件）。
3. 该图层显示在图形下方。其署名显示在图形的右下角。

列表中的每个图层都可以隐藏、调整透明度、上下移动或删除。

对坐标系或图层的每次更改都是{{cmd:UNDO}}的一个步骤。

## 随图形保存

当以 DWG 或 DXF 格式保存时，坐标系和图层列表会保存在图形中，并在任何计算机上再次打开时恢复。从文件导入的图片不会被保存：打开后需重新添加。{{ui:来自互联网的地图图层}}开关不会保存在图形中：它属于此浏览器，因此他人发来的图形在您自行开启之前不会向任何服务器请求任何内容。

其他程序会看到的内容：

| 保存为 | 图形的位置 | 地图图层 |
|---|---|---|
| DWG 2010、2013 或 2018，DXF 2000 | 以程序读取图形地理位置的标准方式写入：坐标系的 EPSG 代码、一个图形点及其在地图网格上的位置、单位和北向。 | 仅CadCraft |
| DWG 2000、2004 或 2007，DXF R12 | 仅CadCraft（保存时 CadCraft 会提示） | 仅CadCraft |

- **已检查：** ODA File Converter 读取位置时没有错误，DXF 库（ezdxf）能准确读取 EPSG 代码和放置参数。
- **尚未检查：** 其他制图程序能否通过 EPSG 代码识别该坐标系。若某程序使用自己的坐标系名称列表，则可能会在没有位置的情况下显示图形。
- 其他程序的块列表中会显示名为`CADCRAFT_GEO`的块。它是 CadCraft 自身的坐标系和图层副本，从不会放置在图形中。请保留它。

## 来自其他程序的图形

当来自其他程序的图形具有地理位置时，CadCraft 会读取它：

- 如果其中给出了 EPSG 代码，{{ui:图形所在位置}}会显示该坐标系，且地图图层将由其定位。
- 如果 CadCraft 不识别该坐标系（其他程序自定义的名称、本地网格或比例因子），则不会使用该位置，但会保留它并按原样保存，以便其他程序仍能找到它。在{{ui:图形所在位置}}中选择一个坐标系即可替换它。

:::note
地图图层仅在屏幕上绘制，不会打印。请仅使用条款允许此用途的地图服务，并保持其署名可见。
:::
