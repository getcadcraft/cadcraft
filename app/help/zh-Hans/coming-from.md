如果你用过 AutoCAD，或基于同一模型的程序，那么你掌握的大部分内容在这里仍然适用：命令行、别名（如`L`、`C`、`TR`和`O`）、按Enter或Space重复命令、窗口与窗交选择、按F3使用对象捕捉、按F8使用正交、带布局和视口的模型空间。本页列出了直接对应的内容，以及容易让人出错的差异。即使只是粗略浏览前半部分，也请阅读后半部分。

## 直接对应的内容

| 习惯 | 在 CadCraft 中 |
|---|---|
| `L`、`PL`、`C`、`A`、`REC`、`POL`、`EL`、`PO`、`T`、`DT` | 命令相同，别名相同 |
| `M`、`CO`、`RO`、`SC`、`MI`、`O`、`TR`、`EX`、`F`、`X`、`E` | 相同 |
| `DLI`、`DAL`、`DAN`、`DRA`、`DDI`、`DCO`、`DBA` | 相同的标注命令 |
| 在命令行输入`DIMSCALE`、`DIMTXT`、`DIMASZ`、`DIMDEC`、`DIMGAP`、`DIMEXE`、`DIMEXO` | 相同，适用于新标注 |
| `B`创建块，`I`插入，`PU`清理 | 相同（清理仅删除未使用的块） |
| `LAYOUT`、`MV`、`PLOT`、`DI`、`ID`、`LI`、`Z`后接`E`或`W` | 相同 |
| 从脚本或习惯中输入`_LINE`或`-LAYER` | 开头的`_`、`-`、`.`或`'`会被忽略 |
| 在空提示下按Enter或Space重复上一个命令 | 相同 |
| Esc取消；再次按Esc清除选择 | 相同 |
| `@dx,dy`、`@d<a`，输入的角度以东向逆时针计算 | 相同 |
| 从左到右为窗口，从右到左为窗交，单击-单击；按下并拖动可使用套索，Space在窗口/窗交/栏选之间切换（LASSOMODE） | 相同 |
| 先选择后执行命令（名词-动词） | 相同；命令完成后会清除选择 |
| 在选择对象提示下输入`ALL`和`L` | 相同 |
| Shift+单击从选择中移除 | 相同。设置可使单击改为替换选择，与 PICKADD 0 的效果相同：参见[CadCraft 设置](topic:settings) |
| Ctrl+C、Ctrl+X、Ctrl+V、Ctrl+Shift+V（COPYCLIP、CUTCLIP、PASTECLIP、PASTEORIG）、COPYBASE | 命令和按键相同；粘贴时以副本的左下角定位，与 PASTECLIP 相同 |
| F3对象捕捉、F7栅格、F8正交 | 按键相同 |
| 双击滚轮缩放至范围 | 相同 |
| 镜像文字保持可读 | 相同（与 MIRRTEXT 0 相同） |
| Ctrl+Z、Ctrl+Y、Ctrl+S、Ctrl+O、Ctrl+P、Ctrl+A | 相同；在 Mac 上也可以使用 Command |

## 容易出错的差异

### 输入的点为绝对坐标

开启动态输入时，其他程序会把第二点输入的`100,0`视为相对坐标。**CadCraft 的命令行则不然：**在这里，`x,y`始终以原点为基准测量。开启{{ui:动态}}（{{key:F12}}）后，请改用其输入框：距离、{{key:Tab}}、角度。若要表示“位于上一点右侧 100 处”，请使用`@100,0`，或将十字光标移到正确方向后直接输入`100`。

### Shift跳过捕捉，但不会切换正交

单击时按住Shift会忽略该次单击的对象捕捉，但不会临时切换正交。请使用F8或{{ui:正交}}按钮。

### 右键始终相当于Enter

没有右键菜单。在图形中右击相当于Enter：结束命令、完成选择或重复上一个命令。在夹点移动或选择框操作期间，右击则改为取消。按住右键拖动可平移。

### 不能用空格键平移

Space相当于Enter，因此按住Space并拖动不会平移。请使用中键或右键平移，或使用滚轮缩小后在其他位置再放大。

### 修剪和延伸

修剪和延伸默认以快速模式启动：每个可见对象都是剪切边或边界，指针下方的部分会显示将被删除的内容，拖动的路径会修剪所经过的每个部分，未与任何对象相交的对象将被删除。{{key:Shift}}可在修剪与延伸之间切换。`O`切换到标准模式（需先选择边），`F`和`C`分别为栏选和窗交，`E`为EDGEMODE，`R`为删除。没有`P`（投影）选项：CadCraft 在图形平面内进行修剪。

### 圆角和倒角

{{cmd:FILLET}}和{{cmd:CHAMFER}}支持你熟悉的选项：放弃、多段线、半径（或距离、角度和方法）、修剪和多个，按住{{key:Shift}}单击可得到尖角。多段线与直线之间的圆角会将圆弧作为独立对象添加，而不会将其合并到多段线中；与圆弧段相邻的多段线拐角保持不变。

### 段落文字和单行文字

`T`、`MT`和`MTEXT`是就地输入的段落文字，可设置宽度、行距和对齐方式；`DT`和`DTEXT`是你熟悉的单行文字。目前没有文字样式或分栏，也尚不能输入文内格式（粗体、堆叠分数）；文件中带来的格式会被保留、绘制并保存（参见[添加文字和标注](topic:text#formatting-inside-paragraph-text-from-other-programs)）。所有文字均以类似 Helvetica 的字体绘制。

### 保存即"下载副本"

{{key:Mod+S}}、`SAVE`和`QSAVE`会以图形的格式下载一个副本：打开的 DWG 保存为 DWG，DXF 保存为 DXF。在浏览器中不会原地覆盖任何文件，已打开的文件也不会被更改。在 CadCraft Studio 中，{{key:Mod+S}}会写回你打开的文件。

`SAVEAS`（{{key:Mod+Shift+S}}）是一个小型对话框，而不是文件浏览器：选择{{ui:DWG}}（及其{{ui:版本}}，AutoCAD 2000 至 2018）、DXF R12或{{ui:DXF 2000}}，然后单击{{ui:保存}}。下载位置由浏览器决定。`DXFOUT`始终下载 DXF R12。

打开的 DWG 按其原有版本保存；新图形除非另行选择，否则以 AutoCAD 2000 格式保存。图纸、标注和图案填充均会保留。参见[文件：可打开和可保存的格式](topic:files#saving)。

### 图层：更简单

- 每次图层更改（开、冻结、锁定、颜色、打印、线型、线宽、当前图层）都是一个撤销步骤。
- 在 CadCraft 中，关闭与冻结的效果相同。
- 图形在某个视口中冻结的图层，将在该视口中保持冻结：屏幕显示、打印以及保存为 DWG 或 DXF 时均如此。
- 若视口以自身的颜色、线型、线宽或透明度显示某图层，则该设置会在屏幕、打印及保存的 DWG 中保持不变（DXF 保留图层自身的设置；保存时会有提示）。尚未实现按视口更改这些设置。
- 没有图层特性管理器，也没有图层状态；{{cmd:RENAME}}、{{cmd:LAYMRG}}和{{cmd:LAYDEL}}分别用于重命名、合并和删除图层。线型和线宽在右侧面板中设置（参见[线宽和线型](topic:units-papers-scales#line-weights-and-linetypes)）；{{cmd:LAYISO}}、{{cmd:LAYOFF}}、{{cmd:LAYFRZ}}和{{cmd:LAYMCUR}}通过拾取对象来工作。
- 保存为 DXF R12 时，图层名称会以大写字母写入。DWG 则保留你输入时的大小写。

### 标注样式

`DIMSTYLE`打开命名样式的管理器（新建、修改、设为当前、比较、应用）。`DIMSCALE`及其他设置仍会更改新标注所使用的值，且每个标注保留其自身的尺寸，也可在特性面板中更改。当前样式不会保存在文件中。标注遵循图形的长度格式（小数，或使用{{cmd:UNITS}}设置的英尺和英寸），或其自身的{{ui:格式}}。参见[设置标注尺寸](topic:dimension-settings)。

### 打印更简单

打印样式表与 CTB 文件一样按颜色工作：内置单色、颜色和灰度三种，你也可以创建自己的样式表，每张图纸保留其自身的样式表。CTB 文件的读取基于公开的规范实现，且仅在我们自己制作的文件上测试过；命名打印样式表（STB）和页面设置尚未实现。线条按其线宽打印，其他对象以统一的笔宽打印。图纸以 1:1 比例在其自身的纸张上打印；模型则按选定比例或适合页面的方式打印。参见[打印为 PDF](topic:plot-pdf)。

### 在视口内工作

与你熟悉的方式相同：在视口内双击（或输入{{cmd:MSPACE}}）即可通过视口编辑模型，在视口外双击（或输入{{cmd:PSPACE}}）则返回图纸。在视口内平移和缩放会改变视口所显示的内容，除非其显示已锁定；此时它们将移动图纸。单击图形下方的选项卡也会退出视口。参见[通过视口编辑模型](topic:sheets-and-viewports#work-on-the-model-through-a-viewport)。

### 支持追踪和动态输入，但尚未支持栅格捕捉

栅格仅供查看，点不会捕捉到栅格（没有 F9 捕捉模式）。极轴追踪（{{key:F10}}，步长使用{{cmd:POLARANG}}设置）和对象捕捉追踪（{{key:F11}}：在捕捉点上停留即可获取）的工作方式与你熟悉的相同；参见[捕捉到对象](topic:object-snaps#polar-tracking)。动态输入（{{key:F12}}）会在十字光标旁显示距离和角度（或 X 和 Y）；参见[坐标和距离输入](topic:coordinate-entry#dynamic-input)。

### 英尺和英寸

选择{{ui:长度格式}}下的{{ui:建筑}}或{{ui:工程}}（或输入{{cmd:UNITS}}），并按你熟悉的方式输入长度：`12'6"`、`12'6-1/2"`。分数前请使用连字符而非空格：Space相当于Enter。同时将{{ui:单位}}设为{{ui:英寸}}，使图纸和打印提供建筑比例。该格式会保存在 DWG 和 DXF 文件中。参见[英尺和英寸](topic:units-papers-scales#feet-and-inches-and-fractions)。

### 复制和粘贴仅限于 CadCraft 内部

{{key:Mod+C}}、{{key:Mod+X}}和{{key:Mod+V}}可在同一图形内、不同图形之间，以及同一浏览器中的 CadCraft 选项卡之间复制、剪切和粘贴对象。剪贴板为 CadCraft 专用：你不能将 CadCraft 对象粘贴到其他程序中，也不能将其他程序中的对象粘贴到 CadCraft 中。从使用其他单位的图形粘贴时不会重新缩放：之后请使用{{cmd:SCALE}}。{{key:Mod+D}}是一个随指针移动的副本，为 CadCraft 新增功能。参见[复制、粘贴和创建副本](topic:copy-paste)。

### 无法使用的浏览器按键

网页无法接管浏览器中的{{key:Mod+N}}、{{key:Mod+W}}或{{key:Mod+T}}：这些键用于打开和关闭窗口及选项卡。请使用{{ui:新建}}按钮或输入`NEW`。参见[按键、鼠标和触控板](common:keys)。
