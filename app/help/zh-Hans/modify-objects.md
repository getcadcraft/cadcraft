## 你将制作的内容

一张桌子，周围复制了一把椅子、将其旋转、镜像并调整了大小。过程中会用到 {{cmd:MOVE}}、{{cmd:COPY}}、{{cmd:ROTATE}}、{{cmd:MIRROR}}、{{cmd:SCALE}} 和 {{cmd:UNDO}}。

## 绘制各部件

1. 输入`REC`并按{{key:Enter}}，输入`0,0`并按{{key:Enter}}，然后输入`@1800,900`并按{{key:Enter}}。这是桌子。
2. 输入`REC`并按{{key:Enter}}，输入`300,-700`并按{{key:Enter}}，然后输入`@450,450`并按{{key:Enter}}。这是一把椅子，位于桌子下方。
3. 单击{{ui:范围}}。

## 移动：基点，然后第二点

每次移动、复制、旋转和缩放都从一个**基点**开始：即被带着走或被旋转所围绕的那个点。

1. 单击椅子以选中它。
2. 输入`M`并按{{key:Enter}}。历史记录显示`1 found`。
3. 在`Specify base point`提示处，捕捉椅子的左上角（端点）并单击。
4. 在`Specify second point`提示处，输入`@0,200`并按{{key:Enter}}。

椅子向上移动了 200，更靠近桌子。

:::tip
在`Specify base point`提示处输入`D`，可以改为给出位移：CadCraft 随后会提示`Specify displacement`，你输入横向和纵向的距离，例如`0,200`（无需`@`）。
:::

## 复制，想复制多少次都行

1. 单击椅子。
2. 输入`CO`并按{{key:Enter}}。
3. 捕捉椅子的左下角并单击，作为基点。
4. 输入`@600,0`并按{{key:Enter}}。出现一个向右 600 的副本。
5. 再次输入`@600,0`并按{{key:Enter}}。出现第二个副本，位于原对象右侧 1200 处。
6. 按{{key:Enter}}结束命令。

{{cmd:COPY}} 会持续运行，直到你按{{key:Enter}}为止。每个副本都按基点到你给定点的距离放置。`@` 点以你最后输入的点为起点，第一个副本之后，最后的点就是该副本的位置，因此两次`@600,0`会得到位于 600 和 1200 处的副本。输入`U`并按{{key:Enter}}，可以在不退出命令的情况下撤回最后一个副本。

你应该会看到桌子下方排成一行的三把椅子。

:::tip
{{cmd:COPY}} 用于在同一图形内按基点放置副本。若要将对象带到另一个图形或选项卡，或稍后粘贴，请使用剪贴板：{{key:Mod+C}}，然后{{key:Mod+V}}。{{key:Mod+D}} 可创建一个随指针移动的副本。参见 [复制、粘贴和创建副本](topic:copy-paste)。
:::

## 将这一行镜像到另一侧

1. 从右向左拖动一个窗交框，框住三把椅子，但不要碰到桌子。
2. 输入`MI`并按{{key:Enter}}。
3. 在`Specify first point of mirror line`提示处，捕捉桌子左边的中点并单击。
4. 在`Specify second point of mirror line`提示处，捕捉桌子右边的中点并单击。
5. 在`Erase source objects? [Yes/No] <N>`提示处，按{{key:Enter}}保留原对象。

你应该会看到桌子下方三把椅子，以及桌子上方三把镜像的椅子。镜像选择集中的文字保持可读：它以镜像方式放置，但文字本身不会反向书写。

## 旋转椅子

1. 单击桌子下方最右侧的椅子。
2. 输入`RO`并按{{key:Enter}}。
3. 捕捉椅子的右下角并单击，作为基点。
4. 输入`90`并按{{key:Enter}}。

椅子绕基点逆时针旋转 90 度。负角度则顺时针旋转。你也可以不输入角度，而是单击第二个点：角度由基点到该点的方向决定。

## 缩放桌子

1. 选中桌子。
2. 输入`SC`并按{{key:Enter}}。
3. 捕捉桌子的左下角并单击，作为基点。
4. 输入`1.2`并按{{key:Enter}}。

桌子放大了 20%，以基点为中心向外扩展。比例小于 1 则会使其缩小。

:::note
若你不输入比例因子而是单击一个点，则比例因子为基点到该点的距离。单击距离基点一个图形单位的位置，比例因子为 1。通常直接输入数字更方便。
:::

## 撤销和重做

- {{key:Mod+Z}}、{{ui:放弃}}按钮，或输入`U`后按{{key:Enter}}，都可以撤销上一个命令。一整个命令算作一步：撤销一次制作了五个副本的 {{cmd:COPY}}，会将五个副本全部移除。
- {{key:Mod+Y}}、{{key:Mod+Shift+Z}}、{{ui:重做}}按钮，或输入`REDO`，可将其恢复。
- 历史记录会显示被撤销的内容（“已撤销 COPY”）。

CadCraft 保留最近 500 步。图层设置（开、冻结、锁定、颜色）属于设置而非编辑，不会被撤销。

## 将房间向右拉宽

{{cmd:STRETCH}}（`S`，或{{ui:拉伸}}）只移动位于窗交框内的部分：框内的角点和线段端点会移动，其余保持不动，因此房间会变宽而不是整体移动。

1. 输入`S`并按{{key:Enter}}。
2. 从右向左拖动一个窗口，覆盖右侧墙体，使其包含墙体的角点以及与之相交的对象的端点。
3. 按{{key:Enter}}。
4. 单击一个基点，然后输入`@600,0`并按{{key:Enter}}。

矩形变宽了 600；端点落在墙上的线段仍然落在墙上。一端位于框内的圆弧会保持其高度；圆和文字在圆心或插入点位于框内时会移动；标注则会测量新的长度。未使用窗口而逐个选中的对象则直接移动。

也可以先选择：在没有运行任何命令的情况下，将窗交框（或窗交套索）拖过墙体，然后输入`S`。STRETCH 会采用该选择集，并拉伸其窗口所包含的内容，就像你在其提示下拖动它们一样。

## 阵列：行和列，或绕中心

{{cmd:ARRAY}}（`AR`，或{{ui:阵列}}）可将选择集复制为网格或圆形。

1. 选中一把椅子，输入`AR`并按{{key:Enter}}。按{{key:Enter}}选用矩形。
2. 出现 4 列 3 行的预览。输入`COU`并按{{key:Enter}}，然后输入`5`作为列数，`2`作为行数。
3. 输入`S`并按{{key:Enter}}，然后输入`600`作为列间距，`-900`作为行间距（负值向下）。
4. 按{{key:Enter}}生成副本。

若要在桌子周围排成一圈椅子，请改选`PO`（极轴），单击桌子的中心，并设置`I`（项目数）、`F`（填充角度：360 表示整圈，180 表示半圈）和`ROT`（副本是否旋转至朝向中心）。{{cmd:ARRAYRECT}} 和 {{cmd:ARRAYPOLAR}} 则会跳过此询问。

## 将各段合并为一条多段线

{{cmd:JOIN}}（`J`，或{{ui:修改}} › {{ui:更多}} › {{ui:合并}}）：选中端点相接的直线、圆弧和开放多段线，然后按{{key:Enter}}。它们会合并为一条多段线；若绕成一圈则闭合，之后可一次性偏移。位于同一直线上的线段即使中间有间隙，也会合并为一条直线；同一圆上的圆弧会合并为一条圆弧，或合并为圆。

## 特性匹配

{{cmd:MATCHPROP}}（`MA`，或{{ui:修改}} › {{ui:更多}} › {{ui:特性匹配}}）：单击你想要其外观的对象，然后选择要更改的对象并按{{key:Enter}}。它们会采用该对象的图层和颜色；文字会采用其高度，标注会采用其尺寸，填充会采用其图案。在第二个询问处输入`S`（设置），可关闭其中任一项。

## 对齐对象

**按点对齐。** {{cmd:ALIGN}}（`AL`，或{{ui:修改}} › {{ui:更多}} › {{ui:对齐}}）：选中对象并按{{key:Enter}}，然后
单击其上的一点（源点），再单击该点应移至的位置（目标点）。

- 一对点会移动对象。在`Specify second source point`提示处按{{key:Enter}}即可停止。
- 两对点还会旋转对象，使两个源点之间的连线与两个目标点之间的连线方向一致。随后 CadCraft 会询问`Scale objects based on alignment points?`：输入`Y`会同时将对象放大或缩小相应比例。
- 当第三对点的两个点位于该线的两侧时，会镜像对象。

**边缘与间距。** {{ui:修改}} › {{ui:更多}} › {{ui:对齐和分布}}（或`ALIGNPANEL`）会在图形上方打开一个小面板。选择对象，然后：

- 在{{ui:对齐到}}中选择对齐的基准（整个选择集、你先选或最后选的对象，或你单击的一点），然后单击{{ui:左}}、{{ui:中心}}、{{ui:右}}、{{ui:俯视}}、{{ui:中}}或{{ui:仰视}}；
- 或选择{{ui:间隙相等}}或{{ui:中心相等}}，然后单击{{ui:水平}}或{{ui:竖直}}：两端的两个对象保持不动，其余对象在它们之间均匀分布（至少三个对象）。

每次单击都是一步撤销，选择集保持不变，因此可以尝试其他方式。每个对象按其外接框计算，若已设置 UCS，则在 UCS 中计算。在命令行中，相同功能对应 {{cmd:ALIGNTO}} 和 {{cmd:DISTRIBUTE}}。

## 删除和分解

- {{cmd:ERASE}}（`E`，或{{key:Delete}}）删除选中的对象。
- {{cmd:EXPLODE}}（`X`）将多段线分解为直线和圆弧，将块参照分解为其组成对象，并将标注分解为直线、箭头和文字。分解后的标注不再自动测量。

## 常见错误

- **在第二个点处输入距离时省略了`@`。** `600,0`表示绝对坐标点 600,0，而不是“向右 600”。请使用`@600,0`，或仅输入`600`，并让十字光标指向正确的方向。
- **旋转方向相反。** 正角度为逆时针旋转。
- **撤销移除了比预期更多的内容。** 一次撤销会撤回整个上一个命令，包括它制作的每一个副本。
- **命令没有要求选择对象。** 对象已被选中，因此命令直接使用它们。请先按{{key:Esc}}，以在未选中任何对象的状态下开始。
