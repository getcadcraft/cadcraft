## 概览

| 格式 | 打开 | 保存 | 备注 |
|---|---|---|---|
| DXF（文本或二进制，任意版本） | 是 | 是，保存为 DXF R12、DXF 2000 或 DXF 2000（二进制） | 二进制 DXF 的打开方式与文本 DXF 相同，保存时仍为二进制。 |
| DWG | 是 | 是，保存为 DWG（AutoCAD 2000、2004、2007、2010、2013 或 2018） | 由 CadCraft 自有的 DWG 库读写（AutoCAD R13 至 2018 文件）。原始 DWG 文件从不被更改。损坏的文件或读取器无法处理的版本会被拒绝并给出提示。 |
| PDF | 将一页导入：作为底图或作为对象（[PDF 底图](topic:pdf-underlay)） | 是，通过打印 | 图纸或按比例打印的模型的矢量 PDF。 |

打开的每个图形（或以{{ui:新建}}开始的图形）都会在绘图区上方获得自己的选项卡；尚未被任何人修改的新图形会被复用，而不是新增选项卡。单击选项卡即可切换，单击其{{ui:×}}即可关闭（若有未保存的更改，CadCraft 会先询问），或将打开的图形并排平铺：参见[拆分屏幕](topic:split-screen)。

## 打开图形

- 按{{key:Mod+O}}，单击{{ui:打开}}，或输入 `OPEN`，然后选择文件。
- 或将 `.dwg` 或 `.dxf` 文件拖到绘图区。

文件在浏览器中读取，不会上传到任何位置。历史记录会报告导入了多少对象和图层以及耗时，左侧面板的{{ui:图形}}部分会显示格式，例如“DWG 2018 (AC1032)”。

DWG 读取器是 CadCraft 的一部分，在页面加载后打开的第一个 DWG 时获取（几百 KB），因此无需单独下载等待。它在后台读取文件，因此打开大型 DWG 时页面仍保持响应。

DXF 以约 4 MB 的块读取，从不作为一整段文本读取，因此超过 512 MB 的 DXF 也能打开。限制因素是计算机的内存：打开 DXF 时，其占用大约为文件大小的 16 至 20 倍（在我们的测试中，一个约 690,000 个对象、100 MB 的 DXF 占用约 1.5 GB）。

### 可导入的内容

- 直线、圆弧、圆、多段线（含圆弧段）、椭圆、点、文字和多行文字、实体、填充（标准图案按其线条绘制，其他图案以平面色调显示）、带属性的块参照（可编辑的属性值；参见[块属性](topic:attributes)）、标注，以及带视口的布局。
- 样条曲线按样条曲线导入（阶数、控制点、节点、权重、拟合点）；参见[样条曲线与多段线](topic:splines)。
- 带一条引线和文字的多重引线会以可编辑的 CadCraft 多重引线导入（参见{{cmd:MLEADER}}）。其他多重引线（带块、多条引线或曲线）按其他程序的绘制方式绘制，并作为一个整体移动；历史记录会显示数量。
- 图像（图片）在通过{{cmd:IMAGE}}向 CadCraft 提供文件之前，显示为带有图像文件名的边框：参见[图形中的图像](topic:pictures#show-the-pictures-a-dwg-uses)。遮盖显示为其边框，其下方的内容仍保持可见。
- DWG 中的表格按其他程序的绘制方式导入。
- 模型空间中的三维面会导入到{{ui:3D}}选项卡，而不是作为二维对象；块内的三维面也是如此，每个块引用在模型中导入一次。在块中和布局上，它们同样以轮廓形式平面绘制。参见[三维模型](topic:3d-solids)。
- 图层保留其颜色、开、冻结、锁定和打印设置。DEFPOINTS 从不打印。
- 当其点可读取时，标注会转换为可编辑的真实 CadCraft 标注。它们最初与其他程序的绘制效果完全相同；一旦更改其中某个标注，CadCraft 就会以自身样式重新绘制。
- 每个布局都会成为一个布局选项卡。在其他程序中，每个布局都有一个隐藏的第一视口，即布局本身；CadCraft 不包含该视口。

### 尚未导入的内容

CadCraft 无法绘制的任何内容都会被计数，而不是猜测。左侧面板中的“关于此文件”框会以“尚未显示：”列出，后面是每种对象及其数量。典型情况包括 DXF 中的表格、网格以及块内的三维实体。模型空间中的三维实体、面域和实体会显示在三维选项卡中（参见[三维模型](topic:3d-solids#solids-from-other-programs)）。文件中扭转的视口会按原样扭转显示，并在保存时保留其扭转；当前 UCS、命名 UCS 和旋转视图同样如此。

文字使用一种 Helvetica 风格的字体绘制。在原程序较窄字体中单行可容纳的标签，在 CadCraft 中可能会换行为两行。

## 保存

保存有三种方式。每种方式都会下载一份副本。

- **保存**：按{{key:Mod+S}}，单击{{ui:保存}}，或输入 `SAVE`（也可用 `QSAVE`）。它以图形的格式保存：若打开的是 DWG，则保存为 DWG；若打开的是 DXF，则保存为 DXF。DWG 保留其导入时的版本（2018 版文件保存为 2018）。新图形使用在本浏览器中“另存为”时最后选定的格式和 DWG 版本；如果从未选择过，则使用 AutoCAD 2000 格式的 DWG。
- **另存为**：按{{key:Mod+Shift+S}}，单击{{ui:另存为}}，或输入 `SAVEAS`。{{ui:将副本另存为}}对话框提供{{ui:DWG}}、{{ui:版本}}列表（AutoCAD 2018、2013、2010、2007、2004 或 2000）、{{ui:DXF R12}}和{{ui:DXF 2000}}，每项都附有其将生成的文件名，并已预先选定图形当前的格式和版本。单击{{ui:保存}}即可下载，或单击{{ui:取消}}（或按{{key:Esc}}）则不保存任何内容；历史记录随后会显示“未保存。”所做的选择会被记住：此后{{key:Mod+S}}会对此图形使用该选择，且本浏览器中的新图形也会以此开始。
- **DXFOUT**：输入 `DXFOUT`。它始终下载一份 DXF R12 副本，下一次{{key:Mod+S}}仍以图形自身的格式保存。

浏览器会下载 `<图形名称>.dwg` 或 `<图形名称>.dxf`。每次保存都是**新下载**；打开的原文件从不会被覆盖或更改。历史记录会确认这一点，例如：“已将副本另存为 Plan.dwg (DWG (AutoCAD 2018))。原始文件 Plan.dxf 未更改。”对于 DXF，它会显示“(DXF R12，可在任何 CAD 程序中打开)”。其下方的行会列出过程中发生更改的任何内容。

在桌面应用中运行 CadCraft 时，保存方式与其他桌面程序相同：{{key:Mod+S}}会将图形以其自身的格式和版本写回到打开的文件，历史记录会显示保存位置。{{ui:另存为}}和导出会显示系统的保存对话框；双击 `.dwg`、`.dxf` 或 `.ccsheets` 文件即可在 CadCraft 中打开。

对于 PDF，请改为打印（见下文）。

## DWG 保留与更改的内容

CadCraft 在浏览器内部自行写入 DWG，使用与读取时相同的 DWG 库。在“另存为”中选择版本：AutoCAD 2000 格式（文件版本 AC1015）可在最多的程序中打开，包括较旧的程序；较新的格式（2004、AC1018，直至 2018、AC1032）还能保留真彩色。不会上传任何内容，保存 DWG 可离线进行。

每个版本都通过用另外三个程序的 DWG 读取器以及 CadCraft 自身读回已保存的文件来进行检查。CadCraft 生成的 DWG 尚未在 AutoCAD 本身中打开过。

### DWG 保留的内容

- 直线、圆弧、圆、椭圆、点，以及带圆弧段的多段线。
- 单行文字及其对齐方式和宽度系数。
- 多行文字和换行文字，保留为多行文字。其他程序会按相同宽度重新换行。
- 对象颜色：随层、随块、255 种标准颜色，以及 2004 格式及更高版本中的真彩色。
- 图层及其颜色、线型、线宽，以及其开、冻结、锁定和打印设置；对象自身的线型、线宽和线型比例、线型图案，以及图形的线型比例。
- 图形单位和长度格式（小数、英尺和英寸、分数…）。
- 块及其基点和属性定义，包括不可见、常量和预设的属性。
- 块参照及其缩放、旋转和属性值。
- 实心填充，以及带图案、比例和角度的图案填充（图案自身的线条，因此其他程序绘制的线条与 CadCraft 相同）。
- 标注保留为真实标注：其他程序在拉伸时会重新测量。每个标注保留其自身设置（文字高度、箭头大小、小数位数、长度格式）及其文字，并附带每个 DWG 标注都有的绘制副本。
- 布局：每个布局保留其图纸尺寸和单位、绘制在其上的内容，以及带有视图和比例的视口。
- 命名视图。
- 多重引线，保留为多重引线。
- 图层和块名称按输入时的原样保留，区分大小写。（DXF R12 以大写形式写入。）

### DWG 更改的内容

以下各项在适用于该图形时，会在保存后列在历史记录中。

| 在 CadCraft 中 | 在保存的 DWG 中 |
|---|---|
| 真彩色（用取色器选取），采用 2000 格式 | 最接近的标准颜色：2000 格式只有 255 种颜色。另存为 2004 或更高版本以保留它们 |
| 布局的命名视图 | 图纸空间视图：DWG 不记录所属布局，因此当 CadCraft 再次打开文件时，它们属于第一个布局 |
| 带宽度系数的多行文字 | 正常字母宽度：在 DWG 中，宽度系数仅适用于单行文字 |
| 含 DWG 不允许字符的图层或块名称 | 已更改：如 `Base\|Walls` 这样来自链接图形的名称会变为 `Base$0$Walls`（绑定链接图形时的命名方式），其他字符变为 `_` |

### 为何使用 R12，以及哪些内容会转换

另存为 DXF 时，CadCraft 写入 DXF R12，这是每个 CAD 程序都能打开的版本。由于它早于某些功能，因此有些内容会以更简单的形式写入：

| 在 CadCraft 中 | 在保存的 R12 文件中 |
|---|---|
| 多行文字 | 每行一个文字对象 |
| 椭圆 | 沿椭圆走向的多段线 |
| 填充（来自打开的文件） | 仅其轮廓 |
| 真彩色（用取色器选取） | 最接近的标准颜色 |
| 线宽，以及对象自身的线型比例 | 省略：R12 两者都不支持（线型会保留） |
| 图层和块名称 | 以大写形式写入；空格和其他字符变为 `_`，名称截断为 31 个字符（“Title block”变为 `TITLE_BLOCK`） |
| 设置为不打印的图层 | 其他程序会打印它们（当图形包含布局时，CadCraft 会记住该设置） |
| 标注 | 带有自身绘制块的真实标注，因此其他程序会按所见方式显示它们 |
| 多重引线 | 其绘制的线条、箭头和文字 |
| 命名视图 | 保留，名称以大写形式写入；布局的视图会返回到第一个布局 |
| 多个布局 | 第一个布局是每个程序都会显示的图纸空间；其他布局保留为名为 `CCLAYOUT_1`、`CCLAYOUT_2` … 的块，CadCraft 打开文件时会将其还原为布局 |

历史记录会列出适用于该图形的每一项。

:::tip
若要连续几天处理同一图形，请另存为 DXF，下次打开该 DXF。CadCraft 能绘制的所有内容都能在往返过程中保留，包括标注、块和所有布局。
:::

## 链接图形（外部参照）

{{cmd:XATTACH}}（`XA`，或{{ui:块}} › {{ui:更多}} › {{ui:链接图形（外部参照）}}）用于链接另一个 DWG 或 DXF：选择文件，然后单击放置位置（按{{key:Enter}}则放在 0,0）。它作为一个以该文件命名的块导入，当两个图形的单位不同时，会按正确的比例导入。其图层和块保留其名称，并在前面加上链接名称，例如 `Plan|Walls`、`Plan|Door`，因此它们永远不会与图形自身的内容混淆：可像管理自己的图层一样打开和关闭、冻结或锁定链接的图层。链接是只读的：更改另一个图形后重新加载即可。对链接图层所做的设置（颜色、线型、线宽、开/关、冻结、锁定、打印）在重新加载时、在链接仍为链接时将图形另存为 DWG 时，以及在另一图形链接此图形时都会保留。

{{cmd:XREF}}（`XR`）：`?` 列出链接（无论是否已加载、所属文件、引用数量）；`A` 附加；`R` 从其文件重新加载某个链接（需重新选择文件：浏览器无法自行访问文件夹）；`B` 绑定某个链接（它将变为普通的块和名为 `Plan$0$Walls` 的图层）；`D` 分离某个链接（其引用和图层会被移除）。每项都是一个撤销步骤。

{{cmd:XCLIP}}（`XC`）用于裁剪块参照和链接：选择它们，输入 `N` 新建边界，然后输入 `R` 并指定两个角点，或输入 `P` 并指定多边形的各点，然后按{{key:Enter}}闭合；`D` 删除裁剪。仅边界内的内容会显示和打印，裁剪会随参照一起移动。DWG 和 DXF 2000 保留裁剪；DXF R12 会完整保存参照，并会给出说明。绑定带有已裁剪参照的链接时，{{cmd:XREF}} 的 `B` 会询问：`A` 绑定全部内容，`C` 仅保留每个参照的裁剪部分（直线和圆弧在边界处被切断；文字和嵌套块在其插入点位于边界内时保留）。

打开的图形可能链接了 CadCraft 无法访问的文件：它会显示有多少未加载。使用{{cmd:XREF}}、`R`，并选择每个文件即可查看。

保存时，已加载的链接会被**绑定**到文件中（其他程序会看到名为 `Plan$0$…` 的普通块和图层），历史记录会说明这一点。未加载的链接在 DWG 和 DXF 中仍保持为指向其文件的链接。

## 在三维中打开

{{ui:视图}} › {{ui:更多}} › {{ui:在ModelCraft中打开}}（{{cmd:OPENIN3D}}）会在新选项卡中以 DWG 形式在三维建模应用中打开图形，不会上传。在那里所做的更改会保留在那里；请在那里保存。该菜单项仅在该应用可接收移交的图形时显示。

## 打印 PDF

按{{key:Mod+P}}，单击{{ui:打印}}，或输入 `PLOT`。PDF 在浏览器内生成并下载，或在新选项卡中打开以便打印。参见[打印为 PDF](topic:plot-pdf)。

## 文件的存放位置

每次保存和每次打印都是下载，因此文件会存放在浏览器下载的位置：通常是“下载”文件夹。若要每次都选择文件夹，请在浏览器中更改下载设置；[浏览器与计算机](common:browsers)中说明了具体位置。

所打开或保存的任何内容都不会发送给我们。参见[文件的去向](common:your-files)。

## PLN 与 PLA 项目文件

CadCraft 打开的是 DWG 和 DXF 图形，而不是 Archicad 自身的文件（`.pln`、`.pla`、`.tpl`、`.bpn`）。打开这类文件时会告知其类型。在 Archicad 中，请将所需的视图或布局另存为 DWG 并在此打开，或将模型导出为 IFC 并在 BimCraft 中打开。当 BimCraft 可接管该文件时，CadCraft 会提供{{ui:在BimCraft中打开}}。

## 保存前页面关闭时

在停止编辑后不久，CadCraft 会仅在本浏览器中保留所更改的每个图形的副本。如果在保存前选项卡关闭、浏览器停止或计算机重启，CadCraft 下次启动时会询问**恢复未保存的内容？**：{{ui:恢复}}会在其自己的选项卡中重新打开该图形（未保存）。保存图形会删除其副本。参见[恢复未保存的内容](common:recover)。

## 在线与离线

打开、绘制、保存（DWG 和 DXF）以及打印都在计算机上进行，因此 CadCraft 加载完成后，即使没有网络连接也能正常工作。

要在完全没有网络连接的情况下使用 CadCraft，请在联网时单击顶部栏中的{{ui:保存以供离线使用}}。标签会计数（“保存中 40 / 212”），最终显示“离线就绪”。保存的副本包括 DWG 读取器，总计约 5 MB，因此一旦保存，**DWG 文件也能离线打开**。再次单击该按钮可选择{{ui:重新保存（获取最新版本）}}或{{ui:移除离线副本}}。“无法保存”表示部分文件未能下载：请检查连接并单击以重试。“离线不可用”表示此浏览器窗口无法保留副本（如隐私窗口和某些受管理的计算机）。

若没有已保存的副本，则在页面加载后首次打开 DWG 时才会获取 DWG 读取器，因此离线打开 DWG 可能失败；DXF 文件则从不需要它。除非 CadCraft 已保存，否则离线时请勿重新加载页面。

详情参见[离线工作](common:offline)。

:::offline
当前处于离线状态。图形可保存为 DWG 或 DXF，并可正常打印，DXF 文件可以打开。若 CadCraft 显示“离线就绪”，或本选项卡中已加载 DWG 读取器，则 DWG 文件可以打开。
:::

## 文件中的约束

约束和参数（参见[约束图形](topic:constraints)）会同时保存到 DWG 和 DXF 中。每个受约束的对象都带有一条小型 CadCraft 注释（扩展数据），名为 `CADCRAFT_PARAMETRIC` 的未使用块保存约束和参数表。其他程序会正常打开图形并忽略这两者；清理时它们可能会删除该未使用块。注释通过对象自身的键引用对象，而不是通过文件的句柄，因此对句柄重新编号的程序不会破坏它们。当其他程序删除或更改了某个受约束的对象时，CadCraft 会在打开文件时移除该对象上的约束，并说明数量。不含这些内容的文件打开时不带约束。

从零件建模程序导出的草图（`.json`）也可以打开：参见[在其他零件建模程序之间移动草图](topic:solidworks-sketches)。
