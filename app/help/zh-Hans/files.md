## 概览

| 格式 | 打开 | 保存 | 说明 |
|---|---|---|---|
| DXF（文本，任何版本） | 是 | 是，保存为 DXF R12 或 DXF 2000 | 二进制 DXF 会被拒绝：请先另存为文本 DXF。 |
| DWG | 是 | 是，保存为 DWG（AutoCAD 2000、2004、2007、2010、2013 或 2018） | 由 CadCraft 自己的 DWG 库读写（AutoCAD R13 至 2018 的文件）。你的 DWG 绝不会被修改。损坏的文件或读取器无法处理的版本会被拒绝并给出提示。 |
| PDF | 导入一页：作为底图或作为对象（[PDF 底图](topic:pdf-underlay)） | 是，通过打印 | 图纸的矢量PDF，或按某一比例的模型的矢量PDF。 |

你打开的每个图形（或用{{ui:新建}}开始的图形）在绘图区上方都有自己的选项卡；尚未被动过的新图形会被直接使用，而不是再添加一个选项卡。单击选项卡可切换，单击其{{ui:×}}可关闭（如有未保存的更改，CadCraft 会先询问），或将已打开的图形并排平铺：参见[分割屏幕](topic:split-screen)。

## 打开图形

- 按{{key:Mod+O}}，单击{{ui:打开}}，或输入 `OPEN`，然后选择文件。
- 或将 `.dwg` 或 `.dxf` 文件拖到绘图区上。

文件在你的浏览器内读取，不会上传到任何地方。历史记录会报告导入了多少个对象和图层以及用了多长时间，左侧面板的{{ui:图形}}部分显示格式，例如“DWG 2018 (AC1032)”。

DWG 读取器是 CadCraft 的一部分，在页面加载后你打开第一个DWG时获取（几百KB），因此无需另外等待下载。它在后台读取文件，所以打开大型DWG时页面仍能响应。

### 导入哪些内容

- 直线、圆弧、圆、多段线（含圆弧段）、椭圆、点、文字和多行文字、实体填充、填充（标准图案绘制为其线条，其他图案绘制为单一色调）、带属性的块参照（属性值可以编辑；参见[块属性](topic:attributes)）、标注，以及带视口的布局。
- 样条曲线作为样条曲线导入（阶数、控制点、节点、权重、拟合点）；参见[样条曲线和多段线](topic:splines)。
- 带一条引线和文字的多重引线作为可编辑的 CadCraft 多重引线导入（参见{{cmd:MLEADER}}）。其他的（带块、多条引线或曲线）按另一个程序绘制的样子显示，并作为一个整体移动；历史记录会说明有多少个。
- 图片（图像）显示为带图片文件名的边框，直到你用{{cmd:IMAGE}}把文件提供给 CadCraft：参见[图形中的图片](topic:pictures#show-the-pictures-a-dwg-uses)。擦除对象（wipeout）显示为其边框，其下方的内容仍然可见。
- DWG中的表格按另一个程序绘制的样子导入。
- 模型空间中的三维面导入到{{ui:3D}}选项卡，而不是作为二维对象；块内的三维面也是如此，模型中每个块参照一次。在块内和图纸上，它们也以轮廓线平面绘制。参见[三维建模](topic:3d-solids)。
- 图层保留其颜色、开、冻结、锁定和打印设置。DEFPOINTS 永不打印。
- 标注在其点可以读取的地方成为真正可编辑的 CadCraft 标注。它们起初完全按另一个程序绘制的样子显示；一旦你修改其中一个，CadCraft 就以自己的样式重新绘制。
- 每个布局成为一个图纸选项卡。在另一个程序中，每个布局都有一个隐藏的第一视口，即图纸本身；CadCraft 省略这一个。

### 尚未导入的内容

CadCraft 无法绘制的任何内容都会被计数，而不是猜测。左侧面板中的“关于此文件”框将其列为“尚未显示：”，后面是每种对象及其数量。典型的有DXF中的表格、网格以及块内的三维实体。模型空间中的三维实体、面域和体显示在3D选项卡上（参见[三维建模](topic:3d-solids#solids-from-other-programs)）。文件中扭转的视口会像原来那样显示为扭转，并在保存时保留其扭转；当前UCS、命名UCS和旋转的视图也是如此。

文字以一种Helvetica风格的字体绘制。在原程序较窄字体中能放进一行的标签，在 CadCraft 中可能会折成两行。

## 保存

有三种保存方式。每一种都会下载一份副本。

- **保存**：按{{key:Mod+S}}，单击{{ui:保存}}，或输入 `SAVE`（也可用 `QSAVE`）。它按图形的格式保存：打开的是DWG就保存为DWG，打开的是DXF就保存为DXF。DWG保留它导入时的版本（2018的文件保存为2018）。新图形使用你上次在此浏览器的“另存为”中选择的格式和DWG版本；如果从未选择过，则使用AutoCAD 2000格式的DWG。
- **另存为**：按{{key:Mod+Shift+S}}，单击{{ui:另存为}}，或输入 `SAVEAS`。{{ui:将副本另存为}}对话框提供{{ui:DWG}}（带{{ui:版本}}列表：AutoCAD 2018、2013、2010、2007、2004或2000）、{{ui:DXF R12}}和{{ui:DXF 2000}}，每一项都显示它将使用的文件名，并已选中图形当前的格式和版本。单击{{ui:保存}}下载，或单击{{ui:取消}}（或按{{key:Esc}}）不保存任何内容；此时历史记录显示“未保存。”你的选择会被记住：此后{{key:Mod+S}}对此图形使用它，此浏览器中的新图形也以它开始。
- **DXFOUT**：输入 `DXFOUT`。它总是下载DXF R12副本，下一次{{key:Mod+S}}仍按图形自己的格式保存。

浏览器会下载 `<图形名称>.dwg` 或 `<图形名称>.dxf`。每次保存都是一次**新的下载**；你打开的文件绝不会被覆盖或修改。历史记录会确认这一点，例如“已将副本保存为 Plan.dwg（DWG (AutoCAD 2018)）。原文件 Plan.dxf 未更改。”对于DXF，它显示“（DXF R12，可在任何CAD程序中打开）”。其下几行列出过程中发生更改的所有内容。

当 CadCraft 在桌面应用中运行时，保存的方式与其他桌面程序相同：{{key:Mod+S}}把图形按其自身的格式和版本写回你打开的文件，历史记录会说明保存到了哪里。{{ui:另存为}}和导出会显示系统的保存对话框，双击 `.dwg`、`.dxf` 或 `.ccsheets` 文件会在 CadCraft 中打开。

对于PDF，请改用打印（见下文）。

## DWG 保留和更改的内容

CadCraft 在你的浏览器内用与读取时相同的DWG库自己写出DWG。请在“另存为”中选择版本：AutoCAD 2000格式（文件版本 AC1015）可在最多的程序中打开，包括旧程序；较新的格式（2004，AC1018，直到2018，AC1032）还会保留真彩色。不会上传任何内容，保存DWG也可离线进行。

每个版本都通过用其他三个程序的DWG读取器以及 CadCraft 自己读回保存的文件来检查。CadCraft 的DWG尚未在AutoCAD本身中打开过。

### DWG 保留的内容

- 直线、圆弧、圆、椭圆、点，以及带圆弧段的多段线。
- 单行文字及其对齐方式和宽度因子。
- 多行文字和自动换行的文字，作为多行文字。另一个程序会按相同的宽度重新换行。
- 对象颜色：随层、随块、255种标准颜色，以及2004格式及更高版本中的真彩色。
- 图层及其颜色、线型、线宽以及开、冻结、锁定和打印设置；对象自己的线型、线宽和线型比例、线型图案以及图形的线型比例。
- 图形单位和长度格式（小数、英尺和英寸、分数……）。
- 带基点和属性定义的块，包括不可见、常量和预设的属性。
- 带比例、旋转和属性值的块参照。
- 实体填充，以及带图案、比例和角度的图案填充（图案自己的线条，因此其他程序绘制的线条与 CadCraft 相同）。
- 标注，作为真正的标注：被拉伸时其他程序会重新测量它们。每个标注保留自己的设置（文字高度、箭头大小、小数位数、长度格式）及其文字，并带有每个DWG标注都有的绘制副本。
- 图纸（布局）：每张图纸连同其纸张大小和单位、其上绘制的内容，以及带视图和比例的视口。
- 命名视图。
- 多重引线，作为多重引线。
- 图层和块的名称，保留你输入时的大小写。（DXF R12 将其写成大写。）

### DWG 更改的内容

这些更改在保存后，只要适用于你的图形，就会列在历史记录中。

| 在 CadCraft 中 | 在保存的DWG中 |
|---|---|
| 2000格式中的真彩色（用颜色选择器选取） | 最接近的标准颜色：2000格式只有255种颜色。另存为2004或更高版本可保留真彩色 |
| 图纸的命名视图 | 图纸空间视图：DWG不记录属于哪张图纸，因此 CadCraft 再次打开该文件时它们属于第一张图纸 |
| 带宽度因子的多行文字 | 正常字宽：在DWG中，宽度因子只适用于单行文字 |
| 含DWG不允许的字符的图层或块名称 | 被更改：来自链接图形的名称如 `Base\|Walls` 变为 `Base$0$Walls`（绑定链接图形时的命名方式），其他字符变为 `_` |

### 为什么用 R12，以及哪些内容会被转换

当你另存为DXF时，CadCraft 写出DXF R12，这是每个CAD程序都能打开的版本。它比某些功能更旧，因此有少数内容以更简单的形式写出：

| 在 CadCraft 中 | 在保存的 R12 文件中 |
|---|---|
| 多行文字 | 每行一个文字对象 |
| 椭圆 | 沿椭圆走向的多段线 |
| 填充（来自已打开的文件） | 仅其轮廓 |
| 真彩色（用颜色选择器选取） | 最接近的标准颜色 |
| 线宽，以及对象自己的线型比例 | 省略：R12 两者都没有（线型会保留） |
| 图层和块的名称 | 写成大写；空格和其他字符变为 `_`，名称截断为31个字符（“Title block”变为 `TITLE_BLOCK`） |
| 设置为不打印的图层 | 其他程序会打印它们（图形有图纸时，CadCraft 会记住该设置） |
| 标注 | 带有自己绘制块的真正标注，因此其他程序显示的样子与你看到的一致 |
| 多重引线 | 它们所绘制的线条、箭头和文字 |
| 命名视图 | 保留，名称为大写；图纸的视图回到第一张图纸上 |
| 多张图纸 | 第一张图纸是每个程序都会显示的图纸空间；其余的作为名为 `CCLAYOUT_1`、`CCLAYOUT_2` ……的块保留，CadCraft 打开文件时会把它们变回图纸 |

历史记录会列出适用于你的图形的每一项。

:::tip
要在几天内持续处理一个图形，请另存为DXF，下次打开该DXF。CadCraft 能绘制的所有内容都能在往返中保留，包括标注、块和所有图纸。
:::

## 链接图形（外部参照）

{{cmd:XATTACH}}（`XA`，或{{ui:块}} › {{ui:更多}} › {{ui:链接图形（外部参照）}}）链接另一个DWG或DXF：选取文件，然后单击放置的位置（按{{key:Enter}}放在 0,0）。它作为一个以文件命名的块导入，当两个图形的单位不同时按正确的比例。它的图层和块保留各自的名称，前面加上链接的名称——`Plan|Walls`、`Plan|Door`——因此永远不会与你自己的混在一起：像对待自己的图层一样，可以打开和关闭、冻结或锁定链接的图层。链接是只读的：修改另一个图形后重新加载即可。你对链接图层所做的设置（颜色、线型、线宽、开/关、冻结、锁定、打印）会在你重新加载时、在链接仍为链接状态下将图形保存为DWG时，以及另一个图形链接此图形时保留。

{{cmd:XREF}}（`XR`）：`?` 列出链接（是否已加载、哪个文件、多少个参照）；`A` 附着；`R` 从其文件重新加载一个（再次选取该文件：浏览器自己无法访问你的文件夹）；`B` 绑定一个（它成为名为 `Plan$0$Walls` 的普通块和图层）；`D` 拆离一个（其参照和图层随之消失）。每一项都是一次撤销步骤。

{{cmd:XCLIP}}（`XC`）剪裁块参照和链接：选择它们，`N` 新建边界，然后 `R` 加两个角点或 `P` 加多边形的各点（按{{key:Enter}}闭合）；`D` 删除剪裁。只有内部的内容会显示和打印，剪裁随参照一起移动。DWG和DXF 2000会保留剪裁；DXF R12 会完整保存参照并给出说明。绑定带有剪裁参照的链接时，{{cmd:XREF}} `B` 会询问：`A` 绑定全部，`C` 只保留每个参照被剪裁的部分（直线和圆弧在边界处被切断；文字和嵌套块在其插入点位于内部时保留）。

你打开的图形可能链接了 CadCraft 看不到的文件：它会说明有多少个未加载。使用{{cmd:XREF}}、`R` 并选取每个文件即可看到它们。

保存时，已加载的链接会被**绑定**到文件中（其他程序看到的是名为 `Plan$0$…` 的普通块和图层），历史记录会说明这一点。未加载的链接在DWG和DXF中仍是指向其文件的链接。

## 在三维中打开

{{ui:视图}} › {{ui:更多}} › {{ui:在ModelCraft中打开}}（{{cmd:OPENIN3D}}）在新标签页中以DWG形式在三维建模应用中打开该图形，无需上传。在那里所做的更改留在那里；请在那里保存。只有在该应用能接收移交的图形时才会显示此菜单项。

## 打印 PDF

按{{key:Mod+P}}，单击{{ui:打印}}，或输入 `PLOT`。PDF 在浏览器内生成并下载，或在新标签页中打开以便打印。参见[打印为 PDF](topic:plot-pdf)。

## 文件去向

每次保存和每次打印都是一次下载，因此文件会出现在浏览器存放下载的位置：通常是“下载”文件夹。要每次选择文件夹，请更改浏览器中的下载设置；[浏览器和电脑](common:browsers)说明了在哪里设置。

你打开或保存的任何内容都不会发送给我们。参见[文件去向](common:your-files)。

## PLN 和 PLA 项目文件

CadCraft 打开DWG和DXF图形，不打开Archicad自己的文件（`.pln`、`.pla`、`.tpl`、`.bpn`）。打开其中一个会告诉你它是什么。请在Archicad中把所需的视图或布局保存为DWG并在这里打开，或将模型导出为IFC并在BimCraft中打开。在BimCraft可以接手文件的地方，CadCraft 提供{{ui:在BimCraft中打开}}。

## 如果页面在保存前关闭

CadCraft 会在你停止编辑片刻之后，仅在此浏览器中为你更改过的每个图形保留一份副本。如果标签页关闭、浏览器停止或电脑在你保存之前重启，CadCraft 下次启动时会询问**要恢复你的工作吗？**：{{ui:恢复}}会在它自己的选项卡中再次打开该图形（未保存状态）。保存图形会删除其副本。参见[恢复你的工作](common:recover)。

## 在线和离线

打开、绘图、保存（DWG和DXF）和打印都在你的电脑上进行，因此 CadCraft 加载完成后无需网络连接即可工作。

要完全无需网络连接地使用 CadCraft，请在联网时单击顶部栏中的{{ui:保存以供离线使用}}。标签会计数（“正在保存40/212”），并在“离线可用”结束。保存的副本包含DWG读取器，总共约5 MB，因此保存后**DWG文件也能离线打开**。再次单击该按钮可选择{{ui:重新保存（获取最新版本）}}或{{ui:移除离线副本}}。“无法保存”表示有些文件没有下载：请检查网络连接并单击重试。“无法离线使用”表示此浏览器窗口无法保留副本（无痕窗口和某些受管理的电脑）。

没有保存的副本时，DWG读取器在页面加载后你第一次打开DWG时获取，因此离线打开DWG可能失败；DXF文件则从不需要它。除非 CadCraft 已保存，否则离线时请勿重新加载页面。

详情参见[离线工作](common:offline)。

:::offline
你现在处于离线状态。图形可正常保存为DWG或DXF并打印，DXF文件可以打开。如果 CadCraft 显示“离线可用”，或DWG读取器已在此标签页中加载，则DWG文件可以打开。
:::

## 文件中的约束

约束和参数（参见[约束图形](topic:constraints)）在DWG和DXF中都会保存。每个受约束的对象带有一条小小的 CadCraft 备注（扩展数据），一个名为 `CADCRAFT_PARAMETRIC` 的未使用块保存约束和参数表。其他程序会正常打开图形并忽略这两者；它们在清理时可能会删除这个未使用的块。备注通过对象自己的键而不是文件的句柄来引用对象，因此重新编号句柄的程序不会破坏它们。当另一个程序删除或更改了受约束的对象时，CadCraft 打开文件时会丢弃其上的约束并说明有多少个。不含约束的文件打开时没有约束。

从零件建模器导出的草图（`.json`）也可以打开：参见[在草图与其他零件建模器之间互相转移](topic:solidworks-sketches)。
