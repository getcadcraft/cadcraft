## 你将学到什么

如何在工具栏上添加你自己的按钮，每个按钮运行一个按照 AutoCAD 方式编写的宏；如何为按钮设置快捷键；以及如何导入 CUIx 文件中的按钮。

## 添加按钮

1. 打开{{ui:设置}}（{{key:Mod+,}}），并停留在{{ui:CadCraft}}选项卡。滚动到{{ui:我的工具}}。
2. 单击{{ui:添加按钮…}}。
3. 填写对话框：
   - {{ui:分组}}：该按钮所在的工具栏分组，例如`My tools`。输入新名称会创建新分组。
   - {{ui:标签}}：按钮上显示的文字。
   - {{ui:宏}}：它要输入的内容，例如`^C^C_rectang;0,0;@100,50;`。
   - {{ui:快捷键}}：单击输入框并按下按键，例如{{key:Ctrl+Alt+B}}。
   - {{ui:图标}}：一张不超过 64 KB 的 PNG 或 SVG 图片，或不设置（将显示星形图标）。
4. 单击{{ui:保存}}。

按钮会出现在工具栏末尾的所在分组中。单击它，或按其快捷键，即可运行。列表中的{{ui:编辑}}和{{ui:删除}}可更改或移除它。

## 编写宏

宏就是你在命令行中输入的内容，并带有几个特殊符号：

| 符号 | 含义 |
|---|---|
| `^C` | 取消正在运行的任何操作（`^C^C`是常用的开头） |
| `;` 或空格 | {{key:Enter}} |
| `\` | 等待你操作：单击或输入答案，然后宏继续执行 |
| 命令前的 `_` 或 `.` | 被接受并忽略（用于国际名称和内置名称） |
| 开头处的 `*` | 每次结束后重新运行，直到你按{{key:Esc}} |
| `^O`、`^G` | 切换正交或栅格的开/关 |
| `$M=` | 其后内容为 DIESEL。仅读取 `$(if,…)`、`$(getvar,…)`、`$(=,…)` 和 `$(eq,…)`；使用其他任何内容的按钮会提示此情况且不执行任何操作 |

示例：

- `^C^C_line;0,0;@100,0;;` 从原点绘制一条长 100 的直线。
- `^C^C_circle;\25;` 会询问圆心，然后在该处绘制半径为 25 的圆。
- `^C^C_turnright` 将视图向右旋转 90°。

## 快捷键

快捷键需要使用{{key:Mod}}（Ctrl，Mac 上为 Cmd）或{{key:Alt}}加字母或数字，或使用未被占用的功能键之一：{{key:F2}}、{{key:F4}}、{{key:F5}}、{{key:F6}}、{{key:F9}}。单独的字母会交给命令行处理。CadCraft、应用程序或浏览器已使用的按键（例如{{key:Ctrl+S}}或{{key:Ctrl+Z}}），以及已被其他按钮占用的按键都会被拒绝，并且输入框会说明原因。

## 共享你的按钮

- {{ui:导出…}}会将每个分组和按钮（包括图标和快捷键）保存为`my-tools.json`。
- {{ui:导入…}}会将此类文件中的分组添加到你现有分组之后。若分组名称已存在，则会添加“(2)”；会与现有按键冲突的快捷键将被去掉，面板会对此予以说明。

## 从 CUIx 文件导入按钮

1. 单击{{ui:导入CUIx…}}，并选择`.cuix`文件。

其工具栏和功能区面板将成为分组，每个按钮都带有其宏和图片（PNG，或转换为 PNG 的 BMP）。其快捷键会单独放入一个分组，每个按钮都带有其按键；其可能包含的命令别名则放入一个{{ui:别名}}分组。面板会列出导入的内容。

:::note
该文件仅被读取。CadCraft 不具备的命令会按名称列出，而不会被猜测：其按钮在被单击时会说明此情况。除上述少数函数之外的 DIESEL、菜单、鼠标按键和工作空间均不会被读取。
:::

## 注意事项

- 按钮保存在此浏览器（或此桌面应用）中，而不是保存在图形中。
- 按钮通过命令行运行，因此与你输入的任何内容一样可以撤销：每个运行的命令需要一次{{key:Mod+Z}}。
