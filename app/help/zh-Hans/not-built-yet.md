CadCraft 仍在开发中。本页列出当前版本尚未实现的功能，以便你不必四处查找。每一项都说明了当前可以如何替代操作。

## 文件与保存

| 尚未实现 | 目前替代方法 |
|---|---|
| 在 AutoCAD 本身中检查 CadCraft 生成的 DWG | 每个保存的版本都会被其他三个程序的 DWG 读取器以及 CadCraft 读回进行验证。参见 [DWG 保留与变更的内容](topic:files#what-a-dwg-keeps-and-changes)。 |
| 保存比 2000 更新的 DXF | 保存为 DXF 2000，或保存为最高至 AutoCAD 2018 的 DWG。 |
| 在浏览器中覆盖已打开的文件 | 每次保存都会下载一个新副本；若需要，请自行替换旧文件。在 CadCraft Studio 中，{{key:Mod+S}}会写回你打开的文件。 |
| 云端保存以及计算机之间的同步 | CadCraft 尚不会将保存内容发送到云端：请将 DWG 和 DXF 文件保存在你自己的文件夹中。在 CadCraft Studio 中，[历史记录](topic:history)会列出从其他位置保存的图形的云端版本，以及此计算机上你自己保存的副本。 |
| 覆盖式外部参照，以及原位编辑链接图形 | 将图形以链接方式附加，并在更改另一图形后重新加载。另存为 DWG 时链接仍保持为链接，{{cmd:XCLIP}}可对其进行裁剪。 |
| DXF 中的图片；会遮挡其下方内容的遮罩 | DXF 会将图片保留为带有文件名的边框；DWG 则将其保留为图片 — 参见 [图形中的图片](topic:pictures)。遮罩显示为其边框。 |
| 编辑带弯曲引线、引线位于内容两侧，或块被不均匀旋转或缩放的多重引线 | 它们按其他程序绘制的方式绘制，并作为一个整体移动。指向同一条基线的直引线、且内容为文字或块的多重引线可以编辑（{{cmd:MLEADEREDIT}}）。 |
| 来自其他程序的表格：单元格中包含块、单元格内的文字格式、DXF 表格的每单元格边框和颜色、表格被拆分为多列 | 表格以可编辑表格（{{cmd:TABLEDIT}}）形式打开，并按其他程序绘制的方式显示，直到你编辑它为止；此后 CadCraft 会根据其单元格重新绘制：纯文本、诸如`=G3*H3`和`=Sum(I3:I9)`之类的公式、对齐方式和文字高度。块单元格此后会变为空白。未经编辑的 DWG 表格会连同其原有的单元格数据一并保存回去。 |
| 保存的 DXF 中的真正表格对象 | DWG 会将表格保存为其他程序可以编辑的表格。DXF 则将其保存为绘制它的块，并附带 CadCraft 自己的记录：CadCraft 会将其重新作为表格打开；其他程序则只会看到一个块。镜像或不均匀缩放的表格在 DWG 中也会以这种方式保存。 |
| 与其他程序之间的复制和粘贴 | CadCraft 的剪贴板仅在同一浏览器中的 CadCraft 图形和选项卡之间有效，不能与其他程序配合使用。请将其保存为 DWG 或 DXF 并在那里打开。参见 [复制、粘贴和创建副本](topic:copy-paste)。 |

## 绘图与编辑

| 尚未实现 | 目前替代方法 |
|---|---|
| CadCraft 没有的填充图案，以及与其他程序完全一致的渐变填充 | 打开的、带有 CadCraft 所没有图案的填充会显示为一种色调。渐变填充（{{cmd:GRADIENT}}）会按 CadCraft 自己的方式为每种类型绘制：在类型上与其他程序相似，但并非逐点一致。DWG 2004 及更高版本会将其保留为真正的渐变填充；在 DXF 2000 或 DWG 2000 文件中，只有 CadCraft 能读回它，其他程序只会看到实心填充。图案可从`.pat`文件加载，填充可与其边界链接并随之变化：参见 [填充与填充区域](topic:hatch)。 |
| 包含形或文字的线型，以及保存的 DXF R12 中的线宽 | 文件线型中的形和文字将从其虚线中省略；若要保留线宽，请保存为 DWG。 |
| 保存的 DXF 中带图案的填充 | R12 没有填充功能：它们会以其轮廓形式保存。若要保留图案，请保存为 DWG。 |
| 其他程序制作或可编辑的阵列；路径阵列和极轴阵列中的行与层；跟随其路径曲线的阵列 | 使用关联方式（{{cmd:ARRAY}}、{{cmd:ARRAYPATH}}；通过{{cmd:ARRAYEDIT}}修改）制作的阵列将保存为块参照，并使用 CadCraft 自己的数值：其他程序可以显示、移动、打印和分解它，但无法更改其数量；而在其他程序中制作的阵列在此处会作为普通块参照打开。路径阵列会保留其路径的副本：之后编辑曲线不会移动项目。 |
| 与其他程序之间裁剪的布局视口 | 使用{{cmd:VPCLIP}}裁剪或用{{cmd:MVIEW}}的多边形或对象方式制作的视口，将以 CadCraft 自己的轮廓保存：其他程序会将其打开为其周围的矩形；在其他程序中裁剪的视口在此处会作为其矩形打开。DXF R12 仅保留矩形。 |
| {{cmd:STRETCH}}与窗交多边形 | 请使用一个或多个窗交框。 |
| {{cmd:PEDIT}}编辑顶点（命令行中一次一个顶点） | 夹点，以及特性面板中的顶点浏览器（每个顶点、其宽度和凸度）。PEDIT 的其余功能已实现：参见 [样条曲线和多段线](topic:splines)。 |
| 椭圆和样条曲线上的{{cmd:BREAK}}、{{cmd:LENGTHEN}}、{{cmd:OFFSET}}、{{cmd:TRIM}}、{{cmd:EXTEND}}、{{cmd:FILLET}}和{{cmd:JOIN}} | 对样条曲线使用{{cmd:EXPLODE}}（或对其使用{{cmd:PEDIT}}），以获得这些命令可以处理的多段线。 |
| 多段线的圆弧段与其相邻线段之间的圆角和倒角；将直线连接成多段线的圆角 | 对多段线使用{{cmd:EXPLODE}}，然后对各部件进行圆角。圆角圆弧将作为其自身的对象添加。 |
| 修剪和延伸：投影选项（3D），以及延伸多段线的圆弧端点 | 在图形平面内修剪；对于圆弧端点，请分解多段线或重新绘制圆弧。 |
| OLE 对象：插入、运行或编辑；显示 DWG 中文件放置它们的位置的对象；图元文件图片 | 参见 [图片](topic:pictures#objects-from-other-programs-ole)。DXF 中的对象显示为其位图或带标签的边框；DWG 中的对象会被保留，但不会在原位绘制（OLELIST 会列出它们，并在你指定的位置放置图片副本）。 |
| 在段落文字中输入格式代码（粗体、堆叠分数、逐词颜色）；除一种 Helvetica 风格字体以外的其他字体；分栏 | 文件中带来的格式会被保留、绘制和保存（参见文字）；新段落文字为单一高度和颜色。 |
| 在旋转状态下编辑段落文字 | 编辑器以水平方式打开；文字保持其旋转。 |
| 在 DXF 中保存为多重引线对象的多重引线 | DWG 会将其保留为多重引线，并包含每条引线和作为内容的块；DXF 则保留它们绘制的内容（直线、箭头以及文字或块）。 |
| 表格（{{cmd:TABLE}}）中：单元格内自动换行的文字、拆分为多个部分的表格、表格样式自身的文字样式以及对话框中按行类型设置的颜色、与电子表格文件（`.xlsx`）的数据链接，或自行读取文件的数据链接 | 单元格中的文字仅在你手动换行处换行（{{key:Alt+Enter}}）；请加宽列。{{cmd:DATALINK}}读取`.csv`文件，{{cmd:DATALINKUPDATE}}会要求你重新选择文件。{{cmd:DATAEXTRACTION}}和{{cmd:COUNTTABLE}}制作的表格不会自动跟随图形：请重新运行它们（实时计数：{{cmd:BOMTABLE}}）。 |
| 保存文件中单独保留的属性定义（不在块内），多行属性 | 保存前请将属性定义放入块中：单独存在时，它们会保存为显示标记的文字。 |
| 图层状态（保存和恢复哪些图层处于开启状态） | 使用{{cmd:LAYISO}} / {{cmd:LAYUNISO}}，或手动开关图层。 |
| 窗口多边形和窗交多边形选择，以及保存的选择过滤器 | 栏选（`F`）、窗口、窗交、移除（`R`）、用于规则的{{cmd:QSELECT}}。 |

| 尚未实现 | 目前替代方法 |

| DWG 2000 和 DXF 文件中的透明度 | 其他程序会将这些对象显示为实体；CadCraft 会保留透明度。若要让所有人都能看到，请保存为 DWG 2004 或更高版本。 |
| 在其他程序中制作的填充链接 | CadCraft 会在 DWG 和 DXF 2000 文件中保存其自己的链接；其他程序制作的链接不会被读取。请使用`HATCHEDIT`和链接：参见 [填充与填充区域](topic:hatch)。 |
| 特性中在 UCS 中的坐标 | 特性显示世界坐标；状态栏和{{cmd:ID}}显示 UCS 坐标。参见 [旋转视图并使用自定义坐标](topic:ucs-and-turned-view)。 |
| 注释性对象在每个比例下各自的独立位置；读取其他程序保存的各比例记录 | 注释性文字或标注会保留一个比例列表（{{cmd:OBJECTSCALE}}），每个视口会以其比例对应的大小在相同位置显示它。该列表以 CadCraft 自己的数据保存：其他程序只会看到对象处于其所设定的那一个比例，而在其他程序中制作的列表不会被读取。参见 [单位、图纸和比例](topic:units-papers-scales#annotate-by-scale)。 |
| 更改动态块的距离、角度或翻转；保存为其他 DWG 版本或 DXF 时保持动态块的动态性 | 在{{ui:特性}} › {{ui:自定义}}中切换其可见性状态；其他值在那里以只读方式显示。若以图形打开时的版本保存为 DWG，它仍保持动态。参见 [动态块](topic:dynamic-blocks)。 |
| 样条曲线拟合公差、6 次及以上的样条曲线、三维样条曲线 | 拟合点和控制点、1 到 5 次以及权重已实现：参见 [样条曲线和多段线](topic:splines)。样条曲线的高度（Z）不会被保留。 |

|---|---|

| 保存当前的标注样式；将标注文字拖到自由位置 | 图形打开时以 Standard 为当前样式。文字位于尺寸线上（DIMTEDIT Left / Right / Center）。参见 [设置标注尺寸](topic:dimension-settings)。 |
| CadCraft 无法推算的已打开文件中，可编辑的双线角度标注 | 它们按文件中的绘制方式显示。坐标标注、弧长标注和折弯半径标注会作为可编辑的标注打开。 |
