## 所有尺寸的统一表格

{{ui:参数}}面板（{{ui:参数化}}组中的{{ui:参数}}按钮，或输入{{cmd:PARAMETERS}}）会将每个尺寸约束（`d1`、`rad1`、`dia1`、`ang1`，或你为其指定的名称）与你自己的参数一起列出。任何名称都可用于任何表达式中。

每一行包含：

- **名称**：输入新名称即可重命名；所有使用它的表达式都会随之更新。
- **表达式**：一个数字（`40`）或一个表达式（`width / 2 + gap`）。在其中输入并按{{key:Enter}}：图形将随之更新。
- **值**：表达式的计算结果。在表达式驱动的行上，你也可以在此处输入数字：CadCraft 会计算出其背后的参数。使用`d1 = width / 2`时，在 d1 的值中输入`30`，会将`width`设为 60。

当两个参数驱动一个值（`width / 2 + gap`）时，对话框会询问要更改哪一个。每次更改都是一步撤销（{{key:Mod+Z}}）。

## 添加你自己的参数

1. 打开{{ui:参数}}面板。
2. 输入名称（`gap`）和值（`10`），然后选择{{ui:添加}}。
3. 使用它：在 d1 的表达式中输入`width / 2 + gap`并按{{key:Enter}}。

名称以字母或`_`开头，由字母、数字和`_`组成。函数名、`pi` 以及单位名称不能用作名称。

## 表达式

| 写法 | 含义 |
|---|---|
| `+ - * / ^ %` | 加、减、乘、除、乘方、取余 |
| `( )` | 分组 |
| `sin cos tan asin acos atan atan2` | 以度为单位的三角函数 |
| `sqrt pow exp ln log abs sign` | 开方、乘幂、对数 |
| `ceil floor int round min max` | 取整与极值 |
| `if(a > b, x, y)` | 选择 |
| `pi` | 3.14159… |

数字可带单位：`25mm`、`1in`、`2'`、`90deg`。带单位的长度会被换算为毫米，因此仅在以毫米计量的图形中使用单位；其他情况下请输入纯数字。

## 在命令行中

`-PARAMETERS`的功能与面板相同，但无需面板：`N` 新建、`E` 编辑（同样适用于尺寸约束）、`R` 重命名、`D` 删除、`?` 列出。

## 被拒绝的情况

- 直接或间接地使用自身的表达式：“width、d1 相互引用。”
- 尺寸无法接受的值：负长度，或超过 180° 的角度。
- 图形无法接受其其他约束所允许的值：无任何改变，消息会指出妨碍的约束。
- 删除正在被使用的参数：面板会提议先将其值写入所有使用处。尺寸约束的名称通过删除该约束本身来删除。
