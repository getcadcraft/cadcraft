## 将要创建的内容

将一个门符号创建为名为 `DOOR-900` 的块，然后放置三次：按原样、旋转 90 度，以及镜像。

块是一组已命名的对象。只需绘制一次；每个使用处都是指向同一个定义的**块参照**。左侧面板中的{{ui:块}}部分列出图形中的块，以及每个块的使用次数。

## 绘制门

1. 输入 `L`，然后按{{key:Enter}}。
2. 输入 `0,0`，然后按{{key:Enter}}。
3. 输入 `@0,900`，按{{key:Enter}}，然后再按一次{{key:Enter}}。这是门扇。
4. 输入 `A`，然后按{{key:Enter}}。
5. 输入 `C`，然后按{{key:Enter}}，先指定圆心。
6. 输入 `0,0`，然后按{{key:Enter}}，作为圆心。
7. 输入 `900,0`，然后按{{key:Enter}}，作为起点。
8. 输入 `0,900`，然后按{{key:Enter}}，作为终点。这是开启轨迹。
9. 单击{{ui:范围}}。

圆弧从起点到终点按逆时针方向绘制。

## 创建块

1. 输入 `B`，然后按{{key:Enter}}，或单击“块”组中的{{ui:创建}}。
2. 在 `输入块名称` 提示处输入 `DOOR-900`，然后按{{key:Enter}}。
3. 在 `指定插入基点` 提示处输入 `0,0`，然后按{{key:Enter}}。这是铰链：放置块时落在此处的点。
4. 在 `选择对象` 提示处，拖出窗口框住门扇和圆弧。
5. 按{{key:Enter}}。

历史记录显示 `块 "DOOR-900" 由 2 个对象创建，它们已被替换为对该块的一个引用。`{{ui:块}}面板中 DOOR-900 旁显示 `1×`，表示一个引用。单击门：它现在作为一个对象被选中，即“块参照”。

:::tip
也可以先选择对象，然后输入 `B`。CadCraft仍会询问名称和基点，之后使用当前选择的对象。
:::

## 插入块

1. 输入 `I`，然后按{{key:Enter}}，或单击{{ui:块}}面板中 DOOR-900 旁的{{ui:插入}}。
2. 在 `输入块名称或 [文件/库] <DOOR-900>` 提示处按{{key:Enter}}。（面板中的{{ui:插入}}按钮会自动填入名称。）
3. 门随十字光标移动。单击铰链应放置的位置。

随即出现第二扇门。

## 旋转或缩放后插入

1. 输入 `I`，然后按{{key:Enter}}，再按一次{{key:Enter}}确认名称。
2. 在 `指定插入点 [缩放/旋转]` 提示处，输入 `R`，然后按{{key:Enter}}。
3. 输入 `90`，然后按{{key:Enter}}。预览随之旋转。
4. 单击放置。

改为输入 `S` 可设置比例因子；它同时作用于两个方向。缩放和旋转会记住，用于下一次插入。要镜像门，先插入它，然后对该引用使用{{cmd:MIRROR}}。

## 修改已放置的块

选择块参照。在右侧面板中，可以更改其{{ui:X}}、{{ui:Y}}、{{ui:X缩放}}、{{ui:Y缩放}}和{{ui:旋转}}。{{ui:X缩放}}为负值时会翻转块。

## 重定义块

要一次更改所有门，请使用相同名称创建块：

1. 绘制门的新版本。
2. 输入 `B`，然后按{{key:Enter}}，并输入 `DOOR-900`。
3. 在 `块 "DOOR-900" 已存在。是否重定义？` 提示处，输入 `Y`，然后按{{key:Enter}}。
4. 与之前一样指定基点并选择新对象。

DOOR-900 的每个引用现在都显示新版本。

或直接编辑块本身：{{ui:块}} › {{ui:更多}} › {{ui:编辑块}}（{{cmd:BEDIT}}）会单独打开它，{{ui:保存块}}会保存并返回。参见[块属性](topic:attributes#change-a-block-the-block-editor)。

## 统计块并导出明细表

输入{{cmd:COUNT}}（或{{ui:块}} › {{ui:更多}} › {{ui:统计块}}），然后：

- 单击一扇门：选中此空间中的所有门，历史记录会显示此处及整个图形中的数量；
- 或按{{key:Enter}}：历史记录按数量从多到少列出每个块及其数量；
- 或输入 `E`，然后输入 `C` 导出数量的 CSV（模型中、布局中、总计），或输入 `A` 导出每个引用一行的 CSV，包含其图层、位置、旋转和所有属性值——即可在电子表格中打开的明细表。

未命名块（标注、表格）以及其他块内部的引用不计入。以公式形式开头的单元格（`=`、`+`、`-`、`@`）会加上前导 `'`，使电子表格将其显示为文本。

## 分解与清理

- {{cmd:EXPLODE}}（`X`）将选中的块参照转换回独立对象。定义保持不变。
- {{cmd:PURGE}}（`PU`）删除不再被使用的块定义。历史记录会显示删除了多少个。

## 块名称

名称最多可包含 255 个字符，可以包含空格，但不能以星号开头，也不能包含 `<` `>` `/` `\` `"` `:` `;` `?` `*` `|` `=` 或反引号。保存为 DXF R12 时，名称以大写形式写入，除字母、数字、`$`、`_` 和 `-` 以外的字符变为 `_`，名称截断为 31 个字符；历史记录会显示有多少名称被更改。像 `DOOR-900` 这样由大写字母、数字和连字符组成的短名称保持不变。保存的 DWG 按输入时的原样保留名称（含大小写）；只有 DWG 不允许的字符会更改（`|` 变为 `$0$`，其他变为 `_`）。

## 将块或对象写入独立文件

输入 `W`（{{cmd:WBLOCK}}），然后选择**对象**、**块**或**整个图形**。结果是一个新的 DWG 或 DXF 文件，仅包含其使用的图层、样式和块，并以指定的基点为原点。对于对象，可以保留、将其转换为块，或将其从此图形中删除。

## 常见错误

- **块落在远离十字光标的位置。** 基点不在对象上。请重新创建块，并将基点设在角点或铰链处。
- **"未选择对象；未创建任何内容。"** 在选择任何对象之前就按了{{key:Enter}}。
- **"此图形尚无块：F 从文件插入，L 从库插入（或用 BLOCK 创建一个）。"** 输入 `F` 可从其他图形导入块，或输入 `L` 从库中获取。参见[从文件或库插入](topic:insert-from-file-and-library)。
- **"视口不能放入块中。"** 选择时不要包含视口边框。
