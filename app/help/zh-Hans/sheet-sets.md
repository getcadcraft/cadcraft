## 学习内容

如何将多个图形文件中的图纸（布局）收集到一个**图纸集**中，为它们编号并命名，自动填写其标题栏，将整个图纸集发布为一个PDF，并将所有内容打包为一个zip以便发送。

图纸集存放在它自己的一个小文件中，即`<name>.ccsheets`，位于存放图形的文件夹中。该图纸集文件使用相对于此文件夹的路径列出各张图纸，因此你可以移动或复制整个文件夹。

:::note
要打开文件夹进行读写，需要Chrome或Edge（它们可以允许页面在你选择的文件夹中工作），或使用桌面应用程序。其他浏览器只能以只读方式打开图纸集：你可以查看并发布它，而图纸集文件会以下载的方式获取，而不会直接保存。
:::

## 创建图纸集

1. 在左侧面板中找到{{ui:图纸集}}部分，并打开其{{ui:图纸集}}菜单。输入{{cmd:SHEETSET}}（或`SSM`）也可直接到达此处。
2. 选择{{ui:新建图纸集…}}。为图纸集命名，如有需要，也可填写项目名称和编号。
3. 选择存放图形的文件夹。图纸集文件会保存在此处。

稍后要打开图纸集，请选择{{ui:打开图纸集…}}并选择同一文件夹。如果该文件夹包含多个图纸集，CadCraft会询问选择哪一个。

## 添加图纸

1. 选择{{ui:从图形添加图纸…}}，并选择文件夹中的一个图形。
2. CadCraft会在后台读取该图形（不会在屏幕上打开），并列出其图纸。勾选你需要的图纸，然后单击{{ui:确定}}。
3. 选择一张图纸，并按{{key:F2}}（或{{ui:重命名并重新编号…}}），为其指定编号和标题，例如`A-101`和`平面图`。

{{ui:从模板新建图纸…}}会根据另一个图形中的某张图纸（其标题栏和视口）创建一个新图形，以新图纸命名，并将其添加。图纸集会记住你用作模板的图形。

## 整理图纸集

- **子集**用于分组图纸，例如建筑 › 平面：选择要放置的位置，然后选择{{ui:新建子集…}}。
- **顺序**：将图纸拖到列表中的其他位置，或拖到某个子集上以将其移入。使用键盘时，选中图纸后按{{key:Alt+Up}}或{{key:Alt+Down}}。
- **打开图纸**：双击它（或按{{key:Enter}}）。其图形会在自己的选项卡中打开，并定位到该图纸。
- **移除**：选中它并按{{key:Delete}}。图形本身不会改变。
- **撤销**：{{ui:撤销图纸集更改}}和{{ui:重做图纸集更改}}可逐步回退或重做你对图纸集所做的更改。
- **重新编号**：{{ui:重新编号图纸…}}按列表顺序为每张图纸（或某个子集中的图纸）编号：一个前缀、起始值和步长（`A-`、`101`即可得到A-101、A-102……）。

每次更改都会立即保存到图纸集文件中。

## 根据字段为图纸编号

与其手动为图纸编号，不如让规则根据图纸的字段生成编号，这样移到另一楼层或专业的图纸会自动获得新的编号。

1. 为每张图纸设置字段：选中它，单击{{ui:重命名…}}，并在{{ui:此图纸的字段}}中每行写一个字段，例如`DISCIPLINE = A`和`LEVEL = 1`。整个图纸集共用的字段（如`DISCIPLINE = A`）可以放入图纸集的{{ui:特性…}}中。
2. 打开面板的菜单，单击{{ui:编号规则…}}。
3. 编写规则，例如`{DISCIPLINE}-{LEVEL}{SEQ:2}`。`{SEQ}`会在其他字段值相同的图纸之间递增，因此楼层1获得A-101、A-102，楼层2则从A-201重新开始。`{SEQ:2}`以两位数字书写；`{SUBSET}`为图纸所在子集的名称。
4. 选择字段变化时的处理方式：{{ui:为图纸重新编号}}会在每次更改后让编号始终遵循规则；另一种选择则只编号一次，即现在。

规则会保存在图纸集文件中。当它自动重新编号时，请修改图纸的字段，而不要修改其编号。

## 根据图纸集字段填写标题栏

当标题栏的属性使用字段名称标记时，它会从图纸集中获取文字：

| 标记 | 显示内容 |
|---|---|
| `SHEETNUMBER`（或`SHEET_NO`、`DWG_NO`） | 图纸的编号 |
| `SHEETTITLE`（或`TITLE`、`SHEET_TITLE`） | 图纸的标题 |
| `SHEETDESC` | 图纸的描述 |
| `PROJECTNAME`（或`PROJECT`） | 项目名称 |
| `PROJECTNUMBER`（或`PROJECT_NO`、`JOB_NO`） | 项目编号 |
| `SHEETSETNAME` | 图纸集的名称 |
| `SHEETINDEX`、`SHEETCOUNT` | “3 of 12”，以及12 |
| 自定义字段，如`CLIENT` | 你在{{ui:设置字段…}}中为其填写的内容 |

{{ui:设置字段…}}保存项目名称和编号，以及自定义字段，每行一个，格式为`名称 = 值`。

{{ui:更新图形}}会将编号、标题和字段写入图纸集中每个图形的标题栏，并按图纸集的设置重命名每张图纸的布局标签（默认为编号加标题，例如`A-101 平面图`；{{ui:设置字段…}} › {{ui:布局标签名称}}可更改此设置）。每个图形都会原位保存，并保持其自身的格式和版本。重新编号或重命名图纸后，再次运行它，标签和标题栏即会同步更新。

## 封面图纸上的图纸列表

在列表中选择封面图纸，然后选择{{ui:将图纸列表放在此图纸上}}。每张图纸的表格（编号和标题，位于其子集下方）会放在图纸的左上角。{{ui:更新图形}}和{{ui:发布为PDF}}会使其保持最新。它是一个块，名为`CC_SHEETLIST`：像任何块参照一样移动它。

## 发布图纸集

{{ui:发布为PDF}}会生成一个PDF，每张图纸为一页，按图纸集的顺序排列，每页使用各自的图纸尺寸，并为每张图纸生成一个书签（“A-101 — 平面图”）。选中某个子集时，CadCraft会询问是否只发布该子集。即使尚未更新图形，PDF中的标题栏也会根据图纸集填写；发布不会更改图形本身。PDF将以下载的方式获取。

{{ui:发布为DWG…}}会为每张图纸分别写出一个DWG（DWG 2018）：包含模型以及该张图纸，其标题栏根据图纸集填写，并以其编号和标题命名（`A-101 一层平面图.dwg`）。选择{{ui:DWG}}，或选择{{ui:DWG + PDF}}以在旁边同时生成图纸集的PDF。`publish.json`会列出每个文件及其大小和SHA-256。当图纸集所在的文件夹可写入时（CadCraft Studio，或你在浏览器中选择的文件夹），文件会放入名为`<图纸集名称> - published`的文件夹中；否则它们会打包为一个zip下载。视口的[视口类覆盖](topic:viewport-overrides)会随每个DWG一同保留。

## 打包图纸集

{{ui:打包为zip}}会将图纸集文件、它所使用的每个图形，以及这些图形所引用的内容（外部参照图形、其引用的内容，以及图片）一同打包，并保留其文件夹结构，另附一个列出每个文件的`Transmittal.txt`。不在图纸集文件夹中的链接会在其中列为缺失。链接根据图形中的路径查找，然后再根据其文件名在文件夹中任意位置查找。

## 图纸集文件

`.ccsheets`文件是可在任何文本编辑器中阅读的JSON：

```
{
  "format": "cadcraft-sheetset", "version": 1,
  "name": "Riverside Clinic",
  "properties": { "PROJECTNAME": "Riverside Clinic", "PROJECTNUMBER": "2026-014" },
  "layoutNames": "number-title",
  "sheets": [],
  "subsets": [ { "id": "plans", "name": "Plans", "sheets": [
    { "id": "p1", "file": "plans/Level 1.dwg", "layout": "A-101 Level 1 floor plan", "number": "A-101", "title": "Level 1 floor plan" }
  ] } ]
}
```

路径相对于图纸集的文件夹，文件夹之间使用`/`分隔。CadCraft在打开文件时会检查它：绝对路径、缺少文件或布局的图纸，或非纯文本的内容会被省略，并在历史记录中说明。

## 故障排除

| 现象 | 原因 | 处理方法 |
|---|---|---|
| “此文件夹在此处为只读” | 浏览器无法在该文件夹中写入 | 使用Chrome或Edge，或桌面应用程序；在此期间，{{ui:下载图纸集文件}}会保留所做的更改 |
| PDF中缺少某张图纸：“没有名为……的布局” | 该图纸在其图形中的布局已被重命名或删除 | 打开图形并检查其选项卡；删除该图纸并重新添加 |
| 标题栏保持为空 | 其属性使用了其他标记 | 将属性标记重命名为上述字段名称（使用BEDIT） |
| “已存在名为……的布局，因此未重命名该标签” | 同一图形的两张图纸会获得相同的标签名称 | 为其中一张图纸设置另一个编号或标题 |
