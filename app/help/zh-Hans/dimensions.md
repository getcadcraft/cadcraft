## 你将制作的图形

一个带尺寸的房间：总宽与总高、沿一面墙的一串标注、一面斜墙、一个弧形转角以及一个角度。

开始前，如果你的图形很大，请先阅读[设置标注尺寸](topic:dimension-settings)：默认情况下，标注文字高 2.5 个图形单位，在以毫米度量的图形中会非常小。对于下面的步骤，请先输入 `DIMSCALE`，按{{key:Enter}}，输入 `50`，然后按{{key:Enter}}。

## 标注工具在哪里

使用 CadCraft 菜单样式（CadCraft 默认使用的样式）时，标注工具位于图形上方的工具栏中，即{{ui:注释}}组：{{ui:线性}}、{{ui:对齐}}、{{ui:角度}}、{{ui:半径}}和{{ui:直径}}。该组的{{ui:更多}}菜单中有{{ui:连续标注}}和{{ui:基线标注}}。将指针悬停在按钮上，即可查看其功能。

- 使用{{ui:经典绘图}}或{{ui:功能区}}菜单样式时，打开{{ui:注释}}选项卡：这些工具位于其{{ui:标注}}面板中。{{ui:经典绘图}}还在{{ui:开始}}选项卡的{{ui:注释}}下有{{ui:线性}}。参见[菜单、按键和鼠标](topic:menus-keys-and-mouse)。
- 或者在图形下方的命令行中输入命令，并按{{key:Enter}}：`DLI`（线性）、`DAL`（对齐）、`DAN`（角度）、`DRA`（半径）、`DDI`（直径）、`DCO`（连续）、`DBA`（基线）。
- 在窄屏幕上，工具栏为一行：横向滑动即可找到{{ui:注释}}。

若要以毫米、厘米、米或千米显示长度，请参见[以毫米、厘米、米或千米计的标注](topic:dimension-settings#dimensions-in-mm-cm-m-or-km)。

## 绘制要标注的对象

1. 输入 `PL`，并按{{key:Enter}}。
2. 输入 `0,0`，并按{{key:Enter}}。
3. 输入 `@6000,0`，并按{{key:Enter}}。
4. 输入 `@1500<60`，并按{{key:Enter}}。
5. 输入 `@0,2700`，并按{{key:Enter}}。
6. 输入 `@-6750,0`，并按{{key:Enter}}。
7. 输入 `C`，并按{{key:Enter}}。轮廓闭合。
8. 输入 `C`，并按{{key:Enter}}，开始绘制圆。
9. 在房间内、远离墙体的位置单击，作为圆心。
10. 输入 `600`，并按{{key:Enter}}。这是一根柱子。
11. 单击{{ui:范围}}。

## 线性：水平或竖直

1. 输入 `DLI`，并按{{key:Enter}}。
2. 在 `Specify first extension line origin` 提示下，捕捉到左下角（端点）并单击。
3. 在 `Specify second extension line origin` 提示下，捕捉到右下角并单击。
4. 将十字光标移到房间下方。标注随之移动，且为水平方向。
5. 单击以放置尺寸线。

历史记录显示 `Dimension text = 6000`。

尺寸线的放置位置决定方向：位于下方或上方得到水平标注；位于左侧或右侧得到竖直标注。若要强制方向，请在放置之前输入 `H`（水平）、`V`（竖直）或 `R`（旋转，然后输入角度）。

:::tip
在第一个提示处不选点，直接按{{key:Enter}}，然后单击一条线、圆弧、圆或多段线线段。CadCraft 会为你取两端。
:::

## 连续：一串标注

{{cmd:DIMCONTINUE}}（{{ui:注释}} › {{ui:更多}} › {{ui:连续标注}}，或 `DCO`）从你最后绘制的线性或对齐标注继续，每个新标注都从上一个标注的终点开始。

1. 输入 `DLI`，并按{{key:Enter}}。
2. 输入 `0,0`，并按{{key:Enter}}，作为第一个原点。
3. 输入 `2000,0`，并按{{key:Enter}}，作为第二个原点。
4. 单击房间下方，以放置该标注。
5. 输入 `DCO`，并按{{key:Enter}}。
6. 输入 `4500,0`，并按{{key:Enter}}。第二个标注紧接第一个，位于同一条线上。
7. 捕捉到右下角并单击。第三个标注完成这一串。
8. 按{{key:Enter}}结束命令。

:::note
此处有意输入绝对坐标。`@` 点从你给出的上一点开始计算，而上一点是你放置上一条尺寸线的位置，而不是标注的终点。在标注串中，绝对点、捕捉，或在开启{{ui:正交}}时输入直接距离，会更加安全。
:::

输入 `U` 并按{{key:Enter}}，可在不退出命令的情况下撤销该串中的最后一个标注。

## 基线：从同一条线堆叠的标注

{{cmd:DIMBASELINE}}（{{ui:注释}} › {{ui:更多}} › {{ui:基线标注}}，或 `DBA`）测量每个新标注时都以最后一个标注的第一个原点为起点，并将每个标注向外逐步堆叠一段距离。

1. 输入 `DLI`，并按{{key:Enter}}。
2. 捕捉到左下角并单击。
3. 捕捉到左上角并单击。
4. 将十字光标移到房间左侧并单击。出现一个竖直标注。
5. 输入 `DBA`，并按{{key:Enter}}。
6. 捕捉到 60 度墙的上端（端点）并单击。出现第二个竖直标注，比第一个再向外一步。
7. 按{{key:Enter}}结束。

## 对齐：斜线的真实长度

1. 输入 `DAL`，并按{{key:Enter}}。
2. 按{{key:Enter}}以选择对象。
3. 单击 60 度墙。
4. 向外移动并单击以放置。

文字显示 1500：即沿墙测得的真实长度。

## 半径和直径

1. 输入 `DRA`，并按{{key:Enter}}。
2. 单击柱子的圆。
3. 移动十字光标。引线从圆心指向十字光标。
4. 单击以放置文字。

文字显示 `R600`。{{cmd:DIMDIAMETER}}（`DDI`）做相同的事，但以 ⌀ 符号和直径表示。

## 角度

这里的墙是一条多段线，因此通过其顶点测量角度。（若是两条独立的线，则可以改为单击这些线。）

1. 输入 `DAN`，并按{{key:Enter}}。
2. 在 `Select arc, circle or line, or Enter for a vertex` 提示下，按{{key:Enter}}。
3. 在 `Specify angle vertex` 提示下，捕捉到右下角并单击。
4. 在 `Specify first angle endpoint` 提示下，捕捉到左下角并单击。
5. 在 `Specify second angle endpoint` 提示下，捕捉到 60 度墙的上端并单击。
6. 在房间内、靠近该角的位置移动十字光标并单击。

文字显示 `120°`，即墙角的内角。若将其放在角的另一侧，标注会测量该侧的角度。在第一个提示处单击一条圆弧，可标注该圆弧所对的角度；或单击两条线，可标注它们之间的角度。

## 更改文字

要写入你自己的文字，请在放置标注之前输入 `T`，并按{{key:Enter}}，然后输入文字。在你的文字中，`<>` 代表测量值：`<> TYP.` 会得到 `6000 TYP.`。在空行上按{{key:Enter}}可保留测量值。

要更改已有的标注：

1. 单击它。
2. 在右侧面板的{{ui:文字}}中输入内容。留空则使用测量值。
3. 按{{key:Enter}}。

## 标注跟随几何图形

标注会记住它的点。拖动其夹点之一，或将其与所测量的对象一起移动、旋转或缩放，它都会重新测量。若你拉伸几何图形而不移动标注，标注不会跟随：它会保持自己的点。

## 常见错误

- **文字和箭头微小或巨大。** 设置总比例：参见[设置标注尺寸](topic:dimension-settings)。
- **“请在要测量的角内拾取一点。”** 你为角度标注单击的点位于其中一条边上。请将其移入该角内。
- **连续从错误的标注开始。** 它始终从本次会话中最后绘制的线性或对齐标注继续。请先绘制（或重新绘制）要继续的那个标注。
- **标注竖直了。** 你将其放在了侧面。放置前输入 `H`。
- **英尺和英寸。** 请先将图形的长度格式设为{{ui:建筑}}，或在{{ui:特性}}中设置标注的{{ui:格式}}：参见[标注中的英尺和英寸](topic:dimension-settings#feet-and-inches-in-dimensions)。
- **数字不是你想要的单位。** 选择{{ui:文字中的单位}}：参见[以毫米、厘米、米或千米计的标注](topic:dimension-settings#dimensions-in-mm-cm-m-or-km)。
