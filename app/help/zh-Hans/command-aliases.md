## 学习内容

如何为命令添加你自己的短名称，例如用 `LL` 代表 {{cmd:LINE}}，并全部保存在一个文本文件中。

## 添加别名

1. 打开 {{ui:视图}} › {{ui:更多}} › {{ui:编辑别名…}}，或输入 {{cmd:ALIASEDIT}} 并按 {{key:Enter}}。
2. 添加一行，写入别名、逗号，然后在星号后写入命令：

```
LL,     *LINE
```

3. 单击 {{ui:保存}}。命令行会显示正在使用的别名数量。
4. 输入 `LL` 并按 {{key:Enter}}：LINE 开始运行。

你的别名优先于 CadCraft 自带的别名。如果你的一行与内置别名同名，则以你的为准；删除该行后，内置别名即恢复。

## CadCraft 拒绝的行

输入时，编辑器会按行号列出每个问题：

- 命令不存在；
- 别名本身就是某个命令的名称（`LINE, *CIRCLE` 会隐藏 LINE）；
- 该行不是 `ALIAS, *COMMAND` 格式；
- 同一别名出现在两行中（后一行生效）。

会在计算机上启动程序的行（例如 `NOTEPAD, START, 1, *File to edit: ,`）会被跳过并附带说明：浏览器中的应用无法启动程序。

## 从其他程序导入别名

1. 在别名编辑器中，单击 {{ui:导入 .pgp…}} 并选择文件。你也可以将 `.pgp` 文件拖放到图形上。
2. 检查列出的问题（CadCraft 没有的命令会被拒绝，其余可以使用）。
3. 单击 {{ui:保存}}。

{{ui:导出 .pgp}} 会将 CadCraft 的别名和你的别名以相同格式保存为一个文件。

## 重新加载文件

输入 {{cmd:REINIT}} 并按 {{key:Enter}}，以重新应用你的别名文件。该文件保存在此浏览器中；桌面应用会将其保存在自己的文件夹中，云服务会进行同步。

## 命令选项的字母

别名用于为命令命名。若要更改回答命令选项的字母（例如 {{cmd:ARRAY}} 中用 `P` 代表极轴），请参阅 [为命令选项设置自定义字母](topic:option-letters)。

## 任意命令的键盘快捷键

别名通过输入来执行；快捷键通过按键来执行。若要为命令设置你自己的按键：

1. 单击 {{ui:视图}} › {{ui:更多}} › {{ui:键盘快捷键…}}，或输入 `KEYS` 并按 {{key:Enter}}。
2. 单击 {{ui:按键}} 框并按下按键，例如 {{key:Alt+Shift+C}}。
3. 在 {{ui:运行}} 中输入命令；如需要，可在其后输入参数：`CIRCLE`，或 `ZOOM E`。
4. 单击 {{ui:添加}}。

按键需要 {{key:Mod}} 或 {{key:Alt}} 加字母或数字，或使用未被占用的功能键（{{key:F2}}、{{key:F4}}、{{key:F5}}、{{key:F6}}、{{key:F9}}）。CadCraft、应用或浏览器已在使用的按键，以及“我的工具”按钮已使用的按键（参见 [自定义按钮](topic:my-tools)），会被拒绝，并在框中说明原因。快捷键保存在此浏览器（或桌面应用）中；{{ui:移除}} 可删除快捷键。
