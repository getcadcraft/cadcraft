## 学习内容

如何为命令添加你自己的简写，例如用`LL`代表{{cmd:LINE}}，所有内容都保存在一个文本文件中。

## 添加别名

1. 打开{{ui:视图}} › {{ui:更多}} › {{ui:编辑别名…}}，或输入{{cmd:ALIASEDIT}}并按{{key:Enter}}。
2. 添加一行，包含别名、逗号，以及在星号后的命令：

```
LL,     *LINE
```

3. 单击{{ui:保存}}。命令行会显示你的别名中有多少个正在使用。
4. 输入`LL`并按{{key:Enter}}：LINE 随即启动。

你的别名优先于 CadCraft 自带的别名。若你的某行与内置别名同名，则以你的为准；删除该行后，内置别名即会恢复。

## CadCraft 拒绝的行

输入时，编辑器会列出每个问题及其行号：

- 命令不存在；
- 别名本身就是某个命令的名称（`LINE, *CIRCLE`会隐藏 LINE）；
- 该行不是`ALIAS, *COMMAND`格式；
- 同一别名出现在两行中（以后面的为准）。

会启动你电脑上程序的行（如`NOTEPAD, START, 1, *File to edit: ,`）会被跳过并附带说明：浏览器中的应用无法启动程序。

## 从其他程序导入别名

1. 在别名编辑器中单击{{ui:导入 .pgp…}}并选择文件。也可以将`.pgp`文件拖放到图形上。
2. 检查列出的问题（CadCraft 没有的命令会被拒绝，其余内容仍可使用）。
3. 单击{{ui:保存}}。

{{ui:导出 .pgp}}会以相同格式将 CadCraft 的别名和你的别名保存为一个文件。

## 重新加载文件

输入{{cmd:REINIT}}并按{{key:Enter}}，以重新应用你的别名文件。该文件保存在此浏览器中；桌面应用会将其保存在自己的文件夹中，云服务则会进行同步。

## 为任意命令设置键盘快捷键

别名需要输入；快捷键则是按键。要为命令设置你自己的按键：

1. 单击{{ui:视图}} › {{ui:更多}} › {{ui:键盘快捷键…}}，或输入`KEYS`并按{{key:Enter}}。
2. 单击{{ui:按键}}框并按下按键，例如{{key:Alt+Shift+C}}。
3. 在{{ui:运行}}中输入命令，如需在命令后自动输入内容，也可一并写入：`CIRCLE`，或`ZOOM E`。
4. 单击{{ui:添加}}。

按键需要{{key:Mod}}或{{key:Alt}}加字母或数字，或使用一个空闲的功能键（{{key:F2}}、{{key:F4}}、{{key:F5}}、{{key:F6}}、{{key:F9}}）。CadCraft、应用程序或浏览器已在使用的按键，以及“我的工具”按钮所用的按键（参见[自定义按钮](topic:my-tools)），均会被拒绝，输入框会说明原因。快捷键保存在此浏览器（或桌面应用）中；{{ui:移除}}可删除某个快捷键。
