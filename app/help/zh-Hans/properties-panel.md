## 学习内容

如何打开特性面板，一步更改一个或一百个对象，输入精确坐标（含 Z），在任何数值字段中使用表达式和单位，以及每种对象显示的内容。

## 打开面板

面板位于右侧。要将其置于最前：

- 按{{key:Mod+1}}，或输入{{cmd:PROPERTIES}}（或 `PR`、`CH`、`MO`）。
- 双击对象（文字和多重引线会打开其文字编辑器）。

面板是可移动的面板，与其他面板一样：拖动其抓手可停靠到左侧、右侧或底部，或将其放在图形上方使其浮动（参见[排列面板并使用第二台显示器](common:arrange-panels)）。

### 收起

面板右上角的图钉按钮会开启**自动隐藏**：面板收起为右侧边缘的一条窄条，图形获得更多空间。将指针指向该窄条（或按{{key:Mod+1}}）即可在图形上方展开；移开后会再次收起。再次单击图钉可保持展开。{{cmd:PROPERTIESCLOSE}}同样会收起面板。

## 分组

特性按可折叠的分组排列：**常规**、**几何**、**文字**、**线和箭头**、**拟合**、**主单位**、**换算单位**、**公差**、**图案**、**其他**，以及块的**属性**和**库项目**。单击分组名称可折叠或展开；CadCraft 会记住你折叠了哪些分组。

拖动名称与数值之间的细线可使名称区域变宽或变窄。双击该线可将其恢复。使用键盘时，将焦点置于该线上并使用方向键。

## 更改数值

1. 单击某一行。标题显示“线”。
2. 单击{{ui:Length}}输入框。编辑时，该字段显示完整数值而非四舍五入后的数值。
3. 输入 `2500` 并按{{key:Enter}}。该线现在长度为 2500，起点和角度保持不变。

按{{key:Enter}}或单击其他位置即可应用数值；按{{key:Esc}}会恢复原值。每次更改都是一个撤销步骤。

### 表达式与单位

每个数值字段都接受的不仅仅是普通数字：

| 输入 | 得到 |
|---|---|
| `=2*45` | 90 |
| `=sqrt(2)*100` | 141.4214 |
| `1/4`, `6-1/2` | 0.25, 6.5 |
| `12'6"`, `12'-6 1/2"` | 150, 150.5（英寸，在以英尺和英寸为单位的图形中） |
| `900mm`, `3.5m`, `2ft` | 转换为图形单位 |
| `45d30'`, `45°30'15"` | 45.5°, 45.5042°（角度字段） |
| `0.5r`, `100g` | 弧度和百分度，换算为度 |

带单位的长度要求图形已设置单位：请先在{{ui:New objects}}下设置{{ui:Units}}（不选择任何对象时）。无效输入会被拒绝，面板下方显示提示，且不会更改任何内容；它绝不会被保存为 0。函数包括：sin, cos, tan, asin, acos, atan, atan2, sqrt, pow, exp, ln, log, abs, round, ceil, floor, min, max, if；角度以度计。

## 同时更改多个对象

1. 选择多个对象，例如 8 条线和 4 个标注。
2. 标题显示“12 个对象”，顶部列表提供**全部 (12)**、**线 (8)** 和**标注 (4)**。
3. **全部**显示每个对象拥有的内容（图层、颜色、线型等）。选择**标注 (4)**可查看标注设置。
4. 更改数值，例如将{{ui:Decimals}}改为 `1`。

四个标注全部更改，且只需一个撤销步骤。显示**各不相同**的字段表示对象之间存在差异；输入一个值即会将其设置到所有对象。位于锁定图层上的对象保持不变，提示会说明数量。

## 所选对象的合计

选择多个对象时，面板顶部的{{ui:Totals}}分组会显示：

- **对象**：每种类型的数量，例如“8 条线、2 条多段线、1 个圆”。
- **总长度**：将线、圆弧和多段线相加（样条曲线也计入），并显示对象的数量。
- **总面积**：将闭合对象相加：圆、完整椭圆、闭合多段线和填充（填充的孔洞会被减去）。

它们以图形的长度格式显示（若图形使用英尺和英寸，则以英尺和英寸显示；面积则以平方英寸和平方英尺显示）。选中对象时，状态栏始终显示相同的长度和面积；若要关闭，请选择{{ui:Settings}} › {{ui:CadCraft}} › {{ui:Length and area of the selection}} › {{ui:Hidden}}。对于单个对象，{{ui:Geometry}}仍会像以前一样显示其自身的长度和面积。

## 坐标

每个点都显示 **X**、**Y** 和 **Z**：直线的起点和终点、圆心、插入点、文字位置、当前多段线顶点。直线还显示 **X 增量**、**Y 增量** 和 **Z 增量**（只读）。多段线和填充具有**高程**（整个对象使用一个 Z 值）。

点名称旁边的十字按钮可让你在图形中拾取该点：单击它，然后单击新位置（捕捉可用）。数值为世界坐标。

## 常规

| 字段 | 说明 |
|---|---|
| {{ui:Layer}}、{{ui:Color}}、{{ui:Linetype}}、{{ui:Linetype scale}}、{{ui:Lineweight}} | 与图层面板中相同；{{ui:By layer}}随图层变化 |
| {{ui:Transparency}} | 随层、随块，或 0 至 90% |
| {{ui:Thickness}} | 直线、圆、圆弧、多段线、点和文字在 Z 方向延伸的距离 |
| {{ui:Material}} | 随层、随块、全局，或图形引入的名称 |
| {{ui:Plot style}} | 只读：图形按颜色打印，通过布局的[打印样式表](topic:plot-pdf#plot-style-tables)进行 |
| {{ui:Hyperlink}} | 与对象一同保存的网址 |

## 每种类型显示的内容

| 所选 | 可更改的内容 |
|---|---|
| 直线 | 起点和终点的 X、Y、Z；长度；角度 |
| 圆 | 圆心；半径；直径；周长；面积（每项都会设置半径） |
| 圆弧 | 圆心；半径；起始和终止角度；总角度；弦长（显示弧长和面积） |
| 椭圆 | 圆心；长半径和短半径；半径比；长轴角度；起始和终止角度 |
| 多段线 | 顶点浏览器（见下）；全局宽度；高程；闭合；闭合时的面积（以其中心缩放） |
| 文字 | 内容；样式；对齐；高度；旋转；宽度系数；倾斜角度；定义宽度；行距；注释性；位置 |
| 块参照 | 插入点；旋转；X、Y、Z 缩放及统一缩放；属性值 |
| 填充 | 图案；比例；角度；原点；关联；孤岛检测；背景颜色；高程 |
| 标注 | 见下 |
| 多重引线 | 文字；高度；宽度；文字侧；箭头大小；着陆距离；箭头点 |
| 视口 | 比例；图纸上的中心和尺寸；模型中的视图中心；开；锁定显示 |

### 多段线顶点

{{ui:Current vertex}}显示其下方字段所属的顶点。使用箭头按钮，或输入编号，即可移动到另一个顶点；顶点数量没有上限。每个顶点都有 X、Y、起始和终止线段宽度，以及从该点开始的线段的凸度（0 表示直线）。

## 标注

标注显示其**标注样式**、所测量的内容、其点，以及所有设置：

- **线和箭头：** 每端的箭头、箭头大小、短划大小、标注线和尺寸界线的颜色与线宽、隐藏任一半或任一尺寸界线、尺寸界线偏移和延伸。
- **文字：** 替代文字（留空则使用测量值；在你自己的文字中，`<>` 代表该值）、样式、颜色、高度、偏移、竖直和水平位置、始终水平、旋转、背景填充。
- **拟合：** 总比例、基线间距、空间不足时移动的内容，以及文字移动方式。
- **主单位：** 格式、小数位数、舍入、前缀、后缀、测量比例、小数分隔符、抑制前导和尾随零；对于角度，为角度格式和小数位数。
- **换算单位：** 开或关、格式、小数位数、乘数（25.4 可将英寸转换为毫米）、舍入、前缀和后缀。
- **公差：** 无、对称、偏差、极限或基本，并设置上下限值、小数位数、高度和位置。

在已打开的标注上更改其中任何设置，都会丢弃其他程序生成的标注图形，CadCraft 会重新绘制。

:::note
在线性和对齐标注上会绘制水平文字位置（位于第一或第二尺寸界线旁）以及线下文字；在其他标注上，这些内容会被保留并保存，但尚未绘制。拟合选项会被保留和保存，但尚未绘制：CadCraft 按自身规则放置文字（位于线上方，空间不足时放在外部）。
:::

## 未选择任何对象

未选择对象时，面板显示：

- **新对象：** 新对象将获得的图层、颜色、线型、线宽和文字高度；图形的单位和长度格式；当前图层的线型和线宽；新标注的尺寸。在布局上，首先显示布局名称、图纸和方向。
- **视图：** 屏幕所示内容的中心、高度和宽度。输入一个值即可将视图移至该处。
- **其他：** UCS 图标的开或关、UCS（始终为世界坐标：CadCraft 尚未支持用户坐标系）以及注释比例。

## 常见错误

- **在字段中输入后没有任何变化。** 按{{key:Enter}}或单击其他位置以应用。红色字段和提示表示该输入被拒绝。
- **带单位的长度被拒绝。** 图形没有设置单位。请在不选择任何对象时设置{{ui:Units}}。
- **只显示图层和颜色。** 选择了多种对象且选择了**全部**。请在顶部列表中选择一种对象类型。
- **部分对象未更改。** 它们位于锁定图层上。请在图层面板中解锁该图层。
- **键入的字母进入了字段。** 字段有光标时，按键会输入到该字段中。请按{{key:Enter}}或{{key:Esc}}，然后输入命令。
