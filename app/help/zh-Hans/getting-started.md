CadCraft 是一款二维绘图应用。你可以绘制和编辑直线、圆弧、多段线、文字、标注和块，设置带标题栏和视口的图纸，并将其打印为PDF。它可以打开DWG和DXF图形，并保存为DWG或DXF。

它在网页浏览器中运行，无需安装：网站给你地址，整个应用就加载到页面中。你的图形从自己的电脑打开，也保存回电脑。**不会上传任何内容。**

如果你以前画过图，请在读完本页后阅读[从其他绘图软件转来](topic:coming-from)。大多数习惯可以沿用，少数不同之处都列在那里。

## 想要有人带着做？

输入 `TOUR`（或点击起始卡片上的{{ui:进行导览}}，或{{ui:设置}} › {{ui:CadCraft}} › {{ui:再次进行导览}}）。图形上方的方框中有六个简短步骤：绘制一条直线和一个圆，移动它，修剪它，删除一些东西并为它标注。每一步在你完成时结束，你可以跳过某一步或整个导览。它只在第一次自动开始。[速查表](topic:cheat-sheet)列出你最常用的40个命令，[命令对照表](topic:command-map)列出所有命令。

## 你需要什么

- 在 Mac、Windows 或 Linux 电脑上使用较新的 Chrome、Edge、Firefox 或 Safari。参见[浏览器和平台](common:browsers)。
- 带滚轮的鼠标最方便。触控板也可以使用；参见[鼠标、触控板和触摸](topic:mouse-trackpad-touch)。
- 键盘。与大多数绘图程序一样，CadCraft 通过输入命令来操作。

## 一段话讲清思路

你输入一个命令（或点击它的按钮），底部的命令行会逐个向你提问：“指定第一个点”、“指定下一个点”。你通过在图形中单击或输入数值来回答每个问题，然后按{{key:Enter}}。按{{key:Esc}}取消。整个交互模型就是这样；其余都是细节。

## 你的第一张图形

你将用直线绘制一个 4000 乘 3000 的矩形，在中间放一个圆，并保存文件。

1. 打开 CadCraft。底部的命令行显示 `命令：`，绘图区显示一张简短的“开始绘图”卡片。
2. 输入 `L` 并按{{key:Enter}}。无需先点击命令行：在任何位置输入都会进入命令行。
3. 提示变为 `指定第一个点：`。输入 `0,0` 并按{{key:Enter}}。
4. 输入 `@4000,0` 并按{{key:Enter}}。出现一条向右延伸的直线。`@` 表示“相对于上一个点”。
5. 输入 `@0,3000` 并按{{key:Enter}}。
6. 输入 `@-4000,0` 并按{{key:Enter}}。
7. 输入 `C` 并按{{key:Enter}}。`C` 是闭合选项：最后一条直线回到第一个点，命令结束。
8. 在工具栏的“视图”组中单击{{ui:范围}}。矩形充满屏幕。

现在你应该看到四条直线构成一个矩形，命令行上方的历史记录列出了你输入的内容。

9. 输入 `C` 并按{{key:Enter}}，开始圆命令。
10. 输入 `2000,1500` 并按{{key:Enter}}，指定圆心。
11. 输入 `500` 并按{{key:Enter}}，指定半径。

矩形中间出现一个圆。

12. 按{{key:Mod+S}}，或单击“文件”组中的{{ui:保存}}。

浏览器会将 `Drawing1.dwg` 下载到你常用的下载文件夹，历史记录显示已将副本保存为DWG。该文件可以再次在 CadCraft 中打开，也能在大多数其他CAD程序中打开。（如果你之前在此浏览器中在{{ui:另存为}}里选择了DXF，新图形会改为保存为 `Drawing1.dxf`。）

:::tip
在空命令行上按{{key:Enter}}可重复上一个命令。如果你愿意，也可以按{{key:Space}}代替{{key:Enter}}：在文字之外，它的作用相同。
:::

## 打开现有图形

1. 按{{key:Mod+O}}，或单击{{ui:打开}}。
2. 在文件选择器中选择一个 `.dwg` 或 `.dxf` 文件。

你也可以从{{pick:mac=访达|windows=文件资源管理器|linux=文件管理器}}中拖动DWG或DXF文件，放到绘图区上。文件在页面中读取，绝不会离开你的电脑。

关于哪些内容被保留、哪些被转换，参见[文件：可打开和可保存的内容](topic:files)。

## 保存：会发生什么

在浏览器中保存与桌面程序不同：

- {{ui:保存}}总是**下载一份新副本**。它不会覆盖你打开的文件。如果下载文件夹中已有同名文件，浏览器通常会加上编号，例如 `Drawing1 (1).dwg`。
- {{ui:保存}}使用图形的格式：打开的是DWG就保存为DWG，打开的是DXF就保存为DXF。要自行选择，请按{{key:Mod+Shift+S}}或单击{{ui:另存为}}，然后选择{{ui:DWG}}（及其版本）、{{ui:DXF R12}}或{{ui:DXF 2000}}。参见[保存](topic:files#saving)。
- 你打开的文件从不会被修改。
- 打开另一个文件，或{{ui:新建}}，会将其放在绘图区上方自己的选项卡中，因此你已打开的内容都不会被关闭。如果你关闭某个图形的选项卡，或带着未保存的更改离开页面，CadCraft 会先询问：{{ui:先保存副本}}、放弃或{{ui:取消}}。关闭浏览器标签页时则显示浏览器自己的“要离开此网站吗？”提示。

云端保存尚不可用。你的文件去向以及为何保持私密，参见[你的文件和隐私](common:your-files)。

- [CadCraft 界面](topic:workspace)说明每个栏和面板的名称。
