## 学习内容

有两种快速更改对象而无需命令的方法：拖动其**夹点**，或在右侧的**特性**面板中输入新值。

## 夹点

选择对象（一次最多 200 个）且未运行任何命令时，对象上会出现小方块。这些方块就是夹点：

| 对象 | 夹点 |
|---|---|
| 直线 | 两端，以及中点（移动整条直线） |
| 圆 | 圆心（移动圆）以及圆上的四个点（更改半径） |
| 圆弧 | 圆心以及两端（更改起点和终点） |
| 多段线 | 每个顶点 |
| 文字、点、块参照 | 插入点 |
| 椭圆 | 圆心 |
| 标注 | 其定义点和尺寸线位置 |
| 视口 | 圆心（移动）以及四个角点（调整大小） |

### 移动夹点

1. 绘制一条直线并单击它。出现三个夹点。
2. 单击某一端的夹点。状态栏显示“单击此夹点的新位置（按 Esc 取消）。捕捉和正交设置同样生效。”
3. 移动十字光标，预览会随之显示。
4. 单击新位置，或捕捉到其他对象上的某个点后单击。

直线的该端点随之移动，其余部分保持不动。也可以在夹点上按下并拖动，然后在目标位置松开。

:::note
无法为夹点输入坐标。若需要精确的位置，请捕捉到某一点，或在特性面板中输入数值。
:::

按{{key:Esc}}或右键单击可取消夹点移动。

## 特性

右侧面板显示所选对象的特性。

1. 单击一条直线。面板标题显示“直线”。
2. 在{{ui:长度}}中单击，输入`2500`，然后按{{key:Enter}}。

该直线的长度现在恰好为2500，起点和角度保持不变。按{{key:Enter}}或单击其他位置即可应用数值；按{{key:Esc}}则恢复原值。每次更改为一个撤销步骤，同时更改多个对象时也是如此。

字段可输入表达式（`=2*45`）以及带单位的长度（`3'6"`、`900mm`），每个点都有 X、Y 和 Z，并且可以同时更改多个对象。以上全部内容见[特性面板](topic:properties-panel)。

## 常见错误

- **没有出现夹点。** 正在运行命令（请按{{key:Esc}}），或选中的对象超过 200 个，或对象位于已锁定的图层上。
- **夹点位置不对。** 捕捉功能捕获了该点。单击时按住{{key:Shift}}可忽略捕捉。
- **在特性中输入后没有变化。** 按{{key:Enter}}或单击其他位置以应用。无效输入（零或负的长度和半径、非数值的文字）会使字段变红，并说明原因。
- **输入的字母进入了特性字段。** 字段有光标时，按键会输入到该字段中。按{{key:Enter}}或{{key:Esc}}后，再输入命令。
