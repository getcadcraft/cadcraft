## 点

提示要求输入点时，输入以下任一形式，然后按{{key:Enter}}：

| 输入 | 含义 | 示例 |
|---|---|---|
| `x,y` | 绝对坐标：从原点 0,0 量取 | `2500,1200` |
| `#x,y` | 同样为绝对坐标（为习惯而接受） | `#2500,1200` |
| `@dx,dy` | 相对坐标：从上一点向右和向上量取 | `@600,0` |
| `@d<a` | 相对极坐标：从上一点量取距离和角度 | `@1500<45` |
| `d<a` | 绝对极坐标：从原点量取距离和角度 | `3000<90` |
| 单个数字 | 直接距离：从基点沿十字光标方向量取该距离 | `1200` |
| `*x,y`、`@*dx,dy` | 设置了 UCS 时的世界坐标 | `*0,0` |

设置了 UCS（{{cmd:UCS}}）时，`x,y`、`@dx,dy` 以及 `d<a` 中的角度沿 UCS 轴量取。参见[转动视图并使用自定义坐标](topic:ucs-and-turned-view)。

也可以在绘图区单击；对象捕捉和正交对单击同样适用。

规则：

- 逗号用于分隔 X 与 Y。小数使用句点：`1250.75,300`。
- 负值向左和向下：`@-600,0`。
- 不要输入空格：{{key:Space}}会提交输入，效果与{{key:Enter}}相同。
- 数字可使用指数：`1e3` 即 1000。
- 不输入单位，也不使用英尺和英寸的记法。请以图形单位输入纯数字。

## 上一点

`@` 从你在**任何点提示中给出的上一点**开始计算，适用于任何命令：单击、捕捉或输入的点都算在内。它会在命令之间保留，因此你可以从上一条线的终点起，以 `@0,500` 开始新的线。在你给出任何点之前，`@` 从 0,0 开始计算。

以下情况需要注意：

- 在{{cmd:COPY}}中，第一次复制后，上一点就是该副本的点。连续两次输入 `@600,0`，会将副本放在距原对象 600 和 1200 的位置。
- 放置标注后，上一点是你放置尺寸线的位置，而不是标注的端点。

存疑时，请使用绝对坐标、捕捉或直接距离。

## 直接距离输入

单独的数字表示从命令的**基点**（橡皮筋线起始的点）沿十字光标方向量取的距离：

1. 将十字光标移向你想要的方向。
2. 输入距离，并按{{key:Enter}}。

开启{{ui:正交}}后，方向会锁定为水平或竖直，这使其成为绘制直角墙体最快的方法。如果没有基点，或十字光标恰好位于基点上，该数字会被拒绝，并提示“需要点或选项关键字。”

## 角度

- 以度为单位，直接输入数字：`30`、`-45`、`112.5`。
- 从正 X 方向（指向右）逆时针量取：0 为右，90 为上，180 为左，270 或 -90 为下。
- 在需要输入角度的地方（旋转、文字角度），也可以单击：角度从基点量至单击点。若尚无基点，第一次单击会设定基点，提示随后要求第二点。

## 距离

在需要输入距离的地方（半径、偏移、文字高度、比例系数）：

- 输入正数（在英尺和英寸图形中也可输入 `12'6"` 或 `6-1/2`：参见[英尺和英寸](topic:units-papers-scales#feet-and-inches-and-fractions)），或
- 单击一点：距离为命令基点至该点的距离，或
- 没有基点时，单击两点：提示变为 `Specify second point`。

提示“需要一个正数或两个点。”表示输入的值不是数字，或为负数。

## 输入值中的算术

在任何需要输入长度、坐标、角度或数字的地方（命令行、动态输入、{{ui:特性}}框和对话框），你都可以用 `+`、`-`、`*`、`/` 和括号输入计算式，无需事先算出结果：

| 输入 | 结果 |
|---|---|
| `4+7/16` | 4.4375 |
| `12'6"+3/4"` | 12'-6 3/4"（在英尺和英寸图形中） |
| `(24'-0")/3` | 8'-0" |
| `2*450mm` | 900 mm，以图形单位计（在设置了单位时） |
| `@4+7/16,0` | 距上一点右侧 4.4375 处的点 |
| `360/7` | 51.43 度的角度 |

- 写入长度中的减号仍属于该长度的一部分：`4-7/16` 为 4 7/16，`24'-6"` 为 24 英尺 6 英寸。若要在英尺符号后做减法，请先完成长度输入，即 `24'-0"-6"`，或将计算放在括号中，并在减号两侧留空格，即 `(24' - 6")`（在括号内，空格就是空格；在括号外，空格会提交输入）。
- 普通数字与长度相加时，按图形单位计算；用一个数字乘以或除以长度，会缩放该长度。两个长度相乘得到面积，因此 `2'*3'` 会被拒绝。
- `abs`、`round`、`ceil` 和 `floor` 也可以使用：`round(10/3)`。
- 无法读取的计算会被拒绝，并指出出错之处，例如“计算过早结束（第 3 个字符）：缺少一个值。” 绝不会把任何内容当作 0 处理。{{cmd:CAL}} 会输出计算结果。

## 动态输入

{{ui:动态}}（{{key:F12}}，位于状态栏中）会在命令要求输入点时，在十字光标旁显示数值。

- 尚无基点时（直线的第一点），两个字段为 **X** 和 **Y**。
- 此后，字段为相对于上一点的**距离**和**角度**。

输入仍进入命令行；十字光标旁的字段会显示输入内容，橡皮筋线随之变化。

1. 输入一个数值：它进入高亮的字段。
2. 按{{key:Tab}}（或在 X 之后输入逗号）。该值被锁定（以粗体显示），下一个字段高亮。锁定的距离会在你用鼠标瞄准时保持橡皮筋线的长度。
3. 输入第二个值，或只是瞄准，然后按{{key:Enter}}。`50`、{{key:Tab}}、`90`、{{key:Enter}} 会从上一点向上画出 50。

在输入一个值后不按{{key:Tab}}而直接按{{key:Enter}}，其效果与直接距离输入相同。英尺和英寸在字段中同样可用（`12'6"`）。距离和角度提示（圆的半径、旋转）同样会在十字光标旁显示其值。

## 选项和默认值

- 选项显示在方括号中。输入选项的大写字母（`D` 代表 `[Diameter]`，`CL` 代表 `CLose`），然后按{{key:Enter}}。词首更长的部分同样有效（`DIA`）。
- 默认值显示在尖括号中，例如 `<500>`。按{{key:Enter}}或右键单击即可使用该默认值。

## 其他键盘布局和小键盘

命令名称、简称和选项字母都是拉丁字母。当你使用希腊字母、西里尔字母（俄语、乌克兰语、白俄罗斯语、塞尔维亚语、马其顿语、保加利亚语）、希伯来语、阿拉伯语、波斯语、泰语或韩语布局时，无需切换布局：当你输入的词按原样不是命令、简称或选项时，CadCraft 会按你所按的键来识别。标有 `L` 的拉丁键盘按键仍然启动 `LINE`，而 `C` 键仍然对应 `Close`，无论该布局在该键上标注的是什么字母。命令行上方的匹配命令列表遵循同样的规则。在命令要求输入文字的地方（{{cmd:TEXT}} 的内容、名称）输入的文字，绝不会被更改。

在小键盘的小数点键输出逗号的布局上，该键会在命令行和数字框中输入一个点，因此可以用小键盘输入 `12.5`。主键盘上的逗号键仍用于分隔 `x,y`。

这两项都可以在{{ui:设置}}中关闭：{{ui:Commands on a non-Latin keyboard layout}} 和 {{ui:Keypad decimal key}}。

## 坐标显示

状态栏显示十字光标的 X 和 Y（若设置了 UCS，则显示 UCS 中的坐标），已考虑捕捉和正交。命令设有基点时，状态栏还会加上 `Δ`，显示距该点的距离和角度，例如 `Δ 1500 < 30°`：即你可以输入 `@1500<30` 的数值。

使用{{cmd:ID}}输出一点的坐标，使用{{cmd:DIST}}测量两点之间的距离。
