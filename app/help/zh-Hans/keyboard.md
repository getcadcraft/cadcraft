快捷键按当前计算机的显示方式列出。在 Mac 上，所有{{key:Mod}}快捷键均使用 Command 键，Control 键同样有效。按键的写法以及如何在 Mac 上使用 F 键，见[按键、鼠标和触控板](common:keys)。

## 输入命令

| 按键 | 作用 |
|---|---|
| 任意字母、数字或符号 | 输入到命令行，无论指针位于何处，除非面板中有输入框获得了光标 |
| {{key:Enter}} | 发送已输入的内容。在空白提示下：重复上一条命令，结束命令，完成选择，或接受 `<…>` 中的默认值 |
| {{key:Space}} | 与{{key:Enter}}相同，但在 CadCraft 要求输入文字（文字、块名、标注文字）时，则输入空格 |
| {{key:Esc}} | 取消命令。未运行命令时：取消夹点移动或选择框，然后清除选择 |
| {{key:Tab}} | 接受命令行右侧显示的建议命令。未输入任何内容且指针位于重叠对象上时：高亮显示该处的下一个对象（单击即可选中） |
| {{key:Up}} {{key:Down}} | 逐条浏览此前输入的行（最近 100 条） |

## 绘图与编辑

| 按键 | 作用 |
|---|---|
| {{key:Mod+Z}} | 撤销上一个命令 |
| {{key:Mod+Y}}或{{key:Mod+Shift+Z}} | 重做 |
| {{key:Mod+A}} | 选择当前打开的标签页上所有可编辑的对象（{{cmd:SELECTALL}}）。若命令行中已输入内容，则改为选择该文字 |
| {{key:Delete}} | 删除所选对象（{{cmd:ERASE}}），但命令行中已输入内容时除外 |
| {{key:Backspace}} | 命令行没有光标时删除所选对象；在命令行中则删除已输入的内容 |
| {{key:Esc}} | 未运行命令时：清除选择（{{cmd:DESELECT}}） |
| {{key:Mod+S}} | 以图形的格式（DWG 或 DXF）保存副本 |
| {{key:Mod+Shift+S}} | 另存为：选择 DWG 或 DXF，然后保存副本 |
| {{key:Mod+O}} | 打开 DWG 或 DXF |
| {{key:Mod+P}} | 打印为 PDF |

命令运行时，撤销、重做、全选和打印均不起作用：请先按{{key:Esc}}。

## 复制、剪切和粘贴

| 按键 | 作用 |
|---|---|
| {{key:Mod+C}} | 将所选内容复制到剪贴板（{{cmd:COPYCLIP}}）。未选中任何内容时：CadCraft 会要求选择对象 |
| {{key:Mod+X}} | 剪切：复制所选内容，然后将其删除（{{cmd:CUTCLIP}}） |
| {{key:Mod+V}} | 粘贴：副本跟随光标移动；单击或输入一个点即可放置（{{cmd:PASTECLIP}}） |
| {{key:Mod+Shift+V}} | 原位粘贴：粘贴到其复制时的坐标位置（{{cmd:PASTEORIG}}） |
| {{key:Mod+D}} | 创建副本：所选内容的副本随指针移动；单击放置，按{{key:Esc}}则不留下任何内容（{{cmd:DUPLICATE}}） |

相同的操作也位于工具栏的{{ui:编辑}}组（{{ui:复制}}、{{ui:粘贴}}）及其{{ui:更多}}菜单中。其他命令运行期间，请先完成该命令或按{{key:Esc}}；副本跟随光标时再次按{{key:Mod+V}}或{{key:Mod+D}}会重新开始。若命令行中已输入内容，或命令正在要求输入文字，这些按键将改为复制、剪切和粘贴该文字。请参阅[复制、粘贴和创建副本](topic:copy-paste)。

## 切换开关

| 按键 | 切换项 | 状态栏按钮 |
|---|---|---|
| {{key:F3}} | 对象捕捉开或关 | {{ui:捕捉}} |
| {{key:F7}} | 栅格开或关 | {{ui:栅格}} |
| {{key:F8}} | 正交开或关 | {{ui:正交}} |
| {{key:F10}} | 极轴追踪开或关 | {{ui:极轴}} |
| {{key:F11}} | 对象捕捉追踪开或关 | {{ui:追踪}} |
| {{key:F12}} | 动态输入开或关 | {{ui:动态}} |

:::mac
在 Mac 上，F3、F7 和 F8 通常用于 Mission Control 和媒体键。请按住 **fn** 再按这些键，或在系统设置中开启标准功能键，具体见[按键、鼠标和触控板](common:keys)。状态栏按钮始终有效。
:::

:::firefox
Firefox 中按 F7 时可能会提示开启插入符浏览。请选择**否**；若仍不断提示，请使用{{ui:栅格}}按钮。
:::

## 帮助

| 按键 | 作用 |
|---|---|
| {{key:F1}} | 在图形旁边打开或关闭本帮助。命令运行时同样有效，且不会传递到命令行。 |
| {{key:Esc}} | 光标位于帮助面板中时：清除搜索内容，或关闭面板 |

顶部栏中的{{ui:帮助}}按钮与{{key:F1}}作用相同。在帮助的搜索框中输入时，内容不会传递到命令行。在图形上单击即可将按键交还给 CadCraft；面板仍保持在图形旁边打开。

:::mac
在 Mac 键盘上，按住 **fn** 并按 F1，或单击{{ui:帮助}}。
:::

## 屏幕

| 按键 | 作用 |
|---|---|
| {{key:Ctrl+Shift+F}} | 依次切换普通、全屏以及隐藏工具栏的全屏模式。所有计算机（包括 Mac）均使用 Control 键。 |
| {{key:Left}} {{key:Right}} | 图形下方的选项卡获得焦点时：切换到上一个或下一个选项卡 |

全屏时，浏览器可能会用第一次按下的{{key:Esc}}退出全屏。再按一次{{key:Esc}}可取消命令。

## 对话框

| 按键 | 作用 |
|---|---|
| {{key:Esc}} | 关闭对话框（{{ui:打印为PDF}}，或“未保存的更改”之类的询问，此时表示{{ui:取消}}） |
| {{key:Tab}} | 在对话框的设置项和按钮之间移动 |

对话框打开时，图形的快捷键不可用。

## 面板字段

在右侧或左侧面板的输入框中：

| 按键 | 作用 |
|---|---|
| {{key:Enter}} | 应用数值并离开输入框 |
| {{key:Esc}} | 恢复原数值并离开输入框 |
| {{key:Tab}} | 应用数值并移至下一个输入框 |

输入框有光标时，字母会输入到该框中，而不是命令行。

## 鼠标

| 操作 | 作用 |
|---|---|
| 单击 | 命令要求指定点时，指定一个点；要求选择对象时，选择一个对象；否则选择对象或夹点 |
| Shift+单击 | 从选择集中移除已选对象（若在[设置](topic:settings)中将{{ui:点击对象}}设为{{ui:替换选择}}，则为添加该对象）。在指定点时：该次单击忽略对象捕捉 |
| 在空白处单击，然后再次单击 | 选择框：从左至右为窗口选择，从右至左为窗交选择 |
| 在空白处拖动 | 套索：向右先移动为窗口选择，向左先移动为窗交选择；拖动时按{{key:Space}}可在窗口、窗交和栏选之间切换；按{{key:Esc}}放弃（LASSOMODE 0 或设置中可将其改回矩形选择框） |
| 在 TRIM 或 EXTEND 中拖过多个对象 | 修剪（或延伸）路径经过的每个对象；按住{{key:Shift}}则执行相反的操作 |
| 拖动夹点 | 移动夹点（或单击夹点，然后单击放置位置） |
| 双击文字 | 选中文字，并将光标置于右侧面板的{{ui:文字}}框中 |
| 右键单击 | 相当于{{key:Enter}}。在夹点移动或选择框期间：取消该操作 |
| 右键拖动 | 平移 |
| 滚轮 | 以十字光标为中心缩放 |
| 拖动滚轮（中键） | 平移 |
| 双击滚轮 | 缩放至整个图形（范围） |
| 将 DWG 或 DXF 拖放到图形上 | 打开该文件 |

在触控板或触摸屏上的操作，请参阅[鼠标、触控板和触摸](topic:mouse-trackpad-touch)。

## 浏览器保留的按键

{{key:Mod+N}}、{{key:Mod+W}}和{{key:Mod+T}}始终归浏览器所有。CadCraft 不使用这些按键：如需新建图形，请使用{{ui:新建}}或输入`NEW`。CadCraft 的剪贴板是独立的：{{key:Mod+C}}和{{key:Mod+V}}只在 CadCraft 图形和标签页之间复制对象，不会与其他程序互通。

:::mac
若{{key:Mod+Y}}打开了浏览器的历史记录而非重做，请使用{{key:Mod+Shift+Z}}或{{ui:重做}}按钮。
:::

## 移动命令的位置

移动是命令`MOVE`（按键{{key:M}}）：先选择对象，再指定基点和第二点，或输入距离。`ALIGN`和`DISTRIBUTE`也在此处。BimCraft 对建筑构件使用相同的命令名称执行相同的操作，但其{{key:M}}为测量：其移动为{{key:Shift+M}}。
