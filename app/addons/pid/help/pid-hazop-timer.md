A study aid for the team. It records the time; it does not decide that a node is finished. No representation.

Open **HAZOP session timer** in the add-on panel. It lists the nodes you drew with `PIDNODE`, one row each, with its minutes.

1. Type the session total and press **Share the minutes out**. Nodes with more guide word and parameter pairs still to cover get more minutes (at least 5 each); with nothing covered yet the minutes are even. Change any node with **+5 min**.
2. Press **Start** on the node the team is discussing. The big clock counts down; past zero it shows the over-time in red and keeps counting. Nothing is stopped for you.
3. **Pause** and **Resume** hold the clock, **Done, next node** marks the node done and starts the next one that is not done, and **Reset all** clears the times.
4. **Times (CSV)** saves node, planned, used and over minutes.

The times are kept with the add-on's storage, so a closed page keeps them. A node you draw or rename later joins the list without losing the time already used.
