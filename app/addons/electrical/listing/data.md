**What ships.** The symbol library (about 30 schematic symbols and a set of installation symbols), each drawn by us; the frame and title block for A3 and A4 sheets; the cable-list, terminal-plan, sheet-list and parts-list layouts; and a sample project (three schematic sheets, four report sheets).

**Planning loads.** Each installation symbol carries a planning load in watts, for example 200 W for a socket outlet, 400 W for a double one, 60 W for a luminaire, 7,400 W for an EV charging point. These are round planning figures we chose, not values from a standard or a maker's data; change them per symbol in Properties.

**What you supply.** Device tags, circuit numbers, breaker ratings, cable types, the routes you draw, board voltages, and the maker, part number and order number of each device. The add-on never looks any of these up.
