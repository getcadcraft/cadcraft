# CadCraft for Linux

CadCraft comes inside [CadCraft Studio](https://github.com/getcadcraft/studio) (all eight apps in one install) from 0.5 on; there are no separate CadCraft installers any more. Get Studio 0.6 from the [download page](https://getcadcraft.com/download#studio) or its [GitHub release](https://github.com/getcadcraft/studio/releases/tag/studio-v0.6.0). Studio ships as a `.deb` and an AppImage.

## File types

- Opens by default: `.ccsheets` (CadCraft sheet set)
- Opens by default unless another program already does: `.dwg` (DWG drawing), `.dxf` (DXF drawing)
- Listed under "Open with": `.pln` (PLN project), `.pla` (PLA archive), `.tpl` (TPL template), `.bpn` (BPN backup)
